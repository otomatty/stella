# Web 本体の変更履歴

`package.json` の `version` を上げたら、`## [版] - YYYY-MM-DD` の節を一番上に足します。
受講者・管理者から見える変化を `### 見出し` で分けると、Google Chat のスレッドに 1 項目ずつ、書いた文章のまま載ります。箇条書きだけでも書けます。
スクリーンショットを添えるには、項目内に `![説明](shot:名前)` だけの行を書きます。箇条書きではその行を字下げします。名前は小文字の英数字と区切りのハイフンで書き、画像は 1 項目につき 2 枚までです。
GitHub Release の本文には AI の要約を載せ、全文は折りたたみに残します。

## [1.1.1] - 2026-11-25

- 動画を見終えて「次の教材へ」を押すと、次の問題を飛ばしてその先の教材へ進んでしまう不具合を直しました。まだ解けない問題も飛ばさずに表示し、先に終える教材へのボタンを出します。
- 動画を見終えた直後から、次の問題に取り組めるようにしました。これまでは、進み具合がサーバーに届くまで問題が解けない状態のままでした。
- 問題が解けるようになる条件をそろえました。ステージの一覧でその問題より前にある動画・スライドと問題をすべて終えると解けます。提出済みの問題はいつでも開けます。
- 最後の問題を提出して課題が合格したときに、ステージの修了をすぐ判定するようにしました。

## [1.1.0] - 2026-11-24

- 問題つきの課題に、次に取り組む問題や動画、全問の提出状況が分かる一覧を追加しました。
- 問題のレッスンで、問題文・例・編集するファイルと、復習に使える動画やまとめを確認できるようにしました。

## [1.0.0] - 2026-11-22

- この版から変更履歴を記録します。

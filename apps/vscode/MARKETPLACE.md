# STELLA

研修 LMS「STELLA」の課題を VS Code で進めるための拡張機能です。STELLA の受講者向けで、STELLA のアカウントが必要です。

## 使い方

1. ブラウザーで STELLA にログインします。
2. 課題の「課題に取り組む」または「VS Code で開く」を押します。
3. VS Code が開き、課題文が表示されます。この拡張機能が入っていなければ、VS Code がインストールするか尋ねます。インストールすると、そのまま課題文が開きます。

初めて課題を開くと、ホームフォルダーに `web-training` (学習フォルダー) を作り、課題をその中に準備します。場所はコマンドパレットの「STELLA: 学習フォルダーを選ぶ」で変えられます。自分のファイルは上書きしません。

## 課題を確かめて提出する

| コマンド | すること |
|------|------|
| STELLA: 課題を確認する | 課題の手順 (テスト・lint など) を手元で実行し、結果を表示します |
| STELLA: 課題を提出する | 確認した課題を提出します。AI の一次レビューと講師のレビューで合否が決まります |
| STELLA: ヒント・解答・レビューの結果を表示する | 解放されたヒント・解答例・レビューの結果を表示します |
| STELLA: 講師に相談する | 進められないときに講師へ相談します |

課題のファイルや画面の文字列をコマンドとして実行することはありません。Workspace Trust で信頼したフォルダーでだけ、課題の手順を実行します。

## 接続とデータ

- ログインは STELLA の画面から行います。ボタンを押したときに発行される一度だけのコードで接続し、トークンは VS Code の SecretStorage に保存します。
- 提出するときに、課題のファイルと確認の結果を STELLA に送ります。確認のたびに送るのは結果の要約 (課題・合否・テストの件数) だけで、コードは送りません。

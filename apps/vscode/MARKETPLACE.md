# STELLA

研修 LMS「STELLA」の課題を VS Code で進めるための拡張機能です。STELLA の受講者向けで、STELLA のアカウントが必要です。

## 使い方

1. ブラウザーで STELLA にログインします。
2. 課題の「課題に取り組む」または「VS Code で開く」を押します。
3. VS Code が開き、左に編集するファイル、右に課題文が表示されます。この拡張機能が入っていなければ、VS Code がインストールするか尋ねます。インストールすると、そのまま課題が開きます。

課題文の先頭の「進め方」には、編集するファイルや、いまどの段階かが出ます。ファイルを編集して保存したら、画面の下のステータスバーかエディター右上の「提出する」ボタンを押します。「課題文」ボタンで課題文に戻れます。

左側の STELLA「学習ガイド」では、ステージと単元を選び、進み具合と「次にやること」を確認できます。教材は学習する順番に並び、開いている教材には現在地が表示されます。課題もこの画面から開けます。クイズや動画には「Web で受講」と表示され、押すとブラウザーで開きます。

初めて課題を開くと、ホームフォルダーに `web-training` (学習フォルダー) を作り、課題をその中に準備します。場所はコマンドパレットの「STELLA: 学習フォルダーを選ぶ」で変えられます。自分のファイルは上書きしません。

## 課題を確かめて提出する

「提出する」を押すと、手元で確認が走ります。前回の確認が通ったときの内容から変更がなければ、その結果を使います。通らなければ結果を表示します。通ったら「取り組んだこと・確認したこと・振り返り」を記入し、「この内容で提出する」を押します。問題つきの課題は通った問題をそのまま提出し、次の未提出の問題を開きます。下書きは自動保存され、送信に失敗したときも入力は残ります。支援の手入力は不要です。

| コマンド | すること |
|------|------|
| STELLA: 課題を確認する | 課題の手順 (テスト・lint など) を手元で実行し、結果を表示します。確認だけを行うときに使います |
| STELLA: 前回の確認の結果を表示する | 課題フォルダーに保存した前回の確認の結果をパネルで開きます |
| STELLA: 課題を提出する | 手元で確認し、通ったら提出に進みます。振り返りを添える課題は AI や講師がレビューします |
| STELLA: ヒント・解答・レビューの結果を表示する | 解放されたヒント・解答例・レビューの結果を表示します |
| STELLA: 講師に相談する | 進められないときに講師へ相談します |

課題のファイルや画面の文字列をコマンドとして実行することはありません。Workspace Trust で信頼したフォルダーでだけ、課題の手順を実行します。

## 接続とデータ

- ログインは STELLA の画面から行います。ボタンを押したときに発行される一度だけのコードで接続し、トークンは VS Code の SecretStorage に保存します。
- 提出するときに、課題のファイルと確認の結果を STELLA に送ります。確認のたびに送るのは結果の要約 (課題・合否・テストの件数) だけで、コードは送りません。

# VS Code 拡張の変更履歴

`package.json` の `version` を上げたら、`## [版] - YYYY-MM-DD` の節を一番上に足します。
受講者・管理者から見える変化を箇条書きで書きます。
AI がこの節を要約し、GitHub Release の本文と Google Chat に掲載します。全文は GitHub Release の折りたたみに残ります。

## [0.11.0] - 2026-11-22

- 動画を見終えると解放される課題では、番号順に1問ずつ取り組めます。まだ解けない問題のファイルは学習フォルダーに置かれません。
- Web の問題レッスンの「VS Code で開く」から、その問題のファイルを直接開けます。

## [0.10.1] - 2026-11-19

- この版から変更履歴を記録します。

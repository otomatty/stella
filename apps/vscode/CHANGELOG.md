# VS Code 拡張の変更履歴

`package.json` の `version` を上げたら、`## [版] - YYYY-MM-DD` の節を一番上に足します。
受講者・管理者から見える変化を `### 見出し` で分けると、Google Chat のスレッドに 1 項目ずつ、書いた文章のまま載ります。箇条書きだけでも書けます。
スクリーンショットを添えるには、項目内に `![説明](shot:名前)` だけの行を書きます。箇条書きではその行を字下げします。名前は小文字の英数字と区切りのハイフンで書き、画像は 1 項目につき 2 枚までです。
GitHub Release の本文には AI の要約を載せ、全文は折りたたみに残します。

## [0.12.2] - 2026-11-25

- 教材の雛形でコメントだけが変わったときは、書いたコードを残したまま新しいバージョンに更新します。

## [0.12.1] - 2026-11-25

- 問題つきの課題を開くと、全問のファイルを最初から学習フォルダーに置きます。まだ解けない問題は一覧に鍵と理由を表示し、提出できません。
- 以前の版で書き出しを待っていた問題のファイルは、次に課題を開いたときに書き出します。書き出しが終わるまで、確認と提出は止まります。

## [0.12.0] - 2026-11-24

- 問題つきの課題では、進み具合といまやることが課題パネルに出ます。まだ解けない問題の数や、次に見る動画も確認できます。
- 確認で通らなかったテストや書き方の指摘を課題パネルに表示し、該当する行を開けるようにしました。
- 問題ファイルの「▷ 確認して提出」と、ステータスバーの「確認して提出」から、問題を確かめて送れます。

## [0.11.2] - 2026-11-24

- 教材の更新後に課題を開くと、書いたコードを残したまま新しいバージョンに移れます。編集したファイルの雛形も変わった場合は、衝突したファイルを表示します。

## [0.11.1] - 2026-11-23

- 提出・相談の画面で、「提出する」と「下書きを保存」のボタンを画面の上部に置きました。スクロールしても上端に残ります。
- 学習ガイドは、表示を残したまま裏で最新の状態に更新します。VS Code に戻るたびに読み込み中の表示へ切り替わることがなくなりました。

## [0.11.0] - 2026-11-22

- 動画を見終えると解放される課題では、番号順に1問ずつ取り組めます。まだ解けない問題のファイルは学習フォルダーに置かれません。
- Web の問題レッスンの「VS Code で開く」から、その問題のファイルを直接開けます。

## [0.10.1] - 2026-11-19

- この版から変更履歴を記録します。

最初に読む

前提：問題のファイルの読み方

どの問題のファイルにも最初から書いてあるものです。ここだけ先に読んでください。

関数の形を読む

最初から書いてある

関数は「値を受け取り、計算して、値を返す」まとまりです。問題のファイルには、外側の形が最初から書いてあります。あなたが書くのは { } の中です。

よくある疑問: number が 2 つあります。かっこの中は受け取る値の型、かっこの後ろは返す値の型です。

型注釈は 01章 q02、関数は 05章 q01、export は 09章 q05

関数を呼ぶ

名前の後ろにかっこを付け、中に渡す値を書きます。呼んだ場所は、返ってきた値に置き換わります。

Math.floor(3.7) のように . が付く呼び方もあります。Math は数の計算をまとめた入れ物で、その中の floor を呼んでいます。Math.floor のように最初から使える関数を「組み込み」と呼びます。

値の書き方

型書き方何を表すか
number1000　0.1数値。整数と小数を区別しません。
string"Fizz"　""文字列。" で囲みます。"" は 0 文字の文字列です。
booleantrue　false「はい」か「いいえ」の 2 つだけです。

よくある間違い"10" は文字列で、10 は数値です。見た目が似ていても別の型です。

コメントと、例の読み方

// から行の終わりまではコメントです。実行されません。問題文はコメントで書いてあります。

// 問1 税込価格を返す（税率10%。税額の1円未満は切り捨て）
//     例: addTax(1000) → 1100
export function addTax(price: number): number {
  // ここに書く
}

例の → は TypeScript の書き方ではありません。「左のように呼ぶと、右の値が返る」という説明です。

このページのサンプルでは、各行の上のコメントに、その行がすることを日本語で書いています。最後の // 結果: は、その時点の変数の値です。

ヒント 1 の骨組みも同じ言い回しで書いています。字下げしたコメントは、くり返しや if の { } の中に書く行です。

書き方文の終わりには ; を書きます。{ } で囲んだ範囲はひとまとまりで、中は 2 文字ぶん字下げします。

01章 値・型・変数

q01 letとconst

変数は const で作り、後から値を入れ直す変数だけ let にします。var は使いません。くり返しや条件分岐（for・if・while）もここで初めて出てきます。くわしくは 04章で学ぶので、ここでは「まねて書ける」ところまでで十分です。

問1税込価格を返す 新しく出てくる書き方：const * + Math.floor() 
export function addTax(price: number): number

価格 price に 10% の税を足した金額を返します。税額に 1 円未満の端数が出たら、捨ててから足します。

テストで確かめる値

1100
税額は 100 円
addTax(980)
1078
税額は 98 円

新しい書き方

const

変数を作る（入れ直せない）

値に名前を付けます。付けた名前は、後ろの行で値の代わりに使えます。

// 合計 total を作り、price と shipping を足した数を入れる

// 結果: total は 1700

よくある間違い= は「等しい」ではなく、「右を左に入れる」です。等しいかを比べる書き方は問9 で出ます。

360
掛け算は × ではなく * です。
360 + 40
400
足し算です。
500 * 0.5

パーセントの計算ではありません。割り算の余りを返します。

`…${式}…`

テンプレートリテラル

文字列の中に、変数や計算の結果を埋め込みます。

サンプル 
// 商品名 item を作り、"ノート" を入れる
const item = "ノート";
// 冊数 count を作り、3 を入れる
const count = 3;
// 文 message を作り、item と count を埋め込んだ「◯を◯冊注文しました」を入れる
const message = `${item}を${count}冊注文しました`;
// 結果: message は "ノートを3冊注文しました"

入力のしかた` は、日本語配列のキーボードでは Shift + @、英語配列では 1 の左のキーです。

決まりitem + "を" のように、文字列を + でつなぐと lint でエラーになります（prefer-template）。

新しい書き方

let

変数を作る（入れ直せる）

後から値を入れ直す変数だけ let にします。それ以外は const です。

const 入れ直せない
// 在庫 stock を作り、10 を入れる

✕ 2 行目がエラーになります

// stock に 5 を足した数を、stock に入れ直す

for ( ; ; )

決まった回数くり返す

サンプル 
// 積立額 saving を入れ直せる変数として作り、0 を入れる

// month を 1 から 3 まで 1 ずつ増やしながらくり返す

  // saving に 5000 を足す

}
// 結果: 毎月 5000 円を 3 か月積み立てる。saving は 15000

かっこの中を ; で 3 つに区切ります。

実行の順番は 1 → 2 → 4 → 3 → 2 → 4 → 3 → … です。

monthmonth <= 3saving
1true5000
2true10000
3true15000
4false終わり

コツ分からなくなったら、この表を紙に書いて、変数の値を 1 行ずつ追ってみてください。

決まり中身が 1 行でも { } は省けません（curly）。

for (const c of text)

文字列の先頭から 1 文字ずつ c に入れて、中身を実行します。数える変数は要りません。

04章 q03（for文と for-of文）

if

条件に合うときだけ実行する

かっこの中が true のときだけ、{ } の中を実行します。false なら飛ばします。

サンプル 
function stockLabel(stock: number): string {
  // 表示 label を入れ直せる変数として作り、"在庫あり" を入れる
  let label = "在庫あり";
  // もし stock が 0 と等しいなら

コツこの問題は、アロー関数を使わなくても解けます。使ったときは、function の形と同じだと説明できるようにしておきましょう。

応用買い物かごの合計金額を返す 新しく出てくる書き方：- 
export function checkout(price: number, quantity: number, coupon: number): number

次の順に計算して、合計金額を返します。

  1. 小計は price × quantity
  2. 小計からクーポン coupon（円）を引く。ただし 0 円より小さくはしない
  3. 2 の金額が 5000 円以上なら送料は無料。5000 円未満なら送料 500 円を足す
  4. 合計金額を返す

変数は const で作り、後から値を入れ直す変数だけ let にします。var は使いません。この条件は lint でも確かめます。

09章 組み込みの API とモジュール

q02 Set

重複を除いたり、2 つの集まりを比べたりする関数を 20 個書き、最後に応用問題に取り組みます。この番号では、TypeScript に最初から用意されている Set を使います。引数と戻り値には型注釈を付けます。型は Set<string> のように書きます。引数の配列や Set は書き換えません。引数の型は string[] や Set<string> と書き、readonly や ReadonlySet は使いません。Set も q01 の Map と同じく、入れた順を覚えています。配列にしたいときは、[...set] のようにスプレッド構文を使います。Set には union（どちらかにあるもの）や intersection（両方にあるもの）といったメソッドもあります。ただし、この課題の設定（ES2022）では使えません。has や add を使って自分で書きます。問18 では、定義済みの型 User を使います。

新しい書き方

Set<T>

同じ値を 1 つずつだけ持つ集まり

Set は、値の集まりを入れておく入れ物です。同じ値は 1 つしか入りません。もう入っている値を足しても、何も変わりません。Map と同じく、入れた順を覚えています。Map のキーだけを集めたもの、と考えると分かりやすいです。型は Set<要素の型> と書きます。配列との違いを表にまとめます。

サバイバルTypeScript「Set<T>」

new Set(配列)

配列から Set を作る

Map と同じく、new を付けて作ります。new Set() のかっこに配列を渡すと、配列の要素を前から順に入れた Set ができます。同じ値は、最初の 1 つだけが残ります。型は、渡した配列から推論されます。

サンプル 
// 注文された品名 orders を作り、"ノート" と "ペン" と "ノート" を並べた配列を入れる
const orders = ["ノート", "ペン", "ノート"];
// 品名の集まり kinds を作り、orders から作った Set を入れる
const kinds = new Set(orders);
// 結果: kinds は Set { "ノート", "ペン" }

kinds の型は Set<string> です。元の配列 orders は変わりません。

新しい書き方

[...set]

Set を配列にする

Set は配列ではないので、.sort() や .map() などの配列のメソッドがありません。[ ] の中で ... を付けて広げると、入れた順に並べた配列になります。Map の [...stock.keys()]（q01 問7）と同じ書き方です。Set は、.keys() を付けずにそのまま広げられます。

サンプル 
// 注文された品名 orders を作り、"ノート" と "ペン" と "ノート" を並べた配列を入れる
const orders = ["ノート", "ペン", "ノート"];
// 品名の一覧 names を作り、orders から作った Set の値を並べた配列を入れる
const names = [...new Set(orders)];
// 結果: names は ["ノート", "ペン"]

names の型は string[] です。新しい配列なので、そのまま .sort() を呼んでも orders は変わりません。

応用配列を集合として扱う 新しい書き方はありません。 
export function unique() {}

export function intersection() {}

export function difference() {}

export function union() {}

export function isSubset() {}

配列を集合（重複のない値の集まり）として扱う関数を 5 つ、Set を使って書きます。型変数（07章 q06 問1）を使い、どんな要素の配列にも使えるようにします。戻り値は、isSubset 以外はすべて配列（T[]）にします。引数の配列は書き換えません。Set の union などのメソッドは使えないので、自分で書きます。どの関数も、配列の .includes() をくり返し呼ぶ代わりに、Set の .has() を使います。

  1. unique(items)：重複を除いた配列を返します。順は最初に出てきた順です。
  2. intersection(a, b)：a と b の両方にある要素の配列を返します。a の順で、重複はなくします。
  3. difference(a, b)：a にあって b にない要素の配列を返します。a の順で、重複はなくします。
  4. union(a, b)：a か b のどちらかにある要素の配列を返します。a の要素を a の順に、その後ろに b にだけある要素を b の順に並べます。重複はなくします。
  5. isSubset(a, b)：a の要素がすべて b にあれば true を返します。a が空なら true です。

「説明すること」もあります。要素が 1 万個の配列どうしの intersection を、配列の .includes() で書いた場合と、Set の .has() で書いた場合とで、比べる回数がおよそ何回になるかを考えます。ファイルの「説明すること」のすぐ下に、// のコメントで書きます。

置き換える、正規表現で探す

.replace() に文字列を渡すと、最初に見つかった 1 つだけを置き換えます。正規表現を渡すと、決まった種類の文字をまとめて探して置き換えられます。

正規表現は 09章の発展問題でくわしく扱います。ここでは、この形をまねて書ければ十分です。

サンプル 
// 商品コード code を作り、"A-1-B-2" を入れる
const code = "A-1-B-2";
// first を作り、code の最初の "-" だけを "" に置き換えたものを入れる
const first = code.replace("-", "");
// noDigits を作り、code の中の数字をすべて "" に置き換えたものを入れる
const noDigits = code.replace(/[0-9]/g, "");
// 結果: first は "A1-B-2"、noDigits は "A--B-"
"A-1-B-2".replace("-", "")
"A1-B-2"
最初の 1 つだけ
"A-1-B-2".replace(/[0-9]/g, "")
"A--B-"
数字をすべて

新しい書き方

決まった位置の 1 文字を取り出す

かっこの中の位置にある 1 文字を返します。位置は 0 から数えます。その位置に文字がないときは、空の文字列 "" を返します。

応用URL の形・文字数の切りつめ・メールアドレスを隠す 新しい書き方はありません。 
export function slugify() {}

export function truncate() {}

export function maskEmail() {}

3 つの関数を書きます。引数と戻り値には型注釈を付けます。

  1. slugify：タイトルを URL に使える形にします。前後の空白を取り除き、英字を小文字にします。間の空白は、いくつ続いていてもハイフン 1 つにします。空白の並びは正規表現 /\s+/g で表せます（\s は空白 1 文字、+ は 1 つ以上続くこと）。
  2. truncate：text が max 文字以下なら、そのまま返します。max 文字を超えるなら、末尾を "…" にして、全体がちょうど max 文字になるように切ります。max が 1 より小さいときは Error を投げます。
  3. maskEmail：メールアドレスの "@" より前を、先頭の 1 文字と "***" に置き換えます。"@" がないときと、"@" より前が空のときは Error を投げます。
テストで確かめる値
slugify("Hello World")
"hello-world"
slugify(" Hello TypeScript World ")
"hello-typescript-world"
空白が続いてもハイフン 1 つ
slugify("agora")
"agora"
truncate("TypeScript入門", 6)
"TypeS…"
5 文字と "…" で 6 文字
truncate("abcdefg", 6)
"abcde…"
truncate("短い文", 10)
"短い文"
max 以下はそのまま
truncate("abcdef", 6)
"abcdef"
ちょうど max 文字もそのまま
truncate("abc", 0)
Error
Error を投げる
maskEmail("taro@example.com")

maskEmail("a@b.jp")

ヒント 2コードへの直し方

05章 関数

q07 コールバック関数

関数を引数として受け取る関数を 20 個書きます。引数と戻り値には型注釈を付けます。関数を受け取る引数の型は、(n: number) => number のように書きます。02章 q04 では、.map() にアロー関数を渡しました。この番号では、関数を受け取る側を自分で書きます。中では map、filter、find、some、every、reduce などの配列のメソッドを使いません。for-of や for で回して、受け取った関数を自分で呼びます。テストは、返す値のほかに、引数と戻り値の型も確かめます。

問1それぞれの要素に fn を当てはめた配列を返す 新しく出てくる書き方：関数の型 (n: number) => number、引数で受け取った関数を呼ぶ fn(n) 
export function mapNumbers() {}

数値の配列 numbers と、関数 fn を受け取ります。fn は、数値を 1 つ受け取って数値を返す関数です。numbers の要素を 1 つずつ fn に渡し、返ってきた数を並べた新しい配列を返します。.map() と同じ働きを、for-of で自分で書きます。

テストで確かめる値
mapNumbers([1, 2], (n) => n * 10)
[10, 20]
それぞれを 10 倍にする関数を渡す

型引数が readonly number[] と (n: number) => number、戻り値が number[] であることも確かめます。

新しい書き方

(amount: number) => number

関数の型（関数を受け取る引数の型）

関数も値の 1 つです。02章 q04 問5 では、.map() にアロー関数を渡しました。渡してあとで呼んでもらう関数を、コールバックと呼びます。同じように、自分で書く関数でも、引数で関数を受け取れます。

受け取る引数には、ほかの引数と同じく型注釈が要ります。関数の型は (引数の名前: 型) => 戻り値の型 と書きます。「この形の引数を受け取り、この型の値を返す関数」という意味です。

サンプル 
// 関数 payAmount を作る。数値 price と、関数 feeOf（数値 amount を受け取り、数値を返す）を受け取り、数値を返す
function payAmount(price: number, feeOf: (amount: number) => number): number {
  // price に、feeOf に price を渡して呼んだ結果を足した数を返す
  return price + feeOf(price);
}
// 支払い pay を作り、payAmount に 3000 と、amount を受け取り、amount が 5000 以上なら 0、そうでなければ 500 を返す関数を渡して呼んだ結果を入れる
const pay = payAmount(3000, (amount) => (amount >= 5000 ? 0 : 500));
// 結果: pay は 3500

呼ぶ側の (amount) => … には、型注釈を書いていません。payAmount の引数の型から、amount は number だと TypeScript が推論します（02章 q04 問5 と同じです）。

関数の型に合わない関数を渡すと、型の確認でエラーになります。

payAmount(3000, (amount) => `${amount}円`)
型の確認でエラー
文字列を返している。戻り値は数値のはず
payAmount(3000, 500)
型の確認でエラー
関数を渡すところに、数値を渡している

よくある疑問関数の型の中の amount は、説明のための名前です。渡す関数の引数の名前と、そろえなくてかまいません。テストの型の確かめも、名前は比べません。fn: (value: number) => number と書いても、テストが求める (n: number) => number と同じ型として通ります。比べるのは、引数の型の並びと戻り値の型です。

よくある間違いfeeOf: (amount: number) => amount + 500 のように、=> の右に計算を書くと、文法のエラーになります。関数の型に書けるのは型だけです。計算は、呼ぶ側が渡す関数の中に書きます。

引数で受け取った関数を呼ぶ

引数で受け取った関数は、自分で書いた関数と同じように呼べます（01章 q01 問20）。引数の名前の後ろにかっこを付けて、渡す値を入れます。呼んだ関数が返した値が、その場所の値になります。

送料 500 を足す
payAmount(6000, (amount) => (amount >= 5000 ? 0 : 500))

5000 以上なので送料 0

// price に feeOf を足した数を返す

✕ 型の確認でエラーになります
かっこを付けて呼ぶ
// price に、feeOf に price を渡して呼んだ結果を足した数を返す
return price + feeOf(price);
○ 3500

feeOf とだけ書くと、関数そのものです。数値と関数は足せないので、Operator '+' cannot be applied to types 'number' and '(amount: number) => number'. というエラーになります。「+ は、数値と関数には使えません」という意味です。

要素ごとに呼びたいときは、for-of の中で呼びます。くり返すたびに、取り出した要素を渡して呼びます。

サンプル 
// 関数 receiptText を作る。読み取り専用の数値の配列 prices と、関数 format（数値 price を受け取り、文字列を返す）を受け取り、文字列を返す
function receiptText(prices: readonly number[], format: (price: number) => string): string {
  // 文 text を入れ直せる変数として作り、空の文字列を入れる
  let text = "";
  // prices から 1 つずつ price に取り出してくり返す
  for (const price of prices) {
    // text と、format に price を渡して呼んだ結果を埋め込んだ「◯[◯]」の文字列を、text に入れ直す
    text = `${text}[${format(price)}]`;
  }
  // text を返す
  return text;
}
// 明細 receipt を作り、receiptText に [1200, 800] と、price を受け取り、price を埋め込んだ「◯円」の文字列を返す関数を渡して呼んだ結果を入れる
const receipt = receiptText([1200, 800], (price) => `${price}円`);
// 結果: receipt は "[1200円][800円]"
price（取り出した要素）format(price) の結果text
（くり返しの前）""
1200"1200円""[1200円]"
800"800円""[1200円][800円]"

よくある疑問receiptText は、受け取った関数が何をするかを知りません。「1 つずつ取り出して呼ぶ」ことだけを決めています。何に変えるかは、呼ぶ側が渡す関数で決めます。(price) => `${price} yen` を渡せば、同じ receiptText のまま "[1200 yen][800 yen]" になります。

問3それぞれの要素と番号を fn に渡して呼ぶ 新しく出てくる書き方：引数が 2 つの関数の型、何も返さない関数の型 => void 
export function eachWithIndex() {}

文字列の配列 items と、関数 fn を受け取ります。fn は、文字列 item と数値 index の 2 つを受け取り、何も返さない関数です。items の要素を前から順に、その要素と番号（0 から数える）を fn に渡して呼びます。eachWithIndex 自身も、何も返しません。.forEach()（02章 q04 問19）と同じ働きです。

テストは、呼ばれた順を記録する関数を fn として渡し、記録の中身を確かめます。

テストで確かめる値

型引数が readonly string[] と (item: string, index: number) => void、戻り値が void であることも確かめます。

新しい書き方

(item: string, left: number) => void

引数が 2 つの関数の型、何も返さない関数の型

受け取る関数の引数が 2 つ以上なら、かっこの中に , で区切って並べます。ふつうの関数の引数と同じ書き方です。

受け取る関数が何も返さないときは、戻り値の型を void にします。void は、04章 q05 問13 で出た「何も返さない」を表す型です。値を返す代わりに、配列に付け足すなどの仕事をする関数に使います。

サンプル 
// 関数 alertIfLow を作る。文字列 name と数値 count と、関数 send（文字列 item と数値 left を受け取り、何も返さない）を受け取り、何も返さない
function alertIfLow(name: string, count: number, send: (item: string, left: number) => void): void {
  // もし count が 5 より小さいなら
  if (count < 5) {
    // send に name と count を渡して呼ぶ
    send(name, count);
  }
}
// 知らせた記録 sent を文字列の配列として作り、空の配列を入れる
const sent: string[] = [];
// alertIfLow に "ペン" と 3 と、item と left を受け取る関数を渡して呼ぶ
alertIfLow("ペン", 3, (item, left) => {
  // sent の最後に、item と left を埋め込んだ「◯ 残り◯個」の文字列を付け足す
  sent.push(`${item} 残り${left}個`);
});
// alertIfLow に "ノート" と 20 と、item と left を受け取る関数を渡して呼ぶ
alertIfLow("ノート", 20, (item, left) => {
  // sent の最後に、item と left を埋め込んだ「◯ 残り◯個」の文字列を付け足す
  sent.push(`${item} 残り${left}個`);
});
// 結果: sent は ["ペン 残り3個"]

ノートは 20 個あり、5 より小さくありません。そのため send は呼ばれず、sent には何も足されません。

send は何も返さないので、send(name, count); と呼ぶだけで、結果を変数に入れたり返したりしません。呼ぶ側のアロー関数は、{ } の中で sent に付け足すだけで、return を書いていません。

数値の配列 numbers、関数 fn、始めの値 initial の 3 つを受け取ります。fn は、ここまでの値 acc と要素 n の 2 つを受け取り、次の値を返す関数です。initial から始めて、要素ごとに fn(ここまでの値, 要素) の結果を次の「ここまでの値」にします。最後の値を返します。

1 つ目のテストで、ここまでの値が変わっていく様子です。

n（要素）fn に渡すものここまでの値

1fn(0, 1)1
2fn(1, 2)3
3fn(3, 3)6

reduceNumbers([1, 2, 3], (acc, n) => acc + n, 0)
6
0 から足していく
reduceNumbers([2, 3], (acc, n) => acc * n, 1)
6
1 からかけていく

型引数が readonly number[] と (acc: number, n: number) => number と number、戻り値が number であることも確かめます。

ヒント 2コードへの直し方

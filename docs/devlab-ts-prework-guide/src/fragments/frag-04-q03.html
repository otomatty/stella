q03 for文と for-of文

配列や文字列を 1 つずつ見る関数を 20 個書きます。くり返しには for 文か for-of 文を使います。map や filter などの配列のメソッド（02章 q04）は使いません。要素を順に見るだけなら for-of が書きやすいです。番号（その要素が何番目か。0 から数える）も要るなら、for 文が書きやすいです。引数と戻り値の型注釈は自分で書きます。引数の配列は、readonly number[] のような読み取り専用の配列にします。

新しい書き方

for と for-of を使い分ける

01章 q01 では、for 文（問5）と for-of 文（問9）を、まねて書きました。この番号では、2 つを使い分けます。決め手は、くり返しの中で番号を使うかどうかです。

くり返しの中で使うもの書き方使う場面
要素だけfor (const stock of stocks)合計する、数える、条件に合う要素を探す
番号for (let i = 0; i < stocks.length; i++)位置を集める、後ろから見る、2 つの配列を同じ番号で見る、決まった回数くり返す
番号と要素の両方for (const [i, stock] of stocks.entries())番号付きの一覧を作る、先頭の要素だけ別に扱う

要素だけを使うときは、for-of で書きます。

サンプル 
// 関数 countSoldOut を作る。読み取り専用の数値の配列 stocks を受け取り、数値を返す
function countSoldOut(stocks: readonly number[]): number {
  // 数 count を入れ直せる変数として作り、0 を入れる
  let count = 0;
  // stocks から 1 つずつ stock に取り出してくり返す
  for (const stock of stocks) {
    // もし stock が 0 と等しいなら
    if (stock === 0) {
      // count を 1 増やす
      count++;
    }
  }
  // count を返す
  return count;
}
// 結果: countSoldOut([12, 0, 5, 0]) は 2

同じことを for 文で書くこともできます。ただ、この課題の設定ではエラーになります。

for 文で書く
for (let i = 0; i < stocks.length; i++) {
  if (stocks[i] === 0) {
    count++;
  }
}
✕ lint で、for-of に書き直すように言われます
for-of で書く
for (const stock of stocks) {
  if (stock === 0) {
    count++;
  }
}
○ 番号の変数が要らず、短く書けます

決まり番号の i を、stocks[i] と取り出すためだけに使う for 文は、lint でエラーになります（prefer-for-of）。for-of に書き直します。

なぜfor 文で stocks[i] と取り出すと、型は number | undefined になります（02章 q04 問3）。for-of で取り出した stock は number のままなので、そのまま計算に使えます。

番号を使う for 文は問4 で、.entries() は問9 で、くわしく見ます。

新しい書き方

for 文の中で、i 番目の要素を取り出す

番号が要るときは、for 文で i を 0 から、配列の要素の数より小さい間 1 ずつ増やします。i 番目の要素は、stocks[i] で取り出します（02章 q04 問3）。

サンプル 
// 関数 refillShelves を作る。読み取り専用の数値の配列 stocks を受け取り、数値の配列を返す
function refillShelves(stocks: readonly number[]): number[] {
  // 棚の番号 shelves を数値の配列として作り、空の配列を入れる
  const shelves: number[] = [];
  // i を 0 から、stocks の要素の数より小さい間 1 ずつ増やしながらくり返す
  for (let i = 0; i < stocks.length; i++) {
    // 在庫 stock を作り、stocks の i 番目の要素を入れる
    const stock = stocks[i];
    // もし stock が undefined でなく、5 より小さいなら
    if (stock !== undefined && stock < 5) {
      // shelves の最後に i を付け足す
      shelves.push(i);
    }
  }
  // shelves を返す
  return shelves;
}
// 結果: refillShelves([12, 3, 8, 0]) は [1, 3]
ii < 4stockstock < 5shelves

1true3true[1]
2true8false[1]
3true0true[1, 3]
4false終わり

stocks[i] の型は number | undefined です。< や > で比べる前に、undefined でないことを確かめます。

確かめない

  shelves.push(i);
}
✕ 「stock は undefined かもしれない」という型のエラーになります

if (stock !== undefined && stock < 5) {
  shelves.push(i);

○ && の右では、stock を number として比べられます

よくある疑問i < stocks.length の間だけ回すので、実際には undefined になりません。それでも、この課題の設定では、[ ] で取り出した要素の型にいつも undefined が含まれます（02章 q04 問3）。

.entries()

番号と要素を組にして取り出す

配列の .entries() を使うと、[番号, 要素] の組を順に取り出せます。for-of で取り出すときに、配列の分割代入（02章 q06 問2）で [i, name] と書くと、番号と要素を別々の変数で受け取れます。02章 q08 問10 の Object.entries() と、書き方が似ています。

サンプル 
// 商品名の配列 names を作り、"ノート" と "ペン" と "のり" を入れる
const names = ["ノート", "ペン", "のり"];
// 一覧 list を入れ直せる変数として作り、空の文字列を入れる
let list = "";
// names の番号と要素の組を 1 つずつ [i, name] に取り出してくり返す
for (const [i, name] of names.entries()) {
  // list の後ろに、i に 1 を足した数と "."、name と " " をつなげる

}
// 結果: list は "1.ノート 2.ペン 3.のり "

>= や <= は、文字列どうしにも使えます。文字には決まった順番があり、その順番で比べます。英大文字は "A" から "Z" まで、数字は "0" から "9" まで、順に並んでいます。英小文字は、英大文字より後ろにあります。

  return initial >= "A" && initial <= "M";
}

return を実行すると、関数はそこで終わります（01章 q07 問2）。くり返しの中で return すると、残りの要素は見ずに、くり返しごと関数が終わります。

// 関数 reservationLabel を作る。読み取り専用の文字列の配列 names と文字列 guest を受け取り、文字列を返す
function reservationLabel(names: readonly string[], guest: string): string {
  // names から 1 つずつ name に取り出してくり返す
  for (const name of names) {

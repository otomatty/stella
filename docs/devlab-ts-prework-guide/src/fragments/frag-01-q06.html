01章 値・型・変数

q06 boolean型

この番号の関数は、どれも true か false を返します。比べた結果はそれだけで true か false になるので、if を使わずに return 比べる式; の 1 行で書けるものが多くあります。条件にも、true か false になる式を書きます。問題のファイルには関数の名前だけが書いてあるので、引数と戻り値の型注釈は自分で付けます。

問10 より大きければ true を返す 新しい書き方はありません。 
export function isPositive() {}

受け取った数が 0 より大きければ true、そうでなければ false を返します。0 は false です。

引数は number を 1 つ、戻り値は boolean です。型注釈は自分で書きます。

問題のファイルには、関数の名前だけが書いてあります。この番号の問題は、どれも同じです。

テストで確かめる値
isPositive(3)
true
isPositive(0)
false
0 は 0 より大きくない

この番号で大事な書き方

return 比べる式;

比べた結果を、そのまま返す

比べた結果は、それだけで true か false になります。だから if を使わずに、比べる式をそのまま return できます。

サンプル 
function isFreeShipping(subtotal: number): boolean {
  // subtotal が 5000 以上かどうか（true か false）を返す
  return subtotal >= 5000;
}
// 結果: isFreeShipping(6000) は true、isFreeShipping(3000) は false

if で書いても同じ結果になります。1 行で書くほうが短く、読みやすくなります。

if で書く
function isFreeShipping(subtotal: number): boolean {
  // もし subtotal が 5000 以上なら
  if (subtotal >= 5000) {
    // true を返す
    return true;
  }
  // false を返す
  return false;
}
1 行で書く
function isFreeShipping(subtotal: number): boolean {
  // subtotal が 5000 以上かどうか（true か false）を返す
  return subtotal >= 5000;
}

コツif の中で return すると、関数はそこで終わります。だから if の後ろの return false; は、条件に合わなかったときだけ実行されます。

&&||!

条件を組み合わせる

「かつ」は &&、「または」は ||、「でない」は ! です。どれも q01〜q04 で出てきました。この番号では、これらを組み合わせて 1 行で返します。

true && true
true
両方が true のときだけ true
true && false
false
false || true
true
どちらかが true なら true
false || false
false
!true
false
true と false を入れ替える
サンプル 
function canReserve(seats: number, isClosed: boolean): boolean {
  // seats が 0 より大きい、かつ isClosed でないかどうか（true か false）を返す
  return seats > 0 && !isClosed;
}
// 結果: canReserve(3, false) は true、canReserve(3, true) は false

よくある間違いisClosed === false と書く必要はありません。「isClosed でない」は !isClosed です。

: boolean

条件と戻り値には、true か false になる式を書く

戻り値の型が boolean の関数で、数値をそのまま返すと型の確認でエラーになります。比べる式にして返します。

数値をそのまま返す
function hasStock(stock: number): boolean {
  // stock をそのまま返す
  return stock;
}
✕ 型の確認でエラーになります
比べる式にして返す
function hasStock(stock: number): boolean {
  // stock が 0 より大きいかどうか（true か false）を返す
  return stock > 0;
}
○ true か false を返します

決まりこの課題では、if などの条件にも、true か false になる式を書きます。if (stock) のように数値をそのまま書くと、0 のときだけ false として扱われます。この決まりを truthy・falsy と呼びますが、読み違えやすいので比べる式で書きます。

サバイバルTypeScript「truthy な値、falsy な値」

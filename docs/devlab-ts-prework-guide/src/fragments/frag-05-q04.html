05章 関数

q04 デフォルト引数

関数を 20 個書きます。問題に「省略したら ◯◯」と書いてある引数は、times = 2 のように、引数の名前の後ろに = 値 を書きます。これをデフォルト引数といいます。値を書いた引数には、型注釈を書きません。型は値から決まります。そのほかの引数と戻り値には、これまでどおり型注釈を付けます。q03 では省略できる引数を ? で書きました。この番号では = 値 で書きます。

問1省略できる name を受け取り「こんにちは、◯◯さん」を返す 新しく出てくる書き方：デフォルト引数 name = "ゲスト" 
export function greetGuest() {}

名前 name を受け取り、「こんにちは、◯◯さん」の文字列を返します。name を省略して呼んだときは、名前を「ゲスト」にします。

テストで確かめる値
greetGuest()
"こんにちは、ゲストさん"
省略したので「ゲスト」
greetGuest("山田")
"こんにちは、山田さん"

型引数が、省略できる string 1 つ（テストでは [string?] と書きます）、戻り値が string であることも確かめます。

新しい書き方

quantity = 1

デフォルト引数（省略されたときの値）

引数の名前の後ろに = 値 を書くと、その引数を省略して呼べるようになります。省略されたときは、書いた値（デフォルト値）が入ります。

サンプル 
// 関数 orderLabel を作る。文字列の item と、quantity（省略したら 1）を受け取り、文字列を返す
function orderLabel(item: string, quantity = 1): string {
  // item と quantity を埋め込んだ「◯ × ◯」の文字列を返す
  return `${item} × ${quantity}`;
}
// 結果: orderLabel("りんご") は "りんご × 1"、orderLabel("りんご", 3) は "りんご × 3"
orderLabel("りんご")
"りんご × 1"
省略したので 1 が入る
orderLabel("りんご", 3)
"りんご × 3"
渡した値が入る
orderLabel("りんご", undefined)
"りんご × 1"
undefined を渡したときも、デフォルト値が入る

文字列の値を書けば、型は string になります。引数がデフォルト引数だけなら、何も渡さずに呼べます。

サンプル 
// 関数 memberLabel を作る。rank（省略したら "一般"）を受け取り、文字列を返す
function memberLabel(rank = "一般"): string {
  // rank の後ろに "会員" をつなげた文字列を返す
  return `${rank}会員`;
}
// 結果: memberLabel() は "一般会員"、memberLabel("ゴールド") は "ゴールド会員"

q03 のオプション引数 ? と比べます。呼び出す側から見ると、2 つは同じ型です。どちらも (item: string, quantity?: number) => string になります。違うのは、関数の中での quantity の型です。

q03 オプション引数 ?
function orderLabel(item: string, quantity?: number): string {
  return `${item} × ${quantity ?? 1}`;
}
○ 中では quantity は number | undefined。省略されたときの値は ?? で決めます
q04 デフォルト引数 =
function orderLabel(item: string, quantity = 1): string {
  return `${item} × ${quantity}`;
}
○ 中では quantity は number。省略されたときは、もう 1 が入っています

テストの型の確認では、省略できる引数を [string, number?] のように ? 付きで書きます。デフォルト引数で書いた関数も、この型になります。

よくある間違いquantity: number = 1 と型注釈も書くと、lint でエラーになります（no-inferrable-types）。値を見れば分かる型を、重ねて書かないための決まりです。

決まりデフォルト引数は、ふつうの引数より後ろに並べます。省略できるのは、後ろのほうの引数だけだからです。

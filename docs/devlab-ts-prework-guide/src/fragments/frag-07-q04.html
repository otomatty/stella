07章 型の再利用とジェネリクス

q04 Pick と Omit

もとの型から、プロパティの一部だけを持つ型を作る問題を 20 問解きます。Pick<T, "a" | "b"> は、T から指定したプロパティだけを取り出した型です。Omit<T, "a" | "b"> は、T から指定したプロパティを除いた型です。型 User と Article は、ファイルにもう書いてあります。型を作る問題では、プロパティを手で書き並べずに、Pick か Omit で作ります。関数を書く問題では、引数と戻り値に型注釈を付けます。Omit した型を返す関数では、除いたプロパティを、返すオブジェクトに入れません。テストは、余分なプロパティが残っていないことも確かめます。

問1型 UserName を、User から name だけを取り出して作る 新しく出てくる書き方：Pick<T, "a" | "b"> 
export type User = { id: number; name: string; email: string; password: string; age: number };

// ここに型 UserName を書く

User から name だけを取り出した型 UserName を作ります。{ name: string } と手で書かずに、Pick を使います。テストがこの型を読むので、export を付けます。

テストで確かめる値
UserName の型
{ name: string }
と同じ型であること

新しい書き方

Pick<T, "a" | "b">

指定したプロパティだけを取り出した型を作る

Pick は、もとの型から、指定したプロパティだけを取り出した型を作ります。07章 q03 の Partial と同じく、< > の中に型を渡して使う組み込みの型です。このような型を、ユーティリティ型と呼びます。Pick の < > には 2 つ書きます。1 つめはもとにする型、2 つめは取り出すプロパティ名です。

サンプル 
// 商品の型 Product を作る。code は文字列、name は文字列、price は数値、stock は数値
type Product = { code: string; name: string; price: number; stock: number };
// ProductName という型を作る。Product から name だけを取り出した型。ほかのファイルから使えるようにする
export type ProductName = Pick<Product, "name">;
// ラベル label を作り、型を ProductName にして、name が "ノート" のオブジェクトを入れる
const label: ProductName = { name: "ノート" };
// 結果: label は { name: "ノート" }

2 つ以上のプロパティを取り出すときは、プロパティ名を | でつなぎます。リテラル型のユニオン型（01章 q07 問1）と同じ書き方です。

サンプル 
// PriceTag という型を作る。Product から name と price を取り出した型。ほかのファイルから使えるようにする
export type PriceTag = Pick<Product, "name" | "price">;
// 値札 tag を作り、型を PriceTag にして、name が "ノート"、price が 120 のオブジェクトを入れる
const tag: PriceTag = { name: "ノート", price: 120 };
// 結果: tag は { name: "ノート", price: 120 }
Pick<Product, "name">
{ name: string }
と同じ型
Pick<Product, "name" | "price">
{ name: string; price: number }
と同じ型
Pick<Product, "nmae">
型のエラー
Product に nmae はない

よくある間違い2 つめに書けるのは、もとの型にあるプロパティ名だけです。keyof Product（07章 q02）に入る名前と同じです。"nmae" のように打ち間違えると、型の確認でエラーになります。

よくある疑問{ name: string } と手で書いても、同じ型になります。テストも同じ型として扱います。Pick で作っておくと、Product の name の型を直したときに、ProductName も一緒に変わります。この番号では、手で書き並べずに Pick を使います。

新しい書き方

Omit<T, "a" | "b">

指定したプロパティを除いた型を作る

Omit は Pick の反対です。もとの型から、指定したプロパティを除いた型を作ります。< > の中の書き方は Pick と同じで、1 つめがもとにする型、2 つめが除くプロパティ名です。

サンプル 
// 商品の型 Product を作る。code は文字列、name は文字列、price は数値、stock は数値
type Product = { code: string; name: string; price: number; stock: number };
// ListedProduct という型を作る。Product から stock を除いた型。ほかのファイルから使えるようにする
export type ListedProduct = Omit<Product, "stock">;
// 一覧の行 row を作り、型を ListedProduct にして、code が "A-01"、name が "ノート"、price が 120 のオブジェクトを入れる
const row: ListedProduct = { code: "A-01", name: "ノート", price: 120 };
// 結果: row は { code: "A-01", name: "ノート", price: 120 }

2 つ以上のプロパティを除くときも、| でつなぎます。

サンプル 
// NameAndPrice という型を作る。Product から code と stock を除いた型。ほかのファイルから使えるようにする
export type NameAndPrice = Omit<Product, "code" | "stock">;
// 結果: NameAndPrice は { name: string; price: number } と同じ型
Omit<Product, "stock">
{ code: string; name: string; price: number }
と同じ型
Omit<Product, "code" | "stock">
{ name: string; price: number }
と同じ型

同じ型を、Pick でも Omit でも作れます。残すプロパティが少ないときは Pick、除くプロパティが少ないときは Omit を使うと、短く書けます。

Pick で残すものを書く
type ListedProduct = Pick<Product, "code" | "name" | "price">;
○ 3 つ並べる
Omit で除くものを書く
type ListedProduct = Omit<Product, "stock">;
○ 1 つで済む。同じ型になります

よくある間違いOmit は、もとの型にない名前を書いても、型のエラーになりません。Omit<Product, "stok"> のように打ち間違えると、何も除かれずに Product と同じ型になります。Pick より間違いに気づきにくいので、名前をよく確かめます。

サンプル 
// 関数 toPriceTag を作る。Product の product を受け取り、Product から name と price を取り出した型のオブジェクトを返す
function toPriceTag(product: Product): Pick<Product, "name" | "price"> {
  // name が product の name、price が product の price のオブジェクトを返す

}
// 結果: toPriceTag({ code: "A-01", name: "ノート", price: 120, stock: 8 }) は { name: "ノート", price: 120 }
受け取ったものをそのまま返す

✕ 型の確認は通りますが、code と stock も残ります

return { name: product.name, price: product.price };
○ name と price だけを持ちます

新しい書き方

(p) => ({ … })

アロー関数でオブジェクトを返す

アロー関数（01章 q01 問20）の => の後ろに { を書くと、関数の本体の始まりとして読まれます。式だけの本体でオブジェクトを返すときは、オブジェクトを ( ) で囲みます。.map()（02章 q04 問5）で、要素をオブジェクトに変えるときによく使います。

サンプル 
// 商品の配列 products を作る。型は Product の配列。2 つの商品を入れる
const products: Product[] = [
  { code: "A-01", name: "ノート", price: 120, stock: 8 },
  { code: "B-02", name: "ペン", price: 80, stock: 0 },
];
// tags を作り、products の要素を 1 つずつ p として、name が p の name、price が p の price のオブジェクトに変えた新しい配列を入れる
const tags = products.map((p) => ({ name: p.name, price: p.price }));
// 結果: tags は [{ name: "ノート", price: 120 }, { name: "ペン", price: 80 }]
( ) で囲まない
products.map((p) => { name: p.name })
✕ { } が本体と読まれ、何も返しません。結果は [undefined, undefined] です
( ) で囲む
products.map((p) => ({ name: p.name }))
○ オブジェクトが返ります

戻り値の型を Pick<Product, "name">[] にした関数の中で、囲まないほうを返すと、型の確認でエラーになります。{ } の本体で書いて、中で return してもかまいません。

サンプル 
// tags2 を作り、products の要素を 1 つずつ p として、次のオブジェクトに変えた新しい配列を入れる
const tags2 = products.map((p) => {
  // name が p の name、price が p の price のオブジェクトを返す
  return { name: p.name, price: p.price };
});

4 つの型は、= の右の unknown を書き換えます。PublicUser は問3、UserSummary は問2、NewUser は問6、UserUpdate は問14 と同じ形です。toPublic は問8、toSummary は問7 と同じ形で、どちらも必要なプロパティだけを書いた新しいオブジェクトを返します。createUser は問11 と同じ形で、引数の名前を id と createdAt にすれば、どちらも省略記法で書けます。applyUpdate は問14 の patchUser と同じ形です。

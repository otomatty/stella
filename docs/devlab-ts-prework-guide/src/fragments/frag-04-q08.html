q08 文字列の解析

文字列を読み取って、数値や配列に変える関数を 20 個書きます。★総合問題（コマンドの解析）で使う書き方を、少しずつくり返す問題です。文字列を .split() や .slice() で分け、数値に変えます。形がおかしいときは Error を投げます。メッセージは問題文のとおりにします。問題文の <text> のところには、受け取った文字列をそのまま入れます。数値かどうかは Number() と Number.isFinite、整数かどうかは Number.isInteger で確かめます。引数と戻り値の型注釈は、自分で書きます。

問1"key=value" を [key, value] にする 新しい書き方はありません。 
export function parseKeyValue() {}

"key=value" の形の文字列を、最初の "=" の前と後ろに分けます。2 つの文字列のタプルにして返します。"=" が 2 つ以上あっても、分けるのは最初の "=" だけです。"=" がなければ、"= がありません: <text>" というメッセージの Error を投げます。

テストで確かめる値
parseKeyValue("a=1")
["a", "1"]
parseKeyValue("url=a=b")
["url", "a=b"]
最初の "=" で分ける
parseKeyValue("abc")
Error
メッセージは "= がありません: abc"

型引数が string、戻り値が [string, string] であることも確かめます。

ヒント 1日本語の手順

やることを、サンプルと同じ言い回しで書きました。1 行ずつコードに直してください。

// 関数 parseKeyValue を作る。文字列 text を受け取り、[文字列, 文字列] のタプルを返す
export function parseKeyValue() {
  // 位置 index を作り、text の中で "=" がある位置を入れる
  // もし index が -1 と等しいなら
  //   text を埋め込んだ「= がありません: ◯」というメッセージのエラーを投げる
  // text の 0 文字目から index 文字目の前まで、text の index + 1 文字目から後ろの順に並べたタプルを返す
}
ヒント 2コードへの直し方

位置は .indexOf()（01章 q05 問11）、取り出すのは .slice()（01章 q02 問10）です。戻り値の型 [string, string] はタプルです（02章 q06 問1）。.split("=") を使うと、"url=a=b" が 3 つに分かれてしまいます。そのため、ここでは位置で分けます。メッセージはテンプレートリテラルで作ります。

新しい書き方

Number("")

空の文字列を数値にすると 0 になる

Number() は、空の文字列 "" や空白だけの文字列を 0 にします。NaN（数ではないことを表す値）にはなりません。0 は有限の数で、整数でもあります。そのため、Number.isFinite や Number.isInteger で確かめても通ってしまいます。

サンプル 
// 入力 input を作り、空の文字列を入れる
const input = "";
// 数量 quantity を作り、input を数値にしたものを入れる
const quantity = Number(input);
// 結果: quantity は 0
Number("")
0
空の文字列
Number(" ")
0
空白だけでも 0
Number(undefined)
NaN
undefined は NaN
Number("3個")
NaN
数字以外がまじっている

区切った配列から既定値つきで取り出すとき（02章 q06 問12）に、この違いが効いてきます。

サンプル 
// 時刻 time を作り、"10" を入れる
const time = "10";
// time を ":" で区切り、0 番目を hour、1 番目を minute として取り出す。ないときは "" にする
const [hour = "", minute = ""] = time.split(":");
// 分 m を作り、minute を数値にしたものを入れる
const m = Number(minute);
// 結果: hour は "10"、minute は ""、m は 0

よくある間違い":" のない "10" でも、m は 0 になり、エラーになりません。分けた数を確かめるときは、区切った配列の要素の数 .length を見ます。既定値を付けずに parts[1] のように取り出すと、ない要素は undefined で、Number(undefined) は NaN です。

ヒント 1日本語の手順

やることを、サンプルと同じ言い回しで書きました。1 行ずつコードに直してください。

// 関数 parseClock を作る。文字列 text を受け取り、数値を返す

  // 時 hour を作り、parts の 0 番目を数値にしたものを入れる
  // 分 minute を作り、parts の 1 番目を数値にしたものを入れる
  // もし parts の要素の数が 2 でない、または hour が整数でない、または minute が整数でない、または hour が 0 より小さい、または hour が 23 より大きい、または minute が 0 より小さい、または minute が 59 より大きいなら
  //   text を埋め込んだ「時刻ではありません: ◯」というメッセージのエラーを投げる

ヒント 2コードへの直し方

parts[0] の型は string | undefined ですが、Number() にはそのまま渡せます。「要素の数が 2 でない」は parts.length !== 2、「整数でない」は !Number.isInteger(hour) です（01章 q04 応用）。「または」は || です（01章 q01 問15）。条件が長いときは、|| の前で改行してかまいません。

新しい書き方

.map(Number)

文字列の配列を、まとめて数値の配列にする

.map() には、名前を付けた関数を渡せます（02章 q04 問5）。Number() も関数なので、Number と名前だけを渡せます。要素を 1 つずつ数値にした、新しい配列ができます。.map((s) => Number(s)) と同じ結果です。

サンプル

// amounts を作り、inputs の要素を 1 つずつ Number に渡して変えた新しい配列を入れる

// 結果: amounts は [1200, 800, 50]。型は number[]
["10", "x"].map(Number)
[10, NaN]
数値にならない要素は NaN

型結果の型は number[] で、タプルではありません。const [y, m, d] = … と取り出すと、要素がないかもしれないので、型は number | undefined になります。そのまま [number, number, number] として返すと、型の確認でエラーになります。既定値（02章 q06 問12）を付けると、型が number になります。

新しい書き方

/…/.exec()

正規表現に合わせて、部分ごとに取り出す

正規表現は、01章 q05 問18 と q06 問13 で出ました。.exec() は、文字列が正規表現に合えば配列を、合わなければ null を返します。配列の 0 番目は合った部分の全体、1 番目からは ( ) で囲んだ部分です。

正規表現は 09章の発展問題でくわしく扱います。ここでは、この形をまねて書ければ十分です。

サンプル 
// 注文 order を作り、"3箱" を入れる
const order = "3箱";
// match を作り、order を正規表現 /^(\d+)(個|箱)$/ に合わせた結果を入れる
const match = /^(\d+)(個|箱)$/.exec(order);
// 結果: match は ["3箱", "3", "箱"]
/^(\d+)(個|箱)$/.exec("12個")
["12個", "12", "個"]
/^(\d+)(個|箱)$/.exec("3袋")
null
単位が違う
/^(\d+)(個|箱)$/.exec("約3箱")
null
先頭が数字でない
/^(\d+)(個|箱)$/.exec("箱")
null
数字がない

null のときを先に if で外すと、そのあとは配列として使えます。

サンプル 
// 関数 countOf を作る。文字列 order を受け取り、数値を返す
function countOf(order: string): number {
  // match を作り、order を正規表現 /^(\d+)(個|箱)$/ に合わせた結果を入れる
  const match = /^(\d+)(個|箱)$/.exec(order);
  // もし match が null と等しいなら
  if (match === null) {
    // 「数量ではありません: ◯」というメッセージのエラーを投げる（◯ は order）
    throw new Error(`数量ではありません: ${order}`);
  }
  // count を作り、match の 1 番目を数値にしたものを入れる
  const count = Number(match[1]);
  // もし match の 2 番目が "箱" と等しいなら
  if (match[2] === "箱") {
    // count × 12 を返す
    return count * 12;
  }
  // count を返す
  return count;
}
// 結果: countOf("3箱") は 36、countOf("5個") は 5

型配列の要素を [ ] で取り出したときと同じく、match[1] の型は string | undefined です。Number() にはそのまま渡せます。=== で文字列と比べることもできます。

総合コマンドの解析（小さな電卓） 新しい書き方はありません。 
import { errorMessage } from "./q05-exception";
import { toNumber } from "./q06-unknown";
import { assertNever } from "./q07-never";

export type Command = { op: "add" | "sub" | "mul" | "div"; a: number; b: number };

export type RunResult = { ok: true; value: number } | { ok: false; error: string };

export function parseCommand() {}

export function execute() {}

export function run() {}

export function runAll() {}

"add 3 5" のような文字列のコマンドを読み取って計算する、小さな電卓を作ります。型 Command と RunResult は定義済みです。関数を 4 つ書きます。引数と戻り値には型注釈を付けます。

  1. parseCommand(text)：文字列を Command にします。前後の空白を取り除き、空白（いくつ続いてもよい）で区切ります。3 つに区切れないときは "書き方が正しくありません: <text>"、1 つ目が add・sub・mul・div のどれでもないときは "知らない計算です: <1つ目>"、2 つ目か 3 つ目が有限の数値でないときは "数値ではありません: <その文字列>" の Error を投げます。
  2. execute(command)：計算して結果を返します。switch で op ごとに分けます。div で b が 0 なら、"0で割ることはできません" の Error を投げます。
  3. run(text)：parseCommand と execute を順に呼びます。成功なら { ok: true, value } を返します。途中で例外が出たら catch して、{ ok: false, error: メッセージ } を返します。
  4. runAll(lines)：1 行ずつ run します。成功なら "add 3 5 = 8"（前後の空白を除いた元の行、" = "、結果）、失敗なら "エラー: メッセージ" を並べた配列を返します。引数は readonly string[] です。

前の問題で書いた関数を 3 つ使います。どれも、ファイルの先頭で読み込んであります（02章 q08 総合）。parseCommand の数値の読み取りには q06 の toNumber を使い、null なら "数値ではありません: …" の Error を投げます。execute の switch の default では、q07 の assertNever を使います。run の catch では、q05 の errorMessage でメッセージを取り出します。前の問題が解けていないと、この問題のテストも通りません。

ヒント 2コードへの直し方

parseCommand の区切り方と取り出し方は、問16 と同じです。op が 4 つのどれでもないかは、!== を && でつないで確かめます。その if を抜けたあとは、問15 と同じく op の型が "add" | "sub" | "mul" | "div" に絞り込まれます。そのため、{ op, a, b }（02章 q01 問3）をそのまま Command として返せます。toNumber は number | null を返すので、=== null で確かめると、そのあとは number になります。execute の取り出しは 02章 q03 問1 の分割代入、default は return assertNever(op); です（04章 q07）。run の「次の中を試す」は try、「例外が投げられたら、投げられたものを error で受け取る」は catch (error) です（04章 q05）。runAll は、.map() に { } のある関数（02章 q04 問19）を渡します。if (result.ok) の中では result.value が、if を抜けたあとは result.error が使えます。

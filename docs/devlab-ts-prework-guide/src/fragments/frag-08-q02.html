q02 async と await

ユーザーを取得する非同期の関数を 20 個書きます。この番号では、async と await を使って書きます。型 User と、関数 fetchUser・wait は、ファイルに書いてあります。fetchUser(id) は、id のユーザーで解決する Promise を返します。いない id なら、"ユーザー 9 はいません" のような Error で失敗します。戻り値の型は Promise<number> のように、中身の型まで書きます。async 関数の中では、Promise の結果を await で受け取ります。.then() は使いません。失敗を受け止めるときは try・catch を使います。try の中で Promise を return するときは、return await と書きます。

問1fetchUser で取得して、年齢を返す 新しく出てくる書き方：async、戻り値の型 Promise<number>、await 
export type User = { id: number; name: string; age: number };

const USERS: User[] = [
  { id: 1, name: "山田", age: 34 },
  { id: 2, name: "佐藤", age: 19 },
  { id: 3, name: "鈴木", age: 52 },
  { id: 4, name: "田中", age: 20 },
];

// id のユーザーを取得する。いなければ失敗する
export function fetchUser(id: number): Promise<User> {
  const user = USERS.find((u) => u.id === id);
  return user === undefined
    ? Promise.reject(new Error(`ユーザー ${id} はいません`))
    : Promise.resolve(user);
}

export function getAge() {}

この番号のサンプルでは、商品を取得する関数 fetchProduct と、待つ関数 wait を使います。fetchProduct は問題の fetchUser と同じ作りで、wait は 08章 q01 問3 と同じものです。

サンプルで使う関数 
// 型 Product を作る。code と name は文字列、price と stock は数値
type Product = { code: string; name: string; price: number; stock: number };

// 商品の一覧 PRODUCTS を作り、3 つの商品を入れる
const PRODUCTS: Product[] = [
  { code: "A1", name: "ノート", price: 120, stock: 30 },
  { code: "B2", name: "ペン", price: 80, stock: 0 },
  { code: "C3", name: "消しゴム", price: 60, stock: 15 },
];

// 関数 fetchProduct を作る。文字列 code を受け取り、Product で解決する Promise を返す
function fetchProduct(code: string): Promise<Product> {
  // 商品 product を作り、PRODUCTS から code が等しい商品を探して入れる
  const product = PRODUCTS.find((p) => p.code === code);
  // product が undefined なら「商品 ◯ はありません」の Error で失敗する Promise、そうでなければ product で解決する Promise を返す
  return product === undefined
    ? Promise.reject(new Error(`商品 ${code} はありません`))
    : Promise.resolve(product);
}

// 関数 wait を作る。数値 ms を受け取り、ms ミリ秒たったら解決する Promise を返す
function wait(ms: number): Promise<void> {
  return new Promise((resolve) => {
    setTimeout(resolve, ms);
  });
}

function の前に async を付けた関数を、async 関数（非同期の関数）と呼びます。async 関数の中では、次の項目の await が使えます。

async 関数は、呼ぶといつも Promise を返します。中で return した値は、すぐには呼んだ側に渡りません。その値で、返した Promise が解決します。そのため、戻り値の型は Promise<T> の形で書きます。T のところには、return する値の型を書きます。

サンプル 
// 非同期の関数 priceOf を作る。文字列 code を受け取り、数値で解決する Promise を返す
async function priceOf(code: string): Promise<number> {
  // 商品 product を作り、fetchProduct に code を渡して呼んだ結果を待って入れる
  const product = await fetchProduct(code);
  // product の price を返す
  return product.price;
}
// 結果: priceOf("A1") は 120 で解決する

○ 数値で解決する Promise を返す関数です

よくある間違い呼んだ側が受け取るのは Promise です。数値はまだ取り出せていません。priceOf("A1") + 10 と書くと、Promise に数を足そうとして、型の確認でエラーになります。呼んだ側も、await か .then() で中身を取り出します。

決まり中で await を 1 つも使わない async 関数は、ESLint が止めます（require-await）。await を使わないなら、async は付けません。

.then() で書く（08章 q01）

○ 続きは、then に渡す関数の中に書きます

○ 同じ結果です。続きを次の行に書けます

どちらも priceOf("A1") は 120 で解決します。取り出す値が増えると、.then() はつなぐ関数が増えていきます。await なら、ふつうの関数と同じように 1 行ずつ書けます。この番号では、await で書きます。

順番 3 で止まるのは、checkStock の中だけです。止まっている間も、呼んだ側は先へ進みます。await の後ろの行は、Promise が解決し、いま動いている処理がひと区切りついてから動きます。そのため、"呼んだ側は先へ進む" が "取得が終わる" より先に入ります。

値を受け取らずに、終わるのを待つだけのときもあります。そのときは、await の行の結果を変数に入れません。

サンプル 
// 非同期の関数 delayedNotice を作る。文字列 message を受け取り、文字列で解決する Promise を返す
async function delayedNotice(message: string): Promise<string> {
  // wait に 500 を渡して呼んだ結果を待つ
  await wait(500);
  // message を埋め込んだ「お知らせ: ◯」の文字列を返す
  return `お知らせ: ${message}`;
}
// 結果: delayedNotice("本日発送") は、500 ミリ秒たってから "お知らせ: 本日発送" で解決する

いくつかの取得を一度に始めて、まとめて待つ

Promise.all は、Promise の配列を受け取り、全部が解決したら「値の配列」で解決する Promise を返します（08章 q01 問13）。その Promise を await すると、値の配列が手に入ります。配列の分割代入（02章 q06 問2）で、1 つずつ名前を付けて取り出せます。

サンプル 
// 非同期の関数 setPrice を作る。文字列 a と文字列 b を受け取り、数値で解決する Promise を返す
async function setPrice(a: string, b: string): Promise<number> {
  // a と b の商品の取得を一度に始め、両方の結果を待って first と second に取り出す
  const [first, second] = await Promise.all([fetchProduct(a), fetchProduct(b)]);
  // first の price と second の price を足した数を返す
  return first.price + second.price;
}
// 結果: setPrice("A1", "C3") は 180 で解決する

テストの task は、呼ばれると記録に「開始 ◯」を足し、少し待ってから「終了 ◯」を足して、◯ の文字列で解決します。

runInOrder([a を返す task, b を返す task])
["a", "b"] で解決する
そのときの記録
["開始 a", "終了 a", "開始 b", "終了 b"]
a が終わってから b を呼ぶ

型戻り値が Promise<string[]> であることも確かめます。

新しい書き方

readonly (() => Promise<boolean>)[]

関数の配列の型

関数の型（05章 q07 問1）を、かっこ ( ) で囲んでから [] を付けると、「その形の関数の配列」の型になります。読み取り専用にするときは、02章 q04 問1 と同じく、前に readonly を付けます。何も受け取らない関数の型は、引数のかっこを空にして () => … と書きます。

サンプル 
// 非同期の関数 countReady を作る。読み取り専用の「何も受け取らず、true か false で解決する Promise を返す関数」の配列 checks を受け取り、数値で解決する Promise を返す
async function countReady(checks: readonly (() => Promise<boolean>)[]): Promise<number> {
  // 数 count を入れ直せる変数として作り、0 を入れる
  let count = 0;
  // checks から 1 つずつ check に取り出してくり返す
  for (const check of checks) {
    // もし check を呼んだ結果を待ったものが true なら
    if (await check()) {
      // count に 1 を足す
      count += 1;
    }
  }
  // count を返す
  return count;
}
// 確認の一覧 checks を作り、true で解決する関数、false で解決する関数、true で解決する関数を入れる
const checks = [
  () => Promise.resolve(true),
  () => Promise.resolve(false),
  () => Promise.resolve(true),
];
// 結果: countReady(checks) は 2 で解決する

配列から取り出した check は関数なので、check() と呼びます。呼ぶと Promise が返るので、await check() で結果を待ちます。

かっこで囲まない
checks: () => Promise<boolean>[]
✕ 「Promise の配列を返す関数」1 つの型になります。for...of で回せず、型の確認でエラーになります
かっこで囲む
checks: readonly (() => Promise<boolean>)[]
○ 「Promise を返す関数」の配列です

よくある間違いかっこで囲まずに readonly () => Promise<boolean>[] と書くと、readonly は関数の型に付けられないので、文法のエラーになります。

ヒント 2コードへの直し方

問18 の for...of の中に、問15 と同じく try・catch を入れます。「くり返しを抜ける」は break です（04章 q04 問11）。抜けたあとは、くり返しの後ろの return results; に進みます。

応用受け取った fetchUser で、1 人・順番に・一度に取得する 新しい書き方はありません。 
export type User = { id: number; name: string };
export type FetchUser = (id: number) => Promise<User>;

export function getUserName() {}

export function getUsersInOrder() {}

export function getUsersAtOnce() {}

export function getNamesText() {}

ユーザーを 1 人取得する非同期の関数 fetchUser を、引数で受け取ります。型は FetchUser で、id を受け取り User で解決する Promise を返す関数です。ドリルと違い、User に age はありません。4 つの関数を、async と await で書きます。

  1. getUserName(fetchUser, id)：ユーザーを取得して、名前を返します。
  2. getUsersInOrder(fetchUser, ids)：ids のユーザーを、for...of と await で 1 人ずつ順番に取得します。前の人の取得が終わってから、次の人の取得を始めます。ids の順のユーザーの配列を返します。
  3. getUsersAtOnce(fetchUser, ids)：ids のユーザーの取得を一度に始め、Promise.all で全部を待ちます。ids の順のユーザーの配列を返します。
  4. getNamesText(fetchUser, ids)：getUsersAtOnce を使って取得し、名前を "、" でつないだ文字列を返します。ids が空なら "" です。

説明すること：ids が 10 件で、1 件の取得に 1 秒かかるとき、getUsersInOrder と getUsersAtOnce はそれぞれ何秒かかるか。順番に取得しなければならないのは、どんなときか。答えは、ファイルの「説明すること」のすぐ下に // のコメントで書きます。

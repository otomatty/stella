q05 複数のAPIの結果をまとめる

いくつかの API の結果を組み合わせる関数を 20 個と、★総合問題を書きます。API の代わりに、定義済みの関数 getUser・getPosts・getComments を使います。どれも Promise を返します。書くときは、async・await と、Promise.all・Promise.allSettled を使います。前の結果を使わない取得は、一度に始めて、まとめて待ちます。問題に「順番に」と書いてあるときだけ、1 つずつ待ちます。getUser はいない id だと失敗し、getPosts(3) はいつも失敗します。引数と戻り値の型注釈も自分で書きます。

問1ユーザーと投稿を同時に取得する 新しく出てくる書き方：種類の違う取得を同時に待つ const [a, b] = await Promise.all([…])、順番に待つ書き方との違い 
export type User = { id: number; name: string };

export type Post = { id: number; userId: number; title: string };

const USERS: User[] = [
  { id: 1, name: "山田" },
  { id: 2, name: "佐藤" },
  { id: 3, name: "鈴木" },
  { id: 4, name: "田中" },
];

const POSTS: Post[] = [
  { id: 10, userId: 1, title: "TypeScript を始めました" },
  { id: 11, userId: 1, title: "型注釈のこつ" },
  { id: 12, userId: 2, title: "非同期処理のまとめ" },
  { id: 13, userId: 1, title: "ジェネリクスに挑戦" },
];

// id のユーザーを取得する。いなければ失敗する
export function getUser(id: number): Promise<User> {
  const user = USERS.find((u) => u.id === id);
  return user === undefined
    ? Promise.reject(new Error(`ユーザー ${id} はいません`))
    : Promise.resolve(user);
}

// ユーザーの投稿を取得する。userId が 3 なら失敗する
export function getPosts(userId: number): Promise<Post[]> {
  return userId === 3
    ? Promise.reject(new Error("投稿を取得できません"))
    : Promise.resolve(POSTS.filter((p) => p.userId === userId));
}

export function userWithPosts() {}

ユーザーと、そのユーザーの投稿を取得して、{ user, posts } のオブジェクトで返します。getUser と getPosts は、どちらも相手の結果を使いません。そこで、2 つを同時に始めて、Promise.all でまとめて待ちます。どちらかが失敗したら、その失敗をそのまま投げます。

問2 から後ろの問題でも、型 User・Post と、getUser・getPosts は、この形で定義済みです。問2 からは、関数の形だけを載せます。

新しい書き方

順番に待つ・まとめて待つ

Promise を返す関数を 2 つ呼ぶとき、待ち方は 2 通りあります。08章 q02 の問7 では、1 つずつ順番に await しました。問8 では、Promise.all でまとめて待ちました。この番号では、取得する中身が違う 2 つを、まとめて待つ書き方を使います。

サンプルでは、API の代わりに次の関数を使います。どれも 100 ミリ秒たってから結果を返します。

サンプルで使う関数 
// 商品の型 Product を作る。id は数値、name は文字列
type Product = { id: number; name: string };
// レビューの型 Review を作る。productId は数値、stars は数値
type Review = { productId: number; stars: number };

// 商品の一覧 PRODUCTS を作る
const PRODUCTS: Product[] = [
  { id: 1, name: "ノート" },
  { id: 2, name: "ペン" },
  { id: 3, name: "消しゴム" },
];

// レビューの一覧 REVIEWS を作る
const REVIEWS: Review[] = [
  { productId: 1, stars: 5 },
  { productId: 1, stars: 3 },
  { productId: 2, stars: 4 },
];

// 関数 wait を作る。数値 ms を受け取り、ms ミリ秒たったら解決する Promise を返す
function wait(ms: number): Promise<void> {
  // 新しい Promise を返す
  return new Promise((resolve) => {
    // ms ミリ秒たったら resolve を呼ぶ
    setTimeout(resolve, ms);
  });
}

// 関数 getProduct を作る。id の商品を取得する（100 ミリ秒かかる）。ない id なら失敗する
async function getProduct(id: number): Promise<Product> {
  // 100 ミリ秒待つ
  await wait(100);
  // product を作り、PRODUCTS の要素を 1 つずつ p として、p の id が id と等しい最初のもの（なければ undefined）を入れる
  const product = PRODUCTS.find((p) => p.id === id);
  // もし product が undefined なら
  if (product === undefined) {
    // 「商品 ◯ はありません」というメッセージのエラーを投げる（◯ は id）
    throw new Error(`商品 ${id} はありません`);
  }
  // product を返す
  return product;
}

// 関数 getStock を作る。商品の在庫の数を取得する（100 ミリ秒かかる）。id が 3 なら失敗する
async function getStock(productId: number): Promise<number> {
  // 100 ミリ秒待つ
  await wait(100);
  // もし productId が 3 と等しいなら
  if (productId === 3) {
    // "在庫を確認できません" というメッセージのエラーを投げる
    throw new Error("在庫を確認できません");
  }
  // productId に 10 をかけた数を返す
  return productId * 10;
}

// 関数 getReviews を作る。商品のレビューを取得する（100 ミリ秒かかる）
async function getReviews(productId: number): Promise<Review[]> {
  // 100 ミリ秒待つ
  await wait(100);
  // REVIEWS から、productId が productId と等しいものだけを残した新しい配列を返す
  return REVIEWS.filter((r) => r.productId === productId);
}
// 結果: getProduct(1) は { id: 1, name: "ノート" } で、getStock(1) は 10 で解決する

まず、順番に待つ書き方です。await を 2 回書きます。

サンプル 
// 関数 stockInOrder を作る。数値 id を受け取り、{ name, stock } で解決する Promise を返す
async function stockInOrder(id: number): Promise<{ name: string; stock: number }> {
  // product を作り、getProduct(id) の結果を待って入れる
  const product = await getProduct(id);
  // stock を作り、getStock(id) の結果を待って入れる

次に、まとめて待つ書き方です。2 つの Promise を配列に並べて Promise.all に渡し、await は 1 回だけ書きます。

サンプル 
// 関数 stockAtOnce を作る。数値 id を受け取り、{ name, stock } で解決する Promise を返す
async function stockAtOnce(id: number): Promise<{ name: string; stock: number }> {
  // getProduct(id) と getStock(id) を同時に始め、両方の結果を待って、product と stock に取り出す
  const [product, stock] = await Promise.all([getProduct(id), getStock(id)]);
  // name に product の name、stock に stock を入れたオブジェクトを返す
  return { name: product.name, stock };
}
// 結果: stockAtOnce(1) は { name: "ノート", stock: 10 } で解決する（約 100 ミリ秒かかる）
// 結果: stockAtOnce(3) は "在庫を確認できません" の Error で失敗する
await を付け忘れる
const [product, stock] = Promise.all([getProduct(id), getStock(id)]);
✕ Promise.all が返すのは Promise です。そのままでは分割代入できず、型の確認でエラーになります
await で待つ
const [product, stock] = await Promise.all([getProduct(id), getStock(id)]);
○ 中身の [Product, number] を取り出せます

どちらかが失敗したらPromise.all は、渡した Promise のどれか 1 つが失敗すると、すぐにその Error で失敗します。await の行で例外が投げられ、関数の残りは実行されません。

取得する数が決まっていないときは、.map() で Promise の配列を作ってから Promise.all に渡します（08章 q02 問10）。結果の並びは、渡した配列の並びと同じです。終わった順には並びません。

サンプル 
// 関数 stocksOf を作る。数値の配列 ids を受け取り、数値の配列で解決する Promise を返す
async function stocksOf(ids: readonly number[]): Promise<number[]> {
  // stocks を作り、ids から 1 つずつ getStock を呼んで同時に始め、すべての結果を待って入れる
  const stocks = await Promise.all(ids.map((id) => getStock(id)));
  // stocks を返す
  return stocks;
}
// 結果: stocksOf([2, 1]) は [20, 10] で解決する

順番に待つとき前の結果を使う取得は、順番に待ちます。たとえば、投稿を取得してから、その投稿の id でコメントを取得するときです（問10）。前の結果を使わないなら、まとめて待つほうが早く終わります。

新しい書き方

await Promise.allSettled(…)

失敗があっても、全部の結果を待つ

Promise.all は、1 つでも失敗すると失敗します（問1）。1 つ失敗しても残りの結果を使いたいときは、Promise.allSettled を使います（08章 q01 問17）。Promise.allSettled は失敗しません。全部が終わると、1 つずつの結果を並べた配列で解決します。async の関数の中では、Promise.all と同じように await で待ちます。

サンプル 
// 関数 foundCount を作る。数値の配列 ids を受け取り、数値で解決する Promise を返す
async function foundCount(ids: readonly number[]): Promise<number> {
  // results を作り、ids から 1 つずつ getProduct を呼んで同時に始め、成功も失敗もすべて終わるのを待って入れる
  const results = await Promise.allSettled(ids.map((id) => getProduct(id)));
  // results から、status が "fulfilled" のものだけを残した新しい配列の要素の数を返す
  return results.filter((r) => r.status === "fulfilled").length;
}
// 結果: foundCount([1, 9, 2]) は 2 で解決する

foundCount([1, 9, 2]) のとき、results の中身は次のようになります。

位置ids の値statusvalue または reason
01"fulfilled"value: { id: 1, name: "ノート" }
19"rejected"reason: Error（"商品 9 はありません"）
22"fulfilled"value: { id: 2, name: "ペン" }

結果の配列は、ids と同じ数で、同じ順に並びます。成功した結果は status が "fulfilled" で、value に値が入ります。失敗した結果は status が "rejected" で、reason に失敗の理由が入ります（08章 q01 問18・問19）。

よくある間違いvalue を読む前に、status が "fulfilled" かを確かめます。確かめずに r.value と書くと、失敗の結果には value がないので、型の確認でエラーになります。

export function commentsOfUser() {}

新しい書き方

.flat()

配列の配列を 1 つにつなぐ

配列の中に配列が並んでいるものを、配列の配列と呼びます。型は number[][] のように、[] を 2 つ重ねて書きます。.flat() は、中の配列を前から順につないで、1 つの新しい配列を作ります。元の配列は変わりません。

サンプル 
// lists を作り、数値の配列を 3 つ並べた配列を入れる
const lists = [[5, 3], [], [4]];
// all を作り、lists の中の配列を 1 つにつないだ新しい配列を入れる
const all = lists.flat();
// 結果: all は [5, 3, 4]

Promise.all で取得した結果をまとめるときに、よく使います。getReviews は 1 つの商品のレビューを配列で返します。何件かの商品ぶんをまとめて待つと、結果は配列の配列になります。

サンプル 
// 関数 starsOf を作る。数値の配列 ids を受け取り、数値の配列で解決する Promise を返す
async function starsOf(ids: readonly number[]): Promise<number[]> {
  // reviewLists を作り、ids から 1 つずつ getReviews を呼んで同時に始め、すべての結果を待って入れる
  const reviewLists = await Promise.all(ids.map((id) => getReviews(id)));
  // reviewLists の中の配列を 1 つにつなぎ、それぞれを stars だけにした新しい配列を返す
  return reviewLists.flat().map((r) => r.stars);
}
// 結果: starsOf([1, 2]) は [5, 3, 4] で解決する
式値型
reviewLists[[{ productId: 1, stars: 5 }, { productId: 1, stars: 3 }], [{ productId: 2, stars: 4 }]]Review[][]
reviewLists.flat()[{ productId: 1, stars: 5 }, { productId: 1, stars: 3 }, { productId: 2, stars: 4 }]Review[]
….map((r) => r.stars)[5, 3, 4]number[]

よくある疑問つなぐのは 1 段だけです。[[1, [2]], [3]].flat() は [1, [2], 3] になります。08章 q01 問18 の .flatMap() は、.map() のあとに .flat() をするのと同じ働きです。

決まった数ずつ区切ってくり返す

for (;;) の 3 つめに i += size と書くと、i が 1 回ごとに size ずつ増えます（01章 q01 問5）。.slice(i, i + size) と組み合わせると、配列を前から size 個ずつ取り出せます（02章 q05 問3）。最後の区切りが size 個に足りなくても、.slice() は残りだけを返します。

サンプル 
// 関数 groupsOf を作る。文字列の配列 codes と数値 size を受け取り、文字列の配列の配列を返す
function groupsOf(codes: readonly string[], size: number): string[][] {
  // groups を作り、空の配列を入れる
  const groups: string[][] = [];
  // i を 0 から、codes の要素の数より小さい間 size ずつ増やしながらくり返す
  for (let i = 0; i < codes.length; i += size) {
    // groups の最後に、codes の i 番目から i + size 番目の前までを取り出した新しい配列を付け足す
    groups.push(codes.slice(i, i + size));
  }
  // groups を返す
  return groups;
}
// 結果: groupsOf(["A1", "A2", "B1", "B2", "C1"], 2) は [["A1", "A2"], ["B1", "B2"], ["C1"]]

Math.min()Math.max()

いちばん小さい数、いちばん大きい数

かっこの中に数をいくつか並べると、いちばん小さい数（min）、いちばん大きい数（max）を返します。

Math.min(3, 9, 2)
2
3 つ以上も並べられます。
Math.max(3, 9, 2)

コツMath.max(◯, 0) は「0 より下にしない」、Math.min(◯, 100) は「100 より上にしない」という意味になります。

新しい書き方

!

true と false を反対にする

! を前に付けると、true は false に、false は true になります。「〜でない」と書きたいときに使います。

サンプル 
function isUnpaid(isPaid: boolean): boolean {
  // isPaid の反対（true なら false、false なら true）を返す
  return !isPaid;
}
// 結果: isUnpaid(true) は false、isUnpaid(false) は true
Number.isInteger()

整数かを調べる

サンプル 
// 数量 quantity を作り、2.5 を入れる
const quantity = 2.5;
// isWhole を作り、quantity が整数か（true か false）を入れる

! と組み合わせると、「整数でないなら」と書けます。

サンプル 
function checkBoxes(boxes: number): number {
  // もし boxes が整数でないなら
  if (!Number.isInteger(boxes)) {
    // "箱の数は整数にしてください" というメッセージのエラーを投げる
    throw new Error("箱の数は整数にしてください");
  }
  // boxes を返す
  return boxes;
}
// 結果: checkBoxes(3) は 3。checkBoxes(2.5) はエラーになる

ヒント 2コードへの直し方

「有限の数でない」「整数でない」は、Number.isFinite() や Number.isInteger() の前に ! を付けます。「または」は ||、「10 の digits 乗」は ** です。最後の行は問19 と同じ考え方で、100 の代わりに scale を使います。percent の中では、自分で作った roundTo を呼びます（q01 の問20）。メッセージの文は自由です。

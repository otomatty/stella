05章 関数

q05 残余引数

いくつでも引数を受け取れる関数を 20 個書きます。引数と戻り値の型注釈は自分で書きます。いくつでも受け取る引数は、...numbers: number[] のように、名前の前に ... を付けて書きます。これを残余引数と呼びます。残余引数は、引数の並びの最後にしか書けません。「1 つ以上」と書いた問題では、1 つ目を普通の引数にして、残りを残余引数にします。こうすると、引数なしで呼んだときに型エラーになります。

問1すべての数の合計を返す 新しく出てくる書き方：残余引数 ...numbers: number[] 
export function total() {}

数をいくつでも受け取り、すべて足した合計を返します。引数がなければ 0 を返します。受け取る引数は配列ではありません。total(1, 2, 3) のように、ばらばらに並んだ数です。

テストで確かめる値
total(1, 2, 3)
6
total()
0
引数がない

型引数が number[]（数値がいくつでも）、戻り値が number であることも確かめます。

新しい書き方

...totals: number[]

いくつでも引数を受け取る（残余引数）

引数の名前の前に ... を付けると、その引数は値をいくつでも受け取れます。受け取った値は、渡した順に 1 つの配列にまとまって入ります。これを残余引数と呼びます。型は、まとまったあとの配列の型（number[] など、01章 q08）で書きます。

サンプル 
// 関数 countFreeShipping を作る。数値をいくつでも totals として受け取り、数値を返す
function countFreeShipping(...totals: number[]): number {
  // 件数 count を入れ直せる変数として作り、0 を入れる
  let count = 0;
  // totals から 1 つずつ total に取り出してくり返す
  for (const total of totals) {
    // もし total が 5000 以上なら
    if (total >= 5000) {
      // count に 1 を足す
      count += 1;
    }
  }
  // count を返す
  return count;
}
// 結果: countFreeShipping(6000, 3000, 5000) は 2、countFreeShipping() は 0
countFreeShipping(6000, 3000, 5000)
totals は [6000, 3000, 5000]
countFreeShipping(6000)
totals は [6000]
1 つでも配列になる
countFreeShipping()
totals は []
引数なしでも呼べる。空の配列になる

関数の中では、totals は普通の配列です。for (const … of …) のくり返し、.length、.join() など、配列で使えるものはそのまま使えます。

決まり残余引数は、引数の並びの最後にしか書けません。function labelOf(...words: string[], mark: string) のように後ろに普通の引数を続けると、型の確認でエラーになります（A rest parameter must be last in a parameter list.）。

よくある間違い02章 q04 では、読み取り専用の配列 readonly number[] を使いました。この番号のテストは、残余引数の型が number[] であることを確かめます。...numbers: readonly number[] と書くと、型のテストが通りません。

サバイバルTypeScript「残余引数」

f(...a)

引数のスプレッド構文との違い

02章 q04 問12 の Math.max(...prices) でも ... を使いました。同じ記号ですが、書く場所によって働きが反対になります。

関数を作るとき：残余引数
function countFreeShipping(...totals: number[]): number {
ばらばらの値を、1 つの配列にまとめます
関数を呼ぶとき：スプレッド構文
countFreeShipping(...orderTotals);
1 つの配列を、ばらばらの値に広げます

残余引数の関数に配列を渡したいときは、呼ぶ側でスプレッド構文を使って広げます。広げられた値は、関数の中でもう一度 1 つの配列にまとまります。

サンプル 
// 注文の合計 orderTotals を作り、[6000, 3000, 5000] を入れる
const orderTotals = [6000, 3000, 5000];
// freeCount を作り、orderTotals の要素をばらばらに countFreeShipping に渡した結果を入れる
const freeCount = countFreeShipping(...orderTotals);
// 結果: freeCount は 2
... を付けない
const freeCount = countFreeShipping(orderTotals);
✕ 配列 1 つを、数値 1 つとして渡したことになります。型の確認でエラーになります（Argument of type 'number[]' is not assignable to parameter of type 'number'.）
... を付ける
const freeCount = countFreeShipping(...orderTotals);
○ 要素が 1 つずつ渡り、中で [6000, 3000, 5000] にまとまります

よくある疑問02章 q07 問18 の [first, ...rest] も、「残りを 1 つの配列にまとめる」働きでした。残余引数は、同じ考え方を関数の引数に使ったものです。

新しい書き方

(main: string, ...others: string[])

1 つ以上を受け取る

残余引数の前には、普通の引数を並べられます。普通の引数は省略できないので、引数なしの呼び出しは型エラーになります。こうして「1 つ以上」を型で決められます。

サンプル 
// 関数 headline を作る。文字列の main と、文字列をいくつでも others として受け取り、文字列を返す
function headline(main: string, ...others: string[]): string {
  // main と others の要素の数を埋め込んだ「◯ほか◯件」の文字列を返す
  return `${main}ほか${others.length}件`;
}
// 結果: headline("ペン", "ノート", "のり") は "ペンほか2件"、headline("ペン") は "ペンほか0件"
headline("ペン", "ノート", "のり")
"ペンほか2件"
main は "ペン"、others は ["ノート", "のり"]
headline("ペン")
"ペンほか0件"
others は []
headline()
型エラー
Expected at least 1 arguments, but got 0.

テストの [number, ...number[]] は、引数の並びを表す型です。「1 つ目が数値で、そのあとに数値がいくつでも続く」という意味です。(first: number, ...rest: number[]) と書くと、引数の並びがこの型になります。

呼ぶ側のかっこには、普通の値とスプレッド構文を並べて書けます。

サンプル 
// 基本の送料 base を作り、500 を入れる

// 地域の送料 extras を作り、[800, 300] を入れる
const extras = [800, 300];
// highest を作り、base と extras の要素をばらばらに Math.max に渡した結果を入れる
const highest = Math.max(base, ...extras);
// 結果: highest は 800
Math.max(500, ...[800, 300])
800
Math.max(500, 800, 300) と同じ
Math.max(500, ...[])
500
広げる配列が空なら、Math.max(500) と同じ

02章 オブジェクト・配列・タプル

q06 タプル

タプルを使う関数を 20 個書きます。タプルは、決まった数の値を決まった順に並べた配列です。型は [number, number] のように、要素の型を順に並べて書きます。引数と戻り値には型注釈を付けます。タプルから要素を取り出すときは、const [x, y] = point; のような配列の分割代入を使うと読みやすくなります。

問1名前と数を、[名前, 数] のタプルにする 新しく出てくる書き方：タプルの型 [string, number] 
export function makePair() {}

名前（文字列）と数（数値）を受け取り、名前、数の順に並べたタプルを返します。戻り値の型は、2 つの要素の型を順に並べたタプルの型にします。

テストで確かめる値
makePair("りんご", 3)
["りんご", 3]

型引数が string と number、戻り値が [string, number] であることも確かめます。

新しい書き方

[string, number]

タプルの型

タプルは、要素の数と、何番目に何の型が入るかが決まっている配列です。型は [ ] の中に、要素の型を順に並べて書きます。値の作り方は、ふつうの配列と同じです。

サンプル 
// 予約 reservation を [文字列, 数値] のタプルとして作り、["会議室A", 8] を入れる
const reservation: [string, number] = ["会議室A", 8];
// 結果: reservation の 0 番目は "会議室A"、1 番目は 8

関数の戻り値をタプルにするときは、かっこの後ろの戻り値の型注釈にタプルの型を書きます。要素は 3 つ以上でもかまいません。

サンプル 
// 関数 shipment を作る。文字列 orderId と数値 boxes と true か false の express を受け取り、[文字列, 数値, true か false] のタプルを返す
function shipment(orderId: string, boxes: number, express: boolean): [string, number, boolean] {
  // orderId、boxes、express の順に並べたタプルを返す
  return [orderId, boxes, express];
}
// 結果: shipment("ORD-001", 2, true) は ["ORD-001", 2, true]

型と合わない値を入れると、型の確認でエラーになります。

const r: [string, number] = [8, "会議室A"];
型のエラー
順番が違う
const r: [string, number] = ["会議室A"];
型のエラー
数が足りない
const r: [string, number] = ["会議室A", 8, 9];
型のエラー
数が多い
型を書かない
const entry = ["会議室A", 8];
✕ 型は (string | number)[] になり、タプルになりません
タプルの型を書く
const entry: [string, number] = ["会議室A", 8];
○ 型は [string, number] になります

よくある間違い[ ] で値を並べただけでは、TypeScript はふつうの配列と推論します。推論は、型を書かなくても TypeScript が型を決めてくれることです。タプルにしたいときは、変数や戻り値に型注釈を書きます。

新しい書き方

配列の分割代入

配列やタプルの要素を、前から順に変数へ取り出す書き方です。const の後ろの [ ] に変数の名前を並べると、0 番目、1 番目… の要素がそれぞれに入ります。

サンプル 
// 配送 delivery を [文字列, 数値] のタプルとして作り、["大阪", 2] を入れる
const delivery: [string, number] = ["大阪", 2];
// delivery の 0 番目を city、1 番目を days として取り出す
const [city, days] = delivery;
// 結果: city は "大阪"、days は 2

よくある疑問オブジェクトの分割代入（02章 q03 問1）は、プロパティの名前で取り出します。配列の分割代入は、位置で取り出します。そのため、変数の名前は自由に決められます。並べる順番だけが大事です。

引数の位置で、配列の分割代入をする

引数の名前の代わりに [ ] を書くと、受け取ったタプルをその場で変数に取り出せます。型は、取り出す部分の後ろに : を付けて書きます。オブジェクトで同じことをする書き方（02章 q03 問13）の、配列版です。

新しい書き方

.split()

決まった文字で区切って、配列にする

文字列を、かっこの中の文字で区切ります。区切った文字列を並べた配列を返します。区切りの文字そのものは、結果に残りません。

サンプル 
// 住所 address を作り、"東京都,港区,芝公園" を入れる

// 結果: parts は ["東京都", "港区", "芝公園"]
"10:30".split(":")
["10", "30"]
"東京都".split(",")
["東京都"]
区切りの文字がなければ、要素は 1 つ

型.split() の戻り値の型は string[] です。いくつに分かれるかは、実行するまで分からないので、タプルにはなりません。

[a = "00"]

分割代入の既定値

分割代入で、変数の後ろに = 値 を書くと、その位置に要素がないときに入る値（既定値）になります。

サンプル 
// 時刻 time を作り、"10" を入れる
const time = "10";
// time を ":" で区切り、0 番目を hour、1 番目を minute として取り出す。ないときは "00" にする
const [hour = "00", minute = "00"] = time.split(":");
// 結果: hour は "10"、minute は "00"

この課題の設定では、ふつうの配列から取り出した値は「ないかもしれない」として、string | undefined の型になります（02章 q04 問4）。既定値を書くと、ないときにも文字列が入るので、型は string になります。

既定値を書かない
const [hour, minute] = time.split(":");
✕ hour と minute の型は string | undefined
既定値を書く
const [hour = "00", minute = "00"] = time.split(":");
○ hour と minute の型は string

よくある間違い既定値を書かずに [hour, minute] を返すと、戻り値の型 [string, string] と合わず、型の確認でエラーになります。

// 関数 withLength を作る。文字列の読み取り専用の配列 names を受け取り、[文字列, 数値] のタプルの配列を返す

型を 1 つと、関数を 3 つ書きます。関数の引数と戻り値には型注釈を付けます。

  1. Point：座標を表す型です。x と y の 2 つの数値を並べたタプルの型にします。unknown を書き換えます。
  2. distance(a, b)：2 つの点 a と b の間の、まっすぐな距離を返します。Math.hypot か Math.sqrt を使います。
  3. midpoint(a, b)：2 つの点のちょうど真ん中の点（中点）を Point で返します。const [x1, y1] = a; のように、配列の分割代入を使います。
  4. minMax(numbers)：数の配列を受け取り、最小値、最大値の順のタプルを返します。引数は readonly number[] にします。空の配列なら Error を投げます。

07章 型の再利用とジェネリクス

q01 typeof 型演算子

定数や関数から、typeof で型を作る問題を 20 問解きます。ファイルにある定数と関数は、書き換えません。問1〜13 は型を作る問題です。型を手で書き写さず、かならず typeof を使って値から作ります。こうしておくと、値を直したときに型も一緒に変わります。配列の要素の型は (typeof 配列)[number]、プロパティの型は (typeof オブジェクト)["キー"] で取り出します。問14〜20 は関数を書く問題です。引数と戻り値に型注釈を付け、その型注釈にも typeof を使います。テストは、作った型や関数の型が決められたとおりかを確かめます。

問1型 DefaultUser を DEFAULT_USER から作る 新しく出てくる書き方：type 名前 = typeof 定数（値から型を作る） 
export const DEFAULT_USER = { name: "ゲスト", age: 0, admin: false };

// ここに型 DefaultUser を書く

定数 DEFAULT_USER から、型 DefaultUser を作ります。{ name: string; … } のように手で書き写さず、typeof を使います。テストがこの型を読むので、ほかのファイルから使えるようにします。

テストで確かめる値
DefaultUser の型
{ name: string; age: number; admin: boolean }
と同じ型であること

新しい書き方

type T = typeof 定数

値から型を作る

03章 q07 問10 では、型の位置の typeof を読むだけでした。この番号から、自分で書きます。type 名前 =（02章 q01 の応用）の右に typeof 定数の名前 と書くと、その定数の型に名前を付けられます。

サンプル 
// 商品の初期値 DEFAULT_PRODUCT を作り、{ name: "ノート", price: 120, inStock: true } を入れる
const DEFAULT_PRODUCT = { name: "ノート", price: 120, inStock: true };
// Product という型を作る。DEFAULT_PRODUCT の型と同じ
type Product = typeof DEFAULT_PRODUCT;
// 商品 pen を作る。型は Product。{ name: "ペン", price: 150, inStock: false } を入れる
const pen: Product = { name: "ペン", price: 150, inStock: false };
// 結果: Product は { name: string; price: number; inStock: boolean }

as const のないオブジェクトでは、プロパティの型は string・number・boolean のような種類の型になります。const の変数でも、プロパティは入れ直せるからです。01章 q03 問1 の const の文字列は、値そのものが型になりました。そこが違います。

typeof DEFAULT_PRODUCT
{ name: string; price: number; inStock: boolean }
プロパティは種類の型
DEFAULT_PRODUCT に category: "文具" を足したとき
{ name: string; price: number; inStock: boolean; category: string }
型にも category が入る
型を手で書き写す
// Product という型を作る。name は文字列、price は数値、inStock は true か false
type Product = { name: string; price: number; inStock: boolean };
✕ この番号では使いません。値に category を足しても、型は古いまま残ります
typeof で作る
// Product という型を作る。DEFAULT_PRODUCT の型と同じ
type Product = typeof DEFAULT_PRODUCT;
○ 値を直すと、型も一緒に変わります

よくある間違いconst kind = typeof DEFAULT_PRODUCT; のように値を書く場所で使うと、03章 q01 問3 の typeof になります。このとき kind は文字列の "object" です。型を取り出す typeof になるのは、type の = の右や、: の後ろに書いたときです。

コツVS Code で Product にマウスを載せると、取り出した型が表示されます。

プロパティの型を取り出す

03章 q07 問10 では、配列の型の後ろに [number] を付けて、要素の型を取り出しました。オブジェクトの型の後ろに ["キーの名前"] を付けると、そのプロパティの型を取り出せます。この書き方をインデックスアクセス型と呼びます。

サンプル 
// 店舗 SHOP を作り、{ name: "本店", address: { city: "大阪", zip: "530-0001" } } を入れる
const SHOP = { name: "本店", address: { city: "大阪", zip: "530-0001" } };
// Address という型を作る。SHOP の address プロパティの型
type Address = (typeof SHOP)["address"];
// 配送先 delivery を作る。型は Address。{ city: "京都", zip: "600-8001" } を入れる
const delivery: Address = { city: "京都", zip: "600-8001" };
// 結果: Address は { city: string; zip: string }
(typeof SHOP)["name"]
string
(typeof SHOP)["address"]
{ city: string; zip: string }
中のオブジェクトの型
(typeof SHOP)["address"]["city"]
string
続けて書くと、もっと中まで取り出せる
あるキーを書く
// Address という型を作る。SHOP の address プロパティの型
type Address = (typeof SHOP)["address"];
○ address は SHOP にあるキーです
ないキーを書く
// Phone という型を作る。SHOP の phone プロパティの型

✕ 型の確認でエラーになります（Property 'phone' does not exist on type '{ name: string; address: { city: string; zip: string; }; }'）

よくある疑問かっこを省いて typeof SHOP["address"] と書いても、同じ型になります。整形（Prettier）にかけると、(typeof SHOP)["address"] とかっこが付きます。型の位置では、.address のようにドットで取り出す書き方はできません。

オブジェクトの値のどれか、という型を作る

問4 の [ ] の中には、ユニオン型も書けます。キーを | でつないで渡すと、それぞれのプロパティの型を | でつないだ型になります。キーのどれかを表す型は、keyof typeof（03章 q07 問12）で作れます。2 つを組み合わせると、「値のどれか」を表す型になります。

サンプル 
// 定数 SHIPPING_FEES を作り、{ standard: 500, express: 1200 } を as const を付けて入れる
const SHIPPING_FEES = { standard: 500, express: 1200 } as const;
// Fee という型を作る。SHIPPING_FEES の値のどれか
type Fee = (typeof SHIPPING_FEES)[keyof typeof SHIPPING_FEES];
// 送料 fee を作る。型は Fee。1200 を入れる
const fee: Fee = 1200;
// 結果: Fee は 500 | 1200
keyof typeof SHIPPING_FEES
"standard" | "express"
キーのどれか
(typeof SHIPPING_FEES)["standard"]
500
キー 1 つなら、そのプロパティの型
(typeof SHIPPING_FEES)["standard" | "express"]
500 | 1200
キーを並べると、値の型も並ぶ
(typeof SHIPPING_FEES)[keyof typeof SHIPPING_FEES]
500 | 1200
上と同じ型

コツSHIPPING_FEES に pickup: 0 を足すと、Fee にも 0 が入ります。キーと値を書き並べなくても、一覧に合わせて型が変わります。

新しい書き方

ReturnType<typeof f>

関数の戻り値の型を取り出す

関数の名前に typeof を付けると、関数の型（05章 q07 問1 の (a: A) => R の形）を取り出せます。ReturnType は、TypeScript にはじめから用意されている型です。関数の型から、戻り値の型だけを取り出します。取り出す元の関数の型は、< > の中に書きます。< > で型を渡す書き方は、ここでは、まねて書ければ十分。くわしくは 07章 q06。

サンプル 
// 関数 makeOrder を作る。文字列の productName と数値の quantity を受け取り、注文のオブジェクトを返す
function makeOrder(productName: string, quantity: number) {
  // productName と quantity と、status が "受付" のオブジェクトを返す
  return { productName, quantity, status: "受付" };
}
// Order という型を作る。関数 makeOrder の戻り値の型
type Order = ReturnType<typeof makeOrder>;
// 結果: Order は { productName: string; quantity: number; status: string }
typeof makeOrder
(productName: string, quantity: number) => { productName: string; quantity: number; status: string }
関数の型
ReturnType<typeof makeOrder>
{ productName: string; quantity: number; status: string }
戻り値の型だけ
関数の名前をそのまま渡す
// Order という型を作る。関数 makeOrder の戻り値の型
type Order = ReturnType<makeOrder>;
✕ 型の確認でエラーになります（'makeOrder' refers to a value, but is being used as a type here. Did you mean 'typeof makeOrder'?）
typeof を付けて渡す
// Order という型を作る。関数 makeOrder の戻り値の型
type Order = ReturnType<typeof makeOrder>;
○ 関数の型を渡すので、型の確認が通ります

関数は値なので、< > には関数の名前をそのまま書けません。typeof を付けて、関数の型にしてから渡します。

新しい書き方

: typeof 定数

引数と戻り値の型注釈に typeof を書く

typeof 定数 は、型を書く場所ならどこにでも書けます。引数や戻り値の型注釈の : の後ろに書くと、「その定数と同じ形の値」を受け取る関数や、返す関数になります。type で名前を付けなくても使えます。

サンプル 
// 商品の初期値 DEFAULT_PRODUCT を作り、{ name: "ノート", price: 120, inStock: true } を入れる
const DEFAULT_PRODUCT = { name: "ノート", price: 120, inStock: true };

// 関数 productLabel を作る。typeof DEFAULT_PRODUCT 型の product を受け取り、文字列を返す
function productLabel(product: typeof DEFAULT_PRODUCT): string {
  // product の name と price を埋め込んだ「◯（◯円）」の文字列を返す
  return `${product.name}（${product.price}円）`;
}

// 関数 newProduct を作る。文字列の name を受け取り、typeof DEFAULT_PRODUCT 型の値を返す
function newProduct(name: string): typeof DEFAULT_PRODUCT {
  // name と、price が 0、inStock が false のオブジェクトを返す
  return { name, price: 0, inStock: false };
}
// 結果: productLabel(DEFAULT_PRODUCT) は "ノート（120円）"、newProduct("ペン") は { name: "ペン", price: 0, inStock: false }

応用設定の型と、設定を重ねる関数・テーマの型と見分ける関数 新しい書き方はありません。 
export const DEFAULT_CONFIG = {
  host: "localhost",
  port: 3000,
  debug: false,
  features: { chat: true, video: false },
};

型を 2 つと、関数を 2 つ書きます。型は unknown になっているところを書き換えます。

  1. 型 Config：typeof を使って、DEFAULT_CONFIG から作ります。
  2. mergeConfig：オブジェクト partial を 1 つ受け取ります。partial の host（文字列）、port（数）、debug（true か false）は、どれもなくてもかまいません。DEFAULT_CONFIG に partial を重ねた、新しい Config を返します。features は DEFAULT_CONFIG のままです。DEFAULT_CONFIG は変えません。
  3. 型 Theme：THEMES の要素のどれかを表す型です。"light" | "dark" | "system" になります。
  4. isTheme：文字列を 1 つ受け取り、Theme のどれかなら true を返します。戻り値の型は text is Theme です。
テストで確かめる値

port だけが変わる
mergeConfig({})
{ host: "localhost", port: 3000, debug: false, features: { chat: true, video: false } }
何も重ねなければ DEFAULT_CONFIG と同じ中身

mergeConfig({ port: 1 }) のあとの DEFAULT_CONFIG.port
3000

"light" | "dark" | "system"
と同じ型であること

true
isTheme("blue")
false

ファイルには「説明すること」もあります。型 Config を手で書いた場合と比べて、typeof で作ると何がうれしいかを、ファイルの下に // のコメントで書きます。考えるときは、DEFAULT_CONFIG に timeout: 5000 のようなプロパティを足して、Config にマウスを載せてみてください。同じ形の型を手で書いておき、値を直したときにどうなるかも比べてみてください。試したら、DEFAULT_CONFIG は元に戻します。

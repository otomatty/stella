決まった値ごとに答えを変える関数を 20 個書きます。どれも switch 文で書きます。switch は 03章 q04 で、shape.kind のような共通のプロパティで場合を分けるときに出ました。この番号では、数値や文字列の値そのもので場合を分けます。引数と戻り値の型注釈は自分で書きます。引数がリテラル型のユニオン（"free" | "pro" | "team" のような型）なら、すべての値の case を書きます。引数が number や string なら、どの case にも当たらないときの default を書きます。同じ答えにしたい値は、case 3: case 4: case 5: のように case を並べてまとめます。switch の形は、問1 でまとめて説明します。

新しい書き方

switch / case

値で場合を分ける（形のおさらい）

switch は、1 つの値を、いくつかの決まった値と順に比べる文です。03章 q04 では shape.kind で場合を分けました。数値や文字列の値そのものでも、同じように書けます。

サンプル 
// 関数 deliveryLabel を作る。数値 code を受け取り、文字列を返す
function deliveryLabel(code: number): string {
  // code で場合を分ける
  switch (code) {
    // 1 の場合
    case 1:
      // "通常便" を返す
      return "通常便";
    // 2 の場合
    case 2:
      // "速達" を返す
      return "速達";
    // それ以外の場合
    default:
      // "不明" を返す
      return "不明";
  }
}
// 結果: deliveryLabel(2) は "速達"、deliveryLabel(9) は "不明"

switch は、次の順で進みます。

  1. 値を出すかっこの中の code の値を出します。
  2. 上から比べるcase の値と、上から順に === で比べます。
  3. そこから進む同じだった case の下の処理を実行します。
  4. 抜けるreturn か break で switch を抜けます。

よくある間違い比べるときは === と同じで、型も同じでないと当たりません。code が number なのに case "1": と書くと、型の確認でエラーになります。数値の case は、引用符で囲まずに書きます。

サバイバルTypeScript「switch文」

default:

どの case にも当たらないとき

default: の下には、どの case にも当たらなかったときの処理を書きます。「それ以外の場合」にあたります。ふつうは switch のいちばん最後に置きます。

引数が number や string のときは、書いた case 以外の値も来ます。default がないと、どの case にも当たらなかった値で、関数が何も返さずに終わってしまいます。そのため、型の確認でエラーになります。

default を書かない
function deliveryLabel(code: number): string {
  switch (code) {
    case 1:
      return "通常便";
    case 2:
      return "速達";
  }
}
✕ 3 などのとき何も返さないので、型の確認でエラーになります
default を書く
function deliveryLabel(code: number): string {
  switch (code) {
    case 1:
      return "通常便";
    case 2:
      return "速達";
    default:
      return "不明";
  }
}
○ どの数でも、必ず文字列を返します

引数がリテラル型のユニオンなら、来る値が決まっています。すべての値の case を書けば、default は要りません。03章 q04 と同じです。

サンプル 
// 関数 boxLabel を作る。"S" か "M" か "L" の size を受け取り、文字列を返す
function boxLabel(size: "S" | "M" | "L"): string {
  // size で場合を分ける
  switch (size) {
    // "S" の場合
    case "S":
      // "60サイズ" を返す
      return "60サイズ";
    // "M" の場合
    case "M":
      // "80サイズ" を返す
      return "80サイズ";
    // "L" の場合
    case "L":
      // "100サイズ" を返す
      return "100サイズ";
  }
}
// 結果: boxLabel("M") は "80サイズ"

決まりユニオン型の値で case を 1 つでも書き忘れると、ESLint がエラーにします（switch-exhaustiveness-check）。たとえば上の case "L": を消すと、「"L" の case がない」と知らせます。型の確認でも、何も返さない場合があるとしてエラーになります。

return と break

case の処理を終えて抜ける

switch は、当たった case から下へ進みます。次の case の行に来ても止まりません。そのため、case の処理の最後には、抜けるための文を書きます。

return は、値を返して関数ごと終わります。この番号の問題は、どれも return で書けます。

break は、switch だけを抜けて、switch の後ろの行に進みます。関数は続きます。値を変数に入れておき、switch の後ろでまとめて返すときに使います。break は、くり返しを途中で抜けるときにも使います。

サンプル 
// 関数 pointRate を作る。"gold" か "silver" か "bronze" の rank を受け取り、数値を返す
function pointRate(rank: "gold" | "silver" | "bronze"): number {
  // 還元率 rate を入れ直せる変数として作り、1 を入れる
  let rate = 1;
  // rank で場合を分ける
  switch (rank) {
    // "gold" の場合
    case "gold":
      // rate に 5 を入れ直す
      rate = 5;
      // switch を抜ける
      break;
    // "silver" の場合
    case "silver":
      // rate に 3 を入れ直す
      rate = 3;
      // switch を抜ける
      break;
    // "bronze" の場合
    case "bronze":
      // switch を抜ける
      break;
  }
  // rate を返す
  return rate;
}
// 結果: pointRate("gold") は 5、pointRate("bronze") は 1
break を書き忘れる
    case "gold":
      rate = 5;
    case "silver":
      rate = 3;
      break;
✕ "gold" のあと "silver" の処理まで進み、rate が 3 になります。ESLint もエラーにします
break を書く
    case "gold":
      rate = 5;
      break;
    case "silver":
      rate = 3;
      break;
○ "gold" なら rate は 5 のまま switch を抜けます

決まり処理を書いた case のあとに、return も break もなく次の case が続くと、ESLint がエラーにします（no-fallthrough）。

04章 q04（while文と break・continue）

case 1: case 2:

同じ処理の case をまとめる

case の下に何も書かずに、次の case を続けて書けます。すると、並べた値のどれでも、同じ処理に進みます。前の項目の「下へ進む」しくみを使った書き方です。

サンプル 
// 関数 areaFee を作る。数値 area を受け取り、数値を返す
function areaFee(area: number): number {
  // area で場合を分ける
  switch (area) {
    // 1 か 2 の場合
    case 1:
    case 2:
      // 500 を返す
      return 500;
    // 3 か 4 か 5 の場合
    case 3:
    case 4:
    case 5:
      // 800 を返す
      return 800;
    // それ以外の場合
    default:
      // 1200 を返す
      return 1200;
  }
}
// 結果: areaFee(2) は 500、areaFee(4) は 800、areaFee(9) は 1200
areaFee(1)
500
case 1: に当たり、そのまま case 2: の下へ進む
areaFee(5)
800
case 5: に当たる

よくある疑問中身のない case は、何も処理をしないので、break がなくても ESLint のエラーになりません。並べる case は、数の順でなくてもかまいません。

新しい書き方

case 1: { }

case の中で変数を作る

case の下で const や let の変数を作るときは、その case の処理を { } で囲みます。switch の { } は、すべての case で 1 つの場所です。囲まないと、作った変数がほかの case からも見えてしまいます。

サンプル 
// 関数 shippingFee を作る。数値 zone と数値 total と true か false の isMember を受け取り、数値を返す
function shippingFee(zone: number, total: number, isMember: boolean): number {
  // zone で場合を分ける
  switch (zone) {
    // 1 の場合（中を { } で囲む）
    case 1: {
      // free を作り、「total が 5000 以上、かつ isMember が true」、または total が 10000 以上かどうか（true か false）を入れる
      const free = (total >= 5000 && isMember) || total >= 10000;
      // free なら 0、そうでなければ 500 を返す
      return free ? 0 : 500;
    }
    // それ以外の場合
    default:
      // 1200 を返す
      return 1200;
  }
}
// 結果: shippingFee(1, 6000, true) は 0、shippingFee(1, 6000, false) は 500、shippingFee(2, 6000, true) は 1200

コメントの「 」でくくった条件は、コードではかっこ ( ) で囲みます。&&（01章 q02 問16）と ||（01章 q01 問15）を 1 つの式で使うときは、先に計算したいほうをかっこで囲むと読みやすくなります。

{ } で囲まない
    case 1:
      const free = (total >= 5000 && isMember) || total >= 10000;
      return free ? 0 : 500;
✕ ESLint がエラーにします（no-case-declarations）
{ } で囲む
    case 1: {
      const free = (total >= 5000 && isMember) || total >= 10000;
      return free ? 0 : 500;
    }
○ free は、この case の中だけで使えます

よくある疑問変数を作らない case は、囲まなくてかまいません。if や throw を書くだけなら、問1 のサンプルと同じ形で書けます。

daysInMonth は、問2 や問13 と同じく case を並べます。2 月の case は、サンプルの shippingFee の case 1: { } と同じ形です。「割った余り」は %（01章 q01 問3）、「leap なら 29、そうでなければ 28」は条件演算子 ? :（01章 q01 問12）です。weekdayName は問1 の dayName と同じ形で、default がエラーを投げる形に変わります。calculate は問3 と同じ形で、"/" の case の中に if を書きます。if の { } のあとに、割った数を返す return を続けます。

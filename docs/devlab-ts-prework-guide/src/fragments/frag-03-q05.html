03章 ユニオン型とそのほかの型

q05 成功と失敗を表す型

成功と失敗を表す型 Result を使う関数を 20 個書きます。Result は、どのファイルにもはじめから書いてあります。引数と戻り値の型注釈は自分で書きます。この番号では、失敗も値として返します。呼ぶ側は result.ok を見て成功か失敗かを分けてから、value や error を使います。失敗のときの error の文は、問題文に書いたとおりにします。1 文字でも違うと、テストが通りません。

問1成功の Result を作る 新しく出てくる書き方：成功と失敗を表す型 Result、戻り値の型に Result を書く 
export type Result = { ok: true; value: number } | { ok: false; error: string };

export function success() {}

数値を 1 つ受け取り、その数を value に入れた成功の Result を返します。Result の型は、ファイルの先頭にはじめから書いてあります。この番号の 20 問は、どれも同じ Result を使います。

テストで確かめる値
success(3)
{ ok: true, value: 3 }

型引数が number、戻り値が Result であることも確かめます。

新しい書き方

Result

成功と失敗を 1 つの型で表す

処理には、うまくいくときと、うまくいかないときがあります。たとえば座席の予約は、空席が足りなければ失敗です。01章 q04 問8 では、うまくいかないときにエラーを投げました（throw）。エラーを投げると、関数はそこで止まります。値は返しません。

もう 1 つのやり方があります。失敗も、値として返すやり方です。成功の形のオブジェクトと、失敗の形のオブジェクトを 1 つずつ決めます。その 2 つを、ユニオン型（q01）でつなぎます。Result は、このやり方のための型です。

ok は、成功の形にも失敗の形にもあります。value は成功の形だけ、error は失敗の形だけにあります。Result の値は、この 2 つの形のどちらかです。

サンプル 
// 在庫の確認 checked を Result として作り、ok が true、value が 12 のオブジェクトを入れる
const checked: Result = { ok: true, value: 12 };
// 在庫の確認 missing を Result として作り、ok が false、error が "在庫がありません" のオブジェクトを入れる
const missing: Result = { ok: false, error: "在庫がありません" };
// 結果: どちらも Result の値として入れられる
{ ok: true, value: 12 }
入れられる
成功の形
{ ok: false, error: "在庫がありません" }
入れられる
失敗の形
{ ok: true, error: "在庫がありません" }
型の確認でエラー
成功の形は error を持たない

失敗の形は value を持たない

関数の戻り値を Result にすると、成功も失敗も同じ型で返せます。次のサンプルは、空席が足りなければ失敗を、足りれば残りの席の数を成功として返します。

サンプル 
// 関数 reserveSeats を作る。数値 left と数値 people を受け取り、Result を返す
function reserveSeats(left: number, people: number): Result {
  // もし people が left より大きいなら
  if (people > left) {
    // ok が false、error が "空席が足りません" のオブジェクトを返す
    return { ok: false, error: "空席が足りません" };
  }
  // ok が true、value が left から people を引いた数のオブジェクトを返す
  return { ok: true, value: left - people };
}
// 結果: reserveSeats(5, 2) は { ok: true, value: 3 }、reserveSeats(5, 8) は { ok: false, error: "空席が足りません" }

失敗したとき関数がそこで止まり、値を返さない失敗の形のオブジェクトを返す
戻り値の型number（成功のときの型だけ）Result（成功と失敗の両方）
呼ぶ側エラーの受け止め方は 04章で学ぶok を見て、成功か失敗かを分ける

なぜ失敗が戻り値の型に出てくるので、呼ぶ側は失敗のことを忘れにくくなります。成功か失敗かを確かめずに value を読むと、型の確認でエラーになります。確かめ方は問4 で学びます。

戻り値の型に Result を書く

オブジェクトを返す関数では、戻り値の型に Result を書きます。書かないと、返したオブジェクトから型が推論されます。そのとき ok: true の true は、boolean として推論されます。

サンプル 
// 関数 remainingSeats を作る。数値 total と数値 booked を受け取り、Result を返す

  // ok が true、value が total から booked を引いた数のオブジェクトを返す
  return { ok: true, value: total - booked };
}
// 結果: remainingSeats(20, 8) は { ok: true, value: 12 }
戻り値の型を書かない
function remainingSeats(total: number, booked: number) {
  return { ok: true, value: total - booked };
}
✕ 戻り値の型が { ok: boolean; value: number } になり、Result と合いません
戻り値の型に Result を書く
function remainingSeats(total: number, booked: number): Result {
  return { ok: true, value: total - booked };
}
○ 戻り値の型が Result になります

よくある間違い戻り値の型を書かないと、ok の型が boolean になります。Result の成功の形の ok は true だけなので、型が合いません。テストは戻り値の型が Result であることを確かめるので、型のテストが通りません。

新しい書き方

if (result.ok)

ok で成功と失敗を見分ける

Result の値は、成功か失敗かが分かるまで value も error も読めません。value は成功の形にしかなく、error は失敗の形にしかないからです。

if (result.ok) と書くと、{ } の中では result が成功の形として扱われます。そのため result.value が読めます。{ } の中で return すれば、if の後ろに進むのは失敗のときだけです。そこでは result.error が読めます。このように、条件で型をせまくすることを絞り込みと呼びます（q01）。q04 で、kind で形を見分けたのと同じ考え方です。

サンプル 
// 関数 stockMessage を作る。Result の result を受け取り、文字列を返す
function stockMessage(result: Result): string {
  // もし result の ok が true なら
  if (result.ok) {

    return `在庫は${result.value}個です`;

  return `確認できません（${result.error}）`;

// 結果: stockMessage({ ok: true, value: 12 }) は "在庫は12個です"、stockMessage({ ok: false, error: "通信エラー" }) は "確認できません（通信エラー）"

新しい書き方

! は、true と false を入れ替えます（01章 q04 の応用）。if (!result.ok) は「もし失敗なら」という意味です。

失敗の Result は、受け取ったものをそのまま返せます。error の文も、そのまま呼ぶ側に伝わります。失敗のときに先に return すると、if の後ろに進むのは成功のときだけです。そこでは result が成功の形として扱われ、value が読めます。

サンプル 
// 関数 orderTotal を作る。Result の price と数値 quantity を受け取り、Result を返す
function orderTotal(price: Result, quantity: number): Result {
  // もし price の ok が false なら
  if (!price.ok) {
    // price をそのまま返す
    return price;
  }
  // ok が true、value が price の value に quantity を掛けた数のオブジェクトを返す
  return { ok: true, value: price.value * quantity };
}

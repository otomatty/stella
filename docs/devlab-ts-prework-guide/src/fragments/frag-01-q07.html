01章 値・型・変数

q07 リテラル型

決まった値しか受け取らない・返さない関数を書きます。"on" | "off" のように、使える値を | でつないで型にします。どの問題も、引数と戻り値の型注釈は自分で書きます。テストは値に加えて、引数と戻り値の型が決めたとおりかも確かめます。

問1"on" なら "off"、"off" なら "on" を返す 新しく出てくる書き方：リテラル型 "on" | "off" 
export function toggle() {}

スイッチの状態を切り替えます。"on" を受け取ったら "off"、"off" を受け取ったら "on" を返します。

受け取る値："on" か "off" の 2 つだけ　／　返す値："on" か "off" の 2 つだけ

テストで確かめる値
toggle("on")
"off"
toggle("off")
"on"

新しい書き方

"card" | "cash"

リテラル型（決まった値だけを受け付ける型）

string はどんな文字列でも受け付けます。"card" のように値そのものを型に書くと、その値だけを受け付ける型になります。これをリテラル型と呼びます。

リテラル型を | でつなぐと、「どれか 1 つ」を受け付ける型になります。"card" | "cash" は、"card" か "cash" だけを受け付けます。

サンプル 
// 関数 paymentLabel を作る。"card" か "cash" の method を受け取り、文字列を返す
function paymentLabel(method: "card" | "cash"): string {
  // method が "card" と等しいなら "カード払い"、そうでなければ "現金払い" を返す
  return method === "card" ? "カード払い" : "現金払い";
}
// 結果: paymentLabel("cash") は "現金払い"
決めた値を渡す
// paymentLabel に "card" を渡して呼ぶ
paymentLabel("card");
○ "カード払い" が返ります
決めていない値を渡す
// paymentLabel に "bank" を渡して呼ぶ
paymentLabel("bank");
✕ 型の確認でエラーになります

数や true も、リテラル型にできます。

"card" | "cash"
"card" か "cash"
文字列のリテラル型
10 | 20 | 50
10 か 20 か 50
数のリテラル型。割引率など
true
true だけ
true | false は boolean と同じです。

コツ値の候補が決まっているところにリテラル型を書くと、打ち間違い（"crad" など）を実行する前に見つけられます。

よくある間違い型の | は 1 本です。「または」の ||（2 本）とは別のものです。

新しい書き方

if (…) { return …; }

条件に合ったら、その場で返す

return を実行すると、関数はそこで終わります。if の中に return を書くと、条件に合ったときだけ、その場で値を返せます。後ろの行は実行されません。

サンプル 
// 関数 stockLevel を作る。数の stock を受け取り、"なし" か "少ない" か "十分" を返す
function stockLevel(stock: number): "なし" | "少ない" | "十分" {
  // もし stock が 0 と等しいなら
  if (stock === 0) {
    // "なし" を返す（ここで関数が終わる）
    return "なし";
  }
  // もし stock が 10 より小さいなら
  if (stock < 10) {
    // "少ない" を返す
    return "少ない";
  }
  // "十分" を返す
  return "十分";
}
// 結果: stockLevel(0) は "なし"、stockLevel(3) は "少ない"、stockLevel(50) は "十分"

最後の return "十分"; まで来るのは、どちらの if にも当てはまらなかったときだけです。

返す値をリテラル型にした関数では、let の変数に入れてから最後に返す書き方がエラーになります。let で作った変数の型が string になり、"なし" | "十分" に入らないからです。

let に入れてから返す
function stockLevel(stock: number): "なし" | "十分" {
  let level = "十分";
  if (stock === 0) {
    level = "なし";
  }
  return level;
}
✕ return の行が型の確認でエラーになります
if の中で返す
function stockLevel(stock: number): "なし" | "十分" {
  // もし stock が 0 と等しいなら
  if (stock === 0) {
    // "なし" を返す
    return "なし";
  }
  // "十分" を返す
  return "十分";
}
○ 返す値が "なし" か "十分" だけなので通ります

コツlet level: "なし" | "十分" = "十分"; のように変数にも型を付ければ、let でも書けます。

4 位より下の順位も来るので、引数は 1 | 2 | 3 にせず number にします。返す値は 4 つに決まっているので、戻り値は 4 つをつないだリテラル型です。

応用リテラル型 新しく出てくる書き方：const で作った値の型（リテラル型になる） 
export function move() {}

// ここに START_POSITION を宣言する

2 つのことをします。

  1. 関数 move(position, direction) を書きます。direction には "up" か "down" だけを渡せるように、リテラル型で型注釈を付けます。"up" なら position に 1 を足した数、"down" なら 1 を引いた数を返します。
  2. 定数 START_POSITION を、export を付けて作ります。値は 0 です。型注釈は書かずに、推論される型が 0 になるようにします。

「説明すること」もあります。let で作った場合と const で作った場合で、推論される型がどう変わるか、なぜそうなるのかを、ファイルの「説明すること」のすぐ下に // のコメントで書きます。

テストで確かめる値
move(5, "up")
6
move(5, "down")
4
move(5, "left")
型の確認でエラー
"left" は渡せないこと
START_POSITION
0
型も 0 であること
move(START_POSITION, "up")
1

新しい書き方

const SIZE = "M"

const で作った値の型

型注釈を書かずに const で作ると、型はその値そのもののリテラル型になります。

サンプル 
// 標準のサイズ DEFAULT_SIZE を作り、"M" を入れる
const DEFAULT_SIZE = "M";
// 結果: DEFAULT_SIZE の型は "M"（string ではない）

型の確かめ方VS Code で変数の名前にマウスを載せると、推論された型が表示されます。const DEFAULT_SIZE: "M" のように出ます。

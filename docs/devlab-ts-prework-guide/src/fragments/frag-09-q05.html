09章 組み込みの API とモジュール

q05 import と export

1 つのプログラムを、いくつかのファイルに分けて書きます。分けたファイルどうしは、export（ほかのファイルに渡す）と import（ほかのファイルから受け取る）でつなぎます。src/shared/q05-modules.lib.ts には、定数・型・関数が用意してあります。このファイルは書き換えません。export の問題では、テストが自分のファイルから import して確かめます。import の問題では、shared/q05-modules.lib から import して使います。import の文は、ファイルの先頭でなくても、その問題のコメントの下に書いてかまいません。★総合問題では、1 つのファイルにまとめて書かれたコードを、3 つのファイルに分けます。

問1関数 double を名前付き export にする 新しく出てくる書き方：モジュール（ファイルを分けて、export と import でつなぐ）、名前付き export 
function double(n: number): number {
  return n * 2;
}

下の関数 double は、いまはこのファイルの中でしか使えません。function の前に export を付けて、ほかのファイルから使えるようにします。関数の中身は変えません。テストは、このファイルから double を import して確かめます。

テストで確かめる値
double(4)
8

新しい書き方

export と import

ファイルどうしをつなぐ（モジュール）

TypeScript では、export や import を使う 1 つ 1 つのファイルをモジュールと呼びます。ファイルの中で作った関数や定数は、そのままではそのファイルの中でしか使えません。ほかのファイルに渡したいものには、前に export を付けます。受け取る側のファイルでは、import の文で名前とファイルの場所を書いて読み込みます。

export function は 00章から書いてきました。この番号では export のしくみを学び、問6 で初めて自分で import を書きます。

次のサンプルは、送料を計算するファイル shipping.ts と、それを使う注文のファイル order.ts の 2 つに分かれています。

サンプル：src/shipping.ts 
// 送料が無料になる金額 FREE_LINE を作り、5000 を入れる
const FREE_LINE = 5000;

// 関数 shippingFee を作る。数値の total を受け取り、数値を返す。ほかのファイルから使えるようにする
export function shippingFee(total: number): number {
  // total が FREE_LINE 以上なら 0、そうでなければ 500 を返す
  return total >= FREE_LINE ? 0 : 500;
}
サンプル：src/order.ts 
// shipping.ts の shippingFee を、このファイルで使えるようにする
import { shippingFee } from "./shipping";

// 送料 fee を作り、3000 を shippingFee に渡した結果を入れる
const fee = shippingFee(3000);
// 結果: fee は 500

export function shippingFee のように、名前を付けて渡す export を名前付き export と呼びます。import する側は、{ } の中に同じ名前を書きます。from の後ろの "./shipping" は、読み込むファイルの場所です。./ は「このファイルと同じフォルダー」という意味で、最後の .ts は付けません。

export していない名前を import する
import { FREE_LINE } from "./shipping";
✕ エラーになります
export した名前を import する
import { shippingFee } from "./shipping";
○ 使えるようになります

よくある間違いexport していない名前を import すると、Module '"./shipping"' declares 'FREE_LINE' locally, but it is not exported.（FREE_LINE はファイルの中にあるが、export されていない）というエラーになります。このエラーが出たら、渡す側のファイルに export を付け忘れていないかを確かめます。

この番号の問題のファイルも、同じようにつながっています。

あとから、まとめて export する

先に作った関数や定数の名前を、export { } の中に , で区切って並べると、まとめて export できます。前に export を付けたときと同じ、名前付き export になります。

サンプル：src/fee.ts 
// 送料が無料になる金額 FREE_LINE を作り、5000 を入れる
const FREE_LINE = 5000;

// 関数 shippingFee を作る。数値の total を受け取り、数値を返す
function shippingFee(total: number): number {
  // total が FREE_LINE 以上なら 0、そうでなければ 500 を返す
  return total >= FREE_LINE ? 0 : 500;
}

// FREE_LINE と shippingFee を、まとめてほかのファイルから使えるようにする
export { FREE_LINE, shippingFee };
サンプル：src/cart.ts 
// fee.ts の FREE_LINE と shippingFee を、このファイルで使えるようにする

// 無料まであと left を作り、FREE_LINE から 3000 を引いた数を入れる

// 送料 fee を作り、3000 を shippingFee に渡した結果を入れる

// 結果: left は 2000、fee は 500

デフォルト export を import する

export default を付けて渡すものを、デフォルト export と呼びます。1 つのファイルに 1 つだけ置ける、そのファイルの代表の export です。デフォルト export を import するときは、{ } を付けません。名前は、import する側が自由に決めます。

  // percent を埋め込んだ「OFF◯」の文字列を返す
  return `OFF${percent}`;
}
サンプル：src/checkout.ts

import makeCoupon from "./coupon";

// クーポン code を作り、20 を makeCoupon に渡した結果を入れる

// 結果: code は "OFF20"

coupon.ts の中の名前は couponCode ですが、checkout.ts では makeCoupon という名前で使っています。export default の書き方は、問16 でくわしく見ます。

{ } を付ける

✕ 名前付き export を探して、エラーになります
{ } を付けない

○ デフォルト export を読み込みます

export const TAX_RATE = 0.1;

export type CartItem = { name: string; price: number; quantity: number };

export function priceWithTax(price: number): number {
  return Math.round(price * (1 + TAX_RATE));
}

export default function formatYen(amount: number): string {
  return `${amount.toLocaleString("ja-JP")}円`;
}

// 同じ名前の商品があれば数を足し、なければ末尾に足した新しい配列を返す
export function addItem(items: readonly CartItem[], item: CartItem): CartItem[] {
  if (!items.some((i) => i.name === item.name)) {
    return [...items, item];
  }
  return items.map((i) =>
    i.name === item.name ? { ...i, quantity: i.quantity + item.quantity } : i,
  );
}

// 税込みの合計金額
export function cartTotal(items: readonly CartItem[]): number {
  return items.reduce((sum, i) => sum + priceWithTax(i.price) * i.quantity, 0);
}

// "2種類 合計880円" の形の文字列
export function cartSummary(items: readonly CartItem[]): string {
  return `${items.length}種類 合計${formatYen(cartTotal(items))}`;
}

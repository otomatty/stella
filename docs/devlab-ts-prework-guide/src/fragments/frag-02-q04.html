02章 オブジェクト・配列・タプル

q04 配列の型

配列を扱う関数を 20 個書きます。引数と戻り値の型注釈は自分で書きます。引数で受け取った配列は、関数の中で書き換えません。そのため、引数の型は readonly number[] や readonly string[] のような読み取り専用の配列にします。戻り値の配列は number[] などのままでかまいません。for-of のほかに、map、filter、includes、indexOf、join、every などの配列のメソッドを使います。この番号から、関数を引数に渡す書き方（コールバック）が出てきます。numbers[0] のように要素を 1 つ取り出すと、型は number | undefined になります。その位置に要素がないかもしれないからです。

問1合計を返す 新しく出てくる書き方：readonly number[]（読み取り専用の配列の型） 
export function sumAll() {}

数値の配列を受け取り、要素をすべて足した合計を返します。空の配列なら 0 を返します。引数の型は、読み取り専用の数値の配列にします。

テストで確かめる値
sumAll([1, 2, 3])
6
sumAll([])
0
空の配列

型引数が readonly number[]、戻り値が number であることも確かめます。

新しい書き方

readonly number[]

読み取り専用の配列の型

配列の型 number[]（01章 q08）の前に readonly を付けると、読み取り専用の配列になります。要素を読むことはできます。要素を書き換えようとすると、型の確認でエラーになります。02章 q02 で出たオブジェクトの readonly プロパティと同じ考え方です。

サンプル 
// 関数 countLowStock を作る。読み取り専用の数値の配列 stocks を受け取り、数値を返す
function countLowStock(stocks: readonly number[]): number {
  // 個数 count を入れ直せる変数として作り、0 を入れる
  let count = 0;
  // stocks から 1 つずつ stock に取り出してくり返す
  for (const stock of stocks) {
    // もし stock が 5 より小さいなら
    if (stock < 5) {
      // count に 1 を足す
      count += 1;
    }
  }
  // count を返す
  return count;
}
// 結果: countLowStock([12, 3, 0, 8]) は 2、countLowStock([]) は 0

呼び出す側は、ふつうの配列をそのまま渡せます。readonly は「この関数の中では書き換えない」という約束なので、渡す配列に印は要りません。

readonly を付けない
function clearFirst(stocks: number[]): number {
  stocks[0] = 0;
  return stocks.length;
}
✕ 受け取った配列を書き換えても、エラーになりません
readonly を付ける
function clearFirst(stocks: readonly number[]): number {
  stocks[0] = 0;
  return stocks.length;
}
○ 書き換えた行がエラーになり、気づけます

なぜ配列を引数に渡すと、関数の中と外で同じ配列を使います。関数の中で書き換えると、呼んだ側の配列まで変わってしまいます。readonly を付けると、それを型の確認で止められます。

よくある間違いnumber[] のままでも足し算の結果は同じです。ただ、テストは引数の型が readonly number[] であることを確かめるので、型のテストが通りません。

新しい書き方

配列の要素を取り出す

01章 q03 問20 では、text[0] で文字列の 1 文字を取り出しました。配列も同じ書き方で、[ ] の中に位置を書くと、その位置の要素が取り出せます。位置は 0 から数えます。

要素がない位置を指すと、エラーにはならずに undefined になります。そのため TypeScript は、prices[1] の型を number | undefined（数値か undefined）とみなします。この型は 01章 q03 問12 で見ました。

[1200, 800][0]
1200
0 番目（先頭）
[1200, 800][1]
800
1 番目
[1200, 800][2]
undefined
2 番目の要素はない

数値を返す関数では、undefined のときに代わりに返す値を決めます。??（02章 q02 問1）を使います。

サンプル 
// 関数 secondPrice を作る。読み取り専用の数値の配列 prices を受け取り、数値を返す
function secondPrice(prices: readonly number[]): number {
  // prices の 1 番目の要素を返す。undefined なら 0 を返す

}
// 結果: secondPrice([1200, 800]) は 800、secondPrice([1200]) は 0

}
✕ undefined かもしれない値は number として返せず、エラーになります

新しい書き方

.map()

すべての要素を変えた、新しい配列を作る

.map() は、配列の要素を 1 つずつ関数に渡します。関数が返した値を順に並べて、新しい配列を返します。要素の数は元の配列と同じです。元の配列は変わりません。

サンプル 
// 商品の値段 prices を作り、[1000, 2500, 300] を入れる
const prices = [1000, 2500, 300];
// 送料込み withShipping を作り、prices の要素を 1 つずつ price として、price に 500 を足した数に変えた新しい配列を入れる
const withShipping = prices.map((price) => price + 500);
// 結果: withShipping は [1500, 3000, 800]、prices は [1000, 2500, 300] のまま
price（渡される要素）関数が返す値新しい配列
10001500[1500]
25003000[1500, 3000]
300800[1500, 3000, 800]

サバイバルTypeScript「配列をループする方法」

(price) => price + 500

関数を引数に渡す（コールバック）

.map() のかっこの中に書いた (price) => price + 500 は、01章 q01 問20 で出たアロー関数です。関数も値の 1 つなので、数値や文字列と同じように、引数として渡せます。メソッドに渡して、あとで呼んでもらう関数をコールバックと呼びます。.map() は、要素の数だけこの関数を呼びます。

コールバックの引数には、型注釈を書かなくてかまいません。prices は数値の配列なので、price は number だと TypeScript が推論します。

名前を付けた関数を先に作っておき、その名前を渡すこともできます。2 つは同じ結果になります。ふつうは右のように、その場でアロー関数を書いて渡します。

名前を付けた関数を渡す
// 関数 addShipping を作る。price を受け取り、price に 500 を足した数を返す
const addShipping = (price: number) => price + 500;
// withShipping を作り、prices の要素を 1 つずつ addShipping に渡して変えた新しい配列を入れる
const withShipping = prices.map(addShipping);
○ [1500, 3000, 800]
その場でアロー関数を書いて渡す
// withShipping を作り、prices の要素を 1 つずつ price として、price に 500 を足した数に変えた新しい配列を入れる
const withShipping = prices.map((price) => price + 500);
○ [1500, 3000, 800]

よくある間違いprices.map(addShipping()) のようにかっこを付けると、その場で addShipping を呼んでしまい、エラーになります。渡すのは関数そのものなので、名前だけを書きます。

よくある間違い(price) => { price + 500; } のように { } を付けたときは、return が要ります。return がないと何も返さないので、新しい配列の要素がすべて undefined になります。

型読み取り専用の配列に .map() を使っても、返ってくる新しい配列は number[] です。元の配列とは別の配列だからです。

条件に合う要素だけを集める

.filter() も、要素を 1 つずつコールバックに渡します。コールバックが true を返した要素だけを集めて、新しい配列を返します。コールバックは、true か false を返す関数にします。

12false集めない
3true集める
0true集める

  const seats: string[] = [];
  // i を 1 から count まで 1 ずつ増やしながらくり返す

.forEach()

.forEach() は、要素を 1 つずつコールバックに渡して呼びます。.map() と違い、新しい配列は作りません。それぞれの要素で何かをするために使います。コールバックに引数を 2 つ書くと、2 つめにその要素の位置（0 から数える）が入ります。

// 関数 firstThreeTotal を作る。読み取り専用の数値の配列 sales を受け取り、数値を返す

  // 合計 total を入れ直せる変数として作り、0 を入れる
  let total = 0;

  sales.forEach((sale, i) => {
    // もし i が 3 より小さいなら
    if (i < 3) {
      // total に sale を足す
      total += sale;
    }
  });
  // total を返す
  return total;
}

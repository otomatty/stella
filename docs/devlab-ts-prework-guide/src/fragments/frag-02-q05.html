02章 オブジェクト・配列・タプル

q05 配列を壊さない操作

配列を扱う関数を 20 個書きます。引数の配列には readonly を付けます。関数の中では、渡された配列を書き換えません。毎回、新しい配列を作って返します。新しい配列は、スプレッド構文 [...items, item]、.slice()、.filter()、.map() で作ります。.sort() と .reverse() は、呼んだ配列そのものを並べ替えてしまいます。先に [...items] でコピーしてから使います。テストは、返す配列のほかに、渡した配列が元のままかと、引数と戻り値の型も確かめます。

問1末尾に item を足した新しい配列を返す 新しく出てくる書き方：配列のスプレッド構文 [...items] 
export function append() {}

文字列の配列 items の最後に、文字列 item を足した新しい配列を返します。渡された items は変えません。

テストで確かめる値
append(["a", "b"], "c")
["a", "b", "c"]
渡した配列（呼んだあと）
["a", "b"]
元のまま

型引数が readonly string[] と string、戻り値が string[] であることも確かめます。

新しい書き方

[...items]

配列の中身を、新しい配列に並べる

配列リテラル [ ] の中で、配列の前に ... を付けます。すると、その配列の要素が、そこに 1 つずつ並びます。これを配列のスプレッド構文と呼びます。できるのは新しい配列で、元の配列は変わりません。

サンプル 
// 買い物かご cart を作り、"りんご" と "みかん" を並べた配列を入れる
const cart = ["りんご", "みかん"];
// added を作り、cart の要素すべてと "ぶどう" をこの順に並べた新しい配列を入れる
const added = [...cart, "ぶどう"];
// 結果: added は ["りんご", "みかん", "ぶどう"]、cart は ["りんご", "みかん"] のまま

... は、配列の中のどこにでも置けます。いくつ並べてもかまいません。... だけを書くと、配列のコピーになります。

サンプル 
// 本店の在庫 mainShop を作り、"ペン" と "ノート" を並べた配列を入れる
const mainShop = ["ペン", "ノート"];
// 支店の在庫 branch を作り、"のり" だけの配列を入れる
const branch = ["のり"];
// copy を作り、mainShop をコピーした新しい配列を入れる
const copy = [...mainShop];
// all を作り、"はさみ"、mainShop の要素すべて、branch の要素すべてをこの順に並べた新しい配列を入れる
const all = ["はさみ", ...mainShop, ...branch];
// 結果: copy は ["ペン", "ノート"]、all は ["はさみ", "ペン", "ノート", "のり"]

よくある間違いcart.push("ぶどう")（q04 問17）でも最後に足せます。でも、cart そのものが変わってしまいます。この番号では、元の配列を変えずに新しい配列を作ります。

よくある疑問... は 3 つの場所で出てきます。オブジェクトの中の { ...todo }（q02 問8）、関数の引数の Math.max(...numbers)（q04 問12）、配列の中の [...cart] です。どれも「中身を広げて並べる」という意味です。

新しい書き方

(_, i) =>

コールバックで、要素の番号も受け取る

.filter() や .map()（q04 問7、問5）に渡す関数は、2 つめの引数で、いま見ている要素の番号を受け取れます。番号は 0 から数えます。.forEach()（q04 問19）の 2 つめの引数と同じです。

サンプル 
// 時間帯 slots を作り、4 つの時刻を並べた配列を入れる
const slots = ["9:00", "10:00", "11:00", "12:00"];
// picked を作り、slots から、番号 i が 2 で割り切れるものだけを残した新しい配列を入れる
const picked = slots.filter((_, i) => i % 2 === 0);
// 会員 members を作り、3 人の名前を並べた配列を入れる
const members = ["佐藤", "鈴木", "高橋"];
// labeled を作り、members の要素 name と番号 i から「番号. 名前」の文字列を作って並べた新しい配列を入れる
const labeled = members.map((name, i) => `${i + 1}. ${name}`);
// 結果: picked は ["9:00", "11:00"]、labeled は ["1. 佐藤", "2. 鈴木", "3. 高橋"]
番号 i要素i % 2 === 0picked に
0"9:00"true残す
1"10:00"false除く
2"11:00"true残す
3"12:00"false除く

よくある疑問番号は 2 つめの引数なので、要素を使わないときも 1 つめの引数を書きます。使わない引数には _ という名前を付けることがよくあります。読む人に「使わない」と伝わります。

新しい書き方

.sort()

配列を並べ替える

配列の要素を並べ替えます。かっこの中には、2 つの要素の比べ方を表す関数を渡します。.sort() は新しい配列を作りません。呼んだ配列そのものを並べ替えます。元の配列を残したいときは、先に [...]（問1）でコピーします。

サンプル 
// 荷物の重さ weights を作り、3 つの数を並べた配列を入れる
const weights = [12, 5, 30];
// light を作り、weights をコピーした配列を、小さい順に並べたものを入れる
const light = [...weights].sort((a, b) => a - b);
// 結果: light は [5, 12, 30]、weights は [12, 5, 30] のまま
関数がマイナスの数を返す
a を前にする
a - b では、a のほうが小さいとき
関数がプラスの数を返す
b を前にする
a - b では、b のほうが小さいとき
関数が 0 を返す
順番を変えない
同じ大きさのとき
コピーせずに並べる
// 荷物の重さ weights を作り、3 つの数を並べた配列を入れる
const weights = [12, 5, 30];
// weights を小さい順に並べる
weights.sort((a, b) => a - b);
✕ weights そのものが [5, 12, 30] に変わります
コピーしてから並べる
// 荷物の重さ weights を作り、3 つの数を並べた配列を入れる
const weights = [12, 5, 30];
// light を作り、weights をコピーした配列を、小さい順に並べたものを入れる
const light = [...weights].sort((a, b) => a - b);
○ weights は [12, 5, 30] のままです

比べ方の関数を渡さないと、要素をいったん文字列にしてから、辞書の順に並べます。文字列の配列なら、それで辞書順になります。数値の配列では、思った順になりません。

["Osaka", "Fukuoka", "Nagoya"].sort()
["Fukuoka", "Nagoya", "Osaka"]
文字列は辞書順
[12, 5, 30].sort()
[12, 30, 5]
"12"、"30"、"5" の辞書順になる

よくある間違い数値を並べるときに比べ方の関数を省くと、上の表のように 5 が 30 より後ろになります。数値では、いつも関数を渡します。

よくある疑問引数の配列は readonly です。readonly の配列に直接 .sort() を呼ぶとどうなるかは、応用問題で自分の言葉で説明します。そのときに試してみてください。

よくある疑問新しい JavaScript には、コピーしてから並べる .toSorted() もあります。この課題の設定では使えません。型の確認でエラーになります。

新しい書き方

a[i] = …

配列の要素を入れ直す

添字 a[i]（01章 q03 問20）の後ろに = と値を書くと、その番号の要素を入れ直せます。配列そのものが変わるので、この番号ではコピーした配列に使います。

サンプル 
// 座席 seats を作り、3 つの "空き" を並べた配列を入れる
const seats = ["空き", "空き", "空き"];
// booked を作り、seats をコピーした新しい配列を入れる
const booked = [...seats];
// booked の 1 番目に "予約済み" を入れ直す
booked[1] = "予約済み";
// 結果: booked は ["空き", "予約済み", "空き"]、seats は元のまま

よくある疑問const で作った配列でも、要素は入れ直せます。const が止めるのは、変数 booked に別の配列を入れ直すことです。

よくある間違いreadonly の配列の要素に代入すると、型の確認でエラーになります。先に [...] でコピーしてから入れ直します。

よくある間違い要素のない番号に代入すると、エラーにならずに配列が伸びます。3 つの配列の 5 番目に入れると、長さが 6 になり、間に空きができます。範囲外を見分けたいときは、代入の前に自分で確かめます。

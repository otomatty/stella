03章 ユニオン型とそのほかの型

q02 リテラル型のユニオン

決まった値だけを持つ型を使って、関数を 20 個書きます。問1〜10 では、ファイルにはじめから書いてある型 Direction（向き）、Weekday（平日）、Plan（料金プラン）を使います。問11〜20 では、"表" | "裏" のような型に type で名前を付け、export を付けてから関数で使います。どの問題も、引数と戻り値の型注釈は自分で書きます。文字列を型の値に変える関数（名前が parse で始まるもの）は、どれにも当てはまらなければ undefined を返します。

問1右に 90 度回った向きを返す 新しい書き方はありません。 
export type Direction = "up" | "down" | "left" | "right";

export function turnRight() {}

向きを受け取り、右に 90 度回った向きを返します。"up" → "right" → "down" → "left" → "up" の順です。Direction は、4 つの文字列のどれかを表す型に付けた名前です。引数と戻り値の型には、この Direction を使います。

テストで確かめる値
turnRight("up")
"right"
turnRight("right")
"down"
turnRight("down")
"left"
turnRight("left")
"up"
最初に戻る

型引数が Direction、戻り値が Direction であることも確かめます。

ヒント 2コードへの直し方

「Direction の direction」は direction: Direction です。戻り値の型も Direction にします。中は 01章 q07 問9 の opposite と同じ形です。最後の行まで来るのは "left" のときだけです。Direction にない値（"upp" など）と比べると型の確認でエラーになるので、打ち間違いにすぐ気付けます。

問2文字列を Direction に変える 新しく出てくる書き方：=== で比べて、string をリテラル型に絞り込む 
export type Direction = "up" | "down" | "left" | "right";

export function parseDirection() {}

文字列を受け取り、前後の空白を取り除いて小文字にします。その結果が Direction の 4 つのどれかなら、それを返します。どれでもなければ undefined を返します。引数は文字列、戻り値は「Direction か undefined」です。

テストで確かめる値

"up"
空白を取り除いて小文字にする
parseDirection("left")
"left"
parseDirection("forward")
undefined
Direction にない

型引数が string、戻り値が Direction | undefined であることも確かめます。

新しい書き方

text === "normal"

比べると、string がリテラル型に絞り込まれる

型が string の変数は、そのままでは Direction を返す関数から返せません。string には、"forward" のような値も入るからです。

if の条件で、変数を決まった値と === で比べます。すると if の中では、変数の型がその値のリテラル型になります。このように型を狭めることを、絞り込みと呼びます。q01 で typeof や === で場合を分けたときと、同じしくみです。

サンプル 
// 配送方法 Delivery という型を作る。"normal" か "express" のどれか。ほかのファイルから使えるようにする
export type Delivery = "normal" | "express";

// 関数 parseDelivery を作る。文字列 text を受け取り、Delivery か undefined を返す。ほかのファイルから使えるようにする
export function parseDelivery(text: string): Delivery | undefined {
  // もし text が "normal" と等しい、または text が "express" と等しいなら
  if (text === "normal" || text === "express") {
    // text を返す（ここでは text の型は Delivery）
    return text;
  }
  // undefined を返す
  return undefined;
}
// 結果: parseDelivery("express") は "express"、parseDelivery("bike") は undefined

string
どんな文字列でも入る
if の中の text の型
"normal" | "express"
Delivery と同じ型
比べずに返す

  return text;

✕ 型の確認でエラーになります。string は Delivery | undefined に入りません
比べてから返す

○ if の中では text の型が Delivery なので、返せます

よくある間違い候補を配列に入れて .includes()（02章 q04 問9）で調べても、text の型は string のままです。if の中で text を返すと、型の確認でエラーになります。この番号では、=== で 1 つずつ比べます。

型の確かめ方VS Code で、if の中の text にマウスを載せます。絞り込まれた型が表示されます。

応用飲み物のサイズ Size と、サイズを扱う関数 新しい書き方はありません。 
export type Size = unknown;

export function priceOf() {}

export function parseSize() {}

export function upsize() {}

飲み物のサイズを表す型と、その型を使う関数を 3 つ書きます。引数と戻り値には型注釈を付けます。

  1. Size："S"、"M"、"L" のどれかだけを表す型です。unknown を書き換えます。テストがこの型を読むので、export は残します。
  2. priceOf(size)：サイズの値段を返します。"S" は 300、"M" は 400、"L" は 500 です。
  3. parseSize(text)：文字列の前後の空白を取り除いて、大文字にします。それが "S"、"M"、"L" のどれかなら、その Size を返します。どれでもなければ undefined を返します。引数は string、戻り値は Size | undefined です。
  4. upsize(size)：1 つ大きいサイズを返します。"L" は "L" のまま返します。

Size の型
"S" | "M" | "L"
と同じ型であること

400

500
priceOf("XL")
型の確認でエラー
"XL" は渡せないこと
parseSize("S")
"S"
parseSize(" m ")
"M"
空白を取り除いて大文字にする
parseSize("l")
"L"
parseSize("XL")
undefined
parseSize("")
undefined
空の文字列
upsize("S")
"M"
upsize("M")
"L"
upsize("L")

いちばん大きいのでそのまま

型priceOf は引数が Size、戻り値が number であることも確かめます。parseSize は引数が string、戻り値が Size | undefined であることを確かめます。upsize は引数と戻り値が Size であることを確かめます。

05章 関数

q09 型ガード関数とアサーション関数

値の型を確かめる関数を 20 個書きます。型 User、Admin、Pet は、問題のファイルに書いてあります。「型ガード関数」は、戻り値の型を value is string のように書きます。true を返したとき、呼び出した側で value がその型に絞り込まれます。「アサーション関数」は、戻り値の型を asserts value is string のように書きます。条件に合わなければ、エラーを投げます。テストは、戻り値の型が型ガードやアサーションになっているかも確かめます。

問1文字列かを確かめる型ガード関数 新しく出てくる書き方：型ガード関数 value is string 
export function isText() {}

どんな値でも 1 つ受け取ります。文字列なら true、それ以外なら false を返します。04章 q06 問1 と同じ働きの関数です。違うのは戻り値の型で、value is string と書きます。引数の型は unknown です。

テストで確かめる値
isText("a")
true
isText(1)
false
数値は文字列ではない

型引数が unknown で、戻り値の型が value is string（文字列に絞り込む型ガード）になっていることも確かめます。

新しい書き方

value is string

true を返したときに型を絞り込む、型ガード関数

04章 q06 では、typeof などで確かめると、if の { } の中で型が狭まることを学びました。これを型の絞り込みと呼びます。確かめる処理を別の関数に分けると、そのままでは絞り込みが起きません。戻り値の型が boolean だと、TypeScript には「true か false が返る」ことしか分からないからです。

戻り値の型を 引数の名前 is 型 と書くと、「true を返したら、この引数はこの型」という約束になります。この形の関数を、型ガード関数と呼びます。呼び出した側の if の { } の中で、渡した値がその型に絞り込まれます。関数の中身は、ふつうに true か false を返すだけです。

サンプル 
// Size という型を作る。"S" か "M" か "L" のどれか
type Size = "S" | "M" | "L";
// 関数 isSize を作る。文字列 text を受け取り、true か false を返す。true のときは text を Size に絞り込む
function isSize(text: string): text is Size {
  // text が "S" と等しい、または "M" と等しい、または "L" と等しいかどうか（true か false）を返す
  return text === "S" || text === "M" || text === "L";
}
// 関数 sizeOrDefault を作る。文字列 input を受け取り、Size を返す
function sizeOrDefault(input: string): Size {
  // もし isSize に input を渡して呼んだ結果が true なら
  if (isSize(input)) {
    // input を返す
    return input;
  }
  // "M" を返す
  return "M";
}
// 結果: sizeOrDefault("L") は "L"、sizeOrDefault("XL") は "M"

戻り値の型を boolean にした場合と比べます。どちらも、返す値は同じです。

戻り値の型を boolean にする
function isSize(text: string): boolean {
  return text === "S" || text === "M" || text === "L";
}

function sizeOrDefault(input: string): Size {
  if (isSize(input)) {
    return input;
  }
  return "M";
}
✕ return input が型の確認でエラーになります。input は string のままです
戻り値の型を text is Size にする
function isSize(text: string): text is Size {
  return text === "S" || text === "M" || text === "L";
}

function sizeOrDefault(input: string): Size {
  if (isSize(input)) {
    return input;
  }
  return "M";
}
○ { } の中で input が Size になり、そのまま返せます

左のエラーは「Type 'string' is not assignable to type 'Size'」です。input が Size だと、TypeScript には分からないからです。

isSize("S")
true
isSize("XL")
false
返す値は、ふつうの true か false
sizeOrDefault("XL")
"M"
Size でないので "M" を返す

よくある間違いis の左には、引数の名前を書きます。引数が text なのに value is Size と書くと、「Cannot find parameter 'value'」というエラーになります。

テスト戻り値の型を boolean にすると、値のテストは通ります。けれど型の確認で、テストのファイルに「Property 'toEqualTypeOf' does not exist on type 'never'」というエラーが出ます。型ガード関数になっていない、という意味です。

新しい書き方

.filter(isBook)

.filter() に型ガード関数を渡すと、結果の配列の型も狭まる

.filter()（02章 q04 問7）に型ガード関数を渡すと、残った要素の型が、is の右の型になります。結果の配列の型も、その型の配列になります。

サンプル 
// Book という型を作る。kind は "book"、title は文字列
type Book = { kind: "book"; title: string };
// Food という型を作る。kind は "food"、name は文字列
type Food = { kind: "food"; name: string };
// 商品 products を作り、本 2 冊と食品 1 つを入れる。型は読み取り専用の、Book か Food の配列
const products: readonly (Book | Food)[] = [
  { kind: "book", title: "TypeScript入門" },
  { kind: "food", name: "りんご" },
  { kind: "book", title: "設計の基本" },
];
// 関数 isBook を作る。Book か Food の item を受け取り、true か false を返す。true のときは item を Book に絞り込む
function isBook(item: Book | Food): item is Book {
  // item の kind が "book" と等しいかどうか（true か false）を返す
  return item.kind === "book";
}
// 本 books を作り、products から、isBook が true になるものだけを残した新しい配列を入れる
const books = products.filter(isBook);
// 書名 titles を作り、books のそれぞれを title だけにした新しい配列を入れる
const titles = books.map((book) => book.title);
// 結果: titles は ["TypeScript入門", "設計の基本"]

.filter(isBook) のように、関数の名前だけを渡します。かっこを付けて isBook() と書くと、その場で呼ぶことになるので付けません。books の型は Book[] になるので、book.title を読めます。

型ガード関数に名前を付けずに、その場でアロー関数として書くこともできます。かっこの後ろに : item is Food を書きます。

サンプル 
// 食品 foods を作り、products から、kind が "food" のものだけを残した新しい配列を入れる。渡す関数は、true のときに item を Food に絞り込む型ガード関数にする
const foods = products.filter((item): item is Food => item.kind === "food");
// 名前 names を作り、foods のそれぞれを name だけにした新しい配列を入れる
const names = foods.map((food) => food.name);
// 結果: names は ["りんご"]
products.filter(isBook) の型
Book[]
型ガード関数を渡した
products.filter((item): item is Food => item.kind === "food") の型
Food[]
その場で書いた型ガード関数
products.filter((item): boolean => item.kind === "book") の型
(Book | Food)[]
戻り値が boolean なので狭まらない

よくある疑問TypeScript 5.5 から、(item) => item.kind === "book" のような簡単な条件なら、: item is Book を書かなくても型ガードだと推論されます。けれど、問2 の NaN の確かめのように、推論されない条件もあります。結果の型が狭まらないときは、is を自分で書きます。

エラーを投げずに戻ったら型を絞り込む、アサーション関数

型ガード関数は、true か false を返し、if の中で型を絞り込みました。アサーション関数は、値を返しません。条件に合わなければ、エラーを投げます。エラーを投げずに戻ってきたら、「条件に合っていた」と分かります。そのため、呼んだ行より下では、ずっと型が絞り込まれます。

戻り値の型は、型ガード関数の形の前に asserts を付けて、asserts 引数の名前 is 型 と書きます。

サンプル 
// Size という型を作る。"S" か "M" か "L" のどれか

// 関数 assertSize を作る。文字列 text を受け取り、何も返さない。エラーを投げずに戻ったときは text を Size に絞り込む
function assertSize(text: string): asserts text is Size {
  // もし text が "S" と等しくない、かつ "M" と等しくない、かつ "L" と等しくないなら
  if (text !== "S" && text !== "M" && text !== "L") {
    // "サイズは S か M か L です" というメッセージのエラーを投げる
    throw new Error("サイズは S か M か L です");
  }
}
// 関数 orderSize を作る。文字列 input を受け取り、Size を返す
function orderSize(input: string): Size {
  // assertSize に input を渡して呼ぶ
  assertSize(input);
  // input を返す
  return input;
}
// 結果: orderSize("M") は "M"、orderSize("XL") は "サイズは S か M か L です" というメッセージのエラーを投げる

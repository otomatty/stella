01章 値・型・変数

q02 型注釈

q01 では、引数と戻り値の型が最初から書いてありました。q02 のファイルには export function subtract() {} のように、関数の名前だけが書いてあります。引数の名前と型、戻り値の型は自分で書きます。引数の数と順番は、問題の例のとおりにします。テストは、返す値に加えて型も確かめます。

問1a から b を引いた数を返す 新しく出てくる書き方：引数と戻り値の型注釈を書く 
export function subtract() {}

2 つの数を受け取り、1 つめから 2 つめを引いた数を返します。かっこの中の引数と、かっこの後ろの戻り値の型を書き足します。

テストで確かめる値
subtract(5, 3)
2
subtract(0, 7)
-7
マイナスになることもある

型引数が number と number、戻り値が number であることも確かめます。

新しい書き方

(名前: 型): 型

引数と戻り値の型注釈を書く

引数は 名前: 型 の形で、, で区切って並べます。戻り値の型は、かっこの後ろに : 型 と書きます。

サンプル 
// 関数 shippingLabel を作る。文字列 city と数値 days を受け取り、文字列を返す
function shippingLabel(city: string, days: number): string {
  // city と days を埋め込んだ「◯まで◯日」の文字列を返す
  return `${city}まで${days}日`;
}
// 結果: shippingLabel("大阪", 2) は "大阪まで2日"

true か false を返す関数は、戻り値の型を boolean にします。比べた結果は true か false なので、そのまま返せます。

サンプル 
// 関数 isFreeShipping を作る。数値 total を受け取り、true か false を返す
function isFreeShipping(total: number): boolean {
  // total が 5000 以上かどうか（true か false）を返す
  return total >= 5000;
}
// 結果: isFreeShipping(6000) は true、isFreeShipping(3000) は false
型を書かない
function shippingLabel(city, days) {
  return `${city}まで${days}日`;
}
✕ 型の確認でエラーになります
型を書く
function shippingLabel(city: string, days: number): string {
  return `${city}まで${days}日`;
}
○ 引数と戻り値の型が決まります

よくある疑問引数の名前は自由に決めてかまいません。テストが確かめるのは、引数の数・順番・型と、戻り値の型です。中身が分かる名前にしましょう。

export function isBetween() {}

3 つの数 value、min、max をこの順に受け取ります。value が min 以上、max 以下の範囲にあれば true を返します。範囲の両はしも含みます。

両方が true なら true

サンプル

応用金額の表示と、メンバーの紹介文を作る 新しい書き方はありません。 
export function formatPrice() {}

export function describeMember() {}

2 つの関数を書きます。引数と戻り値には、すべて型注釈を付けます。

  1. formatPrice(price, unit)：金額を 3 桁ごとに , で区切り、後ろに単位を付けた文字列を返す
  2. describeMember(name, age, isLeader)：名前と年齢から「佐藤（28歳）」の形の紹介文を返す。リーダーなら「佐藤（28歳・リーダー）」にする
テストで確かめる値
formatPrice(1200, "円")
"1,200円"
formatPrice(1234567, "円")
"1,234,567円"
formatPrice(500, "ドル")
"500ドル"
単位は引数で変わる
formatPrice(0, "円")
"0円"
describeMember("佐藤", 28, true)
"佐藤（28歳・リーダー）"
describeMember("鈴木", 31, false)
"鈴木（31歳）"

型formatPrice は引数が number と string、describeMember は引数が string・number・boolean であることも確かめます。戻り値はどちらも string です。

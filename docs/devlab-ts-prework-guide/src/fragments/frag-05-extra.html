05章 発展問題（任意）

発展問題

やってもやらなくてもよい、任意の課題です。章の課題とは別に数えます。番号の順に、1 問ずつ確認して提出します。e01 では、引数の型によって戻り値の型が変わる関数を書きます。e02 では、関数の型に名前を付け、関数を組み合わせて新しい関数を作ります。e01 には「説明すること」があり、ファイルの「説明すること」のすぐ下に // のコメントで書きます。

e01オーバーロード関数 新しく出てくる書き方：オーバーロードのシグネチャ function f(value: string): number; 
export function convert() {}

export function pick() {}

引数の型によって戻り値の型が変わる関数を 2 つ、オーバーロード（同じ名前の関数の型を、呼び方ごとに並べる書き方）で書きます。

  1. convert(value)：文字列を渡したら、数値にして返します。このときの戻り値の型は number です。数値を渡したら、文字列にして返します。このときの戻り値の型は string です。
  2. pick(items, index?)：index を渡したら、その番号の要素を返します。このときの戻り値の型は string | undefined です。index を省略したら、配列のコピーを返します。このときの戻り値の型は string[] です。引数の配列の型は readonly string[] です。

説明すること：オーバーロードを使わずに、戻り値の型を number | string にした場合と比べて、呼び出し側で何がうれしいか。

テストで確かめる値
convert("42")
42
文字列が数値になる
convert(42)
"42"
数値が文字列になる
convert("42") の型
number
convert(42) の型
string
pick(["a", "b"], 1)
"b"
pick(["a", "b"], 5)
undefined
その番号の要素がない
pick(["a", "b"])
["a", "b"]
渡した配列とは別の、新しい配列
pick(["a"], 0) の型
string | undefined
pick(["a"]) の型
string[]

型呼び方ごとの戻り値の型を、テストで確かめます。pick がコピーを返すときは、渡した配列そのものでないことも確かめます。

新しい書き方

function f(value: string): number;

呼び方ごとに型を並べる、オーバーロード

関数の中身の前に、呼び方ごとの型を 1 行ずつ並べます。この 1 行を、オーバーロードのシグネチャと呼びます。シグネチャは、関数の名前・引数の型・戻り値の型だけを書いた行です。{ } を付けずに、; で終えます。最後に、中身を持つ関数（実装）を 1 つ書きます。

サンプル 
// 関数 toTaxed の呼び方 1 を書く。数値 input を受け取り、数値を返す
function toTaxed(input: number): number;
// 関数 toTaxed の呼び方 2 を書く。読み取り専用の数値の配列 input を受け取り、数値の配列を返す
function toTaxed(input: readonly number[]): number[];
// 関数 toTaxed の中身を作る。数値か、読み取り専用の数値の配列の input を受け取り、数値か数値の配列を返す
function toTaxed(input: number | readonly number[]): number | number[] {
  // もし input の型が数値なら
  if (typeof input === "number") {
    // input に 1.1 を掛けて四捨五入した数を返す
    return Math.round(input * 1.1);
  }
  // input のそれぞれに 1.1 を掛けて四捨五入した、新しい配列を返す
  return input.map((price) => Math.round(price * 1.1));
}
// 1 個の税込み価格 one を作り、toTaxed に 1000 を渡して呼んだ結果を入れる
const one = toTaxed(1000);
// 税込み価格の一覧 list を作り、toTaxed に [100, 250] を渡して呼んだ結果を入れる
const list = toTaxed([100, 250]);
// 結果: one は 1100（型は number）、list は [110, 275]（型は number[]）

呼び出す側から見えるのは、1 と 2 の呼び方だけです。TypeScript は、渡した引数に合う呼び方を上から探し、その戻り値の型を使います。

toTaxed(1000) の型
number
呼び方 1 に合う
toTaxed([100, 250]) の型
number[]
呼び方 2 に合う
型が number | readonly number[] の値を渡す
型のエラー
「No overload matches this call」。3 の実装の型では呼べない

引数の数が違う呼び方も、オーバーロードで並べられます。そのときの実装では、省略できる引数に ? を付けて、オプション引数（q03）にします。

よくある間違いほかのファイルから使うときは、シグネチャの行にも実装の行にも、すべて export を付けます。1 行でも抜けると、「Overload signatures must all be exported or non-exported.」というエラーになります。

よくある間違い実装の型が、シグネチャのどれかを受け止められないと、「This overload signature is not compatible with its implementation signature.」というエラーになります。実装の引数の型と戻り値の型は、シグネチャの型を | で合わせたものにします。

// 関数 pick の呼び方 2 を書く。読み取り専用の文字列の配列 items を受け取り、文字列の配列を返す。ほかのファイルから使えるようにする

ヒント 2コードへの直し方

呼び方の行は、e01 のサンプルの toTaxed の 1 行目・2 行目と同じ形で、前に export を付けます。中身は、問題のファイルの export function convert() {} の行に、引数と戻り値の型を書き足して作ります。数値にするのは Number()（01章 q08 問16）、文字列にするのは String()（01章 q01 問12）です。「◯ なら ◯、そうでなければ ◯ を返す」は、条件演算子 ? :（01章 q01 問12）で書けます。pick の「なくてもよい数値 index」は index?: number です（q03）。コピーは [...items]（02章 q05 問1）、「items の index 番目の要素」は items[index] です。説明することは、オーバーロードの 2 行をいったん消して試します。convert("42") にマウスを載せて表示される型を見たり、const n = convert("42"); の下で n を数値として使う行を書いたりして、型の確認の結果を見比べます。試した行は、提出する前に元に戻します。

e02関数の型と、関数の組み合わせ 新しく出てくる書き方：関数の型に名前を付ける type NumberFn = (x: number) => number 
export type NumberFn = unknown;

export function compose() {}

export function pipe() {}

export function repeatFn() {}

「数値を 1 つ受け取って数値を返す関数」に名前を付け、それを組み合わせる関数を 3 つ書きます。3 つとも、関数を受け取って、新しい関数を返します（q08 の関数を返す関数）。

  1. NumberFn：「数値を 1 つ受け取って数値を返す関数」の型にします。unknown を書き直します。
  2. compose(f, g)：「x に f を当てはめ、その結果に g を当てはめる」関数を返します。式で書くと g(f(x)) です。引数も戻り値も NumberFn です。
  3. pipe(...fns)：渡された関数を、前から順に当てはめる関数を返します。関数が 1 つもなければ、x をそのまま返す関数を返します。
  4. repeatFn(fn, times)：fn を times 回当てはめる関数を返します。
テストで確かめる値
NumberFn の型
(x: number) => number
compose((x) => x + 1, (x) => x * 2)(3)
8
3 + 1 で 4、4 × 2 で 8
pipe((x) => x + 1, (x) => x * 10)(2)
30
2 + 1 で 3、3 × 10 で 30
pipe()(7)
7
関数が 1 つもないので、そのまま
repeatFn((x) => x * 2, 3)(1)
8
1 → 2 → 4 → 8
repeatFn((x) => x * 2, 0)(5)
5
0 回なので、そのまま

型compose は引数が NumberFn 2 つ、戻り値が NumberFn です。pipe は残余引数で、引数の型が NumberFn[]、戻り値が NumberFn です。repeatFn は引数が NumberFn と number、戻り値が NumberFn です。どれもテストで確かめます。

新しい書き方

type NumberFn = (x: number) => number

関数の型に名前を付ける

q07 で、引数の型に (n: number) => number のような関数の型を書きました。この型にも、type（02章 q01 の応用）で名前を付けられます。名前を付けると、同じ型を何度も書かずに済みます。

サンプル 
// PriceRule という型を作る。数値 price を受け取り、数値を返す関数の型
type PriceRule = (price: number) => number;
// 割引 discount を PriceRule として作り、数値 price を受け取り、price から 100 を引いた数を返す関数を入れる
const discount: PriceRule = (price) => price - 100;
// 関数 makeRule を作る。数値 rate を受け取り、PriceRule を返す
function makeRule(rate: number): PriceRule {
  // 数値 price を受け取り、次のことをする関数を返す
  return (price) => {
    // 値引き off を作り、price に rate を掛けて四捨五入した数を入れる
    const off = Math.round(price * rate);
    // price から off を引いた数を返す
    return price - off;
  };
}
// 1 割引き tenOff を作り、makeRule に 0.1 を渡して呼んだ結果を入れる
const tenOff = makeRule(0.1);
// 結果: discount(1000) は 900、tenOff(1000) は 900、tenOff(1980) は 1782

変数の型や戻り値の型に PriceRule と書くと、そこに入れるアロー関数の引数 price には、型を書かなくても number が付きます。makeRule が返すアロー関数も同じです。

discount(1000)
900
tenOff(1980)
1782
198 を引く

よくある疑問関数の型の中の引数の名前は、型を読みやすくするためのものです。(x: number) => number と (n: number) => number は同じ型として扱われます。

ヒント 1日本語の手順

// NumberFn という型を作る。数値 x を受け取り、数値を返す関数の型。ほかのファイルから使えるようにする

// 関数 compose を作る。NumberFn の f と NumberFn の g を受け取り、NumberFn を返す
export function compose() {
  // 数値 x を受け取り、「f に x を渡して呼んだ結果」を g に渡して呼んだ結果を返す関数を返す
}

// 関数 pipe を作る。NumberFn をいくつでも fns として受け取り、NumberFn を返す
export function pipe() {
  // 数値 x を受け取り、次のことをする関数を返す
  //   値 value を入れ直せる変数として作り、x を入れる
  //   fns から 1 つずつ fn に取り出してくり返す
  //     value に、fn に value を渡して呼んだ結果を入れ直す
  //   value を返す
}

// 関数 repeatFn を作る。NumberFn の fn と数値 times を受け取り、NumberFn を返す
export function repeatFn() {
  // 数値 x を受け取り、次のことをする関数を返す
  //   値 value を入れ直せる変数として作り、x を入れる
  //   i を 0 から、times より小さい間 1 ずつ増やしながらくり返す
  //     value に、fn に value を渡して呼んだ結果を入れ直す
  //   value を返す
}
ヒント 2コードへの直し方

NumberFn は、e02 のサンプルの PriceRule と同じ形で、前に export を付けます。compose の中身は、q07 問20 の composeTwo と同じ g(f(x)) です。違うのは、x を受け取る関数を返すことで、サンプルの discount の右側のように書いて return します。戻り値の型を NumberFn にしたので、返すアロー関数の x には型を書かなくてもかまいません。pipe の「いくつでも」は、残余引数 ...fns: NumberFn[] です（q05 問1）。pipe と repeatFn は、サンプルの makeRule と同じく { } のあるアロー関数を返し、その中でくり返します。fns が空の配列なら、くり返しは 1 回も動かず、x がそのまま返ります。

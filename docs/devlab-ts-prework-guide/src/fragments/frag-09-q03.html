q03 Date

日付と時刻を扱う関数を 20 個書きます。引数と戻り値には型注釈を付けます。日時は Date で表します。この番号では、パソコンに設定された地域の時刻（ローカル時刻）で日時を扱います。年・月・日などは、.getFullYear()・.getMonth()・.getDate()・.getDay()・.getHours()・.getMinutes() で取り出します。Date の中では、月は 0〜11（1月が 0）、曜日は 0〜6（日曜が 0）で数えます。問題文の「月」は、ふだんどおり 1〜12 で書いてあります。引数の Date は変えません。変えたいときは、new Date(date.getTime()) でコピーしてから変えます。

新しい書き方

.getTime()new Date(date.getTime())

時刻の数を取り出す・Date をコピーする

Date の中には、1 つの数が入っています。1970年1月1日 0時0分（世界標準時）から、何ミリ秒たったかを表す数です。1 ミリ秒は 1000 分の 1 秒です。.getTime() は、この数を返します。この数を new Date() に渡すと、同じ日時の Date がもう 1 つできます。これが Date のコピーです。

サンプル 
// 注文日時 orderedAt を作り、2026年4月1日 0時0分（世界標準時）の Date を入れる
const orderedAt = new Date("2026-04-01T00:00:00Z");
// 時刻の数 time を作り、orderedAt の時刻の数（ミリ秒）を入れる
const time = orderedAt.getTime();
// 控え copy を作り、orderedAt をコピーした Date を入れる
const copy = new Date(orderedAt.getTime());
// 結果: time は 1775001600000、copy は orderedAt と同じ日時の、別の Date

よくある疑問new Date(2026, 3, 1) のようにローカル時刻で作った Date は、.getTime() の数がパソコンの地域によって変わります。日本の 4月1日 0時は、世界標準時ではまだ 3月31日 15時だからです。この数は、日時を比べたり、差を求めたりするのに使います（問13・問14）。

.getDate().setDate()

日を取り出す・日を変える

.getDate() は、日を 1〜31 の数で返します。月と違い、1 から数えます。.setDate() は、その Date の日を、かっこの中の数に変えます。時刻は変わりません。月の日数をこえる数を渡すと、Date が次の月の日付に直します。0 や負の数なら、前の月の日付に直します。

サンプル 
// 発送日 shipAt を作り、2026年3月30日 0時0分の Date を入れる（月は 0 から数えるので 3月は 2）
const shipAt = new Date(2026, 2, 30);
// 届く日 arriveAt を作り、shipAt をコピーした Date を入れる
const arriveAt = new Date(shipAt.getTime());
// arriveAt の日を、arriveAt の日に 5 を足した数にする
arriveAt.setDate(arriveAt.getDate() + 5);
// 結果: arriveAt は 2026年4月4日 0:00、shipAt は 2026年3月30日 0:00 のまま
コピーしないで変える
const arriveAt = shipAt;
arriveAt.setDate(arriveAt.getDate() + 5);
✕ shipAt も 4月4日に変わります
コピーしてから変える
const arriveAt = new Date(shipAt.getTime());
arriveAt.setDate(arriveAt.getDate() + 5);
○ shipAt は 3月30日のままです

const arriveAt = shipAt; は、同じ 1 つの Date に 2 つ目の名前を付けるだけです。そのため、arriveAt を変えると shipAt も変わります。const は入れ直しを止めますが、Date の中身を変えることは止めません。

よくある間違い.setDate() が返すのは、変えたあとの時刻の数（number）です。Date は返しません。戻り値の型が Date の関数で return arriveAt.setDate(…); と書くと、型の確認でエラーになります。先に日を変えて、次の行で Date を返します。

新しい書き方

.toISOString()

ISO 形式の日付は、世界標準時の日付になる

03章 q03 問20 では、.toISOString() の先頭 10 文字で日付を作りました。この文字列は、いつも世界標準時で表します。日本の時刻は世界標準時より 9 時間進んでいるので、日本の 0時から 8時台は、世界標準時ではまだ前の日です。そのため、ローカル時刻の日付とずれることがあります。この問題は、年・月・日をメソッドで取り出して組み立てます。

サンプル 
// 受付 receivedAt を作り、2026年7月15日 8時0分の Date を入れる（月は 0 から数えるので 7月は 6）

// 日付 isoDay を作り、receivedAt を ISO 形式の文字列にしたものの、0 文字目から 10 文字目の前までを入れる
const isoDay = receivedAt.toISOString().slice(0, 10);
// 結果: 日本の時刻（Asia/Tokyo）のパソコンでは、isoDay は "2026-07-14"

ヒント 2コードへの直し方

02章 q05 問8 のサンプルの light の行と同じ形です。比べ方の関数は、a の時刻の数から b の時刻の数を引いた数を返します。a - b のように Date のまま引くと、型の確認で「計算の左側は number などの型でなければならない」という意味のエラーになります。

応用日付を進める・表示する・日数を数える・週末と月末 新しい書き方はありません。 
export function addDays() {}

export function formatDate() {}

export function daysBetween() {}

export function isWeekend() {}

日付を扱う 5 つの関数を書きます。引数と戻り値には型注釈を付けます。日付はローカル時刻で扱い、引数の Date は変えません。

  1. addDays(date, n)：n 日後の新しい Date を返します。n は負の数でもかまいません。月や年をまたいでもかまいません。時刻はそのままにします。
  2. formatDate(date)："2026-04-01" の形の文字列を返します。月と日は 2 桁にします。
  3. daysBetween(a, b)：a の日付から b の日付までの日数を返します。b が a より前なら、負の数です。時刻は見ないで、日付だけで数えます。
  4. isWeekend(date)：土曜日か日曜日なら true を返します。
  5. endOfMonth(date)：date と同じ月の最終日の 0時0分の Date を返します。

「説明すること」もあります。new Date(2026, 3, 31) は何月何日になるか、なぜそうなるかを、ファイルの「説明すること」のすぐ下に // のコメントで書きます。

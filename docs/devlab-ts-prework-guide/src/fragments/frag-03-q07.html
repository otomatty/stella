03章 ユニオン型とそのほかの型

q07 as const

値の後ろに as const を付ける練習を 20 問します。問1〜8 は、定数を as const を付けて作り、ほかのファイルから使えるようにします。テストは値だけでなく、推論される型（読み取り専用と、リテラル型）も確かめます。問9〜20 は、用意された定数 STATUSES、PRIORITY_POINTS、MONTH_NAMES などを使って関数を書きます。引数と戻り値には型注釈を付けます。スターターにある型 Status と Priority の書き方は 07章で学びます。ここでは、出てきた問題で読み方だけを説明します。

問1定数 DAYS を宣言する 新しく出てくる書き方：as const 
// ここに DAYS を宣言する

定数 DAYS を作り、["月", "火", "水"] を入れます。as const を付けて、型が readonly ["月", "火", "水"] になるようにします。テストがこの定数を読むので、ほかのファイルから使えるようにします。

テストで確かめる値
DAYS
["月", "火", "水"]
値
DAYS の型
readonly ["月", "火", "水"]
読み取り専用で、入れた値がそのまま型になる

新しい書き方

as const

値を、細かい型のまま読み取り専用にする

値の後ろに as const を付けると、TypeScript は値をできるだけ細かい型にします。配列に付けると、次の 3 つが起きます。

1 つめは、要素の型が、入れた値そのもののリテラル型（01章 q07 問1）になることです。2 つめは、要素の数と並びが決まったタプル（02章 q06 問1）になることです。3 つめは、読み取り専用（readonly）になり、書き換えられなくなることです。

サンプル 
// 定数 SIZES を作り、["S", "M", "L"] を as const を付けて入れる
const SIZES = ["S", "M", "L"] as const;
// 結果: SIZES の型は readonly ["S", "M", "L"]
as const なし
// サイズ sizes を作り、["S", "M", "L"] を入れる
const sizes = ["S", "M", "L"];
// 結果: 型は string[]
as const あり
// 定数 SIZES を作り、["S", "M", "L"] を as const を付けて入れる
const SIZES = ["S", "M", "L"] as const;
// 結果: 型は readonly ["S", "M", "L"]

読み取り専用なので、要素を足したり入れ直したりすると、型の確認でエラーになります。

as const なしの配列に足す
// sizes の最後に "XL" を足す
sizes.push("XL");
○ 書き換えられる配列なので、足せます
as const ありの配列に足す
// SIZES の最後に "XL" を足す
SIZES.push("XL");
✕ 型の確認でエラーになります（Property 'push' does not exist on type 'readonly ["S", "M", "L"]'）

オブジェクトに付けると、すべてのプロパティが readonly（02章 q02 問7）になり、値の型はリテラル型になります。

サンプル 
// 送料の設定 SHIPPING を作り、{ fee: 500, region: "関東" } を as const を付けて入れる
const SHIPPING = { fee: 500, region: "関東" } as const;
// 結果: SHIPPING の型は { readonly fee: 500; readonly region: "関東" }
{ fee: 500, region: "関東" }
{ fee: number; region: string }
as const なしで推論される型
[10, 20] as const
readonly [10, 20]
数もリテラル型になる
{ open: true } as const
{ readonly open: true }
true もリテラル型になる
["S", 12] as const
readonly ["S", 12]
種類のちがう値を並べたタプル

よくある疑問テストの expectTypeOf は、定数の型が決めた型と同じかを確かめます。VS Code で定数にマウスを載せると、推論された型が表示されます。as const を付け忘れると型が string[] になり、テストが通りません。

決まりas const は型の確認のための印です。JavaScript に変換したあとのコードには残りません。値は変わりません。

新しい書き方

.some()

条件に合う要素が 1 つでもあるかを調べる

要素を 1 つずつコールバックに渡し、1 つでも true が返れば true を返します。すべてで false が返れば false です。「すべて」を調べる .every()（02章 q04 問20）に対して、.some() は「どれか 1 つでも」を調べます。

サンプル 
// 在庫数 stocks を作り、[12, 0, 5] を入れる
const stocks = [12, 0, 5];
// hasSoldOut を作り、stocks の要素のどれかが 0 と等しいか（true か false）を入れる
const hasSoldOut = stocks.some((stock) => stock === 0);
// 結果: hasSoldOut は true
[12, 5].some((stock) => stock === 0)
false
0 の要素がない
[].some((stock) => stock === 0)
false
空の配列は、合う要素がないので false

as const を付けた配列に、型が string の値が含まれるかを調べるときも、.some() を使います。

サンプル 
// 定数 PAYMENTS を作り、["card", "cash"] を as const を付けて入れる
const PAYMENTS = ["card", "cash"] as const;
// 関数 isPaymentMethod を作る。文字列の input を受け取り、true か false を返す
function isPaymentMethod(input: string): boolean {
  // PAYMENTS の要素のどれかが input と等しいか（true か false）を返す
  return PAYMENTS.some((method) => method === input);
}
// 結果: isPaymentMethod("cash") は true、isPaymentMethod("bank") は false
.includes() で調べる
// PAYMENTS に input が含まれるか（true か false）を返す
return PAYMENTS.includes(input);
✕ 型の確認でエラーになります（Argument of type 'string' is not assignable to parameter of type '"card" | "cash"'）
.some() で調べる
// PAYMENTS の要素のどれかが input と等しいか（true か false）を返す
return PAYMENTS.some((method) => method === input);
○ 要素と input を === で比べるので、型の確認が通ります

as const を付けた配列の .includes() は、要素の型（ここでは "card" | "cash"）の値しか受け取りません。input の型は string で、"bank" のような値も入りうるので、エラーになります。

オブジェクトのキーの名前を並べた型

keyof オブジェクトの型 と書くと、その型のキーの名前を | でつないだユニオン型になります。問10 の typeof と組み合わせると、定数のオブジェクトから「キーのどれか」の型を作れます。ここでは、読めれば十分。くわしくは 07章 q02。

サンプル 
// 定数 SHIPPING_FEES を作り、{ standard: 500, express: 1200 } を as const を付けて入れる
const SHIPPING_FEES = { standard: 500, express: 1200 } as const;
// Shipping という型を作る。SHIPPING_FEES のキーのどれか
type Shipping = keyof typeof SHIPPING_FEES;
// 配送方法 method を作る。型は Shipping。"express" を入れる
const method: Shipping = "express";
// fee を作り、SHIPPING_FEES の method の値を入れる
const fee = SHIPPING_FEES[method];
// 結果: Shipping は "standard" | "express"、fee は 1200

右から順に読みます。定数の型を取り出し、その型のキーを並べます。

typeof SHIPPING_FEES
{ readonly standard: 500; readonly express: 1200 }
定数の型
keyof typeof SHIPPING_FEES
"standard" | "express"
キーのどれか
SHIPPING_FEES[method] の型
500 | 1200
method の型が Shipping のとき。undefined は付かない

02章 q08 問1 のインデックス型では、どのキーがあるかが型から分からないので、取り出した値に undefined が付きました。keyof で作った型のキーは、かならずオブジェクトにあります。そのため、取り出した値に undefined が付きません。

あるキーを入れる

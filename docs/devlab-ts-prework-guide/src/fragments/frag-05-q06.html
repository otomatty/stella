05章 関数

q06 分割代入引数

オブジェクトや配列を受け取り、引数のかっこの中で分割代入して取り出す関数を 20 個書きます。引数の位置で分割代入する書き方は、02章 q03 問13（オブジェクト）と 02章 q06 問9（タプル）で出ました。この番号では、受け取るオブジェクトの型を { name: string } のように、その場で書きます。問題に「省略したら ◯」とあるプロパティは、型の側で名前の後ろに ? を付け、取り出す側で = 値 と既定値を書きます（{ x = 0 }: { x?: number }）。使う形は、問1 でまとめて見ておきます。引数と戻り値の型注釈は自分で書きます。テストは、返す値に加えて型も確かめます。

問1{ name } を受け取り「こんにちは、◯◯さん」を返す 新しく出てくる書き方：省略できるプロパティの既定値 { x = 0 }: { x?: number }（あわせて、受け取る型をその場で書く形と、この番号で使う分割代入引数の形を整理します） 
export function hello() {}

名前を持つオブジェクトを受け取り、「こんにちは、◯◯さん」の形のあいさつを返します。name は、引数のかっこの中で分割代入して取り出します。受け取るオブジェクトの型は { name: string } です。戻り値は文字列です。

テストで確かめる値
hello({ name: "山田" })
"こんにちは、山田さん"

型引数が { name: string }、戻り値が string であることも確かめます。

新しい書き方

({ a }: { a: 型 })

受け取るオブジェクトの型を、その場で書く

02章 q03 問13 では、受け取るオブジェクトの型に Order のような型の名前を使いました。型の名前がないときは、: の後ろにオブジェクトの型をそのまま書きます。関数の中では、取り出したプロパティの名前を変数として使います。

サンプル 
// 関数 shippingNote を作る。city が文字列のオブジェクトを受け取り、引数の位置で city を取り出す。文字列を返す
function shippingNote({ city }: { city: string }): string {
  // city を埋め込んだ「◯へ発送します」の文字列を返す
  return `${city}へ発送します`;
}
// 結果: shippingNote({ city: "大阪" }) は "大阪へ発送します"

取り出すプロパティが 2 つ以上のときは、取り出す側にも型の側にも、名前を並べます。

サンプル 
// 関数 lineTotal を作る。price が数値、count が数値のオブジェクトを受け取り、引数の位置で price と count を取り出す。数値を返す
function lineTotal({ price, count }: { price: number; count: number }): number {
  // price と count を掛けた数を返す
  return price * count;
}
// 結果: lineTotal({ price: 300, count: 4 }) は 1200

よくある間違い取り出す側の { } に型を書くことはできません。{ price: number } と書くと、名前を付け替える書き方（02章 q03 問17）になります。型は、いつも { } の後ろの : に続けて書きます。

{ a = 値 }: { a?: 型 }

省略できるプロパティに既定値を付ける

省略できるプロパティは、2 か所に書き足します。型の側では、名前の後ろに ? を付けます（02章 q02 問1 のオプションプロパティ）。取り出す側では、名前の後ろに = 値 を書きます。プロパティがないときは、その値（既定値）が入ります。既定値は、02章 q06 問12 で配列の分割代入に付けたものと同じ書き方です。

サンプル 
// 関数 deliveryText を作る。city が文字列、days がなくてもよい数値のオブジェクトを受け取り、引数の位置で city と days を取り出す。days がないときは 3 にする。文字列を返す
function deliveryText({ city, days = 3 }: { city: string; days?: number }): string {
  // city と days を埋め込んだ「◯まで◯日」の文字列を返す
  return `${city}まで${days}日`;
}
// 結果: deliveryText({ city: "大阪" }) は "大阪まで3日"、deliveryText({ city: "大阪", days: 1 }) は "大阪まで1日"
deliveryText({ city: "大阪" })
"大阪まで3日"
days がないので 3
deliveryText({ city: "大阪", days: 1 })
"大阪まで1日"
渡した 1 が入る

既定値を書くと、関数の中の days の型は number になります。ないときにも数が入るからです。

型に ? を付けるだけ
function deliveryText({ city, days }: { city: string; days?: number }): string {
  return `${city}まで${days}日`;
}
✕ days の型は number | undefined。deliveryText({ city: "大阪" }) は "大阪までundefined日" になります
? と既定値を両方書く
function deliveryText({ city, days = 3 }: { city: string; days?: number }): string {
  return `${city}まで${days}日`;
}
○ days の型は number。deliveryText({ city: "大阪" }) は "大阪まで3日"

よくある間違い型の側の ? を付け忘れると、days を書かずに呼び出したところが型のエラーになります。既定値は取り出す側にだけ書けます。型の側に { days?: number = 3 } と書くと、文法のエラーになります。

よくある疑問省略できるのはプロパティです。引数そのものは省略できません。かっこの中を空にして呼ぶと、型のエラーになります。プロパティを全部省略するときは、空のオブジェクトを渡して pointText({}) のように呼びます。

新しい書き方

encodeURIComponent()

文字列を、URL に入れられる形に変換する

URL の ? の後ろに並べる q=…&limit=… の部分には、日本語や空白をそのまま入れられません。& や = も区切りの記号なので、検索語の中にあると区切りと見分けられなくなります。encodeURIComponent() は、そうした文字を % と英数字の組に変換した文字列を返します。英字と数字は、そのまま残ります。

サンプル

// encoded を作り、word を URL に入れられる形に変換したものを入れる
const encoded = encodeURIComponent(word);
// 結果: encoded は "%E6%9D%B1%E4%BA%AC%20%E9%A7%85"
encodeURIComponent("ts")
"ts"
英字はそのまま
encodeURIComponent("a&b")
"a%26b"
& も変換する
encodeURIComponent("東京 駅")
"%E6%9D%B1%E4%BA%AC%20%E9%A7%85"
空白は %20 になる

よくある疑問encodeURIComponent は、どこからでも呼べる関数です。かっこの中に、変換する文字列を渡します。文字列のメソッドではないので、word.encodeURIComponent() とは書けません。

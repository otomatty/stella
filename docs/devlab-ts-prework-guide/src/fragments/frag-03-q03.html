03章 ユニオン型とそのほかの型

q03 null と undefined

値がないかもしれない引数やプロパティを扱う関数を 20 個書きます。値がないことは、undefined のほかに null でも表します。string | null のような型の値は、そのまま文字列として使えません。?.（オプショナルチェーン）、??、=== null、=== undefined で、ないときの扱いを書きます。== null のように = が 2 つの比べ方は、lint がエラーにします（eqeqeq）。引数と戻り値の型注釈は、これまでと同じく自分で書きます。

問1文字列か undefined を受け取り、文字数を返す 新しく出てくる書き方：オプショナルチェーン ?. 
export function lengthOrZero() {}

文字列か undefined を 1 つ受け取り、文字数を返します。undefined なら 0 を返します。引数の型は「文字列か undefined」、戻り値の型は数値です。

テストで確かめる値
lengthOrZero("abc")
3
lengthOrZero(undefined)
0
undefined なら 0

型引数が string | undefined、戻り値が number であることも確かめます。

新しい書き方

?.

値があるときだけ、プロパティやメソッドを使う

. の代わりに ?. と書くと、左の値が undefined のときは、その先を実行しません。式全体が undefined になります。値があるときは、. と同じように動きます。これをオプショナルチェーンと呼びます。

サンプル 
// 関数 trimCoupon を作る。文字列か undefined の code を受け取り、文字列か undefined を返す
function trimCoupon(code: string | undefined): string | undefined {
  // code の前後の空白を取り除いたもの（code が undefined なら undefined）を返す
  return code?.trim();
}
// 結果: trimCoupon("  SALE10 ") は "SALE10"、trimCoupon(undefined) は undefined
. で書く
function trimCoupon(code: string | undefined): string | undefined {
  return code.trim();
}
✕ 型の確認でエラーになります。code は undefined かもしれません
?. で書く
function trimCoupon(code: string | undefined): string | undefined {
  return code?.trim();
}
○ code が undefined なら undefined を返します

?. の結果は undefined のことがあります。そのまま ??（02章 q02 問1）につなげると、ないときに使う値を決められます。

サンプル 
// 関数 couponLabel を作る。文字列か undefined の code を受け取り、文字列を返す
function couponLabel(code: string | undefined): string {
  // code の前後の空白を取り除いたもの（code が undefined なら "クーポンなし"）を返す
  return code?.trim() ?? "クーポンなし";
}
// 結果: couponLabel("  SALE10 ") は "SALE10"、couponLabel(undefined) は "クーポンなし"
couponLabel(" SALE10 ")
"SALE10"
couponLabel(undefined)
"クーポンなし"
?. で undefined になり、?? で切り替わる
couponLabel(" ")
""
空の文字列は undefined でないので、?? は切り替えない

新しい書き方

// 結果: couponDiscount("SALE10") は 100、couponDiscount("ABC") は null

export function firstLetter() {}

新しい書き方

?.[1]

値があるときだけ、添字で取り出す

添字の [ ]（01章 q03 問20）にも、?. を付けられます。左の値が undefined か null なら、取り出さずに undefined になります。配列にも文字列にも使えます。

09章 q03（Date）

.toISOString()

日時を、決まった形の文字列にする

Date の値を、"2026-04-01T10:30:00.000Z" の形の文字列にします。この形を ISO 形式と呼びます。いつも世界標準時で表すので、どのパソコンで動かしても同じ文字列になります。文字の位置が決まっているので、.slice()（01章 q02 問10）で一部を取り出せます。

サンプル 
// 関数 orderTime を作る。Date の orderedAt を受け取り、文字列を返す
function orderTime(orderedAt: Date): string {
  // orderedAt を ISO 形式の文字列にしたものの、11 文字目から 16 文字目の前までを取り出して返す
  return orderedAt.toISOString().slice(11, 16);
}
// 結果: orderTime(new Date("2026-04-01T10:30:00Z")) は "10:30"
orderTime(new Date("2026-04-01T10:30:00Z"))
"10:30"
11 文字目から 5 文字

q01 関数宣言・関数式・アロー関数

関数を 20 個書きます。関数の作り方には、関数宣言・関数式・アロー関数の 3 つがあります。問1〜7 は関数宣言、問8〜14 は関数式、問15〜20 はアロー関数で、どの書き方を使うかは問題のコードに用意してあります。書き方は変えずに、引数の名前と型、戻り値の型、中身を書き足します。アロー関数は、中身が式 1 つなら (n: number): number => n * 2 のように { } と return を省けます。テストは、返す値に加えて型も確かめます。

関数の 3 つの書き方

関数の作り方には、関数宣言・関数式・アロー関数の 3 つがあります。受け取る引数と返す値が同じなら、どれで作っても同じように呼べます。関数宣言は、00章からずっと使ってきた形です。アロー関数は 01章 q01 問20 で出ました。関数式は問8 でくわしく見ます。

サンプル 
// 関数 withShipping を作る。数値の price を受け取り、数値を返す
function withShipping(price: number): number {
  // price に 500 を足した数を返す
  return price + 500;
}
// 結果: withShipping(1200) は 1700

同じ関数を 3 つの書き方で書くと、次のようになります。

関数宣言
function withShipping(price: number): number {
  return price + 500;
}
○ withShipping(1200) は 1700
関数式
const withShipping = function (price: number): number {
  return price + 500;
};
○ withShipping(1200) は 1700
アロー関数
const withShipping = (price: number): number => price + 500;
○ withShipping(1200) は 1700

見分けるところは、次の表のとおりです。引数の書き方と、戻り値の型を書く場所（引数のかっこのすぐ後ろ）は、3 つとも同じです。

新しい書き方

関数式（関数を値として作り、const に入れる）

function で作った関数を、値として = の右に書きます。それを const で作った名前に入れます。この形を関数式と呼びます。式は、計算すると値になる書き方のことです。function の後ろには名前を書きません。名前は const の後ろに書きます。

サンプル 
// 関数 withTax を作る。数値の price を受け取り、数値を返す
const withTax = function (price: number): number {
  // price に 1.1 を掛けて切り捨てた数を返す
  return Math.floor(price * 1.1);
};
// 結果: withTax(1000) は 1100

関数式で作った関数も、呼び方は関数宣言と同じで withTax(1000) です。{ } の中も、関数宣言と同じように書けます。

よくある間違い問題のコードの function () の後ろに、half と名前を書き足す必要はありません。名前は const の後ろにもうあります。かっこの中に引数を、かっこの後ろに戻り値の型を書き足します。

よくある疑問最後の ; は、書き忘れても整形（prettier）で付きます。関数宣言の } の後ろには付きません。

アロー関数に戻り値の型を書く

01章 q01 問20 のアロー関数には、戻り値の型を書きませんでした。この番号では書きます。戻り値の型は、引数のかっこのすぐ後ろ、=> の前に : 型 と書きます。関数宣言や関数式と同じ場所です。

サンプル 
// 関数 toPoints を作る。数値の price を受け取り、price を 100 で割って切り捨てた数を返す
const toPoints = (price: number): number => Math.floor(price / 100);
// 結果: toPoints(1980) は 19

問題のコードは () => {} と、{ } が付いた形です。{ } の中に return を書いても、{ } と return を省いても、同じ関数になります。

{ } と return で書く
const toPoints = (price: number): number => {
  return Math.floor(price / 100);
};
○ toPoints(1980) は 19
{ } と return を省く
const toPoints = (price: number): number => Math.floor(price / 100);
○ toPoints(1980) は 19
{ } を残して return だけ消す
const toPoints = (price: number): number => {
  Math.floor(price / 100);
};
✕ 型の確認でエラーになります。何も返さない関数になるからです

コツ戻り値の型を書いておくと、return を書き忘れたときに、型の確認がエラーで知らせてくれます。

問20気温が 25 以上なら「夏日」を返す 新しく出てくる書き方：{ } と return を使うアロー関数 
export const describeTemp = () => {};

気温を受け取り、25 以上なら "夏日"、25 より低ければ "普通" を返します。問題のコードはアロー関数の形です。この問題は { } と return を使って書きます。

テストで確かめる値

新しい書き方

=> { return … }

{ } と return を使うアロー関数

中で if を使うときは、{ } と return が要ります。if は値になる式ではないので、=> の右に直接は書けません。{ } の中は、関数宣言の { } の中と同じように書けます。最後の } の後ろには、const の文の終わりの ; を付けます。

サンプル 
// 関数 stockLabel を作る。数値の count を受け取り、"在庫あり" か "在庫なし" を返す
const stockLabel = (count: number): "在庫あり" | "在庫なし" => {
  // もし count が 0 より大きいなら
  if (count > 0) {
    // "在庫あり" を返す
    return "在庫あり";
  }
  // "在庫なし" を返す
  return "在庫なし";
};
// 結果: stockLabel(3) は "在庫あり"、stockLabel(0) は "在庫なし"

.forEach() に渡した関数（02章 q04 問19）も、この形でした。

よくある間違い(count: number) => if (count > 0) … のように、=> の右に if を書くと、構文エラーになります。構文エラーは、書き方の決まりに合っていないというエラーです。

応用温度の単位を変換する 4 つの関数 新しい書き方はありません。 
export function celsiusToFahrenheit() {}

export const fahrenheitToCelsius = function () {};

export const kelvinToCelsius = () => {};

export const convert = () => {};

温度の単位を変換する 4 つの関数を書きます。摂氏（℃）・華氏（アメリカなどで使う単位）・ケルビン（理科で使う単位）の 3 つを扱います。書き方は、問題のコードに用意してある形のまま使います。引数と戻り値には型注釈を付けます。結果は、どれも小数第 2 位までに四捨五入します。

  1. celsiusToFahrenheit(celsius)：関数宣言です。摂氏を受け取り、華氏を返します。華氏 = 摂氏 × 9 ÷ 5 + 32 です。
  2. fahrenheitToCelsius(fahrenheit)：関数式です。華氏を受け取り、摂氏を返します。摂氏 = (華氏 − 32) × 5 ÷ 9 です。
  3. kelvinToCelsius(kelvin)：アロー関数です。ケルビンを受け取り、摂氏を返します。摂氏 = ケルビン − 273.15 です。
  4. convert(value, from, to)：アロー関数です。from の単位の温度 value を、to の単位に直して返します。単位は "C"（摂氏）・"F"（華氏）・"K"（ケルビン）のどれかです。いったん摂氏に直してから、to の単位にします。1〜3 の関数を使います。摂氏からケルビンにするときは、273.15 を足します。

説明すること：関数宣言とアロー関数の違いを 1 つ。ファイルの「説明すること」のすぐ下に、// のコメントで書きます。

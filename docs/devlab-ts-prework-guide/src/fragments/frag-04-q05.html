04章 文と例外

q05 例外処理

例外を扱う関数を 20 個書きます。例外は、処理を続けられないときに投げる知らせです。引数と戻り値には型注釈を付けます。例外を投げるときは throw new Error("メッセージ") と書き、メッセージは問題文のとおりにします。JSON.parse、new URL、decodeURIComponent、BigInt、文字列の .repeat() は、おかしな値を渡すと例外を投げます。その例外を try / catch で受け止める問題もあります。catch で受け取る値の型は unknown です。使う前に instanceof Error などで型を絞り込みます。

テストで確かめる値

requirePositive(0)
エラーを投げる

新しい書き方

/^…$/

正規表現（01章 q05 問18）の中で、^ は文字列の先頭、$ は文字列の最後を表します。両方を付けると、文字列の一部だけでなく、全体がその形かを調べます。? は、すぐ前の 1 文字があってもなくてもよいことを表します。

// 結果: isCode は true
/^[A-Z]+-?\d+$/.test("SKU42")
true
- がなくてもよい
/^[A-Z]+-?\d+$/.test("SKU-42a")
false
最後に a が余っている
/[A-Z]+-?\d+/.test("SKU-42a")
true
^ と $ がないと、一部が合えば true

新しい書き方

try { } catch { }

例外を受け止める

関数の中で throw が実行されると、例外が投げられます。何もしなければ、呼んだ側の関数もそこで止まります。try で囲んでおくと、投げられた例外を受け止めて、catch の中の処理を続けられます。

サンプル 
// 関数 checkStock を作る。数値の stock を受け取り、数値を返す
function checkStock(stock: number): number {
  // もし stock が 0 と等しいなら
  if (stock === 0) {
    // "在庫がありません" というメッセージのエラーを投げる
    throw new Error("在庫がありません");
  }
  // stock を返す
  return stock;
}

// 関数 orderLabel を作る。数値の stock を受け取り、文字列を返す
function orderLabel(stock: number): string {
  // 次の中を試す。例外が投げられたら、catch の中に飛ぶ
  try {
    // checkStock に stock を渡して呼ぶ
    checkStock(stock);
    // "注文できます" を返す
    return "注文できます";
  } catch {
    // （例外が投げられたら）"在庫切れ" を返す
    return "在庫切れ";
  }
}
// 結果: orderLabel(5) は "注文できます"、orderLabel(0) は "在庫切れ"

よくある疑問例外は checkStock の中で投げられています。それでも、checkStock を呼んだ orderLabel の try まで飛んできて、そこで受け止められます。

コツcatch の後ろに (error) と書くと、投げられたものを受け取れます。受け取ったものを使わないときは、サンプルのように catch { } とだけ書きます。受け取る書き方は問18 で出ます。

JSON.parse()

JSON の文字列を値にする

JSON は、データを文字列で書き表す決まった形です。オブジェクトや配列を、TypeScript とほぼ同じ形で書きます。ただし、プロパティの名前は " で囲みます。JSON.parse() は、JSON の文字列を読んで、オブジェクトや配列などの値にします。JSON の形になっていないと、例外を投げます。

サンプル

// 結果: data は { id: 7, qty: 3 }
JSON.parse("[1, 2, 3]")
[1, 2, 3]
JSON.parse('"abc"')
"abc"
" で囲んだ文字列も JSON
JSON.parse("{qty:3}")
例外を投げる
名前の qty を " で囲んでいない
JSON.parse("")
例外を投げる
空の文字列は JSON ではない

Error から作った値かを調べる

値 instanceof Error は、値が new Error() などで作ったエラーなら true を返します。if の条件に書くと、if の中では、その値を Error 型として扱えます。このように、条件で型を狭めることを「型の絞り込み」と呼びます。

サンプル 
// 関数 describeFailure を作る。unknown 型の reason を受け取り、文字列を返す
function describeFailure(reason: unknown): string {
  // もし reason が Error から作った値なら
  if (reason instanceof Error) {
    // reason のメッセージを埋め込んだ「注文に失敗しました: ◯」を返す
    return `注文に失敗しました: ${reason.message}`;
  }
  // "注文に失敗しました" を返す
  return "注文に失敗しました";
}
// 結果: describeFailure(new Error("在庫がありません")) は "注文に失敗しました: 在庫がありません"、describeFailure(404) は "注文に失敗しました"

// reason の型は unknown のまま
return reason.message;
✕ 型の確認でエラーになります
instanceof で絞り込んだあと
if (reason instanceof Error) {
  // ここでは reason の型は Error

○ message を読めます

ヒント 2コードへの直し方

前後の空白を取り除くのは .trim()（01章 q05 問9）です。取り除いた結果を変数に入れておくと、確かめるときと返すときの両方で使えます。

応用年齢を読む・読めなければ null・メッセージを取り出す・まとめて読む 新しい書き方はありません。 
export function parseAge() {}

export function safeParseAge() {}

export function errorMessage() {}

export function parseAges() {}

4 つの関数を書きます。引数と戻り値には型注釈を付けます。

  1. parseAge：文字列を年齢の数値にして返します。前後の空白は取り除きます。0 から 150 までの整数にならないときは、"年齢として読めません: " の後ろに受け取った文字列 input をそのままつなげたメッセージのエラーを投げます。引数は文字列、戻り値は数値です。
  2. safeParseAge：parseAge を try / catch で囲み、例外が投げられたら null を返します。戻り値は number | null です。
  3. errorMessage：catch で受け取った値（型は unknown）からメッセージを取り出します。Error ならその message を、文字列ならその文字列を、それ以外なら "不明なエラー" を返します。
  4. parseAges：文字列の配列を年齢の配列にします。読めなかったものは飛ばし、そのメッセージを errors に集めます。{ ages: number[]; errors: string[] } を返します。引数は readonly string[] です。

ヒント 2コードへの直し方

parseAge では、Number("") が 0 になるので、空の文字列かを先に確かめます。"abc" を数値にすると NaN になり、整数ではないので、Number.isInteger()（01章 q04 応用）の確かめで弾けます。safeParseAge は問12 と同じ形です。errorMessage は問10 を if で書いた形に、typeof（03章 q01 問3）の if を足します。parseAges は問17 の形に、問18 の catch (error) を合わせます。配列の型注釈は const ages: number[] = [] のように書き、最後は { ages, errors }（02章 q01 問3 の省略記法）を返します。

q06 unknown型と型の絞り込み

型の分からない値（unknown）を受け取る関数を 20 個書きます。引数と戻り値には型注釈を付けます。unknown の値は、そのままではメソッドもプロパティも使えません。typeof、instanceof、Array.isArray()、=== null、"name" in value などで、どんな値かを確かめてから使います。確かめると、その先では型が狭まります。これを型の絞り込みと呼びます。any（型の確認をしない型）は使いません。

問1文字列なら true を返す 新しく出てくる書き方：unknown の値の絞り込み 
export function isText() {}

どんな値でも 1 つ受け取ります。文字列なら true、それ以外なら false を返します。引数の型は unknown、戻り値の型は boolean にします。

テストで確かめる値
isText("a")
true
isText(1)
false
数値は文字列ではない

型引数が unknown、戻り値が boolean であることも確かめます。

新しい書き方

typeof value === "string"

unknown の値を確かめて、型を絞り込む

unknown は、02章 q01 の応用で出た「どんな値が入っているか分からない」型です。引数を unknown にすると、文字列でも数値でも配列でも受け取れます。その代わり、中身を確かめるまでは、メソッドもプロパティも使えません。

確かめるには、03章 q01 問3 の typeof を使います。typeof input === "string" は、input の型が文字列なら true です。

サンプル 
// 入力 input を作り、型を unknown にして、"summer" を入れる
const input: unknown = "summer";
// isCode を作り、input の型が文字列かどうか（true か false）を入れる
const isCode = typeof input === "string";
// 結果: isCode は true

この確かめを if の条件に書くと、その { } の中では、値を文字列として使えます。確かめずに使うと、型の確認でエラーになります。

確かめずに使う
// 関数 couponLabel を作る。型の分からない code を受け取り、文字列を返す
function couponLabel(code: unknown): string {
  // code を大文字にしたものを返す
  return code.toUpperCase();
}
✕ code は unknown なので、型の確認でエラーになります
typeof で確かめてから使う
// 関数 couponLabel を作る。型の分からない code を受け取り、文字列を返す
function couponLabel(code: unknown): string {
  // もし code の型が文字列なら
  if (typeof code === "string") {
    // code を大文字にしたものを返す
    return code.toUpperCase();
  }
  // "コードなし" を返す
  return "コードなし";
}
○ couponLabel("summer") は "SUMMER"、couponLabel(500) は "コードなし" になります

couponLabel の code の型は、場所によって次のように変わります。

よくある疑問any も、どんな値でも入る型です。ただし型の確認をしないので、確かめずに .toUpperCase() を呼んでもエラーになりません。数値が来ると、実行したときに初めて失敗します。この課題では any を書くと ESLint でエラーになります（no-explicit-any）。

    item !== null &&
    "stock" in item &&

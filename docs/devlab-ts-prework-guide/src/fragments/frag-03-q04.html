03章 ユニオン型とそのほかの型

q04 判別可能なユニオン型

図形や支払い方法のように、いくつかの形を持つ値を扱う関数を 20 個書きます。どの形にも kind や method のような同じ名前のプロパティがあり、その値で形を見分けられます。この値を調べて形を見分けてから、その形にだけあるプロパティを使います。問1〜11 は、ファイルに書いてある型 Shape・Payment・Notice を使います。問12〜20 は、型を自分で作って export し、その型を使って関数を書きます。switch を使うときは、すべての場合の case を書きます。引数と戻り値には型注釈を付けます。

問1図形の面積を返す 新しく出てくる書き方：判別可能なユニオン型、switch / case、Math.PI 
export type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; size: number }
  | { kind: "rect"; width: number; height: number };

export function shapeArea() {}

Shape は、円・正方形・長方形のどれかを表す型です。kind の値で、どの図形かが分かります。図形を 1 つ受け取り、面積を返します。円は「円周率 × 半径 × 半径」、正方形は「1 辺 × 1 辺」、長方形は「横 × 縦」です。

テストで確かめる値
shapeArea({ kind: "circle", radius: 1 })
3.141592653589793
円周率とほぼ同じ数であること
shapeArea({ kind: "square", size: 3 })
9
3 × 3
shapeArea({ kind: "rect", width: 2, height: 5 })
10
2 × 5

型引数が Shape、戻り値が number であることも確かめます。

新しい書き方

{ kind: "a" } | { kind: "b" }

判別可能なユニオン型

オブジェクトの型を | でつなぐと、「どれか 1 つの形」を表す型になります。どの形にも同じ名前のプロパティを置き、形ごとに違うリテラル型（01章 q07）を書きます。このプロパティの値を見れば、どの形かが分かります。このような型を、判別可能なユニオン型と呼びます。

サンプル 
// Delivery という型を作る。「kind は "store"」か「kind は "home"、distance は数値」のどちらか
type Delivery = { kind: "store" } | { kind: "home"; distance: number };

// 関数 deliveryFee を作る。Delivery の delivery を受け取り、数値を返す
function deliveryFee(delivery: Delivery): number {
  // もし delivery の kind が "store" と等しいなら
  if (delivery.kind === "store") {
    // 0 を返す
    return 0;
  }
  // delivery の distance に 50 を掛けた数を返す
  return delivery.distance * 50;
}
// 結果: deliveryFee({ kind: "store" }) は 0、deliveryFee({ kind: "home", distance: 12 }) は 600

判別するプロパティの値を === で比べると、TypeScript は形を絞り込みます（03章 q01 の絞り込み）。サンプルの if の中では、delivery は店の形です。if の中で return したので、その後ろの行に来るのは家の形だけです。だから delivery.distance が使えます。

形を見分けずに使う
function deliveryFee(delivery: Delivery): number {
  return delivery.distance * 50;
}
エラー。店の形には distance がない
kind で見分けてから使う
function deliveryFee(delivery: Delivery): number {
  if (delivery.kind === "store") {
    return 0;
  }
  return delivery.distance * 50;
}
通る。残りは家の形だけ

よくある間違い見分ける前の delivery は、店の形かもしれません。だから delivery.distance と書くと、型の確認で「{ kind: "store"; } に distance はない」というエラーになります。

switch (…) { case …: }

値で場合を分ける

switch は、1 つの値で場合を分ける文です。switch の後ろのかっこに、調べる値を書きます。{ } の中に case 値: を並べます。調べる値と等しい case を探し、その下の行を実行します。判別可能なユニオン型では、判別するプロパティの値で場合を分けるときによく使います。

サンプル 
// Delivery という型を作る。「kind は "store"」か「kind は "home"、distance は数値」か「kind は "express"、distance は数値、fee は数値」のどれか
type Delivery =
  | { kind: "store" }
  | { kind: "home"; distance: number }
  | { kind: "express"; distance: number; fee: number };

// 関数 deliveryFee を作る。Delivery の delivery を受け取り、数値を返す
function deliveryFee(delivery: Delivery): number {
  // delivery の kind で場合を分ける
  switch (delivery.kind) {
    // "store" の場合
    case "store":
      // 0 を返す
      return 0;
    // "home" の場合
    case "home":
      // delivery の distance に 50 を掛けた数を返す
      return delivery.distance * 50;
    // "express" の場合
    case "express":
      // delivery の distance に 50 を掛け、delivery の fee を足した数を返す
      return delivery.distance * 50 + delivery.fee;
  }
}
// 結果: deliveryFee({ kind: "home", distance: 12 }) は 600、deliveryFee({ kind: "express", distance: 12, fee: 300 }) は 900

case の下でも絞り込みが効きます。case "home": の下では、delivery は家の形として扱われます。だから delivery.distance が使えます。

すべての case を書くこの課題の ESLint は、case が足りない switch をエラーにします。サンプルから case "express": を消すと、「Switch is not exhaustive. Cases not matched: "express"」と出ます。同時に、型の確認でも「関数の最後に return がない」というエラーになります。すべての case で return していれば、switch の後ろに return は要りません。kind が 3 つのどれかしかないことを、TypeScript が知っているからです。

ここでは、まねて書ければ十分です。

04章 q02（switch文）

Math.PI

円周率

Math.PI は円周率（約 3.14）を表す数です。関数ではないので、かっこを付けません。

サンプル 
// 丸いラベルの直径 diameter を作り、4 を入れる
const diameter = 4;
// 周りの長さ edge を作り、Math.PI × diameter を入れる
const edge = Math.PI * diameter;
// 結果: edge は 12.566370614359172

よくある疑問円周率を使う計算は、答えが割り切れない数になります。そのため、テストは「ほぼ同じ数か」で確かめます。Math.PI を使えば、細かい桁は気にしなくてかまいません。

問1 の Shape と同じ形の型を、自分で書きます。type 名前 =（02章 q01 の応用）の右に、オブジェクトの型を | でつないで並べます。どの形にも、見分けるためのプロパティを同じ名前で置き、形ごとに違う値のリテラル型を書きます。

サンプル 
// Member という型を作る。「rank は "gold"、name は文字列、discount は数値」か「rank は "normal"、name は文字列」のどちらか。ほかのファイルから使えるようにする
export type Member =
  { rank: "gold"; name: string; discount: number } | { rank: "normal"; name: string };

// 関数 memberLabel を作る。Member の member を受け取り、文字列を返す
function memberLabel(member: Member): string {
  // 割引 rate を作り、member の rank が "gold" と等しいなら member の discount、そうでなければ 0 を入れる
  const rate = member.rank === "gold" ? member.discount : 0;
  // member の name と rate を埋め込んだ「◯様（割引◯%）」の文字列を返す
  return `${member.name}様（割引${rate}%）`;
}
// 結果: memberLabel({ rank: "gold", name: "佐藤", discount: 10 }) は "佐藤様（割引10%）"

どの形にもあるプロパティは、見分ける前でも使えます。サンプルの name は 2 つの形の両方にあるので、member.name はそのまま書けます。discount は金の会員の形にしかないので、rank を確かめてから使います。

よくある疑問型が長くなると、整形（Prettier）が = の後ろで改行します。形が多いと、問1 の Shape のように | を行の先頭に置いた形にもなります。どちらも同じ型です。

よくある間違い見分けるプロパティの値を rank: string のように書くと、値で形を見分けられません。rank: "gold" のように、値そのものをリテラル型で書きます。テストも型の中身を比べるので、string では失敗します。

サンプル 
// Stock という型を作る。「inStock は true、count は数値」か「inStock は false、arrival は文字列」のどちらか
type Stock = { inStock: true; count: number } | { inStock: false; arrival: string };

// 関数 stockText を作る。Stock の stock を受け取り、文字列を返す
function stockText(stock: Stock): string {
  // stock の inStock が true なら「在庫 ◯個」、そうでなければ「◯入荷予定」の文字列を返す
  return stock.inStock ? `在庫 ${stock.count}個` : `${stock.arrival}入荷予定`;
}
// 結果: stockText({ inStock: true, count: 8 }) は "在庫 8個"、stockText({ inStock: false, arrival: "5月10日" }) は "5月10日入荷予定"

true と比べる

  ? `在庫 ${stock.count}個`
  : `${stock.arrival}入荷予定`;
ESLint のエラー
そのまま条件に書く

  ? `在庫 ${stock.count}個`
  : `${stock.arrival}入荷予定`;
通る

よくある間違いstock.inStock === true と書くと、型の確認は通ります。でも、この課題の ESLint が「boolean の値を boolean と比べる必要はない」というエラーを出します。true か false の値は、そのまま条件に書きます。

型area と describeShape は、どちらも引数が Shape です。戻り値は area が number、describeShape が string であることも確かめます。

// Shape という型を作る。「kind は "circle"、radius は数値」か「kind は "rect"、width は数値、height は数値」か「kind は "triangle"、base は数値、height は数値」のどれか。ほかのファイルから使えるようにする
export type Shape = unknown;

// 関数 area を作る。Shape の shape を受け取り、数値を返す
export function area() {
  // shape の kind で場合を分ける
    // "circle" の場合

    // "rect" の場合
      // shape の width と shape の height を掛けた数を返す
    // "triangle" の場合
      // shape の base と shape の height を掛け、2 で割った数を返す
}

// 関数 describeShape を作る。Shape の shape を受け取り、文字列を返す
export function describeShape() {
  // shape の kind で場合を分ける

      // shape の radius を埋め込んだ「円（半径 ◯）」の文字列を返す
    // "rect" の場合
      // shape の width と shape の height を埋め込んだ「長方形（◯ × ◯）」の文字列を返す
    // "triangle" の場合

ヒント 2コードへの直し方

Shape は、unknown を消して、問1 の Shape と同じ形で書きます。正方形の代わりに三角形が入ります。オブジェクトの型をきちんと書けば、円に width を書いたときに型の確認でエラーになります。2 つの関数は、どちらも問1 と同じ switch の形です。area の三角形と円は問1・問3 の計算と同じ考え方で、describeShape は問9 と同じく case ごとにテンプレートリテラルを返します。

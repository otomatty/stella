q10 配列のユーティリティ

生徒の配列を集計する関数を 20 個書き、最後に★総合問題に取り組みます。ファイルには、生徒を表す型 Student が最初から書いてあります。name が名前、grade が学年、score が点数です。引数の配列は readonly Student[] にします。元の配列も、中の生徒のオブジェクトも書き換えません。引数と戻り値には型注釈を付けます。map・filter・some・every・find などの配列のメソッドを使ってかまいません。sort は元の配列を並べ替えてしまうので、コピーしてから使います。ここで書く関数の多くは、★総合問題で形を広げて、もう一度書きます。

オブジェクトの配列を、プロパティの大きい順に並べる

02章 q05 問8・問9 では、数値の配列を .sort() で並べました。オブジェクトの配列を並べるときは、比べ方の関数の中で、比べたいプロパティを取り出して引き算します。大きい順にするときは、b のプロパティから a のプロパティを引きます。

サンプル 
// 商品 Product という型を作る。name は文字列、price は数値
type Product = { name: string; price: number };
// 商品の配列 products を作る。型は Product の配列。3 つの商品を入れる
const products: Product[] = [
  { name: "ノート", price: 300 },
  { name: "ペン", price: 150 },
  { name: "ファイル", price: 300 },
];
// byPrice を作り、products をコピーした配列を、price の大きい順に並べたものを入れる
const byPrice = [...products].sort((a, b) => b.price - a.price);
// 結果: byPrice は ノート、ファイル、ペン の順。products は ノート、ペン、ファイル の順のまま
abb.price - a.price前になるのは
ノート（300）ペン（150）-150a のノート
ペン（150）ファイル（300）150b のファイル
ノート（300）ファイル（300）0元の順のまま

比べ方の関数が 0 を返した 2 つは、元の配列の順のまま並びます。サンプルのノートとファイルは、どちらも 300 円です。元の配列でノートが前にあるので、並べたあともノートが前です。

オブジェクトどうしを引く
const byPrice = [...products].sort((a, b) => b - a);
✕ 引き算の左右は数値でないといけない、というエラーになります
プロパティどうしを引く
const byPrice = [...products].sort((a, b) => b.price - a.price);
○ 値段の高い順に並びます

よくある疑問安い順にしたいときは、a.price - b.price と引き算の順番を入れ替えます。数値の配列のときと同じです。

.find()

条件に合う最初の要素を探す

.find() は、要素を前から 1 つずつコールバックに渡します。最初に true が返った要素を、そのまま返します。見つかったところで止まり、残りの要素は調べません。1 つも合わなければ undefined を返します。

// 商品の配列 products を作る。型は Product の配列。2 つの商品を入れる

  { code: "A-01", price: 300 },
  { code: "B-02", price: 150 },
];
// found を作り、products の要素を 1 つずつ p として、p の code が "B-02" と等しい最初のもの（なければ undefined）を入れる
const found = products.find((p) => p.code === "B-02");
// missing を作り、products の要素を 1 つずつ p として、p の code が "C-03" と等しい最初のもの（なければ undefined）を入れる
const missing = products.find((p) => p.code === "C-03");
// 結果: found は { code: "B-02", price: 150 }、missing は undefined

.filter()（02章 q04 問7）も条件で選びます。.filter() は、合う要素すべてを配列で返します。.find() は、合う最初の 1 つを、配列に入れずに返します。

8
合うのは 8 と 12。最初の 8 だけを返す
[3, 8, 12].filter((stock) => stock > 5)

合うものすべてを、配列で返す

1 つも合わない

5 つの関数を書きます。どれも生徒の配列 readonly Student[] を受け取り、元の配列も生徒のオブジェクトも変えません。keyFn と predicate は、生徒を 1 人受け取る関数です。引数と戻り値には型注釈を付けます。

  2. countBy(students, keyFn)：keyFn(生徒) が返す文字列ごとに、人数を数えます。戻り値は { [key: string]: number } です。
  3. partition(students, predicate)：predicate が true を返す生徒と false を返す生徒に分け、[true の配列, false の配列] を返します。

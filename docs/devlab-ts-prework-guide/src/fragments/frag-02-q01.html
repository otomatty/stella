02章 オブジェクト・配列・タプル

q01 オブジェクトの型

オブジェクトを受け取る関数と、オブジェクトを作って返す関数を 20 個書きます。オブジェクトは、名前の付いた値をいくつかまとめたものです。引数と戻り値には型注釈を付けます。オブジェクトの型は { name: string; age: number } のように、プロパティ（オブジェクトの中の 1 つ 1 つの値）の名前と型を並べて書きます。type で型に名前を付けてもかまいません。オブジェクトを作るときに、プロパティの名前と変数の名前が同じなら、{ x: x } を { x } と短く書きます。この省略記法で書いているかは、ESLint も確かめます。

問1利用者 { name, age } の name を返す 新しく出てくる書き方：オブジェクトの型 { name: string; age: number }、プロパティの参照 user.name 
export function getName() {}

利用者のオブジェクトを 1 つ受け取り、その名前（name）を返します。利用者は、文字列の name と数値の age の 2 つのプロパティを持ちます。引数の名前と型注釈は自分で書きます。

テストで確かめる値
getName({ name: "山田", age: 30 })
"山田"

型引数が { name: string; age: number }、戻り値が string であることも確かめます。

新しい書き方

{ name: string; stock: number }

オブジェクトの型を書く

オブジェクトは、いくつかの値に名前を付けてまとめたものです。1 つ 1 つの値をプロパティと呼びます。テストの getName({ name: "山田", age: 30 }) では、{ } で囲んだ部分がオブジェクトです。作り方は問3 で説明します。

オブジェクトを受け取る引数には、どんな名前のプロパティを、どんな型で持つかを型注釈に書きます。{ } の中に 名前: 型 を並べ、; で区切ります。

サンプル 
// 関数 isInStock を作る。文字列の name と数値の stock を持つオブジェクト item を受け取り、true か false を返す
function isInStock(item: { name: string; stock: number }): boolean {
  // item の stock が 0 より大きいかどうか（true か false）を返す
  return item.stock > 0;
}
// 結果: isInStock({ name: "ノート", stock: 30 }) は true、isInStock({ name: "付箋", stock: 0 }) は false

item.stock の書き方は、次の項目で説明します。

型に書いたプロパティは、渡すオブジェクトにすべてそろっている必要があります。

プロパティがそろっている
// isInStock に name と stock を持つオブジェクトを渡して呼ぶ
isInStock({ name: "ノート", stock: 30 });
○ true が返ります
stock が足りない
// isInStock に name だけを持つオブジェクトを渡して呼ぶ
isInStock({ name: "ノート" });
✕ 型の確認でエラーになります

よくある間違いテストは、引数の型が { name: string; age: number } とちょうど同じかを確かめます。関数の中で name しか使わなくても、age を省いて { name: string } と書くと、テストの型の確認で失敗します。

コツ型の中の区切りを , にしても型の確認は通ります。ただし、保存したときの整形（Prettier）で ; に直ります。

サバイバルTypeScript「オブジェクトの型注釈」

order.total

プロパティの値を取り出す

オブジェクトの後ろに . とプロパティの名前を書くと、そのプロパティの値を取り出せます。文字列の .length（01章 q02 問13）と同じ書き方です。

サンプル 
// 関数 orderLabel を作る。文字列の id と数値の total を持つオブジェクト order を受け取り、文字列を返す
function orderLabel(order: { id: string; total: number }): string {
  // order の id と order の total を埋め込んだ「注文◯：◯円」の文字列を返す
  return `注文${order.id}：${order.total}円`;
}
// 結果: orderLabel({ id: "A-102", total: 3200 }) は "注文A-102：3200円"

よくある間違い型に書いていないプロパティは取り出せません。このサンプルで order.price と書くと、型の確認でエラーになります。

オブジェクトを作る（オブジェクトリテラル）

{ } の中に 名前: 値 を , で区切って並べると、オブジェクトができます。この書き方をオブジェクトリテラルと呼びます。

サンプル 
// 商品 item を作り、name が "ノート"、stock が 30 のオブジェクトを入れる
const item = { name: "ノート", stock: 30 };
// 結果: item.stock は 30

関数からオブジェクトを返すときは、戻り値の型にオブジェクトの型を書きます。

サンプル 
// 関数 emptyCart を作る。何も受け取らず、数値の count と数値の total を持つオブジェクトを返す
function emptyCart(): { count: number; total: number } {
  // count が 0、total が 0 のオブジェクトを返す
  return { count: 0, total: 0 };
}
// 結果: emptyCart() は { count: 0, total: 0 }

型と値は、見た目が似ています。区切りの記号と、: の後ろに書くものが違います。

書くもの例区切り: の後ろ
型{ name: string; stock: number };型
値（オブジェクトリテラル）{ name: "ノート", stock: 30 },値

よくある疑問1 つめのサンプルのように型注釈を書かないと、入れた値から型が推論されます。VS Code で item にマウスを載せると、{ name: string; stock: number } と表示されます。

サバイバルTypeScript「オブジェクトの型注釈」

{ name, stock }

プロパティの省略記法

プロパティの名前と、入れる変数の名前が同じときは、name: name を name の 1 語に短くできます。この問題のように、引数をそのままプロパティにするときに使います。

サンプル 
// 関数 makeItem を作る。文字列 name と数値 stock を受け取り、文字列の name と数値の stock を持つオブジェクトを返す
function makeItem(name: string, stock: number): { name: string; stock: number } {
  // name と stock を持つオブジェクトを返す
  return { name, stock };
}
// 結果: makeItem("ボールペン", 12) は { name: "ボールペン", stock: 12 }
{ name, stock }
{ name: name, stock: stock }
と同じオブジェクトです。
名前を 2 回書く
return { name: name, stock: stock };
✕ ESLint でエラーになります
省略記法で書く
return { name, stock };
○ 同じオブジェクトが返ります

コツ名前が違うプロパティや、決まった値を入れるプロパティは、そのまま 名前: 値 と書きます。{ name, stock: 0 } のように混ぜてもかまいません。

応用本の型 Book と、本を説明する関数・作る関数 新しく出てくる書き方：型エイリアス type、export type、unknown 
export type Book = unknown;

export function describeBook() {}

export function createBook() {}

本を表す型を作り、その型を使う関数を 2 つ書きます。引数と戻り値には型注釈を付けます。

  1. Book：本を表す型です。title（文字列）・author（文字列）・price（数値）の 3 つのプロパティを持ちます。テストがこの型を読むので、export は残します。
  2. describeBook：Book を 1 つ受け取り、「『タイトル』著者（価格円）」の形の文字列を返します。価格は 3 桁ごとに , で区切ります。かっこはどちらも全角です。
  3. createBook：タイトル・著者・価格をこの順に受け取り、Book を作って返します。プロパティの省略記法を使います。
テストで確かめる値
Book の型
{ title: string; author: string; price: number }
と同じ型であること
describeBook({ title: "TypeScript入門", author: "山田", price: 1200 })
"『TypeScript入門』山田（1,200円）"
describeBook({ title: "React", author: "佐藤", price: 980 })
"『React』佐藤（980円）"
3 桁以下はカンマなし
createBook("TypeScript入門", "山田", 1200)
{ title: "TypeScript入門", author: "山田", price: 1200 }

型describeBook は引数が Book、戻り値が string であることも確かめます。createBook は引数が string・string・number、戻り値が Book であることも確かめます。

新しい書き方

export type Item = { … };

型に名前を付ける（型エイリアス）

type 名前 = 型; と書くと、型に名前を付けられます。これを型エイリアスと呼びます。付けた名前は、型注釈の中で、元の型の代わりに使えます。同じオブジェクトの型を何度も書かずに済みます。

前に export を付けると、ほかのファイルからもその型を使えます。export const（01章 q03 問1）と同じ考え方です。

サンプル 
// Item という型を作る。name は文字列、stock は数値。ほかのファイルから使えるようにする
export type Item = {
  name: string;
  stock: number;
};

// 関数 isSoldOut を作る。Item の item を受け取り、true か false を返す
function isSoldOut(item: Item): boolean {
  // item の stock が 0 と等しいかどうか（true か false）を返す
  return item.stock === 0;
}
// 結果: isSoldOut({ name: "ノート", stock: 0 }) は true
型をそのまま書く
function isSoldOut(item: { name: string; stock: number }): boolean {
  return item.stock === 0;
}
名前を付けた型を書く
function isSoldOut(item: Item): boolean {
  return item.stock === 0;
}

よくある疑問テストは型の中身を比べます。名前を付けた型と、そのまま書いた型は、プロパティが同じなら同じ型として扱われます。プロパティを書く順番も問いません。q01 のドリルで type を使ってもかまいません。

コツ型の名前は、Item や Book のように大文字で始めることがよくあります。

ここでは、まねて書ければ十分です。

03章 q01（型エイリアスとユニオン型）

unknown

中身がまだ分からない型

unknown は「どんな値が入っているか分からない」ことを表す型です。どんな値でも入りますが、中身を確かめるまでは、プロパティを取り出すことも計算に使うこともできません。

サンプル 
// 入力 input を作り、型を unknown にして、"ノート" を入れる
const input: unknown = "ノート";
// 結果: input の型は unknown

よくある間違いこのサンプルの後ろで input.length と書くと、中身は文字列でも、型の確認でエラーになります。

応用のファイルには、はじめから export type Book = unknown; と書いてあります。これは、まだ型を決めていないことを表す仮の書き方です。このままでは、テストの型の確認で失敗します。= の右の unknown を、オブジェクトの型に書き換えます。

ここでは、unknown を書き換えれば十分です。

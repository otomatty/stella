04章 文と例外

q01 if-else文

条件によって返す値を変える関数を 20 個書きます。if・else if・else で書きます。2 つの値のどちらかを返すだけの短い関数は、条件演算子 ? :（01章 q01 問12。三項演算子とも呼びます）で書いてもかまいません。引数と戻り値の型注釈は自分で書きます。決まった値しか返さない関数は、戻り値の型を "合格" | "不合格" のようなリテラル型のユニオン（01章 q07）にします。テストは、返す値に加えて型も確かめます。どの問題でどの型を確かめるかは、「テストで確かめる値」に書いてあります。

問1絶対値を返す 新しく出てくる書き方：else、if-else の形（else if の並べ方、早めに return する書き方） 
export function absValue() {}

数を受け取り、その絶対値を返します。絶対値は、0 からの距離のことです。負の数なら符号を反転して正の数にします。0 と正の数は、そのまま返します。Math.abs は使わずに、if で書きます。

テストで確かめる値
absValue(-5)
5
負の数は符号を反転する
absValue(3)
3
正の数はそのまま
absValue(0)
0

型引数が number、戻り値が number であることも確かめます。

新しい書き方

else

そうでなければ

if の条件に合わなかったときは、else の後ろの { } を実行します。if の { } と else の { } は、必ずどちらか片方だけが実行されます。

サンプル 
// 関数 salesAmount を作る。数値の price と、true か false の isReturn を受け取り、数値を返す
function salesAmount(price: number, isReturn: boolean): number {
  // もし isReturn が true なら
  if (isReturn) {
    // price の符号を反転した数を返す（返品は売上から引く）
    return -price;
  } else {
    // （そうでなければ）price を返す
    return price;
  }
}
// 結果: salesAmount(1200, false) は 1200、salesAmount(1200, true) は -1200

-price のように変数の前に - を付けると、符号を反転した数になります。01章 q05 問4 のマイナスの数と同じ記号です。

if・else if・else を全部使うと、次の形になります。

else if と else は、どちらも省けます。よく使う組み合わせは次の 3 つです。

if { }
合うときだけ実行
合わなければ何もしない（01章 q01 問9）
if { } else { }
2 つのどちらか
必ずどちらか片方を実行する
if { } else if { } else { }
3 つ以上のどれか
上から順に確かめ、最初に合ったものを実行する

決まりelse の後ろの { } も、中身が 1 行でも省けません（curly）。

サバイバルTypeScript「if-else文」、サバイバルTypeScript「三項演算子」

else if

条件を並べる順番

else if を並べると、上から順に確かめ、最初に true になったところだけを実行します。そこから下の条件は確かめません。そのため、並べる順番で結果が変わります。

「◯ 以上」で分けるときは、大きい数から並べます。「◯ より小さい（未満）」で分けるときは、小さい数から並べます。

サンプル 
// 関数 memberRank を作る。数値の points を受け取り、"ゴールド" か "シルバー" か "一般" を返す
function memberRank(points: number): "ゴールド" | "シルバー" | "一般" {
  // もし points が 1000 以上なら
  if (points >= 1000) {
    // "ゴールド" を返す
    return "ゴールド";
  } else if (points >= 300) {
    // （そうでなく、もし points が 300 以上なら）"シルバー" を返す
    return "シルバー";
  } else {
    // （そうでなければ）"一般" を返す
    return "一般";
  }
}
// 結果: memberRank(1500) は "ゴールド"、memberRank(500) は "シルバー"、memberRank(100) は "一般"

100falsefalse"一般"

順番を逆にすると、1500 点でも "シルバー" になります。1500 は 300 以上でもあるので、先に書いた条件に合ってしまうからです。

大きい数から並べる
if (points >= 1000) {
  return "ゴールド";
} else if (points >= 300) {
  return "シルバー";
} else {
  return "一般";
}
○ memberRank(1500) は "ゴールド"
小さい数から並べる

  return "シルバー";
} else if (points >= 1000) {
  return "ゴールド";
} else {

✕ memberRank(1500) が "シルバー" になります。"ゴールド" の行には届きません

よくある間違い境目の数に気をつけます。「以上」は >=、「以下」は <=、「未満（より小さい）」は <、「より大きい」は > です。テストは、bmiLabel(18.5) のように境目の数をよく確かめます。

if (…) { return …; }

早めに return する（else を書かない）

01章 q07 問2 で、if の中で return すると、関数はそこで終わることを見ました。if の { } が return で終わるなら、次の行まで来るのは、条件に合わなかったときだけです。そのため else を書かなくても、結果は同じになります。

サンプル 
// 関数 memberRank を作る。数値の points を受け取り、"ゴールド" か "シルバー" か "一般" を返す
function memberRank(points: number): "ゴールド" | "シルバー" | "一般" {
  // もし points が 1000 以上なら
  if (points >= 1000) {
    // "ゴールド" を返す（ここで関数が終わる）
    return "ゴールド";
  }
  // もし points が 300 以上なら
  if (points >= 300) {
    // "シルバー" を返す
    return "シルバー";
  }
  // "一般" を返す
  return "一般";
}
// 結果: memberRank(1500) は "ゴールド"、memberRank(500) は "シルバー"、memberRank(100) は "一般"

2 つめの if まで来るのは、1000 点より少ないときだけです。上の else if の版と同じ結果になります。

使えない値や、計算しなくてよい値のときに、関数の最初で先に返しておく書き方もよく使います。残りの行では、ふつうの場合だけを考えれば済みます。

サンプル 
// 関数 unitPrice を作る。数値の total と数値の count を受け取り、数値を返す
function unitPrice(total: number, count: number): number {
  // もし count が 0 と等しいなら
  if (count === 0) {
    // 0 を返す（ここで関数が終わる）
    return 0;
  }
  // total ÷ count を切り捨てた数を返す
  return Math.floor(total / count);
}
// 結果: unitPrice(1000, 3) は 333、unitPrice(1000, 0) は 0

コツelse でつないでも、早めに return しても、テストは通ります。この番号のヒントは、早めに return する形で書いています。1 つの関数の中では、どちらかの形にそろえると読みやすくなります。

よくある間違い戻り値をリテラル型のユニオンにした関数で、let の変数に入れてから最後に返すと、型の確認でエラーになります（01章 q07 問2）。if の中で、値を直接返します。

料金を let の変数で決めてから、別の条件で足したり引いたりするときに使います。次のサンプルでは、泊まる日数で 1 泊の料金を決めてから、会員なら 500 円引きます。

サンプル 
// 関数 roomCharge を作る。数値の nights と、true か false の isMember を受け取り、数値を返す
function roomCharge(nights: number, isMember: boolean): number {
  // 1 泊の料金 price を入れ直せる変数として作り、9000 を入れる
  let price = 9000;
  // もし nights が 3 以上なら
  if (nights >= 3) {
    // price に 8000 を入れ直す
    price = 8000;
  }
  // もし isMember が true なら
  if (isMember) {
    // price から 500 を引く
    price -= 500;
  }
  // price に nights を掛けた数を返す
  return price * nights;
}
// 結果: roomCharge(1, false) は 9000、roomCharge(3, true) は 22500

}

else if でつなぐ

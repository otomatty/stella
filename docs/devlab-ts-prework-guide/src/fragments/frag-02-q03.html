02章 オブジェクト・配列・タプル

q03 分割代入とスプレッド構文

商品の型 Item と利用者の型 User は、ファイルに書いてあります。関数を 20 個書き、引数と戻り値には型注釈を付けます。オブジェクトからプロパティを取り出すときは、分割代入を使います。分割代入は、プロパティをまとめて変数に取り出す書き方です。オブジェクトの一部を変えるときは、元のオブジェクトを書き換えません。スプレッド構文（q02 問8）で新しいオブジェクトを作って返します。テストは、元のオブジェクトが変わっていないことも確かめます。

問1分割代入で name と price を取り出し、「りんご 150円」の形にする 新しく出てくる書き方：オブジェクトの分割代入 const { a, b } = obj; 
export type Item = { id: number; name: string; price: number; stock: number };

export function itemLabel() {}

商品 Item を受け取り、名前と価格を「りんご 150円」の形の文字列にして返します。名前と価格の間は半角スペースです。name と price は、分割代入で取り出します。引数は Item 1 つ、戻り値は文字列です。

テストで確かめる値
itemLabel({ id: 1, name: "りんご", price: 150, stock: 12 })
"りんご 150円"

型引数が Item、戻り値が string であることも確かめます。

新しい書き方

const { a, b } = obj;

オブジェクトの分割代入

オブジェクトから、いくつかのプロパティをまとめて取り出し、同じ名前の変数を作ります。= の左に、取り出すプロパティの名前を { } で囲んで並べます。

サンプル 
// 注文の型 Order を作る。id は数値、customer は文字列、total は数値
type Order = { id: number; customer: string; total: number };
// 注文 order を作り、id が 7、customer が "佐藤"、total が 3200 のオブジェクトを入れる
const order: Order = { id: 7, customer: "佐藤", total: 3200 };
// order から customer と total を取り出す
const { customer, total } = order;
// receipt を作り、customer と total を持つオブジェクトを入れる
const receipt = { customer, total };
// 結果: customer は "佐藤"、total は 3200、receipt は { customer: "佐藤", total: 3200 }

よくある疑問const customer = order.customer; と const total = order.total; の 2 行と同じ意味です。分割代入なら 1 行で書けます。receipt の行は、q01 問3 のプロパティの省略記法です。

よくある間違い取り出せるのは、型にあるプロパティだけです。Order には price がないので、const { price } = order; は型の確認でエラーになります。

スプレッドの後ろに書いたプロパティで上書きする

q02 問8 で、{ ...todo, done: true } の形を使いました。{ } の中は、左から順に入ります。先に ... で元のプロパティをすべて写し、後ろに書いたプロパティで同じ名前のものを上書きします。後ろが変数と同じ名前なら、省略記法（q01 問3）で名前だけを書けます。

サンプル 
// 予約の型 Reservation を作る。id は数値、guest は文字列、people は数値
type Reservation = { id: number; guest: string; people: number };
// 予約 booking を作り、id が 3、guest が "田中"、people が 2 のオブジェクトを入れる
const booking: Reservation = { id: 3, guest: "田中", people: 2 };
// 人数 people を作り、4 を入れる
const people = 4;
// changed を作り、booking をもとに people だけを変えた新しいオブジェクトを入れる
const changed = { ...booking, people };
// moved を作り、booking をもとに id を 9 に変えた新しいオブジェクトを入れる
const moved = { ...booking, id: 9 };
// 結果: changed は { id: 3, guest: "田中", people: 4 }、moved は { id: 9, guest: "田中", people: 2 }

changed の { } の中で、プロパティが入っていく順番です。

書いた順idguestpeople
...booking3"田中"2
people3"田中"4

booking そのものは変わりません。booking.people は 2 のままです。

上書きするプロパティを先に書く
const changed = { people, ...booking };
✕ 後ろの booking の people で上書きされるので、型の確認でエラーになります
上書きするプロパティを後ろに書く
const changed = { ...booking, people };
○ people だけが 4 になります

決まり{ ...booking, people: people } とは書きません。ESLint は省略記法の { ...booking, people } を求めます（object-shorthand）。

新しい書き方

2 つのオブジェクトを重ねる

{ } の中には、... をいくつも並べられます。左から順に写すので、同じ名前のプロパティは後ろのオブジェクトの値が残ります。

サンプル 
// 会員の型 Member を作る。id は数値、name は文字列、rank は文字列
type Member = { id: number; name: string; rank: string };
// 会員 member を作り、id が 5、name が "鈴木"、rank が "一般" のオブジェクトを入れる
const member: Member = { id: 5, name: "鈴木", rank: "一般" };
// 変更 change を作り、rank が "ゴールド" のオブジェクトを入れる
const change = { rank: "ゴールド" };
// updated を作り、member に change を重ねた新しいオブジェクトを入れる
const updated = { ...member, ...change };
// 結果: updated は { id: 5, name: "鈴木", rank: "ゴールド" }
{ ...member, ...change }.rank
"ゴールド"
後ろの change が残る
{ ...change, ...member }.rank
"一般"
順番を逆にすると、member が残る

よくある間違い順番を逆にしても、型の確認ではエラーになりません。変更を後ろに書いたか、自分で確かめます。

問11中身が同じで、別のオブジェクトになった Item を返す 新しく出てくる書き方：オブジェクトのコピー { ...obj } と、同じオブジェクトかどうか

商品 item を受け取り、中身が同じ新しい Item を返します。item そのものは返しません。新しく作ったオブジェクトを返します。引数は Item 1 つ、戻り値は Item です。

新しい書き方

{ ...obj }

オブジェクトのコピーと、同じオブジェクトかどうか

後ろに何も書かずに ... だけを使うと、中身が同じ新しいオブジェクトができます。これをコピーと呼びます。

サンプル 
// 配送先 address を作り、city が "大阪"、zip が "530-0001" のオブジェクトを入れる
const address = { city: "大阪", zip: "530-0001" };
// copied を作り、address を広げた新しいオブジェクトを入れる
const copied = { ...address };
// 結果: copied は { city: "大阪", zip: "530-0001" }

オブジェクトを === で比べると、同じ 1 つのオブジェクトかどうかを調べます。中身は比べません。中身が同じでも、別に作ったオブジェクトなら false です。別の変数に入れただけなら、同じオブジェクトなので true です。

copied === address
false
別に作ったオブジェクト
copied.city === address.city
true
中の値は同じ

よくある疑問テストの「中身が同じ」は、プロパティを 1 つずつ比べる確かめ方です。「別のオブジェクト」は、=== と同じ確かめ方です。

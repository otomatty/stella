02章 オブジェクト・配列・タプル

q08 インデックス型

点数表や価格表のように、キーを自由に決められるオブジェクトを扱う関数を 20 個書きます。キーは名前や商品名などの文字列で、値の型はどれも同じです。こういうオブジェクトの型は、インデックス型 { [name: string]: number } で書きます。scores[name] のようにキーで取り出した値は、そのキーがないかもしれないので undefined になることがあります。?? や !== undefined で扱います。キーや値を全部見るときは、Object.keys・Object.values・Object.entries を使います。オブジェクトを変える問題では、元のオブジェクトは書き換えません。新しいオブジェクトを作って返します。引数と戻り値の型注釈は自分で書きます。

問1scores から name の点数を返す（なければ 0） 新しく出てくる書き方：インデックス型 { [name: string]: number }、キーで取り出した値は undefined かもしれない 
export function scoreOf() {}

点数表 scores と名前 name を受け取り、その人の点数を返します。点数表は、キーが名前、値が点数のオブジェクトです。点数表にその名前がなければ、0 を返します。

テストで確かめる値

80
scoreOf({ 山田: 80 }, "鈴木")

新しい書き方

{ [key: string]: T }

キーを自由に決められるオブジェクトの型

02章 q01 のオブジェクトの型 { name: string; age: number } は、キーの名前が決まっていました。点数表や在庫表は、どんなキーが入るかが前もって決まりません。決まっているのは「キーは文字列、値は数値」ということだけです。このようなオブジェクトの型を、インデックス型といいます。

サンプル 
// 在庫表 stock を作る。キーは商品名の文字列、値は数値
const stock: { [item: string]: number } = { ノート: 12, ペン: 0 };
// 商品名 item を作り、"ノート" を入れる
const item = "ノート";
// count を作り、stock の item の値を入れる
const count = stock[item];
// 結果: count は 12

キーで値を取り出すときは、stock[item] のように [ ] の中にキーを書きます。文字列の 1 文字を取り出す text[0]（01章 q03 問20）と同じ形です。[ ] の中には、キーの入った変数をそのまま書けます。

よくある疑問[item: string] の item は、型の確認には使われません。テストの型が [name: string] でも、自分の型を [key: string] と書いてかまいません。

サバイバルTypeScript「インデックス型」

stock[item] ?? 0

取り出した値は undefined かもしれない

インデックス型のオブジェクトは、どのキーが入っているかが型からは分かりません。そのため、stock[item] で取り出した値の型は number | undefined になります。ないキーを取り出すと、本当に undefined が返ります。数値として使う前に、??（02章 q02 問1）で代わりの値を決めるか、!== undefined で確かめます。

サンプル 
// 在庫表 stock を作る。キーは商品名の文字列、値は数値
const stock: { [item: string]: number } = { ノート: 12, ペン: 0 };
// 商品名 missing を作り、"消しゴム" を入れる
const missing = "消しゴム";
// left を作り、stock の missing の値を入れる。なければ 0 を入れる
const left = stock[missing] ?? 0;
// 結果: left は 0
そのまま number の変数に入れる
const left: number = stock[missing];
✕ number | undefined は number に入れられない、というエラーになります
?? で代わりの値を決める
const left: number = stock[missing] ?? 0;
○ ないときは 0 になるので、型は number です

関数の引数にインデックス型を使うときも、同じ書き方です。

サンプル 
// 関数 isInStock を作る。在庫表 stock（キーは商品名の文字列、値は数値）と文字列 item を受け取り、true か false を返す
function isInStock(stock: { [item: string]: number }, item: string): boolean {
  // stock の item の値（なければ 0）が 0 より大きいかどうかを返す
  return (stock[item] ?? 0) > 0;
}
// 結果: isInStock({ ノート: 12, ペン: 0 }, "ペン") は false

よくある間違い?? が代わりの値を使うのは、undefined か null のときだけです。stock["ペン"] のように値が 0 のときは、0 のまま使います。

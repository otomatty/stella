q05 状態を持つクラス

クラスの中にデータを持たせ、メソッドを呼ぶたびにそのデータを変えていくクラスを書きます。呼ぶたびに変わっていく中身のデータを、状態と呼びます。ドリルは 1 つのファイルに 20 問あり、★総合問題の ToDo リストで使う書き方をくり返します。中で持つデータは private にして、外からはメソッドでしか読み書きできないようにします。配列を返すメソッドは、中の配列のコピーを返します。フィールド、constructor の引数、メソッドの引数と戻り値には型注釈を付けます。

ドリルデータを持ち、メソッドで読み書きするクラスを書く 新しく出てくる書き方：.splice()、.find() で見つけた要素を書き換える 
// 問1 NoteBook。add(text) でメモを足し、その番号（1から）を返す。get(id) でメモを返す（なければ undefined）。count() で数を返す
//     例: add("買い物") → 1、get(1) → "買い物"
export class NoteBook {}

ファイルには、20 個のクラスが export class NoteBook {} のように、空の形で書いてあります。{ } の中に、フィールドとメソッドを書きます。問題文に constructor の引数がないクラスは、引数なしで new します。

どのクラスも、中で持つデータは private にします（06章 q01）。配列を返すメソッドは、中の配列のコピーを返します（06章 q02 問15）。受け取った側が配列に要素を足しても、クラスの中の配列が変わらないようにするためです。

  1. NoteBook：add(text) でメモを足し、そのメモの番号を返します。番号は 1 から順に振ります。get(id) は、その番号のメモを返します。なければ undefined を返します。count() は、メモの数を返します。
  2. Playlist：add(song) で曲を足します。何も返しません。next() は、呼ぶたびに先頭から順に曲を返し、最後の曲の次は先頭に戻ります。曲が 1 つもなければ undefined を返します。
  3. ShoppingCart：add(name, price, quantity) で商品を足します。quantity（個数）は省略でき、省略したら 1 です。同じ name の商品がすでにあれば、個数だけを増やします。remove(name) は、その商品を消します。total() は、価格 × 個数の合計を返します。add と remove は何も返しません。
  4. Library：addBook(title) で本を足します。borrow(title) で本を貸し出します。ない本なら "本がありません: C"、貸出中の本なら "貸出中です: A" の形のメッセージのエラーを投げます。giveBack(title) で本を返します。available() は、貸し出せる本の題名を、足した順に並べた配列で返します。addBook・borrow・giveBack は何も返しません。
  5. Scoreboard：record(name, score) で点数を記録します。何も返しません。best(name) は、その人の最高点を返します。記録がなければ undefined を返します。top(n) は、最高点の高い順に、名前を n 人まで並べた配列を返します。同じ点なら、先に記録した人が先です。
  6. EventCalendar：add(date, title) で予定を足します。何も返しません。on(date) は、その日の予定を足した順に並べた配列を返します。予定がなければ [] を返します。
  7. ParkingLot：constructor で台数 capacity を受け取ります。park(car) で車を停めます。空きがなければ false、停められたら true を返します。leave(car) で車が出ます。何も返しません。free() は、空きの台数を返します。
  8. PriorityQueue：enqueue(task, priority) で、優先度 priority の付いたタスクを入れます。何も返しません。dequeue() は、優先度がいちばん大きいタスクを取り出して返します。同じ優先度なら、先に入れた方を取り出します。空なら undefined を返します。
  9. Inbox：receive(from, text) でメッセージを受け取ります。何も返しません。unreadCount() は、まだ読んでいないメッセージの数を返します。read(index) は、index 番目（0 から数える）のメッセージを "山田: こんにちは" の形で返し、読んだことにします。その番号のメッセージがなければ、"メッセージがありません" というメッセージのエラーを投げます。
  10. Gradebook：add(student, score) で生徒の点数を足します。何も返しません。average() は平均点を返します。1 人もいなければ 0 を返します。passed(border) は、border 点以上の生徒の名前を、足した順に並べた配列で返します。
  11. Elevator：constructor で階の数 floors を受け取ります。最初は 1 階にいます。goTo(floor) でその階へ動きます。1 から floors の外なら、"その階はありません" というメッセージのエラーを投げます。何も返しません。current() は今の階を、history() は止まった階を順に並べた配列を返します。history() には、最初の 1 階も入ります。
  12. VotingBox：constructor で選択肢の配列 options（readonly string[]）を受け取ります。vote(option) で投票します。選択肢にないものなら、"選択肢にありません: C" の形のメッセージのエラーを投げます。何も返しません。winner() は、票がいちばん多い選択肢を返します。同じ票数なら、options で先にある方です。1 票もなければ undefined を返します。
  13. HistoryWallet：残高は 0 から始めます。deposit(n) で入金し、withdraw(n) で出金します。どちらも、変えた後の残高を返します。残高より多く出金しようとしたら、"残高が足りません" というメッセージのエラーを投げます。history() は、"+1000"・"-300" の形の履歴を、順に並べた配列で返します。エラーになった出金は、履歴に入れません。
  14. ChatRoom：join(name) で参加し、leave(name) で抜けます。post(name, text) で投稿します。参加していない人なら、"参加していません: 山田" の形のメッセージのエラーを投げます。messages() は、"山田: こんにちは" の形の投稿を、順に並べた配列で返します。join・leave・post は何も返しません。
  15. SeatReservation：reserve(seat, name) で席を予約します。予約済みの席なら、"予約済みです: A1" の形のメッセージのエラーを投げます。cancel(seat) で予約を取り消します。seatsOf(name) は、その人の席を予約した順に並べた配列で返します。reserve と cancel は何も返しません。
  16. TodoStore：add(title) で ToDo を足し、その id を返します。id は 1 から順に振ります。toggle(id) は、その ToDo の完了と未完了を切り替えます。その id の ToDo がなければ、"ToDo がありません: 9" の形のメッセージのエラーを投げます。何も返しません。remaining() は、未完了の数を返します。
  17. LapTimer：start(t) で、時刻 t から計測を始めます。何も返しません。lap(t) は、前回（start か lap）の時刻からの差を返します。laps() は、それまでの差を順に並べた配列で返します。
  18. RateLimiter：constructor で、回数 max とミリ秒 windowMs を受け取ります。hit(time) は、時刻 time に来た受け付けの申し込みです。time - windowMs より後に受け付けた回数が max より少なければ、受け付けて true を返します。そうでなければ、受け付けずに false を返します。
  19. UndoCounter：increment() で 1 増やします。undo() で、直前の increment を取り消します。取り消すものがなければ、何もしません。value() は今の値を返します。increment と undo は何も返しません。
  20. TagIndex：tag(item, label) で、item にタグ label を付けます。同じ組み合わせは 1 回だけ付けます。何も返しません。itemsWith(label) は、そのタグの付いた item を、付けた順に並べた配列で返します。tagsOf(item) は、その item のタグを、付けた順に並べた配列で返します。

.splice()

配列から、位置を決めて要素を取り除く

配列.splice(位置, 個数) は、その位置から個数だけの要素を、配列から取り除きます。取り除いた要素は、新しい配列に入れて返します。元の配列そのものが変わります。.slice()（02章 q05 問3）は、元の配列を変えずに一部を取り出します。.splice() は、元の配列から抜き取ります。

サンプル 
// 待っている人の列 waiting を作り、"佐藤" と "鈴木" と "高橋" を並べた配列を入れる
const waiting = ["佐藤", "鈴木", "高橋"];
// removed を作り、waiting の 1 番目から 1 つを取り除いたものを入れる
const removed = waiting.splice(1, 1);
// 結果: removed は ["鈴木"]、waiting は ["佐藤", "高橋"]

取り除いた要素を 1 つだけ受け取りたいときは、配列の分割代入（02章 q06 問2）で、返った配列の最初を取り出します。

サンプル 
// 注文の列 orders を作り、"A-1" と "A-2" を並べた配列を入れる
const orders = ["A-1", "A-2"];
// orders の 0 番目から 1 つを取り除き、取り除いたものの最初を first に入れる
const [first] = orders.splice(0, 1);
// 結果: first は "A-1"、orders は ["A-2"]
["佐藤", "鈴木", "高橋"].splice(0, 2)
["佐藤", "鈴木"]
元の配列は ["高橋"] になる
["佐藤", "鈴木", "高橋"].slice(0, 2)
["佐藤", "鈴木"]
元の配列は変わらない
[].splice(0, 1)
[]
取り除くものがなければ、空の配列

型2 つめのサンプルの first の型は string | undefined です。配列が空なら、取り除くものがなく、first は undefined になるからです。使う前に、undefined でないことを確かめるか、first?.length のように ?.（03章 q03 問1）で読みます。

.find() で見つけた要素を、書き換える

.find()（05章 q10 問18）が返すのは、配列の中のオブジェクトそのものです。コピーではありません（02章 q03 問11）。そのため、見つけたオブジェクトのプロパティを書き換えると、配列の中のオブジェクトも変わります。見つからなければ undefined が返るので、先に確かめます。

サンプル 
// 在庫 Stock という型を作る。name は文字列、count は数値
type Stock = { name: string; count: number };
// 在庫の配列 stocks を作る。型は Stock の配列。2 つの在庫を入れる
const stocks: Stock[] = [
  { name: "ノート", count: 5 },
  { name: "ペン", count: 0 },
];
// pen を作り、stocks の要素を 1 つずつ s として、s の name が "ペン" と等しい最初のもの（なければ undefined）を入れる
const pen = stocks.find((s) => s.name === "ペン");
// もし pen が undefined でないなら
if (pen !== undefined) {
  // pen の count に 10 を足す
  pen.count += 10;
}
// 結果: stocks は [{ name: "ノート", count: 5 }, { name: "ペン", count: 10 }]

クラスのフィールドの配列に使うと、配列の中の 1 件だけを書き換えられます。数を増やす、完了にする、貸出中にする、といった変更に使います。

決まり配列の中のオブジェクトを書き換えるには、そのプロパティに readonly が付いていないことが要ります。readonly のプロパティに入れ直すと、型エラーになります（02章 q02 問7）。

  next(): number {

    return this.last;

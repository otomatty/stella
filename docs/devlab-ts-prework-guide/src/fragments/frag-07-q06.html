07章 型の再利用とジェネリクス

q06 型変数（ジェネリクス）

どんな型の値や配列にも使える関数を、型変数（<T> など）を使って 20 個書きます。any や unknown は使いません。テストは、数値の配列を渡せば number、文字列の配列を渡せば string のように、渡した型に合わせて戻り値の型が変わるかを確かめます。引数の配列は readonly T[] にします。

問1受け取った値をそのまま返す 新しく出てくる書き方：型変数 <T> 
export function identity() {}

受け取った値を、そのまま返します。どんな型の値でも受け取れるようにします。戻り値の型は、受け取った値と同じ型になるようにします。

テストで確かめる値
identity(nums)
nums
nums は [1, 2]。同じ配列がそのまま返る

型number[] の nums を渡すと戻り値が number[]、文字列を渡すと戻り値が string になることも確かめます。

新しい書き方

<T>

型を引数のように受け取る（型変数）

関数は、値を引数で受け取ります。同じように、型も引数のように受け取れます。関数の名前の後ろに <T> と書くと、受け取った型を T という名前で使えます。この T を型変数といいます。型変数を使う書き方を、ジェネリクスといいます。

T が何の型になるかは、呼ぶたびに決まります。TypeScript が、渡した値の型を見て自動で決めます。次の表の prices は number[]、names は string[]、flags は boolean[] の変数です。

呼び出し渡した配列の型T戻り値の型
first(prices)number[]numbernumber
first(names)string[]stringstring
first(flags)boolean[]booleanboolean

関数は 1 つだけ書けば、どの型の配列にも使えます。そのうえ、戻り値の型が、渡した配列の要素の型になります。

この課題では、引数の配列を readonly T[] にします。空の配列もあるので、要素を 1 つ取り出す関数は、戻り値を T | undefined にします。次のサンプルは、2 番目の要素を返す関数です。

サンプル 
// 関数 secondOf を作る。型変数 T を使い、読み取り専用の T の配列 items を受け取り、T か undefined を返す
function secondOf<T>(items: readonly T[]): T | undefined {
  // items の 1 番目の要素を返す
  return items[1];
}
// 値段 price を作り、secondOf に [1200, 980] を渡した結果を入れる
const price = secondOf([1200, 980]);
// 担当者 staff を作り、secondOf に ["佐藤", "鈴木"] を渡した結果を入れる
const staff = secondOf(["佐藤", "鈴木"]);
// 結果: price は 980 で型は number | undefined、staff は "鈴木" で型は string | undefined
unknown で受け取る
function secondOf(items: readonly unknown[]): unknown {
  return items[1];
}
const price = secondOf([1200, 980]);
price.toFixed();
✕ 戻り値が unknown になり、数値として使うと型の確認でエラーになります
型変数で受け取る
function secondOf<T>(items: readonly T[]): T | undefined {
  return items[1];
}
const price = secondOf([1200, 980]);
○ 戻り値が number | undefined になります

よくある疑問呼ぶときに secondOf<number>(prices) のように < > の中に型を書いて、T を自分で決めることもできます。渡した値から決まるときは、書かなくてかまいません。

新しい書き方

<A, B>

型変数を 2 つ使う

型変数は、, で区切って 2 つ以上並べられます。それぞれに別の型が決まります。名前は自由ですが、A と B、T と U、キーと値なら K と V などがよく使われます。

サンプル 
// 関数 entryOf を作る。型変数 K と V を使い、K の key と V の value を受け取り、key が K で value が V のオブジェクトを返す
function entryOf<K, V>(key: K, value: V): { key: K; value: V } {
  // key に key、value に value を入れたオブジェクトを返す
  return { key, value };
}
// 在庫 stock を作り、entryOf に "A-001" と 30 を渡した結果を入れる
const stock = entryOf("A-001", 30);
// 結果: stock は { key: "A-001", value: 30 } で、型は { key: string; value: number }
entryOf("A-001", 30)
{ key: "A-001", value: 30 }
K は string、V は number に決まる
entryOf(7, true)
{ key: 7, value: true }
K は number、V は boolean に決まる

よくある疑問型変数を 1 つにして entryOf<T>(key: T, value: T) と書くと、key と value が同じ型でなければなりません。"A-001" と 30 を渡すと、型の確認でエラーになります。別々の型を受け取りたいときは、型変数も別々にします。

新しい書き方

type Page<T> =

型エイリアスに型変数を付ける

型エイリアス type（02章 q01 応用）の名前の後ろにも、<T> を書けます。こうすると、型を受け取って、新しい型を作れます。使うときは Page<string> のように、< > の中に型を渡します。q03 問1 の Partial<Options> と同じ書き方です。Partial も、型を受け取る型です。

サンプル 
// Page という型を作る。型変数 T を使い、items は読み取り専用の T の配列、total は数値
type Page<T> = { items: readonly T[]; total: number };
// 会員の名前のページ memberPage を Page<string> として作り、items に ["佐藤", "鈴木"]、total に 2 を入れる
const memberPage: Page<string> = { items: ["佐藤", "鈴木"], total: 2 };
// 結果: memberPage の items は ["佐藤", "鈴木"]、total は 2
Page<string>
{ items: readonly string[]; total: number }
T が string になる
Page<number>
{ items: readonly number[]; total: number }
T が number になる

よくある間違い型変数のある型を、< > を付けずに const memberPage: Page = … と書くと、型の確認でエラーになります。Page は、型を 1 つ渡さないと使えません。

Page<T>

関数の型変数を、型エイリアスに渡す

関数の型注釈の中でも、Page<T> のように、関数の型変数 T を型エイリアスに渡せます。関数を呼んで T が number に決まると、戻り値の型は Page<number> になります。

サンプル 
// 関数 pageOf を作る。型変数 T を使い、読み取り専用の T の配列 items を受け取り、Page<T> を返す
function pageOf<T>(items: readonly T[]): Page<T> {
  // items に items、total に items の要素の数を入れたオブジェクトを返す
  return { items, total: items.length };
}
// 在庫のページ stockPage を作り、pageOf に [30, 0, 12] を渡した結果を入れる
const stockPage = pageOf([30, 0, 12]);
// 結果: stockPage は { items: [30, 0, 12], total: 3 } で、型は Page<number>

問16value が最後に出てくる番号 新しく出てくる書き方：配列の .lastIndexOf() 
export function lastIndexOfValue() {}

配列の中で、value が最後に出てくる位置（0 から数える）を返します。見つからなければ -1 を返します。文字列の配列から数値を探すような呼び出しは、型の確認でエラーになるようにします。

応用型変数（ジェネリクス）を使った first・last・repeat・pair・Box 新しい書き方はありません。 
export function first() {}

export function last() {}

export function repeat() {}

export function pair() {}

export type Box = unknown;

export function box() {}

export function unbox() {}

関数を 6 つと、型を 1 つ書きます。どれも型変数を使い、any や unknown は使いません。

  1. first(items)：最初の要素を返します。空の配列なら undefined です。
  2. last(items)：最後の要素を返します。空の配列なら undefined です。
  3. repeat(value, times)：value を times 個並べた配列を返します。
  4. pair(a, b)：[a, b] のタプルを返します。a と b は別々の型でもよいので、型変数を 2 つ使います。
  5. Box<T>：{ value: T } の型です。unknown を書き換えます。box(value) は value を入れた Box を作り、unbox(box) は中の値を返します。
テストで確かめる値
first([3, 1, 2])
3
last(["a", "b"])
"b"
first([])
undefined
空の配列
last([])
undefined
空の配列
repeat("x", 3)
["x", "x", "x"]
repeat(0, 0)
[]
0 個なら空の配列
pair("a", 1)
["a", 1]
box(5)
{ value: 5 }
unbox({ value: "a" })
"a"

型first と last は、number[] を渡すと number | undefined、string[] を渡すと string | undefined を返すことを確かめます。repeat は、数値を渡すと number[]、文字列を渡すと string[] を返すことを確かめます。pair は、文字列と数値を渡すと [string, number]、数値と string[] を渡すと [number, string[]] を返すことを確かめます。Box<number> が { value: number } と同じ型であること、文字列を渡した box が Box<string> を返すこと、Box<number> を渡した unbox が number を返すことも確かめます。

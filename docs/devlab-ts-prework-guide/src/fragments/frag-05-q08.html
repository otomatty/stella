05章 関数

q08 関数を返す関数

関数を返す関数を 20 個書きます。引数と戻り値には型注釈を付けます。関数を返すときは、戻り値の型を (x: number) => number のような関数の型で書きます。返された関数は、外側の関数の引数や変数を覚えています。外側の関数の呼び出しが終わったあとでも、その値を使えます。外側で let で作った変数を書き換えると、その値は次に呼んだときまで残ります。この仕組みをクロージャーと呼びます。

問1受け取った数に n を足す関数を返す 新しく出てくる書き方：関数を返す関数 return (x) => …、返された関数が外側の値を覚えていること（クロージャー） 
export function makeAdder() {}

数 n を受け取り、関数を返します。返す関数は、数を 1 つ受け取り、その数に n を足した数を返します。makeAdder が返すのは関数です。返された関数を呼ぶと、足し算の答えが出ます。

4 に 3 を足す

同じ関数を、もう一度呼んでもよい

型引数が number、戻り値が (x: number) => number（数値を受け取って数値を返す関数）であることも確かめます。

新しい書き方

return (x) => …

関数を返す関数

関数は、数や文字列と同じ値です。05章 q07 では、関数を引数で受け取りました。同じように、関数を return で返せます。返す関数は、アロー関数（01章 q01 問20）で書くと短く書けます。

サンプル 
// 関数 makeTaxed を作る。数値 percent を受け取り、「数値を受け取って数値を返す関数」を返す
function makeTaxed(percent: number): (price: number) => number {
  // price を受け取り、price に price × percent ÷ 100 を切り捨てた数を足した数を返す関数を返す
  return (price) => price + Math.floor((price * percent) / 100);
}
// 関数 withTax10 を作り、makeTaxed に 10 を渡して呼んだ結果を入れる
const withTax10 = makeTaxed(10);
// 金額 total を作り、withTax10 に 1000 を渡して呼んだ結果を入れる
const total = withTax10(1000);
// 結果: total は 1100
戻り値の型を書かない
function makeTaxed(percent: number) {
  return (price) => price + percent;
}
✕ price の型が決まらず、型の確認でエラーになります
戻り値の型を書く
function makeTaxed(percent: number): (price: number) => number {
  return (price) => price + percent;
}
○ price は number になります

よくある疑問関数の型の中の引数の名前は、自由に決めてかまいません。(x: number) => number と (price: number) => number は同じ型です。テストの型の確認でも、名前は比べません。

新しい書き方

let left = stock;

外側の let を書き換えて、呼ぶたびに値を残す

返す関数の外側で、let の変数を作ります。返す関数の中で、その変数を書き換えます。書き換えた値は、次に呼んだときまで残ります。返された関数が、変数そのものを覚えているからです。

返す関数の中身が 2 行以上あるときは、=> の後ろを { } で囲み、return で返します。

サンプル 
// 関数 makeTaker を作る。数値 stock を受け取り、「何も受け取らず数値を返す関数」を返す
function makeTaker(stock: number): () => number {
  // 残り left を入れ直せる変数として作り、stock を入れる
  let left = stock;
  // 何も受け取らず、次のことをする関数を返す
  return () => {
    // left を 1 減らす
    left--;
    // left を返す
    return left;
  };
}
// 関数 takeApple を作り、makeTaker に 3 を渡して呼んだ結果を入れる
const takeApple = makeTaker(3);
// 関数 takeOrange を作り、makeTaker に 5 を渡して呼んだ結果を入れる
const takeOrange = makeTaker(5);
// first を作り、takeApple を呼んだ結果を入れる
const first = takeApple();
// second を作り、takeApple を呼んだ結果を入れる
const second = takeApple();
// other を作り、takeOrange を呼んだ結果を入れる
const other = takeOrange();
// 結果: first は 2、second は 1、other は 4
呼び出し呼ぶ前の left呼んだ後の left返す値

takeApple()211
takeOrange()544

makeTaker を呼ぶたびに、新しい left が 1 つ作られます。takeApple と takeOrange は、それぞれ別の left を覚えています。だから、りんごを取っても、みかんの残りは減りません。

返す関数の中で let を作る
function makeTaker(stock: number): () => number {
  return () => {
    let left = stock;
    left--;
    return left;
  };
}
✕ 呼ぶたびに left が作り直され、いつも 2 を返します（stock が 3 のとき）
返す関数の外で let を作る
function makeTaker(stock: number): () => number {
  let left = stock;
  return () => {
    left--;
    return left;
  };

○ left は 1 つだけで、呼ぶたびに減っていきます

よくある間違い引数の stock を、そのまま stock-- で書き換えたくなります。引数に値を入れ直すと、ESLint の no-param-reassign でエラーになります。サンプルのように、let の変数に入れてから書き換えます。

新しい書き方

{ add: (name) => { … } }

関数を持つオブジェクトを返す

オブジェクトのプロパティの値に、関数を入れられます。関数を 2 つ以上返したいときは、オブジェクトにまとめて返します。返したどの関数も、外側の同じ変数を覚えています。

サンプル 
// 関数 makeCart を作る。何も受け取らず、add と count を持つオブジェクトを返す（add は文字列を受け取って何も返さない関数、count は何も受け取らず数値を返す関数）
function makeCart(): { add: (name: string) => void; count: () => number } {
  // 商品名 names を文字列の配列として作り、空の配列を入れる
  const names: string[] = [];
  // 次の add と count を持つオブジェクトを返す
  return {
    // add は、name を受け取り、次のことをする関数
    add: (name) => {
      // names の最後に name を付け足す
      names.push(name);
    },
    // count は、何も受け取らず、names の要素の数を返す関数
    count: () => names.length,
  };
}
// 買い物かご cart を作り、makeCart を呼んだ結果を入れる
const cart = makeCart();
// cart の add に "りんご" を渡して呼ぶ
cart.add("りんご");

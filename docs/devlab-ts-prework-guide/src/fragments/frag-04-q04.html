04章 文と例外

q04 while文と break・continue

何回くり返すかが先に分からない処理を、関数で 20 個書きます。引数と戻り値の型注釈は自分で書きます。くり返しには while 文を使います。中身を少なくとも 1 回は実行したいときは、do-while 文を使います。くり返しを途中で抜けるときは break、その回の残りを飛ばすときは continue を使います。引数には値を入れ直せません。変えたい値は、let の変数に写してから使います（01章 q01 問11）。

問11 以上の整数の桁数を返す 新しい書き方はありません。

新しい書き方

/=

割った数を入れ直す

price /= 4 は、price = price / 4 と同じです。price を 4 で割った数を、price に入れ直します。01章 q01 で出た +=・*= と、q01 の応用で出た -= の仲間です。

// 結果: price は 3000
let n = 9; n /= 2;
n は 4.5
割り切れないと小数になる

よくある疑問割り切れないときは小数になります。整数にしたいときは、Math.floor()（01章 q01 問1）で切り捨てます。この問題では偶数だけを 2 で割るので、いつも割り切れます。

新しい書き方

continue

この回の残りを飛ばし、次の回に進む

continue; を実行すると、その回の残りの行を飛ばします。while 文では、そのまま条件の確認に戻ります。条件が true なら、次の回が始まります。

サンプル 
// 日 day を入れ直せる変数として作り、0 を入れる
let day = 0;
// 席の合計 seats を入れ直せる変数として作り、0 を入れる
let seats = 0;
// day が 7 より小さい間くり返す
while (day < 7) {
  // day を 1 増やす
  day++;
  // もし day が 4 と等しいなら
  if (day === 4) {
    // この回の残りを飛ばし、次の回に進む
    continue;
  }
  // seats に 20 を足す
  seats += 20;
}
// 結果: 1 日 20 席の予約枠を 7 日分足す。4 日目は休館日で飛ばすので、seats は 120

新しい書き方

break

break; を実行すると、条件が true のままでも、くり返しをそこで終わります。続きは、くり返しの後の行から進みます。

サンプル

  // days を 1 増やす

while 文は、中身の前に条件を確かめます。do-while 文は、先に中身を 1 回やり、そのあとで条件を確かめます。条件が初めから false でも、中身は 1 回だけ実行されます。

07章 型の再利用とジェネリクス

q08 ジェネリクスのユーティリティ

どんな型の配列にも使える関数を、型変数を使って 20 個書き、最後に★総合問題に取り組みます。05章 q10 では、生徒の配列だけに使える groupBy などを書きました。ここでは同じような処理を、要素の型を型変数 T にして書きます。型変数は 07章 q06、型引数の制約は 07章 q07 で出ました。any や unknown は使いません。引数の配列は readonly T[] にして、元の配列は変えません。findLast や Object.groupBy のようなメソッドは、この課題の設定では型がないので使えません。for 文や、これまでに出たメソッドを使って自分で書きます。引数と戻り値の型注釈も、自分で書きます。

問1keyFn が返す文字列ごとにまとめる 新しい書き方はありません。 
export function groupItems() {}

配列の要素を、keyFn が返す文字列ごとにまとめたオブジェクトを返します。keyFn は、要素を 1 つ受け取って文字列を返す関数です。返すオブジェクトのキーは keyFn が返した文字列で、値はそのキーになった要素の配列です。配列の中は、元の順に並べます。戻り値の型は Record<string, T[]> です。T は、要素の型を表す型変数です。

テストで確かめる値
groupItems(["ab", "c", "de"], (s) => String(s.length))
{ "2": ["ab", "de"], "1": ["c"] }
文字数を文字列にしたものでまとめる

型文字列の配列を渡すと、戻り値の型が Record<string, string[]> になることも確かめます。

問9null と undefined を除いた配列 新しく出てくる書き方：.filter() で null と undefined を除くと、型からも消える

新しい書き方

.filter((x) => x !== null)

null を除いた配列は、型からも null が消える

02章 q04 問7 の .filter() で、null でないものだけを集めたとします。すると TypeScript は、できた配列の要素の型からも null を取り除きます。コールバックが、型ガード関数（05章 q09 問1）と同じ働きをすると読み取るためです。

サンプル 
// 予約した部屋番号の配列 rooms（要素は数値か null）を作り、101 と null と 203 と null を入れる
const rooms: (number | null)[] = [101, null, 203, null];
// 決まった部屋 fixed を作り、rooms の要素を 1 つずつ room として、room が null でないものだけを集めた新しい配列を入れる
const fixed = rooms.filter((room) => room !== null);
// 結果: fixed は [101, 203]。fixed の型は number[]

型から消えるのは、条件で除いた型だけです。seats の型が (number | null | undefined)[] のとき、次のようになります。

null だけを除く
const ready: number[] = seats.filter((seat) => seat !== null);
✕ 要素の型に undefined が残るので、number[] に入れられない、というエラーになります
null と undefined を除く
const ready: number[] = seats.filter((seat) => seat !== null && seat !== undefined);
○ 要素の型が number になります

よくある間違いseats.filter((seat) => seat) のように値そのものを条件にすると、0 も除かれてしまいます。この課題の lint でも、条件に boolean でない値を書くとエラーになります。

05章 q10 総合では、生徒の配列だけに使える groupBy などを書きました。これを型変数 T を使って、どんな配列にも使えるように書き直します。関数を 6 つ書きます。どれも引数の配列は readonly T[] にして、元の配列は変えません。中身は、問1〜問6 で書いたものと同じです。

  1. groupBy(items, keyFn)：keyFn(要素) が返す文字列ごとにまとめます。戻り値は Record<string, T[]> です（問1）。
  2. countBy(items, keyFn)：keyFn(要素) が返す文字列ごとに数えます。戻り値は Record<string, number> です（問2）。
  3. partition(items, predicate)：[true の配列, false の配列] を返します。戻り値は [T[], T[]] です（問3）。
  4. uniqueBy(items, keyFn)：keyFn(要素) が同じものは、最初の 1 つだけ残します。keyFn は文字列か数値を返します（問4）。
  5. sortBy(items, keyFn)：keyFn(要素) が返す数値の小さい順に並べた、新しい配列を返します。同じなら元の順です（問5）。
  6. chunk(items, size)：size 個ずつに区切ります。戻り値は T[][] です。size が 1 より小さいときは Error を投げます（問6）。

01章 値・型・変数

q08 any をなくす

この番号の関数は、引数と戻り値の型が any になっていて、型の確認が効いていません。any を正しい型に書き換えてください。いくつかの関数には、any のせいで気付けなかったバグが隠れています。型を直すとエラーになって見つかるので、あわせて直します。文字列を + でつないでいるところは、テンプレートリテラルに書き換えます。テストは、返す値に加えて、引数と戻り値の型も確かめます。

問12 つの数を足す 新しく出てくる書き方：any 
// 問1 2つの数を足す
//     例: add(2, 3) → 5
export function add(a: any, b: any): any {
  return a + b;
}

2 つの数を足した数を返す関数です。引数と戻り値の型が any になっています。中身はそのままで正しく動きます。直すのは型だけです。

テストで確かめる値
add(2, 3)
5

新しい書き方

any

どんな値でもよい型

最初から書いてある

any は「どんな値でもよい」という型です。any の付いた値には、型の確認が何も言わなくなります。間違いがあっても、実行するまで気付けません。

any のまま
function feeLabel(fee: any): any {
  // fee を小数なしの文字列にする（つづりを間違えた）
  return fee.toFixd(0);
}
✕ 型の確認は通ります。実行すると止まります
型を書いた場合
function feeLabel(fee: number): string {
  // fee を小数なしの文字列にする（つづりを間違えた）
  return fee.toFixd(0);
}
○ 型の確認が、つづりの間違いを教えてくれます

右のエラーには Did you mean 'toFixed'?（toFixed のことですか）と、正しい名前の候補も出ます。つづりを直すと、次のように動きます。

サンプル 
// 関数 feeLabel を作る。数値 fee を受け取り、文字列を返す
function feeLabel(fee: number): string {
  // fee を小数点以下 0 桁の文字列にして返す
  return fee.toFixed(0);
}
// 結果: feeLabel(500) は "500"

型の決め方引数の型は「何を受け取るか」、戻り値の型は「return の右の値が何か」で決めます。数なら number、文字列なら string、true か false なら boolean です。

決まりこの課題の lint は、any を書くとエラーにします（no-explicit-any）。any を 1 つでも残すと提出できません。

新しい書き方

number[]

数値の配列の型

配列は、値を順番に並べたものです。[80, 90, 70] のように [ ] で囲み、, で区切って書きます。数値を並べた配列の型は number[] です。配列は 02章で詳しく学びます。ここでは、型の書き方と、次の 2 つだけ使えれば十分です。

  • for-of で、先頭から 1 つずつ取り出せます。文字列のときと同じ書き方です。
  • .length で、要素（並んでいる値）の数が分かります。
サンプル 
// 関数 hasExpensive を作る。数値の配列 prices を受け取り、true か false を返す
function hasExpensive(prices: number[]): boolean {
  // 見つかったか found を入れ直せる変数として作り、false を入れる
  let found = false;
  // prices から 1 つずつ price に取り出してくり返す
  for (const price of prices) {
    // もし price が 1000 以上なら
    if (price >= 1000) {
      // found に true を入れ直す
      found = true;
    }
  }
  // found を返す
  return found;
}
// 結果: hasExpensive([300, 1500]) は true

02章 q04（配列の型）

.length

配列の要素の数

文字列の .length は文字数でした。配列の .length は、要素の数です。空の配列 [] なら 0 です。

サンプル 
// 関数 countItems を作る。数値の配列 prices を受け取り、数値を返す
function countItems(prices: number[]): number {
  // prices の要素の数を返す
  return prices.length;
}
// 結果: countItems([300, 500, 200]) は 3、countItems([]) は 0

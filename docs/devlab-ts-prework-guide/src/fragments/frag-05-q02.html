05章 関数

q02 引数と戻り値の型、void

関数を 20 個書きます。どの関数も、引数と戻り値に型注釈を付けます。この番号の前半の関数は、受け取った配列やオブジェクトを書き換えて、値を返しません。何も返さない関数の戻り値の型は void です。配列やオブジェクトを引数に渡すと、関数の中で書き換えた結果が、呼んだ側の値にも残ります。そのため、書き換える引数には readonly を付けません。読むだけの引数には、これまでどおり readonly を付けます。テストは引数の型も確かめるので、問題の説明のとおりにします。

問1lines の最後に message を付け足す。何も返さない 新しく出てくる書き方：戻り値の型 void（くわしく）、参照渡し、書き換える引数の型 
export function logTo() {}

文字列の配列 lines の最後に、文字列 message を付け足します。値は返しません。引数は文字列の配列 lines と文字列 message、戻り値の型は void です。lines は書き換えるので、readonly を付けません。

テストで確かめる値
logTo(lines, "start")
lines が ["start"] になる
lines は空の配列から始める
logTo(lines, "end")
lines が ["start", "end"] になる
続けて呼ぶと、後ろに増える

型引数が string[] と string、戻り値が void であることも確かめます。

新しい書き方

: void

何も返さない関数の戻り値の型

void は 04章 q05 問13 で一度出ました。ここで、くわしく見ます。関数には 2 つの種類があります。1 つは、計算した結果を return で返す関数です。もう 1 つは、受け取った配列やオブジェクトを書き換えるなど、仕事をするだけで値を返さない関数です。値を返さない関数は、戻り値の型を void にします。void は「何も返さない」という意味の型です。

サンプル 
// 関数 addStockLog を作る。文字列の配列 logs と文字列 item と数値 count を受け取り、何も返さない
function addStockLog(logs: string[], item: string, count: number): void {
  // logs の最後に、item と count を埋め込んだ「◯: ◯個」の文字列を付け足す
  logs.push(`${item}: ${count}個`);
}
// 在庫の記録 stockLogs を文字列の配列として作り、空の配列を入れる
const stockLogs: string[] = [];
// addStockLog に stockLogs と "りんご" と 3 を渡して呼ぶ
addStockLog(stockLogs, "りんご", 3);
// 結果: stockLogs は ["りんご: 3個"]

値を返す関数と並べると、違いが分かります。呼び出し方も違います。

値を返す関数
function withTax(price: number): number {
  return Math.floor(price * 1.1);
}
const total = withTax(1000);
○ 呼んだ結果（1100）を変数に入れて使います
何も返さない関数（void）
function addStockLog(logs: string[], item: string, count: number): void {
  logs.push(`${item}: ${count}個`);
}
addStockLog(stockLogs, "みかん", 5);
○ 呼ぶだけの 1 行にします。結果は stockLogs の中身に残ります

値を返さない関数に、ほかの戻り値の型を書くと、型の確認でエラーになります。

戻り値の型を string にする
function addStockLog(logs: string[], item: string, count: number): string {
  logs.push(`${item}: ${count}個`);
}
✕ 「値を返していない」として、型の確認でエラーになります
戻り値の型を void にする
function addStockLog(logs: string[], item: string, count: number): void {
  logs.push(`${item}: ${count}個`);
}
○ 何も返さない関数として通ります

よくある間違い戻り値が void の関数で return logs.length; のように値を返すと、型の確認でエラーになります。値を返したいなら、戻り値の型をその値の型にします。

よくある間違いvoid の関数を呼んだ結果は、使う値ではありません。const done = addStockLog(stockLogs, "みかん", 5); のように変数に入れると、ESLint（コードの書き方を確かめる道具）のエラーになります。呼ぶだけの 1 行にします。

サバイバルTypeScript「戻り値がない関数とvoid型」

参照渡し

受け取った配列を書き換えると、呼んだ側の配列も変わる

配列やオブジェクトを引数に渡しても、コピーは作られません。関数の中の引数と、呼んだ側の変数は、同じ 1 つの配列を指します。そのため、関数の中で付け足したり書き換えたりすると、呼んだ側から見ても変わっています。このしくみを参照渡しといいます。サンプルの addStockLog が値を返さなくても役に立つのは、このためです。

オブジェクトも同じです。受け取ったオブジェクトのプロパティを書き換えると、呼んだ側のオブジェクトも変わります。

サンプル 
// 関数 markShipped を作る。オブジェクト order（status は文字列）を受け取り、何も返さない
function markShipped(order: { status: string }): void {
  // order の status に "発送済み" を入れ直す
  order.status = "発送済み";
}
// 注文 myOrder を作り、status が "受付" のオブジェクトを入れる
const myOrder = { status: "受付" };
// markShipped に myOrder を渡して呼ぶ
markShipped(myOrder);
// 結果: myOrder.status は "発送済み"

よくある疑問myOrder は const で作りましたが、中のプロパティは書き換えられます。const が止めるのは、変数そのものに別の値を入れ直すことだけです。

サバイバルTypeScript の教材（pass-by-value）

logs: string[]

書き換える引数には readonly を付けない

02章 q04 問1 では、読むだけの配列の引数に readonly を付けました。readonly の配列には、.push() のような書き換えるメソッドがありません。そのため、書き換える引数に付けると、型の確認でエラーになります。

readonly を付ける
function addStockLog(logs: readonly string[], item: string, count: number): void {
  logs.push(`${item}: ${count}個`);
}
✕ readonly の配列には push がないので、エラーになります
readonly を付けない
function addStockLog(logs: string[], item: string, count: number): void {
  logs.push(`${item}: ${count}個`);
}
○ 受け取った配列に付け足せます

決まり付けるかどうかは、関数の中でその引数を書き換えるかで決めます。書き換えるなら付けず、読むだけなら付けます。1 つの関数の中で、引数ごとに分けることもあります。

新しい書き方

配列.length = 0

配列の要素の数に 0 を入れて、空にする

配列の .length には、数を入れ直せます。入れた数より後ろの要素は消えます。0 を入れると、配列は空になります。01章 q08 問10 では、文字列の .length に入れようとしてエラーになりました。文字列の .length は読むだけですが、配列の .length は書き換えられます。

サンプル 
// 買い物かご cart を作り、"りんご" と "みかん" と "ぶどう" を並べた配列を入れる
const cart = ["りんご", "みかん", "ぶどう"];
// cart の要素の数に 0 を入れ直す
cart.length = 0;
// 結果: cart は []
cart.length = 1
cart は ["りんご"]
3 つ入った cart の、前から 1 つだけが残る

関数の中で配列を空にするときに、引数に空の配列を入れ直したくなります。これは、呼んだ側の配列を変えません。

引数に [] を入れ直す
function resetCart(cart: string[], first: string): void {
  cart = [];
  cart.push(first);
}
✕ ESLint のエラーになります。呼んだ側の配列も元のままです
.length に 0 を入れる
function resetCart(cart: string[], first: string): void {
  cart.length = 0;
  cart.push(first);
}
○ 呼んだ側の配列が、first だけの配列になります

なぜcart = [] は、引数 cart に、別の新しい配列を入れ直すだけです。呼んだ側の変数は、元の配列を指したままです。そのあとの .push() も、新しい配列のほうに入ります。この課題の ESLint は、引数に値を入れ直すこと自体を止めています（no-param-reassign）。

ファイルの大きさ（バイト数）を、読みやすい文字列にして返します。1024 × 1024 以上なら MB、1024 以上なら KB で表します。KB と MB は、小数第 1 位まで書きます。それより小さければ、そのまま B を付けます。数と単位の間には、半角スペースを 1 つ入れます。

"512 B"
1024 より小さい
formatBytes(1536)
"1.5 KB"
1536 ÷ 1024 = 1.5
formatBytes(2 * 1024 * 1024)
"2.0 MB"
ちょうどでも小数第 1 位まで書く

型引数が number、戻り値が string であることも確かめます。

  // もし bytes が 1024 以上なら
  //   bytes ÷ 1024 を小数第 1 位までの文字列にしたものを埋め込んだ「◯ KB」の文字列を返す

問14引数を受け取らず、何もしない関数 新しく出てくる書き方：中身が空の関数と、中に書くコメント 
export function doNothing() {}

引数を受け取らず、何もしない関数を書きます。戻り値の型は void です。中身は空でかまいませんが、中にコメントを 1 行書きます。理由は次の項目で説明します。

テストで確かめる値
doNothing()
エラーを投げずに終わる

型引数がないこと、戻り値が void であることも確かめます。

新しい書き方

{ // コメント }

中身が空の関数には、コメントを 1 行書く

中身が空の関数は、書き忘れたのか、わざと空にしたのかが見分けられません。そのため、この課題の ESLint は、中身が空の関数をエラーにします（no-empty-function）。中にコメントを 1 行書くと、わざと空にしたことが伝わり、エラーになりません。アロー関数でも同じです。

中身が空のまま
const onCancel = (): void => {};
✕ ESLint のエラーになります
中にコメントを書く
const onCancel = (): void => {
  // キャンセルのときは、何もしない
};
○ わざと空にしたことが伝わります
サンプル 
// 関数 onCancel を作る。何も受け取らず、何も返さない
const onCancel = (): void => {
  // キャンセルのときは、何もしない
};
// onCancel を呼ぶ
onCancel();
// 結果: 何も起きず、エラーにもならない

よくある疑問引数を受け取らない関数は、かっこの中を空にして () と書きます。戻り値の型は、かっこの後ろに書きます。

ヒント 1日本語の手順

やることを、サンプルと同じ言い回しで書きました。1 行ずつコードに直してください。

}
ヒント 2コードへの直し方

問14 のサンプルはアロー関数ですが、この問題は用意してある関数宣言の形のまま書きます。かっこの後ろに : void を書き、{ } の中にコメントを 1 行入れます。コメントの文は自由です。

応用引数と戻り値の型、void（3 つの関数） 新しい書き方はありません。 
export function clamp() {}

3 つの関数を書きます。引数と戻り値には、型注釈を付けます。

  1. clamp(value, min, max)：value を min 以上 max 以下に収めて返します。min が max より大きければ、エラーを投げます。
  2. logLine(lines, level, message)：lines の最後に "[INFO] message" の形の行を付け足します。level は "info"、"warn"、"error" のどれかです。大文字にして [ ] で囲みます。値は返さず、戻り値の型は void です。lines は書き換えるので、readonly を付けずに string[] にします。

clamp(-5, 0, 10)
0
clamp(5, 0, 10)

間にあるのでそのまま
clamp(5, 10, 0)
エラーを投げる
min が max より大きい
logLine(lines, "info", "起動しました")
lines が ["[INFO] 起動しました"] になる
lines は空の配列から始める
logLine(lines, "error", "失敗しました")
lines が ["[INFO] 起動しました", "[ERROR] 失敗しました"] になる
続けて呼ぶ

"1時間2分3秒"
formatDuration(125)
"2分5秒"
0 時間は書かない
formatDuration(3600)
"1時間"
0 分と 0 秒は書かない
formatDuration(3605)
"1時間5秒"
間の 0 分も書かない

"0秒"
全部 0 のときだけ「0秒」

型clamp は引数が number 3 つ、戻り値が number です。logLine は引数が string[] と "info" | "warn" | "error" と string、戻り値が void です。formatDuration は引数が number、戻り値が string です。

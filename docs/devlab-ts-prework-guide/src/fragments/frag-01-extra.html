新しい書き方

bigint10n

とても大きな整数を正確に扱う型

number は、とても大きな整数を正確に表せません。bigint は、どんなに大きな整数でも正確に表せる型です。数の後ろに n を付けると、bigint の値になります。

2 ** 53 + 1
9007199254740992
number。1 を足したのに、答えが 1 ずれる
2n ** 53n + 1n
9007199254740993n
bigint。正確
5n < 10n
true
比べることもできます。
サンプル 
// 関数 totalBytes を作る。bigint の files と、bigint の size を受け取り、bigint を返す
function totalBytes(files: bigint, size: bigint): bigint {
  // files に size を掛けた数を返す
  return files * size;
}
// 結果: totalBytes(3000000n, 4000000000n) は 12000000000000000n

++ や *= も、bigint の変数にそのまま使えます。

サンプル 
// 件数 count を入れ直せる変数として作り、bigint の 1n を入れる
let count = 1n;
// count を 1 増やす
count++;
// 結果: count は 2n
bigint と number を混ぜる
const population = 8000000000n;
const doubled = population * 2;
✕ 2 行目が型の確認でエラーになります
bigint どうしで計算する
// 人口 population を作り、bigint の 8000000000n を入れる
const population = 8000000000n;
// doubled を作り、population に 2n を掛けた数を入れる
const doubled = population * 2n;
○ doubled は 16000000000n になります

小数の計算の誤差

小数を足したり掛けたりすると、ほんの少しずれた答えになることがあります。TypeScript（JavaScript）の number の決まりで、どの環境でも同じように起きます。

0.1 + 0.2
0.30000000000000004
0.7 + 0.1
0.7999999999999999
1.15 * 100
114.99999999999999
100 倍しても、ぴったりの整数にならない

よくある間違いお金の計算でこの誤差が残ると、0.3 と比べても等しくならず、テストが通りません。

01章 q04（number型）

Math.round(x * 100)

整数に直してから計算する

整数どうしの足し算や掛け算は、大きすぎなければ誤差が出ません。小数第 2 位までの金額なら、100 倍して整数に直してから計算します。100 倍した数にも誤差が出ることがあるので、Math.round() で四捨五入して整数にそろえます。

サンプル 
// 単価 price を作り、1.15 を入れる（ドル）
const price = 1.15;
// 結果: price * 100 は 114.99999999999999（整数にならない）
// セント cents を作り、price × 100 を四捨五入した数を入れる
const cents = Math.round(price * 100);
// 結果: cents は 115

コツ1 ドルは 100 セントです。セント（整数）で計算して、最後に 100 で割ってドルに戻します。

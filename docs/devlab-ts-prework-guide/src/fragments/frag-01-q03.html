01章 値・型・変数

q03 型推論

型注釈を書かなくても、TypeScript は入れた値や返す値から型を決めます。これを型推論と呼びます。この番号では、定数は型注釈を書かずに export const で作ります。関数は、引数には型注釈を書き、戻り値には型注釈を書きません（推論に任せます）。テストは値に加えて、推論された型が決められたとおりかも確かめます。

問1定数 SITE_NAME を宣言する 新しく出てくる書き方：型推論、export const 
// ここに SITE_NAME を宣言する

定数 SITE_NAME を作り、"Agora" を入れます。型注釈は書きません。テストがこの定数を読むので、ほかのファイルから使えるようにします。推論される型が "Agora" になれば正解です。

テストで確かめる値
SITE_NAME
"Agora"
値
SITE_NAME の型
"Agora"
"Agora" だけを表す型

新しい書き方

型推論

型注釈を書かなくても型が決まる

入れた値を見て、TypeScript が型を決めます。VS Code で変数にマウスを載せると、決まった型が表示されます。

サンプル 
// 送料 SHIPPING_FEE を作り、500 を入れる。型は書かない
const SHIPPING_FEE = 500;
// 結果: SHIPPING_FEE の型は 500

const の変数は入れ直せないので、型は入れた値そのものになります。let の変数は入れ直せるので、同じ種類のどの値でも入る型になります。

const で作る
// 店名 shopName を作り、"本店" を入れる
const shopName = "本店";
// 結果: 型は "本店"
let で作る
// 店名 shopName を入れ直せる変数として作り、"本店" を入れる
let shopName = "本店";
// 結果: 型は string

よくある疑問"本店" のように、値そのものが型になったものをリテラル型と呼びます。くわしくは q07 で学びます。

サバイバルTypeScript「型推論」

export const

ほかのファイルから使える定数を作る

const の前に export を付けると、ほかのファイルから読めるようになります。関数の export function と同じ考え方です。

サンプル 
// 1 回の注文の上限 MAX_ORDER を作り、10 を入れる。ほかのファイルから使えるようにする
export const MAX_ORDER = 10;
// 結果: MAX_ORDER の型は 10

コツプログラム全体で決まっている値の名前は、MAX_ORDER のように大文字と _ で書くことがよくあります。

return が 2 つ以上あるときの推論

if の中で return すると、そこで関数が終わります。決まった文字列を返す return が 2 つ以上あると、戻り値の型はそれらの値を | でつないだ型になります。A | B は「A か B のどちらか」という型です。

サンプル 
// 関数 sizeLabel を作る。weight（number）を受け取る。戻り値の型は書かない
function sizeLabel(weight: number) {
  // もし weight が 2 より小さいなら
  if (weight < 2) {
    // "小" を返す
    return "小";
  }
  // "大" を返す
  return "大";
}
// 結果: 戻り値の型は "小" | "大"。sizeLabel(1) は "小"、sizeLabel(3) は "大"

よくある疑問決まった文字列を返す return が 1 つだけなら、戻り値の型は string になります。

新しい書き方

値がないことを表す値

「返す値がない」「まだ決まっていない」ことを表す特別な値です。" で囲まずに書きます。数を返すときと undefined を返すときがある関数の戻り値は、number | undefined に推論されます。

サンプル 
// 関数 pointOf を作る。price（number）と isMember（boolean）を受け取る。戻り値の型は書かない
function pointOf(price: number, isMember: boolean) {
  // もし isMember が true なら
  if (isMember) {
    // price ÷ 100 を切り捨てた数を返す
    return Math.floor(price / 100);
  }
  // undefined を返す
  return undefined;
}
// 結果: 戻り値の型は number | undefined。pointOf(1980, true) は 19、pointOf(1980, false) は undefined

export function calcBmi() {}

export function bmiReport() {}

BMI（体格指数）を計算する関数を 2 つ書きます。

  1. calcBmi(heightCm, weightKg)：BMI = 体重(kg) ÷ (身長(m) × 身長(m))。身長は cm で受け取るので、m に直してから計算します。結果は小数第 1 位までに四捨五入します。
  2. bmiReport(heightCm, weightKg)：calcBmi で BMI を求め、判定を付けた文字列を返します。BMI は小数第 1 位まで表示します。判定は 18.5 未満が「低体重」、18.5 以上 25 未満が「普通体重」、25 以上が「肥満」です。

引数には型注釈を書きます。戻り値と、関数の中の変数には型注釈を書きません。また、「引数の型注釈を消すと、どんなエラーになるか。なぜ引数だけは推論されないのか」を、ファイルの下に // のコメントで説明します。

if の条件に合わなかったときに、別の条件を確かめます。上から順に確かめ、最初に合った { } だけを実行します。

サンプル 
// 関数 sizeOf を作る。weight（number）を受け取る。戻り値の型は書かない
function sizeOf(weight: number) {
  // サイズ size を入れ直せる変数として作り、"大" を入れる
  let size = "大";
  // もし weight が 2 より小さいなら
  if (weight < 2) {
    // size に "小" を入れ直す
    size = "小";
  } else if (weight < 5) {
    // （そうでなく、もし weight が 5 より小さいなら）size に "中" を入れ直す
    size = "中";
  }
  // size を返す
  return size;
}

04章 q01（if-else文）

.toFixed()

小数点以下の桁数を決めて文字列にする

数の後ろに .toFixed(桁数) を付けると、その桁数までの文字列になります。足りない桁は 0 で埋めます。

サンプル 
// 平均 average を作り、7 ÷ 3 を入れる
const average = 7 / 3;
// 表示 text を作り、average を小数第 1 位までの文字列にしたものを入れる
const text = average.toFixed(1);
// 結果: text は "2.3"。型は string
rate.toFixed(1)
"25.0"
rate が 25 のとき。0 で埋める

よくある間違い結果は文字列です。計算に使う数は、.toFixed() を使う前の数のままにしておきます。

02章 オブジェクト・配列・タプル

q07 構造的型付け

関数を 20 個書きます。引数と戻り値には型注釈を付けます。ファイルには Cat・Dog・Robot などの型が、最初から書いてあります。引数の型には、関数が本当に使うプロパティだけを書きます。名前しか使わないなら { name: string } です。こうしておくと、名前の違う型でも、そのプロパティを持っていれば同じ関数に渡せます。この仕組みを構造的型付けと呼びます。テストは、引数の型がその形になっているかも確かめます。

問1name を返す（Cat でも Robot でも渡せる） 新しく出てくる書き方：構造的型付け（使うプロパティだけを引数の型に書く） 
export type Cat = { name: string; age: number; meow: string };

export type Robot = { name: string; version: number };

export function nameOf() {}

受け取ったオブジェクトの name を返します。Cat と Robot は、持っているプロパティが違います。でも、どちらも name を持っています。引数の型には Cat も Robot も使いません。{ name: string } と書きます。戻り値は文字列です。

テストで確かめる値
nameOf(cat)
"ミケ"
cat は Cat 型の { name: "ミケ", age: 3, meow: "ニャー" }
nameOf(robot)
"R2"
robot は Robot 型の { name: "R2", version: 2 }

型引数が { name: string }、戻り値が string であることも確かめます。

新しい書き方

x: { email: string }

構造的型付け（形が合えば渡せる）

TypeScript は、引数に渡せるかどうかを、オブジェクトの形で決めます。形とは、どんなプロパティを、どんな型で持っているかです。型の名前は見ません。これを構造的型付けと呼びます。

引数の型に、関数が使うプロパティだけを書いておきます。すると、そのプロパティを持つオブジェクトなら、どの型でも渡せます。ほかのプロパティを持っていてもかまいません。

サンプル 
// 会員 Member という型を作る。name は文字列、email は文字列、points は数値
type Member = { name: string; email: string; points: number };
// 取引先 Shop という型を作る。email は文字列、address は文字列
type Shop = { email: string; address: string };

// 関数 mailTo を作る。email（文字列）を持つオブジェクト x を受け取り、文字列を返す
function mailTo(x: { email: string }): string {
  // x の email を埋め込んだ「宛先: ◯」の文字列を返す
  return `宛先: ${x.email}`;
}

// 会員 member を作り、Member 型の値を入れる
const member: Member = { name: "佐藤", email: "sato@example.com", points: 120 };
// 取引先 shop を作り、Shop 型の値を入れる
const shop: Shop = { email: "info@shop.example", address: "大阪市" };
// 文 toMember を作り、mailTo に member を渡して呼んだ結果を入れる
const toMember = mailTo(member);
// 文 toShop を作り、mailTo に shop を渡して呼んだ結果を入れる
const toShop = mailTo(shop);
// 結果: toMember は "宛先: sato@example.com"、toShop は "宛先: info@shop.example"

引数の型を Member にすると、どうなるかを比べます。

引数の型を Member にする
function mailTo(x: Member): string {
  return `宛先: ${x.email}`;
}
// mailTo に shop を渡して呼ぶ
mailTo(shop);
✕ Shop には name と points がないので、エラーになります
使うプロパティだけを書く
function mailTo(x: { email: string }): string {
  return `宛先: ${x.email}`;
}
// mailTo に shop を渡して呼ぶ
mailTo(shop);
○ email があるので渡せます。member も渡せます

よくある間違い関数の中で使えるのは、引数の型に書いたプロパティだけです。x: { email: string } の関数の中で x.points と書くと、エラーになります。使うプロパティは、すべて型に書きます。

コツ先に、関数の中で使うプロパティを数えます。name だけなら { name: string }、width と height なら { width: number; height: number } です。

テストこの番号のテストは、引数の型が問題の形と同じかを確かめます。引数の型を Cat や Cat | Robot にすると、テストは通りません。

新しい書き方

オブジェクトの配列の型

配列の型は、number[] のように、要素の型の後ろに [] を付けて書きました（01章 q08）。要素がオブジェクトのときも同じです。オブジェクトの型の後ろに [] を付けます。前に付けた readonly は、関数の中で配列を書き換えないという印です（q04 問1）。

サンプル 
// 本 Book という型を作る。title は文字列、stock は数値
type Book = { title: string; stock: number };
// 文具 Pen という型を作る。name は文字列、color は文字列、stock は数値
type Pen = { name: string; color: string; stock: number };

// 関数 countInStock を作る。stock（数値）を持つオブジェクトの読み取り専用の配列 items を受け取り、数値を返す
function countInStock(items: readonly { stock: number }[]): number {
  // 件数 count を入れ直せる変数として作り、0 を入れる
  let count = 0;
  // items から 1 つずつ item に取り出してくり返す
  for (const item of items) {
    // もし item の stock が 0 より大きいなら
    if (item.stock > 0) {
      // count に 1 を足す
      count += 1;
    }
  }
  // count を返す
  return count;
}

// 本 book を作り、Book 型の値を入れる
const book: Book = { title: "TypeScript入門", stock: 3 };
// 文具 pen を作り、Pen 型の値を入れる
const pen: Pen = { name: "ボールペン", color: "黒", stock: 0 };
// 在庫のある数 inStock を作り、countInStock に book と pen を並べた配列を渡して呼んだ結果を入れる
const inStock = countInStock([book, pen]);
// 結果: inStock は 1

よくある疑問Book と Pen は違う型ですが、同じ配列に入れて渡せます。どちらも stock を持っているからです。問1 の構造的型付けが、配列の要素 1 つずつに当てはまります。

よくある間違い最後の [] を忘れると、オブジェクト 1 つの型になります。

オブジェクトの配列を受け取り、price がいちばん小さいものの name を返します。同じ価格のものが複数あれば、先に出てきた方を返します。空の配列なら、エラーを投げます。引数の型は readonly { name: string; price: number }[]、戻り値は文字列です。

テストで確かめる値

"りんご"
相談 3000、りんご 150
cheapestName([])
Error を投げる
空の配列

新しい書き方

[first, ...rest]

先頭と、残りをまとめて取り出す

配列の分割代入（q06 問2）で、最後の名前の前に ... を付けます。すると、そこに「残りの要素をまとめた配列」が入ります。先頭を特別に扱い、残りをくり返すときに便利です。

サンプル 
// 予約待ちの名前の配列 waiting を作り、"佐藤"、"鈴木"、"高橋" を入れる
const waiting = ["佐藤", "鈴木", "高橋"];
// waiting の先頭を next に、残りをまとめて others に取り出す
const [next, ...others] = waiting;
// 結果: next は "佐藤"、others は ["鈴木", "高橋"]
["佐藤", "鈴木", "高橋"]
先頭は "佐藤"、残りは ["鈴木", "高橋"]
["佐藤"]
先頭は "佐藤"、残りは []
残りがなければ空の配列
[]
先頭は undefined、残りは []
先頭もない

配列は空かもしれません。そのため、先頭の next の型は string | undefined になります。残りの others は、空でも [] なので string[] です。先頭を使う前に、undefined でないかを確かめます。

サンプル 
// 関数 firstGuest を作る。文字列の読み取り専用の配列 names を受け取り、文字列を返す
function firstGuest(names: readonly string[]): string {
  // names の先頭を head に、残りをまとめて rest に取り出す
  const [head, ...rest] = names;
  // もし head が undefined と等しいなら
  if (head === undefined) {
    // "予約がありません" というメッセージのエラーを投げる
    throw new Error("予約がありません");
  }
  // head と rest の要素の数を埋め込んだ「◯さん（ほか◯人）」の文字列を返す
  return `${head}さん（ほか${rest.length}人）`;
}
// 結果: firstGuest(["佐藤", "鈴木", "高橋"]) は "佐藤さん（ほか2人）"

よくある間違い... を付けられるのは、いちばん最後の名前だけです。[...others, last] と書くとエラーになります。

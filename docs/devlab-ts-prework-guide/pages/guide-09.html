q01 Map

点数表や在庫表のように、キーと値の組を集めて扱う関数を 20 個書き、最後に応用問題に取り組みます。この番号では、TypeScript に最初から用意されている Map を使います。引数と戻り値には型注釈を付けます。型は Map<string, number> のように書きます。「新しい Map を返す」問題では、引数の Map を書き換えません。コピーを作ってから変えます。引数の型は Map<…> と書き、ReadonlyMap は使いません。Map は、組を入れた順を覚えています。keys()・values()・entries() は、入れた順に取り出せます。配列にしたいときは、[...map.keys()] のようにスプレッド構文を使います。

問1[名前, 点数] の配列から Map を作る 新しく出てくる書き方：Map の型 Map<K, V>、new Map() 
export function toMap() {}

名前と点数の組を並べた配列を受け取り、その組をそのまま入れた Map を返します。組は、文字列と数値のタプル [string, number] です（02章 q06 問1）。引数の型は、そのタプルの配列 [string, number][] です。

テストで確かめる値
toMap([["山田", 80], ["佐藤", 65]])
Map { "山田" => 80, "佐藤" => 65 }
"佐藤" の値が 65、入っている組の数が 2 であることを確かめる

型引数が [string, number][]、戻り値が Map<string, number> であることも確かめます。

新しい書き方

Map<K, V>

キーと値の組を持つ入れ物

Map は、キーと値の組をいくつも入れておく入れ物です。キーを渡すと、そのキーの値を取り出せます。点数表なら、キーが名前、値が点数です。同じキーの組は 1 つしか入りません。型は Map<キーの型, 値の型> と書きます。< > に型を渡す形は、07章 q06 問8 の Box<T> と同じです。

キーと値の組は、02章 q08 のインデックス型と、07章 q02 問19 の Record でも表せました。Record<string, number> は { [key: string]: number } と同じ型です。どちらも、中身はただのオブジェクトです。Map との違いを表にまとめます。

Map は、組を足したり取り除いたりしながら使う入れ物です。数えたり集めたりする処理に向いています。キーが前もって決まっているデータは、これまでどおりオブジェクトの型で書きます。

このページでは、Map の中身を Map { "ノート" => 12 } のように書きます。=> の左がキー、右が値です。課題のファイルの例と同じ書き方です。

サバイバルTypeScript「Map<K, V>」

new Map([[k, v], …])

[キー, 値] の組の配列から Map を作る

Map は、new Error()（01章 q04 問8）と同じく、new を付けて作ります。new Map() のかっこに、[キー, 値] の組を並べた配列を渡すと、その組を前から順に入れた Map ができます。かっこの中を空にすると、空の Map ができます（問11）。

サンプル 
// 在庫 stock を作り、["ノート", 12] と ["ペン", 0] の組から作った Map を入れる
const stock = new Map([
  ["ノート", 12],
  ["ペン", 0],
]);
// 結果: stock は Map { "ノート" => 12, "ペン" => 0 }

Map の型は、渡した組から推論されます。stock の型は Map<string, number> です。

よくある間違い組を 1 つだけ入れるときも、外側の [ ] は省けません。new Map(["ノート", 12]) と書くと、型の確認でエラーになります。new Map([["ノート", 12]]) と書きます。

.set()

キーに値を入れる

1 つ目にキー、2 つ目に値を渡します。ないキーなら、その組を最後に足します。あるキーなら、値だけを置き換えます。置き換えても、組の並ぶ順は変わりません。.set() は、呼んだ Map そのものを書き換えます。

サンプル 
// 在庫 stock を作り、["ノート", 12] と ["ペン", 0] の組から作った Map を入れる
const stock = new Map([
  ["ノート", 12],
  ["ペン", 0],
]);
// stock の "ペン" に 30 を入れる
stock.set("ペン", 30);
// stock の "消しゴム" に 5 を入れる
stock.set("消しゴム", 5);
// 結果: stock は Map { "ノート" => 12, "ペン" => 30, "消しゴム" => 5 }

新しい書き方

ReadonlyMap<K, V>

書き換えられない Map の型

ReadonlyMap は、.get()・.has()・.size・.keys()・.values()・.entries() だけが使える Map の型です。.set() や .delete() を呼ぶと、型の確認でエラーになります。読み取り専用の配列 readonly T[]（02章 q04 問1）の Map の版です。引数の型にすると、関数の中で引数の Map を書き換えていないことを、型の確認で確かめられます。ドリルでは使いませんでしたが、応用問題の引数には使ってかまいません。Map<…> のままでもテストは通ります。

サンプル 
// 関数 totalStock を作る。キーが文字列で値が数値の読み取り専用の Map stock を受け取り、数値を返す
function totalStock(stock: ReadonlyMap<string, number>): number {
  // 在庫の合計 total を入れ直せる変数として作り、0 を入れる
  let total = 0;
  // stock の値から 1 つずつ count に取り出してくり返す
  for (const count of stock.values()) {
    // total に count を足す
    total += count;
  }
  // total を返す
  return total;
}
// 結果: totalStock(new Map([["ノート", 12], ["ペン", 8]])) は 20
ReadonlyMap の引数に .set() を呼ぶ
stock.set("ペン", 0);
✕ ReadonlyMap<string, number> に set というプロパティはない、というエラーになります
コピーしてから .set() を呼ぶ
const copy = new Map(stock);
copy.set("ペン", 0);
○ new Map() でコピーした Map は、書き換えられる Map<string, number> です

引数を ReadonlyMap にしても、呼ぶ側はふつうの Map をそのまま渡せます。

やってもやらなくてもよい、任意の課題です。章の課題とは別に数えます。番号の順に、1 問ずつ確認して提出します。e01 では、外から来た JSON の形を確かめて読み、JSON の文字列に書き出します。e02 では、正規表現で文字列を調べ、取り出し、置き換えます。どちらにも「説明すること」があり、ファイルの「説明すること」のすぐ下に // のコメントで書きます。引数と戻り値には型注釈を付けます。

新しい書き方

JSON.stringify(値, null, 2)

字下げした JSON の文字列にする

JSON.stringify()（04章 q07 問1）は、値を JSON の文字列にします。かっこに 1 つだけ渡すと、空白も改行もない 1 行の文字列になります。3 つ目の引数に数を渡すと、その数の空白で字下げし、改行を入れた、人が読みやすい文字列になります。

// 文字列 indented を作り、order を 2 つの空白で字下げした JSON の文字列にしたものを入れる
const indented = JSON.stringify(order, null, 2);

.matchAll()

合った部分を、すべて取り出す

.exec()（04章 q08 問6）は、最初に合った 1 つだけを取り出します。.matchAll() は、文字列の中で合った部分を、すべて順に取り出します。正規表現には g を付けます。取り出した結果は、1 つずつが .exec() の結果と同じ形の配列です。0 番目が合った部分の全体、1 番目からが ( ) で囲んだ部分です。

サンプル 
// 明細 receipt を作り、"ペン 120円、ノート 250円" を入れる
const receipt = "ペン 120円、ノート 250円";
// matches を作り、receipt の中で /(\d+)円/g に合った結果をすべて並べた新しい配列を入れる
const matches = [...receipt.matchAll(/(\d+)円/g)];
// prices を作り、matches の要素を 1 つずつ m として、m の 1 番目を数値にしたものに変えた新しい配列を入れる
const prices = matches.map((m) => Number(m[1]));
// 結果: matches[0] は ["120円", "120"]、prices は [120, 250]

.replace()（01章 q05 問18）の 2 つ目の引数の中で、$1、$2 … と書くと、そこに 1 つ目、2 つ目 … の ( ) に合った部分が入ります。合った部分の一部だけを残して、ほかを書き換えるときに使います。

サンプル 
// 日付 date を作り、"2026-05-10" を入れる

// usDate を作り、date の中の「数字 4 つ、-、数字 2 つ、-、数字 2 つ」を、2 つ目のグループ、/、3 つ目のグループ、/、1 つ目のグループの順に並べ替えたものを入れる
const usDate = date.replace(/(\d{4})-(\d{2})-(\d{2})/g, "$2/$3/$1");
// 結果: usDate は "05/10/2026"

// 在庫の行 line を作り、"SKU-0042:12" を入れる
const line = "SKU-0042:12";
// groups を作り、line を /^(?<code>[A-Z]+-\d+):(?<qty>\d+)$/ に合わせた結果の名前付きグループ（合わなければ undefined）を入れる
const groups = /^(?<code>[A-Z]+-\d+):(?<qty>\d+)$/.exec(line)?.groups;
// 商品コード code を作り、groups の code（groups が undefined なら undefined）を入れる
const code = groups?.code;
// 結果: code は "SKU-0042"。groups の qty は "12"

型.exec() は、合わなければ null を返します。?.（03章 q03 問1）を付けると、null のときは groups が undefined になります。groups?.code の型は string | undefined です。使う前に undefined でないことを確かめます。

.replace(正規表現, 関数)

合った部分ごとに、関数で置き換える

.replace() の 2 つ目の引数には、関数（02章 q04 問5 のコールバック）も渡せます。合った部分が見つかるたびに、その部分の文字列を引数にして関数が呼ばれます。関数が返した文字列で置き換えます。合った部分を、大文字にするなど、変えてから入れたいときに使います。

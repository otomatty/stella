前提：問題のファイルの読み方

どの問題のファイルにも最初から書いてあるものです。ここだけ先に読んでください。

関数の形を読む

最初から書いてある

関数は「値を受け取り、計算して、値を返す」まとまりです。問題のファイルには、外側の形が最初から書いてあります。あなたが書くのは { } の中です。

よくある疑問: number が 2 つあります。かっこの中は受け取る値の型、かっこの後ろは返す値の型です。

型注釈は 01章 q02、関数は 05章 q01、export は 09章 q05

関数を呼ぶ

名前の後ろにかっこを付け、中に渡す値を書きます。呼んだ場所は、返ってきた値に置き換わります。

Math.floor(3.7) のように . が付く呼び方もあります。Math は数の計算をまとめた入れ物で、その中の floor を呼んでいます。Math.floor のように最初から使える関数を「組み込み」と呼びます。

値の書き方

型書き方何を表すか
number1000　0.1数値。整数と小数を区別しません。
string"Fizz"　""文字列。" で囲みます。"" は 0 文字の文字列です。
booleantrue　false「はい」か「いいえ」の 2 つだけです。

よくある間違い"10" は文字列で、10 は数値です。見た目が似ていても別の型です。

コメントと、例の読み方

// から行の終わりまではコメントです。実行されません。問題文はコメントで書いてあります。

// 問1 税込価格を返す（税率10%。税額の1円未満は切り捨て）
//     例: addTax(1000) → 1100
export function addTax(price: number): number {
  // ここに書く
}

例の → は TypeScript の書き方ではありません。「左のように呼ぶと、右の値が返る」という説明です。

このページのサンプルでは、各行の上のコメントに、その行がすることを日本語で書いています。最後の // 結果: は、その時点の変数の値です。

ヒント 1 の骨組みも同じ言い回しで書いています。字下げしたコメントは、くり返しや if の { } の中に書く行です。

書き方文の終わりには ; を書きます。{ } で囲んだ範囲はひとまとまりで、中は 2 文字ぶん字下げします。

q01 letとconst

変数は const で作り、後から値を入れ直す変数だけ let にします。var は使いません。くり返しや条件分岐（for・if・while）もここで初めて出てきます。くわしくは 04章で学ぶので、ここでは「まねて書ける」ところまでで十分です。

価格 price に 10% の税を足した金額を返します。税額に 1 円未満の端数が出たら、捨ててから足します。

テストで確かめる値

const

変数を作る（入れ直せない）

よくある間違い= は「等しい」ではなく、「右を左に入れる」です。等しいかを比べる書き方は問9 で出ます。

`…${式}…`

テンプレートリテラル

文字列の中に、変数や計算の結果を埋め込みます。

サンプル 
// 商品名 item を作り、"ノート" を入れる

// 冊数 count を作り、3 を入れる
const count = 3;
// 文 message を作り、item と count を埋め込んだ「◯を◯冊注文しました」を入れる
const message = `${item}を${count}冊注文しました`;
// 結果: message は "ノートを3冊注文しました"

リテラル型（決まった値だけを受け付ける型）

string はどんな文字列でも受け付けます。"card" のように値そのものを型に書くと、その値だけを受け付ける型になります。これをリテラル型と呼びます。

リテラル型を | でつなぐと、「どれか 1 つ」を受け付ける型になります。"card" | "cash" は、"card" か "cash" だけを受け付けます。

サンプル 
// 関数 paymentLabel を作る。"card" か "cash" の method を受け取り、文字列を返す
function paymentLabel(method: "card" | "cash"): string {
  // method が "card" と等しいなら "カード払い"、そうでなければ "現金払い" を返す
  return method === "card" ? "カード払い" : "現金払い";
}
// 結果: paymentLabel("cash") は "現金払い"
決めた値を渡す
// paymentLabel に "card" を渡して呼ぶ
paymentLabel("card");
○ "カード払い" が返ります
決めていない値を渡す
// paymentLabel に "bank" を渡して呼ぶ
paymentLabel("bank");
✕ 型の確認でエラーになります

数や true も、リテラル型にできます。

コツ値の候補が決まっているところにリテラル型を書くと、打ち間違い（"crad" など）を実行する前に見つけられます。

よくある間違い型の | は 1 本です。「または」の ||（2 本）とは別のものです。

新しい書き方

if (…) { return …; }

条件に合ったら、その場で返す

return を実行すると、関数はそこで終わります。if の中に return を書くと、条件に合ったときだけ、その場で値を返せます。後ろの行は実行されません。

サンプル 
// 関数 stockLevel を作る。数の stock を受け取り、"なし" か "少ない" か "十分" を返す
function stockLevel(stock: number): "なし" | "少ない" | "十分" {
  // もし stock が 0 と等しいなら
  if (stock === 0) {
    // "なし" を返す（ここで関数が終わる）
    return "なし";
  }
  // もし stock が 10 より小さいなら
  if (stock < 10) {
    // "少ない" を返す
    return "少ない";
  }
  // "十分" を返す
  return "十分";
}
// 結果: stockLevel(0) は "なし"、stockLevel(3) は "少ない"、stockLevel(50) は "十分"

最後の return "十分"; まで来るのは、どちらの if にも当てはまらなかったときだけです。

返す値をリテラル型にした関数では、let の変数に入れてから最後に返す書き方がエラーになります。let で作った変数の型が string になり、"なし" | "十分" に入らないからです。

let に入れてから返す
function stockLevel(stock: number): "なし" | "十分" {
  let level = "十分";
  if (stock === 0) {
    level = "なし";
  }
  return level;
}
✕ return の行が型の確認でエラーになります
if の中で返す
function stockLevel(stock: number): "なし" | "十分" {
  // もし stock が 0 と等しいなら
  if (stock === 0) {
    // "なし" を返す
    return "なし";
  }
  // "十分" を返す
  return "十分";
}
○ 返す値が "なし" か "十分" だけなので通ります

コツlet level: "なし" | "十分" = "十分"; のように変数にも型を付ければ、let でも書けます。

# 擬似言語サブセット仕様 (fe-pseudo)

基本情報技術者試験 科目B で使われる擬似言語のうち、**本教材がサポートする範囲**を定める (#133)。

IPA は擬似言語の厳密な言語仕様書を公開しておらず、正本は公開されているサンプル問題の記述形式である。
そのためこのファイルが本教材における唯一の基準になる。ここに書かれていない構文はパーサが
行番号つきの日本語エラーで弾く (黙って誤動作させない)。

実行方式は「擬似言語 → JavaScript にトランスパイル → QuickJS で実行」。TypeScript 課題 (`ts-runner`) と
同じ構図で、新しい実行基盤は増やしていない。

## 1. プログラムの構造

```
○整数型: 二分探索(整数型の配列: data, 整数型: target)
  整数型: low ← 1
  ...
  return -1
```

- 関数定義は `○` で始める。`〇` (漢数字のゼロ) と `●` も同じものとして受け付ける。
- 戻り値の型は省略できる (値を返さない手続き)。
- **関数の本体はインデントで示す**。`○` の行より深いインデントが本体で、
  インデントが `○` の位置まで戻るか次の `○` が来ると本体が終わる。
  擬似言語には `endfunction` に当たる語が無いため、これがブロックの終わりの唯一の手がかりになる。
- 関数の外にも文を書ける (`出力` を使った動作確認など)。

## 2. 変数宣言

```
整数型: i, j
整数型: sum ← 0
整数型の配列: data ← {2, 4, 6}
```

- 型名は `整数型` `実数型` `文字列型` `文字型` `論理型` と、それらの `〜の配列`。
- 宣言と同時に `←` で初期値を書ける。カンマ区切りで複数宣言できる。
- **宣言のスコープは手続き全体**。`if` の中で宣言した変数を `endif` の後で使える
  (JS の `let` と違いブロックスコープではない)。トランスパイラは宣言を手続きの先頭に巻き上げる。

## 3. 制御構造

```
if (条件)          while (条件)        do                 for (i を 1 から n まで 1 ずつ増やす)
  ...                ...                 ...                ...
elseif (条件)      endwhile           while (条件)        endfor
  ...
else
  ...
endif
```

- `for` の見出しは `<変数> を <初期値> から <終了値> まで <増分> ずつ増やす` (または `ずつ減らす`)。
  終了値は**その値も含む**。`ずつ 増やす` のように分かち書きしてもよい。
- `for` の終了値と増分は**ループ開始時に 1 度だけ**評価される。
- `do 〜 while` は後判定 (本体が必ず 1 回は実行される)。
  終端の `while` は `do` と同じ深さに書く。本体の中に書いた (より深い) `while` はループとして扱う。
- `return` は値ありでも値なしでも書ける。

## 4. 演算子

| 種類 | 擬似言語 | ASCII 代替 | 備考 |
|---|---|---|---|
| 代入 | `←` | `<-` | 文の先頭でのみ使える |
| 算術 | `+` `-` `×` `÷` `%` | `*` `/` | `%` は `mod` とも書ける |
| 比較 | `=` `≠` `>` `<` `≧` `≦` | `==` `!=` / `<>` `>=` `<=` | `=` は比較 (代入ではない) |
| 論理 | `and` `or` `not` | — | |

優先順位 (IPA 公式資料どおり、高い順): 添字・関数呼び出し → 単項 `+` `-` `not` → `×` `÷` `%` → `+` `-` → 比較 → `and` → `or`。
`not` は比較より強く結合する (`not a = b` は `(not a) = b`)。意図どおり `not (a = b)` と書く場合は括弧を使う。

全角の英数字・記号 (`１` `＋` `（`) は半角として読む。

## 5. 擬似言語固有の意味論 (重要)

TypeScript に翻訳した課題では学べず、本試験で問われる部分。トランスパイラが吸収する。

### 5.1 配列の添字は 1 から始まる

```
data[1]              // 先頭の要素
data[dataの要素数]   // 末尾の要素
```

- 範囲外 (`0` 以下、要素数超過、非整数) のアクセスは**実行時エラー**にする。
  黙って `undefined` を返すと、科目Bで最も問われる境界の誤りが採点で素通りしてしまうため。
- 要素数は後置の `〜の要素数` で取る (`dataの要素数`)。
- 2 次元配列 (`m[2, 1]` または `m[2][1]`) も同じ規則。公式記法では行・列を `,` で区切る。

### 5.2 整数どうしの除算は商 (切り捨て)

```
10 ÷ 3    → 3
-7 ÷ 2    → -3     (0 方向への切り捨て)
```

- **`実数型` と宣言された値が関わる除算は切り捨てない** (`10.0 ÷ 4` → `2.5`)。
  JS の数値は `10` と `10.0` を区別できないため、実行時の値ではなく**宣言された型**で判定する。
  型が判明しない式は整数として扱う (= 切り捨てる)。
- `0` による除算・剰余は日本語のエラーにする。

## 6. 組み込み

| 記法 | 意味 |
|---|---|
| `<配列>の要素数` | 配列の要素数 |
| `出力(...)` | 標準出力へ 1 行書く (**教材独自の拡張**。IPA の擬似言語には無い) |

`出力` は `stdout` 採点の課題で使う。`function` 採点の課題では不要。

## 7. 識別子の制限

- 識別子は **ASCII の連なり** (`data`, `low_1`) か **日本語の連なり** (`合計`, `配列`) のどちらかで、
  混在させられない (`sum合計` は 2 つの識別子として読まれる)。
  こうしないと `iを1から` が 1 個の識別子に潰れて `for` の見出しが読めなくなる。
- 次の語は日本語の連なりの途中でも助詞として切り出されるため、**識別子に含められない**:
  `を` / `から` / `まで` / `ずつ増やす` / `ずつ減らす` / `の要素数`
- JavaScript の予約語 (`class`, `new`, `var` …) と、`__fe` で始まる名前は使えない
  (生成後の JS と衝突するため)。

## 8. サポート外

以下は意図的に未対応。書かれた場合はエラーになる。

- 大域変数の宣言 (`大域: 〜`)、構造体・クラス・オブジェクト指向の記法
- 例外処理、ファイル入出力、可変長配列への要素追加
- 1 行に複数の文を書くこと

対応範囲を広げるときは、このファイルと `fe-pseudo.test.ts` を同時に更新すること。

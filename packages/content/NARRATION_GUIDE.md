# ナレーション台本ガイド (narration.json)

教材動画 (トピック 1 つ = 動画 1 本) の読み上げ台本のルールです。人・執筆エージェント・`bun run --filter=@stella/content narrate` (Claude による下書き) のすべてがこのファイルに従います。**`narrate` はこのファイルをそのままシステムプロンプトに入れる**ので、ルールを変えるときはここだけを直してください。

## 台本の役割

- 動画の映像は**スライドそのもの**です。台本は、画面にスライドが出ている間に講師が話す言葉を、字幕の単位で並べたものです
- 入力は、スライドの本文・講師ノート (`<!-- ノート: ... -->`)・`doc.md` の該当節です。講師ノートは「読み上げメモ」で、そのまま読める文とは限りません。**演出の指示 (「つかみ。」「強調する」「押さえる」「実演する」) は読まず、その意図を語りに変えて**ください
- 秒数は書きません。時刻は読み上げ音声の長さから自動で決まります

## ファイルの形

```json
{
  "schema": 1,
  "slidesHash": "…",
  "slides": [
    { "cues": [{ "text": "字幕 (= 読み上げ)" }, { "text": "…", "speech": "読みを変えたいときだけ" }] }
  ]
}
```

- `slides` はスライドと同じ枚数・同じ順番です
- `text` は画面に出る字幕で、そのまま読み上げの元になります
- `speech` は、読み辞書 (`narration/readings.json`) で足りないときだけ書く読み上げ用の文です。括弧の言い換え・一回きりの読み・数字の読み方を直すのに使います。`speech` にも読み辞書は当たるので、辞書にある語はそのまま書いてかまいません
- `slidesHash` は `narrate` が入れます。スライドやノートを直すと合わなくなり、`content:check` が落ちます (台本を見直す合図です)

## 字幕 1 つのルール

- **1 字幕 = 1 文、60 字以内**。です・ます調 (STYLE_GUIDE と同じ)
- 改行・Markdown 記法 (`**` やバッククォート) を書かない
- **括弧を使わない**。話し言葉に括弧はありません。「ブラウザ(クライアント)」は「ブラウザ、つまりクライアントです」のように言い直します。takeaway に括弧があって字幕にそのまま出すとき (結論・まとめ) だけは、字幕は括弧込みのまま、`speech` で「ハードウェア、つまり機械の部分を」のように言い換えます
- 書き言葉の記号 (「/」「…」「→」) は使わず、言葉にします

## 長さ

- トピック全体で **600〜900 字** (読み上げて約 2〜3 分)。検査は推定 90〜200 秒から外れると警告します
- 1 スライドに 1〜5 字幕。タイトルスライドは 1〜2 字幕で短く

## スライドの型ごとの話し方

STYLE_GUIDE のスライドの流れに合わせます。

| スライド | 話すこと |
| --- | --- |
| タイトル (`_class: lead`) | このトピックで何を学ぶかを 1〜2 文で。前のトピックとのつながりに触れてよい |
| なぜ必要か | 実務の「あるある」を具体的に。**ここで結論を言わない** |
| 結論 | **`takeaway` をそのまま言う** (字幕を連結したときに takeaway が含まれること)。そのあと、スライドにある用語の定義を話し言葉で補う |
| 最小のコード | コードを記号ごとに読み上げない。**何をしているかを言葉で**説明する (「1 行目で在庫数を 10 にして、2 行目で 8 に入れ直しています」)。エラーはその意味を日本語で言う |
| 図解・対比・表 | 画面の図や表を、見るべき順に案内する (「左の列が〜、右の列が〜」)。全部の行を読み上げなくてよい |
| まとめ (`_class: summary`) | takeaway を言い直すだけ。新情報を足さない |

## 言ってはいけないこと

- **次トピックのタイトル・ID** (順序の入れ替えや単体公開で嘘になるため。STYLE_GUIDE と同じ)。「次は、〜という疑問に答えます」のように問いを残して締めるのはよい
- 「この講座の最後です」のような、講座の中の位置 (構成が変わると嘘になる)
- スライド・ノート・`doc.md` の該当節に**無い数字** (検査が落とします)
- そのトピックまでに導入されていない専門用語 (入力に「これまでに導入済みの語」が渡されます)
- 原典名やクレジット (CLAUDE.md の「クレジット表記を教材本体に入れない」と同じ)
- 静止画の動画で成り立たない指示 (「いま打ち込んでみます」「ここをクリックします」)。「画面のコードでは〜」「表の 2 行目を見てください」のように言い換える

## 読み

- 英単語・略語・読み違えやすい用語は、まず**読み辞書** (`narration/readings.json`、講座ごとの `courses/<slug>/narration-readings.json`) に足します。辞書は全台本に効き、TTS を替えても使えます
- 辞書で表せない一回きりの読みだけ `speech` に書きます
- 数字の読みが自然でないとき (「0.1」を「れいてんいち」と読ませたい等) は `speech` で直します

## 検査

```bash
bun run --filter=@stella/content narration:check            # 台本のある全トピック
bun run --filter=@stella/content narration:check -- courses/it-basics
```

| 検査 | 失敗の扱い |
| --- | --- |
| 枚数がスライドと一致 / `slidesHash` が今のスライドと一致 | エラー |
| 字幕が 1〜60 字・改行や Markdown 記法なし | エラー |
| 読み上げ文にコード記号・括弧が残らない | エラー |
| 数字がスライド・ノート・doc.md の該当節にある | エラー |
| 結論スライドの字幕が takeaway を含む / 次トピックのタイトルを言わない | エラー |
| 推定長が 90〜200 秒 | 範囲外は警告 (300 秒超はエラー) |
| 読み辞書に無い英字 | 警告 |

# レッスン0-1 保存して表示を確かめる

## このレッスンの目標

- [ ] HTMLファイルを保存できます。
- [ ] ブラウザーで保存した変更を確認できます。

## 0-1-1 保存したファイルを表示する

> **ブラウザーには保存したHTMLの内容が表示されます。**

HTMLは、ページの構造を書くための言語です。エディターでファイルを編集したら保存します。ブラウザーでファイルを開き、変更した内容を確認します。

表示が変わらないときは、保存したかを確認します。次にブラウザーを再読み込みします。実務でも、編集した画面を確認するために使う手順です。

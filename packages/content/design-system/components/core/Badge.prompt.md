**Badge** — small status / category chip, always pill-shaped.

```jsx
<Badge tone="accent">DX支援</Badge>
<Badge variant="gradient">NEW</Badge>
<Badge variant="solid" tone="success">導入済み</Badge>
<Badge variant="outline" tone="ink">PM型エンジニア</Badge>
```

`variant`: soft (default tint) · solid · gradient (signature) · outline. `tone`: accent · ink · success · warning · danger. Use `gradient` sparingly — one per view.

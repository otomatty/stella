**Stat** — the signature results metric. Huge gradient numeral + small red unit + caption.

```jsx
<Stat value="300+" label="導入企業数" />
<Stat value="94" unit="点" label="顧客満足度" />
<Stat value="2.5" unit="倍" label="開発速度" size="xl" />
```

Lay several in a row for a results band. `size`: md · lg (default) · xl. Keep the numeral short; long numbers lose the gradient impact.

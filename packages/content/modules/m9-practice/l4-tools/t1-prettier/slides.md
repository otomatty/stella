## なぜ必要か

- インデント、クォート、改行位置。人によって書き方が違う
- レビューで書式の指摘が並ぶと、本題の議論に時間を割けない

<!-- ノート: つかみ。実務のレビューで「ここはスペース2つで」といった指摘が続くのは、双方にとって不毛。機械に任せられる仕事は任せる。 -->

---

## 結論

**Prettierはコードの見た目を自動で揃える。書式の議論をなくす道具**

- フォーマッター = コードの見た目を整える道具
- 中身(動き)は一切変えない

<!-- ノート: 結論を先に言い切る。フォーマッターを定義する。「見た目だけ」という点が重要で、動作は変わらないので安心して実行できる。 -->

---

## 実行してみる

```bash
npm install --save-dev prettier
npx prettier --write src
```

- `--write` で実際にファイルを書き換える

<!-- ノート: 9-2-3で学んだnpm installで導入する。開発中だけ必要なので --save-dev。--write を付けないと確認だけで書き換わらない。 -->

---

## なぜ必要か

- 1ファイルに全部書くと、すぐに何千行にもなる
- 分けたいが、分けると互いの関数が見えなくなる

<!-- ノート: つかみ。2-1-1で学んだスコープと同じ話が、ファイル単位で起きる。分けるだけでは使えないので、行き来する仕組みが要る。 -->

---

## 結論

**`export`で公開し、`import`で取り込む。書かなければファイルの外から見えない**

- モジュール = `export`を持つファイル1つのこと

<!-- ノート: 結論を先に言い切る。モジュールを定義する。既定は非公開で、公開したいものだけexportを付ける。7-2-1のprivateと同じ「狭くしておく」考え方。 -->

---

## 最小のコード

```ts
// tax.ts
export const calcTax = (price: number): number => price * 0.1;

const RATE = 0.1; // exportしていないので外から見えない
```

```ts
// main.ts
import { calcTax } from "./tax";

console.log(calcTax(1000)); // => 100
```

<!-- ノート: exportは宣言の前に付けるだけ。importは波かっこで名前を指定し、fromの後ろにファイルのパスを書く。拡張子の.tsは書かない点に注意。型エイリアスもexportできる。 -->

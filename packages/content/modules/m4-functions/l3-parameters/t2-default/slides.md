# 4-3-2
# デフォルト引数

TypeScript入門研修 — Module 4 / レッスン4-3

<!-- ノート: 前のトピックで、省略できる引数は使うたびにundefinedの確認が要ることを見ました。それが不要になる書き方です。 -->

---

## なぜ必要か

- 「消費税率は普通10%だが、たまに8%」のような既定値がある
- オプション引数だと、使うたびに`undefined`を確認することになる

<!-- ノート: つかみ。4-3-1の不満をそのまま引き継ぐ。値がないことを扱いたいのではなく、既定値を入れたいだけなら、もっと素直な書き方がある。 -->

---

## 結論

**引数に`= 値`を書いておくと、省略時にその値が使われる**

- 省略されても`undefined`にならない
- だから使うときの絞り込みが要らない

<!-- ノート: 結論を先に言い切る。2-3-3の ?? と目的は同じだが、関数の入口で解決してしまう点が違う。中の処理がシンプルになる。 -->

---

## 最小のコード

```ts
const calcTax = (price: number, rate: number = 0.1): number => {
  return price * rate;
};

console.log(calcTax(1000)); // => 100
console.log(calcTax(1000, 0.08)); // => 80
```

- `rate`の型は`number`。`undefined`は入らない

<!-- ノート: 省略した1行目は0.1が使われ、指定した2行目は0.08が使われる。関数の中でrateをそのまま掛け算に使えている点が、4-3-1との違い。 -->

---

## 型注釈は省略できる

```ts
const calcTax = (price: number, rate = 0.1): number => {
  return price * rate;
};
```

- 既定値`0.1`から`number`と推論される

<!-- ノート: 対比枠。4-1-2で「引数には必ず型注釈」と決めたが、既定値があれば推論が効くので例外になる。1-2-5の「推論できるなら任せる」に立ち返ると一貫している。オプション引数と同じく、最後に置くのが原則。 -->

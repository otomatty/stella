# 4-1-2
# 関数宣言と引数の型注釈

TypeScript入門研修 — Module 4 / レッスン4-1

<!-- ノート: 関数の書き方に入ります。ここで、レッスン1-2で決めた「推論に任せる」という方針に例外が1つ現れます。 -->

---

## なぜ必要か

- レッスン1-2で「初期値があれば推論に任せる」と決めた
- 引数には初期値がない。では型はどこから来るのか

<!-- ノート: つかみ。既習の方針と突き合わせる形で入ると、なぜここだけ違うのかが腹落ちする。1-2-5の「書くのは推論できないときだけ」がそのまま当てはまる場面。 -->

---

## 結論

**引数には必ず型注釈を書く。ここだけは推論に任せられない**

```
function 関数名(引数: 型): 戻り値の型 {
  処理
}
```

<!-- ノート: 結論を先に言い切る。この書き方を関数宣言と呼ぶ。引数のかっこの中に「名前: 型」を書き、かっこの外のコロンの後ろに戻り値の型を書く。戻り値の型は推論できるので省略可能だが、本研修では書く方針にすると伝える。 -->

---

## 最小のコード

```ts
function calcTax(price: number): number {
  return price * 0.1;
}

console.log(calcTax(1000)); // => 100
```

- 引数が2つ以上ならカンマで区切る

<!-- ノート: priceが引数で、型注釈がnumber。かっこの後ろの : number が戻り値の型。3-4-4で書いた税額の計算が、これで1か所にまとまる。 -->

---

## 書かないと何が起きるか

```ts
function calcTax(price) {
  return price * 0.1;
}
// エラー: Parameter 'price' implicitly has an 'any' type.
```

- 型が分からないまま何でも受け取ってしまう

<!-- ノート: 対比枠。implicitlyは「暗黙のうちに」、anyは「何でも」の意味。この状態だと文字列を渡しても止めてくれない。anyそのものはModule 5で扱うので、いまは「書き忘れるとチェックが効かなくなる」と理解すれば十分。 -->

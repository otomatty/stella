## 結論

**`filter`は、条件に合う要素だけを残した新しい配列を作る**

- コールバックは`boolean`を返す
- `true`を返した要素だけが残る

<!-- ノート: 結論を先に言い切る。mapとの違いは「コールバックが何を返すか」。mapは変換後の値、filterは残すかどうかの判定。ここを取り違えると結果がまるで変わる。 -->

---

## 最小のコード

```ts
const prices = [3000, 8000, 1200, 12000];

const expensive = prices.filter((price) => price >= 5000);

console.log(expensive); // => [8000, 12000]
console.log(prices); // => [3000, 8000, 1200, 12000]
```

<!-- ノート: コールバックの中身は 2-2-1 で学んだ比較演算子そのもので、結果はboolean。trueになった8000と12000だけが残る。mapと同じく元の配列は変わらない。 -->

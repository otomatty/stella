## なぜ必要か

- 実務のコードで最も多いのがこの書き方
- 後のレッスンで関数を引数に渡すとき、短さが効いてくる

<!-- ノート: つかみ。4-5のコールバックで、関数をその場で書いて渡す場面が来る。そのとき function と書くと長すぎる。だから短い記法が生まれた、という順序で説明すると納得しやすい。 -->

---

## 結論

**アロー関数は「引数 => 処理」と書く、関数式の短い書き方**

```
const 名前 = (引数: 型): 戻り値の型 => {
  処理
};
```

<!-- ノート: 結論を先に言い切る。矢印(arrow)に見えることからアロー関数。functionという単語が消えて、代わりに矢印が入る。等号と大なりで書く。 -->

---

## 最小のコード

```ts
const calcTax = (price: number): number => {
  return price * 0.1;
};

console.log(calcTax(1000)); // => 100
```

- 4-2-1の関数式と、まったく同じ動き

<!-- ノート: 前のトピックのコードと並べて、functionが矢印に置き換わっただけであることを確認する。引数のかっこ、型注釈、中かっこの位置はすべて同じ。 -->

---

## さらに短くできる: 中かっこと return を省く

```ts
const calcTax = (price: number): number => price * 0.1;
```

- 処理が式1つだけなら、中かっこと`return`を省略できる
- 省略すると、その式の結果が自動で返る

<!-- ノート: 対比枠。省略記法は実務で多用されるので読めるようにしておく。ただし複数行の処理があるときは省略できない。オブジェクトを返すときはかっこで囲む必要があるが、そこは必要になったときで十分。 -->

# 7-2-4
# static

TypeScript入門研修 — Module 7 / レッスン7-2

<!-- ノート: これまで何度か使ってきた Math.round の正体が、ここで明らかになります。 -->

---

## なぜ必要か

- 消費税率のように、個々の商品ではなくクラス全体で1つの値がある
- 「四捨五入する」のような処理に、インスタンスは要らない

<!-- ノート: つかみ。1-3-3や7-1-4で使った Math.round は、new Math() をしていない。なぜ動いていたのかという疑問を拾う。 -->

---

## 結論

**`static`を付けると、インスタンスを作らずクラス名から直接使える**

- インスタンスごとではなく、クラスに1つだけ存在する

<!-- ノート: 結論を先に言い切る。staticは「静的な」の意味。設計図そのものに付いている値や処理、というイメージ。Math.roundはまさにこれ。 -->

---

## 最小のコード

```ts
class Tax {
  static readonly RATE = 0.1;

  static calc(price: number): number {
    return Math.round(price * Tax.RATE);
  }
}

console.log(Tax.RATE); // => 0.1
console.log(Tax.calc(1000)); // => 100
```

- `new`は不要。クラス名にドットで直接アクセスする

<!-- ノート: 定数は大文字で書く慣習も紹介する。staticなメソッドの中ではthisが使えない(インスタンスが存在しないため)ので、クラス名で参照している点を指す。 -->

---

## 使いどころは限られる

- クラス全体で共有する定数
- インスタンスの状態を使わない補助的な処理

<!-- ノート: 対比枠。何でもstaticにすると、クラスがただの関数置き場になってしまう。インスタンスのデータを使う処理は通常のメソッドにする。迷ったら通常のメソッドから始めるのが安全。 -->

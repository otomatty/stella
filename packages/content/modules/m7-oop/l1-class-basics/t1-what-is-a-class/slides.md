## 結論

**クラスはデータと処理をまとめた設計図。`new`で実物を作る**

- クラス = 設計図
- インスタンス = 設計図から作られた実物
- `new` = 実物を作る命令

<!-- ノート: 結論を先に言い切る。3語を定義する。5-4-1で使った new Error も、Errorクラスからインスタンスを作っていた。あのときの「決まり文句」の正体がこれ。 -->

---

## 最小のコード

```ts
class Product {
  name = "";
  price = 0;
}

const item = new Product();
console.log(item.name); // => ""
```

- `item`がインスタンス。プロパティの読み書きはオブジェクトと同じ

<!-- ノート: classというキーワードで定義し、newで作る。作ったあとの扱いは3-3-2で学んだドット記法そのもの。クラス名は大文字始まりにするのが慣習。 -->

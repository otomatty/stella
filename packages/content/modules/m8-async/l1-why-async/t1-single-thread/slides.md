# JavaScriptはシングルスレッド

TypeScript入門研修 — Module 8 / レッスン8-1

<!-- ノート: Module 8は非同期処理です。ここまでの道具がすべて揃ったので、実務のコードがそのまま読めるようになります。まずは前提となる仕組みから。 -->

---

## なぜ必要か

- 通信やファイル読み込みは、結果が返るまで時間がかかる
- 待っている間に画面が固まると、使い物にならない

<!-- ノート: つかみ。ボタンを押してから数秒間、画面がまったく反応しないアプリを想像してもらう。なぜそうなるのか、どう避けるのかがこのモジュールのテーマ。 -->

---

## 結論

**JavaScriptは一度に1つの処理しかできない。だから待つと全部止まる**

- シングルスレッド = 処理の担当者が1人だけ
- 同期処理 = 上から順に、1つずつ終わらせていく実行の仕方

<!-- ノート: 結論を先に言い切る。2語を定義する。ワンオペのカフェのたとえが分かりやすい。店員が1人しかいないので、豆を挽いている間は注文も受けられない。 -->

---

## 最小のコード

```ts
const heavy = (): void => {
  // 3秒かかる処理だと思ってください
};

console.log("A");
heavy();
console.log("B"); // heavyが終わるまで表示されない
```

- ここまで書いてきたコードは、すべて同期処理

<!-- ノート: Module 7までのコードは全部これ。上から順に、1つ終わってから次へ。単純で分かりやすいが、時間のかかる処理が混ざると全体が止まる。 -->

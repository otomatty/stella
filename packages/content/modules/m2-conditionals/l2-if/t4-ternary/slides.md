# 三項演算子

TypeScript入門研修 — Module 2 / レッスン2-2

<!-- ノート: レッスン2-2の最後です。ifと似ていますが、用途がはっきり違う道具を1つ覚えます。 -->

---

## なぜ必要か

- 「会員なら割引価格、そうでなければ通常価格」を変数に入れたい
- `if`で書くと`let`にせざるを得ず、`const`が使えない

<!-- ノート: つかみ。1-1-3で「まずconst」と決めたのに、分岐が入ると崩れてしまう。その悩みを解決する道具だと位置づけると、必要性が腹落ちする。 -->

---

## 結論

**三項演算子は、条件によって「値を選ぶ」ときに使う**

```
条件 ? trueのときの値 : falseのときの値
```

<!-- ノート: 結論を先に言い切る。クエスチョンマークとコロンで3つの部分に分かれるので三項演算子。ifが「処理を分ける」のに対し、こちらは「値を選ぶ」。この違いが使い分けのすべて。 -->

---

## 最小のコード

```ts
const isMember = true;

const price = isMember ? 400 : 500;
console.log(price); // => 400
```

- `const`のまま書ける。これが`if`との最大の違い

<!-- ノート: if文で同じことを書くとletにする必要がある。const のまま書けることを強調する。読み方は「isMemberなら400、そうでなければ500」と日本語に置き換えて音読すると覚えやすい。 -->

---

## 使い分け: 処理を分けるか、値を選ぶか

```ts
// 値を選ぶ → 三項演算子
const label = isMember ? "会員価格" : "通常価格";

// 処理を分ける → if
if (isMember) {
  console.log("会員向けクーポンを表示");
}
```

<!-- ノート: 対比枠。三項演算子を入れ子にすると一気に読めなくなるので、2択までにとどめる、というルールも添える。3択以上ならif elseかswitchを使う。 -->

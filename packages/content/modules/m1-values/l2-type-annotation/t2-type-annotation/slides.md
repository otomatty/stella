# 型注釈の書き方

TypeScript入門研修 — Module 1 / レッスン1-2

<!-- ノート: 前のトピックで型が「値の種類」だとわかりました。ここでは、その型をコードに書き表す構文を1つだけ覚えます。 -->

---

## なぜ必要か

- 型を頭の中で意識するだけでは、コンパイラーは助けてくれない
- コードに書いて初めて、機械がチェックできるようになる

<!-- ノート: つかみ。「わかっているつもり」を機械可読な形に落とすのが型注釈。書けば書いた分だけチェックが効く、というシンプルな取引だと伝える。 -->

---

## 結論

**型注釈は、変数名のうしろにコロンと型名を書く**

```
const 変数名: 型 = 値;
```

<!-- ノート: 結論を先に言い切る。変数名が先、型が後という語順を強調する(JavaやC言語とは逆なので、経験者ほど間違えやすい)。注釈は「ちゅうしゃく」と読む。 -->

---

## 最小のコード

```ts
const price: number = 300;
const productName: string = "コーヒー";
```

- コロンの右が型、イコールの右が値

<!-- ノート: コロンとイコールの役割の違いを指しながら説明する。コロンの右は「型の名前」であって値ではない、という点が最初のつまずきポイント。 -->

---

## よくある間違い: 値と型を取り違える

```ts
const price: 300 = number;
// エラー: Cannot find name 'number'.
```

- 左右を逆にすると、型名が値として扱われてしまう

<!-- ノート: 対比枠。エラーメッセージは「numberという名前が見つかりません」。型の名前を値の位置に書いたせいだと読み解く練習をする。慣れるまでは「コロンの右が型」と口に出して確認するとよい。 -->

# boolean型

TypeScript入門研修 — Module 1 / レッスン1-3

<!-- ノート: 数値を見たので、次は真偽値です。地味に見えますが、条件分岐で主役になる型です。 -->

---

## なぜ必要か

- 業務システムは「支払い済みか」「キャンセル済みか」のフラグだらけ
- この型が読めないと、実務のコードはほとんど読めない

<!-- ノート: つかみ。フラグという言葉は現場で日常的に使われるので、ここで「真偽値の変数のこと」と紐づけておく。 -->

---

## 結論

**boolean型に入る値はtrueとfalseの2つだけ**

- 真偽値 = 「はい / いいえ」を表す値

<!-- ノート: 結論を先に言い切る。取りうる値がたった2つしかない、という単純さがこの型の価値。だから条件分岐の判定にそのまま使える。 -->

---

## 最小のコード

```ts
const isPaid = true; // boolean
const isCancelled = false; // boolean
console.log(isPaid); // => true
```

- 変数名を`is○○`にすると、真偽値だと一目でわかる

<!-- ノート: isで始める命名は現場の慣習。読み手が型を推測しやすくなる。命名だけで情報を伝えられる、という設計の考え方の入口でもある。 -->

---

## よくある間違い: クォートを付けてしまう

```ts
const isPaid: boolean = "true";
// エラー: Type 'string' is not assignable to type 'boolean'.
```

- クォートで囲むと、ただの文字列になってしまう

<!-- ノート: 対比枠。trueとfalseはクォートを付けない、と強調する。1-2-3で練習したエラーメッセージの読み方がそのまま使えることも確認する。 -->

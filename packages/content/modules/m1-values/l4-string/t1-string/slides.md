# string型とクォート

TypeScript入門研修 — Module 1 / レッスン1-4

<!-- ノート: レッスン1-4は文字列だけを扱います。業務データの多くは文字列なので、1レッスンかける価値があります。まずは書き方から。 -->

---

## なぜ必要か

- 記事によって`"`だったり`'`だったり`` ` ``だったりする
- 違いがわからないと、コピーしたコードを直せない

<!-- ノート: つかみ。学習中に必ず混乱するポイント。3種類あることと、その使い分けをここで一度で片付ける。 -->

---

## 結論

**文字列はクォートで囲む。研修ではダブルクォートを基本にする**

- `"` ダブルクォート — 本研修の基本
- `'` シングルクォート — 意味は同じ
- `` ` `` バッククォート — 特別な機能つき(次のトピック)

<!-- ノート: 結論を先に言い切る。クォートは「引用符」のこと。3種類どれで囲んでもstring型になる点をまず押さえる。バッククォートだけは追加機能があると引きを作る。 -->

---

## 最小のコード

```ts
const userName = "田中"; // string
const message = 'こんにちは'; // これもstring
console.log(userName); // => "田中"
```

- どれで囲んでも型は同じ`string`

<!-- ノート: 本研修でダブルクォートを基本にするのは、後のレッスンで学ぶPrettierという自動整形ツールの慣習に合わせるため。理由があってのルールだと伝えておく。 -->

---

## よくある間違い: クォートの付け忘れ

```ts
const userName: string = 田中;
// エラー: Cannot find name '田中'.
```

- クォートがないと「田中という名前の変数を探しに行く」

<!-- ノート: 対比枠。エラーメッセージが「型が違う」ではなく「名前が見つからない」になる理由を説明する。クォートの有無で、値なのか変数名なのかが決まる。 -->

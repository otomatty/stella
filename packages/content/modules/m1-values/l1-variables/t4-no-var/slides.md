# 1-1-4
# varを使わない理由

TypeScript入門研修 — Module 1 / レッスン1-1

<!-- ノート: 変数の宣言キーワードには、実はもう1つvarというものがあります。古い記事やAIの出力で見かけるので、扱い方だけ決めておきます。 -->

---

## なぜ必要か

- ネットの記事やAIの出力に`var`が混ざっていることがある
- 「見たことがない書き方」で手が止まらないようにしておきたい

<!-- ノート: つかみ。学習中に必ず遭遇するので、遭遇したときの態度を先に決めておく。知らない記法で止まるのがいちばんもったいない。 -->

---

## 結論

**varは読めればよい。新しいコードではconstとletだけを使う**

- `var`は昔の宣言キーワード
- 同じ名前で二度宣言できてしまうなど、事故を招く性質がある

<!-- ノート: 結論を先に言い切る。varが「悪い」のではなく、後から出たconstとletのほうが安全に作られている、という順序で説明すると納得しやすい。 -->

---

## 最小のコード

```ts
var price = 300;
var price = 500; // 二度宣言してもエラーにならない

let stock = 10;
let stock = 20;
// エラー: Cannot redeclare block-scoped variable 'stock'.
```

<!-- ノート: varは同じ名前の二度宣言を許してしまう。長いファイルで同名の変数を作ってしまい、前の値が消える事故につながる。letなら実行前にエラーで止めてくれる、という対比で見せる。 -->

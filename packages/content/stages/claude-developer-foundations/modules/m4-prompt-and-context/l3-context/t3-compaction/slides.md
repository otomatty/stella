# 長い会話を縮める

---
# 先頭から消した
会話が長くなったので、古いやり取りを先頭から消しました。最初に決めた条件を、Claude が忘れてしまいました。
<!-- ノート: 消したやり取りに、あとで要る情報が入っていました。 -->
---
# 要約に置き換える
長い会話は、圧縮で古いやり取りを要約に置き換えて続けます。
<!-- ノート: 圧縮では、Claude がサーバー側で要約を書くので、自分で要約の処理を書かなくて済みます。 -->
---
# 2 つの始め方
- 自分で頼む: アプリが決めたときに要約を作らせる
- しきい値で始める: 入力が決めた量に届くと API が要約する
<!-- ノート: どちらもベータの機能です。公式ドキュメントは、使える環境では自分で頼むほうを勧めています。 -->
---
# 決まりで消す方法も
古いツールの結果や考える過程は、コンテキストの編集で、決まりに従って消せます。
<!-- ノート: 要約せずに消してよいものは、こちらで減らします。 -->
---

# レッスン4-1 プロンプトの書き方

## このレッスンの目標

- [ ] 理由と出力の条件を添えた、具体的な指示を書けます。
- [ ] 例と XML のタグで、出力の形と中身の区切りを伝えられます。
- [ ] 長い資料を渡すときの並べ方を選べます。

## 4-1-1 具体的に頼む

> **やってほしいことは、理由を添えて具体的に書きます。**

プロンプトは、Claude に渡す指示と情報の全体です(system と messages の両方を含みます)。公式ドキュメントは、Claude を「優秀だが、職場の決まりや進め方をまだ知らない新しい同僚」と考えるように勧めています。やってほしいことを正確に説明するほど、結果はよくなります。

- 出力の形や条件(長さ・含めるもの・含めないもの)を具体的に書きます。
- 順番や漏れのなさが大事な手順は、番号付きの箇条書きで書きます。
- 最低限より多くを望むなら、あいまいな頼み方で察してもらおうとせず、はっきり頼みます。

指示には理由を添えます。理由が分かると、Claude は書かれていない場面にも広げて当てはめます。

| 弱い指示 | 強い指示 |
| --- | --- |
| 「…」を使わないで | 返答は音声で読み上げるので、読み方の分からない「…」は使わないで |

書いたプロンプトは、事情を知らない同僚に見せて、そのとおりに作業できるかを確かめます。同僚が迷うなら、Claude も迷います。

## 4-1-2 例で形を伝える

> **期待する出力の形は、実際の用途に近く種類の違う例を 3〜5 個示します。**

例は、出力の形・調子・構成を伝える最も確かな方法の 1 つです。いくつかの例を示すやり方を few-shot(multishot)と呼びます。例は次の条件を満たすようにします。

- **実際の用途に近い**: 本番の入力と出力に似せる
- **種類が違う**: 例外的な場合も含め、意図しない癖を真似されないようにばらつかせる
- **区別できる**: `<example>` のタグで包み(複数なら `<examples>` の中に並べる)、指示と区別する

公式ドキュメントは、3〜5 個の例を勧めています。例外の規則を思いつく限り並べるより、期待する動きをよく表す、種類の違う代表的な例を選びます。

## 4-1-3 タグで区切る

> **指示・資料・例は、それぞれ XML のタグで包んで区切ります。**

指示・背景・例・入力のように種類の違う中身が混ざったプロンプトは、それぞれを XML のタグで包むと、取り違えが減ります。

```js
const prompt = `<documents>
<document index="1">
${manual}
</document>
</documents>

<instructions>
手引きだけを根拠に答えてください。
</instructions>`;
```

- タグの名前は中身が分かるものにし、プロンプトの間でそろえます(`<instructions>`・`<context>`・`<input>` など)。
- 中身に階層があるときは入れ子にします(`<documents>` の中に、番号を付けた `<document index="n">` を並べる)。

タグは、出力の形を伝えるのにも使えます。「答えは `<answer>` のタグの中に書いてください」と頼めば、アプリはタグの中だけを取り出せます。

## 4-1-4 長い資料は先に置く

> **長い資料はプロンプトの先頭に置き、質問は最後に書きます。**

2 万トークンを超えるような長い資料を渡すときは、資料をプロンプトの先頭に置き、質問・指示・例はそのあとに書きます。公式ドキュメントによると、質問を最後に置くと、複雑な資料を複数渡す場合に、答えの質が最大で 3 割ほど上がりました。

資料が複数あるときは、1 つずつ `<document>` で包み、出どころを `<source>`、本文を `<document_content>` に分けます。

```xml
<documents>
  <document index="1">
    <source>就業規則.pdf</source>
    <document_content>(本文)</document_content>
  </document>
</documents>

交通費の申請の締め切りを答えてください。
```

長い資料から答えるときは、先に関係する箇所を `<quotes>` のタグに引用させ、その引用をもとに答えさせる方法もあります。関係のない部分に引きずられにくくなります。

この並べ方(変わらない資料が前、変わる質問が後ろ)は、プロンプトキャッシュが効く並べ方とも同じです。

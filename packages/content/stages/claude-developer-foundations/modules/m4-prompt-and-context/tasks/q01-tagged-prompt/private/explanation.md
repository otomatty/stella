# 解説

指示・資料・例・質問のように種類の違う中身を 1 つのプロンプトに並べるときは、それぞれを XML のタグで包むと、Claude が中身を取り違えにくくなります。資料に「次の手順で申請してください」のような文があっても、`<document_content>` の中にあれば資料の一部として読めます。

長い資料は、プロンプトの先頭に置き、質問を最後に書きます。資料ごとに `<document index="n">` で包み、出どころを `<source>`、本文を `<document_content>` に分けると、答えの中で「どの資料の話か」を示させやすくなります。例は `<examples>` の中に `<example>` を並べて、指示と区別します。

タグは出力にも使えます。「答えを `<answer>` のタグの中に書いて」と頼めば、前置きや後書きが混ざっても、アプリはタグの中だけを取り出せます。タグがない応答は `null` として扱い、指示に従わなかった応答として別に処理します。

# 何から勉強するか迷う
解説記事ごとに、範囲や配点の書き方が違います。
どれを信じるかで迷います。

# 試験ガイドが正本
出題の範囲と配点は、Partner Academy の試験ガイドで確かめます。
<!-- ノート: 配点は、範囲ごとの出題の割合です。 -->

# 時間の配り方
1. 試験ガイドで、範囲ごとの配点を確かめる
2. 配点をもとに、各領域の学習時間を仮に決める
3. 診断で判断を間違えた領域に、復習の時間を足す
<!-- ノート: Partner Academy には、資格ごとの準備の講座もあります。 -->

# 復習する単元を決める

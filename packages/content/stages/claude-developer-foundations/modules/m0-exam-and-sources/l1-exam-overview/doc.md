# レッスン0-1 試験の全体像

## このレッスンの目標

- [ ] Developer: Foundations が扱う範囲を言えます。
- [ ] 問題数と制限時間をもとに、解答のペースを決められます。
- [ ] 場面に示された原因と条件から、誤りの選択肢を外せます。

## 0-1-1 Developer 資格が測るもの

> **Developer: Foundations は、Claude でアプリを作るエンジニアの資格です。**

Claude の認定試験は、担当する仕事と水準で対象が分かれています。このステージが扱うのは Claude Certified Developer: Foundations です。公式の発表は、Claude でアプリを作るエンジニア向けの資格で、Claude API・ツール使用・エージェント開発の訓練を含むと説明しています。

Claude API は、アプリから Claude を呼び出すための仕組みです。ツール使用は、Claude がアプリの処理(検索や計算など)を呼び出せるようにする仕組みです。エージェントは、手順を自分で考えながら作業を進める仕組みです。

たとえば、ほかの資格には次の対象があります。Associate: Foundations は Claude を使う案件に関わる人全般、Architect: Foundations はエージェントの仕組みを設計する人、Architect: Professional は大きな組織向けの上級の資格です。実務で API を使ってアプリを作る人は、Developer: Foundations から始めます。

## 0-1-4 場面を読んで選ぶ試験

> **本番は、実務の場面を読んで対応を選ぶ問題を、120 分で 70 問解きます。**

資格コードは CCDV-F です。ここでは、2026 年 12 月 7 日からの試験形式を扱います。選択問題では、何が起きたか、どんな条件があるかを読み、候補から対応を選びます。選ぶ数は問題ごとに示されます。「2 つ選ぶ」とあれば、両方が場面の条件に合うかを確かめます。

| 確かめること | 練習での使い方 |
| --- | --- |
| 120 分で 70 問 | 1 問あたり約 100 秒を目安に、場面を読んで答える |
| 採点される 60 問と、採点されない 10 問 | 本番中は区別できないので、全問に答える |
| 英語と日本語。翻訳の道具や資料、メモは使えない | 選んだ対応が仕様に合う理由を、資料を閉じて説明する |

結果には、合否、換算スコア、分野ごとの正答率が出ます。換算スコアは、得点を 100〜1,000 の尺度で表した値です。合計の換算スコアが 720 以上なら合格です。たとえば、換算スコアの 720 から正答率 72% とは読み取れません。分野ごとの正答率は、次に復習する分野を決めるのに使います。

## 0-1-5 誤りの選択肢を見分ける

> **誤りの選択肢の多くは、症状を減らすだけか、原因から離れた場所を直します。**

雨の日、窓の下の床がぬれます。水は窓の傷んだ部品のすき間から入ります。窓はこれまでどおり開け閉めできるようにします。床を何度拭いても水は入り、窓をふさぐと開け閉めできません。窓の手入れの手順に沿って傷んだ部品を替えれば、水が入る原因に対処できます。

選択肢を読む前に、起きたこと、記録から分かる原因、守る条件を拾います。次の表のように、効きそうな対応でも、同じ条件で起きるか、残す機能が使えるかを考えます。

| 対応の例 | 確かめること |
| --- | --- |
| ぬれた床を拭く回数を増やす | 見えている症状だけを減らしていないか |
| 水が入る窓を開かないようにふさぐ | 必要な機能を捨てていないか |
| 入力欄が空だと毎回止まるのに、同じ内容で送り直す | 送り直しても、止まる条件が残っていないか |
| 鍵の番号が違うまま、入力できる時間を延ばす | 設定を変える前に、使える条件がそろっているか |
| 速く印刷するため、図の細い線が消える設定に替える | 速さと引き換えに、必要な品質が落ちていないか |
| 窓の部品を替える代わりに、部屋の入口に注意書きを足す | 対応する場所は、分かった原因に合っているか |

最後に、原因がある場所で、文書に書かれた仕様や手順に沿って直せるかを見ます。練習では、選んだ理由に加えて、迷った選択肢がどの条件に合わなかったかを一文で説明します。

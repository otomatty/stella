# どの資格を受けるか
Claude の認定試験は4つあります。
役割ごとに、問われる力が違います。
<!-- ノート: 自分の仕事に合う資格を選ぶところから始めます。 -->

# アプリを作る人の資格
Developer: Foundations は、Claude でアプリを作るエンジニアの資格です。
<!-- ノート: 公式の発表は、アプリを作るエンジニア向けの資格だと説明しています。 -->
---
# 扱う3つの柱
- Claude API で Claude を呼び出す
- ツール使用で、アプリの処理とつなぐ
- エージェントに、手順のある作業を任せる
<!-- ノート: 公式の発表では、Claude API・ツール使用・エージェント開発の訓練を含むとされています。 -->
---
# ほかの3つの資格
- Associate: Foundations は、Claude を使う案件に関わる人全般
- Architect: Foundations は、エージェントの仕組みを設計する人
- Architect: Professional は、大きな組織向けの上級
<!-- ノート: 設計を担う人は Architect、業務で使う人は Associate が対象です。 -->
---

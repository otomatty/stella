# 誤りの選択肢を見分ける

---
# 雨の日に床がぬれる
いつも窓の下からぬれ始めます。窓のすき間から水が入るのを確かめました。窓は今までどおり開け閉めできるようにします。
<!-- ノート: 問題の場面には、見えている症状、分かった原因、残す機能があります。 -->
---
# 原因のある場所に戻る
誤りの選択肢の多くは、症状を減らすだけか、原因から離れた場所を直します。
<!-- ノート: 窓の手入れの手順を読み、すき間を作っている部品を直せるか考えます。 -->
---
# 対応を条件と照らす
| 対応 | 確かめること |
| --- | --- |
| 床を拭く回数を増やす | 床は乾いても、雨はまた入る |
| 入口に注意書きを足す | 窓のすき間は残る |
| 窓を開かないようにふさぐ | 開け閉めする機能が失われる |
| 手順どおりに窓の傷んだ部品を交換する | 水が入る場所を直し、開け閉めを保てる |
<!-- ノート: その対応をしたあと、同じ条件で症状が起きるか、要る機能が残るかを考えます。 -->
---

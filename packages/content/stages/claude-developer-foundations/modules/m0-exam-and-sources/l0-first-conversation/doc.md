# レッスン0-0 Claude で案内を要約する

## 0-0-1 Claude に初めて頼む

Claude は、入力した文章をもとに質問に答えたり、下書きを作ったりできる AI です。ここでは研修の案内を、初参加の人がすぐ読める一文にします。まず自分で答えをメモし、そのあと回答例を読んでください。ウェブの Claude を使える人は、次の依頼と案内を一緒に送って試せます。この教材の例だけでも練習できます。

**依頼**　次の案内だけを使い、初参加の人に受付時刻と会場を一文で知らせてください。

> 受付は9時半からです。研修は10時に始まります。会場は北館2階です。

回答例は「受付は9時半から、会場は北館2階です。」です。あなたの答えの言い回しが違っても、参加者が正しい時刻と会場にたどり着ければ目的を果たせます。

## 0-0-2 回答を原文で確かめる

別の回答例には「受付は10時からです。北館2階へ筆記用具を持ってお越しください」とあります。参加者に渡す前に、原文と照らし合わせて直してください。

| 回答に含まれる情報 | 原文で確認した結果 |
| --- | --- |
| 受付は10時から | 10時は研修の開始時刻。受付は9時半から |
| 会場は北館2階 | 「会場は北館2階です。」と一致 |
| 筆記用具が必要 | 持ち物の記載がない。必要かどうかは未確認 |

続けて「受付、会場、持ち物を一行ずつ書いてください。案内にない項目は『記載なし』とし、根拠になる一文があれば添えてください」と頼んでみましょう。回答で引用された文も、自分の手元の案内と照合します。

## 0-0-3 ウェブで試した依頼をアプリから送る

案内が一件なら、担当者がウェブのチャットで依頼を試し、回答を読んで直せます。研修の登録画面で毎回下書きを作るなら、Claude API を使います。API はプログラム同士がやり取りするための窓口です。登録画面のアプリが案内と依頼を送り、返ってきた文章を担当者に表示します。

基本の Messages API では、各呼び出しに渡した内容がその回の材料になります。アプリから二度目に「もっと短く」とだけ送ったら、Claude は何を短くするのか特定できません。そこで前の依頼と案内、直前の回答、今回の追加依頼を順に送ります。後のレッスンで、このやり取りを JavaScript で組み立てます。

**確認**　原文の会場だけを「南館1階」に変更して一文を作り直してください。会場が南館1階に変わり、受付が9時半のままで、原文にない持ち物を加えていなければ完了です。

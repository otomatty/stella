# ウェブで試した依頼をアプリから送る
<!-- ノート: 同じ案内の要約を、担当者が毎回手で頼む場合とアプリに組み込む場合で考えます。 -->

# 一件を手で試す
ウェブのチャットでは、人が依頼と案内を入力し、回答を読んで「一文に縮めて」と追加で頼めます。
<!-- ノート: 質問や出力の形式を試したいときは、その場で依頼を書き換えられます。 -->
---
# アプリで何度も使う
Claude API はプログラムから依頼を送り、回答を受け取るための窓口です。
案内が登録されるたびに、お知らせの下書きを作れます。
<!-- ノート: アプリの担当は、資料と依頼を送ること、受け取った回答を確認用に表示することです。 -->
---
# 続きの依頼には文脈が要る
「一文に縮めて」が何を指すか分かるよう、通常の Messages API の呼び出しには、前の依頼と回答も含めます。
<!-- ノート: このレッスンで考えるのは毎回独立した呼び出しです。ウェブで試した会話は、自分のアプリが送る内容には自動で入りません。 -->
---

# まとめ
手作業で試した依頼は、Claude API を通じて自分のアプリから送れます。

## ヒント1 送る前と受け取ったあと

送信回数と費用は、これまで送った分を持ちます。応答を受け取ったら、次の送信が必要かを判断する前に、今回の応答と費用を履歴と合計に残してください。

## ヒント2 直前の失敗を覚える

ツール名と入力を1組にして、直前に失敗した呼び出しと比べます。成功したら、直前の失敗を空にします。呼び出しの ID は結果を結ぶために使うので、入力を比べるときは外します。

```js
const call = { name: block.name, input: block.input };
```

この組を使い、入力はプロパティの並びに左右されない方法で比べます。

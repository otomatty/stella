# 古いツール結果を減らす
<!-- ノート: 枠を使っている中身から、減らす対象を選びます。 -->
---
# 短い会話なのに検索結果で埋まる
商品を 1 件ずつ照合するたび、検索結果が 50 件ずつ返ります。最初の依頼で指定した照合条件を見落とすようになりました。
<!-- ノート: 会話は短くても、検索のたびに結果が会話に加わります。 -->
---
# 古い結果から外す
古いツール結果が溜まったら、コンテキストの編集で古い結果から外します。
<!-- ノート: コンテキストの編集は、決めた規則に従ってサーバー側で対象を外します。 -->
---
# 直近の確認に使う結果を残す
たとえば、直近 3 回のツール使用を残し、それより古い検索結果を削除の対象にします。
<!-- ノート: 外した結果は要約されません。アプリに保存している元の履歴はそのままです。 -->
---
# 枠を使うものに合わせる
| 枠を使うもの | 選ぶ手段 |
| --- | --- |
| 古いツール結果 | コンテキストの編集 |
| 多数のツール定義 | ツール検索で必要な定義を後から読む |
| 長い会話 | 圧縮で古いやり取りを要約する |
<!-- ノート: キャッシュを使った入力もコンテキストウィンドウに数えます。 -->
---

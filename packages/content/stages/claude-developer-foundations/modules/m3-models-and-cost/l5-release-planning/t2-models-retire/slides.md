# モデルには終わりがある

# 固定した ID はいつまで使える？
設定にはモデル ID が 1 つ書いてあります。画面の仕分けと、夜間の集計がその ID を使っています。
<!-- ノート: 変更箇所をアプリの設定だけと考えると、夜間の処理に残った呼び出しを見落とすことがあります。 -->
---
# 今日の判断
モデルは予告のあとに廃止されるので、廃止日より前に次のモデルで評価します。
<!-- ノート: この判断を、続く例で確かめます。 -->
---
# 非推奨と廃止の境目
現行 → レガシー → 非推奨 → 廃止

非推奨の間は呼び出せます。Claude API で廃止された ID を指定すると 404 が返ります。
<!-- ノート: レガシーは更新を終えた状態です。公開モデルでは、廃止の少なくとも 60 日前に利用中の顧客に予告が届きます。 -->
---
# 廃止日から逆算する
対象の ID と利用箇所を洗い出し、候補のモデルを評価します。評価と段階的な切り替えを廃止日までに終えます。
<!-- ノート: 固定した ID は別のモデルへ自動で切り替わりません。使っている提供先の廃止日を確認します。 -->
---

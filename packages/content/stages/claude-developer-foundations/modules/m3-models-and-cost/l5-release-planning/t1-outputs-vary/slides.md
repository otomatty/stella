# 1 回目は通ったのに

# 今日の判断
同じ入力でも出力は毎回同じとは限らないので、複数回の結果で判断します。
<!-- ノート: この判断を、続く例で確かめます。 -->
---
# 3 回とも通るかを見る
成功率が 75% で各回が独立なら、3 回とも成功する確率は `0.75 × 0.75 × 0.75 ≈ 42%` です。
<!-- ノート: 利用者に毎回正しく案内したいなら、同じケースを繰り返し、全回通ったケースの割合を見ます。 -->

# 温度を 0 にする案を見直す
温度を指定できるモデルでも、`temperature: 0` で出力が固定されるとは限りません。API 版 `2026-10-21` では指定すると 400 になります。

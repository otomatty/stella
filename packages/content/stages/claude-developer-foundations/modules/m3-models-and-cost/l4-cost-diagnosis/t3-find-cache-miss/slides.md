# 外れた原因を探す
<!-- ノート: 設備の点検を案内するアプリで、昨日まで読めていたキャッシュが読まれなくなりました。 -->
---
# 数秒おきでも読み込みは 0
点検案内を 10 秒おきに試しました。`usage` には書き込みがあるのに、読み込みは 0 のままです。
<!-- ノート: 書き込めているので、この例ではキャッシュの最低の長さは足りています。どこから前回と違うかを調べます。 -->
---
# 今日の判断
キャッシュが読まれないときは、区切りより前に毎回変わる値がないかを先に調べます。
<!-- ノート: この判断を、続く例で確かめます。 -->
---
# 診断で比較する場所を絞る
診断を有効にした前回の応答 ID を渡すと、差が出た場所を調べられます。この例では `system_changed` が返りました。
<!-- ノート: ID は応答の id です。診断で分かるのはリクエストの差です。実際に読み込んだ量は usage で確かめます。 -->
---
# 時刻の置き場所を直す
`system` の先頭に現在時刻が追加されていました。時刻は区切りの後ろの今回の入力に移し、読み込みを測り直します。
<!-- ノート: 10 秒おきの入力では、同じ前半が戻れば 5 分のキャッシュを読めます。期限だけ延ばしても現在時刻は一致しません。 -->
---

# まとめ

# 解説

質問のあとにだけ区切りがあると、書き込んだ前半に質問も含まれます。次の質問が違うとその前半全体が一致しません。有効期間を延ばすと書き込んだ内容は長く残りますが、共通の指示や資料だけを読める位置は増えません。

解答例は、ツールに続く共通の指示の末尾と、資料があればその末尾に区切りを置きます。各区切りまでの長さが足り、有効期間内に送る場合の動きは次のとおりです。

| 変わった内容 | 読み込みと書き込み                                         |
| ------------ | ---------------------------------------------------------- |
| 共通の指示   | どちらの区切りまでの内容も変わるので、新しい前半を書き込む |
| 資料         | 共通の指示までを読み、更新した資料の分を書き込む           |
| 質問         | 資料までを読み、質問を通常入力として処理する               |

比較は層ごとにブロックを並べ、最後の区切りがある層だけ比較の終点をその区切りまでに絞ります。発言には役割と発言の位置も持たせているので、同じ文でも発言の分け方が変われば検出できます。別解として、層名・層内の位置・内容を持つ 1 本の配列に展開しても、順に比較できます。その場合は、余ったブロックが違う層から来たときに、挿入・削除された層を判定できるようにします。

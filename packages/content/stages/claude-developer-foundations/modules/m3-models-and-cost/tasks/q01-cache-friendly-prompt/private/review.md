# レビューの観点

- 指示と資料を `system` に、時刻と質問を `messages` に置いているか。時刻を `system` に混ぜていないか
- `cache_control` が、毎回同じ部分の最後のブロックにだけ付いているか(資料が空のときは指示のブロック)
- `ttl` が `"1h"` のときだけ `ttl` を書いているか
- 受け取った `documents` を `push` などで書き換えていないか
- `usage` の 3 つの入力の値を足して合計を出しているか。`input_tokens` だけを合計にしていないか
- `null` と省略を 0 として扱い、`status` を読み込み・書き込みの順に判定しているか

よくある違反: すべてのブロックに `cache_control` を付ける、質問のブロックに区切りを残す、時刻を指示の先頭に入れる、`input_tokens` を入力の合計として返す、`null` を足して `NaN` になる。

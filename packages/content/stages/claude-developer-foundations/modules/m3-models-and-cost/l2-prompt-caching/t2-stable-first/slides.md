# 毎回書き込みになる
system の先頭に今の時刻を入れていました。キャッシュは毎回書き込みになり、読み込みが一度もありません。
<!-- ノート: 前半が毎回違うので、使い回せる部分がありませんでした。 -->

# 変わる部分は後ろ
キャッシュは前から一致した部分に効くので、変わる部分は後ろに置きます。
<!-- ノート: tools、system、messages の順に、前から一致しているかが確かめられます。 -->
---
# 並べ方
- 前: ツールの定義・指示・資料・例(毎回同じ)
- 区切り: 毎回同じ部分の最後のブロックに cache_control
- 後ろ: 時刻・質問(毎回変わる)
<!-- ノート: cache_control を付けた位置が、キャッシュの区切りです。毎回変わるブロックに付けると、毎回書き込みになります。 -->
---
<!-- _class: summary -->
# まとめ
キャッシュは前から一致した部分に効くので、変わる部分は後ろに置きます。

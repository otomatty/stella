# 解説

指示に「出典を書いて」と頼むと、モデルがページ番号や引用文を自分で書くことがあります。その位置が資料に実在する保証はありません。引用の機能は、文書ブロックに `citations.enabled` を付け、応答のテキストブロックへ `document_title` と `cited_text` を付けて返します。引用文は渡した資料から取り出されるので、画面の出典をその組でたどれます。

引用と `output_config.format` は同時に送れません。同時に指定すると 400 になります。項目ごとに値を残したいときは、1 行に 1 項目を返させてアプリで読む方法があります。この課題ではリクエストに構造化出力を付けず、引用の有無だけを見ます。

引用の無い文を残すと、前置きや資料に無い主張が、根拠のある文と一緒に画面へ出ます。決まった返事だけの応答も引用が無いので、アプリは `not_found` として決まった表示に切り替えられます。拒否と上限は本文が途中でも成功ではないので、引用を見る前に分けます。

別解として、決まった返事の文字列だけを照合する方法があります。引用の無い別の言い回しを見逃すので、この課題では文字列ではなく引用の有無で残すブロックを決めます。

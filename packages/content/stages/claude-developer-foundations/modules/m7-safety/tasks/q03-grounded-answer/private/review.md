# レビューの観点

- 文書を渡した順に並べ、どの文書も `citations.enabled` が true か
- 質問のテキストを文書のうしろに置き、`output_config` を付けていないか
- `documents` が空のときに例外を投げ、受け取った配列を書き換えていないか
- `refusal` と `max_tokens` を、引用の有無より先に返しているか
- テキスト以外のブロックと、引用の無いテキストを結果に含めていないか
- `sources` が `document_title` と `cited_text` の組で、重複を除き、出てきた順か
- 説明欄が、指示だけで出典を書かせる方法と引用の機能の違い、引用の無い文を出さない理由を、自分のコードに即して述べているか

よくある違反: 一部の文書だけ引用を無効にする、構造化出力を同時に付ける、引用の無い前置きを連結する、同じ引用を sources に繰り返す、上限で切れた応答を answered にする。

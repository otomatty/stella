# 解説

受信メールやウェブページのように外から来た文章には、Claude を操ろうとする指示が紛れ込むことがあります(間接のプロンプトインジェクション)。公式ドキュメントは、外の文章を `tool_result` の中だけに入れ、何の内容でどこから来たかを伝え、JSON にして包むことを勧めています。

外の本文を `<email>…</email>` のようなタグで包み、自分の指示とつなげると、本文に `</email>` を書いておくだけでタグの外へ抜け出し、指示のように見せられます。JSON の文字列にすると、引用符やタグは文字としてエスケープされるので、どこまでがデータかがはっきりします。`source` を必ず入れるのは、Claude が内容をどこまで信じてよいかを判断する手がかりにするためです。

自分の指示を `tool_result` の中に書くと、Claude はそれも信頼できない内容として疑い、従わないか、インジェクションの疑いとして扱うことがあります。指示は、すべての `tool_result` のあとの `text` ブロックで渡します(M5 で学んだとおり、`tool_result` は先頭に並べます)。

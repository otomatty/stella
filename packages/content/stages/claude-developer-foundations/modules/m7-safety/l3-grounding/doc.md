# レッスン7-3 資料に基づいて答えさせる

## このレッスンの目標

- [ ] 引用を有効にし、応答の出典を資料の位置までたどれます。
- [ ] 引用のない主張が、根拠付きの回答として表示されないように処理できます。
- [ ] 資料の量・費用・鮮度から、全文を渡すか検索するかを選べます。

## 7-3-1 出典を付けて返す

> **資料に基づく回答は、引用の機能で出典の位置を付けて返します。**

倉庫の点検案内では、担当者が回答から使った手引きの箇所を開けるようにします。7-2-2 で扱った指示に加え、位置を確かめたい文書には API の引用の機能を使います。指示だけで書かせたページ番号には、その位置が実在する保証がありません。

文書ブロックごとに `citations: { enabled: true }` を付けます。同じリクエスト内の文書では、引用を有効にするかどうかをそろえます。

たとえば、読み込んだ手引きの本文を次の文書ブロックに入れます。

```js
const inspectionDocument = {
  type: "document",
  source: { type: "text", media_type: "text/plain", data: inspectionManual },
  citations: { enabled: true },
};
```

| 渡す文書 | API が区切る単位 | 応答で示す位置 |
| --- | --- | --- |
| テキスト | 文 | 文字の範囲 |
| PDF | 取り出した文字の文 | ページの範囲 |
| 独自に区切った文書 | 渡したブロックのまま | ブロックの範囲 |

画像や、文字を取り出せないスキャン PDF は引用できません。資料を参照した応答では、テキストブロックに `citations` が付きます。その中の文書番号で、渡した文書を特定できます。位置はその文書内に実在することが保証されます。引用された本文の `cited_text` は、出力トークンに数えません。

たとえば手引きの 12 ページを引用した場合、アプリは文書番号から元の PDF を選び、該当ページを開けるリンクを出します。

## 7-3-2 引用のない主張を外す

> **資料の引用が付かない主張は、答えから外すか「資料にない」と返します。**

7-2-1 と 7-2-2 の指示を使い、渡した資料で分からない場合は答えを控えさせます。そのうえで、アプリは応答のテキストブロックごとに引用があるかを見ます。別のブロックに引用が付いていても、根拠のない段落は外します。引用がある場合も、重要な主張は元の箇所が内容を裏付けているか確かめます。

| 応答の一部 | 引用 | 画面に出す内容 |
| --- | --- | --- |
| 棚の耐荷重は 80 kg です | 点検手引きの 12 ページ | 主張と、そのページへのリンク |
| 屋外で使えます | なし | 資料に該当する記載がありません |

必要な根拠が一つも示されなければ、「資料に該当する記載がありません」と返します。このように回答不能の返事をそろえると、根拠がない問いを集めた評価のセットで、回答を控えた件数を数えられます。

項目ごとに値と出典を保存したい場合は、1 行に 1 項目ずつ返すように頼み、アプリで行と引用を読み取ります。たとえば「耐荷重 = 80 kg」の行と、その応答ブロックに付いた引用を一緒に保存します。複数項目の対応を判断できないときは、そのまま保存せず確認に回します。`output_config.format` と引用を同時に指定すると 400 になります。「JSON だけ返す」と指示するだけでも、引用がほとんど付かない場合があります。

## 7-3-3 全部入れるか、探して入れるか

> **資料が小さく変わらないなら全文を入れ、大きいか変わりやすいなら要る部分だけを探して入れます。**

どちらを選ぶかは、量・費用・鮮度で決めます。2024 年に示された目安は約 20 万トークン（約 500 ページ）です。これより小さく安定した資料なら、全文を入れてプロンプトキャッシュを使う方法から試せます。同じ前半を使い回せるので、待ち時間と入力の費用を抑えられます。

| 資料 | 入れ方 | 理由 |
| --- | --- | --- |
| 年に一度更新する短い点検手引き | 全文を渡す | 検索の仕組みを作らず、全体から根拠を示せる |
| 多数の拠点の点検記録 | 検索で関係する記録に絞る | 4-3-2 のように、関係の薄い資料を減らして精度と費用を確かめられる |
| 頻繁に変わる設備情報 | 質問を受けてからツールで最新版を取る | 古い索引を使うと、変更前の条件で答えることがある |

設備の型番や規程番号は、意味の近さだけでは見つけにくい場合があります。意味で探す方法と、語の一致で探す BM25 を組み合わせます。候補は質問との関係で順位を付け直し、必要な部分を選びます。意味で探す場合は文の意味を数値の並びにした「埋め込み」を使えます。Anthropic は埋め込みモデルを提供していないため、別の提供元のモデルを選びます。

取ってきた箇所は、`search_result` ブロックの `source`（出どころ）、`title`（題名）、`content`（本文ブロックの配列）で渡せます。引用を有効にすると、検索結果とその中のブロックの位置をたどれます。ツールで何も見つからなければ、「検索に該当する資料はありません」というテキストを返します。検索が 0 件でも、資料全体に記載があるかは検索結果から確定できません。

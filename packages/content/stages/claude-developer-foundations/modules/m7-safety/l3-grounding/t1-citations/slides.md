# 倉庫の点検手順を案内する
点検担当者が、保管棚の耐荷重を手引きで確かめたいと聞きました。
画面には耐荷重とページ番号が出ますが、その番号を確認すると別の棚の説明でした。

# 出典を付けて返す
資料に基づく回答は、引用の機能で出典の位置を付けて返します。
<!-- ノート: 資料に基づく回答は、引用の機能で出典の位置を付けて返します。 -->
---
# 文書に引用を付ける設定を足す
文書ブロックに `citations: { enabled: true }` を付けます。
応答のテキストブロックに、文書の番号・文書内の位置・引用された本文が付きます。
<!-- ノート: 文書ブロックに `citations: { enabled: true }` を付けます。 応答のテキストブロックに、文書の番号・文書内の位置・引用された本文が付きます。 -->

# PDF ならページが分かる
PDF はページ、テキストは文字、自分で区切った資料はブロックの位置で示されます。

# 運用担当がキーの一覧を出す
運用担当者が、点検メモの要約に使うキーを毎月棚卸しします。
一覧取得と要約を同じキーで動かそうとすると、必要な権限を分けられません。

# 管理用のキーは別物
Admin キーは組織の管理のためのキーで、Claude の呼び出しには使いません。
<!-- ノート: Admin キーは組織の管理のためのキーで、Claude の呼び出しには使いません。 -->
---
# 用件でキーを選ぶ
要約はサーバーから通常の API キーで呼びます。
組織のキー一覧は、組織管理者が発行した Admin キーで取得します。
<!-- ノート: 要約はサーバーから通常の API キーで呼びます。 組織のキー一覧は、組織管理者が発行した Admin キーで取得します。 -->
---
# 一覧では秘密の値を取り出せない
Admin API では、キーの名前を変えたり無効化したりできます。キーの発行や秘密の値の再取得はできません。
<!-- ノート: キーを失くしたら、用途に合う新しいキーを発行します。 -->
---

# まとめ
Admin キーは組織の管理のためのキーで、Claude の呼び出しには使いません。

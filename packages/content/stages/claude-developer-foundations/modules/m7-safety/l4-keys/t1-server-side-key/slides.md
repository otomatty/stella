# モバイルから点検メモを要約する
倉庫の担当者が、モバイルアプリから点検メモの要約を頼めるようにします。
開発時のように画面のコードにキーを渡すと、利用者に配るアプリにもキーが入ります。

# 画面は自分のサーバーを呼ぶ
画面は自分のサーバーに点検メモを送ります。
サーバーが利用者と入力を確かめ、保管しているキーで Claude を呼びます。
<!-- ノート: 画面は自分のサーバーに点検メモを送ります。 サーバーが利用者と入力を確かめ、保管しているキーで Claude を呼びます。 -->

# 配布物を調べる
Web とモバイルの配布物を確かめ、サーバーが使うキーが含まれていないことを確認します。
<!-- ノート: 利用者の画面には要約を返します。Claude に送る認証情報はサーバーで扱います。 -->

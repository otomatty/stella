# 集計に取り込めない応答がある
配送記録から配送番号と状態を抜き出します。応答によって項目名が変わったり、前置きが付いたりします。
<!-- ノート: 文章では意味が通っても、決められた項目名で読む集計処理は失敗します。 -->

# 形をスキーマで決める
出力の形が崩れるなら、構造化出力で必要な形を指定します。
<!-- ノート: フォーマットのドリフトとは、期待する出力の形から応答が外れることです。プログラムで読むなら、4-2-1 の構造化出力を使います。 -->
---
# 集計で使う項目を固定する
| 必須の項目 | スキーマで指定する形 |
| --- | --- |
| `deliveryId` | 文字列 |
| `status` | `shipped` または `pending` |
<!-- ノート: 読む側と同じ項目名と型を指定します。応答が完了したかは stop_reason で確認してから中身を読みます。 -->

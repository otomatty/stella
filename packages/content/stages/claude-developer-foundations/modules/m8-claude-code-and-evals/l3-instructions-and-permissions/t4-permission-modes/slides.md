# 同じ設定で作業を続けていた
まずコードを調査し、方針を見てもらったあとで実装します。調査中から編集を許してもよいでしょうか。
<!-- ノート: 作業の段階によって、Claude に任せたい操作が変わります。 -->
---
# 作業の危険度に合わせる
権限モードは、作業の危険度に合わせて選びます。
<!-- ノート: 権限モードは、人の確認を待つ操作の基本方針です。ツールごとの拒否はどのモードでも効きます。 -->
---
# 作業の段階に合わせて選ぶ
| 場面 | モード |
| --- | --- |
| 調査して計画を出す | `plan` |
| 編集前に人が確認する | `default`（Manual） |
| 確認済みの方針で編集する | `acceptEdits` |
<!-- ノート: plan ではソースを編集しません。acceptEdits では編集や一部のファイル操作が確認なしになります。 -->
---
# 確認を人に求めない場合
- `auto`。分類するモデルが操作を審査します。
- `dontAsk`。確認が必要な操作を拒否します。
<!-- ノート: 人がいない実行で毎回の判断を任せるのか、事前に許した操作に絞るのかで選びます。絶対に止める操作には、拒否のルールかフックを使います。 -->
---

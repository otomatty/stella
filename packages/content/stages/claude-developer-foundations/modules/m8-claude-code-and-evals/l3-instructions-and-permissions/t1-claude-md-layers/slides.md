# 広い範囲から重ねる
複数の場所にある CLAUDE.md は、広い範囲から順に重ねて読み込まれます。
<!-- ノート: ファイルの内容は指示として続けて渡されます。後ろに書いた指示が前の指示を消す仕組みはありません。 -->

# どの順に読むか
1. 組織が配る CLAUDE.md
2. `~/.claude/CLAUDE.md`
3. `./CLAUDE.md` または `./.claude/CLAUDE.md`
4. `./CLAUDE.local.md`

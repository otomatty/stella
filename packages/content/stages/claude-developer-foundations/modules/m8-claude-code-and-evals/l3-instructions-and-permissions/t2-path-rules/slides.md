# ファイルで絞る約束
<!-- ノート: 在庫のテストだけに使う約束を、必要なときに読み込ませます。 -->
---
# 関係のない作業でも指示が長い
在庫テストの細かい約束が、商品説明文だけを直す作業でも毎回読み込まれています。
<!-- ノート: その約束が必要なのは、在庫のテストを扱うときだけです。どこに置けば読み込む場面を絞れるでしょうか。 -->
---
# ファイルのパスで絞る
特定のファイルにだけ効かせたい約束は、パスを指定したルールファイルに書きます。
<!-- ノート: ルールファイルは .claude/rules/ の下に置く Markdown です。下のフォルダーに分けて置くこともできます。 -->
---
# 在庫テストだけに読む
```yaml
paths: ["tests/inventory/**/*.test.ts"]
```
<!-- ノート: たとえば .claude/rules/inventory-tests.md の冒頭の設定欄に書きます。本文には「在庫が 0 件の例を含めてください」と書きます。glob はファイル名をまとめて表す書き方です。この指定では在庫テストを読むか編集するときに読み込みます。 -->
---
# 指定がないルールは起動時に読む
- `paths` あり。対象を扱うときに読みます。
- `paths` なし。起動時に読みます。
<!-- ノート: 圧縮で会話が要約されたあと、パスを指定したルールは、次に対象のファイルを扱ったときに読み直されます。 -->
---

# 合格数は一致
人も採点器も、返品の回答5件のうち4件を通しました。
これで問い合わせ対応を任せられるでしょうか。

# 回答ごとに照合する
人の判定と採点器の判定を同じ回答で照合し、誤って通した回答を特定します。

# 同じ4件だったか
- R2　人は合格、採点器は不合格
- R4　人は不合格、採点器は合格

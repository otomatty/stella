# 設定が届く範囲
<!-- ノート: 手元と CI で結果が違うとき、設定の置き場所から調べます。 -->
---
# 手元で動いたフックが CI で動かない
ガイドの書式を確認するフックは、自分の端末では動きます。CI の実行記録には、その確認がありません。
<!-- ノート: CI では別の作業環境にリポジトリを取得して処理を走らせます。フックの設定をどこに置いたか確認します。 -->
---
# どの環境に届くかを確かめる
リポジトリに入れた設定はチームと CI に届き、端末だけの設定はその端末に残ります。
<!-- ノート: 設定が届くとは、その環境で Claude Code が設定ファイルを参照できることです。 -->
---
# フックの設定をどこに置くか
| 置き場所 | 届く範囲 |
| --- | --- |
| Git に入れた `.claude/settings.json` | チーム、CI、取得したクラウドのセッション |
| Git に入れない `.claude/settings.local.json` | 同じ端末の、このプロジェクト |
| `~/.claude/settings.json` | 同じ端末の、自分の全プロジェクト |
<!-- ノート: CLI と手元のエディターで同じフォルダーを開けば、手元に置いた同じ設定を読みます。クラウドは取得したファイルから始まります。 -->
---
# 組織の管理設定を届ける
端末に配る管理設定と、サーバーで管理する設定があります。クラウドにはサーバーで管理する設定が届きます。
<!-- ノート: サーバーで管理する設定は、組織の管理画面から対応する環境に配る設定です。リポジトリの設定と、組織が配る設定の両方を確認します。 -->
---

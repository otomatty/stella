# 夜間の確認に人はいない
変更のたびに走る CI に、テスト結果を要約する処理を入れます。画面を開いて承認する担当者はいません。
<!-- ノート: CI は変更のたびにテストや検査を自動で行う仕組みです。どの操作を任せるかを、実行する前に決めます。 -->
---
# -p で対話なしに実行する
スクリプトや CI からは -p で対話なしに実行し、許可するツールを指定します。
<!-- ノート: -p は --print の短い書き方です。確認画面を出さずに依頼を実行し、結果を返します。 -->
---
# 検査に要る操作を許可する
```sh
claude -p "テストを実行して結果を要約してください" --permission-mode dontAsk --allowedTools "Bash(npm test)" "Read"
```
<!-- ノート: Bash の許可は npm test に絞ります。dontAsk では確認が必要な操作を拒否します。最初から確認が要らない読み取りなどは実行できます。 -->
---
# 起動時に動くものも確かめる
通常の `-p` は、信頼の確認を表示せず、リポジトリのフックを動かし、MCP サーバーにつなぎます。
<!-- ノート: CI の実行前に、そのリポジトリから何を読み込むか確認します。自動読み込みを省く設定は、必要なフックまで省くので用途に合わせて選びます。 -->
---

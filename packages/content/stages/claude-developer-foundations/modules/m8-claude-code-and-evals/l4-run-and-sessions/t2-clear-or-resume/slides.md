# 作業の区切りで会話を分ける
<!-- ノート: 会話の履歴を使う場面と、手放す場面を見分けます。 -->
---
# 前の仕事の事情が混ざった
在庫テストの調査を終え、同じ会話で利用ガイドを直し始めました。Claude はまだ在庫の話を持ち出します。
<!-- ノート: 同じリポジトリでも、前の仕事の会話が役に立つとは限りません。 -->
---
# 履歴が必要かで決める
関係のない作業に移るときは会話を消し、同じ作業の続きはセッションを再開します。
<!-- ノート: セッションには、その作業で交わした会話が記録されています。次の作業でその会話を使うかを考えます。 -->
---
# 会話を分けるか、読み直すか
| 次にやること | 選ぶ操作 |
| --- | --- |
| 別の仕事を始める | `/clear` |
| 直近の仕事を続ける | `claude -c` |
| 前の仕事を選んで続ける | `claude -r` または `/resume` |
<!-- ノート: /clear は現在の会話を区切ります。前のセッションは保存されるので、必要になったら選び直せます。 -->
---
# 同じ仕事で会話が長くなったら
`/context` で使用量を見て、`/compact` で会話を要約して続けます。
<!-- ノート: 作業は同じで、履歴を短くして続けたいときの選び方です。 -->
---

# まとめ
関係のない作業に移るときは会話を消し、同じ作業の続きはセッションを再開します。

# コピーした二つがずれる
在庫レポートの Skill とフックを二つのリポジトリにコピーしました。一方だけ手順が直り、どちらを配ればよいか迷います。
<!-- ノート: 同じ仕組みを使う場所が増えると、コピーした先ごとに更新する手間が生まれます。 -->
---
# 一式と、組み合わせる版を決める
複数のリポジトリで使う設定は、プラグインにまとめ、依存の版の範囲を決めて配ります。
<!-- ノート: プラグインは、Skill やフックなどをまとめて導入できる形です。必要な別のプラグインがあれば、どの版と組み合わせるかを宣言します。 -->
---
# 使える依存の版を書く
`.claude-plugin/plugin.json` に書きます。
```json
{
  "name": "stock-report-kit",
  "version": "1.0.0",
  "dependencies": [{ "name": "warehouse-data", "version": "~2.1.0" }]
}
```
<!-- ノート: このマニフェストは中身と版を示す設定です。依存先は 2.1 系の修正版までに収めます。 -->
---
# 部品はプラグインの直下
`.claude-plugin/` には `plugin.json` を置きます。部品の `skills/` や `hooks/` は、`.claude-plugin/` と同じ階層に置きます。
<!-- ノート: 手元で試すときは、部品を含むプラグインのディレクトリを指定します。 -->

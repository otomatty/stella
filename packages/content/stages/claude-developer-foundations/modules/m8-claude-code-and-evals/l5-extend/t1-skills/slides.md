# 今週も同じ依頼を書く
在庫レポートを頼むたびに、集計の順序と報告の書式を会話に貼っています。毎回読む指示ファイルに移すと、在庫と関係のない作業にも長い手順が届きます。
<!-- ノート: 報告を作るときにだけ、同じ手順を渡したい場面です。 -->
---
# 使うときに手順を読む
繰り返し使う手順や知識は、Skill にして必要なときだけ読み込ませます。
<!-- ノート: Skill は、Claude が使える手順や知識をひとまとめにしたものです。ふだんは説明で見つけ、呼び出したときに本文を読みます。 -->
---
# 在庫レポートの手順を置く
`.claude/skills/stock-report/SKILL.md` に書きます。

- 説明に、週次の在庫レポートをまとめる場面を書く
- 本文に、補充が必要な商品を倉庫別に並べる手順を書く
<!-- ノート: チームでファイルを共有します。Claude が説明から選ぶか、担当者が /stock-report と入力して使います。 -->
---
# 担当者が選んだときに使う
人がタイミングを決める手順には、`disable-model-invocation: true` を指定できます。
<!-- ノート: この指定では Skill の説明も Claude の文脈に入りません。担当者の呼び出しで本文が読み込まれます。 -->
---

## ヒント1 今決まるものとあとで使うもの

フックの拒否はそこで決まります。許可と確認はあとで使うので、どちらがあったかを別々に覚えてください。許可を受け取ったあとでも、後続のフックやルールが拒否することがあります。

## ヒント2 ルールの対象を切り分ける

ルールのツール名と括弧の中身を分けます。ツール名が一致したら、括弧の有無とツール名で調べる値が決まります。正規表現を使うなら、`*` 以外に意味を持たせず、文字列の全体を照合してください。

```js
const toolNames = matcher.split("|");
```

この配列でフックの対象を調べるときは、呼び出しに含まれるツール名が丸ごと一致するかを見ます。

# 解説

解答例は決まった段で値を返します。フックの許可と確認だけを先に覚え、ルールとの優先順位が決まったところで使います。この順序なら、広い拒否と細かい許可が両方に一致しても、拒否した理由を返せます。

判定の段を配列にして、決定を返した最初の段で止める方法もあります。段ごとに個別のテストを書ける一方、どの段がフックの結果を使うかを追う必要があります。この課題では処理を上から並べると、テストの判定順と照らし合わせやすくなります。

自動で許可される呼び出しは `canUseTool` に届きません。モデルへの指示は振る舞いを導きます。実行を必ず止めたい場合は、実行前に評価される拒否ルールやフックを使います。

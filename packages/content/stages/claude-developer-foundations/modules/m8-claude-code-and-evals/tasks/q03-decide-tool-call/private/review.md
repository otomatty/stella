# レビューで見ること

- フックの許可だけで処理を終えていないかを見ます。後続のフック、拒否ルール、確認ルールが先に判定を決められる必要があります。
- ルールの条件の細かさで並べ替えていないか、モードの自動許可が拒否より後ろにあるかを見ます。
- 一致しないフックは呼ばず、例外時の `block` と結果なしを区別しているかを見ます。通常の拒否と失敗時の拒否では `decidedBy` も変わります。
- ワイルドカード以外の文字をそのまま照合しているかを見ます。部分一致にすると、別のコマンドやパスも一致します。
- 説明欄では、自動許可された場合に `canUseTool` が呼ばれない例を示し、実行前に強制する制約とモデルに渡す指示の役割を説明しているかを見ます。

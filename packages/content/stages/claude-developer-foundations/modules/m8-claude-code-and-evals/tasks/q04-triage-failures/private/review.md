# レビューの観点

- HTTP ステータスを、停止理由と本文より先に見ているか
- 400 と 413 を送り直しにしていないか。429 と、500・529 の送り直しを取り違えていないか
- 拒否を同じモデルへの送り直しにしていないか。上限を空の応答の対策にしていないか
- `pause_turn` を、内容を変えずに送り直す操作にしているか
- 空の応答を、直前の発言で `tool_result` の後ろに `text` があるときだけ組み立ての失敗にしているか
- `expectedFormat` が `json` のとき、つないだ本文が `JSON.parse` できるかを見ているか
- 表に無いステータスと停止理由を `unknown` にしているか
- 説明欄が、5xx だけを見ると見逃す失敗と、空の応答に上限を上げても直らない理由を、自分のコードに即して述べているか

よくある違反: 500 と 400 を同じ送り直しにする、空の応答を `max_tokens` と同じ操作にする、`errorType` だけで 500 と 529 を入れ替える、ツール結果より前のテキストだけで空の応答にする、JSON の前後に付いた文章を成功にする。

# 解説

一覧を空にすると、閲覧権限のない利用者の画面に検索が出なくなります。ただし、名前を指定した呼び出しは一覧を経由するとは限りません。そこで実行時にも認証済みの権限を確かめます。

分類表は URI に対応する資料なので、`contents` に URI と本文を入れます。在庫検索は品番を受け取る操作なので、結果は `content` のテキストで返します。すでに登録済みの品目の在庫ゼロと、品目が台帳にない場合とでは、担当者が次にすることが違います。`null` の場合だけ未登録と判定します。

入力の形式を間違えたときは、検索を行わずにツール結果に理由を含めて返します。未知のツールや資料は別の扱いです。実際のサーバーでは外側の処理が仕様に従ったエラー応答を組み立てます。

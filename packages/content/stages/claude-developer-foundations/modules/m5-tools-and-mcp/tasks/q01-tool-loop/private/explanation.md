# 解説

自分で定義したツールは、Claude が `tool_use` ブロックで呼び出しを求め、アプリが実行します。実行した結果は、次のリクエストで返します。履歴には、応答の `content` を加工せずに assistant の発言として足し、そのすぐあとに `tool_result` を持つ user の発言を置きます。`tool_use_id` に呼び出しの `id` を書くと、どの呼び出しへの結果かが結ばれます。1 つの応答に呼び出しが複数あれば、すべての結果を 1 つの user の発言にまとめます。

`stop_reason` が `"tool_use"` の間だけ繰り返し、`"end_turn"` などほかの値になったら終えます。Claude が呼び出しを続ける場合に備えて、送る回数に上限(`maxTurns`)を設けておくと、ループが必ず止まります。

定義していないツールの名前が来たときに例外にすると、ループ全体が止まります。`is_error: true` の結果で知らないツールだと返せば、Claude は別のやり方を考えられます。ツールの関数の例外も同じ考え方で扱います(次の課題)。

SDK には、このループを代わりに回すツールランナーもあります。仕組みを知っておくと、ツールランナーの動きやエラーを読み解けます。

# 離れたサーバーを守る
<!-- ノート: 会議室の MCP サーバーを複数の部署から使えるようにします。 -->
---
# 同じ発行元のトークンが届く
受付アプリが、備品管理サービス用のトークンを送ってきました。会議室用のトークンと発行元は同じです。通してよいでしょうか？
<!-- ノート: 発行元と、どのサービスに使ってよいかは別の確認項目です。 -->
---
# 受け取り方とあて先を確かめる
HTTP の MCP サーバーは、トークンをヘッダーで受け取り、自分あてのものかを確かめます。
<!-- ノート: アクセスを制限する HTTP サーバーでは、リクエストのヘッダーからトークンを取り出し、あて先を確かめます。 -->
---
# 会議室の入口で検査する
- `Authorization: Bearer <トークン>` で受け取る
- あて先（audience）が会議室の MCP サーバーか確かめる
- トークンがなければ `401` と `WWW-Authenticate` を返す
<!-- ノート: 備品管理サービスあてなら拒否します。トークンは常にヘッダーで渡します。別のサービスを呼ぶときは、そのサービス用に発行された認証情報を使います。 -->
---

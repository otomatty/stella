# 誰が読み、誰が始めるか
空き検索は Claude に任せたいです。利用規則はアプリが画面に出し、予約の案内文は受付の人が選んで作り始めます。

# 使い始める人で分ける
MCP サーバーは、ツール・リソース・プロンプトの 3 つを出します。
<!-- ノート: ホストは利用者が使うアプリです。サーバーごとにクライアントを作り、JSON-RPC 2.0 のメッセージでやり取りします。 -->
---
# 会議室の機能を割り当てる
- ツールを Claude が呼ぶ。空き検索は `tools/call`
- リソースをアプリが読む。利用規則は `resources/read`
- プロンプトを受付の人が選ぶ。案内文のひな形は `prompts/get`
<!-- ノート: Claude Code なら、資料は @ で参照でき、ひな形は /mcp__rooms__reservation_note で開けます。 -->
---
# 失敗は起きた場所で返す
検索の引数を直せるなら、ツール結果に `isError: true` と直し方を入れます。未定義のメソッドを受けたら、JSON-RPC のエラーを返します。
<!-- ノート: ツールまで届いたときと、通信の約束に従えなかったときで、失敗の受け取り方が変わります。 -->
---

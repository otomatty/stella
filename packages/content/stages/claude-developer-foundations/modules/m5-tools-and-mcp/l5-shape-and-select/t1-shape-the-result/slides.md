# 結果を絞って返す
<!-- ノート: 図書館の予約窓口で、貸し出せる本を探すツールを作ります。 -->
---
# 最初の候補が埋もれる
検索のたびに、全館の書誌と更新履歴が返ります。利用者が知りたいのは、今日受け取れる本とその受取館です。
<!-- ノート: 検索はできています。候補を案内する判断に必要な項目を見直します。 -->
---
# 次の判断に合わせて項目を選ぶ
ツールの結果は、次の判断に要る項目だけに絞って返します。
<!-- ノート: Claude が次にする仕事を決めてから、結果に残す項目を選びます。 -->
---
# 予約に向けた結果にする
```js
{ title: "港の地図", pickupBranch: "中央館", available: 2 }
```
候補は既定で 10 件まで返します。
<!-- ノート: 書名、受取館、在庫数があれば候補を案内できます。館の内部 ID や更新履歴はこの判断には使いません。 -->
---
# 上限に達したら続きを案内する
返せる件数で打ち切ったときは、「受取館か著者で絞ると、候補を減らせます」と添えます。
<!-- ノート: 件数を減らすときは、省略したことが分かるようにします。全件が必要な仕事ならページ分割を用意します。 -->
---

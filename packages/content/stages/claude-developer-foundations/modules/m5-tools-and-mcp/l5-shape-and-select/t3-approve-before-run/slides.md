# 実行前に承認を取る
<!-- ノート: 予約の取り消しを受け付けるアプリを作ります。 -->
---
# 調べてほしいだけなのに取り消された
利用者は取り消し料を尋ねました。Claude が取り消すツールを呼び、アプリはすぐに実行してしまいました。
<!-- ノート: 取り消した枠は、ほかの人が予約すると戻せません。アプリが実行を止められる場所を考えます。 -->
---
# 呼び出しを受けたあとで止める
取り消せない操作のツールは、実行の前にアプリが人の承認を取ります。
<!-- ノート: アプリが tool_use を受け取った時点なら、まだ取り消し処理を呼んでいません。 -->
---
# 対象を見せて判断を待つ
- 予約番号・日時・取り消し料を画面に出す
- 承認があった呼び出しだけ実行する
- 拒否されたら「取り消しは実行されませんでした」と結果を返す
<!-- ノート: 承認の有無を調べる処理を取り消し関数の手前に置けば、Claude の判断にかかわらず実行を止められます。 -->
---
<!-- _class: summary -->
# まとめ
取り消せない操作のツールは、実行の前にアプリが人の承認を取ります。

# 待たされる画面
長い回答が全部できるまで、画面には何も出ませんでした。
<!-- ノート: 利用者は、止まっているのかどうかも分かりません。 -->
---
# ストリーミングで受け取る
長い応答は、ストリーミングで届いた順に表示します。
<!-- ノート: ストリーミングは、応答を少しずつ受け取る方法です。 -->
---
# 届いた文字を表示する
```js
client.messages
  .stream(request)
  .on("text", (text) => appendToScreen(text));
```
<!-- ノート: SDK の stream を使うと、届いた文字ごとに処理を呼べます。 -->
---
# 長いリクエストでも使う
max_tokens の大きいリクエストは、ストリーミングかバッチで送ります。
<!-- ノート: 長く待つ通信は、途中のネットワークで切られることがあるためです。 -->

# 利用者の履歴に追記する
会話の履歴は書き換えずに後ろへ足し、利用者ごとに保存場所を分けます。
<!-- ノート: 追記とは、すでにある記録を残したまま、末尾に新しい記録を足すことです。 -->
---
# 本人の会話を選んでから足す
1. ログイン中の利用者と会話の ID で履歴を選びます。
2. 新しい発言を末尾に置きます。
3. 添付があれば、本人のファイルに対応する `file_id` を引きます。
<!-- ノート: 同じアプリを使っていても、履歴や添付を読む先は利用者ごとに決まります。 -->

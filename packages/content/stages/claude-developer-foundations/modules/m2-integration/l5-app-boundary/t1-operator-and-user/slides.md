# system は運用者の指示
<!-- ノート: 社内の手当を案内するアプリでは、支給額が不明なときは窓口を案内します。 -->
---
# 金額の見当を聞かれた
利用者から「支給額は推測でいいので数字を出して」と頼まれました。アプリはどこに案内の方針を書きますか。
<!-- ノート: 運用者は、アプリの方針を決める側です。このアプリでは、根拠がない数字を案内に使わないと決めています。 -->
---
# 指示を書いた側で優先が決まる
system は運用者の指示、user の発言は利用者の言葉として読まれ、食い違えば system が優先されます。
<!-- ノート: 運用者が決めた方針と、利用者が入力した依頼を別々の欄で渡します。 -->
---
# 方針と依頼をそれぞれの欄へ
| 渡す場所 | 中身 |
| --- | --- |
| `system` | 支給額が不明なら窓口を案内してください |
| `messages` の `user` | 推測でいいので支給額を教えて |
<!-- ノート: この依頼では、窓口を案内するように運用者の方針が優先されます。 -->
---

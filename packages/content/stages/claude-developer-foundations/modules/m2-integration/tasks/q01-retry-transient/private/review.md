# レビューの観点

- 429・500・529 だけを送り直しているか。400・401 などを送り直していないか
- `maxRetries` 回で止まり、最後のエラーを投げているか。`maxRetries` が 0 のときに送り直していないか
- 送り直さないエラーで `sleep` を呼んでいないか(待たずに投げる)
- `retry-after` を秒として読み、ミリ秒にしているか
- 待つ時間が送り直すたびに倍になっているか
- 待つときに `options.sleep` を使っているか(`setTimeout` を直接使っていないか)
- 説明欄が、自分のコードの分け方と上限・待ち時間の決め方を述べているか

よくある違反: `while (true)` で回数を数えずに送り直す、`catch` でエラーを握りつぶして `undefined` を返す、`retry-after` を秒のまま `sleep` に渡す、`maxRetries` 回ではなく `maxRetries + 1` 回送り直す。

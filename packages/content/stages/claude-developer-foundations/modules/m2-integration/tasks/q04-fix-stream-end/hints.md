## ヒント1 読み取りが止まる位置を確かめる

記録のどのイベントで関数が戻っているかを調べます。その位置より後ろに、残りの本文と停止理由が届いています。本文の差分を受け取る処理と、応答全体の状態を決める処理を分けて考えます。

## ヒント2 受信中に停止理由を控える

本文と別に、最後に受け取った停止理由を変数に控えます。終了時は、ループ中に終端やエラーが届いた場合と、配列の末尾まで進んだ場合を分けます。

```js
if (event.type === "message_delta" && event.delta.stop_reason != null) {
  reason = event.delta.stop_reason;
}
```

# 解説

バッチの結果は送った順に並ぶとは限らないので、`custom_id` で元のリクエストと結びます。並び順を `custom_id` にすると、結果を問い合わせに戻すために別の対応表が要り、一覧の並びが変わると結び違えます。問い合わせの `id` から作れば、結果の `custom_id` から問い合わせがすぐに分かります。

`custom_id` は 1〜64 文字の英数字・ハイフン・アンダースコアと決まっています。使えない文字や重なりは、送ってから気づくより、送る前に止めたほうが安全です。

結果の種類は 4 つです。`succeeded` だけが応答(`message`)を持ち、`errored`・`canceled`・`expired` は応答がありません(課金もされません)。応答のテキストは、M1 と同じく `type` が `text` のブロックをつなぎます。

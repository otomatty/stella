# 送り直しの間隔
<!-- ノート: 送り直すときの待ち方を確かめます。 -->
---
# すぐに何度も送る
混雑のエラーのあと、待たずに送り直し続けました。
混雑がさらにひどくなり、いつまでも通りません。
<!-- ノート: 送り直しの回数に上限が無いと、処理も終わりません。 -->
---
# 間隔を広げ、上限を決める
送り直しは、間隔を広げながら回数の上限を決めて行います。
<!-- ノート: 間隔を倍々に広げる方法を、指数バックオフと呼びます。 -->
---
# 待つ時間を倍にする
```js
for (let attempt = 0; attempt <= maxRetries; attempt++) {
  // 送って、送り直せるエラーなら待つ
  await sleep(baseDelayMs * 2 ** attempt);
}
```
<!-- ノート: 1 回目は 1 秒、2 回目は 2 秒、3 回目は 4 秒のように延ばします。 -->
---
# 待つ秒数が示されたら
- 応答に retry-after ヘッダーがあれば、その秒数だけ待つ
- SDK は既定で、この待ち方で 2 回まで送り直す
<!-- ノート: 自分で送り直しを書く前に、SDK の maxRetries の設定で足りるかを考えます。 -->
---

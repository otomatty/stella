# 気づかないうちに変わる?
同じモデル名を書いておけば、最新の版に自動で切り替わると考えていました。
<!-- ノート: よくある思い込みとして、公式ドキュメントにも挙げられています。 -->
---
# ID は版を固定する
モデル ID は決まったスナップショットを指し、新しい版は別の ID で出ます。
<!-- ノート: スナップショットは、重みや設定を固定したモデルの版です。 -->
---
# リクエストに書く
```js
const request = {
  model: "claude-opus-5-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "こんにちは" }],
};
```
<!-- ノート: 例の ID は 2026 年 10 月時点のものです。いまの ID はモデルのページで確かめます。 -->
---
# 版を上げるときは
- ID を書き換え、評価で前の版と比べてから切り替える
- 古い ID には、それぞれ提供終了の予定がある
<!-- ノート: 4.6 世代より前のモデルには、最新の版を指す別名もあります。 -->
---

# 書けるかで決める
手順を前もって書ける仕事はワークフローで、柔軟な判断が要る仕事はエージェントで作ります。
<!-- ノート: ワークフローは予測しやすく、エージェントは柔軟です。 -->
---
# 見分け方
| 仕事の形 | 選ぶもの |
| --- | --- |
| 毎回同じ段で処理する | プロンプトの連鎖 |
| 種類ごとに扱いを変える | ルーティング |
| 何をするかが、やってみないと決まらない | エージェント |
<!-- ノート: ワークフローの形は、ほかに並列化・オーケストレーター・評価役があります。 -->
---
# 速さと費用
エージェントは、速さと費用を性能と引き換えにします。単純な作りで足りるなら、エージェントにしません。

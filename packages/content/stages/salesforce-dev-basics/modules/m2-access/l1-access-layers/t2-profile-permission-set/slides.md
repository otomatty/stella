# プロファイルと権限セット

Salesforce開発入門 — Module 2 / レッスン2-1

## なぜ必要か

- 「営業の田中さんにだけ、原価の項目を見せたい」と頼まれる
- 営業プロファイルを直すと、営業全員に見えてしまう

<!-- ノート: つかみ。1人だけ広げたいのに全員に波及する、という具体的な困りごとから入る。 -->

---

## 結論

**プロファイルで土台を配り、権限セットで個別に足す**

- **ユーザ** — ログインする 1 人
- **プロファイル** — ユーザにちょうど 1 つ割り当てる、権限の土台
- **権限セット** — 上乗せで何枚でも足せる権限のかたまり

<!-- ノート: 結論を言い切る。プロファイルは1人1つ、権限セットは何枚でも、という数の違いが使い分けの根拠になる。 -->

---

## 田中さんにだけ原価を見せる

| 相手 | 与えるもの |
| --- | --- |
| 営業全員 | 営業プロファイル |
| 田中さんだけ | 原価参照の権限セット |

- プロファイルは触らず、上に 1 枚重ねる

<!-- ノート: 具体例。冒頭の困りごとの解決形。プロファイルを人数分に増やすのではなく、権限セットで差分を表現する。 -->

---

## 引き算はできない

- 権限セットでできるのは **足すこと** だけ
- 「この人だけ見えなくする」は権限セットでは作れない
- 見せたくないなら、土台のほうを狭くして必要な人に足す

<!-- ノート: 失敗例の枠。引き算を探して設定画面を探し回るのは無駄足になる。設計の向きは「狭く配って足す」だと決めておく。 -->

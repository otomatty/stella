# アクセス権の3つの層

Salesforce開発入門 — Module 2 / レッスン2-1

<!-- ノート: Module 2の始まりです。ここは「見えない」「見えすぎる」の問い合わせで必ず使う地図になります。 -->

---

## なぜ必要か

- 「このユーザだけ商談が見えない」と言われる
- どこを直せばいいのか、設定画面が多すぎて当たりが付かない

<!-- ノート: つかみ。配属直後にいちばん頼まれる調査。設定の場所を暗記する前に、切り分けの軸を持つ。 -->

---

## 結論

**アクセス権は、オブジェクト・項目・レコードの 3 つの層が重なって決まる**

- **オブジェクトレベルセキュリティ** — その種類の箱を扱えるか
- **項目レベルセキュリティ** — その列が見えるか
- **レコードレベルセキュリティ** — その 1 件が見えるか

<!-- ノート: 結論を言い切る。3つは順番に効く関所であり、どれか1つでも閉まっていれば見えない、と押さえる。 -->

---

## 見えない理由を切り分ける

| 症状 | 疑う層 |
| --- | --- |
| メニューに商談が無い | オブジェクト |
| 一覧は出るが金額欄が無い | 項目 |
| 自分の商談しか出ない | レコード |

<!-- ノート: 具体例。症状から層を引く表。この3行が言えれば、問い合わせの一次切り分けはできる。 -->

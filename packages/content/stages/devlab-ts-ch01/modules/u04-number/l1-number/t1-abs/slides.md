# 荷物を置いた位置がずれる

予定より手前か先かにかかわらず、ずれの大きさだけを知りたいときがあります。

<!-- ノート: 倉庫の床に、荷物を置く位置の目印があります。 荷物は、目印より手前に置かれました。 手前か先かを問わず、何歩離れたかが知りたい場面です。 -->

---

# 覚えること

Math.abs(数) で、マイナスを外した大きさになります。

<!-- ノート: 絶対値とは、ゼロからの距離です。 -->

---

# 数の大きさだけを取り出す

```ts
// 予定の位置からのずれの大きさを入れる
const offset = Math.abs(-6);
```

<!-- ノート: 数直線でゼロからどれだけ離れているかを表す数を、絶対値と呼びます。正の数とゼロはそのまま返ります。 -->

---

# 確かめること

正の数とゼロはそのまま返ります。差を求めてから `Math.abs` に渡すと、向きに関係ない大きさになります。

<!-- ノート: 正の数とゼロはそのまま返ります。差を求めてから `Math.abs` に渡すと、向きに関係ない大きさになります。 -->

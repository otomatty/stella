# 花壇の 1 辺の長さを求める

正方形の花壇の 1 辺の長さを、面積から求めたいときがあります。

<!-- ノート: 正方形の花壇に、同じ大きさの苗を並べます。 苗は縦と横に、同じ数ずつです。 全体の個数から、一列に並ぶ個数を求めましょう。 -->

---

# 覚えること

Math.sqrt(数) で、2回掛けるとその数になる数 (平方根) になります。

<!-- ノート: 平方根は、二乗すると元の数になる数です。 -->

---

# 面積から1辺を求める

```ts
// 面積から正方形の一辺を求める
const edge = Math.sqrt(49);
```

<!-- ノート: 平方根は二乗すると元の数になる数です。`Math.sqrt` は、ゼロ以上の平方根を返します。平方根が整数にならない面積もあります。 -->

---

# 確かめること

`Math.sqrt(81)` は九です。九を二乗すると八十一になります。

<!-- ノート: `Math.sqrt(81)` は九です。九を二乗すると八十一になります。 -->

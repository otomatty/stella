# 4-1-4 処理を止めて知らせる

<!-- ノート: この動画では、処理を止めて知らせる書き方を学びます。 -->

---

# 条件を満たさない予約を止める

受け付けられない値で処理を続けると、誤った結果を返すことがあります。

<!-- ノート: 席を予約するとき、希望する席数を受け取ります。 予約には、一席以上という決まりがありました。 ゼロ席の申し込みでは、予約を止める必要があります。 -->

---

# 覚えること

throw new Error("理由") で、その場で処理を止めて理由を伝えます。

<!-- ノート: エラーを投げると、その場で処理は続きません。 -->

---

# 処理を止めて知らせる

```ts
// 予約できない理由を知らせて処理を止める
throw new Error("席を選んでください");
```

<!-- ノート: `new Error` で理由を持ったエラーを作り、`throw` で投げます。エラーを投げた呼び出しは、その場で止まり、通常の戻り値を返しません。 -->

---

# 確かめること

希望する席数が一席未満のときはエラーを投げます。一席以上なら、条件の外にある `return` まで進みます。

<!-- ノート: 希望する席数が一席未満のときはエラーを投げます。一席以上なら、条件の外にある `return` まで進みます。 -->

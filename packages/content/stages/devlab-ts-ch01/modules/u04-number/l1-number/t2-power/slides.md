# 毎日同じ倍率で増える

同じ数を何度も書き並べると、いくつ掛けるのかが分かりにくくなります。

<!-- ノート: 植木鉢に、芽が一本生えました。 次の日には、二倍の本数です。 さらに二倍になると、四本になります。 -->

---

# 覚えること

数 `**` 回数 で、その数を回数だけ掛けた数になります。

<!-- ノート: 同じ数を繰り返し掛ける計算が、累乗です。 -->

---

# 同じ数を何回も掛ける

```ts
// 三を四つ掛けた数を入れる
const copies = 3 ** 4;
```

<!-- ノート: 左に数、右に掛け合わせる個数を書きます。たとえば三の四乗では、三を四つ並べて掛けます。右側にゼロを書くと結果は一です。 -->

---

# 確かめること

三に四を掛ける `3 * 4` は十二です。三を四つ掛ける `3 ** 4` は八十一になります。

<!-- ノート: 三に四を掛ける `3 * 4` は十二です。三を四つ掛ける `3 ** 4` は八十一になります。 -->

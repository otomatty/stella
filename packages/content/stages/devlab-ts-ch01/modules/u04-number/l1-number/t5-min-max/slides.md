# 雨が多い日と少ない日を比べる

複数の測定結果から、いちばん大きい数や小さい数を選びたいときがあります。

<!-- ノート: 雨が降った量を、三日分の記録にまとめました。 棒の高さは、それぞれの日の雨量です。 この中から、いちばん多い量と少ない量を選びます。 -->

---

# 覚えること

Math.max はいちばん大きい数、Math.min はいちばん小さい数を返します。

<!-- ノート: 候補のうち、いちばん大きい数が最大です。 -->

---

# 最大と最小を選ぶ

```ts
// 雨量のいちばん大きい値を選ぶ
const wettest = Math.max(24, 31, 17);
// 雨量のいちばん小さい値を選ぶ
const driest = Math.min(24, 31, 17);
```

<!-- ノート: かっこの中に数をカンマで区切って並べます。最大と最小は、数を渡す順番に関係なく決まります。 -->

---

# 確かめること

下限を守るには、希望の値と下限のうち大きい方を選びます。上限を守るときは、小さい方を選びます。

<!-- ノート: 下限を守るには、希望の値と下限のうち大きい方を選びます。上限を守るときは、小さい方を選びます。 -->

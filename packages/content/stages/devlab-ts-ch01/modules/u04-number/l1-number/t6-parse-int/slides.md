# 4-1-6 文字列から数を取り出す

---

# 入力された金額から数を読む

単位の付いた入力から数を取り出し、数字を読めなかった場合も確かめたいときがあります。

<!-- ノート: 金額を文字列で受け取る入力欄です。 先頭に数字があり、その右に円が付きます。 計算には、単位を除いた整数が必要です。 -->

---

# 覚えること

Number.parseInt(文字列, 10) で先頭の整数を取り出します。取り出せないと NaN です。

<!-- ノート: 文字列の先頭から、整数として読める部分を使います。 -->

---

# 文字列から数を取り出す

```ts
// 金額の文字列から整数を取り出す
const price = Number.parseInt("460円", 10);
```

<!-- ノート: 第二引数は、何進数で読むかを決める基数です。`10` は、ゼロから九の数字を使う十進数を指定します。先頭の空白や符号のあとから読み、数字でない文字や小数点で止まります。 -->

---

# 確かめること

整数を一文字も読めないと `NaN` が返ります。`NaN === NaN` は `false` です。取り出せなかったかは `Number.isNaN` で確かめます。

<!-- ノート: 整数を一文字も読めないと `NaN` が返ります。`NaN === NaN` は `false` です。取り出せなかったかは `Number.isNaN` で確かめます。 -->

---

# レッスン4-1 number型

## このレッスンの目標

- [ ] 求めたい値に合わせて、数の計算に使う書き方を選べる
- [ ] 文字列から整数を読み、有限の数か、整数かを確かめられる
- [ ] 受け付けられない値が渡されたときに、処理を止めて理由を伝えられる

## 4-1-1 数の大きさだけを取り出す

> **Math.abs(数) で、マイナスを外した大きさになります。**

q04 では、スターターの関数に引数と戻り値の型注釈を付けます。数値には `number`、文字列には `string`、真偽値には `boolean` を使います。
数直線でゼロからどれだけ離れているかを表す数を、絶対値と呼びます。正の数とゼロはそのまま返ります。
引数と戻り値には型注釈を付けます。問1〜問3で使う四捨五入・切り捨て・切り上げは、順に `Math.round`、`Math.floor`、`Math.ceil` です。

```ts
// 荷物がずれた向きと歩数を記録する
const shift = -11;
// 向きを外して離れた歩数を求める
const distance = Math.abs(shift);
// => distance は 11
```

## 4-1-2 同じ数を何回も掛ける

> **数 `**` 回数 で、その数を回数だけ掛けた数になります。**

左に数、右に掛け合わせる個数を書きます。たとえば三の四乗では、三を四つ並べて掛けます。右側にゼロを書くと結果は一です。

```ts
// 一日ごとの増え方を入れる
const growth = 2;
// 五日後の芽の本数を求める
const sprouts = growth ** 5;
// => sprouts は 32
```

## 4-1-3 面積から1辺を求める

> **Math.sqrt(数) で、2回掛けるとその数になる数 (平方根) になります。**

平方根は二乗すると元の数になる数です。`Math.sqrt` は、ゼロ以上の平方根を返します。平方根が整数にならない面積もあります。

```ts
// 花壇に並べる苗の総数を入れる
const seedlings = 121;
// 正方形に並べたときの一列の数を求める
const perRow = Math.sqrt(seedlings);
// => perRow は 11
```

## 4-1-4 処理を止めて知らせる

> **throw new Error("理由") で、その場で処理を止めて理由を伝えます。**

`new Error` で理由を持ったエラーを作り、`throw` で投げます。エラーを投げた呼び出しは、その場で止まり、通常の戻り値を返しません。
希望する席数が一席未満のときはエラーを投げます。一席以上なら、条件の外にある `return` まで進みます。

```ts
// 希望する席数を確認して返す
function confirmSeats(seats: number): number {
  // 一席より少ないかを確かめる
  if (seats < 1) {
    // 受け付けられない理由を知らせる
    throw new Error("一席以上を選んでください");
  }
  // 受け付けた席数を返す
  return seats;
}
```

## 4-1-5 最大と最小を選ぶ

> **Math.max はいちばん大きい数、Math.min はいちばん小さい数を返します。**

かっこの中に数をカンマで区切って並べます。最大と最小は、数を渡す順番に関係なく決まります。
下限を守るには、希望の値と下限のうち大きい方を選びます。上限を守るときは、小さい方を選びます。

```ts
// 三日分の雨量から最大を求める
const mostRain = Math.max(26, 34, 21);
// 同じ記録から最小を求める
const leastRain = Math.min(26, 34, 21);
// => mostRain は 34、leastRain は 21
```

## 4-1-6 文字列から数を取り出す

> **Number.parseInt(文字列, 10) で先頭の整数を取り出します。取り出せないと NaN です。**

第二引数は、何進数で読むかを決める基数です。`10` は、ゼロから九の数字を使う十進数を指定します。先頭の空白や符号のあとから読み、数字でない文字や小数点で止まります。
整数を一文字も読めないと `NaN` が返ります。`NaN === NaN` は `false` です。取り出せなかったかは `Number.isNaN` で確かめます。

```ts
// 金額の文字列から整数を取り出す
const price = Number.parseInt("460円", 10);
// 先頭から整数を読めなかったか調べる
const missing = Number.isNaN(Number.parseInt("保留", 10));
// => price は 460、missing は true
```

## 4-1-7 計算に使える数か確かめる

> **Number.isFinite(数) は、NaN でも Infinity でもない数なら true です。**

`Infinity` は無限大、`NaN` は数値として表せない結果です。どちらも型は `number` ですが、重さや個数の集計にそのまま使える値ではありません。
正または負の無限大と `NaN` では `Number.isFinite` が `false` を返します。小数やゼロは有限の数です。

```ts
// 箱の数がゼロの記録を割り算に使う
const perBox: number = 48 / 0;
// 数字を含まない記録から整数を読んでみる
const boxCount: number = Number.parseInt("未記録", 10);
// => perBox は Infinity、boxCount は NaN
```

## 4-1-8 斜めの長さを求める

> **Math.hypot(a, b) で、直角三角形の斜めの辺の長さになります。**

直角を作る二辺を渡すと、向かい側にある辺（斜辺）の長さが返ります。長方形の縦と横も直角を作るので、対角線を求められます。
二辺をそれぞれ二乗して足し、その平方根を求める計算です。

```ts
// 壁の高さを入れる
const wall = 12;
// はしごの足から壁までの幅を入れる
const floor = 16;
// はしごの長さを求める
const ladderLength = Math.hypot(wall, floor);
// => ladderLength は 20
```

## 4-1-9 整数かどうか確かめる

> **Number.isInteger(数) で整数か確かめ、! で「そうでない」を表します。**

`Number.isInteger` は整数なら `true`、半端な小数なら `false` を返します。`NaN` や正負の `Infinity` も整数ではありません。
まず `!true` は `false`、`!false` は `true` です。整数か確かめる式の前に `!` を付ければ、整数でないときに `true` になります。

```ts
// 真偽値を反対にして入れる
const opposite = !true;
// 注文された個数を入れる
const orderCount = 8.75;
// 注文数が整数かを確かめる
const whole = Number.isInteger(orderCount);
// 注文数が整数でないかを確かめる
const fractional = !Number.isInteger(orderCount);
// => opposite と whole は false、fractional は true
```

## 問題ごとのヒント

動画を見たあと、案内された問題に取り組みます。同じ動画に続く問題は、確認して提出すると順に開きます。引数と戻り値の型にも注目しましょう。

### 問 1 小数点以下を四捨五入する

**テストで確かめる値**

- `roundOff(2.5)`：`3`
- `roundOff(2.4)`：`2`

**ヒント**

小数を最も近い整数に丸めるには、1-3-6 の `Math.round` を使います。引数と戻り値の型はどちらも `number` です。

### 問 2 1 の位を切り捨てる（10 の倍数にする）

**テストで確かめる値**

- `floorTo10(123)`：`120`
- `floorTo10(9)`：`0`（10 より小さいと 0）

**ヒント**

十を一まとまりとして数えます。十で割ってから `Math.floor` で切り捨てると、まとまりがいくつあるか分かります。

### 問 3 100 の倍数に切り上げる

**テストで確かめる値**

- `ceilTo100(101)`：`200`
- `ceilTo100(100)`：`100`（100 の倍数はそのまま）

**ヒント**

百を一まとまりとして数えます。百で割った結果に `Math.ceil` を使うと、必要なまとまりの数を切り上げられます。

### 問 4 2 つの数の差の大きさ（絶対値）を返す

**テストで確かめる値**

- `absDiff(3, 10)`：`7`
- `absDiff(10, 3)`：`7`（順番を入れ替えても同じ）

**ヒント**

二つの数を引くと、渡す順番によって差が負になることがあります。4-1-1 の `Math.abs` で差の大きさを取り出します。

### 問 5 a を b で割った余りを返す

**テストで確かめる値**

- `remainder(10, 3)`：`1`
- `remainder(9, 3)`：`0`（割り切れると 0）

**ヒント**

割り算の商ではなく、余りが欲しいときの記号は `%` です。引数の順に、割られる数と割る数を置きます。

### 問 6 n が base の倍数なら true を返す

**テストで確かめる値**

- `isMultipleOf(12, 4)`：`true`（12 は 4 の倍数）
- `isMultipleOf(10, 4)`：`false`

**ヒント**

割り切れるときの余りがいくつかを考えます。`===` で比べた結果は `boolean` なので、そのまま返せます。

### 問 7 3 乗した数を返す

**テストで確かめる値**

- `cube(3)`：`27`（3 × 3 × 3）
- `cube(-2)`：`-8`（(-2) × (-2) × (-2)）

**ヒント**

4-1-2 の `**` の左側に、繰り返し掛ける数を置きます。右側には、並べて掛ける個数を書きます。

### 問 8 平方根を返す。負の数ならエラーを投げる

**テストで確かめる値**

- `squareRoot(9)`：`3`
- `squareRoot(2)`：`1.41421…`（1.41421 にほぼ等しければよい）
- `squareRoot(-1)`：エラーを投げる

**ヒント**

負の数を受け取ったときは、4-1-4 のように条件の内側で処理を止めます。条件に合わない場合は、4-1-3 の `Math.sqrt` で平方根を求めます。

### 問 9 value を min 以上 max 以下に収める

**テストで確かめる値**

- `clamp(15, 0, 10)`：`10`（大きすぎるので max）
- `clamp(-5, 0, 10)`：`0`（小さすぎるので min）
- `clamp(5, 0, 10)`：`5`（範囲の中なのでそのまま）

**ヒント**

4-1-5 を見返し、下限を下回らない値を選ぶときと、上限を超えない値を選ぶときで、どちらの関数を使うか考えます。

### 問 10 小数第 1 位までの文字列にする

**テストで確かめる値**

- `toFixed1(3.14159)`：`"3.1"`（文字列）
- `toFixed1(2)`：`"2.0"`

**ヒント**

3-1-8 の `toFixed` に、残す小数の桁数を渡します。戻り値の型は `string` です。

### 問 11 文字列の先頭の整数を取り出す。取り出せなければ 0

**テストで確かめる値**

- `parseIntOrZero("42px")`：`42`
- `parseIntOrZero("abc")`：`0`（取り出せない）
- `parseIntOrZero("-7")`：`-7`（マイナスも取り出せる）

**ヒント**

4-1-6 と同じように、十進数で先頭の整数を読みます。その結果を `Number.isNaN` で確かめ、読めなかった場合の値を選びます。

### 問 12 NaN でも Infinity でもない数なら true を返す

**テストで確かめる値**

- `isFiniteNumber(1.5)`：`true`
- `isFiniteNumber(NaN)`：`false`
- `isFiniteNumber(-Infinity)`：`false`（マイナスの無限大）

**ヒント**

4-1-7 の確認は、小数でも有限なら `true` です。正と負の無限大や `NaN` もテストで確かめます。

### 問 13 part が total の何パーセントかを、整数に四捨五入して返す

**テストで確かめる値**

- `percentOf(1, 3)`：`33`
- `percentOf(2, 3)`：`67`（66.66… を四捨五入）
- `percentOf(5, 5)`：`100`

**ヒント**

まず全体に占める部分の割合を求めます。百分率にしてから、整数に四捨五入する順番です。

### 問 14 2 つの数の平均を返す

**テストで確かめる値**

- `average2(3, 8)`：`5.5`
- `average2(-2, 2)`：`0`

**ヒント**

二つの数を足すのが先です。一つの式にするときは、足し算をかっこで囲みます。

### 問 15 分を秒に変える

**テストで確かめる値**

- `minutesToSeconds(1.5)`：`90`（1 分 30 秒）
- `minutesToSeconds(0)`：`0`

**ヒント**

一分に何秒あるかを考えます。小数の分数でも、同じ掛け算で秒に直せます。

### 問 16 km を m に変える

**テストで確かめる値**

- `kmToMeters(1.5)`：`1500`
- `kmToMeters(42.195)`：`42195`（フルマラソンの距離）

**ヒント**

一キロメートルに何メートルあるかを考えます。問15 と同じく、単位の関係を使った掛け算です。

### 問 17 直角三角形の 2 辺から、斜辺の長さを返す

**テストで確かめる値**

- `hypotenuse(3, 4)`：`5`
- `hypotenuse(5, 12)`：`13`

**ヒント**

4-1-8 の `Math.hypot` に、直角を作る二辺を渡します。`Math.sqrt` を使うなら、それぞれの二乗を足した数の平方根を求めます。

### 問 18 0 以上の整数の桁数を返す

**テストで確かめる値**

- `digitCount(12345)`：`5`
- `digitCount(0)`：`1`

**ヒント**

テンプレートリテラルに数を埋め込むと、文字列にできます。`length` で調べるのは、その文字列の文字数です。

### 問 19 小数第 2 位までに四捨五入する

**テストで確かめる値**

- `roundTo2(1.234)`：`1.23`
- `roundTo2(9.876)`：`9.88`
- `roundTo2(3)`：`3`

**ヒント**

丸めたい桁を整数の位置まで移動してから `Math.round` を使います。丸めたあと、桁の位置を元に戻します。

### 問 20 華氏を摂氏に変え、小数第 1 位までに四捨五入する

**テストで確かめる値**

- `fahrenheitToCelsius(98.6)`：`37`
- `fahrenheitToCelsius(212)`：`100`（水が沸く温度）
- `fahrenheitToCelsius(50)`：`10`

**ヒント**

まず課題文の式で摂氏を求めます。問19 と同じ考え方で、小数第何位にそろえるかに合わせて倍率を選びます。

### 応用（総合） 指定した桁までに四捨五入する関数と、パーセントを返す関数

**テストで確かめる値**

- `roundTo(3.14159, 2)`：`3.14`
- `roundTo(1234.5678, 1)`：`1234.6`
- `roundTo(2.5, 0)`：`3`（小数第 0 位は整数）
- `roundTo(10, 3)`：`10`
- `roundTo(NaN, 2)`：エラーを投げる（Infinity のときも）
- `roundTo(1, 1.5)`：エラーを投げる（digits が整数でない）
- `roundTo(1, -1)`：エラーを投げる（digits が 0 より小さい）
- `roundTo(1, 11)`：エラーを投げる（digits が 10 より大きい）
- `percent(1, 3)`：`33.3`
- `percent(2, 3)`：`66.7`
- `percent(5, 5)`：`100`
- `percent(0, 8)`：`0`
- `percent(1, 0)`：エラーを投げる（total が 0）

**ヒント**

桁数は、4-1-9 の方法で整数か確かめ、上下の境目も調べます。丸める倍率は固定せず、桁数に合わせて累乗で求めます。百分率を返す関数では、全体がゼロなら処理を止め、自分で作った丸める関数を呼びます。

# 壁と床からはしごの長さを求める

縦と横の長さが分かっていても、足し算では斜めの長さは求まりません。

<!-- ノート: はしごを置くと、壁と床で直角ができます。 壁の高さと、床の幅は測れました。 必要なのは、その先を結ぶ斜めの長さです。 -->

---

# 覚えること

Math.hypot(a, b) で、直角三角形の斜めの辺の長さになります。

<!-- ノート: 直角の向かい側にある辺が、斜辺です。 -->

---

# 斜めの長さを求める

```ts
// 壁と床の長さからはしごの長さを求める
const ladder = Math.hypot(6, 8);
```

<!-- ノート: 直角を作る二辺を渡すと、向かい側にある辺（斜辺）の長さが返ります。長方形の縦と横も直角を作るので、対角線を求められます。 -->

---

# 確かめること

二辺をそれぞれ二乗して足し、その平方根を求める計算です。

<!-- ノート: 二辺をそれぞれ二乗して足し、その平方根を求める計算です。 -->

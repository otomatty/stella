# 2-1-4 文字列をくり返す

<!-- ノート: この動画では、同じ文字列をくり返し並べる方法を学びます。 -->

---

# 同じ印を並べたい

評価の数に合わせて、画面に同じ印を並べます。毎回、印を一つずつ書く必要があるでしょうか。

<!-- ノート: 一つのスタンプを用意しました。 押す回数を変えれば、模様の数も変わります。 -->

---

# 覚えること

.repeat(回数) で、同じ文字列を回数だけ並べられます。

<!-- ノート: 同じ文字列を並べるメソッドが、repeat です。 かっこの中の 4 が、くり返す回数です。 -->

---

# 文字列をくり返す

```ts
// くり返す音を用意する
const sound = "ぽん";
// 音の「ぽん」を続けて並べる
const echo = sound.repeat(4);
```

<!-- ノート: 音の「ぽん」を、続けて並べてみましょう。今回は、同じ音を 4 回くり返します。途中に区切りが入ることはありません。できた文字列を、echo に入れます。 -->

---

# 空白も一緒にくり返す

空白を含む文字列をくり返すと、その空白も毎回残ります。回数が 0 なら、結果は空の文字列です。

参考資料は[サバイバルTypeScript: string型 (string)](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

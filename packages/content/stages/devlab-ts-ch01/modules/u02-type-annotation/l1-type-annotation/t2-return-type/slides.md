# 戻り値に型を書く

```ts
// 税抜価格を受け取って、税額を返す関数
function tax(price: number): number {
  // 値段に税率を掛けて返す
  return price * 0.08;
}
```

<!-- ノート: 税額を求める関数を、呼び出してみましょう。商品の価格として、250 を渡します。価格に税率を掛けた結果は、20 です。税額は数値なので、戻り値の型に合いました。 -->

---

# 返す値と型をそろえる

戻り値の型を `number` にした関数から文字列を返そうとすると、型の確認でエラーになります。

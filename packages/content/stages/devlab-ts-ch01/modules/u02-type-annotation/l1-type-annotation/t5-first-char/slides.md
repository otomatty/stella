# 名前を一文字で表示する

利用者の名前の先頭を、画面の小さな印に表示します。長さの違う名前から、同じ位置の文字をどう取り出すでしょうか。

<!-- ノート: 文字を一枚ずつ、左から順に並べました。 最初のカードを選ぶために、0番へ戻りましょう。 -->

---

# 覚えること

`文字列.charAt(番号)` で、その番号の1文字を取り出せます。番号は 0 から数えます。

<!-- ノート: 文字の位置を表す番号を、添字と呼びます。チャーアットの丸かっこに番号を入れます。ゼロは、最初の位置を表します。 -->

---

# 最初の1文字を取り出す

```ts
// 都市名を用意する
const city = "神戸";
// 都市名の最初の文字を取り出す
const cityMark = city.charAt(0);
```

<!-- ノート: 都市名の神戸を、左から見てみましょう。チャーアットの丸かっこにゼロを入れます。取り出した文字は、神です。その一文字を、シティマークに入れました。 -->

---

# 番号は左から順に付く

最初は 0 番、次は 1 番です。文字が三つ並んでいるとき、最後の番号は 2 です。

参考資料は[サバイバルTypeScript: string型 (string)](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

# 覚えること

引数の名前の後ろに、コロンと型を書きます。

# 引数に型を書く

```ts
// 名前を受け取って、歓迎の文を返す関数
function welcome(name: string) {
  // 受け取った名前を歓迎の文に埋め込んで返す
  return `ようこそ、${name}！`;
}
```

<!-- ノート: 受付で名前を受け取り、歓迎の文を作りましょう。渡す「ミオ」は文字列です。引数に名前が入り、その名前を文の中に埋め込みます。名前に合った歓迎の文ができました。 -->

---

# 型を付け忘れると

この課題の設定では、型を書かずに引数を宣言すると、引数が暗黙に `any`（どんな種類の値も許す型）になってエラーが出ます。

参考資料は[サバイバルTypeScript: 型注釈 (type-annotation)](https://typescriptbook.jp/reference/values-types-variables/type-annotation)です。コード例は教材用に作成しています。

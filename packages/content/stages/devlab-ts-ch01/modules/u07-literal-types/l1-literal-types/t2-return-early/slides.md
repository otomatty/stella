# 7-1-2 条件に合ったらその場で返す

<!-- ノート: この動画では、条件に合ったらその場で値を返す書き方を学びます。 -->

---

# お湯の表示を決める

90度以上は「熱い」、60度以上は「適温」、それ以外は「ぬるい」と表示します。75度なら、どこで表示が決まるでしょうか。

<!-- ノート: 上の条件から順に確かめてみましょう。 -->

---

# 覚えること

if の中で return すると、関数はそこで終わります。

<!-- ノート: 値を返したあと、関数の後ろの行へは進みません。 -->

---

# 条件に合う値を返す

```ts
// お湯の温度から表示を決める
function waterLabel(temp: number): "熱い" | "適温" | "ぬるい" {
  if (temp >= 90) {
    return "熱い";
  }
  if (temp >= 60) {
    return "適温";
  }
  return "ぬるい";
}
```

<!-- ノート: 75度は最初の条件に合いません。次の条件に合うので適温を返し、最後の return には進みません。 -->

---

# 後ろの行は実行されない

`waterLabel(75)` は `"適温"` を返して終わります。

`return "ぬるい";` に来るのは、前の2つの条件に合わなかったときだけです。

<!-- ノート: else を何重にも重ねず、条件を上から順に確かめる形で書けます。 -->

---

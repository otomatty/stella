# 7-1-2 条件に合ったらその場で返す

# お湯の表示を決める

90度以上は「熱い」、それ以外は「ぬるい」と表示します。95度なら、どこで表示が決まるでしょうか。

<!-- ノート: 上の条件から順に確かめてみましょう。 -->

---

# 覚えること

if の中で return すると、関数はそこで終わります。

<!-- ノート: 値を返したあと、関数の後ろの行へは進みません。 -->

---

# 条件に合う値を返す

```ts
function waterLabel(temp: number): "熱い" | "ぬるい" {
  if (temp >= 90) {
    return "熱い";
  }
  return "ぬるい";
}
console.log(waterLabel(95), waterLabel(75)); // => "熱い" "ぬるい"
```

<!-- ノート: ここでは条件を90度以上の1つに絞ります。95度は熱いを返して終わり、75度は最後の return でぬるいを返します。呼び出して両方の結果を表示しています。 -->

---

# 後ろの行は実行されない

`waterLabel(95)` は `"熱い"` を返して終わります。

`return "ぬるい";` に来るのは、90度以上の条件に合わなかったときだけです。

<!-- ノート: 95度では if の中で返すので、最後の行には進みません。まとめと動画では、60度以上の条件も加えた例を扱います。 -->

---

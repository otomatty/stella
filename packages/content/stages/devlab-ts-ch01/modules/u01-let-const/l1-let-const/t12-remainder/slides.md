# 残った数は？

14 個の卵を、4 個入りのパックに詰めます。

パックに入らずに残る卵は、コードでどう求めるのでしょうか。

<!-- ノート: 3 パックできて 2 個残ります。この残りを求める書き方を問いにします。答えはまだ言いません。 -->

---

# 覚えること

割り算の余りは、パーセントという記号で求めます。

割り切れるときの余りは、0 です。

<!-- ノート: パーセントの記号は、ここでは割合ではなく、割り算の余りを求める記号です。14 を 4 で割ると 3 あまり 2 なので、left には 2 が入ります。left は、残りという意味の英語です。 -->

---

# パーセントで余りを求める

```ts
// 余り left を作り、14 を 4 で割った余りを入れる
const left = 14 % 4;
```

<!-- ノート: パーセントの記号は、ここでは割合ではなく、割り算の余りを求める記号です。14 を 4 で割ると 3 あまり 2 なので、left には 2 が入ります。left は、残りという意味の英語です。 -->

---

# 割り算と組み合わせる

`Math.floor(14 / 4)` は `3`、`14 % 4` は `2` です。3 パックと 2 個だと分かります。

`12 % 4` のように割り切れるときは、余りは `0` です。

参考: サバイバルTypeScript [number型](https://typescriptbook.jp/reference/values-types-variables/number)。説明と例は教材用に独自作成しています。

<!-- ノート: ここでは 0 以上の整数を、正の整数で割ります。余りは 0 から割る数の手前までです。 -->

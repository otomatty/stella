# 1-1-10 余りと文字の組み立て

<!-- ノート: 余りと文字の組み立てを、コードと値の動きで確かめます。 -->

---

# 残った数を案内文にできる？

14 個の卵を、4 個ずつパックに詰めます。

残った数を、文字で知らせるにはどう書くでしょうか。

<!-- ノート: 割り算で分けたあとに残る数と、文への埋め込みを問いにします。 -->

---

# 覚えること

余りを求め、テンプレートリテラルに値を埋め込むと、数を説明する文を作れます。

`%` は割った余り、`${式}` は文に埋め込む値です。

<!-- ノート: 4個ずつ3組にすると2個残ります。余りは2です。ここでは0以上の整数を扱います。余りは0から割る数の手前までです。バッククォートで囲み、ドル記号と波かっこで値を埋め込みます。文字列の型はstringです。 -->

---

# 書き方を読む

```ts
// 余り left を作り、14 を 4 で割った余りを入れる
const left = 14 % 4;
// 案内文 message を作り、余りの数を埋め込む
const message = `残りは${left}個です`;
```

<!-- ノート: 4個ずつ3組にすると2個残ります。余りは2です。ここでは0以上の整数を扱います。余りは0から割る数の手前までです。バッククォートで囲み、ドル記号と波かっこで値を埋め込みます。文字列の型はstringです。 -->

---

# よくある間違い

普通の引用符では `${left}` も文字のままです。

この課題では文字列を `+` でつなぐと、lint のエラーになります。

参考: [サバイバルTypeScript: number型](https://typescriptbook.jp/reference/values-types-variables/number)・[サバイバルTypeScript: string型](https://typescriptbook.jp/reference/values-types-variables/string)。説明と例は教材用に独自作成しています。

<!-- ノート: バッククォートは日本語配列でShiftと@、英語配列で1の左のキーです。lint は決まりを確かめる検査です。問3は時間と残りの分を文字列にします。余りとテンプレートリテラルで書いてみましょう。 -->

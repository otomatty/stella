# 1-1-14 計算の順番

<!-- ノート: 計算の順番を、身近な例とコードで確かめます。 -->

---

# 600 円のはずが 1000 円？

800 円の品物と 400 円の送料を、2 人で払います。

`800 + 400 / 2` と書くと、結果はいくつになるでしょうか。

<!-- ノート: 足してから割るつもりで 1 行に書くと、割り算が先に計算されます。答えはまだ言いません。 -->

---

# 覚えること

掛け算と割り算は、足し算より先に計算されます。

先に足したいときは、合計を変数に入れてから割ります。

<!-- ノート: 1 行めで 800 と 400 を足し、結果の 1200 を total に入れます。2 行めで、その total を 2 で割ります。行を分けると、計算の順番を自分で決められます。 -->

---

# 合計を先に作る

```ts
// 合計 total を作り、800 と 400 を足す
const total = 800 + 400;
// 1 人分 share を作り、合計を 2 で割る
const share = total / 2;
```

<!-- ノート: 1 行めで 800 と 400 を足し、結果の 1200 を total に入れます。2 行めで、その total を 2 で割ります。行を分けると、計算の順番を自分で決められます。 -->

---

# 1 行で書くと

`800 + 400 / 2` は `1000` です。`400 / 2` が先に計算され、その `200` に `800` が足されます。

掛け算も同じです。`2 + 3 * 4` は `14` です。

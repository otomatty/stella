# 同じ数ずつ分けるには？

12 枚のクッキーを、3 人で同じ数ずつ分けます。

1 人分の枚数は、コードでどう計算するのでしょうか。

# 覚えること

割り算は、スラッシュという記号で書きます。

割り切れないときは、結果が小数になります。

<!-- ノート: 割り算の記号は、右上がりの斜めの線のスラッシュです。12 割る 3 の結果の 4 が、変数 each に入ります。each は、それぞれという意味の英語です。 -->

---

# スラッシュで割る

```ts
// 1 人分 each を作り、12 を 3 で割る
const each = 12 / 3;
```

<!-- ノート: 割り算の記号は、右上がりの斜めの線のスラッシュです。12 割る 3 の結果の 4 が、変数 each に入ります。each は、それぞれという意味の英語です。 -->

---

# 割り切れないとき

`7 / 2` の結果は `3.5` です。整数どうしで割っても、割り切れなければ小数になります。

端数が勝手に切り捨てられることはありません。

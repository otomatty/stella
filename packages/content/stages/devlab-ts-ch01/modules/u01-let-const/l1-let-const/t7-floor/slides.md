# 19.8 ポイント？

買い物の金額から、ポイントを計算しました。

小数になったポイントは、どう扱うのでしょうか。

<!-- ノート: 掛け算の結果は、小数になることがあります。ここでは、小数点から下を捨てる書き方を見ます。答えはまだ言いません。 -->

# 覚えること

Math.floor を使うと、小数点以下を切り捨てた整数になります。

四捨五入ではないので、19.8 は 19 になります。

<!-- ノート: Math.floor は、最初から用意されている関数です。かっこの中に渡した数の、小数点から下を切り捨てます。19.8 を渡すと 19 が戻り、points に入ります。 -->

---

# Math.floor で切り捨てる

```ts
// ポイント points を作り、19.8 を切り捨てた結果を入れる
const points = Math.floor(19.8);
```

<!-- ノート: Math.floor は、最初から用意されている関数です。かっこの中に渡した数の、小数点から下を切り捨てます。19.8 を渡すと 19 が戻り、points に入ります。 -->

---

# 四捨五入ではない

`Math.floor(7.9)` は、`8` ではなく `7` です。

小数点から下は、どんな数でも捨てます。

参考: サバイバルTypeScript [number型](https://typescriptbook.jp/reference/values-types-variables/number)。説明と例は教材用に独自作成しています。

<!-- ノート: 7.9 は 8 に近い数ですが、Math.floor は四捨五入をしません。小数点から下をそのまま捨てるので、7 になります。 -->

# 3 冊でいくら？

1200 円の本を、3 冊買います。

かける記号は、キーボードのどこにあるのでしょうか。

<!-- ノート: 足し算はプラスの記号で書けました。掛け算は、算数とは違う記号を使います。答えはまだ言いません。 -->

---

# 覚えること

掛け算は、アスタリスクという記号で書きます。

算数のかける記号 × は使いません。

<!-- ノート: 掛け算は、アスタリスクという星のような記号で書きます。1200 掛ける 3 の結果の 3600 が cost に入ります。cost は費用という意味の英語です。 -->

---

# アスタリスクで掛ける

```ts
// 3 冊分の金額 cost を作り、1200 に 3 を掛けた結果を入れる
const cost = 1200 * 3;
```

<!-- ノート: 掛け算は、アスタリスクという星のような記号で書きます。1200 掛ける 3 の結果の 3600 が cost に入ります。cost は費用という意味の英語です。 -->

---

# 小数も掛けられる

`800 * 0.5` は、800 の半分で `400` です。

小数を掛けるときも、同じ記号で書きます。

参考: サバイバルTypeScript [number型](https://typescriptbook.jp/reference/values-types-variables/number)。説明と例は教材用に独自作成しています。

<!-- ノート: 0.5 を掛けると半分になります。割合を掛けて一部分を求めるときにも、アスタリスクを使います。 -->

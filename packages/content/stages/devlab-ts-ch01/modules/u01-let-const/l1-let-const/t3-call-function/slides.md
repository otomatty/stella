# 覚えること

関数は、名前の後ろのかっこに値を書いて呼び出すと動きます。

関数を使うことを「呼び出す」と言い、渡した値が引数に入ります。

<!-- ノート: 関数の名前の後ろにかっこを書き、その中に渡す値を書くと、関数が呼び出されます。1200 が引数 price に入り、中で 500 を足した 1700 が、呼び出した場所に戻ります。 -->

---

# 値を渡して呼び出す

```ts
// 本の値段を受け取り、支払う金額を返す関数
function addShipping(price: number): number {
  // 受け取った値段に、送料の 500 を足して返す
  return price + 500;
}
// 1200 円の本の値段を渡して、関数を呼ぶ
addShipping(1200);
```

<!-- ノート: 関数の名前の後ろにかっこを書き、その中に渡す値を書くと、関数が呼び出されます。1200 が引数 price に入り、中で 500 を足した 1700 が、呼び出した場所に戻ります。 -->

---

# 何度でも呼び出せる

`addShipping(800)` と書けば、同じ関数を別の値で呼び出せます。戻り値は `1300` です。

`export` は、ほかのファイルからその関数を呼び出せるようにする印です。

参考: サバイバルTypeScript [関数宣言](https://typescriptbook.jp/reference/functions/function-declaration)。説明と例は教材用に独自作成しています。

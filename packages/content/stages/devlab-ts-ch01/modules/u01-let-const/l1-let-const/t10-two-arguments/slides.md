# 値が2つ必要なときは？

切符の合計は、料金と枚数の両方が分からないと計算できません。

関数は、値を2つ受け取れるのでしょうか。

<!-- ノート: これまでの関数は、受け取る値が 1 つでした。2 つの値が要る計算を問いにします。答えはまだ言いません。 -->

---

# 覚えること

引数は、カンマで区切って2つ以上受け取れます。

呼び出すときは、渡した順番のとおりに引数へ入ります。

<!-- ノート: かっこの中に、引数をカンマで区切って並べます。どの引数にも型注釈を書きます。呼び出すときも、渡す値をカンマで区切ります。1 つめの 200 が fare に、2 つめの 3 が count に入ります。 -->

---

# カンマで区切る

```ts
// 料金と枚数を受け取り、合計の金額を返す関数
function ticketTotal(fare: number, count: number): number {
  // 料金に枚数を掛けて返す
  return fare * count;
}
// 200 円の切符を 3 枚で、関数を呼ぶ
ticketTotal(200, 3);
```

<!-- ノート: かっこの中に、引数をカンマで区切って並べます。どの引数にも型注釈を書きます。呼び出すときも、渡す値をカンマで区切ります。1 つめの 200 が fare に、2 つめの 3 が count に入ります。 -->

---

# 順番に気を付ける

渡した値は、書いた順番のとおりに引数へ入ります。

割り算のように順番で結果が変わる計算では、渡す順番を間違えると答えが変わります。

参考: サバイバルTypeScript [関数宣言](https://typescriptbook.jp/reference/functions/function-declaration)。説明と例は教材用に独自作成しています。

<!-- ノート: 引数の数は 3 つ以上にもできます。問4 の関数は、引数を 3 つ受け取ります。 -->

# 1-1-13 文字列に値を埋め込む

<!-- ノート: 文字列に値を埋め込むを、身近な例とコードで確かめます。 -->

---

# 文の途中に値を入れるには？

「ノートを 3 冊注文しました」の 3 は、注文ごとに変わります。

変わる部分だけを、あとから入れられるのでしょうか。

<!-- ノート: 文のひな形に穴を空けて、そこに値を入れる考え方を問いにします。答えはまだ言いません。 -->

---

# 覚えること

テンプレートリテラルを使うと、文字列の中に値を埋め込めます。

全体をバッククォートで囲み、値を入れる場所をドル記号と波かっこで書きます。

<!-- ノート: 全体を囲んでいるのは、引用符ではなくバッククォートです。ドル記号と波かっこの中に書いた変数 count が、その値の 3 に置きかわります。数値も、文字として文の中に入ります。 -->

---

# 値を埋め込む

```ts
// 冊数 count を作り、3 を入れる
const count = 3;
// 案内文 message を作り、冊数を埋め込む
const message = `ノートを${count}冊注文しました`;
```

<!-- ノート: 全体を囲んでいるのは、引用符ではなくバッククォートです。ドル記号と波かっこの中に書いた変数 count が、その値の 3 に置きかわります。数値も、文字として文の中に入ります。 -->

---

# よくある間違い

普通の引用符で囲むと、`${count}` は値に置きかわらず、そのままの文字になります。

この課題では、文字列を `+` でつなぐと lint のエラーになります。

参考: サバイバルTypeScript [string型](https://typescriptbook.jp/reference/values-types-variables/string)。説明と例は教材用に独自作成しています。

<!-- ノート: バッククォートは、日本語配列では Shift と @、英語配列では数字の 1 の左のキーです。lint は、コードが決まりに合うかを確かめる検査です。 -->

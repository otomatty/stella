# レッスン1-2 くり返しで値を変える

## このレッスンの目標

- [ ] let の入れ直しと for の実行順を説明できる
- [ ] 数える向きと回数を変え、ゼロ回のときの動きを説明できる
- [ ] 文字を一つずつ取り出し、条件やつなぐ順番を読める

## 1-2-1 入れ直せる変数

> **let で作った変数は、あとから値を入れ直せます。**

作った変数にあとから値を入れ直すことを「再代入」と呼びます。作るときに `let` を書き、入れ直すときは変数名から書きます。入れ直さない値は `const` で作ります。下の関数に `500` を渡すと `600` が返ります。

```ts
// 値段を受け取り、手数料込みの金額を返す関数を作る
function addFee(price: number): number {
  // 金額を入れ直せる変数として作る
  let amount = price;
  // 金額に手数料を足して入れ直す
  amount = amount + 100;
  // 手数料込みの金額を返す
  return amount;
// 関数の中身はここまで
}
```

## 1-2-2 足して入れ直す

> **+= は足して入れ直し、++ は 1 増やします。**

`total += 100` は `total = total + 100` と同じ動きです。`count++` は `count = count + 1` と同じように、値を 1 増やします。どちらも入れ直しなので、変数は `let` で作ります。

```ts
// 今の貯金額を作る
let total = 200;
// 今のスタンプの数を作る
let count = 4;
// 貯金額に百円を足す
total += 100;
// スタンプの数を一つ増やす
count++;
```

## 1-2-3 for でくり返す

> **for は、始め・続ける条件・進め方を決めて、同じ処理をくり返します。**

`for` のかっこには、始め・続ける条件・進め方を `;` で区切って書きます。始めは一度だけ実行します。その後は条件を調べ、中身を実行し、次に進みます。条件が `true` の間は続き、`false` になったら終了します。この例では 1 から 5 までを足し、`total` は 15 になります。

```ts
// 合計を入れる変数を作る
let total = 0;
// 一周目から五周目まで一周ずつ進む
for (let i = 1; i <= 5; i++) {
  // 周回の番号を合計に足す
  total += i;
// くり返しの中身はここまで
}
```

## 1-2-4 掛けて入れ直す

> ***= は掛けて入れ直します。掛け算を重ねるときは 1 から始めます。**

`result *= 2` は、今の値に 2 を掛けて `result` に入れ直します。掛け算を重ねる例では 1 から始めます。0 を最初に入れると、何を掛けても 0 のままです。下の例では `result` が 24 になります。

```ts
// 掛け算の結果を一から始める
let result = 1;
// 一から四まで一ずつ進む
for (let i = 1; i <= 4; i++) {
  // 今の結果に番号を掛ける
  result *= i;
// くり返しの中身はここまで
}
```

## 1-2-5 逆向きに数える

> **i-- で 1 ずつ減らし、>= で終わりを決めると、大きい数から数えられます。**

`>=` は「以上」です。始めを大きい数にし、`i--` で一周に 1 ずつ減らします。この例は 5、4、3、2、1 の順に表示します。次に 0 になると条件が成り立たず、表示せずに終了します。

```ts
// 五から一まで一ずつ減らす
for (let i = 5; i >= 1; i--) {
  // その回の番号を表示する
  console.log(i);
// くり返しの中身はここまで
}
```

## 1-2-6 文字列をつないでいく

> **文字列も += で後ろにつないでいけます。**

空の文字列 `""` は、文字を一つも含まない値です。文字列に `+=` を使うと、右側の文字列を今の値の後ろにつないで入れ直します。数を文字列に入れるにはテンプレートリテラルを使います。下の例では `"3 2 1 "` になり、最後にも空白が残ります。

```ts
// つなぐ先に空の文字列を入れる
let text = "";
// 三から一まで一ずつ減らす
for (let i = 3; i >= 1; i--) {
  // 番号と空白を今の文字列の後ろにつなぐ
  text += `${i} `;
// くり返しの中身はここまで
}
```

## 1-2-7 回数を決めてくり返す

> **0 から始めて < n まで進めると、ちょうど n 回くり返せます。**

`<` は「より小さい」です。0 から 3 の手前までなら、0、1、2 の 3 回です。番号は回数を数えるためだけに使います。回数が 0 なら一度も実行しません。下の例の結果は `"ok ok ok "` です。

```ts
// つなぐ先に空の文字列を入れる
let log = "";
// ゼロから三の手前まで一ずつ増やす
for (let i = 0; i < 3; i++) {
  // 今の文字列の後ろに印と空白をつなぐ
  log += "ok ";
// くり返しの中身はここまで
}
```

## 1-2-8 1文字ずつ取り出す

> **for-of は、文字列から 1 文字ずつ取り出してくり返します。**

`of` の右に文字列を書き、左で取り出す文字の名前を決めます。一周ごとに新しい `c` を作るので、`const` が使えます。空の文字列では一度もくり返しません。下の例の `count` は 2 になります。

```ts
// 文字の数をゼロから始める
let count = 0;
// 「ねこ」から一文字ずつ取り出す
for (const c of "ねこ") {
  // 一文字取り出すたびに個数を増やす
  count++;
// くり返しの中身はここまで
}
```

## 1-2-9 合うときだけ数える

> **if と === で、条件に合うときだけ処理できます。**

`if` のかっこに条件を書き、条件が `true` のときだけ波かっこの中を実行します。`===` は二つの値が等しいかを調べる印です。`=` は右の値を左へ入れます。下の例では、エヌが現れる二回だけ個数が増えます。

```ts
// 合った文字の個数をゼロから始める
let count = 0;
// 英字の列から一文字ずつ取り出す
for (const c of "banana") {
  // 取り出した文字がエヌと等しいか調べる
  if (c === "n") {
    // 合うときに個数を一つ増やす
    count++;
  // 条件に合う処理はここまで
  }
// くり返しの中身はここまで
}
```

## 1-2-10 前につないで逆順にする

> **取り出した文字を前につなぐと、逆の順番になります。**

文字列の `+` は、左に書いた文字列の後ろに右の文字列をつなぎます。`result += c` では、取り出した文字が今の値の後ろに来ます。前につなぐときは新しい文字を `+` の左に置きます。下の例は `"123"` を `"321"` にします。

```ts
// つなぐ先に空の文字列を入れる
let result = "";
// 数字の文字列から一文字ずつ取り出す
for (const c of "123") {
  // 取り出した文字を今までの結果の前につなぐ
  result = c + result;
// くり返しの中身はここまで
}
```

**テストで確かめる値**

- `sumTo(10)` は `55`（1 + 2 + … + 10）
- `sumTo(1)` は `1`
- `sumTo(0)` は `0`

**ヒント 1 日本語の手順**

```ts
export function sumTo(n: number): number {
  // 合計 total を入れ直せる変数として作り、0 を入れる
  // i を 1 から n まで 1 ずつ増やしながらくり返す
  //   total に i を足す
  // total を返す
}
```

**ヒント 2 コードへの直し方**

1-2-3 の周回の例では、最後の数は 5 でした。この問題では、引数 `n` を最後の数にします。

### 問 6 n の階乗を返す

**テストで確かめる値**

- `factorial(5)` は `120`
- `factorial(1)` は `1`
- `factorial(0)` は `1`

**ヒント 1 日本語の手順**

```ts
export function factorial(n: number): number {
  // 結果 result を入れ直せる変数として作り、1 を入れる
  // i を 2 から n まで 1 ずつ増やしながらくり返す
  //   result に i を掛ける
  // result を返す
}
```

**ヒント 2 コードへの直し方**

「掛ける」は `*=` です。`result` を 0 から始めると、何を掛けても 0 のままです。`n` が 0 や 1 のときは、くり返しの中は 1 回も実行されず、1 を返します。

- `countDown(1)` は `"1, 発射"`

**ヒント 1 日本語の手順**

```ts

  // 文 text を入れ直せる変数として作り、空の文字列を入れる
  // i を n から 1 まで 1 ずつ減らしながらくり返す
  //   text の後ろに、i と ", " をつなげる
  // text の後ろに "発射" をつなげた文字列を返す
```

### 問 9 text の中に char が何回出てくるかを返す

**テストで確かめる値**

- `countChar("banana", "a")` は `3`
- `countChar("banana", "z")` は `0`（1 つもない）
- `countChar("", "a")` は `0`（空の文字列）

**ヒント 1 日本語の手順**

```ts
export function countChar(text: string, char: string): number {
  // 数 count を入れ直せる変数として作り、0 を入れる
  // text から 1 文字ずつ c に取り出してくり返す
  //   もし c が char と等しいなら
  //     count を 1 増やす
  // count を返す
}
```

**ヒント 2 コードへの直し方**

「1 文字ずつ取り出してくり返す」は `for-of`、「もし〜なら」は `if`、「等しい」は `===`、「1 増やす」は `++` です。

### 問 10 文字列を逆順にして返す

**テストで確かめる値**

- `reverseText("abc")` は `"cba"`
- `reverseText("あいう")` は `"ういあ"`（日本語も同じ）
- `reverseText("")` は `""`（空の文字列は空のまま）

**ヒント 1 日本語の手順**

```ts
export function reverseText(text: string): string {
  // 結果 result を入れ直せる変数として作り、空の文字列を入れる
  // text から 1 文字ずつ c に取り出してくり返す
  //   c の後ろに result をつなげた文字列を、result に入れ直す
  // result を返す
}
```

**ヒント 2 コードへの直し方**

「c の後ろに result をつなげる」は、1-2-10 の例のつなぎ方と同じ形です。つなぐ順番を逆にすると、元の並びのままになります。

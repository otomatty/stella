# 覚えること

2 つの変数をずらしながら更新すると、前の 2 つから次の値を作れます。

<!-- ノート: 2 つの変数をずらしながら更新すると、前の 2 つから次の値を作れます。 -->

---

# 合計を先に控える

先に `const next = prev + curr;` で次の値を控えます。

```ts
// 一つ前の値をずらす
prev = curr;
// 計算した次の値を移す
curr = next;
```

<!-- ノート: 最後に、計算した値を入れます。 -->

---

# 結果を確かめる

2 と 3 を足して 5 を作ります。 元の一つ前の値は 3 でした。

順に、3 と 5 です。

<!-- ノート: 新しい一つ前には、足して作った 5 が入ります。 -->

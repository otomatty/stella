# 余りを先に控える

最初に `const r = a % b;` で余りを控えます。

```ts
// 元の割る数を移す
a = b;
// 割る数に控えた余りを入れる
b = r;
```

<!-- ノート: 最後に入れるのが、控えておいた余りです。 -->

---

# 結果を確かめる

10 を 4 で割ると、余りは 2 になります。 先に移すのは、元の割る数の 4 です。

順に、4 と 2 です。

<!-- ノート: 最後に余りの 2 を入れます。 -->

# 覚えること

!== は等しくないとき true です。while と組み合わせて、目標になるまでくり返します。

<!-- ノート: !== は等しくないとき true です。while と組み合わせて、目標になるまでくり返します。 -->

# 等しくない間続ける

```ts
// 1階と等しくない間くり返す
while (floor !== 1) {
  // 今の階を1つ下げる
  floor--;
}
```

<!-- ノート: 中に入ったら、次の比較に向けて今の階を変える形です。 -->

---

# 結果を確かめる

4 が 2 になり、一回増えます。 2 が 1 になり、もう一回増えました。

答えは 2 回です。

<!-- ノート: ここで目標に着くので、回数はもう増えません。 -->

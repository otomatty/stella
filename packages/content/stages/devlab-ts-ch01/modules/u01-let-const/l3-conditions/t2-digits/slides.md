# 覚えること

10 で割った余りが 1 の位、10 で割って切り捨てると残りの桁になります。

<!-- ノート: 10 で割った余りが 1 の位、10 で割って切り捨てると残りの桁になります。 -->

# 余りと切り捨て

```ts
// 右端の数字を取り出す
const last = n % 10;
// 右端を外した数を入れ直す
n = Math.floor(n / 10);
```

<!-- ノート: 残りの桁を求めるには、切り捨てが必要です。 -->

---

# この計算で残る数はいくつでしょうか。

```ts
// 右端の数字を外した数を入れる
const rest = Math.floor(789 / 10);
```

答えは 78 です。

<!-- ノート: 割り算の結果は 78.9 になります。 切り捨てるのは、右端から来た 0.9 です。 -->

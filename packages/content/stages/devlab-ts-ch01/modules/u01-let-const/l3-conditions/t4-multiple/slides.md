# 余りは出る？

クッキーを分ける前は 12 枚です。

コードでは、どう表すのでしょうか。

# 覚えること

余りが 0 なら割り切れます。&& で 2 つの条件を両方確かめます。

<!-- ノート: 余りが 0 なら割り切れます。&& で 2 つの条件を両方確かめます。 -->

---

# 割り切れる条件をつなぐ

```ts
// 3と4の両方で割り切れるか調べる
const both = n % 3 === 0 && n % 4 === 0;
```

<!-- ノート: 両方が true なら、全体も true です。 -->

---

# 二つの条件が両方合うでしょうか。

```ts
// 両方で割り切れるか調べる
const both = 15 % 5 === 0 && 15 % 3 === 0;
```

答えは true です。

<!-- ノート: 左では、15 を 5 で割った余りが 0 になります。 右でも、15 を 3 で割った余りは 0 です。 -->

---

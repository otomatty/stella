# 今の候補と比べる

```ts
// 次の値のほうが大きいか調べる
if (second > max) {
  // 大きいほうを残す
  max = second;
}
```

# 結果を確かめる

4、9、7 の順に比べます。最初の候補は 4 です。9 のほうが大きいので、候補を入れ替えます。7 のときは、そのままです。

答えは 9 です。

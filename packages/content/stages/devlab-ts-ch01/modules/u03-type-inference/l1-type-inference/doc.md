# レッスン3-1 型推論

## このレッスンの目標

- [ ] 値から推論される定数と変数の型を説明できる
- [ ] 関数が返す値をたどり、戻り値の型を説明できる
- [ ] 計算に使う値と、桁をそろえた表示用の文字列を使い分けられる

この単元の課題のテストは、値のほかに TypeScript が推論した型も確かめます。関数の引数には型注釈を書き、戻り値の型は推論に任せます。

## 3-1-1 型を書かずに定数を作る

> **const に型を書かないと、値そのものが型になります。**

型を書き添えずに、値から型を決めることを**型推論**と呼びます。文字列・数値・真偽値をそのまま定数に入れると、その値ひとつを表す**リテラル型**になります。別のファイルでも使える定数にするときは `export const` で宣言します。

```ts
// 倉庫の名前を別のファイルでも使える定数にする
export const DEPOT = "北倉庫";
```

`DEPOT` の値は `"北倉庫"`、推論された型も `"北倉庫"` です。

## 3-1-2 戻り値の型を任せる

> **戻り値の型を書かないと、return の値から型が決まります。**

引数にはこれまでどおり型注釈を書きます。閉じ丸かっこの後ろに戻り値の型を書かないと、TypeScript が `return` の式を見て型を決めます。数の計算、文字列への変換、比較の結果から、それぞれ `number`・`string`・`boolean` が推論されます。

```ts
// 商品の代金を受け取り、包装代を足す関数を作る
function withWrapping(price: number) {
  // 包装代を足した金額を返す
  return price + 130;
}
```

`withWrapping` の戻り値の型は `number` です。商品代が 760 円なら、戻り値は 890 です。

## 3-1-3 返す値が分かれたときの型

> **返す値が何通りかあると、型は「または」でつながります。**

関数の中で条件によって別の文字列を直接返すと、この例ではそれぞれのリテラル型が戻り値の候補になります。型を `|` でつなぐと「どれかひとつ」という意味になります。この型を**ユニオン型**と呼びます。

```ts
// 受け取り方を見て、案内を返す関数を作る
function handoff(pickup: boolean) {
  // 店頭で受け取るか確かめる
  if (pickup) {
    // 店頭で受け取る案内を返す
    return "店頭";
  }
  // 自宅へ送る案内を返す
  return "配送";
}
```

`handoff` の戻り値の型は `"店頭" | "配送"` です。

## 3-1-4 条件で値を選ぶ

> **条件 ? A : B で、条件に合えば A、合わなければ B になります。**

`?` の前に条件、直後に条件に合うときの値、`:` の後ろに条件に合わないときの値を書きます。この形を**条件演算子**と呼びます。選んだ値をそのまま `return` できます。

```ts
// 贈り物かどうかで袋を選ぶ関数を作る
function bagFor(gift: boolean) {
  // 贈り物ならリボン袋、それ以外は紙袋を返す
  return gift ? "リボン袋" : "紙袋";
}
```

`bagFor` の戻り値の型は `"リボン袋" | "紙袋"` です。

## 3-1-5 値が無いことを返す

> **返す値が無いときは undefined を返します。型は number | undefined のようになります。**

`undefined` は値が無いことを表す値です。この例では予約がある場合に引数で受け取った席番号を、無い場合に `undefined` を返します。戻り値を使う側にも、数を受け取れない場合があることが型で伝わります。

```ts
// 予約があれば、案内する席の番号を返す関数を作る
function seatFor(reserved: boolean, seat: number) {
  // 予約があるか確かめる
  if (reserved) {
    // 予約した席の番号を返す
    return seat;
  }
  // 案内する席が無いことを返す
  return undefined;
}
```

`seatFor` の戻り値の型は `number | undefined` です。

## 3-1-6 1文字目が無いかもしれない

> **文字列[0] の型は string | undefined です。空の文字列には1文字目が無いからです。**

前に使った `charAt` と同じく、添字は 0 から数えます。角かっこを使うと、空の文字列からの読み取りは `undefined` になります。この課題では `noUncheckedIndexedAccess` が有効です。TypeScript は文字が無い可能性を型に含めるので、文字列の添字で読み取った値は `string | undefined` です。

```ts
// 名札の文字列を用意する
let badgeText = "東受付";
// 名札の先頭にある文字を取り出す
const badgeMark = badgeText[0];
```

`badgeMark` の値は `"東"` です。`badgeText` が空なら値は `undefined` です。どちらも、推論された `string | undefined` に含まれます。

## 3-1-7 let の型は広くなる

> **let に型を書かないと、あとで入れ直せるよう string や number の型になります。**

この例では、最初に入れた文字列から、あとで別の文字列も入れ直せる `string` が推論されます。数から始めるなら `number` が推論され、別の数を入れられます。どちらも、入れ直す前後で変数の型は同じです。同じ文字列を `const` に入れた場合は、その文字列だけを表す型になります。

```ts
// 会場の案内表示に初めの文字列を入れる
let notice = "準備中";
// 開場後の表示に入れ直す
notice = "受付中";
```

`notice` の推論された型は `string` です。値は `"準備中"` から `"受付中"` に変わります。

## 3-1-8 小数を桁でそろえる

> **数.toFixed(1) で、小数第1位までの文字列になります。**

`toFixed` の丸かっこには、小数点の後ろに並べる桁数を書きます。その桁数に丸め、必要なら末尾をゼロで補います。戻るのは表示用の文字列です。応用問題でも、計算した数と表示用の文字列は別に扱います。

```ts
// 測った気温を数として用意する
const temperature = 16.78;
// 小数第1位までの表示用文字列にする
const temperatureText = temperature.toFixed(1);
```

`temperatureText` の値は `"16.8"`、型は `string` です。

## 問題ごとのヒント

動画を見たあと、案内された問題に取り組みます。同じ動画に続く問題は、確認して提出すると順に開きます。ヒントに沿って書き、テストで値と型を確かめましょう。

### 問 1 定数 SITE_NAME を宣言する

**テストで確かめる値**

- `SITE_NAME` → `"Agora"`（値）
- `SITE_NAME` の型 → `"Agora"`（"Agora" だけを表す型）

**ヒント**

定数の名前と値はスターターのコメントで確認します。ほかのファイルから使えるようにし、型注釈は付けずに文字列をそのまま入れます。

### 問 2 定数 MAX_MEMBERS を宣言する

**テストで確かめる値**

- `MAX_MEMBERS` → `50`（値）
- `MAX_MEMBERS` の型 → `50`（50 だけを表す型）

**ヒント**

指定された数を定数に入れます。型が数全般を表すものになっていないか確認しましょう。

### 問 3 定数 IS_BETA を宣言する

**テストで確かめる値**

- `IS_BETA` → `true`（値）
- `IS_BETA` の型 → `true`（true だけを表す型）

**ヒント**

指定された値は真偽値です。文字列のように引用符で囲まずに、定数に入れましょう。

### 問 4 定数 TAX_RATE を宣言する

**テストで確かめる値**

- `TAX_RATE` → `0.1`（値）
- `TAX_RATE` の型 → `0.1`（小数もそのまま型になる）

**ヒント**

小数も整数と同じように型注釈を省き、値を定数に入れます。

### 問 5 2 倍の数を返す

**テストで確かめる値**

- `double(4)` → `8`
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `number`（推論でこの型になればよい）

**ヒント**

数を受け取る引数の型は書きます。掛け算の結果を返したときに、何の型が推論されるかを確かめます。

### 問 6 数値を文字列にする

**テストで確かめる値**

- `toText(42)` → `"42"`
- `toText(-1.5)` → `"-1.5"`（負の数や小数もそのまま）
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `string`

**ヒント**

数を文字列にするには、1-1 で学んだ `String()` を使えます。負の数や小数でも同じ形です。

### 問 7 0 なら true を返す

**テストで確かめる値**

- `isZero(0)` → `true`
- `isZero(3)` → `false`
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `boolean`

**ヒント**

比較した結果は真偽値になります。等しいかを調べた結果を、そのまま返せます。

### 問 8 正なら "plus"、負なら "minus"、0 なら "zero" を返す

**テストで確かめる値**

- `sign(5)` → `"plus"`
- `sign(-3)` → `"minus"`
- `sign(0)` → `"zero"`
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `"plus" | "minus" | "zero"`（3 つのどれか）

**ヒント**

正と負の場合を順に調べると、最後に残るのはゼロの場合です。三通りすべてで、その場合の文字列を直接返しましょう。

### 問 9 60 点以上なら "合格"、それ未満なら "不合格" を返す

**テストで確かめる値**

- `judge(60)` → `"合格"`（ちょうど 60 点は合格）
- `judge(59)` → `"不合格"`
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `"合格" | "不合格"`

**ヒント**

点数が基準にちょうど達した場合を含めます。条件演算子では、条件に合う場合の値をはてなの直後に書きます。

### 問 10 2 乗した数を返す

**テストで確かめる値**

- `square(5)` → `25`
- `square(-3)` → `9`（-3 × -3）
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `number`

**ヒント**

二乗は、受け取った数を同じ数で掛けることです。戻り値の型は、掛け算の結果から決まります。

### 問 11 2 つの単語を半角スペースでつなぐ

**テストで確かめる値**

- `joinWords("Hello", "World")` → `"Hello World"`
- 引数の型 → `string` と `string`（引数は 2 つ）
- 戻り値の型 → `string`

**ヒント**

テンプレートリテラルで二つの単語を並べます。間にある半角スペースも、結果の一部です。

### 問 12 偶数なら半分にした数を、奇数なら undefined を返す

**テストで確かめる値**

- `halfIfEven(8)` → `4`
- `halfIfEven(7)` → `undefined`（奇数）
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `number | undefined`（数か、undefined）

**ヒント**

偶数かどうかは、2 で割った余りから判定できます。数を返せない場合は `undefined` を返します。

### 問 13 0〜11 時なら "午前"、12〜23 時なら "午後" を返す

**テストで確かめる値**

- `ampm(0)` → `"午前"`
- `ampm(11)` → `"午前"`
- `ampm(13)` → `"午後"`
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `"午前" | "午後"`

**ヒント**

午前と午後の境目に注目します。条件演算子のどちら側に正午の判定が入るか、確かめましょう。

### 問 14 2 つの数のうち大きい方を返す

**テストで確かめる値**

- `bigger(3, 8)` → `8`
- `bigger(9, 2)` → `9`
- 引数の型 → `number` と `number`（引数は 2 つ）
- 戻り値の型 → `number`

**ヒント**

条件演算子の条件には二つの数の比較を書きます。同じ数の場合はどちらを選んでも値は同じです。

### 問 15 文字数を返す

**テストで確かめる値**

- `charCount("TypeScript")` → `10`
- `charCount("")` → `0`（空の文字列）
- 引数の型 → `string`（引数は 1 つ）
- 戻り値の型 → `number`

**ヒント**

文字の数は `length` で調べます。空の文字列も試して、返る値と型を確認しましょう。

### 問 16 空の文字列なら true を返す

**テストで確かめる値**

- `isEmptyText("")` → `true`
- `isEmptyText(" ")` → `false`（スペース 1 文字）
- 引数の型 → `string`（引数は 1 つ）
- 戻り値の型 → `boolean`

**ヒント**

空の文字列と等しいかを比較します。空白が一つ入った文字列と区別できるかも確認しましょう。

### 問 17 true なら "はい"、false なら "いいえ" を返す

**テストで確かめる値**

- `yesNo(true)` → `"はい"`
- `yesNo(false)` → `"いいえ"`
- 引数の型 → `boolean`（引数は 1 つ）
- 戻り値の型 → `"はい" | "いいえ"`

**ヒント**

受け取った真偽値が条件になります。条件に合う側と合わない側に、指定された文字列を置きます。

### 問 18 次の年を返す

**テストで確かめる値**

- `nextYear(2026)` → `2027`
- 引数の型 → `number`（引数は 1 つ）
- 戻り値の型 → `number`

**ヒント**

受け取った年に一年分を足します。数のまま返すので、表示用の文字列に変える必要はありません。

### 問 19 文字列を丸かっこ「()」で囲む

**テストで確かめる値**

- `wrapParen("注")` → `"(注)"`
- `wrapParen("")` → `"()"`（空の文字列）
- 引数の型 → `string`（引数は 1 つ）
- 戻り値の型 → `string`

**ヒント**

テンプレートリテラルを使い、文字列を入れる場所の左右に、開き丸かっこと閉じ丸かっこを置きます。

### 問 20 最初の文字を取り出して返す

**テストで確かめる値**

- `firstChar("abc")` → `"a"`
- `firstChar("")` → `undefined`（空の文字列）
- 引数の型 → `string`（引数は 1 つ）
- 戻り値の型 → `string | undefined`

**ヒント**

添字は左から 0、1 と数えます。角かっこを使った読み取りで、空の文字列から何が返るかも確かめます。

### 応用（総合） BMI を計算する 2 つの関数

**テストで確かめる値**

- `calcBmi(170, 65)` → `22.5`
- `calcBmi(160, 45)` → `17.6`
- `calcBmi(180, 90)` → `27.8`
- `bmiReport(160, 45)` → `"BMI 17.6（低体重）"`
- `bmiReport(200, 74)` → `"BMI 18.5（普通体重）"`（ちょうど 18.5 は普通体重）
- `bmiReport(170, 65)` → `"BMI 22.5（普通体重）"`
- `bmiReport(200, 100)` → `"BMI 25.0（肥満）"`（25 も小数第 1 位まで表示）
- `bmiReport(180, 90)` → `"BMI 27.8（肥満）"`
- 引数の型（2 つとも） → `number` と `number`
- 戻り値の型 → `number` と `string`（calcBmi は number、bmiReport は string）

**ヒント**

身長の単位をメートルにそろえ、小数第 1 位に丸めた計算結果を数で返します。判定を付ける関数では、判定用の変数を `let` で用意します。条件に合わせて判定を入れ直し、表示するときに `toFixed` で小数の桁をそろえます。引数の型注釈を消すと何が起きるかは、実際に確かめてからコメントに書きます。

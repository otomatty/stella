# 箱の中身から札を作る

画面の見出しに使う倉庫の名前を、別のファイルでも使い回したいときがあります。

<!-- ノート: 棚に、まだ札の付いていない箱を置きます。ふたを開けて見えた中身は、りんごです。 -->

# 覚えること

const に型を書かないと、値そのものが型になります。

<!-- ノート: 値から型を決めることを、型推論と呼びます。export const は、別のファイルでも使える定数です。定数の値として、北倉庫を入れました。値ひとつを表す型を、リテラル型と呼びます。 -->

---

# 定数の値から型を決める

```ts
// 倉庫の名前を別のファイルでも使える定数にする
export const DEPOT = "北倉庫";
```

<!-- ノート: 倉庫の名前を使い回すために、定数を用意しました。等号の右にあるのは、北倉庫という文字列です。この値ひとつを表す型が、定数に付きます。型注釈を足さずに、値だけを書きましょう。 -->

---

# 定数の型は "北倉庫"

`DEPOT` の値は `"北倉庫"`、推論された型も `"北倉庫"` です。

参考資料は[サバイバルTypeScript「型推論」](https://typescriptbook.jp/reference/values-types-variables/type-inference)です。

<!-- ノート: `DEPOT` の値は `"北倉庫"`、推論された型も `"北倉庫"` です。 -->

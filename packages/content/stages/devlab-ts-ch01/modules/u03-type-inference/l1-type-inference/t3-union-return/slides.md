# 3-1-3 返す値が分かれたときの型

# 配送の方法で札を替える

配送の方法に応じて、伝票に載せる案内を切り替えます。同じ関数を呼んでも、いつも同じ案内になるとは限りません。

<!-- ノート: 配送する荷物を、窓口に持ち込みました。店頭で受け取る荷物は、店の札を付けます。 -->

---

# 覚えること

返す値が何通りかあると、型は「または」でつながります。

<!-- ノート: 受け取り方によって、通る道が分かれます。条件に合えば、返すのは店頭という文字列です。条件に合わないときは、配送を返します。候補の型を縦棒でつないだものが、ユニオン型です。 -->

---

# 返す型を縦棒でつなぐ

関数から返す値を順に見ます。次は `return` の行の抜粋です。

```ts
// 店頭で受け取る案内を返す
return "店頭";
// 自宅へ送る案内を返す
return "配送";
```

<!-- ノート: 店頭で受け取る指定を渡してみましょう。条件に合うので、店頭という値を返します。店頭受け取りの指定がなければ、配送です。二つの候補を縦棒でつないだ型になります。 -->

---

# 型は "店頭" | "配送"

`handoff` の戻り値の型は `"店頭" | "配送"` です。

参考資料は[サバイバルTypeScript「型推論」](https://typescriptbook.jp/reference/values-types-variables/type-inference)です。

# 3-1-7 let の型は広くなる

<!-- ノート: この動画では、let の型が広くなる理由を学びます。 -->

---

# 案内板を書き換える

受付の案内は、開場すると表示が変わります。最初に入れた文字列を書き換えるには、どんな変数を使うでしょうか。

<!-- ノート: 開場する前に、案内板を出しました。最初の表示は、準備中です。 -->

---

# 覚えること

let に型を書かないと、あとで入れ直せるよう string や number の型になります。

<!-- ノート: あとで値を入れ直す変数は、let で作ります。最初に入れた値は、準備中という文字列です。入れ直せるように、型は string になります。別の文字列も、同じ変数に入れられる型です。 -->

---

# 文字列を入れ直せる変数を作る

```ts
// 会場の案内表示に初めの文字列を入れる
let notice = "準備中";
// 開場後の表示に入れ直す
notice = "受付中";
```

<!-- ノート: 準備中を、変数の最初の値として入れます。推論された型は、文字列全体を表す string です。受付が始まったら、別の文字列を入れましょう。値が変わっても、変数に付いた型はそのままです。 -->

---

# 入れ直しても型は string

`notice` の推論された型は `string` です。値は `"準備中"` から `"受付中"` に変わります。

同じ初期値を `const` で宣言すると、型は `"準備中"` です。

参考資料は[サバイバルTypeScript「型推論」](https://typescriptbook.jp/reference/values-types-variables/type-inference)です。

<!-- ノート: `notice` の推論された型は `string` です。値は `"準備中"` から `"受付中"` に変わります。 -->

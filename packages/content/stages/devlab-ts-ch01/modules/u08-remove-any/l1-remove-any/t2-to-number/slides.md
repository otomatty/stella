# 整理券の次の番号

# 文字列を数値に変える

```ts
// 整理券の印字を文字列で受け取る
const ticketText = "42";
// 数値に変えてから、次の番号を求める
const next = Number(ticketText) + 1;
```

<!-- ノート: 整理券の文字列を Number に渡します。数値の四十二に変えたあと、一を足します。 -->

---

# 文字列のまま足すと

`"42" + 1` は文字をつないだ `"421"` です。`Number("42") + 1` は、数値どうしを足した `43` になります。

<!-- ノート: `"42" + 1` は文字をつないだ `"421"` です。`Number("42") + 1` は、数値どうしを足した `43` になります。 -->

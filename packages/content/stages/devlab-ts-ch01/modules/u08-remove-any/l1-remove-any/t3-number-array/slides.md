# 数値を並べた配列の型

```ts
// 歩数の記録が何日ぶんあるか返す
function countDays(steps: number[]): number {
  // 並んでいる値の数を返す
  return steps.length;
}
```

<!-- ノート: steps は数値を並べた配列です。length で数えるのは日数で、戻り値は数値一つです。 -->

---

# length は値の数

配列は値を順番に並べたものです。数値を並べた配列の型は、number に角かっこを付けて書きます。`[3200, 5100, 4800].length` は合計の `13100` でなく、件数の `3` です。

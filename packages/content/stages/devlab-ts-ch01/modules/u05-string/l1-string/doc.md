# レッスン5-1 q05 string型

## このレッスンの目標

- [ ] 文字列の一部を取り出せる
- [ ] 文字列の先頭・末尾の一致や、見つかった位置を調べられる
- [ ] 空白や英字の表記を整え、必要な文字を置き換えられる

動画を見たら、このまとめで書き方を振り返ります。この単元の「01章 q05 string型」を VS Code で開き、解放された問題を一問ずつ確認して提出します。

## 5-1-1 文字列の一部を切り出す

> **文字列.slice(始め, 終わり) で、始めから終わりの手前までを取り出します。**

荷札には区画名と棚の番号が続けて書かれています。

```ts
// 荷札から区画名を取り出す
const zone = "青葉１２".slice(0, 2);
// 結果を表示する（"青葉"）
console.log(zone);
```

負の位置は末尾から数えます。`-1` が最後の文字の位置です。終わりを省くと、始めから末尾まで取り出します。

```ts
// 整理番号の後ろから四文字目を始めにして、末尾まで取り出す
const batch = "便名KITE".slice(-4);
// 結果を表示する（"KITE"）
console.log(batch);
// 整理番号の二番目から末尾まで取り出す
const suffix = "便名KITE".slice(2);
// 結果を表示する（"KITE"）
console.log(suffix);
```

## 5-1-2 始まりを確かめる

> **文字列.startsWith(文字) は、その文字で始まっていれば true です。**

受付票の見出しには、窓口名と用件が続けて書かれています。

```ts
// 受付票の見出しが会計から始まるか確かめる
const forCashier = "会計窓口".startsWith("会計");
// 結果を表示する（true）
console.log(forCashier);
```

途中に同じ文字があっても、先頭で一致しなければ `false` です。

## 5-1-3 小文字にそろえる

> **文字列.toLowerCase() で、英字をすべて小文字にします。**

別々の担当者が登録した棚の名前を、一枚の一覧にまとめます。

```ts
// 棚の名前にある英字を小文字にそろえる
const shelfKey = "RaCK８".toLowerCase();
// 結果を表示する（"rack８"）
console.log(shelfKey);
```

数字や記号など、大文字と小文字の区別がない文字はそのまま残ります。

## 5-1-4 終わりを確かめる

> **文字列.endsWith(文字) は、その文字で終わっていれば true です。**

連絡の宛先を一覧にすると、個人宛てと部署宛てが混ざります。

```ts
// 宛先の名前がチームで終わるか確かめる
const isGroup = "制作チーム".endsWith("チーム");
// 結果を表示する（true）
console.log(isGroup);
```

英字の大文字と小文字は区別します。同じものとして扱いたいときは、先に同じ表記にそろえます。

## 5-1-5 前後の空白を取り除く

> **文字列.trim() で、前後の空白を取り除きます。**

入力欄の宛名をコピーすると、一緒に空白が入ることがあります。

```ts
// 宛名の前後に付いた空白を取り除く
const recipient = "  東 物流部 ".trim();
// 結果を表示する（"東 物流部"）
console.log(recipient);
```

`trim()` で取り除くのは両端です。単語の間にある空白は残ります。

## 5-1-6 同じ文字をまとめて置き換える

> **文字列.replaceAll(探す文字, 新しい文字) で、見つけた文字をすべて置き換えます。**

作業表と表示用の一覧で、区切りの記号が違います。

```ts
// 経路を区切る中点をすべて矢印に替える
const route = "東・北・西".replaceAll("・", "→");
// 結果を表示する（"東→北→西"）
console.log(route);
```

同じ文字が二か所あれば、二か所とも置き換わります。一致する箇所がなければ、同じ内容が返ります。

## 5-1-7 何文字目にあるか調べる

> **文字列.indexOf(文字) で、最初に見つかった位置がわかります。無ければ -1 です。**

駅の案内に、いくつかの地名が区切って書かれています。

```ts
// 案内で最初に出てくる中点の位置を調べる
const firstStopMark = "港・駅前・丘".indexOf("・");
// 結果を表示する（1）
console.log(firstStopMark);
```

見つからないときは `-1` が返ります。`0` は先頭で見つかった位置です。

```ts
// 案内に斜線が出る位置を調べる
const absent = "港・駅前・丘".indexOf("／");
// 結果を表示する（-1）
console.log(absent);
// 案内に港が出る位置を調べる
const atFront = "港・駅前・丘".indexOf("港");
// 結果を表示する（0）
console.log(atFront);
```

## 5-1-8 最後に出てくる位置を調べる

> **文字列.lastIndexOf(文字) で、最後に見つかった位置がわかります。**

保存先の名前を階層ごとに区切って表示します。

```ts
// 保存先で最後に出るスラッシュの位置を調べる
const lastFolderMark = "棚/箱/奥".lastIndexOf("/");
// 結果を表示する（3）
console.log(lastFolderMark);
```

`lastIndexOf` は右から探し、位置は左端の `0` から数えます。見つからないときは `-1` が返ります。

## 5-1-9 決まった形の文字を置き換える

> **文字列.replace(/形/g, 新しい文字) で、正規表現に当てはまる文字をすべて置き換えます。**

資料に品番を載せるとき、英字は残して数字だけを伏せたいことがあります。

正規表現は探したい文字の形です。形をスラッシュで囲み、閉じるスラッシュの後ろに `g` を付けると、当てはまる箇所をすべて探します。`[0-9]` は半角の `0` から `9` のどれか一文字を表します。

```ts
// 品番の半角数字をすべて伏せ字に替える
const publicCode = "Q8K5".replace(/[0-9]/g, "＊");
// 結果を表示する（"Q＊K＊"）
console.log(publicCode);
```

`\s` は空白一文字を表します。`[0-9]` は半角数字一文字を表します。スラッシュで形を囲み、`g` を付けると該当する文字をすべて探します。`replaceAll` に文字列を渡すと決まった文字を探し、正規表現を渡した `replace` では形に当てはまる文字を探せます。

```ts
// 区画の名前にある空白をすべて中点に替える
const marked = "西  港 丘".replace(/\s/g, "・");
// 結果を表示する（"西・・港・丘"）
console.log(marked);
```

## 問題ごとのヒント

### 問1 文字数を返す

文字数は `length` に入っています。値を読む書き方なので、かっこは付けません。

### 問2 英字を大文字にする

`toUpperCase` を使います。数字や記号はそのままです。

### 問3 先頭の三文字を返す

先頭は何番目でしょうか。三文字目を含めるには、終わりにその次の位置を渡します。

### 問4 最後の一文字を返す

`slice` の始めに負の位置を使うと、末尾を基準にできます。

### 問5 指定の文字列を含むか調べる

途中も探せる `includes` を使い、見つかったかどうかを返します。

### 問6 指定の記号で始まるか調べる

`startsWith` の引数は、先頭で照らし合わせる記号です。

### 問7 ファイル名の末尾を確かめる

大文字で書かれた場合も判定できるよう、名前の表記をそろえてから末尾を調べます。

### 問8 番号の桁をそろえる

数値を文字列に変換してから、`padStart` で必要な長さにそろえます。

### 問9 前後の空白と英字の表記を整える

空白を取り除く操作と、小文字にそろえる操作は別です。順番に試しましょう。

### 問10 半角スペースを置き換える

`replaceAll` に、探す一文字と新しい記号をその順で渡します。

### 問11 指定の記号がある位置を返す

先頭で見つかったときと、どこにもないときを分けて確かめます。

### 問12 先頭の英字を大文字にする

先頭と残りに分けます。大文字にするのは、どちらの部分でしょうか。

### 問13 文字列の両側を囲む

囲む文字と元の文字列を、テンプレートリテラルでどんな順番に並べるか考えます。

### 問14 逆から読んでも同じか確かめる

一文字ずつ取り出し、組み立て中の文字列の前に足すと逆順になります。組み立て終えてから元と比べます。

### 問15 電話番号の一部を隠す

表示に残す部分を決め、そこだけを取り出します。隠す部分には指定の文字を使います。

### 問16 ファイル名の拡張子を取り出す

最後の点の位置を探し、点の次から末尾までを取り出します。点がない場合の戻り値も確かめます。

### 問17 時刻の文字列を組み立てる

時と分をそれぞれ文字列にして桁をそろえます。最後に区切りの記号と合わせます。

### 問18 英字の母音を取り除く

角かっこの中に並べた文字は、どれか一文字に当てはまります。取り除くには、何に置き換えればよいでしょうか。

### 問19 指定した位置の一文字を返す

`charAt` は、指定の位置に文字がないときに空の文字列を返します。

### 問20 英字の大文字と小文字を区別せずに比べる

二つの文字列を同じ表記にそろえたあとで、等しいかを確かめます。

### 応用 URL 用の表記・文字数の短縮・メールアドレスの目隠し

- URL 用の表記では、前後の空白と英字の表記を先に整えます。途中の連続した空白は、ひとまとまりとして置き換えます。正規表現で `+` は直前の形が一回以上続くことを表します。
- 文字数を短くする課題では、末尾に足す省略記号も文字数に含めます。上限ちょうどの場合と、上限として使えない値の場合も確かめます。
- メールアドレスでは、区切りの記号を探して隠す範囲を決めます。記号がない場合と、記号が先頭にある場合に注目します。

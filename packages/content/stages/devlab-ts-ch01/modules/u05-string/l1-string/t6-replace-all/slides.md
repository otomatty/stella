# 区切りの表記をそろえる

作業表と表示用の一覧で、区切りの記号が違います。区切りがいくつもあるとき、一つずつ探すと見落とすことがあります。

<!-- ノート: 作業表に、経路を倉庫の名前で書きました。 -->

---

# 覚えること

文字列.replaceAll(探す文字, 新しい文字) で、見つけた文字をすべて置き換えます。

<!-- ノート: 文字列.replaceAll(探す文字, 新しい文字) で、見つけた文字をすべて置き換えます。 -->

---

# 同じ文字をまとめて置き換える

```ts
// 経路を区切る中点をすべて矢印に替える
const route = "東・北・西".replaceAll("・", "→");
```

<!-- ノート: 経路には、区切りの中点が二つあります。 差し替える文字は、矢印です。 二か所とも矢印に替えた経路ができました。 -->

---

# 一致した箇所をまとめて替える

同じ文字が二か所あれば、二か所とも置き換わります。一致する箇所がなければ、同じ内容が返ります。

参考資料は[サバイバルTypeScriptの string 型](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

<!-- ノート: 同じ文字が二か所あれば、二か所とも置き換わります。一致する箇所がなければ、同じ内容が返ります。 -->

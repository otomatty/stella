# 荷札から区画名を読む

荷札には区画名と棚の番号が続けて書かれています。区画名だけが必要なとき、どこを読めばよいでしょうか。

# 覚えること

文字列.slice(始め, 終わり) で、始めから終わりの手前までを取り出します。

# 文字列の一部を切り出す

```ts
// 荷札から区画名を取り出す
const zone = "青葉１２".slice(0, 2);
```

<!-- ノート: 「青」は 0 番目から始まります。 2 番目の「１」は、取り出す範囲の外です。 切り出した青葉を、区画名として保存しました。 -->

---

# 後ろから数える・終わりを省く

負の位置は末尾から数えます。`-1` が最後の文字の位置です。終わりを省くと、始めから末尾まで取り出します。

参考資料は[サバイバルTypeScriptの string 型](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

<!-- ノート: 負の位置は末尾から数えます。`-1` が最後の文字の位置です。終わりを省くと、始めから末尾まで取り出します。 -->

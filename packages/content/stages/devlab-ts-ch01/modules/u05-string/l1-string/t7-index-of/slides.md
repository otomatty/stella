# 案内の区切りを探す

駅の案内に、いくつかの地名が区切って書かれています。一つ目の地名の終わりは、どこで分かるでしょうか。

# 覚えること

文字列.indexOf(文字) で、最初に見つかった位置がわかります。無ければ -1 です。

<!-- ノート: 文字列.indexOf(文字) で、最初に見つかった位置がわかります。無ければ -1 です。 -->

# 何文字目にあるか調べる

```ts
// 案内で最初に出てくる中点の位置を調べる
const firstStopMark = "港・駅前・丘".indexOf("・");
```

<!-- ノート: 調べる案内には、中点が二つあります。 左から見て、港のすぐ後ろにあるのが最初の中点です。 見つかった位置は、0 から数えて 1 番目でした。 -->

---

# 見つからないとき

見つからないときは `-1` が返ります。`0` は先頭で見つかった位置です。

参考資料は[サバイバルTypeScriptの string 型](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

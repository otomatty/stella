# 5-1-5 前後の空白を取り除く

# 宛名を入力欄から移す

入力欄の宛名をコピーすると、一緒に空白が入ることがあります。余分な空白が残ったままだと、宛名の位置がずれて見えます。

<!-- ノート: 入力欄に、荷物の宛名を貼り付けました。 -->

---

# 覚えること

文字列.trim() で、前後の空白を取り除きます。

<!-- ノート: 文字列.trim() で、前後の空白を取り除きます。 -->

---

# 前後の空白を取り除く

```ts
// 宛名の前後に付いた空白を取り除く
const recipient = "  東 物流部 ".trim();
```

<!-- ノート: 東の前と、部の後ろに空白があります。 東と物流部の間にある空白は、宛名の一部です。 前後だけを整えた宛名を保存しました。 -->

---

# 途中の空白は残る

`trim()` で取り除くのは両端です。単語の間にある空白は残ります。

参考資料は[サバイバルTypeScriptの string 型](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

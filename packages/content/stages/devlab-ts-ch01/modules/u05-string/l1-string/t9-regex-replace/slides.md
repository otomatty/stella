# 5-1-9 決まった形の文字を置き換える

<!-- ノート: この動画では、決まった形の文字をまとめて置き換える方法を学びます。 -->

---

# 品番の数字を隠す

資料に品番を載せるとき、英字は残して数字だけを伏せたいことがあります。品番ごとに違う数字を、同じ目印に替えるにはどうすればよいでしょうか。

<!-- ノート: 資料に載せる品番には、英字と数字が混ざっています。 -->

---

# 覚えること

文字列.replace(/形/g, 新しい文字) で、正規表現に当てはまる文字をすべて置き換えます。

<!-- ノート: 文字列.replace(/形/g, 新しい文字) で、正規表現に当てはまる文字をすべて置き換えます。 -->

---

# 決まった形の文字を置き換える

```ts
// 品番の半角数字をすべて伏せ字に替える
const publicCode = "Q8K5".replace(/[0-9]/g, "＊");
```

<!-- ノート: 置き換える前の品番には、数字が二つあります。 それぞれの数字は、指定した形に当てはまる文字です。 数字を二か所とも伏せ字に替えました。 -->

---

# 空白を表す形

`\s` は空白一文字を表します。`[0-9]` は半角数字一文字を表します。スラッシュで形を囲み、`g` を付けると該当する文字をすべて探します。`replaceAll` に文字列を渡すと決まった文字を探し、正規表現を渡した `replace` では形に当てはまる文字を探せます。

参考資料は[サバイバルTypeScriptの string 型](https://typescriptbook.jp/reference/values-types-variables/string)です。コード例は教材用に作成しています。

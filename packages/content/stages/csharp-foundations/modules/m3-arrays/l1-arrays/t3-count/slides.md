# 条件に合う個数
<!-- ノート: 足すものが値か 1 か、という話です。 -->
---
# 要素を足すと、個数にはなりません
合計の形のまま a[i] を足すと、個数ではなく値の合計になります。
<!-- ノート: 結論はこの次です。 -->
---
# 合うたびに 1 を足す
条件に合う要素だけ、個数を 1 増やします。
<!-- ノート: 箱の初期値は 0 です。 -->
---
# 条件だけを変える
```csharp
int c = 0;
for (int i = 0; i < a.Length; i++)
    if (a[i] >= k)
        c = c + 1;
return c;
```
<!-- ノート: 変えるのは if の条件です。 -->
---
# 1 つも無ければ 0
条件を満たす要素が無ければ、箱は 0 のままです。
<!-- ノート: 空の配列も、ループが回らず 0 です。 -->
---

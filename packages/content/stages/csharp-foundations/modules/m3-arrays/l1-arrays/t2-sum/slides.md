# 配列の合計を返す
<!-- ノート: 箱の場所と、足す対象の話です。 -->
---
# ループの中で 0 に戻すと、最後の要素しか残りません
毎回初期化すると、それまでの合計が消えます。
<!-- ノート: 直す場所は、この次で言います。 -->
---
# 要素を箱に足して返す
配列の合計は、ループの外の変数に要素を足して返します。
<!-- ノート: 添字 i は位置です。足すのは a[i] です。 -->
---
# 添字で要素を足す
```csharp
int s = 0;
for (int i = 0; i < a.Length; i++)
    s = s + a[i];
return s;
```
<!-- ノート: 添字は 0 から始まります。積の初期値は 1 です。 -->
---
# 最大は先頭の要素から
答えの初期値は a[0] です。i = 1 から、より大きい要素で上書きします。
<!-- ノート: 最小は > を < にします。0 から始めると、負の最大を落とします。 -->
---

# まとめ
配列の合計は、ループの外の変数に要素を足して返します。

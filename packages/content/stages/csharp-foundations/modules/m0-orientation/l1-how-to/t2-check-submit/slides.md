# 1 問確認して、提出します
その問題のテストが通ってから提出します。提出したら、次の問題を開きます。
<!-- ノート: 確認は、開いている問題に対して行います。 -->
---
# 全部提出すると合格です
問題が全部そろうと、課題が合格になります。合否はテストで決まります。
<!-- ノート: 説明欄と修正記録の提出はありません。 -->
---
# 拡張か CLI で提出します
VS Code の拡張で提出します。CLI の `stella submit` でも提出できます。CLI には Node.js が要ります。
<!-- ノート: 手元でテストが通ったという申告です。サーバーはコードを実行しません。 -->
---
# SDK は 10 系
.NET SDK は 10 系を使います。11 だけでは `net10.0` は動きません。

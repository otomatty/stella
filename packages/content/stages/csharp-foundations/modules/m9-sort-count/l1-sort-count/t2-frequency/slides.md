# 値を添字にして数える
<!-- ノート: 位置が値、中身がその値の個数です。 -->
---
# 箱は値の個数ぶん
0〜4 なら、長さ 5 の配列です。0〜9 なら長さ 10 です。
<!-- ノート: new int[5] は、5 個とも 0 です。 -->
---
# 0回も残す
出なかった値も、0 のまま残します。
<!-- ノート: 3, 1, 3, 0 なら、回数は 1, 1, 0, 2, 0 です。 -->
---
# 値を添字にして足す
```csharp
frequency[a[i]]++;
```
<!-- ノート: a[i] が 3 なら、frequency[3] が 1 増えます。 -->
---
# 同数は更新しない
回数がいまの候補より大きいときだけ、候補を変えます。
<!-- ノート: 同数でも更新すると、大きい値を選びます。 -->
---
<!-- _class: summary -->
# まとめ
0から9の回数は、値を添字にした配列で数えます。
<!-- ノート: 小さい方から見て、より大きい回数だけを採用します。 -->

# 内側は毎回先頭から
i が進んでも、j は 0 から始まります。

# 和が 5 より大きい組
```csharp
if (a[i] + b[j] > 5) count++;
```
<!-- ノート: 1 と 4、3 と 2 は 5 ちょうどです。3 と 4 だけが入ります。 -->
---
# ちょうどは、より大きいには入らない
5 より大きい組は 1 組です。5 ちょうどは数えません。
<!-- ノート: 以上なら、5 ちょうども数えます。問題文の境界を見ます。 -->
---

# まとめ

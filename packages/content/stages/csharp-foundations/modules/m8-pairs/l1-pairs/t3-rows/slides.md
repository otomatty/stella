# 行が変わるたびに戻す
<!-- ノート: 行の合計を、次の行へ持ち越しません。 -->
---
# 行の中で 0 から
その行の値を足し、行の最後に出します。
<!-- ノート: 入力 2 2、1 3、2 5 なら、出力は 4 と 7 です。 -->
---
# 持ち越すと次の行が増える
個数を行の外で一度だけ 0 にすると、前の行の個数が残ります。
<!-- ノート: 2 行とも -1 なら、各行は 1 です。持ち越すと 1 と 2 になります。 -->
---
# 行のたびに宣言する
```csharp
for (int row = 0; row < h; row++)
{
    int count = 0;
}
```
<!-- ノート: 列を変えるたびに 0 にすると、1 行分を数えられません。 -->
---
# 列の合計は外に置く
列ごとの合計は、行のループの外に配列を置いて足します。
<!-- ノート: new int[w] は、w 個の 0 です。 -->
---
<!-- _class: summary -->
# まとめ
行ごとの数は、行が変わるたびに 0 へ戻します。
<!-- ノート: 出す行数は、入力の行数と同じです。 -->

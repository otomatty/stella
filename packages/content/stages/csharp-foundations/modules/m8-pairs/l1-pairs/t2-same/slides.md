# 同じ列は次の位置から
<!-- ノート: 別の列とは、内側の始め方が違います。 -->
---
# 同じ位置は選ばない
j は i + 1 から末尾まで動かします。
<!-- ノート: j を 0 から始めると、自分同士と逆順も数えます。 -->
---
# 順序が逆でも同じ組
2, 2, 5 で値が等しい組は 1 組です。
<!-- ノート: 位置 0 と 1 だけです。1 と 0 は別の組にしません。 -->
---
# 値が等しい組
```csharp
for (int j = i + 1; j < a.Length; j++)
    if (a[i] == a[j]) count++;
```
<!-- ノート: 値が等しくても、位置が違えば選べます。 -->
---
# 差の絶対値
座標の差が負なら、符号を変えて距離にします。
<!-- ノート: 0, 3, 7, 3 で上限 3 なら、距離 3, 7, 3, 4, 0, 4 のうち 3 組です。 -->
---
<!-- _class: summary -->
# まとめ
同じ列の異なる二つは、内側を次の位置から始めます。
<!-- ノート: 長さ N なら、組の数は N×(N-1)/2 です。 -->

# 判定だけを返す部品
```csharp
bool IsSeatCountValid(int seats)
{
    return seats >= 1 && seats <= 3;
}
```
人数を受け取り、範囲内かを返します。

# 表の行を手順に沿って追う
1. 人数が範囲内かを調べます。
2. 範囲外なら失敗を表示して返します。
3. 範囲内でRegisterなら成功のログを出します。
4. 成功を返します。

自分の表で、この順番が期待結果になるか確かめます。

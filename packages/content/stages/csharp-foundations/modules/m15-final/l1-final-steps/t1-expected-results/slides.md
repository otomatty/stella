# 戻り値は合っているのに
予約の成功を返しましたが、失敗のログも出ていました。
戻り値だけを比べて、この誤りに気づけるでしょうか。

# 仕様の分岐を表の行にする

# 表示と戻り値を分ける
```csharp
Console.WriteLine("予約しました");
return "Accepted";
```
期待ログは「予約しました」、期待戻り値は `"Accepted"` です。
<!-- ノート: 予約人数の参考例です。表示と戻り値は表の別の欄に書き、両方を比べます。 -->
---
# 同じ人数でもモードを分ける
| 入力 | モード | 期待ログ | 期待戻り値 |
| --- | --- | --- | --- |
| 1 | Preview | なし | `"Accepted"` |
| 1 | Register | 予約しました | `"Accepted"` |
| 0 | Register | 人数不正 | `"Rejected"` |

複数行のログがある場合は、順番まで書きます。
<!-- ノート: 1〜3人を受け付ける例です。ログなしと、空の行を出すことも区別します。表は提出用ではなく、自分が仕様を読み取れたか確かめるために使います。 -->

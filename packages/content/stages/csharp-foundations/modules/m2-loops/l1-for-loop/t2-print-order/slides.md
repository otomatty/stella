# 順番に1行ずつ出す
<!-- ノート: for の 3 か所だけを変える、という話です。 -->
---
# 1 から出すループのままでは、n から出せません
始まりが 1、増える、終わりが n 以下、のままでは逆順になりません。
<!-- ノート: 結論はこの次のスライドです。 -->
---
# 3 か所を変えると順番が変わる
for の始まり、終わり、増減を変えると、出す順番が変わります。
<!-- ノート: 本体の WriteLine は、出す値だけ見ます。 -->
---
# 1 から n まで
```csharp
for (int i = 1; i <= n; i++)
{
    Console.WriteLine(i);
}
```
<!-- ノート: 逆順なら始まりを n、条件を i >= 1、変化を i-- にします。 -->
---
# 終わりの 0 を落としやすい
`i > 0` は 0 を出しません。「0 まで」は `i >= 0` です。
<!-- ノート: n が 0 のとき、最初の判定で 1 行も出ないことがあります。 -->
---
<!-- _class: summary -->
# まとめ
for の始まり、終わり、増減を変えると、出す順番が変わります。
<!-- ノート: 課題では、この 3 つを問題文の範囲に合わせます。 -->

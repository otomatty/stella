# ループの外で集計する
<!-- ノート: 箱をどこに置くかです。 -->
---
# ループの中で 0 に戻すと、最後の 1 回しか残りません
毎回初期化すると、それまでの合計が消えます。
<!-- ノート: 直す場所は、この次で言います。 -->
---
# 箱はループの外
合計はループの外の変数に足し、終わってから返します。
<!-- ノート: 個数なら 1 を足します。積の初期値は 1 です。 -->
---
# 1 から n の合計
```csharp
int s = 0;
for (int i = 1; i <= n; i++)
    s = s + i;
return s;
```
<!-- ノート: 偶数だけ足すなら、足す直前に if を入れます。 -->
---

# まとめ

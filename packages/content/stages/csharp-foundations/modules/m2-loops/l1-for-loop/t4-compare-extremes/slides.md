# 比べて最大を残す
<!-- ノート: 配列は使いません。 -->
---
# 0 から始めると、負の数の最大を落としやすい
候補が全部 0 より小さいとき、0 のまま残ることがあります。
<!-- ノート: 答えの初期値を、次のスライドで決めます。 -->
---
# 先頭を答えにする
先頭の値を答えにして、残りと比べて上書きします。
<!-- ノート: if の条件が真のときだけ、覚えている値を置き換えます。 -->
---
# 3 つの最大
```csharp
int m = a;
if (b > m) m = b;
if (c > m) m = c;
return m;
```
<!-- ノート: 最小は > を < にします。引数が増えたら if を足します。 -->
---

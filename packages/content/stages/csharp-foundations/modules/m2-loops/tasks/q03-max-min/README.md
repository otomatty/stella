# 最大と最小

`src/<id>.cs` に、その問題のメソッドを 1 つ書きます。クラスは `public static partial class Answers` です。プログラムの入口と、メソッドを呼び出す行は書きません。テストがメソッドを呼びます。

1 問確認して提出し、次の問題へ進みます。全部の問題を提出すると、この課題は合格になります。

どの問題も `int` を `return` します。画面には出しません。 配列は使いません。

★ の問題は、最初に確認する問題です。

| 問題 | ファイル | メソッド |
| --- | --- | --- |
| Q21 | `src/q21-max5.cs` | `public static int Q21Max5(int a, int b, int c, int d, int e)` |
| Q22 | `src/q22-min5.cs` | `public static int Q22Min5(int a, int b, int c, int d, int e)` |
| Q23 | `src/q23-max3.cs` | `public static int Q23Max3(int a, int b, int c)` |
| Q24 | `src/q24-min3.cs` | `public static int Q24Min3(int a, int b, int c)` |

配列は使わない。いまの値と覚えている値を `if` で比べる。

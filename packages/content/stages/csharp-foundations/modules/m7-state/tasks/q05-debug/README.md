# 足し方と停止を直す

`src/<id>.cs` に、その問題のメソッドを 1 つ書きます。クラスは `public static partial class Answers` です。プログラムの入口と、メソッドを呼び出す行は書きません。テストがメソッドを呼びます。

1 問確認して提出し、次の問題へ進みます。全部の問題を提出すると、この課題は合格になります。

R1 は配列を受け取り、最後の値を返します。R2 は 3 つの int を受け取り、回数を返します。入っているコードを、仕様に合うところだけ直します。

| 問題 | ファイル | メソッド |
| --- | --- | --- |
| R1 | `src/r1-final.cs` | `public static int R1Final(int x, int[] changes)` |
| R2 | `src/r2-days.cs` | `public static int R2Days(int x, int t, int d)` |

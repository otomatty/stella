# 条件が続く間繰り返す
<!-- ノート: 回数ではなく、条件で終わります。 -->
---
# while は条件を先に見る
条件が成り立つ間、本体を繰り返します。
<!-- ノート: for のように、最初に回数を書きません。 -->
---
# 3 ずつ増えて 10 以上
0 から 3 ずつ増やすと、日数は 4 です。
<!-- ノート: 3、6、9、12 です。12 で条件が外れます。 -->
---
# 足してから日数を増やす
```csharp
while (amount < 10)
{
    amount = amount + 3;
    days++;
}
```
<!-- ノート: 増加量は正です。0 だと終わりません。 -->
---
# すでに目標以上なら 0
ループに入る前から条件が外れていれば、回数は 0 です。
<!-- ノート: 等しいときも、これ以上は増やしません。 -->
---
<!-- _class: summary -->
# まとめ
while は、条件が成り立つ間、本体を繰り返します。

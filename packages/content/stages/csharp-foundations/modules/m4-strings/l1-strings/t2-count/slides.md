# 文字の個数
<!-- ノート: 数える対象が要素から文字に変わります。 -->
---
# 文字そのものを足すと、個数にはなりません
'0' から '9' の文字コードを足しても、個数にはなりません。
<!-- ノート: 足すのは 1 です。 -->
---
# 合う文字だけ 1 を足す
空文字は 0 回で、条件に合う文字だけ個数を 1 増やします。
<!-- ノート: 箱はループの外で 0 です。 -->
---
# 半角数字を数える
```csharp
int count = 0;
for (int i = 0; i < s.Length; i++)
    if (s[i] >= '0' && s[i] <= '9')
        count = count + 1;
```
<!-- ノート: 変えるのは if の条件です。 -->
---
# 空は false
全部数字かは、1 つでも外れたら false です。空文字も false です。
<!-- ノート: 1 文字も無いので、全部とは言いません。 -->
---

# 条件を変えたら表示まで変わった
注文数の上限を直した後、受付ログが二度出るようになりました。
新しい上限だけを試して、この変化に気づけるでしょうか。
<!-- ノート: 条件の変更に気を取られると、前から動いていた表示や戻り値を見落とすことがあります。 -->
---
# 変えない処理も確かめる
変わる行と変わらない行を表に分け、変更後に前の全ケースを実行します。
<!-- ノート: 仕様の各項目をコードの行に対応させます。期待値を更新するのは、変更した仕様で結果が変わるケースだけです。 -->
---
# 成功時の表示を残す
```csharp
Console.WriteLine("注文を受け付けました");
return "";
```
上限が変わっても、成功時の表示と戻り値が同じなら維持します。
<!-- ノート: これは注文受付の参考例です。戻り値だけでなく、ログの文言と回数、順番も比べます。 -->
---
# 今回変わる行はどこですか
| 処理 | 変更するか |
| --- | --- |
| 月ごとの日数を調べる行 | 変更する |
| 2月の上限を決める行 | 追加する |
| 空白・数字・モードを処理する行 | 変えない |
| ログと戻り値を出す行 | 変えない |

前の全ケースで、残した動作も確かめます。
<!-- ノート: たとえば空白ありのImportは、数字8桁なら削除ログを出します。その後に日付で失敗しても、この順番は今回の基礎課題では変えません。 -->
---

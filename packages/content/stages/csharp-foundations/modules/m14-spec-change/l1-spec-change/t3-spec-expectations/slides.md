# カレンダーと結果が違う
基礎課題では1900年2月29日を受け付けます。
カレンダーにない日なら、実装の誤りでしょうか。

# 問題文の規則で判定する
簡略な規則と実際の暦を区別し、その問題の仕様から期待値を決めます。
<!-- ノート: 基礎課題は4で割り切れればうるう年です。100と400の条件を加えるのは、暦の規則への変更が指定された問題です。 -->
---
# 割り切れるかは余りで分かる
```csharp
int quantity = 12;
int remainder = quantity % 4;
Console.WriteLine(remainder); // => 0
```
`%` は割った余りです。0なら割り切れます。
<!-- ノート: 商品を4個ずつ箱に入れる参考例です。12個なら余りは0、14個なら2です。商を求める割り算とは区別します。 -->
---
# 同じ年でも規則で結果が変わる
| 年 | 基礎課題の簡略な仕様 | グレゴリオ暦 |
| --- | --- | --- |
| 1900 | うるう年 | 平年 |
| 2000 | うるう年 | うるう年 |
| 2023 | 平年 | 平年 |

基礎課題に、100と400の条件は加えません。
<!-- ノート: グレゴリオ暦は、4で割り切れても100で割り切れる年を平年にし、400で割り切れる年をうるう年にします。年の範囲は、どちらの課題でも元の前提どおりです。 -->

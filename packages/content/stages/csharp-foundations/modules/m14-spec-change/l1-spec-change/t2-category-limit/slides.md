# 14-1-2 区分ごとの上限を返す
<!-- ノート: 商品の種類によって、注文できる個数が違う場合を考えます。 -->
---
# 同じ個数でも受け付けられない
通常商品は10個まで、限定商品は2個まで注文できます。
注文数だけを見て、範囲内かを決められるでしょうか。
<!-- ノート: 注文数が3でも、通常商品なら受け付けられ、限定商品なら上限を超えます。 -->
---
# 上限を一つの戻り値にする
区分によって上限が違うときは、区分を受け取り、上限を返す関数にします。
<!-- ノート: 呼び出す側は、返された上限と注文数を比べます。区分を調べる部分と、範囲を比べる部分が分かれます。 -->
---
# 限定商品なら2を返す
```csharp
int GetOrderLimit(string category)
{
    if (category == "限定") { return 2; }
    return 10;
}
```
<!-- ノート: 限定なら最初のreturnで関数を終えます。それ以外は最後の行で10を返します。商品の参考例です。 -->
---
# 上限ちょうども確かめる
| 区分 | 注文数 | 上限 | 期待値 |
| --- | --- | --- | --- |
| 限定 | 2 | 2 | 範囲内 |
| 限定 | 3 | 2 | 範囲外 |
| 通常 | 10 | 10 | 範囲内 |
| 通常 | 11 | 10 | 範囲外 |

「以下」の比較には `<=` を使います。
<!-- ノート: 上限を返せても、比較を間違えると上限ちょうどを受け付けられません。上限とその1つ上を両方確かめます。 -->

# 解説

空白の有無を残して削除し、数字8桁を確かめる順序は変えません。Checkは空白の検知を最初に知らせ、Importは数字8桁を確かめた直後に削除を知らせます。Importで日付が不正なら、削除ログ、日付のログの順で2行になります。

数字8桁だと分かった後に年・月・日を切り出します。月が01〜12に入っていることを確かめ、その月の日数を返すローカル関数を呼びます。日は1からその上限までです。

2月は平年なら28日、年が4で割り切れるなら29日です。1900年もこの教材ではうるう年です。年の範囲は調べないので00000101は成功し、月の日数を超える20260231は失敗します。以前のケースも実行し、日付に関係する期待値だけが変わることを確かめます。

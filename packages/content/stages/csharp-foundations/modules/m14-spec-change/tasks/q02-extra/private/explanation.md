# 解説

Q01はうるう年の条件を変えます。400で割り切れる年、または4で割り切れ、かつ100で割り切れない年がうるう年です。1900年と2100年の2月29日は失敗し、2000年・2024年・2400年の2月29日は成功します。年の範囲と、空白処理・ログの順番は元のままです。

Q02は月ごとの日数と、4で割り切れる年をうるう年とする簡略仕様を、元の入力検証に加えます。Q01の暦の規則やQ03のログの変更は混ぜません。基礎演習と同じ入力・戻り値・ログで確かめます。

Q03はImportの日付判定を済ませてから削除ログを出します。空白があり日付が不正なら、日付のログだけになります。数字8桁でなければ、元の空白の有無から入力の失敗ログを選び、削除ログを出しません。Checkでは空白の検知を最初に知らせる処理を残します。

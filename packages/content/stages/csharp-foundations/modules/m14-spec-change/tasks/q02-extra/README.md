# 日付の仕様変更の追加演習

`src/<id>.cs` に、その問題のメソッドを1つ書きます。クラスは `public static partial class Answers` です。テストがメソッドを呼び、戻り値とログの内容・順番を確かめます。補助の関数は、そのメソッドの中に書きます。

1問確認して提出し、次の問題へ進みます。全部の問題を提出すると、この課題は合格になります。

| 問題 | ファイル | メソッド |
| --- | --- | --- |
| Q01 暦の規則へ変更 | `src/q01-calendar-leap.cs` | `public static string Q01CalendarLeap(string strInput, string strMode)` |
| Q02 仕様から再実装する | `src/q02-reimplement.cs` | `public static string Q02Reimplement(string strInput, string strMode)` |
| Q03 Importの削除ログを変える | `src/q03-import-final-log.cs` | `public static string Q03ImportFinalLog(string strInput, string strMode)` |

# かつは両方、またははどちらか
かつは両方、またははどちらかが成り立つときに使います。
<!-- ノート: かつは &&、またはは || です。 -->
---
# 両方 10 より大きい
```csharp
if (x > 10 && y > 10)
{
    return "both";
}
else
{
    return "no";
}
```
<!-- ノート: 10 ちょうどは、より大きいには入りません。 -->
---
# 範囲は、以上かつ以下
5 以上 11 以下は、n >= 5 && n <= 11 です。
<!-- ノート: またはでつなぐと、範囲の外も入ってしまいます。 -->

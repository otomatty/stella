# 12-1-3 文字のまま数字を調べる
<!-- ノート: 会員コードの先頭の0も、コードを構成する1文字です。 -->
---
# 先頭の0も必要です
会員コード `"01234567"` を整数にすると `1234567` です。
元の入力が何桁だったか、整数だけで分かりますか。
<!-- ノート: 会員コードには桁数の決まりがあります。計算に使う整数と同じ扱いでよいかを考えます。 -->
---
# 長さと文字の範囲を確かめる
数字の桁数は、文字列の長さと各文字が '0'〜'9' かどうかで確かめます。
<!-- ノート: Length で長さを調べ、各文字が半角の0から9に入るかを見ます。 -->
---
# 1文字を範囲で比べる
```csharp
char letter = '4';
bool isDigit = letter >= '0' && letter <= '9';
Console.WriteLine(isDigit); // => True
```
<!-- ノート: 文字の比較で範囲を調べています。全角の４は、この範囲に入りません。 -->
---
# 同じ整数でも桁数は違う
| 文字列 | 長さ | 整数へ変換した値 |
| --- | --- | --- |
| `"01234567"` | 8 | `1234567` |
| `"1234567"` | 7 | `1234567` |

変換した値だけでは、この違いが残りません。
<!-- ノート: 元の8桁仕様では先頭0を許可しています。8文字のコードを、7文字の入力と区別して判断します。 -->
---

# 期待ログを出る順に書く
入力ごとに期待ログを順番どおりに並べ、期待戻り値を別の欄に書きます。
<!-- ノート: ログはメソッドが出す行です。期待値は、実行結果ではなく仕様から決まる正しい結果です。 -->
---
# 表示する文と返す値
```csharp
Console.WriteLine("受付を開始します");
return "受付済み";
```
ログは「受付を開始します」、戻り値は「受付済み」です。
<!-- ノート: これは表示と戻り値を区別するための参考例です。return した値は、自動では画面に出ません。 -->
---
# 空白のある入力が失敗する場合
| 入力 | 期待ログ | 期待戻り値 |
| --- | --- | --- |
| `"12 34 567"` | 空白を検知しました / 入力値が正しくありません | `"Err"` |

`/` は改行です。検知のログが先です。
<!-- ノート: 空白を消すと7文字なので失敗します。二つのログは、この順で出ることまで仕様に含まれます。 -->

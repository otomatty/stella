# 会員コードの追加演習

`src/<id>.cs` に、その問題のメソッドを1つ書きます。クラスは `public static partial class Answers` です。テストがメソッドを呼び、戻り値とログの内容・順番を確かめます。補助の関数は、そのメソッドの中に書きます。

1問確認して提出し、次の問題へ進みます。全部の問題を提出すると、この課題は合格になります。

| 問題 | ファイル | メソッド |
| --- | --- | --- |
| Q01 長さと文字のログを分ける | `src/q01-length-or-char.cs` | `public static string Q01LengthOrChar(string strInput)` |
| Q02 先頭の条件 | `src/q02-leading-zero.cs` | `public static string Q02LeadingZero(string strInput)` |
| Q03 仕様から再実装する | `src/q03-reimplement.cs` | `public static string Q03Reimplement(string strInput)` |
| Q04 空白を受け付けない6桁版 | `src/q04-no-space-six.cs` | `public static string Q04NoSpaceSix(string strInput)` |

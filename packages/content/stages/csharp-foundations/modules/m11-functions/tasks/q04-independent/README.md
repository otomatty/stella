# 関数を組み合わせる

`src/<id>.cs` に、その問題のメソッドを 1 つ書きます。クラスは `public static partial class Answers` です。プログラムの入口と、メソッドを呼び出す行は書きません。テストがメソッドを呼びます。

1 問確認して提出し、次の問題へ進みます。全部の問題を提出すると、この課題は合格になります。

補助の関数は、そのメソッドの中に書きます。呼び出し側は、返った値を次の計算に使います。

| 問題 | ファイル | メソッド |
| --- | --- | --- |
| S01 | `src/s01-count-in-range.cs` | `public static int S01CountInRange(int[] a, int l, int r)` |
| S02 | `src/s02-is-name.cs` | `public static bool S02IsName(string s)` |
| S03 | `src/s03-sum-excess.cs` | `public static int S03SumExcess(int[] a, int k)` |
| S04 | `src/s04-both-four-digits.cs` | `public static bool S04BothFourDigits(string a, string b)` |
| S05 | `src/s05-contains.cs` | `public static bool S05Contains(int[] a, int k)` |
| S06 | `src/s06-minute-diff.cs` | `public static int S06MinuteDiff(int h1, int m1, int h2, int m2)` |
| S07 | `src/s07-middle2-is-digits.cs` | `public static bool S07Middle2IsDigits(string s)` |
| S08 | `src/s08-check-code.cs` | `public static string S08CheckCode(string s)` |
| S09 | `src/s09-payment.cs` | `public static int S09Payment(int[] prices)` |
| S10 | `src/s10-count-invalid6.cs` | `public static int S10CountInvalid6(string[] a)` |

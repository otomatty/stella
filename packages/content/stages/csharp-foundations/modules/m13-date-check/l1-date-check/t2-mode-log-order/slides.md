# 同じ入力でも表示が違う
画面で確かめるときと、取り込むときで表示が違います。
入力だけを記録して、結果を比べられますか。

# 入力とモードを組にする
入力とモードの組合せごとに、期待ログを出る順に並べ、期待戻り値を別の欄に書きます。
<!-- ノート: モードの欄があれば、同じ入力を両方のモードで確かめたかが分かります。 -->
---
# ログと戻り値を分ける
```csharp
Console.WriteLine("受付を開始します");
return "受付済み";
```
ログは「受付を開始します」、戻り値は「受付済み」です。
<!-- ノート: これは表示と戻り値を区別する参考例です。戻り値は自動では表示されません。 -->
---
# 空白を含む不正な日付
| 入力 | モード | 期待ログ | 期待戻り値 |
| --- | --- | --- | --- |
| `"2026 1332"` | Check | 空白を検知しました / 日付が正しくありません | `"Err"` |
| `"2026 1332"` | Import | 空白を削除しました / 日付が正しくありません | `"Err"` |

`/` は改行です。元の仕様では、この順に出します。
<!-- ノート: 空白を削除すると数字8桁なので、Import でも削除ログを出します。その後に日付が不正と分かっても、削除ログは取り消しません。 -->

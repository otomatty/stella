# 検査を増やすと結果も変わる

# 指定された範囲を守る
元の日付仕様では、月01〜12と日01〜31だけを確かめ、年の範囲や月ごとの日数は判定に足しません。
<!-- ノート: 年の範囲、月の日数、うるう年は、元の仕様では調べないと明記されています。 -->
---
# 範囲は二つの比較で表す
```csharp
int shelfNumber = 8;
bool valid = shelfNumber >= 1 && shelfNumber <= 20;
Console.WriteLine(valid); // => True
```
<!-- ノート: これは棚番号が1から20かを調べる参考例です。下限と上限の両方を満たす必要があります。境界の値は仕様で決めます。 -->
---
# 元の仕様では成功する入力
| 入力 | 理由 |
| --- | --- |
| `"00000101"` | 年の範囲を調べないため |
| `"20260231"` | 月01〜12、日01〜31を満たすため |

実際の暦にある日かどうかは、判定の対象外です。
<!-- ノート: 年2000から2099の条件を足すのは、その変更を指定された問題だけです。元の仕様を再実装する問題には足しません。 -->
---

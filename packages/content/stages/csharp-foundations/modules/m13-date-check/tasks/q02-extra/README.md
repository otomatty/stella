# 日付チェックの追加演習

`src/<id>.cs` に、その問題のメソッドを1つ書きます。クラスは `public static partial class Answers` です。テストがメソッドを呼び、戻り値とログの内容・順番を確かめます。補助の関数は、そのメソッドの中に書きます。

1問確認して提出し、次の問題へ進みます。全部の問題を提出すると、この課題は合格になります。

| 問題 | ファイル | メソッド |
| --- | --- | --- |
| Q01 削除ログのタイミングを変える | `src/q01-import-log-timing.cs` | `public static string Q01ImportLogTiming(string strInput, string strMode)` |
| Q02 年の範囲を足す | `src/q02-year-range.cs` | `public static string Q02YearRange(string strInput, string strMode)` |
| Q03 仕様から再実装する | `src/q03-reimplement.cs` | `public static string Q03Reimplement(string strInput, string strMode)` |
| Q04 6桁の時刻を検証する | `src/q04-check-time6.cs` | `public static string Q04CheckTime6(string strInput, string strMode)` |

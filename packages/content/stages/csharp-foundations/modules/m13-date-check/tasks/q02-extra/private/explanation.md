# 解説

Q01はImportの日付の判定を済ませてから削除ログを出します。空白があっても日付が不正なら日付のログだけになります。Checkの処理や、数字8桁でないときの失敗ログは変えません。

Q02は数字8桁を確認してから年を切り出し、2000〜2099に含まれるかを調べます。Importの削除ログは元の位置なので、空白があり年が範囲外なら、削除ログの後に日付のログが出ます。Q03にはQ01・Q02の変更を引き継ぎません。

Q04は数字6桁を確認してから2桁ずつ切り出します。時は00〜23、分と秒は00〜59です。空白処理とログの順番は元の仕様を使い、数字6桁に到達したときだけ時刻を調べます。

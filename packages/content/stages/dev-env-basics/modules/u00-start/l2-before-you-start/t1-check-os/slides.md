# 00-2-1 使うOSを確かめる

<!-- ノート: 同じ教材でも、PC によって操作の案内は変わります。手順を読み始める前に、自分のPCに合う案内を選ぶ準備をします。 -->

---

# 書いてあるボタンが見つからない

教材どおりに進めたいのに、画面に同じメニューがありません。
別のPC向けの手順を読んでいるのかもしれません。

<!-- ノート: ボタンを探しても見つからないとき、操作を間違えたとは限りません。使うPCの種類によって、メニューの名前や入れ方が変わります。 -->

---

# 覚えること

使うPCのOSを確かめ、そのOSの手順だけを読みます。

OS は、PC の基本的な動きを支えるソフトウェアです。
この教材には Windows と macOS の手順があります。

<!-- ノート: まず必要なのは、自分のPCのOSの名前です。その名前が分かると、まとめの中で読むべき手順を選べます。 -->

---

# まとめのOSタブを選ぶ

| 確かめたOS | まとめで読むタブ |
| --- | --- |
| Windows | 「Windows」 |
| macOS | 「macOS」 |

OS の確かめ方は、まとめに載っています。

<!-- ノート: タブを選ぶと、そのOS向けの手順を読めます。どちらか分からない場合は、研修の担当者に画面を見てもらってください。 -->

---

# 会社のPCでは、導入前に確認する

ソフトを入れる前に、研修の担当者へ確認します。

- このPCに入れてよいですか？
- 認められた入れ方はありますか？

<!-- ノート: 会社が管理するPCには、導入方法の決まりがある場合があります。OSを確かめることと、ソフトを入れてよいか確かめることを、準備の段階で済ませます。 -->

---

<!-- _class: summary -->
# まとめ

使うPCのOSを確かめ、そのOSの手順だけを読みます。

<!-- ノート: 使うPCのOSに合う手順を選べば、違う画面を探し続けずに済みます。まとめを開き、自分のOSのタブを選んでください。 -->

# レッスン00-2 始める前の確認

## このレッスンの目標

- [ ] 自分のPCのOSに合う手順を選べる
- [ ] 最初の提出までの見通しを説明できる

## 00-2-1 使うOSを確かめる

> **使うPCのOSを確かめ、そのOSの手順だけを読みます。**

OS は、PC の基本的な動きを支えるソフトウェアです。
この教材では Windows と macOS の手順を用意しています。
自分のOSに合うタブを選び、その手順を読みます。

:::os windows
1. 「スタート」から「設定」を開きます。
2. 「システム」→「バージョン情報」を開きます。
3. 「Windows の仕様」でOSとバージョンを確かめます。

⊞ キーを押し、「winver」と入力して開く方法もあります。
:::

:::os macos
1. 画面左上の Apple メニューを開きます。
2. 「この Mac について」を選びます。
3. macOS の名前とバージョンを確かめます。
:::

会社が管理するPCでは、ソフトを入れてよいか先に確認します。
研修の担当者に、認められた入れ方も聞いてください。
ブラウザーは、Web のページを開くための道具です。
Chrome・Edge・Safari のいずれかを最新版にして使います。
管理端末で更新が必要なときも、担当者に確認します。

## 00-2-2 最初の提出までの見通し

> **最初の数時間で、HTMLを書いて提出するところまで進みます。**

HTML は、Web ページの内容や構造を書くための言葉です。
このステージでは、準備のあとに短いページを書きます。
最初の4〜5時間で、U02 の最初の課題の提出を目指します。
導入で待つ時間や困った時間を、能力の評価には入れません。

| 単元 | 題 | 時間 | ログイン前に読める |
| --- | --- | ---: | --- |
| U00 | STELLAで学ぶ流れと事前確認 | 1 | ○ |
| U01 | VS CodeとSTELLA拡張の準備 | 3 | ○ |

詳しい使い方は U08 で学びます。

## うまくいかないとき

OSが分からないときは、研修の担当者に画面を見てもらいます。
会社のPCで導入や更新が止まったときも、担当者へ相談します。
待つ間は、この公開単元をブラウザーで読み進められます。

# 覚えること
スキルツリーの星を1つずつクリアすると、その先の星が見えてきます。

スキルツリーは、学ぶ順序を星で表した地図です。
星1つが、学ぶ内容をまとめたステージです。

# 確かめる場面
クリア＝終えた星、進行中＝いま進める星、解放済み＝始められる星。

鍵＝条件を満たすと始められる星、ぼやけ＝先にある星の予告です。

通常、最初に始められるのはこのステージです。進めるステージは同時に1つです。

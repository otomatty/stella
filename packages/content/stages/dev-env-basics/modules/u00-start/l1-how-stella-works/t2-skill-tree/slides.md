# 00-1-2 スキルツリーの星

<!-- ノート: ホームに並ぶ星は、学ぶ内容とその先の道筋を表しています。星の見え方から、いま取り組める範囲を読み取ります。 -->

---

# 気になる星に鍵が付いている

ホームで先の星を見つけました。
鍵の付いた星も、名前がぼやけた星もあります。

<!-- ノート: 先に学びたい内容が見えても、その星をすぐ始められるとは限りません。鍵やぼやけた表示には、それぞれ意味があります。 -->

---

# 覚えること

スキルツリーの星を1つずつクリアすると、その先の星が見えてきます。

スキルツリーは、学ぶ順序を星で表した地図です。
星1つが、学ぶ内容をまとめたステージです。

<!-- ノート: 1つの星の中に、レッスンや課題がまとまっています。目の前の星を終えることで、地図の先へ進んでいきます。 -->

---

# 星の状態を読む

| 表示 | 意味 |
| --- | --- |
| クリア | レッスンと課題を終えています |
| 進行中 | いま進めている星です |
| 解放済み | 始められます |
| 鍵 | 始める条件が、まだそろっていません |
| ぼやけ | 少し先にある星の予告です |

<!-- ノート: 「進行中」は現在の学習場所、「解放済み」は始められる場所です。鍵のある星は条件を確かめ、ぼやけた星は先の予告として見ておきます。 -->

---

# まずは、いま進める星を1つ

通常の入口は「開発環境とWebの入口」です。
進めるステージは同時に1つです。

割り当てられた教材によって、見える星は異なります。

<!-- ノート: ほかの人と星の数が違っても、同じ地図にそろえる必要はありません。自分の画面にある、いま進める星を確かめましょう。 -->

---

<!-- _class: summary -->
# まとめ

スキルツリーの星を1つずつクリアすると、その先の星が見えてきます。

<!-- ノート: いまの星をクリアすると、学べる範囲が先へ広がります。ホームに戻ったら、進行中の星を見つけてください。 -->

# 00-1-1 STELLAで学ぶ流れ

<!-- ノート: STELLA は、教材を読み、課題を出して学ぶ場所です。課題は、実際に手を動かす問題です。 -->

---

# 覚えること

STELLA では、Web で読み、VS Code で課題を書き、確認して提出します。

<!-- ノート: レッスンは学ぶ内容のまとまりで、Web で読みます。課題のファイルは VS Code で書きます。 -->

---

# 学ぶ順序

読む → VS Code で課題 → 確認 → 提出 → 結果を見る

| 場所 | すること |
| --- | --- |
| Web | レッスンを読み、知識問題で理解を確かめる |
| VS Code | 課題のファイルを書き、確認して提出する |

<!-- ノート: 知識問題は、読んだ内容を理解できたか確かめる問題です。課題は手元で確認してから提出し、レビューの結果を見ます。 -->

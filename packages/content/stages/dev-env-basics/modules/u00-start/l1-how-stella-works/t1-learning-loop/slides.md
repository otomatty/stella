# 覚えること
STELLA では、読む・確かめる・手を動かす・見てもらう、を1周ずつ進めます。

STELLA は、教材を読み、課題を出して学ぶ場所です。
レッスンは学ぶ内容のまとまりです。
知識問題は理解を確かめる問題、課題は手を動かす問題です。

# 確かめる場面

→「課題を確認する」→ 提出 → AI の確認（必要なら講師）→ 星が進む。

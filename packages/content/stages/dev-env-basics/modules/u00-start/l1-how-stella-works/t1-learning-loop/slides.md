# 00-1-1 STELLAで学ぶ流れ

<!-- ノート: 教材を読むところから課題を見てもらうところまで、STELLA での学び方をたどります。 -->

---

# 読み終わったら、学習は終わり？

スライドとまとめを読み終えました。
でも、読んだ内容を自分で使えるかは、まだ確かめていません。

<!-- ノート: 説明を読んで分かったつもりでも、実際にファイルを書くと手が止まることがあります。読むだけで終えた場合に、何が残るかを考えてみましょう。 -->

---

# 覚えること

STELLA では、読む・確かめる・手を動かす・見てもらう、を1周ずつ進めます。

STELLA は、教材を読み、課題を出して学ぶ場所です。
レッスンは、学ぶ内容のまとまりです。

<!-- ノート: 読む、理解を確かめる、実際に試す、結果を見てもらう、という順に進みます。短いまとまりで繰り返すので、全部を読んでから課題を始める必要はありません。 -->

---

# 読む場所から、手を動かす場所へ

| 場所 | すること |
| --- | --- |
| Web のレッスン | スライドとまとめを読みます |
| Web の知識問題 | 読んだ内容の理解を確かめます |
| PC の VS Code | 課題で実際にファイルを書きます |

<!-- ノート: 知識問題は、理解を確かめる問題です。課題は手を動かす問題で、書くための道具である VS Code は次の単元で準備します。 -->

---

# 書いたあとは、確認して提出する

「課題を確認する」→ 提出 → AI の確認

必要な場合は講師も見ます。
レッスンと課題を終えると、学ぶ内容を表す星が進みます。

<!-- ノート: 手元で確認することと、提出して見てもらうことは、別の段階です。詳しいボタンの操作は U02 で、最初の課題と一緒に学びます。 -->

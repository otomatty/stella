# レッスン00-1 STELLAで学ぶ流れ

## このレッスンの目標

- [ ] 1つの課題が進む順序を説明できる
- [ ] 星の状態と、同時に進めるステージの数が分かる
- [ ] ガイドとヘルプを見つけられる

## 00-1-1 STELLAで学ぶ流れ

> **STELLA では、読む・確かめる・手を動かす・見てもらう、を1周ずつ進めます。**

STELLA は、教材を読み、課題を出して学ぶ場所です。
レッスンは、学ぶ内容をひとまとまりにしたものです。
スライドで要点をつかみ、まとめで読み返します。
知識問題は、読んだことを理解できたか確かめる問題です。
課題は、実際にファイルを書くなど、手を動かす問題です。
課題を書く場所は VS Code です。次の単元で準備します。

### 1つの課題が進む流れ

| 段 | どこで | 何をする |
| --- | --- | --- |
| 1 読む | Web のレッスン | スライドとまとめで学ぶ |
| 2 確かめる | Web の知識問題 | 理解を確かめる（ログイン後） |
| 3 手を動かす | PC の VS Code | 課題に取り組む |
| 4 確認する | VS Code | 「課題を確認する」で手元の結果を確かめる |
| 5 提出する | VS Code | 課題を提出する |
| 6 見てもらう | STELLA | AI が確認し、必要なら講師が見る |
| 7 星が進む | Web のスキルツリー | レッスンと課題を終えると星がクリアになる |

確認と提出の詳しい操作は U02 で学びます。

## 00-1-2 スキルツリーの星

> **スキルツリーの星を1つずつクリアすると、その先の星が見えてきます。**

スキルツリーは、学ぶ順序を星で表した地図です。
星1つが、学ぶ内容をまとめたステージです。

| 星の状態 | 意味 |
| --- | --- |
| クリア | 学ぶ内容と課題を終えた星 |
| 進行中 | いま進めている星 |
| 解放済み | 始められる星 |
| 鍵 | 始める条件が、まだそろっていない星 |
| ぼやけ | 少し先にある星の予告 |

通常、最初に始められるのは「開発環境とWebの入口」です。
別の教材を割り当てられた人は、見える星が異なることもあります。
進めるステージは同時に1つです。
いまの星を進めると、その先の星が見えてきます。

## 00-1-3 ガイドで今日の一歩を選ぶ

> **ホームのガイドが、今日やることを1つずつ出します。**

ホームは、ログイン後に開く最初の画面です。
ガイドは、ホームで次の行動を知らせるカードです。
「次にやること」を読み、大きな主ボタンを押します。
「そのあと」は、続いて取り組む内容の案内です。
ガイドを畳んでも、次の行動と主ボタンを確認できます。

学習のペースは、1週間に学ぶ時間の目安です。
既定は週35時間です。自分の予定に合わせて「設定」で変えられます。
毎日の再開時にガイドを見ると、続きの場所を探しやすくなります。

## 困ったとき

画面の使い方は、右上の「?」からヘルプを開いて確かめます。
課題には「講師に相談」もあります。使い方は U04 で学びます。
ログインできないときも、[問い合わせのページ](/support)を開けます。

## うまくいかないとき

ログイン前の `/start` では、学習の進捗を記録しません。
ガイドや知識問題を使うときは、ログインして開き直します。

## もっと知りたい人へ

- [開始案内](/start)から、ログイン前でもこの単元を読み返せます。
- [問い合わせ](/support)は、ログイン前でも開けます。

ログイン後は、このレッスンの知識問題で確かめます。

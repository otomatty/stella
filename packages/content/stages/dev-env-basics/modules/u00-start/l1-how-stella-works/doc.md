## 00-1-1 STELLAで学ぶ流れ

> **STELLA では、Web で読み、VS Code で課題を書き、確認して提出します。**

STELLA は、教材を読み、課題を出して学ぶ場所です。
レッスンは学ぶ内容のまとまりです。
Web のスライドとまとめを読み、知識問題で理解を確かめます。
課題は、ファイルを書くなど、手を動かす問題です。

**読む → VS Code で課題 → 確認 → 提出 → 結果を見る**

課題のファイルを書く道具が VS Code です。
書いたら「課題を確認する」で手元の結果を確かめ、提出します。
提出後は AI が確認し、必要なら講師が見ます。
結果を読み、直す点があれば修正して、もう一度確認・提出します。
仕事でも、書いたものを確かめて見てもらう流れが役立ちます。
詳しい操作は使い方動画で確認できます。

## 知識問題

この問題と解説は教材用に作成しました。

### Q1. 学ぶ順序として正しいものはどれですか？
<!-- kind: single; skills: stella-task-loop -->

- A. 読む → VS Code で課題 → 確認 → 提出 → 結果を見る
- B. 提出 → 読む → 課題を書く → 結果を見る

<details>
<summary>解答</summary>

**A** — 課題を書いたら、手元で確認してから提出します。

</details>

### Q2. 課題のファイルを書く場所はどこですか？
<!-- kind: single; skills: stella-task-loop -->

- A. Web の知識問題の選択肢
- B. PC の VS Code

<details>
<summary>解答</summary>

**B** — 教材は Web で読み、課題のファイルは VS Code で書きます。

</details>

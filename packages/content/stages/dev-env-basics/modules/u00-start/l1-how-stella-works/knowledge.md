## 知識問題

この問題と解説は教材用に作成しました。

### Q1. 1周の順序として正しいものはどれですか？
<!-- kind: single; skills: stella-task-loop -->

- A. レッスン → 知識問題 → VS Code で課題 → 確認 → 提出 → AI の確認 → 星が進む
- B. 提出 → 星が進む → レッスン → 課題

<details>
<summary>解答</summary>

**A** — 読んで理解を確かめ、手を動かしたものを見てもらいます。

</details>

### Q2. 課題のファイルを書く場所はどこですか？
<!-- kind: single; skills: stella-task-loop -->

- A. Web の知識問題の選択肢
- B. PC の VS Code

<details>
<summary>解答</summary>

**B** — Web で学び、課題のファイルは VS Code で書きます。

</details>

### Q3. 同時に進めるステージはいくつですか？
<!-- kind: single; skills: stella-task-loop -->

- A. 見える星すべて
- B. 1つ

<details>
<summary>解答</summary>

**B** — 1つずつ進めます。

</details>

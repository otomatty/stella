# 学習フォルダーの記録を始める

## 何を作るか

学習フォルダー全体を1つの Git のリポジトリにします。
記録者の名前とメールを、そのリポジトリだけに設定します。
学習フォルダー直下に、指定の3行の `.gitignore` を置きます。
配られた `index.html` を、Git にコミットします。
`h1` の「記録の練習」は変えません。
この課題では HTML の編集より、記録の準備を練習します。

手元の確認では次を見ます。

- リポジトリの一番上が学習フォルダーであること。
- 名前とメールが、そのリポジトリに設定されていること。
- `node_modules/probe` と `.stella/last-run.json` が記録の対象外であること。
- `index.html` が保存した内容でコミットされていること。
- 学習リポジトリに1件以上のコミットがあること。

## 手順

1. Web の「VS Code で開く」で、この課題を開きます。
2. 「表示 > ターミナル」を開きます。
3. いまの場所を確かめます。

```sh
pwd
```

最初から末尾が `web-training` なら、移動は不要です。
課題フォルダーで開いた場合だけ、次を1つずつ実行します。

```sh
cd ..
```

```sh
cd ..
```

```sh
cd ..
```

4. 学習フォルダーにいることを、もう一度確かめます。

```sh
pwd
```

課題フォルダーは学習フォルダーから3つ下です。
`web-training` が末尾にあることを確認してから進みます。

5. 学習フォルダーで、一度だけ初期化します。

```sh
git init
```

すでにここがリポジトリなら、この操作は省略します。
課題フォルダーでは実行しません。

6. 学習フォルダーで、名前とメールを設定します。
次の名前は例です。研修で使う自分の名前に置き換えます。

```sh
git config user.name "yamada"
```

メールも例です。研修で指定されたものに置き換えます。

```sh
git config user.email "training@example.invalid"
```

`--global` は付けません。

7. エクスプローラーで、学習フォルダー直下に `.gitignore` を作ります。
すでにある場合は、次の3行と同じかを確認して保存します。

```text
node_modules/
**/.stella/last-run.json
**/.stella/dotnet/
```

`node_modules/` は npm の大きな部品フォルダーです。
`last-run.json` は毎回変わる手元の確認結果です。
`.stella/dotnet/` は C# のビルド出力です。
`**/` は、下の階層のどこにあっても対象にする指定です。

8. 学習フォルダーのターミナルで、状態を見ます。

```sh
git status
```

一覧を読み、学習のファイル以外があれば講師に相談します。

9. 変更を選びます。

```sh
git add .
```

10. 選んだ状態を読みます。

```sh
git status
```

11. 説明を付けて記録します。

```sh
git commit -m "学習フォルダーの記録を始める"
```

12. この課題の `index.html` に戻り、「課題を確認する」を押します。
13. 通らない項目を確認し、通ったら「提出する」で提出します。

## うまくいかないとき

名前やメールを求められたら、手順6の設定を確認します。
記録するものが無ければ、`git status` と `git log --oneline` を読みます。
すでに対象のファイルを記録していれば、確認へ進めます。
場所の検査で通らなければ、課題の中で初期化していないか確認します。
`.git` を自己判断で削除せず、どこで初期化したかを講師に伝えます。

参照: [git-init](https://git-scm.com/docs/git-init)、[git-config](https://git-scm.com/docs/git-config)、[gitignore](https://git-scm.com/docs/gitignore)、[git-commit](https://git-scm.com/docs/git-commit)

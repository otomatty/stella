# Git の版を確かめる

## 何を確かめるか

Git が2.40以上かを照合します。
U05の Node.js（22.13以上の22系か24系）と npm（10以上）も照合します。
この課題では、編集・提出するファイルはありません。

## 手順

1. l1「Git とは」の自分の OS の手順で Git を入れます。
2. ファイルを保存して VS Code をすべて閉じ、開き直します。
3. 「表示 > ターミナル」を開き、次を実行します。

```sh
git --version
```

4. 表示された版が2.40以上かを読みます。
5. Web の「VS Code で開く」で、この課題を開きます。
6. 「課題を確認する」を押します。
7. 通らない項目では表示された版と必要な版を読みます。
8. すべて通ったら、「提出する」で提出します。

## うまくいかないとき

見つからないと言われたら、導入を終えたかを確認します。
ファイルを保存し、VS Code をすべて閉じて開き直します。
それでも通らなければ、表示された版と必要な版を読みます。
会社の PC に入れられないときは、講師に相談します。
環境の問題は、能力の評価には入りません。
相談には、目的・できたこと・試したコマンド・メッセージを添えます。

参照: [Git の導入](https://git-scm.com/install/windows)

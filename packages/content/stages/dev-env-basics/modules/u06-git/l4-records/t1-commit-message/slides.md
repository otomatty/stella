---

# なぜ必要でしょうか

記録の一覧に「修正」「修正」「修正」と並んでいます。
見出しを変えた記録が、どれか分かりません。

<!-- ノート: どの記録も同じ説明だと、内容を開くまで変更が分かりません。一覧で見分けられる言葉を使います。 -->

---

# 覚えること

コミットの説明には、何を変えたかを 1 行で書きます。

対象と変えた内容を、短く具体的に書きます。

<!-- ノート: 操作した回数だけでなく、何が変わったかを記録します。一行で読める説明にします。 -->

---

# 小さく試します

| 説明の例 | 読み取れること |
| --- | --- |
| 修正 | 変えたものが分かりません |
| index.html の見出しを学習予定に変える | ファイルと変更した内容が分かります |

<!-- ノート: よい例は、何を探す記録かを一覧から判断できます。自分の変更に合う語に置き換えます。 -->

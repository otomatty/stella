# 記録の残し方の知識問題

## 確認クイズ

### Q1. 一覧から変更を探しやすいコミットの説明はどれですか。
<!-- kind: single; skills: git-local-commit -->

- A. 修正
- B. index.html の見出しを学習予定に変える
- C. 終わり

<details>
<summary>解答と解説</summary>

**B** — 対象と変更内容が分かる説明を1行で残します。

</details>

### Q2. 提出に添える説明の組合せはどれですか。
<!-- kind: single; skills: git-local-commit -->

- A. ファイル名・変えた場所と前後の内容・理由
- B. 使ったキーの回数・時刻だけ
- C. できました、という一言だけ

<details>
<summary>解答と解説</summary>

**A** — 説明と提出ファイルが一致していることも確かめます。

</details>

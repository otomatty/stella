# 6-3-1 変更の差を読む

<!-- ノート: 変更を記録する前に、意図した文字だけが変わったかを調べます。 -->

---

# なぜ必要でしょうか

見出しを書き換えて保存しました。
ほかの文字も消していないかを、記録する前に確かめたいです。

<!-- ノート: 完成した画面だけでは、削った文字が分かりにくいことがあります。変更前後を並べて読みます。 -->

---

# 覚えること

`git diff` は、まだ記録していない変更を見せます。

差分は、変更前と変更後の違いです。
引数なしの `git diff` は、まだ add していない変更を見せます。

<!-- ノート: すでに記録済みのファイルを変えて、保存した後に使います。新規ファイルの本文はこの表示には出ません。 -->

---

# 小さく試します


```sh
git diff
```

結果の一部の例です。
```diff
-<h1>学習メモ</h1>
+<h1>今日の学習メモ</h1>
```

<!-- ノート: マイナス側が変更前、プラス側が変更後です。差分の記号は入力する文字ではありません。 -->

---

# 見比べます

add の後は、引数なしの `git diff` が空でも未コミットです。
選んだ変更を見るときは次を使います。

```sh
git diff --cached
```


<!-- ノート: 何も表示されないことだけでコミット済みとは決めません。git status でも状態を確認します。 -->

---

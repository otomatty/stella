# レッスン6-3 変更を読む

## このレッスンの目標

- [ ] 差分で変更前後の文字を読めます。
- [ ] 記録の一覧で説明を確かめられます。

## 6-3-1 変更の差を読む

> **`git diff` は、まだ記録していない変更を見せます。**

差分とは、変更前と変更後の違いです。
すでにコミットしたファイルを編集して、保存します。
`git add` の前に、次を実行します。

```sh
git diff
```

引数なしの場合は、まだ add していない変更を見せます。
たとえば、見出しを変えると次のように出ます。
これは実行結果の一部で、入力するコマンドではありません。

```diff
-<h1>学習メモ</h1>
+<h1>今日の学習メモ</h1>
```

`-` が変更前、`+` が変更後です。
実際の表示では、上に変更したファイルのパスも出ます。
別のファイルを変えていないかも確かめます。

新規のファイルは、引数なしの `git diff` に本文が出ません。
すでに add した変更を読むときは、次を使います。

```sh
git diff --cached
```

何も出ないことだけで、記録済みとは判断しません。

```sh
git status
```

状態を合わせて確かめます。

## 6-3-2 記録の一覧を読む

> **`git log --oneline` で、記録の一覧と説明を読みます。**

記録した後に、次を実行します。

```sh
git log --oneline
```

`--oneline` は、記録を1行ずつ表示する指定です。
結果の例です。先頭の文字列は記録ごとに違います。

```text
8ab12cd 見出しを学習メモに変える
3cd45ef 学習用のページを追加する
```

新しい記録が上に並びます。
先頭に、自分が付けた説明があるかを読みます。
短い文字列は、記録を識別する印です。
この一覧は、学習リポジトリ全体の記録です。
今の課題以外の説明も並ぶことがあります。
実務でも、説明から変更の経緯を探すときに使います。

## うまくいかないとき

### 表示から入力待ちに戻れない

差分や一覧が長い場合は、読むための画面で止まることがあります。
`q` キーを押すと、ターミナルの入力待ちに戻れます。

### 差分が出ない

保存済みか、すでに add したか、新規ファイルかを見ます。
`git status` と、必要なら `git diff --cached` を使います。
空の表示だけで、変更が消えたとは判断しません。

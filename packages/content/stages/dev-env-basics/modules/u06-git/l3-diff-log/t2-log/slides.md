# なぜ必要でしょうか

コミットのコマンドを実行しました。
いま付けた説明が、記録に残ったかを見たいです。

<!-- ノート: コマンドを入れたことと、記録ができたことを分けて確かめます。一覧の説明を読みます。 -->

---

# 覚えること

`git log --oneline` で、記録の一覧と説明を読みます。

`--oneline` は、1つの記録を1行で表示する指定です。
新しい記録から順に並びます。

<!-- ノート: 先頭にある短い文字列は記録を識別する印です。人によって値が違います。 -->

---

# 小さく試します


```sh
git log --oneline
```

結果の例です。
```text
8ab12cd 見出しを学習メモに変える
3cd45ef 学習用のページを追加する
```

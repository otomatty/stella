# 6-1-1 Git の役割

<!-- ノート: 編集を保存しただけでは分かりにくい、変更の経緯を残します。 -->

---

# なぜ必要でしょうか

昨日の見出しを今日書き換えました。
保存した後で、いつ何を変えたかを振り返りたくなりました。

<!-- ノート: 同じファイルを保存し直すだけでは、変更の説明は残りません。作業の区切りを記録できると便利です。 -->

---

# 覚えること

Git は、ファイルの変更を記録として残す道具です。

Git の記録には、その時点のファイルの内容と説明を残せます。

<!-- ノート: 実務でも、変更の経緯を調べるために記録を使います。ファイルの保存とは別の操作です。 -->

---

# 小さく試します

| 操作 | 残すもの |
| --- | --- |
| ファイルの保存 | 編集した内容 |
| Git の記録 | 区切りの内容と変更の説明 |

<!-- ノート: 保存した変更を、あとから Git に記録します。保存と記録の二つを区別してください。 -->

---

<!-- _class: summary -->
# まとめ

Git は、ファイルの変更を記録として残す道具です。

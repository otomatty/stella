# なぜ必要でしょうか

Git のコマンドを入れたら「見つからない」と出ました。
道具がまだ入っていないかもしれません。

<!-- ノート: 書き方だけを変えても、道具が無ければ起動しません。導入の状態を確認します。 -->

# 覚えること

Git は公式の配布元から入れ、`git --version` で確かめます。

この教材では Git 2.40以上を使います。
導入手順は、まとめの自分の OS の欄を選びます。

<!-- ノート: すでに対象の版が使えれば再導入しません。導入後は VS Code を開き直します。 -->

---

# 小さく試します


```sh
git --version
```

結果の例です。
```text
git version 2.40.0
```
版や末尾の文字は人によって違います。

<!-- ノート: git version に続く数字を読み、必要な版と比べます。診断の課題でも確認してください。 -->

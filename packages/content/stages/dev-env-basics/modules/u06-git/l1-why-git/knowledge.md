# Git とはの知識問題

## 確認クイズ

### Q1. ファイルを保存すると、自動で Git の記録になりますか。
<!-- kind: single; skills: git-local-commit -->

- A. はい
- B. いいえ。保存と Git の記録は別の操作です

<details>
<summary>解答と解説</summary>

**B** — 保存した内容を、作業の区切りで Git に記録します。

</details>

### Q2. この研修でリポジトリの一番上にする場所はどこですか。
<!-- kind: single; skills: git-local-commit -->

- A. 課題フォルダーごと
- B. PC の全ファイル
- C. 学習フォルダー web-training

<details>
<summary>解答と解説</summary>

**C** — 学習フォルダー全体を1つのリポジトリとして使い続けます。

</details>

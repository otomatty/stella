# 6-1-2 リポジトリとは

<!-- ノート: 課題が増えても、学習の記録を持つ場所を一つにそろえます。 -->

---

# なぜ必要でしょうか

学習フォルダーには、複数のステージや課題が並びます。
どこをひとまとまりとして記録すればよいでしょうか。

<!-- ノート: 課題ごとに記録場所を作ると、学習全体の記録が分かれます。この研修では範囲をそろえます。 -->

---

# 覚えること

リポジトリは、Git が記録を持つフォルダーです。

学習フォルダー全体を、1つのリポジトリにします。

<!-- ノート: web-training が記録の一番上です。これからのステージのファイルも同じリポジトリに残します。 -->

---

# 小さく試します

```text
web-training/ ← リポジトリの一番上
  dev-env-basics/
    u06-git/
      q01-init-repo/ ← 課題フォルダー
```

<!-- ノート: 課題フォルダーはリポジトリの内側です。課題ごとの記録場所を新しく作る必要はありません。 -->

---

# まとめ

# 6-2-3 記録しないものを決める

<!-- ノート: 自分が書くファイルと、道具が繰り返し作る出力を分けます。 -->

---

# なぜ必要でしょうか

手元の確認をするたびに、結果のファイルが変わります。
この変化まで毎回記録する必要があるのでしょうか。

<!-- ノート: 道具が作る大きなフォルダーや毎回変わる結果は、学習の変更と分けておくと読みやすくなります。 -->

---

# 覚えること

記録しないファイルは `.gitignore` に書きます。

`.gitignore` は、まだ記録していないもののうち、
Git で記録の対象にしないパターンを書くファイルです。

<!-- ノート: 学習フォルダー直下に置きます。すでに記録したファイルを取り除く機能ではありません。 -->

---

# 小さく試します

```text
node_modules/
**/.stella/last-run.json
**/.stella/dotnet/
```

<!-- ノート: node_modules は npm の部品、last-run.json は確認の結果です。dotnet は C# のビルドの出力で、今は使いません。 -->

---

<!-- _class: summary -->
# まとめ

記録しないファイルは `.gitignore` に書きます。

# 6-2-1 記録する場所を決める

<!-- ノート: 初期化する場所が、その後の記録の範囲になります。 -->

---

# なぜ必要でしょうか

ターミナルはいま、課題フォルダーで開いています。
ここで記録の準備を始めてもよいのでしょうか。

<!-- ノート: 課題フォルダーで初期化すると、学習全体を記録する範囲になりません。実行前の場所が大切です。 -->

---

# 覚えること

`git init` は、学習フォルダーで 1 回だけ実行します。

初期化は、Git が記録を持つ準備をすることです。
実行する前に `pwd` で `web-training` かを確かめます。

<!-- ノート: ステージや単元ではなく学習フォルダーを選びます。すでに初期化済みなら繰り返しません。 -->

---

# 小さく試します


```sh
git init
```

学習フォルダーの中に、Git の記録用の `.git` ができます。

<!-- ノート: 課題フォルダーにいる場合は、まずまとめの手順で学習フォルダーへ戻します。場所が合ってから実行します。 -->

---

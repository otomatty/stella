# 6-2-4 選んで記録する

<!-- ノート: 保存済みの変更を、作業の区切りとして説明と一緒に残します。 -->

---

# なぜ必要でしょうか

ファイルは保存しました。
Git にどの変更を残すかは、まだ選んでいません。

<!-- ノート: 保存しただけではコミットになりません。記録の候補を確認してから選びます。 -->

---

# 覚えること

`git add` で選び、`git commit` で記録します。

コミットは、選んだ変更を説明と一緒に残す記録です。
`git status` で、選ぶ前と選んだ後の状態を見ます。

<!-- ノート: add の時点では、まだ記録は完成していません。commit まで進めることで区切りが残ります。 -->

---

# 小さく試します


```sh
git add .
```

`.` は、いまのフォルダー以下を選ぶ指定です。
実行した後に、別の1行で記録します。

```sh
git commit -m "学習メモを追加する"
```


<!-- ノート: 学習フォルダーで実行すると、そこから下の変更を選びます。-m の後ろに記録の説明を書きます。 -->

---

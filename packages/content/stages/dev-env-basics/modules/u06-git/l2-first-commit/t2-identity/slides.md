# 6-2-2 記録者を設定する

<!-- ノート: 変更の記録に添える名前とメールを、学習用の範囲に設定します。 -->

---

# なぜ必要でしょうか

最初の記録を作ろうとしたら、名前とメールを求められました。
PC全体の設定を変える必要があるのでしょうか。

<!-- ノート: 他の作業の設定まで変える必要はありません。学習リポジトリの中で設定します。 -->

---

# 覚えること

名前とメールは、学習リポジトリだけに設定します。

リポジトリの中で `git config` を実行すると、
そのリポジトリだけの設定になります。

<!-- ノート: ここでは --global を使いません。メールは研修で指定されたものを使います。 -->

---

# 小さく試します


```sh
git config user.name "yamada"
```

`yamada` は例です。自分が研修で使う名前に置き換えます。

<!-- ノート: 名前を設定する一行です。メールの設定もまとめにある別の一行で行います。 -->

---

# 確認A: 自己紹介のフォルダーを整える

目安は20分です。ここまでに使った操作で、自力で仕上げます。
公式の資料で、文法や操作を確かめて構いません。
ヒントはありません。解答例は合格するまで表示されません。

## 配られるファイル

- `index.html`: 仮の見出しが入った HTML 文書
- `memo.txt`: 「明日はファイルの名前を変える練習をします」という1行のメモ

## やること

1. `index.html` の `h1` の文字を「自己紹介」に変えて保存し、ブラウザーで表示を確かめます。ほかの要素は増やさず、消さずに残します。
2. 同じ課題フォルダーに新しいファイル `hobby.txt` を作り、「好きなこと」と書いて保存します。続けて自分の好きなことを書いても構いません。
3. `memo.txt` の名前を `todo.txt` に変えます。中身はそのまま残し、元の名前のファイルは残しません。
4. 「課題を確認する」で確かめ、全部通ったら提出します。説明に、作ったファイルの場所と、困ったことと試したことを書きます。困ったことがなければ「なし」と書きます。

## 提出するもの

`index.html`・`hobby.txt`・`todo.txt` と説明です。
提出後はレビューの結果を読み、再提出なら直して保存・確認・提出します。

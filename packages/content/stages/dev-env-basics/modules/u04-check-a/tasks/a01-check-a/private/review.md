# レビューの観点

- index.html の h1 が1つだけあり、文字が「自己紹介」で、ほかの要素を増やしたり消したりしていない
- index.html と同じ課題フォルダーに hobby.txt があり、「好きなこと」と書いて保存されている
- memo.txt が残っておらず、todo.txt の本文が元の文「明日はファイルの名前を変える練習をします」のままである
- 手元の確認を通して提出し、説明に作ったファイルの場所と困ったこと・試したこと（なければ「なし」）があり、提出ファイルと矛盾していない

手元の検査は HTML 文書・見出しの文字と件数・指定の文・元のファイルの不在を確かめます。
ほかの要素の増減と、`todo.txt` の本文が変更されていないことは starter と見比べます。
ブラウザーで表示を確かめた事実は、ファイルだけから断定しません。
説明に作成場所の矛盾がないかを確かめ、パスの OS ごとの表記の違いは認めます。
困ったことがない場合の「なし」は受け入れ、説明の定型文との一致は求めません。
相談・代行操作の支援記録があれば、自力の証拠とは分けて人が確認します。
環境上の問題と操作の不足は分けて扱います。

# 解説

`index.html` は配られた HTML 文書を保ち、`h1` のタグの間だけを「自己紹介」に変えます。
ブラウザーは保存されたファイルを読むので、編集後は保存して再読み込みします。

`hobby.txt` は `index.html` と同じ課題フォルダーに作り、「好きなこと」と書いて保存します。
`memo.txt` は「名前の変更」で `todo.txt` にします。
本文「明日はファイルの名前を変える練習をします」は変えません。
新しい名前のファイルを作るだけで元のファイルを残すと、名前の変更の条件を満たしません。

解答例を starter に重ねるときは、`.stella-solution.json` の指定で `memo.txt` を消します。
提出の説明は、実際に作ったファイルの場所と、困ったこと・試したことを伝えるためのものです。
困ったことがなければ「なし」と書きます。

# レッスン04-1 確認Aに取り組む

## このレッスンの目標

- [ ] 確認Aを自力で仕上げ、説明を添えて提出できる
- [ ] 確認Bが届く時期を説明できる

## 04-1-1 確認Aに取り組む

> **確認Aは、ヒントを使わず、ここまでの操作だけで1つの課題を仕上げます。**

確認Aは、練習と違う題材で、同じ操作を使えるか確かめる課題です。
仕事でも、ファイル名や内容が変わるたびに、必要な操作を選びます。
新しい操作を覚えるのではなく、ここまでの操作を組み合わせます。

Web の確認A「自己紹介のフォルダーを整える」から「VS Code で開く」を押します。
課題文を読み、指定されたファイル名・文字・提出するものを確かめます。
編集・保存、ブラウザーでの表示、新しいファイルの作成、名前の変更を自分で進めます。

公式の資料で、文法や操作を確かめて構いません。
ヒントはありません。解答例は確認Aに合格するまで表示されません。
他の人に作ってもらう代わりに、自分で操作します。
進められなければ「講師に相談」で、困ったことと試したことを伝えます。
支援を受けた記録は、自力でできた記録と分けて確認します。

### 確認して提出する

保存したら「課題を確認する」を押します。
通らない項目があれば結果を読み、課題文と見比べます。
直して保存し、もう一度確認します。

全部通ったら「提出する」を押します。
説明には、作ったファイルの場所と、困ったことと試したことを書きます。
困ったことがなければ「なし」と書きます。
ファイルの場所は、実際に提出するファイルに合わせます。

手元の確認が通っただけでは、提出後の合格にはなりません。
AI の一次レビューと、必要に応じた講師の確認の結果を読みます。
再提出なら、指摘に沿って直し、保存・確認・提出を行います。

### 合格したら

:::tutorial stage-progress

確認Aに合格し、ほかのレッスンや課題も終わると、このステージがクリアになります。
ホームのスキルツリーでは、次の星が見えてきます。
星がクリアにならなければ、ステージ詳細で残っている課題やレビューの状態を確かめます。

確認Bは、確認Aの合格から7日後に届きます。
同じ操作を使う、似た別の課題です。
ホームのガイドに出たら、新しい課題文を読み、自力で取り組みます。
確認Aのファイルをそのまま出し直すものではありません。
確認Bにはヒントがなく、解答例は合格後も表示されません。

# 04-1-1 確認Aに取り組む

# 覚えること

確認Aは、ヒントを使わず、ここまでの操作だけで1つの課題を仕上げます。

公式の資料は見て構いません。

<!-- ノート: 確認Aは、練習と違う題材で自力で仕上げる課題です。ヒントはなく、解答例は合格まで出ません。公式の資料で文法や操作を確かめられます。 -->

---

# 自分で仕上げて提出する

1. 課題文を読み、編集・保存・表示・ファイルの操作を行う
2. 「課題を確認する」で確かめ、説明を添えて提出する
3. AI や講師の確認の結果を読む

確認Bは、確認Aの合格から7日後に届く、似た別の課題です。

<!-- ノート: 手元の確認が通ったら提出します。確認Aに合格し、ほかのレッスンや課題も終わると、このステージがクリアになり、次の星が見えてきます。確認Bは時間を空けて、同じ操作が身に付いたか確かめます。 -->

# サーバーで確かめて記録する

## 作るもの

提供された index.html は、h1 が「お知らせ」で、p が1つあります。
サーバーで表示しながら、h1 を「今週のお知らせ」に変えます。
p は2つ以上にします。変更を Git にコミットしてください。
server.mjs は U07 と同じ提供ファイルです。編集しません。

Git は、U06 で準備した学習フォルダーを使います。
この課題フォルダーに、別のリポジトリを作らないでください。
この課題のフォルダーの変更を、2 回以上に分けてコミットします。
index.html が記録済みの状態にします。
変更前をまだ記録していない場合は、先に開始時点を記録します。
変更後の差分を読めるようにしてから、実装を進めます。

提出は index.html です。説明に開いた URL と、git diff で見えた変更を書きます。
取り組み中に使えるものは、仕様と参照元です。ヒントはありません。

## 手順

1. Web から課題を開き、仕様を読み、配られた開始時点をコミットします。
   この課題の開始時点がすでに記録されていれば、その記録を使います。
2. サーバーで表示しながら変更・保存し、再読み込みして確かめます。
3. 差分を読み、変更後の状態を2回目としてコミットします。使ったサーバーは止めます。
4. 「課題を確認する」で通ったら、説明を添えて提出し、結果を読みます。

## うまくいかないとき

環境の問題は、実行した操作・メッセージ・試したことを伝えて相談します。
課題の解き方を示すヒントや、取り組み中の解答例はありません。
起動・停止や差分を読んだ操作は、自動の確認だけでは分かりません。
実際に行った内容を説明してください。

# 学習予定のページを作る

## 作るもの

この課題フォルダーの中に plan/index.html を作ってください。
HTML の文書にし、h1 は「学習予定」にします。
学習する内容を li で3件以上並べます。
ページをブラウザーで表示できることを確かめます。
提出は plan/index.html です。説明には保存先と、表示を確かめた内容を書きます。
ファイルを作る手順は、自分で選んでください。

## 手順

1. Web の「VS Code で開く」で開き、仕様に合うページを作って保存します。
2. ブラウザーで表示を確かめ、「課題を確認する」を押します。
3. 通ったら、説明を添えて提出し、レビューの結果を読みます。

## うまくいかないとき

U03 のまとめで作成と保存先、下の公式資料で HTML の文書とリストを確かめます。
困った状態と試したことを伝えれば、講師に相談できます。

# 次の日に続きを書く

## 作るもの

diary.html には「学習日記」の h1、「1日目」の h2 と段落があります。
その内容を残し、「2日目」の h2 と、その日に学んだことの段落を加えます。
h2 は合計2つ以上になります。

VS Code を閉じて、次の日に Web から開き直して続きを書いてください。
同じ保存先へ戻り、保存した内容から再開するための練習です。
閉じたことや日をまたいだことは、自動では確かめられません。
授業の都合で日をまたげない場合は、講師と再開する時刻を決めます。
提出は diary.html です。説明に、再開した保存先と加えた内容を書きます。

## 手順

1. Web の「VS Code で開く」で課題を開き、1日目の内容を確認して保存します。
2. VS Code を閉じ、次の日に同じ Web の課題から開き直します。
3. 仕様に合わせて続きを書き、保存してブラウザーで確かめます。
4. 「課題を確認する」で通ったら、説明を添えて提出し、結果を読みます。

## うまくいかないとき

同名の別ファイルではないか、課題フォルダーと保存先を照合します。
再開の操作は U01、ファイルの場所は U03 のまとめに戻れます。

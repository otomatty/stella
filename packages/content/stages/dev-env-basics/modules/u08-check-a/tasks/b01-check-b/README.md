# 確認B: 1週間の予定の 2 ページ

## 作るもの

この課題フォルダーの中に、次の2ページを作ります。
指定したフォルダーとファイル名を使ってください。

| 保存先 | 内容 |
| --- | --- |
| schedule/index.html | HTML の文書。h1 は「1週間の予定」。同じ schedule 内の detail.html へ進むリンク |
| schedule/detail.html | HTML の文書。h1 は「詳しい予定」。同じ schedule 内の index.html へ戻るリンク |

index.html には、予定を li で3件以上並べます。

リンクは相対パスで書き、ブラウザーで行きも帰りも確かめます。
実在の個人名や個人情報を使う必要はありません。
U06 で準備した学習リポジトリで、この2ファイルをコミットします。
学習リポジトリにコミットが1件以上ある状態が条件です。
課題フォルダーの中に別のリポジトリを作らないでください。

提出は schedule/index.html と schedule/detail.html です。
説明に「どのフォルダーで何を作ったか」を書きます。
困ったことと試したことも、実際の操作に合わせて書いてください。
困ったことがなければ、そのことと表示・リンクの確認内容を書きます。

### 参照と支援

教材・公式資料・メニューを参照して構いません。
この確認課題にはヒントがありません。取り組み中の解答例もありません。
講師に相談したら、その提出は人が確認します。
講師が代わりに操作した場合は、自力の記録と分けます。
端末の設定などの環境支援は、操作の評価と分けて扱います。

## 手順

1. VS Code を閉じた状態から、Web の「VS Code で開く」でこの確認Bを開きます。
2. 仕様を読み、自分で操作を選んで作成・保存・表示・記録を行います。
3. 「課題を確認する」で通ったら、説明を添えて提出し、レビューの結果を読みます。

## うまくいかないとき

教材や公式資料で、今止まっている操作を確認できます。
環境の問題で進めないときは、できたところ・メッセージ・試したことを伝えます。
確認結果は、実際にリンクを押した操作や、説明の正しさのすべてを証明しません。
表示を自分で確かめ、説明とファイルを一致させてください。

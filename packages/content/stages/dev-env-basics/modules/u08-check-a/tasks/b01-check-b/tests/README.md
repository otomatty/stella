# 手元の確認

「課題を確認する」を押すと、次を確かめます。

- `schedule/index.html` が HTML の文書の形になっている
- `schedule/detail.html` が HTML の文書の形になっている
- `schedule/index.html` の `h1` の文字が「1週間の予定」と完全に一致する
- `schedule/index.html` の `h1` が 1 つだけある
- `schedule/detail.html` の `h1` の文字が「詳しい予定」と完全に一致する
- `schedule/detail.html` の `h1` が 1 つだけある
- `schedule/index.html` のリンク先のファイルが、課題フォルダーの中にある
- `schedule/detail.html` のリンク先のファイルが、課題フォルダーの中にある
- `schedule/index.html` の `li` が 3 つ以上ある
- `schedule/index.html` と `schedule/detail.html` をコミットしていて、記録していない変更が残っていない
- この課題の変更を 1 回以上コミットしている

手元では、課題フォルダー内のファイルへのリンク先があるかだけを確認し、ページ内・外部 URL・行き先のないリンクは確かめません。
相手のページが開くことは、ブラウザーでリンクを押して自分で確かめます。

このフォルダーのファイルは編集しないでください。

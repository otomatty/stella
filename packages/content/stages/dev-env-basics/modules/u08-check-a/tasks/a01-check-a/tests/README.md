# 手元の確認

「課題を確認する」を押すと、次を確かめます。

- `profile/index.html` が HTML の文書の形になっている
- `profile/hobby.html` が HTML の文書の形になっている
- `profile/index.html` の `h1` の文字が「自己紹介」と完全に一致する
- `profile/hobby.html` の `h1` の文字が「好きなこと」と完全に一致する
- `profile/index.html` のリンク先のファイルが、課題フォルダーの中にある
- `profile/hobby.html` のリンク先のファイルが、課題フォルダーの中にある
- `profile/index.html` と `profile/hobby.html` をコミットしていて、記録していない変更が残っていない
- この課題の変更を 1 回以上コミットしている

このフォルダーのファイルは編集しないでください。

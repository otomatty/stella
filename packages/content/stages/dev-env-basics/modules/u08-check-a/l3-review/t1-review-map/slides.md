# 8-3-1 操作からまとめを探す

<!-- ノート: 復習では、困った状態から必要な単元を探す方法を使います。 -->

---

# なぜ必要でしょうか

リンクが開かないのに、Node.js を入れ直そうとしてしまいました。
困っている操作に合う説明へ戻ると、確認する場所を絞れます。

<!-- ノート: リンクの名前違いは、実行環境を入れ直しても直りません。現象と操作を先に結び付けます。 -->

---

# 覚えること

つまずいた操作は、その単元のまとめに戻って確かめます。

全部を読み直す前に、止まっている操作を一つ選びます。

<!-- ノート: 一つの操作に絞ると、どこを読み返すか決めやすくなります。目次の見出しを手がかりにしてください。 -->

---

# 画面で確かめます

| 止まった操作 | 戻るまとめ |
| --- | --- |
| 表示・提出 | U02 |
| 保存先・再開 | U03 |
| リンク | U04 |
| 場所・版の確認 | U05 |
| 差分・記録 | U06 |
| URL・起動・停止 | U07 |

<!-- ノート: たとえば URL が開かないなら U07、差分が出ないなら U06 です。実務でも現象に合った資料を探します。 -->

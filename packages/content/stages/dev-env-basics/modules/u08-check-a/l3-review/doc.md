# レッスン8-3 復習

## このレッスンの目標

- [ ] 困っている操作から、戻る単元を選べます。
- [ ] 用語を具体的な画面や操作に結び付けられます。

## 8-3-1 操作からまとめを探す

> **つまずいた操作は、その単元のまとめに戻って確かめます。**

全部を最初から読み直す前に、止まっている操作を一つ選びます。
たとえば、ページが変わらないときは保存と表示を見ます。
リンク先だけ開けないときは、相対パスとファイル名を見ます。

| 単元 | 要点 | 戻るまとめ |
| --- | --- | --- |
| U02 | 保存後に再読み込みし、確認して提出する | 保存と表示・課題の進め方 |
| U03 | 課題フォルダーと保存先を照合し、開き直す | 画面とファイルの操作 |
| U04 | リンク元から見た相対パスで行き来する | ページを増やしてつなぐ |
| U05 | ターミナルの場所と Node.js・npm の版を確かめる | ターミナルとNode.js・npm |
| U06 | 差分を読み、変更を選んでコミットする | Gitで変更を残す |
| U07 | 表示された URL で開き、最後にサーバーを止める | ローカルサーバーで開く |

### 用語の一覧

| 用語 | 意味・確かめる場所 |
| --- | --- |
| 学習フォルダー | 学習で使う課題をまとめて置く web-training |
| 課題フォルダー | 今回の課題のファイルを置く場所 |
| 保存 | エディターの変更をファイルに残す操作 |
| 再読み込み | ブラウザーで表示を読み直す操作 |
| 拡張子 | .html など、名前の末尾で種類を示す部分 |
| 相対パス | 基準となるファイルやフォルダーから見た位置 |
| ターミナル | コマンドを入力して結果を読む画面 |
| プロンプト | ターミナルが入力を待つ印 |
| Node.js | JavaScript をブラウザーの外で動かす実行環境 |
| npm | Node.js で使うパッケージを扱う道具 |
| Git | ファイルの変更を記録する道具 |
| コミット | 区切りの内容と説明を Git に残す記録 |
| 差分 | 変更前と変更後の違い |
| サーバー | 要求に応じてファイルなどを返すプログラム |
| localhost | 自分の PC を指す名前 |
| ポート番号 | 接続する窓口を区別する数字 |

用語を覚えるだけでなく、自分の画面を一つ確かめます。
実務でも、困った現象に合う資料を選び、操作を一つずつ試します。

## うまくいかないとき

### 読み返しても直らない

目的・できたところ・実行した操作・メッセージを文字で残します。
試したことも添えて「講師に相談」へ進みます。
認証情報などは貼り付けません。
環境の問題を、ページの修正だけで直そうとしないようにします。

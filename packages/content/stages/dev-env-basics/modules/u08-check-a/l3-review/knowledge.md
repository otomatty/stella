# 復習の知識問題

## 確認クイズ

### Q1. U02: 見出しを変えた後、ブラウザーに反映する順はどれですか。
<!-- kind: single; skills: preview-changes -->

- A. 再読み込みしてから保存だけする
- B. 保存してから再読み込みする
- C. 提出だけする

<details>
<summary>解答と解説</summary>

**B** — 保存した内容をブラウザーで読み直します。

</details>

### Q2. U03: 同名ファイルを違う場所で開いていそうです。何を比べますか。
<!-- kind: single; skills: file-save-reopen -->

- A. 文字の色だけ
- B. ウィンドウの大きさだけ
- C. 課題フォルダーと保存先のパス

<details>
<summary>解答と解説</summary>

**C** — ファイル名だけでなく場所を照合します。

</details>

### Q3. U04: pages/about.html から、一つ上の index.html に戻る相対パスはどれですか。
<!-- kind: single; skills: relative-link -->

- A. ../index.html
- B. pages/index.html
- C. about.html

<details>
<summary>解答と解説</summary>

**A** — .. は一つ上のフォルダーを指します。

</details>

### Q4. U05: コマンドを実行する前に、場所を確かめるものはどれですか。
<!-- kind: single; skills: terminal-location -->

- A. git commit
- B. pwd
- C. ブラウザーの再読み込み

<details>
<summary>解答と解説</summary>

**B** — pwd の結果を課題フォルダーと比べます。

</details>

### Q5. U05: Node.js の導入後も node が見つかりません。最初にどうしますか。
<!-- kind: single; skills: node-npm-ready -->

- A. 学習フォルダーを削除する
- B. 制限をすべて解除する
- C. 保存して VS Code を再起動し、版を再確認する

<details>
<summary>解答と解説</summary>

**C** — 導入前から開いていた画面では、PATH の変更が反映されていない場合があります。

</details>

### Q6. U06: 記録済みファイルの編集後、add 前の差分を読む操作はどれですか。
<!-- kind: single; skills: git-local-commit -->

- A. git diff
- B. git init
- C. git log --oneline

<details>
<summary>解答と解説</summary>

**A** — 変更前後を読んでから選び、コミットします。

</details>

### Q7. U07: サーバーを止める場所と操作はどれですか。
<!-- kind: single; skills: local-server-run -->

- A. エディターでファイルを削除する
- B. 起動したターミナルで Ctrl+C
- C. ブラウザーのタブを閉じるだけ

<details>
<summary>解答と解説</summary>

**B** — 入力待ちへ戻ったことを確認します。

</details>

### Q8. 直らずに相談するとき、何を伝えますか。
<!-- kind: single; skills: report-problem -->

- A. うまくいかない、とだけ書く
- B. 認証情報を含む全文
- C. 目的・できたところ・操作・メッセージ・試したこと

<details>
<summary>解答と解説</summary>

**C** — 状況を文字で伝えると、確認する場所を一緒に絞れます。

</details>

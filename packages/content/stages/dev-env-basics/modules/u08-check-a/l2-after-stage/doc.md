# レッスン8-2 ステージを終えたら

## このレッスンの目標

- [ ] 確認Bが出る時期と、取り組む順を説明できます。
- [ ] 修了の条件と、次の星・島・腕試しの役割を説明できます。

## 8-2-1 時間を空けて確認する

> **確認Bは、確認Aの合格から 7 日後に、別の題材で出ます。**

確認Bは、間を空けて定着を確かめる課題です。
次のステージを進めている時期に、ホームのガイドに出ます。
出たら、次の学習より先に取り組みます。
確認Aのファイルを出し直すのではなく、新しい仕様を読みます。

VS Code を閉じた状態から、Web の「VS Code で開く」で再開します。
教材・公式資料を参照できます。ヒントはありません。
確認Bの解答例は、合格後も表示されません。レビューの所見を読みます。
この定着確認の時間は、次のステージの評価・復習に数えます。

## 8-2-2 修了後の星を見る

:::tutorial stage-progress

> **ステージを修了すると、次の星と島が開きます。**

修了は、ステージを終えた区切りです。
条件はレッスンの完了と、確認Aを含む課題の合格です。
手元の確認が通っただけでは、提出後の合格にはなりません。
確認Bは、確認Aの合格から7日後に出る別の定着確認です。
残っている課題やレビューの状態は、ステージ詳細で確かめます。
修了証は、ステージを終えたことを示すものです。

スキルツリーでは、次の HTML/CSS と JavaScript の星を確認します。
島は、資格などの分野ごとにまとまった星の集まりです。
修了により表示の条件を満たしても、割り当てのない島は出ません。
すべての島を必ず学ぶわけではありません。

腕試しは、知っている内容を先に確かめる機能です。
腕試しがある星のカードで「腕試し」を選びます。
合格すると、その内容の先から始められます。
分からない内容は、教材を使って学習を進めます。

## うまくいかないとき

### レッスンを終えたのに星がクリアにならない

ステージ詳細で、合格していない課題を確かめます。
未提出なら提出し、再提出なら所見を読んで直します。
レビュー待ちなら、通知や提出の状態を確認します。

### 島や腕試しが見つからない

島には表示の条件と割り当てがあります。
腕試しの有無は、星のカードで確認します。
必要な島の割り当てが分からなければ、講師に相談します。

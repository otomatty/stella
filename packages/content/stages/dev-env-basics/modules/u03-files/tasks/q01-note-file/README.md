# メモのファイルを作る

## 何をするか

課題フォルダーに `note.txt` を作り、
「今日から学習を始めました」と書いて保存します。
この課題では、メモのファイルはまだ配られていません。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. エクスプローラーで、この課題のフォルダーを選びます。
3. 「新しいファイル」ボタンか、右クリックの「新しいファイル」を使います。
4. 指定した名前でメモを作り、指定の文を書きます。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. すべて通ったら提出し、届いたレビューの結果を読みます。

## うまくいかないとき

一覧でファイルの場所と名前を確かめます。
`.txt.txt` のように拡張子を二重にしないようにします。

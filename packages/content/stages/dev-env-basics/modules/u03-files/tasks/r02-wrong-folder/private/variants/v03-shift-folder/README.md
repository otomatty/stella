# 当番表の表示だけが古い

## 何をするか

当番表を「来週の当番表」に変えたはずなのに、表示は「当番表」です。
公開用は `current/index.html`、前の記録は `archive/index.html` です。
配布ファイルには、この症状が起きた状態を入れてあります。
2つのページを調べ、公開用に「来週の当番表」を表示させます。
前の記録の見出しは「当番表」に戻します。
名前・場所・h1 以外の要素は変えません。
修正前後に、公開用と前の記録をそれぞれブラウザーで開きます。
修正記録には、比べたファイルの場所と、両方の表示を書きます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
通ったら、原因・直したこと・確かめた結果を修正記録に書いて提出します。

# 違うフォルダーのファイルを直していた

## 何をするか

見出しを「今月のお知らせ」に直したのに、ブラウザーの表示が変わりません。
直したのは `site-old` のほうだった、という状況です。
配布ファイルは調べ始める前の状態で、両方とも「お知らせ」です。
表示に使うページは `site`、以前のページは `site-old` にあります。
表示用の見出しを直し、以前のページの見出しは元のまま残します。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. 2つのフォルダーと、ブラウザーで表示するページの場所を照合します。
3. パンくずリストで保存先を読み、必要な変更を行います。
4. 保存後、表示するページをブラウザーで開き直して確かめます。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. 通ったら、原因・直したこと・確かめた結果を修正記録に書いて提出します。

## うまくいかないとき

タブの名前が同じでも、同じ場所とは限りません。
エディターの上のパンくずリストと、表示するページの場所を比べます。

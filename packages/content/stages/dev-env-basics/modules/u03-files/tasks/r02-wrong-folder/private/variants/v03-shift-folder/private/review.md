# レビューの観点

- current/index.html の h1 が「来週の当番表」と完全に一致する
- archive/index.html の h1 が「当番表」と完全に一致する
- 修正記録に、表示するファイルと編集したファイルの場所の比較が書かれている

修正記録に再現・原因・修正・回帰確認があるかを読みます。
操作した事実は、提出ファイルだけから推測しません。
ヒントや解答例を開いたこと自体は、不合格の理由にしません。

## よくある違反

- 両方を「来週の当番表」にしている。前の記録は「当番表」に戻すよう返します。
- archive だけを直して公開用が古いままです。表示に使う場所を示します。
- 修正記録に場所の比較が無い。パンくずリストで読んだ保存先を求めます。

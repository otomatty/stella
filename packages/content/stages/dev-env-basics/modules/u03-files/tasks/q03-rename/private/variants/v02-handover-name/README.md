# 引継ぎメモの名前を整える

## 何をするか

次の担当者が探しやすいように、メモの名前を整えます。
配られた `draft.txt` を `handover.txt` に改名します。
本文の「返却した鍵は受付で保管します」は変えません。
コピーを増やさず、終わったら `draft.txt` が無い状態にします。
一覧で名前を変え、開き直して本文を確かめます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
すべて通ったら提出し、届いたレビューの結果を読みます。

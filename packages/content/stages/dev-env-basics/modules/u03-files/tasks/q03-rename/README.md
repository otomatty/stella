# ファイルの名前を変える

## 何をするか

配られた `memo.txt` の名前を `plan.txt` に変えます。
本文の「明日の学習でファイルの操作を練習します」は残します。
終わったら `plan.txt` だけがあり、`memo.txt` は無い状態にします。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. memo.txt を開き、元の文を読みます。
3. 一覧のファイルを右クリックし、「名前の変更」で指定の名前にします。
4. 名前を最後まで読み、開き直して本文を確かめます。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. すべて通ったら提出し、届いたレビューの結果を読みます。

## うまくいかないとき

新しい名前でコピーを作る操作とは違います。
一覧に元の名前も残っていないか、拡張子も含めて読みます。

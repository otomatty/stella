# 閉じて開き直して書き足す

## 何をするか

配られた `diary.txt` を閉じて開き直し、記録を書き足します。
1行目の「1日目: VS Code を入れました」を残します。
2行目は「2日目: ファイルを開き直しました」にします。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. diary.txt を保存し、タブの「×」で閉じます。
3. エクスプローラーから同じファイルを開き直します。
4. 1行目が残っていることを読み、2行目を書き足します。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. すべて通ったら提出し、届いたレビューの結果を読みます。

## うまくいかないとき

左の一覧からファイル名を押して開き直します。
タブを閉じる操作と、ファイルの削除を混同しないようにします。

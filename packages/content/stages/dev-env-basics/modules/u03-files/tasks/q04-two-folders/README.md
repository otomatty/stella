# 2つのフォルダーを使い分ける

## 何をするか

2つのフォルダーにある、同名のページを使い分けます。
`practice-a/index.html` の見出しは「練習A」にします。
`practice-b/index.html` の見出しは「練習B」にします。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. practice-a の index.html を開き、パンくずリストで場所を読みます。
3. 見出しを指定の文に変え、保存します。
4. practice-b の index.html を開き、パンくずリストを読んでから変えます。
5. 両方を保存し、それぞれブラウザーで表示を確かめます。
6. 「ファイル > すべて保存」を選びます。
7. 「課題を確認する」で、通らなかった項目を読みます。
8. すべて通ったら提出し、届いたレビューの結果を読みます。

## うまくいかないとき

タブの index.html だけでは区別しにくい場合があります。
エディターの上で、手前のフォルダーの名前まで読みます。

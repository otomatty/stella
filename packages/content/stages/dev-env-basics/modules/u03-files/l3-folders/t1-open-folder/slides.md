# 3-3-1 作業フォルダーを開く

# index.html の本文は見えますが、左に同じ場所のファイルが並びません

index.html の本文は見えますが、左に同じ場所のファイルが並びません。
ほかのページも一緒に扱うには、どうすればよいでしょうか。

<!-- ノート: 本文だけが開いていると、隣にあるファイルを一覧で探せません。作業場所をまとめて開く操作を使います。 -->

---

# 覚えること

VS Code で開くのは、ファイルではなく作業フォルダーです。

作業フォルダーは、作業するファイルをまとめて置く場所です。

<!-- ノート: ここでは、作業フォルダーを開くことを基本にします。関連するファイルを一覧で扱うためです。 -->

---

# 画面で確かめる

「ファイル > フォルダーを開く」を選びます。
学習では `web-training` を選んで開きます。

<!-- ノート: フォルダーを開くメニューで学習フォルダーを選びます。開いたあと、左にその名前が出るか見ましょう。 -->

# レッスン3-3 作業フォルダーと保存先

## このレッスンの目標

- [ ] 作業フォルダーを開けます。
- [ ] パンくずリストで保存先を読めます。

## 3-3-1 作業フォルダーを開く

> **VS Code で開くのは、ファイルではなく作業フォルダーです。**

「ファイル > フォルダーを開く」を選びます。
自分の学習フォルダー `web-training` を選び、「開く」を押します。
開く場所を変える前には「ファイル > すべて保存」を選びます。
学習フォルダーの中のステージ・単元・課題を順に展開します。
単独のファイルだけを開くと、一覧にフォルダーが出ません。
STELLA の学習では、学習フォルダーを開いた状態で進めます。
実務でも、関連するファイル一式を作業フォルダーとして開きます。

## 3-3-2 保存先を確かめる

> **保存先は、エディターの上のパンくずリストで分かります。**

エディターの上の `practice-a > index.html` を読みます。
これは `practice-a` の中のファイルだと分かる表示です。
`practice-b > index.html` なら、同名でも別のファイルです。
表示が無ければ「表示 > 外観 > パンくずリスト」で表示します。
実務でも、似た名前のページを直す前に保存先を照合します。

## うまくいかないとき

### 本文は出るがフォルダーが出ない

単独のファイルだけを開いていないか確かめます。
「ファイル > フォルダーを開く」で学習フォルダーを選びます。

### 直したはずなのに別の表示が変わった

パンくずリストと、ブラウザーで開いているファイルの場所を比べます。
タブの名前だけで決めず、手前のフォルダーも読みます。

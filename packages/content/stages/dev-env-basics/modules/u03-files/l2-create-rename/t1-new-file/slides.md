# 3-2-1 新しいファイルを作る

<!-- ノート: 新しいメモを課題の場所に作りましょう。一覧で選んでいるフォルダーに注目します。 -->

---

# メモを作ったのに、提出する課題フォルダーの中にありません

メモを作ったのに、提出する課題フォルダーの中にありません。
作り始める場所を、どう選べばよいでしょうか。

<!-- ノート: 内容が正しくても、別の場所にあると目的の課題で使えません。入力する前の選択を確かめます。 -->

---

# 覚えること

新しいファイルは、エクスプローラーで場所を選んでから作ります。

ファイルを作る前に、置くフォルダーを選びます。

<!-- ノート: 作成先を選ぶ操作を先にします。名前だけでなく、どこに置くかを決めましょう。 -->

---

# 画面で確かめる

課題フォルダーを右クリックし、「新しいファイル」を選びます。
名前を `note.txt` と入力し、Enter キーで決めます。

<!-- ノート: 右クリックしたフォルダーの中に note.txt が現れます。文字を入力したら保存してください。 -->

---

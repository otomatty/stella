# レッスン3-2 ファイルを作る・名前を変える

## このレッスンの目標

- [ ] 場所を選んで新しいファイルを作れます。
- [ ] 拡張子を残して名前を変えられます。

## 3-2-1 新しいファイルを作る

> **新しいファイルは、エクスプローラーで場所を選んでから作ります。**

課題フォルダーを選び、一覧の上の「新しいファイル」ボタンを押します。
または、課題フォルダーを右クリックして「新しいファイル」を選びます。
`note.txt` と入力し、Enter キーで名前を決めます。
本文を入力し、「ファイル > 保存」を選びます。
一覧で、選んだ課題フォルダーの中にあるか確かめます。
実務でも、ファイルを使う作業場所を先に選びます。

## 3-2-2 名前の最後の拡張子

> **名前の最後の拡張子が、ファイルの種類を表します。**

`.txt` は文章のメモ、`.html` は HTML の文書で使います。
名前を変えるときは、対象を右クリックし「名前の変更」を選びます。
`memo.txt` を `plan.txt` に変えるなら、最後の `.txt` を残します。
変更する範囲を確かめてから、Enter キーで決めます。
`plan.txt.txt` のように拡張子を二重に付けないでください。
拡張子を変えても、本文が別の形式に変換されるわけではありません。

## うまくいかないとき

### 作ったファイルが課題に見つからない

課題フォルダーを展開し、ファイルの位置を見ます。
別の場所に作っていないか確かめます。

### 名前を変えたら開き方が変わった

名前の最後まで読み、元の拡張子が残っているか確かめます。

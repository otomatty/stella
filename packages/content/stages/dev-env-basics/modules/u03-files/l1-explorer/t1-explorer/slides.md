# 昨日作ったメモを編集したいのに、画面には課題文しか出ていません

昨日作ったメモを編集したいのに、画面には課題文しか出ていません。
メモをどこから開けばよいでしょうか。

<!-- ノート: 課題文だけが見えていても、保存したメモがなくなったとは限りません。一覧がある場所へ目を向けます。 -->

# 覚えること

エクスプローラーには、開いているフォルダーの中身が並びます。

エクスプローラーは、フォルダーとファイルの一覧です。
エディターは、選んだファイルの内容を編集する場所です。

<!-- ノート: 一覧には、今開いているフォルダーの中身が出ます。本文を書き換える場所と区別しましょう。 -->

---

# 画面で確かめる

左の「エクスプローラー」で課題フォルダーを展開します。
`diary.txt` を押すと、右のエディターに内容が出ます。

<!-- ノート: diary.txt の名前を押して開きます。編集する前に、本文が目的のメモか読んでください。 -->

# レッスン3-1 エクスプローラーとエディター

## このレッスンの目標

- [ ] 一覧からファイルを開けます。
- [ ] 保存したファイルのタブを閉じ、開き直せます。

## 3-1-1 エクスプローラー

> **エクスプローラーには、開いているフォルダーの中身が並びます。**

VS Code の左端にある「エクスプローラー」を押します。
開いているフォルダーの左の矢印を押すと、中身が並びます。
課題フォルダーまで順に展開し、`diary.txt` を押します。
右のエディターにメモの本文が出れば、開けています。
実務でも、同じ作業場所の複数のファイルを一覧から選びます。

## 3-1-2 タブを閉じる

> **タブを閉じても、保存したファイルは消えません。**

タブを閉じる前に「ファイル > 保存」を選びます。
エディター上の `diary.txt` の横にある「×」を押します。
左の一覧の `diary.txt` を押し、同じ文が出るか確かめます。
ファイルを右クリックして「削除」を選ぶ操作とは違います。
保存を尋ねられたら「保存」を選び、変更を残します。

## うまくいかないとき

### 左の一覧が見当たらない

「表示 > エクスプローラー」を選びます。
フォルダーの中身が閉じていれば、名前の左の矢印を押します。

### タブを閉じて本文が見えなくなった

左の一覧から、同じファイル名を押して開き直します。
保存した文が出るかを読みます。

# 03-1-1 新しいファイルを作る

# 覚えること

新しいファイルは、エクスプローラーで課題フォルダーを選んでから作り、保存します。

<!-- ノート: STELLA では、学習フォルダーの中に課題フォルダーがあります。いま取り組む課題の場所を選びます。 -->

---

# note.txt を作る

1. エクスプローラーで、この課題のフォルダーを選ぶ
2. 「新しいファイル」を押す
3. `note.txt` と入力し、Enter キーで決める
4. 本文を入力し、「ファイル」→「保存」を選ぶ

<!-- ノート: フォルダーを右クリックして「新しいファイル」を選んでも作れます。名前は一覧に、本文はエディターに入力します。 -->

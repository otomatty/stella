# 03-1-2 ファイルの名前を変える

<!-- ノート: ファイルの名前を変えるときは、一覧から対象を選びます。拡張子は、名前の最後に付く .txt や .html の部分です。 -->

---

# 覚えること

ファイルを選び、F2 キー（Mac は Enter キー）で名前を変え、拡張子を確かめます。

<!-- ノート: エクスプローラーで対象を選び、F2 キー（Mac は Enter キー）を押して新しい名前を入力します。名前の最後まで見て、種類が合うか確かめます。 -->

---

# 名前の最後まで読む

1. エクスプローラーで `memo.txt` を選ぶ
2. F2 キー（Mac は Enter キー）を押す
3. `.txt` を残して前半を `plan` に変え、Enter キーで決める

| 拡張子 | 種類 |
| --- | --- |
| `.txt` | 文章のメモ |
| `.html` | HTML の文書 |

種類を保つなら拡張子を残します。変えても本文は変換されません。

<!-- ノート: この課題では .txt を残し、名前の前半を変えます。拡張子を .html に変えただけで、本文が HTML になるわけではありません。 -->

---

# 03-1-2 ファイルの名前を変える

<!-- ノート: ファイルの名前を変えるときは、一覧から対象を選びます。拡張子は、名前の最後に付く .txt や .html の部分です。 -->

---

# 覚えること

ファイルの名前は「名前の変更」で変え、最後の拡張子で種類を確かめます。

<!-- ノート: 対象を右クリックし、「名前の変更」で新しい名前を入力します。名前の最後まで見て、種類が合うか確かめます。 -->

---

# 名前の最後まで読む

`memo.txt` を右クリック →「名前の変更」→ `plan.txt` → Enter

| 拡張子 | 種類 |
| --- | --- |
| `.txt` | 文章のメモ |
| `.html` | HTML の文書 |

種類を保つなら拡張子を残します。変えても本文は変換されません。

<!-- ノート: この課題では .txt を残し、名前の前半を変えます。拡張子を .html に変えただけで、本文が HTML になるわけではありません。 -->

---

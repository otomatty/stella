# VS Code では note.txt と出るのに、OS の画面には note と出ます

VS Code では note.txt と出るのに、OS の画面には note と出ます。
同じファイルなのに、なぜ名前が違って見えるのでしょうか。

<!-- ノート: 見えている文字が少なくても、ファイルが別物になったとは限りません。名前の表示設定を確かめます。 -->

---

# 覚えること

拡張子や隠しファイルは、OS の設定で見え方が変わります。

隠しファイルは、通常の一覧で表示を省かれるファイルです。
フォルダーにも、同じように表示を省くものがあります。

<!-- ノート: 拡張子や隠しファイルは、表示するかを設定できます。見えないことと、存在しないことを区別しましょう。 -->

---

# 画面で確かめる

同じファイルの表示例です。

| 表示の設定 | 名前 |
| --- | --- |
| 拡張子を表示 | note.txt |
| 拡張子を省略 | note |

<!-- ノート: 同じ note.txt でも、拡張子を省くと note と出ます。名前を付け足す前に表示設定を確認します。 -->

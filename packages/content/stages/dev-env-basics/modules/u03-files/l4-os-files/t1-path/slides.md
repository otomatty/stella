# 同じ note.txt が別の課題にもあります

同じ note.txt が別の課題にもあります。
ファイル名だけで、相手に場所を伝えられるでしょうか。

<!-- ノート: 同じ名前のメモが二つあると、名前だけでは区別できません。どのフォルダーの中かを添えて伝えます。 -->

---

# 覚えること

フォルダーは入れ子になり、ファイルの場所はパスで表します。

パスは、フォルダーをたどってファイルの場所を表したものです。

<!-- ノート: パスは場所を表します。入れ子のフォルダーを、外から中へ順番に読みます。 -->

---

# 画面で確かめる

`web-training` の中に `practice` があります。
その中に `note.txt` があります。
`web-training → practice → note.txt` の順にたどります。

<!-- ノート: web-training から practice を開き、その中の note.txt を探します。順序を入れ替えると別の場所になります。 -->

---

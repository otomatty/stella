# レッスン7-1 ファイルで開く・URLで開く

## このレッスンの目標

- [ ] アドレス欄から、ファイルを直接開いたかを見分けられます。
- [ ] localhost とポート番号が指すものを説明できます。

## 7-1-1 ファイルを直接開く

> **ファイルを直接開くと、アドレスは `file://` で始まります。**

U02 から使ってきた、保存した HTML を直接開く方法です。
ブラウザーのアドレス欄を選び、先頭を読みます。
たとえば `file:///…/q01-start-server/index.html` と出ます。
`…` は省略した保存先です。実際には自分の PC のパスが出ます。
ファイル名までを、VS Code で保存した場所と照合します。
見出しが同じでも、別のフォルダーのファイルかもしれません。

## 7-1-2 localhost で開く

> **サーバーから開くと、アドレスは `http://localhost` で始まります。**

サーバーは、ブラウザーの要求に応じてファイルなどを返すプログラムです。
ここでは自分の PC で動かすサーバーを使います。
localhost は自分の PC を指す名前です。
ポート番号は、その PC のどの窓口に接続するかを区別する数字です。

```text
http://localhost:3000
```

これは入力する URL の例です。コマンドではありません。
`:3000` がポート番号です。ブラウザーのアドレス欄に入れます。
提供スターターは、自分の PC の中だけで待ち受けます。
この操作でインターネットにページを公開するわけではありません。
実務でも、公開前のページを自分の PC で確認するときに使います。

| 開き方 | アドレスの先頭 | 表示する側の準備 |
| --- | --- | --- |
| ファイルを直接読む | `file://` | 保存した HTML をブラウザーで開く |
| 提供サーバーから読む | `http://localhost` | サーバーを起動し、表示された URL を開く |

## うまくいかないとき

### アドレスが file:// のままです

起動したターミナルに出た URL を、ブラウザーのアドレス欄に入れます。
HTML ファイルを直接開く操作では、サーバー経由に変わりません。

### 違うページが出ます

ポート番号まで含め、起動時の URL と同じかを確かめます。
編集したファイルも、起動した課題フォルダーの中かを見ます。

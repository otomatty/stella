# 7-1-1 ファイルを直接開く

<!-- ノート: ページの見出しだけでなく、ブラウザーのアドレス欄にも注目します。 -->

---

# なぜ必要でしょうか

同じ index.html を開いたつもりでも、アドレス欄が教材と違います。
どの場所のページを見ているか、確かめたい場面です。

<!-- ノート: 似た見出しの別ファイルを開いている可能性もあります。表示元をアドレスで見分けましょう。 -->

---

# 覚えること

ファイルを直接開くと、アドレスは `file://` で始まります。

`file://` は、PC に保存したファイルを直接読む開き方です。

<!-- ノート: file の後ろに、自分の PC のファイルの場所が続きます。サーバーを起動せずに読んでいます。 -->

---

# 画面で確かめます

アドレス欄の例です。自分の保存先によって、後ろのパスは変わります。

```text
file:///…/q01-start-server/index.html
```

<!-- ノート: 省略した部分は、人によって違う保存先です。ブラウザーのアドレス欄を選んで先頭を読んでください。 -->

---

# 7-1-2 localhost で開く

<!-- ノート: localhost の URL は、自分の PC で動くプログラムへ接続するために使います。 -->

---

# なぜ必要でしょうか

課題では、ファイルを直接開いた画面ではなく、起動後に出る URL を使います。
数字の付いたアドレスを、どこへ入力するか確認します。

<!-- ノート: 数字を省くと、指定した窓口とは違うところへ接続してしまいます。表示された URL を丸ごと使う準備をします。 -->

---

# 覚えること

サーバーから開くと、アドレスは `http://localhost` で始まります。

サーバーは、ブラウザーの要求に応じてファイルなどを返すプログラムです。
localhost は自分の PC を指します。

<!-- ノート: この課題のサーバーは、自分の PC の中でファイルを返します。インターネットへ公開する操作ではありません。 -->

---

# 画面で確かめます

```text
http://localhost:3000
```

ブラウザーのアドレス欄に入れます。
`:3000` は、接続先の窓口を区別するポート番号です。

<!-- ノート: 3000 はこの教材で最初に使う窓口の番号です。localhost とコロンに続く数字を一緒に読みます。 -->

---

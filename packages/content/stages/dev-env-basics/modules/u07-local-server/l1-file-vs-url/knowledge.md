# ファイルで開く・URLで開くの知識問題

## 確認クイズ

### Q1. アドレスが file:// で始まっています。どの開き方ですか。
<!-- kind: single; skills: local-server-run -->

- A. サーバーから受け取っています
- B. PC のファイルを直接開いています
- C. インターネットへ公開しています

<details>
<summary>解答と解説</summary>

**B** — file:// は、保存したファイルを直接読む開き方です。

</details>

### Q2. http://localhost:3000 の localhost は何を指しますか。
<!-- kind: single; skills: local-server-run -->

- A. 自分の PC
- B. 講師の PC
- C. 全員が使う公開サイト

<details>
<summary>解答と解説</summary>

**A** — 自分の PC で動くサーバーへ接続します。

</details>

### Q3. localhost:3000 と localhost:3001 の違いは何ですか。
<!-- kind: single; skills: local-server-run -->

- A. ファイルの拡張子
- B. 保存した日付
- C. 接続する窓口の番号

<details>
<summary>解答と解説</summary>

**C** — ポート番号が違うと、接続する窓口も違います。

</details>

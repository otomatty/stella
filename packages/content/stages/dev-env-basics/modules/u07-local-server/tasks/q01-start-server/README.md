# ローカルサーバーでページを開く

## 作るもの

提供された index.html の h1 を「サーバーで表示しました」に変えます。
HTML の文書の形を保ってください。
server.mjs は起動用の提供ファイルです。変更しません。

サーバー経由の URL で変更を確かめます。
提出するファイルは index.html だけです。
説明の欄に、実際に開いた URL と、サーバーを止めた方法を書きます。
起動・停止の操作は自動では確認できないため、説明でも確かめます。

## 手順

1. Web の「VS Code で開く」から、この課題を開きます。
2. 課題フォルダーを右クリックし、「統合ターミナルで開く」を選びます。
3. 次で現在の場所を見て、末尾が q01-start-server かを確かめます。

```sh
pwd
```

4. 課題フォルダーで、次を実行します。npm install は不要です。

```sh
node server.mjs
```

5. 表示された URL（通常は http://localhost:3000）をブラウザーで開きます。
6. index.html の h1 の文字を指定どおりに変え、「ファイル > 保存」を選びます。
7. ブラウザーを再読み込みし、変えた見出しが出るかを見ます。
8. 起動したターミナルで Ctrl+C を押し、入力待ちへ戻るかを見ます。
9. 同じ起動コマンドをもう一度実行します。
10. 表示された URL で再読み込みし、保存した見出しを確かめます。
11. もう一度 Ctrl+C で止めます。macOS でも Ctrl+C です。
12. 「課題を確認する」を押します。通ったら説明を添えて提出し、結果を読みます。

## うまくいかないとき

- URL が開かないときは、起動したターミナルの表示と URL を照合します。
- 3000 が使用中なら、次で起動し、表示された 3001 の URL を開きます。

```sh
node server.mjs 3001
```

- 変更が出ない場合は、保存と再読み込み、起動した課題フォルダーを確かめます。
- 起動中は次のコマンドを受け付けません。停止には Ctrl+C を使います。
- 解決しなければ、コマンド・URL・出た文字・試したことを「講師に相談」で伝えます。

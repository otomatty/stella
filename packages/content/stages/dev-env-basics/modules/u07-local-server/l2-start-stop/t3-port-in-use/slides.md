# 7-2-3 使うポートを変える

<!-- ノート: ポートが重なったときは、表示されたメッセージから対処を選びます。 -->

---

# なぜ必要でしょうか

起動しようとすると「3000 は使われています」と出ました。
同じ窓口を、すでに別のプログラムが使っています。

<!-- ノート: 二つのサーバーが同じ番号を使おうとすると、後から起動した方は動けません。 -->

---

# 覚えること

ポートが使われているときは、別の番号で起動します。

ポート番号をコマンドの後ろに付けると、別の窓口を選べます。

<!-- ノート: 自分で起動した古いサーバーなら、そのターミナルで止められます。別のものなら勝手に終了せず、番号を変えます。 -->

---

# 画面で確かめます

```sh
node server.mjs 3001
```

表示された `http://localhost:3001` を開きます。

<!-- ノート: 3001 で起動したのに 3000 を開くと、別の表示になることがあります。起動時の URL と照合しましょう。 -->

---

<!-- _class: summary -->
# まとめ

ポートが使われているときは、別の番号で起動します。

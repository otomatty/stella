# 7-2-2 止めて起動し直す

<!-- ノート: 停止はブラウザーではなく、サーバーを起動したターミナルで行います。 -->

---

# なぜ必要でしょうか

ページの確認が終わっても、サーバーは動き続けています。
作業を終える前に、使っていた窓口を閉じます。

<!-- ノート: ブラウザーのタブを閉じても、サーバーの処理は残っています。作業の終わりに止める習慣を付けます。 -->

---

# 覚えること

Ctrl+C でサーバーを止め、同じコマンドで起動し直します。

起動したターミナルを選び、Ctrl キーを押しながら C キーを押します。
入力待ちの印が戻れば、停止しています。

<!-- ノート: Ctrl キーと C キーを同時に使います。入力待ちへ戻ったことまで確認してください。 -->

---

# 画面で確かめます

| 状態 | 操作 |
| --- | --- |
| 起動中 | ターミナルで Ctrl+C |
| 停止後 | `node server.mjs` で再起動 |

ページを開き直して表示を確かめます。

<!-- ノート: 再起動には、最初と同じコマンドを使います。起動したら URL で表示を確かめ、最後にもう一度止めます。 -->

---

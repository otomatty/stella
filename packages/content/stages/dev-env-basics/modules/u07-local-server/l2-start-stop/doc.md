# レッスン7-2 起動と停止

## このレッスンの目標

- [ ] 課題フォルダーでサーバーを起動できます。
- [ ] 停止・再起動して表示を確かめられます。
- [ ] ポートが使われている場合に、番号を変えられます。

## 7-2-1 サーバーを起動する

> **サーバーは、ターミナルでコマンドを実行して起動します。**

U05 で Node.js の版を確かめた PC を使います。
課題の server.mjs と index.html がある状態から始めます。
VS Code のエクスプローラーで課題フォルダーを右クリックします。
「統合ターミナルで開く」を選び、現在の場所を確かめます。

```sh
pwd
```

パスの末尾が、今回の課題フォルダーかを読みます。
提供スターターは Node.js の標準の機能だけで動きます。
npm install は不要です。server.mjs の編集も不要です。

```sh
node server.mjs
```

起動後に出る文字の例です。

```text
http://localhost:3000 で表示しています。止めるときは Ctrl+C を押します。
```

この URL をブラウザーで開きます。
ターミナルは起動中、次のコマンドを受け付けません。
入力待ちに戻らなくても、上の表示が出ていれば通常の状態です。
見出しを直したら「ファイル > 保存」を選びます。
ブラウザーの再読み込みボタンを押し、変えた文字を確かめます。

## 7-2-2 止めて起動し直す

> **Ctrl+C でサーバーを止め、同じコマンドで起動し直します。**

起動したターミナルをクリックし、Ctrl キーを押しながら C キーを押します。
macOS でも Command+C ではなく、Ctrl+C です。
入力待ちの印（プロンプト）が戻れば、停止しています。
ブラウザーを閉じるだけでは、サーバーは止まりません。
停止しても、すでに表示したページは画面に残ることがあります。
表示が残っているだけで、起動中とは判断しません。

同じターミナルで起動し直します。

```sh
node server.mjs
```

URL を開いて再読み込みし、保存したページが出るか確かめます。
終わったら、もう一度 Ctrl+C で止めます。

## 7-2-3 使うポートを変える

> **ポートが使われているときは、別の番号で起動します。**

起動時に次のように出ることがあります。

```text
3000 は使われています。node server.mjs 3001 のように別の番号で起動してください。
```

自分が起動したサーバーなら、そのターミナルに戻って止められます。
何が使っているか分からない場合は、勝手に終了せず番号を変えます。

```sh
node server.mjs 3001
```

起動時の表示は `http://localhost:3001` に変わります。
ブラウザーでも、その URL を開きます。
3001 も使われていたら、3002 など別の番号で試せます。
提供スターターで使える番号は 1〜65535 の整数です。
確認後は、そのサーバーを起動したターミナルで止めます。

## うまくいかないとき

### サーバーを開けない

1. 起動したターミナルを見ます。エラーで終了していないかを確かめます。
2. 起動時に表示された URL を、番号までそのまま開きます。
3. 停止していたら、同じ課題フォルダーで起動し直します。
4. ポートが使用中なら、別の番号で起動し、その URL を開きます。

### server.mjs が見つからない

`pwd` で場所を確かめます。
別の場所なら、課題フォルダーの「統合ターミナルで開く」からやり直します。
node 自体が見つからない場合は U05 のまとめに戻ります。

### 変更が出ない・404 と出る

編集したファイルを保存してから、ブラウザーを再読み込みします。
URL と、起動した課題フォルダーの保存先を照合します。
404 は、要求したファイルが見つからないことを表します。
`/` で開くときは、課題フォルダーに index.html が必要です。
直らなければ、URL・実行したコマンド・メッセージ・試したことを伝えます。
端末の権限などの問題は、研修担当者に相談します。

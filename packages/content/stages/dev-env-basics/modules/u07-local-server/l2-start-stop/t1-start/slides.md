# 7-2-1 サーバーを起動する

<!-- ノート: server.mjs は教材が用意したファイルです。中身を書き換えず、実行して使います。 -->

---

# なぜ必要でしょうか

localhost の URL を開いても、まだページが出ません。
ブラウザーへファイルを返すプログラムを動かす必要があります。

<!-- ノート: URL だけ入力しても、返す側が動いていないと表示できません。ターミナルの状態を確認します。 -->

---

# 覚えること

サーバーは、ターミナルでコマンドを実行して起動します。

提供された server.mjs は、Node.js で動かすファイルです。
課題フォルダーで実行します。npm install は不要です。

<!-- ノート: 課題フォルダーには index.html と server.mjs があります。そこで Node.js に server.mjs を実行させます。 -->

---

# 画面で確かめます

```sh
node server.mjs
```

起動中は、ターミナルが次のコマンドを受け付けません。

<!-- ノート: Enter を押した後もサーバーは動き続けます。入力待ちに戻らないのは、起動中の通常の状態です。 -->

---

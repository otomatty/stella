# 5-2-3 版を照合する

<!-- ノート: 数字が出たら終わりではなく、指定された範囲に入るかを読みます。 -->

---

# なぜ必要でしょうか

Node.js の導入は終わりました。
VS Code から使える版が、教材の条件に合うかを知りたいです。

<!-- ノート: インストーラーを閉じただけでは、実際にどの版が起動するかはまだ分かりません。 -->

---

# 覚えること

版は `node --version` で確かめ、教材の指定と照らし合わせます。

Node.js は22系か24系で22.13以上、npm は10以上です。

<!-- ノート: 最初の数字が系を表します。22.12は不足し、23は指定の系に含まれません。 -->

---

# 小さく試します


```sh
node --version
```

結果の例です。
```text
v22.13.0
```
数字は入っている版によって違います。

<!-- ノート: 表示された版を控えます。npm の版も、まとめの手順に従って別のコマンドで確かめます。 -->

---

# 見比べます

環境診断は、STELLA 拡張が必要な道具の版を照合する確認です。
診断の課題で「課題を確認する」を押します。

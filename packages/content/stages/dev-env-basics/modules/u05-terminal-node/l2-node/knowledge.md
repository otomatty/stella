# Node.js と npm を入れるの知識問題

## 確認クイズ

### Q1. Node.js の役割はどれですか。
<!-- kind: single; skills: node-npm-ready -->

- A. ブラウザーの外で JavaScript を動かす
- B. HTML のファイル名を変える
- C. Git の記録を一覧にする

<details>
<summary>解答と解説</summary>

**A** — Node.js は JavaScript を動かす道具です。

</details>

### Q2. この教材で使う Node.js の版はどれですか。
<!-- kind: single; skills: node-npm-ready -->

- A. 23系
- B. 22.13.0以上の22系、または24系
- C. 番号が最も大きい版なら何でもよい

<details>
<summary>解答と解説</summary>

**B** — 教材の対象の系と最低版を照合します。

</details>

### Q3. 導入を終えた後、版を確かめる前にすることはどれですか。
<!-- kind: single; skills: node-npm-ready -->

- A. HTML にコマンドを書く
- B. すべての設定を変える
- C. 保存して VS Code を閉じ、開き直す

<details>
<summary>解答と解説</summary>

**C** — 開いていたターミナルに新しい道具の場所が伝わっていないことがあります。

</details>

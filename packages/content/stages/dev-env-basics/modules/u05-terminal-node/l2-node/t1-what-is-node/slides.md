# なぜ必要でしょうか

HTML はブラウザーで表示できました。
これから JavaScript の教材で使う道具も準備します。

<!-- ノート: ページが表示できたことだけでは、JavaScript の実行環境が整ったか分かりません。 -->

---

# 覚えること

Node.js は、ブラウザーの外で JavaScript を動かす道具です。

JavaScript は、プログラムを書くための言語です。
npm は、プログラムで使う部品を入れる道具です。

<!-- ノート: Node.js がブラウザーの外で実行を受け持ちます。npm は Node.js と一緒に入ります。 -->

---

# 小さく試します

| 道具 | 役割 |
| --- | --- |
| ブラウザー | HTML を読んでページを表示する |
| Node.js | ブラウザーの外で JavaScript を動かす |
| npm | プログラムで使う部品を入れる |

# 5-2-2 指定の版を入れる

<!-- ノート: ダウンロード画面の先頭だけで決めず、教材の条件に合う版を選びます。 -->

---

# なぜ必要でしょうか

公式サイトに複数の版が並んでいます。
大きい番号なら、どれでもよいのでしょうか。

<!-- ノート: 新しい版でも教材で使えるとは限りません。教材の対象を先に読みます。 -->

---

# 覚えること

Node.js は、教材が指定する版を公式サイトから入れます。

この教材は22系か24系の LTS、22.13以上を使います。
LTS は、長い期間の保守を予定した版です。

<!-- ノート: 22系なら22.13.0以上を選びます。23など奇数の版は使いません。 -->

---

# 小さく試します

公式の「Node.js®をダウンロードする」を開きます。
版の選択で22系か24系を選び、まとめの導入手順を使います。

<!-- ノート: すでに条件に合う版があれば入れ直しません。サイトの既定値が違っても、教材の指定を使います。 -->

---

# 見比べます

入れた後は、保存して VS Code を一度閉じ、開き直します。
開いていたターミナルは、新しい道具の場所をまだ知らないためです。

<!-- ノート: 道具の場所を探す設定を PATH と呼びます。導入前から開いたターミナルには、更新が届いていないことがあります。 -->

---

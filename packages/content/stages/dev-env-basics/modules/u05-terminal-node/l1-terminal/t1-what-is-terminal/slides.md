# 覚えること

ターミナルは、文字でコマンドを入れて実行する画面です。

コマンドは、コンピューターに実行させる文字の指示です。
プロンプトは、入力を待っていることを示す表示です。

<!-- ノート: 入力を待つ行に文字を入れ、Enter で実行します。プロンプトの形は人によって違います。 -->

---

# 小さく試します

「表示 > ターミナル」を選びます。
画面の下の「ターミナル」に入力する行が出ます。

<!-- ノート: ファイル名のタブがある編集欄と、下のターミナルを見分けてください。入力する前に画面の名前を読みます。 -->

# レッスン5-1 ターミナルを使う

## このレッスンの目標

- [ ] ターミナルとエディターを見分けられます。
- [ ] いまの場所を確認し、課題フォルダーへ移動できます。
- [ ] コマンドを1つずつ実行し、結果を読めます。

## 5-1-1 ターミナルとは

> **ターミナルは、文字でコマンドを入れて実行する画面です。**

コマンドは、コンピューターに実行させる文字の指示です。
「表示 > ターミナル」を選びます。
画面下のパネルの「ターミナル」に入力する行が出ます。
入力待ちを示す表示をプロンプトと呼びます。
ユーザー名や記号、色は人によって違います。
教材のコマンドだけを入力し、Enter を押します。
プロンプトの文字は一緒に入力しません。

:::os windows
VS Code のターミナルでは PowerShell を使います。
ターミナルの種類の表示が PowerShell かを確認します。
違う場合は、ターミナルの「＋」の横の矢印から PowerShell を選びます。
:::

:::os macos
VS Code のターミナルでは zsh を使います。
ターミナルの種類の表示が zsh かを確認します。
違う場合は、ターミナルの「＋」の横の矢印から zsh を選びます。
:::

## 5-1-2 いまのフォルダー

> **コマンドは、ターミナルがいま開いているフォルダーで実行されます。**

VS Code では学習フォルダー `web-training` だけを開いています。
最初のターミナルも、学習フォルダーで開きます。
エディターでファイルを選んでも、この場所は変わりません。
まず、いま開いている場所を表示します。

```sh
pwd
```

表示されたパスの末尾が `web-training` なら学習フォルダーです。
ユーザー名など、途中の文字は自分の環境によって違います。
PowerShell でも `pwd` が使えます。

`cd` は、ターミナルの場所を移動するコマンドです。
学習フォルダーから課題へ移動する例です。

```sh
cd dev-env-basics/u05-terminal-node/q01-where-am-i
```

移動したら、別の1行で場所を確かめます。

```sh
pwd
```

パスが `web-training/dev-env-basics/u05-terminal-node/q01-where-am-i` に続くか読みます。
パスの区切りの表示は OS によって違います。
課題フォルダーは、学習フォルダーから3つ下です。

1つ上に戻るコマンドは次のとおりです。

```sh
cd ..
```

これは1つ上へ戻る操作です。学習フォルダーへ一度には戻りません。
また、エクスプローラーで課題フォルダーを右クリックできます。
「統合ターミナルで開く」を選ぶと、その場所で開けます。
この方法でも `pwd` で確かめます。

## 5-1-3 1つずつ実行する

> **コマンドは 1 つずつ入れて、結果を読んでから次へ進みます。**

複数のコマンドをまとめて貼らず、1行ずつ実行します。
入力待ちに戻ったら、結果やエラーの文を読みます。
エラーは、うまく実行できなかったことを伝える文です。
成功したときに何も表示しないコマンドもあります。

フォルダーを作るコマンドの例です。
課題フォルダーへ移動した後に使います。

```sh
mkdir notes
```

エクスプローラーで、その課題の中に `notes` ができたかを見ます。
すでに存在すると言われたら、同じ名前のフォルダーを確認します。
実務でも、結果を見て次へ進むと失敗した場所を調べやすくなります。

コマンドを HTML のエディターに書いても、実行されません。
U04で練習したとおり、誤って書いた文字を消して保存します。
ターミナルの入力行に戻り、コマンドを入れ直します。

## うまくいかないとき

ターミナルが見えなければ「表示 > ターミナル」を選びます。
ファイルが見つからないときは `pwd` を読みます。
思っていた場所と違えば、課題フォルダーを右クリックして開き直します。
エラーが出たら次のコマンドを止め、出た文を確認します。

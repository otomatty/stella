# 5-1-2 いまのフォルダー

<!-- ノート: ファイルを作る前に、ターミナルが指す場所を確かめます。 -->

---

# なぜ必要でしょうか

課題のファイルを作ったのに、課題フォルダーに見当たりません。
別の場所に作ったのかもしれません。

<!-- ノート: エディターで課題を開いても、ターミナルの場所まで自動で変わるとは限りません。 -->

---

# 覚えること

コマンドは、ターミナルがいま開いているフォルダーで実行されます。

`pwd` はいまの場所を表示します。`cd` は場所を移動します。
`cd ..` は1つ上へ戻ります。

<!-- ノート: 最初は学習フォルダーで開きます。エクスプローラーで見ている場所とは別に確認します。 -->

---

# 小さく試します


```sh
pwd
```

表示されたパスの末尾を読み、課題フォルダーか照合します。

<!-- ノート: 場所はユーザーごとに異なります。web-training の下のステージ・単元・課題まで見てください。 -->

---

# 見比べます

学習フォルダーから移動する例です。

```sh
cd dev-env-basics/u05-terminal-node/q01-where-am-i
```

または課題フォルダーを右クリックし、
「統合ターミナルで開く」を選びます。

<!-- ノート: 課題フォルダーは学習フォルダーから3つ下です。右クリックで開いた場合も pwd で確かめます。 -->

---

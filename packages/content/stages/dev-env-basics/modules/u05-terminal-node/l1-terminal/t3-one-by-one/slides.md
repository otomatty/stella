# なぜ必要でしょうか

フォルダーを作る指示でエラーが出ました。
続けて次の指示を入れたら、どこで失敗したか分からなくなりました。

<!-- ノート: 失敗したまま次の指示へ進むと、別のエラーが重なります。最初の結果で立ち止まりましょう。 -->

---

# 覚えること

コマンドは 1 つずつ入れて、結果を読んでから次へ進みます。

Enter を押したら、結果と入力待ちの表示を確かめます。
エラーは、うまく実行できなかったことを伝える文です。

<!-- ノート: 成功しても文字が出ないコマンドがあります。エラーの有無と、指定された確認方法で結果を読みます。 -->

---

# 小さく試します


```sh
mkdir notes
```

`mkdir` はフォルダーを作るコマンドです。
エクスプローラーで `notes` ができたかを見ます。

<!-- ノート: フォルダー名をすでに使っていれば、エラーの文を読んで既存の notes を確かめます。 -->

---

# 見比べます

エディターに `mkdir notes` を書いても実行されません。
誤って書いた文字を消して保存し、ターミナルに入れ直します。

<!-- ノート: ページにコマンドが見えたら、編集欄への入力を疑います。U04で練習した保存と表示の確認も使って戻します。 -->

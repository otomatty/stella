# レッスン5-3 困ったときの伝え方

## このレッスンの目標

- [ ] 目的・できたところ・操作・メッセージを整理できます。
- [ ] 個人情報を除き、必要な文を相談に添えられます。

## 5-3-1 相談に添える情報

> **相談するときは、しようとしたこと・できたところ・出たメッセージを伝えます。**

課題文のパネルの「講師に相談」の欄に、次の4点を書きます。

1. 何をしようとしたか。
2. どこまで成功したか。
3. 実行した操作やコマンド。
4. 表示されたメッセージ。

たとえば、次のように書くと止まったところが伝わります。

```text
したいこと: Node.js の版を確かめたいです。
できたこと: 導入後、VS Code を開き直しました。
試した操作: node --version
メッセージ: 実際に表示された文をここへ貼ります。
```

最後の行は、そのまま送らず実際のメッセージに置き換えます。
メッセージは、ターミナルで必要な文だけを選んでコピーします。
右クリックのメニューの「コピー」を使い、相談欄へ貼り付けます。
画像だけでなく、検索や照合ができる文字で伝えます。
ユーザー名やメールなど、不要な個人情報は伏せます。
パスワードや認証情報は貼りません。
伏せたところは `[ユーザー名]` などと置き換えます。
送る前に、自分で貼った文を読み返します。
実務でも、再現に必要な情報があると調査を始めやすくなります。

## うまくいかないとき

メッセージが出ていなければ「何も表示されない」と書きます。
最後に行った操作と、入力待ちに戻ったかも伝えます。
何度も試して状況が変わった場合は、直近の操作と結果をそろえます。

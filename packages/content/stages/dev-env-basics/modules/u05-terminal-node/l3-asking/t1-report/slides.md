# 5-3-1 相談に添える情報

<!-- ノート: 相手が同じ状態を調べられるよう、操作と結果を短くまとめます。 -->

---

# なぜ必要でしょうか

「動きません」と送ったら、何を試したかを聞き返されました。
実行したコマンドと結果が、相手には見えていません。

<!-- ノート: 調べる入口が分かる相談には、目的と、成功したところと、止まった操作があります。 -->

---

# 覚えること

相談するときは、しようとしたこと・できたところ・出たメッセージを伝えます。

実行した操作やコマンドも添えます。
メッセージは文字でコピーし、不要な個人情報は除きます。

<!-- ノート: パスワードや認証情報は貼りません。画面全体ではなく、必要なメッセージを選んで伝えます。 -->

---

# 小さく試します

しようとしたこと: Node.js の版を確かめたいです。

できたところ: 導入後に VS Code を開き直しました。

試した操作: `node --version`

出たメッセージ: 表示された文を、個人情報を除いて貼ります。

<!-- ノート: メッセージを自分の言葉で置き換えず、文字を残すと調べやすくなります。ユーザー名などは伏せてください。 -->

---

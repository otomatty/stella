# Node.js と npm の版を確かめる

## 何を確かめるか

Node.js が22.13.0以上の22系か24系、npm が10以上かを照合します。
この診断には Git は含まれません。
この課題では、編集・提出するファイルはありません。

## 手順

1. l2「Node.js と npm を入れる」の自分の OS の手順で導入します。
2. ファイルを保存して VS Code をすべて閉じ、開き直します。
3. 「表示 > ターミナル」を開き、次を実行します。

```sh
node --version
```

4. 別の1行で npm の版を確かめます。

:::os windows
PowerShell で次を実行します。
```powershell
npm --version
```
「スクリプトの実行が無効」と出たら、次を使います。
```powershell
npm.cmd --version
```
実行ポリシーは変更しません。
:::

:::os macos
zsh で次を実行します。
```sh
npm --version
```
:::

5. Node.js と npm の版を、下の条件と照合します。
6. Web の「VS Code で開く」で、この課題を開きます。
7. 「課題を確認する」を押し、版と必要な版を読みます。
8. 通らない項目を確認し、通ったら「提出する」で提出します。

## うまくいかないとき

見つからないと言われたら、導入を終えたかを確認します。
ファイルを保存し、VS Code をすべて閉じて開き直します。
それでも通らなければ、表示された版と必要な版を読みます。
会社の PC に入れられないときは、講師に相談します。
環境の問題は、能力の評価には入りません。
相談には、目的・できたこと・試したコマンド・メッセージを添えます。

参照: [Node.js ダウンロード](https://nodejs.org/ja/download)

# レッスン0-1 保存して表示を確かめる

## このレッスンの目標

- [ ] HTML ファイルを保存できます。
- [ ] 保存した HTML ファイルをブラウザーで開けます。
- [ ] 見出しの変更が表示されないとき、保存と再読み込みを確かめられます。

## 0-1-1 保存したファイルを表示する

> **保存したあとブラウザーで再読み込みすると、保存したHTMLの内容が表示されます。**

HTML は、ページの内容と構造を書くための言語です。
ブラウザーは、ページを表示するアプリです。
保存は、編集した内容をファイルに残す操作です。
実務でも、ページを直したら保存して表示を確かめます。

```html
<h1>朝のメモ</h1>
```

`h1` は、ページの大きな見出しを表す要素です。
要素は、開始と終了のタグで内容を囲んだものです。
この例では、`<h1>` と `</h1>` の間の文字が見出しになります。
配られた HTML の文書は残し、指定された文字を変えます。
タグの詳しい書き方は、後のステージで学びます。

VS Code で編集したら、「ファイル > 保存」を選びます。
次にブラウザーの更新ボタンで、ページを再読み込みします。
再読み込みは、表示しているページを読み直す操作です。
保存と再読み込みは、別々に行います。

## 0-1-2 HTMLファイルをブラウザーで開く

> **保存した HTML ファイルは、ブラウザーで開いて表示を確かめます。**

VS Code で `index.html` を保存した状態から始めます。
次の方法で、編集しているファイルの場所を開きます。

:::os windows
1. VS Code の左のエクスプローラーで `index.html` を右クリックします。
2. 「エクスプローラーで表示」を選びます。
3. Windows のエクスプローラーで、そのファイルをダブルクリックします。

ブラウザーで開かないときは、そのファイルをブラウザーへドラッグします。
ドラッグは、押したまま動かし、目的の場所で離す操作です。
ブラウザーの画面の上で離してください。
:::

:::os macos
1. VS Code の左のエクスプローラーで `index.html` を右クリックします。
2. 「Finder で表示」を選びます。
3. Finder で、そのファイルをダブルクリックします。

ブラウザーで開かないときは、そのファイルをブラウザーへドラッグします。
ドラッグは、押したまま動かし、目的の場所で離す操作です。
ブラウザーの画面の上で離してください。
:::

ブラウザーに見出しが出たら、表示できています。
VS Code に戻って文字を変えたら、保存してから再読み込みします。

## うまくいかないとき

### 表示が変わらない

1. VS Code で「ファイル > 保存」を選んだか確かめます。
2. ブラウザーの更新ボタンで再読み込みしたか確かめます。
3. ブラウザーで開いたファイルと、編集したファイルが同じか確かめます。

同じ `index.html` という名前でも、課題フォルダーが違えば別のファイルです。
上の操作で編集しているファイルの場所を開き、表示し直します。

### HTML が文字のまま表示される

ファイル名の末尾が `.html` になっているか確かめます。
この末尾の部分を拡張子と呼び、ファイルの種類を区別します。
`index.html.txt` ではなく `index.html` かを見ます。

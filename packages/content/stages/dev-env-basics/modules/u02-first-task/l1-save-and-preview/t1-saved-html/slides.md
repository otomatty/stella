# 0-1-1 保存したファイルを表示する

<!-- ノート: エディターの文字とブラウザーの見出しを見比べます。編集した変更が、いつ表示に届くかを確かめましょう。 -->

---

# 見出しを直したのに、前のまま

見出しは、ページの題や区切りを表す大きな文字です。
HTML では `h1` などで書きます。

エディターで見出しを「朝のメモ」に変えました。
ブラウザーには、変更前の見出しが出ています。

<!-- ノート: 文字を打ち直しただけでは、ブラウザーの見出しが変わらないことがあります。編集した内容がファイルに残っているかが手がかりです。 -->

---

# 覚えること

保存したあとブラウザーで再読み込みすると、保存したHTMLの内容が表示されます。

HTML は、ページの内容と構造を書くための言語です。
保存は、編集した内容をファイルに残す操作です。
ブラウザーは、ページを表示するアプリです。

<!-- ノート: ブラウザーが読むのは、ファイルに保存された内容です。エディターで編集中の文字が、そのまま表示されるわけではありません。 -->

---

# 文字を変えたら「ファイル > 保存」

```html
<h1>朝のメモ</h1>
```

`h1` は、ページの大きな見出しを表す要素です。
要素は、開始と終了のタグで内容を囲んだものです。

「ファイル > 保存」のあと、ブラウザーで再読み込みします。
再読み込みは、表示しているページを読み直す操作です。

<!-- ノート: h1 の間の文字が、表示する見出しです。保存したら、ブラウザーの更新ボタンでファイルを読み直してください。 -->

---

# 編集・保存・再読み込みの違い

| 操作 | 変わるもの |
| --- | --- |
| エディターで編集 | 編集中の内容 |
| ファイルを保存 | ファイルに残る内容 |
| ブラウザーで再読み込み | ブラウザーに出る表示 |

<!-- ノート: 編集、保存、再読み込みは、それぞれ別の操作です。表示が前のままなら、保存と再読み込みの順に確かめます。 -->

## 知識問題

### Q1. 編集した `index.html` の変更をブラウザーで確かめます。最初に行う操作はどれですか？
<!-- kind: single; skills: preview-changes -->

- A. 編集したファイルを保存する
- B. ブラウザーを再読み込みする
- C. VS Code を閉じる
- D. 同じ内容を、新しいファイルに保存する

<details>
<summary>解答</summary>

**A** — 最初に保存します。保存する前に再読み込みしても、前の内容が表示されます。再読み込みは保存のあとです。

</details>

### Q2. HTMLの文書に含めるものをすべて選んでください。
<!-- kind: multiple; skills: html-document -->

- A. ページの見出し
- B. 文書の構造
- C. ブラウザーで再読み込みする操作
- D. ファイルを保存した時刻

<details>
<summary>解答</summary>

**A, B** — HTMLは見出しなどの内容と、文書の構造を記述します。再読み込みや保存した時刻は、文書には書きません。

</details>

### Q3. 保存していない変更もブラウザーを再読み込みすれば表示されます。
<!-- kind: boolean; skills: preview-changes -->

- A. 正しい
- B. 誤り

<details>
<summary>解答</summary>

**B** — 再読み込みの前にファイルを保存します。

</details>

### Q4. 保存した index.html をページとして表示する方法はどれですか？
<!-- kind: single; skills: preview-changes -->

- A. ファイルをブラウザーの画面へドラッグする
- B. VS Code の設定画面を開く
- C. ファイル名を読むだけでよい

<details>
<summary>解答</summary>

**A** — 保存した HTML ファイルをブラウザーで開き、見出しの表示を確かめます。

</details>

# タグは見えるけれど、ページはどこ？

VS Code には `<h1>朝のメモ</h1>` と出ています。
実際の見出しとして、どう見えるかを確かめたい場面です。

<!-- ノート: VS Code に見えるのは、ページを作るための文字です。利用する人に見える見出しを、別の画面で確かめる必要があります。 -->

# 覚えること

保存した HTML ファイルは、ブラウザーで開いて表示を確かめます。

<!-- ノート: 同じ index.html をブラウザーで開くと、ページとして見られます。編集したファイルと、表示するファイルをそろえます。 -->

# index.html をブラウザーへ

保存した `index.html` を、ブラウザーの画面へドラッグします。
ドラッグは、ファイルを押したまま動かし、目的の場所で離す操作です。

`<h1>朝のメモ</h1>` → ブラウザーには **朝のメモ**

<!-- ノート: ファイルをブラウザーの画面へ運び、離してください。タグの文字ではなく、朝のメモという見出しが出れば表示できています。 -->

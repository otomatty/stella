# レビューの観点

- HTML の文書の形が残っている。
- h1 の文字が「今日の学習予定」と完全に一致する。
- p 要素が1つだけあり、文章「この文章は変えません。」が残っている。
- 提出の説明に、ブラウザーで開いたファイルと、表示された見出しが書かれている。

見出しと段落の数は手元の確認でも確かめる。
段落の文章は提出物で確かめ、書き換えられていれば具体的に指摘する。
表示を確かめたかは、説明に書かれた内容だけで判断する。本当に表示したかは推測しない。
説明の見出しが「今日の学習予定」と違うときは、違う文字を指摘する。
保存や表示の操作を、提出コードだけで行えたと推測しない。
ヒント利用を理由に不合格にせず、自力での定着は別の問題で確かめる。

## よくある違反

- 見出しの一部だけを変えている。全角と半角や、前後の空白が違うこともある。「今日の学習予定」と違う文字を示し、そろえるよう返す。
- `p` の文章を書き換えている、または段落を消したり足したりしている。残す文章を示し、見出しだけを変えるよう返す。
- 説明に、開いたファイルや表示された見出しが無い。何を書くかを示し、表示したとは推測しない。

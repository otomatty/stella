# 見出しをもう一度変える

q01 と同じ手順を、自分だけで行います。
この課題の「VS Code で開く」から、新しい `index.html` を開きます。
次に何をするかは、課題文のパネルの「進め方」を見て決めてください。

## 作るもの

- HTML の文書の形を残します。
- `h1` の「今日の予定」を「今日の学習予定」に変えます。文字は完全に一致させます。
- `p` 要素は1つのままにし、「この文章は変えません。」を残します。

`p` は、文章のまとまりである段落を表す要素です。
今回は見出しだけを変えます。
手元では文書の形、見出しの文字、`p` の数を確認します。
段落の文章が残っているかは、提出後のレビューでも確かめます。

## 進め方

編集したら保存し、同じファイルをブラウザーで開いて表示を確かめます。
「課題を確認する」で全部通ったら、「提出する」を押します。
提出後は、q01 と同じ場所でレビューの結果まで読んでください。

## うまくいかないとき

表示が前のままなら、保存・再読み込み・開いているファイルの順に確かめます。
同じ名前でも、q01 と q02 の `index.html` は別のファイルです。
通らない項目があれば、メッセージと受入条件を見比べます。
行き詰まったら、ヒントを1段開いて試してください。
ヒントを開いた記録は、提出に「支援付き」として残ります。

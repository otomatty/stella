# 返却の案内の見出しを変える

## 何をするか

図書の返却場所を知らせるページに直します。
`index.html` の `h1` を「図書の返却案内」にします。
文字は完全に一致させます。
`p` の「本は入口の箱へ返してください。」は変えません。
段落を増やさず、1つのまま残します。
文書の形を残し、保存後にブラウザーで表示を確かめます。
手元では文書の形・見出し・段落の数を確かめます。
段落の文章は、提出後のレビューでも確かめます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
すべて通ったら提出し、届いたレビューの結果を読みます。

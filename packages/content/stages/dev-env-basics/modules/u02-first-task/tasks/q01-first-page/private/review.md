# レビューの観点

- 必須：HTML の文書の形が残り、h1 の文字が「はじめてのページ」と完全に一致する。
- 任意：starter と比べ、h1 以外の要素を消したり増やしたりしていない。

任意の観点が満たされない場合は、増減した要素を具体的に示す。
手元の必須条件に、追加の隠れた条件を設けない。
保存・表示・最初の失敗・結果を読む操作は、提出コードだけでは判定しない。
失敗回数やヒントを開いたことを理由に、不合格にしない。

## よくある違反

- 見出しの文字の一部だけを変えている。全角と半角や、前後の空白が指定と違うこともある。「はじめてのページ」と違う文字を具体的に示し、1文字ずつそろえるよう返す。
- `<h1>` のタグごと消している、または別のタグに書き換えている。タグは残し、間の文字だけを変えるよう返す。
- `h1` 以外の要素を消したり足したりしている。増減した要素を具体的に示し、配られた要素は残すよう返す。
- 別のフォルダーの `index.html` を直して提出している。この課題のフォルダーの `index.html` を開くよう返す。

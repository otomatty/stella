## ヒント1 見出しの項目を読む

最初の確認では、文書の形は通り、見出しの項目が通りません。
メッセージと課題文の指定を見比べます。
左の `index.html` で、`<h1>` と `</h1>` の間を探してください。
変えるのは、その間の文字だけです。

## ヒント2 タグを残して保存する

見出しは、次の形で書かれています。

```html
<h1>（ここに指定の見出しを書きます）</h1>
```

タグやほかの要素は残し、見出しの文字だけを変えます。
「ファイル > 保存」のあと、ブラウザーで再読み込みします。
もう一度「課題を確認する」を押し、全部通ったら「提出する」を押します。

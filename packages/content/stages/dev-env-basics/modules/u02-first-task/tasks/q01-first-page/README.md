# 最初のページを作る

`index.html` の見出しを変え、保存・表示・確認・提出を一周します。

## 作るもの

- HTML の文書の形を残します。
- `h1` の見出しを「はじめてのページ」にします。文字は完全に一致させます。

`h1` 以外の要素は、消したり増やしたりせずに進めてください。
手元の確認では、文書の形と見出しを確かめます。

## 手順

### 1. 左のファイルと右の課題文を見る

Web の「VS Code で開く」から、この課題を開きます。
初回の学習フォルダーの選択と信頼の確認は、U01 の案内に沿って進めます。
左に開いた `index.html` と、右の課題文のパネルを見ます。
パネルの先頭には「進め方」と「いまここ」があります。

### 2. まず何も変えずに確認する

「課題を確認する」を押します。
見出しの項目が通らないことを確かめ、メッセージを読みます。
わざと1回失敗して、結果の読み方を知るための操作です。
失敗した回数は記録に残りますが、成績にはなりません。

### 3. 見出しを書き換えて保存する

`h1` の中の「ここを変更します」を「はじめてのページ」に書き換えます。
`<h1>` と `</h1>` は残し、間の文字だけを変えます。

:::os windows
「ファイル > 保存」を選びます。Ctrl+S でも保存できます。
:::

:::os macos
「ファイル > 保存」を選びます。Cmd+S でも保存できます。
:::

### 4. ブラウザーで見出しを確かめる

:::os windows
VS Code の左のエクスプローラーで `index.html` を右クリックします。
「エクスプローラーで表示」を選びます。
開いたエクスプローラーでファイルをダブルクリックします。
ブラウザーで開かなければ、ファイルをブラウザーの画面へドラッグします。
:::

:::os macos
VS Code の左のエクスプローラーで `index.html` を右クリックします。
「Finder で表示」を選びます。
Finder でファイルをダブルクリックします。
ブラウザーで開かなければ、ファイルをブラウザーの画面へドラッグします。
:::

ブラウザーに「はじめてのページ」と出れば、表示できています。
すでに開いていた場合は、更新ボタンで再読み込みします。

### 5. もう一度確認して提出する

VS Code に戻り、「課題を確認する」を押します。
全部の項目が通ったら、パネルの「提出する」を押します。
通らない項目があれば、メッセージを読んで直し、保存して確認します。

### 6. 提出の結果を読む

提出すると、AI が課題の観点で最初に確かめます。
結果は、次の場所から見られます。

- VS Code のコマンド「STELLA: ヒント・解答・レビューの結果を表示する」。
- Web のレッスン画面の下の「提出・添削を確認する」。
- Web の右上のベルの通知。

合格なら、この課題は完了です。星の進捗にも反映されます。
再提出なら、指摘を読んで直し、保存・確認・提出を行います。
「講師の確認待ち」なら、講師の結果が届くのを待って読みます。

## 7. うまくいかないとき

- 表示が変わらない：保存、再読み込み、同じファイルを開いているかの順に確かめます。
- HTML が文字で出る：ファイル名の末尾が `.html` か確かめます。
- 確認ボタンが見当たらない：課題文のパネルと学習フォルダーが開いているか見ます。
- 信頼していないと言われる：U01 の手順で、自分の学習フォルダーか確かめて信頼します。
- 提出できない：確認の項目が全部通っているか見ます。
- 直す場所が分からない：上のコマンドからヒントを1段ずつ開きます。開いた記録は提出に「支援付き」として残ります。

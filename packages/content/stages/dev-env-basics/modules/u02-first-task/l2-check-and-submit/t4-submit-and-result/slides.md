# 0-2-4 提出後の結果を読む

<!-- ノート: 手元の確認が全部通ったら、提出へ進めます。提出したあとも、返ってくる結果を読むところまで行いましょう。 -->

---

# 全部通った。これで終わり？

手元の確認は全部通りました。
課題を完了するには、提出してレビューの結果を読む段が残っています。

<!-- ノート: 手元の確認を通すことと、課題の合格は別の段です。確認の次にある「提出する」から、レビューへ進みます。 -->

---

# 覚えること

提出すると AI がまず確かめ、必要なときは講師が見ます。

AI の一次レビューは、提出物を課題の観点で最初に確かめることです。

<!-- ノート: AI が課題の条件や観点に沿って見ます。人が判断する必要があるときは、講師へ引き継がれます。 -->

---

# 「提出する」のあとに読む結果

| 結果 | 次にすること |
| --- | --- |
| 合格 | 課題の完了を確かめる |
| 再提出 | 指摘を読み、直して保存・確認・提出する |
| 講師の確認待ち | 講師の結果を待つ |

<!-- ノート: 再提出なら、指摘を読んで同じ課題を直します。講師の確認待ちのときは、あとから届く結果を確かめてください。 -->

---

# 結果を見る場所

- VS Code：「STELLA: ヒント・解答・レビューの結果を表示する」
- Web：レッスン画面の下の「提出・添削を確認する」
- Web：右上のベルの通知

星の進捗は、レッスンと課題を1件ずつ数えます。
課題は合格すると進みます。

<!-- ノート: VS Code ではコマンドパレットから、この名前のコマンドを選べます。レッスンを終えた分と、課題に合格した分が星の進捗になります。 -->

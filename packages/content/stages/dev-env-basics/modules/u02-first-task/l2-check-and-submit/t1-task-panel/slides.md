# 0-2-1 課題文のパネルを読む

<!-- ノート: 課題を開くと、左に編集するファイル、右に課題文が並びます。右のパネルの先頭にある「進め方」を見てください。 -->

---

# index.html が開いた。次は？

左に `index.html`、右に課題文が開いています。
どこから始めるか、画面の案内を探します。

<!-- ノート: 最初からファイルを書き換える前に、作るものを知る必要があります。右のパネルを先頭まで戻すと、操作の順番が見つかります。 -->

---

# 覚えること

課題文のパネルの「進め方」が、次にすることを示します。

<!-- ノート: 「進め方」は、課題に取り組む順番を示す案内です。上から順に、課題文、編集、確認、提出と進みます。 -->

---

# 「進め方」の4段

1. 課題文を読む
2. ファイルを編集して保存する
3. 「課題を確認する」を押す
4. 提出する

「いまここ」は、前回の確認の結果で決まります。

<!-- ノート: 前回通らなかったときは、直す段へ戻る案内が出ます。全部通ったときは、提出へ進む目印になります。 -->

---

# ボタンから戻れる

エディターの右上と、画面下のステータスバーにあります。
ステータスバーは、画面の下端にある状態や操作の表示です。

| ボタン | すること |
| --- | --- |
| 課題を確認する | 保存したファイルを確かめる |
| 課題文 | 課題文のパネルを開く |

<!-- ノート: 課題文を閉じたら「課題文」で戻れます。「課題を確認する」は、ファイルを直して保存したあとに使います。 -->

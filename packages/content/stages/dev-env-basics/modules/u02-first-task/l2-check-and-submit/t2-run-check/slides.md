# 打ち直したのに、前の見出しで確認された

`index.html` の文字を変えました。
確認の結果には、変更前の見出しが出ています。

<!-- ノート: エディターに新しい文字が見えても、保存していなければファイルは前のままです。確認する対象も、保存済みのファイルです。 -->

---

# 覚えること

「課題を確認する」は、保存したファイルを決まった手順で確かめます。

<!-- ノート: 確認の中身は、課題ごとに決まっています。この単元では、HTML の文書と見出しなどの条件を確かめます。 -->

---

# 保存してから確認する

「ファイル > 保存」→「課題を確認する」

未保存の変更があると、次の選択が出ます。

| 選択 | 確認する内容 |
| --- | --- |
| 保存して確認する | いまの変更を保存した内容 |
| 保存せずに確認する | 前に保存した内容 |

<!-- ノート: いま書いた見出しを確かめたいときは、「保存して確認する」を選びます。「保存せずに確認する」では、編集中の変更は入りません。 -->

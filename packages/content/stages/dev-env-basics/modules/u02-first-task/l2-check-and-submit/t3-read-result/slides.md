# 0-2-3 通らなかった結果を読む

<!-- ノート: 確認が通らなくても、作業を続けられます。結果の中から、次に直すための手がかりを探しましょう。 -->

---

# 文書は通ったのに、見出しは通らない

確認の結果には、通った項目と通らない項目が並んでいます。
どの部分を直すか、項目ごとに見分ける場面です。

<!-- ノート: ひとつ通らなかったからといって、ファイル全体を作り直す必要はありません。通らなかった項目と、そのメッセージを読んでください。 -->

---

# 覚えること

通らなかった項目のメッセージが、直す場所を教えます。

<!-- ノート: 項目の名前で何を確かめたかが分かります。メッセージで、期待した内容と自分のファイルの違いを探します。 -->

---

# 結果の読み方の例

| 項目 | 結果の例 |
| --- | --- |
| HTML の文書 | 通った |
| h1 の見出し | 通らない：指定の文字と一致しません |

見出しの文字を直す → 保存する → もう一度「課題を確認する」

<!-- ノート: これは結果の意味を示した例です。実際の画面のメッセージを読み、h1 の中の文字と課題文の指定を見比べます。 -->

---

# 何度でも直して確かめる

手元の確認は、何度失敗してもかまいません。
失敗した回数は記録に残りますが、成績にはなりません。

<!-- ノート: 回数は、つまずいていることに気づいて支援するために残ります。失敗を避けるより、メッセージを読んで一つずつ直しましょう。 -->

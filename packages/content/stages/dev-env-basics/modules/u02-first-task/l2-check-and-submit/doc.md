# レッスン0-2 確認して提出する

## このレッスンの目標

- [ ] 「進め方」に沿って保存・確認し、通らなかった項目を直せます。
- [ ] 全部通ったら提出し、レビューの結果を読めます。
- [ ] 行き詰まったとき、ヒントを1段ずつ使えます。

## 0-2-1 課題文のパネルを読む

> **課題文のパネルの「進め方」が、次にすることを示します。**

Web の課題の「VS Code で開く」を押します。
U01 の案内に沿って、学習フォルダーを開きます。
左には編集するファイル、右には課題文のパネルが開きます。
パネルの先頭の「進め方」は、次の4段です。

1. 課題文を読む。
2. ファイルを編集して保存する。
3. 「課題を確認する」を押す。
4. 提出する。

画面の3段目の見出しは「手元で確認する」です。
「いまここ」は、前回の確認の結果をもとに示されます。
通らなければ直す段へ、全部通れば提出へ進みます。
ファイルを編集するたびに、自動で確認されるわけではありません。

エディターの右上と、画面下のステータスバーにもボタンがあります。
ステータスバーは、画面の下端にある状態や操作の表示です。
「課題を確認する」で確認し、「課題文」でパネルを開けます。

## 0-2-2 保存した内容を確認する

> **「課題を確認する」は、保存したファイルを決まった手順で確かめます。**

確認は、自分の PC 上で行います。
確認する中身は、課題ごとに決まっています。
この単元では、HTML の文書と見出しなどの条件を確かめます。

まず「ファイル > 保存」を選び、「課題を確認する」を押します。
保存していない変更があると、次の選択が出ます。

| 選択 | 確かめるもの |
| --- | --- |
| 保存して確認する | いまの変更を保存したファイル |
| 保存せずに確認する | 前に保存したファイル |

いまの変更を確かめるなら「保存して確認する」を選びます。
ブラウザーで表示を確かめる操作も行ってください。
実務でも、決まった条件の確認と、実際の表示の確認を行います。

## 0-2-3 通らなかった結果を読む

> **通らなかった項目のメッセージが、直す場所を教えます。**

結果には、項目ごとに通った・通らないが並びます。
たとえば、文書は通っても、見出しだけ通らないことがあります。
通らなかった項目のメッセージを読みます。
課題文の指定とファイルの内容を見比べ、直して保存します。
もう一度「課題を確認する」を押し、その項目が通るか見ます。

手元の確認は、何度失敗してもかまいません。
失敗は回数として記録に残りますが、成績にはなりません。
つまずきに気づいて支援するための記録です。

## 0-2-4 提出後の結果を読む

:::tutorial review-result

> **提出すると AI がまず確かめ、必要なときは講師が見ます。**

全部の項目が通ったら、パネルの「提出する」を押せます。
AI の一次レビューは、提出物を課題の観点で最初に確かめることです。
AI は合格・再提出の結果を返します。
人が見る必要があるときは「講師の確認待ち」になります。

| 結果 | 次にすること |
| --- | --- |
| 合格 | 課題の完了を確かめる |
| 再提出 | 指摘を読み、直して保存・確認・提出する |
| 講師の確認待ち | 講師の結果を待ち、届いたら読む |

結果は、次の場所から見られます。

- VS Code のコマンドパレットで「STELLA: ヒント・解答・レビューの結果を表示する」を選ぶ。
- Web のレッスン画面の下の「提出・添削を確認する」を開く。
- Web の右上のベルで通知を開く。

星の進捗は、レッスンと課題を1件ずつ数えます。
課題は、手元の確認だけでなく、レビューに合格すると済みになります。
レッスンを全部終えても、課題の合格が残っていれば星はクリアになりません。

## 0-2-5 ヒントを1段ずつ開く

> **行き詰まったら、ヒントを 1 段ずつ開きます。**

ヒントは、解くための手がかりです。
VS Code で「STELLA: ヒント・解答・レビューの結果を表示する」を選びます。
ヒント1を開いたら、ファイルに戻って試します。
まだ進まないときに、次の段を開きます。

開いた記録は、提出に「支援付き」として残ります。
支援付きは、手がかりを使って取り組んだという意味です。
悪いことではなく、後で自分だけで解けるか確かめるための区別です。
ヒントを全部開いたあとに、解答例を見られる課題もあります。

## うまくいかないとき

| 困っていること | 確かめること |
| --- | --- |
| 「課題を確認する」が見当たらない | 課題文のパネルが開いているか、学習フォルダーを開いているかを見ます。「課題文」でパネルへ戻れます。戻れなければ、Web の「VS Code で開く」から同じ課題を開き直します。 |
| 信頼していないフォルダーと言われる | U01「フォルダーを信頼する意味」の手順で、自分の学習フォルダーか確認して信頼します。知らないフォルダーを一律に信頼しません。 |
| 「提出する」を押せない | 全部の項目が通っているか見ます。通らない項目を直して保存し、もう一度確認します。 |

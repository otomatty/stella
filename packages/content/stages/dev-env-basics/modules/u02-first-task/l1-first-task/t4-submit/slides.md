# 0-1-4 提出して結果を見る

<!-- ノート: 確認が全部通ったら、課題文のパネルから提出します。提出後は、返ってくる結果も読みます。 -->

---

# 覚えること

手元の確認が通ったら提出し、AI の確認と必要に応じた講師の確認の結果を読みます。

<!-- ノート: AI の一次レビューは、提出物を課題の観点で最初に確かめることです。人の判断が必要なら講師に引き継がれます。 -->

---

# 提出後にすること

パネルの「提出する」を押し、レビューの結果を開きます。

| 結果 | 次にすること |
| --- | --- |
| 合格 | 完了を確かめる |
| 再提出 | 指摘を読み、直して保存・確認・提出する |
| 講師の確認待ち | 講師の結果を待ち、届いたら読む |

<!-- ノート: 結果は、コマンドパレットの「STELLA: ヒント・解答・レビューの結果を表示する」から読めます。Web のレッスン画面からも確認できます。 -->

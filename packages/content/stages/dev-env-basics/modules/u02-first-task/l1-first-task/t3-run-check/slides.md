# 0-1-3 課題を確認する

<!-- ノート: 表示を見たら、課題の条件に合うかも確かめます。確認は自分の PC 上で行います。 -->

---

# 覚えること

「課題を確認する」で手元の結果を読み、通らなければ直して保存し、確認し直します。

<!-- ノート: 確認には、保存したファイルが使われます。通らないときは、結果の1行目から読み始めます。 -->

---

# 保存して確認する

1. ステータスバーかエディター右上の「課題を確認する」を押す
2. 結果の1行目を読み、通らなかった項目のメッセージを見る
3. 課題文と見比べ、直す → 保存する → もう一度確認する

<!-- ノート: ステータスバーは、画面下端にある状態や操作の表示です。メッセージを手がかりに、直す場所を絞ります。 -->

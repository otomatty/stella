# 0-1-2 ブラウザーで表示する

<!-- ノート: 編集した文字が、ページでどう見えるかを確かめます。ブラウザーは、ページを表示するアプリです。 -->

# 覚えること

保存した HTML をブラウザーで開き、直したら保存して再読み込みします。

<!-- ノート: ブラウザーが読むのは、保存したファイルです。再読み込みは、表示中のページを読み直す操作です。 -->

---

# 編集したファイルを表示する

1. エクスプローラーで `index.html` を右クリックし、OS のファイルの画面で表示する（名前は OS で違うため、まとめを見る）
2. そのファイルをダブルクリックしてブラウザーで開く（開かなければブラウザーへドラッグする）
3. 直したら「保存」→ブラウザーの更新ボタンで再読み込みする

OS 別の操作は、まとめで確認します。

<!-- ノート: VS Code のエクスプローラーで index.html を右クリックし、OS のファイルの画面で表示します。メニューの名前は OS で違うので、まとめを見ます。そのファイルをダブルクリックし、開かなければブラウザーへドラッグします。ドラッグは、押したまま動かし、目的の場所で離す操作です。直したら保存して再読み込みします。 -->

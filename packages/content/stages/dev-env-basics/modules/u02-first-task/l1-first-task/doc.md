# レッスン0-1 最初の課題

## このレッスンの目標

- [ ] 課題のファイルを編集して保存できる
- [ ] ブラウザーの表示と手元の確認の結果を確かめられる
- [ ] 提出して結果を読める

## 0-1-1 編集して保存する

> **課題のファイルを編集したら、「ファイル」→「保存」で変更を残します。**

Web の課題「最初のページを作る」から「VS Code で開く」を押します。
右の課題文を読み、左の `index.html` を編集します。
HTML はページの内容や構造を書く言語です。
`h1` は大きな見出しを表す要素です。
`<h1>` と `</h1>` のタグは残し、間の文字を指定どおりに変えます。

保存は、編集した内容をファイルに残す操作です。
「ファイル」→「保存」を選びます。
上のファイル名の見出しをタブと呼びます。
未保存を示す丸印が消えれば、変更が残っています。
仕事でも、編集後に保存してから表示や動作を確かめます。

## 0-1-2 ブラウザーで表示する

> **保存した HTML をブラウザーで開き、直したら保存して再読み込みします。**

ブラウザーは、ページを表示するアプリです。
VS Code の左のファイル一覧をエクスプローラーと呼びます。
一覧から、編集した `index.html` の場所を開きます。

:::os windows
1. VS Code のエクスプローラーで `index.html` を右クリックします。
2. 「エクスプローラーで表示」を選びます。
3. Windows のエクスプローラーで、そのファイルをダブルクリックします。
:::

:::os macos
1. VS Code のエクスプローラーで `index.html` を右クリックします。
2. 「Finder で表示」を選びます。
3. Finder で、そのファイルをダブルクリックします。
:::

ブラウザーで開かなければ、ファイルをブラウザーの画面へドラッグします。
ドラッグは、押したまま動かし、目的の場所で離す操作です。
見出しが表示されたか確かめます。
直したら保存し、ブラウザーの更新ボタンで再読み込みします。
再読み込みは、表示中のページを読み直す操作です。

## 0-1-3 課題を確認する

> **「課題を確認する」で手元の結果を読み、通らなければ直して保存し、確認し直します。**

保存したら、画面下のステータスバーかエディター右上の「課題を確認する」を押します。
ステータスバーは、画面下端の状態や操作の表示です。
自分の PC 上で、保存したファイルが課題の条件に合うか確かめます。

通らなければ結果の1行目を読み、通らなかった項目のメッセージを見ます。
課題文とファイルを見比べ、直して保存し、もう一度確認します。

## 0-1-4 提出して結果を見る

> **手元の確認が通ったら提出し、AI の確認と必要に応じた講師の確認の結果を読みます。**

:::tutorial review-result

全部通ったら、課題文のパネルの「提出する」を押します。
AI の一次レビューは、提出物を課題の観点で最初に確かめることです。
必要なら講師が確認します。
結果は、コマンドパレットの「STELLA: ヒント・解答・レビューの結果を表示する」か、Web のレッスン下の「提出・添削を確認する」から読めます。

合格なら完了です。
再提出なら指摘を読み、直して保存・確認・提出します。
「講師の確認待ち」なら、講師の結果が届くのを待って読みます。

困ったら同じコマンドから、手がかりになるヒントを1段ずつ開けます（使うと「支援付き」と記録されます）。
課題文のパネルの「講師に相談」も使えます。

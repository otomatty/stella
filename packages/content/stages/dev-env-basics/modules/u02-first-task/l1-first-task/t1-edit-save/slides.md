# 0-1-1 編集して保存する

<!-- ノート: 課題文を読んだら、左のファイルを編集します。仕事でも、変更をファイルに残すために保存します。 -->

---

# 覚えること

課題のファイルを編集したら、「ファイル」→「保存」で変更を残します。

<!-- ノート: 保存は、編集した内容をファイルに残す操作です。上のファイル名の見出しをタブと呼び、丸印は未保存の変更を表します。 -->

---

# 指定の文字だけを変える

1. 課題の `index.html` を開く
2. `<h1>` と `</h1>` の間を、課題文の指定に変える
3. 「ファイル」→「保存」を選ぶ
4. タブの丸印が消えたか見る

<!-- ノート: HTML はページの内容や構造を書く言語で、h1 は大きな見出しを表す要素です。山かっこのタグは残し、間の文字を変えます。 -->

---

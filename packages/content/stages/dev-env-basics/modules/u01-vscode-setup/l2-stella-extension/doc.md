# レッスン01-2 STELLA 拡張をつなぐ

## このレッスンの目標

- [ ] 発行元とIDを確かめて STELLA 拡張を入れられる
- [ ] Web から課題を開く流れを説明できる
- [ ] 学習フォルダーと課題フォルダーの場所を説明できる

## 01-2-1 STELLA 拡張を入れる

> **STELLA 拡張は、拡張機能のビューで検索して入れます。**

拡張機能は、VS Code に機能を足すものです。
STELLA 拡張は、課題を受け取るための追加機能です。
左端のアイコンが並ぶ場所を、アクティビティバーと呼びます。

1. VS Code で、四角の「拡張機能」アイコンを押します。
2. 検索欄に「STELLA」と入力します。
3. 発行元が `saedgewell` であることを確かめます。
4. ID が `saedgewell.stella-lms` であることも確かめます。
5. 「インストール」を押します。

似た名前の別の拡張は入れません。
Web の「VS Code で開く」を押したときに、導入を尋ねられることもあります。
その場合も発行元とIDを確かめて入れます。
拡張の詳細で「無効にする」が選べる状態なら、有効になっています。

## 01-2-2 Webから課題を開く

> **Web のレッスンの「VS Code で開く」で、VS Code に課題が届きます。**

ここでは、U02 の最初の課題を開くときの流れを読んでおきます。
この公開単元には、開く課題はありません。
実際に接続できたかは、U02 の課題で確かめます。

学習フォルダーは、学習のファイルをまとめて置く場所です。
課題文のパネルには、取り組む課題の説明が表示されます。

1. Web にログインし、課題文のレッスンを開きます。
2. 「VS Code で開く」を押します。
3. ブラウザーの「Visual Studio Code を開きますか」で「開く」を押します。
4. 初回は、学習フォルダーを選びます。
   おすすめは、自分のホームに `web-training` を作ることです。
   ホームは、自分のユーザー用のフォルダーです。
5. 「このフォルダー内のファイルの作成者を信頼しますか」が出ます。
   自分の学習フォルダーであることを確かめ、「信頼する」を選びます。
6. ウィンドウが開き直るのを待ちます。
7. 左に編集するファイル、右に課題文のパネルがあることを確かめます。

スマートフォン・タブレットには、PCへリンクを送るボタンが出ます。
「VS Code で開く」の代わりに、そのボタンを使います。
届いたページをPCで開いてから、上の操作を進めます。

## 01-2-3 学習フォルダーの並び

> **学習フォルダーには、ステージ・単元・課題の順にフォルダーが並びます。**

課題フォルダーは、1つの課題のファイルが入る場所です。
たとえば、最初の課題は次の並びになります。

```text
web-training/
  dev-env-basics/
    u02-first-task/
      q01-first-page/
```

学習フォルダーの場所には、次のような例があります。
`yamada` はユーザー名の例です。自分のユーザー名に読み替えます。
この例の文字列を、そのまま新しいフォルダー名にはしません。

:::os windows
`C:\Users\yamada\web-training`
:::

:::os macos
`/Users/yamada/web-training`
:::

学習フォルダーは、初回に選んだ場所を STELLA 拡張が覚えます。
既存のフォルダーを選んだ場合は、その場所を使います。
学習者が書いたファイルは上書きしません。
同じ名前があると、準備先と衝突したファイルを知らせて止まります。
通知に出た場所を確かめ、困ったら研修の担当者に相談します。
自分のファイルを、確かめずに削除しないでください。

## うまくいかないとき

### 押しても何も起きない

VS Code が入っているか、まず起動して確かめます。
次に、STELLA 拡張のIDと有効状態を確かめます。
ブラウザーの確認で「開く」を押したかも確かめます。
確認を閉じた場合は、Web からもう一度「VS Code で開く」を押します。

### 信頼を断った

信頼していないフォルダーでは、「課題を確認する」が動きません。
自分の学習フォルダーが開いていることを確かめます。
「表示」→「コマンドパレット」を開きます。
「Workspaces: Manage Workspace Trust」を探して実行します。
対象の場所と出所を確かめてから、信頼する状態に変えます。
すべてのフォルダーを一律に信頼する必要はありません。

### 違うフォルダーが開いた

Web で、開こうとした課題のレッスンをもう一度確かめます。
そこから「VS Code で開く」を押し、切り替わったウィンドウを見ます。
STELLA 拡張は、学習フォルダーを開くように切り替えます。
学習フォルダーの下に、上の順で課題フォルダーがあるか確かめます。
フォルダーが表示されない場合は、単独のファイルだけ開いていないか見ます。
戻れないときは、表示された準備先を控えて研修の担当者に相談します。

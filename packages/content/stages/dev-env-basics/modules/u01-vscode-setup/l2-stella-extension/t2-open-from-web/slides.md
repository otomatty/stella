# 01-2-2 Webから課題を開く

<!-- ノート: Web の課題文から、VS Code に作業を渡す流れを見ておきます。実際に開くのは、この公開単元の次にある U02 の課題です。 -->

---

# Web の課題文を、どうやって手元へ？

U02 で最初の課題文を開いた場面を考えます。
VS Code を起動しただけでは、課題のファイルは並んでいません。

<!-- ノート: 課題文の文章を読むことと、編集するファイルを受け取ることには、橋渡しが要ります。U01 には開く課題が無いので、まずその流れをつかみましょう。 -->

---

# 覚えること

Web のレッスンの「VS Code で開く」で、VS Code に課題が届きます。

Web の課題文と、PC での作業がつながります。

<!-- ノート: 課題を受け取る入口は、Web の課題文にあるボタンです。そこから STELLA 拡張へ、開く課題を渡します。 -->

---

# U02 で開くときの流れ

1. Web にログインし、課題文のレッスンを開きます。
2. 「VS Code で開く」を押します。
3. ブラウザーの確認で「開く」を押します。
4. 初回は、学習フォルダーを選びます。

学習フォルダーは、学習のファイルをまとめて置く場所です。

<!-- ノート: 初回は、自分のユーザー用の場所に web-training を作る方法を選べます。信頼の確認が出たら、自分の学習フォルダーであることを確かめてから進めます。 -->

---

# 届いた目印は、左右に並ぶ画面

| 左 | 右 |
| --- | --- |
| 編集するファイル | 課題文のパネル |

課題文のパネルは、取り組む課題の説明を表示する場所です。
ウィンドウが開き直るのを待ち、この並びを確かめます。

<!-- ノート: 切り替わった先で、ファイルと課題の説明が一緒に見えるか確認します。スマートフォンやタブレットで読んでいる場合は、ページのリンクをPCへ送ってから開きます。 -->

# 覚えること
Web のレッスンの「VS Code で開く」で、VS Code に課題が届きます。

学習フォルダーは、学習のファイルをまとめて置く場所です。
課題文のパネルには、取り組む課題の説明が表示されます。
<!-- ノート: Web のレッスンの「VS Code で開く」で、VS Code に課題が届きます。 -->
---
# 確かめる場面
「VS Code で開く」→ ブラウザーの確認で「開く」→ 初回は学習フォルダーを選ぶ。

自分の学習フォルダーを信頼すると、ウィンドウが開き直ります。
左に編集するファイル、右に課題文のパネルが並びます。

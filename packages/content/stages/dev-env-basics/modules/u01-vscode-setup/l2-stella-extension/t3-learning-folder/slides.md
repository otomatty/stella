# 覚えること
学習フォルダーには、ステージ・単元・課題の順にフォルダーが並びます。

課題フォルダーは、1つの課題のファイルが入る場所です。
学習フォルダーの下に、ステージ・単元・課題の順で置かれます。
<!-- ノート: 学習フォルダーには、ステージ・単元・課題の順にフォルダーが並びます。 -->

# 確かめる場面
例: web-training/dev-env-basics/u02-first-task/q01-first-page/

学習者のファイルは上書きされません。
同じ名前があると、準備が止まり、場所とファイルが知らされます。

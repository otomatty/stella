# 01-2-3 学習フォルダーの並び

<!-- ノート: 受け取った課題のファイルは、学習フォルダーの中に整理されます。最初の課題を例に、どの名前の下へ入るかをたどります。 -->

---

# 似たファイル名が増えてきた

いくつか課題を開くと、同じ名前のファイルが見つかりました。
ファイル名だけでは、どの課題のものか区別できません。

<!-- ノート: 同じ名前でも、置かれている課題が違えば別のファイルです。名前を覚えるだけでなく、どのフォルダーにあるかをたどる必要があります。 -->

---

# 覚えること

学習フォルダーには、ステージ・単元・課題の順にフォルダーが並びます。

課題フォルダーは、1つの課題のファイルが入る場所です。

<!-- ノート: 学習フォルダーの中を、ステージ、単元、課題の順にたどります。課題ごとに場所が分かれるので、作業したファイルを探せます。 -->

---

# 最初の課題の置き場所

```text
web-training/
  dev-env-basics/
    u02-first-task/
      q01-first-page/
```

いちばん内側の `q01-first-page` が課題フォルダーです。

<!-- ノート: 外側の web-training が、学習全体を置く場所です。その下にこのステージ、U02、最初の課題という順で並んでいます。 -->

---

# 同じ名前があると、準備が止まる

STELLA 拡張は、学習者が書いたファイルを上書きしません。

準備が止まったら、通知にある準備先とファイルを確かめます。
確かめずに自分のファイルを削除しないでください。

<!-- ノート: 既存のファイルと衝突したときは、置き場所と対象のファイルが知らされます。判断できなければ、その場所を控えて研修の担当者に相談しましょう。 -->

---

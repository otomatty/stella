# こんなときに迷います
VS Code を開けましたが、STELLA の課題はまだ届きません。

# 覚えること
STELLA 拡張は、拡張機能のビューで検索して入れます。

拡張機能は、VS Code に機能を足すものです。
STELLA 拡張は、課題を受け取るための追加機能です。
左端にビューを切り替えるアイコンが並ぶ場所がアクティビティバーです。
<!-- ノート: STELLA 拡張は、拡張機能のビューで検索して入れます。 -->
---
# 確かめる場面
四角の「拡張機能」→「STELLA」で検索します。
発行元 saedgewell、ID saedgewell.stella-lms を確かめ、
「インストール」を押します。似た名前の別の拡張は選びません。

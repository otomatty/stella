# 01-2-1 STELLA 拡張を入れる

<!-- ノート: VS Code に、STELLA の課題を受け取る機能を加えます。検索結果では、名前に加えて発行元とIDも確認します。 -->

---

# VS Code を開いても、課題が見えない

VS Code は起動できました。
でも、Web で読んでいる STELLA の課題は表示されていません。

<!-- ノート: VS Code 本体を入れただけでは、STELLA の課題を受け取る準備はそろいません。課題とつなぐ追加の機能が必要です。 -->

---

# 覚えること

STELLA 拡張は、拡張機能のビューで検索して入れます。

拡張機能は、VS Code に機能を足すものです。
STELLA 拡張は、課題を受け取るための追加機能です。

<!-- ノート: STELLA 拡張を入れると、VS Code で課題を受け取れるようになります。追加機能を探す場所が、拡張機能のビューです。 -->

---

# 左の四角のアイコンから検索する

左端のアイコンが並ぶ場所が、アクティビティバーです。

「拡張機能」→ 検索欄に「STELLA」

発行元: `saedgewell`
ID: `saedgewell.stella-lms`

<!-- ノート: 四角のアイコンで拡張機能を開き、STELLA と入力します。似た名前を選ばないよう、詳細にある発行元とIDを照合してください。 -->

---

# 入れたあとは、有効な状態を確かめる

発行元とIDが合ったら「インストール」を押します。

詳細で「無効にする」が選べれば、有効な状態です。
この確認のために「無効にする」を押す必要はありません。

<!-- ノート: 表示が「インストール」から変わったことを確かめましょう。「無効にする」は機能を止める操作なので、選べる状態かを見るだけで十分です。 -->

---

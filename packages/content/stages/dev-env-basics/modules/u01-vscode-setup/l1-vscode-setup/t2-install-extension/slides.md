# 覚えること

STELLA 拡張は、拡張機能のビューで検索して入れます。

<!-- ノート: 拡張機能のビューから STELLA を探します。ビューは、機能ごとの表示領域です。 -->

# 名前だけで選ばず、IDも確かめる

1. VS Code の四角の「拡張機能」アイコンを押す
2. 「STELLA」を検索する
3. 発行元 `saedgewell`、ID `saedgewell.stella-lms` を確かめる
4. 「インストール」を押す

<!-- ノート: 似た名前の拡張を避けるため、発行元とIDも見ます。インストール後、有効になっていることを確かめます。 -->

# 覚えること

VS Code は、公式サイトから自分のOS用を入れ、日本語で表示します。

<!-- ノート: OS は、PC の基本的な動きを支えるソフトウェアです。使うOSに合う公式手順で準備します。 -->

# 準備の順序

1. VS Code の公式サイトで自分のOS用を選ぶ
2. インストールして起動する
3. Japanese Language Pack で表示を日本語にする

OS 別の手順は、このレッスンのまとめで確認します。

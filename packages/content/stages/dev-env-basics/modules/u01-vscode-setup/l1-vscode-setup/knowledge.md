## 知識問題

この問題と解説は教材用に作成しました。

### Q1. VS Code を入れる方法はどれですか？
<!-- kind: single; skills: open-learning-folder -->

- A. 公式サイトから自分のOS用を入れる
- B. 検索で最初に出た広告から入れる

<details>
<summary>解答</summary>

**A** — 公式手順で導入し、Japanese Language Pack で日本語にできます。

</details>

### Q2. STELLA 拡張を選ぶとき、確かめるものはどれですか？
<!-- kind: single; skills: open-learning-folder -->

- A. 名前だけ
- B. 発行元 saedgewell、ID saedgewell.stella-lms

<details>
<summary>解答</summary>

**B** — 拡張機能のビューで検索し、発行元とIDも確かめます。

</details>

### Q3. 翌日に同じ課題の続きを開く方法はどれですか？
<!-- kind: single; skills: open-learning-folder -->

- A. Web の同じ課題のレッスンから「VS Code で開く」を押す
- B. 毎回、新しい学習フォルダーを作る

<details>
<summary>解答</summary>

**A** — 拡張が覚えた学習フォルダーに戻り、保存したファイルを使えます。

</details>

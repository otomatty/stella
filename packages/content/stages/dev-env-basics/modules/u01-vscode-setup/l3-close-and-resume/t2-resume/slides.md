# 01-3-2 翌日に同じ課題へ戻る

<!-- ノート: 今日の作業を終えたら、翌日も同じ場所から続きを書きたいですね。閉じる前と開き直すときの、2つの場面をたどります。 -->

---

# 昨日のファイルを、作り直す？

昨日は課題の途中で VS Code を閉じました。
今日は空のウィンドウが開き、昨日のファイルが見えません。

<!-- ノート: 画面から消えたことと、ファイルが無くなったことは別です。保存してあれば、元の課題の場所へ戻って続きを書けます。 -->

---

# 覚えること

続きは、Web のレッスンから開き直せば同じ課題フォルダーに戻れます。

保存したファイルは、VS Code を閉じても学習フォルダーに残ります。

<!-- ノート: 続けるたびに新しい課題フォルダーを作る必要はありません。Web で同じ課題を選んで開けば、保存してある場所に戻れます。 -->

---

# 今日は保存して閉じ、明日はWebから開く

閉じる前: 「ファイル」→「すべて保存」

翌日: Web にログイン → ガイドの案内
→ 同じ課題文のレッスン →「VS Code で開く」
→ ブラウザーの確認で「開く」

<!-- ノート: ガイドには「続きから」など、進み具合に応じたボタンが出ます。表示された「次にやること」を読み、続けたい課題のレッスンへ進んでください。 -->

---

# 戻った先で、課題とファイルを照合する

左のファイルと、右の課題文のパネルを見ます。
昨日取り組んだ課題の続きか、確かめます。

違う課題なら、Web で課題の題を確かめて開き直します。

<!-- ノート: 別のファイルを新しく書き始める前に、戻った課題の題と保存した内容を見ましょう。この閉じて再開する操作も、U02 の最初の課題で試します。 -->

---

# まとめ

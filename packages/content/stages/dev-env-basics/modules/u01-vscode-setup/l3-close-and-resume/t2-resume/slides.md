# こんなときに迷います
翌日、昨日書いたファイルをどこから開くか迷いました。
<!-- ノート: 仕事や学習を始める場面を思い浮かべてください。 -->

# 覚えること
続きは、Web のレッスンから開き直せば同じ課題フォルダーに戻れます。

VS Code を閉じても、書いて保存したファイルは残ります。
Web から同じ課題を開き直すと、その場所へ戻れます。
<!-- ノート: 続きは、Web のレッスンから開き直せば同じ課題フォルダーに戻れます。 -->
---
# 確かめる場面
Web でログイン → ガイドの「続きから」

→ 課題文の「VS Code で開く」→ 同じ課題フォルダー。

閉じる前に保存すると、翌日の仕事や学習を同じ場所から再開できます。

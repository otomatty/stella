# レッスン01-3 閉じて再開する

## このレッスンの目標

- [ ] 信頼してよいフォルダーを判断できる
- [ ] 閉じたあとも同じ課題フォルダーへ戻れる

## 01-3-1 フォルダーを信頼する意味

> **信頼するのは、自分の学習フォルダーと出所を確かめたフォルダーだけです。**

Workspace Trust は、フォルダーの出所を確かめて信頼する仕組みです。
フォルダーの中のプログラムを動かしてよいかを判断します。
STELLA 拡張は、信頼したフォルダーでだけ確認用のプログラムを動かします。

自分の学習フォルダーや、出所を確かめた研修資料を対象にします。
知らない相手から届いたフォルダーは、先に出所を確かめます。
すべてのフォルダーを一律に信頼する必要はありません。
信頼しない状態は、Restricted Mode（制限モード）と呼ばれます。
制限モードでは、STELLA 拡張からプログラムを起動しません。

## 01-3-2 翌日に同じ課題へ戻る

> **続きは、Web のレッスンから開き直せば同じ課題フォルダーに戻れます。**

VS Code を閉じても、保存したファイルは学習フォルダーに残ります。
仕事でも、閉じる前の保存と、再開する場所の確認が役立ちます。

閉じる前に「ファイル」→「すべて保存」を選びます。
そのあと、VS Code のウィンドウを閉じます。
翌日は、次の順で再開します。

1. Web で STELLA にログインします。
2. ホームのガイドの「続きから」を押します。
3. 課題文のレッスンで「VS Code で開く」を押します。
4. ブラウザーの確認で「開く」を押します。
5. 左のファイルと右の課題文のパネルを確かめます。

ガイドのボタン名は、進み具合に応じて変わることがあります。
表示されている「次にやること」を読んで進めます。
別のレッスンが開いた場合は、続けたい課題のレッスンを開きます。
U02 に進んだら、最初の課題で閉じて再開する操作も試します。

## うまくいかないとき

「課題を確認する」が動かなければ、制限モードか確かめます。
自分の学習フォルダーか見てから、信頼の状態を確認します。
手順は前のまとめの「信頼を断った」を読み返します。

違うフォルダーに戻ったら、Web で課題の題を確かめて開き直します。
ファイルが見つからないときは、準備先を控えて担当者に相談します。
同じファイルを別の場所に作り直す前に、学習フォルダーを確かめます。

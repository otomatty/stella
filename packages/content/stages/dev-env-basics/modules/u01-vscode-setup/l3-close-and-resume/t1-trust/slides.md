# 覚えること
信頼するのは、自分の学習フォルダーと出所を確かめたフォルダーだけです。

Workspace Trust は、フォルダーの出所を確かめて信頼する仕組みです。
信頼したフォルダーでだけ、課題の確認のためにプログラムが動きます。

# 確かめる場面
自分の学習フォルダーか、出所を確かめた研修資料かを見ます。

知らない相手から届いたフォルダーは、すぐに信頼せず、
出所を確かめてから判断します。

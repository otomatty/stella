# 01-1-1 VS Codeの役割

<!-- ノート: Web で教材を読む準備ができたら、次は自分でファイルを書く道具を用意します。その道具が VS Code です。 -->

---

# 課題の文章は、どこに書く？

Web で課題文を読みました。
でも、そのページを眺めているだけでは、提出するファイルはできません。

<!-- ノート: 課題文を読む場所と、自分のファイルを書く場所を区別しましょう。学習中は、この2つの場所を行き来します。 -->

---

# 覚えること

VS Code は、ファイルを書いて保存するための道具です。

エディターは、ファイルの中の文章を書く道具です。
VS Code は、そのエディターの1つです。

<!-- ノート: VS Code では、文字を入力してファイルに残します。仕事で開発するときも、こうしたエディターでファイルを書きます。 -->

---

# 文字を、保存して残す

たとえば、ファイルに次の1行を書きます。

```text
今日から学習を始めます。
```

入力した文字を保存すると、あとで読み返せます。

<!-- ノート: この1行も、ファイルに書いて保存する対象になります。特別なプログラムを書く前に、文字を残せる道具だと捉えてください。 -->

---

# 読む場所と、書く場所

| 場所 | 役割 |
| --- | --- |
| Web のレッスン | 説明や課題文を読みます |
| VS Code | 課題のファイルを書いて保存します |

<!-- ノート: Web の説明を読みながら、VS Code で自分のファイルを編集します。課題文を読んだことと、ファイルを作ったことは、それぞれ別の作業です。 -->

---

# 01-1-3 日本語で表示する

<!-- ノート: VS Code のメニューが英語でも、日本語の表示に切り替えられます。教材に出てくるメニュー名と、画面の文字をそろえましょう。 -->

---

# 教材は「表示」、画面は「View」

教材には「表示」を開くと書いてあります。
起動した VS Code には「View」と表示されています。

<!-- ノート: 同じ操作でも、表示言語が違うと別の名前に見えます。教材のメニュー名を探しやすくするために、日本語表示を準備します。 -->

---

# 覚えること

表示言語は Japanese Language Pack で日本語にします。

Japanese Language Pack は、表示を日本語にする追加機能です。

<!-- ノート: 言語パックを使うと、メニューなどの表示が日本語になります。右下に日本語表示の案内が出ていれば、その案内に沿って入れられます。 -->

---

# 操作の名前を検索する

「View」→「Command Palette」を開きます。

`Configure Display Language` を探し、
「日本語」（Japanese）を選びます。

コマンドパレットは、操作の名前を探して実行する場所です。

<!-- ノート: 英語の画面では、View から Command Palette を開きます。Configure Display Language は表示言語を選ぶ操作で、導入を求められたら案内に沿って進めます。 -->

---

# 再起動後のメニューで確かめる

| 切り替える前 | 切り替えたあと |
| --- | --- |
| File | ファイル |
| View | 表示 |

再起動の案内に従い、日本語のメニューになったか見ます。

<!-- ノート: 言語を選んだだけでは、まだ表示が変わらない場合があります。日本語が候補に無いときの言語パックの入れ方は、まとめに載っています。 -->

---

<!-- _class: summary -->
# まとめ

表示言語は Japanese Language Pack で日本語にします。

<!-- ノート: 日本語表示には Japanese Language Pack を使います。切り替えて再起動したら、「ファイル」「表示」の文字を確かめてください。 -->

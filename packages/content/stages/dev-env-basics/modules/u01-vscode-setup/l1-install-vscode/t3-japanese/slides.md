# こんなときに迷います

# 覚えること
表示言語は Japanese Language Pack で日本語にします。

Japanese Language Pack は、表示を日本語にする追加機能です。
コマンドパレットは、操作の名前を探して実行する場所です。
<!-- ノート: 表示言語は Japanese Language Pack で日本語にします。 -->
---
# 確かめる場面
右下に日本語表示の案内が出たら、案内に沿って再起動します。

案内が無ければ「表示」→「コマンドパレット」で
「Configure Display Language」→「日本語」を選び、再起動します。

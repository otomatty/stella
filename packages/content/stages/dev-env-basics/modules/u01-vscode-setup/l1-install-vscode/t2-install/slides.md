# 01-1-2 公式サイトから入れる

# ダウンロード先がいくつもある

検索結果に「VS Code」のページがいくつも並んでいます。
ファイルの名前だけでは、どこから入れればよいか決められません。

<!-- ノート: 似た説明のページがあっても、入手先は慎重に選びます。開いたページの配布元と、用意されているPC向けの種類を確認しましょう。 -->

---

# 覚えること

VS Code は公式サイトから、自分のOS用を入れます。

公式サイトのドメインは `code.visualstudio.com` です。
ドメインは、Web の配布元を見分ける手がかりです。

<!-- ノート: アドレスにある code.visualstudio.com を確かめます。そこから自分のOSに合う通常版へ進みます。 -->

---

# 配布元・OS・通常版を確認する

| 確認するもの | 選ぶもの |
| --- | --- |
| 配布元 | `code.visualstudio.com` |
| 対象 | 自分のOS用 |
| 種類 | 通常版の Stable |

具体的な導入操作は、まとめのOS別手順で進めます。

<!-- ノート: Stable は、ここで使う通常版の名前です。会社のPCを使う場合は、先に担当者へ確認し、認められた方法で導入してください。 -->

---

# ダウンロードしたら、起動まで確かめる

ファイルを受け取っただけでは、導入は終わっていません。

まとめの手順で導入 → VS Code を起動

VS Code のウィンドウが開けば、ここは完了です。

<!-- ノート: ダウンロードは、導入に必要なファイルを受け取る段階です。自分で VS Code を起動し、画面が開くところまで確認します。 -->

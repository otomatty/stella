# 覚えること
VS Code は公式サイトから、自分のOS用を入れます。

公式サイトのドメインは code.visualstudio.com です。
自分のOSの Stable 版を選びます。

# 確かめる場面
まとめで自分のOSの手順を読み、導入します。
会社が管理するPCは、研修の担当者へ先に確認します。

VS Code を起動し、ウィンドウが開けば完了です。

# 案内されたページを開くとき、アドレス欄に長い文字列を入れました

案内されたページを開くとき、アドレス欄に長い文字列を入れました。
この文字列のどこが、開く場所を表しているのでしょうか。

<!-- ノート: 長いアドレスを一つの名前として見ると、どこが違うのか分かりにくくなります。区切りに注目して読みます。 -->

# 覚えること

URL は、どこにある何を開くかを表します。

URL は、開くものの場所を表す文字列です。

<!-- ノート: URL は、開く相手と場所を示します。ここでは方式、相手の名前、その中の場所に分けて見ます。 -->

---

# 画面で確かめる

`https://example.com/pages/about.html`

| 部品 | 例と意味 |
| --- | --- |
| スキーム | https: 開くための方式 |
| ホスト | example.com: 相手の名前 |
| パス | /pages/about.html: 相手の中の場所 |

<!-- ノート: https の部分が方式、example.com が相手、最後がパスです。この例を使って三つの位置を指してみましょう。 -->

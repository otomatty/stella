# 4-4-1 HTML から画面へ

# ファイルには山かっこのタグがあるのに、画面には見出しの文字だけが出ます

ファイルには山かっこのタグがあるのに、画面には見出しの文字だけが出ます。
同じ内容が違う姿で見えるのは、なぜでしょうか。

<!-- ノート: タグの文字がそのまま並ばなくても、読み飛ばされているわけではありません。文書の構造を伝えています。 -->

---

# 覚えること

ブラウザーは HTML を読んで画面を作ります。

ブラウザーは、タグを文書の構造として読み取ります。

<!-- ノート: ブラウザーが HTML を読み、構造に合わせて画面を作ります。見出しのタグは見出しとして扱われます。 -->

---

# 画面で確かめる

```html
<h1>学習の予定</h1>
```

ブラウザーには「学習の予定」が大きな見出しとして出ます。

<!-- ノート: h1 の間の文が画面の見出しになります。ファイルを保存して開き、タグと表示を照らし合わせてください。 -->

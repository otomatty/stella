# レッスン4-1 2つ目のページを作る

## このレッスンの目標

- [ ] 別の名前で2つ目の HTML ファイルを作れます。
- [ ] 保存した2つのページをそれぞれ開けます。

## 4-1-1 別の名前でページを作る

> **2つ目のページは、別の名前の HTML ファイルとして作ります。**

課題フォルダーを選び、「新しいファイル」で `about.html` を作ります。
`index.html` を残し、別の名前にするのが要点です。
HTML の文書の枠組みを用意し、見出しなどの内容を変えます。
すでにある文書を写して始める場合も、別のファイルへ保存します。
一覧に2つの名前が並ぶことを確かめます。
それぞれ保存し、ブラウザーで開いて見出しを比べます。
実務でも、案内と詳しい説明を別のページに分けます。

## うまくいかないとき

### 元のページまで変わってしまった

編集しているタブの名前と保存先を確かめます。
新しいファイルを別の名前で作ったか確認します。

### HTML が文章として開く

ファイル名の末尾が `.html` か確かめます。
保存後に、そのファイルをブラウザーで開き直します。

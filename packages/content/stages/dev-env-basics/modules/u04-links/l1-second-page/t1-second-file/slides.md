# トップページを残したまま、自己紹介のページも作りたくなりました

トップページを残したまま、自己紹介のページも作りたくなりました。
同じ index.html を書き換えると、元の内容が変わってしまいます。

<!-- ノート: 元のファイルに上書きすると、トップページの内容が失われます。二つの内容を別々に持つ必要があります。 -->

---

# 覚えること

2つ目のページは、別の名前の HTML ファイルとして作ります。

ページごとに、別の HTML ファイルを用意します。

<!-- ノート: 別のページは、別の名前の HTML ファイルにします。同じフォルダーに並べて置けます。 -->

---

# 画面で確かめる

同じフォルダーに、2つのファイルを置きます。

| ファイル名 | 内容 |
| --- | --- |
| index.html | トップページ |
| about.html | 自己紹介 |

<!-- ノート: index.html を残して about.html を新しく作ります。それぞれのタブで本文を読み分けてください。 -->

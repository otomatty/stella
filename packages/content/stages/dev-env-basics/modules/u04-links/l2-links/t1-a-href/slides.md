# トップページと自己紹介を作りました

トップページと自己紹介を作りました。
読む人が、トップページの文字を押して移動できるようにしたいです。

<!-- ノート: 二枚のページがあっても、ファイル名を知らない人は移動に困ります。押せる文字から相手を開けるようにします。 -->

---

# 覚えること

a 要素の href に、開きたいファイルの場所を書きます。

リンクは、押すと別の場所へ移動する仕組みです。
`href` は、a 要素に移動先を指定する属性です。
属性は、開始タグに書く追加の情報です。

<!-- ノート: a 要素はリンクを作ります。移動先の場所は、開始タグの href に書きます。 -->

---

# 画面で確かめる

```html
<a href="about.html">自己紹介</a>
```

「自己紹介」が、押せる文字として表示されます。

<!-- ノート: 引用符の中が開く場所、タグの間が画面の文字です。保存したあと、文字を押して確かめてください。 -->

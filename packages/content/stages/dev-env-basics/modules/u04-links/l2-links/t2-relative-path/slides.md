# 4-2-2 今の場所からたどる

# 自己紹介を pages フォルダーへ移したら、前のリンクで開けなくなりました

自己紹介を pages フォルダーへ移したら、前のリンクで開けなくなりました。
移動先の場所をどう書き直すか、位置を見比べます。

<!-- ノート: 相手の名前が同じでも、置くフォルダーが変わると道順も変わります。名前だけを比べないようにします。 -->

---

# 覚えること

相対パスは、今のファイルから見た相手の場所です。

相対パスは、今のファイルがあるフォルダーを基準にします。

<!-- ノート: 相対パスの基準は、リンクを書いたファイルの場所です。学習フォルダーの一番上から数えるわけではありません。 -->

---

# 画面で確かめる

| 相手の位置 | href の値 |
| --- | --- |
| 同じフォルダー | about.html |
| 下の pages の中 | pages/about.html |
| 1つ上のフォルダー | ../index.html |

<!-- ノート: 下へ入るときはフォルダー名を添え、上へ戻るときは二つの点を使います。表の三つを順に読んでください。 -->

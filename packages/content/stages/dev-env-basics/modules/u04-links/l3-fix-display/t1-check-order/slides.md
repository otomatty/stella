# 4-3-1 保存・名前・場所の順

# 見出しを変えたのに前のままで、リンク先も開きません

見出しを変えたのに前のままで、リンク先も開きません。
あちこち直す前に、何から見ればよいでしょうか。

<!-- ノート: 理由が分からないまま書き換えると、どの変更が効いたか分かりにくくなります。保存から一つずつ調べます。 -->

---

# 覚えること

表示がおかしいときは、保存・ファイル名・場所の順に確かめます。

確かめる順番を決めると、同じ操作を繰り返さずに済みます。

<!-- ノート: 保存、ファイル名、場所の順で確認します。見た結果を次の判断の手がかりにします。 -->

---

# 画面で確かめる

1. 「ファイル > 保存」のあと、ブラウザーを再読み込みします。
2. `index.html.txt` など、ファイル名の末尾まで読みます。
3. パンくずリストで、編集した場所を照合します。

<!-- ノート: まず保存して表示を読み直し、次に名前、最後に場所を見ます。確認した内容を短く控えておくと相談にも使えます。 -->

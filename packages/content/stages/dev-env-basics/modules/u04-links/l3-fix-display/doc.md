# レッスン4-3 表示がおかしいときの確かめ方

## このレッスンの目標

- [ ] 保存・名前・場所を順に確認できます。
- [ ] 困った状態と試したことを課題から相談できます。

## 4-3-1 保存・名前・場所の順

> **表示がおかしいときは、保存・ファイル名・場所の順に確かめます。**

実務でも、表示が想定と違うときは確認の順を決めます。
まず「ファイル > 保存」を選び、ブラウザーを再読み込みします。
タブの「●」は、保存していない変更の印です。
次に、ファイル名と拡張子を最後まで読みます。
最後に、パンくずリストと表示しているファイルの場所を照合します。
一度に複数の場所を変えず、一つずつ確かめます。

修正課題は、起きている問題の手がかりから原因を探す課題です。
基礎課題で使った操作を組み合わせ、直す場所を判断します。
提出するときは、原因・直したこと・確かめた結果を修正記録に書きます。

## 4-3-2 講師に相談する

> **通らないまま困ったら、課題から講師に相談できます。**

課題文のパネルの「講師に相談」から送れます。
手元の確認が通らない状態でも使えます。
何をしようとしたか、どこまでできたかを書きます。
実行した操作と、表示されたメッセージも添えます。
不要な個人情報や認証情報は含めません。
実務でも、試したことが分かる相談は調査の助けになります。

### ヒントのあとの解答例

この単元の接続課題は、ヒントを最後まで開くと解答例を開けます。
修正課題は、ヒントの後でもすぐには解答例が開きません。
手元の確認の失敗と提出を合わせて5回挑戦した後か、合格後に開けます。
環境のエラーは、この挑戦の回数に入りません。
解答例を見たら、自分のファイルとの違いを読んで確かめます。

### 類題で確かめる

類題は、合格した課題と同じパターンの別の問題です。
日を空けて「今日の復習」に出るので、新しい題材で試します。

## うまくいかないとき

### 見直しても手元の確認が通らない

通らなかった項目のメッセージを読みます。
保存・名前・場所で何を調べたかを控え、課題から相談します。

### 相談に何を書けばよいか分からない

「したいこと」「できたこと」「試した操作」「出たメッセージ」の順に書きます。
メッセージが無ければ、そのことと今の画面の状態を伝えます。

# レビューの観点

- index.html のリンクが events/session.html を開く
- events/session.html のリンクが index.html を開く
- 両方のページの見出しと名前が配布時のまま残っている

操作した事実は、提出ファイルだけから推測しません。
ヒントや解答例を開いたこと自体は、不合格の理由にしません。

## よくある違反

- 課題フォルダーの一番上を基準に書いている。リンクを書くファイルの場所からたどるよう返します。
- 自分自身へのリンクだけで済ませている。指定した相手のパスを示します。
- 片方向しかリンクが無い。行き帰りの両方を確かめるよう返します。

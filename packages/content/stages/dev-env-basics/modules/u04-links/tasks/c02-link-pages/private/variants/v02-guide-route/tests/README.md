# 手元の確認

「課題を確認する」を押すと、次を確かめます。

- `guide/index.html` の `a` が 1 つ以上ある
- `guide/index.html` のリンク先のファイルが、課題フォルダーの中にある
- `guide/forms/entry.html` の `a` が 1 つ以上ある
- `guide/forms/entry.html` のリンク先のファイルが、課題フォルダーの中にある

手元では、課題フォルダー内のファイルへのリンク先があるかだけを確認し、ページ内・外部 URL・行き先のないリンクは確かめません。
相手のページが開くことは、ブラウザーでリンクを押して自分で確かめます。

このフォルダーのファイルは編集しないでください。

# レビューの観点

links-resolve はリンク先の存在を見るだけなので、リンクが指定の相手を指しているかをレビューする。
自分自身へ飛ぶリンクだけでは条件を満たさない。
表示を確かめたかは、説明に書かれた内容だけで判断する。本当に表示したかは推測しない。
説明の移動先が、指定した相手と違うときは、どのリンクがどこを指すべきかを指摘する。

- index.html のリンクが pages/about.html を開く
- pages/about.html のリンクが1つ上の index.html を開く
- 提出の説明に、開いたページと、リンクを押して移った先が書かれている

## よくある違反

- 両方のページが自分自身を指している、または片方向しかない。どちらのリンクがどのファイルを指すべきかを返す。
- `pages/about.html` を `about.html` と書いたり、戻るリンクに上へたどる書き方を忘れたりしている。今のファイルからの相対の書き方を示して返す。
- 説明に、開いたページやリンクを押して移った先が無い。何を書くかを示し、表示したとは推測しない。

# 2つのページをリンクでつなぐ

## 何をするか

配られた2つのページに、行き帰りのリンクを加えます。
`index.html` からは `pages/about.html` を開けるようにします。
自己紹介からは、1つ上の `index.html` へ戻れるようにします。
各ページに a 要素のリンクを1つ以上置き、見出しは残します。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. 2つのページの位置を、エクスプローラーで確かめます。
3. それぞれのページに、相手へ移動するリンクを加えます。
4. 保存後にトップページをブラウザーで開き、行き帰りのリンクを押します。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. すべて通ったら提出し、届いたレビューの結果を読みます。

提出の説明の「確認したこと」に、次の2つを書きます。

- 開いたページ。
- リンクを押して移った先。

## うまくいかないとき

リンクを書くファイルの場所を出発点にします。
下のフォルダーから戻るときは、上へたどる必要がないか確かめます。

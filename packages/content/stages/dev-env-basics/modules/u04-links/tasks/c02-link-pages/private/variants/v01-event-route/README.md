# 催しの案内へ行って戻る

## 何をするか

配られた `index.html` と `events/session.html` をリンクでつなぎます。
ファイルを扱う練習で覚えた、フォルダーの位置の読み方を使います。
`index.html` に「読書会の案内」のリンクを置きます。
リンクを押すと `events/session.html` が開くようにします。
`events/session.html` には「催しの一覧へ」のリンクを置き、
`index.html` へ戻れるようにします。
各ページに `a` を1つ以上置きます。
ページの名前と見出しは変えません。
保存後は `index.html` をブラウザーで開き、行き帰りを確かめます。
手元ではリンクの数と、リンク先のファイルがあるかを確かめます。
指定の相手へ移るかは、提出後のレビューでも確かめます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
すべて通ったら提出し、届いたレビューの結果を読みます。

# 案内ページから申込先へ進む

## 何をするか

配られた `guide/index.html` と `guide/forms/entry.html` をリンクでつなぎます。
ファイルを扱う練習で覚えた、フォルダーの位置の読み方を使います。
`guide/index.html` に「申込の案内」のリンクを置きます。
リンクを押すと `guide/forms/entry.html` が開くようにします。
`guide/forms/entry.html` には「参加の案内へ」のリンクを置き、
`guide/index.html` へ戻れるようにします。
各ページに `a` を1つ以上置きます。
ページの名前と見出しは変えません。
保存後は `guide/index.html` をブラウザーで開き、行き帰りを確かめます。
手元ではリンクの数と、リンク先のファイルがあるかを確かめます。
指定の相手へ移るかは、提出後のレビューでも確かめます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
すべて通ったら提出し、届いたレビューの結果を読みます。

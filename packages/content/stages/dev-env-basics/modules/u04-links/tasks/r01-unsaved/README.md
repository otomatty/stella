# 直したはずの見出しが出ない

## 何をするか

見出しを「お知らせ」から「新着情報」に変えたのに、ブラウザーが前のままです。
作業中の VS Code のタブには「●」がありました。
「●」は、保存していない変更の印です。
配布したファイルは、保存されている「お知らせ」の状態です。
見出しが「新着情報」と表示される状態に直してください。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. 配布されたページを開き、今の見出しとタブを見ます。
3. 状況の手がかりを使い、表示に届く状態に直します。
4. ブラウザーでページを開き、再読み込みして結果を確かめます。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. 通ったら、原因・直したこと・確かめた結果を修正記録に書いて提出します。

## うまくいかないとき

タブの印と、ファイルに残った内容を分けて考えます。
ブラウザーの更新だけで、編集中の文字まで残るか確かめましょう。

見直しても通らなければ、課題文のパネルの「講師に相談」を使えます。
何をしようとしたか・どこまでできたかを伝えます。
試した操作と出たメッセージも添え、確認が通らない状態のまま相談できます。

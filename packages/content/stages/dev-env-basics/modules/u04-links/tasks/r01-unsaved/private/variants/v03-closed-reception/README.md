# 受付終了の表示に切り替わらない

## 何をするか

受付時間が終わり、見出しを「本日の受付は終了しました」にする予定です。
配られたページを開くと、本文にはまだ「受付中」と出ます。
保存されたファイルを調べ、予定の見出しが出るように直します。
ほかの要素は変えません。
直す前の表示と、保存後に再読み込みした表示を比べます。
修正記録の「修正後に確かめたこと」に、
開いたファイルと、表示された見出しを書きます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
通ったら、原因・直したこと・確かめた結果を修正記録に書いて提出します。

# レビューの観点

保存された見出しと、修正記録の保存・再読み込みの理解を見る。未保存の状態そのものは配布・自動検査できない。
表示を確かめたかは、修正記録の回帰確認（画面の「修正後に確かめたこと」）に書かれた内容だけで判断する。本当に表示したかは推測しない。
記録した見出しが「新着情報」と違うときは、違う文字を指摘する。

- index.html の保存された h1 が「新着情報」になっている
- 修正記録の「修正後に確かめたこと」に、ブラウザーで開いたファイルと、表示された見出しが書かれている

## よくある違反

- 見出しは直したが、保存しないまま提出している。タブの印と、ファイルに残った文字を分けて確かめ、保存してから出すよう返す。
- 「新着情報」の一部だけを変えている、または前後の空白が残っている。指定と違う文字を示して返す。
- 「修正後に確かめたこと」に、開いたファイルや表示された見出しが無い。何を書くかを示し、表示したとは推測しない。

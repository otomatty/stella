# レビューの観点

- index.html から venues/hall.html を開き、そこから index.html へ戻れる
- ファイルの名前・場所・見出し・リンクの文字を変えず、戻るリンクの行き先だけを直している
- 修正記録の「修正後に確かめたこと」に、開いたページと行き帰りの移動先が書かれている

修正記録に再現・原因・修正・回帰確認があるかを読みます。
操作した事実は、提出ファイルだけから推測しません。
ヒントや解答例を開いたこと自体は、不合格の理由にしません。

## よくある違反

- 戻るリンクに上へ戻る記号が無い。出発点と一覧の位置を比べるよう返します。
- 新しい一覧を venues に追加している。元の index.html へ戻すよう返します。
- リンクを削除したり、自分自身を指したりしている。戻る相手を示します。

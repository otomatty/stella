# リンクを押すとページが無いと言われる

## 何をするか

トップページの「自己紹介」を押すと、ページが無いと言われます。
配られたファイルを調べ、リンクを押して自己紹介を開けるように直します。
`about.html` は名前を変えずに残してください。
本文や見出しは変えず、リンク側を直します。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. トップページのリンクを押し、起きる問題を確かめます。
3. リンクに書いた場所と、一覧にあるファイル名を照合します。
4. 必要な箇所を直し、保存後にリンクを押して確かめます。
5. 「ファイル > すべて保存」を選びます。
6. 「課題を確認する」で、通らなかった項目を読みます。
7. 通ったら、原因・直したこと・確かめた結果を修正記録に書いて提出します。

## うまくいかないとき

画面に見える「自己紹介」と、移動先を表す文字は別です。
ファイル名の綴りを、1文字ずつ見比べます。

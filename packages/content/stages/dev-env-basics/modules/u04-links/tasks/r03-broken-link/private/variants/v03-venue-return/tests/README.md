# 手元の確認

「課題を確認する」を押すと、次を確かめます。

- `index.html` のリンク先のファイルが、課題フォルダーの中にある
- `index.html` の `a` が 1 つ以上ある
- `venues/hall.html` のリンク先のファイルが、課題フォルダーの中にある
- `venues/hall.html` の `a` が 1 つ以上ある
- `index.html` がある
- `venues/hall.html` がある

手元では、課題フォルダー内のファイルへのリンク先があるかだけを確認し、ページ内・外部 URL・行き先のないリンクは確かめません。
相手のページが開くことは、ブラウザーでリンクを押して自分で確かめます。

このフォルダーのファイルは編集しないでください。

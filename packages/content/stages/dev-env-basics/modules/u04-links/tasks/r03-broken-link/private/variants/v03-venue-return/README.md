# 会場の案内から一覧に戻れない

## 何をするか

`index.html` の「集会室の案内」は開けます。
その先で「会場の一覧へ」を押すと、ページが無いと言われます。
配られたファイルを調べ、一覧へ戻れるように直します。
名前・場所・見出し・リンクの文字は変えません。
ファイルを追加せず、戻るリンクの行き先だけを直します。
最初に症状を確かめ、修正後に行き帰りを試します。
修正記録の「修正後に確かめたこと」に、
開いたページと行き帰りの移動先を書きます。
手元ではリンク先の存在を、レビューでは指定の移動先も確かめます。

## 進め方

この課題の「VS Code で開く」で課題フォルダーを開きます。
編集したら「ファイル > すべて保存」を選びます。
「課題を確認する」で、通らなかった項目を読みます。
通ったら、原因・直したこと・確かめた結果を修正記録に書いて提出します。

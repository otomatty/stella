# レビューの観点

リンク削除や自己リンクで逃げていないか、href が指定のページを指すかを確認する。
about.html を変更していないか、修正記録が綴りの違いを説明しているかも読む。
表示を確かめたかは、修正記録の回帰確認（画面の「修正後に確かめたこと」）に書かれた内容だけで判断する。本当に表示したかは推測しない。
記録した移動先が about.html と違うときは、どのリンクがどこを指すべきかを指摘する。

- index.html のリンクが about.html を指している
- about.html の名前と内容を変えずに残している
- 修正記録の「修正後に確かめたこと」に、開いたページと、リンクを押して移った先が書かれている

## よくある違反

- リンク先の綴りが `about.html` と1文字違うまま残っている。違う文字を示し、ファイル名とそろえるよう返す。
- ページが無いのを避けるため、リンクを消している、または自分自身を指している。`about.html` を指すよう返す。
- 「修正後に確かめたこと」に、開いたページやリンクを押して移った先が無い。何を書くかを示し、表示したとは推測しない。

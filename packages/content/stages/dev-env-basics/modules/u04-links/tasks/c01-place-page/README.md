# フォルダーの中にページを置く

## 何をするか

課題フォルダーの中の `pages` に `about.html` を作ります。
HTML の文書にし、見出しは「自己紹介」にします。
配られた `index.html` は残します。

## 手順

1. この課題の「VS Code で開く」で課題フォルダーを開きます。
2. 課題フォルダーを右クリックし、「新しいフォルダー」で pages を作ります。
3. 作ったフォルダーの中に、指定の HTML ファイルを作ります。
4. 文書の枠組みと見出しを書き、パンくずリストで場所を読みます。
5. 保存し、新しいページをブラウザーで開いて見出しを確かめます。
6. 「ファイル > すべて保存」を選びます。
7. 「課題を確認する」で、通らなかった項目を読みます。
8. すべて通ったら提出し、届いたレビューの結果を読みます。

## うまくいかないとき

ファイルの名前だけでなく、置いたフォルダーも確認します。
文書の形は U02 のまとめを参照できます。

# STELLAの使い方

新カリキュラムの M01 に対応し、予定時間は2.5時間です。3単元、8トピック、課題1つの草稿がそろっています。参照元と本文は講師の承認待ちです。

2026-11-19 のオーナー決定で、このステージを STELLA の使い方に絞りました。旧 U03「ファイルとフォルダーの操作」と U04「確認A・確認B」は、次のステージ `html-css-basics` の冒頭に移しました。

## 到達目標

STELLA で学ぶ流れを知り、VS Code と STELLA 拡張を準備します。Web から最初の課題を開き、ファイルを編集・保存してブラウザーで表示し、手元で確認して提出します。提出後は結果を読みます。

## 前提ステージ

なし。Basic の入口です。

## 単元構成

| 単元 | フォルダー名 | 題 | 時間 | ログイン前に読める |
| --- | --- | --- | ---: | --- |
| U00 | `u00-start` | STELLAで学ぶ流れ | 0.5 | ○ |
| U01 | `u01-vscode-setup` | VS CodeとSTELLA拡張の準備 | 1 | ○ |
| U02 | `u02-first-task` | はじめての課題を出す | 1 | × |
| 合計 | | | 2.5 | |

U02 の課題は「最初のページを作る」(`dev-env-basics/u02-first-task/q01-first-page`、`basic`) です。修了は全レッスンの完了と課題の合格で判定します。

## 後続ステージへの引き継ぎ

VS Code と STELLA 拡張、学習フォルダー `web-training`、編集・保存・表示と確認・提出の経験を引き継ぎます。新しいファイルの作成、名前の変更、保存先の確認と確認A・Bは、[HTML/CSSとデザイン基礎](../html-css-basics/CURRICULUM.md)で扱います。

## 執筆時の扱い

format 2 を使います。OS で異なる手順は `:::os` で分け、OS 別の PDF を配布します。U02 のトピック ID は `0-1-*` です。8トピックすべてに台本があり、U02 の t1・t3 は収録済みの動画を使います。

教材の書き方は [ADDING_STAGE.md](../../ADDING_STAGE.md) を参照してください。

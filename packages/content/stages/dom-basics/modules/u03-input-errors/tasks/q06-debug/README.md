# 備品貸出フォームの不具合を直す

- 空欄のまま送信してから、たとえば備品名に「三脚」を入力しても、その欄のエラーが残ります。
- 有効な入力で送信するとページが再読み込みされ、完了の表示が残りません。
- 無効な入力のまま送信を繰り返すと、同じエラー文が重なって表示されます。

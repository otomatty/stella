# 工作教室の参加費を表示する

「計算する」を押すと、工作教室の参加費を表示します。参加者には材料セットが 1 つ付きます。参加費は、追加分も含めて材料セット 1 つにつき 480 円です。「追加する材料セットの数」には 0 以上の整数が入ります。

- 2 と入力すると「参加費は1440円です。」と表示します。
- 0 と入力すると「参加費は480円です。」と表示します。
- 空欄で送信したら参加費の表示を消します。
- 送信してもページは再読み込みしません。

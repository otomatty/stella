# レビューの観点

- 送信時点の値を読み、数量を Number で数値に変換している。会員は checked を読んでいる。
- ユーザーの入力を表示するときは textContent を使い、innerHTML を使っていない。
- 各フォームの submit で既定の送信を止め、そのフォームの出力のみを更新している。

## よくある違反

- value を数値に変換せずに計算している。掛け算で暗黙に変換されても、型が処理から読み取れません。変換してから空欄を調べると 0 と区別できません。
- preventDefault を忘れると表示を更新した直後に画面が遷移します。innerHTML に入力を渡すと、入力が HTML として解釈されます。

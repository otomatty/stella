# 入力を読んで表示を更新する

6 つのフォームから、入力欄の種類に応じて値を読み、同じ画面に結果を出します。

## 画面と関数の仕様

`src/inputs.js` の `setupInputs(root)` を完成させます。最初に呼ばれると、`root` の中にある各フォームに `submit` の処理を登録します。各フォームでブラウザーの送信を止め、その時点の入力を読み取って、そのフォームの `output` だけを `textContent` で更新します。最初はすべての出力欄が空です。HTML のエラー用の段落は、この課題では空のままです。

| 問 | 入力と操作 | 表示する内容 | 例 |
| --- | --- | --- | --- |
| 1 | 名前を入力して「あいさつを表示」 | 前後の空白を除いた名前を `こんにちは、〈名前〉さん。` に入れます。空なら表示を空にします。 | `"  山田 太郎  "` → `こんにちは、山田 太郎さん。` |
| 2 | メッセージを入力して「残り文字数を確認」 | 上限は 10 文字です。`length` で数え、空白も 1 文字に含めます。残りを `あと N 文字` と表示し、上限以上では残りを 0 にします。 | `"abc"` → `あと 7 文字`、空欄 → `あと 10 文字` |
| 3 | 数量を入力して「合計を計算」 | 250 円に数値に変換した数量を掛け、`合計 N 円` と表示します。数量は 0 以上の整数か空欄とし、空欄なら表示を空にします。 | `"2"` → `合計 500 円` |
| 4 | 備考を入力して「備考を確認」 | 前後の空白を除いた備考を表示します。空欄や空白だけで確かめ直すと前の表示が消えます。 | `"  午後に受取  "` → `午後に受取` |
| 5 | 会員を選んで「会員区分を確認」 | チェックがあれば `会員`、なければ `非会員` と表示します。 | チェックを外す → `非会員` |
| 6 | 受取方法を選んで「受取方法を確認」 | 選択肢の `value` を表示します。未選択の `value` は空文字です。 | 「店頭で受け取る」 → `店頭` |

## 確かめ方

1. VS Code のコマンドパレットで「STELLA: 課題を確認する」を実行します。
2. テストが落ちたら、失敗した入力と期待される結果を見比べます。
3. 修正したらもう一度確認し、すべて通ったら提出します。

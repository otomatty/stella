# 検証関数でエラー文を返す

登録フォームの入力を確かめるため、値を受け取ってエラー文を返す関数を 6 つ作ります。

## 画面と関数の仕様

編集するのは `src/validators.js` です。すべての引数は文字列です。各関数は、問題がなければ空文字 `""`、問題があれば表にあるエラー文を返します。検証関数の中で画面の要素を取得・更新しません。関数名と引数は starter のまま使います。

`index.html` には「名前」の必須検証を試す小さなフォームがあります。「必須入力を確認」を押すと、画面が `validateRequired` の戻り値を受け取って表示します。ほかの検証はテストで直接確かめます。

| 関数 | 問題がない条件 | エラー文 | 例 |
| --- | --- | --- | --- |
| `validateRequired(value)` | 前後の空白を除いた値が空でない | 入力してください。 | `"   "` → エラー |
| `validateLength(value)` | `length` が 10 以下。空欄でもよく、空白は 1 文字に数える | 10文字以内で入力してください。 | `"0123456789"` → `""` |
| `validateQuantity(value)` | 空欄や空白だけの入力を除き、数値に変換した値が 1〜10 の整数 | 数量は1〜10の整数で入力してください。 | `" 10 "` → `""`、`"10.5"` → エラー |
| `validateEmail(value)` | `@` を含む。この課題ではこの条件だけを調べる | メールアドレスに@を含めてください。 | `"a@example.com"` → `""` |
| `validateConfirmation(value, confirmation)` | 大小文字や空白も含めて完全に一致する。両方が空なら一致する | 確認用の入力が一致しません。 | `"AB", "ab"` → エラー |
| `validatePostalCode(value)` | 先頭の 0 を含め、半角数字がちょうど 7 桁続く。空白やハイフンは含めない | 郵便番号は半角数字7桁で入力してください。 | `"0123456"` → `""`、`"012-3456"` → エラー |

## 確かめ方

1. VS Code のコマンドパレットで「STELLA: 課題を確認する」を実行します。
2. テストが落ちたら、失敗した入力と期待される結果を見比べます。
3. 修正したらもう一度確認し、すべて通ったら提出します。

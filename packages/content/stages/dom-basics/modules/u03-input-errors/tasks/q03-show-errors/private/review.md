# レビューの観点

- submit で preventDefault を呼び、全項目を検証する。
- 値を受け取ってエラー文か空文字を返す処理と、表示を更新する処理を分けている。
- 段落の textContent を置き換える。エラー文が空なら aria-invalid を外すか false にする。

## よくある違反

- ボタンの click だけを扱う、または preventDefault を忘れる。送信の経路によって検証を通らなかったり画面が遷移したりします。
- エラー用の段落に文を追加し続ける。修正した後も文や aria-invalid を残す。別の欄のエラーまで一緒に消す。
- 入力を加工せずに人数の比較をする。ユーザー入力を innerHTML に入れる。

# 登録フォームにエラーを表示する

登録フォームで、どの欄をどう直せばよいかを伝えます。入力を直したら、その欄を再検証して古いエラーを消します。

## 画面と関数の仕様

`src/registration.js` の `setupRegistration(root)` を完成させます。呼ばれたら `root` の中の要素を取り、フォームの `submit` と各欄の `input` の処理を登録します。検証は、入力の値からエラー文か空文字を返す関数に分けます。検証関数の名前は自由です。

| 入力欄 | 問題がない条件 | エラー文 |
| --- | --- | --- |
| 名前 | 前後の空白を除くと空でない | 名前を入力してください。 |
| メールアドレス | `@` を含む | メールアドレスに@を含めてください。 |
| 人数 | 空欄ではなく、数値に変換した値が 1〜10 の整数 | 人数は1〜10の整数で入力してください。 |

1. 「登録する」で送信したら、ブラウザーの送信を止め、3 つの欄をすべて検証します。各エラー文は入力欄の直後にある段落の `textContent` に設定し、文がある欄は `aria-invalid="true"` にします。段落と入力欄を結ぶ `aria-describedby` は HTML で設定済みです。
2. すべての欄に問題がなければ、登録結果に `登録が完了しました。` と表示します。問題があれば登録結果は空にします。登録はこの画面上で完結します。
3. すでにエラーが出ている欄を編集したら、その欄だけ再検証します。問題がなくなったら、その欄のエラー文と `aria-invalid` を消します（属性値を `false` にしても構いません）。まだ問題があれば表示を残します。エラーが出ていない欄の編集では新しくエラーを出しません。どの欄を編集しても、前の登録結果は消します。

たとえば、名前に空白だけを入力して送信すると「名前を入力してください。」が出ます。「佐藤」と入力し直すと、名前欄のエラーだけが消えます。メールを `sato@example.com`、人数を `10` にして送信すると、登録完了の文が出ます。

## 確かめ方

1. VS Code のコマンドパレットで「STELLA: 課題を確認する」を実行します。
2. テストが落ちたら、失敗した入力と期待される結果を見比べます。
3. 修正したらもう一度確認し、すべて通ったら提出します。

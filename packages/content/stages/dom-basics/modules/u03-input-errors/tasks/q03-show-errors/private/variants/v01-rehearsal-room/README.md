# 練習室の利用申込

練習室の利用申込フォームで、団体名と利用時間を確認します。

| 入力欄 | 有効な入力 | エラー文 |
| --- | --- | --- |
| 団体名 | 前後の空白を除いて 1 文字以上 | 団体名を入力してください。 |
| 利用時間 | 1〜4 時間の整数 | 利用時間は1〜4時間の整数で入力してください。 |

- 「利用を申し込む」で各欄を確認します。送信してもページは移動・再読み込みしません。
- 無効な欄には対応するエラー文を 1 回だけ表示し、その欄を `aria-invalid="true"` にします。入力欄とエラー欄の対応は `aria-describedby` で保ちます。
- エラーの出ている欄を編集したら、その欄をもう一度確認します。有効になった欄のエラー文と無効の印を消します。送信するまでは、エラーの出ていない欄に新しいエラーを出しません。
- 全欄が有効な状態で送信したときだけ「利用申込を受け付けました。」を表示します。その後、どれかの欄を編集すると完了の表示を消します。

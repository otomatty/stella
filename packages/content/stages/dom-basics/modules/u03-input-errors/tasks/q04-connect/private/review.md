# レビューの観点

- 数値に変換した数量が 1〜99 の整数であることを確かめ、会員の状態は checked で読む。
- 会員割引を税より先に適用し、税の端数を切り捨て、税込みの金額で送料を決める。
- submit で preventDefault を呼び、エラーと合計を textContent で更新する。数量が有効になったらエラーの文と無効状態を消す。

## よくある違反

- value を数値に変換せず使ったり、会員かどうかをチェックボックスの value で判定したりする。
- 会員割引に税込みの金額を使う。税を四捨五入する。送料を割引前の小計で決める。
- preventDefault を忘れる、エラーを消さない、無効な注文でも前の合計を残す、表示にユーザー入力を innerHTML で入れる。

# 注文フォームで合計を表示する

JavaScript の単元「比較と条件の組合せ」の課題「注文の合計を計算する」で使った条件を、注文フォームにつなぎます。以前に書いた `src/order.js` を見返し、割引・税・送料の計算を今回のファイルで使います。

## 画面と関数の仕様

`src/order.js` の `setupOrder(root)` を完成させます。呼ばれたら、`root` の中にある要素を取得してフォームの `submit` と入力欄の `input` の処理を登録します。計算を関数に分ける場合は、同じファイルに書けます。

- 「合計を確認」で送信したら、ブラウザーの送信を止めます。数量は空欄や空白だけではなく、数値に変換した値が 1〜99 の整数なら有効です。会員欄はチェックが付いていれば会員です。
- 数量が無効なら、欄の直後に `数量は1〜99の整数で入力してください。` と表示し、数量欄を `aria-invalid="true"` にして、前の合計があれば消します。有効なら、エラー文と `aria-invalid` を消し（属性値を `false` にしても構いません）、`合計 N 円` の形で支払う合計を表示します。表示する数値に桁区切りは入れません。
- 数量欄に出ているエラーは、入力を直して有効になった時点で消します。数量や会員欄を編集すると前の合計が消え、次に送信した時点で新しい合計が出ます。数量欄の `aria-describedby` は HTML で設定済みです。

## 支払う合計の計算

1. 単価 1,364 円に数量を掛けて小計を出します。
2. 会員で、かつ小計が 3,000 円以上なら、小計から 300 円引きます。
3. 割引後の小計に税率 10% を掛け、税の 1 円未満を切り捨てます。求めた税を割引後の小計に足します。
4. 税込みの金額が 3,000 円以上なら送料は 0 円、未満なら 600 円です。税込みの金額に送料を足します。

| 数量 | 会員 | 表示 |
| --- | --- | --- |
| 0 | チェックなし | 数量は1〜99の整数で入力してください。 |
| 1 | チェックあり | 合計 2100 円 |
| 2 | チェックあり | 合計 3000 円 |
| 3 | チェックあり | 合計 4171 円 |

## 確かめ方

1. VS Code のコマンドパレットで「STELLA: 課題を確認する」を実行します。
2. テストが落ちたら、失敗した入力と期待される結果を見比べます。
3. 修正したらもう一度確認し、すべて通ったら提出します。

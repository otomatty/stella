# 確認B 予約の変更フォーム

予約の変更フォームを完成させてください。

公式ドキュメント (MDN) と文法の参照はしてよいです。ヒント・AI チャットは使えません。

| 入力欄 | 有効な入力 | エラー文 |
| --- | --- | --- |
| 人数 | 2〜8 の整数 | 人数は2〜8の整数で入力してください。 |
| 変更後の日付 | 空欄でない日付 | 変更後の日付を入力してください。 |
| 変更理由 | 前後の空白を除いて 5〜60 文字 | 変更理由は5〜60文字で入力してください。 |

- 「変更する」で各欄を確認します。送信してもページは移動・再読み込みしません。
- 無効な欄には対応するエラー文を 1 回だけ表示し、その欄を `aria-invalid="true"` にします。入力欄とエラー欄の対応は `aria-describedby` で保ちます。
- エラーの出ている欄を編集したら、その欄をもう一度確認します。有効になった欄のエラー文と無効の印を消します。送信するまでは、エラーの出ていない欄に新しいエラーを出しません。
- 全欄が有効な状態で送信したときだけ「予約の変更を受け付けました。」を表示します。その後、どれかの欄を編集すると完了の表示を消します。

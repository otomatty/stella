# イベントの参加申込フォーム

イベントの参加申込フォームで、入力に応じて次のように画面が変わるようにしてください。

| 入力欄 | 有効な入力 | エラー文 |
| --- | --- | --- |
| 人数 | 1〜20 の整数 | 人数は1〜20の整数で入力してください。 |
| 参加日 | 空欄でない日付 | 参加日を入力してください。 |
| 連絡先 | 前後の空白を除いたあと、`@` を含むメールアドレス、または半角数字だけで 10〜11 桁の電話番号 | 連絡先はメールアドレスか10〜11桁の電話番号を入力してください。 |

- 「申し込む」で各欄を確認します。送信してもページは移動・再読み込みしません。
- 無効な欄には対応するエラー文を 1 回だけ表示し、その欄を `aria-invalid="true"` にします。入力欄とエラー欄の対応は `aria-describedby` で保ちます。
- エラーの出ている欄を編集したら、その欄をもう一度確認します。有効になった欄のエラー文と無効の印を消します。送信するまでは、エラーの出ていない欄に新しいエラーを出しません。
- 全欄が有効な状態で送信したときだけ「参加申込を受け付けました。」を表示します。その後、どれかの欄を編集すると完了の表示を消します。

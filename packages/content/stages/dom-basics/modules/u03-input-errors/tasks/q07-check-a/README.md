# 確認A 問い合わせフォーム

問い合わせフォームを完成させてください。

公式ドキュメント (MDN) と文法の参照はしてよいです。ヒント・AI チャットは使えません。

| 入力欄 | 有効な入力 | エラー文 |
| --- | --- | --- |
| 件名 | 前後の空白を除いて 1〜30 文字 | 件名は1〜30文字で入力してください。 |
| 本文 | 前後の空白を除いて 10〜100 文字 | 本文は10〜100文字で入力してください。 |
| 返信先 | `@` を含む | 返信先に@を含めてください。 |

- 「送信する」で各欄を確認します。送信してもページは移動・再読み込みしません。
- 無効な欄には対応するエラー文を 1 回だけ表示し、その欄を `aria-invalid="true"` にします。入力欄とエラー欄の対応は `aria-describedby` で保ちます。
- エラーの出ている欄を編集したら、その欄をもう一度確認します。有効になった欄のエラー文と無効の印を消します。送信するまでは、エラーの出ていない欄に新しいエラーを出しません。
- 全欄が有効な状態で送信したときだけ「問い合わせを受け付けました。」を表示します。その後、どれかの欄を編集すると完了の表示を消します。

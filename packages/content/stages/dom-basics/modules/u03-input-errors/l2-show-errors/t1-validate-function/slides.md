# 3-2-1 検証を関数に分ける

# 空欄のまま登録しようとする

名前欄に何も書かずに登録しようとしたときは、名前の入力を促します。入力を確かめる処理だけを試すには、どう分ければよいでしょうか。

<!-- ノート: 入力の判定を切り出せれば、空欄や空白だけのときにどんな結果を返すかを、画面を開かずに確かめられます。 -->
---
# 覚えること

検証関数は値を受け取り、直すことがあればエラー文を、問題がなければ空文字を返します。

<!-- ノート: 検証関数は値を受け取り、直すことがあればエラー文を、問題がなければ空文字を返します。 -->
---
# 名前だけを受け取る

```js
export function validateName(name) {
  if (name.trim() !== "") {
    return "";
  }
  return "名前を入力してください。";
}
```

<!-- ノート: 検証は値がルールを満たすか確かめることです。ここでは、名前の前後の空白を除いた結果が空でなければ、エラー文として空文字を返します。空なら、直し方が分かる文を返します。 -->
---
# 値を渡して戻り値を確かめる

```js
console.log(validateName("佐藤")); // => ""
console.log(validateName("   "));  // => 名前を入力してください。
```

<!-- ノート: 画面の要素を関数の中で探さず、入力の文字列を直接渡します。戻り値を期待する文と比べれば、入力の判定だけをテストできます。 -->

# 3-2-2 例外を先に返す

<!-- ノート: 今回のテーマは「例外を先に返す」です。 -->
---
# 受付を止める場合を考える

受付枠が十分でも、窓口が閉まっていれば申し込みは受け付けません。枠を確かめる処理は、どこに置くと読みやすいでしょうか。

<!-- ノート: 受付枠が十分でも、窓口が閉まっていれば申し込みは受け付けません。枠を確かめる処理は、どこに置くと読みやすいでしょうか。 -->
---
# 覚えること

`!` で条件を反転し、例外に当たるときは先に `return` して関数を終えます。

<!-- ノート: `!` で条件を反転し、例外に当たるときは先に `return` して関数を終えます。 -->
---
# 窓口が閉まっていれば先に返す

```js
export function canAcceptRequest(isOpen, slots) {
  if (!isOpen) {
    return false;
  }
  return slots > 0;
}
```

<!-- ノート: isOpen は窓口が開いていれば true です。論理否定の ! は真偽値を反転するので、閉まっているときに !isOpen が true になります。この時点で関数を終える書き方を早期 return と呼びます。 -->
---
# 通常の処理は波括弧の外で読む

`canAcceptRequest(false, 3)` は最初の `return` で終了します。`canAcceptRequest(true, 3)` は `if` の中を通らず、末尾で空き枠を確かめます。

<!-- ノート: 例外で先に返した後は、通常の処理を if の波括弧の外に書けます。最後の行まで来たら、窓口が開いていると分かります。 -->

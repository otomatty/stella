# 3-2-1 条件をつなぐ

<!-- ノート: 今回のテーマは「条件をつなぐ」です。 -->
---
# 通知の送り方を決める

通知を送る時刻にはルールがあります。「平日で、18 時より前なら送る」や「平日または 18 時以降なら送る」のような要件を、どう式にすればよいでしょうか。

<!-- ノート: 通知を送る時刻にはルールがあります。「平日で、18 時より前なら送る」や「平日または 18 時以降なら送る」のような要件を、どう式にすればよいでしょうか。 -->
---
# 覚えること

二つの条件は、どちらも成り立つなら `&&`、少なくともどちらかが成り立つなら `||` でつなぎます。

<!-- ノート: 二つの条件は、どちらも成り立つなら `&&`、少なくともどちらかが成り立つなら `||` でつなぎます。 -->
---
# 平日かつ 18 時より前

```js
export function canSendNotice(isWeekday, hour) {
  return isWeekday && hour < 18;
}
```

<!-- ノート: isWeekday は平日なら true です。右側の比較も真偽値になります。真偽値の条件をつなぐ記号を論理演算子と呼びます。論理積の記号 && は、平日で、かつ時刻が条件を満たすときに true です。 -->
---
# 「または」なら、片方だけでもよい

「平日または 18 時以降なら送る」は `isWeekday || hour >= 18` です。平日の 18 時は両方が成り立つので、この式も `true` になります。

<!-- ノート: 論理和の記号は縦棒を二つ並べます。平日なら時刻に関係なく送れます。休日でも 18 時以降なら送れます。 -->
---

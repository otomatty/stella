# レビューの観点

- 各関数は比較式の真偽値を直接返し、if や三項演算子で真偽値を選び直していない。
- 等しさには === を使い、== や != および商品コードの型変換を使っていない。
- 3,000 円と 18 歳を含め、在庫 0 個、締切ちょうど、定員ちょうどを含めない比較を使っている。

## よくある違反

- 送料・年齢の下限を `>` にすると境界ちょうどで誤ります。在庫・締切・定員に `>=` を使うと、境界ちょうども条件を満たしてしまいます。
- 満点判定に `>=` を使うと 101 点も満点になります。商品コードを数値や文字列にそろえると、型が違う入力を区別できません。空文字の判定前に空白を取り除くと、空白だけの入力も空と見なします。

# 注文の合計を計算する

単価・数量からの計算に、会員割引と送料の条件をつなげます。途中の金額を変数に置き、各条件でどの段階の金額を使うか分かるように書きます。

`src/order.js` の関数を完成させます。各関数の名前と引数はそのまま使い、仮の本体を置き換えます。結果は `return` で返します。

## 1. 支払う合計を求める

`orderTotal(unitPrice, quantity, isMember)`

`unitPrice`（整数、0〜100,000 円）、`quantity`（整数、0〜100 個）、`isMember`（会員なら `true` の真偽値）を受け取り、支払う合計を円単位の整数で返します。数量が 0 個なら、先に 0 円を返します。

1. 単価に数量を掛けて小計を出します。
2. 会員で、かつ小計が 3,000 円以上なら、小計から 300 円引きます。
3. 割引を反映した小計に対して税率 10% で税を計算します。税の 1 円未満の端数は `Math.floor` で切り捨て、税を割引後の小計に足します。
4. 税込みの金額が 3,000 円以上なら送料は 0 円、未満なら 600 円です。税込みの金額に送料を足して返します。送料に税は掛けません。

例は `orderTotal(1500, 2, true) → 3570` です。

## 確かめ方

1. VS Code のコマンドパレットから「STELLA: 課題を確認する」を実行します。
2. テストが通らなければ、失敗した入力と期待する戻り値を見比べます。境界では、直前・ちょうど・直後を確かめます。
3. 修正したらもう一度確認し、すべて通ったら提出します。

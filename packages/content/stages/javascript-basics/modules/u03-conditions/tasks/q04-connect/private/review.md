# レビューの観点

- 数量が 0 個なら、単価や会員区分にかかわらず、通常の計算に入る前に 0 を返す。
- 単価と数量を掛けた小計が 3,000 円以上かつ会員のときだけ 300 円を引き、割引後の小計の 10% を Math.floor で切り捨てて税にする。
- 税を足した金額が 3,000 円以上のときだけ送料無料とし、最後に送料を足して返す。

## よくある違反

- 会員か小計の下限のどちらかだけで値引きしたり、単価で下限を判定したりすると、数量が複数の注文や非会員の注文を誤ります。
- 割引前の小計で税や送料を決めると、3,000 円の会員注文を誤ります。税を四捨五入すると、割引なしの 2,727 円で送料の判定まで変わります。
- 数量が 0 個の入力では、通常の送料の計算へ進む前に 0 円を返します。

# レビューの観点

- 各関数は if・else if・else で範囲を大きい側か小さい側の一方向から順に分けている。
- 各比較は仕様で指定した区分に境界ちょうどの値を含め、最後の else が残った区分の値を返す。

## よくある違反

- 大きい側から調べるときに低い下限を先に置くと、高い値も先の分岐に入ります。送料で 4,000 円以上を先に見ると 6,000 円の結果が 300 円になります。
- 「以上」を `>` にするとちょうどの値が隣の区分へ移ります。「未満」を `<=` にすると境界が手前の区分に入ります。
- 在庫数は負の入力も仕様内です。0 個だけを「売り切れ」にすると、負の在庫数が誤った区分に進みます。

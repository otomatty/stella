# 範囲を順に分ける

入力の範囲ごとに、返す文字列や数値を決める練習です。6 問とも `if`・`else if`・`else` を使い、大きい側か小さい側の一方向から順に分けます。

`src/ranges.js` の関数を完成させます。各関数の名前と引数はそのまま使い、仮の本体を置き換えます。結果は `return` で返します。

## 1. 点数から評価を決める

`scoreGrade(score)`

点数 `score`（0〜100 の整数）に応じて評価を文字列で返します。90〜100 点は `"A"`、80〜89 点は `"B"`、60〜79 点は `"C"`、0〜59 点は `"D"` です。

例は `scoreGrade(85) → "B"` です。

## 2. 注文金額から送料を決める

`shippingFee(total)`

注文金額 `total`（0 円以上の整数）から送料を円単位の数値で返します。6,000 円以上は 0 円、4,000〜5,999 円は 300 円、4,000 円未満は 600 円です。

例は `shippingFee(4500) → 300` です。

## 3. 年齢から入場料を決める

`admissionFee(age)`

年齢 `age`（0 歳以上の整数）から入場料を円単位の数値で返します。0〜5 歳は 0 円、6〜17 歳は 500 円、18〜64 歳は 1,000 円、65 歳以上は 700 円です。

例は `admissionFee(12) → 500` です。

## 4. 気温を区分する

`temperatureLabel(temperature)`

摂氏の気温 `temperature`（整数）を文字列で区分します。0 ℃未満は `"氷点下"`、0〜14 ℃は `"寒い"`、15〜24 ℃は `"穏やか"`、25 ℃以上は `"暑い"` です。

例は `temperatureLabel(20) → "穏やか"` です。

## 5. 在庫数から表示を決める

`stockStatus(stock)`

在庫数 `stock`（整数）に応じて表示を文字列で返します。0 個以下は `"売り切れ"`、1〜4 個は `"残りわずか"`、5 個以上は `"在庫あり"` です。棚卸し前の在庫数は負の値になることがあります。

例は `stockStatus(3) → "残りわずか"` です。

## 6. 注文数から割引額を決める

`orderDiscount(count)`

注文数 `count`（0 以上の整数）から、注文全体の割引額を円単位の数値で返します。20 個以上は 500 円、10〜19 個は 200 円、10 個未満は 0 円です。

例は `orderDiscount(12) → 200` です。

## 確かめ方

1. VS Code のコマンドパレットから「STELLA: 課題を確認する」を実行します。
2. テストが通らなければ、失敗した入力と期待する戻り値を見比べます。境界では、直前・ちょうど・直後を確かめます。
3. 修正したらもう一度確認し、すべて通ったら提出します。

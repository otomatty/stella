# レビューの観点

- 両条件が必要な会員割引と受け取り時間に && を、少なくとも一方が必要な通知と取り置きの通常判定に || を使っている。
- 閉じた窓口、空のコード、利用停止は通常の判定より前に return し、通常の処理はその if の外にある。
- 窓口が閉まった条件を ! で表し、コードの空文字と一致の判定に === を使っている。

## よくある違反

- 会員だけで割引可になったり、休日の 18 時に通知不可になったりする場合は、`&&` と `||` の取り違えを確認します。
- `hour <= 17` では受付終了の 17 時も通します。窓口や取り置きで空き・在庫を先に判定して返すと、閉鎖中・停止中でも許可することがあります。
- コードの空文字を単なる不一致として扱うと `false` を返してしまいます。入力を加工して空白だけの文字列を空文字扱いするのも仕様と異なります。

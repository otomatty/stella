# 在庫に応じて表示を変える

商品ページには「購入できます」か「売り切れ」を表示します。在庫の数を渡すと、表示に使う文を返す関数を考えます。

<!-- ノート: 商品ページには「購入できます」か「売り切れ」を表示します。在庫の数を渡すと、表示に使う文を返す関数を考えます。 -->
---
# 覚えること

条件が成り立つときの処理を `if` に、成り立たないときの処理を `else` に書きます。

<!-- ノート: 条件が成り立つときの処理を `if` に、成り立たないときの処理を `else` に書きます。 -->
---
# 在庫があれば購入できる

```js
export function stockLabel(stock) {
  if (stock > 0) {
    return "購入できます";
  } else {
    return "売り切れ";
  }
}
```

<!-- ノート: if の丸括弧の中を条件式と呼びます。在庫が 0 より大きければ真偽値は true になり、if 側の波括弧の中だけが実行されます。処理の道筋を分けることを分岐と呼びます。 -->
---
# 条件に当たる側から読む

`stockLabel(2)` では `2 > 0` が `true` なので、`if` 側の文を返します。`stockLabel(0)` では `0 > 0` が `false` なので、`else` 側の文を返します。

<!-- ノート: まず丸括弧の中に、受け取った数を当てはめます。結果が false のときだけ else 側を読みます。 -->

# 金額の大きい側から確かめる

```js
export function shippingFee(total) {
  if (total >= 5000) {
    return 0;
  } else if (total >= 3000) {
    return 300;
  } else {
    return 600;
  }
}
```

<!-- ノート: 5,000 円以上は送料無料です。最初の条件が成り立たなかったときだけ else if に進みます。3,000 円以上なら送料は 300 円で、残りは 600 円です。3,000 円を先にすると、5,000 円も先の条件に当たります。 -->
---
# 境界の直前・ちょうど・直後を試す

送料が切り替わる値を境界と呼びます。たとえば 3,000 円の周りで、関数の結果が想定どおりかを確かめます。

| 注文金額 | 期待する送料 |
| --- | --- |
| 2,999 円 | 600 円 |
| 3,000 円 | 300 円 |
| 3,001 円 | 300 円 |

<!-- ノート: 入力と期待する結果を用意して動作を確かめることをテストと呼びます。ちょうど 3,000 円を入れると、以上の記号を、より大きいの記号に取り違えたときに気づけます。5,000 円の周りも同じように確かめます。 -->

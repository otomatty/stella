# 同じ商品を見つける

商品一覧から、入力された商品コードに一致する商品を探します。コードが同じかどうかを、関数で確かめるにはどう書けばよいでしょうか。

# 覚えること

比較演算子は真偽値を返し、等しいかは `===` で確かめます。

# 商品コードを比べる

```js
export function matchesProductCode(inputCode, productCode) {
  return inputCode === productCode;
}

console.log(matchesProductCode("P12", "P12")); // => true
```

<!-- ノート: 比較演算子は値を比べる記号です。比較が成り立てば true、成り立たなければ false です。この2つを真偽値と呼びます。export を付けると、別のファイルからこの関数を使えます。 -->
---
# 型が違う入力を比べる

数値の `12` と文字列の `"12"` を `===` で比べると `false` です。`==` では型を自動でそろえる場合があり、この2つは等しいと判定されます。

<!-- ノート: 厳密等価と呼ばれる三つの等号は、型を変えずに比べます。商品コードが文字列で届く仕様なら、入力の型の違いにも気づけます。 -->

## 知識問題

### Q1. 同じリポジトリの日本語訳だけに、長い用字表を適用します。担当者全員で版をそろえ、別の言語を扱うときには読み込ませたくありません。どこに置きますか。
<!-- kind: single; skills: claude-code-config -->

- A. 全員のホームに同じ CLAUDE.md を手でコピーする
- B. リポジトリの最上位の CLAUDE.md に用字表の全文を追記する
- C. 対象の日本語訳のパスを指定した .claude/rules/ のルールを版管理する

<details>
<summary>解答</summary>

**C** — パスを指定したルールは対象のファイルを扱うときに適用されます。リポジトリで管理すれば、用字表を更新した担当者も変更履歴に残ります。 基礎の復習は「毎回効かせる約束」です。

</details>

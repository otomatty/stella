## 知識問題

### Q1. 備品を返却するツールは借り手の姓だけを引数にしています。利用者の画面で借り手は一人に絞れますが、台帳には同姓の借り手が3人います。意図した1件だけを処理する設計はどれですか。
<!-- kind: single; skills: claude-tool-design -->

- A. 同じ姓の貸出をすべて返却扱いにする
- B. 台帳順で先頭の人を選び、後から利用者に一覧を見せる
- C. 画面で確定した貸出記録の ID を必須の引数にし、特定できなければ返却を保留する

<details>
<summary>解答</summary>

**C** — 姓は記録を一意に特定できません。表示上で確定した貸出 ID を入力に使えば、同姓の別の人の記録を更新せずに済みます。 基礎の復習は「説明に書くこと」です。

</details>

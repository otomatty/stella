## 知識問題

### Q1. MCP 対応の社内アプリで、利用者が一覧から1つの会場を選びます。選んだ会場の座席図を毎回その URI で読めれば十分です。どの機能が合いますか。
<!-- kind: single; skills: claude-mcp -->

- A. 会場別の座席図をリソースとして公開し、ホストが選択した URI を読み取る
- B. すべての座席図をプロンプト名に含めて公開する
- C. 座席図を選んだ時点で会場の予約を作るツールを呼ぶ

<details>
<summary>解答</summary>

**A** — 座席図はアプリが選んで読むデータです。リソースには URI があり、ホストは選んだ図だけを読み取って会話に添えられます。予約を作る操作は要りません。 基礎の復習は「共通の約束でつなぐ」です。

</details>

# 規模の経済

AWS Cloud Practitioner 入門 — Module 1 / レッスン1-1

<!-- ノート: 6つの利点のうち「規模の効果」を経済用語として固めるトピックです。 -->

---

## なぜ必要か

- 1台だけ買う会社と、数百万台を買う会社では、仕入れ値が違う
- 自社でどれだけ工夫しても、この差は埋まらない
- なぜクラウドの単価は下がり続けるのでしょうか

<!-- ノート: つかみ。まとめ買いが安いのは日用品と同じ、という日常の感覚から入る。 -->

---

## 結論

**AWSは大量調達による規模の経済で単価を下げ、値下げとして利用者に還元できる**

- **規模の経済** = 規模が大きいほど、1つあたりのコストが下がる効果
- 世界中の利用量が集まるほど、単価は下がる方向に働く

<!-- ノート: 結論。利用者は自分の使用量に関係なく、この「まとめ買いの安さ」に相乗りできる。 -->

---

## 最小の例

| | 自社1社で調達 | AWSに相乗り |
| --- | --- | --- |
| 調達規模 | 数台〜数十台 | 世界中の需要をまとめて調達 |
| 1台あたりの単価 | 高止まり | 大量調達で低くなる |
| 値下げ | 起きない | 過去にくり返し実施 |

<!-- ノート: 表は構図の理解用。具体的な値下げ回数などの当日値は覚えなくてよい。 -->

---

## 試験での聞かれ方

- 「多数の顧客の使用量が集約される結果、何が起きるか」→ 従量課金の単価が下がる
- 規模の経済は「AWS側の企業努力」ではなく「構造的な効果」として出る
- 自社の努力(節約・設定変更)と混ぜた選択肢に注意

<!-- ノート: 補強枠。economies of scale という英語も口頭で添えておくと選択肢で迷わない。 -->

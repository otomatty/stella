# サポートプランは段階制

AWS Cloud Practitioner 入門 — Module 9 / レッスン9-2

## なぜ必要か

- 本番で障害が起きたとき、「誰に、どれだけ早く」聞けるかは契約で決まる
- 無料の範囲と、有料で増える範囲を知らないと選べない
- 試験は「この要件ならどのプラン?」を選ばせる

<!-- ノート: つかみ。保険の等級と同じで、事が起きる前に選ぶもの。 -->

---

## 結論

**サポートプランは無料のBasicから専任TAM付きのEnterpriseまでの段階制で、上位ほど応答が速く支援が手厚い**

- **サポートプラン** = AWSの技術サポート契約の等級
- **TAM** = 技術アカウントマネージャー。上位プランで付く伴走役

<!-- ノート: 結論。段数の暗記より「上に行くほど速く手厚い」の構造と、TAMの付き方の違い。 -->

---

## 最小の例

試験ガイド(タスク4.3)が挙げるプランです。

| プラン | 一言 |
| --- | --- |
| Basic | 無料。技術サポートなし(請求相談・ドキュメントは可) |
| Developer | 開発・検証向け。営業時間内の技術サポート |
| Business | 本番向け。24時間365日、電話・チャット可 |
| Enterprise On-Ramp | 本番の大規模化の入口。**TAMのプール**に相談できる |
| Enterprise | 大規模向け。**専任のTAM** が付く |

<!-- ノート: 判定キーワード: 本番=Business以上、専任TAM=Enterprise、TAMプール=On-Ramp。 -->

---

## 試験での聞かれ方

- 「本番ワークロードで24時間365日の電話サポート」→ Business以上
- 「専任のTAMによる支援」→ Enterprise(On-RampはTAMプール)
- 「無料プランでも請求・アカウントの相談はできる」→ 正しい
- 販売中のプラン体系は再編が進行中。契約時は公式の比較ページで最新を確認

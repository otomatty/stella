# CLF-C02はどんな試験か

AWS Cloud Practitioner 入門 — Module 0 / レッスン0-1

<!-- ノート: 講座の最初のトピックです。まず敵を知る、つまり試験の形式を数字で押さえます。 -->

## なぜ必要か

- 「AWSの試験」と聞くと、範囲が広くて雲をつかむ印象がある
- 形式を知らないまま勉強を始めると、時間配分も深さも決められない
- 何分で、何問で、何点取れば合格なのでしょうか

<!-- ノート: つかみ。勉強の計画は試験の形式から逆算する、という話につなげる。答えはまだ言わない。 -->

---

## 結論

**CLF-C02は90分65問の選択式で、1000点満点の尺度点700点で合格する試験**

- **CLF-C02** = AWS Certified Cloud Practitioner の現行試験コード
- **尺度点** = 素点ではなく、難易度をならして100〜1000に換算した点数

<!-- ノート: 結論を言い切る。CLFはCloud Practitionerの略記、C02は版番号。尺度点は回によって難易度差をならすための換算点、と補足する。 -->

---

## 最小の例

| 項目 | 数字 |
| --- | --- |
| 試験時間 | 90分 |
| 問題数 | 65問(得点対象50問 + 非得点15問) |
| 点数 | 100〜1000の尺度点 |
| 合格ライン | **700** |

- 65問のうち15問は採点されない調査用の問題
- どれが非得点かは受験中には分からない

<!-- ノート: 数字を1つずつ指す。90分で65問なので1問あたり約80秒。非得点問題は見分けられないので、全問同じ態度で解く。 -->

---

## よくある誤解

- 「700点 = 70%正解」ではない
- 尺度点は換算後の点数なので、正解率と1対1に対応しない
- 「何問正解で合格」という決まった数はない

<!-- ノート: 補強枠。素点と尺度点の混同が定番の誤解。7割正解を目安にしつつ、余裕を持って仕上げるのが安全、と伝える。 -->

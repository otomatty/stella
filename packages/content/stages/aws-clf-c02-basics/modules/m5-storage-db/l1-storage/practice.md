# レッスン5-1 演習 — ストレージ

対象トピック: 5-1-1 〜 5-1-5

## 手元で試す

ストレージ3方式の「用途の一言」を、身の回りのデータで検証するワークです。

1. 紙に3列の表を描き、見出しを S3 / EBS / EFS とする
2. それぞれの下に「用途の一言」を書く(Webから出し入れする置き場 / 1台に取り付けるディスク / 複数台で共有するフォルダー)
3. 次の6つのデータを、どの列に置くべきか仕分けする
   - 商品画像、データベースの本体ファイル、社員が共有する設計書フォルダー、監査用に7年保管するログ、OSの起動領域、Webサイトのバックアップ
4. 仕分けが終わったら、「監査用ログ」にだけ印を付け、ストレージクラス(Glacier系)とライフサイクル(90日後に自動移動)の設定案を1行で書く
5. 表の欄外に脇役3つ(Storage Gateway / FSx / AWS Backup)を書き、役割の一語(橋 / 専用品の共有 / バックアップのまとめ役)を添える

仕分けに迷ったものは、「1台か複数台か」「取り付けるか出し入れか」を自問すると決まります。

## 演習問題

### 問1(基本)

S3の「耐久性」が高い理由を、データの置かれ方に触れて2文以内で説明してください。

### 問2(基本)

「ほとんどアクセスしないが、規定で7年間保管する必要がある契約書PDF」に適したS3のストレージクラスはどれですか。また、Standardのまま置き続けた場合と比べて何が変わるかを書いてください。

### 問3(応用)

S3・EBS・EFSの3つを、「保管の方式」と「用途の一言」の2列で表にまとめてください。

### 問4(応用)

「EC2のデータを守りたいので、EBSのバックアップを毎晩取りたい」という要望に使う機能の名前と、その仕組みを1〜2文で書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

S3はオブジェクトを複数のAZ(独立したデータセンター群)へ自動的に複製して保管します。1か所の障害でデータが失われない設計のため、極めて高い耐久性(いわゆるイレブンナイン)を実現しています。

</details>

<details>
<summary>問2の解答例</summary>

Glacier系(長期保管・アーカイブ用のクラス)が適しています。Standardに比べて保管単価が大きく下がる代わりに、取り出しに時間や費用がかかります。ほぼアクセスしないデータなら、この交換条件が有利に働きます。

</details>

<details>
<summary>問3の解答例</summary>

| サービス | 保管の方式 | 用途の一言 |
| --- | --- | --- |
| S3 | オブジェクトストレージ | Webから出し入れする置き場 |
| EBS | ブロックストレージ | 1台のEC2に取り付けるディスク |
| EFS | ファイルストレージ | 複数台で共有するフォルダー |

</details>

<details>
<summary>問4の解答例</summary>

スナップショットです。ある時点のEBSの内容の複製を保存する機能で、撮っておけばその時点の状態に戻したディスクを作れます。保存先には裏でS3の仕組みが使われるため、高い耐久性で保管されます。

</details>

## 確認クイズ

### Q1. S3の説明として正しいものはどれですか。

- A. EC2に取り付けて使うディスク
- B. オブジェクトをバケットに保管する、耐久性の高いストレージ
- C. ドメイン名を解決するサービス
- D. コンテナの実行を管理するサービス

<details>
<summary>答え</summary>

**B** — S3はオブジェクトストレージです。EC2に取り付けるディスクはEBS、ドメイン名の解決はRoute 53、コンテナの実行管理はECS/EKSの説明です。

</details>

### Q2. 「アクセス頻度は低いが長期保管が必要なアーカイブデータ」に適したストレージクラスはどれですか。

- A. S3 Standard
- B. S3 Glacier系
- C. EBSの追加ボリューム
- D. インスタンスの内蔵領域

<details>
<summary>答え</summary>

**B** — Glacier系は保管単価が安い長期保管用クラスです。アクセスが少ないほど安いクラスが有利になります。

</details>

### Q3. 「30日たったオブジェクトを自動で低頻度アクセスのクラスへ移したい」に使う機能はどれですか。

- A. ライフサイクルルール
- B. スナップショット
- C. Auto Scaling
- D. マウント

<details>
<summary>答え</summary>

**A** — クラス間の自動移動はライフサイクルルールで設定します。手動で移す運用は不要です。

</details>

### Q4. 「社内のWindowsファイルサーバーをAWSへ移したい。Active Directoryとの統合が必須」という要件に最も適したサービスはどれですか。

- A. EFS
- B. FSx
- C. S3
- D. EBS

<details>
<summary>答え</summary>

**B** — WindowsやActive Directoryという専用品のキーワードが出たらFSx(for Windows File Server)です。EFSも共有ファイルストレージですがLinux標準の共有向けで、この2択は「専用品かどうか」で決めます。

</details>

### Q5. 「複数のEC2インスタンスから同時にマウントして使う共有ストレージ」はどれですか。

- A. EBS
- B. EFS
- C. スナップショット
- D. バケット

<details>
<summary>答え</summary>

**B** — 「複数台で共有」がEFSの判定キーワードです。EBSは基本1台に取り付けて使います。

</details>

# 定額のLightsailと一括のBatch

AWS Cloud Practitioner 入門 — Module 3 / レッスン3-2

## なぜ必要か

- 「ブログを1つ、月いくらか分かる形で始めたい」にEC2の構成一式は大げさ
- 「夜間に何万件の計算ジョブを流したい」はEC2の台数管理が大変
- どちらも試験の選択肢に名前で登場する

<!-- ノート: つかみ。本線(EC2/Lambda/コンテナ)の判定表からこぼれる、両端の用途が2つあります。 -->

---

## 結論

**月額定額でサーバー一式を簡単に始めるのがLightsail、大量のジョブをまとめて流すのがBatch**

- **Lightsail** = サーバー・ストレージ・ネットワークを月額定額のセットで提供する簡易版
- **Batch** = 大量のバッチジョブを、必要な計算資源の確保ごと自動でこなすサービス

<!-- ノート: 結論。両極端の2つ。最小の手間で始めるLightsail、最大の物量を裁くBatch。 -->

---

## 最小の例

| サービス | 一言 | 向く場面 |
| --- | --- | --- |
| **Lightsail** | 定額の入門セット | ブログ・小規模サイトを予測可能な料金で |
| **Batch** | ジョブの一括実行 | 夜間の大量計算・シミュレーション |
| EC2 | 自由な仮想サーバー | 構成を自分で細かく決めたいとき |

<!-- ノート: Lightsailの裏側もEC2ですが、「簡単・定額」に全振りした窓口です。 -->

---

## 試験での聞かれ方

- 「予測可能な月額料金で、シンプルな仮想プライベートサーバーを使いたい」→ Lightsail
- 「数十万件の計算ジョブを、リソース確保も含めて自動で実行したい」→ Batch
- 「コードを渡して環境は任せたい」→ Elastic Beanstalk(混同注意。渡すのはWebアプリ)

<!-- ノート: 補強枠。Lightsailは「定額・簡単」、Batchは「ジョブ・大量」が合図の一語です。 -->

---

## 結論

**セキュリティサービスは、防ぐ・気づく・見つけるという動詞で持ち場が分かれる**

- 防ぐ = 攻撃を入口で止める
- 気づく = 起きている異常や弱点を知らせる
- 見つける = 保管しているデータの中身を調べる

<!-- ノート: 結論。3動詞に落とすのがこのトピックのすべて。サービス名は次のスライドで当てはめます。 -->

---

## 最小の例

| 動詞 | サービス | 持ち場 |
| --- | --- | --- |
| 防ぐ | WAF | Webアプリを狙う攻撃を入口で遮る |
| 防ぐ | Shield | DDoS攻撃から守る |
| 気づく | GuardDuty | 不審な振る舞いを継続的に検出する |
| 気づく | Inspector | EC2やコンテナイメージの脆弱性を診断する |
| 見つける | Macie | S3の中の個人情報を見つける |
| まとめる | Security Hub | 上の結果を1画面に集約する |

<!-- ノート: 6行。動詞の列を左に置いてあるので、まず動詞を決めてから行を選ぶ順で読ませる。 -->

---

## 2択の決め方

- 「Webアプリへの攻撃」→ WAF / 「大量のトラフィックで落とされる」→ Shield
- 「不審な通信・振る舞い」→ GuardDuty / 「既知の脆弱性・パッチ漏れ」→ Inspector
- 「S3に個人情報が紛れていないか」→ Macie
- 「複数の検出結果をまとめて見たい」→ Security Hub

<!-- ノート: 補強枠。実際の設問は2択まで絞れた後の判断で決まります。スラッシュの左右が、その2択です。 -->

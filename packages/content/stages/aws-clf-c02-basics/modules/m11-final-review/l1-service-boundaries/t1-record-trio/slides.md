# 記録の3つを動詞で分ける

AWS Cloud Practitioner 入門 — Module 11 / レッスン11-1

<!-- ノート: 直前対策の初日です。模試で間違えやすいのは知らないサービスより「似ているサービス」。まずは記録系の3つから切り分けます。 -->

---

## なぜ必要か

- 選択肢に CloudWatch・CloudTrail・Config が並ぶ設問は多い
- 3つとも「あとから見返すために記録する」サービスに見える
- 名前の似ている順に選ぶと、確実に間違える

<!-- ノート: つかみ。模試の誤答で上位に入る組です。名前ではなく「何を記録するか」で分かれる、という話につなげる。 -->

---

## 結論

**CloudWatchは数値とログ、CloudTrailは操作の証跡、Configは設定の状態を記録する**

- 記録する対象が違うだけで、機能の優劣ではない
- 設問は必ず「何を知りたいか」を書いている

<!-- ノート: 結論。3つは競合ではなく分担。設問文の「知りたいこと」を先に読むのが解き方です。 -->

---

## 最小の例

| 知りたいこと | 選ぶもの |
| --- | --- |
| CPU使用率が80%を超えたら知らせてほしい | CloudWatch |
| 先週このバケットを削除したのは誰か | CloudTrail |
| すべてのEC2に暗号化の設定が入っているか | Config |

<!-- ノート: 1行ずつ指す。数値のしきい値=CloudWatch、人の操作=CloudTrail、設定の状態=Config。この3問が即答できれば十分です。 -->

---

## 設問のキーワード

- 「メトリクス」「アラーム」「しきい値」「ログの収集」→ CloudWatch
- 「誰が・いつ・どのAPIを」「監査」「証跡」→ CloudTrail
- 「設定が基準どおりか」「構成の変更履歴」→ Config
- 迷ったら **数値か・人の操作か・設定か** の3択に落とす

<!-- ノート: 補強枠。キーワードの反射だけで大半が決まります。3択に落とす言い換えを声に出して覚えてもらう。 -->

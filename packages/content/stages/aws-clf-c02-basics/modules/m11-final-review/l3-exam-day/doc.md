# レッスン11-3 受験の手続きと当日

## このレッスンの目標

- [ ] 申し込みから受験までの段取りを、自分で最後まで進められる
- [ ] 当日のチェックインでつまずかない準備ができる
- [ ] 本番にだけある複数回答形式を、部分点がない前提で解ける

このレッスンの内容は **調査日 2026-09-01 時点** のものです。受験料・キャンペーン・キャンセル規定・再認定の条件はいずれも変わりうるので、申し込みの前に必ず公式の認定ページと試験ガイドで最新を確認してください。

## 11-3-1 申し込みはAWS認定アカウントから

> **試験はAWS認定アカウントから予約し、テストセンターかオンライン監督試験のどちらかで受ける**

勉強が仕上がっても、予約の仕方を知らないと受験日が決まりません。そして受験日を先に決めた人ほど、勉強が締まります。

まず **AWS認定アカウント** を作ります。これは受験と認定の管理に使う専用のアカウントで、EC2やS3を使うAWSの利用アカウントとは別物です。ここから試験配信事業者の **Pearson VUE** へ進み、日時と受け方を選んで予約します。

| 項目 | 内容(調査日 2026-09-01) |
| --- | --- |
| 予約 | AWS認定アカウント → Pearson VUE |
| 受け方 | テストセンター / オンライン監督試験 |
| 言語 | 日本語で受験できる |
| 試験時間 | 90分 |
| 受験料 | 100 USD(円換算額は為替で変わる) |

受け方は2つから選びます。静かな個室と安定した回線があるならオンライン監督試験、確実さを取るならテストセンターです。オンラインは機材と部屋の条件を満たせないと当日に中止になりうるため、初めての受験ではテストセンターを選ぶ人も多くいます。

なお、英語で受験する場合に限り、母国語が英語でない受験者は時間延長を申請できます。**日本語で受験するなら対象外**です。日本語で受けるつもりなら、この申請を気にする必要はありません。

## 11-3-2 当日は30分前にチェックイン

> **当日は開始時刻の30分前からチェックインを始め、本人確認と環境の確認を済ませてから解き始める**

開始時刻ちょうどに着けばよいと考えていると、受験できないことがあります。**チェックイン**(受験前の本人確認と受験環境の確認)には時間がかかるためです。早く始めても損はなく、遅れたときの代償だけが大きい、という非対称な手続きだと考えてください。

| 受け方 | 当日にすること |
| --- | --- |
| 共通 | 身分証の氏名を申込時の登録と一致させる(有効期限内・政府発行) |
| **テストセンター** | **身分証は2点必要**。30分前に到着し、私物はロッカーに預ける |
| オンライン | 写真付きの身分証1点。30分前にチェックインし、本人・身分証・部屋を撮影する |
| オンライン | 机の上を空にし、誰も入ってこない個室で受ける |

身分証は**受け方で必要な点数が違います**。テストセンターは2点必要で、1点だけを持参すると受験を断られます(1点は写真付きの政府発行の原本。もう1点として認められる種類は公式の受験ポリシーで確認してください)。オンライン監督試験は写真付きの1点です。

点数と並んで多いつまずきが、身分証の氏名が申込時の登録と一致しないことです。予約したその日に、登録名と身分証の表記を突き合わせておいてください。

試験画面の使い方も、先に知っておくと落ち着けます。

- 迷った問題には「後で見直す」の印を付けられ、最後にまとめて戻れます
- 解答は試験終了まで何度でも変更できます
- 空欄は減点ではなく不正解です。必ず何かを選んでください
- 残り時間は画面に表示されます。M10で練習した「80秒で打ち切って印を付け、先へ進む」がそのまま使えます

## 11-3-3 複数回答には部分点がない

> **複数回答形式には部分点がないため、確実な1つを先に固定してから残りを消去法で選ぶ**

この講座の模擬試験(M10)とドリル(11-2)は、LMSのクイズ機能に合わせてすべて4択・単一回答です。本番にはもう1つ、**複数回答形式**(5つ以上の選択肢から、指示された数を選ぶ出題)があります。

| 項目 | 単一回答 | 複数回答 |
| --- | --- | --- |
| 選択肢 | 4つ | 5つ以上 |
| 選ぶ数 | 1つ | 指示された数(2つなど) |
| 採点 | 正解なら得点 | すべて正しいときだけ得点 |
| 空欄 | 不正解 | 不正解 |

重要なのは3行目です。「2つ選べ」で1つだけ合っていても得点はありません。**部分点がない**ので、2つ目を勘で選ぶ前に消去を尽くします。

1. 確実に正しい選択肢を1つ決めて固定する
2. 明らかに誤りの選択肢を消す
3. 残りから、指示された数だけ選ぶ
4. 迷っても空欄にしない(勘で選んでも減点はない)

出題形式そのものについても補足しておきます。試験ガイドが挙げるCLF-C02の形式は単一回答と複数回答の2つですが、AWSは並べ替えや組み合わせといった形式を各試験へ順次追加しています。受験前に試験ガイドで、自分が受ける版の形式を確認してください。本番の文体と複数回答に慣れておきたい場合は、公式のOfficial Practice Question Set(Skill Builder)が最後の仕上げとして有効です。

## 11-3-4 認定は3年で期限が切れる

> **AWSの認定は取得から3年で期限が切れるため、期限内に再認定して有効な状態を保つ**

合格はゴールではなく、期限のある状態の始まりです。履歴書や社内の資格手当は、有効な認定であることが前提になります。

| 項目 | 内容(調査日 2026-09-01) |
| --- | --- |
| 有効期限 | 取得から3年 |
| 再認定の方法 | 同じ試験の現行版に再合格する / **アソシエイト以上**(アソシエイトまたはプロフェッショナル)の認定に合格する |
| Cloud Practitionerの追加手段 | 期限の6か月前から、AWS Cloud Quest: Recertify Cloud Practitionerの修了でも更新できる |
| 不合格だったとき | 14日間あけてから再受験できる(回数制限はないが毎回受験料がかかる) |

別の認定で更新できるのは **アソシエイト以上** の場合だけです。同じ基礎(ファンデーショナル)レベルの認定に合格しても、Cloud Practitionerの期限は延びません。**再認定**は自分で予定を立てて行う作業なので、期限が近づいたら公式の再認定ページで、そのときの条件を確認してください。

合否と詳細なスコアレポートは、AWS認定アカウントで確認します。レポートにはドメインごとの到達状況が出るので、不合格だった場合はそれがそのまま次の復習先になります。M10の誤答分析と同じ読み方で、弱いドメインのモジュールへ戻ってください。

## もっと知りたい人へ

- 受験料・キャンペーン・キャンセル規定・再認定の条件は変わります。このレッスンの数字は調査日時点の目安として読み、申し込み前に公式ページで確認してください
- 受験日を決めたら、逆算してM10の模擬試験と11-2のドリルをいつ解くかを先に予定に入れてください。日程が決まると、残りの勉強の配分も決まります

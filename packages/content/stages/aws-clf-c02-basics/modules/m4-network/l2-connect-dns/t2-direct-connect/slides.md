# 4-2-2
# Direct Connectは専用線

AWS Cloud Practitioner 入門 — Module 4 / レッスン4-2

<!-- ノート: VPNとの対比で覚える2つ目の接続手段です。 -->

---

## なぜ必要か

- VPNはインターネット品質に左右される
- 基幹システムの大量データを、毎晩安定して流したい場合は不安
- 「混雑と無縁の自分専用の道」が欲しい

<!-- ノート: つかみ。一般道(共用)と専用道路の例えを口頭で。 -->

---

## 結論

**Direct Connectは自社拠点とAWSを専用線でつなぎ、安定した帯域と品質を得る**

- **専用線** = 自社だけが使う物理的な通信回線
- **Direct Connect** = AWSへの専用線接続のサービス

<!-- ノート: 結論。インターネットを経由しない、が最大の特徴。 -->

---

## 最小の例

| | Site-to-Site VPN | Direct Connect |
| --- | --- | --- |
| 回線 | インターネット(共用) | 専用線 |
| 品質・帯域 | 保証されない | 安定 |
| 開通まで | 短い | 長い(物理工事) |
| 費用 | 安い | 高い |

<!-- ノート: この対比表が試験の判定表そのもの。4行を上から読み上げる。 -->

---

## 試験での聞かれ方

- 「安定した帯域」「一貫したネットワーク品質」「インターネットを経由しない」→ Direct Connect
- 「すぐに」「安価に」「暗号化して」→ VPN
- 併用(Direct Connect + VPNをバックアップに)もある

<!-- ノート: 補強枠。キーワード判定を型に。併用構成は一言だけ。 -->

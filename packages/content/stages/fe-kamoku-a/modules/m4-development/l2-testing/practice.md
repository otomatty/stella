# レッスン4-2 演習 — テストの技法

対象トピック: 4-2-1 〜 4-2-3

## ハンズオン

紙とペン(またはメモアプリ)だけでできる、テストする値を洗い出すワークです。次の入力条件を題材にします。

> 会員登録の年齢欄は、18〜64 が有効。それ以外は受け付けない。

次の手順で、試す値を選んでみましょう。

1. 入力を「同じ扱いになるまとまり」に分けて書き出す(17以下 / 18〜64 / 65以上)
2. 各まとまりから代表値を1つずつ選ぶ(同値分割)
3. 有効と無効の境目を見つけ、その両側の値を書き出す(境界値分析: 17、18、64、65)
4. 選んだ値それぞれに、期待する結果(受け付ける / はじく)を書き添える
5. 「18以上」を「18より大きい」と作り間違えた場合を想像し、どの値がその間違いを見つけるかに丸を付ける

身の回りの入力欄(パスワードの文字数、購入できる個数など)でも同じ洗い出しを試すと、定着が早くなります。

## 演習問題

### 問1(基本)

単体テスト・結合テスト・システムテスト・受入れテストを実施する順に並べてください。また、それぞれの段階で見つけたい不具合を1つずつ書いてください。

### 問2(基本)

「商品の注文個数は1〜30が有効」という入力欄があります。同値分割で選ぶ代表値の例と、境界値分析で選ぶ値を、それぞれ挙げてください。

### 問3(応用)

「会員なら1割引きにする。さらに、割引き後の金額が5,000円以上なら送料を無料にする」という処理があります。処理の通り道を網羅するには、どのような組み合わせの入力を試す必要がありますか。すべて挙げてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

順序は、単体テスト → 結合テスト → システムテスト → 受入れテストです。

- 単体テスト — 部品の中の処理の誤り
- 結合テスト — 部品間のデータの受け渡しの誤り
- システムテスト — 要件定義とのずれや性能の不足
- 受入れテスト — 実際の業務で使えない点

部品 → 組み合わせ → 全体 → 発注者の確認、と範囲を内側から外側へ広げます。内側の段階でつぶした不具合は、後の段階に持ち越されません。

</details>

<details>
<summary>問2の解答例</summary>

同値分割では、まとまりを「0以下(無効)」「1〜30(有効)」「31以上(無効)」の3つに分け、代表値を1つずつ選びます。例: 0(または-5)、15、40。

境界値分析では、有効と無効の境目の両側を選びます。0、1、30、31 の4つです。

「1以上」を「1より大きい」と作り間違えたとき、代表値の15では見つかりませんが、境界値の1を試すと見つかります。

</details>

<details>
<summary>問3の解答例</summary>

分岐が2つあるので、組み合わせは次の4通りです。

| 会員かどうか | 割引き後の金額 | 通る道 |
| --- | --- | --- |
| 会員 | 5,000円以上 | 割引きあり・送料無料 |
| 会員 | 5,000円未満 | 割引きあり・送料あり |
| 会員でない | 5,000円以上 | 割引きなし・送料無料 |
| 会員でない | 5,000円未満 | 割引きなし・送料あり |

ホワイトボックステストの発想では、内部構造の分岐を見て、通り道をすべて通るように入力を選びます。1つの組み合わせだけでは、通っていない道が残ります。

</details>

## 確認クイズ

### Q1. テストを実施する順序として、適切なものはどれですか。

- A. 結合テスト → 単体テスト → システムテスト → 受入れテスト
- B. 単体テスト → 結合テスト → システムテスト → 受入れテスト
- C. システムテスト → 結合テスト → 単体テスト → 受入れテスト
- D. 受入れテスト → システムテスト → 結合テスト → 単体テスト

<details>
<summary>答え</summary>

**B** — テストは部品 → 組み合わせ → 全体 → 発注者の確認、と範囲を内側から外側へ広げます。単体・結合・システム・受入れの順です。

</details>

### Q2. 部品同士を組み合わせて、データの受け渡しの誤りを見つけるテストはどれですか。

- A. 単体テスト
- B. 受入れテスト
- C. システムテスト
- D. 結合テスト

<details>
<summary>答え</summary>

**D** — 部品の組み合わせを確かめるのは結合テストです。部品単体では正しくても、部品間の受け渡しで誤ることがあります。Aは部品1つ、Cは全体が対象です。

</details>

### Q3. 入力の有効範囲が1〜99のとき、境界値分析で選ぶ値の組として適切なものはどれですか。

- A. 0、1、99、100
- B. 1、50、99
- C. -1、0、100、101
- D. 2、50、98

<details>
<summary>答え</summary>

**A** — 境界値分析は有効と無効の境目の両側を狙います。有効範囲が1〜99なら、境目は1と99なので、0、1、99、100 を選びます。Cは有効範囲が0〜100の場合の組です。

</details>

### Q4. 内部構造を見ずに、入力と出力だけで動作を確認するテスト技法はどれですか。

- A. ホワイトボックステスト
- B. 受入れテスト
- C. ブラックボックステスト
- D. 同値分割

<details>
<summary>答え</summary>

**C** — 中身を黒い箱とみなして開けず、仕様との照らし合わせだけで確認するのがブラックボックステストです。Dの同値分割は、その中で試す値を選ぶ技法の名前です。

</details>

### Q5. ホワイトボックステストで重視する観点として、適切なものはどれですか。

- A. 入力に対する出力が仕様どおりか
- B. 処理の通り道をすべて通したか
- C. 発注者が実際の業務で使えるか
- D. 有効と無効の境目で正しく動くか

<details>
<summary>答え</summary>

**B** — ホワイトボックステストは内部構造に着目し、処理の通り道の網羅を重視します。AとDはブラックボックステスト、Cは受入れテストの観点です。

</details>

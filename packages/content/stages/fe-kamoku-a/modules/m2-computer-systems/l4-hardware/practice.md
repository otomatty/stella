# レッスン2-4 演習 — 論理回路と組込みシステム

対象トピック: 2-4-1 〜 2-4-4

## ハンズオン

紙とペン(またはメモアプリ)でできる、真理値表の手書きワークです。表を見ずに書けるようになるまで繰り返しましょう。

1. AND・OR・NOT・XORの4つについて、入力と出力の真理値表を何も見ずに書き出す
2. Y = NOT(A AND B) の真理値表を、「A AND B」の列 → 「Y」の列の順に1列ずつ埋める(答え: Yは上から 1, 1, 1, 0)
3. Y = (A OR B) AND (NOT A) の真理値表を同じ手順で作る(答え: Yは上から 0, 1, 0, 0)
4. 2進数1桁の足し算4通り(0+0, 0+1, 1+0, 1+1)を書き出し、「和」と「桁上がり」の列を埋める
5. 4の表の和の列がXOR、桁上がりの列がANDと一致していることを、1で書いた表と見比べて確かめる
6. 家の中にある機器を3つ挙げ、それぞれについて「センサーで何を測り、アクチュエーターで何を動かしているか」を1行ずつ書く(例: 洗濯機 — 水位を測り、モーターでドラムを回す)

2と3のような「内側の演算から1列ずつ埋める」手順は、試験の論理回路問題をそのまま解く手順です。式を変えて2〜3回繰り返すと定着が早くなります。

## 演習問題

### 問1(基本)

出力 Y = NOT(A OR B) の論理回路について、入力4通り(A, B) = (0,0), (0,1), (1,0), (1,1) それぞれの出力Yを求めてください。

### 問2(基本)

半加算器に A = 1, B = 1 を入力したとき、和と桁上がりはそれぞれいくつになりますか。また、和と桁上がりを求めるのに使う論理演算をそれぞれ答えてください。

### 問3(応用)

全自動のコーヒーメーカーを組込みシステムとして設計します。「お湯の温度を90度に保ってからドリップを始める」機能を実現するために、センサーとアクチュエーターがそれぞれ何をするか、「測る → 判断する → 動かす」の3ステップで説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

内側の A OR B から先に求めます。A OR B は上から 0, 1, 1, 1。それをNOTで反転して、Yは上から **1, 0, 0, 0** です。

ORの出力が1になるのは「少なくとも一方が1」のときなので、その否定であるYが1になるのは「両方とも0」のときだけです。複雑な式でも、内側の演算から1列ずつ埋めれば必ず解けます。

</details>

<details>
<summary>問2の解答例</summary>

和は **0**、桁上がりは **1** です(2進数で 1 + 1 = 10)。

和はXOR(排他的論理和)で求めます。A = 1, B = 1 は「2つの入力が同じ」なのでXORは0です。桁上がりはAND(論理積)で求めます。両方1なのでANDは1です。「和はXOR、桁上がりはAND」と対で覚えてください。

</details>

<details>
<summary>問3の解答例</summary>

- 測る: 温度センサーがお湯の温度を電気信号に変えて、組込みシステムに伝える
- 判断する: 組込みシステムが測った温度を90度と比べて、加熱を続けるか、ドリップを始めるかを決める
- 動かす: 90度未満のあいだはヒーターへの通電を続けて加熱し、90度に達したらアクチュエーター(ポンプや電磁弁)を動かしてドリップを始める

センサーは測るだけ、アクチュエーターは動かすだけで、判断はあいだに立つ組込みシステムが行います。この役割分担が書ければ正解です。

</details>

## 確認クイズ

### Q1. AND・OR・NOTなど、1つの論理演算を行う論理回路の基本部品を何と呼びますか。

- A. レジスタ
- B. ゲート
- C. センサー
- D. クロック

<details>
<summary>答え</summary>

**B** — 1つの論理演算を行う基本部品がゲートで、ゲートを組み合わせた電子回路が論理回路です。Aのレジスタは値を保持するCPU内の記憶場所、Dのクロックは動作のタイミングを合わせる信号です。

</details>

### Q2. 出力 Y = NOT(A AND B) の論理回路で、出力Yが0になる入力の組み合わせはどれですか。

- A. A = 0, B = 0
- B. A = 0, B = 1
- C. A = 1, B = 0
- D. A = 1, B = 1

<details>
<summary>答え</summary>

**D** — 内側の A AND B が1になるのは両方が1のときだけで、それをNOTで反転したYはそのときだけ0になります。残りの3通りはANDが0なので、Yは1です。

</details>

### Q3. 2進数1桁の加算を行う半加算器で、和と桁上がりを求める論理演算の組み合わせはどれですか。

- A. 和はXOR、桁上がりはAND
- B. 和はAND、桁上がりはXOR
- C. 和はOR、桁上がりはAND
- D. 和はXOR、桁上がりはOR

<details>
<summary>答え</summary>

**A** — 和は「入力が異なるときだけ1」なのでXOR、桁上がりは「両方1のときだけ1」なのでANDです。1 + 1 = 10 の1通りだけ桁が上がることを真理値表で確かめると、この対応を思い出せます。

</details>

### Q4. 家電や自動車などの機器に組み込まれ、その機器の特定の機能だけを担うコンピュータシステムを何と呼びますか。

- A. 汎用システム
- B. デュアルシステム
- C. 組込みシステム
- D. 仮想記憶

<details>
<summary>答え</summary>

**C** — 機器に組み込まれて特定の機能専用に働くのが組込みシステムです。何のアプリでも動かせるPCのような汎用の機械と違い、専用だからこそ小型・低消費電力にできます。多くの組込みシステムには、決められた時間内に必ず応答するリアルタイム性が求められます。

</details>

### Q5. エアコンの自動運転で、室温を電気信号に変えて制御装置に伝える部品と、電気信号を受けてファンを回す部品の組み合わせはどれですか。

- A. 部品はどちらもアクチュエーター
- B. 室温を伝えるのがセンサー、ファンを回すのがアクチュエーター
- C. 室温を伝えるのがアクチュエーター、ファンを回すのがセンサー
- D. 部品はどちらもセンサー

<details>
<summary>答え</summary>

**B** — 外の状態を電気信号に変えるのがセンサー(入力装置にあたる)、電気信号を動きに変えるのがアクチュエーター(出力装置にあたる)です。センサーは測るだけ、アクチュエーターは動かすだけと役割を分けて覚えてください。

</details>

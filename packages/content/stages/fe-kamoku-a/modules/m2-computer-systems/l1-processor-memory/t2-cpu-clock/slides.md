# 2-1-2
# CPUの速さはクロックで決まる

基本情報 科目A対策 — Module 2 / レッスン2-1

<!-- ノート: 五大装置の中心だったCPUに寄って、その「速さ」が何で決まるかを1つだけ押さえます。 -->

---

## なぜ必要か

- 同じ作業でも、パソコンによってかかる時間が全然違う
- カタログの「3.2GHz」という数字が何を表すのか分からない
- CPUの速さを比べるための、共通のものさしがほしい

<!-- ノート: つかみ。パソコンのカタログを見比べる場面。GHzの意味はまだ言わない。 -->

---

## 結論

**CPUは命令をクロックに合わせて実行し、クロック周波数が高いほど速い**

- **命令** = CPUにやらせる処理の1つひとつ
- クロック = CPUが動く拍(リズム)。**クロック周波数** は1秒あたりの拍の数

<!-- ノート: 結論を言い切る。行進のかけ声のように、拍に合わせて一歩ずつ命令が進むイメージを話す。 -->

---

## 最小の例

クロック周波数は「1秒あたりの拍の数」です。

| クロック周波数 | 1秒あたりの拍の数 |
| --- | --- |
| 1GHz | 10億回 |
| 2GHz | 20億回 |
| 3.2GHz | 32億回 |

同じ種類のCPUなら、3.2GHzは1GHzより多くの命令をこなせます。

<!-- ノート: GHzのG(ギガ)は10億。数字が拍の数に直結することを表で確認する。「同じ種類なら」の条件は次のスライドの伏線。 -->

---

## 「高い=常に速い」とは限らない

- CPUの設計によって、1回の拍でこなせる仕事量が違う
- 設計が違うCPU同士は、クロック周波数だけでは比べられない
- 試験では「周波数が高いほうが常に速い」型の選択肢が誤り

# 2-3-3
# 仮想記憶はメモリ不足を補う

基本情報 科目A対策 — Module 2 / レッスン2-3

<!-- ノート: OSの管理の中身、2つ目は主記憶の管理です。容量の壁をどう越えるかを1つだけ押さえます。 -->

---

## なぜ必要か

- タスクは主記憶に置かれてから実行される
- しかし主記憶の容量には限りがある
- アプリケーションをたくさん開くと、入り切らなくなる

<!-- ノート: つかみ。主記憶が満杯になったら新しいアプリは開けないのか、と問いかける。答えはまだ言わない。 -->

---

## 結論

**仮想記憶は補助記憶を使って、主記憶より大きなメモリ空間を見せる仕組み**

- 入り切らない分は補助記憶装置に置いておく
- タスクからは、大きな1つのメモリ空間に見える

<!-- ノート: 結論を言い切る。足りない分を補助記憶で水増しして見せる、という比喩で腹落ちさせる。 -->

---

## 最小の例

| 場所 | 置くもの |
| --- | --- |
| 主記憶 | いま使っている部分 |
| 補助記憶装置 | いま使っていない部分(退避) |

- 必要になったら、補助記憶から主記憶へ戻す
- 固定サイズのページに区切って出し入れする方式が **ページング**

<!-- ノート: 最小の例。使う部分だけ主記憶に置く、が核心。決まった大きさで区切ると出し入れの管理が簡単になる、とページングを添える。 -->

---

## 注意: 出し入れが増えると遅くなる

- 補助記憶装置は主記憶よりアクセス時間が長い
- 主記憶が小さすぎると、ページの出し入ればかりになる
- 「仮想記憶があれば主記憶は不要」は誤り

<!-- ノート: 失敗例で補強。速さは主記憶のまま増えるわけではない。試験の誤答選択肢になりやすいポイント。 -->

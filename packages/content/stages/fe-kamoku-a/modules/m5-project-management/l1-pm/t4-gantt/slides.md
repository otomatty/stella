# ガントチャートで進捗を見える化

## なぜ必要か

- WBSで作業は洗い出した。計画どおり進んでいる?
- 「順調です」の報告だけでは、遅れに気づけない
- どの作業がどれだけ進んだか、一目でわかる図がほしい

<!-- ノート: つかみ。口頭の報告は当てにならない、図で見たいという要求。答えはまだ言わない。 -->

---

## 結論

**ガントチャートは、作業ごとの予定と実績を横棒で見える化する図**

- 縦に作業、横に日付を並べ、横棒で期間を表す
- 予定に対する進み具合が **進捗**

<!-- ノート: 結論を言い切る。予定の棒と実績の棒を見比べる図、とだけ覚えれば読める。 -->

---

## 最小の例

| 作業 | 1日 | 2日 | 3日 | 4日 |
| --- | --- | --- | --- | --- |
| 設定(予定) | ■ | ■ | | |
| 設定(実績) | ■ | ■ | ■ | |
| 確認(予定) | | | ■ | ■ |

<!-- ノート: 設定の実績の棒が予定より長い=1日遅れている。棒の長さの差がそのまま進捗の遅れとして読める。 -->

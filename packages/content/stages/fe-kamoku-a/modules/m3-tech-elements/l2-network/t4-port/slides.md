# 3-2-4
# ポート番号はアプリの窓口

基本情報 科目A対策 — Module 3 / レッスン3-2

<!-- ノート: IPアドレスで機器までは届きました。ただ、それだけではまだ足りない場面があります。 -->

---

## なぜ必要か

- サーバー(サービスを提供する機器)1台に、Webとメールのアプリが同居することがある
- IPアドレスで特定できるのは「どの機器か」まで
- 届いたデータをどちらのアプリに渡すか、決め手がほしい

<!-- ノート: つかみ。1台のサーバーに複数のアプリが同居している現実を見せて、機器の特定だけでは足りないと気づかせる。答えはまだ言わない。 -->

---

## 結論

**ポート番号は、同じ機器の中のどのアプリに届けるかを区別する番号**

- 宛先は「IPアドレス + ポート番号」の組で指定する
- **HTTP**(Webページをやり取りするプロトコル)は80番を使う

<!-- ノート: 結論を言い切る。HTTPと80番の対応だけ覚えれば十分。他のプロトコルの番号一覧は、ここでは暗記しない。 -->

---

## 最小の例

| 宛先 | 届く先 |
| --- | --- |
| 203.0.113.10 の 80番ポート | Webのアプリ(HTTP) |
| 203.0.113.10 の別の番号のポート | メールのアプリ |

- 同じ機器宛でも、ポート番号でアプリを振り分けられる

<!-- ノート: 同じIPアドレス宛の2つの通信が、ポート番号だけで別々のアプリに届く様子を確認する。 -->

---

## 住所と窓口

- IPアドレス = 建物(機器)を特定する住所
- ポート番号 = 建物の中の窓口(アプリ)の番号
- 住所だけでは、どの窓口宛の用件か分からない

<!-- ノート: 補強枠。役所の建物と窓口番号の比喩で、IPアドレスとポート番号の役割分担を1枚にまとめる。 -->

# 3-2-3
# IPアドレスは機器の住所

基本情報 科目A対策 — Module 3 / レッスン3-2

<!-- ノート: プロトコルという約束事の中でも、まず覚えるべきは「宛先の指定方法」です。 -->

---

## なぜ必要か

- ネットワークにはたくさんの機器がつながっている
- データを届けるには「どの機器宛か」を指定する必要がある
- 住所のない手紙が届かないのと同じ

<!-- ノート: つかみ。宛先を特定する仕組みが要る、という必然だけを作る。番号の名前はまだ出さない。 -->

---

## 結論

**IPアドレスは、ネットワーク上の機器を特定する番号**

- `192.168.1.10` のように数値で表す
- 通信では、宛先の機器をIPアドレスで指定する

<!-- ノート: 結論を言い切る。住所の比喩で覚える。番号の内部構造(ビット数など)には深入りしない。 -->

---

## 最小の例

| 機器 | IPアドレス |
| --- | --- |
| 自分のPC | 192.168.1.10 |
| 同僚のPC | 192.168.1.11 |
| 社内のプリンター | 192.168.1.20 |

- 同じネットワークの中では、番号の重複は許されない

<!-- ノート: 社内の機器に1台ずつ番号が振られているイメージを持たせる。重複したら宛先が定まらないので、住所と同じく一意である必要がある。 -->

---

## グローバルとプライベート

| 種類 | 使う場所 | 一意の範囲 |
| --- | --- | --- |
| **グローバルIPアドレス** | インターネット | 世界で一意 |
| **プライベートIPアドレス** | 拠点の中 | その拠点の中だけ |

- 別々の会社が同じプライベートIPアドレスを使ってもよい

<!-- ノート: 対比枠。世界で通用する住所と、社内だけで通用する内線番号のような住所、という違い。この区別は試験の定番。 -->

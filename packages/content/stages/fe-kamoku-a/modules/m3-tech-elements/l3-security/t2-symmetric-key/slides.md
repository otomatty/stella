# 3-3-2
# 共通鍵暗号は同じ鍵を共有する

基本情報 科目A対策 — Module 3 / レッスン3-3

<!-- ノート: 三要素のうち、機密性を守る代表的な技術が暗号です。まずは基本形の共通鍵暗号方式から。 -->

---

## なぜ必要か

- データは送る途中で第三者に盗み見られるおそれがある
- そのまま送れば、見られた時点で機密性が崩れる
- 途中で見られても読めない形にして送りたい

<!-- ノート: つかみ。はがきに書いた内容は配達員にも読める、という例え。読めない形に変えて送る仕組みが必要になる。 -->

---

## 結論

**共通鍵暗号方式は暗号化と復号に同じ鍵を使い、高速だが鍵の受け渡しが課題**

- 平文 = そのまま読める元のデータ
- 暗号文 = 読めない形に変換したデータ
- 暗号化 = 平文を暗号文にすること、復号はその逆
- 鍵 = この変換に使う秘密の情報

<!-- ノート: 用語を4つ一気に定義する。暗号化の逆は「復号」であって「復号化」ではない、と一言添える。 -->

---

## 最小の例

1. 送る側: 平文を **鍵K** で暗号化して送る
2. 途中で盗み見られても、暗号文なので読めない
3. 受け取る側: 同じ **鍵K** で復号して平文に戻す

送る側と受け取る側が、**同じ鍵**をあらかじめ共有します。

<!-- ノート: 家の合鍵のイメージ。同じ鍵を持つ2人だけが、閉めることも開けることもできる。処理が単純なので高速に動く。 -->

---

## 課題: 鍵をどう渡すか

- 鍵K自体を盗まれたら、暗号文はすべて読まれてしまう
- では、その鍵Kをどうやって安全に相手へ届けるのか
- さらに、相手ごとに別の鍵が必要。相手がn人なら鍵はn個

# 3-3-5
# 代表的なサイバー攻撃

基本情報 科目A対策 — Module 3 / レッスン3-3

<!-- ノート: レッスンの締めは攻める側の手口です。守る技術の意味は、攻撃を知ると初めて腹落ちします。 -->

---

## なぜ必要か

- 攻撃の被害は「ウイルスに感染した」と一括りで語られがち
- しかし実際の手口は、狙いも被害もまったく別物
- 区別できないと、事例を読んで答える問題に手が出ない

<!-- ノート: つかみ。ニュースで聞く攻撃の名前を挙げてもらうイメージ。名前は知っていても中身を言えない、が出発点。 -->

---

## 結論

**サイバー攻撃は「何を狙う手口か」とセットで名前を覚える**

- 名前の丸暗記では、事例問題に対応できません
- 「この手口は何を奪い、何を止めるのか」まで覚えます

<!-- ノート: 結論を言い切る。覚え方の方針を示すトピックなので、次のスライドの表が本体になる。 -->

---

## 最小の例 — 5つの手口

| 名前 | 何を狙う手口か |
| --- | --- |
| マルウェア | 悪意を持って作られたソフトウェアの総称 |
| ランサムウェア | データを使えなくし、身代金を要求する |
| フィッシング | 偽サイトへ誘導し、情報をだまし取る |
| DoS攻撃 | 大量の通信を送りつけ、サービスを止める |
| 標的型攻撃 | 特定の組織を狙い、巧妙に仕掛ける |

<!-- ノート: マルウェアだけは個別の手口ではなく総称で、ランサムウェアはその一種。フィッシングは本物そっくりのサイトによる、なりすましの一種と補足する。 -->

---

## 三要素と対応づける

- ランサムウェア → データが使えない = **可用性** を脅かす
- フィッシング → 情報が漏れる = **機密性** を脅かす
- DoS攻撃 → サービスが止まる = **可用性** を脅かす

<!-- ノート: 補強枠。冒頭の三要素とつなげる。「この攻撃はどの要素を脅かすか」という形式の問題がそのまま出る。 -->

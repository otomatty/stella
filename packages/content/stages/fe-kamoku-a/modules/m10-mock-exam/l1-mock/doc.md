# レッスン10-1 模擬試験

## このレッスンの目標

- [ ] 1問90秒を上限に、迷ったら消去法で選んで次へ進む時間配分を実行できる
- [ ] 講座全範囲の問題を、制限時間内に解き切れる
- [ ] 直前チェックリストで知識の抜けを自分で点検できる

## 10-1-1 本番の時間配分

> **科目Aは1問90秒、迷ったら消去法で1つ選んで次へ進むのが時間配分の基本**

この講座の締めくくりです。ここまでに、基礎理論・コンピュータシステム・技術要素・開発技術・マネジメント・戦略・企業と法務まで、科目Aの全分野を一通り学びました。最後に学ぶのは、その知識を本番で出し切るための **時間配分**(制限時間を問題にどう割り振るかの計画)です。

科目Aは90分で60問です。単純に割ると1問90秒ですが、90秒は「上限の目安」として使います。試験は **CBT**(会場のパソコンで受ける方式)なので、迷った問題には画面の「後で見直す」機能で印を付けられます。手順は次のとおりです。

1. 1周目は、知識問題を30〜60秒、計算問題を90秒のペースで、全問に触れます
2. 90秒で答えが決まらない問題は、その場で消去法で1つ選び、「後で見直す」の印を付けて次へ進みます
3. 1周目を約75分で終え、残り15分で印を付けた問題に戻ります
4. 最後に、未解答の問題が残っていないかを画面で確かめます

印を付けて進むのは諦めではありません。後ろに解ける問題が残っているのに、1問に5分粘るのがいちばんの失敗です。全問に触れてから戻るほうが、合計の得点は高くなります。

答えを選ぶときは **消去法**(誤りと判断できる選択肢を消して候補を絞る解き方)を使います。正解が分からなくても、明らかに違う選択肢は消せることが多いからです。四肢択一なので、2つ消せば正答率は50%まで上がります。**空欄は0点なので、迷っても必ず1つ選んでから進んでください。**

計算問題(基数変換・稼働率・損益分岐点など)は、後回しにすると時間切れで丸ごと落とします。1周目でそのまま解くのが原則です。逆に、用語の意味を思い出せない知識問題は、粘っても出てこないことがほとんどです。ここで消去法に切り替えるのが、時間を守るいちばんのコツです。

## 直前チェックリスト

試験の直前に、1行ずつ「説明できるか」を確かめてください。

基礎理論とコンピュータシステム(M1・M2):

- [ ] 2進数4桁が16進数1桁に対応する(`1011` = B)
- [ ] 2の補数を使うと、引き算を足し算として計算できる
- [ ] ド・モルガンの法則は、ANDとORを入れ替えて個別に否定する
- [ ] 稼働率は MTBF ÷ (MTBF + MTTR)。直列は掛け算、並列は「全滅しない確率」
- [ ] キャッシュメモリはCPUと主記憶の速度差を埋め、仮想記憶は主記憶より広い空間を見せる
- [ ] 半加算器は、XORで和・ANDで桁上がりを求める1桁の加算回路

技術要素(M3):

- [ ] 主キーは行を一意に特定し、外部キーは他のテーブルの主キーを参照する
- [ ] トランザクションは、コミットで確定しロールバックで開始前に戻す
- [ ] IPアドレスは機器の住所、ポート番号はアプリの窓口、DNSは名前とIPアドレスの対応づけ
- [ ] 共通鍵暗号は同じ鍵、公開鍵暗号は公開鍵で暗号化し秘密鍵で復号する
- [ ] デジタル署名は送信者の秘密鍵で署名し、送信者の公開鍵で検証する
- [ ] 音声のデジタル化は、標本化 → 量子化 → 符号化の順
- [ ] 可逆圧縮(ZIP・PNG)は完全に元へ戻り、非可逆圧縮(JPEG・MP3)は戻らない代わりに小さくできる

開発技術とマネジメント(M4・M5・M6):

- [ ] テストは単体・結合・システム・受入れの順に範囲を広げる
- [ ] ブラックボックスは入力と出力、ホワイトボックスは内部の通り道に着目する
- [ ] クリティカルパスは余裕のない経路で、遅れが納期に直結する
- [ ] インシデント管理は原因究明より復旧を優先する(原因究明は問題管理)

戦略と企業・法務(M7・M8・M9):

- [ ] クラウドサービスは、自分で管理する範囲が広い順に IaaS・PaaS・SaaS
- [ ] 調達は RFI で情報を集め、RFP で提案を求める
- [ ] SWOT分析は4象限で現状を整理し、PPMは市場成長率と市場占有率で事業を分類する
- [ ] 技術が事業になるまでの関門は、魔の川 → 死の谷 → ダーウィンの海の順
- [ ] 損益分岐点売上高は、固定費 ÷ (1 − 変動費率) で求める
- [ ] 著作権は作った時点で自動発生、特許権は出願と審査が必要

答えに詰まった行があれば、該当レッスンの doc.md に戻って読み直してください。

## もっと知りたい人へ

- 時間配分は練習しないと身に付きません。演習のクイズを、実際にタイマーで時間を計って解いてみてください
- 計算問題は手順を覚えるより、手を動かした回数がそのまま速さになります。基数変換と稼働率は特に反復しておくと安心です

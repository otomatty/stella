# HTML/CSSとデザイン基礎のカリキュラム

新カリキュラムの M02 に対応し、予定時間は71.5時間です。2026-11-19 のオーナー決定で、`dev-env-basics` からファイル操作と確認A・Bの2単元（1.5時間）を冒頭に移しました。HTML/CSS の続きの教材は準備中です。

## 到達目標

HTMLとCSSで、読みやすく画面幅に対応したページを作れる。

## 前提ステージ

「STELLAの使い方」(`dev-env-basics`) を修了し、VS Code と STELLA 拡張、学習フォルダーを準備しておきます。

## 冒頭の単元

| 単元 | フォルダー名 | 内容 | 時間 |
| --- | --- | --- | ---: |
| U00 | `u00-files` | ファイルの作成・名前の変更・保存先の確認 | 1 |
| U01 | `u01-check-a` | ファイル操作の確認Aと確認B | 0.5 |

U00 の課題は「メモのファイルを作る」(`q01-note-file`) と「ファイルの名前を変える」(`q03-rename`) です。U01 では「自己紹介のフォルダーを整える」(`a01-check-a`) を提出します。このステージの確認Aに合格してから7日後に、確認B「1週間の予定のフォルダーを整える」(`b01-check-b`) の学習予定日になります。

続きの教材の公開予定は、末尾の「続きは準備中」(`u99-coming-soon`) で案内します。

## 予定している内容

- 見出しと情報構造
- リンク・画像・一覧
- フォーム
- ボックスモデルとカスケード
- Flexbox・Grid
- 画面幅への対応
- 余白・文字・色の規則

相対リンクの単元では `relative-link` を評価します。冒頭の課題は `static-web-02` の環境で、`static-preview` を使って確認します。

単元の一覧は [01 §3 M02 HTML CSSとデザイン基礎](../../../../docs/curriculum/01-content-split-and-learning-order.md#m02-html-cssとデザイン基礎) を参照してください。

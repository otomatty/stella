## 結論

**フォーマッタで整形を自動化すると、レビューが本質的な指摘に集中できる**

- コードの見た目を機械的に整える道具が **フォーマッタ**
- 人が変更を読んで確認する作業が **コードレビュー**

## 整形の前と後

```python
x = {'total':300,  'tax':30}
```

```python
x = {"total": 300, "tax": 30}
```

- 中身は同じ。書き方だけがそろう

## 何をどこに任せるか

| 種類 | 例 |
| --- | --- |
| フォーマッタ | 空白・改行・引用符 |
| lint | 未使用の変数・危うい書き方 |
| コードレビュー | 仕様の解釈・設計・命名 |

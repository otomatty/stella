# 5-1-2
# 依存は引数で渡すと差し替えられる

Pythonテスト自動化とCI入門 — Module 5 / レッスン5-1

<!-- ノート: 隠れた依存を見つけたあとの、具体的な直し方です。 -->

---

## なぜ必要か

- テストのために、システムの日付を変えて実行している
- テスト専用の分岐をコードに入れてしまい、本番の動きが読めない

<!-- ノート: つかみ。テストのために本番コードを歪める前に、渡し方を変える。ここで結論は言わない。 -->

---

## 結論

**依存を引数で渡す(注入する)と、テストのときだけ差し替えられるようになる**

- 依存先を外から渡す形にすることが **依存性の注入**
- 渡す先を変えるだけなので、本番コードに分岐は要らない

<!-- ノート: 結論を言い切る。難しい仕組みではなく、引数を1つ増やすだけ。 -->

---

## 最小のコード

```python
import datetime


def is_campaign_period(today):
    return today.month == 12


def test_december_is_campaign():
    assert is_campaign_period(datetime.date(2026, 12, 1)) is True
```

- 呼び出し側が今日の日付を渡す
- テストは好きな日付を渡せる

<!-- ノート: 関数の中から datetime.date.today() が消えた。誰が時刻を知るかを、外へ押し出しただけ。 -->

---

## 既定値で呼び出し側を楽にする

```python
def is_campaign_period(today=None):
    today = today or datetime.date.today()
    return today.month == 12
```

- 本番は引数なしで呼べる
- テストのときだけ日付を渡す

<!-- ノート: 対比枠。既存コードに後から入れるときはこの形が使いやすい。呼び出し側を全部直さずに済む。 -->

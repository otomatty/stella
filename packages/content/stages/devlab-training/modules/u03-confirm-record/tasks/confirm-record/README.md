# 一覧から下書きを確定する

`src/RecordList.jsx` を編集します。作業名と時間を表示する一覧と、渡された ID の記録を確定する処理は準備済みです。

1. 各行に「下書き」または「確定」を表示します。
2. 下書きの行にだけ「確定する」ボタンを置きます。
3. クリックした行の ID を、引数で受け取った `onConfirm` に渡します。

課題フォルダーで「STELLA: 課題を確認する」を実行してから `npm run dev` を実行し、ターミナルに出たローカル URL をブラウザで開きます。`2026-W12` に切り替え、同じ作業名の2件のうち片方を確定します。押した行の状態だけが「確定」に変わり、ボタンが消えること、もう片方も引き続き操作できることを確認します。

コードは自分で書きます。指定された編集ファイルを保存し、確認が通ったら VS Code の課題パネルから提出します。

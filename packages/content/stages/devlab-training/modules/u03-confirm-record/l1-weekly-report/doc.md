# 一覧で下書きを見分ける

## このレッスンの目標

- [ ] 記録の状態に応じて文言とボタンを表示できる
- [ ] 同じ作業名の行でも、操作した行だけが確定することを確かめられる

## 行の表示と操作をつなぐ

> **ボタンの操作は、その行の ID を使って記録の更新につなげます。**

React では、画面の一部をコンポーネントという名前付きの部品として書きます。配布された `RecordList` は表示する記録と、ID を受け取る確定処理を引数で受け取ります。画面の要素を JavaScript の中で書く構文を JSX と呼びます。

`status` が `draft` の場合は下書きと表示し、操作のボタンを置きます。`confirmed` の場合は確定と表示します。クリック時に呼ぶ処理は、次の例のように `onClick` に関数を渡します。

```jsx
<button type="button" onClick={() => showMessage("準備完了")}>
  確認する
</button>
```

この例ではクリック時に「準備完了」を表示する処理が呼ばれます。作業名が同じ記録もあるので、週報の更新には各行の ID を使います。確定後は更新された状態を React が表示に反映します。

## 操作前後の行を照らし合わせる

同じ作業名の下書きが2件ある週を開きます。片方のボタンを押し、その行からボタンが消え、もう片方にはボタンが残ることを確認します。最後に残ったボタンも押せるか試します。

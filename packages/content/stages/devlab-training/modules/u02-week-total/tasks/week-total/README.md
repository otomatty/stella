# 指定した週の合計を出す

`src/sum-week.ts` の `sumWeek` を完成させます。最初の引数は作業記録の配列、2つ目は対象週です。戻り値は合計分数です。

- 同じ週の確定30分と下書き20分は合計50分です。この章では下書きも足します。
- 時間が未入力の記録は合計に0分を足します。
- 対象週の記録が0件のときは0分を返します。

`src/other-week.test.ts` のテストを自分で1件完成させます。入力として対象週の記録を用意し、別の週の60分の記録を加える前後で、対象週の合計が変わらないことを確かめてください。作成したテストはコードと一緒に提出されます。`tests/sum-week.test.ts` は配布テストです。

「STELLA: 課題を確認する」で両方のテストを実行します。依存のインストール後、課題フォルダーで `npm run demo` を実行すると、端末で週報と合計を確認できます。

コードは自分で書きます。指定された編集ファイルを保存し、確認が通ったら VS Code の課題パネルから提出します。

# 週報の記録を API で返す

`src/app.ts` の Hono アプリに、週の一覧と記録の確定を実装します。`src/types.ts` に作業記録の型、`src/records.ts` に見本の記録、`src/sum-week.ts` に第2単元の集計処理があります。

| リクエスト                           | 状態コード | JSON の中身                                            |
| ------------------------------------ | ---------- | ------------------------------------------------------ |
| `GET /weeks/:week/records`           | 200        | `{ week, records, total }`。指定週の記録と分単位の合計 |
| 対象週が `YYYY-Www` の形でない `GET` | 400        | `{ error: "理由を伝える文" }`                          |
| `POST /records/:id/confirm`          | 200        | 確定した作業記録そのもの                               |
| 存在しない ID への `POST`            | 404        | `{ error: "理由を伝える文" }`                          |

- 対象週は年4桁、大文字の `W`、週番号2桁を使います。例は `2026-W10` です。暦上の週番号の範囲は今回の検査に含めません。
- 合計には下書きも含めます。時間が未入力の記録も一覧に残し、集計は配布済みの `sumWeek` を呼び出します。記録のない週は空の一覧と合計0分を返します。
- `POST` の入力は URL に含まれる ID です。指定した ID の状態を `confirmed` にし、同じアプリへの次の `GET` にも反映させます。記録はアプリのメモリに持ちます。

「STELLA: 課題を確認する」で型と動作を確認します。配布テストは `app.request()` でリクエストを渡すので、サーバーの起動は不要です。確認が通ったら VS Code の課題パネルから提出します。

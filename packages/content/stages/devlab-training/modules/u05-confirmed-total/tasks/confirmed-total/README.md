# 週報の合計を確定分に変える

> 週報の合計には確定分だけを含めたい。下書きも引き続き一覧で見たい。

`src/App.tsx` と `src/sum-week.ts` を読み、変更する箇所を探して、対象週の確定分だけを集計してください。画面では「合計」を「確定分の合計」に変えます。

| 入力・操作 | 確認する結果 |
| --- | --- |
| 確定30分と下書き20分の `2026-W10` を開く | 一覧に両方が残り、確定分の合計は30分 |
| 下書き20分の「確定する」を押す | その行が確定に変わり、再読み込みせずに確定分の合計は50分 |
| 下書きだけの `2026-W12` を開く | 下書きの行とボタンが見え、確定分の合計は0分 |
| 元の週の確定が50分になった状態で、別の週に確定60分のあるデータを使い元の週を開く | 確定分の合計は50分のまま |

「STELLA: 課題を確認する」で4つの条件を確かめます。課題フォルダーで `npm run dev` を実行し、ターミナルに出たローカル URL をブラウザで開きます。別の週の60分は配布済みの `2026-W11` にあります。1つ目の週で50分になったあとにその週に切り替え、元の週に戻って表示を確かめます。

提出画面の「今回の振り返り」に、変更箇所と、自分で試した入力・操作・表示結果を短く書きます。変更したファイルは提出時に一緒に送られます。

コードは自分で書きます。指定された編集ファイルを保存し、確認が通ったら VS Code の課題パネルから提出します。

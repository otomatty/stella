# 作業名と時間を表示する

`src/records.ts` で作業記録の型を読み、`src/format-record.ts` の `formatRecord` を完成させます。引数で渡された記録を、作業名と時間を中点「・」でつないだ文字列にしてください。

| 作業名 | 分数 | 期待する表示 |
| --- | --- | --- |
| 設計レビュー | 30 | 設計レビュー・30分 |
| 準備 | 0 | 準備・0分 |
| 設計レビュー | `null` | 設計レビュー・未入力 |

「STELLA: 課題を確認する」で3種類の入力を確かめます。依存のインストール後、課題フォルダーで `npm run demo` を実行すると、端末に対象週の作業記録が出ます。

コードは自分で書きます。指定された編集ファイルを保存し、確認が通ったら VS Code の課題パネルから提出します。

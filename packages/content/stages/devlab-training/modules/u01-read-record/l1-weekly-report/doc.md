# 作業記録1件を読む

## このレッスンの目標

- [ ] 型を読み、どの項目が未入力になりうるか説明できる
- [ ] 30分・0分・未入力に対して作業名と時間の表示を確かめられる

## 作業記録の型を読む

> **数値の 0 と、値が未入力のときに使う `null` は、別々に確かめます。**

週報の記録は、ID、対象週、作業名、作業時間（分）、状態を持ちます。ID は1件を区別するための値です。状態は `draft`（下書き）か `confirmed`（確定）です。

型注釈は、変数や引数にどんな値が入るかをコードに示す書き方です。次の例では、在庫数に数値か `null` が入ります。縦棒 `|` は「どちらか」を表します。

```ts
const stock: number | null = 0;

if (stock === null) {
  console.log("在庫を調べてください");
} else {
  console.log(`在庫は ${stock} 個`);
}
// 結果: 在庫は 0 個
```

条件分岐は、条件に応じて実行する処理を選ぶ書き方です。`=== null` を使うと、0 のときは `else` に進みます。値があるかを `if (stock)` だけで確かめると、0 も未入力と同じ分岐に進みます。

## 表示をテストで確かめる

テストは、入力に対して実際の結果と期待した結果を比べるコードです。まず「設計レビュー・30分」のように期待する文字列を書き出し、次に `0` と `null` でも予想してからテスト結果を読みます。研修のコードは自分の手で書き、確認が通ったら VS Code の課題パネルから提出します。

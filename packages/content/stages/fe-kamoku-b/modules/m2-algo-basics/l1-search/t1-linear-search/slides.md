# 線形探索は先頭から順に調べる

基本情報 科目B対策 — Module 2 / レッスン2-1

<!-- ノート: ここからアルゴリズム(問題を解く手順)の学習に入ります。最初は、配列から目的の値を探す「探索」です。 -->

---

## なぜ必要か

- 「会員番号の一覧から 1024 番を探す」など、値を探す処理は頻出です
- 配列の走査は学びました。では「見つかったかどうか」はどう判定するのでしょうか

<!-- ノート: つかみ。for で配列を順に見る形は前レッスンでやった。そこに「探して、見つかったら答える」を足すとどうなるか、と問いを立てる。 -->

---

## 結論

**線形探索は、配列を先頭から1つずつ比較して目的の値を探す**

- 各要素と目的の値を順に **比較** する
- 一致したら、その添字が答えになります

<!-- ノート: 比較とは、2つの値が等しいかを調べることです。先頭から順に、というのが線形探索の名前の由来です。 -->

---

## 最小のコード

```text
for (i を 1 から 5 まで 1 ずつ増やす)
  if (data[i] が target と等しい)
    return i
  endif
endfor
```

<!-- ノート: for で添字 i を動かし、data[i] と target を比較します。等しくなった瞬間に return するので、それ以降は調べません。 -->

---

## 見つからないときは -1 を返す

```text
endfor
return -1
```

- 最後まで一致しなければ、繰返しを抜けます
- 「無かった」の合図として **-1** を返すのが定番です

<!-- ノート: 補強枠。添字は1から始まるので、-1 は絶対に添字と重ならない。だから「見つからない」の印に使える、と説明する。 -->

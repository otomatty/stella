# レッスン3-2 演習 — 再帰

対象トピック: 3-2-1 〜 3-2-3

## ハンズオン

紙とペンを用意して、fact(4) をトレースします。対象は次の関数です。

```text
○fact(整数型: n)
  if (n が 1 以下)
    return 1
  endif
  return n × fact(n − 1)
```

まず潜る段階を表に書きます。基底条件に届くまで続けてください。

| 呼び出し | n が 1 以下か | 動き |
| --- | --- | --- |
| fact(4) | 偽 | 4 × fact(3) を求めるため fact(3) を呼ぶ |
| fact(3) | 偽 | ... |
| ... | ... | ... |

次に戻る段階を表に書き、戻り値を順に確定させます。

| 呼び出し | 確定する戻り値 |
| --- | --- |
| fact(1) | 1 |
| fact(2) | ... |
| ... | ... |

最後に、fact(4) の戻り値と呼び出しの合計回数を確かめてください(答え: 戻り値 24、呼び出しは fact(4) 自身を含めて4回)。

## 演習問題

### 問1(基本)

ハンズオンと同じ fact を fact(5) で呼び出したとき、戻り値と呼び出しの合計回数を答えてください。

### 問2(基本)

次の関数 sum を sum(4) で呼び出したとき、戻り値を答えてください。値が確定する順序も書いてください。

```text
○sum(整数型: n)
  if (n が 1 以下)
    return 1
  endif
  return n + sum(n − 1)
```

### 問3(応用)

次の関数 fib を fib(5) で呼び出したとき、fib(2) が呼ばれる回数と、呼び出しの合計回数を答えてください。呼び出しを枝の形に書き出して数えてください。

```text
○fib(整数型: n)
  if (n が 2 以下)
    return 1
  endif
  return fib(n − 1) + fib(n − 2)
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

戻り値は 120、呼び出しは合計5回です。

fact(5) → fact(4) → fact(3) → fact(2) → fact(1) と潜り、fact(1) が 1 を返します。戻る段階で 2 × 1 = 2、3 × 2 = 6、4 × 6 = 24、5 × 24 = 120 と確定します。呼び出しは fact(5) 自身を含めて5回です。

</details>

<details>
<summary>問2の解答例</summary>

戻り値は 10 です。値が確定する順序は sum(1) → sum(2) → sum(3) → sum(4) です。

sum は 1 から n までの和を求める再帰です。sum(1) = 1、sum(2) = 2 + 1 = 3、sum(3) = 3 + 3 = 6、sum(4) = 4 + 6 = 10 と、基底条件から順に確定します。掛け算が足し算に変わっただけで、動きは fact と同じです。

</details>

<details>
<summary>問3の解答例</summary>

fib(2) は3回呼ばれ、呼び出しは合計9回です。

- fib(5)
  - fib(4)
    - fib(3)
      - fib(2) … 1回目
      - fib(1)
    - fib(2) … 2回目
  - fib(3)
    - fib(2) … 3回目
    - fib(1)

fib(3) も2回計算されています。同じ計算の重複が、呼び出し回数を急激に増やす原因です。

</details>

## 確認クイズ

### Q1. 再帰の説明として、最も適切なものはどれですか。

- A. 同じ処理を while文 で繰り返す書き方
- B. 2つの関数が交互に呼び出し合う書き方
- C. 関数が自分自身を呼び出す書き方
- D. 関数を配列に入れて順に呼び出す書き方

<details>
<summary>答え</summary>

**C** — 再帰は関数が自分自身を呼び出す書き方です。引数を小さくしながら呼び、基底条件で止まります。

</details>

### Q2. 再帰の関数から基底条件を取り除くと、どうなりますか。

- A. 呼び出しが止まらず、プログラムが終わらない
- B. 基底条件の戻り値が 0 になるだけで、答えは変わらない
- C. 呼び出しが1回だけになり、すぐ終わる
- D. 引数が自動的に 1 で止まる

<details>
<summary>答え</summary>

**A** — 基底条件は「もう自分を呼ばずに値を返す」止まる条件です。無ければ fact(1) → fact(0) → fact(−1) → … と呼び出しが永遠に続きます。

</details>

### Q3. 関数 f(n) が「n ≦ 1 なら 1、それ以外は n × f(n − 1)」のとき、f(4) の値はどれですか。

- A. 4
- B. 24
- C. 10
- D. 120

<details>
<summary>答え</summary>

**B** — f(4) = 4 × f(3) = 4 × 3 × f(2) = 4 × 3 × 2 × f(1) = 4 × 3 × 2 × 1 = 24 です。1 から 4 までの積、つまり階乗です。

</details>

### Q4. 関数 fact(n) が「n ≦ 1 なら 1、それ以外は n × fact(n − 1)」のとき、fact(3) の実行で戻り値が確定する順序はどれですか。

- A. fact(3) → fact(2) → fact(1)
- B. fact(3) → fact(1) → fact(2)
- C. fact(2) → fact(1) → fact(3)
- D. fact(1) → fact(2) → fact(3)

<details>
<summary>答え</summary>

**D** — 呼び出しは fact(3) → fact(2) → fact(1) と潜りますが、戻り値はいちばん深い fact(1) から順に確定します。潜る向きと正反対です。

</details>

### Q5. 関数 fib(n) が「n ≦ 2 なら 1、それ以外は fib(n − 1) + fib(n − 2)」のとき、fib(5) の計算で fib(3) は何回呼び出されますか。

- A. 1回
- B. 3回
- C. 2回
- D. 5回

<details>
<summary>答え</summary>

**C** — fib(5) が直接呼ぶ fib(3) と、fib(4) の中で呼ばれる fib(3) の2回です。同じ答えを2回計算し直すこの重複が、呼び出し回数の急増につながります。

</details>

# レッスン3-4 演習 — 文字列処理

対象トピック: 3-4-1 〜 3-4-3

## ハンズオン

紙とペンを用意して、文字列探索と回文判定をトレースします。

まず、テキスト "AABAB" からパターン "AB" を探す文字列探索を、開始位置ごとに表へ書き出してください。

1. 開始位置1から順に、「何文字目まで一致したか」「外れたか、全部一致か」を1行ずつ書きます
2. 全部一致した開始位置が答えです(答え: 開始位置2。位置1は A=A のあと A≠B で外れます)
3. 次に、答えの先も続けて調べると、開始位置4でも "AB" が一致することを確かめます(最初に見つかった位置を返すコードなら答えは2のままです)

次に、"MADAM" の回文判定をトレース表で追ってください。

| i | j | moji[i] | moji[j] | 結果 |
| --- | --- | --- | --- | --- |
| 1 | 5 | | | |
| 2 | 4 | | | |
| 3 | 3 | | | |

空欄を埋めて、戻り値が true になることを確かめます。最後に "MADAM" を "MADAN" に変えて同じ表を作り、どの行で false が確定するかを確かめてください(答え: i=1, j=5 で M≠N となり、1行目で確定します)。

## 演習問題

### 問1(基本)

文字型の配列 moji ← {"B", "A", "N", "A", "N", "A"} について、`mojiの要素数` と `moji[3]` の値を答えてください。また、"N" の個数を数えるプログラムを実行したとき、結果はいくつになりますか。

### 問2(基本)

テキスト "ABABC"(5文字)からパターン "ABC"(3文字)を探す文字列探索で、試す開始位置は最大いくつまでですか。式と値で答えてください。また、開始位置2の照合が何回目の比較で外れるかを答えてください。

### 問3(応用)

回文判定のプログラム(先頭の添字 i と末尾の添字 j を両端から中央へ動かして比較する)に、6文字の "REDDER" を渡しました。while の中の比較(moji[i] が moji[j] と等しくないかの判定)は全部で何回実行されますか。トレースして答えてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`mojiの要素数` は **6**、`moji[3]` は **"N"** です(添字は1から始まるので、1文字目が moji[1] です)。

"N" の個数は **2** です。走査で6文字を順に見て、moji[3] と moji[5] の2回だけ「"N" と等しい」が成り立ち、cnt が2になります。

</details>

<details>
<summary>問2の解答例</summary>

開始位置の上限は「textの要素数 − patの要素数 + 1」= 5 − 3 + 1 = **3** です。開始位置4以降は残りが2文字しかなく、3文字のパターンと全部一致することはありえません。

開始位置2の照合は、1回目の比較で text[2] の "B" と pat[1] の "A" を比べて等しくないので、**1回目**で外れます。

</details>

<details>
<summary>問3の解答例</summary>

比較は **3回** 実行されます。

| i | j | moji[i] | moji[j] | 結果 |
| --- | --- | --- | --- | --- |
| 1 | 6 | R | R | 等しい |
| 2 | 5 | E | E | 等しい |
| 3 | 4 | D | D | 等しい |

次は i = 4, j = 3 となり、「i が j より小さい」が成り立たないので while を抜けて true を返します。偶数文字の場合は、すべての文字がちょうど1回ずつ比較の組に入ります。

</details>

## 確認クイズ

### Q1. 文字型の配列 moji ← {"E", "X", "A", "M"} のとき、moji[2] の値はどれですか。

- A. "E"
- B. "X"
- C. "A"
- D. "M"

<details>
<summary>答え</summary>

**B** — 擬似言語の添字は1から始まるので、moji[1] が "E"、moji[2] が "X" です。0始まりと取り違えて "A" を選ばないよう注意してください。

</details>

### Q2. テキスト "ABABC" からパターン "ABC" を、開始位置を1つずつずらす文字列探索で探したとき、全部一致する開始位置はどれですか。

- A. 1
- B. 2
- C. 3
- D. 見つからない

<details>
<summary>答え</summary>

**C** — 開始位置1は A=A、B=B のあと3文字目で A≠C となり外れます。開始位置2は1文字目で B≠A。開始位置3で A=A、B=B、C=C と全部一致します。途中まで一致しても、外れたら開始位置は1つだけ進めるのがポイントです。

</details>

### Q3. テキストの要素数が n、パターンの要素数が m のとき、文字列探索で試す開始位置の上限はどれですか。

- A. n
- B. n − m
- C. n − m + 1
- D. n + m − 1

<details>
<summary>答え</summary>

**C** — 開始位置がそれより後ろだと、残りの文字数が m に足りず、全部一致はありえません。n = 5, m = 3 なら 5 − 3 + 1 = 3 まで試せば十分です。具体的な数字を入れて確かめると、+1 の有無を間違えません。

</details>

### Q4. 開始位置 i からの照合で、パターンの j 文字目と比較するテキストの添字はどれですか。

- A. i + j
- B. i + j − 1
- C. i − j + 1
- D. j

<details>
<summary>答え</summary>

**B** — i = 3, j = 1 のとき比べるのは text[3] なので、式は i + j − 1 です。Aの i + j だと text[4] になってずれます。迷ったら小さい数字を代入して確かめるのが確実です。

</details>

### Q5. 先頭の添字 i と末尾の添字 j を両端から中央へ動かし、moji[i] と moji[j] の組をすべて等しいと確かめる判定で、結果が true になる文字列はどれですか。

- A. "LEVEL"
- B. "EXAM"
- C. "ABABC"
- D. "BANANA"

<details>
<summary>答え</summary>

**A** — この判定は回文(逆から読んでも同じ文字列)の判定です。"LEVEL" は L-L、E-E が一致し、中央の V だけが残るので true になります。ほかの3つは最初の組(先頭と末尾)の時点で不一致です。

</details>

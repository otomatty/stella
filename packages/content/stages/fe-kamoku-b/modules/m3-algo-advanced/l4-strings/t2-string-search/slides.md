# 3-4-2
# 文字列探索は開始位置をずらして照合する

基本情報 科目B対策 — Module 3 / レッスン3-4

<!-- ノート: 文字列処理の中心となるトピックです。検索機能の中身にあたる、単純な文字列探索の動きを押さえます。 -->

---

## なぜ必要か

- 「文書からキーワードの出現位置を探す」のは検索機能そのもの
- 線形探索で探せたのは値1つ。今回は「文字の並び」を探したい
- 並びの途中まで一致して外れることもある。どう調べ切るのか

<!-- ノート: つかみ。M2の線形探索との違いは、探すものが1要素ではなく並びであること。途中まで一致する「惜しい」ケースの扱いが問題になる、と予告する。 -->

---

## 結論

**文字列探索は、比べ始める位置を1つずつずらしながらパターンと1文字ずつ照合する**

- 探す側の短い文字列を **パターン** と呼ぶ
- 位置を合わせて1文字ずつ等しいか確かめることを **照合** と呼ぶ
- この方法での探索を **文字列探索** と呼ぶ

<!-- ノート: 結論を言い切る。開始位置を決める→1文字ずつ照合→外れたら開始位置を1つ進めてやり直し、の繰り返し。 -->

---

## 最小の例

テキスト "ABABC" からパターン "ABC" を探す。

| 開始位置 | 照合の結果 |
| --- | --- |
| 1 | A=A、B=B、A≠C で外れる |
| 2 | B≠A で外れる |
| 3 | A=A、B=B、C=C **全部一致** |

- 答え: パターンは開始位置 **3** から現れる

<!-- ノート: 最小の例。開始位置1では2文字目まで一致して外れるのがポイント。外れたら開始位置を1つだけ進めて最初から照合し直す。 -->

---

## 添字の対応を式にする

- 開始位置 i でパターンの j 文字目と比べるのは、テキストの **i + j − 1** 文字目
- 開始位置は 1 から「テキストの要素数 − パターンの要素数 + 1」まで試せば十分

```text
if (text[i + j − 1] が pat[j] と等しくない)
```

<!-- ノート: 強化枠。i=3, j=1 なら text[3]、j=2 なら text[4]。この添字の式の穴埋めが試験の定番。残りを試す長さが足りない位置は開始位置にならないので、上限は n − m + 1。 -->

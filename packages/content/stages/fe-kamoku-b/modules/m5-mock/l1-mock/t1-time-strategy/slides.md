# 本番の時間配分

基本情報 科目B対策 — Module 5 / レッスン5-1

---

## なぜ必要か

- 科目Bは、じっくりトレースすれば解ける問題がほとんどです
- しかし本番には制限時間があり、全問をじっくり解く余裕はありません
- 1問に長く粘って、後ろの解ける問題を落とすのが典型的な失敗です

<!-- ノート: つかみ。実力があっても時間切れで落とすのがいちばんもったいない。解く力と別に、時間の使い方という技術がある、と問題提起します。 -->

---

## 結論

**科目Bは1問5分、詰まったら飛ばして戻るのが時間配分の基本**

- 5分は上限の目安です。超えそうなら印を付けて次へ進みます
- 飛ばすのは諦めではなく、全問に触れるための手順です

<!-- ノート: 時間配分とは、制限時間を問題にどう割り振るかの計画のことです。飛ばす判断まで含めて、事前に決めた手順として実行します。 -->

---

## 時間配分の目安

| 区分 | 時間 |
| --- | --- |
| 全体 | 100分で20問 |
| 1問あたり | 5分が上限の目安 |
| 1周目 | 80分で全問に触れる |
| 2周目 | 残り時間で印の問題に戻る |

<!-- ノート: 100分を20問で割ると1問5分。ただし全問に5分使うのではなく、1周目は4分ペースで回し、残りを印を付けた問題と見直しに充てます。 -->

---

## 飛ばす判断の基準

- 1分読んでもトレースの書き出しが始められない → 印を付けて次へ
- トレースは頭の中でなく、手を動かして表に書きます
- 戻ったときに続きから再開できるよう、途中のトレース表は残します

<!-- ノート: 補強枠。飛ばす基準を感覚でなく行動で決めておくのがコツです。手が動いているなら続行、動かないなら移動。書いた表は財産なので消さない。 -->

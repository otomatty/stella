# レッスン1-1 擬似言語の基本

## このレッスンの目標

- [ ] 科目Bがどんな形式の試験かを説明できる
- [ ] 宣言・代入・if文・繰返しのプログラムを読み、実行後の変数の値を答えられる
- [ ] 関数の呼び出しで、引数と戻り値の流れを追える

## 1-1-1 科目Bは擬似言語を読む試験

> **科目Bの問題は、擬似言語で書かれたプログラムを読み取って答えを選ぶ形式**

基本情報技術者試験の科目Bは、20問の多肢選択式です。問題の中心は、**擬似言語** で書かれた **プログラム** を読むことです。擬似言語とは、試験用に決められたプログラムの書き方です。特定の製品の言語ではなく、この試験の中だけで使われます。

問題はたとえばこんな見た目です。

```text
x ← 1
x ← x + 2
```

このプログラムを読み、「実行後の x の値はどれか」のような問いに選択肢で答えます。

問われないことも押さえておきましょう。キーボードでプログラムを書いて提出することはありません。用語の一問一答でもありません。紙面のプログラムを読み取る力だけが問われます。だから対策も「読む練習」が中心になります。

## 1-1-2 変数の宣言と代入

> **「整数型: x ← 1」のように、変数は型を付けて宣言し、← で代入する**

プログラムは、値に名前を付けて覚えながら進んでいきます。値に名前を付けた入れ物を **変数** と呼びます。変数を使う準備をすることが **宣言**、変数に値を入れることが **代入** です。

```text
整数型: x ← 1
実数型: y ← 2.5
文字列型: s ← "合格"
```

宣言は「型: 名前」の形で書きます。型は値の種類のことで、まず4つ覚えれば十分です。

| 型 | 入る値 | 例 |
| --- | --- | --- |
| 整数型 | 整数 | 1、-5 |
| 実数型 | 小数を含む数 | 2.5 |
| 文字列型 | 文字の並び | "合格" |
| 論理型 | 成り立つ・成り立たない | true、false |

代入は ← で書きます。読み間違えやすいのが次の形です。

```text
x ← x + 1
```

← を「等しい」と読むと意味が通りません。正しい読み方は「右の x + 1 を先に計算し、その結果を左の x に入れる」です。x が 3 なら、右側の計算で 4 になり、それが x に入り直します。この「右を計算してから左へ」は、科目Bの読解で毎回使う読み方です。

## 1-1-3 if文で処理を分岐する

> **if〜elseif〜else〜endifで、条件式が真のブロックだけが実行される**

プログラムは、いつも上から順に全行が実行されるわけではありません。流れが枝分かれすることを **分岐** と呼び、擬似言語では **if文** で書きます。

```text
if (x > 3)
  y ← 1
else
  y ← 2
endif
```

if の後ろの「x > 3」を **条件式** と呼びます。条件式は、成り立つ(**真**)か成り立たない(**偽**)かが決まる式です。x が 5 なら条件式は真なので、y ← 1 だけが実行され、y は 1 になります。x が 2 なら条件式は偽なので、else 側だけが実行され、y は 2 になります。

if文の中の、ひとまとまりの処理をブロック(処理のまとまり)と呼びます。実行されるブロックは、必ず1つだけです。elseif が並ぶ形では特に注意してください。

```text
if (x > 10)
  y ← 1
elseif (x > 3)
  y ← 2
endif
```

x が 20 のときは両方の条件式が真ですが、実行されるのは上の y ← 1 だけです。elseif の条件式は「上が偽だったときだけ」判定されます。上から順に見て、最初に真になった所で残りは飛ばす。ここが科目Bの定番のひっかけです。

## 1-1-4 繰返し処理を読む

> **whileは条件が真の間、forは指定した範囲を順に繰り返す**

同じブロックを何度も実行することを **繰返し** と呼びます。5行のプログラムでも、実行される回数は5回とは限りません。何回実行されたかを数え違えると、変数の値も答えもずれます。

繰返しの記法は2つあります。範囲を決めて回すのが **for文** です。

```text
x ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  x ← x + i
endfor
```

i は 1、2、3 と変わりながら、間のブロックを3回実行します。x は 0 → 1 → 3 → 6 と増えます。endfor まで来たら for の行に戻る、という流れです。

続けるかを条件式で決めるのが **while文** です。

```text
x ← 0
while (x < 3)
  x ← x + 1
endwhile
```

条件式 x < 3 が真の間だけ繰り返します。x が 0、1、2 のとき条件式は真なので3回実行され、x が 3 になった時点で終わります。条件式を確認するのは毎回、ブロックの実行前です。

読むときのコツは、i や x のように値が変わる変数を、1回ごとにメモすることです。頭の中だけで数えず、手を動かして追ってください。

## 1-1-5 関数の定義と呼び出し

> **関数は引数を受け取り、returnで戻り値を呼び出し元へ返す**

本試験のプログラムは、名前の付いた処理のまとまりとして示されます。この、名前を付けた処理のまとまりを **関数** と呼びます。擬似言語では「○関数名(...)」の行で関数を定義します。

```text
○add(整数型: a, 整数型: b)
  return a + b

x ← add(2, 3)
```

関数に渡す値を **引数**、関数が返す値を **戻り値** と呼びます。**return** は、戻り値を呼び出し元へ返す記法です。

値の往復を順に追ってみましょう。

1. add(2, 3) と呼び出すと、a に 2、b に 3 が入る
2. return a + b の結果 5 が、呼び出し元へ戻る
3. 戻った 5 が x に代入される

行きは引数、帰りは戻り値です。この往復さえ追えれば、関数の形をしたプログラムは怖くありません。実行は「○」の定義の行からではなく、呼び出しの行から始まる点にも注意してください。

## もっと知りたい人へ

- 比較の書き方(>、< など)の細かい記法は、本試験では問題文に説明が付きます。暗記よりも「読んで値を追う」練習に時間を使ってください

# 分野を確かめる予備演習

## このレッスンの目標

- [ ] 8分野から、模擬試験の前に復習する分野を選べます。
- [ ] 外した問題を、戻るトピックと公式ドキュメントで確かめ直せます。

## 10-3-1 弱い範囲を繰り返す

> **分野名を手がかりに解き、判断に迷った条件を一つ控えます。**

ドリルには、模擬試験（9-1-1）とは別の自作問題を 24 問用意しました。問題と選択肢は開始時に並び替わります。「D8・ツールと MCP」のように、設問の冒頭にある分野を目印に記録してください。

| 設問の分野 | 練習する判断 | 基礎ステージで戻る単元 |
| --- | --- | --- |
| D1 | 翻訳の誤りを評価役から生成役へ戻す | M6 |
| D2 | 混雑時に SDK と画面が重ねて再試行する原因を探す | M1・M2 |
| D3 | 個人の設定がチームの設定を上書きした箇所を探す | M8 |
| D4 | 全体の平均に隠れた、担当者への引き継ぎ漏れを測る | M8 |
| D5 | 共通の手引きをキャッシュする条件と費用を比べる | M3 |
| D6 | 返金規定の更新後も必要な根拠を残す | M4 |
| D7 | 承認記録を照会できないときに返金処理を止める | M7 |
| D8 | 注文の照会と結果を呼び出し ID で結ぶ | M5 |

D1〜D8 は 2026 年 12 月 7 日適用の Developer 試験ガイド v1.1 の分野です。各分野を 3 問にそろえたのは、STELLA で復習先を選びやすくするためです。

### 進め方

1. 一問一答で間違えた分野と、正解でも理由を言えなかった分野を控えます。ドリルを資料を閉じて解き、選んだ範囲では決め手になった条件を一つ書きます。
2. 間違えたら「採った案／見落とした条件／戻るトピック」を 1 行にします。例は「2 件の照会結果を到着順で結んだ／ID ごとの照合が必要／5-1-2」です。解説の「復習」から公式資料の該当箇所までたどります。
3. 日を空けて、その範囲の 3 問を解き直します。3 問すべてで根拠を説明でき、紛らわしい選択肢を一つ退けられたら、その範囲の復習を終えます。この判断は講座内の目安です。

最後に条件を一つ変えます。たとえば D5 の手引きの問題で 2 件目が翌日なら、5 分のキャッシュへの読み取りを見込めるでしょうか。D7 で照会が復旧したら、返金処理を実行する前にどの記録を確かめますか。条件の変更で判断がどう変わるかまで説明して、「模擬試験（70問・120分）」に進みます。

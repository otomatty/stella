# 全部を解き直す?
一問一答で正解した場面です。条件を変えた別の問い合わせでも、同じ設計を選んでよいでしょうか。

# 範囲を絞って繰り返す
分野名を手がかりに解き、判断に迷った条件を一つ控えます。

# 問題の冒頭で分野を読む
「D8・ツールと MCP」なら、照会と結果を結ぶ ID を探す。

「D4・評価とデバッグ」なら、どの誤りを測るかを先に決める。

# 外したら
1. 見落とした条件と戻るトピックを 1 行にする
2. 公式資料で確認し、日を空けて 3 問を解き直す
3. 根拠と、ほかの案が条件を満たさない理由を言う

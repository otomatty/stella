## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「リクエストがサーバーに届く経路を、DNS・TLS・ポートで説明できる」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- IP とポート
- DNS の引き方
- HTTP と TLS
- ロードバランサとリバースプロキシ
- ファイアウォールで開ける穴

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

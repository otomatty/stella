# SOQLの基本形

Salesforce開発入門 — Module 3 / レッスン3-1

---

## なぜ必要か

- コードから「この条件のレコードを取ってきて」と言う必要がある
- SQL の書き方をそのまま持ち込むと、動かない書き方が混ざる

<!-- ノート: つかみ。既知の道具に引きずられる場面。違いを先に整理しておくと迷いが減る。 -->

---

## 結論

**SOQL は 1 つのオブジェクトから、欲しい項目を名指しして取り出す**

- **SOQL** — Salesforce のレコードを取り出すための問い合わせ言語
- **クエリ** — 取り出す内容を書いた 1 つの問い合わせ

<!-- ノート: 結論を言い切る。名前はSalesforce Object Query Language。表ではなくオブジェクトを相手にする、という一点が名前に出ている。 -->

---

## 最小のクエリ

```apex
SELECT Name, Phone FROM Account
```

- `FROM` に書くのはオブジェクトの API 参照名
- `SELECT` には欲しい項目を並べる

<!-- ノート: 最小のコード。取引先(Account)から名前と電話を取り出す。SQLと同じ形に見えることを確認してから、次のスライドで違いを言う。 -->

---

## SQL と違うところ

| | SQL | SOQL |
| --- | --- | --- |
| 全列を取る | `SELECT *` | 書けない |
| 相手 | 表 | オブジェクト |

- 項目は必ず名指しする。`*` は使えない

<!-- ノート: 対比枠。*が無いのは、取得量に上限がある基盤だから。必要な項目だけ運ぶ設計になっている、と0-1-2につなげる。 -->

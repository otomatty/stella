# レッスン1-1 演習 — オブジェクトと項目

対象トピック: 1-1-1 〜 1-1-4

## 手元で試す

Developer Edition 組織で、カスタムオブジェクトと項目を作ります。

ここで作るオブジェクトと項目は、レッスン1-2 以降の演習でもそのまま使います。**API 参照名は後続の
Apex がそのまま参照する**ので、表のとおりに入力してください(日本語の表示ラベルからは自動で決まりません)。

1. **オブジェクトを作る** — 設定 → オブジェクトマネージャ → 「作成」→「カスタムオブジェクト」
   - 表示ラベル `点検` / 複数形の表示ラベル `点検` / オブジェクト名 `Inspection`
   - **レコード名は「自動採番」**、表示形式 `点検-{0000}`、開始番号 `1`
     (テキストのままだと名前が必須項目になり、レッスン4-2 でまとめて作る演習が失敗します)
   - 「カスタムタブを作成」にチェックを入れて保存(画面から点検を作れるようにするため)
   - 保存後、API 参照名が `Inspection__c` になっていることを確かめてください
2. **項目を 3 つ足す** — 作った点検オブジェクトの「項目とリレーション」から、次の 3 つを作ります。
   **項目名(API 参照名)** の欄は表のとおりに入力してください

   | 表示ラベル | データ型 | 項目名(API 参照名) |
   | --- | --- | --- |
   | 点検日 | 日付 | `Inspection_Date` |
   | 結果 | 選択リスト(`合格` / `要再点検`) | `Result` |
   | 点検料 | 通貨 | `Fee` |

3. **タブから 1 件作る** — アプリケーションランチャーから `点検` タブを開き、「新規」で 1 件保存します。
   名前を入力する欄が無く、`点検-0001` が自動で付くことを確かめてください
4. **標準オブジェクトと見比べる** — オブジェクトマネージャで `取引先` を開き、項目の一覧を眺めます。自分では作っていない項目がいくつも並んでいることを確かめてください

```text
確かめること
- 保存すると、入力した項目名の末尾に __c が付く(Result → Result__c)
- レコード名が自動採番なので、名前を入力しなくても保存できる
- 結果を選択リストにしたので、自由入力の表記ゆれが起きない
```

## 演習問題

### 問1(基本)

次の 4 つを、標準オブジェクトとカスタムオブジェクトに分けてください。

1. `Contact`
2. `Inspection__c`
3. `Opportunity`
4. `Repair_Order__c`

### 問2(基本)

「点検の合計金額を、点検料に消費税を掛けて表示したい」と頼まれました。税込金額をどう持つべきか、1〜2 文で答えてください。

### 問3(応用)

基幹システムから、毎晩 5,000 件の取引先データを取り込みます。取り込みのたびに同じ会社のレコードが増えてしまう、という相談を受けました。原因と対処を 2〜3 文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

標準オブジェクトは 1 と 3、カスタムオブジェクトは 2 と 4 です。末尾の `__c` が自作の印になります。

</details>

<details>
<summary>問2の解答例</summary>

税込金額は通貨の項目に保存せず、数式項目にします。点検料を直したときに自動で追随するので、値が食い違いません。

</details>

<details>
<summary>問3の解答例</summary>

取り込みが毎回「新規作成」になっているのが原因です。基幹システム側の取引先コードを外部 ID 項目に持たせ、その項目を鍵にして upsert すれば、既にあるレコードは更新され、無いものだけが作られます。名前で突き合わせると表記ゆれで失敗するので、コードを使います。

</details>

## 確認クイズ

### Q1. Salesforce の「レコード」に対応する SQL の言葉はどれですか。

- A. 表(テーブル)
- B. 行
- C. 列

<details>
<summary>答え</summary>

**B** — オブジェクトが表、レコードが行、項目が列です。中身は同じで、名前だけが違います。

</details>

### Q2. API 参照名が `Repair_Order__c` のオブジェクトについて、正しいものはどれですか。

- A. 最初から用意されている標準オブジェクトである
- B. 自分たちで作ったカスタムオブジェクトである
- C. 削除されたオブジェクトである

<details>
<summary>答え</summary>

**B** — 末尾の `__c` が、自分たちで作ったものの印です。

</details>

### Q3. 「対応状況」を `未対応` / `対応中` / `完了` のいずれかで持ちたいとき、選ぶべきデータ型はどれですか。

- A. テキスト
- B. 選択リスト
- C. チェックボックス

<details>
<summary>答え</summary>

**B** — 選択肢が決まっているのでテキストにはしません。テキストにすると表記ゆれが混ざり、集計も絞り込みもできなくなります。

</details>

### Q4. 「単価 × 数量」の金額をレコードに持たせたいとき、いちばん適切なものはどれですか。

- A. 通貨の項目を作り、入力時に計算した値を保存する
- B. 数式項目にして、単価と数量から自動で計算させる
- C. テキストの項目に計算結果を書いておく

<details>
<summary>答え</summary>

**B** — 保存すると、単価や数量を直したときに値が食い違います。計算できるものは計算させます。

</details>

### Q5. 外部 ID 項目を使う目的として、いちばん適切なものはどれですか。

- A. Salesforce が自動で付ける ID を上書きするため
- B. 他システムのキーを持たせて、その値でレコードを指定できるようにするため
- C. レコードを検索したときの表示を速くするため

<details>
<summary>答え</summary>

**B** — 取り込み元は Salesforce の ID を知りません。相手側のキーを持っておけば、upsert で重複を作らずに更新できます。

</details>

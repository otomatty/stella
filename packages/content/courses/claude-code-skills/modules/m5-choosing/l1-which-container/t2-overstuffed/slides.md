# 5-1-2
# 詰め込みが一番の失敗

Skillsとサブエージェント — Module 5 / レッスン5-1

<!-- ノート: 使い分けの失敗の代表例を、名前を付けて覚えます。 -->

---

## なぜ必要か

- 使い分けを学んでも、現場のCLAUDE.mdは自然と太っていく
- 「1か所に全部あるほうが分かりやすい」という善意が原因なので、気づきにくい

<!-- ノート: 誰かが悪いのではなく、自然にそうなるのが厄介です。結論はまだ言いません。 -->

---

## 結論

**一番多い失敗は、CLAUDE.mdへの手順書の詰め込みで、どの約束も効きにくくなります**

- **詰め込み** — 効くタイミングの違うものを、1つの入れ物に全部書くこと
- 手順書が全部CLAUDE.mdにあると、Skillの出番がなくなり、約束は埋もれます

<!-- ノート: M1-1-5の禁じ手を、講座の締めとしてもう一度正面から扱います。 -->

---

## 症状と処方

```text
症状  CLAUDE.mdが100行を超えている
      「書いてあるのに守られない」が増えた
      リリース手順・調査手順・レビュー観点が同居している

処方  手順書をSkillへ移す → 毎回の約束だけが残る
```

<!-- ノート: 処方は消すことではなく、移すことです。手順書はSkillでこそ効きます。 -->

---

## 移す前・移した後

| | 詰め込んだCLAUDE.md | 移した後 |
| --- | --- | --- |
| CLAUDE.md | 100行 | 毎回の約束 10行 |
| 手順書 | 埋もれている | Skillとして要るときだけ効く |
| 毎回のコンテキスト | 100行ぶん消費 | 10行+背表紙だけ |

<!-- ノート: 移すだけで、両方の入れ物が本来の効き方に戻ります。定期的にこの棚卸しをするのがチームの手入れです。 -->

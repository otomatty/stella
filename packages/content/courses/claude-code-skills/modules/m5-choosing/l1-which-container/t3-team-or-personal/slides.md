# 5-1-3
# チームに載せる範囲を分ける

Skillsとサブエージェント — Module 5 / レッスン5-1

<!-- ノート: 置き場所のもう1本の軸です。いつ効くかの次は、誰に効くかです。 -->

---

## なぜ必要か

- 自分の好みの口調設定を、チームのリポジトリに入れてしまう
- 逆に、全員に要る約束が、誰かの手元にだけあって配られていない

<!-- ノート: どちらの間違いも実際によく起きます。結論はまだ言いません。 -->

---

## 結論

**チームの全員に効かせたい仕組みはリポジトリに載せ、自分の好みは個人用に置きます**

- **好み** — 正解が1つでない、自分のやりやすさのための設定
- 問いは「これは全員で揃えるべきか、自分の勝手でよいか」

<!-- ノート: いつ効くかで入れ物を選び、誰に効かせるかで置き場所を選ぶ。この2軸で置き先は決まります。 -->

---

## 振り分けの例

```text
チーム(リポジトリ)   テストのコマンド、レビュー手順のSkill
                    命名規約、検証役の定義

個人用              説明は箇条書きでという口調の好み
                    自分の実験中のSkill
```

<!-- ノート: 見分けの目安は「他の人が違うやり方をしていたら困るか」。困るなら揃える、困らないなら好みです。 -->

---

## 間違えたときの症状

| 間違い | 症状 |
| --- | --- |
| 好みをリポジトリに | 他人の環境に自分の癖を押しつける |
| 全員に要る約束を手元に | 自分だけ守られて、チームは揃わない |

<!-- ノート: リポジトリに入れるものはレビューを通す、という運用にすると、この間違いは自然に濾されます。 -->

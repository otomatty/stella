# 迷ったら効くタイミングで決める

Skillsとサブエージェント — Module 5 / レッスン5-1

<!-- ノート: 仕上げのモジュールです。4つの入れ物が出そろったので、判断を1本に束ねます。 -->

---

## なぜ必要か

- 入れ物を4つ知った今こそ、「どれに置くか」で手が止まりやすい
- 機能の印象で選ぶと、置き間違いの症状に後から悩まされる

<!-- ノート: M0で予告した背骨を、実戦の順番に直します。結論はまだ言いません。 -->

---

## 結論

**置き場所に迷ったら、その指示がいつ効いてほしいかという効くタイミングで決めます**

- **置き場所** — その指示を仕組みとして置く先。4つの入れ物のどれか
- 内容の重要さ・文の長さ・新しさでは決めません

<!-- ノート: 最初の1問はいつも同じです。「これはいつ効いてほしい?」 -->

---

## 判断の1本道

```text
いつ効いてほしい?
  毎回効く             → CLAUDE.md
  タスクのとき          → Skill
  別の文脈で(調べる間)   → サブエージェント
  必ず実行(例外なく)     → hook
```

<!-- ノート: この4行がこの講座の持ち帰りです。1問目で4つのうち1つに落ちます。迷いが残るのは「毎回かタスクのときか」の境目くらいです。 -->

---

## 境目の見分け

| 迷う指示 | 問い直し | 答え |
| --- | --- | --- |
| 「テストのコマンド」 | どの作業でも使う? | 使う → CLAUDE.md |
| 「レビュー観点」 | レビュー以外でも要る? | 要らない → Skill |

<!-- ノート: 境目で迷ったら「それ以外の作業のときにも要るか」と問い直します。要らないならタスク側です。 -->

---

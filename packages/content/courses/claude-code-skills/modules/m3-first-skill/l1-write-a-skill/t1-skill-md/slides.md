## 結論

**Skillの正体は、決まったフォルダに置いたSKILL.mdというMarkdownのファイルです**

- **フォルダ** — ファイルをまとめる入れ物
- **Markdown** — 見出しや箇条書きを書ける、ただのテキストの書き方
- **SKILL.md** — Skill 1つぶんの中身を書くファイルの名前

<!-- ノート: プログラムを書く必要はありません。CLAUDE.mdと同じく、テキストのファイルを置くだけです。 -->

---

## 最小の例

```text
.claude/skills/             ← プロジェクト用(執筆時点の例)
└── review-pr/              ← Skill 1つ = フォルダ1つ
    └── SKILL.md            ← 中身はここに書く

~/.claude/skills/           ← 個人用(執筆時点の例)
```

<!-- ノート: Skill 1つにフォルダ1つ、その中にSKILL.mdが1枚。Claude Codeが見つけられるのはこの2系統です。 -->

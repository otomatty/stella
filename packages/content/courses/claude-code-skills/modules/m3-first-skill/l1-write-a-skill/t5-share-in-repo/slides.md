# 3-1-5
# リポジトリに入れて共有する

Skillsとサブエージェント — Module 3 / レッスン3-1

<!-- ノート: M3の締めです。書けたSkillをどこに置くかで、効く相手が決まります。 -->

---

## なぜ必要か

- せっかく書いた手順書が、自分の手元だけで効いてもチームは揃わない
- 逆に、自分の実験中のSkillをいきなり全員に配りたくはない

<!-- ノート: CLAUDE.mdのときと同じ論点が、Skillにもあります。結論はまだ言いません。 -->

---

## 結論

**リポジトリに入れたSkillはチームの共有になり、個人用のSkillは自分だけに効きます**

- **個人用** — リポジトリの外の自分の領域に置き、自分の会話にだけ効く置き方
- 置き場所が2種類あるのは、効かせたい相手が2種類あるからです

<!-- ノート: どちらが正しいではなく、配りたい範囲で選びます。 -->

---

## 最小の例

```text
チームに配る   リポジトリの中のSkill置き場に入れる
             → クローンした全員に同じ手順書が届く

自分だけ      リポジトリの外の自分の領域に置く
             → どのプロジェクトでも自分にだけ効く
```

<!-- ノート: リポジトリに入れる置き方は、コードと同じ配り方です。プルリクエストで直し、履歴も残ります。個人用の正確なパスは製品のドキュメントで確認してください。 -->

---

## どちらに置くかの目安

| Skill | 置き場所 |
| --- | --- |
| チームのレビュー手順 | リポジトリ(共有) |
| チームのリリース前チェック | リポジトリ(共有) |
| 自分の実験中の手順書 | 個人用 → 育ったら共有へ |

<!-- ノート: 実験は個人用で始めて、効くと分かったらリポジトリに入れて配る。この流れが安全です。線引きの判断はM5でもう一度扱います。 -->

# 効くタイミングで見分ける

Skillsとサブエージェント — Module 0 / レッスン0-1

<!-- ノート: 4つの名前が出そろいました。このトピックで、講座全体の背骨になる見分け方を渡します。 -->

---

## なぜ必要か

- 名前を4つ覚えても、置きたい指示を前にすると、どれに置くか決められない
- 機能の一覧で覚えると、製品の画面が変わったときに迷子になる

<!-- ノート: 見分けに使える軸が要ります。機能の名前ではなく、もっと変わりにくいものを軸にします。結論はまだ言いません。 -->

---

## 結論

**4つの入れ物は、毎回・タスクのとき・別の文脈で・必ず実行という効くタイミングで見分けます**

- **効くタイミング** — その指示がいつ働いてほしいか
- **文脈** — Claudeが作業中に読んでいる、会話や資料のひとまとまり

<!-- ノート: 入れ物の違いは、置ける中身の違いではなく、効くタイミングの違いです。この4句がこの講座の背骨で、以降の全モジュールがここに戻ります。 -->

---

## 4つのタイミング

```text
毎回効く       CLAUDE.md        起動時に読み込まれた約束として効く
タスクのとき    Skill            合う作業のときだけ読まれる
別の文脈で     サブエージェント    切り出した仕事を別で進める
必ず実行       hook             指示ではなくコードとして動く
```

<!-- ノート: 上の3つは「Claudeが読む指示」で、hookだけ毛色が違います。読ませるのではなく、決めた操作を機械的に実行します。だから「必ず」と言えます。 -->

---

## 同じ1文でも置き場所が変わる

| 指示の例 | 効いてほしいとき | 入れ物 |
| --- | --- | --- |
| 「コメントは日本語で」 | 毎回 | CLAUDE.md |
| 「リリース前はこの手順で確認」 | その作業のとき | Skill |
| 「このライブラリの使用箇所を調べて」 | 調べる間だけ | サブエージェント |

<!-- ノート: 見分けているのは文の内容ではなく、いつ効いてほしいかです。この問いの立て方だけ持ち帰れば、今日は十分です。 -->

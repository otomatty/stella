# レッスン0-1 演習 — 4つの入れ物

対象トピック: 0-1-1 〜 0-1-3

## 手元で試す

このモジュールの演習は、紙とペン、または手元のメモ帳だけで進められます。Claude Code は Module 1 から実際に触るので、ここでは開かなくて構いません。

まず、自分が Claude Code(または他のAI)への依頼で繰り返し書いている前置きを、3つ書き出します。

```text
例
1. テストは bun run test で走らせて
2. コメントとコミットメッセージは日本語で
3. 直したら変更点を一覧にして見せて
```

書き出せたら、次の2つをやってみましょう。

1. 3つそれぞれに「いつ効いてほしいか」を書き添える。毎回 / 特定の作業のとき / 調べる間だけ、のどれかで構いません
2. 書き添えたタイミングから、置き先の入れ物(CLAUDE.md / Skill / サブエージェント)を仮決めする

ここで決めた仮の置き先は、Module 1 以降で実際に書くときの材料になります。メモは捨てずに残しておいてください。

## 演習問題

### 問1(基本)

毎回依頼に書く場合と比べて、指示を仕組みとして置く利点を、「書き忘れ」という語を使って1〜2文で説明してください。

### 問2(基本)

4つの入れ物の名前を挙げ、それぞれの効くタイミングを1行ずつ書いてください。

### 問3(応用)

「プルリクエストを出す前は、必ずこの3点を確認してほしい」という指示があります。この指示の置き先を効くタイミングから考え、候補になる入れ物を1つ挙げて理由を1文で書いてください。

### 問4(応用)

「hookは他の3つと毛色が違う」と言われます。何が違うのかを、「指示」「実行」の2語を使って1〜2文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

毎回書く方式は、書き忘れた回だけ指示が効かず、結果がぶれます。仕組みとして置けば書き忘れが起きないので、どの回でも同じように効きます。

</details>

<details>
<summary>問2の解答例</summary>

CLAUDE.md(毎回効く)、Skill(合うタスクのときだけ効く)、サブエージェント(切り出した仕事を別の文脈で進める)、hook(指示ではなく、決めた操作を必ず実行する)の4つです。

</details>

<details>
<summary>問3の解答例</summary>

Skillが候補になります。毎回ではなく「プルリクエストを出す」という特定の作業のときだけ効いてほしい手順だからです。

</details>

<details>
<summary>問4の解答例</summary>

CLAUDE.md・Skill・サブエージェントはどれもClaudeが読む指示なので、読み落とされる可能性が残ります。hookは指示ではなく、決めた操作をコードとして必ず実行する仕掛けです。

</details>

## 確認クイズ

### Q1. 依頼のたびに「テストはこのコマンドで走らせて」と書いていて、書き忘れた回だけテストが走りませんでした。この状況への適切な打ち手はどれですか。

- A. 書き忘れないよう、依頼の前に毎回チェックリストを目視する
- B. 同じ指示を仕組みとして置き、書かなくても効くようにする
- C. テストを走らせるのをやめる

<details>
<summary>答え</summary>

**B** — 繰り返している指示は、仕組みとして置けば書き忘れごと消せます。目視のチェックは、忘れる問題を忘れないよう頑張る対策で、ぶれが残ります。

</details>

### Q2. 仕組みの入れ物のうち、「Claudeが読む指示」ではなく「決めた操作を必ず実行する仕掛け」はどれですか。

- A. CLAUDE.md
- B. Skill
- C. hook

<details>
<summary>答え</summary>

**C** — hookだけは読ませる指示ではなく、機械的に実行される仕掛けです。だから「必ず実行」と言えます。作り方は次の講座で扱います。

</details>

### Q3. 「コメントは日本語で書いて」という指示は、どの依頼のときにも効いてほしいものです。効くタイミングから考えて、置き先はどれが適切ですか。

- A. 毎回読まれるCLAUDE.md
- B. 合うタスクのときだけ読まれるSkill
- C. 仕事を切り出して渡すサブエージェント

<details>
<summary>答え</summary>

**A** — 「毎回効いてほしい」がそのまま答えになります。入れ物は機能の名前ではなく、いつ効いてほしいかで見分けます。

</details>

### Q4. 入れ物を選ぶときに、最初に立てる問いとして適切なのはどれですか。

- A. その指示がいつ効いてほしいか
- B. その指示が何文字あるか
- C. どの入れ物が一番新しい機能か

<details>
<summary>答え</summary>

**A** — 見分けの軸は効くタイミングです。文の長さや機能の新しさでは決めません。この問いは製品の画面が変わっても使い続けられます。

</details>

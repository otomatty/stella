## 結論

**仕組みの入れ物には、CLAUDE.md・Skill・サブエージェント・hookの4つがあります**

- **入れ物** — 指示を仕組みとして置く場所のこと
- この講座で書けるようになるのは **CLAUDE.md** と **Skill**
- **サブエージェント** は渡す判断を、**hook** は名前と役割だけを扱います

<!-- ノート: まず4つあること自体が今日の結論です。それぞれの中身は、この後のモジュールで1つずつ扱います。 -->

---

## 4つの名前

```text
CLAUDE.md      プロジェクトの約束を書いたファイル
Skill          特定の作業のやり方をまとめた手順書
サブエージェント  仕事を切り出して渡す別の相手
hook           決めた操作を必ず実行する仕掛け
```

<!-- ノート: 1行ずつの紹介に留めます。どれも「指示を先に置いておく」という同じ目的の、形の違う入れ物です。 -->

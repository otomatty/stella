# CLAUDE.mdとの違いは効くタイミング

Skillsとサブエージェント — Module 2 / レッスン2-1

<!-- ノート: M2の締めです。この講座の中心の判断を、ここで1枚にします。 -->

---

## なぜ必要か

- CLAUDE.mdもSkillも「指示を先に置く」点は同じで、初めは区別がつきにくい
- 区別を間違えると、M1で見た「埋もれるCLAUDE.md」に逆戻りする

<!-- ノート: 機能で覚えず、判断で覚えます。結論はまだ言いません。 -->

---

## 結論

**毎回効かせたい約束はCLAUDE.mdに、タスクのときだけ効かせたい手順書はSkillに置き分けます**

- **使い分け** — 同じ指示を、効くタイミングで置き先に振り分けること
- 問いはいつも1つ:「これは毎回か、タスクのときだけか」

<!-- ノート: M0の背骨の、最初の実戦です。内容の重要さではなく、効くタイミングで分けます。 -->

---

## 振り分けの例

```text
「コメントは日本語で」            毎回         → CLAUDE.md
「テストは bun run test で」     毎回         → CLAUDE.md
「レビューはこの観点の順で」       レビューのとき → Skill
「リリース前はこの項目を確認」     リリースのとき → Skill
```

<!-- ノート: 4つとも大事な指示です。大事かどうかでは分けられません。いつ効いてほしいかだけが線になります。 -->

---

## 間違えたときの症状

| 間違い | 症状 |
| --- | --- |
| 手順書をCLAUDE.mdに | 毎回のコンテキストが減り、約束が埋もれる |
| 毎回の約束をSkillに | そのタスク以外で効かず、ぶれが戻る |

<!-- ノート: 失敗例枠です。どちらの間違いにも、はっきりした症状が出ます。症状から逆に置き間違いに気づくこともできます。 -->

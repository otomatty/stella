# サブエージェントは別の相手

Skillsとサブエージェント — Module 4 / レッスン4-1

<!-- ノート: 3つ目の入れ物です。CLAUDE.mdとSkillは「指示の紙」でしたが、これは相手が増える話です。 -->

---

## なぜ必要か

- 大きめの仕事では、調べものと本題が1つの会話に混ざっていく
- 「この調べもの、誰かに頼んで結果だけ教えてほしい」と思う場面がある

<!-- ノート: 人のチームなら自然にやっている切り出しです。結論はまだ言いません。 -->

---

## 結論

**サブエージェントは、任せた仕事を別の会話として進めて、結果だけを返す相手です**

- **任せる** — 仕事を切り出して渡し、進め方は相手に委ねること(講座4で扱った語です)
- **結果** — 任せた仕事から戻ってくる、まとめの報告

<!-- ノート: Claude Codeの中に、別の会話で働くもう1人がいるイメージです。頼むのは自分ではなくメインのClaudeで、依頼の中で切り出されます。 -->

---

## 最小の例

```text
自分            「この修正の前に、既存の使われ方を調べて」

メインの会話      調べものをサブエージェントへ切り出す
サブエージェント   別の会話でファイルを読み回る
メインの会話      「使われ方は3か所。一覧はこれ」という結果を受け取る
```

<!-- ノート: 調べ回る往復はサブエージェント側の会話で起き、メインには報告だけが届きます。 -->

---

## 自分でやる・別の相手に任せる

| | メインの会話でやる | サブエージェントに任せる |
| --- | --- | --- |
| 進む場所 | いまの会話の中 | 別の会話 |
| 戻ってくるもの | 途中経過も全部 | 結果だけ |

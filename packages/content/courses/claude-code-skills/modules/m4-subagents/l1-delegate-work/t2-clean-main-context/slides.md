# 4-1-2
# メインの文脈を汚さない

Skillsとサブエージェント — Module 4 / レッスン4-1

<!-- ノート: サブエージェントの一番の利点です。M4の芯になるトピックです。 -->

---

## なぜ必要か

- 調べもので30ファイルを読むと、その中身が全部いまの会話に積もる
- 本題に戻るころには、コンテキストの残りが心細くなっている

<!-- ノート: 講座4でコンテキスト上限とのつき合い方を学びました。調べものは、その上限を一番食う作業です。結論はまだ言いません。 -->

---

## 結論

**調べた中身はサブエージェント側に残り、メインの会話には結果だけが戻ります**

- **メインの会話** — 自分が本題を進めている、もとの会話
- 読んだ30ファイルぶんの中身は、メインのコンテキストに入りません

<!-- ノート: 別の会話で進むことの意味はこれです。作業場を分けたから、散らかりも向こうに残ります。 -->

---

## 最小の例

```text
サブエージェント側   30ファイルを読んだ中身で埋まる
                  → この会話は結果を返したら役目を終える

メインの会話       受け取るのは結果の数行だけ
                  → コンテキストはほぼ減っていない
```

<!-- ノート: 大量に読む費用を、使い捨ての会話に払わせる構図です。メインは本題のための余裕を保てます。 -->

---

## 文脈の汚れかたの違い

| | メインで調べる | サブエージェントで調べる |
| --- | --- | --- |
| 調べた中身 | メインに全部積もる | 向こう側に残る |
| メインのコンテキスト | 大きく減る | ほぼ減らない |
| 本題への影響 | 余裕がなくなる | 保たれる |

<!-- ノート: 「文脈を汚さない」はこの表の右列のことです。この利点が、次の向き不向きの判断の根拠になります。 -->

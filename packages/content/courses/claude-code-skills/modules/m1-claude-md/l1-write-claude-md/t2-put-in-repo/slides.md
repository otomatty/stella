# リポジトリに置いて共有する

Skillsとサブエージェント — Module 1 / レッスン1-1

<!-- ノート: 何のファイルかは分かりました。次は置き場所です。 -->

---

## なぜ必要か

- 自分の手元だけで効く約束だと、隣の人のClaude Codeは別の動きをする
- 「あの約束、どこに書いてあるの」が人によって違うと、直すときに揃わない

<!-- ノート: 約束は1人のものではなく、プロジェクトのものです。結論はまだ言いません。 -->

---

## 結論

**プロジェクトのCLAUDE.mdはリポジトリの直下に置き、チームの共有の約束にします**

- **リポジトリ** — プロジェクトのファイル一式の置き場(講座4で扱った語です)
- **チーム** — 同じプロジェクトを触る人たち
- **共有** — チームの全員が同じものを使う状態

<!-- ノート: リポジトリに入れれば、クローンした全員のClaude Codeが同じ約束を読みます。コードと同じ配り方です。 -->

---

## 最小の例

```text
リポジトリ直下
├── CLAUDE.md      ← ここに置く
├── README.md
└── src/
```

<!-- ノート: 置き場所はリポジトリの一番上、READMEの隣です。これだけで、チーム全員に同じ約束が配られます。 -->

---

## 手元に置く・リポジトリに置く

| | 自分の手元だけ | リポジトリの直下 |
| --- | --- | --- |
| 効く相手 | 自分だけ | クローンした全員 |
| 直すとき | 全員がばらばらに直す | 1ファイルを直して配れる |
| 約束のずれ | 人ごとに起きる | 起きにくい |

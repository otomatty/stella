## なぜ必要か

- 「コメントは日本語で」のような約束を、依頼のたびに書き続けたくない
- 毎回効かせたい指示の、置き場所の正体をまだ知らない

<!-- ノート: M0で「毎回効くのはCLAUDE.md」と地図に載せました。今日はその正体です。結論はまだ言いません。 -->

---

## 結論

**作業フォルダとその上位のCLAUDE.mdは会話の始まりに読み込まれ、プロジェクトの約束を書くファイルです**

- **ファイル** — 中身が保存されている入れ物。CLAUDE.mdはただのテキストのファイル
- **会話** — Claude Codeとのひと続きのやり取り(講座4で扱った語です)
- **プロジェクト** — 1つの開発対象のまとまり
- **約束** — そのプロジェクトで毎回守ってほしいこと

<!-- ノート: 特別な登録は要りません。作業フォルダとその上位(親フォルダ側)のCLAUDE.mdは、会話の始まりに自動で読み込まれます。下位フォルダのCLAUDE.mdは、その配下のファイルを触るときに読み込まれます。まずはリポジトリ直下から始めれば十分です。 -->

---

## 最小の例

```text
CLAUDE.md の中身の例

# このプロジェクトの約束
- テストは bun run test で走らせる
- コメントとコミットメッセージは日本語で書く
```

<!-- ノート: 中身はこれだけです。飾りのない箇条書きの約束が、どの会話でも最初から効いています。 -->

## 毎回言う・置いておく

| | 依頼に毎回書く | CLAUDE.mdに書く |
| --- | --- | --- |
| 効くのは | 書いた会話だけ | すべての会話 |
| 読み込み | 自分が書いたとき | 会話の始まりに自動 |
| 忘れると | その回だけ抜ける | 忘れる余地がない |

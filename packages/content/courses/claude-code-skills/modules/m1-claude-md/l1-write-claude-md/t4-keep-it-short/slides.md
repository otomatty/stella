# 1-1-4
# 短く保つ

Skillsとサブエージェント — Module 1 / レッスン1-1

<!-- ノート: 中身の選び方の次は、量の話です。CLAUDE.mdは書くより削るほうが難しい、という話をします。 -->

---

## なぜ必要か

- 効いてほしい約束を足し続けると、CLAUDE.mdは自然に長くなっていく
- 長くなったころ、「書いてあるのに守られない」約束が増えてくる

<!-- ノート: 足すのは簡単で、害が見えにくいのが問題です。結論はまだ言いません。 -->

---

## 結論

**CLAUDE.mdは毎回コンテキストに入るので、読んで守れる長さに短く保ちます**

- **コンテキスト** — Claudeが一度の会話で読める量のこと。上限があります(講座4で扱った語です)
- 長いほど、1つ1つの約束は薄まって効きにくくなります

<!-- ノート: 起動時に読み込まれたCLAUDE.mdは、毎回コンテキストを使います。タダではないのです。 -->

---

## 長さの費用

```text
10行のCLAUDE.md    どの約束もよく効く
                  コンテキストの残りも十分

100行のCLAUDE.md   大事な約束が他の行に埋もれる
                  どの会話でも100行ぶんを毎回消費する
```

<!-- ノート: 行数そのものが基準ではありませんが、量に費用があるという感覚が大事です。埋もれた約束は、書いていないのと同じになります。 -->

---

## 短く保つ習慣

| 習慣 | やること |
| --- | --- |
| 足すとき | 既にある約束を1つ消せないか探す |
| 見返すとき | 守られていない約束を消すか言い換える |
| 迷うとき | 「これがないと毎回困るか?」と問う |

<!-- ノート: 一度書いたら終わりではなく、コードと同じように手入れするファイルです。消すことは失敗ではなく、手入れです。 -->

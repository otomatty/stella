# 伝えたはずなのに
親のエージェントの会話で決めた方針を、サブエージェントが知らずに作業していました。
<!-- ノート: サブエージェントは、親の会話を受け取りません。 -->
---
# 要る情報を書いて渡す
サブエージェントは自分の会話で動くので、要る情報をプロンプトに書いて渡します。
<!-- ノート: 親から渡るのは、呼び出すときのプロンプトの文字列だけです。ファイルの場所・エラー・決めたことを書きます。 -->
---
# agents に定義する
```js
agents: { "code-reviewer": {
  description: "コードを確かめるときに使う", prompt, tools: ["Read", "Grep"] } },
allowedTools: ["Read", "Grep", "Agent"],
```
<!-- ノート: description を見て、Claude が任せる相手を決めます。サブエージェントは Agent のツールで呼ばれます。 -->
---
# 任せる利点
- 途中の結果が親の会話にたまらない
- 同時に動かせる
- 専用の指示と、絞ったツールを持たせられる
<!-- ノート: 親に返るのは、サブエージェントの最後の報告だけです。 -->
---

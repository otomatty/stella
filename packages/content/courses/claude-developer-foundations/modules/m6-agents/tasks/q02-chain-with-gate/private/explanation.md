# 解説

プロンプトの連鎖は、仕事を決まった段に分け、前の段の出力を次の段の入力にするワークフローです。1 回ずつの呼び出しが易しい仕事になるので、答えが正確になりやすくなります。その代わりに、前の段の出力が崩れていると、次の段はその崩れの上に積み上げてしまいます。段の間にゲートを置いて出力をコードで確かめ、条件を満たさなければ先へ進まないことで、崩れが広がるのを止めます。どの段で何が理由で止まったかを返せば、原因も追えます。

ゲートの理由は、そのまま段のやり直しの手がかりになります。`feedback` として渡せば、本物の段では「見出しが足りない」と伝えて作り直させられます。ただし、やり直しには回数の上限を決めます(`retries`)。上限がないと、通らない出力を作り続けて費用と時間を使います。例外(送信の失敗など)は、ゲートの理由とは別のものです。送り直しは M2 で作ったような送信の層に任せ、ここではその場で止めます。

段の名前は `outputs` の鍵になるので、重なると前の段の出力が上書きされます。名前の誤りは、どの段も呼ぶ前に止めます。

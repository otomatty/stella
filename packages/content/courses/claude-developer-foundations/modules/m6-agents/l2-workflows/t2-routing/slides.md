# 1 つの指示で全部
請求・技術・その他の問い合わせを、1 つの system で扱っていました。技術の答えを良くすると、請求の答えが崩れました。
<!-- ノート: ある種類に合わせて直すと、ほかの種類が悪くなることがあります。 -->
---
# 種類で振り分ける
入力の種類で、扱う指示やモデルを振り分けます。
<!-- ノート: 最初に入力を分類し、種類ごとの指示・ツール・モデルへ回します。これをルーティングと呼びます。 -->
---
# 振り分けの例
- 請求 → 請求の手順を書いた指示
- よくある簡単な質問 → 小さく安いモデル
- 難しい・珍しい質問 → 強いモデル
<!-- ノート: 分類が正確にできることが、この形を使う条件です。 -->
---

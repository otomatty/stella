# レッスン10-3 範囲別のドリル

## このレッスンの目標

- [ ] 模擬試験の誤答分析から、ドリルを解く範囲を選べます。
- [ ] 外した問題を、戻るトピックと公式ドキュメントで確かめ直せます。

## 10-3-1 弱い範囲を繰り返す

> **模擬試験で間違えた範囲のドリルを解き、外した問題は戻るトピックの公式ページで確かめます。**

ドリルは、範囲ごとに集めた練習問題です。模擬試験(9-1-1)は本番のように範囲を混ぜて並べましたが、このレッスンの知識問題は範囲ごとに 3 問ずつ並べています。問題は模擬試験とは別に作ったもので、本番の問題を写したものではありません。

| 問題 | 範囲 | 主に戻る単元 |
| --- | --- | --- |
| Q1〜Q3 | Applications and Integration | M1・M2 |
| Q4〜Q6 | Model Selection and Optimization | M3 |
| Q7〜Q9 | Agents and Workflows | M6 |
| Q10〜Q12 | Prompt and Context Engineering | M4 |
| Q13〜Q15 | Tools and MCPs | M5 |
| Q16〜Q18 | Security and Safety | M7 |
| Q19〜Q21 | Claude Code | M8 |
| Q22〜Q24 | Eval, Testing, and Debugging | M8 |

範囲の名前と並びは、模擬試験と同じです。受ける版の試験ガイドで、範囲が変わっていないかを確かめてください。範囲ごとの問題数をそろえたのは、配点の小さい範囲でも弱いところを埋められるようにするためです。本番の配分は、模擬試験のほうが近くなっています。

### 進め方

1. 模擬試験の誤答分析で、間違いの多かった範囲を 2 つほど選びます。
2. その範囲の問題を、解説を開かずに解きます。
3. 外した問題は、解説の「復習」にあるトピック ID の単元を読み直し、公式ドキュメントの該当の節を読みます。
4. 弱い範囲が埋まったら、残りの範囲も解いて、全体で抜けがないかを確かめます。
5. 日を空けて、もう一度解きます。知識問題は復習のカードにもなるので、外した問題は時間を空けてまた出てきます。

答えを覚えてしまった問題は、ほかの選択肢がなぜ誤りかを説明できるかで確かめます。本番の問題は、実際の仕事を映すように作られています(10-4-1)。選択肢の言葉を覚えるより、場面の条件から選べるかを確かめます。

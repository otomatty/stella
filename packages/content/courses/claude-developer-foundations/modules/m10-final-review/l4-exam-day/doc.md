# レッスン10-4 受験の準備と当日

## このレッスンの目標

- [ ] 問題文から場面の条件を拾い、選択肢を比べられます。
- [ ] 申し込みの前と当日に確かめることを、順に言えます。

## 10-4-1 場面の条件を読む

> **本番の問題は実際の仕事を映すように作られているので、場面の条件を拾ってから選択肢を比べます。**

公式の発表では、資格はどれも専門家が作り、資格を取った人が実際に行う仕事を映す内容にしたとされています。機能の名前を覚えているだけでは、どれも動きそうな選択肢から 1 つを選べません。問題文の場面から条件を拾い、条件にいちばん合うものを選びます。

| 問題文の言葉 | 効く選び方 | 戻るトピック |
| --- | --- | --- |
| 利用者が画面で待っている | ストリーミング | 10-1-1 |
| 翌朝まででよい、大量 | バッチ | 10-1-1 |
| 毎回同じ前半、同じ手引き | プロンプトキャッシュ | 3-2-1・10-1-2 |
| ツールの入力が崩れる | strict | 10-1-3 |
| 最後の答えを決まった形で | 構造化出力 | 10-1-3 |
| 切れていた、断られた | stop_reason での分岐 | 10-1-4 |
| 手元で動くサーバー、`npx` で起動 | Agent SDK の MCP | 10-2-1 |
| 手順が毎回同じ | ワークフロー | 10-2-2 |
| 外から取った文章、メールの本文 | プロンプトインジェクションへの備え | 7-1-1 |
| 必ず実行したい | フック | 8-1-2 |

条件を拾ったら、条件に 1 つでも合わない選択肢から外し、残ったものを比べます。「必ず」「すべて」のような強い言い方の選択肢は、仕様で本当にそうかを確かめます。たとえば「バッチの中のキャッシュは必ず当たる」は誤りです(10-1-2)。

## 受験の前に確かめること

受け方の詳しい条件は変わることがあるので、この講座には書きません。申し込むときに、次を公式の案内で確かめます。

1. **受験資格**: 所属する組織が Claude Partner Network に加盟し、受験する人を登録しているか(0-1-2)。
2. **範囲**: 受ける版の試験ガイドで、範囲と配点が、この講座で準備した範囲と合っているか(0-2-1)。出題の範囲は改訂されることがあります。
3. **準備の講座**: Partner Academy に、資格ごとの準備の講座があります。試験ガイドと合わせて使います。
4. **当日の受け方**: 試験は Pearson が監督つきで行い、始める前に本人確認があります(0-1-3)。本人確認に要るもの・受ける場所・時間は、申し込みの案内で前日までに確かめます。
5. **合格のあと**: 合格すると、Credly のデジタルバッジが届きます。

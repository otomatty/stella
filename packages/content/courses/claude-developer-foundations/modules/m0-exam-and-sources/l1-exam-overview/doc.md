# レッスン0-1 試験の全体像

## このレッスンの目標

- [ ] Developer: Foundations が扱う範囲を言えます。
- [ ] 受験できる条件を確かめられます。
- [ ] 試験当日の進め方を説明できます。

## 0-1-1 Developer 資格が測るもの

> **Developer: Foundations は、Claude でアプリを作るエンジニアの資格です。**

Claude の認定試験は4つあり、役割ごとに対象が分かれています。この講座が扱うのは Claude Certified Developer: Foundations です。公式の発表は、Claude でアプリを作るエンジニア向けの資格で、Claude API・ツール使用・エージェント開発の訓練を含むと説明しています。

Claude API は、アプリから Claude を呼び出すための仕組みです。ツール使用は、Claude がアプリの処理(検索や計算など)を呼び出せるようにする仕組みです。エージェントは、手順を自分で考えながら作業を進める仕組みです。

ほかの3つの資格は対象が違います。Associate: Foundations は Claude を使う案件に関わる人全般、Architect: Foundations はエージェントの仕組みを設計する人、Architect: Professional は大きな組織向けの上級の資格です。実務で API を使ってアプリを作る人は、Developer: Foundations から始めます。

## 0-1-2 受験できる人

> **受験できるのは、Claude Partner Network に加盟した組織の人です。**

Claude Partner Network は、Claude を顧客に届ける組織のための仕組みです。公式の発表では、試験は加盟した組織の人が受けられ、加盟は無料で、組織が受験する人を登録するとされています。個人で申し込もうとしても進めないときは、まず組織が加盟しているかを確かめます。

試験は Anthropic Partner Academy(加盟した組織の人が使う学習と試験の場)から受けます。認定は組織ではなく、受験した個人に属します。組織の側は、認定を持つ人の数などで Claude Partner Network の中の段階が決まります。

## 0-1-3 監督つきの試験

> **試験は監督つきで行われ、始める前に本人確認があります。**

監督つき試験とは、試験官が見ている状態で受ける試験のことです。試験は Pearson が実施し、始める前に本人確認をします。合格すると、Credly のデジタルバッジ(合格をネット上で示せる証明)が届きます。

受け方・受験料・再受験などの条件は変わることがあります。この講座には変わりやすい数字を書きません。申し込むときに、Pearson と Partner Academy の案内で確かめます。

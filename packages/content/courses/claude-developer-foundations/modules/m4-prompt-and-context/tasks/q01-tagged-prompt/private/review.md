# レビューの観点

- 資料・例・指示・質問を、それぞれ決まったタグで包んでいるか
- 資料を先頭に、質問を最後に置いているか
- 資料に 1 から番号を振り、`<source>` と `<document_content>` に分けているか
- 空の資料・例のときに、空のタグを入れていないか
- 受け取った配列を書き換えていないか(`push` を `input.documents` にしていないか)
- `readTag` が、開くタグの後ろから閉じるタグを探し、見つからないときに `null` を返しているか
- タグの中身の前後の空白を除いているか

よくある違反: 質問を先頭に置く、番号を 0 から振る、例がないのに `<examples></examples>` を入れる、`split` の結果をそのまま返して閉じるタグや後ろの文章まで含める、タグがないときに `undefined` を返す。

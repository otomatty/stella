# 解説

構造化出力は、応答を JSON スキーマどおりの JSON に絞ります。指示の文にスキーマを貼るだけでは形が保証されないので、スキーマは `output_config.format` に `type: "json_schema"` と一緒に渡します。

書かれていない項目の扱いは、スキーマで決めておきます。項目を必須にしないと、出力から省かれたり、必須の項目のあとに回ったりします。すべてを必須にしたうえで、文字列は `["string", "null"]` で `null` を許し、選択肢は `enum` に `"unknown"` を足すと、「書かれていない」ことを値として受け取れ、Claude に推測させずに済みます。オブジェクトには `additionalProperties: false` を書き、`minLength` のような使えない制限は入れません(400 エラーになります)。日付は `format: "date"` で形を決められます。

構造化出力でも、`stop_reason` が `refusal`(拒否)や `max_tokens`(上限で切れた)の応答は、スキーマどおりとは限りません。そのため、JSON として読む前に `stop_reason` を確かめます。`enum` の値は大文字と小文字までは保証されないので、比べる前にそろえます。

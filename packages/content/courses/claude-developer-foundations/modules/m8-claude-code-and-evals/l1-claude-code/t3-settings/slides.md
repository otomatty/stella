# プロジェクトの設定に置く
チームで共有する設定は、プロジェクトの .claude/settings.json に置いてリポジトリに入れます。
<!-- ノート: 権限の決まり・フック・プロジェクトに要る環境変数などを書きます。 -->
---
# 4 つの置き場所
- ~/.claude/settings.json: 自分の全プロジェクト
- .claude/settings.json: プロジェクトの全員(リポジトリに入れる)
- .claude/settings.local.json: このプロジェクトの自分だけ
- 管理された設定: 組織の全員
<!-- ノート: 同じ項目は、管理された設定・コマンドライン・ローカル・プロジェクト・ユーザーの順に強く効きます。 -->

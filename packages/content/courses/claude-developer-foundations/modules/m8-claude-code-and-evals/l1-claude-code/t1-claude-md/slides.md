# CLAUDE.md に書く
毎回効かせたいプロジェクトの約束は、CLAUDE.md に短く具体的に書きます。

# 確かめられる書き方
- 弱い: 「コードを整えて」
- 強い: 「インデントは 2 文字の空白」「コミットの前に npm test を走らせる」

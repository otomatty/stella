# レビューの観点

- `exactMatch` が、両方の前後の空白を除いてから完全一致で比べているか
- `runEval` が、すべてのケースを順に回しているか
- `generate` の失敗を不合格にして `error` を残し、残りを回し続けているか
- `grade` の結果を `await` しているか(`async` の採点で `Promise` を合格扱いにしていないか)
- 空のケースと `id` の重なりを、回す前にエラーにしているか
- `compareRuns` が、ケースの `id` の集まりが同じかを確かめてから比べているか
- 悪化したケースと直ったケースを、前の結果の順で返しているか
- 説明欄が、同じケースで比べる理由と悪化したケースを返す理由を、自分のコードに即して述べているか

よくある違反: 生成の失敗で評価全体を止める、`grade(...)` を `await` せずに `Promise` を真として数える、ケースの数だけで同じセットと判断して `id` を見ない、`regressions` を並びの番号で比べる、`delta` だけを返す。

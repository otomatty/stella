# 違うツールが呼ばれる
「注文を調べて」と頼むと、在庫を調べるツールが呼ばれていました。
<!-- ノート: ツールの誤用の多くは、ツールの定義の側に原因があります。 -->
---
# 定義から直す
ツールの誤用は、ツールの説明・スキーマ・strict から直します。
<!-- ノート: system の指示を足す前に、まずツールの定義を見直します。 -->
---
# 症状と直し方
- 違うツールが呼ばれる: いつ使うかで説明を書き分ける
- 一度も呼ばれない: 名前の重なりを確かめ、入力の例を足す
- 型や項目が違う・項目を作る: strict を付ける
<!-- ノート: enum の外の値が来るときは、選択肢を減らすか、入力の例で正しい値を見せます。 -->
---

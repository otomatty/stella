# 測れる基準を決める
作る前に、具体的で測れる成功の基準を決めます。
<!-- ノート: 基準が決まれば、変更のたびに良くなったか悪くなったかを数字で言えます。 -->
---
# よい基準の条件
- 具体的: 「よい性能」ではなく「感情の分類が正しい」
- 測れる: 数や、決まった尺度で表す
- 届く: いまのモデルで実現できる目標
- 用途に合う: アプリの目的と利用者に合う
<!-- ノート: 安全性のような捉えにくいものも、「1 万回の出力のうち問題ありと判定されるのが 0.1% 未満」のように数で表せます。 -->
---

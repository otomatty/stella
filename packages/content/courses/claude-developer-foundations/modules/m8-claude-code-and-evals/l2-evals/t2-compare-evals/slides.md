# 同じセットで比べる
プロンプトを変えたら、同じ評価のセットを自動で採点して前と比べます。
<!-- ノート: 合格率の上下だけでなく、前は通って後で落ちた例も見ます。 -->
---
# 採点の方法
- コードで採点: 完全一致・含むかどうか。速く確か
- LLM による採点: 細かな判断ができる。基準をはっきり書く
- 人が採点: 柔軟だが遅く高い
<!-- ノート: できるだけ速く確かな方法を選びます。質の高い少数より、自動で採点できる多くの例のほうが役に立ちます。 -->

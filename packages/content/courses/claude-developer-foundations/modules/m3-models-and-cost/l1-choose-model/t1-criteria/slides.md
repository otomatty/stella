# 優先順位を決めてから選ぶ
モデルは、性能・速度・費用のどれを優先するかを決めてから選びます。

# 2 つの始め方
- 速度・費用を優先: Haiku 5.5 から始め、足りなければ上げる
- 性能を優先: Opus 5.5 から始め、あとで効率を上げる

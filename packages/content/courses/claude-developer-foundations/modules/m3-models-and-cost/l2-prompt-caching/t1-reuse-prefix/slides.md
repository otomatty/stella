# 毎回同じ手引き
社内の手引き 3 万トークンを system に入れ、質問のたびに送っていました。毎回、全部が入力の料金になります。
<!-- ノート: 変わるのは短い質問だけで、前半はいつも同じでした。 -->
---
# キャッシュで使い回す
毎回同じ前半のプロンプトは、プロンプトキャッシュで使い回します。
<!-- ノート: 前半を処理した結果を一時的に覚えさせ、次のリクエストで読み出します。 -->
---
# 使い回す終わりに印を付ける
```js
system: [
  { type: "text", text: manual, cache_control: { type: "ephemeral" } },
],
```
<!-- ノート: cache_control を付けたブロックまでが、使い回す前半になります。 -->
---
# 書き込みと読み込みの料金
- 書き込み(5 分): 通常の入力の 1.25 倍
- 読み込み: 通常の入力の 0.1 倍(一部のモデルはさらに安い)
<!-- ノート: 最初のリクエストで書き込み、5 分以内に使われるたびに期限が延びます。2 回目からが得になります。 -->
---

# まとめ
毎回同じ前半のプロンプトは、プロンプトキャッシュで使い回します。

# レビューの観点

- 単価を 100 万トークンあたりの値として、1,000,000 で割っているか
- `usage` の 4 つの値を、それぞれの単価(`input`・`cacheWrite`・`cacheRead`・`output`)で計算しているか
- `null` と省略を 0 として扱い、0 の値では単価を求めていないか
- トークン数の形と、使った値の単価の有無を確かめ、値や単価の名前を含むエラーを投げているか
- バッチの半額を、キャッシュの料金を含めた合計にかけているか
- キャッシュを使う場合を、1 回目の書き込みと `requests - 1` 回の読み込みで見積もっているか
- 前半が `minCacheableTokens` に届かないとき、キャッシュしない場合と同じにしているか
- 説明欄が、値と単価の対応と、1 回だけならキャッシュが高くなる理由を、自分のコードに即して述べているか

よくある違反: 1,000,000 で割り忘れる、`input_tokens` を入力の合計として扱う、全回を読み込みとして数えて 1 回目の書き込みを落とす、最低の長さの判定を `<=` にする、バッチの割引を出力だけにかける。

# レッスン9-1 模擬試験

## このレッスンの目標

- [ ] 模擬試験を、時間を計って通しで解けます。
- [ ] 間違えた問題から、戻る単元とトピックを選べます。

## 9-1-1 模擬試験で弱点を見つける

> **模擬試験は時間を計って通しで解き、間違えた問題の単元に戻って直します。**

このレッスンの知識問題は、この講座の M1〜M8 の内容から作った、教材独自の模擬試験です。本番の問題を写したものではありません。

本番は Pearson の監督つきで行われ、始める前に本人確認があります。**本番の問題数・時間・合格の基準は、受ける版の試験ガイドで確かめてください。** この模擬試験の 53 問は、第三者の解説で本番の問題数とされている数に合わせたもので、公式の数字ではありません。出題の範囲が改訂されたときは、新しい試験ガイドで範囲を確かめてから使います。

### 解き方

1. 試験ガイドで本番の時間を確かめ、その時間を自分で計ります。
2. 53 問を、途中で解説を開かずに通しで解きます。
3. 解き終えたら、間違えた問題の解説にある「範囲」と「復習」を書き出します。
4. 「復習」のトピック ID(例: `3-2-2`)の単元を読み直し、同じ単元の知識問題と課題を解き直します。
5. 日を空けてから、もう一度通しで解きます。答えを覚えてしまった問題は、選択肢の文を読んで、なぜほかが誤りかを説明できるかで確かめます。

### 範囲ごとの問題数

問題の数は、範囲ごとの配点の比に合わせて割り振っています。問題は本番のように範囲を混ぜて並べてあります。

| 範囲 | 問題数 | 主に戻る単元 |
| --- | --- | --- |
| Applications and Integration | 17 | M1 Messages API の基本・M2 アプリに組み込む |
| Model Selection and Optimization | 9 | M3 モデルの選択と費用・速度の調整 |
| Agents and Workflows | 8 | M6 ワークフローとエージェント |
| Prompt and Context Engineering | 6 | M4 プロンプトとコンテキストの設計 |
| Tools and MCPs | 6 | M5 ツール使用と MCP |
| Security and Safety | 4 | M7 安全性とセキュリティ |
| Claude Code | 2 | M8 Claude Code の設定と評価・デバッグ |
| Eval, Testing, and Debugging | 1 | M8 Claude Code の設定と評価・デバッグ |

範囲ごとに間違えた数を数えると、どの単元に時間を足せばよいかが分かります。間違いが 1 つの範囲に集まっていれば、その単元を最初から読み直します。いくつかの範囲に散らばっていれば、それぞれの「復習」のトピックだけを読み直します。

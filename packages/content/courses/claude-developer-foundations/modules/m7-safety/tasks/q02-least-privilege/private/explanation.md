# 解説

最小権限は、攻撃をすり抜けられたときや Claude が間違えたときに、被害を小さくするための考え方です。Agent SDK では、ツールの呼び出しを、フック → 禁止の決まり → 確認の決まり → 権限のモード → 許可の決まり → `canUseTool` の順で確かめます。

`allowedTools` は、書いたツールを確認なしで使えるようにするだけで、ほかのツールを消しません。人のいないエージェントには確認に答える人がいないので、`permissionMode: "dontAsk"` で、許可していない呼び出しを確認せずに断ります。ただし、作業フォルダーの中のファイルを読むことや、読み取りだけの Bash のコマンドは、`dontAsk` でも確認なしで動きます。Bash の要らない作業では、`disallowedTools: ["Bash"]` で定義ごと消して、見えない・使えないようにします。テストを走らせる作業でも、`Bash` そのものではなく `Bash(npm test)` だけを許可します。

`bypassPermissions` は確認を外し、`allowedTools` に書いていないツールまで使えるようになるので、ここでは使いません。MCP のツールは `mcp__github__*` でまとめて許可できますが、サーバーにツールが足されると、知らないうちに使えるツールが増えます。使うツールを名前で 1 つずつ書けば、許可の範囲が設定から読み取れます。

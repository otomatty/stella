# 環境に置いた秘密
エージェントの環境に、社内 API の鍵を置いていました。紛れ込んだ指示で、鍵ごと外へ送られるおそれがありました。

# 外側で付け足す
API キーなどの秘密はエージェントに渡さず、外側のプロキシで付け足します。
<!-- ノート: エージェントは秘密なしでリクエストを送り、エージェントの外にあるプロキシが秘密を足して転送します。 -->
---
# プロキシの利点
- エージェントは秘密を見ない
- 送ってよい宛先だけを通せる
- すべてのリクエストを記録できる
<!-- ノート: 秘密を 1 か所で管理でき、エージェントごとに配らずに済みます。 -->

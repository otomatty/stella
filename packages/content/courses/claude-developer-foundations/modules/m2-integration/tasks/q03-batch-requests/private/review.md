# レビューの観点

- `custom_id` を問い合わせの `id` から作っているか。並び順(`index`)を使っていないか
- `custom_id` の形(1〜64 文字の英数字・`-`・`_`)と重なりを、送る前に確かめているか
- `params` に `system` を入れ、本文を `user` の発言にしているか
- 結果を並び順に頼らず `custom_id` で引いているか
- `succeeded` だけからテキストを作り、ほかの種類を理由つきで返しているか

よくある違反: `index` を `custom_id` にする、重なりを確かめずに後の問い合わせで上書きする、結果の配列の並び順で問い合わせと結ぶ、`errored` のときに `result.message` を読んで例外になる。

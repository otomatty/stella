# 解説

`for (let retry = 0; ; retry++)` で送り直しの回数を数え、`send()` が成功したら `return` で抜けます。`catch` では、送り直せるエラー(429・500・529)でないか、回数が `maxRetries` に届いていれば、そのエラーを投げます。こうすると、送り直さないエラーは待たずにすぐ呼び出し側へ届き、上限に届いたときは最後のエラーが届きます。

待つ時間は、`retry-after` があればその秒数をミリ秒にしたものです。公式ドキュメントは、これより早い送り直しは失敗すると説明しています。無ければ `baseDelayMs * 2 ** retry` で、送り直すたびに倍になります(指数バックオフ)。

利用額の上限に届いた 429 には `retry-after` が付かず、上限が戻るまで通りません。回数の上限があるので、この場合も無限に送り直さずに止まります。

別解: 送り直せるかの判定を `isRetryable(error)` のような関数に分けると、500 番台をまとめて扱うなどの変更がしやすくなります。実務では、待つ時間に少しのゆらぎ(ジッター)を足して、多くの処理が同時に送り直すのを避けることもあります。

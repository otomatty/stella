# どのエラーも送り直す
エラーが出たら、内容を見ずに同じリクエストを送り直していました。
<!-- ノート: 形の誤りのように、何度送っても通らないエラーもあります。 -->

# 429 と 529 は送り直せる
429 と 529 は、時間を置いて送り直すと通ることがあるエラーです。
<!-- ノート: HTTP ステータスは、応答の結果を表す 3 けたの番号です。 -->
---
# 2 つのエラー
- 429 は、組織の回数や量の制限に届いた
- 529 は、API 全体が一時的に混み合っている
<!-- ノート: 500 の内部エラーも、間隔を広げて送り直すよう案内されています。 -->
---
# 送り直しても通らないもの
- 400 は、リクエストの形や中身の誤り
- 401 は、API キーの誤り
- 利用額の上限に届いた 429 は、上限が戻るまで通らない
<!-- ノート: 上限に届いた 429 には、待つ秒数を示すヘッダーが付きません。 -->
---

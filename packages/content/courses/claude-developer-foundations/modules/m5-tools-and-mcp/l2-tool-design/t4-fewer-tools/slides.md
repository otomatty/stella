# 選べない
API の機能を 1 つずつツールにしたら 40 個になり、Claude が似たツールを取り違えました。

# 目的ごとにまとめる

<!-- ノート: 「一覧・取得・作成」を別々にせず、「予定を入れる」のように仕事の単位でまとめます。 -->

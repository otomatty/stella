# SQL 入門 カリキュラム

SES 未経験者向けの SQL 入門講座です。1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、
テーブルからデータを取り出す SELECT を軸に、絞り込み・並べ替え・結合・集計までを通します。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- コード演習: VS Code 拡張の SQL 採点(`sql.js` / SQLite)。`course.json` の `exercises` で各レッスンに配線
- 前提講座: **ITのきほん(`it-basics`)**。スキルツリーの入口講座で、コンピュータ・ファイル・Web の基本のことばをそろえてから受講します(`course.json` の `prerequisites` に対応)。後続は準備中の **データベース設計入門(`db-design-basics`)** と、バックエンドの足場になる **コマンドライン入門(`cli-basics`)**。ITのきほんから出る本土の枝は HTML/CSS と本講座の 2 本で、CLI は本講座のあとに続く
- 対象外: ウィンドウ関数・トランザクション・インデックス・DDL/DML の書き込み系(INSERT/UPDATE/DELETE)

## 全体構成(6 モジュール / 6 レッスン / 24 トピック)

### M1. SELECT — レッスン1-1 SELECTでデータを取り出す

| ID | トピック | takeaway |
| --- | --- | --- |
| 1-1-1 | SELECTで列を選んで取り出す | SELECT 列名 FROM テーブル名 で、欲しい列だけを取り出せる |
| 1-1-2 | *で全列を取り出す | *(アスタリスク)を使うと、テーブルの全列を取り出せる |
| 1-1-3 | ASで別名を付ける | AS を付けると、取り出した列に別名を付けられる |
| 1-1-4 | 式もSELECTできる | SELECT では列そのものだけでなく、計算した結果も取り出せる |

コード演習: `S0-Sql-Ch00-04-select-columns`

### M2. WHERE — レッスン2-1 WHEREで行を絞り込む

| ID | トピック | takeaway |
| --- | --- | --- |
| 2-1-1 | WHEREで行を絞り込む | WHERE を付けると、条件に合う行だけに絞り込める |
| 2-1-2 | 比較演算子で範囲の条件を書く | = だけでなく > や <= を使って「以上・以下」の条件を書ける |
| 2-1-3 | ANDで条件を重ねる | AND でつなぐと、両方の条件を満たす行だけに絞れる |
| 2-1-4 | ORでどちらかを満たす行を選ぶ | OR でつなぐと、どちらかの条件を満たす行を選べる |
| 2-1-5 | NULLはIS NULLで調べる | 値が入っていないことを表す NULL は、= ではなく IS NULL で調べる |

コード演習: `S0-Sql-Ch00-05-where-only`

### M3. 並べ替えと制限 — レッスン3-1 並べ替えと件数の制限

| ID | トピック | takeaway |
| --- | --- | --- |
| 3-1-1 | ORDER BYで並べ替える | ORDER BY を付けると、結果を指定した列の順に並べ替えられる |
| 3-1-2 | DESCで大きい順に並べる | ORDER BY 列名 DESC で、大きい順(降順)に並べ替えられる |
| 3-1-3 | LIMITで件数を絞る | LIMIT を付けると、先頭から指定した件数だけを取り出せる |

コード演習: `S0-Sql-Ch00-01-select-hello` / `S0-Sql-Ch00-02-where-filter` / `S0-Sql-Ch00-06-order-limit`

### M4. JOIN — レッスン4-1 JOINでテーブルをつなぐ

| ID | トピック | takeaway |
| --- | --- | --- |
| 4-1-1 | データは複数のテーブルに分けて持つ | 同じ情報を繰り返し書かないよう、データは複数のテーブルに分けて持つ |
| 4-1-2 | INNER JOINでテーブルをつなぐ | INNER JOIN ... ON で、IDが一致する行どうしをつなげて取り出せる |
| 4-1-3 | テーブル名.列名で列を区別する | 複数テーブルを使うときは、テーブル名.列名 の形でどの列かを区別する |
| 4-1-4 | LEFT JOINで左の行を全部残す | LEFT JOIN は左のテーブルの行を全部残し、相手がいない部分は NULL になる |
| 4-1-5 | 結合した結果も絞り込める | JOIN した結果もひとつの表なので、WHERE や ORDER BY がそのまま使える |

コード演習: `S0-Sql-Ch00-07-inner-join` / `S0-Sql-Ch00-08-left-join`

### M5. 集計 — レッスン5-1 集計してまとめる

| ID | トピック | takeaway |
| --- | --- | --- |
| 5-1-1 | COUNTで件数を数える | COUNT(*) で、条件に合う行が何件あるかを数えられる |
| 5-1-2 | 集計関数は列をまとめて計算する | SUM や AVG などの集計関数は、列の値をまとめてひとつの結果にする |
| 5-1-3 | GROUP BYでグループごとに集計する | GROUP BY を付けると、同じ値の行ごとにまとめて集計できる |
| 5-1-4 | HAVINGで集計結果を絞り込む | 集計した結果を絞り込むときは、WHERE ではなく HAVING を使う |

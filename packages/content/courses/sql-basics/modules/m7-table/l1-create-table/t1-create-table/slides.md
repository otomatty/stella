## なぜ必要か

- ここまでは、既にあるテーブルを使ってきた
- 新しい機能を作るときは、入れ物から用意する必要がある

## 結論

**CREATE TABLE で、テーブルの名前と列の一覧をあらかじめ決めておく**

- **CREATE TABLE** — テーブルを作るSQL文
- **スキーマ** — テーブルと列の定義。データの設計図

<!-- ノート: 結論を先に言い切ります。行を入れる前に形を決めるのがSQLの流儀です。 -->

---

## 名前と列を決める

```sql
CREATE TABLE products (
  id    INTEGER,
  name  TEXT,
  price INTEGER
);
```

- 列ごとに「名前」と「入れてよい値の種類」を書く
- 定義した後でないと、行は入れられない

<!-- ノート: 表計算ソフトと違い、先に形を決めることが特徴だと補足します。 -->

# 列にはデータ型を決める

SQL入門 — Module 7 / レッスン7-1

## なぜ必要か

- 価格の列に「200円」という文字列が混ざると、合計を計算できない
- 入れる人ごとに書き方が違うと、後の集計が壊れる

<!-- ノート: つかみ。SUM が動かない、という具体的な困りごとから入ります。 -->

---

## 結論

**列ごとにデータ型を決めると、その列に入る値の種類がそろう**

- **データ型** — その列に入れてよい値の種類
- **INTEGER** — 整数 / **TEXT** — 文字列

<!-- ノート: 結論を先に言い切ります。型は入力の間違いを入口で止める仕組みです。 -->

---

## よく使う3つ

```sql
CREATE TABLE orders (
  id       INTEGER,   -- 整数
  customer TEXT,      -- 文字列
  total    REAL       -- 小数
);
```

- 日付は多くの場合 `TEXT` で `'2026-04-12'` の形にそろえる
- SQLiteは違う型の値も受け付ける。型は「そろえる約束」として効く

<!-- ノート: SQLite の型は緩やかで、TEXT 列でも SUM が動いてしまいます。エラーで気づけないぶん危ないので、そろえる約束として決める意味があると伝えます。 -->

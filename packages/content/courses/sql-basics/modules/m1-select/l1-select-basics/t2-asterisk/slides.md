# *で全列を取り出す

SQL入門研修 — Module 1 / レッスン1-1

<!-- ノート: 列を選ぶ書き方の次は、全部まとめて取り出す書き方です。記号1文字だけの短いトピックです。 -->

---

## なぜ必要か

- テーブルにどんな列があるか、まず全体を見たいときがある
- 列名を全部書き並べるのは長くて手間

<!-- ノート: つかみ。初めて触るテーブルの中身をまず眺めたい、という調査の場面がいちばん出番が多い。 -->

---

## 結論

**\*(アスタリスク)を使うと、テーブルの全列を取り出せる**

<!-- ノート: 結論を言い切る。読み方は「アスタリスク」または「スター」。 -->

---

## 最小のコード

```sql
SELECT * FROM products;
```

| id | name | price |
| --- | --- | --- |
| 1 | コーヒー | 300 |
| 2 | サンドイッチ | 450 |

<!-- ノート: 列名の代わりに*を1つ書くだけ。結果には全列が入る。 -->

---

## 使いどころに注意

- 調査で中身を眺めるときは便利
- 画面やプログラムに組み込む文では、**列名を書くのが基本**
- 列が増えたときに、余計なデータまで運ばれてしまうため

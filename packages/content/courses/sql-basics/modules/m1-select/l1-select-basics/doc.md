# レッスン1-1 SELECTでデータを取り出す

## このレッスンの目標

- [ ] SELECT と FROM を使って、指定した列を取り出す文が書ける
- [ ] * と列名指定の使い分けを説明できる
- [ ] AS で別名を付け、式の計算結果を取り出せる

## 1-1-1 SELECTで列を選んで取り出す

> **SELECT 列名 FROM テーブル名 で、欲しい列だけを取り出せる**

最初のSQL文です。役割は2つのキーワードで決まります。

- `SELECT` — どの列がほしいか
- `FROM` — どのテーブルからか

```sql
SELECT name FROM products;
```

この問い合わせの返事として返ってくる表を **結果** と呼びます。取り出したのは `name` 列だけなので、結果も `name` 列だけの表になります。

| name |
| --- |
| コーヒー |
| サンドイッチ |

列は複数選べます。カンマで区切って並べると、並べた順番どおりの列で結果が返ります。

```sql
SELECT name, price FROM products;
```

カンマの付け忘れは最初のつまずきどころです。エラーメッセージが出たら、まず区切りを疑ってください。

## 1-1-2 *で全列を取り出す

> ***(アスタリスク)を使うと、テーブルの全列を取り出せる**

列名の代わりに `*` を1つ書くと、全列が返ります。

```sql
SELECT * FROM products;
```

| id | name | price |
| --- | --- | --- |
| 1 | コーヒー | 300 |
| 2 | サンドイッチ | 450 |

便利ですが、使いどころには注意が要ります。

- 調査でテーブルの中身を眺めるとき — 便利。どんどん使ってください
- 画面やプログラムに組み込む文 — **列名を書くのが基本**。列が増えたときに余計なデータまで運ばれてしまい、列の順番が変わった影響も受けやすくなります

## 1-1-3 ASで別名を付ける

> **AS を付けると、取り出した列に別名を付けられる**

列名は英語の略語が多く、結果をそのまま人に見せると伝わりません。`AS` で結果の見出しを付け直せます。この呼び名を **別名** と呼びます。

```sql
SELECT name AS 商品名 FROM products;
```

| 商品名 |
| --- |
| コーヒー |
| サンドイッチ |

変わるのは結果の見出しだけです。テーブル本体の列名は変わりません。

## 1-1-4 式もSELECTできる

> **SELECT では列そのものだけでなく、計算した結果も取り出せる**

「税込価格」のように、テーブルには無いが計算すれば出せる値があります。計算の書き方(`price * 1.1` など)を **式** と呼び、列名と同じ場所に書けます。

```sql
SELECT name, price * 1.1 AS 税込価格 FROM products;
```

| name | 税込価格 |
| --- | --- |
| コーヒー | 330 |

式に `AS` を付けないと、結果の見出しが `price * 1.1` という式そのものになってしまいます。エラーにはなりませんが、受け取った人が困ります。**式と AS はセットで使う**と覚えてください。

## もっと知りたい人へ

- `*` を本番のコードに残すかどうかは、現場のレビューでよく話題になります。まずは「調査は `*`、組み込みは列名」を守れば大丈夫です
- 式では `+` `-` `*` `/` の四則演算が使えます。文字列の連結など他の書き方は、必要になったときに製品のリファレンスで確認しましょう

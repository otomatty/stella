# 1-1-4
# 式もSELECTできる

SQL入門 — Module 1 / レッスン1-1

<!-- ノート: SELECTの締めくくりです。列をそのまま出すだけでなく、計算してから出せることを覚えます。 -->

---

## なぜ必要か

- 「税込価格」のように、テーブルには無いが計算すれば出せる値がある
- 取り出してから電卓で計算するのではなく、取り出すときに計算させたい

<!-- ノート: つかみ。税込金額の列は普通テーブルに持たない(税率が変わると全行直すことになる)。必要なときに計算で作る、という設計の話を一言だけ。 -->

---

## 結論

**SELECT では列そのものだけでなく、計算した結果も取り出せる**

- 計算の書き方(`price * 1.1` など)を **式** と呼ぶ

<!-- ノート: 結論を言い切る。式という言葉はこのあとの集計でも使うので、ここで定義しておく。 -->

---

## 最小のコード

```sql
SELECT name, price * 1.1 AS 税込価格 FROM products;
```

| name | 税込価格 |
| --- | --- |
| コーヒー | 330 |

<!-- ノート: 掛け算は*記号。前トピックのASがここで効いてくる。式に別名を付けないと、結果の見出しが式そのものになって読みにくい。 -->

---

## 式に別名が無いと

```sql
SELECT price * 1.1 FROM products;
```

| price * 1.1 |
| --- |
| 330.0 |

- 動くが、見出しが式のままで読みにくい。**式には AS を付ける**

<!-- ノート: 失敗例枠。エラーにはならないが、受け取ったプログラムや人が困る。式とASはセットで使う癖をつける。 -->

---

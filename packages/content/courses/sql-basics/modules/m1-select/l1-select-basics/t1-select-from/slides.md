# SELECTで列を選んで取り出す

SQL入門 — Module 1 / レッスン1-1

<!-- ノート: いよいよ最初のSQL文を書きます。この研修の軸になる、データを取り出す文です。 -->

## なぜ必要か

- テーブルには使わない列もたくさんある。全部見せられても困る
- 「どの表から、どの項目を」を指定して、必要な分だけ受け取りたい

<!-- ノート: つかみ。商品一覧画面に原価や仕入先まで出たら困る、のような例で「選んで取り出す」動機を作る。 -->

---

## 結論

**SELECT 列名 FROM テーブル名 で、欲しい列だけを取り出せる**

- `SELECT` = どの列がほしいか
- `FROM` = どのテーブルからか

<!-- ノート: 結論を言い切る。前トピックで形だけ見せた文の意味が、ここで初めて確定する。 -->

---

## 最小のコード

```sql
SELECT name FROM products;
```

| name |
| --- |
| コーヒー |
| サンドイッチ |

<!-- ノート: 問い合わせの返事として返ってくる表を「結果」と呼ぶ。取り出したのはname列だけなので、結果もname列だけの表になる。 -->

---

## 列は複数選べる

```sql
SELECT name, price FROM products;
```

- 列名をカンマで区切って並べる
- 並べた順番どおりの列で **結果** が返る

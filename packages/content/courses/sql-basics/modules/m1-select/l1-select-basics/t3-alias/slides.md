# ASで別名を付ける

SQL入門研修 — Module 1 / レッスン1-1

<!-- ノート: 取り出す列を選べるようになったので、次は結果の列に名前を付け直す方法です。 -->

---

## なぜ必要か

- 列名は英語の略語が多く、結果をそのまま人に見せると伝わらない
- レポートに載せるときは「価格」のような分かりやすい見出しにしたい

<!-- ノート: つかみ。priceのままの帳票と「価格」と書かれた帳票、どちらを上司に出すか、という場面設定。 -->

---

## 結論

**AS を付けると、取り出した列に別名を付けられる**

- 別名 = 結果に表示するための呼び名。元のテーブルは変わらない

<!-- ノート: 結論を言い切る。あくまで結果の見出しが変わるだけで、テーブル本体の列名は変わらないことを強調する。 -->

---

## 最小のコード

```sql
SELECT name AS 商品名 FROM products;
```

| 商品名 |

# レッスン5-1 集計してまとめる

## このレッスンの目標

- [ ] COUNT・SUM・AVG などの集計関数で、行をひとつの結果にまとめられる
- [ ] GROUP BY でグループごとの集計が書ける
- [ ] WHERE と HAVING の使い分けを説明できる

## 5-1-1 COUNTで件数を数える

> **COUNT(*) で、条件に合う行が何件あるかを数えられる**

「今日の注文は何件?」と聞かれたとき、行を全部取り出して自分で数えるのは大変です。数えるのもデータベースに任せられます。行をまとめてひとつの数字にすることを **集計** と呼びます。

```sql
SELECT COUNT(*) FROM orders;
```

| COUNT(*) |
| --- |
| 6 |

結果は行の一覧ではなく、数字1つだけの表になります。カッコの中の `*` は「行そのもの」を指すと読んでください。

WHERE と組み合わせると、「条件に合う行が何件か」が一発で出ます。WHERE が先に効いて、残った行を COUNT が数える、という順番です。

```sql
SELECT COUNT(*) FROM orders WHERE amount >= 200;
```

| COUNT(*) |
| --- |
| 2 |

## 5-1-2 集計関数は列をまとめて計算する

> **SUM や AVG などの集計関数は、列の値をまとめてひとつの結果にする**

件数だけでは「売上の合計は?」「平均は?」に答えられません。COUNT の仲間をまとめて **集計関数** と呼びます。`SUM(列名)` のように、カッコに対象の列を書きます。

```sql
SELECT SUM(amount) FROM orders;
```

| SUM(amount) |
| --- |
| 890 |

`amount` 列の6つの値が、足し算されてひとつの数字になります。まずは次の5つを覚えれば、実務の集計のほとんどが書けます。

| 集計関数 | 意味 |
| --- | --- |
| COUNT(*) | 行の数 |
| SUM(列) | 合計 |
| AVG(列) | 平均 |
| MAX(列) | 最大 |
| MIN(列) | 最小 |

## 5-1-3 GROUP BYでグループごとに集計する

> **GROUP BY を付けると、同じ値の行ごとにまとめて集計できる**

全体の合計だけでなく、「顧客ごとの注文件数」を知りたいことがあります。顧客の人数ぶんSQL文を書くのは現実的ではありません。

`GROUP BY` を付けると、同じ値を持つ行がまとまりになります。このまとまりを **グループ** と呼び、集計関数はグループごとに1回ずつ働きます。

```sql
SELECT customer, COUNT(*) AS cnt FROM orders GROUP BY customer;
```

| customer | cnt |
| --- | --- |
| alice | 2 |
| bob | 1 |
| carol | 3 |

6行の注文が、顧客3人ぶんの3行にまとまりました。グループの数がそのまま結果の行数になります。

なお、`SELECT` に書いてよいのは、GROUP BY した列と集計関数だけです。それ以外の列は「グループの中のどの行の値か」が決められないためです。

## 5-1-4 HAVINGで集計結果を絞り込む

> **集計した結果を絞り込むときは、WHERE ではなく HAVING を使う**

「合計金額が300円以上の顧客だけ」を知りたいとします。合計は集計してみないと分からないので、WHERE では絞れません。`WHERE amount >= 300` と書くと「1回の注文が300円以上」という別の意味になってしまいます。

集計した結果への条件は、GROUP BY の後ろに `HAVING` で書きます。条件の書き方そのものは WHERE と同じ形です。

```sql
SELECT customer, SUM(amount) AS total
FROM orders
GROUP BY customer
HAVING SUM(amount) >= 300;
```

| customer | total |
| --- | --- |
| alice | 350 |
| carol | 420 |

bob は合計120なので消えます。使い分けは次の表のとおりです。

| | 絞るタイミング | 絞る対象 |
| --- | --- | --- |
| WHERE | 集計の前 | 行 |
| HAVING | 集計の後 | 集計した結果 |

迷ったら「条件に集計関数が入るなら HAVING」と覚えてください。両方を同じ文で使うこともできます。

## もっと知りたい人へ

- 集計の文が読めなくなったら、「まず WHERE で行を絞る → GROUP BY でまとめる → 集計関数が働く → HAVING で結果を絞る」の順に紙に書き出してみてください。どんな文もこの順で分解できます
- COUNT・SUM・AVG・MAX・MIN のほかにも集計関数はあります。必要になったときに、使っているデータベースのリファレンスで調べる習慣をつけましょう

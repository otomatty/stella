# 5-1-1
# COUNTで件数を数える

SQL入門 — Module 5 / レッスン5-1

<!-- ノート: 最後のModule 5は「まとめて数える」話です。行を取り出すのではなく、行から数字を作ります。 -->

---

## なぜ必要か

- 「今日の注文は何件?」と聞かれたとき、行を全部取り出して自分で数えるのは大変
- 数えた結果の数字だけがほしい

<!-- ノート: つかみ。1万件の注文を目で数える人はいない。数えるのもデータベースの仕事にしてしまおう、という動機。 -->

---

## 結論

**COUNT(*) で、条件に合う行が何件あるかを数えられる**

- 行をまとめてひとつの数字にすることを **集計** と呼ぶ
- `COUNT(*)` = 行の数を数える

<!-- ノート: 結論。集計という言葉をここで定義する。COUNTは数えるの英語。カッコの中の*は「行そのもの」を指すと読む。 -->

---

## 最小のコード

```sql
SELECT COUNT(*) FROM orders;
```

| COUNT(*) |
| --- |
| 6 |

<!-- ノート: 結果は行の一覧ではなく、数字1つだけの表になる。6行が1つの数字にまとまった、という見た目の変化を強調する。 -->

---

## WHEREと組み合わせる

```sql
SELECT COUNT(*) FROM orders WHERE amount >= 200;
```

| COUNT(*) |
| --- |
| 2 |

- WHERE で絞ってから数える。「条件に合う行が何件か」が一発で出る

<!-- ノート: 対比枠。全件の6件に対し、200円以上に絞ると2件。WHEREが先に効いて、残った行をCOUNTが数える、という順番を押さえる。 -->

---

## まとめ

**COUNT(*) で、条件に合う行が何件あるかを数えられる**

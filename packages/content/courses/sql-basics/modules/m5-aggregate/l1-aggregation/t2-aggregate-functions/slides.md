# 5-1-2
# 集計関数は列をまとめて計算する

SQL入門 — Module 5 / レッスン5-1

<!-- ノート: COUNTには仲間がいます。数えるだけでなく、足したり平均したりする道具を一気に揃えます。 -->

---

## なぜ必要か

- 「今日の売上の合計は?」「客単価の平均は?」— 件数だけでは答えられない
- 列の値を足したり、平均したりした数字がほしい

<!-- ノート: つかみ。COUNTで件数は出せるようになったが、実務で聞かれるのは合計と平均のほうが多い、と橋を架ける。 -->

---

## 結論

**SUM や AVG などの集計関数は、列の値をまとめてひとつの結果にする**

- COUNT の仲間をまとめて **集計関数** と呼ぶ
- `SUM(列名)` のように、カッコに対象の列を書く

<!-- ノート: 結論。関数という言葉が初めてなら「値を渡すと計算結果を返す道具」と補足する。カッコに列名を渡す形はCOUNT(*)と同じ。 -->

---

## 最小のコード

```sql
SELECT SUM(amount) FROM orders;
```

| SUM(amount) |
| --- |
| 890 |

<!-- ノート: amount列の6つの値が、足し算されてひとつの数字になる。列がまるごと計算に入る感覚をつかむ。 -->

---

## 集計関数は5つ覚えれば十分

| 集計関数 | 意味 |
| --- | --- |
| COUNT(*) | 行の数 |
| SUM(列) | 合計 |
| AVG(列) | 平均 |
| MAX(列) | 最大 |
| MIN(列) | 最小 |

# 3-1-2
# DESCで大きい順に並べる

SQL入門 — Module 3 / レッスン3-1

<!-- ノート: 並べ替えの向きを逆にします。付け足すのはキーワード1つだけです。 -->

---

## なぜ必要か

- 「高い順」「売れた順」「新しい順」— 実務では大きい方から見たい場面が多い
- ORDER BY だけだと小さい順になってしまう

<!-- ノート: つかみ。ランキングはほぼ全部「大きい方から」。既定の昇順では逆向きになってしまう。 -->

---

## 結論

**ORDER BY 列名 DESC で、大きい順(降順)に並べ替えられる**

- 大きい方から小さい方へ並ぶ順を **降順** と呼ぶ

<!-- ノート: 結論を言い切る。DESCはdescending(下っていく)の略、と一言添えると覚えやすい。 -->

---

## 最小のコード

```sql
SELECT name, price FROM products ORDER BY price DESC;
```

| name | price |
| --- | --- |
| サンドイッチ | 450 |
| コーヒー | 300 |
| クッキー | 200 |

<!-- ノート: 列名の後ろにDESCを置くだけ。さっきと同じデータが逆向きに並んだことを指差し確認する。 -->

---

## 昇順と降順

| 並び順 | 書き方 | 向き |
| --- | --- | --- |
| 昇順 | ORDER BY price | 小さい順(既定) |
| 降順 | ORDER BY price DESC | 大きい順 |

<!-- ノート: 対比枠。昇順は書かなくても既定で効く、降順だけDESCが要る、と整理する。 -->

---

## まとめ

# レッスン3-1 並べ替えと件数の制限

## このレッスンの目標

- [ ] ORDER BY で結果を指定した列の昇順に並べ替えられる
- [ ] DESC を付けて降順に並べ替えられる
- [ ] ORDER BY と LIMIT を組み合わせて「上位N件」を取り出せる

## 3-1-1 ORDER BYで並べ替える

> **ORDER BY を付けると、結果を指定した列の順に並べ替えられる**

何も指定しないと、結果の並び順は **保証されません**。たまたま `id` 順に見えても、それは偶然です。「安い順に見たい」のように順番に意味があるなら、`ORDER BY` を文のいちばん後ろに付けて明示します。

```sql
SELECT name, price FROM products ORDER BY price;
```

| name | price |
| --- | --- |
| クッキー | 200 |
| コーヒー | 300 |
| サンドイッチ | 450 |

何も指定しなければ **昇順**(小さい順)に並びます。数値なら小さい順、文字なら辞書の順です。

| 書き方 | 並び順 |
| --- | --- |
| ORDER BY なし | 保証されない(毎回同じとは限らない) |
| ORDER BY price | 必ず price の昇順 |

## 3-1-2 DESCで大きい順に並べる

> **ORDER BY 列名 DESC で、大きい順(降順)に並べ替えられる**

「高い順」「売れた順」のように、実務では大きい方から見たい場面が多くあります。大きい方から小さい方へ並ぶ順を **降順** と呼び、列名の後ろに `DESC` を置くだけで切り替えられます。

```sql
SELECT name, price FROM products ORDER BY price DESC;
```

| name | price |
| --- | --- |
| サンドイッチ | 450 |
| コーヒー | 300 |
| クッキー | 200 |

| 並び順 | 書き方 | 向き |
| --- | --- | --- |
| 昇順 | ORDER BY price | 小さい順(既定) |
| 降順 | ORDER BY price DESC | 大きい順 |

昇順は既定なので何も書かなくても効きます。降順のときだけ `DESC` が必要です。

## 3-1-3 LIMITで件数を絞る

> **LIMIT を付けると、先頭から指定した件数だけを取り出せる**

「売上トップ3」のように上位の数件だけほしいとき、何千行もの結果を全部受け取るのは無駄です。`LIMIT 件数` を文のいちばん後ろに書くと、先頭から指定した件数だけが返ります。

```sql
SELECT name, price FROM products
ORDER BY price DESC LIMIT 2;
```

| name | price |
| --- | --- |
| サンドイッチ | 450 |
| コーヒー | 300 |

LIMIT が数えるのは「並べ替えが終わった後の先頭から」です。並べ替えずに LIMIT だけ書くと、どの行が先頭かは保証されません。だから ORDER BY とセットで使うのが基本です。

```sql
SELECT item, amount FROM orders
ORDER BY amount DESC LIMIT 3;
```

「大きい順に並べて、先頭3件」— この `ORDER BY 〜 DESC LIMIT 3` が「トップ3」の定番形です。このまま丸ごと覚えてしまって構いません。

## もっと知りたい人へ

- ORDER BY は複数の列を指定できます。「価格が同じなら名前の順」のような並べ替えが必要になったら調べてみてください
- LIMIT には「先頭を何件か飛ばしてから取り出す」書き方もあります。一覧画面のページ送りを作るときに出会うはずです

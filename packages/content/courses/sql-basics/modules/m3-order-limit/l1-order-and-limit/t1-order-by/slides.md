# 3-1-1
# ORDER BYで並べ替える

SQL入門研修 — Module 3 / レッスン3-1

<!-- ノート: Module 3では、取り出した結果の見せ方を整えます。まずは並べ替えです。 -->

---

## なぜ必要か

- 何も指定しないと、結果の並び順は **保証されない**
- 「安い順に見たい」のように、順番そのものに意味がある場面は多い

<!-- ノート: つかみ。たまたまid順に見えても、それは偶然。順番に頼るなら明示的に指定する必要がある、という動機を作る。 -->

---

## 結論

**ORDER BY を付けると、結果を指定した列の順に並べ替えられる**

- 何も指定しなければ **昇順**(小さい順)に並ぶ

<!-- ノート: 結論を言い切る。昇順という言葉はここで定義する。数値なら小さい順、文字なら辞書の順。 -->

---

## 最小のコード

```sql
SELECT name, price FROM products ORDER BY price;
```

| name | price |
| --- | --- |
| クッキー | 200 |
| コーヒー | 300 |
| サンドイッチ | 450 |

<!-- ノート: ORDER BYは文のいちばん後ろに書く。priceの小さい順に並んだことを指差し確認する。 -->

---

## 指定なしとの違い

| 書き方 | 並び順 |
| --- | --- |
| ORDER BY なし | 保証されない(毎回同じとは限らない) |
| ORDER BY price | 必ず price の昇順 |

<!-- ノート: 対比枠。「見た目がid順だったから大丈夫」が事故のもと。順番に意味があるなら必ずORDER BYを書く。 -->

---

## まとめ

**ORDER BY を付けると、結果を指定した列の順に並べ替えられる**

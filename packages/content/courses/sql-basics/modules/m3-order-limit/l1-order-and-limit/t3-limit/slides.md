# 3-1-3
# LIMITで件数を絞る

SQL入門 — Module 3 / レッスン3-1

<!-- ノート: Module 3の仕上げです。並べ替えと組み合わせると、実務の定番形が完成します。 -->

---

## なぜ必要か

- 「売上トップ3」のように、上位の数件だけ見たい場面がある
- 何千行もある結果を全部受け取るのは無駄が大きい

<!-- ノート: つかみ。ランキングは上位だけ見えれば十分。全件取ってから目で数えるのはやめたい。 -->

---

## 結論

**LIMIT を付けると、先頭から指定した件数だけを取り出せる**

- `LIMIT 件数` を文のいちばん後ろに書く

<!-- ノート: 結論を言い切る。LIMITが数えるのは「並べ替えが終わった後の先頭から」。だからORDER BYとセットで使う。 -->

---

## 最小のコード

```sql
SELECT name, price FROM products
ORDER BY price DESC LIMIT 2;
```

| name | price |
| --- | --- |
| サンドイッチ | 450 |
| コーヒー | 300 |

<!-- ノート: 高い順に並べてから先頭2件。3件目以降は結果に入らない。 -->

---

## 定番形: 上位N件

```sql
SELECT item, amount FROM orders
ORDER BY amount DESC LIMIT 3;
```

- 「売上トップ3」= **大きい順に並べて、先頭3件**
- 並べ替えずに LIMIT だけ書くと、どの行が先頭かは保証されない

<!-- ノート: 強化枠。ORDER BY 〜 DESC LIMIT N はこのまま丸ごと覚えてよい定番形。LIMIT単独は「とりあえず数行だけ眺める」調査用途に限る。 -->

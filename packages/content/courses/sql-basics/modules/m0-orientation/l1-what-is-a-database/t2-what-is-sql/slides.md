## なぜ必要か

- テーブルには何万行ものデータが入っている。目で探すのは現実的ではない
- 「この条件のデータをください」と頼む、決まった言い方が要る

<!-- ノート: つかみ。会員10万人から1人を探す場面を想像してもらう。人力で表をスクロールする世界と、頼めば一瞬で返ってくる世界の対比。 -->

---

## 結論

**SQLは、データベースにデータの出し入れを頼むための言語**

- 頼みごとの例: 「products テーブルから全部の行をください」
- こうした頼みごとを **問い合わせ** と呼ぶ

<!-- ノート: SQLはプログラミング言語というより「依頼の書式」に近い。英語の Structured Query Language の略だが、名前の暗記より「頼むための言語」という役割を覚えてもらう。 -->

---

## どこで使われているか

| 場面 | 裏で起きている問い合わせ |
| --- | --- |
| ECサイトの商品一覧 | 商品テーブルから一覧をください |
| 会員のログイン | この会員のデータをください |
| 売上レポート | 今月の注文を集計してください |

<!-- ノート: 対比枠の代わりに実務との接続。画面の裏側ではほぼ必ずSQLが動いている。SESの現場でも、どの言語のプロジェクトに入ってもSQLだけは共通して使う、と動機づけする。 -->

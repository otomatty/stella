# レッスン0-1 演習 — データベースとSQL

対象トピック: 0-1-1 〜 0-1-3

このレッスンはSQLを書く前の回です。演習は読んで考える問題が中心になります。

## ハンズオン

身の回りの業務を1つ選び、テーブルの形で書き出してみましょう。

1. 「社員名簿」をテーブルにするなら、列は何にしますか。3つ以上挙げてください(例: 名前、所属、入社日)
2. その表に自分のデータを1行ぶん書き入れてください
3. 「この表から◯◯をください」と頼みたくなる場面を1つ考えてください(例: 所属が営業部の人の一覧がほしい)

この「頼みごと」を書式どおりに書けるようになるのが、次のモジュールからの内容です。

## 演習問題

### 問1(基本)

次の orders テーブルについて、行の数と列の数を答えてください。

| id | item | amount |
| --- | --- | --- |
| 1 | コーヒー | 300 |
| 2 | ケーキセット | 800 |
| 3 | クッキー | 200 |

### 問2(基本)

「会員のログイン」「商品一覧の表示」「売上レポートの作成」に共通して裏側で使われているものは何ですか。一言で答えてください。

### 問3(応用)

次のSQL文について、キーワードと思われる部分をすべて挙げてください。意味はまだ知らなくて構いません。

```sql
SELECT name FROM products;
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

行は3、列は3です。

横の1件ぶん(`1, コーヒー, 300`)が行で、3件あります。縦の項目(`id` / `item` / `amount`)が列で、3つあります。ヘッダー(項目名の段)は行数には数えません。

</details>

<details>
<summary>問2の解答例</summary>

SQL(データベースへの問い合わせ)です。

どの場面も「データベースから条件に合うデータを取り出す」処理で、その頼みごとはSQLで書かれています。

</details>

<details>
<summary>問3の解答例</summary>

`SELECT` と `FROM` です。

役割が決まっている英単語がキーワードです。`name` や `products` は列名・テーブル名なので、キーワードではありません。末尾の `;` は文の終わりを示すセミコロンです。

</details>

## 確認クイズ

### Q1. データベースの中でデータを保管している「表」を何と呼びますか。

- A. シート
- B. テーブル
- C. フォルダ

<details>
<summary>答え</summary>

**B** — データベースの中の1枚の表をテーブルと呼びます。横の1件ぶんが行、縦の項目が列です。

</details>

### Q2. テーブルの「行」の説明として正しいものはどれですか。

- A. 縦に並んだ項目のこと
- B. データ1件ぶんの横並びのこと
- C. テーブルの項目名のこと

<details>
<summary>答え</summary>

**B** — 行はデータ1件ぶんです。縦の項目は列、項目名はヘッダーにあたります。

</details>

### Q3. SQLの役割として最も近いものはどれですか。

- A. Webページの見た目を作る言語
- B. データベースにデータの出し入れを頼むための言語
- C. コンピューターの電源を管理する言語

<details>
<summary>答え</summary>

**B** — SQLはデータベースへの問い合わせ(頼みごと)を書くための言語です。画面の裏側で広く使われています。

</details>

### Q4. SQL文の書き方のルールとして正しいものはどれですか。

- A. 文の終わりにセミコロンを付ける
- B. キーワードは必ず小文字で書かないと動かない
- C. 1つの文を必ず1行で書かないと動かない

<details>
<summary>答え</summary>

**A** — SQL文はセミコロンで終えます。キーワードの大文字・小文字は区別されず、文の途中で改行しても動きます。

</details>

# レッスン0-1 データベースとSQL

## このレッスンの目標

- [ ] テーブル・行・列という言葉で、データの保管の形を説明できる
- [ ] SQLが何をするための言語かを説明できる
- [ ] SQL文の見た目のルール(キーワードとセミコロン)を知っている

## 0-1-1 データは表で管理する

> **データベースは、データをテーブル(表)の行と列で管理する**

まず言葉を3つ決めておきます。

- **データ** — 業務で扱う記録(商品名、価格、注文など)
- **データベース** — データを安全にしまっておく保管庫
- **テーブル** — データベースの中の1枚の表

ECサイトの商品も、会員情報も、注文履歴も、裏側ではテーブルに入っています。

products テーブルの例:

| id | name | price |
| --- | --- | --- |
| 1 | コーヒー | 300 |
| 2 | サンドイッチ | 450 |

- 横の1件ぶん(`1, コーヒー, 300`)が **行** です
- 縦の項目(`id` / `name` / `price`)が **列** です

見た目はExcelの表とよく似ています。違いは、データベースが大量のデータを、複数の人やプログラムから同時に、安全に扱えるように作られていることです。

## 0-1-2 SQLはデータベースへの命令文

> **SQLは、データベースにデータの出し入れを頼むための言語**

テーブルには何万行ものデータが入ります。目で探すのは現実的ではないので、「この条件のデータをください」とデータベースに頼みます。その頼みごとを書くための言語が **SQL** です。頼みごとのことを **問い合わせ** と呼びます。

SQLは画面の裏側のいたるところで動いています。

| 場面 | 裏で起きている問い合わせ |
| --- | --- |
| ECサイトの商品一覧 | 商品テーブルから一覧をください |
| 会員のログイン | この会員のデータをください |
| 売上レポート | 今月の注文を集計してください |

プロジェクトで使うプログラミング言語が変わっても、データベースへの頼みごとはほぼSQLで共通です。一度覚えれば、どの現場でも使えます。

## 0-1-3 SQL文の基本ルール

> **SQL文はキーワードの組み合わせで書き、セミコロンで終える**

頼みごと1つぶんの文を **SQL文** と呼びます。書き方には決まりがあります。

```sql
SELECT name FROM products;
```

- `SELECT` や `FROM` のように役割が決まっている英単語を **キーワード** と呼びます
- 文の終わりには **セミコロン**(`;`)を付けます
- キーワードは大文字でも小文字でも動きます。この教材では読みやすさのため大文字で書きます

この文の意味は次のレッスンで扱います。ここでは「キーワード+対象を並べて、セミコロンで締める」という形だけ覚えてください。

## もっと知りたい人へ

- データベースにはいくつも製品があり、細かい書き方(方言)が少しずつ違います。この講座では、どの製品でも通じる基本の書き方だけを扱います
- 現場で製品固有の書き方に出会ったら、その製品の公式リファレンスを確認する習慣をつけましょう

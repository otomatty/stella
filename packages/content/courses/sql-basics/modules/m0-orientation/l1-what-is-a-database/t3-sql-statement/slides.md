# SQL文の基本ルール

SQL入門研修 — Module 0 / レッスン0-1

<!-- ノート: SQLが「頼むための言語」だと分かったところで、その頼みごと1つぶんの書き方のルールを覚えます。 -->

---

## なぜ必要か

- 頼みごとには決まった書式がある。自由な日本語では伝わらない
- 書式のルールを先に知っておくと、次のモジュールからの例文が読める

<!-- ノート: つかみ。書式が決まっているからこそ、世界中のデータベースが同じ言葉で動く。ルールは少ないので、ここでまとめて覚えてしまう。 -->

---

## 結論

**SQL文はキーワードの組み合わせで書き、セミコロンで終える**

- SQL文 = 頼みごと1つぶんの文
- キーワード = 役割が決まっている英単語

<!-- ノート: 結論を言い切る。キーワードは「予約された英単語」で、次のモジュールから1つずつ覚えていくと予告する。 -->

---

## 最小の例

```sql
SELECT name FROM products;
```

- `SELECT` と `FROM` がキーワード。末尾の `;` が **セミコロン**
- キーワードは大文字でも小文字でも動く。この教材は大文字で書く

<!-- ノート: 意味の説明はまだしない。「キーワード+対象を並べ、セミコロンで締める」という形だけ見てもらう。この文が何をするかは次のモジュールの主役なので、ここでは形の観察に留める。 -->

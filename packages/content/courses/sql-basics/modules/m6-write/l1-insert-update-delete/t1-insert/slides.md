## なぜ必要か

- ここまでは、既にあるデータを取り出すだけだった
- 実際のシステムは、申し込みや登録でデータが増えていく

## 結論

**INSERT INTO テーブル名 (列) VALUES (値) で、テーブルに新しい行を追加する**

- **INSERT** — 行を追加するSQL文
- **VALUES** — 追加する値を並べる場所

<!-- ノート: 結論を先に言い切ります。列と値が同じ順で対応する点が読み方の鍵です。 -->

---

## 列と値を同じ順で書く

```sql
INSERT INTO products (name, price)
VALUES ('ノート', 200);
```

- 書いていない列には、既定の値かNULLが入る
- 列の並びと値の並びは、必ず同じ順にする

<!-- ノート: 列名を省略する書き方もありますが、順序に依存して壊れやすいので教えません。 -->

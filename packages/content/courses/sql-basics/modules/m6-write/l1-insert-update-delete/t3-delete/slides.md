# DELETEで行を消す

SQL入門 — Module 6 / レッスン6-1

<!-- ノート: 取り消せない操作です。淡々と書き方を教え、危険性は次のトピックでまとめて扱います。 -->

---

## なぜ必要か

- 退会した会員や、取り消された注文の行を消したい
- 残したままにすると、集計の結果が実態と合わなくなる

<!-- ノート: つかみ。消す理由を業務の言葉で説明します。 -->

---

## 結論

**DELETE FROM テーブル名 WHERE 条件 で、条件に合う行を消す**

- **DELETE** — 行を消すSQL文。列だけを消すことはできない

<!-- ノート: 結論を先に言い切ります。消す単位は行であることを押さえます。 -->

---

## 消えるのは行の単位

```sql
DELETE FROM products
WHERE id = 1;
```

- 列の値だけを空にしたいなら、`UPDATE` で `NULL` を入れる
- 実務では、消さずに「削除済み」の印を付ける設計も多い

<!-- ノート: 論理削除の存在に軽く触れます。設計の詳細はデータベース設計入門の範囲です。 -->

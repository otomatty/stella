# 2-1-2
# 比較演算子で範囲の条件を書く

SQL入門研修 — Module 2 / レッスン2-1

<!-- ノート: WHEREの条件に使える記号を一気にそろえます。種類は多く見えますが、算数の不等号と同じです。 -->

---

## なぜ必要か

- 「300円ちょうど」より「300円以上」のような条件のほうが多い
- 「在庫が5個以下の商品」= 発注が必要な商品、のような実務の質問に答えたい

<!-- ノート: つかみ。ぴったり一致だけでは実務の質問に答えられない。範囲で聞きたい場面を思い浮かべてもらう。 -->

---

## 結論

**= だけでなく > や <= を使って「以上・以下」の条件を書ける**

- 値どうしを比べる記号を **比較演算子** と呼ぶ

<!-- ノート: 結論を言い切る。比較演算子という名前だけ覚えれば、記号自体は算数で見たものばかり。 -->

---

## 最小のコード

```sql
SELECT name, stock FROM products WHERE stock <= 5;
```

| name | stock |
| --- | --- |
| サンドイッチ | 0 |
| ケーキ | 5 |
| 紅茶 | 0 |

<!-- ノート: 在庫5個以下 = 発注候補の一覧。<= は「以下」なので、ちょうど5のケーキも残る。 -->

---

## 比較演算子は6つ

| 演算子 | 意味 |
| --- | --- |
| `=` | 等しい |
| `!=` | 等しくない |
| `>` / `>=` | より大きい / 以上 |
| `<` / `<=` | より小さい / 以下 |

- 文字列の条件は `name = 'コーヒー'` のようにシングルクォートで囲む

<!-- ノート: 対比枠。>と>=の違い(境目の値を含むか)がいちばんのつまずきどころ。文字列は'で囲む、数値は囲まない、もここで指差し確認する。 -->

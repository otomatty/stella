# 2-1-4
# ORでどちらかを満たす行を選ぶ

SQL入門研修 — Module 2 / レッスン2-1

<!-- ノート: ANDとペアになるもうひとつのつなぎ方です。1文字違いで結果が大きく変わります。 -->

---

## なぜ必要か

- 「コーヒーまたは紅茶」のように、候補のどれかに当てはまれば良い場面がある
- AND で書くと「両方同時」になってしまい、1行も残らない

<!-- ノート: つかみ。ドリンクだけの一覧を出したい場面。name = 'コーヒー' AND name = '紅茶' は両方同時に満たせないので0行になる、と口頭で触れる。 -->

---

## 結論

**OR でつなぐと、どちらかの条件を満たす行を選べる**

- `条件1 OR 条件2` の形で、WHERE の中に書く

<!-- ノート: 結論を言い切る。ORは日本語の「または」。どちらか一方でも合格すれば残る。 -->

---

## 最小のコード

```sql
SELECT name, price FROM products
WHERE name = 'コーヒー' OR name = '紅茶';
```

| name | price |
| --- | --- |
| コーヒー | 300 |
| 紅茶 | 350 |

<!-- ノート: どちらかの名前に当てはまる行が残る。1行が両方を同時に満たす必要はない。 -->

---

## ANDとORの違い

| つなぎ方 | 残る行 |
| --- | --- |
| `AND` | **両方** の条件を満たす行だけ |
| `OR` | **どちらか** の条件を満たす行 |

- 迷ったら「かつ」なら AND、「または」なら OR と読み替える

<!-- ノート: 対比枠。同じ条件のペアでも、ANDは絞る方向、ORは広げる方向に働く。日本語に読み替える癖を付けてもらう。 -->

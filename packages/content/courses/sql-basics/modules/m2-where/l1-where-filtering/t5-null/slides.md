# NULLはIS NULLで調べる

SQL入門 — Module 2 / レッスン2-1

<!-- ノート: Module 2の締めくくりは、実務で必ず出会うNULLです。書き方をひとつだけ覚えれば怖くありません。 -->

---

## なぜ必要か

- テーブルには「値がまだ入っていない」欄がある
- 例: セール対象の商品だけ discount_price(割引価格)が入り、対象外は空のまま

<!-- ノート: つかみ。全商品に割引価格があるわけではない。「空の行だけ探したい」という場面はとても多い。 -->

---

## 結論

**値が入っていないことを表す NULL は、= ではなく IS NULL で調べる**

- **NULL** = 値が入っていないことを表す特別な印。0 とも空文字とも違う

<!-- ノート: 結論を言い切る。NULLは「不明・未設定」であって値ではない。だから比較演算子では調べられない。 -->

---

## 最小のコード

```sql
SELECT name FROM products
WHERE discount_price IS NULL;
```

| name |
| --- |
| サンドイッチ |
| クッキー |

<!-- ノート: 割引価格が入っていない = セール対象外の商品一覧。逆に「値が入っている行」はIS NOT NULLで取り出せる。 -->

---

## 失敗例: = では調べられない

```sql
SELECT name FROM products
WHERE discount_price = NULL;
```

- 1行も返らない(エラーにもならないので気づきにくい)
- NULL は値ではないため、`=` の比べる相手になれない

<!-- ノート: 失敗例枠。エラーが出ないのがいちばん怖いところ。「NULLには IS を使う」を合言葉にする。 -->

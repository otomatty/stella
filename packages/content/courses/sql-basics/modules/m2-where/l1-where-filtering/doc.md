# レッスン2-1 WHEREで行を絞り込む

## このレッスンの目標

- [ ] WHERE と比較演算子を使って、条件に合う行だけを取り出せる
- [ ] AND / OR を使い分けて、複数の条件を組み合わせられる
- [ ] NULL の行を IS NULL / IS NOT NULL で調べられる

## 2-1-1 WHEREで行を絞り込む

> **WHERE を付けると、条件に合う行だけに絞り込める**

実際のテーブルには何百・何千という行があります。見たいのはその一部だけです。`WHERE` を `FROM テーブル名` の後ろに付けると、行を絞り込めます。行を残す基準を **条件** と呼びます。

```sql
SELECT name, price FROM products WHERE price >= 300;
```

| name | price |
| --- | --- |
| コーヒー | 300 |
| サンドイッチ | 450 |
| ケーキ | 500 |

データベースは1行ずつ条件を調べ、合う行だけを結果に残します。`SELECT` と `WHERE` の役割の違いを整理しておきましょう。

| 書くもの | 選ぶもの |
| --- | --- |
| SELECT 列名 | どの **列** を出すか |
| WHERE 条件 | どの **行** を残すか |

この **絞り込み** と列の指定を組み合わせるのが、SQLの基本形です。

## 2-1-2 比較演算子で範囲の条件を書く

> **= だけでなく > や <= を使って「以上・以下」の条件を書ける**

実務の質問は「300円ちょうど」より「300円以上」「在庫5個以下」のような範囲の形がほとんどです。値どうしを比べる記号を **比較演算子** と呼びます。

| 演算子 | 意味 |
| --- | --- |
| `=` | 等しい |
| `!=` | 等しくない |
| `>` | より大きい |
| `>=` | 以上 |
| `<` | より小さい |
| `<=` | 以下 |

```sql
SELECT name, stock FROM products WHERE stock <= 5;
```

| name | stock |
| --- | --- |
| サンドイッチ | 0 |
| ケーキ | 5 |
| 紅茶 | 0 |

`<=` は「以下」なので、ちょうど5のケーキも残ります。`>` と `>=` の違い(境目の値を含むかどうか)は、いちばんのつまずきどころです。

文字列の条件は `name = 'コーヒー'` のように、値をシングルクォートで囲みます。数値は囲みません。

## 2-1-3 ANDで条件を重ねる

> **AND でつなぐと、両方の条件を満たす行だけに絞れる**

「300円以上、かつ在庫あり」のように、実務の絞り込みはほとんど複数条件です。`条件1 AND 条件2` の形で WHERE の中に書きます。

```sql
SELECT name, price FROM products
WHERE price >= 300 AND stock >= 1;
```

| name | price |
| --- | --- |
| コーヒー | 300 |
| ケーキ | 500 |

データベースは行ごとに両方の条件を調べます。片方だけ合格しても残りません。

| 行 | price >= 300 | stock >= 1 | 結果 |
| --- | --- | --- | --- |
| コーヒー | ○ | ○ | 残る |
| サンドイッチ | ○ | × | 消える |
| クッキー | × | ○ | 消える |

## 2-1-4 ORでどちらかを満たす行を選ぶ

> **OR でつなぐと、どちらかの条件を満たす行を選べる**

「コーヒーまたは紅茶」のように、候補のどれかに当てはまれば良い場面では `OR` を使います。

```sql
SELECT name, price FROM products
WHERE name = 'コーヒー' OR name = '紅茶';
```

| name | price |
| --- | --- |
| コーヒー | 300 |
| 紅茶 | 350 |

これを `AND` で書くと「1行が両方の名前を同時に持つ」ことになり、1行も返りません。使い分けはこう整理できます。

| つなぎ方 | 残る行 |
| --- | --- |
| `AND` | **両方** の条件を満たす行だけ |
| `OR` | **どちらか** の条件を満たす行 |

迷ったら日本語に読み替えてください。「かつ」なら AND、「または」なら OR です。

## 2-1-5 NULLはIS NULLで調べる

> **値が入っていないことを表す NULL は、= ではなく IS NULL で調べる**

テーブルには「値がまだ入っていない」欄があります。たとえばセール対象の商品だけ `discount_price`(割引価格)が入り、対象外の商品は空のままです。この「値が入っていない」ことを表す特別な印が **NULL** です。0 とも空文字とも違います。

NULL は値ではないため、比較演算子では調べられません。

```sql
SELECT name FROM products WHERE discount_price = NULL;
-- 1行も返らない(エラーにもならない)
```

エラーが出ないので気づきにくい、要注意の失敗例です。NULL を調べるときは `IS NULL` を使います。

```sql
SELECT name FROM products WHERE discount_price IS NULL;
```

| name |
| --- |
| サンドイッチ |
| クッキー |

逆に「値が入っている行」は `IS NOT NULL` で取り出せます。「NULL には IS を使う」を合言葉にしてください。

## もっと知りたい人へ

- 条件が3つ以上になったら、丸カッコで意図を明示する書き方があります。AND と OR が混ざる文を書くようになったら調べてみてください
- NULL が「なぜ = で比べられないのか」の理屈は、NULLを「不明」と読むと納得しやすくなります。不明なもの同士が等しいかどうかも不明、という考え方です

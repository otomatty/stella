# WHEREで行を絞り込む

SQL入門研修 — Module 2 / レッスン2-1

<!-- ノート: Module 2の始まりです。列を選べるようになったので、今度は行を選びます。実務でいちばん使う書き方です。 -->

---

## なぜ必要か

- 実際のテーブルには何百・何千という行がある
- 「300円以上の商品だけ」のように、見たい行は一部だけ

<!-- ノート: つかみ。商品が増えた店を想像してもらう。全行を目で探すのではなく、データベースに選ばせたい、という動機を作る。 -->

---

## 結論

**WHERE を付けると、条件に合う行だけに絞り込める**

- `WHERE` は `FROM テーブル名` の後ろに書く
- 「行を残す基準」を **条件** と呼ぶ

<!-- ノート: 結論を言い切る。データベースが1行ずつ条件を調べ、合う行だけを返してくれる、と補足する。 -->

---

## 最小のコード

```sql
SELECT name, price FROM products WHERE price >= 300;
```

| name | price |
| --- | --- |
| コーヒー | 300 |
| サンドイッチ | 450 |
| ケーキ | 500 |

<!-- ノート: price >= 300 が条件。>= は「以上」と読む。300ちょうどのコーヒーも残ることを指差し確認する。記号の種類は次の動画で詳しくやる、と口頭で添える。 -->

---

## SELECTは列、WHEREは行

| 書くもの | 選ぶもの |
| --- | --- |
| SELECT 列名 | どの **列** を出すか |
| WHERE 条件 | どの **行** を残すか |

- この **絞り込み** で、必要な行だけの結果になる

<!-- ノート: 対比枠。SELECTは縦方向、WHEREは横方向の選択、と役割を整理する。この2つの組み合わせがSQLの基本形になる。 -->

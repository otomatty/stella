# 3-1-4
# dialogはページに1つ載せる

ページ構成入門 — Module 3 / レッスン3-1

<!-- ノート: 重ねて出す部品の2つ目、ダイアログです。これで載せる部品は最後です。 -->

---

## なぜ必要か

- 申し込みの前に、キャンセルの決まりを確認してもらいたい
- ページ遷移させると、入力の途中が消えてしまう
- 作ってあるダイアログの出番。置き場所だけ決めたい

<!-- ノート: つかみ。フォームのそばで「読んでから戻る」動きに合うのはモーダルです。 -->

---

## 結論

**作ってあるダイアログは、開くボタンと同じ区画に置いてモーダルで開く**

- **モーダル** は背面を止めて前面に集中させる開き方
- ボタンと`dialog`本体を同じ区画に置くと、関係が読んで分かる

<!-- ノート: 結論。ポップオーバーは背面が生きたまま、モーダルは背面を止める。使い分けの再確認です。 -->

---

## 最小のコード

```html
<section>
  <h2>参加申し込み</h2>
  <button command="show-modal" commandfor="policy">
    キャンセルの決まりを見る
  </button>
  <dialog id="policy" aria-labelledby="policy-title">
    <h3 id="policy-title">キャンセルの決まり</h3>
    <p>開催2日前まではキャンセルできます。</p>
    <button command="close" commandfor="policy">閉じる</button>
  </dialog>
</section>
```

<!-- ノート: 部品講座のdialogそのまま。aria-labelledbyの名前の配線も落とさず持ってきます。閉じているdialogは表示されないので、区画の途中に書いても見た目は崩れません。 -->

---

## ポップオーバーとの使い分け

- ちら見のヒント → ポップオーバー(背面はそのまま)
- 読んでから進んでほしい決まり → モーダルのダイアログ
- どちらも、1枚のページに1つずつに留める

<!-- ノート: 迷ったら「背面を触られて困るか」で選びます。困るならモーダルです。 -->

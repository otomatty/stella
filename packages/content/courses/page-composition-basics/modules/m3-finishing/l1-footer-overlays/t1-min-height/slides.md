# bodyを画面の高さまで伸ばす

ページ構成入門研修 — Module 3 / レッスン3-1

<!-- ノート: 下端の仕上げに入ります。まず、フッタが浮く問題の前半を片づけます。 -->

---

## なぜ必要か

- 本文が短いページで、フッタが画面の途中に浮く
- フッタの下に、何もない空白が広がって見える
- 中身が少なくても、ページとしての体裁は保ちたい

<!-- ノート: つかみ。エラーページや検索結果0件のページで必ず起きる、定番の崩れです。 -->

---

## 結論

**本文が短いページでは、まず`body`を`min-height: 100svh`で画面の高さまで伸ばす**

- `body`の高さは、既定では **中身のぶんだけ**
- 画面の高さまで伸ばさない限り、配れる「余り」が存在しない

<!-- ノート: 結論。フッタを動かす前に、動かす余地を作る、という順番です。 -->

---

## 最小のコード

```css
body {
  min-height: 100svh;
}
```

<!-- ノート: minが付くのは、本文が長いページでは中身なりに伸びてほしいからです。heightで固定してはいけません。 -->

---

## 100svhという単位

- `svh` は画面の高さの1% (小さい方の画面基準)
- スマートフォンのアドレスバーが出ている状態でも収まる
- `min` 付きなので、長いページは今までどおり伸びる

<!-- ノート: vhだとアドレスバーのぶんはみ出すことがあります。svhは「確実に収まる方」の高さです。アドレスバーが引っ込んだ間は下に少し空きが残りますが、高さが動き続けるdvhより安定を取っています。 -->

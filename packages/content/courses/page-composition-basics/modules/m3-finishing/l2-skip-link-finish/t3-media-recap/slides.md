# 3-2-3
# 狭い幅は@media 1本で整える

ページ構成入門研修 — Module 3 / レッスン3-2

<!-- ノート: 入門講座で覚えたメディアクエリー1本を、このページに当てる回です。 -->

---

## なぜ必要か

- 画面を縮めると、カードは1列に畳まれて無事
- でもナビは横並びのまま、狭い幅で窮屈になる
- 直しが要る場所と、要らない場所を見分けたい

<!-- ノート: つかみ。auto-fillのおかげで、直す場所は実は少ししか残っていません。 -->

---

## 結論

**狭い画面向けの直しは、幅1本の`@media`にまとめて書くだけに留める**

- `@media`は **メディアクエリー** を書く構文。境の幅は1つだけ決める
- 幅で崩れる場所だけを直す。崩れない場所に書かない

<!-- ノート: 結論。本格的なレスポンシブ設計はこの講座の外です。1本で足りる作りにしてきました。 -->

---

## 最小のコード

```css
@media (max-width: 600px) {
  .site-nav ul {
    flex-direction: column;
    align-items: flex-start;

    .login {
      margin-inline-start: 0;
    }
  }
}
```

<!-- ノート: 600pxより狭いときだけナビを縦積みに。autoマージンの右寄せも狭い幅では解除します。 -->

---

## 直さなくてよい場所

- カードの列数 … `auto-fill`が畳んでくれる
- wrapperの左右 … `padding-inline`が逃げになっている
- フォームの幅 … `max-inline-size`は上限なので狭い幅では効かない

<!-- ノート: ここまでの作り方が正しければ、@mediaに入るのはナビの向きくらいです。それが答え合わせでもあります。 -->

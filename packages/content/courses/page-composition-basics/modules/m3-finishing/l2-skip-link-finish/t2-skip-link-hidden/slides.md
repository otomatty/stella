# 3-2-2
# skip linkは普段は隠す

ページ構成入門 — Module 3 / レッスン3-2

<!-- ノート: skip linkの見た目の話です。隠し方を間違えると、部品ごと消えます。 -->

---

## なぜ必要か

- 「本文へ飛ぶ」がヘッダに常に見えているのは邪魔
- でも `display: none` で消すと、Tabでも止まらなくなる
- 見えないが、フォーカスは受け取れる状態にしたい

<!-- ノート: つかみ。displayで消す=存在ごと消す、を思い出させます。 -->

---

## 結論

**skip linkは画面の外に置いておき、フォーカスされたときだけ見える位置に戻す**

- 消すのではなく **画面の外へ動かす**。Tabの順番には残る
- 戻すきっかけは `:focus-visible`

<!-- ノート: 結論。キーボードで進んだ瞬間だけ現れるリンクになります。 -->

---

## 最小のコード

```css
.skip-link {
  position: absolute;
  inset-block-start: -100%;

  &:focus-visible {
    inset-block-start: 0;
  }
}
```

<!-- ノート: 普段は画面の上の外。フォーカスが当たったら0に戻して画面内へ。背景色などはトークンで整えます。 -->

---

## display: noneとの対比

- `display: none` … 存在ごと消える。Tabで止まれない
- 画面の外 … 見えないだけ。Tabの1回目で戻ってくる
- 「見えない」と「無い」は別もの

<!-- ノート: 対比の枠。dialogが既定で閉じているのとは違い、こちらは自前で隠すぶん、隠し方の選択が問われます。 -->

# スプリットナビはheaderに載せる

ページ構成入門 — Module 1 / レッスン1-2

<!-- ノート: ここから部品の配置です。1つ目は、部品講座で作ったスプリットナビをヘッダに載せます。 -->

---

## なぜ必要か

- ナビの部品は作ってあるが、いままでは単体で表示していた
- ページに載せるとき、書き直しが要るのか不安になる
- 置き場所は骨格で決まっている。`nav` の行き先は `header`

<!-- ノート: つかみ。部品を作る講座と組む講座の境目です。答えは「書き直さない」。 -->

---

## 結論

**作ってあるスプリットナビは、中身を変えずに`header`の中へそのまま載せる**

- 部品は class で当ててあるので、置き場所が変わっても CSS はそのまま効く
- 「載せるときに作り直し」が要るなら、それは部品の作り方の問題

<!-- ノート: 結論。classで当てる作り方をしてきたのは、この日のためです。 -->

---

## 最小のコード

```html
<header>
  <nav class="site-nav">
    <ul>
      <li><a href="/">ホーム</a></li>
      <li class="login"><a href="/login">ログイン</a></li>
    </ul>
  </nav>
</header>
```

<!-- ノート: 部品講座のスプリットナビそのままです。ログインのリンクが右端へ寄る動きも、CSSごと持ってくるだけで効きます。 -->

---

## そのまま効く理由

- `.site-nav` の指定は「どの class か」しか見ていない
- 親が `body` でも `header` でも、当たり方は変わらない
- 持ってくるのは HTML と、その部品の CSS のひとまとまり

<!-- ノート: 部品のCSSを入れ子のひとまとまりで書いてきたので、コピーの単位も明確です。 -->

# パンくずはmainの先頭に置く

ページ構成入門 — Module 1 / レッスン1-2

## なぜ必要か

- パンくずリストの部品はある。どこに置く?
- ヘッダの中? 本文の中? サイトによって見え方はいろいろ
- 「このページがどこか」を示す情報だから、置き場所には意味がある

<!-- ノート: つかみ。置き場所の選択肢を見せて、基準を考えさせます。 -->

---

## 結論

**パンくずリストは、`main`の先頭に置いて現在地までの道筋を示す**

- パンくずは「この本文がサイトのどこにあるか」という **現在地** の情報
- 本文の一部だから `main` の中。読み始めに要るから先頭

<!-- ノート: 結論。サイト共通のナビはheader、このページの現在地はmainの先頭、と覚えます。 -->

---

## 最小のコード

```html
<main>
  <div class="wrapper">
    <nav class="breadcrumb">
      <ol>
        <li><a href="/">ホーム</a></li>
        <li aria-current="page">勉強会一覧</li>
      </ol>
    </nav>
    <h1>勉強会一覧</h1>
  </div>
</main>
```

<!-- ノート: 部品講座のパンくずそのままです。h1より前、mainの先頭に入れます。 -->

---

## headerに入れない理由

- `header` はサイト共通の帯。どのページでも同じ中身にしたい
- パンくずはページごとに変わる、本文側の情報
- 「本文へ移動したらすぐ現在地が分かる」形になる

<!-- ノート: landmark単位で移動する人は、mainに飛んだ直後にパンくずへ出会えます。これが先頭に置く実利です。 -->

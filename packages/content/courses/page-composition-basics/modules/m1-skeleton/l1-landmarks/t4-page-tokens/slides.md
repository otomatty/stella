# 1-1-4
# ページのトークンは1セット

ページ構成入門 — Module 1 / レッスン1-1

<!-- ノート: 骨格の最後に、CSS側の土台を1つに固めます。部品講座で使ってきたトークンの再確認です。 -->

---

## なぜ必要か

- 部品は1つずつ別々に練習してきた
- 練習ごとの`:root`をそのまま持ち寄ると、同じ名前の定義がぶつかる
- 1枚のページには、値の出どころも1つにしたい

<!-- ノート: つかみ。組み立ての最初の事故は、コピペで:rootが2つできることです。 -->

---

## 結論

**ページ全体の色と余白は、`:root`に置いた1セットのトークンを`var()`で参照して当てる**

- 役割に名前を付けた値が **トークン**。`:root`に置くとページ全体で使える
- 部品側は`var()`で参照するだけ。生の値は書かない

<!-- ノート: 結論。トークンの作り方は既習なので、ここでは「1枚に1セット」という置き方だけを決めます。 -->

---

## 最小のコード

```css
:root {
  --surface: oklch(99% 0 0);
  --ink: oklch(25% 0 0);
  --line: oklch(88% 0 0);
  --accent: oklch(55% 0.16 264);
  --space-3: 16px;
}
```

<!-- ノート: このページで使う色と余白の正本です。style.cssの先頭に1回だけ書き、以降のレッスンでもこのセットを参照し続けます。 -->

---

## 2セットあると何が起きるか

- 後から読まれた`:root`が同じ名前を上書きする
- 「ボタンだけ色が違う」のに、部品のCSSを見ても原因が無い
- 定義は先頭の1か所へ集め、部品のCSSには参照だけ残す

<!-- ノート: 失敗例。原因が定義側にあると、探す場所を間違えます。1セットに保つのはこのためです。 -->

# 2-2-2
# フォームの幅は読みやすく絞る

ページ構成入門研修 — Module 2 / レッスン2-2

<!-- ノート: 3つ目の区画は参加申し込みです。部品講座のフォーム部品一式を載せます。 -->

---

## なぜ必要か

- ラベルと入力欄の組(form group)は作ってある
- wrapperの幅960pxいっぱいに入力欄が伸びると、間のびして使いにくい
- 区画には載せたい。幅だけ何とかしたい

<!-- ノート: つかみ。全幅の入力欄は視線の移動が長く、どこまで書くのか不安にさせます。 -->

---

## 結論

**申し込みフォームは区画にそのまま載せ、幅は`max-inline-size`で読みやすく絞る**

- 絞るのは **フォーム全体**。部品のCSSは触らない
- 本文の幅(wrapper)と、読み書きする幅(フォーム)は別もの

<!-- ノート: 結論。1行の長さをchで抑えた話の、入力欄版です。 -->

---

## 最小のコード

```css
.signup {
  max-inline-size: 40rem;
}
```

```html
<section>
  <h2>参加申し込み</h2>
  <form class="signup">
    <div class="field">…</div>
    <button type="submit">申し込む</button>
  </form>
</section>
```

<!-- ノート: form自体に上限幅を1つ。中のfieldは幅100%で作ってあるので、全員がこの幅に収まります。 -->

---

## 中央に寄せない理由

- フォームだけ`margin-inline: auto`で中央に置くと、
  見出しや本文の左端とラインがずれる
- 区画の中身は左端をそろえたまま、幅だけ絞る

<!-- ノート: 対比。wrapperの中央寄せはページの単位、フォームの絞りは区画の中の単位。混ぜないのがコツです。 -->

# 2-2-1
# 更新情報はメディアオブジェクトで積む

ページ構成入門研修 — Module 2 / レッスン2-2

<!-- ノート: 2つ目の区画は更新情報です。ここでもメディアオブジェクトの部品をそのまま使います。 -->

---

## なぜ必要か

- 「誰がいつ何を更新したか」の一覧を載せたい
- 1件ぶんの形(画像+本文)はメディアオブジェクトそのもの
- 決めるのは、何件も並べるときの積み方だけ

<!-- ノート: つかみ。カードのときと同じで、部品はあるので入れ物を考えます。 -->

---

## 結論

**更新情報の一覧は、メディアオブジェクトを縦に積んで区切り線で区切る**

- 時系列の **一覧** は、格子ではなく縦積みが読み順に合う
- 件と件の境目は、余白だけでなく区切り線で示す

<!-- ノート: 結論。カードは敷き詰め、時系列は縦積み。集合の形は中身の性質で選びます。 -->

---

## 最小のコード

```css
.update-list {
  list-style: none;
  padding-inline-start: 0;
  margin-block: 0;

  > li + li {
    border-block-start: 1px solid var(--line);
  }
}
```

<!-- ノート: ulをそのまま縦に使い、2件目以降の上に線を引きます。+は直後の要素だけに当たるセレクタでした。 -->

---

## HTMLでの入れ子

```html
<section>
  <h2>更新情報</h2>
  <ul class="update-list">
    <li><div class="media">…</div></li>
    <li><div class="media">…</div></li>
  </ul>
</section>
```

<!-- ノート: liの中にメディアオブジェクトを1件ずつ。線が先頭に付かないのは、+が最初のliに当たらないからです。 -->

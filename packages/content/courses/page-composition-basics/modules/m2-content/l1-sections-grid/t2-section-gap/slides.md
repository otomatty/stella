# 2-1-2
# 区画の間隔は親のgapで空ける

ページ構成入門 — Module 2 / レッスン2-1

<!-- ノート: 区画ができたので、区画と区画の間を空けます。部品の中で使った考え方の、ページ版です。 -->

---

## なぜ必要か

- 区画がくっついていると、話題の切れ目が見た目に出ない
- 区画ごとに`margin`を書くと、値がばらばらになりがち
- ページ全体の縦のリズムは、1か所で決めたい

<!-- ノート: つかみ。部品の中身の間隔を親のgapに集めたのと同じ悩みが、ページの単位でも起きます。 -->

---

## 結論

**区画どうしの間隔は、区画を積む親を縦の`flex`にして`gap`でまとめて空ける**

- 間隔の持ち主は区画ではなく、区画を積んでいる **親**
- `gap`は間にだけ効くので、先頭と末尾に余計な余白が出ない

<!-- ノート: 結論。カードの中で覚えた「間隔は親のgapに集める」を、そのままページに持ち上げます。 -->

---

## 最小のコード

```css
main .wrapper {
  display: flex;
  flex-direction: column;
  gap: var(--space-5);
}
```

<!-- ノート: 区画を積んでいるのはmainの中のwrapperなので、そこに書きます。値は大きめの余白トークンです。 -->

---

## 区画ごとのmarginとの対比

- `section { margin-block-end: 48px }` … 最後の区画の下にも余白が付く
- 書き忘れ・書きすぎが区画の数だけ起きる
- 親の`gap`なら、区画を足しても消しても間隔は一定

<!-- ノート: 対比。部品のときと同じ結論になるのがポイントです。間隔は積んでいる側の仕事。 -->

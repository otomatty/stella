# subgridで行の高さをそろえる

ページ構成入門 — Module 2 / レッスン2-1

<!-- ノート: カードの集合の仕上げです。使わなくても崩れない、そろえたいときの上積みです。 -->

---

## なぜ必要か

- 見出しが2行のカードと1行のカードが隣に並ぶ
- 本文の始まる高さがずれて、横のラインがそろわない
- カードごとに高さを直すのは、枚数が増えると破綻する

<!-- ノート: つかみ。敷き詰めた直後に必ず気づく「ガタつき」です。 -->

---

## 結論

**隣のカードと行の高さをそろえたいときは、`subgrid`で親の`grid`の行を借りる**

- カードが自分で行の高さを決めるから、隣とずれる
- 親の行に乗れば、高さは **列をまたいで共有** される

<!-- ノート: 結論。高さの持ち主をカードから親に移す、という考え方です。 -->

---

## 最小のコード

```css
.card-grid > .card {
  grid-row: span 3;
  display: grid;
  grid-template-rows: subgrid;
}
```

<!-- ノート: カードが親の3行ぶんを使い、中の見出し・本文・リンクをその行に乗せます。行の高さは同じ行のカード全員で共有されます。 -->

---

## 使いどころの判断

- 中身の行数がそろっているなら、無くても困らない
- 「隣とそろっていないと気になる一覧」にだけ足す
- カードの中身のHTMLは変えずに済む

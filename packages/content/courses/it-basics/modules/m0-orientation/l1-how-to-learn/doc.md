# レッスン0-1 学び方のきほん

## このレッスンの目標

- [ ] スキルツリーの星・前提・クリアの関係を説明できる
- [ ] レッスンをスライド → まとめ → 確認クイズの順で進められる
- [ ] 詰まったとき、試したことを添えて 15 分で質問に切り替えられる

## 0-1-1 スキルツリーで進む

> **この研修は、スキルツリーの星(講座)を前提の順に1つずつクリアして進みます**

まず、この研修で使う言葉をそろえます。

- **講座** — ひとまとまりの教材です。画面では 1 つの星として表示されます
- **スキルツリー** — 講座どうしのつながりを描いた地図です
- **前提** — その講座の前に終えておく講座です
- **クリア** — 講座を最後まで終えることです

スキルツリーの画面を開くと、中心にこの「ITのきほん」の星があり、そこから線が外へ伸びています。線は前提の関係を表していて、**線の元の星をクリアすると、その先の星が開きます**。遠くの星はまだ名前が見えませんが、手前の星を進めるとだんだん見えてきます。

```text
中心の星   … いま読んでいる「ITのきほん」(いちばん最初の講座)
つながる線 … 前提の関係。線の元をクリアすると、先の星が開く
遠くの星   … まだ名前が見えない。近づくと(前提を進めると)見えてくる
```

順序が決まっているのは、やる気を試すためではありません。**分からない語が突然出てこないようにするため**です。各講座は「前提の講座で習った語だけを使って書く」約束で作られています。だから前提の順に進む限り、読めない教材には出会いません。

| | 手当たり次第に選ぶ | 前提の順に進む |
| --- | --- | --- |
| 最初の難しさ | 講座によっては高すぎる | いつも「ちょうど次」の難しさ |
| 分からない語 | 前の講座の語が突然出る | 出てくる語は習った語だけ |
| 迷い | 毎回どれにするか迷う | 開いた星から選ぶだけ |

## 0-1-2 1レッスンの型

> **レッスンは、スライドを見る → まとめを読む → 確認クイズ、の順で進めます**

星(講座)の中身は **レッスン** の集まりです。1 レッスンはどの講座でも同じ 3 点セットでできています。

- **スライド** — 短い動画教材です。1 本で覚えることは 1 つだけです
- **まとめ** — スライドの内容を読み物にした文章です(いま読んでいるこのページです)
- **確認クイズ** — 覚えたかを確かめる数問のテストです。80 点で合格です

3 つの順番には意味があります。同じ内容を、形を変えて 3 回通しています。

```text
1回目 スライド   … 耳と目で「聞いたことがある」状態にする
2回目 まとめ     … 文章で読み直して、抜けを埋める
3回目 確認クイズ … 思い出す練習。ここで初めて記憶に残る
```

確認クイズは試験ではなく、**思い出す練習**です。人は思い出そうとしたときにいちばん覚えるので、クイズを飛ばすとそのレッスンはほとんど残りません。時間を惜しんでスライドだけ流すのが、いちばん損な進め方です。

| | スライドだけ見る | 型どおり3点通す |
| --- | --- | --- |
| かかる時間 | 短い | 少し長い |
| 翌日残る量 | ほとんど残らない | クイズで出た分は残る |
| 講座のクリア | 進まない | クイズ合格で前に進む |

## 0-1-3 詰まったら15分で聞く

> **15分調べて分からなければ、試したことを添えて質問します**

型どおり進めても、必ずどこかで詰まります。そのときの動き方を先に決めておきます。

- **質問** — 分からないことを、状況と一緒に人に伝えることです

境界線は 15 分です。15 分は「自分で調べる価値がある時間」と「ひとりで抱えると損になる時間」の境目です。何時間もひとりで悩むのは、能力の証明ではなく時間の損失です。逆に、何も調べずすぐ聞くと、調べる力が育たず、同じことを何度も聞くことになります。

質問するときは、次の 3 点を添えます。

```text
やりたいこと … レッスン1-1の確認クイズを開きたい
試したこと   … まとめのページから戻ったが、クイズのボタンが見当たらない
分からないこと … クイズはどこから開くのか
```

試したことが書いてあると、答える側は状況をそのまま再現できるので、短い時間で正確に答えられます。「わかりません」だけの質問より、答える側の負担はむしろ小さくなります。

| | ひとりで抱え込む | 15分で聞く |
| --- | --- | --- |
| 止まる時間 | 数時間〜数日 | 最長15分 + 返事待ち |
| 答える側の負担 | (聞かないので)ゼロに見える | 試したことがあるので小さい |
| 自分に残るもの | 疲れだけ | 調べた過程 + 正しい答え |

## もっと知りたい人へ

- スキルツリーの画面を実際に開いて、この「ITのきほん」から線がどこへ伸びているかを眺めてみてください。クリア後に何が開くのかが、学習の見通しになります
- 質問の 3 点セット(やりたいこと・試したこと・分からないこと)は、この研修だけでなく実務のチャットやチケットでもそのまま使えます

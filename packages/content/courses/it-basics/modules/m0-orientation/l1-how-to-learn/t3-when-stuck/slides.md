# 詰まったら15分で聞く

ITのきほん — Module 0 / レッスン0-1

<!-- ノート: 学び方の最後は「詰まったときの動き方」。ここが決まっていないと、詰まった瞬間に学習が止まります。 -->

---

## なぜ必要か

- 分からないまま何時間もひとりで悩んでしまう
- 逆に、何も調べずすぐ聞いて、同じことを何度も聞いてしまう

<!-- ノート: つかみ。悩みすぎも聞きすぎも、どちらも進みを止めます。境界線を1本引くのがこのトピックです。 -->

---

## 結論

**15分調べて分からなければ、試したことを添えて質問します**

- **質問** — 分からないことを、状況と一緒に人に伝えること

15 分は「自分で調べる価値がある時間」と「ひとりで抱えると損になる時間」の境界線です

<!-- ノート: 結論を先に言い切る。15分は目安ですが、境界線を持つこと自体に意味があります。 -->

---

## 良い質問の形

```text
やりたいこと … レッスン1-1の確認クイズを開きたい
試したこと   … まとめのページから戻ったが、クイズのボタンが見当たらない
分からないこと … クイズはどこから開くのか
```

<!-- ノート: この3点があると、答える側は状況を再現できます。「わかりません」だけの質問との差を見せます。 -->

---

## 抱え込む vs 15分で聞く

| | ひとりで抱え込む | 15分で聞く |
| --- | --- | --- |
| 止まる時間 | 数時間〜数日 | 最長15分 + 返事待ち |
| 答える側の負担 | (聞かないので)ゼロに見える | 試したことがあるので小さい |
| 自分に残るもの | 疲れだけ | 調べた過程 + 正しい答え |

<!-- ノート: 対比枠。質問は迷惑ではなく、試したことを添えれば答える側も短時間で済むと伝えます。 -->

# 1レッスンの型

ITのきほん — Module 0 / レッスン0-1

<!-- ノート: 星の中身の話。どの講座も同じ型なので、ここで一度だけ覚えれば全部に使えます。 -->

---

## なぜ必要か

- 動画を全部見たのに、翌日にはほとんど思い出せない
- どこまでやれば「終わった」と言えるのか分からない

<!-- ノート: つかみ。見ただけの学習は消えます。型がないと終わりも決められません。 -->

---

## 結論

**レッスンは、スライドを見る → まとめを読む → 確認クイズ、の順で進めます**

- **レッスン** — 講座の中の 1 回分。この 3 点セットでできています
- **スライド** — 短い動画教材。覚えることは 1 本につき 1 つだけ
- **まとめ** — スライドの内容を読み物にした文章
- **確認クイズ** — 覚えたかを確かめる数問のテスト(80 点で合格)

<!-- ノート: 結論を先に言い切る。3つの順番に意味があることを次で話します。 -->

---

## 同じ内容を3回通す

```text
1回目 スライド   … 耳と目で「聞いたことがある」状態にする
2回目 まとめ     … 文章で読み直して、抜けを埋める
3回目 確認クイズ … 思い出す練習。ここで初めて記憶に残る
```

<!-- ノート: 同じ内容を形を変えて3回通すのが狙いだと伝えます。クイズは試験ではなく思い出す練習です。 -->

---

## よくある間違い

| | スライドだけ見る | 型どおり3点通す |
| --- | --- | --- |
| かかる時間 | 短い | 少し長い |
| 翌日残る量 | ほとんど残らない | クイズで出た分は残る |
| 講座のクリア | 進まない | クイズ合格で前に進む |

<!-- ノート: 対比枠。時間を惜しんでスライドだけ流すのがいちばん損だ、という話です。 -->

# 頼むブラウザ、返すサーバー

ITのきほん — Module 2 / レッスン2-1

<!-- ノート: Webの動く仕組み。頼む側と返す側、という1つの型だけを入れます。 -->

---

## なぜ必要か

- ページが表示されるまでに何が起きているのか、想像がつかない
- 「サーバーが落ちてる」と聞いても、何が落ちたのか分からない

<!-- ノート: つかみ。「サーバーが落ちる」は入社初日から聞く言葉です。ここで正体を知っておきます。 -->

---

## 結論

**Webは、ブラウザ(クライアント)が頼み、サーバーが返す、の繰り返しで動いています**

- **ブラウザ** — Webページを見るためのアプリ。Chrome や Safari が代表です
- **サーバー** — 頼まれたものを返す側のコンピュータ。24 時間動き続けています
- **クライアント** — 頼む側のこと。Web ではブラウザがクライアントです

<!-- ノート: 結論を先に言い切る。登場人物は2人だけ。頼む側と返す側です。 -->

---

## 1回の表示で起きること

```text
1. ブラウザ  「このページをください」 → インターネット越しにサーバーへ
2. サーバー  保管しているページのデータを探して返す
3. ブラウザ  受け取ったデータを、人が読める形で画面に描く
```

<!-- ノート: リンクを1回押すたびに、この3手が毎回起きています。この学習サイトも同じです。 -->

---

## 「サーバーが落ちてる」の正体

| 症状 | どちら側の問題か |
| --- | --- |
| どのページも開けない | 自分の側(網につながっていない)かもしれない |
| このサイトだけ開けない | 返す側(サーバー)が止まっているかもしれない |
| 自分のPCを再起動しても直らない | 返す側の問題なら、待つ以外にできることはない |

<!-- ノート: 頼む側と返す側のどちらの問題か、で切り分ける型を見せます。これも実務の頻出会話です。 -->

# レッスン2-1 Web のきほん

## このレッスンの目標

- [ ] インターネットと Web を区別して使い分けられる
- [ ] ページが表示される流れを、ブラウザとサーバーのやり取りとして説明できる
- [ ] URL を 3 つの部分に区切って読め、パスワードの基本の守りを実践できる

## 2-1-1 網の上のWeb

> **インターネットは機器どうしをつなぐ世界中の網で、Webはその上で動くサービスの1つです**

まず、日常では同じ意味で使われがちな 2 つのことばを分けます。

- **インターネット** — 世界中のコンピュータをつなぐ、通信の網そのものです
- **Web** — その網の上で、ページを公開して見られるようにする仕組みです
- **Webページ** — Web で公開されている 1 枚 1 枚のページです

関係は、道路と宅配便に似ています。インターネットが道路の網で、Web はその道路を使うサービスの 1 つです。同じ道路の上を、メールやビデオ会議のような別のサービスも走っています。

```text
インターネット(道路の網)
├── Web         … ページを見る(この学習サイトもここ)
├── メール      … 手紙を送る
└── ビデオ会議  … 顔を見て話す
```

区別できると、トラブルの言い方が変わります。「ネットが使えない」ではなく、「網ごと切れているのか、Web のこのサイトだけ見られないのか」を分けて言えると、対処もそれぞれ変わります。

| あいまいな言い方 | 区別した言い方 |
| --- | --- |
| ネットが使えない | 網ごと切れているのか、Web だけ見られないのか |
| ネットで調べた | Web のページを調べた |
| ネットの仕事 | Web のページやサービスを作る仕事 |

## 2-1-2 頼むブラウザ、返すサーバー

> **Webは、ブラウザ(クライアント)が頼み、サーバーが返す、の繰り返しで動いています**

Webページが手元に届くまでの登場人物は 2 人だけです。

- **ブラウザ** — Webページを見るためのアプリです。Chrome や Safari が代表です
- **サーバー** — 頼まれたものを返す側のコンピュータです。24 時間動き続けています
- **クライアント** — 頼む側のことです。Web ではブラウザがクライアントです

リンクを 1 回押すたびに、次の 3 手が起きています。

```text
1. ブラウザ  「このページをください」 → インターネット越しにサーバーへ
2. サーバー  保管しているページのデータを探して返す
3. ブラウザ  受け取ったデータを、人が読める形で画面に描く
```

この型が入っていると、「サーバーが落ちてる」という会話の正体が分かります。返す側のコンピュータが止まっているという意味です。

| 症状 | どちら側の問題か |
| --- | --- |
| どのページも開けない | 自分の側(網につながっていない)かもしれない |
| このサイトだけ開けない | 返す側(サーバー)が止まっているかもしれない |
| 自分のPCを再起動しても直らない | 返す側の問題なら、待つ以外にできることはない |

頼む側の問題か、返す側の問題か。この切り分けは実務で毎週のように使います。

## 2-1-3 URLはWebの住所

> **URLはWeb上の住所で、どのサーバーの何が欲しいかを指します**

前のトピックの「このページをください」の「この」を指す仕組みが URL です。

- **URL** — ブラウザのアドレス欄に出ている文字列です。Webページ 1 枚 1 枚に付いた住所です

住所なので、読み方(区切り)が決まっています。3 つに分けて読みます。

```text
https://example.com/training/lesson1

https        … 渡し方の取り決め(sはやり取りが暗号化される印)
example.com  … どのサーバーか(建物の住所にあたる)
/training/lesson1 … その中のどのページか(部屋番号にあたる)
```

いちばん大事なのは真ん中の「どのサーバーか」です。ここが読めると、次のことができるようになります。

| 場面 | 読み方 |
| --- | --- |
| 銀行を名乗るメールのリンク | サーバー名が本物の銀行の名前と違えば偽物 |
| ページの共有 | アドレス欄の URL を丸ごとコピーして渡せば同じページが開く |
| 「s」の無い `http://` | 暗号化されない渡し方。入力は控える |

URL を読む習慣は、それだけで偽サイトへの防御になります。

## 2-1-4 パスワードは長く、使い回さない

> **パスワードは、長くすること・使い回さないことがいちばんの守りです**

最後は、Web を使ううえでの守りの話です。

- **アカウント** — サービスを使うための自分の登録です。サーバー側に作られます
- **パスワード** — そのアカウントが本人のものだと確かめるための合いことばです

パスワードの敵は、人間の勘ではなく**機械の総当たり**です。だから記号を混ぜた複雑さより、長さが効きます。そして、どこか 1 つのサービスのサーバーから漏れることは自分では防げないので、**使い回さない**ことが被害を 1 か所で止める唯一の方法です。

```text
短いパスワード … 機械が総当たりで試すと、すぐ当たってしまう
使い回し       … どこか1つのサーバーから漏れると、他の全部が開く
長くて別々     … 総当たりに強く、漏れても被害がそのサービスで止まる
```

| やること | やらないこと |
| --- | --- |
| 長めのパスワードにする(目安は12文字以上) | 誕生日や名前を入れる |
| サービスごとに別のパスワードにする | 同じものを使い回す |
| 覚えられない分は道具(パスワード管理)に覚えさせる | 付せんで画面に貼る・チャットで送る |

「全部覚える」は無理で構いません。覚える仕事はパスワード管理の道具に任せるのが現代のやり方です。

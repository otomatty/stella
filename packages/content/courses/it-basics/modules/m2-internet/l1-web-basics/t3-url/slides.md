# URLはWebの住所

## なぜ必要か

- アドレス欄の文字列を、読まずに雰囲気でクリックしている
- 「この URL を共有して」と言われて、どこを渡せばいいか迷う

<!-- ノート: つかみ。URLを読める人と読めない人では、偽サイトへの強さも変わります。 -->

---

## 結論

**URLはWeb上の住所で、どのサーバーの何が欲しいかを指します**

- **URL** — ブラウザのアドレス欄に出ている文字列。Webページ 1 枚 1 枚に付いた住所

<!-- ノート: 結論を先に言い切る。住所なので、読み方(区切り)が決まっています。 -->

---

## 読み方は3つの部分

```text
https://example.com/training/lesson1

https        … 渡し方の取り決め(sはやり取りが暗号化される印)
example.com  … どのサーバーか(建物の住所にあたる)
/training/lesson1 … その中のどのページか(部屋番号にあたる)
```

<!-- ノート: 真ん中の「どのサーバーか」がいちばん大事です。ここを読めることが次のスライドの守りにつながります。 -->

---

## 住所が読めると防げること

| 場面 | 読み方 |
| --- | --- |
| 銀行を名乗るメールのリンク | サーバー名が本物の銀行の名前と違えば偽物 |
| ページの共有 | アドレス欄の URL を丸ごとコピーして渡せば同じページが開く |
| 「s」の無い `http://` | 暗号化されない渡し方。入力は控える |

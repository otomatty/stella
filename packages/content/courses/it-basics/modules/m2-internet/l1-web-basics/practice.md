# レッスン2-1 演習 — Web のきほん

対象トピック: 2-1-1 〜 2-1-5

## 手元で試す

ブラウザと紙とペンだけで進めてください。

1. **URL を区切って読む** — いま開いているこの学習サイトのアドレス欄を見て、「渡し方 / サーバー名 / ページ」の 3 つに区切って紙に書き出してください。先頭が `https` (s あり)になっていることも確かめてください
2. **3 手の流れを言う** — この学習サイトのリンクをどれか 1 回押して、「URL を開いてから画面が出るまで」を 3 手で口に出して言ってください (人が開く → ブラウザが頼む → サーバーが返し、ブラウザが描く)
3. **パスワードの棚卸し** — 自分が使っているサービスを 5 つ書き出して、パスワードを使い回しているものに印を付けてください(パスワードそのものは紙に書かないでください)

```text
棚卸しの例(パスワードは書かない)
1. メール          … 専用
2. 動画サイト      … 買い物サイトと同じ ← 印
3. 買い物サイト    … 動画サイトと同じ ← 印
4. この学習サイト  … 専用
5. チャット        … 専用
```

## 演習問題

### 問1(基本)

「インターネット」と「Web」の違いを、道路のたとえを使って 1〜2 文で説明してください。

### 問2(基本)

あるサイトだけが開けず、他のサイトは普通に見られます。頼む側(自分のブラウザや網)と返す側(サーバー)のどちらの問題と考えるのが自然ですか。理由も 1 文で書いてください。

### 問3(応用)

銀行を名乗るメールに `https://example-bank.安全確認.com/login` というリンクがありました。URL の読み方をふまえて、開く前に確かめるべき部分とその理由を 1〜2 文で書いてください。

### 問4(応用)

「パスワードは記号をたくさん混ぜた 6 文字にしている。覚えられる自信があるので全サービス共通にしている」という人に、直すべき点を優先順位を付けて 2 文で助言してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

インターネットは世界中のコンピュータをつなぐ道路の網そのものです。Web はその道路の上を走るサービスの 1 つで、ほかにメールやビデオ会議も同じ道路を使っています。

</details>

<details>
<summary>問2の解答例</summary>

返す側(そのサイトのサーバー)の問題と考えるのが自然です。自分の側の網が切れているなら、他のサイトも開けないはずだからです。

</details>

<details>
<summary>問3の解答例</summary>

確かめるのはサーバー名の部分です。本物の銀行のサーバー名と違っていれば、見た目がそっくりでも別のサーバーへ連れて行かれる偽物のリンクです。

</details>

<details>
<summary>問4の解答例</summary>

まず使い回しをやめてください。どこか 1 つのサーバーから漏れると全部のサービスが開かれてしまいます。次に長さを 12 文字以上に伸ばしてください。機械の総当たりには記号の複雑さより長さが効きます。

</details>

## 確認クイズ

### Q1. インターネットと Web の関係として正しいものはどれですか。

- A. インターネットと Web は同じものの別の呼び方である
- B. インターネットは通信の網そのもので、Web はその上で動くサービスの 1 つである
- C. Web が網そのもので、インターネットはその上のサービスである

<details>
<summary>答え</summary>

**B** — 道路(インターネット)と、その上を走る宅配便(Web)の関係です。メールやビデオ会議も同じ道路を使う別のサービスです。

</details>

### Q2. URL を開いてから画面が出るまでの流れとして正しいものはどれですか。

- A. ブラウザがサーバーにページを頼み、返ってきたデータを画面に描く
- B. サーバーがブラウザにページを頼み、ブラウザがデータを返す
- C. ブラウザとサーバーが同時にページを作り始める

<details>
<summary>答え</summary>

**A** — URL を開くと、ブラウザがサーバーに頼み、返ってきたデータを画面に描きます。Web エンジニアとして最初に答えられるようになってほしい流れです。

</details>

### Q3. 「サーバーが落ちている」の意味として、いちばん近いものはどれですか。

- A. 自分の PC の電源が切れている
- B. 頼まれたものを返す側のコンピュータが止まっている
- C. ブラウザのアプリが古くなっている

<details>
<summary>答え</summary>

**B** — サーバーは返す側のコンピュータです。返す側が止まっているなら、自分の PC を再起動しても直りません。

</details>

### Q4. `https://example.com/training/lesson1` の `example.com` の部分は何を表しますか。

- A. どのサーバーか
- B. ページの中のどの位置か
- C. 通信を暗号化するかどうか

<details>
<summary>答え</summary>

**A** — 真ん中の部分がどのサーバーか(建物の住所)です。偽サイトの見分けでいちばん先に読む部分です。

</details>

### Q5. パスワードの守りとして、いちばん効果が大きい組み合わせはどれですか。

- A. 記号を多く混ぜて、覚えやすいように全サービス共通にする
- B. 長くして、サービスごとに別のものにする
- C. 短くして、毎週変える

<details>
<summary>答え</summary>

**B** — 敵は機械の総当たりなので長さが効きます。使い回しをやめると、どこかで漏れても被害がそのサービスで止まります。

</details>

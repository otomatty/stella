# 網の上のWeb

ITのきほん — Module 2 / レッスン2-1

<!-- ノート: ここからつながりの話。まず「インターネット」と「Web」を同じ意味で使うのをやめるところからです。 -->

---

## なぜ必要か

- 「インターネット」と「Web」を同じ意味で使ってしまう
- メールも動画もゲームも「ぜんぶネット」で、区別がない

<!-- ノート: つかみ。日常会話ではそれで通じますが、開発の会話では区別が要ります。 -->

---

## 結論

**インターネットは機器どうしをつなぐ世界中の網で、Webはその上で動くサービスの1つです**

- **インターネット** — 世界中のコンピュータをつなぐ、通信の網そのもの
- **Web** — その網の上で、ページを公開して見られるようにする仕組み
- **Webページ** — Web で公開されている 1 枚 1 枚のページ

<!-- ノート: 結論を先に言い切る。道路(インターネット)と、道路を使う宅配便(Web)の関係です。 -->

---

## 道路と、その上のサービス

```text
インターネット(道路の網)
├── Web         … ページを見る(この学習サイトもここ)
├── メール      … 手紙を送る
└── ビデオ会議  … 顔を見て話す
```

<!-- ノート: 同じ道路の上を、性質の違うサービスが走っています。Webはそのうちの1つにすぎません。 -->

---

## 区別すると会話が変わる

| あいまいな言い方 | 区別した言い方 |
| --- | --- |
| ネットが使えない | 網ごと切れているのか、Web だけ見られないのか |
| ネットで調べた | Web のページを調べた |
| ネットの仕事 | Web のページやサービスを作る仕事 |

<!-- ノート: 「ネットが使えない」の切り分けは実務の頻出会話です。網の問題かサービスの問題かで対処が変わります。 -->

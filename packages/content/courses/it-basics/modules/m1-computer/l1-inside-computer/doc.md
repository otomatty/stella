# レッスン1-1 コンピュータの中身

## このレッスンの目標

- [ ] ハードウェアとソフトウェアを、身近な例で区別できる
- [ ] OS とアプリの関係を 2 階建ての図で説明できる
- [ ] ファイルの場所を道順で言え、拡張子から種類を読み取れる

## 1-1-1 体と指示に分かれる

> **コンピュータは、ハードウェア(機械の部分)をソフトウェア(指示のまとまり)が動かしています**

まず、この講座でいちばん大事な区別をそろえます。

- **コンピュータ** — 指示のとおりに計算や表示をする機械です。PC もスマホも同じ仲間です
- **ハードウェア** — 手で触れる機械の部分です。画面、キーボード、中の部品がそうです
- **ソフトウェア** — 機械に何をさせるかを書いた、指示のまとまりです。手では触れません

コンピュータは、体(ハードウェア)だけでは何もしません。指示(ソフトウェア)だけでも動く場所がありません。**体を指示が動かして、初めて仕事になります**。迷ったら「手で触れるか」で分けてください。触れれば体、触れなければ指示です。

```text
ハードウェア … 画面 / キーボード / マウス / 中の部品(計算する部品、覚えておく部品)
ソフトウェア … この学習サイト / 文書を書く道具 / スマホに入れる道具ぜんぶ
```

この区別があるだけで、日常のトラブルの切り分けが変わります。

| 場面 | 勘違い | 実際 |
| --- | --- | --- |
| 動きが遅い | 機械が古いせいに決まっている | 指示の側(入れすぎ・不具合)のことも多い |
| 新しい機能が増えた | 機械が変わった | 指示を入れ替えただけ(アップデート) |
| 水をこぼして壊れた | 中身のデータも必ず消えた | 壊れたのは体。指示やデータは残ることもある |

## 1-1-2 OSが土台、アプリはその上

> **OSは機械全体を管理する土台のソフトウェアで、アプリはその上で動きます**

ソフトウェアを、もう 1 段だけ分けます。

- **OS** — ハードウェア全体を管理する、土台のソフトウェアです。Windows や macOS が代表です
- **アプリ** — 特定の仕事のために、OS の上で動かすソフトウェアです

図にすると 2 階建てです。

```text
アプリ         … ブラウザ / 文書作成 / この学習サイトを開く道具
────────────────
OS             … Windows / macOS (機械全体を管理する土台)
────────────────
ハードウェア   … 画面 / キーボード / 中の部品
```

アプリは機械を直接さわりません。必ず OS を通します。だからアプリは OS に合わせて作られていて、「Mac では使えないアプリ」のようなことが起きます。

| 場面 | 説明 |
| --- | --- |
| 「Mac では使えないアプリ」 | アプリが Windows という土台に合わせて作られているから |
| 「OS のアップデート」 | 土台の入れ替え。全アプリに影響しうるので大ごと |
| 「アプリのインストール」 | 土台はそのまま、上に道具を 1 つ足すだけ |

## 1-1-3 ファイルで残し、フォルダで整理

> **作ったものはファイルとして保存され、フォルダで整理します**

アプリで作ったものの行き先の話です。

- **ファイル** — 名前の付いたデータのまとまりです。文書 1 つ、写真 1 枚がそれぞれ 1 ファイルです
- **保存** — アプリで作った内容を、ファイルとして残す操作です
- **フォルダ** — ファイルを入れて整理する入れ物です。フォルダの中にフォルダも作れます

覚えることは 2 つだけです。**保存しなければ残らない**こと、そして**残ったものは必ずどこかのフォルダにいる**ことです。フォルダは入れ子にできるので、ファイルの場所は道順として言えます。

```text
書類
└── 研修
    ├── メモ.txt
    └── 提出
        └── レポート.txt
```

「レポート.txt は、書類の中の研修の中の提出フォルダにある」— この言い方は、後の講座(プログラミングや Git)でそのまま使います。

| 失敗 | 何が起きるか | 防ぎ方 |
| --- | --- | --- |
| 保存せずに閉じる | 作った内容が消える | 作業の区切りごとに保存する |
| 全部デスクトップに置く | 数が増えると探せない | 仕事ごとにフォルダを分ける |
| 同じ名前で上書き保存 | 前の内容が消える | 別の内容は別の名前を付ける |

## 1-1-4 拡張子は種類の印

> **拡張子は、ファイルの種類を表す名前の末尾の印です**

- **拡張子** — ファイル名の最後の「.」より後ろの部分です。`メモ.txt` なら `txt` です

拡張子は 2 つの役割を持ちます。人間にとっては**種類の読み取り**、OS にとっては**どのアプリで開くかの決定**です。

```text
メモ.txt      … ただの文字だけのファイル
レポート.pdf  … 配布用の文書
写真.png      … 画像
資料.xlsx     … 表計算
ページ.html   … Webページのもと(あとの講座で作ります)
```

全部を覚える必要はありません。「末尾を見れば種類が分かる」という読み方だけ持ち帰ってください。後続の講座では、ファイルを `.ts` や `.html` のように拡張子で呼びます。

注意することが 3 つあります。

| 場面 | 何が起きるか |
| --- | --- |
| 拡張子が画面に出ていない | OS の設定で隠れているだけ。設定で表示できる |
| 拡張子だけ書き換える | 中身は変わらない。開けなくなることもある |
| 知らない拡張子の添付ファイル | 種類が分からないものは開く前に確認する |

とくに 2 つ目は定番の勘違いです。拡張子は**印**であって中身ではないので、名前を変えても種類は変わりません。

## もっと知りたい人へ

- 自分の PC で、拡張子を表示する設定にしてみてください。Windows はエクスプローラーの「表示」、macOS は Finder の設定から変えられます
- いま PC に入っているアプリを 3 つ挙げて、「OS の上で動くアプリだ」と言い直してみてください。2 階建ての図が自分のことばになります

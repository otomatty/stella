# OSが土台、アプリはその上

ITのきほん — Module 1 / レッスン1-1

<!-- ノート: ソフトウェアをもう1段だけ分けます。土台(OS)と上に載るもの(アプリ)の2階建てです。 -->

---

## なぜ必要か

- 「Windows」「macOS」「アプリ」という言葉を、区別せずに使ってしまう
- 「このアプリは Mac では使えません」がなぜ起きるのか分からない

<!-- ノート: つかみ。全部まとめて「パソコンの中身」と呼んでいると、この種の話が理解できません。 -->

---

## 結論

**OSは機械全体を管理する土台のソフトウェアで、アプリはその上で動きます**

- **OS** — ハードウェア全体を管理する土台のソフトウェア。Windows や macOS が代表です
- **アプリ** — 特定の仕事のために OS の上で動かすソフトウェア

<!-- ノート: 結論を先に言い切る。ソフトウェアは1種類ではなく、土台と上物の2階建てです。 -->

---

## 2階建ての図

```text
アプリ         … ブラウザ / 文書作成 / この学習サイトを開く道具
────────────────
OS             … Windows / macOS (機械全体を管理する土台)
────────────────
ハードウェア   … 画面 / キーボード / 中の部品
```

<!-- ノート: アプリは機械を直接さわらず、必ずOSを通します。だからアプリはOSに合わせて作られます。 -->

---

## この区別でわかること

| 場面 | 説明 |
| --- | --- |
| 「Mac では使えないアプリ」 | アプリが Windows という土台に合わせて作られているから |
| 「OS のアップデート」 | 土台の入れ替え。全アプリに影響しうるので大ごと |
| 「アプリのインストール」 | 土台はそのまま、上に道具を1つ足すだけ |

<!-- ノート: よく聞く3つの場面が、2階建ての図だけで説明できることを見せます。 -->

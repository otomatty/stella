# 体と指示に分かれる

ITのきほん — Module 1 / レッスン1-1

<!-- ノート: ここから中身。最初の区別は「体と指示」です。IT の説明はほぼ全部この区別の上に載ります。 -->

---

## なぜ必要か

- 「パソコンの調子が悪い」の原因が、機械なのか中身なのか切り分けられない
- 「インストール」「アップデート」が何をしているのか、実は説明できない

<!-- ノート: つかみ。日常の言葉の裏に、体と指示の区別が隠れています。ここで結論は言わない。 -->

---

## 結論

**コンピュータは、ハードウェア(機械の部分)をソフトウェア(指示のまとまり)が動かしています**

- **コンピュータ** — 指示のとおりに計算や表示をする機械。PC もスマホも同じ仲間です
- **ハードウェア** — 手で触れる機械の部分。画面、キーボード、中の部品
- **ソフトウェア** — 機械に何をさせるかを書いた、指示のまとまり。手では触れません

<!-- ノート: 結論を先に言い切る。体(ハード)と指示(ソフト)、どちらが欠けても動かないことを押さえます。 -->

---

## 身近な例で分ける

```text
ハードウェア … 画面 / キーボード / マウス / 中の部品(計算する部品、覚えておく部品)
ソフトウェア … この学習サイト / 文書を書く道具 / スマホに入れる道具ぜんぶ
```

<!-- ノート: 迷ったら「手で触れるか」で分けられます。触れれば体、触れなければ指示です。 -->

---

## よくある勘違い

| 場面 | 勘違い | 実際 |
| --- | --- | --- |
| 動きが遅い | 機械が古いせいに決まっている | 指示の側(入れすぎ・不具合)のことも多い |
| 新しい機能が増えた | 機械が変わった | 指示を入れ替えただけ(アップデート) |
| 水をこぼして壊れた | 中身のデータも必ず消えた | 壊れたのは体。指示やデータは残ることもある |

<!-- ノート: 体と指示を分けて考えるだけで、トラブルの切り分けが会話になるレベルまで進みます。 -->

# 拡張子は種類の印

ITのきほん — Module 1 / レッスン1-1

<!-- ノート: ファイルの話の仕上げ。開発の教材はこのあとずっと「.ts」「.html」のような拡張子でファイルを呼びます。 -->

## なぜ必要か

- 「.txt で保存して」と言われて、何のことか分からない
- 見た目そっくりのファイルが並んでいて、どれを開けばいいか選べない

<!-- ノート: つかみ。後続講座はファイルを拡張子で呼びます。ここで読めるようにしておきます。 -->

---

## 結論

**拡張子は、ファイルの種類を表す名前の末尾の印です**

- **拡張子** — ファイル名の最後の「.」より後ろの部分。`メモ.txt` なら `txt`

OS は拡張子を見て、どのアプリでそのファイルを開くかを決めます

<!-- ノート: 結論を先に言い切る。人間にとっては種類の読み取り、OSにとっては開くアプリの決定に使われます。 -->

---

## よく出会う拡張子

```text
メモ.txt      … ただの文字だけのファイル
レポート.pdf  … 配布用の文書
写真.png      … 画像
資料.xlsx     … 表計算
ページ.html   … Webページのもと(あとの講座で作ります)
```

<!-- ノート: 全部を覚える必要はありません。「末尾を見れば種類が分かる」という読み方だけ持ち帰ります。 -->

---

## 注意すること

| 場面 | 何が起きるか |
| --- | --- |
| 拡張子が画面に出ていない | OS の設定で隠れているだけ。設定で表示できる |
| 拡張子だけ書き換える | 中身は変わらない。開けなくなることもある |
| 知らない拡張子の添付ファイル | 種類が分からないものは開く前に確認する |

<!-- ノート: 「名前を変えれば種類が変わる」は定番の勘違いです。印と中身は別だと押さえます。 -->

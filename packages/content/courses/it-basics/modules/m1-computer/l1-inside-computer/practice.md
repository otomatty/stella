# レッスン1-1 演習 — コンピュータの中身

対象トピック: 1-1-1 〜 1-1-4

## 手元で試す

自分の PC で、次の 3 つをやってみてください(スマホしかない場合は、紙に図を書くところまでで構いません)。

1. **2 階建ての図を自分の PC で言う** — 使っている OS の名前(Windows / macOS など)と、その上で動いているアプリを 3 つ書き出して、「(アプリ名)は(OS 名)の上で動くアプリ」と言い直してください
2. **フォルダを作って保存する** — 書類フォルダの中に「研修」フォルダを作り、メモ帳(テキストを書けるアプリなら何でも構いません)で 1 行書いて、`メモ.txt` という名前で「研修」フォルダに保存してください。保存できたら、その場所を「〜の中の〜にある」と道順で言ってください
3. **拡張子を表示する** — OS の設定で拡張子を表示に切り替えて、さっき作った `メモ.txt` の末尾に `.txt` が見えることを確かめてください

```text
道順の例
メモ.txt は、書類の中の研修フォルダにある
```

## 演習問題

### 問1(基本)

次の 4 つを、ハードウェアとソフトウェアに分けてください。

1. キーボード
2. ブラウザ
3. 画面(ディスプレイ)
4. Windows

### 問2(基本)

「新しいアプリをインストールした」とき、変わったのは 2 階建て(アプリ / OS / ハードウェア)のどの階ですか。1 文で答えてください。

### 問3(応用)

同僚が「`報告書.txt` の名前を `報告書.pdf` に変えたのに、PDF として開けない」と困っています。何が起きているのかを 1〜2 文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

ハードウェアは 1 と 3(手で触れる機械の部分)、ソフトウェアは 2 と 4(指示のまとまり)です。4 の Windows はソフトウェアの中でも土台にあたる OS です。

</details>

<details>
<summary>問2の解答例</summary>

いちばん上のアプリの階だけが変わりました。土台の OS とハードウェアはそのままで、上に道具が 1 つ増えただけです。

</details>

<details>
<summary>問3の解答例</summary>

拡張子はファイルの種類を表す印であって、中身を変える仕組みではありません。名前の末尾を `.pdf` にしても中身は文字のままなので、PDF としては開けません。

</details>

## 確認クイズ

### Q1. ハードウェアとソフトウェアの説明として正しいものはどれですか。

- A. 高価なものがハードウェア、安価なものがソフトウェア
- B. 手で触れる機械の部分がハードウェア、機械に何をさせるかという指示のまとまりがソフトウェア
- C. PC 本体がハードウェア、スマホがソフトウェア

<details>
<summary>答え</summary>

**B** — 迷ったら「手で触れるか」で分けます。触れれば体(ハードウェア)、触れなければ指示(ソフトウェア)です。

</details>

### Q2. OS の説明として正しいものはどれですか。

- A. 機械全体を管理する土台のソフトウェアで、アプリはその上で動く
- B. コンピュータの中の、計算をする部品のこと
- C. インターネットに接続するための機械のこと

<details>
<summary>答え</summary>

**A** — OS は土台、アプリは上物という 2 階建てです。アプリは機械を直接さわらず、必ず OS を通します。

</details>

### Q3. 「このアプリは macOS では使えません」と書いてある理由として、いちばん適切なものはどれですか。

- A. macOS の機械には性能が足りないから
- B. そのアプリが Windows という土台に合わせて作られているから
- C. macOS ではアプリを追加できない決まりだから

<details>
<summary>答え</summary>

**B** — アプリは OS に合わせて作られます。土台が違えば、その上で動けないことがあります。

</details>

### Q4. アプリで文書を書いたのに、後で開いたら何も残っていませんでした。原因として、いちばんありそうなものはどれですか。

- A. 保存の操作をせずにアプリを閉じた
- B. フォルダを作らずに保存した
- C. 拡張子を表示する設定にしていなかった

<details>
<summary>答え</summary>

**A** — 作った内容は、保存して初めてファイルとして残ります。フォルダの有無や拡張子の表示設定は、内容が残るかどうかとは関係ありません。

</details>

### Q5. 拡張子の説明として正しいものはどれですか。

- A. ファイルの中身を変換する機能で、名前を変えると種類も変わる
- B. ファイル名の末尾に付く、種類を表す印で、OS が開くアプリを決めるのにも使う
- C. ファイルの保存場所を表す住所のこと

<details>
<summary>答え</summary>

**B** — 拡張子は印であって中身ではありません。名前だけ変えても種類は変わらず、開けなくなることもあります。

</details>

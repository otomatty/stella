# ITのきほん カリキュラム

すべての講座の入口になる研修です。スキルツリーの**中心のスキル**として最初に受講し、
これをクリアすると各分野の入門講座(プログラミング・資格対策・AI駆動開発)が開きます。
1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、**学び方 → コンピュータ → インターネット** の順に通します。
いちばん答えられるようになってほしい問いは、「URL を開いてから画面が出るまで、何が起きているか」です。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- 手を動かす部分: `practice.md` の「手元で試す」。自分の PC と紙の上で確かめます
- コード演習(VS Code 拡張の採点)は **この講座にはありません**。学習対象がことばの理解であってコードではないため、
  `course.json` に `exercises` を持ちません
- 前提講座: **なし**。この講座がスキルツリーの入口で、PC の電源を入れられること・文字入力ができることだけを前提にします
- 対象外:
  - プログラミング言語の文法(TypeScript 入門以降の範囲)
  - コマンドライン・ターミナルの操作(必要になる講座で扱う)
  - ネットワークの技術的な詳細(IP アドレス・DNS・HTTP のヘッダーなど。基本情報の対策講座の範囲)
  - 特定製品の操作手順(Windows / macOS の細かい設定画面など)

## 到達目標

1. スキルツリーとレッスンの進め方を理解し、自分で学習を **進められる**
2. ハードウェア・ソフトウェア・OS・アプリの関係を、自分のことばで **説明できる**
3. ファイル・フォルダ・拡張子を使って、作ったものを **整理できる**
4. ブラウザ・サーバー・URL ということばで、「URL を開いてから画面が出るまで」を **説明できる**
5. パスワードとアカウントの基本の守り方を **実践できる**

## 全体構成(3 モジュール / 3 レッスン / 12 トピック)

表の `introduces` はそのトピックで新しく導入する語、`requires` は前提として使う語です。
**この表が語彙台帳の正本**で、各 `slides.md` の front-matter にそのまま写します。並びは学習順(パスの自然順)で、
`requires` の語はすべて、それより上の行の `introduces` に現れます(`check_vocab.mjs` が検査します)。

## 後続講座との関係

この講座は、次の入門講座すべての**前提講座**です(各講座の `course.json` の `prerequisites` に `it-basics` が入ります)。

- プログラミング: TypeScript 入門研修 / SQL 入門研修 / HTML/CSS 入門研修 / Git 入門研修 / Python テスト自動化と CI 入門 / テスト設計と品質保証 入門研修
- 資格対策: 基本情報技術者 科目A対策 / 科目B対策 / AWS Cloud Practitioner 入門
- AI駆動開発: AI駆動開発の考え方(Claude 研修シリーズの 1 本目)

逆方向の依存(この講座が他講座に依存すること)は作りません。中心のスキルが閉じるとツリー全体が開かなくなるためです。

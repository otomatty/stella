# ITのきほん カリキュラム

すべての講座の入口になる研修です。スキルツリーの**中心のスキル**として最初に受講し、
これをクリアすると、本土では HTML/CSS 入門と SQL 入門の 2 本が開きます (スキルツリーの枝は最大 2 本)。資格・AI・DevOps の島は表示条件を満たすと現れますが、本土から線は引きません。
1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、**コンピュータ → インターネット** の順に通します。
いちばん答えられるようになってほしい問いは、「URL を開いてから画面が出るまで、何が起きているか」です。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- 手を動かす部分: `practice.md` の「手元で試す」。自分の PC と紙の上で確かめます
- コード演習(VS Code 拡張の採点)は **この講座にはありません**。学習対象がことばの理解であってコードではないため、
  `course.json` に `exercises` を持ちません
- 前提講座: **なし**。この講座がスキルツリーの入口で、PC の電源を入れられること・文字入力ができることだけを前提にします
- 対象外:
  - スキルツリーの使い方・レッスンの進め方・質問のしかた(画面のヘルプと UI が担う。教材に書くと画面の改訂と二重管理になる)
  - プログラミング言語の文法(TypeScript 入門以降の範囲)
  - コマンドライン・ターミナルの操作(必要になる講座で扱う)
  - ネットワークの技術的な詳細(IP アドレス・DNS・HTTP のヘッダーなど。基本情報の対策講座の範囲)
  - 特定製品の操作手順(Windows / macOS の細かい設定画面など)

## 到達目標

1. ハードウェア・ソフトウェア・OS・アプリの関係を、自分のことばで **説明できる**
2. ファイル・フォルダ・拡張子を使って、作ったものを **整理できる**
3. ブラウザ・サーバー・URL ということばで、「URL を開いてから画面が出るまで」を **説明できる**
4. パスワードとアカウントの基本の守り方を **実践できる**

## 後続講座との関係

この講座はスキルツリーの入口です。クリアすると、まだ他講座を前提にしていない入門が開きます。
スキルツリーは [roadmap.sh](https://roadmap.sh/) を参考にした 2 本のルート(フロントエンド / バックエンド)を軸に組んでいます。

- 基礎(入口直下の共通スキル): Git 入門(実体は 1 講座。スキルツリーではフロントエンドとバックエンドの両方の扇に同じ星を出す。クリアは共有)
- フロントエンドルート: HTML/CSS 入門 → JavaScript 入門 → TypeScript 入門 が本線。見た目の深化(モダンCSS → UI部品 → ページ構成)と、fetch・npm・React などの準備中講座が枝分かれします
- バックエンドルート: コマンドライン入門(準備中) → Node.js 入門(準備中) → TypeScript 入門（サーバー、準備中） → HTTP と REST API 入門(準備中) が背骨。SQL 入門も入口直下に置きます。Python 入門(準備中) → Python テスト自動化と CI 入門 → テスト設計と品質保証 入門 は、開発を知らないと空回りする発展概念なのでサーバー TypeScript の先に置きます
- AWS資格(島): AWS Cloud Practitioner 入門。この講座をクリアすると本土から離れた「島」としてスキルツリーに現れます
- 情報処理資格(島): 基本情報技術者 科目A対策 → 科目B対策 と段階的に進みます。島の現れ方は AWS資格 と同じ
- AI駆動開発(島): AI駆動開発の考え方(Claude 研修シリーズの 1 本目)から始まる島
- DevOps(島): バックエンドの Python 入門をクリアした受講者にだけ現れる。入口は DevOps 入門。本土から線は引かない

TypeScript 入門は入口直下には置きません(JavaScript 入門が先)。

逆方向の依存(この講座が他講座に依存すること)は作りません。中心のスキルが閉じるとツリー全体が開かなくなるためです。

# 3-1-2
# 同値パーティション

テスト設計入門研修 — Module 3 / レッスン3-1

<!-- ノート: 入力の決め方の話です。勘で選ぶのをやめて、仕様から導きます。 -->

---

## なぜ必要か

- 送料の計算を試すのに、100 円・200 円・300 円…と並べた手順書がある
- 全部で 40 件あるが、どれも同じ場所を通っている
- 一方で 3,000 円ちょうどは 1 件も入っていない

<!-- ノート: つかみ。数が多いことと、網が広いことは別です。全数テストは不可能なので、選び方が要ります。 -->

---

## 結論

**同じ扱いを受ける入力はひとつのグループ(同値パーティション)にまとめられる**

- **同値パーティション** — 仕様の上で同じ結果になる入力の集まり
- **同値分割** — 入力の全体を、重なりのないパーティションに分ける作業

<!-- ノート: 結論を言い切る。「同じ扱いを受ける」の根拠は仕様であって、コードではありません。だからブラックボックスの技法です。 -->

---

## 送料計算を同値分割する

> 仕様: 購入額 3,000 円以上なら送料無料。3,000 円未満なら送料 500 円。購入額は 1 円以上。

| パーティション | 範囲 | 結果 |
| --- | --- | --- |
| P1 | 1 〜 2,999 円 | 送料 500 円 |
| P2 | 3,000 円以上 | 送料 0 円 |
| P3 | 0 円以下 | エラー |

<!-- ノート: 具体例の枠。100 円も 200 円も 2,999 円も、すべて P1 の一員です。40 件並べても P1 を 40 回試しただけになります。 -->

---

## 分け方を間違えている例

| 分け方 | どこが問題か |
| --- | --- |
| 1〜3,000 と 3,000 以上 | 3,000 が両方に入る(重なっている) |
| 1〜2,999 と 3,001 以上 | 3,000 がどこにも入らない(抜けている) |
| 1〜2,999 と 3,000 以上 と 0 以下 | ○ 重なりも抜けもない |

<!-- ノート: 失敗例の枠。重なりと抜けが無いことが、同値分割ができている条件です。抜けはそのままテストの穴になります。 -->

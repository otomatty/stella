## なぜ必要か

- 部品も、つなぎ目も、ひととおり確認は済んでいる
- それでも「この画面から先に進めない」という報告が上がってくる

## 結論

**システムテストは利用者の視点で全体の振る舞いを確かめる**

- **システムテスト** — 構築したシステム全体を、本番に近い環境で対象にするテストレベル

<!-- ノート: 結論を言い切る。見る単位が「部品」から「利用者がやりたいこと」に変わるのがこのレベル。 -->

---

## 通しの流れで確かめる

| 手順 | 利用者がやること |
| --- | --- |
| 1 | 会員登録フォームから登録する |
| 2 | 届いたメールのリンクで有効化する |
| 3 | 商品を選び、料金と送料を確認する |
| 4 | 注文を確定し、確認メールを受け取る |

<!-- ノート: 具体例の枠。1 本のシナリオが複数の部品をまたぐ。ここで見つかる欠陥は「流れが途切れる」形で現れる。品質の全体像はこのレベルで初めて見える。 -->

# 2-1-3
# 統合テスト

テスト設計入門 — Module 2 / レッスン2-1

<!-- ノート: 部品どうしをつないだ瞬間に現れる欠陥を扱います。 -->

---

## なぜ必要か

- 会員登録フォームも会員登録 API も、単体では正しく動いていた
- つないだら、生年月日が 1 日ずれて保存されていた

<!-- ノート: つかみ。どちらの部品にも欠陥は無いのに、組み合わせると壊れる。ここで結論は言わない。 -->

---

## 結論

**部品どうしのつなぎ目に潜む欠陥は統合テストで狙う**

- **統合テスト** — 2 つ以上の部品をつないだ状態を対象にするテストレベル

<!-- ノート: 結論を言い切る。コンポーネントテストでは部品の中身、統合テストでは部品の間を見る。 -->

---

## つなぎ目で起きる欠陥の型

| 型 | 会員登録での例 |
| --- | --- |
| 形式の食い違い | 日付を送る側は文字列、受ける側は時刻 |
| 単位の食い違い | 金額を送る側は円、受ける側は銭 |
| 想定外の値 | 任意項目が空のまま届く |
| 順序の前提ずれ | 保存前にメールが送信される |

<!-- ノート: 具体例の枠。つなぎ目の欠陥は「約束の解釈違い」で起きる。だから片方だけを見ても見つからない。 -->

---

## まとめ

**部品どうしのつなぎ目に潜む欠陥は統合テストで狙う**

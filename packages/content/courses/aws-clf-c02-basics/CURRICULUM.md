# AWS Cloud Practitioner 入門 カリキュラム

AWS Certified Cloud Practitioner (**CLF-C02**) の対策講座です。平日10日(1日 ≒ 1モジュール、目安 1.5〜2.5時間)で
公式試験ガイドの4ドメインを一巡し、11日目に本番と同じ65問の模擬試験(M10)で腕試しし、
12日目の直前対策(M11)で誤答を潰してから受験日を決めます。
1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、
サービス名の暗記ではなく「シナリオを読んで、用途に合うサービス・考え方を選べる」状態を目指します。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- 手を動かす部分: `practice.md` の「手元で試す」。紙の上の概念マップ作りや、公式デジタルトレーニングの視聴チェックが中心で、
  **有料の AWS アカウントやコンソール操作は完走条件にしません**(試験ガイド自体がコーディング・設計・実装を対象外と明記しているため)
- 前提講座: **ITのきほん(`it-basics`)**。スキルツリーの入口講座で、コンピュータ・ファイル・Web の基本のことばをそろえてから受講します(`course.json` の `prerequisites` に対応)
- コード演習(VS Code 拡張の採点)は **この講座にはありません**。学習対象が用途選択の判断であってコードではないため、
  `course.json` に `exercises` を持ちません
- 問題はすべて自作です。AWS 公式の Practice Question・サンプル問題・非公式問題集・いわゆる過去問サイトの転載はしません
- 直前対策(M11)は、模試の誤答を潰すための仕上げです。まぎらわしいサービスの切り分け(11-1)・
  ドメイン別のドリル40問(11-2)・受験の手続きと当日(11-3)の3レッスンで、M10の誤答分析からそのまま続けて使います
- 模擬試験(M10)は自作65問を通常の確認クイズとして持ちます。時間計測は受講者が自前のタイマーで行います
  (LMS に模試専用の計時・採点エンジンは持たない)。**本番に合わせているのは問題数と時間だけ**で、
  出題は LMS のクイズ機能に合わせて全問 4 択・単一回答です(本番にある複数回答形式は含みません)。
  本番の文体と複数回答形式への慣らしとして、公式の Skill Builder /
  Official Practice Question Set の並走を引き続き推奨します
- **合格を保証するものではありません**
- 対象外:
  - Associate / Professional / AI Practitioner など他の認定
  - 設計・実装・障害対応・負荷試験・コーディング(CLF-C02 のスコープ外)
  - 有料アカウント必須のラボを完走条件にすること
  - 模試専用の計時・採点エンジン(模試の中身は M10 として提供する)

## 試験の前提(初回調査 2026-08-27 / 再確認 2026-09-01)

現行試験は **CLF-C02** です。2026-09-01 の再確認時点でも後継コード(CLF-C03 等)の公式発表は確認できませんでした。
受講開始時には、認定ページと試験ガイドで後継試験・in-scope サービスの変更が無いか確認してください。

**執筆環境から AWS ドメイン(`aws.amazon.com` / `docs.aws.amazon.com`)への直接取得はできません**(egress で遮断される)。
2026-09-01 の再確認は Web 検索経由で公式ガイド・公式 FAQ・公式ドキュメントの記述を突き合わせる形で行いました。
数値そのものを引く用途には、受講者・執筆者ともに公式ページの直接確認を前提にしてください。

- 認定ページ: https://aws.amazon.com/certification/certified-cloud-practitioner/
- 試験ガイド: https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html
- 90分 / 65問(得点対象50、非得点15) / 尺度点 100–1000、合格 700
- 採点は補償方式(ドメインごとの足切りは無く、総合点だけで合否が決まる)
- 出題は選択式のみ。コーディング・設計・実装・障害切り分け・負荷試験はスコープ外
- 出題形式は単一回答と複数回答の2つ。複数回答に部分点は無く、無回答は不正解として採点される
  (AWS は 2024-08 以降、並べ替え・組み合わせ・ケーススタディの形式を各試験へ順次追加している。
  CLF-C02 の試験ガイドは 2026-09-01 時点で 2 形式のままだが、受験前の確認を M11 で案内している)
- 受験料 100 USD / 日本語で受験可 / 予約は AWS 認定アカウント経由で Pearson VUE(2023-01 以降、配信事業者は Pearson VUE のみ)
- 認定の有効期限は 3 年。再認定は同じ試験の現行版への再合格か、**アソシエイト以上**(アソシエイト / プロフェッショナル)の認定への合格。
  同じ基礎レベルの別の認定(AI Practitioner など)では更新されない。
  Cloud Practitioner は期限の 6 か月前から AWS Cloud Quest: Recertify Cloud Practitioner の修了でも更新できる
- 不合格時は 14 日あけて再受験できる(回数上限は無いが受験料は毎回かかる)

## 到達目標(観測可能)

1. シナリオを見て、共有責任の境界(AWS / 顧客 / 共有)をサービス種別に応じて **選べる**
2. 用途(可用性、低遅延、データ主権、DR)を見て、リージョン / AZ / エッジの使い分けを **説明できる**
3. コンピュート・ストレージ・DB・ネットワークの典型用途から、公式 in-scope の代表サービスを 1 つ **選べる**
4. On-Demand / Reserved / Spot / Savings Plans と、Cost Explorer / Budgets / Pricing Calculator の用途を **区別できる**
5. Well-Architected の 6 本柱の名前と、柱ごとの問いの違いを短文で **言える**
6. まぎらわしいサービスの組(記録・ストレージ・セキュリティ・サインイン・移行)を、設問のキーワードから 1 つに **絞り込める**
7. 申し込みから当日・再認定までの段取りを、自分で **進められる**

## M11. 直前対策と受験本番(3 レッスン / 10 トピック)

### レッスン11-1 まぎらわしいサービスの切り分け

本番の設問は「どれも当てはまりそうな4択」で作られるため、誤答は**似ているサービスの境界**に集中します。

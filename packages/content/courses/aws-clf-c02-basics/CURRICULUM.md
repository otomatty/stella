# AWS Cloud Practitioner 入門 カリキュラム

AWS Certified Cloud Practitioner (**CLF-C02**) の対策講座です。平日10日(1日 ≒ 1モジュール、目安 1.5〜2.5時間)で
公式試験ガイドの4ドメインを一巡し、仕上げの11日目に本番と同じ65問の模擬試験(M10)で腕試しします。
1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、
サービス名の暗記ではなく「シナリオを読んで、用途に合うサービス・考え方を選べる」状態を目指します。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- 手を動かす部分: `practice.md` の「手元で試す」。紙の上の概念マップ作りや、公式デジタルトレーニングの視聴チェックが中心で、
  **有料の AWS アカウントやコンソール操作は完走条件にしません**(試験ガイド自体がコーディング・設計・実装を対象外と明記しているため)
- コード演習(VS Code 拡張の採点)は **この講座にはありません**。学習対象が用途選択の判断であってコードではないため、
  `course.json` に `exercises` を持ちません
- 問題はすべて自作です。AWS 公式の Practice Question・サンプル問題・非公式問題集・いわゆる過去問サイトの転載はしません
- 模擬試験(M10)は自作65問を通常の確認クイズとして持ちます。時間計測は受講者が自前のタイマーで行います
  (LMS に模試専用の計時・採点エンジンは持たない)。**本番に合わせているのは問題数と時間だけ**で、
  出題は LMS のクイズ機能に合わせて全問 4 択・単一回答です(本番にある複数回答形式は含みません)。
  本番の文体と複数回答形式への慣らしとして、公式の Skill Builder /
  Official Practice Question Set の並走を引き続き推奨します
- **合格を保証するものではありません**
- 対象外:
  - Associate / Professional / AI Practitioner など他の認定
  - 設計・実装・障害対応・負荷試験・コーディング(CLF-C02 のスコープ外)
  - 有料アカウント必須のラボを完走条件にすること
  - 模試専用の計時・採点エンジン(模試の中身は M10 として提供する)

## 到達目標(観測可能)

1. シナリオを見て、共有責任の境界(AWS / 顧客 / 共有)をサービス種別に応じて **選べる**
2. 用途(可用性、低遅延、データ主権、DR)を見て、リージョン / AZ / エッジの使い分けを **説明できる**
3. コンピュート・ストレージ・DB・ネットワークの典型用途から、公式 in-scope の代表サービスを 1 つ **選べる**
4. On-Demand / Reserved / Spot / Savings Plans と、Cost Explorer / Budgets / Pricing Calculator の用途を **区別できる**
5. Well-Architected の 6 本柱の名前と、柱ごとの問いの違いを短文で **言える**

# 申し込みはAWS認定アカウントから

AWS Cloud Practitioner 入門 — Module 11 / レッスン11-3

## なぜ必要か

- 勉強が仕上がっても、予約の仕方を知らないと受験日が決まらない
- 受験日を先に決めた人ほど、勉強が締まる
- 会場で受けるか、自宅で受けるかも選べる

<!-- ノート: つかみ。日程を決めるのが最後のひと押しになります。結論はまだ言わない。 -->

---

## 結論

**試験はAWS認定アカウントから予約し、テストセンターかオンライン監督試験のどちらかで受ける**

- **AWS認定アカウント** = 受験・認定の管理に使う専用のアカウント(AWSの利用アカウントとは別)
- 予約と実施は試験配信事業者の **Pearson VUE** が担当する

<!-- ノート: 結論。AWSを使うアカウントと認定のアカウントは別物、という点を強調します。 -->

---

## 最小の例

調査日 2026-09-01 時点の目安です。

| 項目 | 内容 |
| --- | --- |
| 予約 | AWS認定アカウント → Pearson VUE |
| 受け方 | テストセンター / オンライン監督試験 |
| 言語 | 日本語で受験できる |
| 試験時間 | 90分 |
| 受験料 | 100 USD(円換算額は為替で変わる) |

<!-- ノート: 数字は変わりうるので、必ず申込前に公式ページで確認する前提で読み上げます。 -->

---

## どちらで受けるか

- 静かな個室と安定した回線があるならオンライン、確実さを取るならテストセンター
- オンラインは機材と部屋の条件を満たせないと当日に中止になりうる
- 英語で受験する場合に限り、母国語が英語でない受験者は時間延長を申請できる(日本語受験なら対象外)
- 受験料・キャンペーン・キャンセル規定は変わる。申し込み前に公式ページで確認する

<!-- ノート: 補強枠。日本語で受けるなら延長の申請は不要、という点は毎年質問が出るので明示します。 -->

# 11-3-4
# 認定は3年で期限が切れる

AWS Cloud Practitioner 入門 — Module 11 / レッスン11-3

<!-- ノート: 講座の最後のトピックです。合格はゴールではなく、期限のある状態の始まりだと伝えます。 -->

---

## なぜ必要か

- 「合格したら終わり」と思っていると、いつの間にか失効している
- 履歴書や社内の資格手当は、有効な認定であることが前提
- 不合格だったときに、いつから受け直せるかも知っておきたい

<!-- ノート: つかみ。合否のどちらに転んでも、次の予定が立つ状態で終わりたい。 -->

---

## 結論

**AWSの認定は取得から3年で期限が切れるため、期限内に再認定して有効な状態を保つ**

- **再認定** = 期限が切れる前に、認定を有効な状態へ更新すること
- 期限は取得日から起算する

<!-- ノート: 結論。3年という数字と、更新が自分の作業であることを押さえます。 -->

---

## 最小の例

調査日 2026-09-01 時点の内容です。

| 項目 | 内容 |
| --- | --- |
| 有効期限 | 取得から3年 |
| 再認定の方法 | 同じ試験の現行版に再合格する / **アソシエイト以上**(アソシエイトまたはプロフェッショナル)の認定に合格する |
| Cloud Practitionerの追加手段 | 期限の6か月前から、AWS Cloud Quest: Recertify Cloud Practitionerの修了でも更新できる |
| 不合格だったとき | 14日間あけてから再受験できる(回数制限はないが毎回受験料がかかる) |

<!-- ノート: 4行。2行目は「アソシエイト以上」がポイント。同じ基礎レベルの別の認定に受かっても更新にはなりません。制度は変わりうるので、期限が近づいたら公式ページで確認する前提です。 -->

---

## 結果の見方

- 合否と詳細なスコアレポートはAWS認定アカウントで確認する
- レポートにはドメインごとの到達状況が出る
- 不合格でも、どのドメインが弱かったかが分かるので次の復習先になる
- 制度・条件は変わりうる。期限が近づいたら公式の再認定ページで最新を確認する

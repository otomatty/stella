# レッスン11-2 ドメイン別の仕上げドリル

## このレッスンの目標

- [ ] 模試の誤答を、全問の解き直しではなくドメイン別のドリルで潰せる
- [ ] 間隔をあけた解き直しで、定着したかどうかを自分で判定できる
- [ ] 受験前日に見返す「自分だけのリスト」を作れる

## 11-2-1 2周目は誤答だけを解き直す

> **2周目は全問を解き直さず、誤答だけをドメイン別にまとめて解き直す**

M10の模擬試験を解いた翌日、もう一度65問を頭から解く人は多いのですが、それは時間の使い方としては効率が悪い方法です。正解できた問題を解き直しても増える知識はほとんどなく、時間の大半を「できることの確認」に使ってしまいます。

代わりに、誤答だけをドメイン別にまとめて解きます。誤答は偏るので、同じドメインの問題を続けて解くと、間違いの原因が知識不足なのか切り分けの失敗なのかがはっきりします。

| 手順 | やること |
| --- | --- |
| 1 | 誤答分析表を見て、誤答が多い順にドメインを並べる |
| 2 | 多いドメインのドリルだけを解く(このレッスンの確認クイズはドメイン順) |
| 3 | 間違えた問題の復習先トピックを開き、takeawayだけ読み直す |
| 4 | 24時間以上あけて、同じ問題をもう一度解く |

手順3の「takeawayだけ」が重要です。誤答のたびにモジュール全体を読み直すと、1ドメインで力尽きます。まず1文だけ読み直し、それでも腑に落ちなければ該当トピックのdoc.mdへ広げてください。

解き直しの間隔もあけます。解いた直後にもう一度解くのは、覚えているだけで思い出す練習になりません。1日以上あけて、解説を見ずに解けたら定着したと判断します。2回続けて正解した問題は以後は飛ばしてよく、最後まで残った数問が、受験前日に見返す自分だけのリストになります。

## このドリルの使い方

演習の確認クイズは40問で、**ドメイン順に並べてあります**。弱いドメインだけを抜き出して解けるように、区切りを次のとおりにしています。

| 問番号 | ドメイン | 主な復習先 |
| --- | --- | --- |
| Q1〜Q10 | 1 クラウドの概念 | M0・M1・M8(CAF・7R) |
| Q11〜Q20 | 2 セキュリティとコンプライアンス | M7・M8(CloudTrail)・11-1 |
| Q21〜Q32 | 3 テクノロジーとサービス | M2〜M6・11-1 |
| Q33〜Q40 | 4 請求・料金・サポート | M9 |

M10の65問とは重複しない新しい設問です。M10が「通しで解いて現在地を測る」ためのものだったのに対し、こちらは**弱点だけを狙って潰す**ためのドリルなので、時間は計らなくて構いません。1問ずつ、選んだ理由を言葉にしてから解答を開いてください。理由が言えずに正解した問題は、実力ではなく偶然です。印を付けて解き直しの対象に入れてください。

各問の解説末尾には、M10と同じ形式で「(ドメインN / 復習: トピックID)」を付けています。

## もっと知りたい人へ

- 40問を通しで解いても構いませんが、その場合も時間は計りません。時間を計った通しの練習はM10の65問で行い、こちらは精度を上げる用途に使ってください
- ドリルでも正答が安定しないドメインが残る場合は、受験日を先に延ばす判断も選択肢です。日程は自分で選べます

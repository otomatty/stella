# EFSは共有ファイルストレージ

AWS Cloud Practitioner 入門 — Module 5 / レッスン5-1

<!-- ノート: ストレージ3方式の最後。共有、がキーワードのトピックです。 -->

---

## なぜ必要か

- EBSは基本、1台のEC2に取り付けるもの
- でも、複数のWebサーバーで同じアップロード画像を見たい場面がある
- 「共有フォルダー」に当たるものが要る

<!-- ノート: つかみ。社内のファイルサーバー(共有ドライブ)の例え。 -->

---

## 結論

**EFSは、複数のインスタンスから同時にマウントできる共有ファイルストレージ**

- **ファイルストレージ** = フォルダー階層で整理し、ネットワーク越しに共有する方式
- **マウント** = ストレージを自分のフォルダーとして接続すること
- **EFS** = そのマネージド版

<!-- ノート: 結論。複数台から同時に、が判定キーワード。容量は自動で伸縮する。 -->

---

## 最小の例

ストレージ3方式の総まとめです。

| 方式 | サービス | 用途の一言 |
| --- | --- | --- |
| オブジェクト | S3 | Webから出し入れする置き場 |
| ブロック | EBS | 1台に取り付けるディスク |
| ファイル | EFS | 複数台で共有するフォルダー |

<!-- ノート: この3行がレッスンの成果物。1行ずつ読み上げて締める。 -->

---

## 試験での聞かれ方

- 「複数のEC2から同時にアクセスできる共有ストレージ」→ EFS
- Windows向けのファイル共有にはFSxという仲間もある(名前だけ)
- 迷ったら「1台ならEBS、複数台で共有ならEFS」

<!-- ノート: 補強枠。FSxは深入りせず名前だけ。判定の1行で締める。 -->

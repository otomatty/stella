# ストレージクラスで安くする

AWS Cloud Practitioner 入門 — Module 5 / レッスン5-1

<!-- ノート: S3の料金の考え方。頻度と単価のトレードオフを覚えるトピックです。 -->

---

## なぜ必要か

- 毎日見るファイルと、年に1度見るかどうかの保管用ファイルがある
- 同じ棚に同じ値段で置くのはもったいない
- S3には「棚のグレード」がある

<!-- ノート: つかみ。手元の棚と倉庫の使い分け、の例え。 -->

---

## 結論

**アクセス頻度に合わせてStandardからGlacierまでのストレージクラスを選ぶと保管コストが下がる**

- **ストレージクラス** = S3の保管グレード。保管単価と取り出し条件が違う
- **Glacier** = 長期保管(アーカイブ)用の低価格クラス

<!-- ノート: 結論。原則:アクセスが少ないほど保管は安く、取り出しに時間や費用がかかる。 -->

---

## 最小の例

| クラス | 向くデータ |
| --- | --- |
| Standard | 毎日使うデータ |
| Standard-IA | たまにしか使わない(低頻度アクセス) |
| Glacier系 | ほぼ使わない長期保管(監査ログなど) |
| Intelligent-Tiering | 頻度が読めないデータ(自動で移動) |

<!-- ノート: IA=Infrequent Access。下に行くほど保管が安く、取り出しが重い。 -->

---

## 移動は自動化できる

- **ライフサイクル** ルール = 日数に応じてクラスを自動で移す設定
- 例: 30日後にIAへ、90日後にGlacierへ、1年後に削除
- 「手で移す」運用にしない

<!-- ノート: 補強枠。ライフサイクルという語は試験に出る。設定例を1つ読み上げる。 -->

# 5-1-3
# EBSはブロックストレージ

AWS Cloud Practitioner 入門 — Module 5 / レッスン5-1

<!-- ノート: S3との対比で覚える2つ目のストレージです。 -->

---

## なぜ必要か

- EC2で動くOSやデータベースには「ディスク」が要る
- S3はファイル置き場であって、OSをインストールする先ではない
- サーバーに「取り付ける」タイプのストレージが必要

<!-- ノート: つかみ。前トピックの対比の伏線を回収する。 -->

---

## 結論

**EBSは、EC2にディスクとして取り付けて使うブロックストレージ**

- **ブロックストレージ** = データを細かいブロック単位で読み書きする、ディスク型の方式
- **EBS** = EC2に取り付けるそのサービス

<!-- ノート: 結論。外付けSSDをサーバーに挿すイメージ。OS・DBの置き場はこちら。 -->

---

## 最小の例

| | S3 | EBS |
| --- | --- | --- |
| 形 | ファイル置き場 | ディスク |
| つなぎ方 | ネットワーク越しに出し入れ | EC2に取り付ける |
| 典型用途 | 画像・バックアップ | OS・データベースの領域 |

<!-- ノート: この対比表が試験の判定表。取り付ける=アタッチ、という言葉も口頭で。 -->

---

## バックアップはスナップショット

- **スナップショット** = ある時点のEBSの内容の複製
- 撮っておけば、その時点の状態に戻したディスクを作れる
- 保存先は裏でS3が使われる(高い耐久性に相乗り)

<!-- ノート: 補強枠。snapshot=その瞬間の写真。試験は「EBSのバックアップ=スナップショット」の対応で出る。 -->

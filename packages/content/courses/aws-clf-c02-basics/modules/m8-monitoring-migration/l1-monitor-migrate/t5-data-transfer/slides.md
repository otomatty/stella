# 8-1-5
# データの引っ越し道具

AWS Cloud Practitioner 入門 — Module 8 / レッスン8-1

<!-- ノート: M8の締め。データ移送の3道具を運ぶ物と量で選ぶトピックです。 -->

---

## なぜ必要か

- ペタバイト級のデータを回線で送ると、数か月かかる計算になることがある
- 業務中のデータベースは、止めて引っ越すわけにいかない
- 「量」と「止められなさ」に応じた道具がある

<!-- ノート: つかみ。回線より宅配便が速い世界がある、という意外性。 -->

---

## 結論

**回線で送りきれない大容量はSnowファミリーで運び、データベースはDMSで動かしたまま移す**

- **Snowファミリー** = データを物理装置に入れて配送で運ぶサービス群
- **DMS** = 稼働中のデータベースを止めずに移すサービス

<!-- ノート: 結論。物理輸送という選択肢の存在自体が試験ポイント。 -->

---

## 最小の例

| 道具 | 一言 | 向く場面 |
| --- | --- | --- |
| **Snowファミリー** | 装置ごと配送で運ぶ | 回線では間に合わない大容量 |
| **DMS** | DBを動かしたまま移す | 止められない業務DB |
| **DataSync** | ファイルを回線で自動転送 | オンプレのファイルをS3等へ定期同期 |

<!-- ノート: 3道具の判定は「何を、どれだけ、止められるか」。 -->

---

## 試験での聞かれ方

- 「ネットワーク経由では現実的でないペタバイト級の移送」→ Snowファミリー
- 「ダウンタイム最小でデータベースを移行」→ DMS
- 「オンプレのファイルサーバーからS3へ継続的に転送」→ DataSync

# スコープ外を知って絞る

AWS Cloud Practitioner 入門 — Module 0 / レッスン0-1

<!-- ノート: 「何が出ないか」を公式ガイドの言葉で押さえて、勉強を絞るトピックです。 -->

---

## なぜ必要か

- AWSには200を超えるサービスがあり、全部は覚えきれない
- 「コードが書けないと受からないのでは」という不安もよく聞く
- 実は、公式ガイドは「出ないこと」も明記している

<!-- ノート: つかみ。試験勉強の半分は捨てる勇気。公式が捨ててよいと言っている範囲を確認する。 -->

---

## 結論

**コーディング・設計・実装は出題されず、問われるのは用途に合うサービスの選択**

- **用途選択** = シナリオを読み、目的に合うサービスや考え方を選ぶ出題形式
- 手を動かす問題は出ない。選択式だけ

<!-- ノート: 結論。試験ガイドが「対象外のタスク」を列挙している。この講座もその方針に合わせている。 -->

---

## 最小の例

公式ガイドが「求めない」と明記しているタスクの例です。

| 出ないもの | 代わりに問われるもの |
| --- | --- |
| コーディング | サービス名と用途の対応 |
| アーキテクチャ設計 | 「この用途ならどれ?」の選択 |
| 実装・移行の実作業 | 移行の考え方・進め方 |
| 障害切り分け・負荷試験 | 責任分担と相談先 |

<!-- ノート: 左の列に時間を使わないこと。右の列がこの講座の本体になる。 -->

---

## 勉強のしかたが決まる

- サービス一覧は「非網羅で変更あり」と公式が明記している
- 200サービスの暗記ではなく、代表サービスの「用途の一言」を作る
- 例:「静かに保管 → S3」「仮想サーバー → EC2」

<!-- ノート: 補強枠。以降の全モジュールで「サービス名 = 用途の一言」を積み上げていく、という学び方の宣言。 -->

# クラウドコンピューティングとは

AWS Cloud Practitioner 入門 — Module 0 / レッスン0-1

## なぜ必要か

- サーバーを自前で買うと、届くまで数週間、置き場所も電源も自分持ち
- 使わない夜間も、買った代金は返ってこない
- 「必要なときだけ、必要な分だけ」使う方法はないのでしょうか

<!-- ノート: つかみ。物理サーバー調達の面倒さを15秒で。ここで結論は言わない。 -->

---

## 結論

**クラウドは、ITリソースをインターネット越しにオンデマンドで借りて従量課金で使う仕組み**

- **ITリソース** = サーバー・ストレージ・データベースなど、ITの部品
- **オンデマンド** = 必要になったその場で、すぐに
- **従量課金** = 使った量と時間の分だけ支払う

<!-- ノート: 定義を3語に分解して言い切る。この3語は今後の全モジュールで前提になる。 -->

---

## 最小の例

サーバーを1台用意する場合の比較です。

| | 自前で買う | クラウドで借りる |
| --- | --- | --- |
| 使えるまで | 数週間 | 数分 |
| 支払い | 先に全額 | 使った分だけ毎月 |
| やめるとき | 廃棄・売却 | 解放すれば課金も止まる |

<!-- ノート: 3行の対比だけ。電気や水道と同じ「使った分だけ」のモデル、という例えを添える。 -->

---

## よくある誤解

- クラウド = 「誰かのコンピュータに置くだけ」ではない
- 数分で借りて、数分で返せる**オンデマンド性**が本質
- 使い終わった資源を返せば(解放すれば)、その分の支払いは止まる

<!-- ノート: 補強枠。置き場所の話ではなく、借り方と払い方の話だと強調する。「停止」だけではディスクなど関連リソースの課金が残る場合がある、という注意はM3のEC2で具体的に扱う。 -->

## 結論

**クラウドの利点は、先行投資なしで始められることと、数分で世界に展開できる俊敏性に集約される**

- **俊敏性** = 思いついてから使えるまでが速いこと
- お金の利点と、速さの利点の2系統で覚える

<!-- ノート: 6つを丸暗記する前に、「お金」と「速さ」の2系統に束ねると忘れない。 -->

---

## 最小の例

| 系統 | 利点 |
| --- | --- |
| お金 | 先行投資を従量課金に置き換える |
| お金 | 大規模な規模の効果で単価が下がる |
| お金 | データセンターの維持にお金を使わない |
| 速さ | 必要な容量を予想しなくてよい |
| 速さ | 俊敏性が上がり試行錯誤が速くなる |
| 速さ | 数分で世界中に展開できる |

<!-- ノート: 6つを2系統に振り分けた表。個々の深掘りはM1(経済)とM2(グローバル基盤)で行う、と予告。 -->

---

## ひっかけの見分け方

- 「クラウドにすれば障害が起きなくなる」→ 誤り。起きる前提で備える
- 「クラウドにすれば必ず安くなる」→ 誤り。使い方しだい
- 「絶対」「必ず」「ゼロになる」が付く選択肢はまず疑う

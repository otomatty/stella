# TCOで比べる

AWS Cloud Practitioner 入門 — Module 1 / レッスン1-1

<!-- ノート: 「クラウドは高い/安い」論争を正しく裁く物差しを覚えるトピックです。 -->

---

## なぜ必要か

- 「サーバー1台の値段ならオンプレミスの方が安い」と言われることがある
- でも、その比較には電気代も人件費も入っていない
- 何と何を足して比べるのが正しいのでしょうか

<!-- ノート: つかみ。見積書に載る金額だけの比較は片手落ち、という問題提起。 -->

---

## 結論

**クラウドとオンプレミスの費用比較は、機器代だけでなく運用まで含めた総所有コスト(TCO)で行う**

- **TCO** (Total Cost of Ownership) = 持つこと・使うことにかかる費用の総額
- 機器代は氷山の一角にすぎない

<!-- ノート: 結論。TCOは総所有コストという訳語ごと覚える。試験は略語のまま出る。 -->

---

## 最小の例

オンプレミスのTCOに含まれる費用の例です。

| 見えやすい費用 | 見えにくい費用 |
| --- | --- |
| サーバー購入費 | 電気代・空調・設置スペース |
| ソフトウェアライセンス | 保守・交換部品・廃棄 |
| 回線費用 | 運用担当者の人件費 |

<!-- ノート: 右の列が抜けた比較が「オンプレの方が安い」の正体になりがち、と指摘する。 -->

---

## 試験での聞かれ方

- 「移行の費用対効果を検討したい」→ TCOの比較が答えの軸
- 人件費・電気代・データセンター維持費が選択肢の文中に出たらTCOの話
- 見積もりの道具(Pricing Calculator)はM9で扱う

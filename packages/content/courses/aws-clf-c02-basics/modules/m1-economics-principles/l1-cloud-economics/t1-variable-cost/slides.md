# 固定費から変動費へ

AWS Cloud Practitioner 入門 — Module 1 / レッスン1-1

## なぜ必要か

- サーバーを買うお金は、使っても使わなくても先に出ていく
- 新規事業が外れたら、買った機材だけが残る
- この「先に払う怖さ」を消す仕組みが試験でも問われる

<!-- ノート: つかみ。設備投資の意思決定が重い、という業務あるある。結論はまだ。 -->

---

## 結論

**クラウドでは、サーバー購入の固定費が使った分だけ払う変動費に置き換わる**

- **固定費** = 使う量に関係なく発生する費用(設備の購入など)
- **変動費** = 使った量に比例して発生する費用
- 自社で機器を持つ形態は **オンプレミス** と呼ぶ

<!-- ノート: 結論。英語の選択肢では capital expense(CapEx)から variable expense への置き換えと表現される、と口頭で添える。 -->

---

## 最小の例

月100時間だけ使う検証サーバーの例です。

| | オンプレミス | クラウド |
| --- | --- | --- |
| 初期費用 | 数十万円の購入費 | 0円 |
| 毎月の費用 | 使わなくても一定 | 使った100時間分だけ |
| やめるとき | 機材が残る | 解放すれば0円 |

<!-- ノート: 従量課金(M0)の復習を経済の言葉で言い直しただけ、と気づかせる。 -->

## 試験での聞かれ方

- 「先行投資(upfront investment)を減らしたい」→ 変動費への置き換えが答えの軸
- 「初期費用なしで始めたい」も同じ型
- 固定費・変動費という語が選択肢に出たら、このトピックの話

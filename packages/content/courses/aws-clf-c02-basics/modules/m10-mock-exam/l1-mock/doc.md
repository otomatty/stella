# レッスン10-1 模擬試験

## このレッスンの目標

- [ ] 90分・65問を、平均69秒(迷ったら80秒で打ち切り)の配分で解き切れる
- [ ] 誤答をドメイン別に数え、戻るべきモジュールを自分で特定できる
- [ ] 反射表と一言辞書で、知識の抜けを受験前に点検できる

## 10-1-1 模試の受け方と誤答分析

> **模試は時間を計って解き切り、間違いをドメイン別に数えて弱いモジュールへ戻るのが受け方**

この講座の仕上げは、演習の **模擬試験** 65問です。本番のCLF-C02と同じ問題数で、ドメインの配点比(概念24% / セキュリティ30% / 技術とサービス34% / 料金とサポート12%)に近い比率で混ぜてあります。9-2-4で学んだ解き方の型(キーワード → 消去 → 2択を用途で決める)を、初めて「通し」で使う場です。

ただし、**本番に合わせてあるのは問題数と時間だけ** です。本番には4択・単一回答のほかに「5つ以上の選択肢から2つ以上を選ぶ」複数回答形式がありますが、この模試はLMSのクイズ機能に合わせて全問が4択・単一回答です。複数回答形式の練習は、公式のOfficial Practice Question Set(Skill Builder)で補ってください。

受け方は本番と同じ時間の制約にします。

1. 90分のタイマーをセットし、途中で止めない
2. 1周目は平均69秒(75分 ÷ 65問)のペースで進める。80秒かけても決まらない問題は消去法で1つ選び、印を付けて次へ進む(空欄にしない)
3. 全問に触れてから、残り時間で印の問題に戻る
4. 採点し、**誤答分析** を行う——間違いをドメイン別に数え、いちばん多いドメインの該当モジュールを読み直す

配点の対応表です。誤答分析ではこの表で「戻り先」を決めてください。

| ドメイン | 主な戻り先 |
| --- | --- |
| 1 クラウドの概念 | M0・M1・M8(CAF・7R) |
| 2 セキュリティとコンプライアンス | M7・M8(CloudTrail) |
| 3 テクノロジーとサービス | M2〜M6 |
| 4 請求・料金・サポート | M9 |

合格ラインの目安は52問(80%)です。本番は1000点満点の尺度点で700点合格なので単純比較はできませんが、模試で8割を安定して超えていれば安全圏と考えてよい水準です。45〜51問なら、弱いドメインを潰してから受験日を確定してください。この模試は公式問題の転載ではない自作問題であり、合格を保証するものではありません。受験前に公式のOfficial Practice Question Set(Skill Builder)も解いておくことを勧めます。

## 直前チェックリスト — 反射表の完成版

9-2-4で作り始めた反射表の完成版です。試験直前の30分は、この表と各日の絵だけを見返してください。

| 設問のキーワード | 反射で出すもの |
| --- | --- |
| 責任・誰が守る | 共有責任モデル(OF=AWS / IN=利用者。データとアクセス権は常に利用者) |
| 止めたくない・障害に耐える | 複数AZ・ELB・Auto Scaling・マルチAZ配置 |
| Webコンテンツを世界中に速く配信 | CloudFront(HTTP以外のTCP/UDP・固定IP・素早い切り替えならGlobal Accelerator) |
| 自社の建物の中でAWS | Outposts(都市ならLocal Zones、5GならWavelength) |
| サーバー管理なしで実行 | Lambda(コンテナならFargate) |
| 大量ジョブの一括実行 | Batch(定額で簡単に始めるならLightsail) |
| 環境を繰り返し構築 | CloudFormation(届ける流れはCodePipeline、日常運用はSystems Manager) |
| ファイル置き場・アーカイブ | S3(クラスで安く、移動はライフサイクル) |
| ディスク / 共有フォルダー | EBS(1台) / EFS(複数台。WindowsならFSx) |
| 表のデータ・取引 | RDS / Aurora(キーで速く引くならDynamoDB、キャッシュはElastiCache) |
| S3をSQLで調べる | Athena(倉庫で本格集計はRedshift、可視化はQuickSight) |
| ためる・配る・きっかけ・段取り | SQS・SNS・EventBridge・Step Functions |
| 電話窓口・メール送信 | Connect・SES |
| 最小権限・一時的な権限 | IAM(人の集まりはグループ、貸し出す鍵はロール) |
| 鍵・秘密・証明書・個人情報 | KMS・Secrets Manager・ACM・Macie |
| 誰が何を操作したか | CloudTrail(設定変更の記録・評価はConfig、メトリクスと通知はCloudWatch) |
| 安く買う主な方法 | オンデマンド・リザーブド/Savings Plans・スポット(専有や容量確保はDedicated Hosts / Dedicated Instances / Capacity Reservations) |
| 過去の分析・見積もり・見張り | Cost Explorer・Pricing Calculator・Budgets |
| 複数アカウント・一括請求 | Organizations |
| 24時間365日の電話サポート | Business以上(専任TAMはEnterprise) |

## 一言辞書 — 選択肢で見かけたら

本文で深掘りしなかったin-scopeサービスの「一言」です。正解になることは多くありませんが、消去法で迷わないために、名前と一言だけ対応づけておいてください。

| サービス | 一言 |
| --- | --- |
| API Gateway | アプリのAPIの窓口を作る |
| X-Ray | アプリの遅い箇所をリクエスト単位で追跡 |
| IAM Identity Center | 複数アカウントへのサインインを1か所に(旧AWS SSO) |
| Cognito | アプリの一般利用者のログイン機能(IAMは操作する人の権限) |
| Control Tower | 複数アカウント環境をガードレール付きで敷設 |
| Service Catalog | 社内で許可した構成の品ぞろえを配る |
| Compute Optimizer | リソースのサイズの最適化案を提案 |
| Migration Hub | 移行プロジェクトの進捗を1画面で追う |
| Application Discovery Service | 移行前にオンプレの資産を棚卸し |
| Neptune / DocumentDB | グラフ専用 / 文書(ドキュメント)専用のデータベース |
| Comprehend / Lex / Textract / Kendra | 文章の意味分析 / チャットボット / 文書の文字読み取り / 社内検索 |
| Data Exchange | 外部のデータ商品をMarketplace経由で使う |
| Well-Architected Tool | 6本柱の点検を自分の環境に当てて実施 |
| Dedicated Hosts / Dedicated Instances | 物理サーバーを丸ごと専有 / 専有ハードウェア上でインスタンスを動かす(ライセンス・規制要件向け) |
| Capacity Reservations | 特定AZの容量を先に確保しておく(割引ではなく在庫の確保) |

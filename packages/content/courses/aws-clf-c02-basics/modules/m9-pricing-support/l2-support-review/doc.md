## 9-2-1 サポートプランは段階制

> **サポートプランは無料のBasicから専任TAM付きのEnterpriseまでの段階制で、上位ほど応答が速く支援が手厚い**

本番で障害が起きたとき「誰に、どれだけ早く」聞けるかは、**サポートプラン**(AWSの技術サポート契約の等級)で決まります。**TAM**(技術アカウントマネージャー)は、上位プランで付く技術支援の伴走役です。試験ガイド(タスク4.3)が挙げるプランは次の段階です。

| プラン | 一言 |
| --- | --- |
| Basic | 無料。技術サポートなし(請求・アカウントの相談とドキュメントは可) |
| Developer | 開発・検証向け。営業時間内の技術サポート |
| Business | 本番向け。24時間365日、電話・チャットで相談可 |
| Enterprise On-Ramp | 本番の大規模化の入口。**TAMのプール**に相談できる |
| Enterprise | 大規模向け。**専任のTAM** が付く |

判定キーワードは3つです。「本番ワークロードで24時間365日の電話サポート」ならBusiness以上、「専任のTAM」ならEnterprise、「TAMのプールへのアクセス」ならEnterprise On-Rampです。無料のBasicでも、請求やアカウントの相談はできる——この点も正誤問題で出ます。応答時間の分単位の数値は深追いせず、段階の判定を確実にしてください。

1つ注意があります。実際に販売されているプランの体系は再編が進んでおり(新しいプランの提供や、一部プランの新規受付終了が案内されています)、申込画面の並びは上の表と違うことがあります。試験は試験ガイドの体系で問われるので学習は上の表で行い、実際に契約するときは公式のサポートプラン比較ページで最新を確認してください。

## 9-2-2 助言と健康診断

> **Trusted Advisorは改善の助言を、Health Dashboardは自分の環境に影響する障害情報を知らせる**

「もっと安全に・安くできるのに気づいていない」設定は必ずあります。また、AWS側の障害が自分に影響しているのか知りたいときもあります。この2つは別の道具です。

| | Trusted Advisor | Health Dashboard |
| --- | --- | --- |
| 教えてくれること | ベストプラクティスとの差(改善点) | 障害・メンテナンスの自分への影響 |
| 例 | 「使っていないEBSがあります」 | 「東京リージョンで障害、あなたのEC2に影響」 |

**Trusted Advisor** の点検はコスト最適化・パフォーマンス・セキュリティ・耐障害性・サービス上限の観点に分かれます。かつては全項目のチェックが上位サポートプラン限定でしたが、現在はチェック自体は全利用者が利用でき、上位プランには組織横断の集計やAPI経由の利用といった追加機能が付きます(提供条件は変わりうるので、最新は公式ページで確認してください)。**Health Dashboard** は、AWS側のイベントを「自分のリソースへの影響」として表示します。試験では「改善推奨」ならTrusted Advisor、「AWS側のイベント通知」ならHealth Dashboardです。

## 9-2-3 困ったときの情報源

> **公式ドキュメント・re:Post・Marketplace・パートナーと、困りごとに応じた入口を使い分ける**

すべての困りごとをサポート起票で解決するわけではありません。動詞で入口を選びます。

| 困りごと | 入口 |
| --- | --- |
| 仕様を調べたい | 公式ドキュメント |
| 使い方を聞きたい | **re:Post**(公式のQ&Aコミュニティ) |
| 出来合いのソフトを買いたい | **Marketplace**(サードパーティ製ソフトのカタログ) |
| 導入・構築を頼みたい | **パートナーネットワーク**(認定事業者の制度。APN) |

区別を1つだけ足します。パートナーは「社外の認定事業者」、Professional ServicesはAWS自身のコンサルティング部隊です。「移行を支援する外部の事業者」ならパートナー、と読み分けてください。

## 9-2-4 総復習 解き方の型

> **設問の用途キーワードからドメインを見分け、消去法で候補を2つまで絞るのが解き方の型**

知識はそろいました。仕上げは65問を90分でさばく段取りです。1問あたり約80秒。毎問これを同じリズムで回します。

1. 設問の動詞・名詞から用途キーワードを拾う
2. 「絶対」「必ず」「無料になる」の言い過ぎ選択肢を消す
3. 残った2択を「用途の一言」で決める

10日間で作った反射表の抜粋です。practice.md で自分版を完成させてください。

| 設問のキーワード | 反射で出すもの |
| --- | --- |
| 責任・誰が | 共有責任モデル(データと権限は常に利用者) |
| 止めたくない・障害 | 複数AZ・ELB・Auto Scaling・マルチAZ配置 |
| 安くしたい | 買い方4つ・ストレージクラス・ライトサイジング |
| 6本の柱 | Well-Architected |
| 組織・移行準備 | CAF・7R |
| 誰が操作した | CloudTrail |

残り時間の使い方も型にします。分からない問題は旗(後で見直すマーク)を立てて先へ進む。非得点問題が15問あるので、難問1つに執着しない。そして受験を申し込む前に、認定ページで試験コードとin-scopeサービスの最新を必ず確認する——ここまでがこの講座の作法です。

仕上げの腕試しには、公式のOfficial Practice Question SetやPractice Exam(Skill Builder)を使ってください。本講座は65問形式の模試を持ちません。本番形式の練習は公式に任せるのが、いちばん確実です。

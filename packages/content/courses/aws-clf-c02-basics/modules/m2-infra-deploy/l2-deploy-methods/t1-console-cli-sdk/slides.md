## なぜ必要か

- 画面でポチポチ? コマンド? プログラム?

---

## 結論

**AWSの操作手段は、画面のマネジメントコンソール・コマンドのCLI・プログラムから呼ぶSDKの3つ**

- **マネジメントコンソール** = ブラウザーの管理画面
- **CLI** = コマンドラインから操作する道具
- **SDK** = プログラミング言語からAWSを呼ぶ部品集

<!-- ノート: 結論。3つの裏側はすべて同じAPI(サービスを呼び出す窓口)につながっている。 -->

---

## 最小の例

| 手段 | 向いている場面 |
| --- | --- |
| マネジメントコンソール | 初めての操作、たまの確認 |
| CLI | 繰り返す操作、スクリプト化 |
| SDK | アプリケーションに組み込む |

<!-- ノート: 「学ぶときはコンソール、繰り返すならCLI、アプリからならSDK」と言い換える。 -->

---

## 裏側は同じAPI

- **API** = サービスを呼び出す共通の窓口
- コンソールもCLIもSDKも、同じAPIを呼んでいる
- だから「コンソールでできてCLIでできない」は基本ない

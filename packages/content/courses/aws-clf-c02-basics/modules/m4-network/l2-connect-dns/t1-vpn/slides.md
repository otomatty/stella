## なぜ必要か

- ハイブリッドでは、社内ネットワークとVPCをつなぐ必要がある
- インターネット経由の通信は、途中で盗み見られるリスクがある
- 「安く、すぐ、安全に」つなぐ方法から見ていく

<!-- ノート: つかみ。M2のハイブリッドの「つなぐ」を具体化する回、と位置づける。 -->

---

## 結論

**Site-to-Site VPNは、インターネット越しに自社拠点とVPCを暗号化してつなぐ**

- **暗号化** = 内容を第三者に読めない形に変換すること
- **VPN** = 公衆回線の上に、暗号化された専用のトンネルを作る技術

<!-- ノート: 結論。Site-to-Site=拠点とVPCの間。インターネットを使うので安くて早い。 -->

---

## 最小の例

| 項目 | Site-to-Site VPN |
| --- | --- |
| 使う回線 | 既存のインターネット回線 |
| 安全性 | 暗号化トンネルで確保 |
| 開通まで | 短い(機器設定のみ) |
| 通信品質 | インターネット品質に依存 |

<!-- ノート: 最後の行が次トピックへの伏線。品質の保証はできない。 -->

## 試験での聞かれ方

- 「オンプレミスとVPCを、暗号化された接続で早く安価につなぎたい」→ VPN
- 「インターネットを経由してよい」が問題文にあればVPN寄り
- 品質・帯域の保証が要件なら、次のDirect Connectへ

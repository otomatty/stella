# 入口を守るWAFとShield

AWS Cloud Practitioner 入門 — Module 7 / レッスン7-2

<!-- ノート: 入口防御の2枚看板を攻撃の種類と対で覚えるトピックです。 -->

---

## なぜ必要か

- 公開したWebサイトには、招かれざる通信も届く
- 攻撃には「中身が悪意」と「量で潰す」の2系統がある
- 系統ごとに専用の盾がある

<!-- ノート: つかみ。攻撃の2分類を先に置くと、サービスが1対1で刺さる。 -->

---

## 結論

**WAFはWebアプリを狙う攻撃を、ShieldはDDoS攻撃を防ぐ、入口の防御サービス**

- **WAF** = Webアプリへの攻撃(不正な内容のリクエスト)を検査して弾く壁
- **DDoS** = 大量の通信で押し潰す攻撃。**Shield** がその盾

<!-- ノート: 結論。中身を見るWAF、量に耐えるShield。 -->

---

## 最小の例

| 攻撃 | 例 | 防ぐ |
| --- | --- | --- |
| 中身が悪意 | SQLインジェクションなど不正なリクエスト | **WAF** |
| 量で潰す | 大量アクセスで麻痺させる(DDoS) | **Shield** |

<!-- ノート: WAFはCloudFrontやELBに取り付けて使う。Shieldの標準版は自動で全員に有効。 -->

---

## 試験での聞かれ方

- 「SQLインジェクションからWebアプリを守る」→ WAF
- 「DDoS攻撃からの保護」→ Shield
- セキュリティグループ(M4)は許可制のフィルター、WAFは攻撃パターンの検査、と役割が違う

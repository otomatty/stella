# まずstatus/log/diff

Git入門 — Module 10 / レッスン10-4

<!-- ノート: 研修最後のレッスンです。新しいコマンドはもう出てきません。困ったときにどう動くか、という型を4つ覚えて仕上げます。 -->

---

## なぜ必要か

- 「なんか変だ」と思ったとき、原因も現在地も分からないまま焦りだけがある
- 当てずっぽうにコマンドを打つと、傷を広げることがある

<!-- ノート: 困ったときに一番危ないのは、状況が分からないまま手を動かすことです。まず何をするかを型にしておきます。 -->

---

## 結論

**困ったらまず status・log・diff の3つで現在地を確かめる**

- この3つは見るだけで、何も変更しない安全なコマンド
- 現在地が分かれば、打つ手はたいてい絞れる

<!-- ノート: 3つとも研修の前半で学んだコマンドです。読み取り専用なので、何度打っても状況は悪化しません。 -->

---

## 最小の例

```bash
git status          # 今どの枝にいて、何が変更中か
git log --oneline   # どこまでコミットできているか
git diff            # まだ記録していない変更の中身
```

<!-- ノート: 順番もこのままでいいです。枝と変更中のファイル、コミットの進み具合、変更の中身。この3枚で現在地の地図がそろいます。 -->

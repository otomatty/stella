## なぜ必要か

- 困って検索すると、reset --hard や強制pushが「解決策」として出てくる
- それが今の状況に合っているかは、検索結果には書いていない

<!-- ノート: 検索で見つかる強いコマンドは、誰かの状況での正解です。自分の状況での正解とは限りません。 -->

---

## 結論

**分からなくなったら、履歴を消すコマンドを打つ前に人に聞く**

- 履歴を消す操作だけは、取り返しがつかない
- コミット済みの変更は、消さない限り残っている。相談する時間は十分ある

<!-- ノート: 聞くのは恥ではなく、チームの損失を防ぐ行動です。状況を説明できるように、statusとlogの結果を控えてから聞きに行きましょう。 -->

---

## よくある間違い

```text
NG: 焦って reset --hard や強制pushをコピペで実行
    → コミットや共有の履歴ごと消え、チーム全員に影響

OK: status と log で現在地を控えて、詳しい人に相談
    → 消さない限り、コミットした作業は無事なまま
```

<!-- ノート: 待っている間に状況が悪化しないのがGitの良いところです。コミットさえしてあれば、落ち着いて助けを求められます。 -->

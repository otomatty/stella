# 10-4-2
# エラーは次の一手を書いている

Git入門 — Module 10 / レッスン10-4

<!-- ノート: 現在地の確かめ方の次は、Gitが赤い文字で何か言ってきたときの対処です。 -->

---

## なぜ必要か

- 赤い英語のメッセージが出ると、読まずに閉じて検索に走りがち
- 検索で出てきたコマンドをコピペするのは、状況に合わない一手になりやすい

<!-- ノート: エラーが出たときの反射で一番多いのが「読まずに検索」です。実は答えはもっと近くにあります。 -->

---

## 結論

**Git のエラーメッセージには、次に打つべき一手が書いてある**

- Git のエラーの多くは、原因と対処のヒントをセットで表示する
- まず読む。読んでから動くほうが結局速い

<!-- ノート: Gitのメッセージは意外なほど親切で、やるべきことを文章で提案してくれます。英語でも、コマンド名だけ拾えば十分読めます。 -->

---

## 最小の例

```text
error: Your local changes to the following files would be overwritten:
        meeting-notes.txt
Please commit your changes or stash them before you switch branches.

# → 「切り替える前に commit するか stash して」と一手が書いてある
```

<!-- ノート: 枝の切り替えが止められたときの実物です。commitかstashか、知っているコマンドがそのまま提案されています。 -->

# 10-3-4
# 裏では同じGit

Git入門研修 — Module 10 / レッスン10-3

<!-- ノート: ボタンで add も commit もコンフリクト解決もできると分かりました。最後に、この画面とコマンドの関係を整理します。 -->

---

## なぜ必要か

- ボタンを押すだけの操作は、慣れないうちは「何が起きたのか」が見えず不安になる
- 画面で困ったとき、画面の中だけで原因を探すと行き詰まる

<!-- ノート: GUIだけで覚えた人がつまずくのがここです。皆さんはコマンドから学んだので、この不安を種明かしできます。 -->

---

## 結論

**GUI の操作は裏では同じ Git(意味はこの研修で覚えたコマンドと同じ)**

- ボタンの1つ1つが、学んだコマンドに対応している
- だから画面で迷ったら、ターミナルで確かめればよい

<!-- ノート: GUIは別の道具ではなく、同じGitの別の入口です。コマンドで身につけた理解が、そのまま画面の理解になります。 -->

---

## 最小の例

```text
ソース管理ビューの操作        裏で動いている意味
──────────────────────────────────────────
「+」でステージする        =  git add
「コミット」ボタン          =  git commit
「変更の同期」              =  git pull と git push
```

<!-- ノート: 対応表はこれだけです。逆に言うと、画面の操作で分からないことが出たら、対応するコマンドの知識で説明できます。 -->

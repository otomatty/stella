# 10-3-3
# コンフリクトはエディタで

Git入門 — Module 10 / レッスン10-3

<!-- ノート: コンフリクトの解決は、マーカーを手で消して直すと学びました。VS Codeには、その作業のための専用画面があります。 -->

---

## なぜ必要か

- ターミナルでの解決は、マーカーを自分で消して正しい形に直す作業だった
- マーカーの消し忘れや消し間違いが、そのまま事故につながる

<!-- ノート: マーカーはただのテキストなので、消し忘れてもGitは止めてくれません。手作業ゆえのミスが起きやすい場面です。 -->

---

## 結論

**コンフリクトはマージエディタで「どちらを残すか」を選んで解決できる**

- **マージエディタ** = VS Code のコンフリクト解決の専用画面
- 両方の変更を見比べながら、ボタンで選ぶだけ。マーカーは手で触らない

<!-- ノート: マージエディタという名前をここで導入します。選んだ結果にはマーカーが残らないので、消し忘れの事故が起きません。 -->

---

## 最小の例

```text
上段左: 自分の枝の内容        上段右: 相手の枝の内容
下段:   結果(選んだ内容がここに入る)

1. コンフリクト中のファイルで「マージ エディターで解決」を開く
2. 残したい側の「取り込む」を選ぶ(両方選んで組み合わせも可)
3. 完了したら、いつもどおり add して commit
```

<!-- ノート: 上の2つが選択肢、下が答案用紙というレイアウトです。最後にaddとcommitで確定するのはターミナルの手順と同じです。 -->

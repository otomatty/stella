## なぜ必要か

- ここまでの操作は、すべてターミナルにコマンドを打ってきた
- 実務で使うエディタには、Git の操作が画面として組み込まれている

<!-- ノート: コマンドを覚えたからこそ、画面の操作が「何をしているか」まで分かります。まず画面の場所と構成を押さえます。 -->

## 結論

**VS Code のソース管理ビューから add・commit・push ができる**

- **ソース管理ビュー** = VS Code 左端の、枝分かれした形のアイコンで開く画面
- 変更したファイルの一覧と、メッセージ入力欄、コミットボタンが並ぶ

<!-- ノート: ソース管理ビューという名前をここで導入します。左端の縦のアイコン列から枝分かれマークを押すと開きます。 -->

---

## 最小の例

```text
1. 左端の枝分かれアイコンをクリック → ソース管理ビューが開く
2. 「変更」に並ぶファイルの「+」を押す        = add(ステージングエリアへ)
3. 上部の入力欄にメッセージを書いて「コミット」 = commit
4. 「変更の同期」ボタン                        = push(あわせて pull も行う)
```

<!-- ノート: 画面の上から、入力欄、ステージ済みの変更、変更、の順に並びます。プラスのボタンがadd、コミットボタンがcommitに対応します。 -->

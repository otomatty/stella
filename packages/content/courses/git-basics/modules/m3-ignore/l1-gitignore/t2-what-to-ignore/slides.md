# 3-1-2
# 無視するのは作り直せるもの

Git入門研修 — Module 3 / レッスン3-1

<!-- ノート: .gitignoreの書き方は分かった。次は「何を書くべきか」という判断基準を1つだけ覚えます。 -->

---

## なぜ必要か

- 無視リストは便利だが、何でも書いてよいわけではない
- 記録すべきファイルまで無視すると、履歴に残らず消えても戻れない

<!-- ノート: 道具を覚えた直後の不安。「これは書いていいのか」を毎回悩まなくて済む基準が欲しい。 -->

---

## 結論

**無視するのは生成物・ログ・依存フォルダなど「作り直せるもの」**

- 生成物 = 元のファイルから機械が作り出したもの(ビルド結果など)
- 判断基準は1つ:「消えても、また作り直せるか」

<!-- ノート: 生成物という言葉をここで定義する。作り直せるものは履歴に残す価値がない、と言い切ってよい。 -->

---

## 対比で覚える

```text
無視する(作り直せる)      記録する(作り直せない)
--------------------      ----------------------
ビルドの生成物             自分で書いたプログラム
動作ログ                   README などの文書
依存フォルダ               設定ファイルの正本
```

- 迷ったら「消えたら困るか?」と自分に聞く。困るなら記録する

<!-- ノート: 依存フォルダは、外部からダウンロードし直せる部品置き場のこと。左の列はいつでも再現できるから、履歴に入れるとかえって邪魔になる。 -->

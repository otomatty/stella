# .gitignoreで無視する

Git入門 — Module 3 / レッスン3-1

<!-- ノート: ここからModule 3です。記録のやり方は覚えたので、今度は「記録しないもの」を決める道具を学びます。 -->

---

## なぜ必要か

- リポジトリには、記録したくないファイルも生まれる(動作ログなど)
- status を打つたびに Untracked に並び、add の候補に毎回混ざって邪魔になる

<!-- ノート: つかみ。statusのたびに「記録しないと決めたファイル」が出続けるうっとうしさを思い出してもらう。 -->

---

## 結論

**.gitignore に書いたファイルを、Gitは無いものとして扱う**

- .gitignore はリポジトリ直下に置く、ただのテキストファイル
- 書かれたファイルは status に出ず、add の対象にもならない

<!-- ノート: 無視リストというシンプルな道具。特別な設定画面ではなく、1行1件で書くテキストファイルだと押さえる。 -->

---

## 最小の例

```text
# .gitignore の中身
app.log
```

- 保存すると、app.log は git status に出なくなる
- .gitignore 自体はコミットして、チームで同じ無視リストを共有する

<!-- ノート: ファイル名を1行書くだけ。.gitignore自体は記録に含めるのがポイントで、全員が同じルールで無視できるようになる。 -->

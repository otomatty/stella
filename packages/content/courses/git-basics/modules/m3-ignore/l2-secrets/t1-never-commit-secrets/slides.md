# 秘密はコミットしない

Git入門 — Module 3 / レッスン3-2

<!-- ノート: このレッスンは安全の話です。技術というより、事故を起こさないための約束を3つ覚えます。 -->

---

## なぜ必要か

- プログラムを動かすには、パスワードや接続先の鍵が必要になる
- コードのそばに書いておけば動く。だから、つい一緒に記録したくなる

<!-- ノート: 悪意ではなく利便性から事故が起きる、という導入。動かすことを優先すると自然にやってしまう。 -->

---

## 結論

**パスワードやAPIキーは、コミットしてはいけない**

- APIキー = 外部サービスを使うための合鍵の文字列
- パスワードやAPIキーのような、漏れると悪用されるものが秘密情報

<!-- ノート: 秘密情報とAPIキーをここで定義する。コミットは履歴に残って共有相手全員に見えるから、鍵の置き場にしてはいけない。 -->

---

## よくある間違い

```text
// 接続の設定をコードに直接書いてしまった例
apiKey = "sk-a1b2c3d4..."   // ← これをコミットしてはいけない
```

- コミットした瞬間、履歴を見られる人全員に鍵が渡る
- GitHub で公開すれば、世界中から見える

<!-- ノート: 公開リポジトリのキーは自動巡回で数分で拾われて悪用される。会社の請求やお客様の情報に直結する事故だと伝える。 -->

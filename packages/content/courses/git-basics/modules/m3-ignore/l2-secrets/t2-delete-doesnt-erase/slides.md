# 3-2-2
# 削除コミットでは消えない

Git入門研修 — Module 3 / レッスン3-2

<!-- ノート: 秘密をコミットしてしまった後の話です。直感に反する性質なので、1本使ってしっかり押さえます。 -->

---

## なぜ必要か

- うっかりAPIキーをコミットしてしまった。急いで消したい
- 「ファイルを消してコミットし直せば大丈夫」— 本当にそうか?

<!-- ノート: 誰もがまず思いつく対処が「消すコミット」。その直感が危ない、というのがこのトピックの核心。 -->

---

## 結論

**一度コミットした秘密は削除コミットでは消えない(まずキーを無効化する)**

- コミットはスナップショットとして履歴に全部残る
- 漏れた鍵は「隠す」ではなく「使えなくする」(無効化)が正解

<!-- ノート: 履歴は消さずに積む道具だから、削除もまた1つの記録にすぎない。対処の一手目はGitではなく、鍵の発行元での無効化。 -->

---

## よくある間違い

```text
記録1: 設定ファイルを追加(APIキー入り) ← ここに残り続ける
記録2: APIキーの行を削除
```

- 記録2の後でも、記録1を開けばキーは丸見え
- 削除コミットは「最新の状態」を変えるだけで、過去は消さない

<!-- ノート: 履歴をさかのぼれば過去のスナップショットがそのまま開ける。消したつもりで公開を続ける、が最悪のパターン。 -->

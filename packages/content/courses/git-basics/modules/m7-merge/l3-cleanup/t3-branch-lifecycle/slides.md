# ブランチの一生

Git入門研修 — Module 7 / レッスン7-3

<!-- ノート: Module 6と7のまとめにあたるトピックです。ブランチの操作を1つの流れとして覚えます。 -->

---

## なぜ必要か

- ブランチの操作が、ここまででひととおり出そろった
- ばらばらに覚えるより、1つの流れとして持つと迷わない

<!-- ノート: 個々のコマンドは知っていても、いざ作業となると順番に迷います。型として1周を覚えてしまいましょう。 -->

---

## 結論

**「作る → 積む → 合流 → 消す」がブランチの一生**

- この1周を短く回すのが、ブランチ運用の基本
- 消すところまでやって、1つの作業が完了

<!-- ノート: 4つの動詞で言えるようになれば、ブランチは道具として手になじんだと言えます。 -->

---

## 最小の例

```bash
git switch -c fix-typo    # 1. 作る
#   (編集してコミットを積む)  2. 積む
git switch main
git merge fix-typo        # 3. 合流
git branch -d fix-typo    # 4. 消す
```

<!-- ノート: この5行が1周です。実務ではこの1周を、1つの小さな作業ごとに何度も繰り返します。 -->

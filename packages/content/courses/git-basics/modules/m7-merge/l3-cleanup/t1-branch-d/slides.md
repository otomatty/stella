# 7-3-1
# branch -dで消す

Git入門 — Module 7 / レッスン7-3

<!-- ノート: マージが済んだ後の片付けです。消すのが怖くない理由まで含めて押さえます。 -->

---

## なぜ必要か

- マージが済んだ枝を残したままだと、branch の一覧が増え続ける
- どれが作業中の枝か、だんだん分からなくなる

<!-- ノート: 役目を終えた枝は次の作業の邪魔になります。片付けまでがマージの仕事です。 -->

---

## 結論

**マージし終えたブランチは git branch -d で消す(消えるのは付箋だけ)**

- コミットは履歴に残ったまま
- 消えるのはブランチという名前(付箋)だけ

<!-- ノート: ブランチは動く付箋でした。付箋をはがしても、貼ってあったコミットは消えません。だから安心して消せます。 -->

---

## 最小の例

```bash
git branch -d fix-typo
# Deleted branch fix-typo (was 8e4b7d2).
```

- 表示された ID(8e4b7d2)のコミットは、履歴に残っている

<!-- ノート: 出力のwas以降は、付箋が最後に指していたコミットのIDです。マージ済みなので、その中身はもう受け皿の枝に入っています。 -->

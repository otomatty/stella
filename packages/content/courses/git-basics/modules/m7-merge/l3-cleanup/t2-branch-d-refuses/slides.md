# 7-3-2
# -dは未マージを断る

Git入門 — Module 7 / レッスン7-3

<!-- ノート: -dの安全装置の話です。断られたときの正しい受け止め方を押さえます。 -->

---

## なぜ必要か

- 消そうとした枝に、まだマージしていないコミットが残っていることがある
- 気づかずに消すと、積んだ変更を見失ってしまう

<!-- ノート: 片付けのつもりで、まだ取り込んでいない作業ごと消してしまうのが一番怖い事故です。 -->

---

## 結論

**-d は未マージなら断ってくれる(-D の強制は本当によいか確かめてから)**

- 断られたら、まず log でその枝の中身を確かめる
- 大文字の -D は「本当に捨ててよい」と確かめてからだけ

<!-- ノート: 断られたのは失敗ではなく安全装置が働いた合図です。-Dで押し切る前に、必ず中身を見ます。 -->

---

## 最小の例

```bash
git branch -d try-layout
# error: the branch 'try-layout' is not fully merged
```

- 「まだ取り込んでいないコミットがある」という警告

<!-- ノート: not fully mergedは、まだ合流していない変更が残っているという意味です。必要ならマージしてから-dで消します。 -->

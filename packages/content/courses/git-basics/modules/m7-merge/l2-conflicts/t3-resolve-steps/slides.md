# 7-2-3
# 直し方は編集→add→commit

Git入門 — Module 7 / レッスン7-2

<!-- ノート: コンフリクトへの答え方です。特別なコマンドは出てきません。 -->

---

## なぜ必要か

- 両方の言い分は読めた。次はマージを完了させたい
- コンフリクトの間、マージは途中で止まっている状態

<!-- ノート: 質問に答えるまでマージは保留中です。答え方を知らないと、ここで止まったままになってしまいます。 -->

---

## 結論

**あるべき形に編集してマーカーを消し、add して commit すれば解決**

- 特別な解除コマンドは無い
- いつもの「記録の手順」でマージを完了させる

<!-- ノート: どちらかを残すでも、両方を活かした第3の形でも構いません。正解の形に整えたら、あとは普段どおりadd、commitです。 -->

---

## 最小の例

```bash
# 1. ファイルを編集し、マーカーごと「あるべき1つの形」にする
git add practice.txt              # 2. 直した結果を選ぶ
git commit -m "単価改定を反映"     # 3. コミットして完了
```

- マーカーの消し忘れが無いか、コミット前に見直す

<!-- ノート: addは「この形で解決した」という宣言になります。commitまで終えると、それがマージコミットになります。 -->

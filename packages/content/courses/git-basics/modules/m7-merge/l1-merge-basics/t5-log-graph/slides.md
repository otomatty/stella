# 7-1-5
# --graphで形を見る

Git入門 — Module 7 / レッスン7-1

<!-- ノート: レッスン7-1の締めくくりです。マージした結果の形を、自分の目で確かめる方法を覚えます。 -->

---

## なぜ必要か

- マージを重ねると、履歴は一直線ではなくなる
- 枝分かれの形は、文字の一覧だけでは思い浮かべにくい

<!-- ノート: 普通のlogは1列に並べて見せるので、どこで分かれてどこで合流したかが読み取れません。 -->

---

## 結論

**git log --graph --oneline で、枝分かれと合流の形を確かめられる**

- --graph は履歴を線(グラフ)付きで表示するオプション
- マージの前後に打てば、何が起きたか一目で分かる

<!-- ノート: --onelineと組み合わせるのが定番の形です。マージしたら--graphで確かめる、を習慣にします。 -->

---

## 最小の例

```bash
git log --graph --oneline
# *   9c3f2e1 価格表の更新を取り込む
# |\
# | * 4d8a7b2 単価を改定
# * | 1f6e9c3 会議メモを追加
# |/
# * 7a2b5d8 企画書を作成
```

<!-- ノート: 線が二股に分かれて、また1点に戻っています。一番上の9c3f2e1が、親を2つ持つマージコミットです。 -->

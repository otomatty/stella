# 7-1-4
# マージコミット

Git入門研修 — Module 7 / レッスン7-1

<!-- ノート: fast-forwardできない場合、つまり枝が二股に育った場合の合流のしかたです。 -->

---

## なぜ必要か

- 枝で作業している間に、main 側にも新しいコミットが増えることがある
- 二股に育った枝は、付箋を先へ進めるだけでは合流できない

<!-- ノート: 並行して作業すれば枝は自然に二股になります。早送りでは済まないとき、Gitはどう合流させるのでしょうか。 -->

---

## 結論

**二股に育った枝は、両方を親に持つマージコミットで束ねられる**

- 両方の変更を合わせた新しいコミットが1つ作られる
- 親を2つ持つのがマージコミットの特徴

<!-- ノート: 普通のコミットの親は1つですが、マージコミットは2つです。二股の先端どうしを1点に束ねる結び目だと思ってください。 -->

---

## 最小の例

```text
main:      A---B---C-------M   ← M がマージコミット
                \         /
add-price:       D---E---
```

- M は C と E の両方を親に持ち、両方の変更を含む

<!-- ノート: mainに居てgit merge add-priceを打つと、結び目Mが作られてmainの付箋はMに進みます。add-priceの付箋はEのままです。 -->

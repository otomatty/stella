# git showで中身を見る

Git入門 — Module 4 / レッスン4-2

<!-- ノート: このレッスンでは、履歴の一覧ではなく「1つのコミット」を狙い撃ちで調べます。最初は git show です。 -->

## なぜ必要か

- --oneline の一覧で「気になるコミット」が1つ見つかった
- そのために log -p で全コミットの差分を出すのは大げさ
- 狙ったコミット1つだけを詳しく見たい

<!-- ノート: 一覧で目星を付けて、1件だけ精読する。この流れの後半を担うコマンドを覚えます。 -->

---

## 結論

**git show ID で、そのコミットのメッセージと差分を見る**

- ID には --oneline で見えた短いハッシュが使える
- 表示は「コミットの情報 + メッセージ + 差分」のセット

<!-- ノート: showは「見せる」の意味そのままです。コミット1つ分だけが表示されるので、log -p より的を絞れます。 -->

---

## 最小の例

```bash
git show a1b2c3d
# commit a1b2c3d...
#     価格表に単価を追記
#
# -コーヒー
# +コーヒー 450円
```

<!-- ノート: --onelineで拾ったハッシュをそのまま渡します。メッセージと差分が1コミット分だけ出ることを確認します。 -->

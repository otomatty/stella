# 4-2-2
# HEADは今いる場所

Git入門研修 — Module 4 / レッスン4-2

<!-- ノート: log の画面に出てくる HEAD という表示の正体を押さえます。この研修で何度も出てくる大事な言葉です。 -->

---

## なぜ必要か

- git log の一番上に HEAD という表示が出てくる
- 「最新のコミットを見たい」だけでハッシュを調べるのは面倒
- 「今の自分の位置」を指す書き方があると楽になる

<!-- ノート: 学習者が必ず目にするのに説明されないままになりがちな表示です。ここで名前を付けて解決します。 -->

---

## 結論

**HEAD は「自分が今どのコミットに居るか」を指す印**

- ふだんは、一番新しいコミットを指している
- ハッシュの代わりに HEAD と書いてコミットを指せる

<!-- ノート: 自分の現在地を指す印、とだけ覚えれば今は十分です。コミットするたびに、印は新しいコミットへ進みます。 -->

---

## 最小の例

```bash
git show HEAD
# commit a1b2c3d...
#     価格表に単価を追記
#
# -コーヒー
# +コーヒー 450円
```

- ハッシュを調べずに、最新のコミットを表示できた

<!-- ノート: show HEAD は「今いるコミットを見せて」という意味になります。log で最新ハッシュを探す手間が消えます。 -->

# 4-2-3
# HEAD~1は1つ前

Git入門研修 — Module 4 / レッスン4-2

<!-- ノート: HEADを起点にして「1つ前」「2つ前」を指す書き方を覚えます。数字を変えるだけの単純なしくみです。 -->

---

## なぜ必要か

- 「1つ前のコミットと見比べたい」はよくある場面
- そのたびに一覧を開いてハッシュを探すのは手間
- 「今の1つ前」と、位置関係で指せたら速い

<!-- ノート: 調べたいコミットは「最新のちょっと前」であることが多いです。番地ではなく相対位置で指す発想を導入します。 -->

---

## 結論

**HEAD~1 のように、今いる場所から相対的にコミットを指せる**

- `HEAD~1` は1つ前、`HEAD~2` は2つ前のコミット
- ハッシュを調べずに、さかのぼった先を指せる

<!-- ノート: チルダの後ろの数字が「何個さかのぼるか」です。HEADが動けば、HEAD~1が指す先も一緒に動きます。 -->

---

## 最小の例

```bash
git show HEAD~1
# commit 9e8f7a6...
#     価格表を作成
```

- 最新(HEAD)の1つ前のコミットが表示された

<!-- ノート: 直前のトピックのshow HEADと見比べると、1つ過去のコミットが出ています。数字を2にすればもう1つ戻ります。 -->

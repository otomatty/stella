# 4-2-4
# git blameで書いた人を調べる

Git入門研修 — Module 4 / レッスン4-2

<!-- ノート: モジュール4の最後は、コミット単位ではなく「行単位」でいきさつを調べる道具です。 -->

---

## なぜ必要か

- ファイルを読んでいて「この行、なぜこう書いた?」と思うことがある
- 事情を知りたくても、誰に聞けばいいか分からない
- 行ごとに「最後に変えた記録」をたどれると助かる

<!-- ノート: 実務で頻出の場面です。書いた本人に理由を聞くのが一番早いのですが、その本人を探す道具がまだありません。 -->

---

## 結論

**git blame で「その行を最後に変えたコミットと人」を調べられる**

- 行ごとに「ハッシュ・名前・日時」が表示される
- 責めるためでなく、いきさつを知って相談するための道具

<!-- ノート: blameは「責める」という物騒な名前ですが、実際は経緯調査の道具です。使い方の心得も一言添えます。 -->

---

## 最小の例

```bash
git blame price.txt
# a1b2c3d (佐藤花子 2026-08-18) コーヒー 450円
# 9e8f7a6 (佐藤花子 2026-08-10) 紅茶
```

- 出てきたハッシュを `git show` で調べれば理由まで追える

<!-- ノート: 各行の左に、その行を最後に変えたコミットの情報が付きます。ハッシュをshowに渡せばメッセージと差分まで読めます。 -->

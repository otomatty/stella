# 4-1-2
# --onelineで一覧する

Git入門 — Module 4 / レッスン4-1

<!-- ノート: git log の表示を1行に圧縮するオプションを1つだけ覚えます。実務で一番よく打つ形です。 -->

---

## なぜ必要か

- git log は1コミットに数行を使う、詳しい表示
- コミットが増えると、全体の流れを見渡すには長すぎる
- 「最近の10件をざっと眺めたい」ときに向く表示が欲しい

<!-- ノート: 詳細表示は数件見るには良いのですが、20件30件になると流れが追えません。一覧向けの表示に切り替えます。 -->

---

## 結論

**git log --oneline で、1行1コミットの一覧になる**

- 各行は「短いハッシュ + コミットメッセージ」
- 全体の流れをざっと見渡す用途に向く

<!-- ノート: onelineは「1行」の意味です。ハッシュは先頭7文字ほどに短縮されますが、コミットを指す目印としてそのまま使えます。 -->

---

## 最小の例

```bash
git log --oneline
# a1b2c3d 価格表に単価を追記
# 9e8f7a6 価格表を作成
# 4d5e6f7 日報のひな形を追加
```

- 並び順は git log と同じで、一番上が最新

<!-- ノート: 1行1コミットなので、画面1枚で数十件を見渡せます。メッセージを丁寧に書いてきた効果が、この一覧で表れます。 -->

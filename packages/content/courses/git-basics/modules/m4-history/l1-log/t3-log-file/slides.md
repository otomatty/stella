# 4-1-3
# ファイルで絞る

Git入門研修 — Module 4 / レッスン4-1

<!-- ノート: 履歴を「特定のファイルだけ」に絞り込む方法です。コマンドの後ろにファイル名を足すだけです。 -->

---

## なぜ必要か

- 履歴にはいろいろなファイルへの変更が混ざって並ぶ
- 「この価格表、最後に直したのはいつ?」を知りたいことがある
- 全部の履歴から目で探すのは、件数が増えるほどつらい

<!-- ノート: 実務では「このファイルのいきさつだけ知りたい」場面が頻繁にあります。目視で探すのではなく、絞り込ませます。 -->

---

## 結論

**git log ファイル名 で、そのファイルの履歴だけに絞れる**

- そのファイルを変えたコミットだけが表示される
- ほかのファイルだけを変えたコミットは出てこない

<!-- ノート: log の後ろにファイル名を添えるだけです。対象を後ろに書いて絞り込む形は、この先もいろいろなコマンドで登場します。 -->

---

## 最小の例

```bash
git log price.txt
# commit a1b2c3d...
#     価格表に単価を追記
# commit 9e8f7a6...
#     価格表を作成
```

- 日報など、price.txt に関係ないコミットは表示されない

<!-- ノート: 全履歴には日報やメモの変更も並んでいますが、price.txtを変えたコミットだけに絞られています。 -->

---

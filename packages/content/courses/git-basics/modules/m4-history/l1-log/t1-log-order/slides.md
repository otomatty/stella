# 4-1-1
# logは新しい順

Git入門 — Module 4 / レッスン4-1

<!-- ノート: ここからは、積み上げてきた履歴を「読む」モジュールです。最初は git log の表示順という基本を1つだけ押さえます。 -->

---

## なぜ必要か

- コミットを重ねると、履歴は何十件にも育っていく
- 「さっき何をコミットした?」「先週は何をした?」を確かめたい
- そのとき、画面のどこを見れば最新なのかを知っておきたい

<!-- ノート: 履歴は記録するだけでは価値が出ません。読み返せてはじめて役に立ちます。まず表示の並び順から確認します。 -->

---

## 結論

**git log は履歴を新しい順に表示する**

- 一番上が最新のコミット
- 下へ読み進めるほど、過去へさかのぼる

<!-- ノート: 新聞の最新ニュースが1面に来るのと同じで、直近の仕事ほど確認したい頻度が高いからこの順です。上が最新、と体で覚えます。 -->

---

## 最小の例

```bash
git log
# commit a1b2c3d...   ← 一番上が最新
#     価格表に単価を追記
# commit 9e8f7a6...
#     価格表を作成
```

- 表示が長いときは `q` キーで一覧から抜けられる

<!-- ノート: 出力は上から新しい順に並びます。件数が多いとスクロール画面になるので、qで抜けることも一緒に伝えます。 -->

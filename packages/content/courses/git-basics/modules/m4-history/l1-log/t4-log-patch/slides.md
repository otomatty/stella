# 4-1-4
# -pで差分ごと読む

Git入門 — Module 4 / レッスン4-1

<!-- ノート: レッスン4-1の締めくくりです。履歴を、メッセージだけでなく変更内容ごと読む方法を覚えます。 -->

---

## なぜ必要か

- log で分かるのは、いつ・誰が・何のためのコミットか
- 「実際にどの行が変わったのか」まではメッセージに書き切れない
- diff の形で、過去のコミットの中身も読みたい

<!-- ノート: メッセージは要約なので、細部は本文である差分を見るしかありません。作業中の diff と同じ形で過去も読めます。 -->

---

## 結論

**git log -p で、各コミットの差分も一緒に読める**

- 各コミットの下に、そのコミットの差分が続けて表示される
- `+` が追加された行、`-` が削除された行

<!-- ノート: -p は patch(差分)の頭文字です。diff の読み方がそのまま通用します。履歴を精読したいときの表示です。 -->

---

## 最小の例

```bash
git log -p
# commit a1b2c3d...
#     価格表に単価を追記
#
# -コーヒー
# +コーヒー 450円
```

- 長くなりがちなので、`q` キーで途中で抜けてよい

<!-- ノート: メッセージのすぐ下に差分が並びます。全コミット分が続くのでかなり長くなります。qで抜けられれば安心です。 -->

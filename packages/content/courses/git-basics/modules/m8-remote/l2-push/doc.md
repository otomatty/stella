# レッスン8-2 push

## このレッスンの目標

- [ ] git push で手元のコミットをリモートへ送れる
- [ ] 新しいブランチの初回だけ -u が要る理由を説明できる
- [ ] push で送られるのがコミットだけであること、認証が要ることを説明できる

## 8-2-1 git pushで送る

> **git push で、手元のコミットをリモートへ送る**

手元でいくらコミットを積んでも、リモートには1つも反映されていません。GitHub のページを開いても、自分の変更はまだどこにも見えません。手元とリモートは別のリポジトリだからです。

手元に増えた分をリモートへ送るのが **push**(押し出す)です。

```bash
git push
```

```text
To https://github.com/sato-dev/daily-report.git
   a1b2c3d..e4f5a6b  main -> main
```

- `main -> main` は「手元の main をリモートの main へ」という意味です
- push した時点で、チームの全員がそのコミットを受け取れるようになります

実行後に GitHub のリポジトリページを開き直すと、自分のコミットが表示されます。「送って初めて共有が成立する」が push の要点です。

## 8-2-2 初回は-uで紐づける

> **新しいブランチの初回は git push -u origin 枝名 で紐づける**

手元で新しく作ったブランチは、リモートのどの枝に対応するかがまだ決まっていません。そのまま `git push` すると「送り先が分からない」と止められます。

初回だけ、送り先を教えながら push します。

```bash
git push -u origin fix-typo
```

```text
 * [new branch]      fix-typo -> fix-typo
```

- `-u` は「このブランチの送り先はここ」と Git に覚えさせるオプションです
- リモートに `fix-typo` 枝が新しく作られ、紐づけも済みます
- 紐づけは初回の1回だけ。2回目からは `git push` だけで届きます

なお、clone でできた main は最初からリモートの main に紐づいているので、`-u` は不要です。`-u` が要るのは「手元で新しく作ったブランチの初回」だけと覚えましょう。

## 8-2-3 送られるのはコミットだけ

> **push が送るのはコミットだけ(保存や add では届かない)**

「直したのに、リモートに反映されていない」という相談は現場で絶えません。原因の多くは、直した内容がまだコミットになっていないことです。

push は「コミットの列」をリモートへ運ぶ道具です。コミットになっていない変更は、push しても運ばれません。

```text
編集して保存する   → まだ手元のファイルだけ
git add           → まだ下書きに載せただけ
git commit        → 記録になった。でもまだ手元だけ
git push          → ここで初めてリモートに届く
```

反映されないと感じたら、まず `git status` で「commit まで済んでいるか」を確かめましょう。編集 → add → commit → push までがワンセットです。

## 8-2-4 pushには認証が要る

> **GitHub への push は本人確認が要る(パスワードではなくトークンやSSH鍵)**

リモートは共有の置き場です。誰でも書き込めたら大事故になるため、GitHub は push してきた相手が本人かどうかを必ず確かめます。この本人確認を **認証** と呼びます。

注意したいのは、GitHub のログインパスワードでは push できないことです。

```text
Password: (GitHubのログインパスワードを入力)
remote: Support for password authentication was removed.
fatal: Authentication failed
```

認証の手段は主に2つです。

| 手段 | 中身 |
| --- | --- |
| **トークン** | GitHub に発行してもらう長い合言葉。パスワード入力欄にはこれを貼る |
| **SSH** 鍵 | PCに作った鍵ペアで本人確認する方式。一度設定すれば入力は不要 |

どちらを使うかは現場のルールに従ってください。一度設定すれば毎回聞かれることはありません。認証で止まっても壊れたわけではなく、本人確認が済んでいないだけです。

# 8-2-3
# 送られるのはコミットだけ

Git入門研修 — Module 8 / レッスン8-2

<!-- ノート: 「pushしたのに反映されていない」という定番の問い合わせを、仕組みで防ぐトピックです。 -->

---

## なぜ必要か

- 「直したのに、リモートに反映されていない」という相談が現場で絶えない
- 原因の多くは、直した内容がまだコミットになっていないこと

<!-- ノート: エディタで保存した=共有された、と思い込みやすい。どの段階の変更が送られるのかを確かめます。 -->

---

## 結論

**push が送るのはコミットだけ(保存や add では届かない)**

- push は「コミットの列」をリモートへ運ぶ道具
- コミットになっていない変更は、push しても運ばれない

<!-- ノート: 運送屋は箱しか運ばない。箱詰め(コミット)まで済ませたものだけがリモートに届きます。 -->

---

## よくある間違い

```text
編集して保存する   → まだ手元のファイルだけ
git add           → まだ下書きに載せただけ
git commit        → 記録になった。でもまだ手元だけ
git push          → ここで初めてリモートに届く
```

- 反映されないときは、commit まで済んでいるかを疑う

<!-- ノート: 4段の流れを指差しで。どこで止まっているかをstatusで確かめる習慣と組み合わせると強いです。 -->

# 8-2-1
# git pushで送る

Git入門研修 — Module 8 / レッスン8-2

<!-- ノート: 共有の中心となるコマンドです。手元に積んだコミットを、ついにチームへ届けます。 -->

---

## なぜ必要か

- 手元でコミットを積んでも、リモートには1つも反映されていない
- GitHub を開いても、自分の変更はまだどこにも見えない

<!-- ノート: コミットしたのにGitHubに出てこない、は初学者が最初に戸惑うところ。手元とリモートは別物だからです。 -->

---

## 結論

**git push で、手元のコミットをリモートへ送る**

- push は「押し出す」。手元に増えた分をリモートへ押し出す
- 送った時点で、チームの全員がそのコミットを受け取れるようになる

<!-- ノート: 手元の履歴とリモートの履歴の差分を送り届けるのがpush。送って初めて共有が成立します。 -->

---

## 最小の例

```bash
git push
# To https://github.com/sato-dev/daily-report.git
#    a1b2c3d..e4f5a6b  main -> main
```

- main -> main は「手元の main をリモートの main へ」という意味

<!-- ノート: 矢印の左が手元、右がリモート。実行後にGitHubのページを開き直すと、自分のコミットが見えます。 -->

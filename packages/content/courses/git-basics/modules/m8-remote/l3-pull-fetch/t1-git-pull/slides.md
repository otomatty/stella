# 8-3-1
# git pullで取り込む

Git入門研修 — Module 8 / レッスン8-3

<!-- ノート: pushの逆方向です。チームの変更を自分の手元に取り込む、毎朝打つことになるコマンドです。 -->

---

## なぜ必要か

- 自分が push する間に、同僚もリモートへ push している
- リモートに増えた分を受け取らないと、手元がどんどん古くなる

<!-- ノート: 共有は送るだけでは片手落ち。受け取る手段がないと、古い状態の上で作業を続けてしまいます。 -->

---

## 結論

**git pull で、リモートに増えたコミットを手元へ取り込む**

- pull は「引き寄せる」。リモートに増えた分を手元へ引き込む
- 作業を始める前に pull する習慣で、手元を最新に保つ

<!-- ノート: pushが押し出す、pullが引き寄せる。対になる2つで、リモートとのやり取りは完成します。 -->

---

## 最小の例

```bash
git pull
# Updating a1b2c3d..e4f5a6b
# Fast-forward
#  README.md | 2 ++
```

- 同僚が README.md に加えた2行が、手元にも反映された

<!-- ノート: Fast-forwardはマージのモジュールで学んだ、付箋が先へ進むだけの取り込み。pullの表示にも出てきます。 -->

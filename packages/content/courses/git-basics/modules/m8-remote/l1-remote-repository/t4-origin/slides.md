# 8-1-4
# originは呼び名

Git入門研修 — Module 8 / レッスン8-1

<!-- ノート: これから何度も目にするoriginという単語の正体を、ここで押さえます。 -->

---

## なぜ必要か

- リモートを指すたびに、あの長い URL を打つのは大変すぎる
- Git の画面表示にも origin という単語が頻繁に出てくる

<!-- ノート: URLを毎回タイプするのは現実的でない。だから短い呼び名で済ませる仕組みがある、という流れです。 -->

---

## 結論

**origin は clone 元のリモートに自動で付く呼び名**

- clone すると、Git が自動で付けてくれる(自分で設定しなくてよい)
- 以後は URL の代わりに origin と書けば伝わる

<!-- ノート: originは特別な機能名ではなく、ただのあだ名。自動で付くので、見かけても身構えなくてよいと伝えます。 -->

---

## 最小の例

```text
origin = https://github.com/sato-dev/daily-report.git

「origin へ送る」= この URL のリモートへ送る、という意味
```

- 連絡先に登録した「会社」の宛先のようなもの

<!-- ノート: スマホの連絡先のたとえが通じやすい。番号を暗記せず名前で呼ぶのと同じことをGitがやっています。 -->

---

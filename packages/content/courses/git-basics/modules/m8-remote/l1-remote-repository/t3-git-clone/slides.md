# 8-1-3
# git cloneでコピーする

Git入門 — Module 8 / レッスン8-1

<!-- ノート: リモートと手元を繋ぐ最初のコマンドです。現場に配属されて最初に打つのも、たいていこのコマンドです。 -->

---

## なぜ必要か

- リモートにあるリポジトリを、自分のPCでも触れるようにしたい
- 現場では「まずプロジェクトを手元に持ってくる」ことから仕事が始まる

<!-- ノート: 配属初日のあるある。リポジトリのURLだけ渡されて「持ってきて」と言われる場面を想像してもらう。 -->

---

## 結論

**git clone URL で、リモートを履歴ごと手元にコピーできる**

- ファイルの最新版だけでなく、過去の履歴もまるごと手に入る
- コピー先として、リポジトリ名のフォルダが自動で作られる

<!-- ノート: cloneは複製という意味。最新のファイルだけでなく履歴ごと、というのが分散型のGitらしいところです。 -->

---

## 最小の例

```bash
git clone https://github.com/sato-dev/daily-report.git
# Cloning into 'daily-report'...
cd daily-report
```

- clone した後は cd で中に入ってから作業する

<!-- ノート: URLは前のトピックでコピーしたもの。daily-reportフォルダができるので、cdで入るところまでがワンセットです。 -->

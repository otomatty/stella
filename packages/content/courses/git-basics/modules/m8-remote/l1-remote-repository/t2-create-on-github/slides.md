# 8-1-2
# GitHubでリポジトリを作る

Git入門 — Module 8 / レッスン8-1

<!-- ノート: リモートの置き場をGitHub上に実際に用意する手順です。画面操作は少しだけで、覚えるのは1つです。 -->

---

## なぜ必要か

- リモートを使うには、まず GitHub 上に置き場を用意する必要がある
- 用意した置き場を Git に教えるための「住所」も要る

<!-- ノート: 置き場と住所。この2つが揃って初めて、手元のGitとGitHubが繋がります。 -->

---

## 結論

**GitHub で空のリポジトリを作ると、共有用の URL が手に入る**

- URL はそのリポジトリのインターネット上の住所
- 以後の共有の操作は、この URL を通して行う

<!-- ノート: URLという語をここで定義する。作る操作そのものより、URLが手に入ることがこのトピックの覚えどころです。 -->

---

## 最小の例

```text
1. GitHub にログインし「New repository」を選ぶ
2. リポジトリ名(例: daily-report)を入力して作成
3. 表示された URL をコピーする
   https://github.com/sato-dev/daily-report.git
```

- 画面の説明どおりに進めば数十秒で終わる

<!-- ノート: 手順は3ステップだけ。URLの末尾が .git で終わる形をここで見せておくと、次のトピックで迷いません。 -->

# 8-1-1
# リモートは共有の置き場

Git入門研修 — Module 8 / レッスン8-1

<!-- ノート: ここから共有のモジュールです。コミットもブランチもマージも、これまでは全部自分のPCの中だけの話でした。 -->

---

## なぜ必要か

- これまでのコミットは、すべて自分のPCの中に積まれている
- このままではチームに見せられないし、PCが壊れたら履歴ごと消える

<!-- ノート: 手元だけの履歴の限界を突く。共有と保険の2つの困りごとを、1つの置き場が解決します。 -->

---

## 結論

**リモートリポジトリは、共有のために GitHub 上に置くもう1つのリポジトリ**

- 手元のリポジトリとは別に、チームで見える場所にもう1つ置く
- 略して **リモート** と呼ぶ

<!-- ノート: リモートという語をここで定義する。中身は今まで学んだリポジトリと同じで、置き場所がGitHub上というだけです。 -->

---

## 最小の例

```text
佐藤のPCのリポジトリ ─┐
                      ├─ リモートリポジトリ(GitHub上)
田中のPCのリポジトリ ─┘
```

- 全員がリモートを経由してコミットをやり取りする

<!-- ノート: ハブの絵を言葉で。メンバーどうしが直接やり取りするのではなく、真ん中のリモートを介するのがポイントです。 -->

---

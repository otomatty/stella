# 5-1-3
# --stagedでaddを取り消す

Git入門 — Module 5 / レッスン5-1

<!-- ノート: 今度は「編集は残したい、addだけ取り消したい」場面のやり直しです。 -->

---

## なぜ必要か

- 関係ないファイルまでまとめて add してしまった
- 編集そのものは消したくない。次のコミットから外したいだけ

<!-- ノート: add . で余計なファイルまで載せてしまうのはよくある事故です。編集を守ったまま載せ直したい、が今回の困りごとです。 -->

---

## 結論

**git restore --staged で add だけを取り消す(ファイルの中身は変わらない)**

- ステージングエリア(次のコミットの下書き)から降ろすだけ
- ファイル名だけの restore(編集を捨てる)とは効果が別物

<!-- ノート: --stagedが付くと対象がステージングエリアに変わります。作業中のファイルには一切触りません。 -->

---

## 最小の例

```bash
git add 価格表.md            # 間違えて載せてしまった
git restore --staged 価格表.md
# → 次のコミットから外れる。編集した中身はそのまま
```

- 落ち着いて選び直してから、必要なものだけ add し直せばよい

<!-- ノート: 載せる→降ろす→選び直す、の流れです。編集が消えないことを強調してください。 -->

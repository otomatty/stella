# 5-1-1
# git restoreで戻す

Git入門研修 — Module 5 / レッスン5-1

<!-- ノート: 「やり直す」モジュールの最初のトピックです。まずはコミット前の編集を捨てて戻す方法を1つだけ覚えます。 -->

---

## なぜ必要か

- 直しているうちに、動いていたファイルをぐちゃぐちゃにしてしまった
- まだコミットしていないので、「最後の正常な状態」へ手作業で戻すしかない?

<!-- ノート: 編集して壊す事故は誰にでも起きます。Ctrl+Zで少しずつ戻すのは限界がある、という困りごとから入ります。 -->

---

## 結論

**git restore ファイル名 で、作業中の変更を捨てて最後のコミットに戻せる**

- 戻り先は「そのファイルを最後にコミットした状態」
- 消えるのはコミット前の編集だけ。履歴は変わらない

<!-- ノート: restoreは「作業中の編集を捨てて、最後の記録に合わせ直す」コマンドです。履歴そのものには触りません。 -->

---

## 最小の例

```bash
# 日報.md を編集して壊してしまった(まだコミットしていない)
git restore 日報.md
# → 日報.md が最後にコミットした内容に戻る
```

- 指定したファイルだけが戻る。他のファイルには触らない

<!-- ノート: ファイル名を指定するのがポイントです。壊したファイルだけを狙って、最後のコミットの内容に置き換えます。 -->

# 5-2-1
# --amendで作り直す

Git入門 — Module 5 / レッスン5-2

<!-- ノート: このレッスンでは「コミットした直後のやり直し」を扱います。まずはコマンドから覚えます。 -->

---

## なぜ必要か

- コミットした直後に、コミットメッセージの誤字に気づいた
- 一緒に入れるはずのファイルを add し忘れたまま記録してしまった

<!-- ノート: コミット直後の「あっ」は誰にでもあります。誤字コミットをもう1つ積むのも格好が悪い、という場面です。 -->

---

## 結論

**git commit --amend で、直前のコミットを作り直せる(メッセージ修正・入れ忘れ)**

- 修正版で置き換えた1つのコミットになる(記録は増えない)
- 入れ忘れたファイルは add してから --amend すれば一緒になる

<!-- ノート: amendは英語で「修正する」。直前のコミットだけが対象で、それより古いコミットには使えません。 -->

---

## 最小の例

```bash
git commit -m "日報を追加w"        # 誤字に気づいた
git commit --amend -m "日報を追加"
# → 直前のコミットが正しいメッセージで作り直される
```

- コミットの数は増えず、直前の1つがきれいになる

<!-- ノート: 誤字修正の最短パターンです。-mと組み合わせて、新しいメッセージで作り直しています。 -->

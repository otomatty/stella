# 5-3-1
# git revertで打ち消す

Git入門 — Module 5 / レッスン5-3

<!-- ノート: コミット済みの変更を取り消す方法です。この研修での取り消しの主役になるコマンドを覚えます。 -->

---

## なぜ必要か

- コミットしてしまった変更を、後から取り消したくなった
- そのコミットはもう履歴に積まれている。どう無かったことにする?

<!-- ノート: コミット前のやり直しとは状況が違います。すでに記録として積まれたものをどう扱うか、が今回の問いです。 -->

---

## 結論

**git revert ID は「反対の変更」を新しいコミットとして積む**

- 行を足したコミットなら、その行を消すコミットが新しくできる
- 元のコミットはそのまま残り、記録が1つ増えるだけ

<!-- ノート: 消すのではなく、打ち消しの変更を上から積む。差し引きゼロにして無かったことにする発想です。 -->

---

## 最小の例

```bash
git revert a1b2c3d
# 履歴(新しい順):
#   f9e8d7c Revert "価格表を更新"   ← 反対の変更が積まれた
#   a1b2c3d 価格表を更新            ← 元のコミットは残ったまま
```

- ID は打ち消したいコミットのもの(先頭7桁でよい)

<!-- ノート: revertの後にはRevertで始まるコミットが自動で増えます。元のコミットが消えていない点に注目させてください。 -->

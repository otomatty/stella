# 9-1-4
# 説明には何を・なぜ

Git入門研修 — Module 9 / レッスン9-1

<!-- ノート: レッスン9-1の最後は、PRを開くときに書くタイトルと説明欄の話です。何を書けばレビューが速く進むかを押さえます。 -->

---

## なぜ必要か

- PR を開くと、タイトルと説明を書く欄が出てくる
- 空欄や「修正しました」だけでは、見る側は差分の意図が分からない
- 何を書けばレビューがすぐ始まるか?

<!-- ノート: 説明のないPRは、レビューする人が差分から意図を推理するはめになります。その時間はまるごと無駄です。 -->

---

## 結論

**タイトルと説明には「何を・なぜ」を書く(どう変えたかは差分が語る)**

- 「どう変えたか」は差分を見れば分かるので、書かなくてよい
- コミットメッセージと同じ考え方を、PR 全体に当てはめる

<!-- ノート: 差分に写っていないのは目的と背景だけです。だから人間が書くのは「何を・なぜ」に絞る、という役割分担です。 -->

---

## 最小の例

```text
タイトル: 会員一覧の並び順を五十音順に修正

説明:
何を: 会員一覧の並び順を、登録順から五十音順に変更
なぜ: 営業チームから「目的の会員を探しにくい」と要望があったため
```

<!-- ノート: この2行があるだけで、レビューする人は「要望対応として妥当か」という観点で差分を読めるようになります。 -->

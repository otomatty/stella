# 9-2-4
# コメントには全部返事

Git入門 — Module 9 / レッスン9-2

<!-- ノート: レビューのレッスンの最後は、コメントをもらった側の返事の作法です。地味ですが信頼に直結する習慣です。 -->

---

## なぜ必要か

- 指摘どおり直して push した。それで終わりにしていい?
- 返事のないコメントは、見た側から「読まれたのか」すら分からない
- 直さないと決めた指摘は、黙っていていいのか?

<!-- ノート: 修正pushだけして無言、は本当によくあります。相手の画面では、コメントが放置されたままに見えています。 -->

---

## 結論

**もらったコメントには全部返事をする(直した/直さない理由)**

- 直したら「直しました」、直さないなら「理由」を書く
- 返事がそろって初めて、レビューのやりとりが完了する

<!-- ノート: 返事は長文でなくてかまいません。全コメントに応答が付いている状態が、やりとりの完了条件だと覚えてもらいます。 -->

---

## 最小の例

```text
「修正しました」                          ← 直した場合
「ここは既存の表記に合わせているため、
  今回はこのままにします」                ← 直さない場合
「この指摘の意図を教えてください」        ← 分からない場合
```

- 無言で直す・無言で無視、の2つだけは避ける

<!-- ノート: 直さない自由はありますが、理由を添えるのが条件です。分からなければ質問で返すのも立派な返事です。 -->

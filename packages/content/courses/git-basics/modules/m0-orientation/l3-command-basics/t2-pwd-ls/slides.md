# 今いる場所を確かめる

Git入門研修 — Module 0 / レッスン0-3

<!-- ノート: ターミナルで最初に覚えるのは、操作ではなく「現在地の確認」です。コマンドを2つ導入します。 -->

---

## なぜ必要か

- ターミナルには「今開いているフォルダ」があるが、画面からは分かりにくい
- 場所を勘違いしたまま作業すると、別のフォルダを触ってしまう

<!-- ノート: エクスプローラーと違って、ターミナルは現在地が一目では見えない。だから確認のコマンドが要る、という動機付けです。 -->

---

## 結論

**pwd と ls で「今どこに居て、何があるか」を確かめる**

- `pwd`: 今いるフォルダの場所を表示する
- `ls`: 今いるフォルダの中身を一覧する

<!-- ノート: pwdが現在地、lsが持ち物確認。迷子にならないためのセットとして、2つまとめて手癖にします。 -->

---

## 最小の例

```bash
pwd
# /Users/sato/git-practice   ← 今ここに居る
ls
# 企画書.md  価格表.xlsx     ← ここにあるファイル
```

- 思っていた場所・中身と違ったら、作業を始める前に気づける

<!-- ノート: 出力例ごと読む。作業フォルダに居るつもりが違った、という事故はこの2つを打つだけで防げます。 -->

# Gitはターミナルで操作する

Git入門 — Module 0 / レッスン0-3

<!-- ノート: このレッスンでは、Gitを触る前の最後の準備として、操作の入口になる画面と言葉を覚えます。 -->

---

## なぜ必要か

- Gitを入れても、アイコンやメニューが並んだ専用画面は出てこない
- 「どこから操作するのか」が分からず、最初の一歩で止まりがち

<!-- ノート: 未経験者が最初に戸惑うのは操作の入口。ボタンを探しても見つからない、から始めます。 -->

---

## 結論

**Gitはターミナルに打つコマンドで操作する(GUIも裏では同じコマンド)**

- **ターミナル**: 文字で指示を打ち、文字で結果が返る画面
- **コマンド**: そこに打ち込む1行の指示

<!-- ノート: ターミナルとコマンドをここで定義する。マウス操作のGitツールも、裏では同じコマンドを実行しているだけです。 -->

---

## 最小の例

```text
ターミナルの開き方の例:
  VS Code   … メニューの「表示」→「ターミナル」
  Mac       … 「ターミナル」アプリ
  Windows   … 「PowerShell」
```

- この研修では、VS Codeの中のターミナルを使って進める

<!-- ノート: 入口さえ分かれば怖くない。以降のハンズオンはすべてVS Codeのターミナルでそのまま試せます。 -->

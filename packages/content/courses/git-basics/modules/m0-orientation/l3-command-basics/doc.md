# レッスン0-3 コマンド操作の基礎

## このレッスンの目標

- [ ] ターミナルとコマンドが何かを説明できる
- [ ] pwd・ls・cd で現在地の確認とフォルダの移動ができる
- [ ] コマンドを「git+動詞+対象+オプション」の形に分解して読める

## 0-3-1 Gitはターミナルで操作する

> **Gitはターミナルに打つコマンドで操作する(GUIも裏では同じコマンド)**

Git をPCに入れても、アイコンやメニューが並んだ専用画面は出てきません。最初に戸惑うのはここです。操作の入口は **ターミナル** という画面です。

- **ターミナル**: 文字で指示を打ち、文字で結果が返ってくる画面
- **コマンド**: そこに打ち込む1行の指示

ターミナルの開き方はいくつかあります。

```text
VS Code   … メニューの「表示」→「ターミナル」
Mac       … 「ターミナル」アプリ
Windows   … 「PowerShell」
```

この研修では、VS Code の中のターミナルを使って進めます。エディタと同じ画面で完結するので、行き来が楽です。

マウスで操作できる Git のツールもありますが、それらも裏では同じコマンドを実行しているだけです。コマンドの意味を先に覚えておけば、どのツールに出会っても応用が利きます。

## 0-3-2 今いる場所を確かめる

> **pwd と ls で「今どこに居て、何があるか」を確かめる**

ターミナルには「今開いているフォルダ」という現在地があります。エクスプローラーと違って画面からは分かりにくいため、場所を勘違いしたまま別のフォルダを触ってしまう事故が起きがちです。

そこで最初に覚えるのは、操作ではなく確認のコマンド2つです。

- `pwd`: 今いるフォルダの場所を表示する(print working directory)
- `ls`: 今いるフォルダの中身を一覧する(list)

```bash
pwd
# /Users/sato/git-practice   ← 今ここに居る
ls
# 企画書.md  価格表.xlsx     ← ここにあるファイル
```

pwd が現在地、ls が持ち物確認です。思っていた場所・中身と違ったら、作業を始める前に気づけます。迷ったらまずこの2つ、を手癖にしましょう。

## 0-3-3 フォルダを移動する

> **cd でフォルダを移動してから git コマンドを打つ**

Git への指示は「今いるフォルダ」に対して働きます。目的の作業フォルダの外で打っても、思った場所には効きません。だからコマンドを打つ前に、正しい場所へ移動しておく必要があります。

移動のコマンドが `cd`(change directory)です。

```bash
cd git-practice
pwd
# /Users/sato/git-practice   ← 移動できた
```

- `cd フォルダ名` で、そのフォルダの中へ移動する
- `cd ..` で、1つ上のフォルダへ戻る

基本の型は「cd で移動 → pwd で確認 → git を打つ」です。移動したら pwd で着いたことを確かめてから本題に入る。この型を守るだけで、場所の勘違いによる事故はほぼ防げます。

## 0-3-4 コマンドの読み方

> **コマンドは「git+動詞+対象+オプション」の形で読める**

この先の研修では、たくさんの git コマンドが登場します。1つずつ丸暗記しようとするとすぐ限界が来ます。そこで、個々のコマンドの前に共通の「形」を覚えます。

```text
git  <動詞>  <対象>  <オプション>

git         … Gitへの指示の合図(先頭に必ず付く)
<動詞>      … 何をするか
<対象>      … どのファイル・フォルダに
<オプション> … どのように(- で始まる細かい指定)
```

- **オプション**: 動きを細かく指定する追加の指示(多くは `-` で始まる)
- 対象やオプションは、コマンドによっては省略される

英文法のように、形を1つ知れば初見のコマンドも読めるようになります。次のモジュールから具体的なコマンドが出てくるたびに、「どれが動詞で、どれが対象で、どれがオプションか」を分解して読む習慣をつけましょう。

最後に、この研修全体でのターミナルの使い方を1つ決めておきます。**ターミナルで打つのは git コマンドと移動(cd)だけ**にし、**ファイルの作成・編集・削除は VS Code のエディタ側で行います**。ターミナルの機能でもファイルは作れますが、環境(特に Windows)によって文字コードの問題が起きやすいためです。以降のハンズオンもすべてこの分担で書かれています。

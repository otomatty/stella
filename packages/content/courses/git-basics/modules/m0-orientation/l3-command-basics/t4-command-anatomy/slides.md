## なぜ必要か

- この先の研修では、たくさんのgitコマンドが登場する
- 1つずつ丸暗記しようとすると、すぐに限界が来る

<!-- ノート: 暗記ではなく読解で乗り切る、が今回の狙い。英文法のように、形を1つ知れば応用が利きます。 -->

---

## 結論

**コマンドは「git+動詞+対象+オプション」の形で読める**

- **オプション**: 動きを細かく指定する追加の指示(多くは `-` で始まる)
- 対象やオプションは、コマンドによっては省略される

<!-- ノート: オプションをここで定義する。4つの部品に切って読む、が今後ずっと使う読み方です。 -->

---

## 最小の例

```text
git  <動詞>  <対象>  <オプション>

git         … Gitへの指示の合図(先頭に必ず付く)
<動詞>      … 何をするか
<対象>      … どのファイル・フォルダに
<オプション> … どのように(- で始まる細かい指定)
```

<!-- ノート: 具体的なコマンドは次のモジュールから登場します。出てくるたびに、この4部品のどれに当たるかを指差しで確認していきます。 -->

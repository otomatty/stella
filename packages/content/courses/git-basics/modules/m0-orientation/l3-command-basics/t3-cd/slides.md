# 0-3-3
# フォルダを移動する

Git入門 — Module 0 / レッスン0-3

<!-- ノート: 現在地の確認の次は移動です。gitコマンドを打つ前の型として覚えます。 -->

---

## なぜ必要か

- Gitへの指示は「今いるフォルダ」に対して働く
- 目的の作業フォルダの外で打っても、思った場所には効かない

<!-- ノート: コマンドは現在地基準で動く、が今回の前提。だから打つ前に正しい場所へ移動しておく必要があります。 -->

---

## 結論

**cd でフォルダを移動してから git コマンドを打つ**

- `cd フォルダ名` で、そのフォルダの中へ移動する
- 「cd で移動 → pwd で確認 → git を打つ」が基本の型

<!-- ノート: cdはchange directoryの略。移動したら pwd で着いたことを確かめてから本題に入る、を型として繰り返します。 -->

---

## 最小の例

```bash
cd git-practice
pwd
# /Users/sato/git-practice   ← 移動できた
```

- `cd ..` と打つと、1つ上のフォルダへ戻れる

<!-- ノート: 移動して確認、までで1セット。戻り方(cd ..)も一緒に覚えておくと迷子になりません。 -->

# レッスン0-3 演習 — コマンド操作の基礎

対象トピック: 0-3-1 〜 0-3-4

このレッスンから、実際にターミナルでコマンドを打ちます。git コマンドはまだ使いません。

## ハンズオン

手元の VS Code のターミナルで、現在地の確認と移動を一通り試します。以降のレッスンで使う練習用フォルダもここで作ります。

1. VS Code を開き、メニューの「表示」→「ターミナル」でターミナルを開いてください
2. `pwd` と打って Enter を押し、今いるフォルダの場所を確かめてください
3. `ls` と打って、今いるフォルダの中身を一覧してください
4. 練習用フォルダを作ります。`mkdir git-practice` と打ってください(mkdir はフォルダを作るコマンドです。Git の一部ではなく、ここでだけ使います)
5. `ls` で、`git-practice` が増えたことを確かめてください
6. `cd git-practice` で移動し、`pwd` で場所が変わったことを確かめてください
7. `ls` を打つと何も表示されません(空のフォルダなので正常です)
8. VS Code で `git-practice` フォルダの中に `practice.txt` という空のファイルを作り、もう一度 `ls` で表示されることを確かめてください
9. `cd ..` で1つ上に戻り、`pwd` で戻れたことを確かめてください

「pwd で現在地 → ls で中身 → cd で移動」が手癖になれば合格です。`git-practice` フォルダは次のモジュール以降も使うので、消さずに残しておいてください。

## 演習問題

### 問1(基本)

ターミナルを開いた直後に、「今どこに居て、何があるか」を確かめたいです。打つコマンドを2つ、確かめられる内容とセットで答えてください。

### 問2(基本)

`cd git-practice` を実行した後、移動できたことを確かめるには何を打てばよいですか。

### 問3(応用)

同僚が「git のコマンドを打ったのに、目的のフォルダに何も起きない」と困っています。このレッスンの範囲で、最初に確かめるべきことと、その直し方を説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`pwd` で今いるフォルダの場所、`ls` でそのフォルダの中身を確かめます。

pwd が現在地、ls が持ち物確認です。作業を始める前にこの2つを打つと、場所の勘違いに気づけます。

</details>

<details>
<summary>問2の解答例</summary>

`pwd` を打ちます。

表示される場所の末尾が `git-practice` になっていれば、移動できています。「cd で移動 → pwd で確認」までで1セットです。

</details>

<details>
<summary>問3の解答例</summary>

まず `pwd` で「今いるフォルダ」を確かめます。目的のフォルダと違っていたら、`cd 目的のフォルダ名` で移動してから打ち直します。

Git への指示は「今いるフォルダ」に対して働くため、場所が違うと目的のフォルダには効きません。cd で移動してから git コマンドを打つ、が基本の型です。

</details>

## 確認クイズ

### Q1. Gitの操作について正しいものはどれですか。

- A. Git専用のメニュー画面があり、そこからマウスで操作する
- B. ターミナルに打つコマンドで操作する(GUIツールも裏では同じコマンド)
- C. ブラウザでGitのWebサイトを開いて操作する

<details>
<summary>答え</summary>

**B** — Git はターミナルに打つコマンドで操作します。マウスで使える GUI ツールも、裏では同じコマンドを実行しているだけです。

</details>

### Q2. 今いるフォルダの場所を表示するコマンドはどれですか。

- A. pwd
- B. ls
- C. cd

<details>
<summary>答え</summary>

**A** — pwd が現在地の表示です。ls は今いるフォルダの中身の一覧、cd はフォルダの移動に使います。

</details>

### Q3. git-practice フォルダの中へ移動するとき、次に打つコマンドはどれですか。

- A. ls git-practice
- B. pwd git-practice
- C. cd git-practice

<details>
<summary>答え</summary>

**C** — フォルダの移動は cd です。移動したら pwd で着いたことを確かめてから、次の作業に進みます。

</details>

### Q4. コマンドの形「git+動詞+対象+オプション」のうち、「- で始まる、動きを細かく指定する部分」を何と呼びますか。

- A. 対象
- B. オプション
- C. 動詞

<details>
<summary>答え</summary>

**B** — 動きを細かく指定する追加の指示がオプションで、多くは - で始まります。動詞は「何をするか」、対象は「どのファイル・フォルダに」を表します。

</details>

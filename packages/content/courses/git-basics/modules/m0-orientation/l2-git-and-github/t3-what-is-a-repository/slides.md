# リポジトリとは

Git入門 — Module 0 / レッスン0-2

## なぜ必要か

- Gitの解説やエラーの文には「リポジトリ」という語が必ず出てくる
- この語のイメージが無いままだと、この先の説明が全部あいまいになる

<!-- ノート: リポジトリは研修全体で使い続ける最重要語。ここで1回きちんと定義しておくと、以降の説明が短くなります。 -->

---

## 結論

**リポジトリは「作業フォルダ+その履歴」のセット**

- **作業フォルダ** は、ふだんファイルを編集しているフォルダのこと
- そのフォルダをGitに管理させると、履歴が付いてリポジトリになる

<!-- ノート: 特別な場所を新しく作るのではなく、いつものフォルダに履歴が付いたものがリポジトリ、と押さえます。 -->

---

## 最小の例

```text
リポジトリ
├─ 作業フォルダ … いま編集している最新のファイルたち
└─ 履歴       … これまでの記録の積み重ね
```

- 「企画書のリポジトリ」= 企画書のフォルダと、その全記録のセット

<!-- ノート: セットである、が要点。最新のファイルだけでも、記録だけでもなく、両方そろって1つのリポジトリです。 -->

# 0-2-4
# 履歴は.gitフォルダにある

Git入門 — Module 0 / レッスン0-2

<!-- ノート: リポジトリのうち「履歴」の実体がどこにあるのかを押さえます。場所を知ることが事故防止になります。 -->

---

## なぜ必要か

- 履歴はどこに保存されているのか、目に見えないと不安になる
- 場所を知らないまま「不要そうなフォルダ」として消してしまう事故がある

<!-- ノート: 履歴の置き場所は普通に見ても見えない。見えないものは、知らないと守れません。 -->

---

## 結論

**履歴は作業フォルダ直下の .git フォルダに入っている(消すと履歴ごと消える)**

- `.git` は隠しフォルダで、ふだんの画面には表示されないことが多い
- 中身を手で開いて編集する必要はない(触らない)

<!-- ノート: 「.gitを消す = そのリポジトリの履歴が全部消える」を言い切る。逆に、作業フォルダのファイル自体は残ります。 -->

---

## 最小の例

```text
企画書プロジェクト/      ← 作業フォルダ
├── .git/               ← 履歴の保管庫(隠しフォルダ)
├── 企画書.md
└── 価格表.xlsx
```

- ファイルと同じ階層に、履歴の保管庫が同居している

<!-- ノート: 作業フォルダの直下に.gitが1つ、という配置を目に焼き付ける。だからフォルダごと持ち運べば履歴も一緒に付いてきます。 -->

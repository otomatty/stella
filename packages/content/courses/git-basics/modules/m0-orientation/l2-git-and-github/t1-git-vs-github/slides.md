# GitとGitHubは別物

Git入門 — Module 0 / レッスン0-2

<!-- ノート: このレッスンでは、前のレッスンで学んだ「履歴のしくみ」を実現する道具に名前を付けていきます。まずは一番混同されやすい2つの名前からです。 -->

---

## なぜ必要か

- 現場でも求人でも「Git」「GitHub」の2つの名前をセットで聞く
- 名前が似ているので同じものだと思い込むと、会話がかみ合わなくなる

<!-- ノート: 「GitHubなら使ったことあります」「それはGitの話?」というすれ違いは実際によく起きる。まず2つを切り分けます。 -->

---

## 結論

**Gitは履歴を記録する道具、GitHubはそれを共有して共同作業する場所**

- **Git** は自分のPCに入れて使うバージョン管理の道具
- **GitHub** はGitの履歴を置いて共有するWebサービス

<!-- ノート: Gitは手元で動くソフトウェア、GitHubはブラウザで開くサービス、という置き場所の違いで覚えるのが早い。GitHubなしでもGitは使えます。 -->

---

## 最小の例

```text
Git    : 自分のPCで動く。変更を記録して履歴を作る
GitHub : Web上のサービス。履歴を置いて、チームで共有する
```

- この研修の前半はGitだけで進み、共有の回でGitHubが登場する

<!-- ノート: 役割の対比を1行ずつで確認する。学ぶ順番も「まず手元のGit、その後に共有のGitHub」で、この対応関係のとおりです。 -->

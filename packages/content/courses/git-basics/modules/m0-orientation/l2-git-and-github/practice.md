# レッスン0-2 演習 — GitとGitHub

対象トピック: 0-2-1 〜 0-2-4

このレッスンもまだコマンドは打ちません。言葉の整理を確かめる問題が中心です。

## ハンズオン

自分のPCにあるフォルダを1つ思い浮かべて(例: 資料置き場、日報のフォルダ)、次の3つをメモに書き出してみましょう。

1. そのフォルダがリポジトリになったとしたら、「作業フォルダ」に当たるのはどの部分かを書いてください
2. そのフォルダに「履歴」が付いたら何がうれしいかを、前のレッスンの言葉で1つ書いてください
3. その履歴を置いて共有する場所(GitとGitHubのどちらの役割か)を答えてください

「手元のフォルダに履歴が付く」という見方ができれば、このレッスンの準備は完了です。

## 演習問題

### 問1(基本)

次の2つの文の空欄に、Git / GitHub のどちらかを入れてください。

- (ア)は自分のPCで動き、変更を記録して履歴を作る道具
- (イ)は履歴を置いて共有し、共同作業するWebサービス

### 問2(基本)

リポジトリは2つのものの「セット」です。その2つを答えてください。

### 問3(応用)

同僚が「このフォルダ、`.git` という見慣れないフォルダがあるから消しておいたよ」と言いました。何が起きたかと、作業フォルダのファイルがどうなっているかを説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

(ア)Git、(イ)GitHub です。

Git は手元で動くバージョン管理の道具、GitHub はその履歴を共有する場所です。GitHub が無くても Git だけで履歴は作れます。

</details>

<details>
<summary>問2の解答例</summary>

「作業フォルダ」と「その履歴」です。

ふだん編集している最新のファイルたち(作業フォルダ)と、これまでの記録の積み重ね(履歴)がそろって、1つのリポジトリになります。

</details>

<details>
<summary>問3の解答例</summary>

そのリポジトリの履歴が全部消えました。作業フォルダのファイル(最新の状態)自体は残っています。

履歴の実体は作業フォルダ直下の `.git` フォルダに入っているため、これを消すと記録だけがすべて失われます。ただし Git は分散型なので、他の人のPCなどに完全な履歴のコピーが残っていれば、そこから復元できる可能性があります。

</details>

## 確認クイズ

### Q1. GitとGitHubの説明として正しいものはどれですか。

- A. Gitは履歴を記録する道具で、GitHubはそれを共有して共同作業する場所
- B. GitはGitHubの略称で、2つは同じもの
- C. GitはWebサービスで、GitHubは自分のPCに入れる道具

<details>
<summary>答え</summary>

**A** — Git は自分のPCで動くバージョン管理の道具、GitHub は履歴を置いて共有するWebサービスです。名前は似ていますが別物です。

</details>

### Q2. Gitが「分散型」と呼ばれる理由として正しいものはどれですか。

- A. 履歴を細かく分割して、別々のサーバーに保存するから
- B. 全員が完全な履歴のコピーを自分の手元に持つから
- C. 1台のサーバーに全員の履歴を集めて管理するから

<details>
<summary>答え</summary>

**B** — 分散型とは、全員が完全な履歴のコピーを手元に持つしくみのことです。だからネットが無くても作業でき、1か所が失われても復元できます。

</details>

### Q3. リポジトリの説明として正しいものはどれですか。

- A. 作業フォルダとその履歴のセット
- B. GitHubのアカウントのこと
- C. 最新のファイルだけを保存する特別なフォルダ

<details>
<summary>答え</summary>

**A** — リポジトリは「作業フォルダ+その履歴」のセットです。いつものフォルダに履歴が付いたもの、と考えます。

</details>

### Q4. 作業フォルダ直下の .git フォルダを消すとどうなりますか。

- A. 作業フォルダのファイルも含めて、すべて消える
- B. 何も起きない(.gitは使われていない予備のフォルダ)
- C. そのリポジトリの履歴がすべて消える(作業フォルダのファイルは残る)

<details>
<summary>答え</summary>

**C** — 履歴の実体は .git フォルダに入っているため、消すと履歴ごと失われます。最新のファイル自体は作業フォルダに残ります。

</details>

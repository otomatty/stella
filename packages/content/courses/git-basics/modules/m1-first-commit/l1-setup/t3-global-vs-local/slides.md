# globalとローカルの設定

Git入門 — Module 1 / レッスン1-1

<!-- ノート: 前のトピックで設定した名乗りが「どこまで効くのか」を押さえます。 -->

---

## なぜ必要か

- 仕事のPCでは、複数のリポジトリを扱うのが普通
- リポジトリごとに毎回名乗りを設定し直すのは手間だし、忘れる

<!-- ノート: 「毎回設定するの?」という自然な疑問から入ります。答えはまだ言いません。 -->

---

## 結論

**--global はPC全体、指定なしはそのリポジトリだけの設定になる**

- 普段の名乗りは --global で一度だけ設定すればよい
- 両方に設定があるときは、リポジトリだけの設定が優先される

<!-- ノート: 基本は--globalで一度だけ。例外的に、このリポジトリだけ別名にしたいときに指定なしを使う、という使い分けです。 -->

---

## 最小の例

```bash
git config --global user.name "Sato Kenta"   # PC全体の設定
git config user.name "Sato K."               # このリポジトリだけの設定
```

- 上を一度やっておけば、どのリポジトリでも名乗りが刻まれる
- 下は「この案件だけ表記を変えたい」ような特別な場合に使う

## なぜ必要か

- 現場に入って最初の仕事は、たいてい環境の確認から始まる
- 「Gitが入っているか分からないまま作業を始める」と、途中で止まって手戻りになる

<!-- ノート: 未経験者が最初に不安になるのは「そもそも自分のPCで動くのか」。確認の一手を最初に覚えてもらいます。 -->

---

## 結論

**git --version が表示されれば、Gitは使える状態にある**

- --version は「バージョンを教えて」というオプション
- 何も変更しない安全なコマンドなので、遠慮なく打ってよい

<!-- ノート: 結論はこれだけ。--versionは読み取り専用で、何度打っても壊れないことを強調します。 -->

---

## 最小の例

```bash
git --version
# git version 2.45.1
```

- 表示されたら、数字が **2.23 以上** かも確かめる(この研修で使うコマンドがそろう版)
- 表示されない、または 2.23 より古いなら、公式サイトから入れ直す

<!-- ノート: 表示されることに加えて、2.23以上かどうかまで見てもらいます。この研修で使うコマンドの一部は2.23で追加されたので、古いままだと後半で「コマンドがない」と言われます。入れ直しは公式サイトから最新版を入れるだけです。 -->

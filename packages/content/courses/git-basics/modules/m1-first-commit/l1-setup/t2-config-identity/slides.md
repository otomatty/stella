## なぜ必要か

- バージョン管理の記録には「誰が変えたか」が必ず入る
- Gitで作る記録の1件1件を **コミット** と呼ぶ
- 名乗りを設定しないと、誰の仕事か分からない履歴になってしまう

<!-- ノート: ここでコミットという言葉を導入します。「いつ・誰が・何を・なぜ」の「誰が」を名乗るのがこの設定です。 -->

---

## 結論

**git config でユーザー名とメールを設定する(すべてのコミットに刻まれる)**

- config は「Gitの設定を読み書きする」コマンド
- 一度設定すれば、あとは自動で全コミットに刻まれる

<!-- ノート: 毎回名乗る必要はなく、最初に一度設定すればよいことを伝えます。 -->

---

## 最小の例

```bash
git config --global user.name "Sato Kenta"
git config --global user.email "sato@example.com"
```

- user.name は表示名、user.email は連絡先。チームの決まりに合わせる
- 打ち間違えても、もう一度同じ形で打てば上書きできる

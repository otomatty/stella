## なぜ必要か

- Gitのコマンドとオプションは多く、全部の暗記は無理
- 現場では「その場で正確に調べられる人」が信頼される

<!-- ノート: 暗記しなくてよい、という安心を先に渡します。調べ方さえ覚えれば足ります。 -->

---

## 結論

**git help(または --help)で、コマンドの説明をいつでも引ける**

- 説明はGit本体に入っているので、ネットがなくても読める
- 何も変更しない安全なコマンドなので、迷ったらまず引く

<!-- ノート: helpも読み取り専用で安全、という点を--versionと同じ言い方で繰り返します。 -->

---

## 最小の例

```bash
git help config
# → config の説明が開く

git config --help   # 書き方が違うだけで、意味は同じ
```

- Windows ではブラウザで開く。ターミナル内に表示される環境では q キーで閉じる

<!-- ノート: 表示のされ方は環境で違います。Windows版のGitは既定でブラウザに説明を開き、MacやGit Bashの一部設定ではターミナル内に表示されます。ターミナル内のときの詰まりどころは閉じ方で、qを押せば戻れます。実演するならここで閉じるところまで見せます。 -->

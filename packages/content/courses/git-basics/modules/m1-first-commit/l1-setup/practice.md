# レッスン1-1 演習 — 準備する

対象トピック: 1-1-1 〜 1-1-4

## ハンズオン

手元のVS Codeのターミナルで、Gitを使う準備を実際に済ませます。

1. VS Codeでターミナルを開きます(メニューの「ターミナル」→「新しいターミナル」)
2. Gitが使える状態かを確かめます

    ```bash
    git --version
    ```

    `git version 2.45.1` のような表示が出て、数字が **2.23 以上** なら合格です(この研修で使うコマンドは 2.23 で出そろいました)。表示されない場合や 2.23 より古い場合は、公式サイト(git-scm.com)から最新版をインストールしてからやり直してください
3. 名乗りをPC全体に設定します(名前とメールは自分のものに置き換えてください)

    ```bash
    git config --global user.name "Sato Kenta"
    git config --global user.email "sato@example.com"
    ```

4. あわせて、新しく作るリポジトリの「最初の置き場」の名前を main に統一する設定も済ませます(言葉の意味は Module 6 で学びます。ここでは打っておくだけで大丈夫です)

    ```bash
    git config --global init.defaultBranch main
    ```

5. 設定できたかを読み出して確かめます

    ```bash
    git config --global user.name
    git config --global user.email
    ```

    設定した値がそのまま表示されれば成功です
6. ヘルプを引いてみます

    ```bash
    git help config
    ```

    説明が開いたら閉じます。**Windows ではブラウザのタブで開く**のでタブを閉じれば OK、ターミナル内に表示された場合は **q** キーで閉じます。閉じられたらこのレッスンの操作はすべて完了です

ここで設定した名乗りは、この後の研修で作るすべてのコミットに刻まれます。

## 演習問題

### 問1(基本)

新しく貸与されたPCで、Gitがインストール済みかどうかを確かめたいです。最初に打つコマンドを書いてください。

### 問2(基本)

user.name と user.email を設定しないまま記録を始めると、後からどんな問題が起きますか。1文で説明してください。

### 問3(応用)

あるリポジトリの中で、PC全体には `user.name "Sato Kenta"`、そのリポジトリだけには `user.name "Sato K."` が設定されています。このリポジトリで作ったコミットに刻まれる名前はどちらですか。理由も書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```bash
git --version
```

バージョンが表示されればGitは使える状態です。何も変更しない安全なコマンドなので、環境確認の最初の一手として覚えておきます。

</details>

<details>
<summary>問2の解答例</summary>

すべてのコミットに「誰が変えたか」が正しく刻まれず、後から履歴を見ても誰の仕事か分からなくなります。

バージョン管理の記録は「いつ・誰が・何を・なぜ」のセットです。名乗りの設定はその「誰が」を支えています。

</details>

<details>
<summary>問3の解答例</summary>

「Sato K.」です。--global(PC全体)と指定なし(そのリポジトリだけ)の両方に設定があるときは、リポジトリだけの設定が優先されるためです。

普段は --global に一度設定しておき、特別な案件だけリポジトリ側で上書きする、という使い分けをします。

</details>

## 確認クイズ

### Q1. Gitがインストール済みで使える状態かを確かめるコマンドはどれですか。

- A. git --version
- B. git check
- C. git install

<details>
<summary>答え</summary>

**A** — git --version でバージョンが表示されれば、Gitは使える状態です。B・Cのようなコマンドはありません。

</details>

### Q2. git config で user.name と user.email を設定する理由として正しいものはどれですか。

- A. 設定しないとGitのコマンドが一切動かないため
- B. すべてのコミットに「誰が変えたか」として刻まれるため
- C. GitHubのパスワードとして使われるため

<details>
<summary>答え</summary>

**B** — 名乗りはすべてのコミットに刻まれ、履歴の「誰が」を支えます。パスワードではありませんし、未設定でも動くコマンドはあります。

</details>

### Q3. git config --global の --global の意味として正しいものはどれですか。

- A. 設定を今いるリポジトリだけに効かせる
- B. 設定をPC全体(すべてのリポジトリ)に効かせる
- C. 設定をチーム全員のPCに配る

<details>
<summary>答え</summary>

**B** — --global はPC全体の設定です。指定なしだと今いるリポジトリだけに効きます。他人のPCに配る機能はありません。

</details>

### Q4. コマンドの説明を調べたいときの操作として正しいものはどれですか。

- A. git help config のように打つ(表示は q で閉じる)
- B. 説明はネット上にしかないので、ブラウザでしか調べられない
- C. git config を実行すると説明が表示される

<details>
<summary>答え</summary>

**A** — git help コマンド名(または --help)でいつでも説明を引けます。説明はGit本体に入っているのでネットがなくても読めます。

</details>

# git commitで記録する

Git入門研修 — Module 1 / レッスン1-4

## なぜ必要か

- ステージングエリアには下書きが載ったまま。まだ記録は増えていない
- 下書きのままでは、後から戻ることも見返すこともできない

<!-- ノート: 前レッスンの終わりの状態から始めます。確定して初めて履歴になります。 -->

---

## 結論

**git commit -m "メッセージ" で、記録が1つ増える**

- -m は「メッセージをその場で付ける」オプション
- メッセージは「何をしたか」の一言。**コミットメッセージ**と呼ぶ

<!-- ノート: コマンドの形とオプションの意味、メッセージという用語をここで導入します。 -->

---

## 最小の例

```bash
git add practice.txt
git commit -m "練習用のメモを追加"
git status
# → ステージングエリアが空になり、きれいな状態に戻る
```

- 記録されるのは、ステージングエリアに載っていた分だけ

<!-- ノート: commitの後にstatusを打つと表示が静かになります。下書きが記録に変わって、置き場が空いた状態です。 -->

# git logで確かめる

Git入門 — Module 1 / レッスン1-4

<!-- ノート: モジュールの締めくくり。自分の作った記録を自分の目で確かめます。 -->

---

## なぜ必要か

- コミットを作っても、フォルダの見た目は何も変わらない
- 「本当に記録されたのか」を確かめる手段がないと不安が残る

<!-- ノート: commitは静かに終わるので、初心者は成功したのか確信が持てません。確かめる道具を渡します。 -->

---

## 結論

**git log で、記録が積み上がったことを確かめられる**

- コミットの一覧が、ハッシュ・名乗り・日時・メッセージ付きで並ぶ
- 何も変更しない読み取り専用のコマンド。いつ打っても安全

<!-- ノート: これで「いつ・誰が・何を」が本当に記録されていたと自分の目で確認できます。logも安全なコマンドの仲間です。 -->

---

## 最小の例

```bash
git log
# commit 3f2a1c9d8e7b...
# Author: Sato Kenta <sato@example.com>
# Date:   Wed Aug 19 10:00:00 2026
#
#     練習用のメモを追加
```

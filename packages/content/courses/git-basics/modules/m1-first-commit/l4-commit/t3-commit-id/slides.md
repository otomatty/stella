# 1-4-3
# コミットにはIDが付く

Git入門 — Module 1 / レッスン1-4

<!-- ノート: コミットの呼び名、IDの話です。長い英数字の正体を知って怖くなくします。 -->

---

## なぜ必要か

- コミットが増えてくると「どのコミットの話?」を伝える手段が要る
- 「昨日の3番目のやつ」のような呼び方では、正確に指し示せない

<!-- ノート: 会話やチャットで特定のコミットを指すには、確実な名前が必要です。 -->

---

## 結論

**コミットには英数字のID(ハッシュ)が付き、先頭7桁で指し示せる**

- ハッシュは中身から自動で計算される値。自分で付ける必要はない
- 全部で40桁あるが、普段は先頭7桁で十分区別できる

<!-- ノート: ハッシュは自動採番の背番号のようなもの。40桁全部を扱う場面はほぼなく、先頭7桁が実務の通貨です。 -->

---

## 最小の例

```text
ID(全体): 3f2a1c9d8e7b6a5f4c3d2e1f0a9b8c7d6e5f4a3b
先頭7桁:  3f2a1c9   ← 普段はこれだけで指し示せる
```

- チャットで「3f2a1c9 の件ですが」と書けば、相手も同じコミットを見られる

<!-- ノート: 長い英数字の羅列に見えても、使うのは先頭だけ。実務の会話例で使いどころを見せます。 -->

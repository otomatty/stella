# レッスン1-2 演習 — リポジトリを作る

対象トピック: 1-2-1 〜 1-2-3

## ハンズオン

手元のVS Codeのターミナルで、練習用のリポジトリを実際に作ります。ここで作るフォルダは、この後のレッスンでもずっと使います。

1. ホームフォルダに練習用フォルダを作って移動します(`~` はホームフォルダ、`mkdir` はフォルダを作るコマンドです)

    ```bash
    cd ~
    mkdir git-practice
    cd git-practice
    pwd
    ```

    pwd の表示が `.../git-practice` で終わっていれば、正しい場所に居ます
2. このフォルダをリポジトリにします

    ```bash
    git init
    ```

    `Initialized empty Git repository in ...` と表示されれば成功です
3. 現在地を確かめます

    ```bash
    git status
    ```

    まだ記録するものが何もない、という趣旨の表示が出ます。読めなくて構いません。「打てば現状が出る」ことを確かめるのが目的です
4. VS Codeの「ファイル」→「フォルダーを開く」で `git-practice` を開き、新しいファイル `practice.txt` を作ります。中身は1行だけ書いて保存します

    ```text
    Git練習用のメモ
    ```

5. もう一度状態を確かめます

    ```bash
    git status
    ```

    `Untracked files:` の下に `practice.txt` が表示されていれば、この
    レッスンのゴールです。保存しただけのファイルは、Gitからはまだ
    「見ていない新しいファイル」に見えている——それを自分の目で確認できました

この practice.txt は次のレッスンでGitに見てもらう(記録の対象にする)ところから続けます。

## 演習問題

### 問1(基本)

`~/reports` というフォルダを新しくリポジトリにしたいです。ターミナルで打つコマンドを順番に書いてください(フォルダはすでにあるものとします)。

### 問2(基本)

「操作に迷ったら、まず git status を打つとよい」と言われるのはなぜですか。1文で説明してください。

### 問3(応用)

リポジトリの中で新しいファイル `nippou.txt` を作って保存し、git status を打ったところ、Untracked files に表示されました。この時点で `nippou.txt` の内容はGitの記録に入っていますか。理由も書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```bash
cd ~/reports
git init
```

init は「今いるフォルダ」に効くので、先に cd で対象フォルダへ移動してから打ちます。initが必要なのはフォルダごとに最初の一度だけです。

</details>

<details>
<summary>問2の解答例</summary>

status は何も変更せずに今の状態を教えてくれる安全なコマンドなので、現在地を確かめてから次の操作を選べるためです。

地図アプリの現在地と同じで、どこに居るか分かれば次の一手を落ち着いて選べます。

</details>

<details>
<summary>問3の解答例</summary>

入っていません。Untracked は「Gitがまだ見ていない新しいファイル」という意味で、エディタで保存してもGitの記録には何も入らないためです。

「保存」と「Gitの記録」は別の操作です。記録の対象にする方法は次のレッスンで学びます。

</details>

## 確認クイズ

### Q1. 今いるフォルダをリポジトリにするコマンドはどれですか。

- A. git status
- B. git init
- C. git config

<details>
<summary>答え</summary>

**B** — git init で今のフォルダがリポジトリになります。status は状態の確認、config は設定のコマンドです。

</details>

### Q2. git init を実行したときに起きることとして正しいものはどれですか。

- A. フォルダの中の既存ファイルがすべて書き換えられる
- B. 履歴の入れ物(.git)ができて、フォルダがリポジトリになる
- C. フォルダの中のファイルが自動で記録される

<details>
<summary>答え</summary>

**B** — init は履歴の入れ物を作るだけで、既存ファイルには触りません。ファイルが自動で記録されることもありません。

</details>

### Q3. git status の説明として正しいものはどれですか。

- A. 何も変更しない読み取り専用のコマンドで、困ったらまず打つとよい
- B. 打つたびに記録が1つ増えるので、打ちすぎてはいけない
- C. リポジトリの外で打つとPCが壊れる

<details>
<summary>答え</summary>

**A** — status は今の状態を表示するだけの安全なコマンドです。何度打っても記録は増えませんし、外で打ってもエラーが出るだけです。

</details>

### Q4. git status に「Untracked files: practice.txt」と表示されました。この意味として正しいものはどれですか。

- A. practice.txt が壊れているという警告
- B. practice.txt は「Gitがまだ見ていない新しいファイル」だという状態表示
- C. practice.txt が誤って削除されたという通知

<details>
<summary>答え</summary>

**B** — Untracked はエラーではなく状態の名前です。新しいファイルは誰が作っても最初はUntrackedから始まります。

</details>

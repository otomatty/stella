# レッスン1-2 リポジトリを作る

## このレッスンの目標

- [ ] git init で普通のフォルダをリポジトリにできる
- [ ] git status を「困ったらまず打つコマンド」として使える
- [ ] status に出る Untracked の意味を説明できる

## 1-2-1 git initで始める

> **git init で、今のフォルダがリポジトリになる**

リポジトリは「作業フォルダ+その履歴」のセットでした。手元の普通のフォルダをリポジトリにするコマンドが **init** です。

```bash
cd ~/git-practice
git init
```

```text
Initialized empty Git repository in /home/sato/git-practice/.git/
```

- init は「今いるフォルダ」に効きます。先に cd で対象のフォルダへ移動してから打つのが型です
- 表示のとおり、履歴の入れ物(.git)がフォルダ直下に作られます。これで「リポジトリになった」と言えます
- 必要なのはフォルダごとに最初の一度だけです。もともとあったファイルの中身は何も変わりません

「initを打つと何か壊れそう」と身構える必要はありません。空の履歴の入れ物ができるだけで、既存のファイルには触りません。

## 1-2-2 git statusは現在地

> **git status は今の状態を教えてくれる(困ったらまずこれを打つ)**

リポジトリの中の状況は、フォルダを眺めているだけでは分かりません。「今どういう状態?」を教えてくれるのが **status** です。地図アプリの現在地表示のようなコマンドです。

```bash
cd ~/git-practice
git status
```

- 何も変更しない読み取り専用のコマンドです。いつ、何度打っても安全です
- 上手な人ほど頻繁に打ちます。操作の前後で毎回打つくらいでちょうどよいです
- リポジトリの外で打つとエラーになりますが、それも「今リポジトリの外に居る」という現在地の情報です

表示される英文の読み方は、この先のトピックで少しずつ覚えます。まずは「困ったら status」を体に入れてください。この研修のあらゆる場面で最初の一手になります。

## 1-2-3 Untrackedの意味

> **Untracked は「Gitがまだ見ていない新しいファイル」という意味**

リポジトリに新しいファイル(例: practice.txt)を作って status を打つと、こんな表示が出ます。

```text
Untracked files:
        practice.txt
```

英語の表示に驚くかもしれませんが、これは警告でもエラーでもなく、ただの状態の名前です。

- track は「追いかける」という意味。**Untracked = Gitがまだ追いかけていない**
- Gitは勝手に記録を始めません。新しいファイルは、誰が作っても最初は Untracked です

ここで大事なサインを1つ読み取れます。**エディタで保存しただけでは、Gitの記録には何も入っていない**ということです。保存とGitの記録は別の操作です。ではどうすればGitに見てもらえるのか——それが次のレッスンの主題です。

# git statusは現在地

Git入門研修 — Module 1 / レッスン1-2

<!-- ノート: この研修で一番よく打つことになるコマンドを紹介します。 -->

---

## なぜ必要か

- リポジトリの中の状況は、フォルダを眺めているだけでは分からない
- 「今どういう状態?」が分からないまま操作すると、事故のもとになる

<!-- ノート: 地図アプリの現在地と同じで、まず自分がどこに居るかが分からないと動けない、というたとえで入ります。 -->

---

## 結論

**git status は今の状態を教えてくれる(困ったらまずこれを打つ)**

- 何も変更しない読み取り専用のコマンド。いつ打っても安全
- 打つ回数に上限はない。操作の前後で毎回打ってよい

<!-- ノート: statusは読み取り専用で安全、を強調します。上手な人ほど頻繁に打つコマンドです。 -->

---

## 最小の例

```bash
cd ~/git-practice
git status
# → 今のリポジトリの状態の説明が数行で表示される
```

- 表示の読み方はこれから少しずつ覚える。まず「打てば現状が分かる」でよい
- リポジトリの外で打つとエラーになる(それも「外に居る」という情報)

<!-- ノート: 表示の中身の読解はこの先のトピックで積み上げます。ここでは打つ習慣づけが目的です。エラーすら現在地のヒントになります。 -->

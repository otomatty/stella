# git initで始める

Git入門 — Module 1 / レッスン1-2

<!-- ノート: 準備が済んだので、自分のリポジトリを初めて作ります。 -->

---

## なぜ必要か

- リポジトリは「作業フォルダ+その履歴」のセットだと学んだ
- では、手元の普通のフォルダをリポジトリにするにはどうするのか

<!-- ノート: M0で覚えた「リポジトリ」の定義を思い出させてから、作り方という問いを立てます。 -->

---

## 結論

**git init で、今のフォルダがリポジトリになる**

- init は「このフォルダでGitの記録を始める」という宣言
- 必要なのは一度だけ。フォルダの中身は何も変わらない

<!-- ノート: initは各フォルダで最初の一度だけ。既存のファイルが消えたり変わったりしない、という安心も添えます。 -->

---

## 最小の例

```bash
cd ~/git-practice
git init
# Initialized empty Git repository in /home/sato/git-practice/.git/
```

- 対象のフォルダに cd で移動してから打つ
- 表示のとおり、履歴の入れ物(.git)がフォルダ直下にできる

<!-- ノート: 「今いるフォルダ」に効くコマンドなので、先にcdで移動するのが型です。.gitができた=リポジトリになった、と読み替えます。 -->

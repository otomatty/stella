# git addで選ぶ

Git入門研修 — Module 1 / レッスン1-3

<!-- ノート: 2段階の1段目、addを実際に打ちます。 -->

---

## なぜ必要か

- 作った practice.txt は Untracked のまま。Gitはまだ見ていない
- 「このファイルを次の記録に入れる」とGitに伝える手段が要る

<!-- ノート: 前のレッスンの続きです。Untrackedのままでは何も記録できない、から入ります。 -->

---

## 結論

**git add ファイル名 で、次の記録に入れるファイルを選ぶ**

- add した瞬間に記録されるのではない。あくまで「選んだ」だけ
- どれを選んだかは、直後の status で確かめられる

<!-- ノート: addは選ぶ操作であって記録の確定ではない、を強調します。確定は2段目の仕事です。 -->

---

## 最小の例

```bash
git add practice.txt
git status
# → practice.txt が「次の記録に入る」側の欄に移って表示される
```

- 表示の欄が変わったら、選択が効いたサイン
- 選ぶファイルを間違えても、まだ記録は増えていないので慌てない

<!-- ノート: addの前後でstatusの表示が変わるのを実演で見せたいところです。addは静かに成功するので、statusで確かめる癖をここで付けます。 -->

# switch -cで作って移る

Git入門 — Module 6 / レッスン6-2

<!-- ノート: いよいよブランチを作ります。作る操作と移る操作を1コマンドで済ませる、実務でいちばんよく打つ形から覚えます。 -->

---

## なぜ必要か

- 「作業はブランチで」と決めた。作業を始めるたびにブランチが要る
- 作ってから移る、を毎回2手でやるのは面倒

<!-- ノート: レッスン6-1の方針をコマンドに落とす回。実務で最頻出の形を最初に体に入れる。 -->

---

## 結論

**git switch -c 名前 で、新しいブランチを作ってそこへ移る**

- switch はブランチを移るコマンド、`-c` は「作ってから」のオプション
- 作った瞬間から、コミットはそのブランチに積める

<!-- ノート: switchと-cをここで導入する。-cはcreateのc。作る+移るが1回で済むので、作業開始の合図としてこのまま覚える。 -->

---

## 最小の例

```bash
git switch -c add-template
# Switched to a new branch 'add-template'
```

- 日報テンプレートを足す作業用に、add-template を作って移った

<!-- ノート: ブランチ名は英数字とハイフンで、何の作業か分かる名前にする。出力の1行が「作って移った」の確認になっている。 -->

# 6-2-3
# switchで移る

Git入門 — Module 6 / レッスン6-2

<!-- ノート: -cなしのswitch、既にあるブランチへの移動です。移ると何が起きるのかを1つだけ押さえます。 -->

---

## なぜ必要か

- 作業の途中で「main の状態をちょっと確認したい」はよく起きる
- ブランチを移ったとき、手元のファイルがどうなるのか知らないと不安

<!-- ノート: 移動そのものより「移ったら手元がどうなるか」への不安に答える回だと最初に示す。 -->

---

## 結論

**git switch 名前 で移ると、フォルダの中身がそのブランチの状態になる**

- Git が作業フォルダのファイルを、そのブランチの最新コミットに合わせて入れ替える
- 見えなくなったファイルも消えてはいない。元のブランチに戻れば現れる

<!-- ノート: 中身が変わるのは正常な動き。ファイルが消えた!と焦る事故が定番なので、付箋の位置に合わせて手元が変わるだけと言い切る。 -->

---

## 最小の例

```bash
git switch main
# Switched to branch 'main'
```

- add-template で作ったファイルは、main では見えない(main には無い状態だから)

<!-- ノート: 移った直後にエクスプローラを見ると、ブランチごとに世界が切り替わる感覚がつかめる。戻ればまた現れることも必ず添える。 -->

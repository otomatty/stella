# 6-2-4
# コミットは今いる枝に積まれる

Git入門研修 — Module 6 / レッスン6-2

<!-- ノート: このレッスンの締め。ブランチ時代のコミットの大原則と、事故を防ぐ習慣を1つ持ち帰ります。 -->

---

## なぜ必要か

- ブランチが複数あると、コミットの行き先はどこになるのか
- 「main のつもりで作業ブランチに」「その逆」という積み間違いは定番の事故

<!-- ノート: ブランチを覚えた直後に必ず起きる疑問と事故。行き先のルールを1つ覚えれば防げる。 -->

---

## 結論

**コミットは「今いるブランチ」に積まれる(commit の前に branch で確かめる)**

- 行き先を指定する方法はない。今いる場所がすべて
- だからこそ、コミットの前に現在地を確かめる習慣が効く

<!-- ノート: ルールは1つだけ。今いるブランチの付箋が1つ進む。積む前にgit branchで*の位置を見る、を習慣として結論に含める。 -->

---

## 最小の例

```bash
git branch
#   main
# * add-template   ← いまここ
git commit -m "日報テンプレートを追加"
# → add-template に積まれる。main は動かない
```

- 別のブランチに積みたければ、先に移ってからコミットする

<!-- ノート: branchで確かめてからcommit、の2手をワンセットで見せる。mainの付箋は動かないことも口頭で補足する。 -->

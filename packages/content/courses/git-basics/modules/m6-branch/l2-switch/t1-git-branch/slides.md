# 6-2-1
# git branchで一覧する

Git入門 — Module 6 / レッスン6-2

<!-- ノート: このレッスンからブランチをコマンドで操作します。最初は現在地の確認から。statusと同じで、迷ったらまず見るコマンドです。 -->

---

## なぜ必要か

- ブランチが増えると「いま自分はどのブランチに居るのか」を見失う
- 現在地を確かめずに作業を始めるのは、地図を見ずに歩くのと同じ

<!-- ノート: ブランチ操作の第一歩は作ることではなく、現在地の確認だという順序を強調する。 -->

---

## 結論

**git branch でブランチを一覧でき、今いる場所に * が付く**

- 引数なしで打てば、このリポジトリのブランチが全部並ぶ
- `*` が付いている行が、いま自分の居るブランチ

<!-- ノート: takeawayを言い切る。一覧と現在地確認が同時にできる、軽くて安全なコマンド。 -->

---

## 最小の例

```bash
git branch
#   add-template
# * main
```

- ブランチは2本あり、いま居るのは main だと分かる

<!-- ノート: 出力の読み方を指差しで。行頭の*が現在地。打っても何も変わらない見るだけのコマンドなので、何度打ってもよい。 -->

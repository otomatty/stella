# 6-4-4
# stashは一時置き

Git入門研修 — Module 6 / レッスン6-4

<!-- ノート: stashの使い方を覚えた直後に、使いすぎへの歯止めをかける回です。道具の位置づけを1つ持ち帰ります。 -->

---

## なぜ必要か

- stash は便利なので、何でもしまいたくなる
- しまったまま日が経つと、何を退避したのか自分でも思い出せなくなる

<!-- ノート: 便利な道具ほど乱用の事故が起きる。stashの中身は履歴のような説明が付かないことが伏線。 -->

---

## 結論

**stash は一時置き(長居させず、早めにコミットへ昇格させる)**

- 割り込みをしのぐための机の引き出しであって、保管庫ではない
- 用が済んだら pop で出し、区切りが付いたら add して commit で記録に昇格させる

<!-- ノート: stashにはメッセージも履歴の並びもない。ちゃんとした記録はコミットだけ、というModule 5までの学びに接続する。 -->

---

## よくある間違い

```text
×: stash に入れたまま数日放置
   → 何を・なぜ退避したのか分からなくなる

○: 割り込みが済んだらすぐ pop
   → 区切りが付き次第、コミットに昇格させる
```

- 「しまう時間は短いほどよい」が stash の使い方のコツ

<!-- ノート: 対比で締める。stashが溜まっている状態は黄色信号。コミットになっていれば、いつ・何を・なぜが残るので安心。 -->

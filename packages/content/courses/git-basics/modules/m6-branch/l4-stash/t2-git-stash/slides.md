# 6-4-2
# git stashで退避する

Git入門 — Module 6 / レッスン6-4

<!-- ノート: 切り替えを止められたときの解決策です。中途半端な変更の一時避難場所を覚えます。 -->

---

## なぜ必要か

- 切り替えられない原因は、コミットしていない中途半端な変更
- とはいえ、作りかけをコミットしたくない場面もある

<!-- ノート: 前トピックの問題を受けて。コミットで解決もできるが、中途半端な状態を記録に残したくないときの第3の道。 -->

---

## 結論

**git stash で、作業中の変更をいったん退避して手元をきれいにできる**

- 変更は消えずに、退避場所へしまわれる
- 手元は最後のコミットの状態に戻り、ブランチを切り替えられるようになる

<!-- ノート: stashをここで導入する。引き出しに一時的にしまうイメージ。捨てるのではなく、しまうだけという点を強調する。 -->

---

## 最小の例

```bash
git stash
# Saved working directory and index state WIP on main: ...
git status
# nothing to commit, working tree clean
```

- 手元がきれいになったので、これで切り替えられる

<!-- ノート: 出力のWIPは作業中(work in progress)の意味。statusがcleanになるのが退避成功のサイン。しまった変更の取り出し方は次のトピックで。 -->

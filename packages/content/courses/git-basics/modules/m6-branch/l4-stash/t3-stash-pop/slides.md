# 6-4-3
# stash popで戻す

Git入門研修 — Module 6 / レッスン6-4

<!-- ノート: しまった変更の取り出し方です。stashとpopで往復がワンセット、というところまで持っていきます。 -->

---

## なぜ必要か

- 割り込み作業が済んだら、退避した変更の続きをやりたい
- しまったままでは、作業が途中のまま忘れられてしまう

<!-- ノート: stashは往復してこそ意味がある。取り出しまでがワンセットという位置づけを最初に示す。 -->

---

## 結論

**git stash pop で、退避した変更を作業フォルダに戻す**

- しまった変更が作業フォルダに戻り、退避場所からは取り出される
- 編集途中だったファイルが、そのままの姿で帰ってくる

<!-- ノート: popをここで導入する。取り出すと退避場所から無くなる、まさに引き出しから出す動き。戻した後は普段の編集の続きができる。 -->

---

## 最小の例

```bash
git stash pop
# Changes not staged for commit:
#   modified:   memo.md
# Dropped refs/stash@{0} (...)
```

- memo.md の編集途中の変更が、手元に戻ってきた

<!-- ノート: 出力の見方だけ確認。modifiedとして変更が戻り、最後の行が退避場所から取り出した報告。ここから続きを編集すればよい。 -->

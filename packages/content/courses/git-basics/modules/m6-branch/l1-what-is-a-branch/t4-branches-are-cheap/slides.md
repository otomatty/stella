# 6-1-4
# ブランチ作成は軽い

Git入門 — Module 6 / レッスン6-1

<!-- ノート: このレッスンの締め。作業のたびにブランチを作る運用が現実的なのは、作成が軽いからだ、という裏付けをします。 -->

---

## なぜ必要か

- 「直しのたびにブランチを作る」と聞くと、面倒で重い作業に思える
- フォルダのコピーと同じ感覚でいると、作るのをためらってしまう

<!-- ノート: 前トピックで残した「面倒そう」という感覚に正面から答える回。 -->

---

## 結論

**ブランチを作るのは一瞬(気軽に作って、終わったら消す)**

- 増えるのは付箋1枚だけ。ファイルは複製されない
- 試したいことがあれば作る。要らなくなったら消す。それでよい

<!-- ノート: ブランチは動く付箋、の帰結。付箋を1枚増やすだけだから一瞬で終わる。使い捨てでよい、という気軽さまで含めて結論。 -->

---

## よくある間違い

```text
×: フォルダのコピーで別案を試す
   → 作業フォルダが複製されて重い。どれが本物か分からなくなる

○: ブランチで別案を試す
   → 増えるのは付箋1枚。ファイルは1組のまま
```

- ためらう理由がないので、実験用・練習用に作っても構わない

<!-- ノート: Module 0の「コピー管理の破綻」との対比。同じ目的を、Gitでは付箋1枚で安全に実現できる。 -->

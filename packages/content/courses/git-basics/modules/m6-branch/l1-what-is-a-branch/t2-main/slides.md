# 6-1-2
# mainは完成の置き場

Git入門 — Module 6 / レッスン6-1

<!-- ノート: ブランチという言葉を覚えた直後に、実はもうずっと1本のブランチの上に居た、という種明かしをします。 -->

---

## なぜ必要か

- これまで積んできたコミットは、どこに積まれていたのか
- 実は git init した瞬間から、ブランチは1本だけ存在していた

<!-- ノート: ブランチは新しい道具ではなく、最初から使っていたと気づかせる。名前だけ知らなかった、という導入。 -->

---

## 結論

**main は既定のブランチで、完成した状態を置く場所**

- 何もしなくても最初からある、いわば本流のブランチ
- チームの誰が見ても「main = 完成している状態」と信じられるように保つ

<!-- ノート: mainという語をここで定義する。技術的には他のブランチと同じただの付箋だが、役割として「完成の置き場」という約束を載せる。 -->

---

## 最小の例

```text
コミットA ← コミットB ← コミットC
                          ↑
                        main
```

- これまでの研修で積んだコミットは、すべて main に積まれていた

<!-- ノート: 前トピックの図の付箋に、mainという名前が付いただけ。見慣れた履歴の正体がこれ、と指差しで確認する。 -->

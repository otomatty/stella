# ブランチに戻る

Git入門 — Module 6 / レッスン6-3

## なぜ必要か

- 過去の見学が済んだら、いつもの作業に戻りたい
- detached HEAD のまま作業を続けてよいのか、判断に迷う

<!-- ノート: 見学モードは長居する場所ではない。帰り方が分かっていれば、安心して見に行ける。 -->

---

## 結論

**git switch main のようにブランチへ移れば、いつもの状態に戻る**

- 帰り方は、普通のブランチ移動とまったく同じ
- HEAD が付箋(ブランチ)に戻り、見学モードは終わる

<!-- ノート: 特別な脱出コマンドは要らない、が安心ポイント。switchでブランチ名を指定するだけ。作業を再開する前に必ず帰る、を型にする。 -->

---

## 最小の例

```bash
git switch main
# Switched to branch 'main'
git status
# On branch main
```

- 見慣れた「On branch main」に戻れば、見学は終わり

<!-- ノート: statusの表示が普段どおりに戻ることで「帰ってきた」を確認する。見学前に居たのが作業ブランチなら、そのブランチ名を指定して帰ればよい。 -->

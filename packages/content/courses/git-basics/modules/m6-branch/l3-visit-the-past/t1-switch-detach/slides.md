# 6-3-1
# 過去のコミットを開く

Git入門 — Module 6 / レッスン6-3

<!-- ノート: このレッスンは「過去を見に行く」です。履歴を読むだけでなく、過去の状態をフォルダごと開く方法を覚えます。 -->

---

## なぜ必要か

- 「先週の時点では動いていたはず。実物を開いて確かめたい」はよくある
- 差分を読むだけでは分からないことも、当時の状態を丸ごと開けば分かる

<!-- ノート: log や show で読むのと、実際にその時点のファイル一式を開くのとの違いを示す導入。 -->

---

## 結論

**git switch --detach ID で、過去のスナップショットをその場で開ける**

- コミットは全体のスナップショットだから、丸ごと開ける
- 作業フォルダの中身が、そのコミット時点の状態になる

<!-- ノート: --detachをここで導入する。ブランチではなくコミットIDを指定して移る形。スナップショットという既習語とつながる瞬間。 -->

---

## 最小の例

```bash
git switch --detach 3f2a9c1
# HEAD is now at 3f2a9c1 価格表を追加
```

- ID は先頭7桁で十分。フォルダの中身が当時の状態になる

<!-- ノート: IDはlogで調べた先頭7桁を使う。開いた後は普通にファイルを読める。眺め終わったらどう戻るかは、この後のトピックで扱う。 -->

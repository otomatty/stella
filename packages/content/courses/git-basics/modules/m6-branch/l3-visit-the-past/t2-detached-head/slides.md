# 6-3-2
# detached HEADは見学モード

Git入門研修 — Module 6 / レッスン6-3

<!-- ノート: 過去を開いた直後に出る英語の表示が今回の主役です。初見で全員が不安になる表示なので、正体を先に知っておきます。 -->

---

## なぜ必要か

- 過去のコミットを開くと「detached HEAD」という見慣れない表示が出る
- 警告っぽい見た目なので「壊してしまったのでは」と焦りやすい

<!-- ノート: 実際に未経験者が最初につまずくポイント。エラーではないのに、エラーに見えるのが厄介。 -->

---

## 結論

**detached HEAD は「どの枝にも居ない見学モード」の表示(壊れていない)**

- HEAD(今いる場所の印)が、ブランチではなくコミットを直接指している状態
- 過去を眺める分にはまったく問題ない。故障でもエラーでもない

<!-- ノート: detached HEADをここで定義する。HEADは4章で覚えた「今いる場所の印」。それが付箋から外れて直接コミットに刺さっている、と説明する。 -->

---

## 最小の例

```bash
git status
# HEAD detached at 3f2a9c1
```

- 「いま 3f2a9c1 を直接見ています」という現在地の報告にすぎない

<!-- ノート: statusで見ると1行で書いてある。読めてしまえば怖くない。見学モードでコミットを積むと迷子になりやすいので、見るだけに留めるのが安全、と口頭で添える。 -->

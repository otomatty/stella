# 2-1-3
# diffの読み方

Git入門研修 — Module 2 / レッスン2-1

<!-- ノート: git diffの表示そのものを読めるようになる回です。覚える記号は2つだけです。 -->

---

## なぜ必要か

- git diff を打つと、行頭に記号の付いた行がずらっと並ぶ
- 記号の意味を知らないと、読まずに閉じてしまいがち

<!-- ノート: 初めてdiffを見た人は情報量に圧倒されます。実は見るべき記号は2つだけ、と安心させてから結論へ。 -->

---

## 結論

**diff は - の行が変更前、+ の行が変更後**

- \- の行: 消えた(直される前の)内容
- \+ の行: 新しく書かれた内容

<!-- ノート: マイナスが前、プラスが後。この2つさえ読めれば、diffの本体は読めたも同然です。 -->

---

## 最小の例

```text
-単価: 1,000円
+単価: 1,200円
+※ 4月から改定
```

- 1,000円 の行を 1,200円 に直し、注記を1行足したと読める

<!-- ノート: 価格表の修正例。-と+のペアは書き換え、+だけの行は追加。逆に-だけなら削除です。 -->

---

## まとめ

**diff は - の行が変更前、+ の行が変更後**

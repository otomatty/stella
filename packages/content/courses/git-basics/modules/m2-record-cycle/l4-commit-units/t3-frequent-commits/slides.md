# 2-4-3
# こまめなコミットは保険

Git入門 — Module 2 / レッスン2-4

<!-- ノート: 単位の話の3つ目、頻度です。コミットをためらう初学者の背中を押す回でもあります。 -->

---

## なぜ必要か

- 「キリのいいところまでやってから」とためて、夕方に事故が起きる
- 半日分の作業を失うか、10分分で済むかは、記録の間隔で決まる

<!-- ノート: コミットをためらう心理はもったいない精神。ためるほど失うものが大きくなる、と損得で語ります。 -->

---

## 結論

**こまめにコミットするほど「戻れる場所」が増える**

- コミットは無料の保険。多すぎて困ることはまずない
- 小さな一歩でも、動く状態になったらすぐ記録する

<!-- ノート: 履歴は戻れる場所の一覧でした。保険のかけ直しを頻繁にするほど、失う量が小さくなります。 -->

---

## 最小の例

```text
こまめな記録: 記録A → 記録B → 記録C → 事故!
              ← 直前の記録Cまで戻れば10分の損害

ためた記録:   記録A → (半日ぶん作業) → 事故!
              ← 記録Aまで半日巻き戻し
```

<!-- ノート: 同じ事故でも損害が段違い。戻れる場所の間隔=失う作業の最大量、という図式で腹落ちさせます。 -->

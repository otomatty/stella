# 2-2-1
# git diffは未addの変更

Git入門研修 — Module 2 / レッスン2-2

<!-- ノート: このレッスンではdiffの守備範囲を正確にします。まずは素のgit diffが何を見せているのかです。 -->

---

## なぜ必要か

- add してから git diff を打つと、何も表示されない
- 「さっきの変更が消えた?」と焦るが、消えてはいない

<!-- ノート: 全員が一度は通る「diffが空っぽ」事件。原因はdiffの守備範囲を知らないことです。 -->

---

## 結論

**git diff が見せるのは、まだ add していない変更**

- ステージングエリアに載せた変更は、git diff には出ない
- 表示が空なのは「未 add の変更がない」という意味

<!-- ノート: diffは「作業中のファイル」と「ステージングエリア」の差を見せる道具。add済みの変更は守備範囲の外に移っただけです。 -->

---

## 最小の例

```bash
git diff
# +単価: 1,200円 が表示される
git add price.txt
git diff
# (何も表示されない = 未addの変更がない)
```

<!-- ノート: 同じ変更でもaddの前後で表示が変わることを実演します。変更が消えたのではなく、置き場所が変わっただけです。 -->

# git mvは移動の記録

Git入門研修 — Module 2 / レッスン2-3

<!-- ノート: 削除に続いて、名前の変更と移動です。これも変更の一種として記録します。 -->

---

## なぜ必要か

- 「ファイル名が分かりにくいから直したい」は実務でよくある
- 整理のための名前変更や置き場所の移動も、履歴に残したい変更

<!-- ノート: 資料が増えると名前や置き場所の整理が必ず発生します。これをGitでどう扱うかがこの回のテーマです。 -->

---

## 結論

**git mv は「名前を変えた・移動した」という変更を記録する**

- 名前の変更と移動を、次のコミットに入る変更として載せる
- あとは commit すれば「名前を変えた」ことが履歴に残る

<!-- ノート: mvはmove(動かす)の略。名前変更も「別の名前へ動かす」の一種として、同じコマンドで扱います。 -->

---

## 最小の例

```bash
git mv price.txt price-list.txt
git status
# renamed:    price.txt -> price-list.txt
git commit -m "価格表のファイル名を整理"
```

<!-- ノート: statusにrenamedと出るのが「移動が変更として載った」印。古い名前と新しい名前が矢印でつながって表示されます。 -->

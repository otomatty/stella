# 普通に消してもよい

Git入門研修 — Module 2 / レッスン2-3

<!-- ノート: git rmを使わずに消してしまった場合の話です。よくやる操作なので、救済策とセットで覚えます。 -->

---

## なぜ必要か

- つい VS Code のエクスプローラで右クリック削除してしまうことがある
- git rm を使い忘れたら、削除は記録できないのか?

<!-- ノート: GUIで消すのは自然な操作。使い忘れても大丈夫、と安心させてから結論へ入ります。 -->

---

## 結論

**エクスプローラで消しても、git add -A が削除を変更として拾ってくれる**

- -A は「削除も含めて、変更を全部載せる」オプション
- どの消し方でも、最後に add で載れば同じように記録できる

<!-- ノート: -AはAll(全部)の意味。普通に消す→add -Aで拾う、でgit rmと同じ状態に追いつけます。 -->

---

## 最小の例

```bash
# エクスプローラで old-memo.txt を削除した後
git add -A
git status
# deleted:    old-memo.txt
```

- 削除が変更として載ったので、あとはいつも通り commit するだけ

<!-- ノート: 消した直後のstatusでは「載っていない削除」だったものが、add -Aでdeletedとして載ります。 -->

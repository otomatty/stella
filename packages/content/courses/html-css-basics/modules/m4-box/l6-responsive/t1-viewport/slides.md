# 4-6-1
# viewportの指定で実際の幅に合わせる

HTML/CSS入門 — Module 4 / レッスン4-6

<!-- ノート: 最後のレッスンは画面幅です。まず、書かないと何も始まらない1行から。 -->

---

## なぜ必要か

- パソコンでは整っているのに、スマートフォンでは全体が縮小されて字が読めない
- 拡大しないと読めないページは、そこで離脱される

<!-- ノート: つかみ。実機で見せると一発。ここで結論は言わない。 -->

---

## 結論

**headにviewportのmetaを書くと、スマートフォンが実際の画面幅で表示する**

- **ビューポート** = ページが表示される領域の幅
- 書かないと、パソコン向けの幅だと想定して縮小表示される

<!-- ノート: 結論を言い切る。この1行が無いと、以降の指定がすべて意味を失う。 -->

---

## 最小のコード

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
</head>
```

- `width=device-width` = 端末の実際の幅を使う

<!-- ノート: 丸ごと覚える1行。骨組みの一部として毎回書く、でよい。 -->

---

## 書き忘れると何が起きるか

| 状態 | スマートフォンでの表示 |
| --- | --- |
| 書いた | 実際の幅で表示され、文字が読める |
| 書かない | 広い画面ぶんを縮小して表示。字が小さい |

<!-- ノート: 対比枠。ここが本題。CSS をいくら書いても、この1行が無いと直らない。 -->

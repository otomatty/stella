# 4-6-2
# max-widthで伸び縮みさせる

HTML/CSS入門研修 — Module 4 / レッスン4-6

<!-- ノート: viewport を書いても、幅を px で決め打っていると、はみ出しは直りません。 -->

---

## なぜ必要か

- `width: 600px` の箱は、幅400pxの画面でははみ出す
- はみ出すと横スクロールが出て、読むのに指2本が要る

<!-- ノート: つかみ。横スクロールの出るページは、それだけで使いにくい。ここで結論は言わない。 -->

---

## 結論

**widthの代わりにmax-widthを使うと、狭い画面でははみ出さずに縮む**

- **max-width** = 「ここまでは広がってよい」という上限
- **可変幅** = 画面に合わせて伸び縮みする幅

<!-- ノート: 結論を言い切る。width は「必ずこの幅」、max-width は「上限」。 -->

---

## 最小のコード

```css
.container {
  max-width: 600px;
  margin: 0 auto;
}
```

- 広い画面では600pxで中央、狭い画面では画面幅まで縮む

<!-- ノート: 4-2-5 の中央寄せと組で使う定番。この2行が実務のほぼ標準形。 -->

---

## 画像にも同じ手が要る

```css
img {
  max-width: 100%;
  height: auto;
}
```

- 画像は元の大きさのままはみ出すことがある
- `height: auto` で縦横比を保つ

<!-- ノート: 失敗例の枠。横スクロールの原因は、たいてい画像か決め打ちの width。 -->

---

**widthの代わりにmax-widthを使うと、狭い画面でははみ出さずに縮む**

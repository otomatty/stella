# レッスン4-6 画面幅に合わせる(最小)

## このレッスンの目標

- [ ] viewport の meta を書ける
- [ ] max-width と max-width: 100% ではみ出しを防げる
- [ ] メディアクエリーを1本書いて、狭い画面で並びを切り替えられる

## 4-6-1 viewportの指定で実際の幅に合わせる

> **headにviewportのmetaを書くと、スマートフォンが実際の画面幅で表示する**

パソコンでは整っているページが、スマートフォンでは全体が縮小されて字が読めない。これは、指定を1行書き忘れているために起きます。

スマートフォンのブラウザーは、指定が無いと「このページはパソコン向けに作られている」と想定し、広い画面ぶんの幅で組み立ててから、それを縮小して表示します。結果として、拡大しないと読めないページになります。

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
</head>
```

**ビューポート** は、ページが表示される領域の幅のことです。`width=device-width` は「端末の実際の幅を使う」、`initial-scale=1` は「最初の拡大率は等倍」という意味です。

| 状態 | スマートフォンでの表示 |
| --- | --- |
| 書いた | 実際の幅で組み立てられ、そのまま読める |
| 書かない | 広い画面ぶんを縮小表示。字が小さい |

この1行が無いと、このあと扱う指定はすべて効き目を失います。骨組みの一部として毎回書く、と決めてしまってください。

## 4-6-2 max-widthで伸び縮みさせる

> **widthの代わりにmax-widthを使うと、狭い画面でははみ出さずに縮む**

`viewport` を書いても、幅を `px` で決め打っているとはみ出しは直りません。`width: 600px` の箱は、幅400pxの画面でも600pxのままだからです。はみ出すと横スクロールが出て、読むのに指2本が必要になります。

```css
.container {
  max-width: 600px;
  margin: 0 auto;
}
```

**max-width** は「ここまでは広がってよい」という上限です。`width` が「必ずこの幅」なのに対し、`max-width` は上限だけを決めるので、画面が狭ければそのぶん縮みます。これが **可変幅** です。

広い画面では600pxで中央に置かれ、狭い画面では画面幅いっぱいまで縮む。4-2-5 の中央寄せと組み合わせたこの2行が、実務でのほぼ標準形です。

もう1つ、忘れやすいのが画像です。

```css
img {
  max-width: 100%;
  height: auto;
}
```

画像は元の大きさのまま表示されるので、画面より大きい写真を置くと、そこだけはみ出します。`max-width: 100%` で「親の幅を超えない」と決め、`height: auto` で縦横比を保ちます。横スクロールが出るときの原因は、たいてい画像か決め打ちの `width` です。

## 4-6-3 メディアクエリーで幅ごとに切り替える

> **メディアクエリーを1本書くと、決めた幅を境に別の宣言へ切り替えられる**

伸び縮みで耐えられる範囲には限界があります。横並びのメニューは、狭い画面では潰れて読めません。ここから先は、並べ方そのものを切り替える必要があります。

```css
.row {
  display: flex;
}

@media (max-width: 600px) {
  .row {
    display: block;
  }
}
```

`@media (...)` で始まる囲みが **メディアクエリー** です。条件に合うときだけ、中の宣言が有効になります。上の例は「画面の幅が600px以下のとき」という条件です。切り替える境目の幅を **ブレークポイント** と呼びます。

囲みの中の書き方は、いつものセレクタと宣言のままです。新しく覚えるのは囲みの形だけです。

実務で気をつける点は数です。端末ごとに何本もブレークポイントを作ると、直すたびにすべての幅を確認することになります。この講座では **1本だけ** 書ける状態を目標にします。

- まず `max-width` の可変幅で耐えられるところまで耐える
- ブラウザーの幅を少しずつ狭めて、**実際に崩れる幅** を見つける
- その幅をブレークポイントにして、1本だけ書く

端末の一覧から幅を決めるのではなく、自分のページが崩れる幅で決めてください。

## もっと知りたい人へ

- 複数のブレークポイントを使う本格的な設計や、親要素の幅で切り替えるコンテナクエリはこの講座の範囲外です。1本で足りない場面に出会ってから調べてください
- 条件には `min-width` も使えます。「600px以上のとき」という書き方で、狭い画面向けを既定にする作り方もあります

# 4-6-3
# メディアクエリーで幅ごとに切り替える

HTML/CSS入門研修 — Module 4 / レッスン4-6

<!-- ノート: この講座で扱う最後の並べ方です。1本だけ書けるようにします。 -->

---

## なぜ必要か

- 横並びのメニューは、狭い画面では潰れて読めない
- 伸び縮みだけでは、縦積みに切り替えることはできない

<!-- ノート: つかみ。可変幅で耐えられる限界があり、その先が切り替え。ここで結論は言わない。 -->

---

## 結論

**メディアクエリーを1本書くと、決めた幅を境に別の宣言へ切り替えられる**

- **メディアクエリー** = 条件に合うときだけ効かせるCSSの囲み
- **ブレークポイント** = 切り替える境目の幅

<!-- ノート: 結論を言い切る。条件に合うときだけ中身が有効になる、という形。 -->

---

## 最小のコード

```css
.row {
  display: flex;
}

@media (max-width: 600px) {
  .row {
    display: block;
  }
}
```

- 600px以下のときだけ、中の宣言が効いて縦積みになる

<!-- ノート: @media の中も、書き方はいつものセレクタと宣言。新しい構文は囲みだけ。 -->

---

## 1本で足りるようにする

- 端末ごとに何本も書くと、直すたびに全部を確認することになる
- まず可変幅で耐え、崩れる1点だけを切り替える

<!-- ノート: 失敗例の枠。ブレークポイントは端末の一覧ではなく、実際に崩れる幅で決める。 -->

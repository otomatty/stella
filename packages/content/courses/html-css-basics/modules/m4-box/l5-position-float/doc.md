# レッスン4-5 位置指定と浮動

## このレッスンの目標

- [ ] position: relative で、周りを動かさずに微調整できる
- [ ] position: absolute で、基準の箱の中に重ねられる
- [ ] float で文章の回り込みを作れる

## 4-5-1 position relativeは元の位置からずらす

> **position: relativeを指定すると、場所を保ったまま元の位置からずらせる**

ここまでの並べ方は、すべて **通常フロー** の上での話でした。通常フローとは、書いた順に上から積まれていく既定の並びのことです。ブロックは縦に積まれ、インラインは文字の流れに沿って横に並びます。

このレッスンでは、その流れから外れる置き方を扱います。

まず、アイコンを数px下げたいだけの微調整を考えます。`margin` で動かすと、隣の要素も一緒にずれます。`margin` は周りを押しのける指定だからです。

```css
.badge {
  position: relative;
  top: 4px;
  left: 8px;
}
```

**position** に **relative** を指定すると、その要素は **元の場所を空けたまま**、見た目だけがずれます。周りの要素は動きません。

`top` / `right` / `bottom` / `left` は、**その辺からのずらし幅** です。「その方向へ押す」ではない点に注意してください。

| 指定 | 動く向き |
| --- | --- |
| `top: 4px` | 上辺から4px、**下** へ |
| `left: 8px` | 左辺から8px、**右** へ |
| `right: 8px` | 右辺から8px、**左** へ |
| `bottom: 4px` | 下辺から4px、**上** へ |

まずは `top` と `left` の2つで足ります。

| 指定 | 周りへの影響 |
| --- | --- |
| `margin` | 隣を押しのけて、周りも動く |
| `position: relative` | 元の場所はそのまま。自分だけ動く |

間隔を設計するのは `margin`、数pxの微調整は `relative`、と使い分けてください。

## 4-5-2 position absoluteは基準の箱に重ねる

> **position: absoluteは通常フローから抜け、relativeを持つ先祖を基準に置かれる**

カードの右上に「新着」のラベルを重ねたい、という場面があります。通常フローに沿って置くかぎり、要素は他の要素の上には乗りません。

**absolute** を指定すると、その要素は通常フローから完全に抜けます。元の場所は空かず、周りは詰めて並び直します。流れの外に出るので、**重なり** を作れます。

```html
<div class="card">
  <span class="badge">新着</span>
</div>
```

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

ここでいちばん大切なのは **基準の決まり方** です。`absolute` を指定した要素は、先祖をさかのぼって最初に見つかった「`position` が `static` 以外の要素」を基準にします。実務では、基準にしたい親に `position: relative` を書いて指定します。

- 基準にしたい親 → `position: relative`
- 重ねたい子 → `position: absolute`

この2行はセットで覚えてください。親の `relative` を書き忘れると、基準がページ全体になります。カードの右上ではなく、画面の右上にラベルが飛んでいきます。**absolute が思わぬ場所に行ったら、まず親の relative を疑ってください。**

## 4-5-3 floatは文章を回り込ませる

> **floatを指定すると、その要素が左右に寄り、後ろの文章が回り込む**

記事の中の写真を左に置き、本文をその横に流したい。この **回り込み** は、Flexでも Grid でも作れません。並べた箱の中で文章が折り返すだけで、写真の下まで文章が回ることはないからです。

```css
.photo {
  float: left;
  margin-right: 16px;
}
```

```html
<img class="photo" src="images/venue.png" alt="会場" width="200" height="120" />
<p>4月から新しい研修が始まります。</p>
```

**float** に `left` を指定すると、その要素が左に寄り、後ろに続く文章が横と下を流れるように回り込みます。`right` なら右に寄ります。

`margin` を添えないと文字が画像にぴったりくっつくので、`float` と `margin` は組で使ってください。

注意点が1つあります。`float` は昔、横並びのレイアウトを作るためにも使われていました。古い解説記事をそのまま持ち込むと、崩れの原因になります。**段組みは Flex か Grid、`float` は回り込みだけ** と割り切ってください。

## もっと知りたい人へ

- `position` には、画面に貼り付ける `fixed` と、スクロールで途中から貼り付く `sticky` もあります。ヘッダーを常に表示させたいときに使います
- 回り込みを途中でやめたいときは、後ろの要素に `clear: both;` を指定します

# 4-5-3
# floatは文章を回り込ませる

HTML/CSS入門研修 — Module 4 / レッスン4-5

<!-- ノート: 古い指定ですが、いまも現役の用途が1つだけあります。そこに絞ります。 -->

---

## なぜ必要か

- 記事の中の写真を左に置き、本文をその横に流したい
- Flexで並べると、写真の下まで文章が回り込まない

<!-- ノート: つかみ。雑誌のような回り込みは、Flex でも Grid でも作れない。ここで結論は言わない。 -->

---

## 結論

**floatを指定すると、その要素が左右に寄り、後ろの文章が回り込む**

- **回り込み** = 文章が、寄せた要素の横と下を流れること
- 値は `left` または `right`

<!-- ノート: 結論を言い切る。かつてはレイアウト全般に使われたが、いまは回り込み専用。 -->

---

## 最小のコード

```css
.photo {
  float: left;
  margin-right: 16px;
}
```

```html
<img class="photo" src="images/venue.png" alt="会場" width="200" height="120" />
<p>4月から新しい研修が始まります。</p>
```

<!-- ノート: margin を添えないと文字が画像にくっつく。float と margin は組で使う。 -->

---

## 段組みには使わない

- 昔は横並びのレイアウトを `float` で作っていた
- いまは Flex か Grid を使う。`float` は回り込みだけ

<!-- ノート: 失敗例の枠。古い記事のコピーで float 段組みを持ち込むと、崩れの原因になる。 -->

# レッスン4-2 並べ方

## このレッスンの目標

- [ ] ブロックとインラインの違いを説明できる
- [ ] display: flex と gap で子要素を並べられる
- [ ] Flex の既定を説明でき、margin: 0 auto で箱を中央に置ける

## 4-2-1 ブロックは縦、インラインは横に並ぶ

> **要素にはブロックとインラインがあり、既定の並ぶ向きが違う**

同じCSSを書いたのに、要素によって結果が違うことがあります。段落は何もしなくても縦に積まれるのに、リンクは横に並びます。これは要素ごとに既定の性質が決まっているためです。

- **ブロック** — 横幅いっぱいを取り、縦に積まれます
- **インライン** — 文字の流れの中に置かれ、横に並びます

| 要素 | 性質 |
| --- | --- |
| 段落・見出し・div | ブロック |
| リンク・画像 | インライン |

文章の中に置くものがインライン、文章のかたまりを作るものがブロック、と考えるとおおむね合います。

この違いは幅の指定にも表れます。

```css
a {
  width: 300px;
}
```

インラインの要素には、この指定は効きません。幅は中身の文字の長さで決まるためです。「幅を指定したのに効かない」ときは、まず要素の性質を疑ってください。

## 4-2-2 display:flexで子を横に並べる

> **親にdisplay: flexを指定すると、子の要素が横に並ぶ**

カードを3枚横に並べたい、という場面はどの案件でも出てきます。ブロックの要素は何もしなければ縦に積まれるので、並べ方を変える指定が要ります。それが **display** というプロパティで、値に **flex** を指定します。

```html
<div class="row">
  <div class="card">1枚目</div>
  <div class="card">2枚目</div>
</div>
```

```css
.row {
  display: flex;
}
```

重要なのは **指定する相手** です。並べたいカードそのものではなく、それらを囲む **親要素** に書きます。

```css
.card {
  display: flex;
}
```

これはよくある間違いです。この指定で変わるのは、そのカードの **中身** の並び方です。「自分の子をどう並べるか」の指定だと覚えてください。並べたいものが2つ以上あるなら、それらを `div` で囲んで親を作ります。

## 4-2-3 gapで並べた箱のすき間を空ける

> **gapは、並べた子どうしのすき間だけをまとめて空ける**

横に並べると、今度は箱どうしがくっついて境目が分からなくなります。子に `margin` を付けて離すこともできますが、それだと両端にも余白が付いて、左右の位置が他の要素とずれます。

並べたものの **すき間** だけを空けるプロパティが **gap** です。

```css
.row {
  display: flex;
  gap: 16px;
}
```

子どうしのあいだだけが16px空きます。指定するのは、ここでも親です。子の数が増えても、指定は1行のままで足ります。

| 指定 | 効く場所 |
| --- | --- |
| 子に `margin` | 端を含むすべての外側 |
| 親に `gap` | 子どうしのあいだだけ |

並べたものの間隔は `gap`、単体の箱を隣から離すのは `margin`、と使い分けてください。

## 4-2-4 Flexの子は主軸に沿って縮む

> **flexの子は既定で主軸に沿って1行に並び、収まらなければ縮む**

`display: flex` の効果を「横に並ぶ」だけで覚えると、実務で必ずつまずきます。並べたカードが `width: 300px` と書いたのに300pxより細くなったり、高さがばらばらのはずのカードがなぜか揃ったりするからです。どちらも壊れているのではなく、既定の動きです。

まず用語を2つ決めます。

- **フレックスコンテナ** — `display: flex` を書いた親の要素
- **フレックスアイテム** — そのコンテナの直接の子

次に、軸が2本あることを押さえます。

- **主軸** — アイテムが並んでいく向き。既定は横
- **交差軸** — 主軸と直角の向き。既定は縦

以降で出てくる指定は、すべて「どちらの軸の話か」で決まります。ここを押さえると、プロパティ名を丸暗記せずに済みます。

既定の動きは3つです。

| 動き | 既定 |
| --- | --- |
| 並ぶ向き | 主軸(横)に1行で並ぶ |
| 収まらないとき | 折り返さずに、アイテムが縮む |
| 交差軸の大きさ | いちばん高いアイテムに合わせて高さが揃う |

「幅を指定したのに細くなる」のは2番目の動きです。並べたアイテムの幅の合計がコンテナより大きいとき、アイテムは折り返さずに縮んで収まろうとします。「高さが揃う」のは3番目です。カードの見た目が自然に揃うのは、この既定のおかげでもあります。

これらの既定を変える指定は、レッスン4-3でまとめて扱います。

## 4-2-5 margin autoで箱を中央に置く

> **幅を決めたブロックにmargin: 0 autoを指定すると、左右中央に置かれる**

画面の広いパソコンでページを開くと、本文が左端に寄って読みづらくなります。かといって `margin-left: 200px` のように数値で寄せると、画面幅が変わるたびに位置がずれます。

箱そのものをページの中央に置く定番の型があります。

```css
.container {
  width: 600px;
  margin: 0 auto;
}
```

**auto** は「残りを自動で分ける」という値です。左右の余白を両方 `auto` にすると、余った幅が左右に同じだけ配られ、結果として箱が真ん中に来ます。これが **中央寄せ** です。

`margin: 0 auto` の2つの値は「上下 左右」の意味です(4-1-3 で扱った書き方です)。

効かないときの原因はほぼ2つです。

- **幅を決めていない** — ブロックの要素は既定で横いっぱいに広がるので、分ける余りがありません。`width` か、あとで扱う `max-width` で幅を決めてください
- **中の文字を中央にしたかった** — `margin: 0 auto` が動かすのは箱そのものです。文字の寄せ方はレッスン5-2で扱います

## もっと知りたい人へ

- `display: flex` を指定した親には、子を中央に寄せたり、右端に寄せたりする指定も追加できます。まずは横に並べる、すき間を空ける、の2つを確実に使えるようにしてください
- 画面の幅が狭いときに縦積みに切り替える書き方もあります。この講座の範囲を超えるので、必要になったときに調べてください

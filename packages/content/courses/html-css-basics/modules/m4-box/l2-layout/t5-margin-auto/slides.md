# 4-2-5
# margin autoで箱を中央に置く

HTML/CSS入門研修 — Module 4 / レッスン4-2

<!-- ノート: 並べ方の最後です。1つの箱をページの中央に置く、という定番の型を渡します。 -->

---

## なぜ必要か

- 画面が広いと、本文が左端に寄って読みづらい
- 左の余白を数値で決めると、画面幅が変わるたびにずれる

<!-- ノート: つかみ。margin-left: 200px で寄せた画面を、幅を変えて見せると一発で伝わる。 -->

---

## 結論

**幅を決めたブロックにmargin: 0 autoを指定すると、左右中央に置かれる**

- **auto** = 「残りを自動で分ける」という値
- 左右に同じだけ配られるので、真ん中に来る

<!-- ノート: 結論を言い切る。仕組みは「余った幅を左右で山分けする」。 -->

---

## 最小のコード

```css
.container {
  width: 600px;
  margin: 0 auto;
}
```

- 上下は0、左右は `auto`
- **中央寄せ** の型として、そのまま覚えてよい

<!-- ノート: margin の2つ値は「上下 左右」。4-1-3 で扱った書き方の復習にもなる。 -->

---

## 効かないときの2つの原因

- 幅を決めていない(既定では横いっぱいなので、余りが無い)
- 中の文字ではなく、箱そのものが動く指定である

<!-- ノート: 失敗例の枠。文字を中央に寄せたいなら別のプロパティ。5-2 で扱う。 -->

---

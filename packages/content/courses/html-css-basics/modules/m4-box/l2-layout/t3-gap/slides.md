# 4-2-3
# gapで並べた箱のすき間を空ける

HTML/CSS入門研修 — Module 4 / レッスン4-2

<!-- ノート: レッスン4-2の最後です。横に並べたあとの仕上げにあたる指定です。 -->

---

## なぜ必要か

- 横に並べた箱がくっついて、境目が分からない
- 外側の余白で離すと、両端にも余白が付いて左右がずれる

<!-- ノート: つかみ。marginで離したときに端が揃わない、という経験を先に見せる。ここで結論は言わない。 -->

---

## 結論

**gapは、並べた子どうしのすき間だけをまとめて空ける**

- **gap** = 並べたものの **すき間** を指定するプロパティ
- 端には余白が付かない

<!-- ノート: 結論を言い切る。間だけに効く、が margin との決定的な違い。 -->

---

## 最小のコード

```css
.row {
  display: flex;
  gap: 16px;
}
```

- 子どうしのあいだだけが16px空く
- 指定するのは、ここでも親

<!-- ノート: flexと同じ場所に1行足すだけ。子の数が増えても指定は変わらない。 -->

---

## marginとの違い

| 指定 | 効く場所 |
| --- | --- |
| 子に `margin` | 端を含むすべての外側 |
| 親に `gap` | 子どうしのあいだだけ |

<!-- ノート: 対比枠。並べたものの間隔はgap、単体の箱を隣から離すのはmargin、と使い分ける。 -->

# 4-2-2
# display:flexで子を横に並べる

HTML/CSS入門研修 — Module 4 / レッスン4-2

<!-- ノート: この講座でいちばん実務で使う指定です。カードを横に並べる、が一発でできます。 -->

---

## なぜ必要か

- カードを3枚、横に並べたい
- ブロックの要素は、何もしなければ縦に積まれてしまう

<!-- ノート: つかみ。商品一覧やメニューの横並びは、どの案件でも必ず出てくる。ここで結論は言わない。 -->

---

## 結論

**親にdisplay: flexを指定すると、子の要素が横に並ぶ**

- **display** = 並び方の性質を変えるプロパティ
- **flex** を指定するのは、並べたいものの **親要素**

<!-- ノート: 結論を言い切る。指定するのは子ではなく親。ここを間違える人が多い。 -->

---

## 最小のコード

```html
<div class="row">
  <div class="card">1枚目</div>
  <div class="card">2枚目</div>
</div>
```

```css
.row {
  display: flex;
}
```

- 親の `.row` に指定すると、中の2枚が横に並ぶ

<!-- ノート: HTMLとCSSを並べて見せる。親に1行足すだけで並びが変わる、という手応えを渡す。 -->

---

## よくある間違い

```css
.card {
  display: flex;
}
```

- 並べたい箱そのものに指定している
- 変わるのは、その箱の **中身** の並び方

<!-- ノート: 失敗例の枠。flexは「自分の子をどう並べるか」の指定。誰に書くかで結果が変わる。 -->

---

**親にdisplay: flexを指定すると、子の要素が横に並ぶ**

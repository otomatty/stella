# レッスン4-2 演習 — 並べ方

対象トピック: 4-2-1 〜 4-2-3

## 手元で試す

`index.html` の body に、カードを2枚囲んだ親を作ります。

```html
<div class="row">
  <div class="card">
    <h2>4月研修</h2>
    <p>対象は入社1年目の方です。</p>
  </div>
  <div class="card">
    <h2>5月研修</h2>
    <p>対象は2年目以降の方です。</p>
  </div>
</div>
```

`style.css` に次を足して保存し、再読み込みしてください。カードどうしの間隔は `gap` に任せるので、レッスン4-1で `.card` に付けた `margin: 24px;` は 0 に戻します(後に書いた宣言が勝ちます)。

```css
.row {
  display: flex;
  gap: 16px;
}

.card {
  margin: 0;
}
```

2枚のカードが横に並び、あいだにすき間ができれば成功です。書けたら、次の改造をしてみましょう。

1. `display: flex;` の行を消して、縦に積まれることを確かめる(確かめたら戻す)
2. `gap` を 0 にして、カードがくっつくことを確かめる(確かめたら16pxに戻す)
3. `display: flex;` を `.row` ではなく `.card` に書いてみて、期待した並びにならないことを確かめる(確かめたら戻す)

## 演習問題

### 問1(基本)

`.menu` という親の中にある子要素を横に並べるCSSを書いてください。

### 問2(基本)

段落は縦に積まれるのに、リンクは横に並びます。この違いは何によるものですか。

### 問3(応用)

横に並べた3枚のカードのあいだだけに24pxの間隔を空けたいとします。gap と margin のどちらを使いますか。理由も1文で書いてください。

### 問4(応用)

`a` に `width: 300px;` を指定しても幅が変わりませんでした。理由を1文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```css
.menu {
  display: flex;
}
```

指定するのは並べたい子ではなく、囲んでいる親です。

</details>

<details>
<summary>問2の解答例</summary>

要素の既定の性質の違いです。段落はブロックで縦に積まれ、リンクはインラインで文字の流れの中に横に並びます。

</details>

<details>
<summary>問3の解答例</summary>

gap を使います。gap は子どうしのあいだだけに効くので、両端に余白が付かず、左右の位置が他の要素とそろいます。

</details>

<details>
<summary>問4の解答例</summary>

`a` はインラインの要素で、幅は中身の文字の長さで決まるためです。

</details>

## 確認クイズ

### Q1. 何も指定しないとき、縦に積まれるのはどちらの性質ですか。

- A. ブロック
- B. インライン
- C. どちらも縦に積まれる

<details>
<summary>答え</summary>

**A** — ブロックは横幅いっぱいを取り、縦に積まれます。インラインは文字の流れの中で横に並びます。

</details>

### Q2. display: flex を指定する相手はどれですか。

- A. 横に並べたい要素そのもの
- B. 横に並べたい要素を囲む親要素
- C. body だけ

<details>
<summary>答え</summary>

**B** — 「自分の子をどう並べるか」の指定なので、親に書きます。

</details>

### Q3. 並べた子どうしのあいだだけを空けるプロパティはどれですか。

- A. margin
- B. padding
- C. gap

<details>
<summary>答え</summary>

**C** — gap は間だけに効きます。margin は端にも余白が付きます。

</details>

### Q4. インラインの要素に width を指定するとどうなりますか。

- A. 指定した幅になる
- B. 効かず、中身の長さで幅が決まる
- C. エラーになって表示されなくなる

<details>
<summary>答え</summary>

**B** — 幅の指定が効かないときは、要素の性質を疑ってください。

</details>

### Q5. カードを横に並べたいのに縦に積まれてしまいます。まず確認することはどれですか。

- A. 親に display: flex を書いたか
- B. カードの文字数がそろっているか
- C. 画像を使っているか

<details>
<summary>答え</summary>

**A** — 指定する相手を間違えていないかを確認します。書く場所は親です。

</details>

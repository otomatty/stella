# ブロックは縦、インラインは横に並ぶ

HTML/CSS入門 — Module 4 / レッスン4-2

<!-- ノート: 並べ方の話に入ります。まず、何もしなくてもどう並ぶのかを押さえます。 -->

---

## なぜ必要か

- 段落は勝手に縦に並ぶのに、リンクは横に並ぶ
- 幅を指定しても効く要素と効かない要素がある

<!-- ノート: つかみ。同じCSSを書いたのに結果が違う、という体験の説明がここにある。 -->

---

## 結論

**要素にはブロックとインラインがあり、既定の並ぶ向きが違う**

- **ブロック** = 横幅いっぱいを取り、縦に積まれる
- **インライン** = 文字の流れの中で横に並ぶ

<!-- ノート: 結論を言い切る。要素ごとに既定の性質が決まっている。 -->

---

## どちらの仲間か

| 要素 | 性質 |
| --- | --- |
| 段落・見出し・div | ブロック |
| リンク・画像 | インライン |

<!-- ノート: 代表的なものだけ。文章の中に置くものがインライン、と考えるとおおむね合う。 -->

---

## 幅の指定が効かないことがある

```css
a {
  width: 300px;
}
```

- インラインの要素には、この指定は効かない
- 中身の文字の長さで幅が決まるため

<!-- ノート: 失敗例の枠。「効かない」の原因が性質の違いにある、と分かれば調べ方が変わる。 -->

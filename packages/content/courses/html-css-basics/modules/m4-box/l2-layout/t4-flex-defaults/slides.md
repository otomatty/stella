# 4-2-4
# Flexの子は主軸に沿って縮む

HTML/CSS入門 — Module 4 / レッスン4-2

<!-- ノート: 「横に並ぶ」で止めると、あとで必ず「なぜ縮む」でつまずきます。ここで既定を回収します。 -->

---

## なぜ必要か

- `width: 300px` と書いたカードが、並べたら300pxより細くなる
- カードの高さがばらばらのはずなのに、なぜか揃っている

<!-- ノート: つかみ。どちらも flex の既定の動き。知らないとバグに見える。ここで結論は言わない。 -->

---

## 結論

**flexの子は既定で主軸に沿って1行に並び、収まらなければ縮む**

- **フレックスコンテナ** = `display: flex` を書いた親
- **フレックスアイテム** = その直接の子

<!-- ノート: 結論を言い切る。用語を2つ先に固めてから、軸の話に進む。 -->

---

## 2つの軸

- **主軸** = アイテムが並んでいく向き。既定は横
- **交差軸** = 主軸と直角の向き。既定は縦

<!-- ノート: 以降の指定はすべて「どちらの軸か」で決まる。ここが理解の分かれ目。 -->

---

## 既定の3つの動き

| 動き | 既定 |
| --- | --- |
| 並ぶ向き | 主軸(横)に1行 |
| 収まらないとき | 折り返さず縮む |
| 交差軸の大きさ | 高さが揃う |

<!-- ノート: 対比枠。ここが本題。「縮む」「揃う」は壊れているのではなく既定の動き。 -->

---

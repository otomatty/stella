# 4-1-3
# marginは箱の外側の余白

HTML/CSS入門研修 — Module 4 / レッスン4-1

<!-- ノート: 内側の次は外側です。2つの違いがはっきりすると、余白の調整で迷わなくなります。 -->

---

## なぜ必要か

- カードが隣とくっついて、どこまでが1枚か分からない
- 内側の余白をいくら増やしても、隣との距離は変わらない

<!-- ノート: つかみ。paddingを増やして箱が太っただけ、という失敗を先に見せる。ここで結論は言わない。 -->

---

## 結論

**marginは、ボーダーの外側に空ける、隣とのあいだの余白**

- **margin** = 箱の **外側の余白**
- 背景色は、この余白には付かない

<!-- ノート: 結論を言い切る。外側なので背景の外。paddingとの違いはここで見分けられる。 -->

---

## 最小のコード

```css
.card {
  border: 1px solid gray;
  padding: 16px;
  margin: 24px;
}
```

- 箱の外に24pxの余白ができ、隣と離れる
- 書き方は `padding` と同じ

<!-- ノート: 書き方が同じなので、覚えるのは違いだけ。内側か外側か。 -->

---

## 使い分け

| したいこと | 使うもの |
| --- | --- |
| 枠と文字を離す | padding |
| 隣の箱と離す | margin |

<!-- ノート: 対比枠。この表だけで実務の判断はほぼ足りる。背景色を付けて見比べると違いが体感できる。 -->

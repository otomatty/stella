# レッスン4-1 ボックスと余白

## このレッスンの目標

- [ ] 要素を箱として捉えられる
- [ ] padding と margin を使い分けられる
- [ ] box-sizing で幅の数え方を揃えられる

## 4-1-1 要素は四角い箱として置かれる

> **すべての要素は、幅と高さを持つ四角い箱として置かれる**

配置の調整が勘だのみになるのは、見えないものを動かしているからです。見方を1つ変えます。見出しも段落も画像も、例外なく四角い箱として置かれています。この箱を **ボックス** と呼びます。

```css
.card {
  width: 300px;
  height: 120px;
  border: 1px solid gray;
}
```

- `width` — 箱の **幅**
- `height` — 箱の **高さ**
- `border` — 箱の縁の **ボーダー**。「太さ 線の種類 色」の順に書きます

配置に迷ったら、`border` を仮に付けて箱の位置と大きさを目で確かめてください。どこまでが1つの箱か分かるだけで、原因が一気に絞れます。直し終わったら消します。

なお、`height` はできるだけ指定しないのが基本です。文字数が増えたときに中身がはみ出すためです。高さは中身に決めさせて、余白で調整します。

## 4-1-2 paddingは箱の内側の余白

> **paddingは、ボーダーと中身のあいだに空ける内側の余白**

枠や背景色を付けると、文字が縁にくっついて窮屈に見えます。縁と中身のあいだに空ける **内側の余白** が **padding** です。

```css
.card {
  border: 1px solid gray;
  padding: 16px;
}
```

値を1つ書くと、上下左右すべてに効きます。背景色を付けた場合、色はこの余白の分まで広がります。内側の余白だからです。

辺ごとに変えることもできます。

```css
.card {
  padding: 16px 24px;
}
```

値が2つのときは「上下、左右」の順です。片側だけ変えたいときは `padding-top` のように書きます。まずは値1つ、次に値2つの書き方を覚えれば足ります。

## 4-1-3 marginは箱の外側の余白

> **marginは、ボーダーの外側に空ける、隣とのあいだの余白**

カードが隣とくっついているとき、`padding` をいくら増やしても解決しません。箱が太るだけで、隣との距離は変わらないからです。隣と離すのは **外側の余白** である **margin** です。

```css
.card {
  border: 1px solid gray;
  padding: 16px;
  margin: 24px;
}
```

書き方は `padding` と同じです。値1つで四辺、値2つで上下と左右です。違うのは効く場所だけです。背景色は `margin` の領域には付きません。外側だからです。

| したいこと | 使うもの |
| --- | --- |
| 枠や背景と文字を離す | padding |
| 隣の箱と離す | margin |

見分けがつかなくなったら、背景色を付けてみてください。色が付くほうが内側です。

## 4-1-4 box-sizingで幅の数え方を揃える

> **box-sizing: border-box にすると、widthがボーダーまで含めた幅になる**

幅を300pxに指定した箱に `padding` を足したら、横並びが折り返してしまった。よくある崩れ方です。原因は幅の数え方です。既定では、`width` は **中身だけ** の幅を指します。余白と枠は、そこにあとから足されます。

数え方を変えるプロパティが **box-sizing** です。**border-box** を指定すると、`width` が余白と枠まで含めた幅になります。

```css
.card {
  box-sizing: border-box;
  width: 300px;
  padding: 16px;
  border: 1px solid gray;
}
```

| box-sizing | width 300px の実際の幅 |
| --- | --- |
| 既定 | 300 + padding + border |
| `border-box` | ちょうど 300 |

`border-box` にしておけば、指定した数字がそのまま見た目の幅になります。余白を足しても全体の幅は変わらず、中身の幅が自動で調整されます。実務では、スタイルシートの先頭ですべての要素にまとめて指定することが多い設定です。まずは使う箱に個別に書けば十分です。

## もっと知りたい人へ

- ボーダーには `solid` のほか `dashed`(破線)や `dotted`(点線)などの種類があります
- `margin` を `auto` にすると、箱を左右の中央に寄せられます。幅を指定した箱で使える書き方です

# 4-1-5
# borderは太さ・線種・色をまとめて書く

HTML/CSS入門研修 — Module 4 / レッスン4-1

<!-- ノート: ボーダーは 4-1-1 から名前だけ出ていました。ここで実際に引きます。 -->

---

## なぜ必要か

- カードの範囲が背景色だけでは分かりにくい
- 入力欄や区切り線は、線が引けないと作れない

<!-- ノート: つかみ。箱の境目が見えると、余白の効き方も目で確かめられる。ここで結論は言わない。 -->

---

## 結論

**ボーダーはborderに太さ・線種・色の3つを空白で並べて指定する**

- **border** = 箱の枠線を引くプロパティ
- 3つの値を、この順で空白区切りで書く

<!-- ノート: 結論を言い切る。3つ別々のプロパティもあるが、まとめて書く形を覚えれば足りる。 -->

---

## 最小のコード

```css
.card {
  border: 1px solid gray;
  padding: 16px;
}
```

- **線種** = 線の引き方。`solid` は実線

<!-- ノート: padding を添えているのは、枠と文字がくっつくのを避けるため。4-1-2 の復習にもなる。 -->

---

## よく使う線種

| 値 | 見た目 |
| --- | --- |
| `solid` | 実線 |
| `dashed` | 破線 |
| `none` | 線を引かない |

<!-- ノート: 対比枠。none は「既定の枠を消す」場面で使う。入力欄の枠を消すときなど。 -->

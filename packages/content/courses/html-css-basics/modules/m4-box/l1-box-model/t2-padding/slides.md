# 4-1-2
# paddingは箱の内側の余白

HTML/CSS入門 — Module 4 / レッスン4-1

<!-- ノート: 箱の見方ができたので、余白を2種類に分けます。まず内側です。 -->

---

## なぜ必要か

- 枠を付けたら、文字が枠にぴったりくっついて読みにくい
- 背景色を付けたら、文字と色の境目が窮屈に見える

<!-- ノート: つかみ。実際にpadding無しのカードを見せると一目で伝わる。ここで結論は言わない。 -->

---

## 結論

**paddingは、ボーダーと中身のあいだに空ける内側の余白**

- **padding** = 箱の **内側の余白**
- 背景色や枠は、この余白の分まで広がる

<!-- ノート: 結論を言い切る。内側なので、背景色はpaddingの領域にも付く。 -->

---

## 最小のコード

```css
.card {
  border: 1px solid gray;
  padding: 16px;
}
```

- 上下左右すべてに16pxの余白が付く
- 枠と文字のあいだにゆとりができる

<!-- ノート: 1つの値を書くと四辺すべてに効く。上下と左右で変えたいときは値を2つ並べる書き方もある。 -->

---

## 辺ごとに指定できる

```css
.card {
  padding: 16px 24px;
}
```

- 値が2つのときは「上下、左右」の順
- 片側だけなら `padding-top` のように書く

<!-- ノート: 対比枠。値の個数で意味が変わる。まずは1つの値、次に2つの値、の順で覚えれば足りる。 -->

---

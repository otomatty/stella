# 要素は四角い箱として置かれる

HTML/CSS入門 — Module 4 / レッスン4-1

<!-- ノート: ここから配置の話です。まず、画面に何が並んでいるのかの捉え方を変えます。 -->

---

## なぜ必要か

- 「もう少し右に」「もう少し空けて」の調整が、勘でしかできない
- 見えていない領域があると、余白の増減が予想と合わない

<!-- ノート: つかみ。CSSの配置で迷子になるのは、見えないものを操作しているから。ここで結論は言わない。 -->

---

## 結論

**すべての要素は、幅と高さを持つ四角い箱として置かれる**

- この箱を **ボックス** と呼ぶ
- 見出しも段落も画像も、例外なく箱

<!-- ノート: 結論を言い切る。画面は箱が積まれたもの、という見方に切り替えてもらう。 -->

---

## 最小のコード

```css
.card {
  width: 300px;
  height: 120px;
  border: 1px solid gray;
}
```

- `width` が **幅**、`height` が **高さ**
- `border` が箱の縁の **ボーダー**

<!-- ノート: borderを付けると箱の輪郭が見える。学習中は仮に枠を付けて確かめるのが早い。 -->

---

## まず枠を見えるようにする

- 配置に迷ったら、`border` を仮に付けて箱の位置を目で確かめる
- 直し終わったら消す

<!-- ノート: 対比枠。透明な箱を勘で動かすより、いったん見えるようにするほうが速い。デバッグの型として渡す。 -->

---

## まとめ

**すべての要素は、幅と高さを持つ四角い箱として置かれる**

<!-- ノート: 結論の再掲だけ。箱の内側と外側では余白の意味が違う、と引いて締める。 -->

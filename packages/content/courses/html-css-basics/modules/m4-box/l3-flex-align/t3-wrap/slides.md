# flex-wrapで折り返しを許す

## なぜ必要か

- カードを6枚並べたら、1枚ずつが細くなって中身が読めない
- スマートフォンで見ると、文字が縦一列になってしまう

<!-- ノート: つかみ。実際に細長く潰れたカードを見せると伝わる。ここで結論は言わない。 -->

---

## 結論

**flex-wrap: wrapを指定すると、1行に収まらないアイテムが次の行へ送られる**

- 既定は `nowrap`。1行のまま、アイテムが縮んで収まろうとする
- **折り返し** を許すと、収まらないぶんが次の行へ回る

<!-- ノート: 結論を言い切る。既定を1行変えるだけで、狭い画面でも読める並びになる。 -->

---

## 最小のコード

```css
.row {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  width: 300px;
}
```

<!-- ノート: 幅を決めたアイテムと組で使うのが基本形。gap は行間にも効く。 -->

---

## 縮むか、折り返すか

| 指定 | 収まらないとき |
| --- | --- |
| `nowrap`(既定) | 1行のまま、アイテムが縮んで収まろうとする |
| `wrap` | 複数の行に分けて並べる |

<!-- ノート: 対比枠。ここが本題。wrap は行を分ける指定で、縮む・縮まないを決める指定ではない。どちらが正しいではなく、中身が読めるほうを選ぶ。 -->

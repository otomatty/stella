# 4-3-1
# justify-contentは主軸の寄せ方

HTML/CSS入門研修 — Module 4 / レッスン4-3

<!-- ノート: 既定の並びを覚えたので、ここからは並びの調整です。まず主軸から。 -->

---

## なぜ必要か

- ヘッダーで、ロゴを左、メニューを右に置きたい
- 余白を `margin` で調整すると、画面幅が変わるたびにずれる

<!-- ノート: つかみ。両端に寄せる並びは、どの案件でも必ず出てくる。ここで結論は言わない。 -->

---

## 結論

**justify-contentは、フレックスアイテムを主軸のどこに寄せるかを決める**

- 指定するのは、いつもどおりコンテナ側
- 既定は先頭寄せ(`flex-start`)

<!-- ノート: 結論を言い切る。名前は覚えにくいが、「主軸の寄せ方」とだけ覚える。 -->

---

## 最小のコード

```css
.header {
  display: flex;
  justify-content: space-between;
}
```

- **space-between** = 両端に寄せて、余りを間に配る

<!-- ノート: ロゴとメニューの2つなら、これだけで左右に離れる。margin の調整は要らない。 -->

---

## よく使う値

| 値 | 並び方 |
| --- | --- |
| `flex-start` | 先頭に寄せる(既定) |
| `center` | 中央に寄せる |
| `flex-end` | 末尾に寄せる |
| `space-between` | 両端に寄せ、余りを間に配る |

<!-- ノート: 対比枠。4つで足りる。値の名前より「どこに寄るか」の絵で覚えてもらう。 -->

# 4-3-2
# align-itemsは交差軸の揃え方

HTML/CSS入門研修 — Module 4 / レッスン4-3

<!-- ノート: 主軸の次は交差軸。プロパティが違うだけで、考え方は同じです。 -->

---

## なぜ必要か

- アイコンと文字を横に並べると、高さがずれて不格好になる
- 文章の量が違うカードで、ボタンの位置がばらばらになる

<!-- ノート: つかみ。1pxのずれでも目立つ。ここで結論は言わない。 -->

---

## 結論

**align-itemsは、フレックスアイテムを交差軸のどこに揃えるかを決める**

- 主軸が `justify-content`、交差軸が `align-items`
- 既定は `stretch`(引き伸ばして高さを揃える)

<!-- ノート: 結論を言い切る。4-2-4 で見た「高さが揃う」は、この既定によるもの。 -->

---

## 最小のコード

```css
.row {
  display: flex;
  align-items: center;
}
```

- 高さの違うアイテムが、上下の中心でそろう

<!-- ノート: アイコンと文字の縦位置合わせは、実務でいちばん使う指定のひとつ。 -->

---

## よく使う値

| 値 | 揃え方 |
| --- | --- |
| `stretch` | 高さを引き伸ばして揃える(既定) |
| `center` | 交差軸の中央にそろえる |
| `flex-start` | 交差軸の先頭(上)にそろえる |

<!-- ノート: 対比枠。center を指定した瞬間、伸びるのをやめて中身の高さになる点だけ補う。 -->

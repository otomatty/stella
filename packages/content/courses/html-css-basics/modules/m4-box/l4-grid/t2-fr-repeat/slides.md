# 4-4-2
# frは余った幅を配る単位

HTML/CSS入門研修 — Module 4 / レッスン4-4

<!-- ノート: 列幅を px で決め打つ問題を、ここで解きます。 -->

---

## なぜ必要か

- `200px` を3つ並べると、画面が広いとき右側が大きく余る
- 画面が狭いときは、横にはみ出してしまう

<!-- ノート: つかみ。決め打ちの幅は、作った環境でしか正しくない。ここで結論は言わない。 -->

---

## 結論

**列幅にfrを使うと、余った幅がその比率で配られる**

- **fr** = 余った幅を分け合うための単位
- `1fr 1fr 1fr` なら、3等分

<!-- ノート: 結論を言い切る。fr は fraction(分数)の略。px のような固定の長さではない。 -->

---

## 最小のコード

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}
```

- 画面幅が変わっても、3等分のまま

<!-- ノート: gap を引いた残りが分けられる。計算をこちらでする必要がない点が大きい。 -->

---

## repeatで繰り返しを短く

```css
grid-template-columns: repeat(3, 1fr);
```

- **repeat** = 同じ指定の繰り返しをまとめる書き方
- 列数が増えても1か所直せば済む

<!-- ノート: 12列など数が増えると効果が分かる。混ぜて `200px repeat(2, 1fr)` とも書ける。 -->

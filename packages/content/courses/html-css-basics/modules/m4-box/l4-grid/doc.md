# レッスン4-4 Gridの基本

## このレッスンの目標

- [ ] display: grid と grid-template-columns で格子を作れる
- [ ] fr と repeat で列幅を配分できる
- [ ] grid-column の span で複数の列にまたがらせられる

## 4-4-1 display gridは格子に並べる

> **親にdisplay: gridとgrid-template-columnsを書くと、子が決めた列数の格子に並ぶ**

Flexは1方向に並べる仕組みでした。折り返しても、それは「収まったところで改行する」動きなので、行ごとの列の位置がきれいにそろうとは限りません。「3列 × 2行」のような格子を作りたいときは、別の仕組みを使います。

**グリッド** は、行と列であらかじめ区切った格子です。先に枠を決めて、そこに子を流し込みます。

```css
.grid {
  display: grid;
  grid-template-columns: 200px 200px 200px;
  gap: 16px;
}
```

**grid-template-columns** に並べた値の数が、そのまま列の数になります。上の例は3列です。子は左上から順に、1行目の3マス、2行目の3マス……と埋まっていきます。

行の数を指定する必要はありません。子の数に合わせて、必要なぶんだけ行が作られます。

`gap` はFlexのときと同じように使えます。列と列、行と行のあいだにすき間が空きます。

| 仕組み | 決め方 | 向いている場面 |
| --- | --- | --- |
| Flex | 1方向に並べ、収まらなければ縮む・折り返す | 横一列のヘッダー、ボタンの並び |
| Grid | 先に列を決め、その枠に流し込む | カードの一覧、ページ全体の区画 |

「並びが縦横そろってほしい」ならGrid、と選んでください。

## 4-4-2 frは余った幅を配る単位

> **列幅にfrを使うと、余った幅がその比率で配られる**

列幅を `200px` のように決め打つと、画面の広い環境では右側が大きく余り、狭い環境では横にはみ出します。作った環境でしか正しくない指定です。

**fr** は、余った幅を分け合うための単位です。

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}
```

`1fr` が3つなので、使える幅が3等分されます。画面幅が変わっても3等分のままです。`gap` のぶんを引いた残りが分けられるので、こちらで計算する必要はありません。

比率も指定できます。`2fr 1fr` と書けば、左が2、右が1の割合になります。

同じ指定の繰り返しは **repeat** でまとめられます。

```css
grid-template-columns: repeat(3, 1fr);
```

意味は `1fr 1fr 1fr` と同じです。列数が増えたときに書き換えが1か所で済みます。固定幅と混ぜて `200px repeat(2, 1fr)` のようにも書けます。左の200pxはそのままで、残りを2つで分け合う形です。

## 4-4-3 grid-columnで複数の列にまたがる

> **grid-columnにspanを書くと、そのアイテムが複数の列にまたがる**

すべてのマスが同じ大きさだと、どれが重要なのか伝わりません。「先頭の1件だけ大きく」といった強弱を付けたいときは、そのアイテムに指定します。

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

.featured {
  grid-column: span 2;
}
```

ここまでの指定はすべてコンテナ側に書いてきましたが、**これはアイテム側に書きます**。並べ方はコンテナ、個別の大きさはアイテム、と役割で分かれていると考えてください。

**span** は「いくつぶん使うか」を表す書き方です。`span 2` なら2列ぶんを占め、残りの1列に次のアイテムが入ります。

気をつける点は1つです。列数より大きい値を書かないでください。

```css
.featured {
  grid-column: span 4;
}
```

3列しかないのに4列ぶんを要求しているので、足りないぶんの列がブラウザーによって自動で作られます。`grid-template-columns` に書いた3列の設計は崩れ、中身の量によっては横にはみ出します。列数を変えたときは、`span` の値もあわせて見直してください。

## もっと知りたい人へ

- 行方向にまたがらせる `grid-row` もあります。書き方は `grid-column` と同じです
- `grid-template-areas` を使うと、区画に名前を付けて図のようにレイアウトを書けます。ページ全体の骨組みを作るときに便利です

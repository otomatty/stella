## なぜ必要か

- お知らせの一覧で、先頭の1件だけ大きく見せたい

## 結論

**grid-columnにspanを書くと、そのアイテムが複数の列にまたがる**

- 指定するのは、コンテナではなく **そのアイテム**
- **span** = 「いくつぶん使うか」を表す書き方

<!-- ノート: 結論を言い切る。ここだけ子に書く。並べ方はコンテナ、個別の大きさはアイテム。 -->

---

## 最小のコード

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

.featured {
  grid-column: span 2;
}
```

<!-- ノート: 3列のうち2列ぶんを使う。残りの1列に次のアイテムが入る。 -->

---

## 列数より大きい値に注意

```css
.featured {
  grid-column: span 4;
}
```

- 3列しかないのに4列ぶんを要求している
- 足りないぶんの列が自動で作られ、3列の設計が崩れる

<!-- ノート: 失敗例の枠。宣言していない列(暗黙の列)が足される。幅は中身次第なので、はみ出すこともある。span の値は列数以下にする。 -->

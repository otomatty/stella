# リストは箇条書きを表す

HTML/CSS入門 — Module 1 / レッスン1-2

<!-- ノート: 業務のページで最も出番が多いのが箇条書きです。入れ子の実例にもなります。 -->

---

## なぜ必要か

- 持ち物や手順は、文章より箇条書きのほうが伝わる
- 記号を手で打って並べると、番号のふり直しが毎回発生する

<!-- ノート: つかみ。「・」を全角で打って並べた資料あるある。順番が変わるたびに打ち直しになる。 -->

---

## 結論

**並んだ項目はulまたはolの中にliを並べて表す**

- `ul` = 順番のない **リスト**(黒丸が付く)
- `ol` = 順番のあるリスト(番号が付く)
- `li` = 1つの **項目**

<!-- ノート: 結論を言い切る。ulとolの違いは順番に意味があるかどうか。番号は自動で付く。 -->

---

## 最小のコード

```html
<ul>
  <li>筆記用具</li>
  <li>ノートパソコン</li>
</ul>
```

- `ul` が親要素、`li` が子要素
- 記号や番号は自分で書かない

<!-- ノート: 入れ子の実例。liは必ずulかolの中に置く。単独では使わない。 -->

---

## 順番があるならol

```html
<ol>
  <li>申し込みフォームを送る</li>
  <li>受講案内のメールを受け取る</li>
</ol>
```

- 手順や順位は `ol`
- 途中に項目を足しても、番号は自動でふり直される

<!-- ノート: 対比枠。ulとolの選び分けは「順番を入れ替えたら意味が変わるか」で決める。 -->

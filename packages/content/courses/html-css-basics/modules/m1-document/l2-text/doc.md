# レッスン1-2 文章とリンク

## このレッスンの目標

- [ ] 見出しの番号を階層で選べる
- [ ] 段落とリストを使い分けて文章を書ける
- [ ] href で行き先を指定したリンクを作れる

## 1-2-1 見出しはh1〜h6で階層を作る

> **見出しはh1〜h6の番号で、内容の階層を表す**

**見出し** には `h1` から `h6` までの6段階があります。番号が小さいほど上位で、番号の順が内容の **階層** を表します。

```html
<h1>社内研修のご案内</h1>
<h2>対象者</h2>
<h2>受講の流れ</h2>
<h3>1. 申し込み</h3>
```

本にたとえると、タイトルが `h1`、章が `h2`、節が `h3` です。`h1` はそのページが何のページかを表すので、ページに1つが基本です。

気をつけたいのは、**大きさで選ばない** ことです。

```html
<h1>社内研修のご案内</h1>
<h4>対象者</h4>
```

「`h2` は大きすぎたから `h4` にした」という選び方をすると、階層が壊れます。目次を自動で作る仕組みや、画面を読み上げるソフトは、この番号を手がかりにページの構成を判断しています。大きさが気に入らないときは、CSSで大きさを変えてください(モジュール5で扱います)。

## 1-2-2 段落はpで区切る

> **文章のひとかたまりは、pで1段落ずつ区切る**

HTMLは、エディタで入れた **改行** をそのまま画面の改行にはしません。空行をいくつ入れても、表示は変わりません。連続した空白や改行は、まとめて1つの空白として扱われます。

**段落** の区切りは `p` で伝えます。

```html
<p>4月から新しい研修が始まります。</p>
<p>対象は入社1年目の方です。</p>
```

段落が2つになり、あいだに余白が付きます。この余白はブラウザーの既定値で、あとからCSSで調整できます。

次の書き方は表示が1行につながります。

```html
<p>
  4月から新しい研修が始まります。
  対象は入社1年目の方です。
</p>
```

`p` の中で改行しても、それは書き手の都合の改行としか扱われません。段落を分けたいなら `p` を分けてください。

## 1-2-3 リストは箇条書きを表す

> **並んだ項目はulまたはolの中にliを並べて表す**

持ち物や手順のように並んだものは、**リスト** で書きます。

- `ul` — 順番のないリスト。黒丸が付きます
- `ol` — 順番のあるリスト。番号が付きます
- `li` — 1つの **項目**

```html
<ul>
  <li>筆記用具</li>
  <li>ノートパソコン</li>
</ul>
```

`ul` が親要素、`li` が子要素です。入れ子の実例になっています。`li` は必ず `ul` か `ol` の中に置きます。

記号や番号は自分で書きません。「・」を打って並べると、あとから並び替えたときに手で直すことになります。

順番に意味があるなら `ol` を使います。

```html
<ol>
  <li>申し込みフォームを送る</li>
  <li>受講案内のメールを受け取る</li>
</ol>
```

途中に項目を足しても、番号は自動でふり直されます。選び分けの基準は「順番を入れ替えたら意味が変わるか」です。変わるなら `ol`、変わらないなら `ul` です。

## 1-2-4 リンクはaのhrefでつなぐ

> **aのhref属性に行き先を書くと、クリックで移動できるリンクになる**

**リンク** は `a` という要素で作ります。行き先は **href** という属性に書きます。

```html
<p>詳細は<a href="https://example.com/training">研修案内</a>をご覧ください。</p>
```

押せるのはタグで囲んだ「研修案内」の部分だけです。行き先のURLは画面には出ません。属性は画面に出ない情報、中身は画面に出る文字、という1-1-2の役割分担がそのまま当てはまります。

中身に書く言葉にも注意してください。

```html
<a href="https://example.com/training">こちら</a>
<a href="https://example.com/training">研修案内</a>
```

上の書き方だと、リンクだけを拾って読む人には何のリンクか分かりません。画面を読み上げるソフトには、リンクだけを一覧にする機能があります。リンクの中身には、それだけ読んで行き先が分かる言葉を書いてください。

## 1-2-5 見出しの番号は飛ばさない

> **見出しはh1から順に使い、番号を飛ばさない**

見出しの番号は、文字の大きさを選ぶためのつまみではありません。**見出しレベル**、つまり内容の深さを表す番号です。「`h2` は大きすぎるから `h4` にする」という選び方をすると、見た目は整っても構造が崩れます。

1ページの `h1` はそのページの題で、1つだけです。その下の章立てが `h2`、`h2` の中の細目が `h3` になります。

```html
<h1>社内研修のご案内</h1>
<h2>対象者</h2>
<p>入社1年目の方が対象です。</p>
<h2>日程</h2>
<h3>4月</h3>
```

字下げして読むと、そのまま目次になっているのが分かります。逆に、目次として読めない並びになっていたら、番号の選び方を間違えています。

```html
<h1>社内研修のご案内</h1>
<h4>対象者</h4>
```

これは `h2` と `h3` が抜けた状態です。読み上げソフトは見出しレベルを頼りにページを飛ばし読みするので、抜けがあると「途中の階層が失われた文書」として伝わります。

大きさが気に入らないときは、番号ではなくCSSで文字の大きさを変えます。**番号は深さ、大きさはCSS** と分けて考えてください。

## もっと知りたい人へ

- 同じ研修サイトの中の別ページへリンクするときは、URL全体ではなくファイルの場所だけを書けます。この書き方はレッスン2-1で扱います
- 「新しいタブで開く」といった動きも属性で指定できます。必要になったときに製品のリファレンスで確認してください

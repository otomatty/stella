# レッスン1-2 演習 — 文章とリンク

対象トピック: 1-2-1 〜 1-2-5

## 手元で試す

レッスン1-1で作った `index.html` の body を、次の内容に書き換えて保存し、ブラウザーで開いてください。

```html
<body>
  <h1>社内研修のご案内</h1>
  <p>4月から新しい研修が始まります。</p>
  <h2>持ち物</h2>
  <ul>
    <li>筆記用具</li>
    <li>ノートパソコン</li>
  </ul>
  <p>詳細は<a href="https://example.com/training">研修案内</a>をご覧ください。</p>
</body>
```

書けたら、次の改造をしてみましょう。

1. `<p>` の中で改行してみて、表示が1行につながることを確かめる(確かめたら戻す)
2. `<ul>` を `<ol>` に変えて、黒丸が番号に変わることを確かめる(確かめたら `<ul>` に戻す)
3. `<li>` を1つ増やして、項目が増えることを確かめる
4. `<h2>持ち物</h2>` を `<h4>持ち物</h4>` に変えて、見た目は小さくなるが階層が飛ぶことを確かめる(確かめたら戻す)

## 演習問題

### 問1(基本)

「受講の流れ」という見出しの下に、「1. 申し込み」「2. 受講」という2つの手順を並べるHTMLを書いてください。見出しは `h2` を使ってください。

### 問2(基本)

次のHTMLは、2つの文が1行につながって表示されます。2段落に分けてください。

```html
<p>
  会場は本社の会議室です。
  開始は10時です。
</p>
```

### 問3(応用)

`h1` の次に `h4` を書くのがよくないのはなぜですか。1〜2文で説明してください。

### 問4(応用)

次のリンクを、リンクだけを読んでも行き先が分かる形に直してください。

```html
<p>申し込みは<a href="https://example.com/form">こちら</a>から。</p>
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```html
<h2>受講の流れ</h2>
<ol>
  <li>申し込み</li>
  <li>受講</li>
</ol>
```

順番に意味があるので `ol` を使います。番号は自動で付くので、`li` の中には書きません。

</details>

<details>
<summary>問2の解答例</summary>

```html
<p>会場は本社の会議室です。</p>
<p>開始は10時です。</p>
```

`p` の中の改行は表示に反映されません。段落を分けたいなら `p` を分けます。

</details>

<details>
<summary>問3の解答例</summary>

見出しの番号は文字の大きさではなく内容の階層を表すからです。番号を飛ばすと、目次を作る仕組みや読み上げソフトが構成を正しく判断できません。

</details>

<details>
<summary>問4の解答例</summary>

```html
<p><a href="https://example.com/form">申し込みフォーム</a>から申し込んでください。</p>
```

リンクの中身に行き先が分かる言葉を入れます。「こちら」だけでは、リンクを一覧にしたときに区別できません。

</details>

## 確認クイズ

### Q1. 見出しの番号の選び方として正しいものはどれですか。

- A. 内容の階層に合わせて選ぶ
- B. ちょうどよい文字の大きさになるものを選ぶ
- C. ページの上から順に h1、h2、h3 と使い切る

<details>
<summary>答え</summary>

**A** — 見出しは階層の指定です。大きさを変えたいときはCSSで変えます。

</details>

### Q2. p の中で改行を入れると表示はどうなりますか。

- A. 改行がそのまま表示に反映される
- B. 1行につながって表示される
- C. エラーになって表示されない

<details>
<summary>答え</summary>

**B** — HTMLは書いた改行をそのままの見た目にはしません。段落を分けるなら p を分けます。

</details>

### Q3. 手順のように順番に意味がある並びに使うのはどれですか。

- A. ul
- B. ol
- C. p

<details>
<summary>答え</summary>

**B** — ol は番号が自動で付きます。順番を入れ替えると意味が変わる並びに使います。

</details>

### Q4. li を置く場所として正しいものはどれですか。

- A. body の直下
- B. ul または ol の中
- C. p の中

<details>
<summary>答え</summary>

**B** — li は必ずリストの中の項目として置きます。単独では使いません。

</details>

### Q5. リンクの行き先を書く場所はどれですか。

- A. a の href 属性
- B. a で囲んだ中身
- C. a の終了タグ

<details>
<summary>答え</summary>

**A** — 行き先は属性値として href に書きます。囲んだ中身は画面に出て、押せる部分になります。

</details>

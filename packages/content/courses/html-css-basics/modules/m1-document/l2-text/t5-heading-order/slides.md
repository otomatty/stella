# 1-2-5
# 見出しの番号は飛ばさない

HTML/CSS入門 — Module 1 / レッスン1-2

<!-- ノート: 見出しの書き方は 1-2-1 で扱いました。ここは「番号の選び方」だけに絞ります。 -->

---

## なぜ必要か

- 大きさがちょうどいいから、という理由で `h4` を選んでしまう
- 見た目は整っているのに、読み上げソフトでは章立てが崩れて聞こえる

<!-- ノート: つかみ。番号を大きさで選ぶのは、未経験者がほぼ全員やる。ここで結論は言わない。 -->

---

## 結論

**見出しはh1から順に使い、番号を飛ばさない**

- **見出しレベル** = `h1` 〜 `h6` の番号が表す、内容の深さ
- 1ページの `h1` は1つ。その下に `h2`、さらに下に `h3`

<!-- ノート: 結論を言い切る。番号は深さを表す道具で、大きさを選ぶつまみではない。 -->

---

## 最小のコード

```html
<h1>社内研修のご案内</h1>
<h2>対象者</h2>
<p>入社1年目の方が対象です。</p>
<h2>日程</h2>
<h3>4月</h3>
```

- `h2` の下に来る細目が `h3`

<!-- ノート: 目次の形になっているかを口頭で確かめる。字下げして読むと階層が耳でも分かる。 -->

---

## よくある間違い

```html
<h1>社内研修のご案内</h1>
<h4>対象者</h4>
```

- 「`h2` は大きすぎるから `h4`」で選んでいる
- 大きさを変えたいだけなら、CSSで変える

<!-- ノート: 失敗例の枠。h2 と h4 のあいだの階層が抜けたページになる。大きさの調整はCSSの仕事。 -->

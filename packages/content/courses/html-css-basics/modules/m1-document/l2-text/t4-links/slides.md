# リンクはaのhrefでつなぐ

HTML/CSS入門研修 — Module 1 / レッスン1-2

## なぜ必要か

- 案内ページから申し込みページへ移動させたい
- URLを本文にそのまま書くと、長くて読みにくく、押せない

<!-- ノート: つかみ。URLがベタ書きされた社内文書のつらさを思い出してもらう。ここで結論は言わない。 -->

---

## 結論

**aのhref属性に行き先を書くと、クリックで移動できるリンクになる**

- `a` = **リンク** を作る要素
- **href** = 行き先を書く属性

<!-- ノート: 結論を言い切る。属性の実例としてもここでしっかり見せる。 -->

---

## 最小のコード

```html
<p>詳細は<a href="https://example.com/training">研修案内</a>をご覧ください。</p>
```

- 押せるのは、タグで囲んだ「研修案内」の部分だけ
- 行き先は画面に出ない

<!-- ノート: 中身が押せる部分、属性値が行き先。1-1-2で扱った属性の役割がここで具体化する。 -->

---

## 押す前に行き先が分かる文にする

```html
<a href="https://example.com/training">こちら</a>
<a href="https://example.com/training">研修案内</a>
```

- 上は、リンクだけを拾い読みすると何のリンクか分からない
- 中身にはリンク先が分かる言葉を書く

<!-- ノート: 対比枠。「こちら」は読み上げソフトで一覧にしたときに区別できない。読みやすさの観点はM5でも扱う。 -->

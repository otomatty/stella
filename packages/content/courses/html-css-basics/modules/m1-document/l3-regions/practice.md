# レッスン1-3 演習 — ページの領域

対象トピック: 1-3-1 〜 1-3-3

## 手元で試す

`index.html` の body を、次の内容に書き換えて保存し、ブラウザーで開いてください。

```html
<body>
  <header>
    <p>社内研修センター</p>
  </header>
  <nav>
    <a href="https://example.com/">トップ</a>
  </nav>
  <main>
    <h1>社内研修のご案内</h1>
    <article>
      <h2>4月研修のお知らせ</h2>
      <p>4月10日に開催します。</p>
    </article>
    <section>
      <h2>持ち物</h2>
      <ul>
        <li>筆記用具</li>
      </ul>
    </section>
    <aside>
      <h2>関連リンク</h2>
      <p>過去の研修一覧をご覧いただけます。</p>
    </aside>
  </main>
  <footer>
    <p>お問い合わせ: 総務部</p>
  </footer>
</body>
```

見た目はほとんど変わりません。書けたら、次の改造をしてみましょう。

1. `header` を `div` に変えて、表示が変わらないことを確かめる(確かめたら戻す)
2. `aside` の中身を丸ごと消して、案内としては成り立つことを確かめる(確かめたら戻す)
3. `article` の中の `h2` を消して、そのまとまりが何の話か分からなくなることを確かめる(確かめたら戻す)

## 演習問題

### 問1(基本)

ページ全体のメニューになるリンクのまとまりを囲む要素はどれですか。

### 問2(基本)

`main` を1ページに2つ置いてはいけないのはなぜですか。1文で説明してください。

### 問3(応用)

お知らせ一覧のページで、1件ぶんのお知らせを囲む要素として `article` と `section` のどちらを選びますか。理由も1文で書いてください。

### 問4(応用)

ページの横に「今週のおすすめ研修」を出したい、と頼まれました。この内容を `aside` で囲んでよいか、判断の基準とあわせて1文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`nav` です。ページを移動するためのリンクのまとまりを囲みます。

</details>

<details>
<summary>問2の解答例</summary>

`main` はそのページの主役になる中身を表すので、1ページに1か所しか存在しないためです。

</details>

<details>
<summary>問3の解答例</summary>

`article` を選びます。お知らせ1件は切り出して別のページに置いても意味が通るためです。

</details>

<details>
<summary>問4の解答例</summary>

消しても本文が成り立つ内容なら `aside` でよい、という基準で判断します。おすすめ研修が案内の本題でないなら `aside` です。

</details>

## 確認クイズ

### Q1. ページの主役になる中身を囲む要素はどれですか。

- A. header
- B. main
- C. footer

<details>
<summary>答え</summary>

**B** — main はそのページの主役になる中身を表し、1ページに1つだけ置きます。

</details>

### Q2. 切り出して別のページに置いても意味が通るまとまりを囲むのはどれですか。

- A. article
- B. section
- C. nav

<details>
<summary>答え</summary>

**A** — article は単独で成り立つまとまりです。ページの中でだけ意味を持つ区切りは section です。

</details>

### Q3. aside を使うかどうかの判断の基準はどれですか。

- A. 画面の横に置くかどうか
- B. 消しても本文が成り立つかどうか
- C. 文字数が少ないかどうか

<details>
<summary>答え</summary>

**B** — 位置ではなく、本文との関係で決まります。

</details>

### Q4. 役割の名前が付けられないまとまりを囲むときはどうしますか。

- A. div のままにする
- B. とりあえず section にする
- C. 囲まずに並べる

<details>
<summary>答え</summary>

**A** — 意味が無いのに名前のある要素を使うと、機械には嘘の情報が伝わります。div は正解の選択肢です。

</details>

### Q5. header や main を使うと変わるものはどれですか。

- A. 画面上の見た目
- B. 領域の役割が機械に伝わるかどうか
- C. ファイルの読み込み速度

<details>
<summary>答え</summary>

**B** — 見た目は div と変わりません。変わるのは伝わる意味です。

</details>

# レッスン1-3 ページの領域

## このレッスンの目標

- [ ] header / nav / main / footer でページを大きく分けられる
- [ ] section と article を、切り出せるかどうかで使い分けられる
- [ ] 補足を aside に、意味の無い囲みを div に置ける

## 1-3-1 ページの大きな領域に名前を付ける

> **ページの上下や本文といった大きな領域は、専用の要素で名前を付ける**

レッスン1-1で、意味を持たない入れ物として `div` を使いました。`div` は便利ですが、それだけで組み立てたページは、どこがヘッダーでどこが本文なのか、書いた本人にしか分かりません。

```html
<div class="header">社内研修センター</div>
<div class="main">...</div>
```

class の名前は人間向けの目印です。ブラウザーにも読み上げソフトにも、その文字列の意味は伝わりません。そこでHTMLには、ページの **領域** に名前を付けるための要素が用意されています。

```html
<body>
  <header>社内研修センター</header>
  <nav><a href="/">トップ</a></nav>
  <main>
    <h1>社内研修のご案内</h1>
  </main>
  <footer>お問い合わせ: 総務部</footer>
</body>
```

| 要素 | 囲むもの |
| --- | --- |
| `header` | ページや章の先頭に置く、題やロゴ |
| `nav` | ページを移動するためのリンクのまとまり |
| `main` | そのページの主役になる中身 |
| `footer` | ページや章の末尾に置く、連絡先や補足 |

見た目は `div` で囲んだときと変わりません。変わるのは、伝わる意味です。読み上げソフトの利用者は、この名前を頼りに「メニューを飛ばして本文へ」といった移動ができます。

気をつける点が1つあります。**`main` は1ページに1つだけ** です。そのページの主役になる中身は1か所しかない、という決まりだと考えてください。`header` と `footer` は、ページ全体だけでなく、記事のまとまりの中にも置けます。

## 1-3-2 本文の区切りはsectionとarticleで示す

> **本文の中の区切りは、単独で成り立つならarticle、章の一区切りならsectionで囲む**

`main` の中が長くなると、今度はその中の区切りが要ります。ここでも `div` ではなく、意味のある要素を選べます。

- **article** — それだけ取り出しても意味が通るまとまり。お知らせ1件、記事1本、商品1つ
- **section** — 見出しでまとまる、文書の中の一区切り。「持ち物」「日程」など

```html
<main>
  <article>
    <h2>4月研修のお知らせ</h2>
    <p>4月10日に開催します。</p>
  </article>
  <section>
    <h2>持ち物</h2>
    <p>筆記用具をお持ちください。</p>
  </section>
</main>
```

迷ったときの判断は1つだけです。**そのまとまりを切り出して別のページに置いても意味が通るか**。通るなら `article`、このページの中でだけ意味を持つ区切りなら `section` です。

どちらにも、そのまとまりの見出しを添えてください。見出しが思いつかないということは、区切る理由が無いということです。その場合は `div` のままで構いません。

## 1-3-3 本筋から外れる補足はasideで囲む

> **本筋から外れていて、無くても本文が成り立つ内容はasideで囲む**

関連リンク、豆知識、広告のような内容は、本文に混ぜると本題が薄まります。こうした **補足** は `aside` で囲みます。

```html
<main>
  <h1>社内研修のご案内</h1>
  <p>4月から新しい研修が始まります。</p>
  <aside>
    <h2>関連リンク</h2>
    <p>過去の研修一覧をご覧いただけます。</p>
  </aside>
</main>
```

判断はここでも一問です。**消しても本文が成り立つか**。成り立つなら `aside`、消すと話が通らなくなるなら本文の一部なので `section` や `p` です。

画面の横に置くから `aside`、ではありません。位置ではなく内容の関係で決まります。

最後に、`div` の立ち位置を確認しておきます。ここまでに出た要素はどれも「役割の名前」です。役割の名前が付けられないまとまりは、`div` のままで正解です。意味が無いのに `aside` や `section` を使うと、機械には嘘の情報が伝わります。

## もっと知りたい人へ

- ここで扱った要素は、レイアウトを変える力を持ちません。並べ方や余白はモジュール4で扱うCSSの仕事です
- `header` と `footer` は `article` の中にも置けます。「その記事の見出し部分」「その記事の末尾」という使い方です

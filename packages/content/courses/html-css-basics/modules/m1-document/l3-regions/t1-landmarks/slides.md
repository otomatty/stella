# ページの大きな領域に名前を付ける

HTML/CSS入門 — Module 1 / レッスン1-3

<!-- ノート: ここからはページ全体の組み立てです。1-1-4 で覚えた div を、名前のある入れ物に置き換えていきます。 -->

---

## なぜ必要か

- `div` だけで組むと、どれがヘッダーでどれが本文か、書いた本人しか分からない
- 読み上げソフトの利用者は「本文まで飛ぶ」ができず、毎回メニューを聞かされる

<!-- ノート: つかみ。div class="header" は人間向けの目印でしかない。機械には伝わらない。ここで結論は言わない。 -->

---

## 結論

**ページの上下や本文といった大きな領域は、専用の要素で名前を付ける**

- **領域** = ページを大きく分けたときの、役割ごとのまとまり
- 中身は同じでも、囲む要素で役割が伝わる

<!-- ノート: 結論を言い切る。見た目は div と変わらない。変わるのは伝わる意味。 -->

---

## 最小のコード

```html
<body>
  <header>社内研修センター</header>
  <nav><a href="/">トップ</a></nav>
  <main>
    <h1>社内研修のご案内</h1>
  </main>
  <footer>お問い合わせ: 総務部</footer>
</body>
```

<!-- ノート: 4つとも body の直下に置く。中身は前のレッスンまでで書けるものだけ。 -->

---

## それぞれの役割

| 要素 | 囲むもの |
| --- | --- |
| `header` | ページや章の先頭に置く、題やロゴ |
| `nav` | ページを移動するためのリンクのまとまり |
| `main` | そのページの主役になる中身。1ページに1つ |
| `footer` | ページや章の末尾に置く、連絡先や補足 |

<!-- ノート: 対比枠。main が1つだけ、という点だけ強調する。残りは複数あってよい。 -->

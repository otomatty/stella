# 要素は入れ子にできる

HTML/CSS入門 — Module 1 / レッスン1-1

---

## なぜ必要か

- 「このまとまりごと右に寄せたい」という指定をしたくなる
- 1行ずつ並べただけでは、どこからどこまでが1つのまとまりか分からない

<!-- ノート: つかみ。カードやセクションのような「かたまり」は、あとから必ず必要になる。 -->

---

## 結論

**要素の中に要素を入れると、親子の構造ができる**

- 入れることを **入れ子** と呼ぶ
- 外側が **親要素**、内側が **子要素**

<!-- ノート: 結論を言い切る。親子という言い方はCSSでも使うので、ここで定着させる。 -->

---

## 最小のコード

```html
<body>
  <div>
    <p>4月から新しい研修が始まります。</p>
  </div>
</body>
```

- `div` は、まとまりを作るための入れ物
- `div` から見て `p` が **子要素**

<!-- ノート: divは意味を持たない入れ物。まとめる目的で使う、とだけ伝える。 -->

---

## よくある間違い

```html
<div><p>研修のご案内</div></p>
```

- 内側の要素より先に、外側の終了タグが来ている
- 入れ子は **内側から順に閉じる**

<!-- ノート: 失敗例の枠。開けた順の逆で閉じる、と覚える。字下げをそろえて書くと目で気づける。 -->

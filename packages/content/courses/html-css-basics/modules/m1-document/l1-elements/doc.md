# レッスン1-1 要素とタグ

## このレッスンの目標

- [ ] 開始タグと終了タグで要素を作れる
- [ ] 属性を開始タグの中に正しく書ける
- [ ] head と body を持つHTMLファイルを最初から書ける

## 1-1-1 タグで囲んで要素を作る

> **HTMLは、開始タグと終了タグで中身を囲んで要素を作る**

HTMLでは「ここからここまでが段落」という範囲を、印で囲んで伝えます。この印が **タグ** です。`<` と `>` で囲んで書きます。

```html
<p>4月から新しい研修が始まります。</p>
```

- `<p>` — **開始タグ**
- `</p>` — **終了タグ**。スラッシュが付きます
- 囲んだひとかたまり全体が **要素** です

タグと要素は混同しやすい言葉です。囲む印がタグ、囲んだ結果が要素、と覚えてください。

終了タグを書き忘れても、エラーは出ません。ブラウザーは足りない部分を自分で補って解釈します。そのため、意図とは違う構造のまま表示されます。

```html
<h1>社内研修のご案内
<p>4月から新しい研修が始まります。</p>
```

`</h1>` がないので、続きの段落まで見出しの中に入ります。段落の文字まで見出しの大きさで表示されるため、見ればすぐに分かります。表示が崩れたら、まず閉じ忘れを疑ってください。

やっかいなのは、**見た目が変わらない閉じ忘れもある** ことです。段落の `</p>` を忘れた場合、ブラウザーは次の要素が始まる位置で段落が閉じたものとして扱うため、表示は変わらないことがほとんどです。表示が正しいからといって、書き方が正しいとは限りません。開始タグと終了タグは必ず対で書いてください。

## 1-1-2 属性でタグに情報を足す

> **属性は開始タグの中に書き、その要素に追加の情報を与える**

リンクの行き先や画像のファイル名のように、画面には出さないが要素に必要な情報があります。これを書く場所が **属性** です。開始タグの中に `名前="値"` の形で書きます。`"` で囲んだ部分を **属性値** と呼びます。

```html
<a href="https://example.com">研修の詳細</a>
```

- `href` — 属性の名前
- `https://example.com` — 属性値
- 画面に出るのは、囲まれた「研修の詳細」だけです

属性は開始タグの中だけに書きます。終了タグには書きません。次はよくある間違いです。

```html
<a>研修の詳細 href="https://example.com"</a>
```

属性を中身の側に書いてしまった例です。`href="https://example.com"` という文字がそのまま画面に表示され、リンクにもなりません。

値を囲む `"` は、書かなくても動くことがあります。ただし、値に空白が入るとそこで値が終わったものとして読まれます。

```html
<a href=https://example.com/研修 案内>研修の詳細</a>
```

この書き方では、行き先が `https://example.com/研修` までで切れ、残りの「案内」は別の属性として扱われます。**属性値は必ず `"` で囲む** と決めておけば、この事故は起きません。この講座でも常に囲みます。

## 1-1-3 HTMLファイルの決まった骨組み

> **HTMLファイルは、headとbodyを持つ決まった骨組みから書き始める**

HTMLファイルには、毎回同じ形で書く **骨組み** があります。考えて作るものではなく、コピーして使うものです。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>社内研修のご案内</title>
  </head>
  <body>
    <p>4月から新しい研修が始まります。</p>
  </body>
</html>
```

大きく2つに分かれます。

- **head** — 画面に出ない設定を書く場所
- **body** — 画面に出る中身を書く場所

それぞれの行の役割です。

| 書くもの | 役割 |
| --- | --- |
| `<!DOCTYPE html>` | HTMLのファイルだという宣言。1行目に書く |
| `lang="ja"` | 日本語のページだという指定 |
| `<meta charset="UTF-8" />` | 文字の種類の指定。文字化けを防ぐ |
| `<title>` | タブやブックマークに出るページ名 |

`title` は head に書きますが、ページの本文としては表示されません。「見出しを付けたのにタブの名前が変わらない」「タブの名前を変えたのに本文に出ない」という混乱は、この違いから起きます。画面に出したい文字は body に書いてください。

## 1-1-4 要素は入れ子にできる

> **要素の中に要素を入れると、親子の構造ができる**

要素の中に別の要素を入れられます。これを **入れ子** と呼び、外側を **親要素**、内側を **子要素** と呼びます。

```html
<body>
  <div>
    <p>4月から新しい研修が始まります。</p>
  </div>
</body>
```

`div` は、それ自体に意味を持たない入れ物です。「このまとまりごと右に寄せたい」「この範囲だけ背景色を変えたい」というときのために、複数の要素をひとかたまりにする目的で使います。

入れ子で気をつけるのは閉じる順番です。**内側から順に閉じます**。

```html
<div><p>研修のご案内</div></p>
```

これは外側の `div` を先に閉じてしまった間違いです。開けた順の逆で閉じる、と覚えてください。子要素を1段字下げして書くと、目で気づけるようになります。

## 1-1-5 骨組みの宣言は不具合を防いでいる

> **doctype・charset・lang・ページ名の宣言は、それぞれ決まった不具合を防いでいる**

骨組みはコピーして使うもの、と説明しました。ただし「使わなさそうだから」と行を消すと、あとから原因の分かりにくい不具合が出ます。上半分の宣言には、1行ずつ担当している役割があります。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>社内研修のご案内</title>
  </head>
</html>
```

`meta` は、画面に出ない情報をブラウザーに伝えるための要素です。ここでは文字の種類を伝えています。

| 宣言 | 消したときに起きること |
| --- | --- |
| `<!DOCTYPE html>` | ブラウザーが古い解釈に切り替わり、表示がずれる |
| `<meta charset="UTF-8" />` | 文字コードの判定がブラウザーの推測任せになり、環境によって日本語が文字化けする |
| `lang="ja"` | 読み上げソフトや翻訳が、ページの言語を誤る |
| `<title>` | タブやブックマークに、ページ名の代わりにファイル名が出る |

`charset` を消しても、手元では読めてしまうことがあります。多くのブラウザーは中身から文字コードを推測するためです。ただし推測は環境やサーバーの設定に左右されるので、**読めたのは運が良かっただけ** です。宣言しておけば推測に頼らずに済みます。

**lang** は `html` の開始タグに書く属性で、そのページが何語で書かれているかを伝えます。日本語のページなら `ja` です。読み上げソフトはこの値を見て発音を切り替えるので、書き忘れると日本語が英語として読み上げられます。

**ページ名** は `title` に書きます。`head` に書くので画面には出ませんが、タブ・ブックマーク・検索結果に出る、そのページの名前です。ページごとに違う名前を付けてください。

## もっと知りたい人へ

- 親子という言い方はCSSでも使います。「親に指定した文字色が子にも効く」といった話がモジュール3で出てきます
- `head` には、ほかにもページの説明や表示の設定を書く `meta` を並べられます。まずはこの4つを消さないことから始めてください
- `div` を使わずに済むなら使わないほうが読みやすいコードになります。意味のあるまとまりには、あとで学ぶ専用の要素を選べる場面もあります

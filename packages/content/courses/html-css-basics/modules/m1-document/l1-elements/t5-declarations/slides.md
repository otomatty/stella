# 骨組みの宣言は不具合を防いでいる

HTML/CSS入門 — Module 1 / レッスン1-1

<!-- ノート: 骨組みはコピーして使うもの、と伝えました。ここでは「なぜその行が要るのか」を1行ずつ回収します。 -->

---

## なぜ必要か

- コピーした骨組みの行を「使わなさそう」と消してしまう
- 消したあとに文字化けやタブ名の不備が出ても、原因にたどり着けない

<!-- ノート: つかみ。実際に「meta の行を消したら文字化けした」という質問は毎年出る。ここで結論は言わない。 -->

---

## 結論

**doctype・charset・lang・ページ名の宣言は、それぞれ決まった不具合を防いでいる**

- 飾りではなく、1行ごとに防いでいるものがある
- どれも `head` より前か `head` の中に書く

<!-- ノート: 結論を言い切る。4行それぞれに担当があるので、消していい行は無い。 -->

---

## 最小のコード

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>社内研修のご案内</title>
  </head>
</html>
```

- `meta` = 画面に出ない情報を伝えるための要素

<!-- ノート: 1-1-3 で見た骨組みの上半分だけを再掲する。新しい要素は meta だけ。 -->

---

## 消すと何が起きるか

| 宣言 | 消したときに起きること |
| --- | --- |
| `<!DOCTYPE html>` | ブラウザーが古い解釈に切り替わり、表示がずれる |
| `<meta charset="UTF-8" />` | 文字コードの判定が推測任せになり、文字化けが起きうる |
| `lang="ja"` | 読み上げや翻訳が言語を誤る |
| `<title>` | タブやブックマークにファイル名が出る |

<!-- ノート: 対比枠。ここが本題。1行ずつ「何を防いでいるか」で読み上げる。charset は消しても手元では読めることがあるが、それは推測が当たっただけ、と補う。 -->

## なぜ必要か

- 文字化けしたページを見たことがあるはず。あれは宣言の書き忘れで起きる
- タブに出るページ名も、書く場所が決まっている

<!-- ノート: つかみ。実際に文字化けした画面を見せられるとよい。ここで結論は言わない。 -->

---

## 結論

**HTMLファイルは、headとbodyを持つ決まった骨組みから書き始める**

- **head** = 画面に出ない設定を書く場所
- **body** = 画面に出る中身を書く場所

<!-- ノート: 結論を言い切る。毎回ゼロから考えるものではなく、決まった型があると伝える。 -->

---

## 最小のコード

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>社内研修のご案内</title>
  </head>
  <body>
    <p>4月から新しい研修が始まります。</p>
  </body>
</html>
```

<!-- ノート: この骨組みは丸ごと覚えるものではなく、コピーして使うもの。1行ずつ役割だけ読み上げる。 -->

---

## それぞれの役割

| 書くもの | 役割 |
| --- | --- |
| `<!DOCTYPE html>` | HTMLのファイルだという宣言 |
| `lang="ja"` | 日本語のページだという指定 |
| `<meta charset="UTF-8" />` | 文字化けを防ぐ文字の種類の指定 |
| `<title>` | タブやブックマークに出るページ名 |

<!-- ノート: 対比枠。titleはheadに書くのに画面には出ない、という点だけ強調する。中身はbodyに書く。 -->

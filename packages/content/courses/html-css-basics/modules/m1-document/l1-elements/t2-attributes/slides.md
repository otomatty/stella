# 属性でタグに情報を足す

HTML/CSS入門研修 — Module 1 / レッスン1-1

<!-- ノート: 囲むだけでは足りない情報を、どこに書くかという話です。 -->

---

## なぜ必要か

- リンクは「どこへ行くか」を伝えないと成立しない
- 画像は「どのファイルか」を伝えないと表示できない
- 中身として書くと、その文字が画面に出てしまう

<!-- ノート: つかみ。行き先のURLを中身に書いたら、URLがそのまま本文に出てしまう。置き場所が別に要る。 -->

---

## 結論

**属性は開始タグの中に書き、その要素に追加の情報を与える**

- **属性** = 開始タグの中に書く `名前="値"` の指定
- `"` で囲んだ部分が **属性値**

<!-- ノート: 結論を言い切る。属性は開始タグの中だけ。終了タグには書かない。 -->

---

## 最小のコード

```html
<a href="https://example.com">研修の詳細</a>
```

- `href` が属性の名前、`https://example.com` が **属性値**
- 画面に出るのは、囲まれた「研修の詳細」だけ

<!-- ノート: 属性は画面に出ない情報、中身は画面に出る文字。この違いを指差しで確認する。aタグそのものは1-2-4で扱う。 -->

---

## よくある間違い

```html
<a>研修の詳細 href="https://example.com"</a>
```

- 属性を中身の側に書いている
- `href="..."` の文字がそのまま画面に出て、リンクにもならない

<!-- ノート: 失敗例の枠。属性の置き場所は開始タグの中だけ。なお値の "" は省いても動くことがあるが、空白の入った値で切れるので必ず囲むと決めておく。 -->

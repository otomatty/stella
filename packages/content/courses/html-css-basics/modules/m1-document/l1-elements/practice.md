# レッスン1-1 演習 — 要素とタグ

対象トピック: 1-1-1 〜 1-1-4

## 手元で試す

`index.html` を作り、次の骨組みを写して保存し、ブラウザーで開いてください。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>社内研修のご案内</title>
  </head>
  <body>
    <div>
      <h1>社内研修のご案内</h1>
      <p>4月から新しい研修が始まります。</p>
    </div>
  </body>
</html>
```

書けたら、次の改造をしてみましょう。

1. `<title>` の中身を書き換えて、ブラウザーのタブの表示が変わることを確かめる
2. `<p>...</p>` をもう1つ `div` の中に足して、段落を2つにする
3. わざと `</h1>` を消して保存し、続きの段落まで見出しの大きさになることを確かめる(見たら戻す)
4. 今度は `</p>` を消して保存し、こちらは表示が変わらないことを確かめる(見たら戻す)

## 演習問題

### 問1(基本)

次のHTMLには間違いが1つあります。どこが間違いか指摘して、直してください。

```html
<p>受付は3月末までです。<p>
```

### 問2(基本)

「お問い合わせ」という文字をクリックすると `https://example.com/contact` に移動するリンクを書いてください。

### 問3(応用)

次のHTMLには間違いが2つあります。指摘して、直してください。

```html
<div>
  <p>研修は全5回です。</div>
</p>
```

### 問4(応用)

`title` に書いた文字がページの本文に表示されません。原因を1文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

終了タグのスラッシュが抜けています。

```html
<p>受付は3月末までです。</p>
```

`</p>` のようにスラッシュを付けて閉じます。段落の場合はブラウザーが閉じ位置を補うため表示が変わらないこともありますが、書き方としては誤りです。

</details>

<details>
<summary>問2の解答例</summary>

```html
<a href="https://example.com/contact">お問い合わせ</a>
```

行き先は属性値として `href` に書き、画面に出したい文字はタグで囲みます。

</details>

<details>
<summary>問3の解答例</summary>

閉じる順番が逆になっています。内側の `p` を先に閉じます。

```html
<div>
  <p>研修は全5回です。</p>
</div>
```

開けた順の逆で閉じる、と覚えてください。

</details>

<details>
<summary>問4の解答例</summary>

`title` は head に書く設定で、画面に出るのは body の中身だけだからです。

</details>

## 確認クイズ

### Q1. 開始タグと終了タグの組み合わせとして正しいものはどれですか。

- A. 開始タグが <p> で、終了タグも <p>
- B. 開始タグが <p> で、終了タグが </p>
- C. 開始タグが <p> で、終了タグが <\p>

<details>
<summary>答え</summary>

**B** — 終了タグは要素名の前にスラッシュを付けます。向きは `/` です。

</details>

### Q2. 属性を書く場所として正しいものはどれですか。

- A. 開始タグの中
- B. 終了タグの中
- C. 開始タグと終了タグに囲まれた中身

<details>
<summary>答え</summary>

**A** — 属性は開始タグの中だけに書きます。中身に書くと、その文字がそのまま画面に出ます。

</details>

### Q3. ページのタブに出る名前を書く場所はどれですか。

- A. head の中の title
- B. body の先頭
- C. DOCTYPE の宣言の中

<details>
<summary>答え</summary>

**A** — `title` は head に書きます。画面の本文には出ません。

</details>

### Q4. 文字化けを防ぐために head に書くのはどれですか。

- A. lang="ja" の指定
- B. meta charset="UTF-8" の指定
- C. DOCTYPE html の宣言

<details>
<summary>答え</summary>

**B** — 文字の種類の指定です。`lang` はページの言語、`DOCTYPE` はHTMLだという宣言で、役割が違います。

</details>

### Q5. 入れ子の書き方として正しいものはどれですか。

- A. div を開き、p を開き、p を閉じ、div を閉じる
- B. div を開き、p を開き、div を閉じ、p を閉じる
- C. p を開き、div を開き、p を閉じ、div を閉じる

<details>
<summary>答え</summary>

**A** — 内側から順に閉じます。開けた順の逆で閉じるのが基本です。

</details>

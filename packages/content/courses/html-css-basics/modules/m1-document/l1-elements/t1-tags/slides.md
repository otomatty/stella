# タグで囲んで要素を作る

HTML/CSS入門研修 — Module 1 / レッスン1-1

<!-- ノート: ここからHTMLの文法に入ります。この講座でいちばん基本になる書き方です。 -->

---

## なぜ必要か

- 「ここからここまでが見出し」という範囲を伝えたい
- 始まりだけを書いても、どこで終わるのかが分からない

<!-- ノート: つかみ。文章の途中まで見出し、という指定はできない。範囲を伝える仕組みが要る、という動機づけ。 -->

---

## 結論

**HTMLは、開始タグと終了タグで中身を囲んで要素を作る**

- **タグ** = `<` と `>` で囲んだ印
- 囲んだ範囲ひとかたまりが **要素**

<!-- ノート: 結論を言い切る。タグと要素は混同されやすい。囲む印がタグ、囲んだ結果が要素。 -->

---

## 最小のコード

```html
<p>4月から新しい研修が始まります。</p>
```

- `<p>` が **開始タグ**
- `</p>` が **終了タグ**(スラッシュが付く)

<!-- ノート: 1行を指しながら3つの部品を確認する。開始・中身・終了の順に読み上げる。 -->

---

## よくある間違い

```html
<h1>社内研修のご案内
<p>4月から新しい研修が始まります。</p>
```

- `</h1>` の書き忘れ
- 続きの段落まで見出しの中に入り、大きな文字になる

<!-- ノート: 失敗例の枠。エラーは出ないまま、ブラウザーが足りない部分を補って解釈する。閉じ忘れを最初に疑う癖を付ける。 -->

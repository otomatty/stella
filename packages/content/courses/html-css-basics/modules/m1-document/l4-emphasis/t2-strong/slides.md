# strongは重要さの印

HTML/CSS入門研修 — Module 1 / レッスン1-4

## なぜ必要か

- 締切や注意事項は、読み飛ばされると事故になる
- 太字にしただけでは、読み上げソフトには「重要」と伝わらない

<!-- ノート: つかみ。申込期限を見落とした、は実際に起きる。ここで結論は言わない。 -->

---

## 結論

**読み飛ばされると困るほど重要な語句はstrongで囲む**

- **重要** = 読み飛ばすと不利益がある、という印
- 既定の見た目は太字になる

<!-- ノート: 結論を言い切る。strong は「重み」の印。声の調子ではなく内容の重み。 -->

---

## 最小のコード

```html
<p><strong>申込は3月末まで</strong>です。</p>
```

- 期限を落とすと申し込めない。だから `strong`

<!-- ノート: 注意・警告・期限が典型例。ページに何個もあると重みが薄れる、とも添える。 -->

## emとの使い分け

| 印 | 使いどころ |
| --- | --- |
| `em` | そこを強く読むと文の焦点が変わる語句 |
| `strong` | 読み飛ばされると困る、重要な語句 |

# 用語と説明の組はdlで表す

## なぜ必要か

- 「日時」「会場」「持ち物」のような、項目名と内容の並びをよく書く
- 段落で「日時: 4月10日」と書くと、どこまでが項目名か機械に伝わらない

<!-- ノート: つかみ。案内ページの概要欄は必ずこの形になる。ここで結論は言わない。 -->

---

## 結論

**用語とその説明が組になる並びは、dlの中にdtとddを並べて表す**

- **説明リスト** = 用語と説明が組になった並び
- `dt` = 用語、`dd` = その説明

<!-- ノート: 結論を言い切る。ul / ol と違い、1項目が2つの要素の組になる。 -->

---

## 最小のコード

```html
<dl>
  <dt>日時</dt>
  <dd>4月10日 13時</dd>
  <dt>会場</dt>
  <dd>本社3階 会議室</dd>
</dl>
```

- `dt` と `dd` は、必ず `dl` の中に置く

<!-- ノート: 既定では dd が字下げされて表示される。組になっているのが目でも分かる。 -->

---

## リストの使い分け

| 要素 | 表すもの |
| --- | --- |
| `ul` | 順番に意味のない並び |
| `ol` | 順番に意味のある並び |
| `dl` | 用語と説明の組 |

<!-- ノート: 対比枠。3つ目のリストとして位置づけると迷わない。1つの dt に dd を複数付けることもできる。 -->

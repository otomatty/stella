# 見た目だけ変えたいならCSSで変える

HTML/CSS入門研修 — Module 1 / レッスン1-4

<!-- ノート: em と strong を覚えると、今度は何でもそれで囲みたくなります。そこに歯止めをかけます。 -->

---

## なぜ必要か

- 「ここを太字に」と頼まれて `strong` で囲んでしまう
- 重要でない語まで重要の印が付き、本当に重要な語が埋もれる

<!-- ノート: つかみ。強調だらけのページは、どこも強調されていないのと同じ。ここで結論は言わない。 -->

---

## 結論

**太字や斜体にしたいだけなら、意味の印ではなくCSSで見た目を変える**

- 意味があるとき → `em` / `strong`
- 見た目だけのとき → CSSの出番

<!-- ノート: 結論を言い切る。判断は「読み上げたときに変わってほしいか」。 -->

---

## 意味が別にある語句

```html
<p><i>Falcon</i>は製品名です。</p>
<p>単語 <b>margin</b> を覚えます。</p>
```

- `i` = 専門用語や外国語など、周りと種類が違う語句
- `b` = 目立たせたいが、重要ではない語句

<!-- ノート: i と b は「見た目タグ」ではなく、意味の薄い印として残っている。まずは使わなくてよい。 -->

---

## 迷ったときの順番

1. 読み上げで変わってほしい → `em` / `strong`
2. 語句の種類が違うだけ → `i` / `b`
3. どちらでもない → 囲まずにCSSで見た目を変える

<!-- ノート: 対比枠。ここが本題。未経験のうちは 1 と 3 だけで足りる。 -->

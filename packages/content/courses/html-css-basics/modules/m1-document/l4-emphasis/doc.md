# レッスン1-4 強調と意味のある語句

## このレッスンの目標

- [ ] em と strong を意味の違いで使い分けられる
- [ ] 見た目だけ変えたい場面ではCSSを選べる
- [ ] 用語と説明の組を dl で書ける

## 1-4-1 emは読み方が変わる強調

> **文の中で読み方が変わるほど強めたい語句はemで囲む**

文の一部を強めたいとき、書き手はつい「斜体にする」「太字にする」と、見た目の操作で済ませてしまいます。しかし見た目を変えただけでは、読み上げソフトを使う人にも、検索する機械にも、強調は伝わりません。

HTMLには、語句に意味の印を付ける要素があります。まず **強調** の印が `em` です。

```html
<p>研修は<em>4月10日</em>に開催します。</p>
```

`em` は、**そこを強く読むと文の意味が変わる** 語句に使います。声に出して読み比べると分かります。「研修は4月10日に開催します」と平坦に読む場合と、「4月10日」を強めて読む場合とでは、伝わる要点が変わります。

既定の見た目は斜体ですが、それは結果であって目的ではありません。「斜体にしたい」だけの用途には使いません。判断は **声に出したときに強めるかどうか** です。

## 1-4-2 strongは重要さの印

> **読み飛ばされると困るほど重要な語句はstrongで囲む**

もう1つの印が `strong` です。こちらは声の調子ではなく、内容の **重要** さを表します。

```html
<p><strong>申込は3月末まで</strong>です。</p>
```

締切、注意事項、警告のように、**読み飛ばされると不利益が出る** 語句に使います。既定の見た目は太字です。

| 印 | 使いどころ |
| --- | --- |
| `em` | そこを強く読むと文の焦点が変わる語句 |
| `strong` | 読み飛ばされると困る、重要な語句 |

どちらも、1ページに何個も付けると効果が薄れます。強調だらけのページは、どこも強調されていないのと同じです。本当に落とせない語句だけに絞ってください。

## 1-4-3 見た目だけ変えたいならCSSで変える

> **太字や斜体にしたいだけなら、意味の印ではなくCSSで見た目を変える**

`em` と `strong` を覚えると、今度は何でもそれで囲みたくなります。「ここを太字にして」と頼まれて `strong` を使う、というのが典型です。これをやると、重要でない語にまで重要の印が付き、本当に重要な語が埋もれます。

判断はこの順番です。

1. 読み上げたときに変わってほしい → `em` / `strong`
2. 語句の種類が周りと違うだけ → `i` / `b`
3. どちらでもない、見た目だけの都合 → 囲まずにCSSで見た目を変える

`i` と `b` は、見た目のためのタグとして生まれましたが、いまは意味の薄い印として位置づけ直されています。

```html
<p><i>Falcon</i>は製品名です。</p>
<p>単語 <b>margin</b> を覚えます。</p>
```

`i` は専門用語・外国語・製品名のように **周りと種類が違う語句**、`b` は **目立たせたいが重要ではない語句** に使います。未経験のうちは、1番と3番だけで足ります。

CSSでの見た目の変え方はモジュール3以降で扱います。ここでは「見た目の都合でHTMLの要素を選ばない」という判断だけ持ち帰ってください。

## 1-4-4 用語と説明の組はdlで表す

> **用語とその説明が組になる並びは、dlの中にdtとddを並べて表す**

案内ページには「日時」「会場」「持ち物」のような、項目名と内容の並びが必ず出てきます。段落で `日時: 4月10日` と書いても人は読めますが、どこまでが項目名なのかは機械に伝わりません。

こうした並びのために、3つ目のリストとして **説明リスト** があります。

```html
<dl>
  <dt>日時</dt>
  <dd>4月10日 13時</dd>
  <dt>会場</dt>
  <dd>本社3階 会議室</dd>
</dl>
```

- `dl` — 説明リスト全体を囲む
- `dt` — 用語(項目名)
- `dd` — その説明(内容)

`dt` と `dd` は必ず `dl` の中に置きます。既定では `dd` が字下げされて表示されるので、組になっていることが目でも分かります。

| 要素 | 表すもの |
| --- | --- |
| `ul` | 順番に意味のない並び |
| `ol` | 順番に意味のある並び |
| `dl` | 用語と説明の組 |

## もっと知りたい人へ

- 1つの `dt` に `dd` を複数続けて書けます。「持ち物」に対して複数の内容を並べたいときに使えます
- `em` は入れ子にすると、さらに強い強調を表せます。ただし読み手には伝わりにくいので、実務ではほとんど使いません

## なぜ必要か

- 文書をそのまま置くと、どれが見出しでどれが本文か、ブラウザーには分からない
- 「ここは見出し」「ここはリンク」と伝える書き方が要る

<!-- ノート: つかみ。文字だけのメモ帳の内容を渡されても、機械は構造を判断できない、という話。ここで結論は言わない。 -->

---

## 結論

**HTMLは、ページに何を置くかを書くための言語**

- **HTML** = ページの **中身** を書く言語
- 何をどんな役割で置くかを、印を付けながら書いていく

<!-- ノート: 結論を言い切る。中身という語は、このあと「見た目」と対にして何度も使う。 -->

---

## 最小のコード

```html
<h1>社内研修のご案内</h1>
<p>4月から新しい研修が始まります。</p>
```

- `h1` の印 = 大見出し
- `p` の印 = 段落

<!-- ノート: 印の書き方そのものはM1で扱う。ここでは「役割の印を付けて書く」という感覚だけ持ち帰ってもらう。 -->

---

## HTMLが決めないこと

- 文字の色、大きさ、余白、並べ方
- それらは書かなくても、ブラウザーが既定の見た目で表示する
- 見た目を指定したくなったら、HTMLとは別の担当がいる

<!-- ノート: 対比枠。HTMLに見た目の指定を書き込もうとするのが、未経験者の最初のつまずき。担当が分かれていることを先に伝える。 -->

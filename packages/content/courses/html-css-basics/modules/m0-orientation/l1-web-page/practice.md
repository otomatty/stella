# レッスン0-1 演習 — Webページのしくみ

対象トピック: 0-1-1 〜 0-1-4

## 手元で試す

この講座に自動採点の演習はありません。テキストエディタとブラウザーだけで手を動かせます。スマートフォンで受講している場合は、この節は飛ばして「演習問題」から進めてください。

1. テキストエディタ(メモ帳、VS Code など何でも構いません)を開く
2. 次の内容を書く

```html
<h1>社内研修のご案内</h1>
<p>4月から新しい研修が始まります。</p>
```

3. `index.html` という名前で、分かる場所(デスクトップなど)に保存する
4. 保存したファイルをブラウザーで開く

見出しが大きく、段落が普通の大きさで表示されれば成功です。色や大きさを何も指定していないのに差が付くのは、ブラウザーが既定の見た目を持っているからです。

書けたら、次の改造を試してみましょう。

1. `<p>` の行の文章を書き換えて、保存 → 再読み込みで表示が変わることを確かめる
2. `<p>...</p>` の行をもう1行増やして、段落が2つになることを確かめる
3. わざと保存せずに再読み込みして、表示が変わらないことを確かめる(確かめたら保存する)

## 演習問題

### 問1(基本)

次の依頼を受けたとき、HTMLとCSSのどちらを直しますか。理由も一言で書いてください。

1. お知らせの項目を1つ増やしたい
2. 見出しの文字を大きくしたい

### 問2(基本)

`index.html` を直して保存したのに、ブラウザーの表示が変わりません。原因として考えられることを2つ挙げてください。

### 問3(応用)

「見出しを紺色にする」という指定を全10ページに入れたいとき、CSSに書くとHTMLに書くより何が楽になりますか。1〜2文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

1. HTML — 項目を増やすのはページの中身を変えることだから
2. CSS — 文字の大きさは見た目の指定だから

「中身か、見た目か」で切り分けます。

</details>

<details>
<summary>問2の解答例</summary>

- 保存していない
- 再読み込みしていない
- ブラウザーで開いているのが、直したファイルとは別のファイル

このどれかであることがほとんどです。この順に確認してください。

</details>

<details>
<summary>問3の解答例</summary>

CSSに書けば1か所を直すだけで10ページすべてに効きます。HTMLに書くと同じ指定を10回書くことになり、変更のたびに10ファイルを開くことになります。

</details>

## 確認クイズ

### Q1. ブラウザーの役割として正しいものはどれですか。

- A. 完成した画像を受け取って、そのまま表示している
- B. 受け取ったファイルを読んで、画面を組み立てている
- C. ページを組み立ててから、ファイルとして保存している

<details>
<summary>答え</summary>

**B** — ページは置いてある絵ではなく、ブラウザーが材料のファイルから組み立てた結果です。

</details>

### Q2. HTMLが担当するのはどれですか。

- A. ページに何を置くか
- B. 文字の色や大きさ
- C. ページを表示する速さ

<details>
<summary>答え</summary>

**A** — HTMLは中身の担当です。色や大きさは見た目の担当であるCSSに書きます。

</details>

### Q3. 「全ページの見出しの色を変えたい」という依頼で触るのはどちらですか。

- A. HTML
- B. CSS
- C. どちらでもよく、違いはない

<details>
<summary>答え</summary>

**B** — 見た目の指定はCSSです。CSSにまとめておけば1か所の変更で全ページに効きます。

</details>

### Q4. 書いたHTMLをブラウザーで確認する手順として正しいものはどれですか。

- A. 拡張子を .html にして保存し、そのファイルをブラウザーで開く
- B. サーバーソフトをインストールしてから、公開設定をする
- C. テキストエディタの中でプレビュー用のソフトを購入する

<details>
<summary>答え</summary>

**A** — テキストエディタとブラウザーだけで確認できます。特別な準備は要りません。

</details>

### Q5. ファイルを直したのに表示が変わりません。まず確認することはどれですか。

- A. パソコンを再起動する
- B. 保存したか、再読み込みしたかを確認する
- C. ブラウザーを別の製品に入れ替える

<details>
<summary>答え</summary>

**B** — ブラウザーは開いた時点の内容を表示しています。保存と再読み込みの2つを先に疑ってください。

</details>

# 保存して開けばすぐ試せる

HTML/CSS入門 — Module 0 / レッスン0-1

---

## なぜ必要か

- 「環境構築が終わらないと試せない」と思うと、学習が止まる
- 書いたものがすぐ見えないと、どこを間違えたのか分からない

<!-- ノート: つかみ。他の言語の研修と違い、この講座は準備がほとんど要らない。その安心をここで渡す。 -->

---

## 結論

**HTMLファイルは保存してブラウザーで開けば、その場で結果を確認できる**

- 必要なのはテキストエディタとブラウザーだけ
- サーバーもインストール作業も要らない

<!-- ノート: 結論を言い切る。準備の少なさが、この分野を学びやすくしている。 -->

---

## 手順は3つ

1. テキストエディタで書く
2. **拡張子** を `.html` にして **保存** する(例: `index.html`)
3. そのファイルをブラウザーで開く

<!-- ノート: 拡張子はファイル名の末尾に付ける種類の印。.txtのまま保存すると文字がそのまま出るので、ここが最初のつまずきどころ。 -->

---

## 直したら再読み込み

- ブラウザーは開いた時点の内容を表示している
- ファイルを直したら **再読み込み**(リロード)で表示が入れ替わる
- 変わらないときは、まず保存したかを疑う

<!-- ノート: 失敗例の枠。「直したのに変わらない」の原因はたいてい未保存か別ファイルを開いている。指差し確認の順番を渡す。 -->

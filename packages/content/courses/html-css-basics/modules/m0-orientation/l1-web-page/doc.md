# レッスン0-1 Webページのしくみ

## このレッスンの目標

- [ ] ブラウザーが何をしているかを説明できる
- [ ] HTMLとCSSの担当の違いを説明できる
- [ ] 書いたHTMLをブラウザーで開いて確認できる

## 0-1-1 Webページはブラウザーが組み立てる

> **ブラウザーは、受け取ったファイルを読んで画面を組み立てている**

画面に見えている **Webページ** は、そのままの形でどこかに置いてある絵ではありません。**ブラウザー**(Chrome や Safari など、ページを見るためのソフト)が、材料の **ファイル** を受け取って、その場で組み立てた結果です。

材料は主に3種類です。

| 届くもの | 役割 |
| --- | --- |
| `.html` のファイル | ページに何を置くか |
| `.css` のファイル | それをどう見せるか |
| 画像のファイル | 写真やイラスト |

組み立てられている、と分かると直す場所が決まります。

- 文字や項目を足したい → 中身のファイルを直す
- 色や大きさを変えたい → 見た目のファイルを直す

どちらを直しても、ブラウザーがもう一度読み直して組み立て直します。

## 0-1-2 HTMLはページの中身を書く

> **HTMLは、ページに何を置くかを書くための言語**

文章をそのまま渡しても、どこが見出しでどこが本文かはブラウザーには分かりません。そこで、役割の印を付けながら書きます。この書き方が **HTML** で、ページの **中身** を担当します。

```html
<h1>社内研修のご案内</h1>
<p>4月から新しい研修が始まります。</p>
```

- `h1` の印 — 大見出し
- `p` の印 — 段落

印の書き方そのものはレッスン1-1で扱います。ここでは「役割の印を付けて書く」という感覚を持っていれば十分です。

HTMLが決めないこともあります。文字の色、大きさ、余白、並べ方は、HTMLには書きません。何も指定しなくてもブラウザーが既定の見た目で表示してくれるので、まず中身だけを書けます。

## 0-1-3 CSSは見た目を決める

> **CSSは、HTMLで置いたものの見た目を決めるための言語**

**見た目** の担当が **CSS** です。「見出しは紺色にする」といった指定をこちらに書きます。

```css
h1 {
  color: navy;
}
```

書き方はモジュール3で扱います。いま押さえるのは分担です。

| やりたいこと | 触るのは |
| --- | --- |
| 項目を1つ増やす | HTML |
| 見出しの色を変える | CSS |
| 全ページの見出しの色を変える | CSS(1か所) |

見た目の指定をHTMLの中に混ぜて書くこともできますが、そうすると同じ指定があちこちに散らばります。「全ページの色を変えてほしい」という依頼が来たときに、開くファイルが50個になるか1個で済むかの差になります。中身はHTML、見た目はCSS。この分担がこの講座全体の骨格です。

## 0-1-4 保存して開けばすぐ試せる

> **HTMLファイルは保存してブラウザーで開けば、その場で結果を確認できる**

この分野の学びやすいところは、準備がほとんど要らない点です。テキストエディタとブラウザーがあれば始められます。サーバーも、追加のインストール作業も要りません。

手順は3つです。

1. テキストエディタで書く
2. **拡張子**(ファイル名の末尾に付ける種類の印)を `.html` にして **保存** する。例: `index.html`
3. そのファイルをブラウザーで開く(ダブルクリック、またはブラウザーにドラッグ&ドロップ)

拡張子が `.txt` のままだと、書いた印がそのまま文字として表示されます。うまく表示されないときは、まずファイル名を確認してください。

ファイルを直したあとは **再読み込み**(リロード)が要ります。ブラウザーは開いた時点の内容を表示しているので、直しただけでは画面は変わりません。「直したのに変わらない」ときは、次の順で確かめてください。

1. 保存したか
2. 再読み込みしたか
3. ブラウザーで開いているのが、いま直したファイルか

## もっと知りたい人へ

- 拡張子がファイル名に表示されない設定のパソコンでは、`index.html.txt` のような二重の名前になっていることがあります。エクスプローラーやFinderの設定で拡張子を表示しておくと、この事故を防げます
- 実務ではファイルをサーバーに置いて公開しますが、書きながら確認する段階では手元で開くだけで十分です

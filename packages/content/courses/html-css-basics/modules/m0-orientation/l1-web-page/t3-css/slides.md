# CSSは見た目を決める

HTML/CSS入門 — Module 0 / レッスン0-1

<!-- ノート: 中身の担当がHTMLだと分かったので、もう一方の担当を確定させます。 -->

---

## なぜ必要か

- 「見出しは青で大きく」を中身の側に書くと、同じ指定を何度も書くことになる
- 全ページの色を変える依頼が来たとき、全部のファイルを開く羽目になる

<!-- ノート: つかみ。色の変更依頼で50ファイル開いた、という失敗談を置く。ここで結論は言わない。 -->

---

## 結論

**CSSは、HTMLで置いたものの見た目を決めるための言語**

- **CSS** = **見た目** を書く言語
- 中身はHTML、見た目はCSS。担当が分かれている

<!-- ノート: 結論を言い切る。この分担がこの講座全体の骨格になる。 -->

---

## 最小のコード

```css
h1 {
  color: navy;
}
```

- 「`h1` の文字色を紺色にする」という指定
- 書き方はM3で扱う。ここでは分担の感覚だけ

<!-- ノート: 読み方は言葉で補う。ここで書き方の細部に立ち入らない。 -->

---

## 分担が効くところ

| やりたいこと | 触るのは |
| --- | --- |
| 項目を1つ増やす | HTML |
| 見出しの色を変える | CSS |
| 全ページの見出しの色を変える | CSS(1か所) |

<!-- ノート: 対比枠。分担のうまみは「1か所を直すと全ページに効く」こと。依頼から触る側が決まる。 -->

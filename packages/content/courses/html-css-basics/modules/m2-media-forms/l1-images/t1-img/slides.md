# 画像はimgのsrcで貼る

HTML/CSS入門研修 — Module 2 / レッスン2-1

<!-- ノート: ここから文字以外のものをページに載せます。まずは画像です。 -->

---

## なぜ必要か

- 案内ページに会場の地図や製品の写真を載せたい
- 画像そのものはHTMLファイルの中には書けない

<!-- ノート: つかみ。テキストファイルであるHTMLに写真は書き込めない。ではどうするのか、で引く。 -->

---

## 結論

**画像はimgタグのsrc属性にファイルの場所を書いて表示する**

- **img** = **画像** を表示するタグ
- **src** = 画像ファイルの場所を書く属性

<!-- ノート: 結論を言い切る。画像は別ファイルで、HTMLはその置き場所を指しているだけ。 -->

---

## 最小のコード

```html
<img src="venue.png" />
```

- 囲む中身がないので **終了タグ** がない
- 末尾を `/>` で閉じる書き方が一般的

<!-- ノート: これまでのタグと違い、imgは囲まない。中身がない要素はこの形になる。 -->

---

## よくある間違い

```html
<img src="venue.png">会場の地図</img>
```

- `</img>` は無視され、「会場の地図」はただの本文になる
- 画像の説明は中身ではなく属性で渡す

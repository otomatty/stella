# レッスン2-1 画像を載せる

## このレッスンの目標

- [ ] img と src で画像を表示できる
- [ ] 意味のある alt を書ける
- [ ] 相対パスでファイルの場所を正しく指せる

## 2-1-1 画像はimgのsrcで貼る

> **画像はimgタグのsrc属性にファイルの場所を書いて表示する**

HTMLファイルは文字だけのファイルなので、写真そのものを書き込むことはできません。**画像** は別のファイルとして用意し、HTMLからはその置き場所を指します。使うタグが **img**、場所を書く属性が **src** です。

```html
<img src="venue.png" />
```

`img` はこれまでのタグと形が違います。囲む中身がないため、**終了タグ** がありません。末尾を `/>` で閉じる書き方が一般的です。

囲まないタグなので、次の書き方は誤りです。

```html
<img src="venue.png">会場の地図</img>
```

エラーにはなりません。ブラウザーは `</img>` を無視するので、画像が表示され、その後ろに「会場の地図」がただの本文として並びます。画像の説明としては扱われないため、画像が表示できないときの代わりにもなりません。

画像の説明を渡したいときは、中身ではなく属性を使います。その属性が次のトピックです。

## 2-1-2 altは画像の代わりになる文

> **alt属性には、画像が見えないときに代わりに伝わる文を書く**

画像は、いつも見えるとは限りません。通信が遅い、ファイル名を間違えた、画面を読み上げて使っている、といった場面があります。そのときに代わりに伝わる文を **alt** 属性に書きます。この文を **代替テキスト** と呼びます。

```html
<img src="venue.png" alt="本社3階の会議室までの地図" />
```

画像を見ずにこの文だけを読んでも、何の画像かが分かります。読み上げソフトはこの文を読み上げます。

次の書き方は、書いていないのとほとんど同じです。

```html
<img src="venue.png" alt="画像" />
<img src="venue.png" alt="venue.png" />
```

「画像」やファイル名を読んでも、伝わる情報がありません。**その画像が何を伝えているか** を文にしてください。地図なら「どこからどこまでの地図か」、グラフなら「何がどうなっているか」です。

## 2-1-3 相対パスでファイルの場所を指す

> **相対パスは、いま書いているファイルから見た位置でファイルを指す**

「ファイル名は合っているのに画像が出ない」の原因は、たいてい場所の指し方です。`src` に書くのは **相対パス** で、起点は **そのHTMLファイルが置いてあるフォルダ** です。

```html
<img src="images/venue.png" alt="会場の地図" />
```

これは「HTMLファイルと同じ場所にある `images` という **フォルダ** の中の `venue.png`」という意味です。区切りは `/`(スラッシュ)です。

| 書き方 | 指す場所 |
| --- | --- |
| `venue.png` | HTMLファイルと同じフォルダの中 |
| `images/venue.png` | 同じフォルダにある images の中 |
| `../venue.png` | 1つ上のフォルダ |

`..` が「1つ上」を意味します。この書き方はリンクの `href` でもまったく同じです。同じサイトの中の別ページへは `about.html` のように相対パスで書けます。

手元では表示できたのに、サーバーに上げると表示されないことがあります。多くはファイル名の大文字と小文字の違いです。手元のパソコンは区別しないことがありますが、サーバーは区別します。`Venue.png` と `venue.png` は別のファイルとして扱われる、と考えて書いてください。

## もっと知りたい人へ

- 画像ファイルの形式は、写真なら `.jpg`、図やアイコンなら `.png` や `.svg` が一般的です。用途で選びます
- 大きすぎる画像をそのまま貼ると、ページの表示が遅くなります。実務では表示する大きさに合わせて縮小してから使います

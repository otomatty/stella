# レッスン2-1 演習 — 画像を載せる

対象トピック: 2-1-1 〜 2-1-4

## 手元で試す

`index.html` と同じフォルダに `images` というフォルダを作り、手元にある画像を1枚入れてください(スマートフォンで受講している場合は、この節は飛ばして「演習問題」から進めてください)。

body に次の1行を足して保存し、ブラウザーで開きます。

```html
<img src="images/venue.png" alt="本社3階の会議室までの地図" />
```

2か所を自分の画像に合わせて書き換えてください。

- `src` のファイル名 — 実際に入れた画像の名前にする
- `alt` の文 — その画像が何を伝えているかを書く。地図でなければ「本社3階の会議室までの地図」は嘘になります

表示されたら、次の改造をしてみましょう。

1. `src` のファイル名をわざと1文字変えて、代替テキストが表示されることを確かめる(確かめたら戻す)
2. `src` を間違えたまま `alt` も消して、画像が出ないときに何も伝わらなくなることを確かめる(確かめたら両方戻す)
3. 画像を `images` フォルダの外に出し、`src` から `images/` の部分だけを消して(ファイル名はそのまま)表示できることを確かめる(確かめたら、画像を `images` に戻して `src` も元に戻す。あとのレッスンでこのパスを使います)
4. `width` と `height` を画像の実際の大きさで書き足し、そのあと `height` だけを半分の値に変えて、画像が歪むことを確かめる(確かめたら戻す)

## 演習問題

### 問1(基本)

`index.html` と同じフォルダにある `logo.png` を表示するHTMLを書いてください。代替テキストは「株式会社ファルコンのロゴ」としてください。

### 問2(基本)

次のHTMLは書き方として誤りです。ブラウザーでどう表示されるかを説明して、直してください。

```html
<img src="photo.jpg">研修の様子</img>
```

### 問3(応用)

`pages` フォルダの中にある `about.html` から、`images` フォルダの中の `team.png` を表示したいとします。`images` は `pages` と同じ階層にあります。src には何と書きますか。

### 問4(応用)

売上が前年より20%増えたことを示す棒グラフの画像に付ける alt を書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```html
<img src="logo.png" alt="株式会社ファルコンのロゴ" />
```

同じフォルダのファイルは、ファイル名だけで指せます。

</details>

<details>
<summary>問2の解答例</summary>

`img` は囲むタグではないので、中身と終了タグを書けません。ブラウザーは `</img>` を無視するため、画像は表示されたうえで、「研修の様子」がその後ろにただの本文として並びます。画像の説明としては扱われないので、画像が表示できないときの代わりにもなりません。

```html
<img src="photo.jpg" alt="研修の様子" />
```

説明は中身ではなく `alt` 属性に書きます。

</details>

<details>
<summary>問3の解答例</summary>

```html
<img src="../images/team.png" alt="チームの集合写真" />
```

起点は `about.html` のある `pages` フォルダです。`..` で1つ上に戻ってから `images` に入ります。

</details>

<details>
<summary>問4の解答例</summary>

```html
<img src="sales.png" alt="売上は前年比20%増" />
```

グラフの見た目ではなく、そのグラフが伝えたい結論を文にします。「棒グラフ」とだけ書いても情報になりません。

</details>

## 確認クイズ

### Q1. 画像ファイルの場所を書く属性はどれですか。

- A. src
- B. href
- C. alt

<details>
<summary>答え</summary>

**A** — 画像の場所は `src` です。`href` はリンクの行き先に使います。

</details>

### Q2. img タグの書き方として正しいものはどれですか。

- A. 開始タグと終了タグで説明の文を囲む
- B. 囲む中身がないので終了タグを書かない
- C. 終了タグだけを書く

<details>
<summary>答え</summary>

**B** — img は囲まないタグです。末尾を /> で閉じる書き方が一般的です。

</details>

### Q3. alt に書く内容として適切なものはどれですか。

- A. 画像
- B. venue.png
- C. 本社3階の会議室までの地図

<details>
<summary>答え</summary>

**C** — 画像が見えない人にも伝わる内容を書きます。「画像」やファイル名では何も伝わりません。

</details>

### Q4. 相対パスの起点はどこですか。

- A. パソコンの一番上のフォルダ
- B. そのHTMLファイルが置いてあるフォルダ
- C. ブラウザーがインストールされているフォルダ

<details>
<summary>答え</summary>

**B** — いま書いているファイルの場所が起点です。だから同じフォルダのファイルは名前だけで指せます。

</details>

### Q5. 1つ上のフォルダにある venue.png を指す書き方はどれですか。

- A. venue.png
- B. images/venue.png
- C. ../venue.png

<details>
<summary>答え</summary>

**C** — `..` が1つ上のフォルダを表します。

</details>

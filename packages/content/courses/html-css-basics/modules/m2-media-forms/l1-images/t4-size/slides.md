# widthとheightで場所を先に確保する

HTML/CSS入門研修 — Module 2 / レッスン2-1

<!-- ノート: 画像が表示できるようになったので、次は「表示されるまでの間」の話です。 -->

---

## なぜ必要か

- 読み込みの遅い画像があると、あとから割り込んで本文が下にずれる
- 押そうとしたリンクが動いて、別のリンクを押してしまう

<!-- ノート: つかみ。スマートフォンでニュースを読むときに全員が経験している。ここで結論は言わない。 -->

---

## 結論

**imgにwidthとheight属性を書くと、読み込み前から表示場所が確保される**

- **レイアウトのずれ** = 表示中に中身が動いて、位置が変わること
- 画像が届く前に、どれだけの場所を空けるか計算できる

<!-- ノート: 結論を言い切る。属性は「表示サイズ」ではなく「元の画像の大きさ」を書く。 -->

---

## 最小のコード

```html
<img src="images/venue.png" alt="本社3階の会議室" width="800" height="450" />
```

- 単位は書かない。画像そのものの大きさを数値だけで書く

<!-- ノート: 800px ではなく 800。画像ファイルのプロパティで確認できる値をそのまま書く。 -->

---

## 縦横比が合わないと歪む

```html
<img src="images/venue.png" alt="本社3階の会議室" width="800" height="200" />
```

- 元の画像と違う比率を書くと、引き伸ばされて歪む
- 縮めて表示したいときは、比率を保ったままCSSで調整する

<!-- ノート: 失敗例の枠。属性は「元の大きさの申告」。表示の調整はCSSの仕事、と分けておく。 -->

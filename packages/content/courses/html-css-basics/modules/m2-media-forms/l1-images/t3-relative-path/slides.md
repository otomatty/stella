## なぜ必要か

- ファイル名を正しく書いたのに画像が出ない
- 手元では出たのに、サーバーに上げたら出なくなった

<!-- ノート: つかみ。誰もが一度は踏む。原因は名前ではなく場所の指し方。 -->

---

## 結論

**相対パスは、いま書いているファイルから見た位置でファイルを指す**

- **相対パス** = 自分のいる場所を起点にした道順
- 起点は「そのHTMLファイルが置いてある **フォルダ**」

<!-- ノート: 結論を言い切る。起点がHTMLファイルの場所である、という点がすべて。 -->

---

## 最小のコード

```html
<img src="images/venue.png" alt="会場の地図" />
```

- 同じフォルダにある `images` の中の `venue.png`
- 区切りは `/`(スラッシュ)

<!-- ノート: 同じ階層のファイルはファイル名だけ。1つ下の階層はフォルダ名/ファイル名。 -->

---

## 書き方の型

| 書き方 | 指す場所 |
| --- | --- |
| `venue.png` | 同じフォルダの中 |
| `images/venue.png` | 同じフォルダにある images の中 |
| `../venue.png` | 1つ上のフォルダ |

<!-- ノート: 対比枠。..が1つ上。リンクのhrefもまったく同じ書き方で書ける。大文字小文字の違いはサーバーでは区別される点も触れる。 -->

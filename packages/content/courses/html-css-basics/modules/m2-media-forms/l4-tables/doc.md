# レッスン2-4 表でデータを示す

## このレッスンの目標

- [ ] table / tr / td で表を組み立てられる
- [ ] 見出しのセルを th と scope で示せる
- [ ] caption で表に題名を付けられる

## 2-4-1 表は行と列でデータを並べる

> **表はtableの中にtrで行を作り、その中にtdでセルを並べて作る**

日程・会場・定員のように、1件あたりの項目が複数ある一覧は、箇条書きでは表せません。「4月10日 本社3階 20名」と並べても、どれがどの項目の値なのかが読み取れないからです。

こういうデータのために **表** があります。

```html
<table>
  <tr>
    <td>4月10日</td>
    <td>本社3階</td>
  </tr>
  <tr>
    <td>5月8日</td>
    <td>本社5階</td>
  </tr>
</table>
```

- `table` — 表全体を囲む
- `tr` — **行**(横一列)を作る
- `td` — **セル**(1マス)を作る

書く順番は「表 → 行 → セル」です。**列**(縦一列)を作る要素はありません。各行に同じ数のセルを並べた結果として、列が揃います。

ここが最初のつまずきどころです。**行ごとに `td` の数が違うと、表が欠けて崩れます**。値が無いセルは、空の `td` を置いて数を合わせてください。

```html
<tr>
  <td>6月12日</td>
  <td></td>
</tr>
```

## 2-4-2 見出しのセルはthで示す

> **その行や列が何を表すかを示すセルは、tdではなくthで書く**

上の表は、1列目が日程で2列目が会場だ、ということがどこにも書かれていません。1行目を追加して太字にすれば人は読めますが、機械には「太字のセル」としか伝わりません。

見出しのセルには **th** を使います。

```html
<table>
  <tr>
    <th scope="col">日程</th>
    <th scope="col">会場</th>
  </tr>
  <tr>
    <td>4月10日</td>
    <td>本社3階</td>
  </tr>
</table>
```

`th` は既定で太字・中央寄せで表示されますが、それは結果です。目的は「このセルは見出しである」と伝えることです。

**scope** は、その見出しがどちらを向いているかを伝える属性です。

| 値 | 意味 |
| --- | --- |
| `col` | この見出しは、下に続く列のもの |
| `row` | この見出しは、右に続く行のもの |

読み上げソフトは `scope` を見て、「日程: 4月10日」「会場: 本社3階」と組にして読み上げます。表を目で追えない人にとって、この対応関係がすべてです。

1列目に項目名を並べる形の表なら、その列のセルを `<th scope="row">` にします。

## 2-4-3 captionで表に題名を付ける

> **その表が何の表かは、tableの先頭に置いたcaptionで示す**

ページに表がいくつも並ぶと、どれが何の表なのかが分からなくなります。表の上に段落で題を書くこともできますが、機械から見ればそれは「近くにある文章」でしかありません。

表そのものに題名を付ける要素が **caption** です。

```html
<table>
  <caption>2026年度 研修日程</caption>
  <tr>
    <th scope="col">日程</th>
    <th scope="col">会場</th>
  </tr>
</table>
```

置く場所が決まっています。**`table` の中の、いちばん先頭** です。`tr` より前に書いてください。

既定では表の上に中央寄せで表示されます。読み上げでは、表の中身に入る前に題名が読まれるので、利用者は「これから何の表を聞くのか」が分かった状態で中身に進めます。

## もっと知りたい人へ

- 1つのセルを横や縦にまたがらせる `colspan` / `rowspan` という属性があります。まずは1マス1セルの表を確実に書けるようにしてください
- 表はデータを並べるためのものです。ページの段組み(横並びのレイアウト)に使ってはいけません。並べ方はモジュール4のCSSで扱います

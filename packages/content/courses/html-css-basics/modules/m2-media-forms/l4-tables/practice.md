# レッスン2-4 演習 — 表でデータを示す

対象トピック: 2-4-1 〜 2-4-3

## 手元で試す

`index.html` の `main` の中に、次を足して保存し、ブラウザーで開いてください。

```html
<table>
  <caption>2026年度 研修日程</caption>
  <tr>
    <th scope="col">日程</th>
    <th scope="col">会場</th>
    <th scope="col">定員</th>
  </tr>
  <tr>
    <td>4月10日</td>
    <td>本社3階</td>
    <td>20名</td>
  </tr>
  <tr>
    <td>5月8日</td>
    <td>本社5階</td>
    <td>15名</td>
  </tr>
</table>
```

題名が上に出て、1行目が太字になっていれば成功です。書けたら、次の改造をしてみましょう。

1. 2行目の `td` を1つ消して保存し、表が欠けて崩れることを確かめる(確かめたら戻す)
2. `th` を `td` に変えて、見出しの見た目が消えることを確かめる(確かめたら戻す)
3. `caption` を `table` の直前(外)に移して保存し、表の題名としての扱いが失われて、ただの文字として表示されることを確かめる。ブラウザーは書き方の間違いをエラーにせず、黙って解釈しようとします(確かめたら戻す)
4. 行を1つ増やして、3列ぶんの `td` を並べる

## 演習問題

### 問1(基本)

2行2列の表を作るとき、`tr` と `td` はそれぞれいくつ書きますか。

### 問2(基本)

「氏名」「所属」を列の見出しとして持つ表の1行目を書いてください。

### 問3(応用)

表の1列目に「日程」「会場」「定員」という項目名を縦に並べる形にしました。この列のセルに書く `scope` の値はどれですか。理由も1文で書いてください。

### 問4(応用)

表の上に `<p>2026年度 研修日程</p>` と書くのと、`caption` に書くのとでは何が違いますか。1文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`tr` を2つ、`td` は各 `tr` の中に2つずつで合計4つです。列を作る要素は無く、行の中のセルの数で列が決まります。

</details>

<details>
<summary>問2の解答例</summary>

```html
<tr>
  <th scope="col">氏名</th>
  <th scope="col">所属</th>
</tr>
```

見出しのセルなので `td` ではなく `th` を使います。

</details>

<details>
<summary>問3の解答例</summary>

`row` です。その見出しは右に続く行についてのものだからです。

</details>

<details>
<summary>問4の解答例</summary>

`caption` は表の一部として結び付くので、読み上げでも表の題名として先に読まれます。段落は近くにある文章としか伝わりません。

</details>

## 確認クイズ

### Q1. 表の行を作る要素はどれですか。

- A. tr
- B. td
- C. table

<details>
<summary>答え</summary>

**A** — tr が行、td がその中のセルです。列を作る要素はありません。

</details>

### Q2. 行ごとに td の数が違うとどうなりますか。

- A. 足りないセルが自動で補われる
- B. 表が欠けて崩れる
- C. エラーになって表が消える

<details>
<summary>答え</summary>

**B** — 値が無いセルは、空の td を置いて数を合わせます。

</details>

### Q3. 見出しのセルに使う要素はどれですか。

- A. th
- B. caption
- C. strong

<details>
<summary>答え</summary>

**A** — th は「このセルは見出しである」と伝えます。太字になるのは結果です。

</details>

### Q4. scope="col" が表す向きはどれですか。

- A. 下に続く列の見出し
- B. 右に続く行の見出し
- C. 表全体の見出し

<details>
<summary>答え</summary>

**A** — 行の見出しなら row を指定します。読み上げはこの値を見て組にして読みます。

</details>

### Q5. caption を書く場所はどこですか。

- A. table の直前
- B. table の中のいちばん先頭
- C. 最後の tr の後ろ

<details>
<summary>答え</summary>

**B** — tr より前、table の中の先頭に置きます。

</details>

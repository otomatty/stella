# 表は行と列でデータを並べる

HTML/CSS入門 — Module 2 / レッスン2-4

<!-- ノート: 一覧やスケジュールは箇条書きでは表せません。ここから表の書き方に入ります。 -->

---

## なぜ必要か

- 日程・会場・定員のように、項目が複数ある一覧を並べたい
- 箇条書きにすると、どれがどの項目の値か読み取れない

<!-- ノート: つかみ。「4月10日 本社 20名」と並べても、意味の対応が伝わらない。ここで結論は言わない。 -->

---

## 結論

**表はtableの中にtrで行を作り、その中にtdでセルを並べて作る**

- **行** = 横一列、**列** = 縦一列、**セル** = その交差する1マス
- 書く順番は「表 → 行 → セル」

<!-- ノート: 結論を言い切る。列を作る要素は無い。行を並べた結果として列が揃う。 -->

---

## 最小のコード

```html
<table>
  <tr>
    <td>4月10日</td>
    <td>本社3階</td>
  </tr>
  <tr>
    <td>5月8日</td>
    <td>本社5階</td>
  </tr>
</table>
```

<!-- ノート: tr が2つで2行。各 tr の中の td が2つなので2列。数を揃えるのがコツ。 -->

---

## セルの数を揃える

- 行ごとに `td` の数が違うと、表が欠けて崩れる
- 値が無いセルは、空の `td` を置いて数を合わせる

<!-- ノート: 失敗例の枠。未経験者が最初に踏むのはこれ。データが無い=タグも無い、ではない。 -->

---

# 2-4-3
# captionで表に題名を付ける

HTML/CSS入門研修 — Module 2 / レッスン2-4

<!-- ノート: 表の最後のトピックです。表の外側に題名を置く方法を扱います。 -->

---

## なぜ必要か

- ページに表がいくつも並ぶと、どれが何の表か分からない
- 表の上に段落で題を書いても、その表のものだとは伝わらない

<!-- ノート: つかみ。p で書いた題名は、機械から見ればただの近くの文章。ここで結論は言わない。 -->

---

## 結論

**その表が何の表かは、tableの先頭に置いたcaptionで示す**

- **caption** = 表の題名を表す要素
- `table` の中の、いちばん先頭に置く

<!-- ノート: 結論を言い切る。置く場所が決まっている点が重要。tr より前。 -->

---

## 最小のコード

```html
<table>
  <caption>2026年度 研修日程</caption>
  <tr>
    <th scope="col">日程</th>
    <th scope="col">会場</th>
  </tr>
</table>
```

<!-- ノート: 既定では表の上に中央寄せで表示される。読み上げでは表に入る前に読まれる。 -->

---

## 段落で書いた題名との違い

```html
<p>2026年度 研修日程</p>
<table>...</table>
```

- 見た目はほぼ同じ
- 機械には「近くにある文章」としか伝わらない

<!-- ノート: 失敗例の枠。caption は表の一部として結び付く。だから読み上げで先に読まれる。 -->

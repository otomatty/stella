# 見出しのセルはthで示す

HTML/CSS入門研修 — Module 2 / レッスン2-4

<!-- ノート: 表の形はできました。ここで「どの列が何か」を機械にも伝えます。 -->

---

## なぜ必要か

- 1行目を太字にしただけでは、見出しの行だと機械には伝わらない
- 読み上げでは、値だけが延々と続いて何の数字か分からなくなる

<!-- ノート: つかみ。表は目で見れば分かるが、読み上げでは対応関係が消える。ここで結論は言わない。 -->

---

## 結論

**その行や列が何を表すかを示すセルは、tdではなくthで書く**

- **th** = 見出しのセル
- 既定で太字・中央寄せになる

<!-- ノート: 結論を言い切る。見た目が変わるのは結果。目的は役割を伝えること。 -->

---

## 最小のコード

```html
<table>
  <tr>
    <th scope="col">日程</th>
    <th scope="col">会場</th>
  </tr>
  <tr>
    <td>4月10日</td>
    <td>本社3階</td>
  </tr>
</table>
```

<!-- ノート: 1行目がまるごと th。列の見出しなので scope は col。 -->

---

## scopeで向きを伝える

| 値 | 意味 |
| --- | --- |
| `col` | この見出しは、下に続く列のもの |
| `row` | この見出しは、右に続く行のもの |

<!-- ノート: 対比枠。ここが本題。読み上げは scope を見て「日程: 4月10日」と組にして読む。 -->

# レッスン2-3 動画と音声の基本

## このレッスンの目標

- [ ] video で動画をページに埋め込める
- [ ] audio で音声をページに埋め込める
- [ ] track で字幕を添えて、音に頼らず内容を届けられる

## 2-3-1 動画はvideoに埋め込む

> **動画はvideoのsrcにファイルを指定し、controlsで操作できるようにする**

案内ページに、会場の様子や操作手順の動画を載せたい場面があります。動画ファイルへのリンクを置くだけでも開けますが、それでは利用者がページを離れてしまいます。ページの中で再生させるための要素が **video** です。

```html
<video src="videos/guide.mp4" controls>
  この動画は再生できません。
</video>
```

`src` の書き方は `img` と同じで、相対パスでファイルの場所を指します。

**controls** は、再生ボタン・一時停止・音量・再生位置のバーを表示させる指定です。値を書かず、属性名だけを書けば有効になります。書き忘れると、利用者は再生する手段が無いまま動画の1コマ目を眺めることになります。

`video` は終了タグを持ち、囲んだ中身は **`video` に対応していない環境でだけ** 表示されます。代わりの案内やダウンロードリンクを置いておくと親切です。

実務で気をつける点が2つあります。

- 動画ファイルは重くなりがちです。長い動画をそのまま置くと、ページの表示が遅くなります
- `autoplay` を付けると自動再生になりますが、音が突然鳴って利用者を驚かせます。多くのブラウザーは音付きの自動再生を止めるようになっています

## 2-3-2 音声はaudioに埋め込む

> **音声はaudioのsrcにファイルを指定し、videoと同じ書き方で埋め込む**

面談の練習音声や読み上げの例のように、音だけを載せたい場面もあります。映像が要らないのに動画にすると、そのぶんファイルが重くなります。

```html
<audio src="audio/sample.mp3" controls>
  この音声は再生できません。
</audio>
```

書き方は `video` と同じです。新しく覚えるのは要素名だけだと考えてください。

| 要素 | 画面に出るもの |
| --- | --- |
| `video` | 映像のぶんの四角い領域と操作バー |
| `audio` | 操作バーだけ |

`audio` には映像がないので、`controls` を書き忘れると **画面に何も表示されません**。「音声を置いたのに何も出ない」ときは、まず `controls` を確認してください。

## 2-3-3 trackで字幕を付ける

> **動画の内容を音に頼らず伝えるには、trackで字幕のファイルを添える**

画像に `alt` を付けたのと同じ考え方が、動画にもあります。音が聞こえない人には、動画の内容がまったく伝わりません。電車の中で音を出せない人も同じ状態です。

そこで **字幕** を添えます。字幕は別のファイルとして用意し、**track** で動画に結び付けます。

```html
<video src="videos/guide.mp4" controls>
  <track src="videos/guide.vtt" kind="captions" srclang="ja" label="日本語" default />
</video>
```

- `track` は `video` の中に書く
- **kind** — そのファイルの種類
- `srclang` — 字幕の言語
- `label` — 字幕の選択メニューに出る名前
- **default** — 最初から表示する

`default` を書き忘れると、字幕は **付いてはいるが表示されない** 状態になります。利用者が再生画面のメニューから選べば出ますが、気づかれないことがほとんどです。音に頼らず届けるのが目的なら `default` を付けてください。

`kind` の値は、**何のために字幕を付けるのか** で選びます。日本語では両方まとめて「字幕」と呼びますが、役割は別です。

| 値 | 想定する相手 | 中身 |
| --- | --- | --- |
| `captions` | 音を聞けない人。耳が聞こえない人や、音を出せない場面 | 話している内容に加えて、効果音や音楽などの音の情報も入れる |
| `subtitles` | 音は聞こえるが、その言語が分からない人 | 話している内容の翻訳 |

このトピックの目的は「音に頼らず内容を届ける」ことなので、選ぶのは `captions` です。

字幕ファイル(`.vtt`)はただのテキストファイルです。メモ帳でも書けます。

```text
WEBVTT

00:00:01.000 --> 00:00:04.000
本日は研修にご参加いただきありがとうございます。
```

先頭に `WEBVTT` と書き、あとは「表示する時間の範囲」と「表示する文」の組を並べるだけです。

## もっと知りたい人へ

- 同じ動画に `captions` と、別の言語の `subtitles` を両方添えることもできます。利用者が選択メニューから選びます
- 動画の形式(mp4 など)によっては、環境ごとに再生できたりできなかったりします。複数の形式を用意して切り替える書き方もありますが、この講座では1つだけ扱います

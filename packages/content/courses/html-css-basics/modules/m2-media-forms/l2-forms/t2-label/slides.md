# 2-2-2
# labelは入力欄と説明を結び付ける

HTML/CSS入門 — Module 2 / レッスン2-2

<!-- ノート: 入力欄を置けるようになったので、それを使えるフォームにする作法を扱います。 -->

---

## なぜ必要か

- 欄の隣に文字を置いただけでは、どの欄の説明かは見た目の並びでしか分からない
- スマートフォンでは、小さなチェックボックスを指で押しづらい

<!-- ノート: つかみ。人間は並びで判断できるが、機械には伝わらない。押しづらさの話も実感があってよい。 -->

---

## 結論

**labelのforとinputのidを同じ値にすると、説明と入力欄が結び付く**

- **label** = 入力欄の説明を書く要素
- **for** と **id** を同じ値にして対応させる

<!-- ノート: 結論を言い切る。for と id のペアが結び付けの仕組み。 -->

---

## 最小のコード

```html
<label for="name">お名前</label>
<input type="text" id="name" />
```

- `for="name"` と `id="name"` が同じ値
- ラベルを押すと、その欄にカーソルが入る

<!-- ノート: 実際に押して見せると効く。押せる範囲が広がるのは、そのまま使いやすさになる。 -->

---

## よくある間違い

```html
<label for="name">お名前</label>
<input type="text" id="fullname" />
```

- `for` と `id` の値が違うので結び付かない
- 見た目は変わらないため、気づきにくい

<!-- ノート: 失敗例の枠。値が一致しているかは、ラベルを押して欄にカーソルが入るかで確かめられる。 -->

---

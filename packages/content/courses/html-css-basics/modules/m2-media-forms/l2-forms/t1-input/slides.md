# inputは入力欄を作る

HTML/CSS入門 — Module 2 / レッスン2-2

## なぜ必要か

- 申し込みには名前やメールアドレスを書いてもらう必要がある
- 「ここに書いてください」と文字で頼んでも、書く場所がない

<!-- ノート: つかみ。読むだけのページから、使ってもらうページへ。ここで結論は言わない。 -->

---

## 結論

**inputはtype属性で種類が変わる、1つの入力欄を作るタグ**

- **input** = 1つの **入力欄** を作るタグ
- **type** = どんな種類の入力欄かを指定する属性

<!-- ノート: 結論を言い切る。inputはtypeで姿を変える。1つ書くと欄が1つできる。 -->

---

## 最小のコード

```html
<input type="text" />
```

- 1行の文字を入力する欄ができる
- `img` と同じく囲む中身がないタグ

<!-- ノート: 実際にブラウザーで表示させ、枠が出ることを見せる。ここではtypeの種類を並べない。 -->

---

## typeで姿が変わる

| type | できる欄 |
| --- | --- |
| `text` | 1行の文字 |
| `email` | メールアドレス用 |
| `date` | 日付を選ぶ欄 |
| `checkbox` | チェックボックス |

<!-- ノート: 対比枠。type一つで見た目も入力方法も変わる。スマホでは表示されるキーボードまで変わる。 -->

# 2-2-4
# typeは入力の種類に合わせて選ぶ

HTML/CSS入門研修 — Module 2 / レッスン2-2

<!-- ノート: type で種類が変わることは 2-2-1 で扱いました。ここは「どれを選ぶか」に絞ります。 -->

---

## なぜ必要か

- 全部 `type="text"` で作ると、スマートフォンで数字を打つのに毎回切り替えが要る
- メールアドレスの打ち間違いも、そのまま送られてしまう

<!-- ノート: つかみ。実際にスマホで電話番号を text 欄に打たせてみると全員が納得する。ここで結論は言わない。 -->

---

## 結論

**typeは見た目ではなく、受け取りたい入力の種類に合わせて選ぶ**

- 種類を伝えると、キーボードと入力チェックが自動で変わる
- 迷ったら「何を書いてほしい欄か」で選ぶ

<!-- ノート: 結論を言い切る。type は入力の中身の宣言。見た目を変えるつまみではない。 -->

---

## よく使うtype

| type | 受け取るもの |
| --- | --- |
| `text` | 短い文字列。名前など |
| `email` | メールアドレス |
| `tel` | 電話番号 |
| `date` | 日付 |
| `checkbox` | 複数選べる選択肢 |
| `radio` | 1つだけ選ぶ選択肢(グループにする指定が別に要る) |

<!-- ノート: 6つで足りる。checkbox と radio は「複数か1つか」で選ぶ、と口頭で補う。radio は置いただけでは全部選べてしまい、グループにする指定が要る。それは次のトピックで扱う。 -->

---

## 最小のコード

```html
<label for="mail">メールアドレス</label>
<input type="email" id="mail" placeholder="rei@example.com" />

<input type="checkbox" id="agree" />
<label for="agree">利用規約に同意する</label>
```

- `placeholder` = 空のときに薄く出る入力例

<!-- ノート: placeholder はラベルの代わりにはならない。入力すると消えるので、説明は label に書く。 -->

# レッスン2-2 入力を受け取る

## このレッスンの目標

- [ ] 受け取りたい内容に合わせて type を選べる
- [ ] label と input を for と id で結び付けられる
- [ ] form で入力欄をまとめ、button で送る形にできる

## 2-2-1 inputは入力欄を作る

> **inputはtype属性で種類が変わる、1つの入力欄を作るタグ**

申し込みや問い合わせでは、利用者に書いてもらう必要があります。1つの **入力欄** を作るタグが **input** です。どんな種類の欄になるかは **type** 属性で決まります。

```html
<input type="text" />
```

これで1行の文字を入力する欄ができます。`img` と同じく囲む中身がないタグなので、終了タグは書きません。

`type` を変えると、欄の姿と入力の方法が変わります。

| type | できる欄 |
| --- | --- |
| `text` | 1行の文字 |
| `email` | メールアドレス用 |
| `date` | 日付を選ぶ欄 |
| `checkbox` | チェックボックス |

スマートフォンでは、`type` に合わせて表示されるキーボードまで変わります。`email` なら記号が打ちやすい配列に、`date` なら日付を選ぶ画面になります。適切な `type` を選ぶことが、そのまま入力のしやすさになります。

## 2-2-2 labelは入力欄と説明を結び付ける

> **labelのforとinputのidを同じ値にすると、説明と入力欄が結び付く**

欄の隣に「お名前」と書くだけでは、人間は並びから判断できても、機械には対応が伝わりません。説明と欄を結び付ける要素が **label** です。`label` の **for** と `input` の **id** を同じ値にします。

```html
<label for="name">お名前</label>
<input type="text" id="name" />
```

`id` は、そのページの中でその要素を指すための名前です。同じ値を2か所で使わないようにします。

結び付けると2つのことが起こります。

- 読み上げソフトが「お名前の入力欄」と読める
- ラベルの文字を押しても、その欄にカーソルが入る

2つ目は使いやすさに直結します。特にチェックボックスは、四角そのものが小さいため、指では押しにくいものです。ラベルを押せるようになると、押せる範囲が文字の分だけ広がります。

次の書き方は結び付いていません。

```html
<label for="name">お名前</label>
<input type="text" id="fullname" />
```

見た目は正しく並んでいるので気づきにくい間違いです。ラベルを押して欄にカーソルが入るかどうかで確かめられます。

## 2-2-3 buttonは押せる部品を作る

> **buttonは、利用者が押して操作を始めるための部品を作る**

入力欄だけでは、書き終えたことを伝えられません。押して操作を始める **ボタン** を作る要素が **button** です。

```html
<button type="submit">送信する</button>
```

囲んだ中身が、ボタンに表示される文字になります。枠や影は、何も書かなくてもブラウザーが付けます。見た目はあとからCSSで自由に変えられます。

`div` に「送信する」と書いて枠を付ければ、見た目はボタンにできます。しかしそれは押せる部品ではありません。キーボードだけで操作する人はそこにたどり着けず、読み上げソフトもボタンだとは伝えません。押せる部品には `button` を使ってください。

リンクとの使い分けも役割で決めます。

| したいこと | 使うもの |
| --- | --- |
| 別のページへ移動する | リンク(`a`) |
| その場で操作を始める(送信など) | ボタン(`button`) |

見た目はどちらにも似せられますが、利用者はマウスの右クリックやキーボードの操作で「これは移動か、操作か」を区別しています。役割どおりの要素を選んでください。

## 2-2-4 typeは入力の種類に合わせて選ぶ

> **typeは見た目ではなく、受け取りたい入力の種類に合わせて選ぶ**

`type` で入力欄の種類が変わることは 2-2-1 で扱いました。では、どれを選べばよいのでしょうか。判断は1つです。**その欄に何を書いてほしいか** で選びます。

全部を `type="text"` にしても、見た目は成立します。しかしスマートフォンで開いたとき、電話番号の欄で数字キーボードが出ず、利用者が毎回切り替えることになります。メールアドレスの打ち間違いも、そのまま送られます。

| type | 受け取るもの |
| --- | --- |
| `text` | 短い文字列。名前など |
| `email` | メールアドレス |
| `tel` | 電話番号 |
| `date` | 日付 |
| `checkbox` | 複数選べる選択肢 |
| `radio` | 1つだけ選ぶ選択肢(グループにする指定が別に要る) |

まずはこの6つで足ります。**チェックボックス** は複数選べる選択肢、**ラジオボタン** は1つだけ選ぶ選択肢です。「複数か、1つか」で選び分けてください。

ラジオボタンには注意点が1つあります。**`type="radio"` を並べただけでは、全部選べてしまいます。** どれとどれが同じ選択肢の集まりなのかを伝える指定が別に必要で、それを付けて初めて「1つだけ」になります。その指定は次のトピックで扱うので、ここでは「グループにする指定が要る」とだけ押さえてください。

```html
<label for="mail">メールアドレス</label>
<input type="email" id="mail" placeholder="rei@example.com" />

<input type="checkbox" id="agree" />
<label for="agree">利用規約に同意する</label>
```

**placeholder** は、欄が空のときに薄く表示される入力例です。便利ですが、**ラベルの代わりにはなりません**。入力を始めると消えてしまうので、何を書く欄なのかという説明は `label` に書いてください。

## 2-2-5 formでひとまとまりにして送る

> **1回で送りたい入力欄はformで囲み、中のbuttonが送る部品になる**

欄とボタンが揃っても、それだけでは「1回の申込」になりません。どの欄がひとまとまりなのか、入力内容をどこへ渡すのかが決まっていないからです。

これを決めるのが **form** です。

```html
<form action="/apply">
  <label for="applicant">お名前</label>
  <input type="text" id="applicant" name="applicant" />
  <button>送信する</button>
</form>
```

- `form` — 1回の送信で扱う入力欄のまとまり
- `action` — 入力内容の **送信** 先
- **name** — 送られるときの、その欄の項目名

`button` は 2-2-3 で「押せる部品」として学びました。`form` の中に置くと、それは **送る部品** になります。押すと、その `form` の中の入力内容がまとめて `action` の送り先へ渡ります。

ここで欠かせないのが `name` です。**`name` を書いていない欄は、送られる内容に含まれません。** 入力はできるのに届け先には何も渡らない、という分かりにくい不具合になります。

`id` と `name` は役割が違います。混同しないでください。

| 属性 | 役割 |
| --- | --- |
| `id` | `label` と結び付けるための、ページ内の名札 |
| `name` | 送られるときの項目名。無いと送られない |

上の例では両方に同じ値を書いていますが、これは読みやすさのためで、決まりではありません。

`name` にはもう1つ役割があります。2-2-4 で保留にした、**ラジオボタンをグループにする指定** がこれです。

```html
<input type="radio" id="am" name="slot" />
<label for="am">午前</label>
<input type="radio" id="pm" name="slot" />
<label for="pm">午後</label>
```

同じ `name` を付けたラジオボタンは1つのグループになり、その中では1つしか選べません。`name` が違えば別のグループなので、両方選べてしまいます。`id` は1つずつ違う値、`name` はグループで同じ値、と使い分けます。

`form` で囲み忘れると、見た目は同じでもボタンを押して何も起きません。「入力欄とボタンは作ったのに動かない」ときは、まず `form` があるかを確認してください。

送られた内容をサーバー側でどう受け取るかは、この講座の範囲外です。ここでは「1回ぶんの入力を `form` でまとめる」というHTML側の役割まで押さえてください。

## もっと知りたい人へ

- 実際にデータを送るには、入力欄とボタンを `form` という要素で囲み、送り先を指定します。送信の仕組みそのものはサーバー側の話になるので、この講座では扱いません
- 入力を必須にする、文字数を制限するといった指定も属性でできます。必要になったときに製品のリファレンスで確認してください

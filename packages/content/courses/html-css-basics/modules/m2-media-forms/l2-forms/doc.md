# レッスン2-2 入力を受け取る

## このレッスンの目標

- [ ] type を選んで入力欄を作れる
- [ ] label と input を for と id で結び付けられる
- [ ] リンクとボタンを役割で使い分けられる

## 2-2-1 inputは入力欄を作る

> **inputはtype属性で種類が変わる、1つの入力欄を作るタグ**

申し込みや問い合わせでは、利用者に書いてもらう必要があります。1つの **入力欄** を作るタグが **input** です。どんな種類の欄になるかは **type** 属性で決まります。

```html
<input type="text" />
```

これで1行の文字を入力する欄ができます。`img` と同じく囲む中身がないタグなので、終了タグは書きません。

`type` を変えると、欄の姿と入力の方法が変わります。

| type | できる欄 |
| --- | --- |
| `text` | 1行の文字 |
| `email` | メールアドレス用 |
| `date` | 日付を選ぶ欄 |
| `checkbox` | チェックボックス |

スマートフォンでは、`type` に合わせて表示されるキーボードまで変わります。`email` なら記号が打ちやすい配列に、`date` なら日付を選ぶ画面になります。適切な `type` を選ぶことが、そのまま入力のしやすさになります。

## 2-2-2 labelは入力欄と説明を結び付ける

> **labelのforとinputのidを同じ値にすると、説明と入力欄が結び付く**

欄の隣に「お名前」と書くだけでは、人間は並びから判断できても、機械には対応が伝わりません。説明と欄を結び付ける要素が **label** です。`label` の **for** と `input` の **id** を同じ値にします。

```html
<label for="name">お名前</label>
<input type="text" id="name" />
```

`id` は、そのページの中でその要素を指すための名前です。同じ値を2か所で使わないようにします。

結び付けると2つのことが起こります。

- 読み上げソフトが「お名前の入力欄」と読める
- ラベルの文字を押しても、その欄にカーソルが入る

2つ目は使いやすさに直結します。特にチェックボックスは、四角そのものが小さいため、指では押しにくいものです。ラベルを押せるようになると、押せる範囲が文字の分だけ広がります。

次の書き方は結び付いていません。

```html
<label for="name">お名前</label>
<input type="text" id="fullname" />
```

見た目は正しく並んでいるので気づきにくい間違いです。ラベルを押して欄にカーソルが入るかどうかで確かめられます。

## 2-2-3 buttonは押せる部品を作る

> **buttonは、利用者が押して操作を始めるための部品を作る**

入力欄だけでは、書き終えたことを伝えられません。押して操作を始める **ボタン** を作る要素が **button** です。

```html
<button type="submit">送信する</button>
```

囲んだ中身が、ボタンに表示される文字になります。枠や影は、何も書かなくてもブラウザーが付けます。見た目はあとからCSSで自由に変えられます。

`div` に「送信する」と書いて枠を付ければ、見た目はボタンにできます。しかしそれは押せる部品ではありません。キーボードだけで操作する人はそこにたどり着けず、読み上げソフトもボタンだとは伝えません。押せる部品には `button` を使ってください。

リンクとの使い分けも役割で決めます。

| したいこと | 使うもの |
| --- | --- |
| 別のページへ移動する | リンク(`a`) |
| その場で操作を始める(送信など) | ボタン(`button`) |

見た目はどちらにも似せられますが、利用者はマウスの右クリックやキーボードの操作で「これは移動か、操作か」を区別しています。役割どおりの要素を選んでください。

## もっと知りたい人へ

- 実際にデータを送るには、入力欄とボタンを `form` という要素で囲み、送り先を指定します。送信の仕組みそのものはサーバー側の話になるので、この講座では扱いません
- 入力を必須にする、文字数を制限するといった指定も属性でできます。必要になったときに製品のリファレンスで確認してください

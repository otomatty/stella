# レッスン3-2 どの指定が効くのか

## このレッスンの目標

- [ ] 同じ条件の指定が重なったときの勝ち負けを説明できる
- [ ] 詳細度の違いで優先順位が変わることを説明できる
- [ ] 継承されるプロパティとされないプロパティを区別できる

## 3-2-1 同じ相手に当たると後の宣言が勝つ

> **同じ条件で同じプロパティを指定したら、後に書いた宣言が勝つ**

CSSでいちばん時間を溶かすのが「書いたのに効かない」です。原因の1つが指定の重なりです。指定が重なったときの決め方を **カスケード** と呼びます。CSSの頭文字のCはこのカスケードです。重なることを前提にした仕組みだ、と考えてください。

```css
h1 {
  color: navy;
}
h1 {
  color: crimson;
}
```

表示されるのは後に書いた深紅です。前の指定は消えたのではなく、**上書き** されて負けています。プロパティが違えば両方効きます。負けるのは、同じ相手に同じプロパティを指定したときだけです。

「効かない」ときは、次の順で探すと早く見つかります。

1. 同じプロパティを、後ろでもう一度指定していないか
2. スタイルシートを2つ読み込んでいないか(後に読み込んだ方が勝ちます)
3. そもそも保存と再読み込みをしたか

## 3-2-2 詳細度が高いセレクタが優先される

> **書いた順より先に、より細かく指定したセレクタの宣言が優先される**

順番の話だけでは説明できない現象があります。一番下に書いたのに効かない、という場面です。

```css
.note {
  color: crimson;
}
p {
  color: navy;
}
```

```html
<p class="note">受付は3月末までです。</p>
```

この段落は深紅で表示されます。後に書いた `p` の紺色が負けています。セレクタの細かさを **詳細度** と呼び、詳細度が高いほうが優先されるためです。

書いた順で決まるのは、**詳細度が同じときだけ** です。順番の勝負は同点のときの決着方法だった、と考えると整理できます。

この講座の範囲では、強さは2段階で足ります。

| セレクタ | 強さ |
| --- | --- |
| 要素の名前(`p`) | 弱い |
| クラスセレクタ(`.note`) | 強い |

迷ったらクラスセレクタで書いてください。効かせたいからと、より強いセレクタや `!important` という指定で無理やり勝たせる書き方があります。しかし一度それを始めると、次に直す人はさらに強い書き方をするしかなくなります。強さで殴り合ったCSSは、誰にも直せなくなります。

## 3-2-3 文字の指定は子に受け継がれる

> **文字にかかわる一部のプロパティは、親から子へ受け継がれる**

指定していない要素の見た目が変わっていることがあります。これは **継承** です。親要素に指定した一部のプロパティは、子要素にも受け継がれます。

```css
body {
  color: dimgray;
}
```

`body` はすべての要素の親なので、これだけでページ全体の文字が灰色になります。段落や見出しに1つずつ書く必要はありません。ページ全体の既定値を `body` に置くのは、実務でもよく使う書き方です。

ただし、すべてのプロパティが継承されるわけではありません。

| プロパティ | 継承 |
| --- | --- |
| 文字色・文字サイズ | される |
| 余白・枠線・背景 | されない |

余白や枠線が子に伝わってしまうと、入れ子にするたびに二重の枠が出てしまいます。継承されないのには理由がある、と考えると覚えやすくなります。子に効かせたいときは、子を選んで指定してください。

## もっと知りたい人へ

- ブラウザーには、何も指定しなくても適用される既定のスタイルがあります。見出しが大きく表示されるのはそのためです。自分で書いた指定は、この既定のスタイルより優先されます
- 詳細度には実際にはもう少し細かい段階があります。要素名とクラスの2段階を押さえておけば、この講座の範囲では困りません

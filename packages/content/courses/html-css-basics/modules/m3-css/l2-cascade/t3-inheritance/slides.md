# 3-2-3
# 文字の指定は子に受け継がれる

HTML/CSS入門研修 — Module 3 / レッスン3-2

<!-- ノート: レッスン3-2の最後です。指定していないのに効いている、の正体です。 -->

---

## なぜ必要か

- ページ全体の文字色をそろえたいのに、要素の数だけ指定を書くのは大変
- 指定していない要素の色が変わって、原因が分からなくなることもある

<!-- ノート: つかみ。うまく使えば楽になるが、知らないと混乱する仕組み。ここで結論は言わない。 -->

---

## 結論

**文字にかかわる一部のプロパティは、親から子へ受け継がれる**

- 受け継がれることを **継承** と呼ぶ
- 文字色・文字サイズなどが対象

<!-- ノート: 結論を言い切る。すべてのプロパティが継承されるわけではない、が重要な但し書き。 -->

---

## 最小のコード

```css
body {
  color: dimgray;
}
```

- `body` の中のすべての要素の文字が灰色になる
- 段落や見出しに1つずつ書かなくてよい

<!-- ノート: bodyは全要素の親。ページ全体の既定値をここに置く、という使い方が定番。 -->

---

## 継承されないものもある

| プロパティ | 継承 |
| --- | --- |
| 文字色・文字サイズ | される |
| 余白・枠線・背景 | されない |

- 子に効かせたいなら、子を選んで指定する

<!-- ノート: 対比枠。余白や枠が子に伝わったら、入れ子のたびに二重の枠が出てしまう。継承されない理由も納得できる。 -->

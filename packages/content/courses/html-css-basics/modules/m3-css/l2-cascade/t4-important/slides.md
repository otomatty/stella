# important は最後の手段

HTML/CSS入門 — Module 3 / レッスン3-2

## なぜ必要か

- 詳細度を上げても効かない指定があり、時間だけが過ぎる
- 検索して出てきた `!important` を貼ると、とりあえず直る

<!-- ノート: つかみ。「とりあえず直る」がこの話の危うさそのもの。ここで結論は言わない。 -->

---

## 結論

**!importantは順序も詳細度も飛び越えて勝つので、最後の手段にする**

- 付けた宣言が、他のどの宣言よりも優先される
- 強すぎるので、あとから正攻法で直せなくなる

<!-- ノート: 結論を言い切る。禁止ではないが、使うと次の人の選択肢を奪う。 -->

---

## 最小のコード

```css
p {
  color: crimson !important;
}

.note {
  color: navy;
}
```

- 詳細度は `.note` が高いのに、`p` の深紅が勝つ

<!-- ノート: 3-2-2 で学んだ順位が逆転する。値の後ろ、セミコロンの前に書く。 -->

---

## 打ち消すには重ねるしかない

```css
.note {
  color: navy !important;
}
```

- `!important` を打ち消せるのは `!important` だけ
- こうして、ページ全体が `!important` だらけになる

<!-- ノート: 失敗例の枠。まず開発者ツールで、なぜ効かないかを調べる。それが正攻法。 -->

# 詳細度が高いセレクタが優先される

HTML/CSS入門研修 — Module 3 / レッスン3-2

<!-- ノート: 順番の話だけでは説明できない現象を扱います。 -->

---

## なぜ必要か

- 一番下に書いたのに効かない指定がある
- 効かせたくて `!important` を足すと、あとで誰も直せなくなる

<!-- ノート: つかみ。無理やり効かせる書き方が積み上がった現場の惨状を軽く触れる。ここで結論は言わない。 -->

---

## 結論

**書いた順より先に、より細かく指定したセレクタの宣言が優先される**

- セレクタの細かさを **詳細度** と呼ぶ
- 詳細度が同じときだけ、書いた順で決まる

<!-- ノート: 結論を言い切る。順番の勝負は同点のときの決着方法だった、という順序で理解させる。 -->

---

## 最小のコード

```css
.note {
  color: crimson;
}
p {
  color: navy;
}
```

```html
<p class="note">受付は3月末までです。</p>
```

- 後に書いた `p` ではなく、`.note` の深紅が勝つ

<!-- ノート: 実際に表示させて見せる。後に書いたほうが負ける、が初見では驚きになる。 -->

---

## 強さの順

| セレクタ | 強さ |
| --- | --- |
| 要素の名前(`p`) | 弱い |
| クラスセレクタ(`.note`) | 強い |

- 迷ったらクラスセレクタで書く
- 強さで殴り合うと、あとで直せなくなる

<!-- ノート: 対比枠。この講座の範囲では2段階で足りる。id セレクタや !important は、まだ使わせない。 -->

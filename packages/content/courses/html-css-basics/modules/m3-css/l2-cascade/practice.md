# レッスン3-2 演習 — どの指定が効くのか

対象トピック: 3-2-1 〜 3-2-4

## 手元で試す

`style.css` を次の内容にして保存し、`index.html` を再読み込みしてください。

```css
body {
  color: dimgray;
}

.note {
  color: crimson;
}

p {
  color: navy;
}
```

目印を付けていない段落は紺色、`class="note"` を付けた段落は深紅になります。見出しは、どこにも指定がないので `body` から受け継いだ灰色です。

確かめられたら、次の改造をしてみましょう。

1. `.note` の並びを `p` より後ろに移動して、表示が変わらないことを確かめる(順番より詳細度が先)
2. `p` の宣言をもう1つ下に足して `color: green;` にし、緑になることを確かめる(確かめたら足した宣言を消す)
3. `body` に `border: 1px solid gray;` を足して、枠が子に受け継がれないことを確かめる(確かめたら消す)
4. `p` の `color` に `!important` を付けて、詳細度の高い `.note` に勝つことを確かめる(確かめたら消す)

## 演習問題

### 問1(基本)

次のCSSで、段落は何色で表示されますか。理由も書いてください。

```css
p {
  color: navy;
}
p {
  color: green;
}
```

### 問2(基本)

次のCSSとHTMLで、この段落は何色で表示されますか。理由も書いてください。

```css
.note {
  color: crimson;
}
p {
  color: navy;
}
```

```html
<p class="note">受付は3月末までです。</p>
```

### 問3(応用)

ページ全体の文字色を灰色にしたいとき、どのセレクタに指定するのが効率的ですか。その理由も書いてください。

### 問4(応用)

`body` に指定した余白が、中の段落には受け継がれませんでした。これは不具合ですか。1〜2文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

緑です。セレクタが同じで詳細度も同じなので、後に書いた宣言が勝ちます。

</details>

<details>
<summary>問2の解答例</summary>

深紅です。クラスセレクタのほうが詳細度が高く、書いた順より優先されるためです。

</details>

<details>
<summary>問3の解答例</summary>

`body` に指定します。文字色は継承されるプロパティなので、すべての子要素に受け継がれ、1か所の指定でページ全体に効きます。

</details>

<details>
<summary>問4の解答例</summary>

不具合ではありません。余白や枠線、背景は継承されないプロパティです。継承されると入れ子のたびに余白が重なってしまうためです。

</details>

## 確認クイズ

### Q1. 同じセレクタで同じプロパティを2回指定したとき、勝つのはどちらですか。

- A. 先に書いた宣言
- B. 後に書いた宣言
- C. 値が短いほうの宣言

<details>
<summary>答え</summary>

**B** — 詳細度が同じときは、後に書いたほうが勝ちます。

</details>

### Q2. p のセレクタと、クラスセレクタで同じプロパティを指定したとき、優先されるのはどちらですか。

- A. 要素の名前のセレクタ
- B. クラスセレクタ
- C. あとに書いたほう

<details>
<summary>答え</summary>

**B** — 詳細度が高いクラスセレクタが優先されます。順番で決まるのは詳細度が同じときだけです。

</details>

### Q3. 指定が重なったときの決め方を何と呼びますか。

- A. カスケード
- B. 継承
- C. 相対パス

<details>
<summary>答え</summary>

**A** — CSSのCはカスケードのCです。重なることを前提にした仕組みです。

</details>

### Q4. 継承されるプロパティはどれですか。

- A. 文字色
- B. 余白
- C. 枠線

<details>
<summary>答え</summary>

**A** — 文字にかかわる一部のプロパティが継承されます。余白や枠線、背景は継承されません。

</details>

### Q5. CSSが効かないときに最初に確認することとして適切でないものはどれですか。

- A. 同じプロパティを後ろで指定していないか
- B. 保存と再読み込みをしたか
- C. パソコンのメモリが足りているか

<details>
<summary>答え</summary>

**C** — 効かない原因のほとんどは、指定の重なりか、保存と再読み込みのし忘れです。

</details>

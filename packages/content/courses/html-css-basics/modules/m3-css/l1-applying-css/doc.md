# レッスン3-1 CSSを書いて読み込む

## このレッスンの目標

- [ ] セレクタと宣言の形でCSSを書ける
- [ ] スタイルシートを作って link で読み込める
- [ ] class を付けて、当てる相手を選べる

## 3-1-1 CSSはセレクタと宣言で書く

> **CSSは「どれに」を表すセレクタと、「何を」を表す宣言の組で書く**

CSSは覚えることが多そうに見えますが、文の形は1つしかありません。「どの要素に」を表す **セレクタ** と、「何をどうするか」を表す **宣言** の組です。

```css
h1 {
  color: navy;
}
```

「`h1` という要素すべてに、文字色を紺色にする」と読みます。`h1` がセレクタ、波かっこの中の `color: navy;` が宣言です。

宣言は2つの部分でできています。

```css
h1 {
  color: navy;
  font-size: 32px;
}
```

- **プロパティ** — 何を変えるか(`color`)
- **値** — どう変えるか(`navy`)

プロパティと値はコロン(`:`)で結び、宣言の終わりにセミコロン(`;`)を付けます。宣言はいくつでも並べられます。

セミコロンの付け忘れは定番のつまずきです。区切りがないと、次の行までがひとつづきの値として読まれます。その値は解釈できないので宣言ごと捨てられ、**2つの宣言がまとめて効かなくなります**。1つだけ効かないのではない、という点が探すときの手がかりになります。うまく効かないときは区切りを疑ってください。

## 3-1-2 CSSは別ファイルにしてlinkで読み込む

> **CSSは.cssファイルに分け、headのlinkで読み込む**

CSSを書いたファイルを **スタイルシート** と呼びます。`.css` という拡張子で保存し、HTMLの head から **link** で読み込みます。

```html
<head>
  <meta charset="UTF-8" />
  <link rel="stylesheet" href="style.css" />
</head>
```

- `href` — スタイルシートの場所。**相対パス** の書き方は画像やリンクと同じです
- **rel** — 読み込むファイルとの関係の種類。スタイルシートだという指定です

これでファイルが2つになります。

| ファイル | 中身 |
| --- | --- |
| `index.html` | ページの中身 |
| `style.css` | 見た目の指定 |

`style.css` の中にはHTMLのタグを書きません。セレクタと宣言だけを書きます。逆にHTMLの中には見た目の指定を書きません。

分けておくと、同じ `style.css` を何ページからでも読み込めます。「全ページの見出しの色を変えてほしい」という依頼が、1ファイルの1行の変更で済みます。

## 3-1-3 classで当てる相手を選ぶ

> **class属性を付けると、同じ見た目を必要な要素にだけ当てられる**

セレクタに要素の名前を書くと、そのページのすべての同じ要素に当たります。「注意書きの段落だけ赤くしたい」ときには当たりすぎます。

そこで、HTML側の要素に **class** という目印を付け、CSS側でその目印を狙います。

```html
<p class="note">受付は3月末までです。</p>
```

```css
.note {
  color: crimson;
}
```

HTML側は `class="note"` と書き、CSS側は先頭に `.` を付けて `.note` と書きます。この `.` の有無が最初の混乱ポイントです。**HTMLには点を書かない、CSSには点を書く** と覚えてください。CSS側で書くこの形を **クラスセレクタ** と呼びます。

同じ目印は何度でも使えます。

```html
<p class="note">受付は3月末までです。</p>
<p>会場は本社です。</p>
<p class="note">定員があります。</p>
```

目印を付けた2つの段落だけが赤くなります。

目印の名前は、見た目ではなく役割で付けるのがおすすめです。`red` という名前を付けると、あとで色を青に変えたときに名前が嘘になります。`note`(注意書き)のように役割で名付けておけば、色を変えても名前は正しいままです。

## もっと知りたい人へ

- 1つの要素に複数の目印を付けることもできます。`class="note important"` のように空白で区切ります
- セレクタには他にも書き方があります。まずは要素の名前とクラスセレクタの2つで十分です

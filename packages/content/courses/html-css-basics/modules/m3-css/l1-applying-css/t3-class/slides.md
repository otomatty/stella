# classで当てる相手を選ぶ

HTML/CSS入門 — Module 3 / レッスン3-1

## なぜ必要か

- 「注意書きの段落だけ赤くしたい」のに、要素名で選ぶと全部赤くなる
- かといって、赤くしたい段落だけを別の要素にすることはできない

<!-- ノート: つかみ。pを選ぶと全部のpに当たる。この「当たりすぎ」が困りごと。 -->

---

## 結論

**class属性を付けると、同じ見た目を必要な要素にだけ当てられる**

- **class** = 要素に付ける目印の属性
- CSS側は `.目印` で選ぶ

<!-- ノート: 結論を言い切る。HTMLに目印を付け、CSSでその目印を狙う。2つでワンセット。 -->

---

## 最小のコード

```html
<p class="note">受付は3月末までです。</p>
```

```css
.note {
  color: crimson;
}
```

- HTML側で `class="note"` と付ける
- CSS側は先頭に `.` を付けて **クラスセレクタ** にする

<!-- ノート: HTML側には点を書かない、CSS側には点を書く。ここが最初の混乱ポイント。 -->

---

## 同じ目印は何度でも使える

```html
<p class="note">受付は3月末までです。</p>
<p>会場は本社です。</p>
<p class="note">定員があります。</p>
```

- 目印を付けた要素だけに当たる
- 別の要素にも同じ目印を付けられる

<!-- ノート: 対比枠。目印は使い回せる。名前は見た目ではなく役割で付けると、あとで色を変えても名前が嘘にならない。 -->

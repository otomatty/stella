## なぜ必要か

- HTMLの中に見た目を書くと、ページが増えるたびに同じ指定が増える
- 「全ページの色を変えて」の依頼で、全ファイルを開くことになる

<!-- ノート: つかみ。0-1-3で触れた分担の話が、ここで具体的な作業になる。ここで結論は言わない。 -->

---

## 結論

**CSSは.cssファイルに分け、headのlinkで読み込む**

- CSSを書いたファイルを **スタイルシート** と呼ぶ
- **link** で、HTMLからスタイルシートを読み込む

<!-- ノート: 結論を言い切る。1つのスタイルシートを何ページからでも読み込める、が要点。 -->

---

## 最小のコード

```html
<head>
  <meta charset="UTF-8" />
  <link rel="stylesheet" href="style.css" />
</head>
```

- `href` にスタイルシートの場所を **相対パス** で書く
- **rel** はその関係の種類(スタイルシートである、という指定)

<!-- ノート: linkはheadに書く。hrefの書き方は画像やリンクと同じ相対パス。 -->

---

## ファイルは2つになる

| ファイル | 中身 |
| --- | --- |
| `index.html` | ページの中身 |
| `style.css` | 見た目の指定 |

# 3-1-1
# CSSはセレクタと宣言で書く

HTML/CSS入門研修 — Module 3 / レッスン3-1

<!-- ノート: ここから見た目の担当に入ります。まずCSSの文の形を固定します。 -->

---

## なぜ必要か

- 見た目を変えたいが、どこに何をどう書けばいいのか分からない
- 書き方の型が分からないと、リファレンスを読んでも当てはめられない

<!-- ノート: つかみ。CSSは覚えるプロパティが多いが、文の形は1つしかない。そこを先に固める。 -->

---

## 結論

**CSSは「どれに」を表すセレクタと、「何を」を表す宣言の組で書く**

- **セレクタ** = どの要素に当てるか
- **宣言** = 何をどうするか

<!-- ノート: 結論を言い切る。この2つの組み合わせしかない、と伝えると学習がぐっと楽になる。 -->

---

## 最小のコード

```css
h1 {
  color: navy;
}
```

- `h1` が **セレクタ**
- `color: navy;` が **宣言**

<!-- ノート: 「h1という要素すべてに、文字色を紺色にする」と読み上げる。波かっこの中が宣言の置き場所。 -->

---

## 宣言はプロパティと値

```css
h1 {
  color: navy;
  font-size: 32px;
}
```

- **プロパティ** = 何を変えるか(`color`)
- **値** = どう変えるか(`navy`)
- 宣言は `;` で区切って何個でも並べられる

<!-- ノート: 対比枠。プロパティと値はコロンで結ぶ。宣言の終わりのセミコロン忘れは定番のつまずき。 -->

# CSSの当て方は3通りある

HTML/CSS入門研修 — Module 3 / レッスン3-1

<!-- ノート: 外部ファイルの書き方は覚えました。ここで「なぜそれを選ぶのか」を他の2つとの比較で固めます。 -->

## なぜ必要か

- ネットで見つけた例が、タグの中に直接 `style=` と書いていて戸惑う
- 手っ取り早く直したくて、その場で `style=` を足してしまう

<!-- ノート: つかみ。3通りあることを知らないと、混ざったコードを読めない。ここで結論は言わない。 -->

---

## 結論

**CSSはstyle属性・style要素・外部ファイルの3通りで当てられ、既定は外部ファイル**

- 書ける場所は3つある
- 実務で選ぶのは、原則いちばん下の外部ファイル

<!-- ノート: 結論を言い切る。3つ知ったうえで1つを選ぶ、という形にする。 -->

---

## 3つの書き方

```html
<p style="color: crimson;">その要素だけ</p>

<style>
  p { color: crimson; }
</style>

<link rel="stylesheet" href="style.css" />
```

- 上から順に **インラインスタイル**、**style要素**、外部ファイル

<!-- ノート: 上2つは説明のためだけに見せる。書けるようになる必要はない。 -->

---

## なぜ外部ファイルを選ぶのか

| 書き方 | 困ること |
| --- | --- |
| `style` 属性 | 要素1つぶんしか効かず、同じ指定が散らばる |
| `style` 要素 | そのページの中でしか使い回せない |
| 外部ファイル | 全ページで共有でき、1か所直せば全部直る |

<!-- ノート: 対比枠。ここが本題。0-1-3 の「見た目を分ける」がここで実利になる。 -->

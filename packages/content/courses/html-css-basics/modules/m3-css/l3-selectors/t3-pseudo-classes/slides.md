# 3-3-3
# 擬似クラスは状態で当たる

HTML/CSS入門研修 — Module 3 / レッスン3-3

<!-- ノート: ここまでは「どの要素か」でした。ここからは「どんな状態か」で選びます。 -->

---

## なぜ必要か

- 押せる場所なのかどうかが、見た目で分からない
- キーボードで操作する人は、いまどこにいるのかを見失う

<!-- ノート: つかみ。マウスを乗せても何も反応しないボタンは、押せるのか判断できない。 -->

---

## 結論

**コロンで始まる擬似クラスを付けると、その要素が特定の状態のときだけ当たる**

- **擬似クラス** = 状態を表す、コロン付きの追加条件
- HTMLには何も書き足さない

<!-- ノート: 結論を言い切る。class と違い、HTML側の準備が要らない点が重要。 -->

---

## 最小のコード

```css
a:hover {
  color: crimson;
}

input:focus {
  background-color: lightyellow;
}
```

- **hover** = 上にマウスが乗っている状態

<!-- ノート: hover は「重なっている」の意味。触れている間だけ当たる。 -->

---

## focusは消さない

- **focus** = キーボードなどで、その要素が操作対象になっている状態
- 既定の枠が邪魔だからと消すと、キーボードでは操作できなくなる

<!-- ノート: 失敗例の枠。outline: none だけ書くのは事故。消すなら代わりの目印を必ず付ける。 -->

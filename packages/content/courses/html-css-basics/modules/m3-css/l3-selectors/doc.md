# レッスン3-3 セレクタと状態

## このレッスンの目標

- [ ] 要素セレクタ・クラスセレクタ・IDセレクタを書き分けられる
- [ ] 子孫セレクタで当てる範囲を絞れる
- [ ] :hover と :focus で状態ごとの見た目を指定できる

## 3-3-1 セレクタは要素・class・idで選ぶ

> **当てる相手は、要素名・class・idの3つの書き分けで選ぶ**

レッスン3-1では、要素名で選ぶ書き方と、`class` を付けて選ぶ書き方を使いました。ここで書き分けを整理し、3つ目を足します。

```css
p { color: navy; }
.note { color: crimson; }
#footer-note { color: gray; }
```

```html
<p class="note" id="footer-note">お問い合わせ</p>
```

- **要素セレクタ** — 記号なし。その種類の要素すべてに当たる
- クラスセレクタ — `.` 付き。その `class` を付けた要素すべてに当たる
- **IDセレクタ** — `#` 付き。その `id` を持つ要素に当たる

`id` は 2-2-2 で `label` と結び付けるために使いました。同じ値をページ内で2つ以上使えない、という決まりがある属性です。

| 書き方 | 当たる範囲 | 使いどころ |
| --- | --- | --- |
| `p` | その種類の要素すべて | ページ全体の土台になる指定 |
| `.note` | 付けた要素すべて | 見た目の使い回し。**まずこれ** |
| `#footer-note` | ページに1つだけ | 実務ではほとんど使わない |

IDセレクタを避けるのは、ページに1つしか使えないうえ、詳細度が高すぎるためです。あとから `class` で上書きしようとしても勝てず、`!important` に頼ることになります。**既定は class** と覚えてください。

## 3-3-2 空白でつなぐと中の要素だけに当たる

> **セレクタを空白でつなぐと、その中にある要素だけに当たる**

「カードの中の段落だけ小さくしたい」という場面を考えます。`p` で選ぶとページ中の段落すべてに当たります。かといって、対象の段落ひとつひとつに `class` を付けて回るのは大変ですし、HTMLが `class` だらけになります。

そこで、セレクタを空白でつなぎます。

```css
.card p {
  color: gray;
}
```

```html
<div class="card"><p>研修のご案内</p></div>
<p>この段落には当たらない</p>
```

これが **子孫セレクタ** です。「`.card` の中にある `p`」という意味になります。左が範囲、右が当てる相手です。読むときは右から「`p` のうち、`.card` の中にあるもの」と読むと分かりやすくなります。

間に何段の入れ子があっても当たります。`.card` の中の `div` の中の `p` にも当たります。

気をつけるのは、カンマとの違いです。

```css
.card, p {
  color: gray;
}
```

これは **セレクタリスト** で、「`.card` と、すべての `p`」の両方に同じ宣言を当てます。空白は **絞る**、カンマは **まとめる** です。カンマを打ち忘れると、当たる相手が丸ごと変わってしまいます。

## 3-3-3 擬似クラスは状態で当たる

> **コロンで始まる擬似クラスを付けると、その要素が特定の状態のときだけ当たる**

ここまでのセレクタは「どの要素か」で選んでいました。もう1つ、「どんな状態のときか」で選ぶ書き方があります。

```css
a:hover {
  color: crimson;
}

input:focus {
  background-color: lightyellow;
}
```

コロンで始まる部分が **擬似クラス** です。`class` と違って、HTML側には何も書き足しません。ブラウザーが状態を判断して、当てたり外したりします。

- **hover** — その要素の上にマウスが乗っている状態
- **focus** — キーボードのタブ移動やクリックで、その要素が操作対象になっている状態

`:hover` は「押せる場所だ」と伝える手がかりになります。反応しないリンクやボタンは、押せるのかどうかが利用者に分かりません。

`:focus` にはさらに重要な役割があります。キーボードだけで操作する人は、いま自分がどの要素にいるのかを **focus の枠** だけで判断しています。ブラウザーは既定でこの枠を表示しますが、「デザイン上じゃまだから」と消してしまう例がよくあります。

```css
input:focus {
  outline: none;
}
```

これだけを書くと、キーボード利用者は現在地を見失い、操作できなくなります。既定の枠を消すなら、**代わりの目印を必ず付けて** ください。

## もっと知りたい人へ

- 擬似クラスには `:hover` `:focus` のほかにも、並びの何番目かで選ぶ `:nth-child()` などがあります。リンクの状態を表す擬似クラスはレッスン5-3で扱います
- コロン2つで始まる擬似要素(`::before` など)もあります。要素の一部や、無かった部分を作って当てるための書き方です

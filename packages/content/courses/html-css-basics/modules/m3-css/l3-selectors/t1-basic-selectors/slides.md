# セレクタは要素・class・idで選ぶ

HTML/CSS入門 — Module 3 / レッスン3-3

<!-- ノート: 3-1 で要素名と class を使いました。ここで書き分けを整理し、id を足します。 -->

---

## なぜ必要か

- 見つけたCSSの先頭に `#` が付いていて、何のことか分からない
- 「1か所だけ直したい」ときに、どの選び方をすればよいか迷う

<!-- ノート: つかみ。記号の意味を知らないと、他人のCSSが読めない。ここで結論は言わない。 -->

---

## 結論

**当てる相手は、要素名・class・idの3つの書き分けで選ぶ**

- **要素セレクタ** = 記号なし。その種類の要素すべて
- クラスセレクタ = `.` 付き。**IDセレクタ** = `#` 付き

<!-- ノート: 結論を言い切る。記号が3つの書き分けそのもの。 -->

---

## 最小のコード

```css
p { color: navy; }
.note { color: crimson; }
#footer-note { color: gray; }
```

```html
<p class="note" id="footer-note">お問い合わせ</p>
```

<!-- ノート: 同じ1つの段落が、3つのどの書き方でも選べる。選び分けの基準を次で示す。 -->

---

## 使い分け

| 書き方 | 当たる範囲 | 使いどころ |
| --- | --- | --- |
| `p` | その種類の要素すべて | 全体の土台 |
| `.note` | 付けた要素すべて | 見た目の使い回し |
| `#footer-note` | ページに1つだけ | ほぼ使わない |

<!-- ノート: 対比枠。id はページに1つという制約があり、詳細度も高すぎる。既定は class。 -->

# 空白でつなぐと中の要素だけに当たる

HTML/CSS入門研修 — Module 3 / レッスン3-3

<!-- ノート: 選び方が広すぎる・狭すぎる、を解決する書き方です。実務でいちばん使います。 -->

---

## なぜ必要か

- 「カードの中の段落だけ小さくしたい」のに、`p` で選ぶと全部が小さくなる
- そのためだけに、段落ひとつひとつに class を付けて回るのは大変

<!-- ノート: つかみ。class を付けて回った結果、HTMLが class だらけになる。ここで結論は言わない。 -->

---

## 結論

**セレクタを空白でつなぐと、その中にある要素だけに当たる**

- **子孫セレクタ** = 「AのなかにあるB」を表す書き方
- 左が範囲、右が当てる相手

<!-- ノート: 結論を言い切る。読み方は右から。「p のうち .card の中にあるもの」。 -->

---

## 最小のコード

```css
.card p {
  color: gray;
}
```

```html
<div class="card"><p>研修のご案内</p></div>
<p>この段落には当たらない</p>
```

<!-- ノート: .card の外にある段落は変わらない。範囲を絞れたことを画面で見せる。 -->

---

## カンマは意味が違う

```css
.card, p {
  color: gray;
}
```

- **セレクタリスト** = カンマで並べて、同じ宣言を両方に当てる
- 空白は「絞る」、カンマは「まとめる」

<!-- ノート: 対比枠。ここが本題。カンマを空白と書き間違えると、当たる相手が丸ごと変わる。 -->

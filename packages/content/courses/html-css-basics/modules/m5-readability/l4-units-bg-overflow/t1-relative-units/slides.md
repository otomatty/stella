# 5-4-1
# 相対的な単位は基準を持つ

HTML/CSS入門研修 — Module 5 / レッスン5-4

<!-- ノート: ここまで px だけを使ってきました。最後のレッスンで、他の単位を扱います。 -->

---

## なぜ必要か

- 利用者がブラウザーの文字サイズを大きくしても、`px` 指定は変わらない
- 入れ子にした要素で `em` を使うと、なぜか倍々に大きくなる

<!-- ノート: つかみ。基準を知らないまま使うと、思わぬ大きさになる。ここで結論は言わない。 -->

---

## 結論

**em・rem・%は、それぞれ何を基準にするかが決まっている**

- **絶対的な単位** = `px` のように、それ自体で長さが決まる
- **相対的な単位** = 何かを基準に、その何倍かで決まる

<!-- ノート: 結論を言い切る。単位の名前ではなく「基準は何か」で覚える。 -->

---

## 3つの基準

| 単位 | 基準 |
| --- | --- |
| **em** | その要素の文字サイズ。`font-size` に書くときだけ親の文字サイズ |
| **rem** | ページの基準の文字サイズ(ルート) |
| **パーセント** | プロパティごとに決まる。`width` なら親の幅 |

<!-- ノート: rem は root em の略。基準が1か所なので、入れ子でも倍々にならない。% はプロパティで基準が変わるので、幅以外に使うときは調べる。 -->

---

## 最小のコード

```css
.card {
  padding: 1rem;
  width: 50%;
}
```

- `1rem` = ルートの文字サイズぶん(既定なら16px)

<!-- ノート: 迷ったら rem。利用者が文字を大きくすると余白も一緒に広がる。 -->

---

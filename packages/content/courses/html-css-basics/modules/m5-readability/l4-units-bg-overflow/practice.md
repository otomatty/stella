# レッスン5-4 演習 — 単位・背景・はみ出し

対象トピック: 5-4-1 〜 5-4-3

## 手元で試す

`style.css` に次を足して保存し、再読み込みしてください。`url()` の中は、レッスン2-1で `images` フォルダに入れた画像の実際のパスに読み替えてください。

```css
.card {
  padding: 1rem;
}

.hero {
  background-image: url("images/venue.png");
  background-size: cover;
  height: 240px;
}

.table-area {
  overflow-x: auto;
}

.table-area table {
  min-width: 900px;
}
```

`index.html` の `main` の先頭に `<div class="hero"></div>` を置き、レッスン2-4で作った表を `<div class="table-area">` で囲んでください。

`.table-area table` の `min-width` は、この演習で必ずはみ出させるための仕掛けです。手元の表は列が3つで短いので、これが無いと画面に収まってしまい、`overflow-x` の効果が見えません。

背景の写真が領域いっぱいに広がり、**ブラウザーの幅を900pxより狭くしたときに表の部分だけが横スクロールになれば** 成功です。

書けたら、次の改造をしてみましょう。

1. `background-size` を `cover` から `80px` に変えて、小さくなった画像がタイル状に繰り返し並ぶことを確かめる(既定では繰り返される。確かめたら `cover` に戻す)
2. `.hero` の `height` を消して、背景が見えなくなることを確かめる(確かめたら戻す)
3. ブラウザーの幅を900pxより狭くしたまま `.table-area` の `overflow-x` を消して、表の中だけでなくページ全体が横に伸びることを確かめる(確かめたら戻す)
4. `.card` の `padding` を `1rem` と `16px` で切り替え、ブラウザーの文字サイズを大きくしたときの違いを確かめる

## 演習問題

### 問1(基本)

`rem` は何を基準にする単位ですか。`em` と違って扱いやすい理由も1文で書いてください。

### 問2(基本)

背景に敷いた画像を、箱いっぱいに広げるCSSを1行で書いてください。

### 問3(応用)

会場の地図の画像をページに載せます。`img` と背景のどちらで置きますか。理由も1文で書いてください。

### 問4(応用)

幅の広い表を置いたら、狭い画面でページ全体が横に伸びました。どう直しますか。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

ページの基準になる文字サイズ(ルート)です。基準がページに1か所しかないので、入れ子になっても倍々に大きくならないためです。

</details>

<details>
<summary>問2の解答例</summary>

```css
background-size: cover;
```

箱全体を埋めるように拡大・縮小します。はみ出した部分は切れます。

</details>

<details>
<summary>問3の解答例</summary>

`img` で置きます。地図は内容を伝える画像で、背景に置くと読み上げに出ず、`alt` も付けられないためです。

</details>

<details>
<summary>問4の解答例</summary>

表を `div` で囲み、その `div` に `overflow-x: auto;` を指定します。表の部分だけが横スクロールになります。

</details>

## 確認クイズ

### Q1. font-size に em を使ったとき、基準になるのはどれですか。

- A. 親から受け継いだ文字サイズ
- B. ページの基準になる文字サイズ
- C. 親要素の幅

<details>
<summary>答え</summary>

**A** — 自分の文字サイズはまだ決まっていないためです。入れ子で使うと倍々に大きくなるのはこれが積み重なるからで、ルートを基準にするのは rem です。

</details>

### Q2. 利用者がブラウザーの文字サイズを大きくしたとき、一緒に広がるのはどれですか。

- A. px で指定した余白
- B. rem で指定した余白
- C. どちらも広がらない

<details>
<summary>答え</summary>

**B** — 相対的な単位は基準に付いていくので、詰まった見た目になりません。

</details>

### Q3. 背景に敷いた画像について正しいものはどれですか。

- A. alt を付けられる
- B. 読み上げに出ない
- C. img より読み込みが速い

<details>
<summary>答え</summary>

**B** — 内容を伝える画像は img で置きます。背景は飾り用です。

</details>

### Q4. overflow の既定値はどれですか。

- A. visible
- B. hidden
- C. auto

<details>
<summary>答え</summary>

**A** — 箱の外にそのまま表示されます。あふれているのは、扱いを決めていないだけです。

</details>

### Q5. overflow: hidden を使うときに確かめることはどれですか。

- A. 隠れて読めなくなる中身が無いか
- B. 背景画像が敷かれているか
- C. 単位が rem になっているか

<details>
<summary>答え</summary>

**A** — hidden ははみ出した部分を隠すので、読めなくなる中身が出ることがあります。

</details>

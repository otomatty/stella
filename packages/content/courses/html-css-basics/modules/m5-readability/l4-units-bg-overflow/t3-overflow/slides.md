# 5-4-3
# はみ出した中身はoverflowで決める

HTML/CSS入門 — Module 5 / レッスン5-4

<!-- ノート: この講座の最後のトピックです。高さを決めた箱で必ず出会う問題を扱います。 -->

---

## なぜ必要か

- 高さを決めた箱に、思ったより長い文章が入って外へあふれる
- 幅の広い表が、狭い画面でページごと横に伸びる

<!-- ノート: つかみ。中身の量は自分では決められない、という前提を共有する。ここで結論は言わない。 -->

---

## 結論

**箱に収まらない中身をどう扱うかは、overflowで決める**

- **overflow** = はみ出した中身の扱いを決めるプロパティ
- 既定は `visible`。箱の外にそのまま表示される

<!-- ノート: 結論を言い切る。あふれているのは異常ではなく、扱いを決めていないだけ。 -->

---

## 最小のコード

```css
.table-area {
  overflow-x: auto;
}
```

- 幅の広い表を、その部分だけ横に **スクロール** させる

<!-- ノート: ページ全体が横に伸びるのを防ぐ定番。表を div で囲んで当てる。 -->

---

## よく使う値

| 値 | 扱い |
| --- | --- |
| `visible` | 箱の外に表示(既定) |
| `auto` | 収まらないときだけスクロールバーを出す |
| `hidden` | はみ出した部分を隠す |

<!-- ノート: 対比枠。hidden は「隠す」ので、読めなくなる中身がないかを必ず確かめる。 -->

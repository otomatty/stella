# レッスン5-4 単位・背景・はみ出し

## このレッスンの目標

- [ ] em / rem / % の基準の違いを説明できる
- [ ] background-image と background-size で背景を敷ける
- [ ] overflow ではみ出した中身の扱いを決められる

## 5-4-1 相対的な単位は基準を持つ

> **em・rem・%は、それぞれ何を基準にするかが決まっている**

ここまで、長さはすべて `px` で書いてきました。`px` は **絶対的な単位** です。それ自体で長さが決まり、周りの状況に左右されません。

一方、**相対的な単位** は「何かの何倍か」で長さが決まります。基準が何かを知らないまま使うと、思わぬ大きさになります。

| 単位 | 基準 |
| --- | --- |
| **em** | その要素の文字サイズ。ただし `font-size` に書くときだけは、親から受け継いだ文字サイズ |
| **rem** | ページの基準になる文字サイズ(ルート) |
| **パーセント** | プロパティごとに決まっている。`width` なら親の幅 |

`em` の行に例外が付いているのには理由があります。`font-size: 1.5em` と書いている時点では、その要素の文字サイズはまだ決まっていません。そのため、このときだけは親から受け継いだ文字サイズが基準になります。文字サイズを `em` で指定した要素の中で、さらに `em` を使うと倍々に大きくなっていくのは、これが積み重なるためです。`padding: 1em` のように文字サイズ以外へ書くときは、その要素自身の文字サイズが基準です。

`rem` は「root em」の略で、基準がページに1か所しかありません。既定では16pxです。入れ子になっても基準が変わらないので、扱いやすい単位です。

パーセントも「親の同じ値」と覚えると外します。**基準はプロパティごとに決まっています。**

| 書く場所 | パーセントの基準 |
| --- | --- |
| `width` / `padding` / `margin` | 親の **幅**(`padding-top` のような上下でも幅) |
| `line-height` | その要素自身の文字サイズ |
| `font-size` | 親から受け継いだ文字サイズ |

幅の割り当て以外でパーセントを使うときは、基準が何かを一度確かめてから書いてください。

```css
.card {
  padding: 1rem;
  width: 50%;
}
```

`1rem` は既定なら16pxぶん、`50%` は親の幅の半分です。

相対的な単位を使う利点は、利用者の設定に付いていけることです。ブラウザーの文字サイズを大きくする設定をしている人がいます。`px` で固定した余白はそのままですが、`rem` なら文字と一緒に広がるので、詰まった見た目になりません。

**迷ったら `rem`** を使い、幅の割り当てには `%` を使う、と決めておけば実務では足ります。

## 5-4-2 背景の画像はsizeで収め方を決める

> **background-imageで敷いた画像は、background-sizeで収め方を決める**

見出しの後ろに写真を敷きたい、という場面があります。`img` で置いた画像に文字を重ねること自体は position などでできますが、飾りの画像を文字の背面に敷くだけなら、背景として指定するほうが簡単で意図も伝わります。

```css
.hero {
  background-image: url("images/venue.png");
  background-size: cover;
  height: 240px;
}
```

**background-image** は箱の背景に画像を敷くプロパティです。`url()` の中には、いつもどおり相対パスを書きます。

敷いただけでは、画像は元の大きさのまま置かれ、足りないぶんは繰り返して並べられます。収め方を決めるのが **background-size** です。

- **cover** — 箱全体を埋めるように拡大・縮小する。はみ出した部分は切れる
- `contain` — 画像全体が見えるように収める。余白ができることがある

背景の箱に高さが無いと、そもそも見える領域がありません。中身が少ない箱に背景を敷くときは `height` や `padding` で領域を作ってください。

判断の基準は1つです。

| 画像の役割 | 置き方 |
| --- | --- |
| 内容を伝える(地図・製品写真) | `img` と `alt` |
| 飾り(見出しの後ろの模様) | 背景 |

**背景の画像は読み上げに出ません。** 内容を伝える画像を背景で置くと、その情報は届かない人が出ます。

## 5-4-3 はみ出した中身はoverflowで決める

> **箱に収まらない中身をどう扱うかは、overflowで決める**

高さを決めた箱に、思ったより長い文章が入ることがあります。幅の広い表を置くと、狭い画面ではページごと横に伸びます。中身の量は自分では決められないので、**収まらなかったときにどうするか** を決めておく必要があります。

それを決めるのが **overflow** です。

| 値 | 扱い |
| --- | --- |
| `visible` | 箱の外にそのまま表示する(既定) |
| `auto` | 収まらないときだけスクロールバーを出す |
| `hidden` | はみ出した部分を隠す |
| `scroll` | 常にスクロールバーを出す |

既定は `visible` です。あふれているのは異常ではなく、扱いを決めていないだけだと考えてください。

実務でいちばん使うのは、幅の広い表を囲む形です。

```html
<div class="table-area">
  <table>...</table>
</div>
```

```css
.table-area {
  overflow-x: auto;
}
```

`overflow-x` は横方向だけの指定です。表の部分だけが横に **スクロール** するので、ページ全体が横に伸びることを防げます。レッスン4-6で扱った「横スクロールを出さない」という目標と、この指定は組で使います。

`hidden` を使うときは注意してください。はみ出した部分は **読めなくなります**。隠して困る中身が無いかを必ず確かめてから使ってください。

## もっと知りたい人へ

- 背景には、色・画像・繰り返し・位置をまとめて書ける `background` という書き方もあります
- 単位には画面の幅を基準にする `vw` などもあります。基準が何かという考え方は同じです

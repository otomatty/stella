# 5-2-1
# font-familyは候補を並べて書く

HTML/CSS入門研修 — Module 5 / レッスン5-2

<!-- ノート: 文字の大きさと行間は扱いました。ここからは書体そのものです。 -->

---

## なぜ必要か

- 指定した書体が、相手の端末に入っているとは限らない
- 入っていないと、意図しない書体で表示されて印象が変わる

<!-- ノート: つかみ。Windows と Mac で見え方が違う、は必ず起きる。ここで結論は言わない。 -->

---

## 結論

**font-familyは使いたい書体から順に候補を並べ、最後に総称名で締める**

- **フォント** = 文字の書体
- 左から順に探し、最初に見つかったものが使われる

<!-- ノート: 結論を言い切る。1つだけ書くのではなく、候補のリストを書くのがこのプロパティ。 -->

---

## 最小のコード

```css
body {
  font-family: "Hiragino Sans", "Meiryo", sans-serif;
}
```

- 空白を含む名前は引用符で囲む

<!-- ノート: Mac 向け、Windows 向け、そして総称名の順。body に書けば継承で全体に効く。 -->

---

## 最後は総称名で締める

| 総称名 | 意味 |
| --- | --- |
| `sans-serif` | ゴシック体(飾りのない書体) |
| `serif` | 明朝体(飾りのある書体) |
| `monospace` | 等幅。コードの表示向き |

<!-- ノート: 対比枠。**総称フォント** はどの端末にもある。締めに置くと、最悪でも意図に近い形になる。 -->

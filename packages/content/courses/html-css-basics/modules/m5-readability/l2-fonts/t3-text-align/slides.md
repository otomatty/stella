# 5-2-3
# text-alignは行の寄せ方

HTML/CSS入門研修 — Module 5 / レッスン5-2

<!-- ノート: 4-2-5 で「箱を中央に」を扱いました。ここは「文字を中央に」です。混同しやすいので対比します。 -->

---

## なぜ必要か

- 見出しだけを中央に置きたいのに、`margin: 0 auto` が効かない
- 表の数字を右にそろえたいが、方法が分からない

<!-- ノート: つかみ。箱を動かす指定と文字を寄せる指定は別物。ここで結論は言わない。 -->

---

## 結論

**text-alignは箱の中で行をどちらに寄せるかを決める**

- **行揃え** = 箱の中での、行の左右の位置
- 動くのは箱ではなく、中の行

<!-- ノート: 結論を言い切る。箱そのものは1ミリも動かない。 -->

---

## 最小のコード

```css
h1 {
  text-align: center;
}

.price {
  text-align: right;
}
```

- 値は `left` / `center` / `right`

<!-- ノート: 既定は start で、日本語なら左そろえになる。数字の桁をそろえたいときは right が読みやすい。 -->

---

## 箱を動かす指定との違い

| やりたいこと | 使うもの |
| --- | --- |
| 箱そのものを中央に置く | `margin: 0 auto` |
| 箱の中の行を中央に寄せる | `text-align: center` |

<!-- ノート: 対比枠。ここが本題。効かないときは、どちらを動かしたいのかを確かめる。 -->

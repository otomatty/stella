# レッスン5-2 フォントと文字の装飾

## このレッスンの目標

- [ ] font-family を候補のリストとして書ける
- [ ] font-weight と strong を使い分けられる
- [ ] text-align と margin: 0 auto の違いを説明できる

## 5-2-1 font-familyは候補を並べて書く

> **font-familyは使いたい書体から順に候補を並べ、最後に総称名で締める**

**フォント**(文字の書体)は、指定すればそのとおりに表示されるとは限りません。その書体が相手の端末に入っていなければ使えないからです。WindowsとMacで見え方が違うのは、入っている書体が違うためです。

そこで `font-family` には、**候補を並べて** 書きます。

```css
body {
  font-family: "Hiragino Sans", "Meiryo", sans-serif;
}
```

ブラウザーは左から順に探し、最初に見つかった書体を使います。空白を含む名前は引用符で囲みます。

`body` に書けば、継承によってページ全体に効きます。要素ごとに書く必要はありません。

最後に置いている `sans-serif` は **総称フォント** です。特定の書体名ではなく「ゴシック体ならどれでも」という指定なので、どの端末でも必ず何かに当たります。

| 総称名 | 意味 |
| --- | --- |
| `sans-serif` | ゴシック体(飾りのない書体) |
| `serif` | 明朝体(飾りのある書体) |
| `monospace` | 等幅。コードの表示に向く |

候補の最後を総称名で締めておけば、どの端末でも意図から大きく外れない見た目になります。**書体名だけを1つ書く指定は避けてください。**

## 5-2-2 font-weightで文字の太さを決める

> **font-weightは文字の太さを決め、太字にしたいだけのときはこれを使う**

レッスン1-4で「太字にしたいだけなら意味の印ではなくCSSで」と説明しました。そのCSSがこれです。

```css
.lead {
  font-weight: bold;
}

h2 {
  font-weight: 500;
}
```

値は名前でも数値でも書けます。数値は100〜900で、400が標準、700が `bold` と同じ太さです。書体によっては用意されていない太さがあり、その場合は近い太さに寄せて表示されます。

| やりたいこと | 使うもの |
| --- | --- |
| 読み飛ばされると困ると伝える | `strong` |
| 見た目だけ太くする | `font-weight` |

**太字** は見た目であって、重要さの印ではありません。`strong` を「太字にする道具」として使うと、読み上げソフトには重要な語だと伝わってしまいます。

見出しが既定で太いのも `font-weight` の初期値によるものなので、太さを調整したいときはこのプロパティで上書きします。

## 5-2-3 text-alignは行の寄せ方

> **text-alignは箱の中で行をどちらに寄せるかを決める**

「見出しを中央に置きたい」と思って `margin: 0 auto` を書いても、文字は動きません。あれは **箱そのもの** を動かす指定だからです。

箱の中で行を寄せるのが `text-align` です。

```css
h1 {
  text-align: center;
}

.price {
  text-align: right;
}
```

値は `left` / `center` / `right` です。既定は `start` で、日本語のように左から右へ書く言語では左そろえになります。**行揃え** で動くのは箱ではなく、中の行だけです。箱は1ミリも動きません。

| やりたいこと | 使うもの |
| --- | --- |
| 箱そのものを中央に置く | `margin: 0 auto`(幅の指定が要る) |
| 箱の中の行を中央に寄せる | `text-align: center` |

「中央に寄らない」と困ったときは、**箱を動かしたいのか、行を動かしたいのか** を先に決めてください。

数字を並べるときは `right` が読みやすくなります。桁の位置がそろうためです。

## もっと知りたい人へ

- `font-style: italic` で斜体にできます。意味のある強調は `em`、見た目だけなら `font-style` という使い分けは `font-weight` と同じです
- 端末に入っていない書体をファイルとして読み込む「Webフォント」という仕組みもあります。ページの表示速度に影響するので、必要になってから調べてください

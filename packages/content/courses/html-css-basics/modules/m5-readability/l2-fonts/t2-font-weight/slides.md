# font-weightで文字の太さを決める

HTML/CSS入門研修 — Module 5 / レッスン5-2

<!-- ノート: 1-4-3 で「太字はCSSで」と言いました。その約束をここで回収します。 -->

---

## なぜ必要か

- 太字にしたいだけなのに `strong` で囲んでしまう
- 見出しの太さが強すぎて、本文との差が付きすぎる

<!-- ノート: つかみ。意味の印と見た目の指定を混ぜないため。ここで結論は言わない。 -->

---

## 結論

**font-weightは文字の太さを決め、太字にしたいだけのときはこれを使う**

- **太字** は見た目。重要さの印とは別物
- 値は数値か、`bold` などの名前で書く

<!-- ノート: 結論を言い切る。1-4-2 の strong と対にして説明すると納得が早い。 -->

---

## 最小のコード

```css
.lead {
  font-weight: bold;
}

h2 {
  font-weight: 500;
}
```

- 数値は100〜900。400が標準、700が `bold`

<!-- ノート: 書体によっては用意されていない太さがあり、その場合は近いものに寄せられる。 -->

---

## 意味の印と使い分ける

| やりたいこと | 使うもの |
| --- | --- |
| 読み飛ばされると困ると伝える | `strong` |
| 見た目だけ太くする | `font-weight` |

<!-- ノート: 対比枠。ここが本題。strong を「太字にする道具」として使わない。 -->

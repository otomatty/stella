# 仕上げは開発者ツールで確かめる

HTML/CSS入門研修 — Module 5 / レッスン5-1

## なぜ必要か

- 「効かない」を、CSSを書き換えては再読み込みして探すのは遅い
- どの宣言が勝っているのかを、コードを読んで当てるのは難しい

<!-- ノート: つかみ。3-2で扱った上書きの調査を、手作業でやるつらさを思い出してもらう。 -->

---

## 結論

**ブラウザーの開発者ツールを使うと、当たっているCSSをその場で確かめられる**

- **開発者ツール** = ブラウザーに標準で付いている調査用の画面
- 右クリックの「検証」から開く

<!-- ノート: 結論を言い切る。追加でインストールするものはない。全ブラウザーに入っている。 -->

---

## できること

- その要素に当たっている宣言の一覧を見る
- 負けている宣言に取り消し線が付くので、上書きが目で分かる
- 値をその場で書き換えて、見た目の変化を試す

<!-- ノート: 取り消し線が見えるだけで、詳細度の学習が一気に進む。実演して見せたい。 -->

---

## 試した結果はファイルに戻す

- 開発者ツールでの変更は、再読み込みで消える
- 良い値が見つかったら、必ずCSSファイルに書き写す

<!-- ノート: 失敗例の枠。ここで直したつもりになって消してしまう事故は本当によくある。 -->

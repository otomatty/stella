# 効かない指定は5つの原因に切り分ける

HTML/CSS入門 — Module 5 / レッスン5-1

## なぜ必要か

- 書いたはずのCSSが効かず、あてずっぽうで書き換えてしまう
- 直った理由が分からないので、次も同じところで止まる

<!-- ノート: つかみ。効かない原因は無限にあるように見えるが、実際は数が限られている。 -->

---

## 結論

**効かない宣言は、書き方・セレクタ・順序・詳細度・継承のどれが原因かを開発者ツールで確かめて直す**

- **切り分け** = 原因の候補を順に消していく進め方
- 候補は5つ。うち3つはモジュール3で学んだもの

<!-- ノート: 結論を言い切る。3-2 の3トピックに「書き方そのものが無効」と「そもそも当たっていない」を足した5つが、そのまま調査の手順になる。 -->

---

## 開発者ツールで見るもの

- 警告アイコンが付く → その宣言の書き方が無効
- 取り消し線が付いている → 別の宣言に負けている
- 一覧に出てこない → そのセレクタが当たっていない
- 薄い文字で出る → 親から受け継いだ値

<!-- ノート: 見え方と原因の対応。ここを覚えると、調べる時間が一気に短くなる。警告アイコンは綴りや値の間違いで、カスケードとは別の話。 -->

---

## 直し方の順番

| 見えたもの | 直し方 |
| --- | --- |
| 警告アイコンが付く | プロパティ名・値・記号を直す |
| 一覧に出てこない | セレクタの綴りを直す |
| 同じ詳細度で負けている | 後ろに書く(順序) |
| 詳細度で負けている | セレクタを絞る |
| 指定していない値が付く | その要素自身に指定する(継承) |

<!-- ノート: 対比枠。ここが本題。上から順に見る。書き方が無効なものを順序や詳細度で直そうとしても直らない。!important は最後。 -->

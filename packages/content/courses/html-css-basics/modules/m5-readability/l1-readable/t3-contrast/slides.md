# 5-1-3
# 文字色と背景色はコントラストで決める

HTML/CSS入門研修 — Module 5 / レッスン5-1

<!-- ノート: 色の話です。好みではなく、読めるかどうかで決める観点を渡します。 -->

---

## なぜ必要か

- 薄いグレーの文字は、上品に見えるが読みにくい
- 屋外や古い画面では、作った環境より見えづらくなる

<!-- ノート: つかみ。デザイン案で薄いグレーが選ばれがちだが、現場では読めない。ここで結論は言わない。 -->

---

## 結論

**文字色と背景色は、明るさの差が十分にある組み合わせを選ぶ**

- **color** = 文字色、**background-color** = 背景色
- 明るさの差を **コントラスト** と呼ぶ

<!-- ノート: 結論を言い切る。色相ではなく明るさの差が効く、が要点。 -->

---

## 最小のコード

```css
body {
  color: #1a1a1a;
  background-color: #ffffff;
}
```

- `#` で始まる6桁は色の指定の書き方
- 黒に近い文字 × 白い背景が最も読みやすい

<!-- ノート: 色名でも書けるが、実務では16進数の指定が多い。ここでは形だけ見せる。 -->

---

## 避けたい組み合わせ

| 組み合わせ | 問題 |
| --- | --- |
| 薄い灰色 × 白 | 明るさの差が小さい |
| 黄色 × 白 | 同上 |
| 赤 × 緑 | 色の区別が付かない人がいる |

<!-- ノート: 対比枠。色だけで情報を伝えないことも大事。「赤い項目が必須です」は文字でも書く。 -->

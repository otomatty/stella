# 5-1-2
# 行間を空けると文章が読みやすい

HTML/CSS入門研修 — Module 5 / レッスン5-1

<!-- ノート: 文字の大きさの次は、行と行のあいだです。効果が大きいわりに知られていません。 -->

---

## なぜ必要か

- 文字は十分な大きさなのに、長い文章が読みにくい
- 行を読み終えて次の行に移るとき、目が迷子になる

<!-- ノート: つかみ。行間が詰まった文書を見せると全員が実感する。ここで結論は言わない。 -->

---

## 結論

**line-heightを1.5〜1.8にすると、長い文章が読みやすくなる**

- **line-height** = **行間** を含めた1行分の高さ
- 単位なしの数字は、文字サイズの何倍かを表す

<!-- ノート: 結論を言い切る。単位なしで書くのが基本。文字サイズが変わっても比率が保たれる。 -->

---

## 最小のコード

```css
body {
  font-size: 16px;
  line-height: 1.6;
}
```

- 1行の高さが文字サイズの1.6倍になる
- 日本語の長い文章では1.7前後も読みやすい

<!-- ノート: 日本語は漢字とかなが混ざるため、英語より広めが合うことが多い。 -->

---

## 使い分け

| 場所 | 目安 |
| --- | --- |
| 本文の段落 | 1.5〜1.8 |
| 大きな見出し | 1.2前後 |

<!-- ノート: 対比枠。見出しは1〜2行なので、広げると逆に間延びして見える。場所で変える。 -->

---

## まとめ

**line-heightを1.5〜1.8にすると、長い文章が読みやすくなる**

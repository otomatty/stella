# 本文の文字サイズは16px前後にする

HTML/CSS入門研修 — Module 5 / レッスン5-1

<!-- ノート: 最後のモジュールです。作ったページを「読める」状態に仕上げます。 -->

---

## なぜ必要か

- デザインを詰めたくて文字を小さくすると、読めない人が出る
- 自分の目には見えていても、利用者全員に見えるとは限らない

<!-- ノート: つかみ。作る側は画面に近づいて見ているので気づきにくい。ここで結論は言わない。 -->

---

## 結論

**本文のfont-sizeは16px前後を基準にし、小さくしすぎない**

- **font-size** = 文字の大きさを決めるプロパティ
- **px** は画面上の点の数を表す単位

<!-- ノート: 結論を言い切る。16pxはブラウザーの既定値でもあり、根拠のある基準。 -->

---

## 最小のコード

```css
body {
  font-size: 16px;
}
```

- **継承** されるので、これだけで本文全体に効く
- 入力欄とボタンは受け継がないので、別に指定する

<!-- ノート: 3-2-3の継承がここで役に立つ。既定値をbodyに置く型を再確認する。inputとbuttonはブラウザーが独自の文字サイズを持つため対象外、と補足する。 -->

---

## 小さくしてよい場所・いけない場所

| 場所 | 目安 |
| --- | --- |
| 本文・入力欄 | 16px前後 |
| 注釈・補足 | 14px程度まで |
| 本文全体 | 12pxまで下げない |

<!-- ノート: 対比枠。補足を少し小さくするのは許容。本文全体を小さくするのは読み手を選ぶことになる。 -->

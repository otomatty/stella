# レッスン5-3 リストとリンクの見た目

## このレッスンの目標

- [ ] list-style-type でマーカーを変えられる
- [ ] リンクの5つの状態を正しい順番で書ける
- [ ] 下線を消すときに代わりの手がかりを用意できる

## 5-3-1 list-styleでマーカーを変える

> **リストの先頭に付く印は、list-style-typeで種類を変えられる**

ナビゲーションのメニューは、意味としてはリンクの並び、つまりリストです。`ul` で組むのが自然ですが、そのままだと黒丸が付いて邪魔になります。

ここで「黒丸が出るから `ul` をやめて `div` にする」と考えないでください。見た目のために意味のあるタグを捨てるのは、レッスン1-4で扱った判断と同じ間違いです。**HTMLはそのままで、CSSで印を消します。**

```css
.menu {
  list-style-type: none;
}

.steps {
  list-style-type: decimal;
}
```

**マーカー** は、項目の先頭に付く黒丸や番号のことです。`list-style-type` で種類を変えられます。

| 値 | 印 |
| --- | --- |
| `disc` | 黒丸(`ul` の既定) |
| `decimal` | 1. 2. 3.(`ol` の既定) |
| `none` | 印なし |

指定するのは `li` ではなく `ul` / `ol` 側です。この値は継承されるので、親に1回書けば中の項目すべてに効きます。

## 5-3-2 リンクは状態の順番どおりに書く

> **リンクの状態を指定するときは、link・visited・hover・focus・activeの順に書く**

リンクには状態が5つあります。3-3-3 で扱った `:hover` と `:focus` に加えて、次の3つです。

- `:link` — まだ開いていないリンク
- **visited** — 一度開いたことがあるリンク
- **active** — いま押している最中のリンク

問題は書く順番です。この5つは詳細度がすべて同じなので、**後に書いたほうが勝ちます**(3-2-1 のカスケードです)。

```css
a:link { color: navy; }
a:visited { color: purple; }
a:hover { color: crimson; }
a:focus { color: crimson; }
a:active { color: orangered; }
```

この **状態の順番** で書くと、それぞれの指定が必要な場面で効きます。順番を崩すと打ち消し合います。

```css
a:hover { color: crimson; }
a:link { color: navy; }
```

これは「マウスを乗せても色が変わらない」状態です。マウスを乗せているリンクも `:link` の条件を満たすので、後に書いた `:link` が勝ってしまいます。

呪文として覚える必要はありません。**「効かないときはまず順番を疑う」** で足ります。

## 5-3-3 下線を消すなら別の手がかりを残す

> **text-decorationで下線を消すときは、色以外の手がかりを必ず残す**

リンクの下線は、デザインの都合で消したくなることがよくあります。消すこと自体は **text-decoration** でできます。

```css
.menu a {
  text-decoration: none;
}

.menu a:hover {
  text-decoration: underline;
}
```

問題は、消した結果どこがリンクなのか分からなくなることです。「色を変えてあるから分かる」と考えがちですが、色の違いを見分けにくい人には伝わりません。押せると気づかれないリンクは、無いのと同じです。

判断の基準は、**下線以外の手がかりがあるかどうか** です。

- ナビゲーションのメニュー — 並びと位置が手がかりになるので、消してもよい
- 文章の中に混ざるリンク — 手がかりが下線しかないことが多いので、**残す**

どうしても本文中の下線を消したいときは、太字にする、枠を付ける、マウスを乗せたときに下線を戻すなど、色以外の目印を必ず足してください。

## もっと知りたい人へ

- `text-decoration` には下線の色や太さを細かく指定する書き方もあります。下線を残しつつ細くする、といった調整ができます
- リストの印を画像や記号に差し替えることもできますが、まずは `none` と既定の切り替えができれば足ります

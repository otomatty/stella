## なぜ必要か

- 下線がデザインに合わないので消したい
- 消した結果、どこがリンクなのか分からないページになる

<!-- ノート: つかみ。「押せると気づかれないリンク」は、無いのと同じ。ここで結論は言わない。 -->

---

## 結論

**text-decorationで下線を消すときは、色以外の手がかりを必ず残す**

- **text-decoration** = 下線などの装飾を決めるプロパティ
- 色の違いだけでは、色を見分けにくい人に伝わらない

<!-- ノート: 結論を言い切る。消してはいけない、ではなく、代わりを用意する。 -->

---

## 最小のコード

```css
.menu a {
  text-decoration: none;
}

.menu a:hover {
  text-decoration: underline;
}
```

- 平常時は消し、マウスを乗せたときに戻す

<!-- ノート: ナビゲーションは並びと位置が手がかりになるので、本文中のリンクより消しやすい。 -->

---

## 本文の中のリンクは残す

- 文章に混ざるリンクは、**手がかり** が下線しかない
- 太字や枠など、色以外の目印を足せるなら消してもよい

<!-- ノート: 失敗例の枠。文章中のリンクを色だけで表すのは避ける。判断の基準を渡して締める。 -->

# list-styleでマーカーを変える

## なぜ必要か

- ナビゲーションをリストで組むと、黒丸が邪魔になる
- 意味としてはリストのままにしたいので、`ul` はやめられない

<!-- ノート: つかみ。見た目のために意味のあるタグを捨てない、が判断の軸。ここで結論は言わない。 -->

---

## 結論

**リストの先頭に付く印は、list-style-typeで種類を変えられる**

- **マーカー** = 項目の先頭に付く黒丸や番号
- HTMLは変えず、CSSだけで見た目を変える

<!-- ノート: 結論を言い切る。ul のまま印だけ消せる、というのが実務での価値。 -->

---

## 最小のコード

```css
.menu {
  list-style-type: none;
}

.steps {
  list-style-type: decimal;
}
```

- `none` にすると印が消える

<!-- ノート: 指定するのは li ではなく ul / ol 側。継承されるので親に書けば足りる。 -->

---

## よく使う値

| 値 | 印 |
| --- | --- |
| `disc` | 黒丸(`ul` の既定) |
| `decimal` | 1. 2. 3.(`ol` の既定) |
| `none` | 印なし |

<!-- ノート: 対比枠。3つで足りる。ol を使いつつ番号を消す、といった組み合わせもできる。 -->

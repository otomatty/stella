# レッスン0-1 この講座について

## このレッスンの目標

- [ ] この講座がスキルツリーのどこにあり、何を学ぶ場所なのかを知る

## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「メトリクス・ログ・トレースのどれで異常を追うかを選べる」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- 監視とオブザーバビリティの違い
- メトリクスで傾向を見る
- ログで出来事を追う
- トレースでリクエストの経路を見る
- アラートの閾値の置き方

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

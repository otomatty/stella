# 2-1-3
# 入れ子は部品のまとまりに留める

モダンCSS入門 — Module 2 / レッスン2-1

<!-- ノート: 便利な入れ子にも使いすぎがあります。線引きを決めておきます。 -->

---

## なぜ必要か

- 入れ子は何段でも書けてしまう
- 深くすると、1つの宣言がどこに当たるのか追えなくなる

<!-- ノート: つかみ。HTMLの入れ子をそのまま写すと、5段6段のCSSができあがります。 -->

---

## 結論

**入れ子は部品1つのまとまりまでにして、深くしない**

- **部品** = カードやボタンのような、見た目のひとかたまり
- 目安は2段まで。3段目が欲しくなったら分ける

<!-- ノート: 結論。「.cardのことは.cardの中に」が目的で、HTMLの構造の写しではありません。 -->

---

## 最小のコード

```css
.card {
  border: 1px solid gray;

  img { border-radius: 8px; }
  p { color: gray; }
  &:hover { border-color: navy; }
}
```

<!-- ノート: 良い形。カードという部品の中身と状態が、1つの波かっこに収まっています。どれも2段です。 -->

---

## 深くしすぎた例

```css
.card {
  div {
    ul {
      li { color: gray; }
    }
  }
}
```

- 当たる条件が読めず、直すときも壊しやすい

<!-- ノート: 失敗例の枠。こうなったら li に class を付けて、浅いセレクタに戻します。 -->

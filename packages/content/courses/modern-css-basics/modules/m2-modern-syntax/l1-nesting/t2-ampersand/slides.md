# 2-1-2
# &は外側のセレクタ自身を指す

モダンCSS入門 — Module 2 / レッスン2-1

<!-- ノート: 入れ子は「中の要素」に当てる書き方でした。では、その部品自身の状態はどう書くのでしょうか。 -->

---

## なぜ必要か

- ボタンのホバー時の色も、ボタンのまとまりの中に書きたい
- 入れ子の中に `:hover` とだけ書いても、「何の」ホバーか決まらない

<!-- ノート: つかみ。中の要素ではなく「自分自身の状態」を入れ子で書くときに困ります。 -->

---

## 結論

**`&`は外側のセレクタ自身を指し、`:hover`のような状態の指定を入れ子の中に書ける**

- `&:hover` = 「この部品自身にマウスが乗ったとき」
- 自分の状態も、部品のまとまりの中に置ける

<!-- ノート: 結論。&は「外側のセレクタをここに写す」記号です。 -->

---

## 最小のコード

```css
.button {
  background-color: navy;

  &:hover {
    background-color: crimson;
  }
}
```

- `.button:hover` と同じ意味

<!-- ノート: & の直後にコロンを続けます。& を付けずに :hover だけ書くと意味が変わるので、状態には必ず & を付けます。 -->

---

## &の有無で意味が変わる

- `&:hover` → `.button:hover`(自身の状態)
- `:hover`だけ → `.button`の中の、ホバー中の要素

<!-- ノート: 失敗例の枠。&を忘れると「中の要素」への指定になってしまい、自分の色は変わりません。 -->

---

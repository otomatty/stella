# レッスン2-1 入れ子で書く

## このレッスンの目標

- [ ] 部品のルールを入れ子でひとまとまりに書ける
- [ ] `&:hover` で自身の状態を入れ子の中に書ける
- [ ] 入れ子を深くしない線引きを説明できる

## 2-1-1 ルールの中にルールを書ける

> **ルールの中にルールを書くと、外側のセレクタの中にある要素だけに当たる**

HTML/CSS 入門では、カードの中の要素に当てるとき子孫セレクタを使いました。

```css
.card { border: 1px solid gray; }
.card p { color: gray; }
.card img { border-radius: 8px; }
```

部品が育つほど、同じ `.card` を先頭に何度も書くことになります。しかもこの3つのルールは、ファイルの離れた場所に置けてしまうので、「カードの見た目の全体像」がどこにも見えません。

現代の CSS では、ルールの中にルールを書けます。これを **入れ子**(ネスト)と呼びます。

```css
.card {
  border: 1px solid gray;

  p {
    color: gray;
  }

  img {
    border-radius: 8px;
  }
}
```

中に書いた `p` は「`.card` の中にある `p`」という意味で、当たり方は `.card p` と**まったく同じ**です。変換ツールなどは不要で、この書き方のままブラウザーが読めます。

変わるのは書く場所です。カードに関するルールが `.card` の波かっこの中に全部集まるので、「この部品の見た目はここを読めば分かる」状態になります。

## 2-1-2 &は外側のセレクタ自身を指す

> **&は外側のセレクタ自身を指し、:hoverのような状態の指定を入れ子の中に書ける**

入れ子は「中の要素」に当てる書き方でした。では、部品**自身**のホバー時の色はどう書くのでしょうか。入れ子の中に `:hover` とだけ書いても、「何の」ホバーかが決まりません。

そこで **`&`** を使います。`&` は「外側のセレクタをここに写す」記号です。

```css
.button {
  background-color: navy;

  &:hover {
    background-color: crimson;
  }
}
```

`&:hover` は `.button:hover` と同じ意味です。これで、自身の状態の指定も部品のまとまりの中に置けます。入門のレッスン3-3で学んだ `:hover` / `:focus` は、今後この形で書いていきます。

気をつけるのは、`&` の有無で意味が変わることです。

- `&:hover` → `.button:hover`。**自身**にマウスが乗ったとき
- `:hover` だけ → `.button :hover`(空白あり)と同じ。`.button` の**中の要素**がホバー中のとき

`&` を忘れると「中の要素」への指定になり、ボタン自身の色は変わりません。**状態の指定には必ず `&` を付ける**と覚えてください。

## 2-1-3 入れ子は部品のまとまりに留める

> **入れ子は部品1つのまとまりまでにして、深くしない**

入れ子は何段でも書けてしまいます。HTML の構造をそのまま写すと、こうなりがちです。

```css
.card {
  div {
    ul {
      li {
        color: gray;
      }
    }
  }
}
```

これは `.card div ul li` という4段のセレクタです。1つの宣言がどんな条件で当たるのか読み取りにくく、HTML の構造を少し変えただけで効かなくなります。入門で「セレクタは浅く、class でまず選ぶ」と学んだ原則は、入れ子でも変わりません。

線引きはこうです。入れ子にするのは、カードやボタンのような見た目のひとかたまり――**部品**――の単位まで。目安は2段です。

```css
.card {
  border: 1px solid gray;

  img { border-radius: 8px; }
  p { color: gray; }
  &:hover { border-color: navy; }
}
```

3段目が欲しくなったら、それは入れ子が深すぎるサインです。対象の要素に class を付けて、浅いセレクタに戻してください。

入れ子の目的は「`.card` のことは `.card` の中に」というまとまりであって、HTML の構造の写しではありません。

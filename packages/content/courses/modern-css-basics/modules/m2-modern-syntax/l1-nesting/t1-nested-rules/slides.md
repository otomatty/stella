# ルールの中にルールを書ける

モダンCSS入門 — Module 2 / レッスン2-1

<!-- ノート: Module 2では、CSSの書き方そのものを今どきにします。1本目は入れ子です。 -->

---

## なぜ必要か

- `.card p`、`.card img`、`.card a` … 同じ`.card`を何度も書いている
- カードのルールがファイルのあちこちに散って、まとまりが見えない

<!-- ノート: つかみ。入門で学んだ子孫セレクタは、部品が育つと先頭の繰り返しだらけになります。 -->

---

## 結論

**ルールの中にルールを書くと、外側のセレクタの中にある要素だけに当たる**

- これを **入れ子**(ネスト)と呼ぶ
- `.card p` と書いたのと同じ意味になる

<!-- ノート: 結論。意味は入門の子孫セレクタと同じで、書く場所が変わるだけです。 -->

---

## 最小のコード

```css
.card {
  border: 1px solid gray;

  p {
    color: gray;
  }
}
```

- 中の `p` は「`.card` の中にある `p`」

<!-- ノート: 外側のルールの波かっこの中に、もう1つルールを書きます。CSSだけでこのまま動きます。 -->

---

## 何が変わるのか

| | 従来 | 入れ子 |
| --- | --- | --- |
| 意味 | `.card p { }` | 同じ |
| 書く場所 | ばらばらに置ける | `.card` の中にまとまる |

<!-- ノート: 対比の枠。当たり方は変わりません。「カードのことはカードの波かっこの中に全部ある」が価値です。 -->

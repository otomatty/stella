# 属性セレクタは属性の値で選ぶ

モダンCSS入門 — Module 2 / レッスン2-3

<!-- ノート: 結合子は位置で選びました。今度は、要素が持っている属性で選びます。 -->

---

## なぜ必要か

- `input` は `type` の値で見た目がまるで違うのに、要素名では区別できない
- 区別のためだけに class を付けるのは二度手間

<!-- ノート: つかみ。テキスト欄とチェックボックスは同じ input。HTMLにはもう区別の情報が書いてあります。 -->

---

## 結論

**角かっこのセレクタは、要素に付いている属性とその値で当てる相手を選ぶ**

- これを **属性セレクタ** と呼ぶ
- HTMLに書いてある情報をそのまま条件にする

<!-- ノート: 結論。classを足すのではなく、既にある属性を使うのがポイントです。 -->

---

## 最小のコード

```css
input[type="checkbox"] {
  accent-color: var(--color-brand);
}
```

- `type` が `checkbox` の `input` だけに当たる

<!-- ノート: accent-colorはチェック印の色を変えるプロパティ。トークンの参照もさっそく使っています。 -->

---

## 値の合い方も選べる

| 書き方 | 意味 |
| --- | --- |
| `[href]` | その属性を持っていれば当たる |
| `[type="url"]` | 値が完全に一致 |
| `[href^="https"]` | 値がその文字で始まる |

<!-- ノート: 関連の枠。^= のような形もあると知っていれば、必要なとき調べられます。まずは完全一致から。 -->

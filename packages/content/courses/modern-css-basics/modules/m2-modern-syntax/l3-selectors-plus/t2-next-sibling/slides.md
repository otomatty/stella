# 2-3-2
# +は直後の要素に当たる

モダンCSS入門研修 — Module 2 / レッスン2-3

<!-- ノート: 結合子の2つ目。親子ではなく、横並びの関係で絞ります。 -->

---

## なぜ必要か

- 「見出しの直後の段落だけ、先頭の余白を詰めたい」
- その段落に毎回 class を付けて回るのは手間

<!-- ノート: つかみ。位置関係で決まる見た目は、class を振るより並び順で選びたい。 -->

---

## 結論

**`+`でつないだセレクタは、同じ親の中で直後に続く要素だけに当たる**

- `+` は **隣接兄弟結合子**
- 親子(縦)ではなく、並び(横)の関係で選ぶ

<!-- ノート: 結論。兄弟=同じ親を持つ要素どうし。そのうち「すぐ隣」だけに当たります。 -->

---

## 最小のコード

```css
h2 + p {
  margin-block-start: 0;
}
```

- `h2` の直後の `p` だけ、上の余白が消える

<!-- ノート: 見出しと最初の段落を近づける定番の指定です。2つ目以降の段落は変わりません。 -->

---

## >との違い

- `.card > p` = `.card` の**中**(直下)の段落
- `h2 + p` = `h2` の**隣**(直後)の段落

<!-- ノート: 対比の枠。>は縦の関係、+は横の関係。矢印の向きで覚えます。 -->

---

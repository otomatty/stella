# レッスン2-3 セレクタを広げる

## このレッスンの目標

- [ ] 空白と `>` の当たる範囲の違いを説明できる
- [ ] `+` と属性セレクタで、class を足さずに相手を絞れる
- [ ] `:has()` で「中に何を持っているか」を条件に親を選べる

## 2-3-1 >は直下の子だけに当たる

> **>でつないだセレクタは、中身全部ではなく直下の子だけに当たる**

HTML/CSS 入門では、セレクタを空白でつなぐ子孫セレクタを学びました。空白は「中にあるもの全部」に当たります。何段深くても当たるので、ときどき広すぎます。

メニューを考えます。中に入れ子のリスト(サブメニュー)がある形です。

```html
<ul class="menu">
  <li>ホーム</li>
  <li>
    研修一覧
    <ul>
      <li>HTML/CSS</li>
    </ul>
  </li>
</ul>
```

`.menu li` に線を引くと、サブメニューの `li` にも線が付いてしまいます。1段目だけに絞りたいときは、空白の代わりに `>` でつなぎます。

```css
.menu > li {
  border-bottom: 1px solid gray;
}
```

セレクタをつなぐ記号を **結合子** と呼びます。空白も結合子の1つ(子孫結合子)で、`>` は **子結合子** です。

| 書き方 | 当たる範囲 |
| --- | --- |
| `.menu li` | 中の `li` 全部(何段でも) |
| `.menu > li` | 直下の `li` だけ |

迷ったら「全部に当てたいのか、1段だけか」と自問して選んでください。レッスン2-1の入れ子の中でも `> li { ... }` の形で使えます。

## 2-3-2 +は直後の要素に当たる

> **+でつないだセレクタは、同じ親の中で直後に続く要素だけに当たる**

「見出しの直後の段落だけ、上の余白を詰めて見出しに近づけたい」。こんなとき、その段落に毎回 class を付けて回るのは手間ですし、段落を並べ替えたら class も付け替えることになります。

位置関係で決まる見た目は、並び順で選びます。

```css
h2 + p {
  margin-block-start: 0;
}
```

`+` は **隣接兄弟結合子** です。兄弟とは、同じ親を持つ要素どうしのこと。`h2 + p` は「`h2` と同じ親の中で、`h2` の**直後**に続く `p`」だけに当たります。2つ目以降の段落は変わりません。

`>` との違いは、関係の向きです。

- `.card > p` — `.card` の**中**(直下)にある段落。親子の縦の関係
- `h2 + p` — `h2` の**隣**(直後)にある段落。並びの横の関係

## 2-3-3 属性セレクタは属性の値で選ぶ

> **角かっこのセレクタは、要素に付いている属性とその値で当てる相手を選ぶ**

入門のレッスン2-2で見たとおり、`input` は `type` の値によって、テキスト欄にもチェックボックスにもなります。見た目がまるで違うのに、要素名はどれも `input`。要素セレクタでは区別できません。

区別のためだけに class を付けるのは二度手間です。HTML にはすでに `type="checkbox"` という区別の情報が書いてあるからです。それをそのまま条件にするのが **属性セレクタ** です。

```css
input[type="checkbox"] {
  accent-color: var(--color-brand);
}
```

角かっこの中に「属性とその値」を書きます。`type` が `checkbox` の `input` だけに当たり、テキスト欄には当たりません。`accent-color` はチェック印などの色を変えるプロパティで、ここでもレッスン1-2の色トークンを参照しています。

値の合い方も選べます。

| 書き方 | 意味 |
| --- | --- |
| `a[href]` | その属性を持っていれば当たる |
| `input[type="url"]` | 値が完全に一致したら当たる |
| `a[href^="https"]` | 値がその文字で始まったら当たる |

まずは完全一致だけ使えれば十分です。`^=`(で始まる)のような形もあると知っておけば、必要になったとき調べられます。

## 2-3-4 :has()は中身で親を選ぶ

> **:has()は、中に何があるかを条件にして、囲んでいる側の要素を選べる**

ここまでのセレクタは、すべて「外から内へ」の一方通行でした。`.card img` で選べるのは中の画像であって、「画像を持っているカード」自体は選べません。「画像入りのカードだけ余白を詰めたい」が、これまでの道具では書けなかったのです。

**`:has()`** がこの向きを逆にします。

```css
.card:has(img) {
  padding: 0;
}
```

かっこの中に「持っているもの」の条件を書きます。当たるのは条件を満たした**外側**の要素、つまり `.card` 自身です。画像を持つカードだけ余白が消え、持たないカードは変わりません。HTML には1文字も手を入れていません。

かっこの中には、このレッスンで学んだ結合子や属性セレクタも書けます。

```css
.form-row:has(> input[type="checkbox"]) {
  flex-direction: row;
}
```

「直下にチェックボックスを持つ行だけ横並びにする」。`>` で1段に絞り、属性セレクタで種類を絞り、`:has()` で親に当てる。このレッスンの道具が1行に組み合わさった形です。

`:has()` は強力ですが、まず使うべきは今までどおりの浅い class セレクタです。「HTML を変えずに、中身の有無で外側を変えたい」ときの切り札として覚えてください。

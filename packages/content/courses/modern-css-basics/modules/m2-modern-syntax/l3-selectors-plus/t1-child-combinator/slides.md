# 2-3-1
# &gt;は直下の子だけに当たる

モダンCSS入門研修 — Module 2 / レッスン2-3

<!-- ノート: このレッスンでは、当てる相手の絞り方を4つ足します。1つ目は子結合子です。 -->

---

## なぜ必要か

- 空白の子孫セレクタは、何段深くても全部に当たる
- リストの中のリストまで巻き込んで、意図しない場所が変わる

<!-- ノート: つかみ。入門の空白つなぎは便利ですが、当たる範囲が広すぎる場面があります。 -->

---

## 結論

**`>`でつないだセレクタは、中身全部ではなく直下の子だけに当たる**

- セレクタをつなぐ記号を **結合子** と呼ぶ
- `>` は **子結合子**。空白(子孫)より1段だけに絞る

<!-- ノート: 結論。空白は「中にあるもの全部」、>は「直接の子だけ」です。 -->

---

## 最小のコード

```css
.menu > li {
  border-bottom: 1px solid gray;
}
```

- `.menu` の直下の `li` だけに線が付く
- 中に入れ子のリストがあっても、その `li` には当たらない

<!-- ノート: メニューの1段目だけ線を引く、が1行で書けます。空白だと入れ子のリストにも線が付いてしまいます。 -->

---

## 空白と>の違い

| 書き方 | 当たる範囲 |
| --- | --- |
| `.menu li` | 中の `li` 全部(何段でも) |
| `.menu > li` | 直下の `li` だけ |

<!-- ノート: 対比の枠。迷ったら「1段だけ?全部?」と自問して選びます。入れ子の中でも > は使えます。 -->

---

## まとめ

**`>`でつないだセレクタは、中身全部ではなく直下の子だけに当たる**

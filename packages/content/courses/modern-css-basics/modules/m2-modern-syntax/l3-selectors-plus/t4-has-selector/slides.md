# 2-3-4
# :has()は中身で親を選ぶ

モダンCSS入門研修 — Module 2 / レッスン2-3

<!-- ノート: ここまでのセレクタは全部「外から内へ」でした。最後は逆向きです。 -->

---

## なぜ必要か

- 「画像入りのカードだけ、余白を詰めたい」
- 子孫セレクタで選べるのは中の画像で、カード側は選べなかった

<!-- ノート: つかみ。今までは内側へ向かう一方通行で、「持っている親」は選べませんでした。 -->

---

## 結論

**`:has()`は、中に何があるかを条件にして、囲んでいる側の要素を選べる**

- かっこの中に「持っているもの」の条件を書く
- 当たるのは、条件を満たす**外側**の要素

<!-- ノート: 結論。「〜を持っているなら」という条件付きのセレクタです。 -->

---

## 最小のコード

```css
.card:has(img) {
  padding: 0;
}
```

- 画像を持つカードだけ、内側の余白が消える
- 画像の無いカードは変わらない

<!-- ノート: 当たる相手は .card 自身です。img はあくまで条件。HTMLは1文字も変えていません。 -->

---

## 条件には結合子も書ける

```css
.form-row:has(> input[type="checkbox"]) {
  flex-direction: row;
}
```

- 直下にチェックボックスを持つ行だけ横並びに

<!-- ノート: 関連の枠。かっこの中には > や属性セレクタも書けます。このレッスンの道具が全部組み合わさりました。 -->

---

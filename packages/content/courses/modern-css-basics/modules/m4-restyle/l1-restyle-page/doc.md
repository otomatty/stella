# レッスン4-1 既存ページをやり直す

## このレッスンの目標

- [ ] 既存のCSSから色と余白の値を棚卸しして、段階に絞れる
- [ ] `:root` のトークンを定義し、宣言を `var()` の参照に置き換えられる
- [ ] 部品ごとのルールを入れ子にまとめ、トークン1か所の変更で全体が変わる状態にできる

## 4-1-1 作り直しは値の棚卸しから始める

> **作り直しは、いまのCSSに散らばった色と余白の値を書き出して、段階に絞ることから始める**

いよいよ、HTML/CSS 入門で作った1枚のページを作り直します。大事なのは、**いきなり書き換え始めない**ことです。基準を決めずに直し始めると、途中で「ここは何色にするんだっけ」とぶれて、置き換えの前より散らかることさえあります。

最初の作業は **棚卸し** です。コードはまだ1行も変えません。いまの `style.css` を上から読み、色と余白の値を全部書き出して数えます。エディタの検索機能で `px` や `#` を拾うと速く進みます。

```text
色:   navy ×5   #336699 ×2   gray ×4   white ×3
余白: 8px ×3   15px ×2   16px ×6   18px ×1   32px ×2
```

この表から、絞り込みます。

- `navy` と `#336699` — 見比べて、同じ役割で使っているなら**1つのブランド色**に統合する
- `15px`・`16px`・`18px` — 意図した違いでなければ、**中サイズ16px** に寄せる

微妙に違う値は、たいてい意図ではなく揺れです。「その違いに理由があるか」を問い、無ければ統合します。結果として、色が3〜4個、余白が3段階(レッスン3-2の小・中・大)ほどに収まるのが目安です。

この表が、以降の全作業の設計図になります。

## 4-1-2 宣言をトークンの参照に置き換える

> **棚卸しした値を:rootのトークンにまとめ、各宣言をvar()の参照に置き換える**

設計図ができたら、CSS に手を入れます。まず、絞った値を `:root` のトークンとして定義します。色はレッスン1-2で学んだ `oklch()` で書き直し、役割の名前を付けます。

```css
:root {
  --color-brand: oklch(45% 0.12 250);
  --color-brand-soft: color-mix(in oklch, var(--color-brand) 20%, white);
  --color-text: oklch(25% 0.02 250);
  --space-s: 8px;
  --space-m: 16px;
  --space-l: 32px;
}
```

次に、既存の宣言を1つずつ `var()` の参照に置き換えます。

```css
h1 {
  color: var(--color-brand);
}

.card {
  padding: var(--space-m);
}
```

この工程は**見た目を変える工程ではありません**。`navy` 相当の色は `--color-brand` に、16pxに寄せた余白は `--space-m` に。値の置き場所を `:root` に移しているだけなので、置き換えのたびにブラウザーを再読み込みして、**見た目がほぼ変わっていないこと**を確かめながら進めます(15px→16pxのような棚卸しの統合分だけ、わずかに変わります)。

進め方のコツは2つです。

- **種類ごとに一気に**。色を全部置き換えてから、余白を全部。1種類ずつ潰すと漏れに気づきやすい
- 置き換え漏れは**検索で探す**。元の値(`navy` など)をファイル内検索して、ヒットがゼロ件になったらその値は完了

## 4-1-3 部品のルールは入れ子にまとめ直す

> **同じ部品に当てているルールは、入れ子で1つのまとまりに書き直す**

値は1か所にまとまりました。仕上げはセレクタの整理です。入門から積み上げた CSS は、書いた順に並んでいるだけで、`.card` のルールがファイルのあちこちに散っているはずです。

```css
.card { border: 1px solid navy; padding: 16px; }
/* …離れた場所に… */
.card img { max-width: 100%; }
.card:hover { background-color: lightblue; }
```

レッスン2-1の入れ子で、部品ごとに集めます。

```css
.card {
  padding: var(--space-m);
  border: 1px solid var(--color-brand);

  img {
    max-width: 100%;
  }

  &:hover {
    background-color: var(--color-brand-soft);
  }
}
```

- `.card ...` で始まるルールを集めて、`.card` の波かっこの中へ
- 状態(`:hover` / `:focus-visible`)は `&` を付けて中へ
- 深さは**2段まで**。3段目が欲しくなったら class を付けて浅くする

これで「カードのことは、この波かっこを読めば全部わかる」状態になりました。

最後に、作り直しのゴール判定をします。`:root` の `--color-brand` の色相を1か所だけ変えて、再読み込みしてください。

- 見出し・ボーダー・ホバーの背景・フォーカスの枠……**ページ全体が付いて変わる**なら、トークン化は成功です
- 変わらない場所が残っていたら、それは置き換え漏れです。検索で見つけて `var()` に直します

1か所の変更でページ全体の見た目が動く。これが、この講座で作ってきた「トークン経由で見た目を変えられるCSS」の完成形です。新しい部品は1つも足していません。次の講座では、この土台の上に UI 部品を作っていきます。

# 4-1-3
# 部品のルールは入れ子にまとめ直す

モダンCSS入門 — Module 4 / レッスン4-1

<!-- ノート: 値はトークンになりました。最後はセレクタの整理です。 -->

---

## なぜ必要か

- `.card` のルールが、ファイルのあちこちに散っている
- 値は1か所になったのに、部品の全体像はまだ読めない

<!-- ノート: つかみ。入門から積み上げたCSSは、書いた順に並んでいるだけのはずです。 -->

---

## 結論

**同じ部品に当てているルールは、入れ子で1つのまとまりに書き直す**

- `.card ...` で始まるルールを集めて、`.card` の中へ
- 状態(`:hover` / `:focus-visible`)は `&` で中へ

<!-- ノート: 結論。「この部品のことはここを読めば全部わかる」を作ります。 -->

---

## 最小のコード

```css
.card {
  padding: var(--space-m);
  border: 1px solid var(--color-brand);

  img { max-width: 100%; }
  &:hover { background-color: var(--color-brand-soft); }
}
```

<!-- ノート: 散っていた4つのルールが1つの箱に。深さは2段までを守ります。 -->

---

## 仕上げの確認

- `:root` のブランド色を1か所変える → **ページ全体が付いて変わる**
- そうならない場所は、置き換え漏れ

<!-- ノート: これが作り直しのゴール判定です。1か所の変更で全体が動けば、トークン化は成功です。 -->

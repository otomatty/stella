# レッスン4-1 演習 — 既存ページをやり直す

対象トピック: 4-1-1 〜 4-1-3

## 手元で試す

この演習が、この講座の総仕上げです。HTML/CSS 入門で作った `index.html` / `style.css` を使います(手元に無ければ、この講座のレッスン1-1〜3-3で作ってきた練習ファイルでかまいません)。

**手順1: 棚卸し。** `style.css` を上から読み、色と余白の値をメモに書き出して数えてください。まだコードは変えません。

```text
例)
色:   navy ×5   gray ×4   white ×3
余白: 8px ×3   15px ×2   16px ×6   32px ×2
```

似た値(15pxと16pxなど)を統合し、色3個前後・余白3段階に絞ります。

**手順2: トークン定義と置き換え。** `:root` にトークンを定義し、宣言を1つずつ `var()` に置き換えます。色→余白の順で、種類ごとに一気に進めてください。

```css
:root {
  --color-brand: oklch(45% 0.12 250);
  --color-brand-soft: color-mix(in oklch, var(--color-brand) 20%, white);
  --color-text: oklch(25% 0.02 250);
  --space-s: 8px;
  --space-m: 16px;
  --space-l: 32px;
}
```

置き換えのたびに再読み込みし、見た目がほぼ変わらないことを確かめます。元の値(`navy` など)をファイル内検索してゼロ件になったら、その値は完了です。

**手順3: 入れ子への整理。** 同じ部品(`.card` など)に当てているルールを集め、入れ子と `&` で1つのまとまりに書き直します。深さは2段までです。

**ゴール判定:** `:root` の `--color-brand` の色相を `250` から `150` に変えて再読み込みしてください。ページ全体の色がそろって緑系に変われば合格です。変わらない場所があれば置き換え漏れなので、検索で見つけて直します。

## 演習問題

### 問1(基本)

棚卸しの段階で、コードを書き換えてよいですか。理由とあわせて1文で答えてください。

### 問2(基本)

棚卸しで `14px ×1` と `16px ×8` が見つかりました。どう扱うのが定石ですか。

### 問3(応用)

トークンへの置き換えが漏れている場所を、効率よく見つける方法を1文で答えてください。

### 問4(応用)

作り直しが成功したかどうかを判定する、最後の確認方法を1文で答えてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

書き換えません。先に値の全体像と絞り方(設計図)を決めないと、置き換えの途中で基準がぶれるからです。

</details>

<details>
<summary>問2の解答例</summary>

意図した違いでなければ `16px` に統合し、`--space-m` のような1つのトークンに寄せます。

</details>

<details>
<summary>問3の解答例</summary>

元の値(`navy` や `16px`)をファイル内検索し、ヒットが残っていないかを確かめます。

</details>

<details>
<summary>問4の解答例</summary>

`:root` のトークンを1か所変えて、ページ全体の見た目がそろって変わることを確かめます。

</details>

## 確認クイズ

### Q1. 作り直しの最初の工程はどれですか。

- A. :root にトークンを定義する
- B. 散らばった値を書き出して段階に絞る
- C. セレクタを入れ子に書き直す

<details>
<summary>答え</summary>

**B** — 棚卸しが最初です。設計図を決めてから、定義→置き換え→整理の順に進めます。

</details>

### Q2. 棚卸しで見つかった 15px と 16px の混在は、ふつう何を意味しますか。

- A. 意図的なデザインの違い
- B. 揺れ。理由がなければ統合する
- C. ブラウザーの計算誤差

<details>
<summary>答え</summary>

**B** — 微妙に違う値はたいてい揺れです。「違いに理由があるか」を問い、無ければ1つに寄せます。

</details>

### Q3. トークンへの置き換え工程で確かめることはどれですか。

- A. 見た目がほぼ変わっていないこと
- B. 見た目が大きく変わったこと
- C. ファイルサイズが減ったこと

<details>
<summary>答え</summary>

**A** — この工程は値の置き場所を変えるだけです。見た目が大きく変わったら、どこかを壊しています。

</details>

### Q4. 入れ子にまとめ直すときの深さの目安はどれですか。

- A. 2段まで
- B. 4段まで
- C. 制限なし

<details>
<summary>答え</summary>

**A** — 部品のまとまりの2段までです。深くなったら class を付けて浅く戻します。

</details>

### Q5. 「トークン経由で見た目を変えられる」状態の証拠はどれですか。

- A. CSSの行数が半分になった
- B. :root を1か所変えるとページ全体が付いて変わる
- C. class 名がすべて英語になった

<details>
<summary>答え</summary>

**B** — 1か所の変更で全体が動くことが、値が1か所に集まったことの証明です。

</details>

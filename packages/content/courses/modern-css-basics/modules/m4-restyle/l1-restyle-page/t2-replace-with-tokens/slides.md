# 宣言をトークンの参照に置き換える

モダンCSS入門研修 — Module 4 / レッスン4-1

---

## なぜ必要か

- 表を作っただけでは、CSSはまだ散らばったまま
- 「決めた段階しか使えない」状態を、コードの形にする

<!-- ノート: つかみ。棚卸しの成果を、:rootという1か所に固定します。 -->

---

## 結論

**棚卸しした値を`:root`のトークンにまとめ、各宣言を`var()`の参照に置き換える**

- 定義を先に書き、参照への置き換えは1宣言ずつ
- 置き換えのたびに、見た目が変わらないことを確かめる

<!-- ノート: 結論。見た目を変える工程ではなく、値の置き場所を変える工程です。 -->

---

## 最小のコード

```css
:root {
  --color-brand: oklch(45% 0.12 250);
  --space-m: 16px;
}

h1 { color: var(--color-brand); }
.card { padding: var(--space-m); }
```

<!-- ノート: navy だった宣言が var の参照になりました。棚卸しで16pxに寄せた余白も同じです。 -->

---

## 進め方のコツ

- **色を全部 → 余白を全部** の順で、種類ごとに一気に
- 置き換え漏れは、元の値(navyなど)をファイル内検索して探す

<!-- ノート: 1種類ずつ潰すと漏れに気づきやすい。検索でゼロ件になったら置き換え完了です。 -->

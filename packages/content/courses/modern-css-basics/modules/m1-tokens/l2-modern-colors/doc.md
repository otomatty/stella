# レッスン1-2 色の今どきの書き方

## このレッスンの目標

- [ ] `oklch()` の3つの数字が何を表すかを説明できる
- [ ] `color-mix()` で元の色から薄い色・濃い色を派生できる
- [ ] 色を役割の名前でトークン化して `:root` にまとめられる

## 1-2-1 oklch()は明るさから色を作る

> **oklch()は、明るさ・鮮やかさ・色相の3つの数字で色を書く**

HTML/CSS 入門では、色を `navy` のような色名や `#336699` のような16進数で書いてきました。16進数には2つの弱点があります。見ても何色か分からないことと、「同じ色の少し暗い版」を作るのが勘だよりになることです。

現代の CSS には、人間が色を考える順番のまま書ける関数があります。

```css
h1 {
  color: oklch(45% 0.12 250);
}
```

**`oklch()`** の3つの数字は、順に次を表します。

| 数字 | 名前 | 意味 |
| --- | --- | --- |
| 45% | **明るさ**(L) | 0%が黒、100%が白 |
| 0.12 | 鮮やかさ(C) | 0がグレー。0.1前後で落ち着いた色、0.2を超えるとかなり鮮やか |
| 250 | **色相**(H) | 色相環の角度(0〜360)。何色みかを決める |

色相のおおまかな目安は、30前後が赤み、90前後が黄み、150前後が緑み、250前後が青みです。

`oklch()` の大きな特徴は、**明るさの数字がそのまま見た目の明るさに効く**ことです。明るさが同じ2色は、色相が違っても同じくらいの明るさに見えます。似た形の関数に `hsl()` がありますが、こちらは色相を変えると見た目の明るさが大きくばらつきます。

この性質のおかげで、色の調整が「数字の操作」になります。

- 暗い版が欲しい → 明るさの%を下げる
- 別の色みで同じ調子の色が欲しい → 色相だけ変える

入門で学んだ「文字色と背景色は明るさの差で決める」も、oklch なら明るさの数字の差として直接読めます。

## 1-2-2 color-mix()は2つの色を混ぜる

> **color-mix()は、2つの色を指定した割合で混ぜた色を作る**

ブランド色が決まると、次に欲しくなるのは「その薄い版」です。バッジの背景、お知らせ欄の下地など、元の色の親戚はページのあちこちで使います。そのたびに別の色の数字を作って管理するのは大変です。

**`color-mix()`** を使うと、派生色を「数字」ではなく「作り方」で持てます。

```css
.badge {
  background-color: color-mix(in oklch, navy 30%, white);
}
```

読み方は次のとおりです。

- `in oklch` — どの物差しで混ぜるか。この講座では oklch で統一します
- `navy 30%` — 1つ目の色と、その割合
- `white` — 2つ目の色。残りの70%を受け持つ

`navy 30%, white` はかなり薄い青、`navy 70%, white` は少し薄い青になります。白と混ぜれば薄く、黒と混ぜれば濃くなる。絵の具と同じ発想です。

作り方で持つ利点は、**元の色を変えると混ぜた結果も付いて変わる**ことです。ブランド色を差し替えたとき、派生色を1つずつ作り直す必要がありません。

## 1-2-3 色は役割の名前でトークンにする

> **色は:rootのカスタムプロパティに役割の名前を付けて、トークンとして使い回す**

`oklch()` と `color-mix()` で色を作れるようになりました。ただし、作った色を宣言のあちこちに直接書いたら、結局は入門のときと同じ「散らばった値」に戻ってしまいます。ここでレッスン1-1のカスタムプロパティと組み合わせます。

名前を付けて使い回す、デザインの決めごとの値を **トークン** と呼びます。色のトークンは `:root` にまとめます。

```css
:root {
  --color-brand: oklch(45% 0.12 250);
  --color-brand-soft: color-mix(in oklch, var(--color-brand) 20%, white);
  --color-text: oklch(25% 0.02 250);
}

h1 {
  color: var(--color-brand);
}

.badge {
  background-color: var(--color-brand-soft);
}
```

この3つが最小の色トークンです。`--color-brand-soft` は `--color-brand` から `color-mix()` で派生させているので、ブランド色を1か所差し替えるだけで、薄い版も付いて変わります。

もう1つ大事なのが、名前の付け方です。

- `--color-navy` のような **見た目の名前** は避ける。色を `crimson` に変えた瞬間、名前が嘘になります
- `--color-brand`(ブランド色)、`--color-text`(本文の色)のような **役割の名前** なら、値を差し替えても意味が通ります

トークンの名前は「何色か」ではなく「何に使う色か」。この講座の後半でページを作り直すときも、この名付けを使います。

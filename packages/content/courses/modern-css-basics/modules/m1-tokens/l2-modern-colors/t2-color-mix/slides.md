# color-mix()は2つの色を混ぜる

モダンCSS入門 — Module 1 / レッスン1-2

<!-- ノート: oklchで色を1つ作れるようになりました。今度はその色から、派生の色を作ります。 -->

---

## なぜ必要か

- ボタンの背景に、ブランド色の「薄い版」を敷きたい
- そのたびに別の色の数字を作って管理するのは大変

<!-- ノート: つかみ。淡い背景・ホバーの少し濃い色など、「元の色の親戚」は頻出です。 -->

---

## 結論

**`color-mix()`は、2つの色を指定した割合で混ぜた色を作る**

- 白と混ぜれば薄く、黒と混ぜれば濃くなる
- 元の色を変えれば、混ぜた結果も付いて変わる

<!-- ノート: 結論。絵の具と同じ発想です。派生色を「数字」ではなく「作り方」で持てます。 -->

---

## 最小のコード

```css
.badge {
  background-color: color-mix(in oklch, navy 30%, white);
}
```

- `in oklch` = oklchの尺度で混ぜる
- navyを30%、残り70%はwhite

<!-- ノート: in oklch は「どの物差しで混ぜるか」。この講座ではoklchで混ぜる、で統一します。 -->

---

## 割合の読み方

- `navy 30%, white` → navyが3割の、かなり薄い色
- `navy 70%, white` → navyが7割の、少し薄い色

<!-- ノート: 対比の枠。%は最初の色の割合です。数字を動かして濃さを選びます。 -->

# カスタムプロパティは値に名前を付ける

モダンCSS入門研修 — Module 1 / レッスン1-1

<!-- ノート: この講座の1本目です。入門で作ったページを、現代の書き方で作り直していきます。その土台がこのカスタムプロパティです。 -->

---

## なぜ必要か

- 同じ色の指定が、CSSのあちこちに書いてある
- 「メインの色を少し変えたい」だけで、全部の行を探して直す羽目になる

<!-- ノート: つかみ。入門で作ったページを思い出してもらう。同じ #336699 のような値が何か所にもコピーされているはず。 -->

---

## 結論

**`--`で始まる名前のプロパティを書くと、CSSの値に自分で名前を付けて覚えさせられる**

- これを **カスタムプロパティ** と呼ぶ
- 名前は `--` の後ろに自分で決めて付ける

<!-- ノート: 結論を言い切る。色やサイズの値そのものに、意味の分かる名前を付けられるようになります。 -->

---

## 最小のコード

```css
.card {
  --brand-color: navy;
}
```

- 書き方は普通の宣言と同じ「名前: 値」
- ただし名前が `--` で始まる

<!-- ノート: 見た目はまだ何も変わりません。値を「覚えさせた」だけです。取り出して使う方法は次のトピックで扱います。 -->

---

## 普通のプロパティとの違い

| | 普通のプロパティ | カスタムプロパティ |
| --- | --- | --- |
| 名前 | `color` など決まっている | `--` の後ろは自由 |
| 働き | 見た目を変える | 値を覚えるだけ |

<!-- ノート: 対比の枠。color は書いた瞬間に見た目が変わりますが、カスタムプロパティは覚えるだけで、単体では何も起きません。 -->

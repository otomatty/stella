# 1-1-4
# 同じ名前を書き直すと、その中だけ変わる

モダンCSS入門研修 — Module 1 / レッスン1-1

<!-- ノート: :root に置いた値を、一部の場所だけ変えたいときの話です。 -->

---

## なぜ必要か

- お知らせ欄だけ、強調のために別の色にしたい
- そのためだけに `--notice-color` のような別の名前を増やしたくない

<!-- ノート: つかみ。全体は navy でいいけれど、この一角だけ変えたい、はよくある要望です。 -->

---

## 結論

**要素の中でカスタムプロパティを定義し直すと、その要素の中だけ値が変わる**

- これを **上書き** と呼ぶ
- 外側(`:root`)の定義は変わらない

<!-- ノート: 結論。継承は「近い親の値が勝つ」ので、途中で定義し直すとそこから下だけが入れ替わります。 -->

---

## 最小のコード

```css
:root { --accent: navy; }

.notice { --accent: crimson; }

h2 { color: var(--accent); }
```

- `.notice` の中の `h2` だけ crimson になる

<!-- ノート: h2 の宣言は1行のまま。場所によって取り出される値が変わる、が上書きの効き方です。 -->

---

## 使う側は書き換えない

- 変えるのは **定義**(`--accent: ...`)だけ
- `var(--accent)` と書いた行は、1行も直していない

<!-- ノート: ここがトークンの強さです。使う側の宣言はそのままで、値の差し替えだけで見た目が変わります。 -->

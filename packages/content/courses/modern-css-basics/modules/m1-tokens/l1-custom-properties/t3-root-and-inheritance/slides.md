# 1-1-3
# :rootに置くとページ全体で使える

モダンCSS入門 — Module 1 / レッスン1-1

<!-- ノート: 定義と参照ができました。次は「どこに定義するか」です。 -->

---

## なぜ必要か

- `.card` に定義した値は、カード以外の場所では取り出せない
- ページ全体の色や余白は、1か所にまとめて定義したい

<!-- ノート: つかみ。ボタンでもフッターでも同じブランド色を使いたいのに、.card の中の定義では届きません。 -->

---

## 結論

**カスタムプロパティは子に継承されるので、`:root`に置くとページ全体で使える**

- **継承** = 親に書いた指定が、中の要素にも受け継がれること
- **`:root`** = ページ全体の根っこ(html要素)を指すセレクタ

<!-- ノート: 文字色が親から子へ受け継がれるのと同じ仕組みです。根っこに置けば、全部の要素がその子孫になります。 -->

---

## 最小のコード

```css
:root {
  --brand-color: navy;
}

.card { border-color: var(--brand-color); }
button { background-color: var(--brand-color); }
```

<!-- ノート: 定義は :root に1か所。カードでもボタンでも、ページのどこからでも var() で取り出せます。 -->

---

## 定義を置く場所の使い分け

- ページ全体で使う値 → **`:root`**
- その部品の中だけの値 → 部品のセレクタ

<!-- ノート: 全部を :root に置く必要はありません。まず「全体の値は根っこへ」が既定、と覚えてもらえば十分です。 -->

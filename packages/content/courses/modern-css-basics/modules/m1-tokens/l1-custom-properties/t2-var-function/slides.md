# var()で名前から値を取り出す

モダンCSS入門研修 — Module 1 / レッスン1-1

<!-- ノート: 前のトピックで値に名前を付けました。今度はそれを取り出して使います。 -->

---

## なぜ必要か

- カスタムプロパティは、書いただけでは見た目に何も起きない
- 覚えさせた値を、色や余白の指定で使う方法が要る

<!-- ノート: つかみ。--brand-color: navy と書いても画面は変わりませんでした。使う側の書き方がこのトピックです。 -->

---

## 結論

**`var()`にカスタムプロパティの名前を渡すと、覚えさせた値を取り出して使える**

- 値を書く場所ならどこでも使える
- 定義を1か所直せば、使っている場所が全部変わる

<!-- ノート: 結論。定義は1か所、参照は何か所でも。これが「探して全部直す」作業を無くします。 -->

---

## 最小のコード

```css
.card {
  --brand-color: navy;
  border: 2px solid var(--brand-color);
  color: var(--brand-color);
}
```

<!-- ノート: border と文字色が同じ navy になります。--brand-color を crimson に変えると、2か所が一度に変わります。 -->

---

## 取り出せないときの備え

```css
color: var(--brand-color, gray);
```

- 2つ目に **予備の値** を書ける
- 名前の書き間違いなどで見つからないとき、予備が使われる

<!-- ノート: 関連の枠はフォールバックだけ。var の 2 つ目の引数は「見つからなかったときの保険」です。 -->

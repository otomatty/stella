# レッスン1-1 カスタムプロパティ

## このレッスンの目標

- [ ] `--名前: 値` でカスタムプロパティを定義し、`var()` で取り出せる
- [ ] ページ全体で使う値を `:root` にまとめられる
- [ ] 一部の要素の中だけ、定義し直して値を変えられる

## 1-1-1 カスタムプロパティは値に名前を付ける

> **--で始まる名前のプロパティを書くと、CSSの値に自分で名前を付けて覚えさせられる**

HTML/CSS 入門で作ったページの `style.css` を思い出してください。同じ色の値が、見出し・ボーダー・ボタンなど、あちこちに書いてあったはずです。「メインの色を少し変えたい」となったとき、その全部を探して直すのは大変ですし、直し漏れも起きます。

この講座の最初の道具が **カスタムプロパティ** です。値そのものに、自分で決めた名前を付けられます。

```css
.card {
  --brand-color: navy;
}
```

書き方は普通の宣言と同じ「名前: 値」ですが、名前が `--` で始まる点だけが違います。`--` の後ろは自分で自由に決められます。

普通のプロパティとの違いは、働きです。

| | 普通のプロパティ | カスタムプロパティ |
| --- | --- | --- |
| 名前 | `color` など決まっている | `--` の後ろは自由 |
| 働き | 見た目を変える | 値を覚えるだけ |

`color: navy;` は書いた瞬間に文字色が変わりますが、`--brand-color: navy;` は値を覚えさせただけで、見た目には何も起きません。取り出して使う方法が次のトピックです。

名前は `--main-color` と `--Main-Color` を別物として区別します。小文字とハイフンだけで揃えておくと迷いません。

## 1-1-2 var()で名前から値を取り出す

> **var()にカスタムプロパティの名前を渡すと、覚えさせた値を取り出して使える**

覚えさせた値は、`var()` で取り出します。値を書く場所ならどこでも使えます。

```css
.card {
  --brand-color: navy;
  border: 2px solid var(--brand-color);
  color: var(--brand-color);
}
```

ボーダーの色と文字色が、どちらも `navy` になります。ここで `--brand-color` の定義を `crimson` に変えると、**使っている2か所が一度に変わります**。定義は1か所、参照は何か所でも。これが「値を探して全部直す」作業を無くす仕組みです。

`var()` には、2つ目の値を書くこともできます。

```css
color: var(--brand-color, gray);
```

名前の書き間違いなどで値が見つからないとき、2つ目に書いた **予備の値** が代わりに使われます。カスタムプロパティは名前を打ち間違えてもエラーが出ないので、この保険が効く場面があります。

## 1-1-3 :rootに置くとページ全体で使える

> **カスタムプロパティは子に継承されるので、:rootに置くとページ全体で使える**

`.card` の中に定義した値は、カードとその中でしか取り出せません。ボタンでもフッターでも同じブランド色を使いたいなら、もっと外側に定義する必要があります。

ここで効くのが **継承** です。HTML/CSS 入門で「文字の指定は親から子へ受け継がれる」ことを学びました。カスタムプロパティも同じで、親に定義した値は中の要素すべてで取り出せます。

そこで、ページ全体の根っこである `html` 要素を指すセレクタ **`:root`** に定義します。

```css
:root {
  --brand-color: navy;
}

.card {
  border-color: var(--brand-color);
}

button {
  background-color: var(--brand-color);
}
```

すべての要素は `html` の子孫なので、`:root` に置いた値はページのどこからでも取り出せます。

定義を置く場所は、次の使い分けが既定です。

- ページ全体で使う値 → `:root`
- その部品の中だけの値 → 部品のセレクタ

## 1-1-4 同じ名前を書き直すと、その中だけ変わる

> **要素の中でカスタムプロパティを定義し直すと、その要素の中だけ値が変わる**

「全体は `navy` でいいけれど、お知らせ欄だけ強調のために別の色にしたい」。こんなとき、別の名前を増やす必要はありません。同じ名前を、その要素の中で定義し直します。これを **上書き** と呼びます。

```css
:root {
  --accent: navy;
}

.notice {
  --accent: crimson;
}

h2 {
  color: var(--accent);
}
```

`h2` の宣言は1行だけですが、取り出される値は場所によって変わります。

- ふつうの場所の `h2` → `:root` の `navy`
- `.notice` の中の `h2` → 上書きされた `crimson`

継承は「いちばん近い親の値が勝つ」ので、途中で定義し直すと、そこから下だけが入れ替わります。`:root` の定義自体は変わりません。

注目してほしいのは、**`var(--accent)` と書いた行は1行も直していない**ことです。使う側の宣言はそのままで、定義の差し替えだけで見た目が変わる。この性質が、次のレッスン以降で「値に役割の名前を付けて使い回す」土台になります。

# 画像はmax-widthで箱に収める

モダンCSS入門 — Module 3 / レッスン3-2

## なぜ必要か

- 大きい写真を置いたら、カードや画面から突き抜けた
- 文章は箱に合わせて折り返すのに、画像は折り返せない

<!-- ノート: つかみ。横スクロールが出る原因の定番が、幅を持った画像のはみ出しです。 -->

---

## 結論

**`img`に`max-width: 100%`を当てると、画像が置いた箱の幅からはみ出さなくなる**

- 画像は自分の実寸で描かれる **置換要素**(中身が外部ファイルの要素)
- だから箱に合わせて勝手には縮まない。上限を明示する

<!-- ノート: 結論。videoやiframeも同じ性質の仲間です。理由ごと覚えます。 -->

---

## 最小のコード

```css
img {
  max-width: 100%;
  height: auto;
}
```

- 100% = 置かれた箱の幅が上限
- `height: auto` で縦横の比率を保つ

<!-- ノート: 要素セレクタで全画像に一括。ページの土台に最初から入れておく2行です。 -->

---

## widthではなくmaxな理由

- `width: 100%` — 小さい画像まで引き伸ばされてぼやける
- `max-width: 100%` — 大きい画像だけ縮む。小さい画像は実寸のまま

<!-- ノート: 対比の枠。上限だけ決めて、あとは実寸に任せるのが正解です。 -->

# レッスン3-2 余白トークンと画像の収め方

## このレッスンの目標

- [ ] 余白の段階を決めて `:root` のトークンにできる
- [ ] `max-width: 100%` で画像のはみ出しを止められる
- [ ] `object-fit` で枠と比率の違う画像を収められる

## 3-2-1 余白は段階を決めてトークンにする

> **余白の値は少ない段階に絞って、:rootのトークンにする**

ページを作り込んでいくと、`padding: 15px`、`margin-block: 18px`、`gap: 22px`…と、微妙に違う余白が増えていきます。1つ1つは「ここはこのくらいがちょうどいい」と決めたはずなのに、全体を見るとリズムがそろわず、それだけで雑な印象になります。

レッスン1-2で色に対してやったことを、余白にも適用します。使ってよい値をあらかじめ数個に絞った並び――**段階**――を決めて、`:root` のトークンにするのです。

```css
:root {
  --space-s: 8px;
  --space-m: 16px;
  --space-l: 32px;
}

.card {
  padding: var(--space-m);
}

.section {
  margin-block: var(--space-l);
}
```

小・中・大の3段階が最小構成です。`padding` も `margin` も `gap` も、余白はすべてこのトークンから選びます。**迷ったら段階から選ぶ。中間の値をその場で作らない**。これが運用のルールです。

効き目は2つあります。

- 選択肢が数個しかないので、ページ全体の余白のリズムが自然にそろう
- 「全体に詰まりすぎている」と感じたら、トークンの定義を1か所変えるだけで一括調整できる

なお、段階をいくつにするか・比率をどう組むかの体系論(8pt グリッドなど)には踏み込みません。まずは「少ない段階に絞って名前で選ぶ」ことが本質です。

## 3-2-2 画像はmax-widthで箱に収める

> **imgにmax-width: 100%を当てると、画像が置いた箱の幅からはみ出さなくなる**

レイアウトを一番よく壊す犯人が画像です。大きい写真をカードに置いたら、枠を突き抜けて横スクロールが出た。誰もが一度は踏む事故です。

文章は箱の幅に合わせて折り返しますが、画像は折り返せません。画像は、中身が外部ファイルで、その**実寸**で描かれる **置換要素** と呼ばれる仲間です(`video` や `iframe` も同じ性質を持ちます)。箱に合わせて勝手に縮んではくれないので、上限をこちらで明示します。

```css
img {
  max-width: 100%;
  height: auto;
}
```

- `max-width: 100%` — 置かれた箱の幅を上限にする。それより大きい画像は縮む
- `height: auto` — 幅が縮んだ分だけ高さも追従し、縦横の比率が保たれる

`width: 100%` ではなく `max-width: 100%` である点が大事です。

- `width: 100%` — 小さい画像まで箱いっぱいに引き伸ばされて、ぼやける
- `max-width: 100%` — 大きい画像だけ縮み、小さい画像は実寸のまま

上限だけ決めて、あとは実寸に任せる。この2行は要素セレクタで全画像に一括で当てて、ページの土台に最初から入れておく定番です。

## 3-2-3 収め方はobject-fitで決める

> **枠と比率が合わない画像をどう収めるかは、object-fitで決める**

はみ出しは止まりました。次はもう一歩進んで、「決めた枠に画像を収める」場面です。

カードのサムネイルは、同じ大きさの枠でそろえたい。でも元の写真は縦長も横長もあります。幅と高さを両方固定した瞬間、比率の違う画像は必ずつぶれるか引き伸ばされるかします。

枠のサイズと、中身の収め方を別々に決めるのが **`object-fit`** です。

```css
.card img {
  width: 100%;
  height: 160px;
  object-fit: cover;
}
```

主な値は3つです。

| 値 | 収め方 |
| --- | --- |
| `fill`(既定) | 比率を無視して、ゆがんででも枠を埋める |
| `cover` | 比率を保ったまま枠を埋め、はみ出す部分は切る |
| `contain` | 比率を保ったまま全体を見せ、足りない部分はすき間になる |

既定の `fill` がゆがみの正体です。サムネイルのように「そろって見えること」が大事な場面は `cover`、図版のように「全体が見えること」が大事な場面は `contain`、と使い分けます。迷ったら `cover` が無難です。

`cover` でどこが切られるかは、既定では中央が残ります。被写体が端に寄っている写真では `object-position` で残す位置を調整できます。

# 収め方はobject-fitで決める

モダンCSS入門 — Module 3 / レッスン3-2

<!-- ノート: はみ出しは止めました。今度は「決めた枠に、形の違う画像を収める」段です。 -->

---

## なぜ必要か

- カードのサムネイルは同じ大きさの枠でそろえたい
- でも元の写真は縦長も横長もあり、枠に押し込むとつぶれる

<!-- ノート: つかみ。幅も高さも固定した瞬間、比率の違う画像は必ずゆがみます。 -->

---

## 結論

**枠と比率が合わない画像をどう収めるかは、`object-fit`で決める**

- 置換要素の「中身の収め方」を決めるプロパティ
- 既定はゆがんで埋める。ふつうは `cover` を選ぶ

<!-- ノート: 結論。枠のサイズと、中身の収め方を別々に決められるようになります。 -->

---

## 最小のコード

```css
.card img {
  width: 100%;
  height: 160px;
  object-fit: cover;
}
```

- `cover` = 比率を保ち、はみ出す部分を切って枠を埋める

<!-- ノート: 枠は160px固定。どんな比率の写真でも、ゆがまずに枠いっぱいに表示されます。 -->

---

## 主な値

| 値 | 収め方 |
| --- | --- |
| `fill`(既定) | ゆがんででも枠を埋める |
| `cover` | 比率を保って埋め、余りは切る |
| `contain` | 比率を保って全体を見せ、すき間は空く |

<!-- ノート: 迷ったらcover。全体が見えないと困る図版はcontain、と使い分けます。 -->

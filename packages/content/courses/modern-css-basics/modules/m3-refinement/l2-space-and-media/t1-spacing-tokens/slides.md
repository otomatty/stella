# 3-2-1
# 余白は段階を決めてトークンにする

モダンCSS入門研修 — Module 3 / レッスン3-2

<!-- ノート: 色でやったトークン化を、余白にも広げます。 -->

---

## なぜ必要か

- 15px、18px、22px…と、微妙に違う余白が増えていく
- ばらばらの余白は、そろっていないだけで雑に見える

<!-- ノート: つかみ。1つ1つは「ちょうどよく」決めたはずが、全体では不揃いになります。 -->

---

## 結論

**余白の値は少ない段階に絞って、`:root`のトークンにする**

- **段階** = 使ってよい値を数個に絞った並び
- 迷ったら段階から選ぶ。中間の値は作らない

<!-- ノート: 結論。選択肢を減らすことが、そろって見えることの正体です。 -->

---

## 最小のコード

```css
:root {
  --space-s: 8px;
  --space-m: 16px;
  --space-l: 32px;
}

.card { padding: var(--space-m); }
```

<!-- ノート: 小・中・大の3段階が最小構成。gapやmarginもこのトークンから選びます。 -->

---

## 効き目

- ページ全体の余白のリズムがそろう
- 「詰まりすぎ?」の調整が、トークン1か所の変更で済む

<!-- ノート: 色トークンと同じ構図です。値の散らばりを定義側に寄せておくと、後から一括で動かせます。 -->

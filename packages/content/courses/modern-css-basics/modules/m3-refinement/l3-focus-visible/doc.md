# レッスン3-3 フォーカスの見た目

## このレッスンの目標

- [ ] `:focus` と `:focus-visible` の当たる場面の違いを説明できる
- [ ] 既定の枠を消しつつ、キーボード操作の枠を用意できる

## 3-3-1 :focus-visibleは必要なときだけ枠を出す

> **:focus-visibleは、キーボード操作のようにフォーカスの枠が必要なときだけ当たる**

いま操作対象になっている状態を **フォーカス** と呼びます。HTML/CSS 入門のレッスン3-3で、`:focus` の枠(既定の光る囲み)を消してはいけない、と学びました。キーボードだけで操作する人は、この枠だけを頼りに現在地を判断しているからです。

一方で、現場ではこんな不満もよく聞きます。「マウスでクリックしただけなのに、ボタンに枠が付いてじゃまに見える」。クリック操作では、いまどこを押したかは見れば分かるので、枠の必要性が薄いのです。

この「操作によって枠の要不要が違う」を、そのまま引き受けてくれる擬似クラスが **`:focus-visible`** です。

```css
button:focus-visible {
  outline: 3px solid var(--color-brand);
}
```

`:focus-visible` は、フォーカスの枠を**表示すべき操作かどうか**をブラウザーが判断して当たります。

| | 当たる場面 |
| --- | --- |
| `:focus` | フォーカスされたら常に(クリックでも) |
| `:focus-visible` | 枠の表示が必要な操作(Tab移動など)のときだけ |

マウスでクリックしたボタンには枠が出ず、Tab キーで移動してきたときには枠が出る。フォーカスの**状態**は同じでも、**見た目**は操作に応じて変わります。フォーカスの見た目の指定は、原則 `:focus-visible` に寄せるのが現代の既定です。

## 3-3-2 枠は消すだけにしない

> **outline: noneで枠を消すなら、:focus-visibleで代わりの枠を必ず用意する**

「既定の枠がデザインに合わないので消してほしい」。この要望への答え方を、このトピックで確定させます。

フォーカスの枠を描いているのは **`outline`** というプロパティです。`outline: none` の1行で枠は消えますが、それ**だけ**で終わるとキーボード利用者が現在地を失う事故になります。入門で学んだとおりです。

答えは「消すな」ではありません。「**消すなら置き換える**」です。

```css
button {
  &:focus {
    outline: none;
  }

  &:focus-visible {
    outline: 3px solid var(--color-brand);
    outline-offset: 2px;
  }
}
```

- クリック時のじゃまな枠は消える(`:focus` で `none`)
- キーボード操作では、ブランド色のはっきりした枠が出る(`:focus-visible` で上書き)

デザインの要望と操作性が、これで両立します。書き方にも注目してください。レッスン2-1の入れ子と `&`、レッスン1-2の色トークンが、そのまま実戦投入されています。

なお、実は `:focus-visible` だけ書けば十分な場面も多くあります。既定の枠は `:focus-visible` 相当のタイミングで出るブラウザーがほとんどだからです。上の形は「既定の枠を明示的に消したい」と言われたときの、安全の担保付きの答えです。

代わりの枠を `border` で描かないことも大事です。

- `outline` は**レイアウトに影響しません**。枠が出ても要素は動きません
- `border` は要素の一部なので、枠のぶんだけ要素が太って周りが動きます
- `outline-offset` を使うと、枠を要素から少し離して描けて、視認性が上がります

フォーカス表示は `outline` の仕事、と覚えてください。

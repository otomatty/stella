# 3-3-1
# :focus-visibleは必要なときだけ枠を出す

モダンCSS入門研修 — Module 3 / レッスン3-3

<!-- ノート: 仕上げの3本目はフォーカスです。入門で「消すな」と学んだ枠を、今度は上手に出します。 -->

---

## なぜ必要か

- クリックのたびにボタンへ枠が付いて、じゃまに見える
- かといって枠を消すと、キーボードで操作する人が現在地を見失う

<!-- ノート: つかみ。デザイン要望と操作性が正面衝突する、実務の頻出場面です。 -->

---

## 結論

**`:focus-visible`は、キーボード操作のようにフォーカスの枠が必要なときだけ当たる**

- **フォーカス** = いま操作対象になっている状態
- クリック直後のボタンには当たらず、Tab移動では当たる

<!-- ノート: 結論。「枠が必要な操作かどうか」をブラウザーが判断してくれます。 -->

---

## 最小のコード

```css
button:focus-visible {
  outline: 3px solid var(--color-brand);
}
```

- Tabで移動したときだけ、ブランド色の枠が付く

<!-- ノート: outlineはフォーカスの枠を描くプロパティ。レイアウトを動かさずに枠だけ足せます。 -->

---

## :focusとの違い

| | 当たる場面 |
| --- | --- |
| `:focus` | フォーカスされたら常に |
| `:focus-visible` | 枠の表示が必要な操作のときだけ |

<!-- ノート: 対比の枠。見た目の指定は原則focus-visibleに寄せる、が現代の既定です。 -->

# レッスン3-1 流体タイプ

## このレッスンの目標

- [ ] `font-size` を `vw` 単独で書いてはいけない理由を説明できる
- [ ] `clamp()` で画面幅に応じて滑らかに変わる文字サイズを書ける
- [ ] 本文の1行の長さを `max-inline-size` と `ch` で抑えられる

## 3-1-1 vwだけの文字サイズは拡大できない

> **font-sizeをvwだけで書くと、利用者が文字を拡大できなくなる**

広い画面では見出しを大きく、狭い画面では控えめに。この要望自体は正当です。CSS には画面幅に比例する単位 **`vw`**(画面幅の1/100)があるので、こう書きたくなります。

```css
h1 {
  font-size: 4vw;
}
```

画面幅1000pxなら40px、画面幅600pxなら24px。一見うまく動きます。しかしこの書き方には、見た目では気づきにくい重大な問題があります。

文字が小さくて読みにくい利用者は、ブラウザーの文字サイズ設定やズームで文字を**拡大**して読んでいます。ところが `vw` だけの文字サイズは**画面幅だけ**で決まるため、この操作がまったく効きません。設定をいくら上げても40pxのまま。拡大が必要な人にとって、読めないページになります。

直し方の方針は2つです。

- `vw` を**単独で**使うのをやめる
- 拡大に追従する単位(`rem` など)と**組み合わせる**

`vw` そのものが悪いのではなく、「だけ」が問題です。組み合わせるための道具が次のトピックです。

## 3-1-2 clamp()で下限と上限を決める

> **clamp()は最小・普段・最大の3つの値で、画面幅に応じて滑らかに変わる文字サイズを作る**

画面幅に合わせたい。拡大は壊したくない。小さすぎ・大きすぎの行き過ぎも止めたい。この3つを1行で満たすのが **`clamp()`**(挟む、の意)です。

```css
h1 {
  font-size: clamp(1.5rem, 1rem + 2vw, 2.5rem);
}
```

3つの値は、順に **最小・普段・最大** です。

| 位置 | 値 | 意味 |
| --- | --- | --- |
| 最小 | `1.5rem` | どんなに狭い画面でも、これより下がらない |
| 普段 | `1rem + 2vw` | ふだんの計算式。画面幅に応じて滑らかに変わる |
| 最大 | `2.5rem` | どんなに広い画面でも、これより上がらない |

こうして作る、画面幅に応じて滑らかに変わる文字サイズを **流体タイプ** と呼びます。境目でガクッと切り替わるのではなく、幅に連れて連続的に変わるのが特徴です。

前のトピックの問題がなぜ解決するのかも押さえておきましょう。`rem` は、入門のレッスン5-4で学んだとおり利用者の文字サイズ設定に比例する単位です。上の式は**3つの値すべてに `rem` が入っている**ので、設定を上げれば最小も普段も最大もそろって持ち上がります。`vw` は「普段」の式の中で幅への追従だけを受け持ちます。

真ん中の式を自分で設計するのは慣れが要りますが、まずは「両端は `rem`、真ん中は `rem + vw` の足し算」という形を守れば、拡大を壊さない流体タイプになります。

## 3-1-3 1行の長さはchで抑える

> **max-inline-sizeをchで指定すると、1行の文字数を読める長さに抑えられる**

文字サイズを整えたら、次は**1行の長さ**です。広い画面で本文が端から端まで伸びると、1行が100文字を超えることもあります。行が長すぎると目の移動距離が長くなり、次の行の頭を見失いやすくなります。

このとき考えたいのは「幅を何pxにするか」ではなく「**1行に何文字入るか**」です。文字数で幅を指定できる単位が **`ch`** です。

```css
p {
  max-inline-size: 60ch;
}
```

`ch` は、その書体の「0」の文字幅を1とする単位です。`60ch` はおよそ60文字ぶんの幅を意味します。レッスン2-2で学んだ `max-inline-size` と組むことで、「1行はおよそ60文字で頭打ち。狭い画面ではそのまま縮む」という指定になります。

`640px` のような固定値と比べた利点は、**文字サイズに追従する**ことです。

- `max-inline-size: 640px` — 利用者が文字を大きくすると、1行に入る文字数が減っていく
- `max-inline-size: 60ch` — 文字が大きくなれば幅も伸びて、1行の文字数が保たれる

流体タイプで文字サイズが動く前提なら、行の長さも `ch` で動くようにしておくのが自然な組み合わせです。目安は、英文で45〜75文字。日本語の全角文字は「0」より幅が広いので、`60ch` でおよそ35文字前後になります。見た目で読みやすい行数に調整してください。

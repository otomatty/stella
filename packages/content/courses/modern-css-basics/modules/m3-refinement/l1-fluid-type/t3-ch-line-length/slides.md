# 3-1-3
# 1行の長さはchで抑える

モダンCSS入門研修 — Module 3 / レッスン3-1

<!-- ノート: 文字サイズの次は、1行の長さです。読みやすさは行の長さでも決まります。 -->

---

## なぜ必要か

- 広い画面で本文が端から端まで伸びると、目の移動が長くて読みにくい
- 「幅を何pxにするか」ではなく「1行に何文字か」で決めたい

<!-- ノート: つかみ。横に長すぎる行は、次の行の頭を見失う原因になります。 -->

---

## 結論

**`max-inline-size`を`ch`で指定すると、1行の文字数を読める長さに抑えられる**

- **ch** = その書体の「0」の文字幅を1とする単位
- 文字数の感覚のまま、行の長さを指定できる

<!-- ノート: 結論。chはcharacterのch。フォントサイズを変えても文字数の意味が保たれます。 -->

---

## 最小のコード

```css
p {
  max-inline-size: 60ch;
}
```

- 1行がおよそ60文字ぶんで頭打ちになる
- 狭い画面ではそのまま縮む

<!-- ノート: maxなので、狭い画面を邪魔しません。英文で45〜75文字、日本語なら見た目で35文字前後が目安です。 -->

---

## pxで決めた場合との違い

- `640px` — 文字を大きくすると1行の文字数が減ってしまう
- `60ch` — 文字サイズに付いて幅も伸び、**文字数が保たれる**

<!-- ノート: 対比の枠。流体タイプと組むならch。文字が育てば行も育ちます。 -->

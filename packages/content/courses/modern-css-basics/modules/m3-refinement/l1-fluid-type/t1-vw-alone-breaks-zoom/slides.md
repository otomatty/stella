# vwだけの文字サイズは拡大できない

モダンCSS入門研修 — Module 3 / レッスン3-1

<!-- ノート: Module 3は仕上げの調整です。まず文字サイズ。便利そうで危ない書き方から入ります。 -->

---

## なぜ必要か

- 画面の広さに合わせて、見出しの文字も大きくしたい
- 画面幅に比例する単位があると聞くと、そのまま使いたくなる

<!-- ノート: つかみ。要望自体は正当です。ただし素朴にやると事故になります。 -->

---

## 結論

**`font-size`を`vw`だけで書くと、利用者が文字を拡大できなくなる**

- **vw** = 画面幅の1/100を表す単位
- 画面幅だけで文字サイズが決まり、**拡大**の操作を無視してしまう

<!-- ノート: 結論。ブラウザーの文字サイズ設定やズームで文字を大きくしている人の操作が効かなくなります。 -->

---

## 危ない例

```css
h1 {
  font-size: 4vw;
}
```

- 画面幅1000pxなら40px
- 利用者が文字を大きく設定しても、40pxのまま

<!-- ノート: 見た目は動いて見えるのが罠です。拡大が必要な利用者にとっては読めないページになります。 -->

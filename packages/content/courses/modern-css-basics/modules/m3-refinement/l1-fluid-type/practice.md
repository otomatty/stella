# レッスン3-1 演習 — 流体タイプ

対象トピック: 3-1-1 〜 3-1-3

## 手元で試す

`index.html` に見出しと長めの段落を用意します。

```html
<h1>研修ポータル</h1>
<p>
  この研修では、HTMLとCSSで作ったページを、現代の書き方で
  作り直します。トークン・入れ子・論理プロパティを使い、
  見た目だけを段階的に整えていきます。
</p>
```

`style.css` に次を足して保存し、再読み込みしてください。

```css
h1 {
  font-size: clamp(1.5rem, 1rem + 2vw, 2.5rem);
}

p {
  max-inline-size: 60ch;
}
```

ブラウザーの窓の幅を広げたり狭めたりして、見出しが滑らかに変わること、段落が一定の長さで頭打ちになることを確かめてください。書けたら、次の改造をしてみましょう。

1. `h1` を `font-size: 4vw;` に変え、ブラウザーの拡大(Ctrl/Cmd と +)をしても見出しがほとんど育たないことを確かめる(確かめたら clamp に戻す)
2. clamp の最大値 `2.5rem` を `2rem` に下げて、広い画面での頭打ちが下がることを確かめる
3. `60ch` を `30ch` に変えて、1行の文字数が半分ほどになることを確かめる(確かめたら戻す)

## 演習問題

### 問1(基本)

`clamp(1rem, 0.5rem + 1.5vw, 1.5rem)` の3つの値は、それぞれ何を表しますか。

### 問2(基本)

1行をおよそ40文字ぶんで頭打ちにする宣言を、論理プロパティで書いてください。

### 問3(応用)

`font-size: 5vw` がアクセシビリティ上問題になる理由を1文で説明してください。

### 問4(応用)

`max-inline-size` を `px` ではなく `ch` で書く利点を1文で説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

順に、最小値(これより下がらない)・普段の計算式(画面幅で滑らかに変わる)・最大値(これより上がらない)です。

</details>

<details>
<summary>問2の解答例</summary>

```css
max-inline-size: 40ch;
```

`ch` は文字数の感覚で幅を書ける単位です。

</details>

<details>
<summary>問3の解答例</summary>

文字サイズが画面幅だけで決まり、利用者がブラウザーの設定やズームで文字を拡大しても反映されないからです。

</details>

<details>
<summary>問4の解答例</summary>

文字サイズを変えると幅も追従するので、1行に入る文字数が保たれるからです。

</details>

## 確認クイズ

### Q1. `vw` はどんな単位ですか。

- A. 画面幅の1/100
- B. 親要素の幅の1/100
- C. 文字サイズ設定の1/100

<details>
<summary>答え</summary>

**A** — viewport width の略で、画面(ビューポート)の幅に比例します。

</details>

### Q2. `font-size` を `vw` 単独で書いたときに起きる問題はどれですか。

- A. 画面を狭めると文字が消える
- B. 利用者の拡大操作が効かなくなる
- C. フォントの種類が変わってしまう

<details>
<summary>答え</summary>

**B** — 画面幅だけでサイズが決まるため、文字サイズ設定やズームに追従しません。

</details>

### Q3. `clamp(1.5rem, 1rem + 2vw, 2.5rem)` で、広い画面での上限になる値はどれですか。

- A. 1.5rem
- B. 1rem + 2vw
- C. 2.5rem

<details>
<summary>答え</summary>

**C** — 3つ目が最大値です。並びは最小・普段・最大の順です。

</details>

### Q4. clamp の式で拡大が効くのはなぜですか。

- A. clamp が拡大を検知して切り替えるから
- B. 値に rem が入っていて、文字サイズ設定に比例して持ち上がるから
- C. vw が拡大率も含んで計算されるから

<details>
<summary>答え</summary>

**B** — rem は利用者の文字サイズ設定に比例します。3つの値すべてに rem を入れるのが基本形です。

</details>

### Q5. `1ch` の基準はどれですか。

- A. その書体の「0」の文字幅
- B. 全角文字1文字の幅
- C. 画面幅の1/100

<details>
<summary>答え</summary>

**A** — ch はその書体の「0」の幅を1とします。日本語の全角文字はそれより広いので、60chはおよそ35文字前後です。

</details>

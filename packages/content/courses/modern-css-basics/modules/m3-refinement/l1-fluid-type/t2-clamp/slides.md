# clamp()で下限と上限を決める

モダンCSS入門 — Module 3 / レッスン3-1

---

## なぜ必要か

- 画面幅に合わせたい、でも拡大は壊したくない
- 小さすぎ・大きすぎの行き過ぎも止めたい

<!-- ノート: つかみ。前トピックの要望をあきらめずに、安全に実現します。 -->

---

## 結論

**`clamp()`は最小・普段・最大の3つの値で、画面幅に応じて滑らかに変わる文字サイズを作る**

- こうして作る文字サイズを **流体タイプ** と呼ぶ
- 真ん中にvwを含む式、両端にremを置くのが基本形

<!-- ノート: 結論。clampは「挟む」という意味。行き過ぎを両側から止めます。 -->

---

## 最小のコード

```css
h1 {
  font-size: clamp(1.5rem, 1rem + 2vw, 2.5rem);
}
```

- 狭い画面でも1.5remより下がらない
- 広い画面でも2.5remより上がらない

<!-- ノート: 真ん中の 1rem + 2vw が普段の計算式。remの下駄があるので、拡大にも追従します。 -->

---

## なぜ拡大が効くのか

- remは利用者の文字サイズ設定に比例する単位
- 3つの値**すべてにremが入っている**ので、設定を上げれば全体が持ち上がる

<!-- ノート: vw単独との違いはここ。remを混ぜることが「拡大できる」ことの正体です。 -->

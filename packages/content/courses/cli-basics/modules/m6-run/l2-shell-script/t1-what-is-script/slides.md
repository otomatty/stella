- **シェルスクリプト** — コマンドを並べたファイル。拡張子は `.sh` が慣習

## 打っていたものを、そのまま書く

```bash
# backup.sh という名前で保存する
mkdir -p backup
cp config.json backup/
echo "バックアップしました"
```

- 中身は、いつも打っているコマンドそのまま
- 順番に上から実行される

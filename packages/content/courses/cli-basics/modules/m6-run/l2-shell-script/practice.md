# レッスン6-2 演習 — シェルスクリプトの初歩

対象トピック: 6-2-1 〜 6-2-4

## 手元で試す

練習用の場所を作り、最初のスクリプトを書きます。

```bash
mkdir -p ~/cli-practice/scripts
cd ~/cli-practice/scripts

cat > hello.sh <<'SH'
#!/bin/bash
echo "はじめてのスクリプト"
SH
```

そのまま実行しようとすると失敗します。権限を付けてから実行してください。

```bash
./hello.sh          # => Permission denied
chmod +x hello.sh
./hello.sh          # => はじめてのスクリプト
ls -l hello.sh      # x が付いたことを確かめる
```

引数を受け取るスクリプトを書きます。

```bash
cat > greet.sh <<'SH'
#!/bin/bash
echo "$1 さん、おはようございます"
SH
chmod +x greet.sh
./greet.sh 佐藤
./greet.sh          # 引数なし。$1 が空になる
```

最後に、`&&` と `;` の違いを確かめます。

```bash
cd /nosuchdir && echo "進んだ"    # 何も出ない(左が失敗した)
cd /nosuchdir ; echo "進んだ"     # 「進んだ」が出てしまう
```

## 演習問題

### 問1(基本)

`backup.sh` を実行しようとしたら `Permission denied` と表示されました。実行できるようにするコマンドを書いてください。

### 問2(基本)

スクリプトの中で、1つ目の引数を受け取るにはどう書きますか。

### 問3(応用)

次の2行の違いを説明してください。どちらが安全ですか。

```bash
cd /backup && rm old.log
cd /backup ; rm old.log
```

### 問4(応用)

`./backup.sh` のように `./` を付けて実行する必要があるのはなぜですか。レッスン5-1で学んだ内容を使って説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```bash
chmod +x backup.sh
```

テキストファイルには既定で実行権限がありません。`chmod +x` で実行してよいという印を付けます。`ls -l` で `x` が付いたことを確認できます。

</details>

<details>
<summary>問2の解答例</summary>

`$1` と書きます。

渡された引数は順番に `$1` `$2` と受け取れます(位置パラメータ)。引数が渡されなければ空になります。

</details>

<details>
<summary>問3の解答例</summary>

- `&&` は、左の `cd` が成功したときだけ `rm` を実行します。
- `;` は、`cd` が失敗しても `rm` を実行します。

安全なのは `&&` です。`;` では、移動できずに別のディレクトリにいるまま削除が走り、消すつもりのなかったファイルを消す危険があります。

</details>

<details>
<summary>問4の解答例</summary>

シェルはコマンドをPATHに並んだディレクトリから探しますが、カレントディレクトリはPATHに含まれていないためです。

`./backup.sh` と書くことで「いまいる場所にあるこのファイル」と場所を明示しています。

</details>

## 確認クイズ

### Q1. シェルスクリプトの説明として正しいものはどれですか。

- A. 実行したいコマンドを上から順に書いたテキストファイル
- B. シェル専用の特別なプログラミング言語で書いた設定ファイル
- C. コマンドの実行結果を保存したファイル

<details>
<summary>答え</summary>

**A** — 中身はいつも打っているコマンドそのままで、上から順に実行されます。

</details>

### Q2. `Permission denied` と表示されたスクリプトを実行できるようにするコマンドはどれですか。

- A. `chmod +x script.sh`
- B. `touch script.sh`
- C. `export script.sh`

<details>
<summary>答え</summary>

**A** — `chmod +x` で実行権限を付けます。`ls -l` の `x` がその印です。

</details>

### Q3. スクリプトに渡した1つ目の引数を受け取る書き方はどれですか。

- A. `$0`
- B. `$1`
- C. `$ARG`

<details>
<summary>答え</summary>

**B** — 渡された順に `$1` `$2` で受け取ります(位置パラメータ)。

</details>

### Q4. `cd /backup && rm old.log` の説明として正しいものはどれですか。

- A. `cd` が成功したときだけ `rm` を実行する
- B. `cd` の成否にかかわらず `rm` を実行する
- C. `cd` と `rm` を同時に実行する

<details>
<summary>答え</summary>

**A** — `&&` は左が成功したときだけ右へ進みます。成否は終了ステータス(成功は0)で判断されます。

</details>

### Q5. 消す・上書きする操作をスクリプトに書くとき、推奨される書き方はどれですか。

- A. `;` でつないで、必ず順に実行されるようにする
- B. `&&` でつないで、前の処理が成功したときだけ実行されるようにする
- C. 1行にまとめず、必ず別々のスクリプトに分ける

<details>
<summary>答え</summary>

**B** — `;` は失敗しても次へ進むため、意図しない対象を消す事故につながります。危険な操作ほど `&&` を使います。

</details>

# 6-2-2
# 実行権限を付けて動かす

コマンドライン入門 — Module 6 / レッスン6-2

<!-- ノート: 「Permission denied」で止まる定番の壁です。理由まで理解させます。 -->

---

## なぜ必要か

- スクリプトを書いて実行したら `Permission denied` と言われた
- ファイルはあるのに、なぜ動かないのか分からない

<!-- ノート: つかみ。書けたのに動かない、という段階で多くの人が止まります。 -->

---

## 結論

**スクリプトはchmod +xで実行権限を付けると、コマンドとして実行できる**

- **実行権限** — そのファイルを実行してよいという印
- **chmod** — 権限を変えるコマンド

<!-- ノート: 結論を先に言い切ります。テキストファイルは既定では実行できない、が前提です。 -->

---

## 権限を付けて実行する

```bash
chmod +x backup.sh    # 実行権限を付ける
./backup.sh           # 実行する(./ が要る)

ls -l backup.sh
# => -rwxr--r--   ← x が実行権限の印
```

- 1行目に `#!/bin/bash`(**シバン**)を書くと、どのシェルで動かすかを指定できる

<!-- ノート: ./ が要る理由は「カレントディレクトリは PATH に無いから」です。5-1 とつながります。 -->

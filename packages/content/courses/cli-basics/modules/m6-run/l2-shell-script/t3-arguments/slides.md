## なぜ必要か

- 対象のファイル名だけが違う、ほぼ同じスクリプトが増えていく
- 名前を変えるたびにファイルを開いて書き換えている

<!-- ノート: つかみ。コピーして1行だけ直したスクリプトが並ぶ、という状況を示します。 -->

---

## 結論

**スクリプトに渡した引数は、中では $1 $2 の順で受け取れる**

- **位置パラメータ** — 渡された引数を順番で受け取る `$1` `$2` などの名前

<!-- ノート: 結論を先に言い切ります。0-1-4 で学んだ引数が、スクリプト側でどう見えるかという話です。 -->

---

## 渡した順に $1 $2

```bash
# greet.sh
echo "$1 さん、おはようございます"
```

```bash
./greet.sh 佐藤
# => 佐藤 さん、おはようございます
```

- 引数が渡されないと `$1` は空になる

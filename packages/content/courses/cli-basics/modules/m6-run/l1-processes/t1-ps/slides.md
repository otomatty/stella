## なぜ必要か

- サーバーが重い。何が動いているのかを知りたい

## 結論

**実行中のプログラム1つ1つがプロセスで、psで一覧できる**

- **プロセス** — 実行中のプログラム。1つ1つに番号が振られる
- **ps** — process status の略

<!-- ノート: 結論を先に言い切ります。ファイルは置いてあるもの、プロセスは動いているものと対比します。 -->

---

## 動いているものを一覧する

```bash
ps
# =>   PID TTY          TIME CMD
# =>  4821 ttys000  0:00.03 -zsh

ps aux | grep node     # node で動いているものを絞り込む
```

- 全部は多すぎるので、`grep` で絞り込んで見るのが実務の定番

# レッスン6-1 演習 — プロセスを見る・止める

対象トピック: 6-1-1 〜 6-1-3

## 手元で試す

まず、いま動いているものを見ます。

```bash
ps              # 自分のターミナルで動いているもの
ps aux | head   # 全部は多いので先頭だけ
```

次に、止まらないコマンドを動かして `Ctrl+C` で止めます。

```bash
sleep 100       # プロンプトが戻らない
# Ctrl+C を押す → プロンプトが戻る
```

最後に、`kill` で止める練習をします。別のターミナルを開くか、次の手順で試してください。

```bash
sleep 300 &     # 末尾の & で後ろで動かす(プロンプトが戻る)
ps aux | grep sleep
# => sato  5120  ... sleep 300
kill 5120       # 表示された PID を指定する
ps aux | grep sleep   # 消えたことを確かめる
```

> `&` は「後ろで動かす」書き方です。この演習で `kill` の対象を作るために使っています。

## 演習問題

### 問1(基本)

いま動いているプロセスのうち、`node` を含むものだけを表示するコマンドを書いてください。

### 問2(基本)

`tail -f app.log` を実行したままプロンプトが戻りません。どうすれば止められますか。

### 問3(応用)

ターミナルを閉じてしまったため `Ctrl+C` が押せない状態で、残ったサーバーのプロセスを止めたい。手順を3ステップで書いてください。

### 問4(応用)

`kill` と `kill -9` の違いを1文で説明し、どちらを先に試すべきかを書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```bash
ps aux | grep node
```

`ps aux` は全プロセスを表示します。数が多いので、パイプで `grep` に渡して絞り込みます。

</details>

<details>
<summary>問2の解答例</summary>

`Ctrl+C` を押します。

手前で動いているプロセスに終了を伝え、プロンプトが戻ります。ターミナルの窓を閉じる必要はありません。

</details>

<details>
<summary>問3の解答例</summary>

1. `ps aux | grep <プロセス名>` で対象を探し、PIDを確認する
2. `kill <PID>` で終了を伝える
3. もう一度 `ps aux | grep <プロセス名>` で消えたことを確かめる

3ステップ目を省くと、止まったつもりで残っていることに気づけません。

</details>

<details>
<summary>問4の解答例</summary>

- 違い: `kill` は終了を伝える操作で、`kill -9` は問答無用で終わらせる強制的な操作です。
- 順番: まず `kill` を試します。`-9` は保存の途中でも終わらせるため、データが壊れることがあります。

</details>

## 確認クイズ

### Q1. プロセスの説明として正しいものはどれですか。

- A. 実行中のプログラム1つ1つのこと
- B. ディスクに保存されているファイルのこと
- C. コマンドの実行結果を保存する場所

<details>
<summary>答え</summary>

**A** — ファイルが置いてあるもの、プロセスが動いているものです。1つ1つにPIDという番号が振られます。

</details>

### Q2. 動いているプロセスから `node` を含むものだけを見たいときのコマンドはどれですか。

- A. `ps aux > node`
- B. `ps aux | grep node`
- C. `find . -name node`

<details>
<summary>答え</summary>

**B** — `ps aux` の出力をパイプで `grep` に渡して絞り込みます。`find` はファイルを名前で探すコマンドです。

</details>

### Q3. `Ctrl+C` の説明として正しいものはどれですか。

- A. いま手前で動いているプロセスに終了を伝える
- B. ターミナルの表示をコピーする
- C. 直前のコマンドを繰り返す

<details>
<summary>答え</summary>

**A** — 手前のプロセスに終了を伝え、プロンプトを取り戻します。

</details>

### Q4. `kill` を使う場面として最も適切なものはどれですか。

- A. 手前で動いているコマンドをすぐ止めたいとき
- B. ターミナルを閉じてしまい、残ったプロセスを止めたいとき
- C. ファイルを削除したいとき

<details>
<summary>答え</summary>

**B** — 手前にいないプロセスはPIDを指定して止めます。手前のものは `Ctrl+C` で足ります。ファイル削除は `rm` です。

</details>

### Q5. プロセスを `kill` で止めたあとに行うべきことはどれですか。

- A. すぐ次の作業に移る
- B. `ps` でもう一度探し、消えたことを確かめる
- C. ターミナルを再起動する

<details>
<summary>答え</summary>

**B** — 「調べて、止めて、確かめる」の3手順です。確認を省くと、止まっていないことに気づけません。

</details>

# 6-1-3
# killは番号を指定して止める

コマンドライン入門 — Module 6 / レッスン6-1

<!-- ノート: ポートが空かない、という定番のトラブルを自力で解けるようにする回です。 -->

---

## なぜ必要か

- 前に起動したサーバーが残っていて、ポートが使用中になっている
- そのターミナルは既に閉じてしまい、Ctrl+Cが押せない

<!-- ノート: つかみ。手前にいないプロセスは Ctrl+C では止められません。 -->

---

## 結論

**killは、PIDで指定したプロセスに終了を伝える**

- **PID** — プロセスに振られた番号(process ID)
- **kill** — 指定したPIDのプロセスに終了を伝える

<!-- ノート: 結論を先に言い切ります。名前は物騒ですが、やっていることは Ctrl+C と同じ「伝える」です。 -->

---

## 番号を調べてから止める

```bash
ps aux | grep node
# => sato  4821  ... node server.js
#           └ PID

kill 4821          # 終了を伝える
ps aux | grep node # 消えたか確かめる
```

- 止まらないときの `kill -9` は最終手段(保存されず終わることがある)

<!-- ノート: -9 を先に教えると乱用されます。まず kill、だめなら相談、という順にさせてください。 -->

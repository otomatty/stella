# 6-1-2
# Ctrl+Cで手前のプロセスを止める

コマンドライン入門 — Module 6 / レッスン6-1

<!-- ノート: 実務で1日に何度も使う操作です。知らないとターミナルを閉じるしかなくなります。 -->

---

## なぜ必要か

- 開発サーバーを起動したら、プロンプトが戻ってこない
- 止め方が分からず、ターミナルの窓ごと閉じてしまう

<!-- ノート: つかみ。窓を閉じる対処は、止まらないまま残ることもあり危ういと後で触れます。 -->

---

## 結論

**Ctrl+Cは、いま動いているプロセスに終了を伝えてプロンプトを取り戻す**

- **Ctrl+C** — 手前で動いているプロセスに「終わってください」と伝えるキー

<!-- ノート: 結論を先に言い切ります。強制ではなく「伝える」操作だという点が後の kill につながります。 -->

---

## 止めて、プロンプトを取り戻す

```bash
tail -f app.log      # ログを流し続ける。プロンプトが戻らない
# Ctrl+C を押す
# => プロンプトが戻る

sleep 100            # 100秒待つ
# Ctrl+C で待たずに終われる
```

- `tail -f` は追記を待ち続けるオプション。監視でよく使う

<!-- ノート: tail -f は実務で頻出です。止め方とセットで覚えると使い始められます。 -->

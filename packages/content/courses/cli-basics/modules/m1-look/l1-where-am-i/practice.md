# レッスン1-1 演習 — いまいる場所と移動

対象トピック: 1-1-1 〜 1-1-5

## 手元で試す

ターミナルを開いて、次の順に実行してください。結果を見ながら進めます。

```bash
pwd                 # いまいる場所を確かめる
ls                  # 中身を一覧する
ls -a               # 隠しファイルも含めて一覧する
ls -l               # 詳しい形式で一覧する
```

次に、練習用のディレクトリを作って移動します(作成コマンドはレッスン2-1で扱います。ここでは移動の練習に使うだけです)。

```bash
cd ~                # ホームへ移る
mkdir -p cli-practice/logs
cd cli-practice     # 中へ入る
pwd                 # 移れたか確かめる
cd logs
pwd
cd ..               # 1つ上へ戻る
pwd
cd ~                # ホームへ戻る
```

最後に、同じ場所を絶対パスと相対パスの両方で指定してみましょう。

```bash
cd ~
cd cli-practice/logs        # 相対パス
pwd                         # 出た文字列をコピーしておく
cd ~
cd <さっきコピーしたパス>     # 絶対パス。同じ場所に着く
```

## 演習問題

### 問1(基本)

`ls` を実行しても、あるはずの設定ファイルが表示されません。どのオプションを付ければ確認できますか。

### 問2(基本)

いまいる場所が `/Users/sato/projects/app` です。`cd ..` を実行した後のカレントディレクトリはどこですか。

### 問3(応用)

次の2行は、どちらも同じディレクトリへ移動しました。それぞれ絶対パス・相対パスのどちらか答え、見分けた理由も書いてください。

```bash
cd /Users/sato/projects
cd projects
```

### 問4(応用)

手順書に `cd /Users/tanaka/work` と書かれていました。自分の環境でそのまま実行すると失敗します。理由と対処を1文ずつで説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`-a` を付けて `ls -a` とします。

`.` で始まる隠しファイルは、`-a` を付けたときだけ表示されます。設定ファイルの多くはこの形なので、見当たらないときはまず `-a` を試します。

</details>

<details>
<summary>問2の解答例</summary>

`/Users/sato/projects` です。

`..` は親ディレクトリ(1つ上)を指します。`cd ../..` と書けば2つ上の `/Users/sato` に移ります。

</details>

<details>
<summary>問3の解答例</summary>

- `cd /Users/sato/projects` — 絶対パス
- `cd projects` — 相対パス

見分け方は「`/` で始まっているかどうか」です。絶対パスはどこから実行しても同じ場所を指し、相対パスはカレントディレクトリによって指す先が変わります。

</details>

<details>
<summary>問4の解答例</summary>

- 理由: 絶対パスに書かれた `tanaka` は手順書を書いた人のホームディレクトリの名前で、自分の環境には存在しないためです。
- 対処: 自分の環境のパスに読み替えます(`cd ~/work` のように `~` を使うと、誰の環境でも通ります)。

</details>

## 確認クイズ

### Q1. カレントディレクトリを確かめるコマンドはどれですか。

- A. `ls`
- B. `cd`
- C. `pwd`

<details>
<summary>答え</summary>

**C** — `pwd`(print working directory)がいまいる場所を表示します。`ls` は中身の一覧、`cd` は移動です。

</details>

### Q2. `ls -a` を使う場面として正しいものはどれですか。

- A. `.` で始まる隠しファイルも含めて見たいとき
- B. ファイルのサイズを見たいとき
- C. 別のディレクトリへ移動したいとき

<details>
<summary>答え</summary>

**A** — `-a` は隠しファイルも表示します。サイズや更新日時は `-l` です。

</details>

### Q3. `cd projects` を実行しましたが、画面には何も表示されませんでした。この状況の説明として正しいものはどれですか。

- A. コマンドが失敗している
- B. 成功している。コマンドラインでは成功時に何も表示しないことが多い
- C. 実行中で、まだ終わっていない

<details>
<summary>答え</summary>

**B** — 無言は成功のしるしです。失敗したときだけエラーが表示されます。不安なら `pwd` で確かめられます。

</details>

### Q4. 絶対パスの説明として正しいものはどれですか。

- A. `/` から始まり、どこで実行しても同じ場所を指す
- B. カレントディレクトリからの道順で書いたパス
- C. `~` で始まるパスだけを指す

<details>
<summary>答え</summary>

**A** — `/`(ルートディレクトリ)から書いた道順が絶対パスです。カレントディレクトリからの道順は相対パスです。

</details>

### Q5. `cp ~/memo.txt .` の末尾の `.` は何を指していますか。

- A. 隠しファイル
- B. ホームディレクトリ
- C. カレントディレクトリ

<details>
<summary>答え</summary>

**C** — `.` はいまいる場所を指します。この行は「ホームの memo.txt を、いまいる場所へコピーする」という意味です。

</details>

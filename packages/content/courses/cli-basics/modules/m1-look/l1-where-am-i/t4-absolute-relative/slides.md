# 絶対パスと相対パスの違い

コマンドライン入門 — Module 1 / レッスン1-1

## なぜ必要か

- 同僚に教わったコマンドを貼り付けたら、自分の環境では動かなかった
- 場所の書き方には2通りあり、意味が変わることを知らないと直せない

<!-- ノート: つかみ。写経が動かない経験を挙げます。ここで結論は言いません。 -->

---

## 結論

**絶対パスは / から書いた道順、相対パスはいまいる場所からの道順**

- **パス** — 場所を表す文字列
- **ルートディレクトリ** — いちばん外側の `/`。すべての出発点

<!-- ノート: 結論を先に言い切ります。住所と道案内のたとえが伝わりやすいです。 -->

---

## 同じ場所を2通りで書く

```bash
# いまいる場所が /Users/sato のとき

cd /Users/sato/projects   # 絶対パス: どこにいても同じ場所に着く
cd projects               # 相対パス: いまいる場所の中の projects
```

- 絶対パスは `/` で始まる。相対パスは `/` で始まらない
- 手順書に絶対パスがあるときは、自分の環境の名前に読み替える

<!-- ノート: 「/ で始まるかどうか」が唯一の見分け方だと強調します。 -->

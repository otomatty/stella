コマンドライン入門 — Module 1 / レッスン1-1

## なぜ必要か

- 手順書どおりに打ったのに `No such file or directory` と返ってくる
- ファイルが無いのではなく、自分が別の場所にいるだけ、ということが多い

<!-- ノート: つかみ。初心者が最初にぶつかるエラーの正体を、原因ではなく現象として挙げます。 -->

---

## 結論

**シェルには「いまいるディレクトリ」があり、pwdで確かめられる**

- **ディレクトリ** — フォルダのこと。コマンドラインではこう呼ぶ
- **カレントディレクトリ** — シェルがいま作業の基準にしている場所

<!-- ノート: 結論を先に言い切ります。GUIの「いま開いているフォルダ」に当たるものが、目に見えない形で常にあると伝えます。 -->

---

## 最小のコマンド

```bash
pwd
# => /Users/sato/projects
```

- `pwd` は print working directory の略
- 迷ったらまずこれ。すべての操作はこの場所を基準に動く

<!-- ノート: 出力は環境で違います。自分の画面に出た文字列を読ませて、階層になっていることに気づかせます。 -->

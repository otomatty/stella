# 「.」「..」「~」が指す場所

コマンドライン入門 — Module 1 / レッスン1-1

<!-- ノート: 相対パスで頻出する3つの記号です。読めないと手順書が読めません。 -->

---

## なぜ必要か

- 手順書に `cd ..` や `cp file .` と書いてある
- 記号の意味が分からないと、何をする行なのか判断できない

<!-- ノート: つかみ。記号は調べにくいので、検索しても答えにたどり着きにくいと添えます。 -->

---

## 結論

**「.」はいまいる場所、「..」は1つ上、「~」はホームディレクトリを指す**

- **親ディレクトリ** — 1つ上のディレクトリ。`..` で表す
- **ホームディレクトリ** — 自分専用の作業場所。`~` で表す

<!-- ノート: 結論を先に言い切ります。3つとも「場所を短く書くための記号」だとまとめます。 -->

---

## 3つの記号を使う

```bash
pwd          # => /Users/sato/projects/app
cd ..        # => /Users/sato/projects   (1つ上へ)
cd ~         # => /Users/sato            (ホームへ)
cp ~/memo.txt .   # ホームのmemo.txtを、いまいる場所へコピー
```

- `..` は重ねられる(`cd ../..` で2つ上)

<!-- ノート: 最後の行の「.」が見落とされがちです。コピー先として今いる場所を指していると読ませます。 -->

---

# cdでカレントディレクトリを移す

コマンドライン入門 — Module 1 / レッスン1-1

<!-- ノート: 見る・移る・確かめるの3点セットの最後です。ここまでで基本の移動ができるようになります。 -->

---

## なぜ必要か

- 作業したいファイルは、たいてい別のディレクトリにある
- 遠くのファイルを毎回長い名前で指定するのは、打ち間違いのもと

<!-- ノート: つかみ。移動してから作業する方が短く安全だ、という後の結論につながる導入です。 -->

---

## 結論

**cdはカレントディレクトリを、指定した場所に移す**

- **cd** — change directory の略。引数に移動先を書く

<!-- ノート: 結論を先に言い切ります。移動しても画面には何も出ないのが普通だと添えます。 -->

---

## 移ったら必ず確かめる

```bash
cd projects     # projects の中へ移る(何も表示されない)
pwd             # => /Users/sato/projects
ls              # 移った先の中身を見る
```

- 成功すると何も言わない。無い場所を指定したときだけエラーが出る

<!-- ノート: 「無言の成功」はコマンドラインの流儀です。心配なら pwd で確かめる癖をつけさせます。 -->

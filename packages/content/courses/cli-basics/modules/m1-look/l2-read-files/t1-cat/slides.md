# catでファイルを丸ごと表示する

コマンドライン入門 — Module 1 / レッスン1-2

<!-- ノート: ファイルを開く道具の1つ目です。エディタを起動せずに中身を確かめる場面は現場で頻出します。 -->

---

## なぜ必要か

- 設定ファイルの中身を1行だけ確かめたい
- そのためにエディタを立ち上げるのは重いし、うっかり書き換える危険もある

<!-- ノート: つかみ。読むだけなら読む道具を使う、という考え方につなげます。 -->

---

## 結論

**catは、指定したファイルの中身をそのまま画面に出す**

- **cat** — ファイルの中身を表示する。書き換えはしない

<!-- ノート: 結論を先に言い切ります。読み取り専用なので安全だと添えます。 -->

---

## 最小のコマンド

```bash
cat memo.txt
# => ファイルの中身がそのまま表示される
```

- 引数にはパスを書く(`cat ~/memo.txt` のように離れた場所も指定できる)
- ファイルが無ければ `No such file or directory` が出る

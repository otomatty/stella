## なぜ必要か

- 取り込んだCSVが何件あるかを、目で数えるわけにはいかない
- 「増えたのか減ったのか」を件数で言えると、報告がぶれない

<!-- ノート: つかみ。件数の確認は実務で毎日発生する作業です。 -->

---

## 結論

**wcはファイルの行数・単語数・文字数を数える**

- **wc** — word count の略。数えるだけで中身は変えない

<!-- ノート: 結論を先に言い切ります。名前は単語数ですが、実務では行数の用途が多いと添えます。 -->

---

## 行数だけ見るなら -l

```bash
wc users.csv
# =>   120     360    5400 users.csv
#     行数    単語数  文字数

wc -l users.csv
# => 120 users.csv
```

- 見出し行があるときは、データの件数は行数から1を引いた数になる

<!-- ノート: 見出し行の1件ずれは現場でよくある誤りです。注意点として押さえます。 -->

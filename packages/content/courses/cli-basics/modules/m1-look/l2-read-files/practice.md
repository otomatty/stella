# レッスン1-2 演習 — ファイルの中身を見る

対象トピック: 1-2-1 〜 1-2-4

## 手元で試す

まず練習用のログファイルを作ります(中身を作るコマンドはレッスン4-1で扱うので、ここでは貼り付けて実行するだけで構いません)。

```bash
cd ~/cli-practice
seq 1 100 > numbers.txt      # 1から100までを1行ずつ書いたファイル
```

作ったファイルを、4つの道具で見比べてください。

```bash
cat numbers.txt        # 全部流れる。読み切れないことを体験する
head numbers.txt       # 先頭10行
tail numbers.txt       # 末尾10行
tail -n 3 numbers.txt  # 末尾3行
wc -l numbers.txt      # 行数を数える
less numbers.txt       # 開いたら、スペースで進み、/50 で検索し、q で抜ける
```

最後に、自分のホームにある設定ファイルを覗いてみましょう(無ければ飛ばして構いません)。

```bash
cd ~
ls -a                  # 「.」で始まるファイルを探す
cat .zshrc             # 見つけた設定ファイルを表示してみる
```

## 演習問題

### 問1(基本)

10万行あるログファイルの、いちばん新しい5行だけを見たいとき、どのコマンドを打ちますか。

### 問2(基本)

`less` でファイルを開きました。プロンプトに戻るにはどのキーを押しますか。

### 問3(応用)

`wc -l users.csv` の結果が `120` でした。このCSVの1行目は見出し行です。データは何件ですか。理由も書いてください。

### 問4(応用)

`cat` `head` `tail` `less` はどれもファイルを読む道具です。このうち「エラーの前後を、検索しながら読みたい」ときに最も向いているものはどれですか。理由も書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```bash
tail -n 5 app.log
```

ログは新しい記録が末尾に追加されるので、直近を見るときは `tail` を使います。`-n 5` で行数を指定します。

</details>

<details>
<summary>問2の解答例</summary>

`q` を押します。

`less` は読むための画面を開くので、終了操作が必要です。抜け方を知らないと閉じられなくなるため、開く前に覚えておきます。

</details>

<details>
<summary>問3の解答例</summary>

119件です。

`wc -l` はファイルの行数を数えるので、見出し行も1行として数に入ります。データの件数は、行数から見出しの1行を引いた数になります。

</details>

<details>
<summary>問4の解答例</summary>

`less` です。

`cat` は全部流れてしまい、`head` と `tail` は端しか見られません。`less` はスクロールして途中を読め、`/文字列` で検索もできます。

</details>

## 確認クイズ

### Q1. `cat` の説明として正しいものはどれですか。

- A. ファイルの中身をそのまま画面に表示する
- B. ファイルを編集できる状態で開く
- C. ファイルの行数だけを表示する

<details>
<summary>答え</summary>

**A** — `cat` は表示するだけで、書き換えはしません。行数を数えるのは `wc -l` です。

</details>

### Q2. ログの末尾3行だけを見たいときのコマンドはどれですか。

- A. `head -n 3 app.log`
- B. `tail -n 3 app.log`
- C. `wc -l app.log`

<details>
<summary>答え</summary>

**B** — `tail` が末尾、`head` が先頭です。`-n` で行数を指定します。

</details>

### Q3. `less` を終了してプロンプトに戻るキーはどれですか。

- A. `Esc`
- B. `x`
- C. `q`

<details>
<summary>答え</summary>

**C** — `q`(quit)で終了します。スペースで1画面進み、`/文字列` で検索できます。

</details>

### Q4. `wc -l` が返す数の説明として正しいものはどれですか。

- A. ファイルの単語数
- B. ファイルの行数
- C. ファイルの文字数

<details>
<summary>答え</summary>

**B** — `-l` は行数です。オプションを付けない `wc` は、行数・単語数・文字数の3つを並べて表示します。

</details>

### Q5. 10万行のログの中身を、途中まで読み進めながら確認したいときに最も向いている道具はどれですか。

- A. `cat`
- B. `less`
- C. `wc`

<details>
<summary>答え</summary>

**B** — `less` は1画面ずつ表示し、スクロールと検索ができます。`cat` は流れてしまい、`wc` は量を数えるだけです。

</details>

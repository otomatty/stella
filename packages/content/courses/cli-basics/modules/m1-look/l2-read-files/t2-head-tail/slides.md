# 長いファイルは端だけ見る

コマンドライン入門 — Module 1 / レッスン1-2

<!-- ノート: ログを読む現場で最も使う2つです。全部見る必要はほとんどありません。 -->

---

## なぜ必要か

- 10万行のログを `cat` したら、画面が一気に流れて何も読めなかった
- 知りたいのは、たいてい「いちばん新しい数行」だけ

<!-- ノート: つかみ。受講者が実際にやりがちな失敗から入ります。 -->

---

## 結論

**headは先頭から、tailは末尾から、指定した行数だけを取り出す**

- **head** — 先頭から。既定は10行
- **tail** — 末尾から。既定は10行

<!-- ノート: 結論を先に言い切ります。ログは新しいものが末尾に付くので tail が主役だと添えます。 -->

---

## 行数はオプションで指定する

```bash
head app.log          # 先頭10行
tail app.log          # 末尾10行
tail -n 3 app.log     # 末尾3行だけ
```

- 障害調査では、まず `tail` で直近のエラーを見るのが定石

<!-- ノート: -n の n は number です。行数を明示する癖をつけさせます。 -->

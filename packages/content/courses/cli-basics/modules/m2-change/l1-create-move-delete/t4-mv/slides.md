# 2-1-4
# mvは移動と改名を兼ねる

コマンドライン入門 — Module 2 / レッスン2-1

<!-- ノート: GUIでは別々の操作である「移動」と「名前の変更」が、CLIでは同じ1つのコマンドです。 -->

---

## なぜ必要か

- ファイルの名前を変えたい。移動もしたい
- GUIでは別の操作なので、コマンドも別だと思ってしまう

<!-- ノート: つかみ。GUIの経験がかえって邪魔をする場面です。 -->

---

## 結論

**mvはファイルを移す。同じ場所で名前だけ変えるのにも同じコマンドを使う**

- **mv** — move の略。`cp` と同じく「元 → 先」の順に書く

<!-- ノート: 結論を先に言い切ります。「行き先を書き換える操作」と考えると1つに見えると添えます。 -->

---

## 同じコマンドで2つの仕事

```bash
mv draft.md report.md        # 名前を変える(同じ場所)
mv report.md archive/        # 移動する(名前はそのまま)
mv report.md archive/old.md  # 移動しながら名前も変える
```

- `cp` と違い、元のファイルは残らない

<!-- ノート: 3行目で「移動と改名は同じ操作の2つの側面」だと腑に落ちます。 -->

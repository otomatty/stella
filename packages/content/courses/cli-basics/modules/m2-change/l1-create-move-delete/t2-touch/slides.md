# touchで空のファイルを作る

コマンドライン入門 — Module 2 / レッスン2-1

<!-- ノート: 中身を書く前に、まず置き場所としてのファイルを用意する操作です。 -->

---

## なぜ必要か

- 設定ファイルが「存在すること」自体が条件になっている場面がある
- 中身は後で書くとして、まず器だけ用意したい

<!-- ノート: つかみ。空ファイルに意味がある場面を挙げます(存在チェックをするツールは多い)。 -->

---

## 結論

**touchは、中身が空のファイルをその場に作る**

- **touch** — 無ければ作る。既にあれば中身はそのまま

<!-- ノート: 結論を先に言い切ります。既存ファイルを壊さない点が重要です。 -->

---

## 作って確かめる

```bash
touch notes.md
ls -l notes.md
# => -rw-r--r--  1 sato  staff  0  4 12 10:00 notes.md
#                          サイズ0 = 中身が空
```

- 既にあるファイルに `touch` しても、中身は消えない(更新日時だけ変わる)

<!-- ノート: サイズ 0 を指差して、空であることを確認させます。 -->

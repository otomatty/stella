## なぜ必要か

- 作業用の置き場所を、決まった形で用意したい
- サーバー上にはGUIが無い。フォルダ作成もコマンドで行う

<!-- ノート: つかみ。手元のPCなら右クリックで作れますが、サーバーではその選択肢が無いと伝えます。 -->

## 結論

**mkdirは新しいディレクトリを作る。-p を付けると途中の階層もまとめて作る**

- **mkdir** — make directory の略

<!-- ノート: 結論を先に言い切ります。-p は「親も作る」の意味だと添えます。 -->

---

## 途中の階層ごと作る

```bash
mkdir logs               # logs を作る
mkdir data/2026/04       # エラー: data も 2026 も無い
mkdir -p data/2026/04    # 途中の階層ごと作る
```

- 同じ名前が既にあると `File exists` で止まる(`-p` なら黙って何もしない)

<!-- ノート: -p は途中を作るだけでなく、既にある場合にエラーにしない性質もあります。手順書で多用される理由です。 -->

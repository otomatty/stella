# cpでファイルを複製する

コマンドライン入門 — Module 2 / レッスン2-1

## なぜ必要か

- 設定ファイルを直す前に、元の状態を残しておきたい
- 戻せる状態を作ってから触る、が現場の基本動作

<!-- ノート: つかみ。壊してから後悔する前に、複製を取る癖を付けさせます。 -->

---

## 結論

**cpは元を残したまま複製を作る。ディレクトリごと複製するには -r が要る**

- **cp** — copy の略。書く順番は「元 → 先」

<!-- ノート: 結論を先に言い切ります。引数の順番を取り違えると事故になるので、ここで強調します。 -->

---

## 元が先、コピー先が後

```bash
cp config.json config.json.bak   # 同じ場所に別名で複製
cp config.json backup/           # backup の中に同じ名前で複製
cp -r logs/ backup/              # ディレクトリごと複製するには -r
```

- コピー先に同じ名前があると、確認なしで上書きされる

# rmで消したものは戻らない

コマンドライン入門 — Module 2 / レッスン2-1

<!-- ノート: この研修でいちばん慎重に扱うトピックです。取り返しがつかない操作だと最初に伝えます。 -->

## なぜ必要か

- GUIで消したファイルは、ごみ箱から戻せる
- 同じつもりでコマンドを打つと、戻す手段が無いことに後で気づく

<!-- ノート: つかみ。GUIの安全網がここには無い、という一点に絞ります。 -->

---

## 結論

**rmで消したファイルはごみ箱に入らず、そのまま消える**

- **rm** — remove の略。確認も出ない

<!-- ノート: 結論を先に言い切ります。脅かすためではなく、確認の手順を身につけるためだと添えます。 -->

---

## 消す前に、対象を目で確かめる

```bash
ls old/            # 1. 何が入っているかを見る
rm old/memo.txt    # 2. ファイルを1つ消す
rm -r old/         # 3. ディレクトリごと消す(-r が要る)

rm -i old/memo.txt # 心配なときは -i。1件ずつ確認してくれる
```

- `rm -rf /` のような広い範囲の指定は、システムごと壊す

<!-- ノート: -i を勧めます。最後の行は「打ってはいけない例」として読み上げ、実演しないでください。 -->

## なぜ必要か

- 手順書の `ls -l /var/log` を、意味の切れ目が分からないまま写している
- 切れ目が読めないと、自分の環境に合わせて直すことができない

<!-- ノート: つかみ。写経はできるが応用できない状態を挙げます。ここで結論は言いません。 -->

---

## 結論

**コマンドは「コマンド名・オプション・引数」の3つの部品でできている**

- **コマンド名** — 何をする道具か
- **オプション** — どう動かすか(`-` で始まる)
- **引数** — 何に対して行うか

<!-- ノート: 結論を先に言い切ります。3つは半角スペースで区切る、という点も添えます。 -->

---

## 3つの部品を切り分ける

```bash
ls -l /var/log
# └┬ └┬ └────┬──
#  │  │      └ 引数    : /var/log を対象にする
#  │  └ オプション     : 詳しい形式で表示する
#  └ コマンド名        : 一覧する道具
```

- 引数を変えれば対象が変わり、オプションを変えれば見せ方が変わる

<!-- ノート: 同じコマンド名でも、部品を差し替えれば別の仕事になると伝えます。 -->

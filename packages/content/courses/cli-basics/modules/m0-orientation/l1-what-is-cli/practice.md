# レッスン0-1 演習 — コマンドラインとは何か

対象トピック: 0-1-1 〜 0-1-5

## 手元で試す

ターミナルを開くところから始めます。

- **macOS** — Launchpad から「ターミナル」を開く(またはSpotlightで `terminal`)
- **Windows** — スタートメニューから「Windows Terminal」を開く
- **VS Code を使う場合** — メニューの「ターミナル」→「新しいターミナル」

開いたら、次の順に打って結果を確かめてください。

```bash
echo hello        # 打った文字がそのまま返る。動作確認になる
sleep 5           # 5秒間プロンプトが戻らない。戻るまで待つ
echo hello        # 上キーを2回押すと、この行を打ち直さずに呼び戻せる
```

3行目は、実際に上キーで呼び戻して実行してみましょう。次に、`ec` まで打ってTabキーを押し、補完が効くことも確かめてください。

> **Windows で研修を進める場合** — 以降のレッスンで扱うコマンドはmacOS・Linuxのものです。Windowsでは Git Bash か WSL(Windows Subsystem for Linux)のターミナルを使うと、同じコマンドがそのまま動きます。どちらも用意できない場合は、講師に相談してください。

## 演習問題

### 問1(基本)

次のコマンドを「コマンド名」「オプション」「引数」に切り分けてください。

```bash
ls -a /etc
```

### 問2(基本)

ターミナルとシェルの役割の違いを、それぞれ1文で説明してください。

### 問3(応用)

コマンドを打ったあと、画面に何も出ないまま止まっているように見えます。「まだ実行中である」と判断できる材料は何ですか。

### 問4(応用)

`cat report-2026-04.csv` と打つ代わりに `cat rep` まででTabキーを押しました。何も補完されませんでした。考えられる原因を1つ挙げてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

- コマンド名: `ls`
- オプション: `-a`
- 引数: `/etc`

`-` で始まるものがオプション、対象を示すものが引数です。この形はすべてのコマンドに共通します。

</details>

<details>
<summary>問2の解答例</summary>

- ターミナル: 文字を表示し、キー入力を受け取る窓の役割のアプリです。
- シェル: 受け取った文字をコマンドとして解釈し、実行するプログラムです。

ターミナルを別のアプリに替えても、シェルが同じなら打つコマンドは変わりません。

</details>

<details>
<summary>問3の解答例</summary>

プロンプト(`$` や `%`)が戻ってきていないことです。

プロンプトが出ていない間は、前のコマンドがまだ動いています。この間にキーを打っても、シェルには届きません。

</details>

<details>
<summary>問4の解答例</summary>

いま見ている場所にそのファイルが無い(または名前が `rep` で始まっていない)ことが考えられます。

補完はシェルが実在する名前を探して埋める機能なので、補完されないこと自体が「その名前は無い」という手がかりになります。

</details>

## 確認クイズ

### Q1. GUIとコマンドラインの違いの説明として、最も適切なものはどれですか。

- A. コマンドラインの方が常に処理が速い
- B. GUIは画面から探して押し、コマンドラインは名前を打って頼む
- C. GUIでできることは、コマンドラインではできない

<details>
<summary>答え</summary>

**B** — 違いは頼み方です。速さではなく、操作を文字として残せることがコマンドラインの利点です。

</details>

### Q2. ターミナルとシェルの関係として正しいものはどれですか。

- A. ターミナルが文字をやり取りする窓で、シェルがその文字を解釈して実行する
- B. ターミナルとシェルは同じものの別名である
- C. シェルが窓を表示し、ターミナルがコマンドを実行する

<details>
<summary>答え</summary>

**A** — 窓がターミナル、中で解釈するのがシェルです。bash や zsh はシェルの種類です。

</details>

### Q3. プロンプトの役割として正しいものはどれですか。

- A. コマンドの実行結果を表示する
- B. シェルが入力を待っていることを示す
- C. エラーが起きたことを知らせる

<details>
<summary>答え</summary>

**B** — `$` や `%` が出ているときだけ、次のコマンドを受け付けます。出ていない間は前のコマンドが動いています。

</details>

### Q4. `cp -r src backup` の `-r` は3つの部品のうちどれですか。

- A. コマンド名
- B. オプション
- C. 引数

<details>
<summary>答え</summary>

**B** — `-` で始まるものがオプションで、動かし方を指定します。`cp` がコマンド名、`src` と `backup` が引数です。

</details>

### Q5. タブ補完について正しいものはどれですか。

- A. 打ちかけの名前の続きをシェルが埋める。実在するかの確認にもなる
- B. 直前に実行したコマンドを呼び戻す
- C. コマンドの使い方を説明する画面を開く

<details>
<summary>答え</summary>

**A** — 補完はシェルが実在する名前から埋めます。直前のコマンドを呼び戻すのは上キー(コマンド履歴)です。

</details>

# ターミナルとシェルは役割が違う

コマンドライン入門 — Module 0 / レッスン0-1

<!-- ノート: 「ターミナル」「シェル」「bash」が同じものの別名だと思われがちなので、ここで一度だけ切り分けます。 -->

---

## なぜ必要か

- 手順書に「ターミナルを開いて」「シェルで実行」「bash で叩く」と書いてある
- 同じことを言っているのか違うことなのか、判断できないと手が止まる

<!-- ノート: つかみ。現場の手順書は3つの言葉を混ぜて使います。読み解けるようにするのがこのトピックの目的です。 -->

---

## 結論

**ターミナルは文字をやり取りする窓、シェルは打った文字をコマンドとして解釈する係**

- **ターミナル** — 文字を表示し、キー入力を受け取るアプリ(窓)
- **シェル** — 受け取った文字を読んで、コマンドを実行するプログラム(中の人)

<!-- ノート: 窓と中の人、という比喩で覚えてもらいます。窓を替えても中の人は同じ、という話につなげます。 -->

---

## 窓と中の人は取り替えられる

```text
[ターミナル]  Terminal.app / Windows Terminal / VS Codeの統合ターミナル
     ↕ 文字
[シェル]      bash / zsh
     ↕ 実行
[コマンド]    ls / cp / grep ...
```

- **bash** と **zsh** は代表的なシェル。この研修はどちらでも同じように進められる
- ターミナルを替えても、打つコマンドは変わらない

<!-- ノート: macOSの既定はzsh、Linuxはbashが多い、という程度に触れます。どちらでも本研修の内容は同じだと安心させます。 -->

# レッスン5-1 演習 — 環境変数とPATH

対象トピック: 5-1-1 〜 5-1-4

## 手元で試す

自分の環境の値を見てみましょう。

```bash
echo $HOME        # ホームディレクトリ
echo $PATH        # コマンドを探す場所の一覧
echo $SHELL       # いま使っているシェル
echo HOME         # $ が無いとどうなるか確かめる
```

自分で設定して、引き継がれることを確かめます。

```bash
export GREETING="こんにちは"
echo $GREETING

bash -c 'echo $GREETING'   # 別のシェルを起動しても引き継がれる
```

コマンドの実体を突き止めます。

```bash
which ls
which grep
which nosuchcmd     # 何も出ない = PATH のどこにも無い
```

最後に、PATHの並びを読んでみてください。`:` で区切られた1つ1つがディレクトリです。

```bash
echo $PATH | tr ':' '\n'    # 1行に1つずつ表示する
```

## 演習問題

### 問1(基本)

環境変数 `HOME` の中身を表示するコマンドを書いてください。

### 問2(基本)

`echo $PATH` の結果に含まれる `:` は何を表していますか。

### 問3(応用)

ツールをインストールしたのに `command not found` と表示されました。考えられる原因を、PATHの観点から1つ説明してください。

### 問4(応用)

`node` コマンドが古いバージョンで動いているようです。どのファイルが実行されているかを確かめるコマンドと、その結果から何が分かるかを書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

```bash
echo $HOME
```

名前の前に `$` を付けると、シェルが値に置き換えてから `echo` に渡します。`$` が無いと `HOME` という文字がそのまま表示されます。

</details>

<details>
<summary>問2の解答例</summary>

ディレクトリの区切りです。

PATHは、コマンドを探すディレクトリを `:` でつないで並べた1つの文字列です。シェルは左から順に見ていきます。

</details>

<details>
<summary>問3の解答例</summary>

インストール先のディレクトリがPATHに含まれていないためです。

`command not found` は「入っていない」とは限らず、「入れた場所をシェルが探していない」場合にも出ます。`echo $PATH` で並びを確認します。

</details>

<details>
<summary>問4の解答例</summary>

```bash
which node
```

実際に実行されているファイルのパスが分かります。PATHの並び順で先に見つかった場所が返るので、意図しない場所の古いバージョンが使われていることが確認できます。

</details>

## 確認クイズ

### Q1. 環境変数の説明として正しいものはどれですか。

- A. シェルが持つ名前つきの値で、実行するコマンドにも引き継がれる
- B. ファイルの中にだけ保存される設定で、コマンドには渡らない
- C. コマンドの実行結果を保存する場所

<details>
<summary>答え</summary>

**A** — 実行するコマンドに引き継がれる点が要点です。だから設定をプログラムの外から渡せます。

</details>

### Q2. `echo $HOME` と `echo HOME` の違いとして正しいものはどれですか。

- A. どちらも同じ結果になる
- B. `$` を付けると値に置き換わり、付けないと文字がそのまま出る
- C. `$` を付けるとエラーになる

<details>
<summary>答え</summary>

**B** — `$` はシェルに「値へ置き換えてから渡せ」と伝える印です。付け忘れると名前がそのまま表示されます。

</details>

### Q3. 環境変数 `PATH` の役割はどれですか。

- A. カレントディレクトリを記録する
- B. シェルがコマンドを探すディレクトリの一覧
- C. ファイルの保存先を決める

<details>
<summary>答え</summary>

**B** — PATHに並んだディレクトリを順に見て、打たれたコマンドの実体を探します。

</details>

### Q4. `command not found` が出る原因として正しいものはどれですか。

- A. そのコマンドがPATHに並んだディレクトリのどこにも無い
- B. 必ずインストールされていない
- C. カレントディレクトリが間違っている

<details>
<summary>答え</summary>

**A** — インストール済みでも、その場所がPATHに含まれていなければ見つかりません。

</details>

### Q5. `which node` を実行して何も表示されませんでした。分かることはどれですか。

- A. `node` は正常に動作している
- B. `node` はPATHのどこにも見つからない
- C. `node` のバージョンが古い

<details>
<summary>答え</summary>

**B** — `which` はPATHを探して最初に見つかった場所を返します。何も出ないのは、どこにも無いということです。

</details>

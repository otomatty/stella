# 5-1-2
# echoで環境変数の中身を見る

コマンドライン入門 — Module 5 / レッスン5-1

<!-- ノート: 設定が効いていないときの切り分けは、まず値を見ることから始まります。 -->

---

## なぜ必要か

- 「環境変数を設定した」はずなのに、プログラムが古い値で動く
- そもそも何が入っているのかを見ないと、切り分けができない

<!-- ノート: つかみ。設定したつもりで違う値が入っている、という事故は頻出です。 -->

---

## 結論

**echo $名前 と打つと、その環境変数の中身が表示される**

- **echo** — 受け取った文字をそのまま出すコマンド
- `$` を付けると、シェルが名前を値に置き換えてから渡す

<!-- ノート: 結論を先に言い切ります。ここでも「シェルが手前で置き換える」構図が出てきます。 -->

---

## 見るのが $、設定するのが export

```bash
echo $HOME
# => /Users/sato

echo HOME       # $ を付け忘れると、ただの文字として出る
# => HOME

export API_URL="https://example.com"   # このシェルに設定する
echo $API_URL
```

<!-- ノート: $ の付け忘れは初心者が必ずやります。3行目の結果を見せて印象づけます。 -->

# 5-1-4
# whichでどれが実行されるか確かめる

コマンドライン入門 — Module 5 / レッスン5-1

<!-- ノート: 同じ名前のツールが複数入っている環境での切り分け方です。バージョン違いの事故に効きます。 -->

---

## なぜ必要か

- 新しいバージョンを入れたのに、古いバージョンが動いている
- 同じ名前のコマンドが、複数の場所に入っていることがある

<!-- ノート: つかみ。原因が分からないまま再インストールを繰り返す、という時間の浪費を挙げます。 -->

---

## 結論

**whichは、そのコマンド名で実際に実行されるファイルの場所を教えてくれる**

- **which** — PATHを上から探して、最初に見つかった場所を返す

<!-- ノート: 結論を先に言い切ります。PATH の並び順とセットで理解させます。 -->

---

## 実体の場所を突き止める

```bash
which ls
# => /bin/ls

which node
# => /usr/local/bin/node      ← このファイルが動いている

which nosuchcmd
# => (何も出ない。PATH のどこにも無い)
```

<!-- ノート: 何も出ないことが「PATH に無い」という診断結果になります。command not found と対応させます。 -->

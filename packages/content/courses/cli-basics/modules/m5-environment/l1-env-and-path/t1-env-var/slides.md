# 5-1-1
# 環境変数はシェルが覚えている値

コマンドライン入門 — Module 5 / レッスン5-1

<!-- ノート: 設定を渡すしくみの話です。開発でも運用でも避けて通れません。 -->

---

## なぜ必要か

- 接続先やAPIキーを、プログラムの中に直接書きたくない
- 環境ごとに違う値を、同じプログラムに渡したい

<!-- ノート: つかみ。ソースに書くと環境ごとに書き換えが必要になり、秘密の値も残ってしまいます。 -->

---

## 結論

**環境変数は、シェルが覚えていて、実行するコマンドにも引き継がれる名前つきの値**

- **環境変数** — シェルが持つ名前と値の組。大文字の名前が慣習

<!-- ノート: 結論を先に言い切ります。「引き継がれる」が普通の変数との違いです。 -->

---

## 値はシェルからコマンドへ渡る

```text
[シェル]  HOME=/Users/sato  LANG=ja_JP.UTF-8  PATH=...
    │
    │ コマンドを実行するとき、この値ごと渡す
    ▼
[コマンド]  受け取った値を見て動きを変える
```

- プログラムの中に書かずに、外から値を渡せる

<!-- ノート: 設定を外に出す考え方は、後のNode.jsやDockerの研修にもそのまま続きます。 -->

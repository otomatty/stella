# 5-1-3
# PATHはコマンドを探す場所の一覧

コマンドライン入門 — Module 5 / レッスン5-1

<!-- ノート: 「command not found」の正体を明かす回です。インストールしたのに使えない、を自力で解けるようにします。 -->

---

## なぜ必要か

- ツールをインストールしたのに `command not found` と言われる
- ファイルは確かにあるのに、なぜ見つからないのか分からない

<!-- ノート: つかみ。受講者がこの先必ず出会うエラーです。 -->

---

## 結論

**シェルは環境変数PATHに並んだディレクトリを順に見て、打たれたコマンドを探す**

- **PATH** — 探索するディレクトリを `:` で区切って並べた環境変数

<!-- ノート: 結論を先に言い切ります。コマンド名は魔法の言葉ではなく、ファイルの名前だと伝えます。 -->

---

## 並び順に上から探す

```bash
echo $PATH
# => /usr/local/bin:/usr/bin:/bin

# ls と打ったとき、シェルは順に見る
#   /usr/local/bin/ls  … 無い
#   /usr/bin/ls        … あった → これを実行
```

- 一覧のどこにも無ければ `command not found`

<!-- ノート: インストール先が PATH に入っていないだけ、というのがよくある原因です。 -->

# 3-1-3
# findで名前からファイルを探す

コマンドライン入門 — Module 3 / レッスン3-1

<!-- ノート: grep が中身、find が名前。2つの探し方を対にして覚えさせます。 -->

---

## なぜ必要か

- 「どこかにあるはずの設定ファイル」の置き場所が思い出せない
- 中身は分からないが、名前の一部は覚えている

<!-- ノート: つかみ。grep では解けない探し物であることに気づかせます。 -->

---

## 結論

**findは、指定したディレクトリの下から、名前の条件に合うファイルを探す**

- 書き方は `find 探す場所 -name 名前の条件`

<!-- ノート: 結論を先に言い切ります。探す場所を最初に書く点が grep と逆で、間違えやすいと添えます。 -->

---

## 場所が先、条件が後

```bash
find . -name "config.json"     # いまいる場所の下から探す
find . -name "*.log"           # 拡張子で探す
find logs -type f              # logs 配下のファイルだけ一覧する
```

- 見つかったものは **パス付き** で出るので、そのまま `cat` に渡せる

<!-- ノート: -type f はファイル、d はディレクトリです。使う場面は限られるので軽く触れる程度にします。 -->

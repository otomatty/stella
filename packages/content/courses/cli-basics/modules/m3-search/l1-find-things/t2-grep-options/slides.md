# 3-1-2
# grepのよく使う3つのオプション

コマンドライン入門 — Module 3 / レッスン3-1

<!-- ノート: grep は多機能ですが、実務で使うのはほぼこの3つです。範囲を絞って渡します。 -->

---

## なぜ必要か

- `grep error` では `ERROR` の行が見つからない
- 見つけた行が「何行目か」が分からないと、直しに行けない

<!-- ノート: つかみ。素の grep だけでは足りない場面を2つ挙げます。 -->

---

## 結論

**-i で大文字小文字を無視し、-n で行番号を出し、-r でディレクトリ全体を探せる**

- **再帰的** — ディレクトリの中の、そのまた中まで順にたどること

<!-- ノート: 結論を先に言い切ります。3つとも他のコマンドでも同じ意味で使われる記号です。 -->

---

## 3つを使い分ける

```bash
grep -i error app.log       # ERROR も Error も拾う
grep -n error app.log       # => 42:2026-04-12 10:03 error: timeout
grep -r error logs/         # logs 配下のファイルを全部探す
grep -rn error logs/        # 重ねて指定できる
```

<!-- ノート: -rn の組み合わせが現場で最頻出です。ファイル名と行番号が同時に出ます。 -->

# 「>>」で消さずに追記する

コマンドライン入門 — Module 4 / レッスン4-1

---

## なぜ必要か

- 毎日の実行結果を、同じファイルに積み上げていきたい
- `>` で書くと、昨日までの記録が毎回消えてしまう

<!-- ノート: つかみ。前トピックの性質が困る場面として自然につなげます。 -->

---

## 結論

**「>>」は、既にある内容を残したまま末尾に書き足す**

- **追記** — 末尾に書き足すこと。`>` は置き換え、`>>` は追記

<!-- ノート: 結論を先に言い切ります。> が1つか2つかだけの違いだと強調します。 -->

---

## 1文字違いで結果が変わる

```bash
echo "1回目" > log.txt    # log.txt は「1回目」だけ
echo "2回目" > log.txt    # 「2回目」に置き換わる(1回目は消える)
echo "3回目" >> log.txt   # 「2回目」の下に足される

cat log.txt
# => 2回目
# => 3回目
```

<!-- ノート: 実演すると一目で伝わります。消えた1回目に注目させてください。 -->

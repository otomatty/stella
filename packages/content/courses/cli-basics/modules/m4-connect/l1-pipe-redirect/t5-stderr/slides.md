# 4-1-5
# エラーは別の口から出ている

コマンドライン入門 — Module 4 / レッスン4-1

<!-- ノート: 「ファイルに保存したのにエラーだけ画面に残る」という不思議の答えです。 -->

---

## なぜ必要か

- 結果をファイルに書き出したのに、エラーだけ画面に出てきた
- 保存したファイルを見ると、そのエラーが入っていない

<!-- ノート: つかみ。理由が分からないと「壊れた」と感じる現象です。 -->

---

## 結論

**エラーメッセージは標準出力ではなく標準エラー出力に流れる**

- **標準エラー出力** — 異常を知らせるための、もう1つの出口

<!-- ノート: 結論を先に言い切ります。出口が2つある理由(結果と異常を混ぜない)まで添えます。 -->

---

## 出口は2つある

```bash
cat nofile.txt > out.txt
# => cat: nofile.txt: No such file or directory   ← 画面に残る
cat out.txt                                       # 空。エラーは入っていない

cat nofile.txt > out.txt 2> error.txt   # エラーだけ error.txt へ
```

- `2>` は標準エラー出力の行き先を変える書き方

<!-- ノート: 番号の 2 は標準エラー出力を指す固定の番号です。暗記でよいと伝えます。 -->

---

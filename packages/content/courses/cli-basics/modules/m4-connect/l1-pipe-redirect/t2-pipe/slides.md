# パイプで出力を次のコマンドに渡す

コマンドライン入門 — Module 4 / レッスン4-1

<!-- ノート: コマンドラインが強力だと言われる理由そのものです。1つずつは単純な道具がつながります。 -->

---

## なぜ必要か

- エラー行を `grep` で取り出した。その件数が知りたい
- いったんファイルに保存して `wc` で数えるのは、手間が多い

<!-- ノート: つかみ。2つの道具を続けて使いたい場面を具体的に示します。 -->

---

## 結論

**「|」は、左のコマンドの標準出力を右のコマンドの標準入力につなぐ**

- **パイプ** — コマンドどうしをつなぐ縦棒 `|`

<!-- ノート: 結論を先に言い切ります。管でつなぐ、という名前のとおりのイメージです。 -->

---

## 道具をつないで1行で解く

```bash
grep error app.log | wc -l
# => 12          エラー行の件数

grep -r error logs/ | head -n 5
# => 最初の5件だけ表示
```

- いくつでもつなげる(`... | grep ... | wc -l`)

<!-- ノート: 小さな道具を組み合わせる、というのがコマンドラインの設計思想だと補足します。 -->

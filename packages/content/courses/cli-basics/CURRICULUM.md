## 講座の概要

- **到達目標 (canDo)**: ターミナルでファイル操作・プロセス確認・コマンドの組み合わせができる

- **後続**: `node-basics`(バックエンドの背骨)と `docker-basics`
- **参考にしたロードマップ**: roadmap.sh のバックエンドロードマップ
- **コード演習**: 配線していません。ターミナル操作を採点する基盤(サンドボックスと judge)が現在の採点基盤(`@falcon/code-runner` は JavaScript / TypeScript / SQL / 擬似言語)に無いためです。手を動かす部分は各レッスンの `practice.md`「手元で試す」に置き、LMS 上はスライド → まとめ → 確認クイズだけで完走できます
- **対象環境**: macOS / Linux のシェル(bash / zsh)。Windows の受講者は Git Bash か WSL を使えば同じコマンドがそのまま動きます(レッスン0-1の演習に案内を置いています)

## 設計の方針

- **コマンドの暗記講座にしない。** 0-1-4 で「コマンド名・オプション・引数」という共通の形を先に渡し、以降のコマンドはその形の実例として扱います
- **シェルが手前で仕事をしている、という視点を通す。** ワイルドカードの展開(3-1-4)、`$` による値の置き換え(5-1-2)、PATH からの探索(5-1-3)は同じ構図です。記号の暗記ではなく、誰が処理しているかで説明します
- **取り返しのつかない操作は、確認の手順とセットで教える。** `rm`(2-1-5)は「消す前に `ls` で確かめる」、`kill`(6-1-3)は「調べて・止めて・確かめる」を本文に入れています。`rm -rf` と `kill -9` は打たせません
- **到達点は自動化。** M6 でスクリプト化まで進み、`&&` で失敗時に止める書き方(6-2-4)で締めます

## 対象外

次の内容はこの講座では扱いません。

- **テキストエディタ(vim / nano)の操作** — ファイルの編集は VS Code で行う前提です
- **権限の詳細(`chmod 755` の数字、所有者とグループ)** — 6-2-2 で実行権限に触れるだけに留めます
- **sed / awk による本格的なテキスト処理** — `grep` と `wc` までを扱います
- **ジョブ制御(`fg` / `bg` / `jobs`)** — 6-1 の演習で `&` を使いますが、体系的には扱いません
- **`if` / `for` を使ったスクリプトの制御構造** — 6-2 はコマンドを並べる段階までです
- **SSH によるリモート接続** — 接続先での操作は本講座の範囲外です

# 3-1-2
# Skillsは進め方の作り置き

Claudeチャット入門 — Module 3 / レッスン3-1

<!-- ノート: 材料の次は進め方です。ここも中身は「何のためにあるか」だけを扱います。 -->

---

## なぜ必要か

- 同じ体裁の資料を作るたび、書き方の説明を依頼に書き足している
- 説明する人が変わると、出てくるものの形もそろわなくなる

<!-- ノート: つかみ。手順や制約を毎回書くのは、地味に時間を取られます。ここで結論は言わない。 -->

---

## 結論

**Skillsは、毎回説明していた進め方をClaudeが読める形で作り置きする仕組みです**

- **手順** — 進め方の段取り。M1で扱った語です
- **Skills** — 進め方を書いて置いておき、必要なときに使わせる仕組み

<!-- ノート: 結論を先に言い切ります。手順はM1の復習なので1行で流します。M2の指示の固定も同じ悩みへの答えでしたが、置き場所が違うという点は次のトピックで扱います。 -->

---

## 作り置きにできるものの例

```text
報告書の体裁    → 見出しの並びと分量の決まり
見積もりの出し方 → 数える単位と丸め方
レビューの観点  → 毎回見るべき項目の一覧
```

<!-- ノート: 3つとも、いつも同じ形で説明していた内容です。人ではなく仕組みの側に置くと、書き手が変わってもそろいます。 -->

---

## 毎回書く場合との違い

| | 依頼に毎回書く | Skillsに置く |
| --- | --- | --- |
| 書く手間 | 依頼のたび | 作るときだけ |
| そろい方 | 書いた人しだい | 読ませた分だけそろう |
| 直したいとき | 次の依頼から直す | 置いたものを直す |

<!-- ノート: 対比枠。直したいときの列が要点です。一か所を直せば以降の依頼に効きます。作り方や置き場所は後続の講座で扱います。 -->

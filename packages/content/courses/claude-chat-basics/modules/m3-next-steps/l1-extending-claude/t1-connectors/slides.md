# 3-1-1
# コネクタは外の道具につなぐ

Claudeチャット入門 — Module 3 / レッスン3-1

<!-- ノート: ここからM3です。操作は扱わず、次に何があるかだけを紹介します。まずは材料の届け方を広げる仕組みから。 -->

---

## なぜ必要か

- 予定表や社内の資料を、毎回コピーして会話に貼っている
- 元の資料が更新されるたび、貼り直しからやり直しになる

<!-- ノート: つかみ。今回の対象は渡さないと知らない相手なので、材料を運ぶ手間が毎回かかります。ここで結論は言わない。 -->

---

## 結論

**コネクタは、会話の外にある道具やデータをClaudeの材料にする仕組みです**

- **材料** — こちらが会話に渡した情報。M0で扱った語です
- **ツール** — Claudeが会話の外に対して使える道具
- **コネクタ** — 外の道具やデータの置き場をつなぐ仕組み

<!-- ノート: 結論を先に言い切ります。材料はM0の復習なので1行で流し、残りはつなぐ意味の説明に使います。 -->

---

## つなぐ先の例

```text
予定表        → 今週の空き時間を材料にする
社内の資料置き場 → 該当ページを材料にする
課題の一覧    → 担当中の項目を材料にする
```

<!-- ノート: いずれも中身は自分で貼っても渡せます。違うのは、こちらが運ばなくてよくなる点です。具体的な連携先の名前は変わるので挙げません。 -->

---

## 貼って渡す場合との違い

| | 会話に貼る | コネクタでつなぐ |
| --- | --- | --- |
| 材料の運び役 | 自分 | 仕組み |
| 更新への追従 | 貼り直す | つないだ先を見る |
| 準備の手間 | 毎回かかる | 最初だけかかる |

<!-- ノート: 対比枠。最初だけ手間がかかるという点は、このあとの「いつ広げるか」に効いてきます。設定手順はこの講座では扱いません。 -->

# レッスン3-2 演習 — どこに進むかを選ぶ

対象トピック: 3-2-1 〜 3-2-3

## 手元で試す

このレッスンで練習するのは操作ではなく判断です。紙とペン、または手元のメモ帳だけで進められます。

まず、自分の業務から仕事を3つ書き出します。粒は「障害の一次調査」くらいで構いません。できれば、量も対象もばらばらな3つを選んでください。

```text
例
1. エラーメッセージの原因を知りたい
2. 過去の議事録20本から決定事項を拾う
3. 既存の機能に手を入れる前に影響範囲を調べる
```

書き出せたら、次の3つをやってみましょう。

1. 3つそれぞれについて、**その仕事がいまどこに置かれているか** を書く(チャットに貼れる断片 / 手元のフォルダや資料の一式 / 手元のリポジトリの中)
2. 1で書いた置き場所から、進める先を選ぶ(チャット / Cowork / Claude Code)
3. 3つのうち1つを選び、**自分でやる部分** と **渡す部分** の線を引く。線を引いた理由も一言添える

最後に、3つすべてについて「出したものを誰がどう確かめるか」を1行で書いてください。進める先が変わっても、この行の答えは変わらないはずです。

余力があれば、claude.ai を開いて、1で「貼れる断片」に分類した仕事を実際に頼んでみてください。貼れる範囲に収まったかどうかを、自分の手で確かめられます。**アカウントが無い人は、この段落を飛ばして構いません。** 上の分類だけで演習は成立します。

## 演習問題

### 問1(基本)

次の3つの仕事を、チャット・Cowork・Claude Codeのどれで進めるか選び、理由を1文ずつ添えてください。

1. エラーメッセージを1つ貼って、考えられる原因を挙げてもらう
2. 手元のリポジトリで、ある関数を変えたときの影響範囲を調べる
3. 手元のフォルダに一式で置いてある40件の問い合わせ履歴を読んで、多い順に分類した一覧を作る

### 問2(基本)

「Claude Codeがいちばん新しくて高機能なので、これからは全部Claude Codeで進めます」という意見に、1〜2文で助言してください。

### 問3(応用)

Coworkでまとまった作業を任せ、仕上がりを受け取りました。体裁は整っています。このあと自分がやるべきことを2つ挙げてください。

### 問4(応用)

自分の担当業務から1つ選び、「どこに置かれている仕事か」「進める先」「自分でやる部分」の3点を書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

1はチャットです。仕事が1つの断片として貼れる大きさに収まっているためです。2はClaude Codeです。対象が手元のリポジトリの中に置かれているためです。3はCoworkです。40件の問い合わせ履歴は手元に資料の一式として置かれていて、チャットに貼れる断片には収まらないためです。

</details>

<details>
<summary>問2の解答例</summary>

3つは上下ではなく、仕事の置き場所で選ぶものです。貼れば済む相談まで手元の環境を対象にする道具でやると、準備の手間だけが増えます。

</details>

<details>
<summary>問3の解答例</summary>

1つ目は、中身が正しいかを確かめることです。体裁が整っていることと、内容が合っていることは別です。2つ目は、渡した範囲が想定どおりだったかを見ることです。まとめて任せた分、ずれていたときの範囲も大きくなります。どちらも「責任を持つ」の話で、道具が変わっても自分の仕事です。

</details>

<details>
<summary>問4の解答例</summary>

例として「月次の障害報告のとりまとめ」を挙げます。置かれている場所は、手元に書き出したチケットの一覧という資料の一式です。進める先はCoworkです。自分でやる部分は、重大度の判定と、再発防止として何を書くかの決定です。判断の根拠を自分で持つ必要があるためです。

</details>

## 確認クイズ

### Q1. エラーメッセージを1つ貼って原因の候補を挙げてもらいたいとき、進める先はどれですか。

- A. チャット
- B. Cowork
- C. Claude Code

<details>
<summary>答え</summary>

**A** — 仕事が1つの断片として貼れる大きさに収まっています。貼れるなら貼るのがいちばん早い方法です。

</details>

### Q2. 手元のリポジトリで、ある変更の影響範囲を調べたい場合はどれですか。

- A. チャット
- B. Cowork
- C. Claude Code

<details>
<summary>答え</summary>

**C** — 仕事が手元の作業環境の中に置かれています。貼って渡すには広すぎ、切り出す手間のほうが大きくなります。

</details>

### Q3. 手元のフォルダに一式で置いてある40件の問い合わせ履歴を読んで、分類した一覧にまとめたい場合はどれですか。

- A. チャット
- B. Cowork
- C. Claude Code

<details>
<summary>答え</summary>

**B** — 40件の問い合わせ履歴は、手元に資料の一式として置かれています。チャットに貼れる断片には収まらず、リポジトリの中にあるわけでもありません。置き場所で見れば Cowork です。

</details>

### Q4. 3つの製品を選ぶときの基準として正しいものはどれですか。

- A. 新しく発表されたものほど優先して使う
- B. 扱う仕事が、いまどこに置かれているかで選ぶ
- C. 自分が使い慣れているものを常に選ぶ

<details>
<summary>答え</summary>

**B** — 3つは上下関係ではありません。置き場所で選ばないと、貼れば済む相談まで重い道具でやることになります。

</details>

### Q5. まとまった作業を任せて、体裁の整った仕上がりを受け取りました。正しい進め方はどれですか。

- A. 体裁が整っているので、そのまま提出する
- B. 中身が正しいかを自分で確かめてから使う
- C. 任せた時点で責任は移っているので、確認は不要

<details>
<summary>答え</summary>

**B** — 進める先が変わっても、出したものの責任は自分にあります。まとめて受け取った分、確かめる範囲も広くなります。

</details>

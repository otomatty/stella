# Coworkはまとめて任せる場

Claudeチャット入門 — Module 3 / レッスン3-2

<!-- ノート: ここからは進む先を選ぶレッスンです。まず、チャットの外にある製品を1つずつ紹介します。操作は扱いません。 -->

## なぜ必要か

- 一往復ずつのやり取りだと、数の多い作業に時間がかかる
- ファイルを渡し、受け取り、また渡す運び役を自分がやっている

<!-- ノート: つかみ。チャットが向かない仕事の形を先に見せます。ここで結論は言わない。 -->

---

## 結論

**Coworkは、まとまった作業を任せて仕上がりを受け取るための製品です**

- **任せる** — 何を自分でやり、何を渡すか決めること。講座1で扱った語です
- **Cowork** — 作業のまとまりを渡し、成果物を受け取るための製品

<!-- ノート: 結論を先に言い切ります。任せるは講座1の復習なので1行で流します。単位が一往復ではなく作業のまとまりだ、という点が要点です。 -->

---

## 向いている仕事の例

```text
資料一式の整理  → 30枚を同じ体裁にそろえる
調査してまとめる → 候補を調べ、比較表にする
下書きを並べる  → 章ごとに書き起こす
```

<!-- ノート: 3つとも、途中を1つずつ確認するより、ひとまとまりで受け取ったほうが早い仕事です。逆に、一言相談したいだけならチャットが早い。 -->

## チャットとの違い

| | チャット | Cowork |
| --- | --- | --- |
| 渡す単位 | 会話の一往復 | 作業のまとまり |
| 自分の関わり | 途中を都度見る | 仕上がりを受け取って見る |
| 向く量 | 目を通せる量 | 手で回すと重い量 |

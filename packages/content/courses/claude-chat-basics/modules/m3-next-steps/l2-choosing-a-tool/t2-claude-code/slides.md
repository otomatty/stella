# Claude Codeは手元の開発で使う

## なぜ必要か

- 関係するファイルが10個あると、チャットに貼りきれない
- 直してもらった内容を、自分で手元のファイルに書き戻している

<!-- ノート: つかみ。仕事の中身が手元にあるほど、貼って渡す形は無理が出ます。ここで結論は言わない。 -->

---

## 結論

**Claude Codeは、手元のコードやファイルを対象に使う開発者向けの製品です**

- **ツール** — Claudeが会話の外に対して使える道具。前のレッスンで扱った語です
- **Claude Code** — 手元の作業環境そのものを対象にする開発者向けの製品

<!-- ノート: 結論を先に言い切ります。貼る相手ではなく、対象の場所に置いて使う道具だ、という点が要点です。 -->

---

## 向いている仕事の例

```text
仕様の把握   → 関係するファイルを横断して読む
修正の反映   → 手元のファイルを直したうえで示す
確認まで通す → テストを走らせ、結果を見て直す
```

<!-- ノート: 3つとも、対象がリポジトリの中にあります。貼れる断片に切り出せない仕事ほど、ここが向きます。 -->

## 貼って渡す場合との違い

| | チャットに貼る | Claude Code |
| --- | --- | --- |
| 対象の場所 | 貼った文章の中 | 手元の作業環境 |
| 切り出す手間 | 自分で選んで貼る | 対象を指せば足りる |
| 反映のしかた | 自分で書き戻す | 手元に対して行う |

# レッスン3-2 どこに進むかを選ぶ

## このレッスンの目標

- [ ] Coworkが何のための製品かを説明できる
- [ ] Claude Codeが何のための製品かを説明できる
- [ ] 仕事の置き場所を見て、進める先を選べる

## 3-2-1 Coworkはまとめて任せる場

> **Coworkは、まとまった作業を任せて仕上がりを受け取るための製品です**

ここまで扱ってきたチャットは、一往復ずつ進む形です。書いて、返ってきたものを読んで、また書く。この形は、相談したいときや、短い成果物を作りたいときに向いています。

ところが、量が増えると合わなくなります。30枚の資料を同じ体裁にそろえる、という仕事を考えてください。1枚ずつ貼り、返ってきたものを受け取り、次を貼る。この間、自分は判断ではなく運搬をしています。

**Cowork** は、この運搬を減らすための製品です。渡す単位が会話の一往復ではなく、作業のまとまりになります。渡したあとは仕上がりを受け取り、そこで確かめます。

向いているのは、次のような仕事です。

```text
資料一式の整理   → 30枚を同じ体裁にそろえる
調査してまとめる → 候補を調べ、比較表にする
下書きを並べる   → 章ごとに書き起こす
```

3つに共通するのは、途中を1つずつ見るより、ひとまとまりで受け取ったほうが早い点です。逆に、一言だけ相談したい場合は、チャットのほうが早く終わります。

| | チャット | Cowork |
| --- | --- | --- |
| 渡す単位 | 会話の一往復 | 作業のまとまり |
| 自分の関わり | 途中を都度見る | 仕上がりを受け取って見る |
| 向く量 | 目を通せる量 | 手で回すと重い量 |

ここで **任せる** の話が戻ってきます。渡す単位が大きくなっても、どこまで渡すかを決めるのは自分です。まとめて任せられるからといって、全部を渡してよいわけではありません。

## 3-2-2 Claude Codeは手元の開発で使う

> **Claude Codeは、手元のコードやファイルを対象に使う開発者向けの製品です**

もう1つ、扱う対象が手元にある場合の製品があります。

開発の仕事では、関係するファイルが10個、20個と広がることがあります。これをチャットに貼るのは現実的ではありません。貼れたとしても、直してもらった内容は自分で手元のファイルに書き戻すことになります。

**Claude Code** は、この形を変える製品です。貼った文章ではなく、手元の作業環境そのものを対象にします。開発者が使う道具なので、対象になるのはコードやファイルです。

向いているのは、次のような仕事です。

```text
仕様の把握   → 関係するファイルを横断して読む
修正の反映   → 手元のファイルを直したうえで示す
確認まで通す → テストを走らせ、結果を見て直す
```

前のレッスンの **ツール** の話とつながります。会話の外に働きかける道具があるからこそ、読むだけでなく、確かめるところまで任せられます。

| | チャットに貼る | Claude Code |
| --- | --- | --- |
| 対象の場所 | 貼った文章の中 | 手元の作業環境 |
| 切り出す手間 | 自分で選んで貼る | 対象を指せば足りる |
| 反映のしかた | 自分で書き戻す | 手元に対して行う |

任せられる範囲が広い分、確かめる仕事はむしろ増えます。手元に直接反映される以上、何が変わったのかを自分で見る必要があります。導入や操作は、この講座では扱いません。

## 3-2-3 選ぶ基準は仕事の置き場所

> **チャット・Cowork・Claude Codeは、扱う仕事がどこに置かれているかで選びます**

3つ並ぶと、どれが上位互換かを考えたくなります。新しいものほど強そうに見えるためです。しかしこの見方で選ぶと、一言の相談まで重い道具でやることになります。

**使い分け** の基準は1つだけです。扱う仕事が、いまどこに置かれているかを見ます。

| 仕事がどこにあるか | 進める先 |
| --- | --- |
| チャットに貼れる断片 | チャット |
| 手元のフォルダや資料の一式 | Cowork |
| 手元のリポジトリの中 | Claude Code |

3行とも、見ているのは置き場所だけです。量や渡し方ではありません。具体的に当てはめると、次のようになります。

```text
エラー文の原因を知りたい        → 貼れる断片。チャット
30枚の資料を同じ体裁にそろえる  → 手元のフォルダにある一式。Cowork
リポジトリ全体の影響範囲を調べる → 手元のリポジトリの中。Claude Code
```

迷ったら「この仕事はいま、どこに置いてありますか」と自分に聞いてください。貼れるなら貼るのがいちばん早い方法です。貼りきれないと感じた時点で、次の選択肢を考えます。

そして、どれを選んでも変わらないことが2つあります。講座1で扱った **任せる** と **責任を持つ** です。

- **任せる** — どこまで渡すかは、毎回自分が決めます。道具が広い範囲を扱えることと、その範囲を全部渡してよいことは別です
- **責任を持つ** — 出したものの責任は、道具が変わっても自分にあります。まとめて受け取っても、手元に反映されても、確かめる仕事は消えません

選ぶのは進め先だけです。決める人と、責任の持ち主は変わりません。ここが、この講座と講座1のつながる場所です。

## もっと知りたい人へ

- 自分の直近の仕事を3つ思い出し、それぞれがどこに置かれているかを言葉にしてみてください。置き場所が言えれば、進める先も決まります
- 製品の名前や画面は変わっていきます。実際に使うときは、使う製品のドキュメントで確認してください
- Cowork と Claude Code の導入や操作は、この講座の範囲外です。後続の講座で扱います

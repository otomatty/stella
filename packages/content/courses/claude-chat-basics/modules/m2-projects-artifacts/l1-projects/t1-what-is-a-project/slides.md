# Projectは文脈の入れ物

Claudeチャット入門 — Module 2 / レッスン2-1

<!-- ノート: モジュール2の入り口です。M0で体感した不便を回収する回だと意識して話します。 -->

---

## なぜ必要か

- Claudeは、この会話に渡していない社内の事情や今回の対象を知らない
- 話題が変われば新しい会話にするので、材料はそのたびに渡し直し
- チームの体制も命名の決まりも、毎回コピーして貼っている

<!-- ノート: つかみ。M0で学んだ2つを重ねます。渡していない社内の事情や今回の対象は知らない。話題が変わったら新しい会話を始める。この2つが揃うと、同じ説明を何度も書くことになります。ここでは不便の確認だけで止め、結論は言いません。 -->

---

## 結論

**Projectは、同じ前提を使う会話をまとめて置いておく入れ物です**

- **前提** — どの会話でも同じように使う、変わらない材料や決まりです
- **Project** — その前提を1か所に置き、中の会話すべてに読ませる単位です

<!-- ノート: 結論を言い切ります。貼り直しの手間には置き場がある、という着地です。会話の中ではなく、会話の外側に前提を置く発想だと伝えます。 -->

---

## 貼り直す場合との違い

```text
Projectを使わない
  会話A: 前提を貼る → 本題
  会話B: 前提を貼る → 本題   ← 貼り忘れた回だけ的が外れる

Projectを使う
  Project(前提はここに1回だけ)
    ├ 会話A: 本題だけ
    └ 会話B: 本題だけ
```

<!-- ノート: 対比枠。会話はまるごとコンテキストとして読まれます。Projectの中の会話は、置いた前提とあわせて読まれるので、本題だけを書けば済みます。 -->

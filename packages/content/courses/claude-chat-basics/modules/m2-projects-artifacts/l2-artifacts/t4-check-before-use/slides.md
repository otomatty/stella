# 2-2-4
# 仕上がって見えても仮説

Claudeチャット入門 — Module 2 / レッスン2-2

<!-- ノート: モジュール2の締めです。講座1の見極めるを、Artifactという画面の上で使い直します。 -->

---

## なぜ必要か

- 見出しと表が整っていると、完成品に見えてしまう
- 会話の文章なら読み直すのに、枠の中身は読み飛ばす
- そのまま持ち出して、数字の誤りを提出先で指摘される

<!-- ノート: つかみ。Artifact特有の危うさです。体裁が整うほど、確かめる気持ちが薄れます。ここで結論は言いません。 -->

---

## 結論

**Artifactは体裁が整って見えても、確かめるまでは仮説です**

- **仮説** — 確かめるまで、正しいと決まっていない内容のことです。講座1で扱った語です
- 4Dの「見極める」を、枠の中身に対して行います

<!-- ノート: 結論を言い切ります。仮説の定義は1行の復習で通過し、時間は確かめ方に使います。 -->

---

## 見た目と確かさは別

| | 会話の中の返答 | Artifactの中身 |
| --- | --- | --- |
| 見え方 | 途中の話に見える | 完成品に見える |
| 読み手の反応 | 確かめようとする | そのまま使いたくなる |
| 実際の確かさ | 同じ | 同じ |

<!-- ノート: 対比枠。3行目が要です。枠に入れても中身の確かさは1ミリも上がりません。上がるのは見た目の説得力だけです。 -->

---

## 持ち出す前の3つ

- 数字と固有名詞の出どころを、自分で確かめたか
- 手元の資料や実物と、食い違っていないか
- 自分の名前で出せるか

<!-- ノート: 3つとも「はい」になってから持ち出します。1つでも「いいえ」なら、まだ仮説のまま外へ出そうとしている状態です。 -->

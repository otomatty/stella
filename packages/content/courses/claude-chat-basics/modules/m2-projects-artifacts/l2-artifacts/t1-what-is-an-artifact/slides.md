# Artifactは成果物そのものの枠

Claudeチャット入門 — Module 2 / レッスン2-2

<!-- ノート: レッスン2-2の入り口です。前半は渡すものの置き場でした。ここからは出てきたものの置き場です。 -->

---

## なぜ必要か

- 長い文書を頼むと、返答の文章に本文が混ざって出てくる
- 直してもらうたびに全文が流れ、どれが最新か分からない
- 提出前に、上へ何度もさかのぼって探している

<!-- ノート: つかみ。会話は一列に流れるので、長い成果物とは相性が悪いという体験です。ここで結論は言いません。 -->

---

## 結論

**Artifactは、やり取りの流れとは別に成果物そのものを表示する枠です**

- **Artifact** — 会話の横に開く、成果物だけを入れておく枠です
- 画面での呼び名は変わることがあります。役割は変わりません

<!-- ノート: 結論を言い切ります。会話とArtifactは同じ画面の別の場所だと伝えます。呼び名の紹介は1行に抑えます。 -->

---

## 会話の中 / Artifactの枠

| | 会話の中 | Artifactの枠 |
| --- | --- | --- |
| 並び方 | 発言が下へ流れる | 1つの内容が残る |
| 最新はどれか | さかのぼって探す | 枠を見れば分かる |
| 向くもの | 相談、短い答え | 文書、表、下書き |

<!-- ノート: 対比枠。流れる場所と、留まる場所です。相談は流れてよく、成果物は留まってほしい。この違いが枠がある理由です。 -->

---

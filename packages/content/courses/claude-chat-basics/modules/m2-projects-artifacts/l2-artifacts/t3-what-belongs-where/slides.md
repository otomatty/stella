# Artifactに置くのは持ち出すもの

Claudeチャット入門 — Module 2 / レッスン2-2

## なぜ必要か

- 便利なので、短い答えまで枠に入れたくなる
- 枠が増えると、本命の成果物がどれか分からなくなる
- 逆に、提出する文書を会話の中に流したままにしてしまう

<!-- ノート: つかみ。入れすぎと入れなさすぎの両方を出します。ここで判断の基準はまだ言いません。 -->

---

## 結論

**Artifactには、会話の外へ持ち出して使うものだけを置きます**

- **持ち出し** — 会話の外にある文書やチケットへ、内容を移して使うことです

<!-- ノート: 結論を言い切ります。基準は長さでも出来のよさでもなく、会話の外で使うかどうかです。 -->

---

## 持ち出す / 持ち出さない

| | 置く(Artifact) | 会話のまま |
| --- | --- | --- |
| 使う場所 | 会話の外 | この会話の中 |
| 例 | 手順書、報告の下書き、表 | 用語の確認、方針の相談 |
| 会話を閉じたら | 使い続ける | 用が済んでいる |

判断の一問: **この会話を閉じたあとも、これを使いますか**

<!-- ノート: 対比枠。一問で決めます。はいなら枠に置く、いいえなら会話のままでよい。相談の途中経過まで枠にすると、探す手間が戻ってきます。 -->

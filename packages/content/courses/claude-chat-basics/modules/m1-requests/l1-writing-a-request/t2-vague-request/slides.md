# 丸投げの依頼は的を外す

Claudeチャット入門 — Module 1 / レッスン1-1

---

## なぜ必要か

- 「このログ見といて」と投げたら、ログの要約が返ってきた
- 欲しかったのは原因の候補だったので、また書き直しになった

<!-- ノート: つかみ。返答は間違っていないのに使えない、という状況を思い出させます。ここで結論は言いません。 -->

---

## 結論

**何が出てきたら完了かを書かない丸投げの依頼は、返答が毎回的を外します**

- **丸投げ** — 何をどこまでやれば終わりかを書かずに渡す依頼のことです

<!-- ノート: 結論を言い切ります。的を外すのは相手の性能ではなく、こちらが的を置かなかったからだと伝えます。 -->

---

## よくある丸投げ

```text
「このログ見といて」
「議事録、いい感じにまとめて」
「このコード、なんとかして」
```

どれも目的すら書かれていません。

<!-- ノート: 失敗例の枠。人に頼むなら通じる言い方ですが、社内の事情を共有していない相手には通じません。 -->

---

## 同じ一言から返りうるもの

| 投げた依頼 | 返りうる返答 |
| --- | --- |
| 「このログ見といて」 | ログの要約 |
| 「このログ見といて」 | エラー行の抜き出し |
| 「このログ見といて」 | 原因の候補と対処案 |

<!-- ノート: 対比の枠。3つとも依頼に対しては正しい返答です。的が置かれていないので、どれが当たりかは運になります。 -->

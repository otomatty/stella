# チャットは検索窓ではない

Claudeチャット入門 — Module 0 / レッスン0-1

## なぜ必要か

- 一度投げて、思った内容と違ったので閉じてしまう
- キーワードだけを並べて送り、うまくいかないと諦める

<!-- ノート: つかみ。多くの人は無意識に検索と同じ手つきで使っています。ここで結論は言わない。 -->

---

## 結論

**チャットは一度で正解を引く検索ではなく、やり取りを重ねて近づける対話です**

- **検索** — 一度の入力で、目的の情報を1発で引き当てる使い方
- **対話** — こちらと相手が交互に補い合い、ほしいものへ近づける進め方

<!-- ノート: 結論を先に言い切ります。1回で当てる前提を捨てることが、この講座全体の土台になります。 -->

---

## 1往復と3往復

```text
検索のつもり
  自分「テストの観点を教えて」
  → 一般的な観点が並ぶ。閉じる

対話のつもり
  自分「テストの観点を教えて」
  → 一般的な観点が並ぶ
  自分「対象は入会フォームです。入力値に絞って」
  → 絞られる
  自分「異常系だけ、表で」
  → ほしい形になる
```

<!-- ノート: 送った文章の総量は大差ありません。違うのは、返ってきたものを見てから足している点です。 -->

---

## 検索と対話の違い

| | 検索 | 対話 |
| --- | --- | --- |
| 1回目の位置づけ | 答え | たたき台 |
| ずれたとき | 言葉を変えて引き直す | ずれた点を伝えて続ける |
| 前の入力 | 関係ない | 引き継がれる |

<!-- ノート: 対比枠。特に3行目が効きます。同じ会話の中では、前のやり取りが土台として残ります。 -->

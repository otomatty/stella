# ずれた返答は言い直して寄せる

Claudeチャット入門 — Module 0 / レッスン0-2

<!-- ノート: 1回目がずれたときの扱いです。ここを知らないと、対話が1往復で終わります。 -->

## なぜ必要か

- ずれた内容を見て、その場を閉じて最初から書き直している
- 長いプロンプトを、少しずつ変えて何度も書き直している

<!-- ノート: つかみ。書き直しの手間が大きいので、だんだん使わなくなります。ここで結論は言わない。 -->

---

## 結論

**返答がずれたら、ずれた点を言い直して同じ会話の中で寄せていきます**

- **返答** — こちらの指示に対してClaudeが返してくる内容
- **言い直し** — ずれた点だけを短く伝えて、続けて頼み直すこと

<!-- ノート: 結論を先に言い切ります。ゼロからやり直さない、というのがこの回の主題です。 -->

---

## 言い直しの例

```text
自分「入会フォームの異常系を洗い出して」
→ 30項目が箇条書きで返る

自分「多すぎます。入力値の検証だけに絞ってください」
→ 8項目に絞られる

自分「表にして。列は 入力値 / 期待する挙動 の2つで」
→ ほしい形になる
```

<!-- ノート: 1回ごとの言い直しは1行です。前提を書き直していないことに注目させます。 -->

---

## 書き直す / 言い直す

| | 書き直す | 言い直す |
| --- | --- | --- |
| 前に渡した材料 | もう一度貼る | そのまま使える |
| 伝える内容 | 依頼まるごと | ずれた点だけ |
| 近づき方 | 運任せ | 1回ごとに寄る |

<!-- ノート: 対比枠。同じ会話の中に前のやり取りが残っていることが、言い直しを短くしています。 -->

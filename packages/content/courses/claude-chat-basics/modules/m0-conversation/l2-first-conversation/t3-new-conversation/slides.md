# 話題が変わったら新しい会話

Claudeチャット入門 — Module 0 / レッスン0-2

<!-- ノート: レッスン0-2の締めです。言い直しで続けるか、切り替えるかの線引きを扱います。 -->

---

## なぜ必要か

- 1本の会話にいろいろ足したら、返答が前の話に引きずられた
- 関係ない話題が混ざって、だんだん噛み合わなくなった

<!-- ノート: つかみ。長く使った会話ほど起きます。ここで結論は言わない。 -->

---

## 結論

**会話はまるごとコンテキストとして読まれるため、話題が変わったら新しい会話を始めます**

- **コンテキスト** — 判断のもとになる前後の情報。講座1で扱った語です
- **新しい会話** — 前のやり取りを引き継がず、まっさらから始める会話
- **履歴** — 過去の会話が一覧で残る仕組み。後から開き直せます

<!-- ノート: 3語を1行ずつ配ります。会話の全体が毎回読まれる、という点だけ強く押さえます。 -->

---

## 混ぜたとき / 分けたとき

```text
混ぜた
  会話A: 入会フォームの異常系 → 就業規則の要約を追加で依頼
  → 直前のテストの話に引きずられた要約が返る

分けた
  会話A: 入会フォームの異常系
  会話B: 就業規則の要約
  → それぞれ余計な前提なしで返る
```

<!-- ノート: 分けても困りません。前の会話は履歴に残るので、必要になったら開き直せます。 -->

---

## 続けるか、新しくするか

| 場面 | どうするか |
| --- | --- |
| 返答がずれた | 同じ会話で言い直す |
| 同じ材料をもっと深掘る | 同じ会話で続ける |
| 材料も目的も別のものになった | 新しい会話を始める |

<!-- ノート: 対比枠。判断の軸は「材料と目的が同じか」です。長さや時間ではありません。 -->

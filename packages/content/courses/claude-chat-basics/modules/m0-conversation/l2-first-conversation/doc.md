# レッスン0-2 最初の会話

## このレッスンの目標

- [ ] 最初の一言に目的を入れて会話を始められる
- [ ] ずれた返答を、書き直さずに言い直して寄せられる
- [ ] 会話を続けるか、新しく始めるかを判断できる

## 0-2-1 最初の一言で目的を伝える

> **最初の一言には、何のためのやり取りかという目的を書きます**

Claudeに送る指示の文章を **プロンプト** と呼びます。講座1で扱った語です。ここでは、1本目のプロンプトに何を書くかだけを扱います。

短く投げたのに長い一般論が返ってきた、という経験はよくあります。原因は、**何のためのやり取りかを書いていない** ことです。用途が分からなければ、相手は広く浅く答えるしかありません。

そこで最初の一言に **目的** を入れます。目的とは、その材料を使って最後に自分が何をしたいのか、ということです。

```text
目的なし
  「この仕様書をレビューして」
  → 誤字から設計まで、広く浅く返る

目的あり
  「明日の設計レビューに出す前に、
    抜けている異常系を洗い出したい。この仕様書を見て」
  → 異常系に絞って返る
```

後者は、文章がうまいのではありません。目的の1行が足されているだけです。分量を増やす話ではない、という点が大事です。

書くときは、次の3つがそろっているかを見てください。

| 要素 | 例 |
| --- | --- |
| いつ・どこで使うか | 明日の設計レビューで |
| 何をしたいか | 抜けている異常系を洗い出したい |
| 渡す材料 | この仕様書 |

3つそろえば、1本目としては十分です。よく効く言い回しを探すより、この3つが書けているかを確かめるほうが確実です。

## 0-2-2 ずれた返答は言い直して寄せる

> **返答がずれたら、ずれた点を言い直して同じ会話の中で寄せていきます**

目的を書いても、1回目がずれることはあります。こちらの指示に対してClaudeが返してくる内容を **返答** と呼びます。

ずれた返答を見て、その場を閉じ、最初から長いプロンプトを書き直す人が多くいます。手間が大きいので、何度か繰り返すうちに使わなくなります。

ここで使うのが **言い直し** です。ずれた点だけを短く伝えて、続けて頼み直すことを指します。

```text
自分「入会フォームの異常系を洗い出して」
→ 30項目が箇条書きで返る

自分「多すぎます。入力値の検証だけに絞ってください」
→ 8項目に絞られる

自分「表にして。列は 入力値 / 期待する挙動 の2つで」
→ ほしい形になる
```

2回目と3回目は、それぞれ1行です。対象も目的も書き直していません。同じ会話の中に前のやり取りが残っているので、足りない一言だけで済みます。

| | 書き直す | 言い直す |
| --- | --- | --- |
| 前に渡した材料 | もう一度貼る | そのまま使える |
| 伝える内容 | 依頼まるごと | ずれた点だけ |
| 近づき方 | 運任せ | 1回ごとに寄る |

コツは、**何がずれたかを具体的に言うこと** です。「違います」だけでは、どこを直せばよいか分かりません。「多すぎる」「対象が違う」「形式が違う」のように、ずれた軸を1つ挙げてください。

## 0-2-3 話題が変わったら新しい会話

> **会話はまるごとコンテキストとして読まれるため、話題が変わったら新しい会話を始めます**

言い直しで続けられるなら、1本の会話に何でも足していけばよいのでしょうか。そうではありません。

判断のもとになる前後の情報を **コンテキスト** と呼びます。講座1で扱った語です。会話の中では、それまでのやり取りがまるごとコンテキストとして読まれます。だから短い言い直しが通じるのですが、裏を返せば、関係ない話も一緒に読まれるということです。

ただし、講座1で扱ったとおり、一度に読める量には上限があります。会話がとても長くなると、古いやり取りが返答に反映されないことがあります。長くなった会話で序盤の前提が効いていないと感じたら、大事な前提を言い直すか、前提を書き直して新しい会話に移してください。

```text
混ぜた
  会話A: 入会フォームの異常系 → 就業規則の要約を追加で依頼
  → 直前のテストの話に引きずられた要約が返る

分けた
  会話A: 入会フォームの異常系
  会話B: 就業規則の要約
  → それぞれ余計な前提なしで返る
```

そこで、話題が変わったときは **新しい会話** を始めます。前のやり取りを引き継がず、まっさらから始める会話のことです。

分けても困りません。過去の会話は **履歴** として一覧に残るからです。履歴とは、これまでの会話が一覧で残る仕組みで、後から開き直して続きを頼めます。分けることは、捨てることではありません。なお、記憶などの補助機能があっても前の会話の本文がそのまま読まれるわけではないので、対象になる材料は使う会話に渡します。

続けるか新しくするかは、次の軸で決めます。

| 場面 | どうするか |
| --- | --- |
| 返答がずれた | 同じ会話で言い直す |
| 同じ材料をもっと深掘る | 同じ会話で続ける |
| 材料も目的も別のものになった | 新しい会話を始める |

判断の軸は、会話の長さや経過時間ではありません。**材料と目的が同じかどうか** です。同じなら続け、変わったら新しく始めてください。

## もっと知りたい人へ

- 直近で「思ったのと違う」と感じたやり取りを1つ思い出し、目的の3要素のどれが抜けていたかを確かめてみてください
- 会話を分ける習慣がつくと、履歴から目的の会話を探すのも楽になります。1本の会話に詰め込むほど、後から探しにくくなります
- 画面の並びや呼び名は変わります。操作で迷ったときは、使っている製品の公式ドキュメントで最新のものを確認してください

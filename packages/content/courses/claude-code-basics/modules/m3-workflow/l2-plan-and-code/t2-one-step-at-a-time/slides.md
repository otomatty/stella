# 3-2-2
# 頼むのは一度に一段だけ

Claude Code入門 — Module 3 / レッスン3-2

<!-- ノート: 3つめの段、書かせる場面の進め方です。 -->

---

## なぜ必要か

- 「計画どおり全部やって」と言うと、大量の変更がまとめて返ってきます
- どこで話がずれたのか、返ってきたものからは切り分けられません

<!-- ノート: つかみ。まとめて頼んだときの、あの読む気の失せる分量を思い出してもらいます。結論はまだ言いません。 -->

---

## 結論

**Codeでは一度に全部ではなく一段ずつ書かせて、そのつど確かめます**

- **一段** — 計画のうちの1項目ぶんの作業
- 段が終わるたびに、自分が見て、次を頼みます

<!-- ノート: 結論です。Code の段は一往復ではなく、小さな往復の繰り返しになると言い切ります。 -->

---

## 一段ずつ頼む

```text
まとめて  計画の1から3まで、まとめて進めてください

一段ずつ  まず1だけ書いてください。2はまだ書かないでください
          → 出てきたものを確かめる
          → では2をお願いします
```

<!-- ノート: 最小の例です。「2はまだ」と書き添えるところが要点で、これが無いと勝手に先へ進みます。 -->

---

## まとめて頼んだときとの違い

| | まとめて書かせる | 一段ずつ書かせる |
| --- | --- | --- |
| 確かめる単位 | 全部まとめて | 一段ぶん |
| ずれの場所 | 探し回る | 直前の一段 |
| やり直し | 大きい | 一段ぶん |

<!-- ノート: 対比枠です。一段ずつのほうが遅そうに見えて、やり直しを含めると結局速いと言い添えます。 -->

# レッスン3-2 演習 — 計画してから書かせる(Plan → Code)

対象トピック: 3-2-1 〜 3-2-3

## 手元で試す

このレッスンで練習するのは、計画を読んでから一段ずつ書かせることです。メモ帳だけでも進められます。

1. レッスン3-1で選んだ小さな修正を、そのまま使います
2. 自分がClaude Codeになったつもりで、その修正の **計画** を3項目で書きます。うち1項目は、わざと頼んでいない作業(「ついでに周辺も整理する」など)にしておきます
3. 書いた計画を依頼者の目で読み直し、**過不足** を見つけて、外す一言を書きます
4. 残った計画から一段だけを選び、「まず1だけ書いてください。2はまだ書かないでください」という形の依頼文を書きます
5. 進み方がずれた場面を1つ想像し、**中断** したあとに戻す一言を、計画の番号を入れて書きます

余力があれば、VS Code で Claude Code を Planモードにして計画だけ出させ、過不足を1つ直してから、一段だけ書かせてみてください。**Claude Code が使えない環境の人は、この段落を飛ばして構いません。** 1〜5 を紙の上で書くだけで演習は成立します。

## 演習問題

### 問1(基本)

Planモードと Plan の段は何が違いますか。1〜2文で説明してください。

### 問2(基本)

計画を読むときに見る点を2つ挙げてください。

### 問3(応用)

計画が次のように返ってきました。Codeに進む前にどう直しますか。直す一言も書いてください。

```text
1. 更新日を組み立てている処理の書式を直す
2. 商品一覧ページの呼び出し側を合わせる
3. ついでに周辺の関数名を分かりやすく変える
4. 使っていない古いファイルを消す
```

### 問4(応用)

一段目だけを頼んだのに、二段目と三段目まで書き進み始めました。取る行動を順を追って2〜3文で書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

Planモードは、ファイルを変更させずに計画だけ出させるための選び方です。Plan の段は、出てきた計画を自分で読んで過不足を直すワークフロー上の場面です。モードを選んだだけでは段は終わりません。

</details>

<details>
<summary>問2の解答例</summary>

頼んだことが手順に入っているか(不足)と、頼んでいないことが混ざっていないか(余計)の2点です。

</details>

<details>
<summary>問3の解答例</summary>

3と4は頼んでいない作業なので外します。「3と4は今回やめてください。1と2だけでお願いします」と一言返してから、Codeに進みます。4は取り消せない操作にもつながるので、特に残したままにしません。

</details>

<details>
<summary>問4の解答例</summary>

まず中断します。次に「計画の1に戻ってください。2以降はまだ書かないでください」と、番号を示して戻します。そのうえで一段目の結果だけを確かめ、問題なければ改めて二段目を頼みます。最初からのやり直しにはなりません。

</details>

## 確認クイズ

### Q1. 計画に、頼んでいない変更が1項目混ざっていました。適切な行動はどれですか。

- A. 動くなら害はないので、そのままCodeに進む
- B. その項目を外してもらってから、Codeに進む
- C. 計画を全部捨てて、依頼から書き直す

<details>
<summary>答え</summary>

**B** — 計画の1行を消すほうが、書かれたコードを消すよりずっと安く済みます。全部捨てる必要もありません。

</details>

### Q2. 次のうち、まだCodeに進むべきでない状況はどれですか。

- A. 計画の手順が依頼どおりで、余計な項目もない
- B. 計画が3行で、触るファイルが挙がっている
- C. 計画に「ついでに設定ファイルも整理する」と入っている

<details>
<summary>答え</summary>

**C** — 頼んでいない作業が入ったまま進むと、できてから外すことになります。過不足を直してから進みます。

</details>

### Q3. Codeの段の進め方として適切なものはどれですか。

- A. 一段ずつ書かせて、そのつど確かめてから次を頼む
- B. 計画の全段をまとめて書かせ、最後に一度だけ確かめる
- C. 段の順番は無視して、書きやすそうなところから頼む

<details>
<summary>答え</summary>

**A** — 一段ずつなら、ずれたとき探す場所が直前の一段に限られます。やり直しも一段ぶんで済みます。

</details>

### Q4. 一段目を頼んだのに、二段目・三段目まで書き進み始めました。適切な行動はどれですか。

- A. せっかく進んでいるので、最後まで進ませる
- B. 中断して、計画の一段目のところまで戻して確かめる
- C. 会話を閉じて、依頼から作り直す

<details>
<summary>答え</summary>

**B** — 中断はワークフローの想定内の操作です。戻る先は最初ではなく、計画のところまでです。

</details>

### Q5. 途中でずれに気づいたとき、最後まで待たないほうがよい理由はどれですか。

- A. 待つと相手が機嫌を損ねるから
- B. 一度始めた作業は途中で止められないから
- C. 待つあいだ、ずれた土台の上に次の一段が積み上がるから

<details>
<summary>答え</summary>

**C** — 早く止めるほど、戻す量が小さくて済みます。相手は人ではないので、口を挟む遠慮は要りません。

</details>

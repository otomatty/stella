# 3-2-3
# ずれたら途中で止めて戻す

Claude Code入門 — Module 3 / レッスン3-2

<!-- ノート: 一段ずつ見ていて、ずれに気づいたときの動きです。 -->

---

## なぜ必要か

- ずれに気づいても「最後まで見てから言おう」と待ってしまいます
- 待っているあいだ、ずれた土台の上に次の一段が積み上がります

<!-- ノート: つかみ。遠慮して黙って見ている場面を共有します。結論はまだ言いません。 -->

---

## 結論

**進み方がずれたら最後まで待たずに中断して、計画のところまで戻して直します**

- **中断** — 進んでいる途中で止めること
- **軌道修正** — 向きを直してから続けること
- 戻る先は最初ではなく、計画のところまでです

<!-- ノート: 結論です。止めるのは失敗ではなく想定内の操作だと言い切ります。 -->

---

## 止めて戻す4行

```text
気づく  頼んでいないファイルまで書き換え始めた
中断    いったん止める
戻す    計画の2に戻ってください。触るのは商品一覧ページだけです
続ける  直した向きで、その一段をやり直してもらう
```

<!-- ノート: 最小の例です。戻すときに、計画のどこへ戻るのかを番号で示すのが効きます。 -->

---

## よくある思い込み

| 思い込み | 実際 |
| --- | --- |
| 途中で止めるのは失礼 | 相手は人ではないので遠慮は要らない |
| 止めたら最初からやり直し | 戻すのは計画のところまで |
| 最後まで見てから言うほうが早い | ずれた上に積み上がるぶん遅くなる |

<!-- ノート: 失敗例の枠です。3つとも「待つ理由がない」という一点に集約されます。 -->

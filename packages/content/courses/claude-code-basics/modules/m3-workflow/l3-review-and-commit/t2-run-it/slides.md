# 読んだら動かして確かめる

Claude Code入門 — Module 3 / レッスン3-3

<!-- ノート: 差分を読んだあとの、もう一手です。 -->

---

## なぜ必要か

- 読んで筋が通っていても、動かすとあっさり落ちることがあります
- 直したところは良くても、別のところが動かなくなることがあります

<!-- ノート: つかみ。目で見てOKだったのに動かなかった経験を思い出してもらいます。結論はまだ言いません。 -->

---

## 結論

**差分を読んだあとは、テストを走らせて実際に動くところまで動作確認します**

- **テスト** — 期待どおり動くかを自動で調べる仕組み
- **動作確認** — 実際に動かして、目で結果を確かめること

<!-- ノート: 結論です。読むと動かすは別の確かめ方で、片方では足りないと言い切ります。 -->

---

## 動かすところまで頼む

```text
1. テストを走らせるコマンドを実行してもらう
2. 通らなければ、出力ごと見せてもらって直す
3. テストが無いところは、自分で画面を開いて確かめる
```

<!-- ノート: 最小の例です。3行目が要点で、テストが無い場所は自分の目が動作確認になります。 -->

---

## どの確かめ方で何が見つかるか

| 確かめ方 | 見つかるずれ |
| --- | --- |
| 差分を読む | 頼んでいない変更・筋の通らない直し |
| テストを走らせる | 動かすと落ちる失敗・別の場所の壊れ |
| 自分で動かす | 画面や出力の見た目のずれ |

<!-- ノート: 対比枠です。3つとも見つかるものが違うので、上から順に通すと言い添えます。 -->

---

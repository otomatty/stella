## なぜ必要か

- 直してほしいコードは、いつも開いている画面の中にある
- 別の画面に貼り付けて、返ってきたものをまた貼り戻すのは手間

<!-- ノート: つかみ。作業する場所と頼む場所が離れている状態を共有します。ここで結論は言いません。 -->

## 結論

**Claude Codeは、VS Codeに拡張機能として入れると、エディターの中から使い始められます**

- **エディター** — コードを読み書きする画面です
- **VS Code** — 広く使われているエディターの1つです
- **拡張機能** — エディターに後から足せる機能です

<!-- ノート: 結論を言い切ります。新しいアプリを別に立ち上げるのではなく、いま使っている画面に足すだけだと伝えます。 -->

# パネルで会話しながら進める

Claude Code入門 — Module 1 / レッスン1-1

<!-- ノート: 範囲が決まったあと、どこでどう話しかけるかの話です。 -->

---

## なぜ必要か

- 頼みごとが一度で決まりきることは、まずない
- 言い足すたびに事情を最初から説明し直すのは、割に合わない

<!-- ノート: つかみ。一問一答だと思っていると起きる無駄を共有します。ここで結論は言いません。 -->

---

## 結論

**Claude Codeとのやり取りは、エディターの横のパネルで会話として続いていきます**

- **パネル** — エディターの横に開く、やり取り用の表示領域です
- **会話** — 一往復で切れず、続けて積み上がっていくやり取りです

<!-- ノート: 結論を言い切ります。コードを見ながら、その横で話しかけられる。画面を離れずに続けられることが要点です。 -->

---

## 続けて言い足せる

```text
自分   このリポジトリが何をするものか、3行で説明してください
相手   (説明が返る)
自分   そのうち、注文まわりを扱っているのはどのフォルダですか
相手   (最初の説明を踏まえて答える)
```

<!-- ノート: 最小の例です。2回目に事情を書き直していない点だけを指してください。読ませる依頼から始めているのも意図的です。 -->

---

## 一問一答のつもりだと損をする

| | 一問一答のつもり | 会話として続ける |
| --- | --- | --- |
| 2回目の書き方 | 事情を書き直す | 続きを一言足す |
| 話のかみ合い | 毎回ふりだし | 前を踏まえる |
| こちらの手間 | 増える | 減る |

<!-- ノート: 対比の枠です。パネルの位置や見た目は変わりますが、続きとして話せるという性質は変わらない、と言い添えます。 -->

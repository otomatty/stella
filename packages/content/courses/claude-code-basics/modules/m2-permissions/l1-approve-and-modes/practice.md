# レッスン2-1 演習 — 許可の出し方を決める

対象トピック: 2-1-1 〜 2-1-4

## 手元で試す

このレッスンで練習するのは、どこまで先に許可を出すかを自分で決めることです。1 は紙とメモ帳だけで進められます。

1. 自分の普段の作業で出てきそうな操作を6つ書き出し、「戻せる / 戻せない」の2列に仕分けます(例: 中身を読む、検索する、ファイルを消す、外へ送る、外から取り込んで入れる)。仕分けたら、自動承認に入れてよいのはどちらの列かを1行で書きます
2. VS Code で Claude Code を開き、コメントの誤字を1文字直すなど、書き換えを伴う小さな依頼を1つ出して、承認を求められる場面を眺めます。何をしようとしているかが先に示されることを確かめてください。承認が出ないときは、許可の出し方が自動寄りになっています。毎回確認する側に切り替えてから試してください(切り替え方は製品のドキュメントで確かめます)
3. 同じ確認が繰り返されたら、その操作が「戻せる」列にあるかを確かめてから、自動承認にして進み方の変化を見ます
4. Planモードを選び、「どう直すつもりか先に出して」とだけ頼みます。ファイルが変更されないまま計画が返ってくることを確かめます

**Claude Code が使えない環境の人は、2〜4 を飛ばして構いません。** 1 の仕分けと、以下の演習問題・確認クイズだけで演習は成立します。

## 演習問題

### 問1(基本)

Claude Code が書き換えやコマンド実行の前に承認を求めるのは何のためか、「権限」という語を使って2文で説明してください。

### 問2(基本)

次の4つの操作を、自動承認に「入れてよい」「入れない」に仕分け、判断の理由を1行で書いてください。

- 対象のファイルの中身を読む
- 一時的に作ったファイルをまとめて消す
- リポジトリの中を検索する
- 成果物を外部の共有先へ送る

### 問3(応用)

依頼を出したところ、「古い出力ファイルをまとめて消します」という確認が出ました。この場面で取る行動を、順を追って2〜3文で書いてください。

### 問4(応用)

見た目の崩れているページを直したいのですが、原因の見当がついていません。Planモードを選ぶ理由を1文で書き、そのときに出す依頼を1行で書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

Claude Code は書き換えやコマンド実行の前に止まり、何をするかを先に示して承認を待ちます。実行してよい範囲、つまり権限を自分が決められるようにし、手元に変化が起きる前に止められるようにするためです。

</details>

<details>
<summary>問2の解答例</summary>

入れてよい: 中身を読む / 検索する。どちらも手元の状態を変えず、何度実行しても元に戻す必要がありません。

入れない: まとめて消す / 外部へ送る。どちらも取り消せない操作で、間違っていたときに元の状態へ戻せません。

</details>

<details>
<summary>問3の解答例</summary>

消す操作は取り消せないので、自動承認には入れず、この確認をそのまま受け止めます。どのファイルが対象かを読み、消えて困るものが混ざっていないかを確かめます。問題なければ承認し、少しでも怪しければ断って、対象を絞ってから頼み直します。

</details>

<details>
<summary>問4の解答例</summary>

理由: 直し方が決まっていないので、先に進め方の計画だけを見たいからです。

依頼: 「このページの表示が崩れる原因を調べて、どう直すつもりか先に出してください。まだファイルは変更しないでください」

</details>

## 確認クイズ

### Q1. Claude Code が書き換えやコマンド実行の前に承認を求めるのは、何のためですか。

- A. 実行の速さを上げるため
- B. 手元に変化が起きる前に、自分が知って決められるようにするため
- C. 会話を長く続けるため

<details>
<summary>答え</summary>

**B** — 承認は、止められる時点を「終わったあと」から「実行の前」へ動かす仕組みです。

</details>

### Q2. 次のうち、自動承認に入れる候補としていちばん向いているのはどれですか。

- A. 結果の表示を確かめるために何度も走らせる、状態を変えないコマンド
- B. 成果物を外部の共有先へ送る操作
- C. 使わなくなったファイルをまとめて消す操作

<details>
<summary>答え</summary>

**A** — 状態を変えない操作は、間違っても戻す必要がありません。読むだけの操作がはじめから聞かれないのと同じ扱いを広げる形です。

</details>

### Q3. 「送る操作を毎回聞かれるのが面倒なので、自動承認に入れたい」と相談されました。適切な答えはどれですか。

- A. 何度も繰り返す操作なので、入れてよい
- B. 送った事実は取り消せないので、入れずに毎回止めて確かめる
- C. 承認をすべて切ってしまえば、もっと速くなる

<details>
<summary>答え</summary>

**B** — 判断の分かれ目は繰り返しの回数ではなく、間違ったときに元へ戻せるかどうかです。

</details>

### Q4. 自動承認を使っていても、取り消せない操作では毎回止まるようにしておく理由はどれですか。

- A. 結果に責任を持つのは、依頼した自分だから
- B. エージェントループをわざと遅くするため
- C. 権限という言葉を覚えるため

<details>
<summary>答え</summary>

**A** — 自動承認は権限を先に渡す約束です。渡してよいのは、渡し間違えても戻せる範囲だけです。

</details>

### Q5. Planモードを選ぶのが適切なのは、次のうちどの場面ですか。

- A. 直し方がまだ決まっていない修正で、まず進め方を出させたいとき
- B. 誤字を1文字直すだけだと分かっているとき
- C. すべての確認を自動承認にしたいとき

<details>
<summary>答え</summary>

**A** — Planモードはファイルを変更させずに計画だけを出させる状態で、直し方が決まっていないときに向きます。

</details>

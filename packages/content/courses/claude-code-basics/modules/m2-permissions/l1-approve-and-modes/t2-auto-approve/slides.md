# 2-1-2
# 繰り返す操作は自動承認にできる

Claude Code入門 — Module 2 / レッスン2-1

<!-- ノート: 承認の次に出てくる、進め方の調整の話です。 -->

---

## なぜ必要か

- 同じ「このコマンドを実行してよいですか」に、十回続けて返事をしていることがあります
- 返事のたびに手が止まり、何を頼んでいたか思い出し直しになります

<!-- ノート: つかみ。承認そのものではなく、同じ確認の繰り返しがしんどいという実感から入ります。 -->

---

## 結論

**毎回同じ確認が続く安全な操作は、自動承認にして手を止めずに進められます**

- **自動承認** — この種類の操作は聞かずに実行してよい、と先に決めておくこと

<!-- ノート: 結論です。承認を捨てるのではなく、返事の内容が毎回同じものだけを先に決めておく、という言い方をします。 -->

---

## 先に決めておく

```text
繰り返される確認   表示を確かめるコマンドを実行してよいですか(何度も)
先に決めておく     この確認用のコマンドは、聞かずに実行してよい
その後             エージェントループが止まらずに進む
```

<!-- ノート: 最小の例です。読むだけの操作がはじめから聞かれないのと同じ扱いを、安全と分かっている操作へ自分で広げるのが自動承認です。 -->

---

## 手が止まるかどうか

| | 毎回承認する | 自動承認にする |
| --- | --- | --- |
| 確認用のコマンド | 何十回も返事する | 返事は不要 |
| 表示を作り直すコマンド | そのつど止まる | そのまま続く |
| 自分の集中 | 途切れる | 続く |

<!-- ノート: 対比枠です。自動承認にすると、返事の回数だけが減って、進む中身は変わりません。 -->

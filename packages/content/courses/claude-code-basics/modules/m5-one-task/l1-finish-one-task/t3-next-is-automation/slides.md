# 5-1-3
# 繰り返しが見えたら仕組み化する

Claude Code入門 — Module 5 / レッスン5-1

<!-- ノート: 講座の締めです。1本を通せるようになった人が、次に何を見るかの話です。 -->

---

## なぜ必要か

- 何本か通すと、依頼のたびに同じ前置きを書いている自分に気づく
- 書き忘れた回だけ結果がぶれて、原因が思い出せない

<!-- ノート: つかみ。手で書き続けることの費用は、手間よりも書き忘れのぶれです。結論はまだ言いません。 -->

---

## 結論

**同じ指示を毎回書いていると気づいたら、次はそれを仕組みとして置く番です**

- **繰り返し** — 依頼のたびに毎回書いている、同じ内容の指示
- **仕組み化** — その指示を、毎回書かずに済むよう先に置いておくこと

<!-- ノート: 結論を先に言い切ります。この講座で学ぶのは、仕組みの作り方ではなく「ここが仕組みの出番だ」と気づく判断です。 -->

---

## 気づき方

```text
毎回書いている  「テストはこのコマンドで走らせて」
                「直したら必ずこの手順で確かめて」
                「この書き方に合わせて」
判断            3回書いたら、それは仕組みにする候補
```

<!-- ノート: 最小の例です。数えるのは回数だけで構いません。3回書いた指示は、これからも書き続ける指示です。 -->

---

## 毎回書く・置いておく

| | 毎回書く | 仕組みとして置く |
| --- | --- | --- |
| 手間 | 依頼のたびに同じ文 | 一度置けば効き続ける |
| ぶれ | 書き忘れた回だけ抜ける | 抜けにくい |
| この講座 | ここまでが範囲 | 名前だけ紹介 |

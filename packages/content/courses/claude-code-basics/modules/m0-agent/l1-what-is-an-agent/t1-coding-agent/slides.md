# Claude Codeはコードを直す相手

Claude Code入門 — Module 0 / レッスン0-1

<!-- ノート: この講座の1本目です。まず、これから付き合う相手が何者かをそろえます。 -->

---

## なぜ必要か

- 一覧の並びが逆、という小さな不具合ひとつでも、直す場所を探すところから始まる
- 探して、直して、動かしてみる。この往復が細切れの時間を埋めていく

<!-- ノート: つかみ。難しい仕事だから時間が要るのではなく、小さな修正ほど往復が多い、という実感から入ります。ここで結論は言いません。 -->

---

## 結論

**Claude Codeは、手元のコードを読んで直すところまで進めるコーディングエージェントです**

- **Claude** — 文章で仕事を頼める生成AI。講座1・講座2で扱った相手です
- **コード** — 動くソフトウェアのもとになる、書かれた命令
- **コーディングエージェント** — 頼まれた修正を、手元のコードの上で進めるAI
- **Claude Code** — Claudeをコーディングエージェントとして使うための製品

<!-- ノート: 結論を先に言い切ります。Claudeは復習なので1行で流します。新しいのは「手元のコードの上で進める」という点だけです。 -->

---

## 頼み方のイメージ

```text
自分         一覧の日付が古い順に出ている。新しい順にしたい
Claude Code  並び順を決めている場所を手元のコードから探して読む
             そのうえで、新しい順になるよう直す
結果         直したあとのコードが手元に残る
```

<!-- ノート: 最小の例です。「探して読む」と「直す」が同じ相手の中で続くところが、この講座の出発点です。 -->

---

## 向く頼みごと・向かない頼みごと

| 頼みごと | 向き |
| --- | --- |
| 一覧の並び順が逆なのを直す | 向く |
| 返している項目を1つ足す | 向く |
| どの機能を来期に作るか決める | 向かない(コードの話ではない) |

<!-- ノート: 対比枠。相手にするのは手元のコードです。コードの外側の意思決定は、この講座の相手ではありません。 -->

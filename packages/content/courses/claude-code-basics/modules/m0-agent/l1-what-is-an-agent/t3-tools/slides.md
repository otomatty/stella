## なぜ必要か

- 文章を書くAIが、なぜ手元のファイルを変えられるのかが分からない
- 仕組みが分からないままだと、何をどこまで頼んでよいかも決められない

<!-- ノート: つかみ。中身の見えない箱には頼みごとの当てをつけられない、という素朴な引っかかりです。結論はまだ言いません。 -->

---

## 結論

**コーディングエージェントは、ファイルを読み書きしたりコマンドを実行したりするツールを使います**

- **ツール** — エージェントが手元を触るための操作の口。読む・書く・探す・走らせる、など
- **コマンド** — 手元の機械に出す1行の命令
- **実行** — コマンドを実際に走らせること

<!-- ノート: 結論を先に言い切ります。文章を書く力とは別に、手元を触る口が用意されている、という理解でいきます。 -->

---

## 1つの修正で使われるツール

```text
頼みごと  一覧の日付を新しい順にしたい
探す      並び順を決めている場所を手元から探す
読む      見つかったファイルの中身を読む
書く      新しい順になるよう書き換えて保存する
実行      表示を作り直すコマンドを実行する
```

<!-- ノート: 最小の例です。1つの頼みごとの中で、いくつものツールが順に使われます。ツールの名前を覚える必要はありません。 -->

---

## 文章だけの相手との違い

| | チャット | ツールを持つエージェント |
| --- | --- | --- |
| できること | 説明・提案 | 探す・読む・書く・実行する |
| 手元への影響 | ない | 実際に変わる |

手元が実際に変わるからこそ、勝手に進まない仕組みが要ります(Module 2 で扱います)

## なぜ必要か

- 返ってきた直し方をコピーして、貼る場所を探して、貼る係は自分に残る
- 3行の直しでも、貼り間違いも貼り忘れも起きる

<!-- ノート: つかみ。相談の質ではなく、そのあとの手作業が残る、という困りごとです。結論はまだ言いません。 -->

---

## 結論

**チャットは提案で止まりますが、コーディングエージェントにはファイルの変更まで任せられます**

- **チャット** — 文章の一往復で相談する使い方。講座2で扱った語です
- **任せる** — 何を自分でやり、何を渡すか決めること。講座1で扱った語です
- **提案** — 「こう直すとよい」という案。手元は変わらない
- **ファイル** — コードが書かれて保存されている、1つ1つの入れ物

<!-- ノート: 結論を先に言い切ります。チャットと任せるは復習なので1行ずつで流します。境目は「手元が変わるかどうか」の一点です。 -->

---

## 同じ修正を頼んだとき

```text
チャット                「並び順のところを次のように書き換えてください」
                        → 場所を探して貼って保存するのは自分

コーディングエージェント  該当するファイルを開いて、その場で書き換える
                        → 手元のファイルがもう変わっている
```

<!-- ノート: 最小の例です。返ってくるものが文章か、変わったファイルか。ここだけが違います。 -->

---

## どこで止まるか

| | チャット | コーディングエージェント |
| --- | --- | --- |
| 返ってくるもの | 提案 | 変更されたファイル |
| 手元の状態 | 変わらない | 変わる |
| 自分に残る作業 | 貼って直す | 変わった結果を見る |

<!-- ノート: 対比枠。上位版ではなく、止まる位置が違います。相談で足りる用は、チャットのほうが早く終わります。 -->

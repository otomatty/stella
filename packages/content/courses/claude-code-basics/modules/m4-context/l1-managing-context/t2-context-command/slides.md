# /contextで今の使用量を見る

Claude Code入門 — Module 4 / レッスン4-1

---

## なぜ必要か

- 「そろそろ長いかな」は勘で、当たっているか分からない
- 手詰まりになってから気づくと、作業の途中で慌てることになる

<!-- ノート: つかみです。長さは見えないから放置される、という順で入ります。ここでは打つものをまだ言いません。 -->

---

## 結論

**`/context`は、いまコンテキストをどれだけ使っているかを確かめるスラッシュコマンドです**

- 役割は **使用量を見る** こと。その役割に付いている名前が `/context` です
- **スラッシュコマンド** — パネルに `/` で始まる語を打って使う、会話の中の操作

<!-- ノート: 結論を先に言い切ります。覚えてほしいのは名前ではなく役割です。製品の名前は変わることがあるので、「使用量を見る道具がある」を先に置き、名前を後ろに置きます。 -->

---

## 打ってみると分かること

```text
やりたいこと   いまどれだけ使っているか知りたい
打つもの       /context
分かること     使用量の目安 / 上限までの余裕
```

<!-- ノート: 最小の例です。数字そのものを覚える必要はありません。余裕が大きいか小さいかが読めれば、このトピックの目的は足ります。 -->

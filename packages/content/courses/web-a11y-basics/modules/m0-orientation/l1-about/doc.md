## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「APG のパターンに沿って、キーボードと支援技術で使える対話 UI を作れる」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- アクセシビリティとは何か
- セマンティクスと ARIA のきほん
- キーボード操作とフォーカス管理
- APG パターンでつくる対話 UI (タブ・ダイアログなど)
- 支援技術での確認方法

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

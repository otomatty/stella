# ページ送りもnavとolで書く

UI部品入門 — Module 2 / レッスン2-3

<!-- ノート: Module 2 の3つ目、一覧の下によくあるページ送りです。 -->

---

## なぜ必要か

- 一覧が 200 件あるのに、1 ページに全部出すと重い
- 「次へ」だけだと、10 ページ目に直接飛べない

<!-- ノート: つかみ。一覧ページには必ず出てくる部品です。 -->

---

## 結論

**ページ送りは、`nav`の中の`ol`に前後と番号のリンクを並べて書く**

- ページ送りの部品を **ページネーション** と呼ぶ
- 番号には順番があるので `ol`

<!-- ノート: 結論。パンくずと同じ骨格ですが、中身が番号のリンクになります。 -->

---

## 最小のコード

```html
<nav class="pagination" aria-label="ページ送り">
  <ol>
    <li><a href="?page=1">前へ</a></li>
    <li><a href="?page=1">1</a></li>
    <li><a href="?page=2">2</a></li>
  </ol>
</nav>
```

<!-- ノート: リンク先はページ番号を渡すURLです。button ではなく a を使います。 -->

---

## buttonではなくaを使う

- ページ送りは「別のページへ移動する」操作
- 移動は `a`、その場での操作は `button`
- `a` なら新しいタブで開ける・URL を共有できる

<!-- ノート: 対比の枠。この使い分けは、あとのフォームのレッスンでも出てきます。 -->

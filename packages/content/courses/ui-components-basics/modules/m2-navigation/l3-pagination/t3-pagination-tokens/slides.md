# 2-3-3
# 押せる大きさをトークンで確保する

UI部品入門研修 — Module 2 / レッスン2-3

<!-- ノート: 3段階目です。ページ送りでは、トークンが「押しやすさ」に直結します。 -->

---

## なぜ必要か

- 番号の「1」は文字が細く、指では狙いにくい
- 「1」と「10」で幅が違い、並びがガタガタに見える

<!-- ノート: つかみ。小さすぎる当たり判定は、スマートフォンで押し間違いを生みます。 -->

---

## 結論

**番号のリンクは、トークンの余白と最小の寸法で押せる大きさを確保する**

- 余白で厚みを作る
- 最小の寸法で幅をそろえる

<!-- ノート: 結論。文字の大きさに任せず、部品側で下限を決めます。 -->

---

## 最小のコード

```css
:root {
  --tap-size: 44px;
  --space-2: 12px;
}
```

<!-- ノート: tap-sizeは「指で押せる最小の大きさ」という役割の名前です。 -->

---

## 部品側は参照だけ

```css
.pagination a {
  display: grid;
  place-items: center;
  min-inline-size: var(--tap-size);
  min-block-size: var(--tap-size);
  border-radius: var(--radius-1);
}
```

<!-- ノート: place-items: center は中身を縦横中央に置く指定です。1桁でも2桁でも同じ大きさになります。 -->

---

# 2-3-4
# 現在のページはリンクにしない

UI部品入門研修 — Module 2 / レッスン2-3

<!-- ノート: 4段階目の状態です。パンくずで使った印が、ここでも効きます。 -->

---

## なぜ必要か

- いま 3 ページ目にいるのに、「3」を押せてしまう
- 押しても同じページが再読み込みされるだけ

<!-- ノート: つかみ。押せるのに何も起きない操作は、迷いのもとです。 -->

---

## 結論

**現在のページはリンクにせず、`aria-current`を付けて見た目を反転する**

- リンクを外す … 押せなくする
- `aria-current="page"` … いまここだと伝える

<!-- ノート: 結論。パンくずの最後の項目と同じ考え方です。 -->

---

## 最小のコード

```html
<li><span aria-current="page">3</span></li>
```

```css
.pagination [aria-current="page"] {
  background-color: var(--accent);
  color: var(--surface);
}
```

<!-- ノート: 背景と文字色を入れ替えて、そこだけ塗りつぶした見た目にします。 -->

---

## 色の反転だけに頼らない

- 塗りつぶしは分かりやすいが、色だけの手がかり
- `aria-current` があれば、読み上げでも「現在のページ」と伝わる
- 見た目と印の両方を用意する

<!-- ノート: 失敗例の枠。見た目だけ・印だけ、どちらか片方では足りません。 -->

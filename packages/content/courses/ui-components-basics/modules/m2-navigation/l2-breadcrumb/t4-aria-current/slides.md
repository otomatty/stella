## なぜ必要か

- 色を濃くしただけでは、読み上げでは何も変わらない
- 「最後の項目が現在地」という約束は、機械には見えていない

<!-- ノート: つかみ。見た目で表した情報は、見た目を使えない人には届きません。 -->

---

## 結論

**現在地の項目は`aria-current="page"`で示し、その属性セレクタで見た目を変える**

- `aria-current` … いまここだと機械に伝える属性
- 角かっこのセレクタ = **属性セレクタ**

<!-- ノート: 結論。印を HTML に付け、その印を手がかりに CSS を当てます。 -->

---

## 最小のコード

```html
<li aria-current="page">UI部品 入門</li>
```

```css
.breadcrumb [aria-current="page"] {
  color: var(--ink);
  font-weight: 600;
}
```

<!-- ノート: HTMLに印を付け、CSSはその印で選びます。位置ではなく意味で選ぶ形です。 -->

---

## last-child で選んだ場合との違い

- `:last-child` … 位置で選ぶ。並べ替えると意味がずれる
- `[aria-current="page"]` … 意味で選ぶ。読み上げにも伝わる
- 同じ見た目でも、伝わる情報が違う

<!-- ノート: 対比の枠。この講座で繰り返し出てくる「意味で選ぶ」の実例です。 -->

# 主従はトークンの濃さで付ける

UI部品入門 — Module 2 / レッスン2-2

<!-- ノート: 3段階目です。パンくずは補助情報なので、本文より控えめに見せます。 -->

---

## なぜ必要か

- パンくずが本文と同じ濃さだと、ページの主役に見えてしまう
- 逆に薄くしすぎると、区切り記号も文字も読めない

<!-- ノート: つかみ。補助情報は「読めるが目立たない」濃さに置きます。 -->

---

## 結論

**パンくずの文字と区切りは、濃さの違うトークンで主従を付ける**

- 道のりのリンク … 少し控えめ
- 区切り記号 … いちばん薄い
- 現在地 … 本文と同じ濃さ

<!-- ノート: 結論。3段階の濃さを、既にあるトークンから選んで当てます。 -->

---

## 最小のコード

```css
:root {
  --ink: oklch(25% 0 0);
  --muted: oklch(55% 0 0);
  --faint: oklch(75% 0 0);
}
```

<!-- ノート: 濃さの違いも役割の名前で持ちます。muted は控えめ、faint は最も薄い、という意味です。 -->

---

## 部品側は参照だけ

```css
.breadcrumb {
  font-size: 0.875rem;

  a { color: var(--muted); }
  li:last-child { color: var(--ink); }
  li::after { color: var(--faint); }
}
```

<!-- ノート: 現在地だけが濃く、区切りが最も薄い。この差が「いまここ」を伝えます。 -->

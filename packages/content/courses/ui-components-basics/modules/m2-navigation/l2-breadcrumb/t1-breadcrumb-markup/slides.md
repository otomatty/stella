# 2-2-1
# パンくずは順番のあるol

UI部品入門 — Module 2 / レッスン2-2

<!-- ノート: 2つ目のナビ部品です。いまページのどこにいるかを示す帯を作ります。 -->

---

## なぜ必要か

- 検索から直接入ってきた人が、いまサイトのどこにいるか分からない
- 1 つ上の階層に戻る手段が、ブラウザーの戻るボタンしかない

<!-- ノート: つかみ。深い階層のページほど、現在位置の手がかりが要ります。 -->

---

## 結論

**パンくずリストは、上の階層から順に`nav`の中の`ol`で並べる**

- **パンくずリスト** = 現在位置までの道のりを示す帯
- 順番に意味があるので `ul` ではなく `ol`

<!-- ノート: 結論。順序が意味を持つ一覧なので、番号付きリストの ol を使います。 -->

---

## 最小のコード

```html
<nav class="breadcrumb" aria-label="パンくず">
  <ol>
    <li><a href="/">ホーム</a></li>
    <li><a href="/courses">研修一覧</a></li>
    <li>UI部品 入門</li>
  </ol>
</nav>
```

<!-- ノート: aria-labelは、ページに複数あるナビを読み上げで呼び分けるための名前です。 -->

---

## 最後の項目はリンクにしない

- 最後 = いま見ているページ
- 押しても同じページに来るだけ
- リンクにしないことで「ここが現在地」が伝わる

<!-- ノート: 対比の枠。最後だけ a で包まないのがパンくずの型です。 -->

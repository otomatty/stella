# ナビはnavとulで書く

UI部品入門研修 — Module 2 / レッスン2-1

<!-- ノート: Module 2 はナビゲーションの部品です。まずは骨格から作ります。 -->

---

## なぜ必要か

- リンクを `<a>` だけ横に並べると、いくつあるのか読み上げでは分からない
- ページのどこがナビなのか、機械には区別が付かない

<!-- ノート: つかみ。見た目は同じでも、リストにするかどうかで伝わり方が変わります。 -->

---

## 結論

**ナビゲーションは、`nav`の中の`ul`にリンクを1つずつ並べて書く**

- `nav` … ここが案内であることを示す
- `ul` … 項目が何個あるかを伝える

<!-- ノート: 結論。この2つが揃うと「5項目のナビゲーション」として読み上げられます。 -->

---

## 最小のコード

```html
<nav class="site-nav">
  <ul>
    <li><a href="/">ホーム</a></li>
    <li><a href="/courses">研修一覧</a></li>
  </ul>
</nav>
```

<!-- ノート: liで1項目ずつ包みます。順番に意味がないのでulを使います。 -->

---

## aだけを並べた場合との違い

- `a` だけ … 「リンク」が続くだけ。個数が伝わらない
- `nav` + `ul` … 「ナビゲーション、リスト、5 項目」と伝わる
- 見た目は CSS でどちらも同じにできる

<!-- ノート: 対比の枠。骨格の段階では、見た目ではなく伝わる情報で選びます。 -->

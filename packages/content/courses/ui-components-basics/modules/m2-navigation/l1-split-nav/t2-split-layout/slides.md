# 離す項目はautoマージンで寄せる

UI部品入門研修 — Module 2 / レッスン2-1

## なぜ必要か

- 左にメニュー、右にログイン。よくある形なのに書き方が思いつかない
- 幅を数えて `margin-left: 320px` と書くと、項目が増えた瞬間に崩れる

<!-- ノート: つかみ。固定値で押しやると、文言が1文字変わっただけでずれます。 -->

---

## 結論

**横並びのナビは、離したい項目に`margin-inline-start: auto`を当てると端へ寄る**

- 左右に分かれたナビを **スプリットナビ** と呼ぶ
- `auto` は「余った幅を全部ここに」の意味

<!-- ノート: 結論。autoマージンは余白を数えずに端へ寄せる、レイアウトの定番です。 -->

---

## 最小のコード

```css
.site-nav ul {
  display: flex;
  gap: 16px;
}

.site-nav li.login {
  margin-inline-start: auto;
}
```

<!-- ノート: 当てる相手は flex アイテム、つまり ul の直下の li です。中の a に付けても効きません。 -->

---

## 効かないときは当てる相手を見る

- `auto` が効くのは **flex アイテム** だけ
- `ul` が flex なら、アイテムは直下の `li`
- 中の `a` に付けても、余りは吸収されない

<!-- ノート: 失敗例の枠。いちばん多い間違いが、リンクの側に class を付けてしまうことです。 -->

# ナビのリンクの状態を描く

UI部品入門研修 — Module 2 / レッスン2-1

<!-- ノート: 4段階目です。前のトピックで下線を消したので、その代わりを用意します。 -->

---

## なぜ必要か

- 下線を消したので、どれがリンクなのか静止状態では分かりにくい
- キーボードで進んだとき、枠が出ないと現在位置を見失う

<!-- ノート: つかみ。装飾を消したなら、消したぶんの手がかりを別の形で返す必要があります。 -->

---

## 結論

**ナビのリンクは`&:hover`で色を変え、`&:focus-visible`で枠を出す**

- ホバーは「押せる」の合図
- フォーカスは「いまここ」の合図

<!-- ノート: 結論。2つは役割が別なので、両方書きます。 -->

---

## 最小のコード

```css
.site-nav a {
  &:hover {
    color: var(--accent);
  }

  &:focus-visible {
    outline: 2px solid var(--accent);
    outline-offset: 4px;
  }
}
```

<!-- ノート: outline-offsetは枠を少し外側に離す指定です。文字に食い込みません。 -->

---

## 色だけで伝えない

- 色の変化だけでは、色の見え方が違う人に伝わりにくい
- 下線を戻す・太さを変えるなど、形の変化も足すと確実

<!-- ノート: 失敗例の枠。ホバー時に text-decoration を戻すのが手軽で確実です。 -->

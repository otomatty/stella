# 2-1-3
# リンクの見た目をトークンでそろえる

UI部品入門 — Module 2 / レッスン2-1

<!-- ノート: 3段階目です。ナビのリンクは既定の見た目が主張しすぎるので、当て直します。 -->

---

## なぜ必要か

- リンクの既定は青くて下線付き。ナビに並ぶと落ち着かない
- 項目ごとに色を書くと、増えたときに書き忘れる

<!-- ノート: つかみ。ナビは同じ見た目の項目が並ぶ場所なので、既定のままだとうるさく見えます。 -->

---

## 結論

**ナビのリンクの色と余白は、トークンで全項目そろえる**

- 1 つのセレクタで全項目に当てる
- 色は役割のトークンから取る

<!-- ノート: 結論。項目ごとではなく「ナビの中のa」にまとめて当てます。 -->

---

## 最小のコード

```css
.site-nav a {
  color: var(--ink);
  padding-block: var(--space-2);
  text-decoration: none;
}
```

<!-- ノート: inkは本文の文字色というトークンです。下線は消し、状態のときだけ出します。 -->

---

## 押せる高さも余白で作る

- 文字だけだと当たり判定が細くて押しにくい
- `padding-block` で上下に厚みを持たせる
- 指でもマウスでも狙いやすくなる

<!-- ノート: 対比の枠。余白は見た目だけでなく、押しやすさのための指定でもあります。 -->

---

# レッスン1-1 カード

## このレッスンの目標

- [ ] カードの HTML 骨格を、意味の合う要素で書ける
- [ ] 中身の積み方と間隔を、親の指定だけで決められる
- [ ] 色・余白をトークンで当て、状態を押せる要素に書ける

## 1-1-1 カードはarticleで1つに囲む

> **カードは、見出し・本文・リンクをarticleで1つに囲んだ部品**

お知らせ・イベント・記事の一覧では、1 件ぶんの情報がひとかたまりの箱で並びます。この箱を **カード** と呼びます。

この講座では、こうした何度も出てくる見た目のかたまりを **部品** と呼び、部品ごとに次の 4 段階で仕上げます。

1. **HTML骨格** — 意味の合う要素で中身を囲む
2. **レイアウト** — 並べ方を決める
3. **トークン** — 色と余白を当てる
4. **状態** — ホバーやフォーカスの見た目を描く

1 段階目は HTML だけです。CSS はまだ 1 行も書きません。

```html
<article class="card">
  <h3>社内勉強会</h3>
  <p>毎週金曜の夕方に開催しています。</p>
  <a href="/events/study">詳細を見る</a>
</article>
```

囲む要素に `article` を選んだ理由は、カードが「それだけ取り出しても意味が通る 1 件」だからです。`div` でも見た目は同じにできますが、`div` は意味を持たない箱なので、読み上げソフトや検索エンジンには「1 件のまとまり」だと伝わりません。

判断に迷ったら、**切り出して別のページに置いても通じるか**で決めてください。通じるなら `article`、ページの中の区画にすぎないなら `section`、どちらでもなくレイアウトのためだけの箱なら `div` です。

`class="card"` は、あとで CSS を当てるための名前です。要素の種類ではなく class で当てるので、同じカードを `li` の中に置いても指定は変わりません。

## 1-1-2 カードの中身は縦に積む

> **カードの中身はflex-direction: columnで縦に積み、間隔はgapで空ける**

骨格ができたら 2 段階目のレイアウトです。ここで決めるのは **並べ方だけ** で、色にはまだ触りません。

HTML をそのまま表示すると、見出しと段落とリンクの間隔はブラウザーの既定にまかせた、ばらばらの値になります。カードの中は同じリズムで積みたいので、親がまとめて決めます。

```css
.card {
  display: flex;
  flex-direction: column;
  gap: 8px;

  > * {
    margin-block: 0;
  }
}
```

- `display: flex` … 子を並べる箱にする
- `flex-direction: column` … 積む向きを縦にする
- `gap: 8px` … 子と子の間隔をまとめて空ける
- `> * { margin-block: 0 }` … 見出しや段落が持っている既定の上下 margin を消す

最後の 1 つを忘れると、`gap` の 8px に `h3` や `p` の既定の margin が **足された**間隔になります。flex の子(フレックスアイテム)どうしでは margin が相殺されないので、既定の margin を残したままだと、間隔が要素の組み合わせごとにばらばらになります。まず 0 にしてから `gap` で決める、という順番です。

間隔を子ごとの `margin` で書くこともできますが、書き忘れが出ますし、先頭と末尾にも余白が付いてカードの `padding` と二重になります。`gap` は **間だけ**に効くので、**カードの中の間隔は親の `gap` に集める**と、子が増えても減っても崩れません。

この段階でやることは、レイアウトのレシピを 1 つ選んで書くところまでです。flex 自体の仕組みは HTML/CSS 入門で扱ったので、ここでは「縦積みなら column と gap」という**指定だけ**を覚えてください。

## 1-1-3 色と余白はトークンで当てる

> **カードの色と余白は、:rootに置いたトークンをvar()で参照して当てる**

3 段階目で、はじめて色を当てます。ここで部品ごとに好きな色を決めてしまうと、部品が増えるほどページ全体がちぐはぐになります。

そこで、値には役割の名前を付けて `:root` に集めます。この名前付きの値を **トークン** と呼びます。

```css
:root {
  --surface: oklch(99% 0 0);
  --surface-2: oklch(96% 0 0);
  --line: oklch(88% 0 0);
  --accent: oklch(55% 0.16 264);
  --space-3: 16px;
  --radius-1: 8px;
}
```

名前は `--gray-100` のような見た目そのままではなく、`--surface`(面の色)・`--surface-2`(一段沈んだ面。ホバーの背景などに使う)・`--line`(境界線)・`--accent`(目立たせる色)・`--radius-1`(角丸)のように **役割** で付けます。役割で付けておくと、あとで色を変えても名前が嘘になりません。

部品側は、この名前を参照するだけです。

```css
.card {
  background-color: var(--surface);
  border: 1px solid var(--line);
  padding: var(--space-3);
  border-radius: var(--radius-1);
}
```

**部品の CSS に生の値が 1 つも出てこない**のがこの段階の目標です。次のレッスン以降で作る部品も同じトークンを参照するので、ページ全体の見た目が自然にそろいます。この `:root` は、以降のレッスンでもそのまま使い続けます。

## 1-1-4 状態は押せる要素に当てる

> **カードの状態は、押せる要素に当てて部品の入れ子の中に書く**

最後の 4 段階目は **状態** です。状態とは、ホバー中・フォーカス中・選択中のような、そのときだけの見た目を指します。

ここで決めることが 2 つあります。**どの要素に当てるか**と、**どこに書くか**です。

当てる相手は **押せる要素** です。このカードで押せるのは「詳細を見る」のリンクだけで、カードの枠そのものは押せません。押せない場所の見た目が変わると、「ここを押せる」と読めてしまい、押しても何も起きません。

書く場所は **部品のまとまりの中** です。

```css
.card {
  background-color: var(--surface);
  border: 1px solid var(--line);

  a {
    &:hover {
      color: var(--accent);
    }

    &:focus-visible {
      outline: 2px solid var(--accent);
      outline-offset: 2px;
    }
  }
}
```

`&` は外側のセレクタ自身、ここでは `.card a` を指します。カードの波かっこの中にあるので、「このカードがどんなときにどう見えるか」は 1 か所を読めば分かります。

気をつけたいのは、`:hover` だけで終わらせないことです。`:hover` はマウスのある環境でしか起きません。キーボードで操作する人には何も起きないので、`:focus-visible` の枠を必ずセットで用意します。

`:focus-visible` は、**フォーカスの枠が必要なときだけ**当たる指定です。マウスでクリックしたときには枠が出ず、キーボードで進んだときには出ます。枠を `outline: none` で消したままにせず、この形で出し直してください。

カードの枠ごと押せるようにしたい場合は、見た目ではなくマークアップを変えます。その作り方は次のレッスンで扱います。

これで HTML 骨格 → レイアウト → トークン → 状態の 4 段階が 1 周しました。この順番は、以降のすべての部品で同じです。

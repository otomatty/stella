# カードはarticleで1つに囲む

UI部品入門研修 — Module 1 / レッスン1-1

<!-- ノート: この講座の1本目です。最初の部品はカードで、まずHTMLだけを書きます。 -->

---

## なぜ必要か

- お知らせやイベントを、ひとかたまりの箱で並べたい
- 見出しと本文とリンクがばらばらに置いてあると、どこまでが1件か分からない

<!-- ノート: つかみ。一覧ページで必ず出てくる形です。見た目の前に、まとまりの単位を決める必要があります。 -->

---

## 結論

**カードは、見出し・本文・リンクを`article`で1つに囲んだ部品**

- 何度も出てくる見た目のかたまりを **部品** と呼ぶ
- まず作るのは CSS のない **HTML骨格**

<!-- ノート: 結論。この講座では部品を4段階で作ります。1段階目がこのHTML骨格です。 -->

---

## 最小のコード

```html
<article class="card">
  <h3>社内勉強会</h3>
  <p>毎週金曜の夕方に開催しています。</p>
  <a href="/events/study">詳細を見る</a>
</article>
```

<!-- ノート: articleは「それだけ取り出しても意味が通るかたまり」に使います。classは後でCSSを当てるための名前です。 -->

---

## divで囲んだ場合との違い

- `div` でも見た目は同じにできる
- `article` は「独立した1件」だと機械にも伝わる
- 迷ったら、切り出して別の場所に置いても通じるかで決める

<!-- ノート: 対比の枠。見た目が同じでも、要素の選び方で伝わる情報が変わります。 -->

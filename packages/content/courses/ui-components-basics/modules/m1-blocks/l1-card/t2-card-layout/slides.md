# カードの中身は縦に積む

UI部品入門研修 — Module 1 / レッスン1-1

<!-- ノート: 骨格ができたので、2段階目のレイアウトです。並べ方だけを決めます。 -->

---

## なぜ必要か

- 見出しと本文とリンクの間隔が、要素ごとにばらばらに空く
- `margin` を1つずつ足していくと、足し忘れが出る

<!-- ノート: つかみ。既定の余白は要素ごとに違うので、そのままだとリズムが崩れます。 -->

---

## 結論

**カードの中身は`flex-direction: column`で縦に積み、間隔は`gap`で空ける**

- 積む向きは1行で決める
- 間隔は親が1か所で持つ

<!-- ノート: 結論。並べ方の指定は親に集め、子には書かないのがこの段階の型です。 -->

---

## 最小のコード

```css
.card {
  display: flex;
  flex-direction: column;
  gap: 8px;
}
```

<!-- ノート: 子が何個に増えても、間隔はこの1行が面倒を見ます。既定のmarginは別途0にしておきます。 -->

---

## margin で空けた場合との違い

- `margin` … 子ごとに書く。先頭と末尾にも余白が出る
- `gap` … 親に1回書く。間だけに効き、要素が増減しても崩れない

<!-- ノート: 対比の枠。gapは「間だけ」に効きます。カード内の間隔は親のgapに集約する、と覚えてください。 -->

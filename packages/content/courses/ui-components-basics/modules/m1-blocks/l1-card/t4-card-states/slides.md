# 1-1-4
# 状態は押せる要素に当てる

UI部品入門 — Module 1 / レッスン1-1

<!-- ノート: 4段階目、最後は状態です。カードはこれで完成します。 -->

---

## なぜ必要か

- マウスを乗せても何も変わらず、押せるのか分からない
- キーボードで進むと、いまどこにいるのか見えない

<!-- ノート: つかみ。動かない見た目のままだと、操作できることが伝わりません。 -->

---

## 結論

**カードの状態は、押せる要素に当てて部品の入れ子の中に書く**

- **状態** = ホバー中・フォーカス中のような、そのときだけの見た目
- カード自身は押せない。押せるのは中のリンク

<!-- ノート: 結論。当てる相手は押せる要素、書く場所は部品のまとまりの中です。 -->

---

## 最小のコード

```css
.card {
  a {
    &:hover { color: var(--accent); }
    &:focus-visible { outline: 2px solid var(--accent); }
  }
}
```

<!-- ノート: 当てる相手はカードの中のリンクですが、指定はカードの波かっこの中に置きます。 -->

---

## :hover だけで終わらせない

- `:hover` … マウスのある環境でしか起きない
- `:focus-visible` … キーボードで進んだときに枠が出る
- 両方書いて、はじめて全員に伝わる

<!-- ノート: 失敗例の枠。ホバーだけだと、キーボードやスマートフォンの利用者には何も起きません。 -->

# 色と余白はトークンで当てる

UI部品入門研修 — Module 1 / レッスン1-1

<!-- ノート: 3段階目です。並べ方が決まったので、色と余白を当てます。 -->

---

## なぜ必要か

- カードだけ枠の色が濃く、隣の部品と合っていない
- 部品を作るたびに新しい色と余白の値が増えていく

<!-- ノート: つかみ。部品ごとに値を決めると、ページ全体がちぐはぐになります。 -->

---

## 結論

**カードの色と余白は、`:root`に置いたトークンを`var()`で参照して当てる**

- **トークン** = 役割の名前を付けた値
- 部品側には生の値を書かない

<!-- ノート: 結論。値は1か所に集め、部品はそれを参照するだけにします。 -->

---

## 最小のコード

```css
:root {
  --surface: oklch(99% 0 0);
  --line: oklch(88% 0 0);
  --accent: oklch(55% 0.16 264);
  --space-3: 16px;
}
```

<!-- ノート: まず値に名前を付けます。surfaceは面の色、lineは境界線の色という役割の名前です。 -->

---

## 部品側は参照だけ

```css
.card {
  background-color: var(--surface);
  border: 1px solid var(--line);
  padding: var(--space-3);
}
```

<!-- ノート: 部品側に生の色が1つも無いのが目標です。次の部品も同じトークンを参照します。 -->

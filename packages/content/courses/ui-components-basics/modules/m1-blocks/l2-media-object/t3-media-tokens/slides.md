# 1-2-3
# 画像の幅はトークンで決める

UI部品入門研修 — Module 1 / レッスン1-2

<!-- ノート: 3段階目です。この部品では、色よりも先に「画像の大きさ」がトークンの出番になります。 -->

---

## なぜ必要か

- コメント欄は 40px、通知は 48px と、画面ごとに顔写真の大きさが違う
- 画像の元サイズがばらばらだと、並べたときに行の高さが揃わない

<!-- ノート: つかみ。同じ部品なのに大きさが揃っていないと、リストが不揃いに見えます。 -->

---

## 結論

**画像の幅と本文との間隔は、トークンの値を`var()`で当てて決める**

- 画像の幅もトークンにする
- 元画像の大きさに見た目を任せない

<!-- ノート: 結論。寸法もまた「役割のある値」なので、色や余白と同じくトークンにできます。 -->

---

## 最小のコード

```css
:root {
  --avatar-size: 48px;
  --space-2: 12px;
}
```

<!-- ノート: avatar-sizeは「一覧に並ぶ人物画像の大きさ」という役割の名前です。 -->

---

## 部品側は参照だけ

```css
.media {
  gap: var(--space-2);

  img {
    inline-size: var(--avatar-size);
    block-size: var(--avatar-size);
    object-fit: cover;
  }
}
```

<!-- ノート: object-fitは、比率の合わない画像を枠に収める指定です。正方形の枠に切り抜いて収めます。 -->

# 全体を押させるなら囲みごとリンクにする

UI部品入門研修 — Module 1 / レッスン1-2

<!-- ノート: 4段階目の状態です。前のレッスンとは逆の場合を扱います。 -->

---

## なぜ必要か

- 通知の行は、どこを押しても開いてほしい
- 中のリンクだけが押せると、狙いを外した指が反応しない

<!-- ノート: つかみ。行全体を押させたい部品は珍しくありません。 -->

---

## 結論

**メディアオブジェクト全体を押させたいときは、囲みごとリンクにして状態を当てる**

- 見た目で押せるようにするのではない
- 囲みの要素そのものを `a` にする

<!-- ノート: 結論。押せる範囲はマークアップで決まります。CSSでは広げられません。 -->

---

## 最小のコード

```html
<a class="media" href="/notices/1">
  <img src="./avatar.png" alt="">
  <div class="media-body">
    <p>15時から会議室Aです。</p>
  </div>
</a>
```

<!-- ノート: 囲みの div を a に変えるだけです。a は中に段落や画像を入れられます。 -->

---

## 状態は囲み自身に当たる

```css
.media {
  &:hover { background-color: var(--surface-2); }
  &:focus-visible { outline: 2px solid var(--accent); }
}
```

- 押せる範囲と、見た目が変わる範囲が一致する

<!-- ノート: 対比の枠。div のままで .media:hover を書くと、押せないのに押せるように見えます。 -->

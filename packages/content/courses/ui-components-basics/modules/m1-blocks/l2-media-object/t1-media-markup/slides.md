# メディアオブジェクトは画像と本文

UI部品入門 — Module 1 / レッスン1-2

<!-- ノート: 2つ目の部品です。コメント欄や通知でおなじみの、顔写真と本文が横に並ぶ形を作ります。 -->

---

## なぜ必要か

- コメント・通知・プロフィールで、同じ「画像 + 本文」の形が何度も出る
- そのたびに違う書き方をすると、間隔も位置もそろわない

<!-- ノート: つかみ。名前の付いた型を1つ持っておくと、同じ形を毎回作り直さずに済みます。 -->

---

## 結論

**メディアオブジェクトは、画像と本文が横に並ぶ2つの中身だけの部品**

- 中身は必ず 2 つ。増やさない
- 投稿者名も本文の枠の中に入れる

<!-- ノート: 結論。「2つだけ」という制約が、この部品を使い回せるものにしています。 -->

---

## 最小のコード

```html
<div class="media">
  <img src="./avatar.png" alt="">
  <div class="media-body">
    <p><strong>佐藤</strong></p>
    <p>15時から会議室Aです。</p>
  </div>
</div>
```

<!-- ノート: 本文側に投稿者名を置きます。名前が文字で読めるので、隣の顔写真は飾りになり alt は空にします。 -->

---

## 画像の alt は文脈で決まる

- 隣に投稿者名がある → 画像は飾り。`alt=""`
- 名前が画像だけにしかない → `alt="佐藤"` のように書く
- 「顔写真だから空」ではなく、**文字で読めるかどうか**で決める

<!-- ノート: 対比の枠。同じ顔写真でも、隣に名前があるかどうかでaltの答えが変わります。 -->

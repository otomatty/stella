# レッスン1-2 メディアオブジェクト

## このレッスンの目標

- [ ] 画像 + 本文の 2 枠で骨格を書け、`alt` を文脈で決められる
- [ ] 横並びの縦位置と、本文の枠を広げる指定を書ける
- [ ] 全体を押させたいときに、囲みごとリンクにできる

## 1-2-1 メディアオブジェクトは画像と本文

> **メディアオブジェクトは、画像と本文が横に並ぶ2つの中身だけの部品**

コメント欄・通知・プロフィールの行には、同じ形が何度も出てきます。左に小さな画像、右に本文。この形を **メディアオブジェクト** と呼びます。

```html
<div class="media">
  <img src="./avatar.png" alt="">
  <div class="media-body">
    <p><strong>佐藤</strong></p>
    <p>15時から会議室Aです。</p>
  </div>
</div>
```

中身は **必ず 2 つ** です。画像の枠と、本文の枠。投稿者名も本文の枠の中に入れます。3 つ目を横に足したくなったら、それは別の部品を作るサインです。この「2 つだけ」という制約があるから、どこにでも置いて使い回せます。

`alt=""` と空にしてよいのは、**同じ情報が隣の文字で読めるとき**です。上の例では投稿者名の「佐藤」が本文の枠にあるので、顔写真は飾りになります。

判断は「顔写真だから空」ではありません。文脈で決めます。

- 隣に投稿者名がある → 画像は飾り。`alt=""`
- 名前が顔写真にしかない → その画像が唯一の手がかりなので、`alt="佐藤"` のように書く
- 画像自体が本題(グラフや写真) → `alt` に内容を書く

迷ったら、**画像を消しても同じことが分かるか**を確かめてください。分からなくなるなら、空にしてはいけません。

前のレッスンのカードと比べると、違いは並ぶ向きと枠の数だけです。カードは 1 件ぶんを縦に積んだ箱、メディアオブジェクトは画像と本文を横に並べた 2 枠。部品に名前を付けておくと、この違いを短く言えます。

## 1-2-2 横並びは上端でそろえる

> **メディアオブジェクトはflexで横に並べ、align-items: flex-startで上端にそろえる**

2 段階目のレイアウトです。横に並べるだけなら `display: flex` の 1 行ですが、それだけだと縦の揃え方が思ったとおりになりません。

```css
.media {
  display: flex;
  gap: 12px;
  align-items: flex-start;
}
```

`align-items` の既定値は `stretch` です。stretch は「交差軸(ここでは縦)のサイズを、行の高さに合わせて引き伸ばす」という意味なので、**高さを指定していない画像は縦に引き伸ばされて歪みます**。本文が 5 行あれば、画像もその 5 行ぶんの高さに伸びます。

`flex-start` を明示すると引き伸ばしが止まり、本文が何行になっても画像は元の比率のまま上端に置かれます(このあと画像に高さを指定するので、そのときは伸びませんが、`flex-start` は「上端に置く」という意図をはっきりさせます)。

なお、次のトピックで足す `object-fit: cover` を当てていると、stretch で伸びるのは **画像の枠** で、中の絵は歪まずに切り取られます。歪むのは `object-fit` を書いていないときです。

もう 1 つ、本文の枠に次を足します。

```css
.media-body {
  flex: 1;
}
```

`flex: 1` は「主軸(ここでは横)の余った幅を、この枠が受け取って広がる」という指定です。書かないと、本文の箱は中身の幅までしか広がりません。本文に背景色や境界を付けたときや、文字の折り返し位置に差が出ます。

flex の仕組みそのものは HTML/CSS 入門で扱いました。ここで覚えるのは **この部品のレシピ**、つまり「`display: flex` + `align-items: flex-start` + 本文に `flex: 1`」という組み合わせです。

## 1-2-3 画像の幅はトークンで決める

> **画像の幅と本文との間隔は、トークンの値をvar()で当てて決める**

3 段階目です。この部品では色よりも先に、**画像の大きさ**がトークンの出番になります。

画像の元サイズはばらばらです。何も指定しないと、行ごとに高さが変わって一覧が不揃いに見えます。

```css
:root {
  --avatar-size: 48px;
  --space-2: 12px;
}

.media {
  gap: var(--space-2);

  img {
    inline-size: var(--avatar-size);
    block-size: var(--avatar-size);
    object-fit: cover;
  }
}
```

- `--avatar-size` … 「一覧に並ぶ人物画像の大きさ」という役割の名前
- `inline-size` / `block-size` … 論理プロパティで書いた幅と高さ
- `object-fit: cover` … 比率の合わない画像を、枠いっぱいに切り抜いて収める

寸法もまた役割のある値なので、色や余白と同じくトークンにできます。`--avatar-size` を 1 か所変えれば、コメント欄も通知もまとめて変わります。

## 1-2-4 全体を押させるなら囲みごとリンクにする

> **メディアオブジェクト全体を押させたいときは、囲みごとリンクにして状態を当てる**

4 段階目の状態です。前のレッスンでは「状態は押せる要素に当てる」と学びました。カードで押せたのは中のリンクだけだったので、状態もそのリンクに当てました。

では、通知の行のように **どこを押しても開いてほしい** 部品はどう作るのでしょうか。

答えは CSS ではありません。押せる範囲は **マークアップで決まります**。囲みの要素そのものをリンクにします。

```html
<a class="media" href="/notices/1">
  <img src="./avatar.png" alt="">
  <div class="media-body">
    <p><strong>佐藤</strong></p>
    <p>15時から会議室Aです。</p>
  </div>
</a>
```

`div` を `a` に変えただけです。`a` の中には段落や画像を入れられます。

1 つ制約があります。**リンクの中にリンクは置けません。** 行全体をリンクにするなら、中にあった「返信する」のようなリンクは外に出すか、`button` などリンク以外の操作に変えます(不正な HTML はブラウザーが勝手に組み替えるので、思ったとおりには動きません)。

囲み自身が押せるようになったので、状態も囲み自身に当てられます。

```css
.media {
  &:hover {
    background-color: var(--surface-2);
  }

  &:focus-visible {
    outline: 2px solid var(--accent);
    outline-offset: 2px;
  }
}
```

これで **押せる範囲と、見た目が変わる範囲が一致します**。

やってはいけないのは、`div` のままで `.media:hover` を書くことです。行全体の色が変わるので「ここを押せる」と読めますが、実際に押せるのは中のリンクだけです。見た目が約束したことを、マークアップが果たせていません。

まとめると、判断はこうなります。

- 押せるのが中のリンクだけ → 状態はそのリンクに当てる(レッスン1-1 のカード)
- 全体を押させたい → 囲みごと `a` にしてから、囲みに状態を当てる(この形)

**見た目で押せる範囲を広げることはできない**、と覚えてください。

# 横並びは上端でそろえる

UI部品入門 — Module 1 / レッスン1-2

<!-- ノート: 2段階目のレイアウトです。横に並べるだけでなく、縦のそろえ方も決めます。 -->

---

## なぜ必要か

- 本文が長いコメントだけ、画像が縦に間のびして見える
- 高さを指定していない画像が、行の高さに合わせて伸びてしまう

<!-- ノート: つかみ。横に並べただけでは、交差軸の既定の揃え方が画像に効いてしまいます。 -->

---

## 結論

**メディアオブジェクトは`flex`で横に並べ、`align-items: flex-start`で上端にそろえる**

- 並べる向きは横
- 縦の位置は「上端」で固定する

<!-- ノート: 結論。既定のstretchは交差軸のサイズを親に合わせて引き伸ばすので、flex-startを明示します。 -->

---

## 最小のコード

```css
.media {
  display: flex;
  gap: 12px;
  align-items: flex-start;
}
```

<!-- ノート: flexは既定で横並びなので、directionは書きません。gapは画像と本文の間隔です。 -->

---

## 本文の枠を余りまで広げる

```css
.media-body {
  flex: 1;
}
```

- 本文の箱が、主軸(横)の余った幅を受け取って広がる
- 書かないと、箱は中身の幅までしか広がらない

<!-- ノート: 対比の枠。背景色や境界を付けると差が見えます。文字の折り返し位置も変わります。 -->

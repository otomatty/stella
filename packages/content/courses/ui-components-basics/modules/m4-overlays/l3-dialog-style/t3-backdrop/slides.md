# 4-3-3
# 背面の暗さは::backdrop

UI部品入門研修 — Module 4 / レッスン4-3

<!-- ノート: 講座の最後のトピックです。4段階目の状態にあたる、背面の見た目です。 -->

---

## なぜ必要か

- ダイアログと背面のページが同じ明るさで、どちらを見ればいいか迷う
- 背面を暗くしたいが、そのための要素を置きたくない

<!-- ノート: つかみ。暗い面のためにdivを1枚足すのは、昔からの手でした。 -->

---

## 結論

**モーダルの背面の暗さは`::backdrop`で指定する**

- `::backdrop` … 前面の要素の後ろに敷かれる面
- HTML に要素を足さなくてよい

<!-- ノート: 結論。モーダルで開いたときだけ、この面が現れます。 -->

---

## 最小のコード

```css
dialog::backdrop {
  background-color: oklch(0% 0 0 / 0.5);
}
```

<!-- ノート: 黒の半透明です。0.5 は透け具合で、数字を上げるほど背面が暗くなります。 -->

---

## 暗くしすぎない

- 濃すぎると、背面の文脈が読めなくなる
- 薄すぎると、前面との差が付かない
- 目安は半分前後

<!-- ノート: 失敗例の枠。真っ黒にすると「どこから来たか」を見失わせます。 -->

---

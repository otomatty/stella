# 中身はトークンで組む

## なぜ必要か

- ダイアログだけ枠が太く、角も四角くて浮いて見える
- 中の見出し・本文・ボタンの間隔がばらばら

<!-- ノート: つかみ。前面に出る部品ほど、ページとの一体感が要ります。 -->

---

## 結論

**ダイアログの余白・境界・角丸は、他の部品と同じトークンで当てる**

- 値は増やさない
- 中身は縦に積む

<!-- ノート: 結論。この講座で作ってきた部品と、まったく同じ4つのトークンです。 -->

---

## 最小のコード

```css
dialog {
  border: 1px solid var(--line);
  border-radius: var(--radius-1);
  padding: var(--space-3);
  background-color: var(--surface);
}
```

<!-- ノート: カード・details・ポップオーバーと同じ4行です。 -->

---

## 中身の積み方

```css
dialog[open] {
  display: flex;
  flex-direction: column;
  gap: var(--space-2);
}

dialog > * { margin-block: 0; }
```

- `display` は開いている間だけに限る
- 既定の margin を 0 にしてから `gap` で決める

<!-- ノート: dialog に直接 display を書くと、閉じている間も表示されてしまいます。理由は doc にあります。 -->

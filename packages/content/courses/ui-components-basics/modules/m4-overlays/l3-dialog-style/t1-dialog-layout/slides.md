# 幅と位置は論理プロパティで決める

UI部品入門 — Module 4 / レッスン4-3

<!-- ノート: 最後のレッスンです。開いたダイアログの見た目を、2段階目から仕上げます。 -->

---

## なぜ必要か

- 文章が短いときは細く、長いときは画面いっぱいに広がってしまう
- 幅を固定すると、狭い画面ではみ出す

<!-- ノート: つかみ。中身の量に見た目が振り回されないよう、上限を決めます。 -->

---

## 結論

**ダイアログの幅と位置は、`max-inline-size`と`margin: auto`で決める**

- 幅は上限だけ決める
- 位置は自動マージンで中央に

<!-- ノート: 結論。固定値ではなく上限にするのが、狭い画面でも壊れない書き方です。 -->

---

## 最小のコード

```css
dialog {
  box-sizing: border-box;
  max-inline-size: 32rem;
  inline-size: calc(100% - 2rem);
  margin: auto;
}
```

<!-- ノート: 上限は32rem、狭い画面では左右に1remずつ余白が残ります。border-boxが無いと余白とはみ出しが変わります。 -->

---

## 中身が長いとき

```css
dialog {
  max-block-size: 80dvh;
  overflow: auto;
}
```

- 縦も画面を超えないよう上限を決める
- 超えた分は中でスクロールさせる

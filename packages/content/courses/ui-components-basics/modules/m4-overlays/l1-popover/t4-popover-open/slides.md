# 4-1-4
# 開いている間は:popover-open

UI部品入門研修 — Module 4 / レッスン4-1

<!-- ノート: 4段階目の状態です。detailsの[open]に当たるものが、ここにもあります。 -->

---

## なぜ必要か

- 開いている間だけ、影を強くしたり枠を目立たせたりしたい
- 閉じているときの指定と混ざると、読み分けられない

<!-- ノート: つかみ。状態ごとの指定は、状態のセレクタで分けておくと読めます。 -->

---

## 結論

**開いているポップオーバーは`:popover-open`で選び、見た目を変えられる**

- 開いている間だけ当たる
- 閉じている間は既定で表示されない

<!-- ノート: 結論。details の [open] と同じ役割の、ポップオーバー版です。 -->

---

## 最小のコード

```css
[popover]:popover-open {
  border-color: var(--accent);
}
```

<!-- ノート: 開いている間だけ枠の色が変わります。閉じているときは何も描かれません。 -->

---

## [open]との違い

- `details[open]` … HTML の属性を見ている
- `:popover-open` … ブラウザーが持つ状態を見ている
- どちらも「いま開いているか」で当てる形は同じ

<!-- ノート: 対比の枠。書き方は違っても、状態で選ぶという考え方は共通です。 -->

# 4-1-3
# 中身の見た目はトークンで当てる

UI部品入門 — Module 4 / レッスン4-1

<!-- ノート: 3段階目です。ポップオーバーにも既定の枠があるので、当て直します。 -->

---

## なぜ必要か

- 既定の細い枠と余白が、ページの他の部品と合わない
- 重ねて出す面なので、背景が透けると読めない

<!-- ノート: つかみ。重ねる部品では、背景色を必ず自分で持つ必要があります。 -->

---

## 結論

**ポップオーバーの余白・角丸・境界はトークンで当てて、他の部品とそろえる**

- 使う値はカードと同じトークン
- 背景色は必ず指定する

<!-- ノート: 結論。ここでも新しい値は増やさず、既にあるトークンを参照します。 -->

---

## 最小のコード

```css
[popover] {
  border: 1px solid var(--line);
  border-radius: var(--radius-1);
  padding: var(--space-2);
  background-color: var(--surface);
}
```

<!-- ノート: カードと同じ4行です。重ねても下が透けません。 -->

---

## 浮いていることを示す

```css
[popover] {
  box-shadow: 0 8px 24px oklch(0% 0 0 / 0.15);
}
```

- 影は「上に浮いている」ことの手がかり
- 濃くしすぎず、薄く広げる

<!-- ノート: 関連情報の枠。重ねて出す部品にだけ影を使うと、階層が伝わります。 -->

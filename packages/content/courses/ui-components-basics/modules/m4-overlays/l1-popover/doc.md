# レッスン4-1 ポップオーバー

## このレッスンの目標

- [ ] `popover` と `popovertarget` で開閉する面を作れる
- [ ] 最前面に出る部品の位置を `inset` と `margin` で決められる
- [ ] 開いている間の見た目を `:popover-open` で書ける

## 4-1-1 popoverは属性2つで開閉する

> **popover属性を付けた要素は、popovertargetで指すボタンだけで開閉できる**

ボタンを押したら小さなメニューを出したい、という場面があります。前のレッスンの `details` でも開閉はできますが、**他の要素の上に重ねて出す**ことはできません。

重ねて出す小さな面を **ポップオーバー** と呼びます。必要な属性は 2 つだけです。

```html
<button popovertarget="menu">メニュー</button>

<div id="menu" popover>
  <a href="/profile">プロフィール</a>
  <a href="/logout">ログアウト</a>
</div>
```

- **popover属性** … この要素をポップオーバーにする
- **popovertarget** … 開閉の相手を `id` で指すボタンの属性

この 2 つを書くだけで、次のふるまいが手に入ります。

- ボタンを押すと開き、もう一度押すと閉じる
- ポップオーバーの外側を押すと閉じる
- Esc キーで閉じ、フォーカスがボタンへ戻る
- Tab を押すと、続きがポップオーバーの中になる

自分で書こうとすると難しいのは、外側を押したときの判定と Esc の処理です。それが既定で付いてきます。

1 つ、勘違いしやすい点があります。**開いた瞬間にフォーカスが中へ飛ぶわけではありません。** 開いてもフォーカスはボタンに残ったままで、そこから Tab を押すとポップオーバーの中へ進みます(画面上の位置ではなく、この関係で順番が決まります)。

開いたらすぐ中の要素にフォーカスを当てたいときは、その要素に `autofocus` を書きます。

```html
<div id="menu" popover>
  <a href="/profile" autofocus>プロフィール</a>
</div>
```

これはモーダルのダイアログとの違いでもあります。ダイアログは背面を止めてフォーカスを閉じ込めますが、ポップオーバーは背面をそのまま使えます。

> **この機能は比較的新しく、古いブラウザーでは動きません。** 動かない環境では書いた結果の確認までに留め、代わりに動く JavaScript(フォールバック)は書きません。この講座の範囲は HTML と CSS だけです。業務で使うかどうかは、対象ブラウザーの範囲を見て案件ごとに判断してください。

## 4-1-2 ポップオーバーは最前面に出る

> **ポップオーバーは最前面に出るので、位置はinsetとmarginで決める**

2 段階目のレイアウトです。重ねて出す部品は、位置の決め方がこれまでと違います。

ポップオーバーは **最前面** に出ます。ページのどの要素よりも上に描かれる、専用の層です。この層に出るおかげで、次の 2 つの悩みが消えます。

- 親に `overflow: hidden` があっても、はみ出した部分が切られない
- `z-index` を足し合う争いにならない

位置の既定は「画面の中央」です。ブラウザーが `inset: 0` と `margin: auto` を当てているので、上下左右の余りが均等に分かれて中央に来ます。

ボタンの近くに出したいときは、この既定を書き換えます。

```css
[popover] {
  inset: auto;
  inset-block-start: 64px;
  inset-inline-end: 16px;
  margin: 0;
}
```

`inset: auto` でいったん中央寄せを解いてから、出したい辺だけを指定するのがコツです。`margin: 0` を忘れると、`auto` のマージンが残って位置がずれます。

中央のままでよければ、位置の指定は要りません。何も書かなくても画面中央に出ます。

## 4-1-3 中身の見た目はトークンで当てる

> **ポップオーバーの余白・角丸・境界はトークンで当てて、他の部品とそろえる**

3 段階目です。ポップオーバーにもブラウザーの既定の枠と余白があるので、当て直します。

```css
[popover] {
  border: 1px solid var(--line);
  border-radius: var(--radius-1);
  padding: var(--space-2);
  background-color: var(--surface);
}
```

カードや `details` と **同じ 4 行** です。同じトークンを参照しているので、重ねて出しても浮かずになじみます。

1 つだけ、重ねる部品ならではの注意があります。**背景色は必ず自分で指定してください。** 透明のままだと下の文字が透けて読めなくなります。

浮いていることを示したいときは、影を足します。

```css
[popover] {
  box-shadow: 0 8px 24px oklch(0% 0 0 / 0.15);
}
```

影は「上に浮いている」という手がかりです。濃くしすぎず、薄く広げるのがコツです。重ねて出す部品にだけ影を使うと、ページの階層が見た目で伝わります。

## 4-1-4 開いている間は:popover-open

> **開いているポップオーバーは:popover-openで選び、見た目を変えられる**

4 段階目の状態です。`details` の `[open]` に当たるものが、ポップオーバーにもあります。

```css
[popover]:popover-open {
  border-color: var(--accent);
  box-shadow: 0 12px 32px oklch(0% 0 0 / 0.2);
}
```

`:popover-open` は、開いている間だけ当たります。閉じている間はそもそも表示されないので、閉じたときの見た目を書く必要はありません。

`details[open]` との違いは、状態の在りかです。

- `details[open]` … HTML の `open` 属性を見ている
- `:popover-open` … ブラウザーが持つ開閉の状態を見ている

書き方は違いますが、**「いま開いているか」で当てる**という形は同じです。開閉する部品では、この形が繰り返し出てきます。

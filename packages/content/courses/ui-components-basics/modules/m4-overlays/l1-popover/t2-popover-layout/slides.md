# 4-1-2
# ポップオーバーは最前面に出る

UI部品入門研修 — Module 4 / レッスン4-1

<!-- ノート: 2段階目のレイアウトです。重ねて出す部品は、位置の決め方が他と違います。 -->

---

## なぜ必要か

- 親要素に `overflow: hidden` があっても、メニューを切りたくない
- `z-index` を足していく戦いから抜けたい

<!-- ノート: つかみ。重なりの制御は、これまで z-index の数値争いになりがちでした。 -->

---

## 結論

**ポップオーバーは最前面に出るので、位置は`inset`と`margin`で決める**

- **最前面** = ページのどの要素より上に描かれる層
- 既定では画面の中央に出る

<!-- ノート: 結論。最前面に出るので、z-index も overflow も関係しなくなります。 -->

---

## 最小のコード

```css
[popover] {
  inset: auto;
  inset-block-start: 64px;
  inset-inline-end: 16px;
  margin: 0;
}
```

<!-- ノート: 既定の中央寄せを一度 auto で解いてから、出したい位置を決めます。 -->

---

## 中央のまま使うとき

- 既定は `inset: 0` と `margin: auto` で中央
- そのまま使えるなら、位置の指定は不要
- ボタンの隣に出したいときだけ書き換える

<!-- ノート: 対比の枠。何も書かなければ画面中央に出ます。 -->

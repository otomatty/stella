# 4-2-1
# dialogは既定で閉じている

UI部品入門研修 — Module 4 / レッスン4-2

<!-- ノート: Module 4 の2つ目です。確認や入力を、いったん受け止める面を作ります。 -->

---

## なぜ必要か

- 削除の確認を、ページ遷移せずにその場で取りたい
- 自前で作った確認画面は、閉じ忘れやフォーカスの迷子が起きやすい

<!-- ノート: つかみ。確認ダイアログは自作が難しい部品の代表です。 -->

---

## 結論

**`dialog`は既定で閉じていて、開くまでページに表示されない**

- **ダイアログ** = 作業を受け止める面
- 書いても、開くまでは出てこない

<!-- ノート: 結論。まずこの性質を知らないと「書いたのに出ない」で止まります。 -->

---

## 最小のコード

```html
<dialog id="confirm">
  <p>この講座の受講を取り消しますか?</p>
</dialog>
```

<!-- ノート: これだけでは画面に何も出ません。閉じているのが既定の状態だからです。 -->

---

## div で作った確認画面との違い

- `div` … 自分で隠して、自分で出す
- `dialog` … 閉じているのが既定。開き方は次のトピック
- 閉じ忘れの状態が生まれない

<!-- ノート: 対比の枠。状態の初期値がブラウザー側にあるのが利点です。 -->

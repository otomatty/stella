# 4-2-3
# 中のボタンでcloseする

UI部品入門 — Module 4 / レッスン4-2

<!-- ノート: 開けたら、閉じ方も用意します。閉じられないダイアログは事故です。 -->

---

## なぜ必要か

- 開いたはいいが、閉じるボタンが無い
- Esc キーを知らない利用者が、そこから進めなくなる

<!-- ノート: つかみ。閉じる手段は、必ず目に見える形で置きます。 -->

---

## 結論

**ダイアログの中に`command="close"`のボタンを置くと、そのボタンで閉じられる**

- 開くときと同じ 2 属性
- 値が `close` になるだけ

<!-- ノート: 結論。開く・閉じるが同じ書き方で揃うのが、この仕組みの良いところです。 -->

---

## 最小のコード

```html
<dialog id="confirm">
  <p>この講座の受講を取り消しますか?</p>
  <button command="close" commandfor="confirm">やめる</button>
</dialog>
```

<!-- ノート: 中に置くボタンでも、commandfor で相手を明示します。 -->

---

## 閉じる手段は2つ以上

- 画面に見える「閉じる」ボタン
- Esc キー(モーダルなら既定で効く)
- 押し間違いが怖い操作ほど、逃げ道を広く

<!-- ノート: 関連情報の枠。見える手段と、既定のふるまいの両方を用意します。 -->

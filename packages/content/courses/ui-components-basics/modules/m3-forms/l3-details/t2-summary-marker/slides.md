# summaryの印は置き換えられる

UI部品入門 — Module 3 / レッスン3-3

---

## なぜ必要か

- 既定の三角の形が、ページの他の記号と合っていない
- 印と文字の間隔が詰まっていて読みにくい

<!-- ノート: つかみ。既定のままでも動きますが、他の部品と印象がそろいません。 -->

---

## 結論

**`summary`の既定の三角は`::marker`で消して、自分の印に置き換えられる**

- `::marker` … リストや `summary` の印を指す
- 消したら、代わりの印を必ず置く

<!-- ノート: 結論。印を消すだけだと、開閉できることが伝わらなくなります。 -->

---

## 最小のコード

```css
summary {
  display: flex;
  gap: 8px;
  cursor: pointer;

  &::marker {
    content: "";
  }
}
```

<!-- ノート: contentを空にして既定の三角を消し、flexで印と文字を並べる準備をします。 -->

---

## 代わりの印を置く

```css
summary::before {
  content: "＋";
  color: var(--muted);
}
```

- 印は `::before` で足す
- 開いたときの印は、次のトピックで切り替える

<!-- ノート: 対比の枠。区切り記号のときと同じで、飾りの文字はCSS側に置きます。 -->

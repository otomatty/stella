# 開いている間は[open]で選ぶ

UI部品入門研修 — Module 3 / レッスン3-3

<!-- ノート: 4段階目の状態です。開閉の部品の状態は「開いているかどうか」です。 -->

---

## なぜ必要か

- 印が「＋」のままなので、開いているのか閉じているのか分からない
- 開いている項目を目立たせて、読む場所を示したい

<!-- ノート: つかみ。開閉は状態が2つある部品なので、両方の見た目が要ります。 -->

---

## 結論

**開いている`details`は`[open]`の属性セレクタで選び、見た目を変えられる**

- 開くと `open` 属性が付く
- 閉じると外れる

<!-- ノート: 結論。パンくずの aria-current と同じ、属性を手がかりに選ぶ形です。 -->

---

## 最小のコード

```css
details[open] {
  border-color: var(--accent);

  summary::before {
    content: "−";
  }
}
```

<!-- ノート: 開いている間だけ枠の色が変わり、印がマイナスに変わります。 -->

---

## 状態はHTMLに現れる

- `open` はブラウザーが自動で付け外しする属性
- CSS は「いま付いているか」を見るだけ
- JavaScript で状態を持たなくてよい

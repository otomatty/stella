# 3-2-4
# 選択と操作不可を状態で描く

UI部品入門研修 — Module 3 / レッスン3-2

<!-- ノート: レッスン3-2の最後です。フォームには、フォーカス以外にも状態があります。 -->

---

## なぜ必要か

- 選んだ項目が、小さな丸の塗りつぶしでしか分からない
- 押せないボタンなのに、見た目が普通のボタンと同じ

<!-- ノート: つかみ。状態が見えないと、操作の結果が確認できません。 -->

---

## 結論

**選ばれている・操作できないという状態は、`:checked`と`:disabled`で見た目を変える**

- `:checked` … 選ばれているとき
- `:disabled` … 操作できないとき

<!-- ノート: 結論。どちらもブラウザーが持っている状態を、CSS から選ぶ書き方です。 -->

---

## 最小のコード

```css
input:checked + label {
  font-weight: 600;
  color: var(--accent);
}
```

<!-- ノート: + は直後の要素を指す結合子です。選ばれた入力の隣のラベルだけが変わります。 -->

---

## 操作できない状態

```css
button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
```

- 薄くして「いまは押せない」と伝える
- 消してしまうと、条件が揃えば押せることが分からない

<!-- ノート: 対比の枠。無効なボタンは隠すより、薄く残すほうが親切です。 -->

# 3-2-1
# 1行1組で縦に積む

UI部品入門研修 — Module 3 / レッスン3-2

<!-- ノート: 前のレッスンで作った骨格に、ここから見た目を当てます。まずレイアウトです。 -->

---

## なぜ必要か

- ラベルと入力欄が行の途中で折り返して、どれがどれか分からない
- 入力欄の幅がばらばらで、視線が左右に振られる

<!-- ノート: つかみ。フォームは「上から順に埋める」形がいちばん迷いません。 -->

---

## 結論

**フォームはラベルと入力欄を1組にして、縦に積んで並べる**

- 1 組を 1 つの箱にまとめる
- 箱を縦に積む

<!-- ノート: 結論。組を作ってから積む、という2段構えです。 -->

---

## 最小のコード

```html
<div class="field">
  <label for="dept">部署</label>
  <select id="dept" name="dept"></select>
</div>
```

<!-- ノート: ラベルと入力欄を .field で1組にします。この箱がフォームの1行になります。 -->

---

## 積む指定

```css
form {
  display: flex;
  flex-direction: column;
  gap: var(--space-3);
}

.field {
  display: flex;
  flex-direction: column;
  gap: 4px;
}
```

<!-- ノート: 外側は組と組の間隔、内側はラベルと入力欄の間隔です。値を変えて主従を付けます。 -->

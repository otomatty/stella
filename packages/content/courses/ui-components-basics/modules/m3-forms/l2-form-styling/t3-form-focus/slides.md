# 3-2-3
# フォーカスは:focus-visibleで出す

UI部品入門 — Module 3 / レッスン3-2

<!-- ノート: 4段階目の状態です。フォームでは、フォーカスがいちばん大事な状態です。 -->

---

## なぜ必要か

- 既定の枠が見た目に合わないので `outline: none` で消した
- その結果、いまどの欄を入力しているのか分からなくなった

<!-- ノート: つかみ。消すところまでで手が止まると、フォームは一気に使えなくなります。 -->

---

## 結論

**入力欄のフォーカスは、枠を消したままにせず`:focus-visible`で出し直す**

- 消してよいのは、代わりを用意したときだけ
- 長いフォームほど、現在位置の表示が効く

<!-- ノート: 結論。消す・出し直すはセットで書きます。 -->

---

## 最小のコード

```css
.field :is(input, select, textarea) {
  &:focus-visible {
    outline: 2px solid var(--accent);
    outline-offset: 2px;
  }
}
```

<!-- ノート: 枠を消す指定は書かず、必要なときだけ自分の枠を出す形にします。 -->

---

## 枠の代わりに使えるもの

- `outline` の色と太さを変える(いちばん素直)
- `border-color` を変えて、枠自体を強調する
- 影を付けて、入力欄を浮かせる

<!-- ノート: 関連情報の枠。どれを使っても構いませんが、背景色だけの変化は弱いので避けます。 -->

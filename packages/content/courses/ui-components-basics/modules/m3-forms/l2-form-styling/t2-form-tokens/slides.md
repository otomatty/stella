# 3-2-2
# 既定の見た目を他の部品にそろえる

UI部品入門 — Module 3 / レッスン3-2

<!-- ノート: 3段階目です。フォーム部品には、他の部品には無い癖があります。 -->

---

## なぜ必要か

- 入力欄の中の文字だけ、ページの他の場所と書体が違う
- 枠の色や角丸も、カードやボタンと合っていない

<!-- ノート: つかみ。入力欄はブラウザーが独自の見た目を持っているのが原因です。 -->

---

## 結論

**入力欄は既定の見た目を持つので、書体を継承させてトークンで枠を当て直す**

- 書体は継承されない → 明示して受け継ぐ
- 枠と角丸はトークンから当てる

<!-- ノート: 結論。フォーム部品だけは「戻してから当てる」ひと手間が要ります。 -->

---

## 最小のコード

```css
input,
select,
textarea {
  font: inherit;
  color: inherit;
}
```

<!-- ノート: font: inherit が「書体の継承」です。親の書体と大きさをそのまま受け継ぎます。 -->

---

## トークンで当て直す

```css
.field :is(input, select, textarea) {
  border: 1px solid var(--line);
  border-radius: var(--radius-1);
  padding: var(--space-2);
  background-color: var(--surface);
}
```

<!-- ノート: 他の部品と同じトークンを使うので、カードやボタンと自然にそろいます。 -->

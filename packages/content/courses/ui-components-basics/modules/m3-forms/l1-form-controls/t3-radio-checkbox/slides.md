# 3-1-3
# radioは1つ、checkboxは複数

UI部品入門研修 — Module 3 / レッスン3-1

<!-- ノート: 選ばせる部品の使い分けです。判断の基準は「いくつ選ばせたいか」だけです。 -->

---

## なぜ必要か

- 「どちらか一方」のはずなのに、両方選べてしまう
- 逆に、複数選ばせたいのに 1 つしか選べない

<!-- ノート: つかみ。要素の選び間違いは、そのまま入力ミスになります。 -->

---

## 結論

**同じ`name`のラジオボタンは1つだけ選べ、チェックボックスはそれぞれ独立して選べる**

- 1 つだけ選ばせたい → `type="radio"`
- いくつでも選ばせたい → `type="checkbox"`

<!-- ノート: 結論。ラジオボタンは name が同じもの同士でグループになります。 -->

---

## 最小のコード

```html
<input type="radio" id="on" name="place" value="on">
<label for="on">出社</label>
<input type="radio" id="off" name="place" value="off">
<label for="off">在宅</label>
```

<!-- ノート: name が同じ2つなので、どちらか一方しか選べません。id と for は個別に対応させます。 -->

---

## nameを別々にすると

- `name` が違うラジオボタンは、それぞれ別のグループ
- 結果として両方選べてしまう
- 「1 つだけ選べない」ときは、まず `name` を疑う

<!-- ノート: 失敗例の枠。実務でいちばん多いフォームの不具合です。 -->

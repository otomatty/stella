# 3-1-2
# textareaは複数行を書かせる

UI部品入門 — Module 3 / レッスン3-1

<!-- ノート: 問い合わせ本文や備考のような、長い文章の入力欄です。 -->

---

## なぜ必要か

- 問い合わせ本文を 1 行の入力欄で書かせると、全体が見えない
- 改行を入れたいのに、`input` では改行できない

<!-- ノート: つかみ。1行の入力欄と複数行の入力欄は、別の要素です。 -->

---

## 結論

**`textarea`は複数行の入力欄で、初期値は開始タグと終了タグの間に書く**

- `input` … 1 行。値は `value` 属性
- `textarea` … 複数行。値はタグの間

<!-- ノート: 結論。ここが input と違うので、書き間違えやすい点です。 -->

---

## 最小のコード

```html
<label for="body">お問い合わせ内容</label>
<textarea id="body" name="body" rows="5"></textarea>
```

<!-- ノート: rows は最初に見える行数です。中身が空なら、タグの間には何も書きません。 -->

---

## 空白に気をつける

```html
<textarea>ここが初期値</textarea>
```

- タグの間の改行や空白も、そのまま初期値になる
- 空にしたいなら、開始タグと終了タグを続けて書く

<!-- ノート: 失敗例の枠。見た目には分からない空白が初期値に入るので、整形するときは注意します。 -->

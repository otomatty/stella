# MCPは道具を繋ぐ共通の口

検証・hooks・MCP — Module 3 / レッスン3-1

---

## なぜ必要か

- 仕事の情報は、課題管理・社内DB・チャットなどリポジトリの外にもある
- 外の情報は、毎回人がコピーして貼り付けて渡すことになる

<!-- ノート: エージェントが最初から触れるのは手元のファイルとコマンドだけです。外との間に、人力の運搬が挟まっています。 -->

---

## 結論

**MCPは、Claude Codeに社内ツールや外部サービスを繋ぐための共通の口です**

- **MCP** — エージェントに外の道具を繋ぐための共通の決まりごと
- **社内ツール** — 課題管理や社内DBなど、社内で使っている道具
- **外部サービス** — 社外のWebサービス

<!-- ノート: 道具ごとに専用の繋ぎ方を作るのではなく、口を1つに揃えたのがMCPです。USBの口のような標準化だと言うと伝わります。 -->

---

## 最小の例

```text
MCPなし   課題管理の内容を人がコピーして貼る

MCPあり   「課題123の内容を読んで対応して」
          → エージェントが自分で読みに行く
```

<!-- ノート: 人が運搬役をやめられるのが効果です。どうやって繋がるのかは、次のトピックで見ます。 -->

---

## 口が共通だと起きること

| 専用の繋ぎ込み | 共通の口(MCP) |
| --- | --- |
| 道具ごとに作り込みが要る | 対応した道具はそのまま繋がる |
| 作った人しか保守できない | 同じ形でチームに配れる |

<!-- ノート: 共通の口だからこそ、既に対応済みの道具が世の中にたくさんあります。それを使う側がこの講座の範囲です。 -->

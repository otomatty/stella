## 結論

**既存のMCPサーバーは、名前と繋ぎ方を設定に書いて足します**

- **設定** — どのサーバーを使うかを書いておくファイル
- **繋ぎ方** — そのサーバーの起動のしかた、または接続先
- **スコープ** — 設定が効く範囲(local / project / user)

<!-- ノート: 設定の綴りは製品ごと・時期ごとに変わります。覚えるのは「名前と繋ぎ方を書く」とスコープの使い分けです。 -->

---

## 最小の例

```text
設定に書くこと(意味だけ)

  名前:    issue-tracker (自分がつける呼び名)
  繋ぎ方:  起動するコマンド、または接続先のURL

→ 次の会話から、そのサーバーの能力が使える
```

<!-- ノート: 正確な書式は製品のドキュメントを見ながらで大丈夫です。各項目が何を意味しているかを説明できることが目標です。 -->

---

## スコープの使い分け

| スコープ | 効く範囲 | チーム共有 |
| --- | --- | --- |
| local(既定) | 自分だけ・このプロジェクト | しない |
| project | このプロジェクト | `.mcp.json` で共有 |
| user | 自分の全プロジェクト | しない |

<!-- ノート: `claude mcp add` の既定は local です。チームに配るなら project スコープ。APIキーは ${VAR} で環境変数参照にします。 -->

## 結論

**既存のMCPサーバーは、名前と繋ぎ方を設定に書くだけで足せます**

- **設定** — どのサーバーを使うかを書いておくファイル
- **繋ぎ方** — そのサーバーの起動のしかた、または接続先
- 書くのは実質この2つ。プログラミングは不要です

<!-- ノート: 設定の綴りは製品ごと・時期ごとに変わります。覚えるのは「名前と繋ぎ方を書く」という意味だけです。 -->

---

## 最小の例

```text
設定に書くこと(意味だけ)

  名前:    issue-tracker (自分がつける呼び名)
  繋ぎ方:  起動するコマンド、または接続先のURL

→ 次の会話から、そのサーバーのツールが使える
```

<!-- ノート: 正確な書式は製品のドキュメントを見ながらで大丈夫です。各項目が何を意味しているかを説明できることが目標です。 -->

---

## 設定の2項目の意味

| 項目 | 意味 |
| --- | --- |
| 名前 | どのサーバーか区別する呼び名 |
| 繋ぎ方 | 手元で起動するか、どこかへ接続するか |

<!-- ノート: 繋ぎ方には手元起動型と接続型の2系統がある、と知っておくとドキュメントが読みやすくなります。 -->

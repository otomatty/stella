# レッスン3-1 演習 — 既存のサーバーを繋ぐ

対象トピック: 3-1-1 〜 3-1-5

## 手元で試す

VS Code 上の Claude Code で進めます。使えない場合は、1と4〜5を紙の上でやるだけでも選定の練習として成立します。

1. 自分の仕事で「毎回コピーして貼り付けている外の情報」を1つ挙げる(課題管理の内容、社内DBの値、チャットのやり取りなど)
2. Claude Code が使えるなら、製品のドキュメントでMCPの設定方法を確認し、公式の(または社内で用意済みの)MCPサーバーを1つ、設定に足してみる
3. 繋いだサーバーのツールが増えたことを確かめ、小さな依頼で1回使ってみる
4. 繋ぐ前の3問(出どころは? 何に触れる? いま要る?)を、2で選んだサーバーに当てはめて答えを書く
5. 使い終わって今後使わないなら、設定から外す(棚卸しの練習)

## 演習問題

### 問1(基本)

MCPが何のための仕組みかを、「共通の口」という語を使って1〜2文で説明してください。

### 問2(基本)

MCPサーバーの設定に書く2つの項目と、それぞれの意味を書いてください。

### 問3(応用)

「社内の課題管理と繋ぎたいが、MCPサーバーが見つからない。週末に自作しようと思う」という同僚に、この講座の方針に沿った助言を2〜3文で書いてください。

### 問4(応用)

出どころの分からないMCPサーバーの設定がリポジトリに追加されていました。使う前に確認すべきことを、繋ぐ前の3問を使って書いてください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

MCPは、Claude Codeに社内ツールや外部サービスを繋ぐための共通の口です。道具ごとに専用の繋ぎ込みを作らなくても、対応した道具を同じ形で繋げます。

</details>

<details>
<summary>問2の解答例</summary>

名前と繋ぎ方です。名前はどのサーバーか区別するための呼び名で、繋ぎ方はそのサーバーを手元で起動するコマンド、またはどこかで動いているサーバーへの接続先です。

</details>

<details>
<summary>問3の解答例</summary>

MCPサーバーは道具と情報の出入口なので、開発と保守の責任が重く、自作はしない方針です。まず公式や社内で用意済みのものを探し、無ければ担当チームに相談するのが順番です。

</details>

<details>
<summary>問4の解答例</summary>

まず出どころを確認します(公式か、社内の担当が配ったものか、誰が設定に入れたのか)。次に何に触れるかを確認します(読むだけか、書き換えもするか)。最後にいまの仕事に要るかを確認し、要らなければ設定から外します。確認が済むまで使いません。

</details>

## 確認クイズ

### Q1. MCPの説明として適切なのはどれですか。

- A. Claude Codeに社内ツールや外部サービスを繋ぐための共通の口
- B. コードの見た目を揃えるための道具
- C. 会話を要約して短くする機能

<details>
<summary>答え</summary>

**A** — MCPは外の道具を繋ぐ共通の決まりごとです。整形はフォーマッタ、要約はコンテキスト管理の話で、別の道具です。

</details>

### Q2. MCPサーバーを繋ぐと何が変わりますか。

- A. Claude Codeの応答が速くなる
- B. Claude Codeが使えるツールが増える
- C. コードが自動で整形される

<details>
<summary>答え</summary>

**B** — サーバーはツールを提供する側です。繋ぐと、エージェントの道具箱に新しいツールが並びます。

</details>

### Q3. 既存のMCPサーバーを使い始めるのに必要な作業はどれですか。

- A. サーバーのプログラムを開発する
- B. 名前と繋ぎ方を設定に書く
- C. 増えるツールの使い方をすべて暗記する

<details>
<summary>答え</summary>

**B** — 既存のサーバーは設定で足せます。プログラミングは不要で、増えたツールはエージェントが自分で選んで使います。

</details>

### Q4. 使いたい社内ツールのMCPサーバーが見つからないとき、この講座の方針に沿った行動はどれですか。

- A. 自分でサーバーを実装する
- B. 公式・社内の用意済みを探し、無ければ担当チームに相談する
- C. あきらめて手作業に戻る

<details>
<summary>答え</summary>

**B** — 探す順番は公式 → 社内で用意済み → 相談です。出入口となるサーバーの開発・保守は、利用者の片手間仕事にしません。

</details>

### Q5. MCPサーバーの繋ぎ方として適切なのはどれですか。

- A. 便利そうなサーバーを見つけしだい全部繋ぐ
- B. 信頼できるものだけを、いまの仕事に要るぶんだけ繋ぐ
- C. 一度繋いだサーバーは外さずに残しておく

<details>
<summary>答え</summary>

**B** — サーバーは道具と情報の出入口です。出どころを確かめ、要るぶんだけ繋ぎ、使わなくなったら外します。

</details>

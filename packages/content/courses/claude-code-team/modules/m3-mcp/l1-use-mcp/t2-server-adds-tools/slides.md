## なぜ必要か

- 「繋がる」と言われても、何がどう変わるのかが見えない
- 変化の正体が分かると、繋ぐ価値の見積もりができる

<!-- ノート: MCPの効果を一言で言えるようにするトピックです。 -->

---

## 結論

**MCPサーバーを繋ぐと、ツール・資料・定型依頼などの能力が増えます(この講座ではツールを例にします)**

- **MCPサーバー** — MCPの口で道具を提供する側のプログラム
- **能力** — ツール(操作)・資料(読み取り)・定型依頼(ひな形)の総称
- ツールがゼロのサーバーもある。この講座ではツールを代表例にします

<!-- ノート: ツールは講座4で扱った語です。エージェントの手持ちの道具箱に、サーバーが能力を足すという絵です。 -->

---

## 最小の例

```text
繋ぐ前   ファイルを読む / 書く / コマンドを実行する

課題管理のMCPサーバーを繋ぐ

繋いだ後  上に加えて
          課題を検索する / 課題の詳細を読む ...
          (ツールの例)
```

<!-- ノート: 増えたツールは、エージェントが依頼に応じて自分で選んで使います。使い方を人が覚える必要はありません。 -->

---

## 増えた能力は誰が使うか

| 人がすること | エージェントがすること |
| --- | --- |
| どのサーバーを繋ぐか決める | 増えた能力から必要なものを選ぶ |
| 依頼を書く | ツールを実行して結果を使う |

<!-- ノート: 人の仕事は選定と依頼で、操作はエージェント側です。次は、繋ぐ作業そのものを見ます。 -->

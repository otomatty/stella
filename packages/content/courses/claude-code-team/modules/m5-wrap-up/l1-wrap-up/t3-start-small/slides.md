## なぜ必要か

- 学んだ道具が多いほど、「全部整えてから使おう」と構えてしまう
- 構えている間は、何も変わらない

<!-- ノート: 完璧な準備を待つのが、一番よくある止まり方です。 -->

---

## 結論

**シリーズで学んだ道具は、実務の小さな1タスクに使うことから始めます**

- **タスク** — 完了を言い切れるひとまとまりの仕事(講座4で扱った語です)
- **実務** — 練習ではない、ふだんの仕事
- 全部の仕組みを整えてからではなく、1タスクに1つずつ

<!-- ノート: 検証できる小さな1本から。任せ方はM0で決めたとおりです。 -->

---

## 最小の例

```text
明日の1タスクで

  小さな修正を1本任せて、検証して受け取る
  繰り返しに気づいたら、1つだけ仕組みにする

→ 次のタスクでは、その仕組みのぶん速くなっている
```

<!-- ノート: 1タスクごとに仕組みが1つ増えれば十分です。積み上がる速さは、あとから効いてきます。 -->

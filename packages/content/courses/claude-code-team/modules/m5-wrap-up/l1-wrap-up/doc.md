# レッスン5-1 4Dに戻して締める

## このレッスンの目標

- [ ] この講座の道具を4Dの地図に対応づけて説明できる
- [ ] 仕組み化のチェックリスト(気づく→選ぶ→検証を付ける→配る)を回せる
- [ ] 明日の実務の1タスクで、何から始めるかを決められる

## 5-1-1 検証と仕組みは4Dの実践

> **検証・hook・MCPの使いこなしは、任せる・伝える・見極める・責任を持つという4Dの実践です**

総仕上げは、シリーズ1本目の地図に戻るところから始めます。新しい道具は出てきません。

シリーズの最初に **4D**(**任せる**・**伝える**・**見極める**・**責任を持つ**)という枠組みを学びました。講座ごとの学びがバラバラのままだと現場で思い出せませんが、実はこの講座の道具は、どれも4Dのどれかを仕組みにしたものです。

```text
任せる       検証できる範囲だけ任せる (M0)
伝える       検証手順をSkillに書く (M1)
見極める     テスト・lint・自分の目 (M0)
責任を持つ   hookで止める、MCPは最小に (M2, M3)
```

任せる範囲の判断はDelegation、検証手順を手順書として書き切るのはDescription、テスト・lint・自分の目で確かめるのはDiscernment、危険なコマンドを止めるhookや最小に絞るMCPの選定はDiligenceの実践です。考え方は1本目から一貫して同じでした。

| 講座1のころ | この講座を終えた今 |
| --- | --- |
| 4Dを自分の心がけとして守る | 4Dをチームの仕組みとして置ける |

変わったのは置き場所です。心がけは破られますが、仕組みは残ります。個人の習慣をチームの仕組みに変えるのが、このシリーズの旅でした。

## 5-1-2 仕組み化は順番で回す

> **繰り返しに気づいたら、入れ物を選ぶ・検証を付ける・チームに配るの順で仕組みにします**

道具を全部知っていても、どの順で使うかで迷うと手が止まります。そこで、シリーズで学んだ手順を1本のチェックリストにまとめます。

**仕組み化**(繰り返しの作業や指示を仕組みとして置くこと)の手順は4歩です。

```text
仕組み化のチェックリスト

  1. 気づく       同じ指示・同じ確認を繰り返していないか
  2. 選ぶ         いつ効いてほしいかで入れ物を選ぶ
  3. 検証を付ける  その仕組みが正しく動くことを確かめる
  4. 配る         チームに効かせるならリポジトリへ

```

1と2は前の講座で学びました。繰り返しに気づいたら、**入れ物**(CLAUDE.md・Skill・サブエージェント・hook)を「いつ効いてほしいか」で選びます。3がこの講座で足した歩です。仕組みも生成した変更と同じで、正しく動くことを検証してから使い始めます。4はM4のとおり、チームに効かせたいものはリポジトリにコミットして配ります。

| 抜けた歩 | 症状 |
| --- | --- |
| 2を飛ばす | 全部CLAUDE.mdに詰め込む |
| 3を飛ばす | 動かない仕組みが配られる |
| 4を忘れる | 自分だけ便利で、チームは変わらない |

どの歩が抜けても仕組み化は失敗します。現場ではこの4歩をチェックリストとして使ってください。

## 5-1-3 実務の1タスクから始める

> **シリーズで学んだ道具は、実務の小さな1タスクに使うことから始めます**

最後は、明日からの始め方です。

学んだ道具が多いほど、「全部整えてから使おう」と構えてしまいます。しかし構えている間は、何も変わりません。答えはシリーズを通じて同じです。小さく始めます。

**実務**(練習ではない、ふだんの仕事)の中から、完了を言い切れるひとまとまりの仕事、つまり小さな **タスク** を1本選びます。任せ方はM0で決めたとおり、自分が検証できる範囲で。

```text
明日の1タスクで

  小さな修正を1本任せて、検証して受け取る
  繰り返しに気づいたら、1つだけ仕組みにする

→ 次のタスクでは、その仕組みのぶん速くなっている
```

1タスクごとに仕組みが1つ増えれば十分です。積み上がる速さは、あとから効いてきます。

| 講座 | 持ち帰り |
| --- | --- |
| 考え方・チャット・Cowork | 任せ方と伝え方 |
| Claude Code 入門・Skills | 進め方と仕組みの入れ物 |
| この講座 | 検証と、チームへの広げ方 |

シリーズ6本の旅はここまでです。あとは実務の中で、小さく使って大きく育ててください。

## もっと知りたい人へ

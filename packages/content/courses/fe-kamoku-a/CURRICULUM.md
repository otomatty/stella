# 基本情報技術者 科目A対策 カリキュラム

基本情報技術者試験(FE)科目Aの対策講座です。1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、
シラバスの「大分類 → 中分類」をそのまま「モジュール → レッスン」に写像します。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- 問題はすべて自作。公式のサンプル問題・公開問題は難易度と出題形式の校正基準としてのみ使う(転載しない)
- 科目Bのアルゴリズム演習は別講座 `fe-kamoku-b` で扱う
- 前提講座: **ITのきほん(`it-basics`)**。スキルツリーの入口講座で、コンピュータ・ファイル・Web の基本のことばをそろえてから受講します(`course.json` の `prerequisites` に対応)

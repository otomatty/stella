# レッスン4-2 テストの技法

## このレッスンの目標

- [ ] 単体・結合・システム・受入れの各テストで確かめる範囲を説明できる
- [ ] 入力の有効範囲から、同値分割と境界値分析で試す値を選べる
- [ ] ブラックボックステストとホワイトボックステストの違いを説明できる

## 4-2-1 テストは段階を踏んで広げる

> **テストは単体・結合・システム・受入れの順に範囲を広げて行う**

実装が終わったソフトウェアを、いきなり全体で動かすとどうなるでしょうか。不具合は見つかりますが、どの部品が原因なのかを絞り込めません。そこでテストは、確かめる範囲を内側から外側へ、段階を踏んで広げます。

| 段階 | 確かめる範囲 | 見つけたい不具合 |
| --- | --- | --- |
| **単体テスト** | 部品1つ | 部品の中の処理の誤り |
| **結合テスト** | 部品の組み合わせ | 部品間のデータの受け渡しの誤り |
| **システムテスト** | システム全体 | 要件定義とのずれや性能の不足 |
| **受入れテスト** | 発注者による確認 | 実際の業務で使えない点 |

- **単体テスト** — 部品を1つずつ確かめます。ここで不具合が出れば、原因はその部品の中と分かります
- **結合テスト** — 部品同士を組み合わせて確かめます。部品単体では正しくても、データの受け渡しで誤ることがあります
- **システムテスト** — システム全体を動かし、要件定義どおりかを確かめます。性能の不足もここで見つけます
- **受入れテスト** — 発注者が、実際の業務で使えるかを確認します。これが最後の関門です

内側の段階でつぶした不具合は、後の段階に持ち越されません。だから部品から始めて外へ広げる順序が合理的です。試験では「この不具合はどの段階で見つけるか」という形で問われます。上の表の右列が判定基準になります。

## 4-2-2 ブラックボックステスト

> **ブラックボックステストは、内部構造を見ずに入力と出力だけで確認する**

「0〜100を受け付ける」入力欄をテストするとします。試せる値は数えきれないほどあり、全部は試せません。そこで、中身を黒い箱とみなして開けずに、「この入力ならこの出力になるはず」という仕様との照らし合わせだけで確認します。これが **ブラックボックステスト** です。

全部試せない以上、値の選び方が勝負になります。代表的な技法が2つあります。

| 技法 | 値の選び方 | 試す値の例 |
| --- | --- | --- |
| **同値分割** | 同じ扱いのまとまりから代表値を1つ | -10、50、150 |
| **境界値分析** | 有効と無効の境目を狙う | -1、0、100、101 |

**同値分割** は、入力を同じ扱いになるまとまりに分け、各まとまりから代表値を1つ選びます。「0〜100が有効」なら、まとまりは次の3つです。

- 0未満(無効) — 代表値の例: -10
- 0〜100(有効) — 代表値の例: 50
- 101以上(無効) — 代表値の例: 150

50で正しく動くなら、30でも70でも同じように動くはず。だから代表1つでよい、という間引きの発想です。

**境界値分析** は、有効と無効の境目とその隣を狙います。「0〜100が有効」なら、-1、0、100、101 の4つです。不具合は境目に集まりやすいからです。たとえば「0以上」とすべきところを「0より大きい」と作り間違えると、50を試しても見つかりませんが、0を試せば見つかります。

## 4-2-3 ホワイトボックステスト

> **ホワイトボックステストは、内部構造に着目して処理の通り道を網羅する**

入力と出力の確認だけでは、一度も動かしていない処理が中に残るかもしれません。そこで中身を白い箱とみなして開き、内部構造に着目して確かめるのが **ホワイトボックステスト** です。中身の分岐を見て、処理の通り道をすべて通るように値を選びます。通り道をすべて通すことを **網羅** と呼びます。

点数の判定処理で考えます。

- 処理: 60以上なら「合格」、60未満なら「不合格」と表示する
- 通り道は2本。合格になる道と、不合格になる道
- 75(合格の道)と 40(不合格の道)の両方を試して、初めて網羅できます
- 75だけでは、不合格の道を一度も通っていません

ブラックボックステストとの違いを整理します。

| | ブラックボックステスト | ホワイトボックステスト |
| --- | --- | --- |
| 見るもの | 入力と出力 | 内部構造 |
| 観点 | 仕様どおりの出力か | 処理の通り道を網羅したか |

試験では「内部構造に着目するのはどちらか」という形で問われます。ホワイト=中が見える=通り道、と結び付けて判定してください。2つの技法は対立するものではなく、実務では併用します。

## もっと知りたい人へ

- 網羅には「すべての命令を通す」「すべての分岐を通す」など、測り方の段階があります。まずは「通り道をすべて通す」という発想を固めるのが先です
- 結合テストには、上位の部品から進める方法と下位の部品から進める方法があります。興味があれば調べてみてください
- 実務では、テストを自動で繰り返し実行する仕組みづくりが重視されています。修正のたびに同じテストを流せると、直したことで別の場所が壊れていないかを確かめられます

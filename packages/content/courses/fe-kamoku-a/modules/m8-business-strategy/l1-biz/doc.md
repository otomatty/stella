# レッスン8-1 経営戦略とビジネス

## このレッスンの目標

- [ ] SWOT分析の4象限を、内部要因と外部要因に分けて説明できる
- [ ] PPMの4分類と、資金配分の定石を説明できる
- [ ] 4PとIoT・ビッグデータ活用の流れを説明できる

## 8-1-1 SWOT分析で現状を整理

> **SWOT分析は、強み・弱み・機会・脅威の4象限で現状を整理する手法**

経営戦略は、まず自社の現状を知ることから始まります。しかし思いつきで書き出すと、大事な視点が抜け落ちます。そこで使うのが **SWOT分析** です。自社の現状を4つの象限に分けて整理します。

- 自社の中の話(内部要因) — **強み** と **弱み**
- 自社の外の話(外部要因) — **機会** と **脅威**

駅前の喫茶店を例にすると、次のようになります。

| | 良い影響 | 悪い影響 |
| --- | --- | --- |
| 内部要因(自社) | 強み: 常連客が多い | 弱み: 席が少ない |
| 外部要因(環境) | 機会: 近くに大学ができる | 脅威: 大手チェーンの出店 |

縦は内部か外部か、横は良い影響か悪い影響かで読みます。試験では「これはどの象限か」という出題が定番です。迷ったら「自社の努力で変えられるか」で判定してください。大手チェーンの出店は自社では変えられないので外部要因、席の少なさは自社で変えられるので内部要因です。

## 8-1-2 PPMで事業の配分を決める

> **PPMは、市場成長率と市場占有率で事業を4つに分類する手法**

会社は複数の事業を同時に抱えていますが、お金と人は限られています。どの事業に配分するかを決める物差しが **PPM** です。2つの軸で事業を分類します。

- **市場成長率** — その市場が伸びる勢い
- **市場占有率** — 市場の中で自社が占める割合

| | 占有率が高い | 占有率が低い |
| --- | --- | --- |
| 成長率が高い | 花形 | 問題児 |
| 成長率が低い | 金のなる木 | 負け犬 |

4つの分類には個性的な名前が付いています。

- **花形** — 勢いも取り分もある主力事業。維持にも投資が必要です
- **金のなる木** — 成長は落ち着いたが、安定して稼げる事業です
- **問題児** — 市場は伸びているのに、自社の取り分が小さい事業です
- **負け犬** — 勢いも取り分もなく、撤退を検討する事業です

資金配分には定石があります。**金のなる木で稼いだ資金を問題児に投資し、花形に育てる**という流れです。負け犬に資金を注ぎ続けるのは失敗パターンとされます。試験では「どこで稼ぎ、どこへ投資するか」がそのまま問われます。

## 8-1-3 マーケティングの4P

> **マーケティングの基本は、製品・価格・流通・販売促進の4Pの組み合わせ**

良い商品を作ったのに売れない、はビジネスでよくある話です。商品が売れる仕組みを作る活動を **マーケティング** と呼びます。その基本形が **4P** です。4つの要素の頭文字がすべてPなのでこう呼ばれます。

ペットボトルのお茶を例に整理します。

| P | 意味 | 例 |
| --- | --- | --- |
| Product(製品) | 何を売るか | 飲みやすい緑茶 |
| Price(価格) | いくらで売るか | 150円 |
| Place(流通) | どこで売るか | コンビニ・自動販売機 |
| Promotion(販売促進) | どう知らせるか | テレビCM・キャンペーン |

ポイントは「組み合わせ」であることです。良い製品でも、売る場所(流通)がなければ客に届きません。知らせる手段(販売促進)がなければ気づかれません。4つをセットで設計するのがマーケティングの基本です。試験では英語名と日本語名の対応がよく問われるので、両方をセットで覚えてください。

## 8-1-4 データを価値に変える技術

> **IoTで集めたビッグデータを分析して、業務や製品の改善につなげる**

工場の機械は、ある日突然故障して生産が止まります。人が見回るだけでは前兆に気づけません。そこで、現場の状態をデータで捉える仕組みが使われます。

- **IoT** — モノをインターネットにつなぐ仕組みです。センサーを付けた機械が、自分の状態をデータとして送ります
- **ビッグデータ** — 従来の仕組みでは扱えなかった、大量・多様なデータのことです

工場の故障予知は、この2つとAIの組み合わせで実現します。

| 段階 | 使う技術 | すること |
| --- | --- | --- |
| 集める | IoT | センサーで機械の温度や振動を測る |
| 貯まる | ビッグデータ | 大量の測定データを蓄積する |
| 分析する | AI(機械学習) | 故障の前兆となるパターンを見つける |

前兆を見つけたら、壊れる前に部品を交換できます。突然の停止がなくなり、業務が改善されます。

注意したいのは、データは集めるだけでは価値にならないことです。分析して業務や製品の改善に使って、初めて価値になります。「何を改善したいか」から逆算してデータを集める、という順番が大切です。

## もっと知りたい人へ

- SWOT分析の4象限を掛け合わせて「強みで機会を活かすには?」と戦略を考える発展形もあります。まずは4象限の整理を確実にしてください
- PPMはボストンコンサルティンググループが考案した手法です。プロダクトポートフォリオマネジメントの略です
- 4Pに買い手側の視点を加えた発展形もあります。試験対策としては、まず4Pの対応を固めるのが先です

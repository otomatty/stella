# 2-1-4
# 消えるメモリと消えないメモリ

基本情報 科目A対策 — Module 2 / レッスン2-1

<!-- ノート: メモリの分類の話です。「消えるか、消えないか」という軸を1つだけ押さえます。 -->

---

## なぜ必要か

- 保存前の文書が、停電やフリーズで消えた経験はないか
- 一方で、電源を入れ直しても機器の起動手順は消えていない
- メモリの「消える・消えない」の違いを整理する軸がほしい

<!-- ノート: つかみ。保存し忘れて泣いた経験を思い出してもらう。なぜ消えるのかはまだ言わない。 -->

---

## 結論

**RAMは電源を切ると消える読み書き用、ROMは消えない読み出し用のメモリ**

- **揮発性** = 電源を切ると内容が消える性質
- **RAM** は揮発性、**ROM** は消えない

<!-- ノート: 結論を言い切る。揮発はアルコールが蒸発する「揮発」と同じ字、と補足すると覚えやすい。 -->

---

## 最小の例

2つのメモリを対比すると、次のとおりです。

| | RAM | ROM |
| --- | --- | --- |
| 読み書き | 読み書きできる | 読み出し専用 |
| 電源を切ると | 消える(揮発性) | 消えない |
| 主な用途 | 主記憶 | 起動用の命令の保存 |

<!-- ノート: 表の3行を上から読み上げる。主記憶に使われるのはRAM、という行が次のスライドの伏線。 -->

---

## ひっかけは「どちらが主記憶か」

- 主記憶に使われるのは **RAM**(読み書きが必要だから)
- だから保存前の作業データは、電源を切ると消える
- 「主記憶はROMである」型の選択肢は誤り

<!-- ノート: 補強枠。冒頭の「文書が消えた」の種明かし。作業場所が揮発性のRAMだから消える、と回収する。 -->

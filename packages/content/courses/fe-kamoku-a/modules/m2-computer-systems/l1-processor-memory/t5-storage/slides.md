# 2-1-5
# 補助記憶装置はデータを残す

基本情報 科目A対策 — Module 2 / レッスン2-1

<!-- ノート: レッスン最後のトピックです。消えては困るデータの置き場を1つだけ押さえます。 -->

---

## なぜ必要か

- 主記憶はRAMで揮発性。電源を切ると作業データは消える
- でも文書や写真は、明日も来年も残っていてほしい
- 電源と関係なくデータを置いておける場所が必要になる

<!-- ノート: つかみ。前トピックの「消える」問題を受けて、残す場所の必要性だけを立てる。答えはまだ言わない。 -->

---

## 結論

**補助記憶装置は電源を切ってもデータを保存し、HDDとSSDが代表**

- 主記憶を補助して、データを長く残す装置が **補助記憶装置**
- 代表は **HDD** と **SSD** の2つ

<!-- ノート: 結論を言い切る。「ストレージ」と呼ばれている部品のことだ、と身近な呼び名につなぐ。 -->

---

## 最小の例

HDDとSSDを対比すると、次のとおりです。

| | HDD | SSD |
| --- | --- | --- |
| 記録のしくみ | 磁気の円盤を回す | 電子部品に記録する |
| 速さ | 遅い | 速い |
| 衝撃 | 弱い | 強い |
| 価格 | 安価で大容量 | 容量あたり高価 |

<!-- ノート: HDDは円盤が物理的に回る、SSDは動く部品がない。この違いから速さと衝撃耐性の差を導けると暗記が減る。 -->

---

## 主記憶との役割分担

| | 主記憶(RAM) | 補助記憶装置 |
| --- | --- | --- |
| 役割 | 作業中のデータの置き場 | データを長く残す置き場 |
| 電源を切ると | 消える(揮発性) | 消えない |
| 速さ | 速い | 遅い |

<!-- ノート: 補強枠。机(主記憶)と本棚(補助記憶)の例え。「速いが消える」と「遅いが残る」の分担を対で覚える。 -->

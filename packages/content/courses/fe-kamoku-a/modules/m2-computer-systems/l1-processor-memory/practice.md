# レッスン2-1 演習 — プロセッサとメモリ

対象トピック: 2-1-1 〜 2-1-5

## ハンズオン

自分のパソコンのCPU・メモリ・ストレージの仕様を、このレッスンの用語で確認するワークです。

Windowsの場合は、次の手順で確認します。

1. 「設定」→「システム」→「バージョン情報」を開く
2. 「プロセッサ」の欄でCPUの名前とクロック周波数(GHz)を確認する
3. 「実装RAM」の欄で主記憶の容量(GB)を確認する
4. タスクマネージャーの「パフォーマンス」タブを開く
5. 「ディスク」の欄でストレージがHDDかSSDかを確認する

Macの場合は、アップルメニューの「このMacについて」で同じ項目を確認できます。

確認した値を、次の観点でメモしてみましょう。

- CPUのクロック周波数は何GHzか。1秒あたり何億回の拍か
- 主記憶(RAM)の容量と、ストレージの容量はどちらが大きいか
- ストレージがSSDなら、HDDと比べて何がうれしいか

家族や同僚のパソコンでも同じ場所を見比べると、仕様表を読む力が付きます。

## 演習問題

### 問1(基本)

五大装置のうち、CPUが担当する2つの役割は何ですか。また、主記憶が担当する役割は何ですか。

### 問2(基本)

クロック周波数2GHzのCPUは、1秒あたり何回の拍で動きますか。また、同じ種類の1GHzのCPUと比べてどちらが多くの命令をこなせますか。

### 問3(応用)

作成した文書を、電源を切っても残したいとします。主記憶(RAM)と補助記憶装置(SSD)のどちらに保存すべきですか。「揮発性」という語を使って理由を説明してください。

## 解答例と解説

<details>
<summary>問1の解答例</summary>

CPUは制御と演算の2つの役割を担当します。主記憶は記憶の役割を担当します。

五大装置は制御・演算・記憶・入力・出力の5つです。役割は5つでも、制御装置と演算装置はCPUという1つの部品にまとまっています。「CPU=制御+演算」の対応づけは選択肢の判定でそのまま使えます。

</details>

<details>
<summary>問2の解答例</summary>

2GHzは1秒あたり20億回の拍です。同じ種類なら、1GHzより2GHzのCPUのほうが多くの命令をこなせます。

G(ギガ)は10億を表すので、2GHz=20億回です。ただし「同じ種類なら」が条件です。設計が違うCPU同士は、1回の拍でこなせる仕事量が違うため、クロック周波数だけでは比べられません。

</details>

<details>
<summary>問3の解答例</summary>

補助記憶装置(SSD)に保存すべきです。主記憶(RAM)は揮発性で、電源を切ると内容が消えてしまうためです。

補助記憶装置は電源を切ってもデータを保存できます。主記憶は速いが消える作業用の置き場、補助記憶装置は遅いが残る保存用の置き場、という役割分担で覚えてください。

</details>

## 確認クイズ

### Q1. コンピュータの五大装置の組合せとして、適切なものはどれですか。

- A. 制御・演算・記憶・通信・出力
- B. 演算・記憶・入力・出力・表示
- C. 制御・演算・記憶・入力・出力
- D. 制御・計測・記憶・入力・出力

<details>
<summary>答え</summary>

**C** — 五大装置は制御・演算・記憶・入力・出力です。通信や表示は五大装置の名前には含まれません。

</details>

### Q2. クロック周波数の説明として、適切なものはどれですか。

- A. CPUが動く拍の、1秒あたりの回数である
- B. 主記憶が記憶できるデータの量である
- C. CPUが一度に読み書きできるデータの大きさである
- D. 補助記憶装置の読み書きの速さである

<details>
<summary>答え</summary>

**A** — クロック周波数は1秒あたりの拍の数です。1GHzなら10億回で、同じ種類のCPUなら高いほど多くの命令をこなせます。

</details>

### Q3. レジスタ・キャッシュメモリ・主記憶を、アクセス時間が短い順に並べたものはどれですか。

- A. 主記憶 → キャッシュメモリ → レジスタ
- B. キャッシュメモリ → レジスタ → 主記憶
- C. レジスタ → 主記憶 → キャッシュメモリ
- D. レジスタ → キャッシュメモリ → 主記憶

<details>
<summary>答え</summary>

**D** — CPUに近いほどアクセス時間が短く、容量は小さくなります。レジスタが最も速く、次にキャッシュメモリ、主記憶の順です。

</details>

### Q4. 電源を切ると記憶内容が消える、揮発性のメモリはどれですか。

- A. ROM
- B. RAM
- C. SSD
- D. HDD

<details>
<summary>答え</summary>

**B** — RAMは揮発性の読み書き用メモリで、主記憶に使われます。ROMは消えない読み出し専用、SSDとHDDは電源を切ってもデータが残る補助記憶装置です。

</details>

### Q5. HDDと比較したときのSSDの特徴として、適切なものはどれですか。

- A. 磁気の円盤を回して記録するため、衝撃に強い
- B. 容量あたりの価格が安く、大容量に向く
- C. 動く部品がないため、読み書きが速く衝撃に強い
- D. 揮発性のため、電源を切るとデータが消える

<details>
<summary>答え</summary>

**C** — SSDは電子部品に記録し、動く部品がありません。そのため読み書きが速く、衝撃にも強いのが特徴です。Aの記録方式とBの安価・大容量はHDDの特徴です。

</details>

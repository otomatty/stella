# レッスン2-1 プロセッサとメモリ

## このレッスンの目標

- [ ] 五大装置の名前と、CPU・主記憶などの担当部品を対応づけられる
- [ ] クロック周波数とキャッシュメモリが速さにどう関わるか説明できる
- [ ] RAM・ROM・補助記憶装置を「消える・消えない」で区別できる

## 2-1-1 コンピュータの五大装置

> **コンピュータは制御・演算・記憶・入力・出力の5つの装置で構成される**

パソコンの中身は箱の中で、何がどう働いているか見えません。部品の名前を覚える前に、役割の全体像を整理する枠が必要です。その枠が **五大装置** です。どんなコンピュータも、制御・演算・記憶・入力・出力の5つの役割に分解できます。

| 役割 | 担当する装置 | 例 |
| --- | --- | --- |
| 制御・演算 | **CPU** | パソコンの頭脳 |
| 記憶 | **主記憶** | 作業中のデータの置き場 |
| 入力 | **入力装置** | キーボード、マウス |
| 出力 | **出力装置** | ディスプレイ、プリンタ |

役割は5つなのに、部品は4つしかありません。**CPU** が、制御装置(各装置に指示を出す)と演算装置(計算する)の2つを兼ねているためです。試験では「CPU=制御+演算」の対応づけがよく問われます。「CPUは記憶装置である」型の選択肢は誤りです。

## 2-1-2 CPUの速さはクロックで決まる

> **CPUは命令をクロックに合わせて実行し、クロック周波数が高いほど速い**

カタログの「3.2GHz」という数字は、CPUの速さのものさしです。CPUにやらせる処理の1つひとつを **命令** と呼びます。CPUは、クロックという拍(リズム)に合わせて命令を実行します。1秒あたりの拍の数が **クロック周波数** です。

| クロック周波数 | 1秒あたりの拍の数 |
| --- | --- |
| 1GHz | 10億回 |
| 2GHz | 20億回 |
| 3.2GHz | 32億回 |

GHzのG(ギガ)は10億を表します。同じ種類のCPUなら、3.2GHzは1GHzより多くの命令をこなせます。

ただし「周波数が高い=常に速い」とは限りません。CPUの設計によって、1回の拍でこなせる仕事量が違うからです。歩幅の違う2人を歩数だけで比べられないのと同じで、設計が違うCPU同士はクロック周波数だけでは比べられません。断定しすぎの選択肢を切る判定基準になります。

## 2-1-3 キャッシュメモリは速さの中継役

> **キャッシュメモリは、CPUと主記憶の速度差を埋める小さくて速いメモリ**

クロック周波数が高いCPUでも、データが届かなければ働けません。主記憶の読み書きはCPUの速さに追いつけないため、速いCPUを待たせない工夫が必要です。それが **キャッシュメモリ** です。よく使うデータをキャッシュメモリに置いておくことで、CPUが主記憶まで取りに行く回数を減らします。

記憶の場所には階層があります。読み書きにかかる時間を **アクセス時間** と呼び、階層は次のようになっています。

| 場所 | アクセス時間 | 容量 |
| --- | --- | --- |
| **レジスタ**(CPU内部の置き場) | 最も短い | 最も小さい |
| キャッシュメモリ | 短い | 小さい |
| 主記憶 | 長い | 大きい |

速いものほど容量が小さい、という関係です。「アクセス時間が短い順に並べよ」という出題が定番なので、レジスタ → キャッシュメモリ → 主記憶の順序をそのまま覚えてください。

キャッシュメモリに目当てのデータがあればすぐCPUへ渡せます。なければ主記憶まで取りに行くので時間がかかります。よく使うデータほどキャッシュに置くと、待ち時間が減ります。

## 2-1-4 消えるメモリと消えないメモリ

> **RAMは電源を切ると消える読み書き用、ROMは消えない読み出し用のメモリ**

保存前の文書が停電で消えた経験はないでしょうか。一方で、電源を入れ直しても機器の起動手順は消えていません。この違いを整理する軸が「消える・消えない」です。電源を切ると内容が消える性質を **揮発性** と呼びます。

| | RAM | ROM |
| --- | --- | --- |
| 読み書き | 読み書きできる | 読み出し専用 |
| 電源を切ると | 消える(揮発性) | 消えない |
| 主な用途 | 主記憶 | 起動用の命令の保存 |

**RAM** は揮発性の読み書き用メモリ、**ROM** は消えない読み出し専用メモリです。

ひっかけどころは「どちらが主記憶か」です。主記憶は作業中のデータを何度も読み書きするので、使われるのは **RAM** です。だから保存前の作業データは電源を切ると消えます。「主記憶はROMである」型の選択肢は誤りです。

## 2-1-5 補助記憶装置はデータを残す

> **補助記憶装置は電源を切ってもデータを保存し、HDDとSSDが代表**

主記憶はRAMで揮発性ですから、電源を切ると作業データは消えます。しかし文書や写真は、明日も来年も残っていてほしいものです。主記憶を補助して、電源と関係なくデータを長く残す装置が **補助記憶装置** です。ふだん「ストレージ」と呼ばれている部品のことで、代表は **HDD** と **SSD** です。

| | HDD | SSD |
| --- | --- | --- |
| 記録のしくみ | 磁気の円盤を回す | 電子部品に記録する |
| 速さ | 遅い | 速い |
| 衝撃 | 弱い | 強い |
| 価格 | 安価で大容量 | 容量あたり高価 |

HDDは磁気の円盤を物理的に回して読み書きします。SSDには動く部品がありません。この違いを押さえると、「SSDは速くて衝撃に強い」「HDDは安価で大容量」という特徴を暗記に頼らず導けます。

主記憶との役割分担も対で覚えてください。

| | 主記憶(RAM) | 補助記憶装置 |
| --- | --- | --- |
| 役割 | 作業中のデータの置き場 | データを長く残す置き場 |
| 電源を切ると | 消える(揮発性) | 消えない |
| 速さ | 速い | 遅い |

机(主記憶)と本棚(補助記憶装置)の関係です。「速いが消える」と「遅いが残る」の分担で、コンピュータは速さと保存を両立しています。

## もっと知りたい人へ

- 自分のパソコンのカタログや仕様表を、このレッスンの用語で読み直してみてください。CPUのGHz、メモリのGB、ストレージの種類(HDD/SSD)が読めるようになっています
- キャッシュメモリには1次・2次といった段階があります。まずは「CPUと主記憶の間にある速い中継役」という位置づけを固めるのが先です
- CPUが命令を1つずつどう処理するかは、この後のレッスンでさらに詳しく扱います

# 2-1-3
# キャッシュメモリは速さの中継役

基本情報 科目A対策 — Module 2 / レッスン2-1

<!-- ノート: 速くなったCPUの相棒、主記憶とのスピード差をどう埋めるかを1つだけ押さえます。 -->

---

## なぜ必要か

- クロック周波数が高いCPUでも、データが届かなければ働けない
- 主記憶の読み書きは、CPUの速さに追いつけない
- 速いCPUを待たせない工夫が、どこかに必要になる

<!-- ノート: つかみ。仕事の速い人が資料待ちで手を止める場面に例える。解決策はまだ言わない。 -->

---

## 結論

**キャッシュメモリは、CPUと主記憶の速度差を埋める小さくて速いメモリ**

- よく使うデータを **キャッシュメモリ** に置いておく
- CPUは主記憶まで取りに行く回数を減らせる

<!-- ノート: 結論を言い切る。手元の机によく使う資料だけ置いておく、というイメージで話す。 -->

---

## 最小の例

記憶の場所には階層があります。**アクセス時間**(読み書きにかかる時間)と容量を比べます。

| 場所 | アクセス時間 | 容量 |
| --- | --- | --- |
| **レジスタ**(CPU内部の置き場) | 最も短い | 最も小さい |
| キャッシュメモリ | 短い | 小さい |
| 主記憶 | 長い | 大きい |

<!-- ノート: 速いものほど小さい、というトレードオフを表で確認する。並べ替え問題が定番なので順序を声に出して読む。 -->

---

## キャッシュにあるか、ないか

- キャッシュメモリにあれば、すぐCPUへ渡せる
- なければ主記憶まで取りに行くので、時間がかかる
- よく使うデータほどキャッシュに置くと、待ち時間が減る

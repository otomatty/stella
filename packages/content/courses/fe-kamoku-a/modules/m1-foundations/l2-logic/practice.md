# レッスン1-2 演習 — 論理演算と集合

対象トピック: 1-2-1 〜 1-2-4

## ハンズオン

紙とペン(またはメモアプリ)だけでできる、真理値表を自分で埋めるワークです。

1. 次の表を書き写し、空欄をすべて埋めましょう

| A | B | A AND B | A OR B | A XOR B |
| --- | --- | --- | --- | --- |
| 0 | 0 |  |  |  |
| 0 | 1 |  |  |  |
| 1 | 0 |  |  |  |
| 1 | 1 |  |  |  |

2. NOT A の表(A=0 と A=1 の2行)も自分で書きましょう
3. さらに NOT(A AND B) と (NOT A) OR (NOT B) の列を書き足しましょう
4. 2つの列が全行で一致することを確かめましょう(ド・モルガンの法則)
5. 最後に「犬を飼っている人」「猫を飼っている人」の2つの円を描きます
6. 積集合・和集合・補集合がベン図のどこか、指で差して言ってみましょう

埋め終わった表は、本文の真理値表と照合してください。

## 演習問題

### 問1(基本)

A=1、B=0 のとき、次の4つの値をそれぞれ求めてください。

- A AND B
- A OR B
- A XOR B
- NOT A

### 問2(基本)

会員サイトの条件「会員である かつ 20歳以上」に当てはまらない人を考えます。ド・モルガンの法則を使って、この否定を「または」を含む形に書き換えてください。

### 問3(応用)

40人のクラスで、通学に電車を使う人は25人、バスを使う人は18人です。両方使う人は9人います。次の2つを求めてください。

1. 電車またはバスを使う人(和集合)は何人ですか
2. どちらも使わない人(和集合の補集合)は何人ですか

## 解答例と解説

<details>
<summary>問1の解答例</summary>

- A AND B = 0 — 両方1のときだけ1です。B=0 なので0になります
- A OR B = 1 — どちらかが1なら1です
- A XOR B = 1 — 入力が異なる(1と0)ので1です
- NOT A = 0 — 1を反転して0です

ANDとXORの違いは真理値表の行で確かめてください。

</details>

<details>
<summary>問2の解答例</summary>

「会員でない または 20歳未満」です。

ド・モルガンの法則で、全体の否定は「かつ」と「または」を入れ替え、個別に否定した式になります。「会員でない かつ 20歳未満」は誤りです。20歳の非会員のように、片方だけ外れる人が漏れてしまいます。

</details>

<details>
<summary>問3の解答例</summary>

1. 34人です。25 + 18 = 43 とすると、両方使う9人(積集合)を2回数えています。重なりを1回引いて、25 + 18 - 9 = 34人です
2. 6人です。全体40人から和集合の34人を除いた残り、40 - 34 = 6人です

ベン図を描くと、重なり部分を2回数えてしまう理由がひと目でわかります。

</details>

## 確認クイズ

### Q1. A=1、B=1 のとき、A OR B と A XOR B の結果の組み合わせとして適切なものはどれですか。

- A. ORは0、XORは0
- B. ORは1、XORは0
- C. ORは1、XORは1
- D. ORは0、XORは1

<details>
<summary>答え</summary>

**B** — ORはどちらかが1なら1なので1です。XORは入力が同じとき0になります。両方1の行がORとXORの唯一の違いです。

</details>

### Q2. 真理値表の説明として、適切なものはどれですか。

- A. 2進数を10進数に変換するための対応表
- B. 集合の重なりを円で表した図
- C. データを行と列で管理する表
- D. 入力の全組み合わせと演算の結果をまとめた表

<details>
<summary>答え</summary>

**D** — 真理値表は入力(0と1)の全組み合わせに対する結果の一覧です。Bはベン図の説明です。

</details>

### Q3. 排他的論理和(XOR)の結果が1になるのはどんなときですか。

- A. 両方の入力が1のとき
- B. 両方の入力が0のとき
- C. 2つの入力が異なるとき
- D. どちらかの入力が1のとき(両方1を含む)

<details>
<summary>答え</summary>

**C** — XORは「同じなら0、違えば1」です。Dは論理和(OR)の説明で、両方1のときの扱いが違います。

</details>

### Q4. 「AかつB」の否定と等しい式はどれですか。

- A. 「Aでない」かつ「Bでない」
- B. 「Aでない」または「Bでない」
- C. 「AまたはB」
- D. 「AかつB」

<details>
<summary>答え</summary>

**B** — ド・モルガンの法則です。全体の否定は、ANDとORを入れ替えて個別に否定します。Aは「AまたはB」の否定にあたります。

</details>

### Q5. 2つの集合の両方に属する部分を表す用語として、適切なものはどれですか。

- A. 積集合
- B. 和集合
- C. 補集合
- D. ベン図

<details>
<summary>答え</summary>

**A** — 両方に属する部分(ベン図で円が重なった部分)が積集合で、論理積(AND)に対応します。Bは「どちらかに属する」、Cは「属さない」に対応します。

</details>

# プロトコルは通信の約束事

基本情報 科目A対策 — Module 3 / レッスン3-2

## なぜ必要か

- ケーブルや電波でつながっても、それだけで会話は成立しない
- 日本語しか話せない人と、フランス語しか話せない人の電話と同じ
- 「どんな手順・形式でやり取りするか」を双方で揃えておきたい

<!-- ノート: つかみ。回線がつながっていても言語が違えば通じない。機器の通信にも「共通の言語」にあたるものが要る、と期待させる。名前はまだ出さない。 -->

---

## 結論

**通信の手順を決めた約束事がプロトコルで、インターネットの標準はTCP/IP**

- **プロトコル** = 通信の手順や形式を決めた約束事
- **TCP/IP** = インターネットの「共通語」にあたるプロトコル

<!-- ノート: 結論を言い切る。TCP/IPの中身の詳細には入らず、「インターネットの共通語」という一言定義で止める。 -->

---

## 最小の例

プロトコルが決めていることの例です。

- データをどんな形式で表すか
- どんな順番で送り、どう受け取ったと知らせるか
- 送受信の双方が **同じプロトコル** に従って、初めて通信が成立する

<!-- ノート: 約束事の中身を具体化する。形式と手順の両方を決めているのがポイント。片方だけ守っても通信にならない。 -->

---

## メーカーが違っても通信できる理由

- 世界中のPCやスマートフォンは、メーカーもOSもばらばら
- それでも通信できるのは、全員がTCP/IPに従っているから
- 逆に、従うプロトコルが違えば、つながっていても通信できない

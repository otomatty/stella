# 3-2-5
# DNSは名前をIPアドレスに変換する

基本情報 科目A対策 — Module 3 / レッスン3-2

<!-- ノート: レッスン最後のトピックです。宛先の番号と、私たちが普段使う「名前」をつなぎます。 -->

---

## なぜ必要か

- 通信の宛先指定はIPアドレス。でも番号の列は人間には覚えにくい
- 私たちは `www.example.com` のような名前でサイトを開いている
- 名前と番号の間を、何かがつないでいるはず

<!-- ノート: つかみ。普段の操作と、前トピックまでの知識(宛先は番号)のギャップを見せる。仕組みの名前はまだ出さない。 -->

---

## 結論

**DNSは、ドメイン名とIPアドレスを対応づける仕組み**

- **ドメイン名** = `example.com` のような、人が覚えやすい宛先の名前
- DNS(Domain Name System)が対応表を引いて変換する

<!-- ノート: 結論を言い切る。覚えやすい名前と機械が使う番号の、対応表を引く仕組み。電話帳のイメージ。 -->

---

## 最小の例

```text
① 「www.example.com のIPアドレスは?」と DNS に問い合わせる
② 「192.0.2.10 です」と返ってくる
③ 192.0.2.10 宛に通信を始める
```

<!-- ノート: 名前解決の3ステップ。ブラウザでサイトを開くたびに、裏でこの問い合わせが起きている。 -->

---

## 名前が引けないと届かない

- 対応表にないドメイン名では、相手にたどり着けない
- IPアドレスを直接指定すれば、通信そのものはできる
- 名前でアクセスできるのは、DNSに支えられているから

<!-- ノート: 失敗例枠。DNSが引けない状態を想像させると、役割の理解が確かめられる。通信自体の仕組みとは独立している点も試験で問われる。 -->

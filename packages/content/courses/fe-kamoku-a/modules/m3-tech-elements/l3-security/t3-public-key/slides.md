# 3-3-3
# 公開鍵暗号は鍵を2つ使う

基本情報 科目A対策 — Module 3 / レッスン3-3

<!-- ノート: 共通鍵暗号方式の「鍵の受け渡し問題」を解決する、もう1つの方式です。 -->

---

## なぜ必要か

- 共通鍵暗号方式では、同じ鍵を相手と共有する必要があった
- しかし、その鍵を安全に届ける手段がそもそもない
- 鍵を渡さずに、暗号のやり取りを始めたい

<!-- ノート: つかみ。前トピックで残した鍵の受け渡し問題を再確認する。「渡さなくて済む仕組み」への期待を作る。 -->

---

## 結論

**公開鍵暗号方式は公開鍵で暗号化し、対になる秘密鍵だけで復号できる**

- 鍵をペアで作り、役割を分けます
- 公開鍵 = 暗号化用。誰に知られてもよい鍵
- 秘密鍵 = 復号用。自分だけが持つ鍵

<!-- ノート: 結論を言い切る。ポイントは「公開鍵で暗号化したものは、対の秘密鍵でしか復号できない」という一方通行の関係。 -->

## 共通鍵暗号方式との対比

| | 共通鍵暗号方式 | 公開鍵暗号方式 |
| --- | --- | --- |
| 鍵 | 同じ鍵を共有 | 公開鍵と秘密鍵のペア |
| 速度 | 高速 | 低速 |
| 鍵の受け渡し | 課題になる | 公開鍵は配ってよい |

<!-- ノート: 対比枠。公開鍵暗号方式は計算が複雑で遅い。だから実務では両方を組み合わせるが、その話は深入りせず「一長一短」とだけ押さえる。 -->

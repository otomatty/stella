# 3-4-2
# アクセシビリティは「誰でも使える」

基本情報 科目A対策 — Module 3 / レッスン3-4

<!-- ノート: UI設計の続きです。「使いやすいか」の前に「そもそも使えるか」を問う考え方を押さえます。 -->

---

## なぜ必要か

- 赤と緑の色だけで「正常・異常」を区別したグラフは、色の見え方によっては区別できない
- 小さい文字、音だけの通知、マウス必須の操作にも、同じ壁がある
- 「平均的な使い手」だけを想定した画面は、使えない人を生んでしまう

<!-- ノート: つかみ。色覚の多様性は男性の約5%と言われ、決して少数ではない。高齢や一時的なけがでも同じ壁に当たる、と自分ごとにさせる。 -->

---

## 結論

**アクセシビリティは、年齢や障害の有無にかかわらず誰でも使えるようにする考え方**

- 情報やサービスへの「たどり着きやすさ」を保証する

<!-- ノート: 結論を言い切る。access + ability、つまり「利用できる度合い」。使いやすさ以前の、入り口に立てるかどうかの話。 -->

---

## 最小の例

| 壁になる画面 | 誰でも使える画面 |
| --- | --- |
| 色だけで正常・異常を区別 | 色に加えて形やラベルでも区別 |
| 画像に説明がない | 画像に **代替テキスト**(読み上げ用の説明文)を付ける |
| マウスでしか操作できない | キーボードだけでも操作できる |

<!-- ノート: 最小の例。代替テキストは、目の不自由な人が使う読み上げソフトが画像の代わりに読む文章。3つとも「別の手段を用意する」という同じ型だと気づかせる。 -->

---

## ユーザビリティとの違い

| 観点 | 問い |
| --- | --- |
| アクセシビリティ | そもそも **使えるか**(入り口に立てるか) |
| ユーザビリティ | **使いやすいか**(迷わず操作できるか) |

- アクセシビリティが土台で、その上にユーザビリティが乗る

<!-- ノート: 対比枠。試験ではこの2語の使い分けが問われる。「誰でも」が出てきたらアクセシビリティ、「効率よく・迷わず」が出てきたらユーザビリティ。 -->

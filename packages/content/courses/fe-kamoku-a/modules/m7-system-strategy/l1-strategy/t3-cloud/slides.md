# 7-1-3
# クラウドサービスの使い分け

基本情報 科目A対策 — Module 7 / レッスン7-1

<!-- ノート: ITを自前で持たずに借りる選択肢の話です。3つの区分の見分け方を1つだけ押さえます。 -->

---

## なぜ必要か

- サーバーを自前でそろえると、お金も時間もかかる
- 「借りて使う」サービスが広まっている
- でも種類が複数あり、何が違うのか分かりにくい

<!-- ノート: つかみ。機器の購入や設置を待たずに使い始めたい場面。区分の名前と違いはまだ言わない。 -->

---

## 結論

**クラウドサービスは、どこまで自分で管理するかで SaaS・PaaS・IaaS に分かれる**

- **クラウドサービス** = ネットワーク越しにITの機能を借りるサービス
- 違いは機能の中身ではなく「借りる範囲」

<!-- ノート: 結論を言い切る。3つの名前の暗記ではなく「どこまで借りるか」という1本の軸で整理する。 -->

---

## 最小の例

| 区分 | どこまで借りるか |
| --- | --- |
| **SaaS** | アプリケーションまで |
| **PaaS** | 実行環境まで |
| **IaaS** | サーバー(ハードウェア)まで |

<!-- ノート: SaaSはアプリまで全部借りるのですぐ使える。PaaSはアプリを動かす環境まで。IaaSは機器だけ借りるイメージ。 -->

---

## 自分で管理する範囲で並べる

| 区分 | 自分で管理する範囲 |
| --- | --- |
| **IaaS** | 広い(OSやソフトウェアも自分で用意) |
| **PaaS** | 中(アプリケーションだけ自分で用意) |
| **SaaS** | 狭い(ほぼ管理不要で、すぐ使える) |

- 自分で管理する範囲が広い順: IaaS → PaaS → SaaS

<!-- ノート: 補強枠。試験は「利用者の管理範囲が最も広いのはどれか」の形で問う。借りる範囲と管理する範囲は逆の関係になる。 -->

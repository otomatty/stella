# 引数は型も個数もチェックされる

TypeScript入門 — Module 4 / レッスン4-1

<!-- ノート: レッスン4-1の最後です。関数を書く側だけでなく、呼び出す側にも型が効いているという話です。 -->

---

## なぜ必要か

- 関数は「他人が作ったものを使う」場面がほとんど
- 使い方を間違えたときに、実行前に止まってほしい

<!-- ノート: つかみ。ライブラリーもチームメンバーのコードも、中身を読まずに使う。だから呼び出し側のチェックが実務では効いてくる。 -->

---

## 結論

**呼び出し側は、引数の型だけでなく個数もチェックされる**

<!-- ノート: 結論を先に言い切る。型のチェックは想像しやすいが、個数まで見てくれる点が重要。JavaScriptは個数を見ないので、TypeScriptならではの守り。 -->

---

## 最小のコード

```ts
function calcTax(price: number): number {
  return price * 0.1;
}

calcTax("1000");
// エラー: Argument of type 'string' is not
// assignable to parameter of type 'number'.

calcTax();
// エラー: Expected 1 arguments, but got 0.
```

<!-- ノート: 上が型の不一致、下が個数の不一致。argumentは「渡した値」、parameterは「受け取る側」。3-2-1のpushで見たメッセージと同じ形であることも指摘すると、既習知識がつながる。 -->

## 結論

**関数は、入力を受け取って結果を返す処理に名前を付けたもの**

- 引数 = 関数へ渡す入力
- 戻り値 = 関数から返ってくる結果
- 呼び出し = 名前を書いて関数を動かすこと

<!-- ノート: 結論を先に言い切る。引数・戻り値・呼び出しの3語をここで定義する。「材料を入れると製品が出てくる機械」というイメージ。中身を知らなくても使えるのが利点。 -->

---

## 最小のコード

```ts
function double(value: number): number {
  return value * 2;
}

console.log(double(5)); // => 10
console.log(double(120)); // => 240
```

- 1回書けば、何度でも呼び出せる

<!-- ノート: 定義と呼び出しを指し分けながら説明する。valueが引数、value * 2 の結果が戻り値、double(5)が呼び出し。書き方の細かい説明は次のトピックで行うので、ここでは形だけ見てもらう。 -->

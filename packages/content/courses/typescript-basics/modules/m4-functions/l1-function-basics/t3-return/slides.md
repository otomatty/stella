# 4-1-3
# returnで値を返す

TypeScript入門 — Module 4 / レッスン4-1

<!-- ノート: 関数から結果を取り出す方法です。1つのキーワードに2つの働きがあるので、そこを押さえます。 -->

---

## なぜ必要か

- 計算しただけでは、呼び出した側は結果を受け取れない
- `console.log`で表示するのと、値を返すのはまったく違う

<!-- ノート: つかみ。未経験者が最初に混同するのがここ。表示は画面に出すだけで、呼び出し元は何も受け取っていない。返して初めて次の計算に使える。 -->

---

## 結論

**`return`は値を返し、同時にその関数の処理をそこで終える**

- 返す働きと、終える働きの2つがある

<!-- ノート: 結論を先に言い切る。2つ目の「終える」が見落とされやすい。この性質が次のスライドの早期リターンにつながる。 -->

---

## 最小のコード

```ts
function calcTotal(price: number): number {
  const tax = price * 0.1;
  return price + tax;
  console.log("ここは実行されない");
}

console.log(calcTotal(1000)); // => 1100
```

<!-- ノート: returnの後ろの行は実行されない。エディター上でも薄く表示される(到達不能コード)。返した時点で関数の仕事は終わり、という感覚を持ってもらう。 -->

---

## 「終える」性質の使いどころ

```ts
function getLabel(stock: number): string {
  if (stock === 0) {
    return "在庫切れ";
  }
  return "在庫あり";
}
```

- 条件に当たったら、そこで抜ける(早期リターン)

<!-- ノート: 対比枠。elseを書かなくても済むので、ネストが浅くなり読みやすい。実務で非常によく使う形。2-2-3で学んだif elseと見比べて、どちらが読みやすいか考えてもらう。 -->

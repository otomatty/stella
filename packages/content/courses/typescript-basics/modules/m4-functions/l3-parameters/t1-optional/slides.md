# 4-3-1
# オプション引数

TypeScript入門 — Module 4 / レッスン4-3

<!-- ノート: レッスン4-3では引数を柔軟にする道具を4つ扱います。まずは「渡さなくてもよい引数」から。 -->

---

## なぜ必要か

- 4-1-4で見たとおり、引数の個数は厳密にチェックされる
- しかし「クーポンコードは任意」のように、省略したい引数はある

<!-- ノート: つかみ。厳密さは守りになる一方、そのままでは現実のデータに合わない。3-4-2のオプショナルプロパティと同じ構図だと接続すると理解が速い。 -->

---

## 結論

**引数名のうしろに`?`を付けると、渡さずに呼び出せる**

- 3-4-2のオプショナルプロパティと同じ記号、同じ考え方

<!-- ノート: 結論を先に言い切る。新しい概念ではなく、既に学んだ ? が引数にも使えるという話。位置も同じで、コロンの手前に置く。 -->

---

## 最小のコード

```ts
const greet = (name: string, title?: string): string => {
  return `${name}さん`;
};

console.log(greet("田中", "部長")); // OK
console.log(greet("田中")); // OK
```

<!-- ノート: 2通りの呼び出しがどちらも通る。titleを使わないコードなのは意図的で、次のスライドで「使うには絞り込みが要る」と続けるため。 -->

---

## 使うときは絞り込みが要る

```ts
const greet = (name: string, title?: string): string => {
  if (title !== undefined) {
    return `${name} ${title}`;
  }
  return `${name}さん`;
};
```

- 渡されなければ`undefined`。型は`string | undefined`

<!-- ノート: 対比枠。3-4-2とまったく同じ話。2-3-2のifによる絞り込みか、2-3-3の ?? がそのまま使える。ルールが1つ: オプション引数は必ず最後に置く(前に置くと、どれを省略したのか判別できない)。 -->

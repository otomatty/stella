## なぜ必要か

- 合計したい金額が、すでに配列に入っていることがある
- `sum(prices)`と渡しても、配列そのものが1つ目の引数になってしまう

<!-- ノート: つかみ。4-3-3で作ったsum関数に、3-1-1で作ったような配列を渡したい。素直に書くと型が合わずエラーになる。その解決策。 -->

---

## 結論

**呼び出し側で`...`を付けると、配列を1つずつの引数に展開できる**

- この書き方をスプレッド構文と呼ぶ

<!-- ノート: 結論を先に言い切る。スプレッドは「広げる」の意味。残余引数が「集める」、スプレッドが「広げる」。同じ記号で正反対の働きをする。 -->

---

## 最小のコード

```ts
const sum = (...prices: number[]): number => {
  let total = 0;
  for (const price of prices) {
    total = total + price;
  }
  return total;
};

const prices = [480, 500, 450];
console.log(sum(...prices)); // => 1430
```

<!-- ノート: sum(prices) だと配列そのものを1つ渡すことになり型が合わない。ドット3つを付けると、480, 500, 450 と並べて書いたのと同じになる。 -->

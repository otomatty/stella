# 4-3-3
# 残余引数

TypeScript入門研修 — Module 4 / レッスン4-3

<!-- ノート: 引数の個数が決まっていないときの書き方です。使う場面は限られますが、読めないと詰まるので押さえます。 -->

---

## なぜ必要か

- 「渡された金額を全部合計する」関数は、引数が何個になるか分からない
- オプション引数を10個並べるわけにはいかない

<!-- ノート: つかみ。合計や連結など「いくつでも受け取りたい」処理は実在する。配列で渡してもらう手もあるが、呼び出し側が角かっこを書く手間が増える。 -->

---

## 結論

**引数の前に`...`を付けると、残りをすべて配列で受け取れる**

- この引数を残余引数と呼ぶ
- 型注釈は配列の型で書く

<!-- ノート: 結論を先に言い切る。残余は「残り」の意味。ドット3つ。関数の中では普通の配列として扱えるので、3-2-3のfor-ofがそのまま使える。 -->

---

## 最小のコード

```ts
const sum = (...prices: number[]): number => {
  let total = 0;
  for (const price of prices) {
    total = total + price;
  }
  return total;
};

console.log(sum(480, 500, 450)); // => 1430
```

<!-- ノート: 呼び出し側は角かっこを書かずに値を並べるだけ。関数の中では prices が number[] の配列になっている。3-2-4で書いた集計処理が、そのまま関数の中に入っている点も確認する。 -->

---

## ルール: 残余引数は最後に1つだけ

```ts
const summarize = (label: string, ...prices: number[]): string => {
  return `${label}: ${prices.length}件`;
};

console.log(summarize("金額", 480, 500)); // => "金額: 2件"
```

<!-- ノート: 対比枠。前に通常の引数を置くのはよいが、残余引数の後ろには何も置けない(どこまでが残りか判別できないため)。受け取ったpricesが普通の配列なので、3-1-3で学んだlengthもそのまま使える。 -->

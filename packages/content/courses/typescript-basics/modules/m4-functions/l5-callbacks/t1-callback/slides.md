## なぜ必要か

- 「一覧を作る」処理は同じで、「1件をどう整形するか」だけ変えたい
- 処理の一部分だけを差し替えたい場面が実務には多い

<!-- ノート: つかみ。全体の流れは共通で、一部だけ違う。コピーして1行だけ変えるのがいちばん素朴な解決策だが、それでは同じコードが増えていく。 -->

---

## 結論

**関数は値なので、他の関数に引数として渡せる**

- 引数として渡される関数をコールバックと呼ぶ
- 渡された側が、あとで呼び出す(call back)

<!-- ノート: 結論を先に言い切る。コールバックという言葉を定義する。「渡した関数を、向こうが好きなタイミングで呼び返す」というイメージ。 -->

---

## 最小のコード

```ts
type Formatter = (name: string) => string;

const shout: Formatter = (name) => `${name}!!`;

const show = (name: string, format: Formatter): void => {
  console.log(format(name));
};

show("コーヒー", shout); // => "コーヒー!!"
```

<!-- ノート: showの2つ目の引数がコールバック。型は4-4-4で学んだ関数型の型エイリアスで書ける。showの中身を変えずに、渡す関数を差し替えるだけで挙動が変わることを強調する。 -->

---

## よくある間違い: 実行結果を渡してしまう

```ts
show("コーヒー", shout("コーヒー"));
// エラー: Argument of type 'string' is not assignable
// to parameter of type 'Formatter'.
```

- かっこを付けると「呼び出した結果」になる

<!-- ノート: 対比枠。関数そのものを渡すときはかっこを付けない。かっこは「いま実行する」という合図。ここは未経験者が必ず一度は間違えるので、型が止めてくれることも含めて確認する。 -->

# レッスン4-2 関数の書き方3種

## このレッスンの目標

- [ ] 関数式とアロー関数を読める
- [ ] 「関数は値である」という考え方を説明できる
- [ ] 3つの書き方を使い分ける基準を持っている

## 4-2-1 関数式

> **関数は値なので、変数に入れて名前を付けられる**

他人のコードに `const 名前 = function ...` という形が出てきます。関数宣言しか知らないと、別の言語かと思ってしまいます。

```ts
const calcTax = function (price: number): number {
  return price * 0.1;
};

console.log(calcTax(1000)); // => 100
```

この書き方を**関数式**と呼びます。`function`の後ろに名前がなく、名前は変数名のほうが担っています。末尾のセミコロンは、これが代入文だから必要です(関数宣言には付けません)。

**「関数は値である」がここでの本質です。** 数値や文字列と同じように変数へ代入できます。この考え方はレッスン4-5のコールバックで決定的に効いてきます。

関数宣言との違いは1つあります。

```ts
console.log(calcTax(1000));
// エラー: Block-scoped variable 'calcTax' used
// before its declaration.

const calcTax = function (price: number): number {
  return price * 0.1;
};
```

関数宣言なら定義より前の行でも呼び出せますが、関数式は変数なので宣言前には使えません。レッスン1-1で学んだ変数のルールがそのまま適用されます。

## 4-2-2 アロー関数

> **アロー関数は「引数 => 処理」と書く、関数式の短い書き方**

実務のコードで最も多いのがこの書き方です。矢印(arrow)に見えることからアロー関数と呼びます。

```
const 名前 = (引数: 型): 戻り値の型 => {
  処理
};
```

```ts
const calcTax = (price: number): number => {
  return price * 0.1;
};

console.log(calcTax(1000)); // => 100
```

4-2-1の関数式と、まったく同じ動きです。`function`という単語が消えて、代わりに矢印が入っただけで、引数のかっこ・型注釈・中かっこの位置はすべて同じです。

処理が式1つだけなら、さらに短くできます。

```ts
const calcTax = (price: number): number => price * 0.1;
```

中かっこと`return`を省略すると、その式の結果が自動で返ります。実務で多用されるので読めるようにしておいてください。複数行の処理があるときは省略できません。

## 4-2-3 3つの書き方をどう選ぶか

> **本研修はアロー関数を基本にする。関数宣言も読めれば十分**

同じことが3通りに書けると、書くたびに迷います。レッスン1-1の「まず`const`」、レッスン1-2の「推論に任せる」と同じで、基準を1つ持っておくと迷いません。

| 書き方 | 特徴 |
| --- | --- |
| 関数宣言 | `function` で書く。いちばん基本の形 |
| 関数式 | 関数を「値」として変数に代入する |
| アロー関数 | `=>` で短く書ける。本研修はこれを基本にする |

違うのは書き出しの形だけで、引数・型注釈・処理は同じです。読み替えができれば、どの書き方のコードでも読めます。

実務でも新しいコードはアロー関数が主流ですが、関数宣言は古いコードや一部のスタイルで現役です。**配属先の規約が最優先**である点は変わりません。

いま覚えておく違いは1つだけです。

| | 宣言前に呼べる |
| --- | --- |
| 関数宣言 | できる |
| 関数式 / アロー関数 | **できない** |

他にも違いはありますが(`this`の扱いなど)、クラスを学ぶModule 7で必要になったときに扱います。

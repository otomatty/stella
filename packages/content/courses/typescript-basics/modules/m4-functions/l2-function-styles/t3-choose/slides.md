# 3つの書き方をどう選ぶか

TypeScript入門 — Module 4 / レッスン4-2

<!-- ノート: レッスン4-2の最後です。3つ出そろったので、迷わないための基準を1つだけ決めます。 -->

---

## なぜ必要か

- 同じことが3通りに書けると、書くたびに迷う
- チームで揃っていないと、レビューで無用な指摘が増える

<!-- ノート: つかみ。1-1-3のconstファースト、1-2-5の推論優先と同じ構図。技術的にどれでも動くからこそ、基準を持っておくと迷わない。 -->

---

## 結論

**本研修はアロー関数を基本にする。関数宣言も読めれば十分**

- 実務でも新しいコードはアロー関数が主流
- 関数宣言は古いコードや一部のスタイルで現役

<!-- ノート: 結論を先に言い切る。ただし配属先の規約が最優先であることを必ず添える。関数宣言を基本にするチームもあり、どちらも間違いではない。 -->

---

## 3つの書き方の対応

| 書き方 | 特徴 |
| --- | --- |
| 関数宣言 | `function` で書く。いちばん基本の形 |
| 関数式 | 関数を「値」として変数に代入する |
| アロー関数 | `=>` で短く書ける。本研修はこれを基本にする |

<!-- ノート: 同じ処理を3通りで並べた表。違うのは書き出しの形だけで、引数・型注釈・処理は同じ。読み替えができれば、どの書き方のコードでも読める。 -->

---

## 覚えておく違いは1つだけ

| | 宣言前に呼べる |
| --- | --- |
| 関数宣言 | できる |
| 関数式 / アロー関数 | **できない** |

# 関数式

TypeScript入門 — Module 4 / レッスン4-2

<!-- ノート: レッスン4-2では、関数の書き方が3つあることを扱います。まず2つ目の書き方から。ここに後の回で効いてくる重要な考え方が入っています。 -->

---

## なぜ必要か

- 他人のコードに `const 名前 = function ...` という形が出てくる
- 関数宣言しか知らないと、別の言語かと思ってしまう

<!-- ノート: つかみ。3つの書き方が混在しているのが現実のコード。読めるようにしておくのが目的で、どれを書くかは4-2-3で決める。 -->

---

## 結論

**関数は値なので、変数に入れて名前を付けられる**

- この書き方を関数式と呼ぶ

<!-- ノート: 結論を先に言い切る。「関数は値である」がここでの本質。数値や文字列と同じように変数へ代入できる。この考え方はレッスン4-5のコールバックで決定的に効いてくる。 -->

---

## 最小のコード

```ts
const calcTax = function (price: number): number {
  return price * 0.1;
};

console.log(calcTax(1000)); // => 100
```

- 呼び出し方は関数宣言と同じ

<!-- ノート: functionの後ろに名前がない点を指す。名前は変数名のほうが担っている。末尾のセミコロンは、これが代入文だから必要。関数宣言には付けないので、違いとして指摘しておく。 -->

---

## 関数宣言との違い: 書く前には使えない

```ts
console.log(calcTax(1000));
// エラー: Block-scoped variable 'calcTax' used
// before its declaration.

const calcTax = function (price: number): number {
  return price * 0.1;
};
```

<!-- ノート: 対比枠。関数宣言なら定義より前の行でも呼び出せるが、関数式は変数なので宣言前には使えない。1-1-1で学んだ変数のルールがそのまま適用されると理解すればよい。 -->

---

## まとめ

**関数は値なので、変数に入れて名前を付けられる**

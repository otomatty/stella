# 関数の型

TypeScript入門 — Module 4 / レッスン4-4

---

## なぜ必要か

- 関数を変数に入れるなら、その変数の型は何なのか
- 次のレッスンで関数を引数として渡すとき、必ず必要になる

<!-- ノート: つかみ。4-2-1で関数を変数に代入した。数値ならnumber、文字列ならstring。では関数の型は?という素直な疑問。4-5のコールバックの準備でもある。 -->

---

## 結論

**関数そのものの型は`(引数: 型) => 戻り値の型`と書く**

- アロー関数の書き方から、中身だけ取り除いた形

<!-- ノート: 結論を先に言い切る。アロー関数の定義とよく似ているので、見比べれば覚えられる。矢印の右が処理ではなく戻り値の型になる点だけが違う。 -->

---

## 最小のコード

```ts
const calcTax: (price: number) => number = (price) => {
  return price * 0.1;
};

console.log(calcTax(1000)); // => 100
```

- 変数の型注釈として書ける

<!-- ノート: コロンの後ろが関数の型。右辺の実装側では、引数の型注釈を省略できる点も指摘する(左の型から推論されるため)。ただしこの書き方は長いので、次のトピックで名前を付ける。 -->

---

## Playgroundで推論された型を見る

```ts
const calcTax = (price: number): number => price * 0.1;
// 推論: (price: number) => number
```

<!-- ノート: 対比枠。実は今まで書いてきた関数にも、この形の型が付いていた。PlaygroundでcalcTaxにカーソルを乗せると表示される。新しい概念ではなく、見えていなかったものに名前が付いただけだと伝える。 -->

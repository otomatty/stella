TypeScript入門 — Module 6 / レッスン6-2

---

## なぜ必要か

- 設定オブジェクトと、その型を別々に書くと二重管理になる
- 項目を足したとき、片方だけ直して食い違う

<!-- ノート: つかみ。3-4-1で型エイリアスを導入したときと同じ「重複を減らす」動機。ただし今回は、型どうしではなく値と型の重複。 -->

---

## 結論

**型の位置で使う`typeof`は、変数から型を取り出す**

- 1-6-3の`typeof`(値を調べる)とは**別物**
- 見分け方は、書いてある場所が型の位置かどうか

<!-- ノート: 結論を先に言い切る。同じ綴りで違う機能なので、必ず区別を明示する。1-6-3は実行時に文字列を返す演算子、こちらはコンパイル時に型を作る演算子。 -->

---

## 最小のコード

```ts
const config = {
  env: "production",
  port: 3000,
};

type Config = typeof config;
// { env: string; port: number }
```

- 値を1回書けば、型は自動で付いてくる

<!-- ノート: 型注釈の位置(typeの右)にtypeofが書かれている点を指す。configに項目を足すと、Configにも自動で反映される。二重管理がなくなる。 -->

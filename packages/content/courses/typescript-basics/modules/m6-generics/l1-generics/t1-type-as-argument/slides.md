# 型も引数にできる

TypeScript入門研修 — Module 6 / レッスン6-1

## なぜ必要か

- 「配列の先頭を返す」処理を、`string[]`用と`number[]`用に2つ書くことになる
- `any`にすると動くが、戻り値の型が分からなくなる

<!-- ノート: つかみ。中身の処理はまったく同じで、型だけが違う。コピーするか、anyで諦めるかの二択に見える。5-3-1で学んだとおりanyは避けたい。 -->

---

## 結論

**ジェネリクスは、型を後から決められるようにする仕組み**

- 型引数 = あとで決まる型を入れておく「型の変数」

<!-- ノート: 結論を先に言い切る。ジェネリクスと型引数を定義する。値を受け取る引数と同じ発想を、型に対して行う。「型のテンプレート」というイメージ。 -->

---

## 最小のコード

```ts
// 型ごとに書いていた
const firstString = (items: string[]): string => items[0];
const firstNumber = (items: number[]): number => items[0];

// 型を引数にすれば1つで済む
const first = <T>(items: T[]): T => items[0];
```

- `T`が型引数。呼び出すときに決まる

<!-- ノート: 上2つは中身が同じで型だけ違う。下の1つで両方をまかなえる。Tは Type の頭文字で、慣習的によく使われる名前。書き方の詳細は次のトピックで扱う。 -->

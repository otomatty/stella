## なぜ必要か

- 「もし在庫が0なら」を書くには、まず「在庫が0かどうか」を値にする必要がある
- その値を作る道具が比較演算子

<!-- ノート: つかみ。分岐を書くには判定結果が要る。判定結果は1-3-4で学んだbooleanそのものだと接続すると、既習知識が生きる。 -->

---

## 結論

**比較演算子の結果は`boolean`。等価の判定は`===`を使う**

| 記号 | 意味 |
| --- | --- |
| `===` / `!==` | 等しい / 等しくない |
| `>` `<` | より大きい / より小さい |
| `>=` `<=` | 以上 / 以下 |

<!-- ノート: 結論を先に言い切る。イコールが3つ並ぶ形に驚く受講者が多いので、ここで理由も添える。イコール1つは代入、2つは緩い比較、3つが厳密な比較。実務では常に3つを使う。 -->

---

## 最小のコード

```ts
const stock = 0;

console.log(stock === 0); // => true
console.log(stock > 10); // => false
console.log(stock !== 0); // => false
```

- 結果はすべて`true`か`false`

<!-- ノート: 3行とも結果がbooleanであることを確認する。この値をそのまま変数に入れられることも見せると、1-3-4のisPaidのような真偽値の変数につながる。 -->

---

## よくある間違い: `=` と `===`

```ts
let stock = 5;

stock = 0; // 代入(値が変わる)
stock === 0; // 比較(true/falseを作る)
```

- `=` は代入、`===` は比較。**まったく別物**

<!-- ノート: 対比枠。イコール1つで比較したつもりが代入していた、というバグは定番。TypeScriptはconstなら代入をエラーにしてくれるので、1-1-3のconstファーストがここでも効くと接続する。 -->

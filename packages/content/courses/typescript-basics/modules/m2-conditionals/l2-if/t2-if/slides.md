## 結論

**`if`は、条件がtrueのときだけブロックを実行する**

```
if (条件) {
  条件がtrueのときだけ実行される
}
```

<!-- ノート: 結論を先に言い切る。条件という言葉をここで定義する。かっこの中がtrueかfalseかで、中かっこの中を通るかどうかが決まる。中かっこは2-1-1で学んだブロックそのもの。 -->

---

## 最小のコード

```ts
const stock = 0;

if (stock === 0) {
  console.log("在庫切れです");
}
// => "在庫切れです"
```

- `stock`を`5`に変えると、何も表示されなくなる

<!-- ノート: Playgroundでstockの値を書き換えて、出力が消えることを実演する。条件がfalseならブロックごと飛ばされる、という動きを目で見てもらうのが大事。 -->

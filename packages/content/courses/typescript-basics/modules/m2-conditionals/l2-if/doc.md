# レッスン2-2 条件分岐

## このレッスンの目標

## 2-2-1 比較演算子

> **比較演算子の結果は`boolean`。等価の判定は`===`を使う**

「もし在庫が0なら」を書くには、まず「在庫が0かどうか」を値にする必要があります。それを作るのが比較演算子です。結果はレッスン1-3で学んだ`boolean`そのものです。

| 記号 | 意味 |
| --- | --- |
| `===` / `!==` | 等しい / 等しくない |
| `>` `<` | より大きい / より小さい |
| `>=` `<=` | 以上 / 以下 |

```ts
const stock = 0;

console.log(stock === 0); // => true
console.log(stock > 10); // => false
console.log(stock !== 0); // => false
```

イコールが3つ並ぶ形に驚くかもしれません。イコール1つは代入、2つは緩い比較、3つが厳密な比較です。**実務では常に3つを使います。**

```ts
let stock = 5;

stock = 0; // 代入(値が変わる)
stock === 0; // 比較(true/falseを作る)
```

`=` と `===` はまったく別物です。イコール1つで比較したつもりが代入していた、というバグは定番なので注意してください。

## 2-2-2 if文

> **`if`は、条件がtrueのときだけブロックを実行する**

ここまでのコードは、上から下へ1本道でしか進めませんでした。`if`を使うと場合分けができます。

```
if (条件) {
  条件がtrueのときだけ実行される
}
```

```ts
const stock = 0;

if (stock === 0) {
  console.log("在庫切れです");
}
// => "在庫切れです"
```

`stock`を`5`に変えると、何も表示されなくなります。条件が`false`ならブロックごと飛ばされます。中かっこは2-1-1で学んだブロックそのものです。

## 2-2-3 elseとelse if

> **`else`は条件がfalseのとき、`else if`は別の条件を続けて試すときに使う**

上から順に判定し、**最初に当たった1つだけ**が実行されます。

```ts
const point = 250;

if (point >= 500) {
  console.log("ゴールド会員");
} else if (point >= 100) {
  console.log("シルバー会員");
} else {
  console.log("一般会員");
}
// => "シルバー会員"
```

250は「500以上」ではないので次へ進み、「100以上」に当たった時点で確定します。3つ目の`else`は見に行きません。

この順序性が落とし穴になります。

```ts
if (point >= 100) {
  console.log("シルバー会員"); // 500点でもここに入ってしまう
} else if (point >= 500) {
  console.log("ゴールド会員"); // 永遠に実行されない
}
```

範囲が広い条件を先に書くと、後ろが届かなくなります。エラーは出ません。**範囲で分岐するときは、狭い条件から順に書いてください。**

## 2-2-4 三項演算子

> **三項演算子は、条件によって「値を選ぶ」ときに使う**

「会員なら割引価格、そうでなければ通常価格」を変数に入れたいとき、`if`で書くと`let`にせざるを得ず、レッスン1-1で決めた「まず`const`」が崩れます。

```
条件 ? trueのときの値 : falseのときの値
```

```ts
const isMember = true;

const price = isMember ? 400 : 500;
console.log(price); // => 400
```

`const`のまま書けるのが`if`との最大の違いです。「isMemberなら400、そうでなければ500」と日本語に置き換えて読むと覚えやすくなります。

使い分けは明快です。

```ts
// 値を選ぶ → 三項演算子
const label = isMember ? "会員価格" : "通常価格";

// 処理を分ける → if
if (isMember) {
  console.log("会員向けクーポンを表示");
}
```

入れ子にすると一気に読めなくなるので、三項演算子は2択までにとどめます。3択以上なら`if` / `else if`か`switch`を使ってください。

# 「??」で既定値を用意する

TypeScript入門研修 — Module 2 / レッスン2-3

<!-- ノート: レッスン2-3の最後です。「値がなければ代わりにこれ」を1行で書く演算子を1つ覚えます。実務で毎日使います。 -->

---

## なぜ必要か

- 「ニックネームが未設定なら『ゲスト』と表示する」ような既定値は頻出する
- 毎回`if`で囲むと、3行が5行になっていく

<!-- ノート: つかみ。2-3-2のifによる絞り込みは正しいが、既定値を入れたいだけなら大げさ。用途に合った短い道具があると伝える。 -->

---

## 結論

**`??`は、左が`null`か`undefined`のときだけ右の値を使う**

```
値 ?? 値がなかったときの代わり
```

<!-- ノート: 結論を先に言い切る。クエスチョンマーク2つでnull合体演算子と読む。「左がなければ右」と覚える。左に値があれば右は一切評価されない。 -->

---

## 最小のコード

```ts
const nickname: string | undefined = undefined;

const display = nickname ?? "ゲスト";
console.log(display); // => "ゲスト"
```

- `display`の型は`string`に確定する

<!-- ノート: undefinedの可能性が消えるので、結果はstringになる。Playgroundでdisplayにカーソルを乗せて型を確認させると効果的。nicknameに値を入れると、そちらが使われることも実演する。 -->

---

## `||` との違い: 0と空文字の扱い

```ts
const stock = 0;

console.log(stock ?? 10); // => 0  (0は「値がある」)
console.log(stock || 10); // => 10 (0はfalsy)
```

<!-- ノート: 対比枠。似た演算子に||があるが、こちらは2-3-1のfalsy判定なので0や空文字も置き換えてしまう。在庫0が10に化ける事故につながる。既定値を入れたいなら ?? を使う、と結論を明確にする。 -->

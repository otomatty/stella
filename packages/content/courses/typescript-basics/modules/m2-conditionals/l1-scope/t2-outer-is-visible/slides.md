# 内側からは外の変数が見える

TypeScript入門研修 — Module 2 / レッスン2-1

<!-- ノート: 前のトピックで「中の変数は外から見えない」ことを確認しました。では逆はどうなのかを、ここで決着させます。 -->

---

## なぜ必要か

- 中かっこの中で、外側の変数を使いたい場面は日常的にある
- 使えるのか使えないのかが曖昧だと、書くたびに迷う

<!-- ノート: つかみ。たとえば税率を外で決めて、条件分岐の中で使う。実務のコードはほぼこの形になるので、ここを確定させておく。 -->

---

## 結論

**スコープは内側からは外が見える。外からは内側が見えない**

- 見える向きは一方通行

<!-- ノート: 結論を先に言い切る。前のトピックと合わせて、これでスコープの規則は完結する。「外は共有スペース、中は個室」というイメージが伝わりやすい。 -->

---

## 最小のコード

```ts
const taxRate = 0.1;

{
  const price = 300;
  console.log(price * (1 + taxRate)); // => 330.00000000000006
}
```

- 内側から外の`taxRate`が使えている

<!-- ノート: 外で宣言したtaxRateが、ブロックの中から問題なく使えることを確認する。結果に誤差が出ているのは1-3-3で学んだ小数の誤差。ここでは本題ではないので軽く触れるだけにする。 -->

---

## 一方通行だから安全になる

```ts
const taxRate = 0.1;

{
  const price = 300;
}

console.log(price);
// エラー: Cannot find name 'price'.
```

<!-- ノート: 対比枠。同じコードで逆向きを試すと、やはり見えない。共通のものは外に、その場限りのものは中に置く、という置き場所の判断につながると添える。 -->

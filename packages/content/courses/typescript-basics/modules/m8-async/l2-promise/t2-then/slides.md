# 8-2-2
# thenで結果を受け取る

TypeScript入門 — Module 8 / レッスン8-2

<!-- ノート: Promiseの中身を取り出す方法です。そして、コールバック地獄が解ける瞬間でもあります。 -->

---

## なぜ必要か

- 箱の中身は、できあがるまで直接は取り出せない
- 「できたら教えて」と登録しておく必要がある

<!-- ノート: つかみ。8-2-1でconsole.logしたとき pending としか出なかった。中身を待って使う手段が要る。 -->

---

## 結論

**`then`は結果が出たら動くコールバックを登録し、新しい`Promise`を返す**

- **新しい`Promise`を返す**のが肝。だからつなげられる

<!-- ノート: 結論を先に言い切る。前半は素直な説明、後半が本質。4-5-4でmapとfilterがつなげられたのと同じ理屈で、戻り値が同じ種類だからチェーンできる。 -->

---

## 最小のコード

```ts
const order = new Promise((resolve) => {
  setTimeout(() => resolve("コーヒー"), 1000);
});

order.then((item) => {
  console.log(`${item}ができました`);
});
// 1秒後 => "コーヒーができました"
```

<!-- ノート: thenのかっこの中がコールバック。resolveに渡した値が、そのまま引数itemに入る。8-1-2のsetTimeoutと同じく、その場でアロー関数を書いて渡している。 -->

---

## つなげると入れ子が消える

```ts
order
  .then((item) => `${item}を包装`)
  .then((packed) => console.log(`${packed}しました`));
// 1秒後 => "コーヒーを包装しました"
```

<!-- ノート: 対比枠。8-1-4の入れ子が、縦に並ぶ形になった。thenの中でreturnした値が、次のthenの引数になる。4-5-4のメソッドチェーンとまったく同じ読み方ができる。 -->

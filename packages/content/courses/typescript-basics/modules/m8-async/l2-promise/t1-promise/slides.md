# Promiseとは

TypeScript入門研修 — Module 8 / レッスン8-2

---

## なぜ必要か

- 「結果はまだないが、いずれ来る」という状態を表す値がほしい
- 値として扱えれば、変数に入れたり関数から返したりできる

<!-- ノート: つかみ。コールバックは「処理を渡す」形だった。Promiseは「結果を受け取る」形。値になるので、8-1-4の入れ子から抜け出せる。 -->

---

## 結論

**`Promise`は「あとで結果が入る箱」。成功か失敗のどちらかに一度だけ決まる**

- `resolve` = 成功として結果を入れる
- `reject` = 失敗として理由を入れる

<!-- ノート: 結論を先に言い切る。3語を定義する。引換券のイメージ。券そのものはすぐもらえるが、中身は後から確定する。一度決まったら変わらない点も重要。 -->

---

## 最小のコード

```ts
const order = new Promise((resolve) => {
  setTimeout(() => {
    resolve("コーヒーができました");
  }, 1000);
});

console.log(order); // => Promise { <pending> }
```

- `new`で作るので、7-1-1で学んだクラスのインスタンス

<!-- ノート: pendingは「保留中」。この時点ではまだ中身がない。resolveを呼んだ瞬間に成功が確定する。実務でPromiseを自分で作る機会は少ないが、仕組みを知ると後が楽になる。 -->

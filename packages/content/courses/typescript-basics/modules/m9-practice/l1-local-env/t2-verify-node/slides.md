# インストールを確認する

TypeScript入門 — Module 9 / レッスン9-1

## なぜ必要か

- 入れたつもりでも、ターミナルがまだ知らないことがある
- 「動くはず」で進むと、あとで原因が分からなくなる

<!-- ノート: つかみ。自習ではここが一番つまずく。確認コマンドを成功条件にする。 -->

---

## 結論

**インストール後は、ターミナルで`node -v`と`npm -v`を確認する**

<!-- ノート: 結論を先に言い切る。バージョン番号の数字自体は環境で違うので気にしなくてよい。表示されれば成功。 -->

---

## 入れるものと確認コマンド

- 公式サイトから**LTS版**(長く保守される安定版)を入れる
- 入れたらターミナルを開き直す

```bash
node -v
npm -v
```

<!-- ノート: Windowsではコマンドプロンプト(cmd)を正とする。PowerShellは実行ポリシーでnpmが止まることがある。インストール後はターミナルをいったん閉じて開き直す。詳細なクリック手順はdocと演習に書く。 -->

---

## よくあるつまずき

- インストール後、**ターミナルを開き直していない**
- 「command not found」は、まだ認識されていないだけのことが多い
- PowerShellで`npm`が止まるときは、**コマンドプロンプト**を使う

<!-- ノート: 対比枠。それでも駄目ならPCの再起動を案内する。PATHの深い編集や実行ポリシーの変更は、この研修では扱わない。cmdに切り替えれば足りる。 -->

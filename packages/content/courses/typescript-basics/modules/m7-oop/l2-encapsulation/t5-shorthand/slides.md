# コンストラクタショートハンド

TypeScript入門研修 — Module 7 / レッスン7-2

<!-- ノート: レッスン7-2の最後です。TypeScriptにしかない省略記法を1つ覚えます。実務のコードで頻繁に見かけます。 -->

---

## なぜ必要か

- プロパティ名を、宣言・引数・代入の**3か所**に書いている
- 項目が5つあれば15回書くことになる

<!-- ノート: つかみ。7-1-3で書いたコードを見返してもらう。name という単語が3回出てくる。1つ増やすたびに3か所直すのは、これまで嫌ってきた重複そのもの。 -->

---

## 結論

**コンストラクタの引数に修飾子を付けると、宣言と代入を省略できる**

- `private` や `readonly` を引数の前に書くだけ

<!-- ノート: 結論を先に言い切る。修飾子を書くことが「これはプロパティです」という宣言も兼ねる。TypeScript独自の記法で、JavaScriptにはない。 -->

---

## 省略前

```ts
class Product {
  private readonly id: string;
  private name: string;

  constructor(id: string, name: string) {
    this.id = id;
    this.name = name;
  }
}
```

<!-- ノート: 宣言・引数・代入の3ブロックがある。idもnameも3回ずつ登場している。 -->

---

## 省略後

```ts
class Product {
  constructor(
    private readonly id: string,
    private name: string,
  ) {}
}
```

- 引数に修飾子を書くだけで、プロパティが自動で作られる

<!-- ノート: 対比枠。同じ動きで、行数が半分以下になった。中かっこが空でも問題ない。注意点は「修飾子を書き忘れると、ただの引数になってプロパティが作られない」こと。何も書かない引数と混在させないほうが安全。 -->

## なぜ必要か

- 税込価格の計算は、その商品のデータがあってこそ意味がある
- 関数を外に置くと、毎回データを引数で渡すことになる

<!-- ノート: つかみ。Module 4なら calcTotal(product) と書いていた。データを持っている本人が計算できれば、引数を渡す必要がない。 -->

---

## 結論

**クラスの中に書いた関数をメソッドと呼び、`this`で自分のデータを使える**

- 実は既に使っている: `push` や `map` はメソッド

<!-- ノート: 結論を先に言い切る。3-2-1のpushや4-5-2のmapは、配列というオブジェクトが持つメソッドだった。ドット記法で呼ぶものはメソッド、と整理すると既習知識がつながる。 -->

---

## 最小のコード

```ts
class Product {
  name: string;
  price: number;

  constructor(name: string, price: number) {
    this.name = name;
    this.price = price;
  }

  taxIncluded(): number {
    return Math.round(this.price * 1.1);
  }
}
```

<!-- ノート: functionもアロー関数も書かず、関数名とかっこだけ。中では this.price で自分のデータにアクセスできる。引数が要らない点が、外に関数を置く場合との最大の違い。 -->

# 5-2-2
# typeofによる型ガード

TypeScript入門 — Module 5 / レッスン5-2

<!-- ノート: 型ガードの1つ目です。1-6-3で道具として紹介したtypeofが、ここで型を動かす役割を持ちます。 -->

---

## なぜ必要か

- `string | number` を、値の有無ではなく**種類**で分けたい
- `!== undefined` では、この2つを区別できない

<!-- ノート: つかみ。2-3-2で学んだのは「値があるか」の判定。ここでは「どの種類か」の判定。同じ絞り込みでも、判定の軸が違う。 -->

---

## 結論

**`typeof`で比べると、プリミティブ型のユニオンを絞り込める**

- `typeof 値 === "string"` のように書く

<!-- ノート: 結論を先に言い切る。1-6-3で学んだtypeofは型名を文字列で返す演算子だった。その戻り値を比較すると、コンパイラーが型ガードとして認識してくれる。 -->

---

## 最小のコード

```ts
const id: string | number = "A-1001";

if (typeof id === "string") {
  console.log(id.length); // ここでは string
} else {
  console.log(id * 2); // ここでは number
}
```

<!-- ノート: 5-1-1で使えなかったlengthが、ifの中では使えている。elseの側ではnumberに確定しているので掛け算ができる。両方の枝で型が決まっている点を確認する。 -->

---

## 使えるのはプリミティブ型だけ

```ts
type Success = { data: string };
type Failure = { message: string };

// typeof はどちらも "object" を返すので分けられない
```

<!-- ノート: 対比枠。5-1-2で見たとおり。オブジェクト同士には効かない。だから5-1-3の判別可能なユニオン型や、次のトピックのinが必要になる。道具ごとに守備範囲が違うと整理する。 -->

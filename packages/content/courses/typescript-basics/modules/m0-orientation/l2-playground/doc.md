# レッスン0-2 Playgroundを使う

## このレッスンの目標

- [ ] TypeScript Playgroundを開いてコードを書ける
- [ ] `console.log`で結果を確認できる
- [ ] エラーメッセージを読んで、次の一手を決められる

## 0-2-1 Playgroundで書き始める

> **Playgroundを開けば、インストールなしでTypeScriptを書いて動かせる**

未経験者が学習をやめてしまう理由の上位が環境構築です。本研修では後回しにします。Module 8まではブラウザだけで完結し、自分のPCへの環境構築はModule 9で扱います。

**TypeScript Playground**: <https://www.typescriptlang.org/ja/play>

ブックマークしておいてください。覚えるのは画面の3か所だけです。

![Playgroundの画面構成図。左がエディター、右に.JSタブとErrorsタブ](t1-playground/assets/playground-layout.svg)

- **左** — コードを書く場所
- **右「.JS」** — 変換後のJavaScript。0-1-3で学んだ「型が消える」ことを目で確かめられます
- **右「Errors」** — エラーの一覧

書いたコードに合わせてURLが自動で変わります。そのURLを送れば、相手も同じコードを開けます。演習で詰まったときの共有手段として使ってください。

## 0-2-2 console.logで結果を確かめる

> **`console.log`は、かっこの中の値を画面に表示する命令**

コードを書いても、結果が見えなければ合っているかわかりません。学習中は「予想 → 実行 → 答え合わせ」の繰り返しがいちばん速く身につきます。

コンソール(console)は「結果を出す場所」、ログ(log)は「記録」の意味です。

```ts
console.log("こんにちは");
// => "こんにちは"

console.log(300 + 50);
// => 350
```

Playgroundでは「Run」を押すと下に結果が出ます。本教材では、実行結果をコメントの`// =>`で示す約束です。

表示されないときは、次の順に確認してください。

1. 「Run」を押したか
2. かっこや引用符が閉じているか
3. そもそもエラーが出ていないか

## 0-2-3 エラーメッセージの読み方

> **赤い波線にカーソルを乗せれば、何が悪いかが書いてある**

未経験者がいちばん手を止めるのは、赤い波線を見た瞬間です。ですが実際には、原因と直し方がそこに書いてあります。

**エラーが出ることは失敗ではありません。気づけたということです。** 0-1-1で見たとおり、気づくのが早いほど直す手間は小さくなります。

```ts
const price: number = "300";
// エラー: Type 'string' is not assignable to type 'number'.
```

「string型は、number型に代入(assign)できません」という意味です。英語ですが、**型の名前**と`assignable`という単語だけ拾えば意味は取れます。翻訳ツールに貼るのも十分ありです。

詰まったときの手順を決めておきましょう。

1. 赤い波線にカーソルを乗せて、メッセージを読む
2. メッセージに出てくる**型の名前**を見る
3. それでもわからなければ、PlaygroundのURLをそのまま共有して聞く

1人で15分悩んだら聞く、を目安にしてください。

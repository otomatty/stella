## 結論

**JavaScriptは、値の種類を間違えても実行するまで気づけない**

- プログラム = コンピューターへの命令を並べたもの
- 値 = そのプログラムが扱うデータ(金額、名前、個数など)
- バグ = 意図したとおりに動かない箇所

<!-- ノート: 結論を先に言い切る。プログラム・値・バグという3つの言葉をここで定義する。JavaScriptはWebページを動かすために作られた言語で、この研修の土台にあたる、と一言添える。 -->

---

## 最小のコード

```js
const price = "300"; // 数値のつもりが、文字列だった
const total = price + 50;

console.log(total); // => "30050"
```

- エラーは出ない。**画面を見るまで気づけない**

<!-- ノート: 期待は350、実際は"30050"。フォームの入力値は文字列で届くので、この取り違えは現場で本当に起きる。エラーが出ないことが最大の問題だと強調する。詳しい仕組みはModule 1で扱う。 -->

# 1-6-2
# null

TypeScript入門 — Module 1 / レッスン1-6

<!-- ノート: 「値がない」を表す値の2つめです。undefinedとの違いが、このトピックの核心です。 -->

---

## なぜ必要か

- 「まだ入力されていない」と「無いことが確定している」は意味が違う
  - 例: ミドルネームは、未入力ではなく「無い」ことがある
- コードを読む人に、その違いを伝えたい

<!-- ノート: つかみ。データベースの世界でも同じ議論がある。意味の違いを値で表現できる、というのがnullの存在理由。 -->

---

## 結論

**nullは「意図的に空である」ことを表す値。自然発生しない**

- 誰かが書いたときだけ現れる

<!-- ノート: 結論を先に言い切る。undefinedは勝手に生まれる、nullは誰かがわざと入れた空。「自然発生するかどうか」が最大の違いだと押さえる。 -->

---

## 最小のコード

```ts
const middleName: null = null;
console.log(middleName); // => null
```

- 型名も値も、同じ`null`と書く

<!-- ノート: undefinedと同じく、型名と値名が一致している珍しい型。ただしnullだけの型注釈を実務で書くことはまずなく、後のトピックで学ぶユニオン型と組み合わせて使うと補足する。 -->

## なぜ必要か

- 「田中さんの注文金額は300円です」のような文を組み立てたい
- 変数を混ぜるたびに文字列をつなぎ合わせるのは、読みにくく壊れやすい

<!-- ノート: つかみ。通知メッセージ、ログ、画面表示。文字列の組み立ては実務で毎日発生する。素朴なやり方の不便さを一度想像してもらってから解決策を出す。 -->

---

## 結論

**バッククォートで囲むと、文字列の中に変数を埋め込める**

- 埋め込みの書き方は `${変数名}`
- この書き方をテンプレートリテラルと呼ぶ

<!-- ノート: 結論を先に言い切る。バッククォートの打ち方(日本語キーボードではShift+@)を実際に案内する。ここでつまずく受講者が毎回いるので、必ず口頭で補足する。 -->

---

## 最小のコード

```ts
const userName = "田中";
const price = 300;
const message = `${userName}さんの注文金額は${price}円です`;
console.log(message);
// => "田中さんの注文金額は300円です"
```

<!-- ノート: 変数の値がそのまま文中にはめ込まれることを、指しながら確認する。ドルマークと波かっこがセットである点を強調する。 -->

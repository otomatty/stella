## なぜ必要か

- プログラムは「値を保存して、加工する」ことの繰り返し
- 保存しておく場所がなければ、計算した結果を次の行で使えない

## 結論

**変数は、値に名前を付けて後から呼び出す仕組み**

- 名前を付ける操作 = 宣言
- 名前に値を入れる操作 = 代入
- 名前で値を取り出す操作 = 参照

<!-- ノート: 結論を先に言い切る。宣言・代入・参照という3つの用語をここで定義する。難しく聞こえるが、やっていることは「箱に名札を貼る、中身を入れる、中身を見る」の3つだけだと言い添える。 -->

---

## 最小のコード

```ts
let userName = "田中";
console.log(userName); // => "田中"
```

- 1行目: `userName`という名前を用意し、値を入れた
- 2行目: 名前を書くだけで値を取り出せる

<!-- ノート: コードを1行ずつ指しながら説明する。console.logはModule 0で使った「値を画面に表示する命令」だと復習する。ここではletの意味には触れない。次のトピックの主役なので温存する。 -->

## なぜ必要か

- 実際のコードを見ると、型注釈が書かれていない変数のほうが多い
- 「書き忘れ」なのか「書かなくてよい」のか、区別がつかないと不安になる

<!-- ノート: つかみ。他人のコードを読むときに必ずぶつかる疑問。ここで答えを持っておくと、以降のレッスンのコード例も落ち着いて読める。 -->

---

## 結論

**型注釈を書かなくても、初期値から型は自動で決まる**

- 初期値 = 宣言と同時に入れる、最初の値
- この仕組みを型推論と呼ぶ

<!-- ノート: 結論を先に言い切る。初期値と型推論という2つの用語をここで定義する。推論は「すいろん」。コンパイラーが値を見て型を言い当ててくれる、という素朴なイメージでよい。 -->

---

## 最小のコード

```ts
let price = 300; // 型注釈なし → number型と推論される
price = "無料";
// エラー: Type 'string' is not assignable to type 'number'.
```

- 型注釈があるときと、まったく同じエラーが出る

<!-- ノート: 型注釈を書いた場合と結果が同じであることが最大のポイント。Playgroundで変数にマウスカーソルを乗せると、推論された型が表示されることを実演する。 -->

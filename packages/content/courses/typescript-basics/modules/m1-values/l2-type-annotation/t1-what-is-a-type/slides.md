# 型とは何か

TypeScript入門研修 — Module 1 / レッスン1-2

<!-- ノート: レッスン1-1では変数の作り方を学びました。ここからは、その変数に「何を入れてよいか」を決める仕組みに入ります。TypeScriptという名前の由来そのものです。 -->

---

## なぜ必要か

- 金額を入れるつもりの変数に、文字列が入ってしまうことがある
- 実務あるある: 集計したら金額が`"1001"`のような文字列になっていた

<!-- ノート: つかみ。フォームの入力値は文字列で届くので、数値のつもりが文字列だった、という事故は現場で本当に起きる。この事故を防ぐ仕組みが「型」だと位置づける。 -->

---

## 結論

**型とは、その変数に入れてよい値の種類のこと**

- `number` — 数値
- `string` — 文字列
- `boolean` — 真偽値(はい/いいえ)

<!-- ノート: 結論を先に言い切る。型は7種類あるが、まずはこの3つの名前だけ覚えれば十分。それぞれの詳しい性質はレッスン1-3と1-4で掘り下げると予告する。ここでは名前を借りているだけ。 -->

---

## 最小のコード

```ts
const price = 300; // 数値 → number型
const productName = "コーヒー"; // 文字列 → string型
const isOnSale = true; // 真偽値 → boolean型
```

- 型名はすべて小文字で書く

<!-- ノート: 値を見れば型がわかる、という感覚をここで作る。大文字始まりのNumberやStringは別物なので使わない、とルールとして伝えておく(補完で誤選択しがち)。 -->

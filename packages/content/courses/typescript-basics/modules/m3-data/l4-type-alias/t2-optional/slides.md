# 3-4-2
# オプショナルプロパティ

TypeScript入門 — Module 3 / レッスン3-4

<!-- ノート: 型に名前が付きました。次は、実務のデータでほぼ必ず出てくる「任意項目」の書き方です。 -->

---

## なぜ必要か

- 会員登録フォームには任意入力の項目がある(電話番号、備考など)
- 必須として書くと、任意項目のないデータが作れなくなる

<!-- ノート: つかみ。3-3-4で見たとおり、必須プロパティが欠けているとエラーになる。しかし現実には「なくてよい項目」がある。それを型で表現する方法。 -->

---

## 結論

**プロパティ名のうしろに`?`を付けると、あってもなくてもよくなる**

- 省略できるプロパティをオプショナルプロパティと呼ぶ

<!-- ノート: 結論を先に言い切る。クエスチョンマークを1つ足すだけ。型注釈のコロンの手前に置く点に注意する(name?: string の順)。 -->

---

## 最小のコード

```ts
type User = {
  name: string;
  phone?: string; // 省略できる
};

const a: User = { name: "田中", phone: "090-0000-0000" }; // OK
const b: User = { name: "佐藤" }; // OK
```

<!-- ノート: 両方とも通ることを確認する。phoneを書かなくても、書いても問題ない。1-6-5で書いた string | undefined と近いが、こちらは「プロパティごと省略できる」点が違うと補足する。 -->

---

## 使うときは絞り込みが要る

```ts
const user: User = { name: "佐藤" };

const phone: string = user.phone;
// エラー: Type 'string | undefined' is not
// assignable to type 'string'.
```

<!-- ノート: 対比枠。省略できるということは、読み出したときundefinedかもしれないということ。2-3-2で学んだifによる絞り込みや、2-3-3の ?? がそのまま使える。型が正直に「ないかもしれない」と言ってくれている。 -->

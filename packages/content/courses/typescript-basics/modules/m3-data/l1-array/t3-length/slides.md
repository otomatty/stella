# 3-1-3
# lengthで要素数を数える

TypeScript入門研修 — Module 3 / レッスン3-1

<!-- ノート: 取り出し方はわかりました。では、いくつ入っているのかを知る方法です。 -->

---

## なぜ必要か

- 配列の中身は、動かしてみるまで何個か分からないことが多い
- 「1件もなければ案内を出す」といった判定にも要素数が要る

<!-- ノート: つかみ。検索結果やAPIの応答は件数が事前にわからない。だから数える手段が要る。2-2-2の条件分岐と組み合わせる場面が実務では多い。 -->

---

## 結論

**配列の要素数は`length`でわかる。最後のインデックスは`length - 1`**

<!-- ノート: 結論を先に言い切る。lengthは「長さ」の意味。個数そのものなので1から数える一方、インデックスは0から数える。この1つのズレがバグの温床になるので、ここで対応関係を固める。 -->

---

## 最小のコード

```ts
const items = ["コーヒー", "紅茶", "緑茶"];

console.log(items.length); // => 3
console.log(items[items.length - 1]); // => "緑茶"
```

- 個数は`3`、最後のインデックスは`2`

<!-- ノート: ドットに続けてlengthと書く。かっこは付けない点に注意(付ける書き方は関数で、Module 4で扱う)。2行目は「最後の要素」を取り出す定番の書き方なので、そのまま覚えてよい。 -->

---

## 条件分岐と組み合わせる

```ts
const results: string[] = [];

if (results.length === 0) {
  console.log("該当する商品はありません");
}
// => "該当する商品はありません"
```

<!-- ノート: 対比枠。空の配列は角かっこだけで書ける。件数0の判定は実務で頻出。2-3-1で学んだfalsyを使わず、lengthを明示的に比較するほうが意図が伝わると添える。 -->

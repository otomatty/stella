## なぜ必要か

- まとめただけでは使えない。1つずつ取り出せて初めて役に立つ
- 番号の数え方を間違えると、隣の値を取ってしまう

<!-- ノート: つかみ。「1つずれる」バグは実務でも定番。原因はほぼ番号の数え方なので、ここで正しく入れておく。 -->

---

## 結論

**要素は角かっこと番号で取り出す。番号は0から始まる**

- インデックス = 要素の位置を表す番号
- **1番目の要素はインデックス`0`**

<!-- ノート: 結論を先に言い切る。インデックスという言葉を定義する。0から始まる理由は歴史的なもので、深追いは不要。「1番目は0番」と口に出して覚えてもらう。 -->

---

## 最小のコード

```ts
const items = ["コーヒー", "紅茶", "緑茶"];

console.log(items[0]); // => "コーヒー"
console.log(items[1]); // => "紅茶"
console.log(items[2]); // => "緑茶"
```

<!-- ノート: 3行を順に指しながら、番号と中身の対応を確認する。角かっこは3-1-1の配列リテラルでも使ったが、こちらは取り出しの角かっこ。位置が違う(変数名の直後)と区別する。 -->

# 3-2-4
# 繰り返しで集計する

TypeScript入門 — Module 3 / レッスン3-2

<!-- ノート: レッスン3-2の最後です。繰り返しの応用として、実務でいちばん多い使い方を1つ押さえます。 -->

---

## なぜ必要か

- 合計金額、件数、平均。業務システムは集計だらけ
- ここでレッスン2-1のスコープの知識が効いてくる

<!-- ノート: つかみ。カートの合計金額はどの画面にもある。単純に見えて、変数の置き場所を間違えると動かない。だからスコープの理解が要る。 -->

---

## 結論

**集計は、ループの外に置いた`let`の変数に足し込んでいく**

- 置き場所が外でなければならない理由 → ブロックの中だと毎回消えるため

<!-- ノート: 結論を先に言い切る。2-1-1で学んだ「ブロックの中の変数は外から見えない」がここで効く。中で宣言すると1回ごとに作り直されるので、集計にならない。 -->

---

## 最小のコード

```ts
const prices = [480, 500, 450];

let total = 0; // ループの外で用意する

for (const price of prices) {
  total = total + price;
}

console.log(total); // => 1430
```

<!-- ノート: totalは再代入するのでlet。1-1-3の「再代入が必要なときだけlet」に当てはまる数少ない場面。total = total + price は「いまの合計に足す」と読み下す。 -->

---

## よくある間違い: 中で宣言してしまう

```ts
const prices = [480, 500, 450];

for (const price of prices) {
  let total = 0; // 毎回0に戻る
  total = total + price;
}

console.log(total);
// エラー: Cannot find name 'total'.
```

<!-- ノート: 対比枠。中で宣言すると毎回リセットされ、しかもループの外からは見えない。エラーメッセージは2-1-1で見たものと同じ。スコープの知識が実際のバグ解決に使える瞬間。 -->

# レッスン5-1 総合演習

## このレッスンの目標

- [ ] 1問5分を上限に、飛ばして戻る時間配分を実行できる
- [ ] 講座全範囲の問題を、トレース表を書いて解き切れる
- [ ] 直前チェックリストで知識の抜けを自分で点検できる

## 5-1-1 本番の時間配分

> **科目Bは1問5分、詰まったら飛ばして戻るのが時間配分の基本**

この講座の締めくくりです。ここまでに、擬似言語の読み方から始めて、探索・整列・データ構造・再帰・木構造、そしてセキュリティのケース問題まで学びました。最後に学ぶのは、その力を本番で出し切るための **時間配分**(制限時間を問題にどう割り振るかの計画)です。

科目Bは100分で20問です。単純に割ると1問5分ですが、5分は「上限の目安」として使います。手順は次の通りです。

1. 1周目は1問4分前後のペースで、全問に触れます
2. 1分読んでもトレースの書き出しが始められない問題は、印を付けて次へ進みます
3. 1周目を約80分で終え、残り時間で印の問題に戻ります
4. 最後に、自信のない答えから順に見直します

飛ばすのは諦めではありません。後ろに解ける問題が残っているのに、1問に10分粘るのがいちばんの失敗です。全問に触れてから戻るほうが、合計の得点は高くなります。

トレースは必ず手を動かして表に書きます。頭の中だけのトレースは、繰返しが2周を超えたあたりで必ずずれます。飛ばすときも途中のトレース表は消さずに残してください。戻ったときに続きから再開できます。

## 直前チェックリスト

試験の直前に、1行ずつ「説明できるか」を確かめてください。

擬似言語の記法:

- [ ] `←` は代入。「x ← x + 1」は x を1増やす
- [ ] 変数は「整数型: x」のように型を付けて宣言する
- [ ] if〜elseif〜else は、条件式が真のブロックだけが実行される
- [ ] while は条件が真の間、for は指定した範囲を順に繰り返す
- [ ] 配列の添字は1から始まり、「配列名[添字]」で要素を参照する
- [ ] 関数は引数を受け取り、return した瞬間に戻り値を返して終わる

定番アルゴリズム:

- [ ] 線形探索は先頭から順に比較し、見つからなければ -1 を返す
- [ ] 二分探索は整列済みが前提で、範囲を半分ずつに絞る
- [ ] バブルソートは隣どうしを比較し、逆順なら交換する
- [ ] 選択ソートは未整列部分の最小値を先頭と交換する
- [ ] 挿入ソートは要素を取り出し、整列済み部分に差し込む
- [ ] スタックは後入れ先出し、キューは先入れ先出し
- [ ] 再帰は基底条件に達してから、値が呼び出し元へ順に戻る

セキュリティの読み方:

- [ ] まず状況説明から、資産と脅威・脆弱性を読み取る
- [ ] アクセス制御は、認証した利用者に最小権限だけを与える
- [ ] 対策は、機密性・完全性・可用性のどれを守るかで選ぶ

答えに詰まった行があれば、該当レッスンの doc.md に戻って読み直してください。

## もっと知りたい人へ

- 時間配分は練習しないと身に付きません。演習のクイズを、実際にタイマーで時間を計って解いてみてください
- トレース表は、列の並びを自分なりに定型化しておくと本番で速く書けます。変数を左、配列を右に置くなど、型を決めておきましょう

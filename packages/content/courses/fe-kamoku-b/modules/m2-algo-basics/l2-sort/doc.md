# レッスン2-2 整列アルゴリズム

## このレッスンの目標

- [ ] バブルソートの1パスをトレースし、交換の回数を数えられる
- [ ] 選択ソートの「探す」と「交換する」の2段構えを説明できる
- [ ] 挿入ソートで整列済み部分が左から育つようすを説明できる

## 2-2-1 隣どうしの交換で並べ替える

> **バブルソートは、隣どうしを比較して逆順なら交換を繰り返して整列する**

データを大小の順に並べ替えることを **整列** と呼びます。二分探索の前提だった「整列済みの配列」は、整列アルゴリズムが作り出すものです。

いちばん素朴な整列がバブルソートです。隣どうしの2要素を比較し、左が大きければ入れ替えます。この入れ替えを **交換** と呼びます。

```text
整数型の配列: array ← {5, 3, 8, 1}
整数型: i, j, temp
for (i を 1 から 3 まで 1 ずつ増やす)
  for (j を 1 から 4 - i まで 1 ずつ増やす)
    if (array[j] > array[j + 1])
      temp ← array[j]
      array[j] ← array[j + 1]
      array[j + 1] ← temp
    endif
  endfor
endfor
```

交換は作業用の変数 `temp` を使った3行で書きます。片方を `temp` に退避してから入れ替えないと、値が消えてしまいます。この3行は穴埋めの定番です。

内側の繰返し1往復を「パス」と呼びます。`{5, 3, 8, 1}` の1パス目(`i = 1`)をトレースしてみましょう。

| 比較 | 逆順か | 交換後の配列 |
| --- | --- | --- |
| array[1]=5 と array[2]=3 | 逆順 | {3, 5, 8, 1} |
| array[2]=5 と array[3]=8 | 正順 | {3, 5, 8, 1} |
| array[3]=8 と array[4]=1 | 逆順 | {3, 5, 1, 8} |

大きい値は交換のたびに右へ運ばれます。そのため1パス目の終わりには、最大値の 8 が必ず末尾に着きます。末尾が確定するので、次のパスは1つ短い範囲で済みます。内側の上限が `4 - i` と縮んでいくのはこのためです。

## 2-2-2 最小値を選んで並べ替える

> **選択ソートは、未整列部分から最小値を選んで先頭と交換していく**

バブルソートの弱点は交換回数の多さです。選択ソートは、動かす前にまず探すことで交換を減らします。ある範囲でいちばん小さい値を **最小値** と呼びます。

```text
整数型の配列: array ← {5, 3, 8, 1}
整数型: i, j, min, temp
for (i を 1 から 3 まで 1 ずつ増やす)
  min ← i
  for (j を i + 1 から 4 まで 1 ずつ増やす)
    if (array[j] < array[min])
      min ← j
    endif
  endfor
  temp ← array[i]
  array[i] ← array[min]
  array[min] ← temp
endfor
```

各パスは2段構えです。

1. **探す** — 未整列部分を走査し、最小値の添字を `min` に覚える
2. **交換する** — 未整列部分の先頭 `array[i]` と `array[min]` を1回だけ交換する

`min` に入るのは値そのものではなく添字である点に注意してください。トレースすると次のようになります。

| i | 未整列部分 | 最小値 | パス後の配列 |
| --- | --- | --- | --- |
| 1 | {5, 3, 8, 1} | 1 | {1, 3, 8, 5} |
| 2 | {3, 8, 5} | 3 | {1, 3, 8, 5} |
| 3 | {8, 5} | 5 | {1, 3, 5, 8} |

走査の間、配列は一切動きません。交換は各パスの最後の1回だけです。`{5, 3, 8, 1}` の1パス目で比べると、バブルソートの交換は2回、選択ソートは1回でした。比較の回数は変わらず、交換の回数だけが減ります。

## 2-2-3 取り出して差し込む

> **挿入ソートは、要素を1つ取り出して整列済み部分の正しい位置に差し込む**

手持ちのトランプを並べるときを思い出してください。引いた1枚を、並べ終わった手札の正しい位置へ差し込んでいくはずです。挿入ソートはこの手つきをそのまま配列にした整列です。

配列の左側を整列済み部分(手札)とみなします。最初は先頭の1要素だけが整列済みです。右から要素を1つずつ取り出し、整列済み部分の正しい位置に差し込みます。

```text
整数型の配列: array ← {5, 3, 8, 1}
整数型: i, j, x
for (i を 2 から 4 まで 1 ずつ増やす)
  x ← array[i]
  j ← i - 1
  while (j ≧ 1 and array[j] > x)
    array[j + 1] ← array[j]
    j ← j - 1
  endwhile
  array[j + 1] ← x
endfor
```

条件式の `and` は「両方が真のあいだ」という意味です。取り出した値 `x` より大きい要素を右へ1つずつずらし、空いた場所に `x` を置きます。

| i | 取り出す値 | 整列済み部分 | 未処理 |
| --- | --- | --- | --- |
| 2 | 3 | {3, 5} | {8, 1} |
| 3 | 8 | {3, 5, 8} | {1} |
| 4 | 1 | {1, 3, 5, 8} | — |

差し込むたびに、整列済み部分が左から1つずつ育ちます。8 の番では `array[j] > x` が最初から偽なので、何もずらしません。すでにほとんど整列済みの配列に対して、挿入ソートが速いのはこのためです。

## もっと知りたい人へ

- 3つの整列法は、いずれも計算量が O(n²) です。要素数が2倍になると手間はおよそ4倍になります
- 試験では「1パス後の配列の状態」と「交換の回数」が定番の問われ方です。演習でトレースを繰り返してください
- 実務のプログラムでは、言語に用意された整列の関数を使うのが普通です。中の仕組みを読める力が、科目Bで試されます

# レッスン2-2 演習 — 整列アルゴリズム

対象トピック: 2-2-1 〜 2-2-3

## ハンズオン

紙とペンを用意してください。同じ配列 `{5, 3, 8, 1}` を、3つの整列法で最後まで紙上トレースします。

1. **バブルソート** — パスごとに、比較した組と交換の有無、パス後の配列を書く
2. **選択ソート** — パスごとに、見つけた最小値と、交換後の配列を書く
3. **挿入ソート** — 取り出した値と、差し込み後の整列済み部分を書く

書き終えたら、次の2点を見比べてください。

- 3つとも最終結果は `{1, 3, 5, 8}` になったか
- 全体の交換(または差し込み)の回数は、それぞれ何回だったか

途中の配列の状態を書き出す手が、そのまま本試験の解き方になります。

## 演習問題

### 問1(基本)

配列 `{4, 2, 5, 1}` をバブルソートで整列します。1パス目が終わった直後の配列を答えてください。

### 問2(基本)

配列 `{6, 3, 5, 2}` を選択ソートで整列します。1パス目と2パス目のそれぞれについて、見つけた最小値とパス後の配列を答えてください。

### 問3(応用)

次のプログラムは、挿入ソートで配列を昇順に整列します。`a` に入る正しい記述を答えてください。

```text
整数型の配列: array ← {5, 3, 8, 1}
整数型: i, j, x
for (i を 2 から 4 まで 1 ずつ増やす)
  x ← array[i]
  j ← i - 1
  while (j ≧ 1 and array[j] > x)
    [   a   ]
    j ← j - 1
  endwhile
  array[j + 1] ← x
endfor
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`{2, 4, 1, 5}`

隣どうしを左から順に比較します。

| 比較 | 交換 | 配列 |
| --- | --- | --- |
| 4 と 2 | する | {2, 4, 5, 1} |
| 4 と 5 | しない | {2, 4, 5, 1} |
| 5 と 1 | する | {2, 4, 1, 5} |

1パス目の終わりに、最大値の 5 が末尾に来ています。

</details>

<details>
<summary>問2の解答例</summary>

- 1パス目: 最小値は 2。先頭の 6 と交換して `{2, 3, 5, 6}`
- 2パス目: 未整列部分 `{3, 5, 6}` の最小値は 3。先頭の 3 自身と交換するので、配列は `{2, 3, 5, 6}` のまま

最小値がすでに先頭にある場合、交換しても配列は変化しません。トレースで慌てないよう覚えておいてください。

</details>

<details>
<summary>問3の解答例</summary>

`array[j + 1] ← array[j]`

差し込む場所を空けるため、`x` より大きい要素を右へ1つずらす行です。`while` を抜けたあと、空いた `array[j + 1]` に `x` を置きます。逆向きの `array[j] ← array[j + 1]` にすると、値が消えてしまいます。

</details>

## 確認クイズ

### Q1. 配列 {5, 3, 8, 1} をバブルソートで整列するとき、1パス目が終わった直後の配列はどれですか。

- A. {1, 3, 5, 8}
- B. {3, 5, 1, 8}
- C. {3, 5, 8, 1}
- D. {5, 3, 1, 8}

<details>
<summary>答え</summary>

**B** — 5と3を交換、5と8はそのまま、8と1を交換で {3, 5, 1, 8} です。1パス目で最大値の8が末尾に来ます。

</details>

### Q2. 配列 {5, 3, 8, 1} を選択ソートで整列するとき、1パス目が終わった直後の配列はどれですか。

- A. {1, 3, 8, 5}
- B. {3, 5, 8, 1}
- C. {1, 3, 5, 8}
- D. {1, 5, 3, 8}

<details>
<summary>答え</summary>

**A** — 走査で最小値の1を見つけ、先頭の5と1回だけ交換します。5は1のあった場所へ移るので {1, 3, 8, 5} です。

</details>

### Q3. 配列 {5, 3, 8, 1} を挿入ソートで整列するとき、最初の差し込みが終わった直後の配列はどれですか。

- A. {5, 3, 8, 1}
- B. {3, 5, 1, 8}
- C. {1, 3, 5, 8}
- D. {3, 5, 8, 1}

<details>
<summary>答え</summary>

**D** — 2番目の3を取り出し、整列済み部分 {5} の前に差し込んで {3, 5, 8, 1} です。8と1はまだ手つかずのままです。

</details>

### Q4. 配列 {4, 3, 2, 1} をバブルソートで最後まで整列するとき、交換は全部で何回起きますか。

- A. 3回
- B. 4回
- C. 6回
- D. 12回

<details>
<summary>答え</summary>

**C** — 1パス目で3回、2パス目で2回、3パス目で1回の計6回です。完全に逆順の並びは、すべての比較で交換が起きます。

</details>

### Q5. 要素数4の配列を選択ソートで最後まで整列するとき、交換は最大で何回起きますか。

- A. 1回
- B. 3回
- C. 6回
- D. 16回

<details>
<summary>答え</summary>

**B** — 選択ソートの交換は各パスの最後に1回だけです。要素数4ならパスは3回なので、交換は最大3回です。

</details>

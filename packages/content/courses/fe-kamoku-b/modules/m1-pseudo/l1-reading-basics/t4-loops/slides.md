# 1-1-4
# 繰返し処理を読む

基本情報 科目B対策 — Module 1 / レッスン1-1

<!-- ノート: 分岐の次は、同じ行を何度も実行する記法です。科目Bの読解の中心になります。 -->

---

## なぜ必要か

- 5行のプログラムでも、実行される回数は5回とは限らない
- 何回実行されたかを数え違えると、変数の値も答えもずれる

<!-- ノート: つかみ。科目Bの問題の大半は「同じ処理を何度も行った後の値」を聞いてきます。回数の数え違いが一番多いミスだ、と伝えるだけにして、記法はまだ見せません。 -->

---

## 結論

**whileは条件が真の間、forは指定した範囲を順に繰り返す**

- 同じブロックを何度も実行することを **繰返し** と呼ぶ
- while文 = 続けるかを条件式で決める / for文 = 範囲を決めて回す

<!-- ノート: 結論を言い切ります。2つの記法はどちらも繰返しで、終わり方の決め方が違うだけ、と整理してください。 -->

---

## 最小のコード

```text
x ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  x ← x + i
endfor
```

- i は 1、2、3 と変わり、x は 0 → 1 → 3 → 6 と増える

<!-- ノート: for文の最小形です。i のように範囲を動く変数の値を毎回メモしながら読むのがコツです。endfor まで来たら for の行に戻ります。 -->

---

## while文との対比

```text
x ← 0
while (x < 3)
  x ← x + 1
endwhile
```

- 条件式 x < 3 が真の間だけ繰り返し、成り立たなくなったら終わる

<!-- ノート: 対比枠。この例は x が 0、1、2 のとき条件式が真なので3回実行され、x が 3 になった時点で終わります。「真の間」を確認するのは毎回、ブロックの実行前です。 -->

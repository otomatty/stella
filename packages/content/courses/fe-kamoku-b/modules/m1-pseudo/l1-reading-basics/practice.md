# レッスン1-1 演習 — 擬似言語の基本

対象トピック: 1-1-1 〜 1-1-5

## ハンズオン

このレッスンの演習は、紙とペンで行います。本試験も画面上でプログラムを動かせないので、手で読む練習がそのまま本番の練習になります。

次のプログラムを紙に書き写してください。

```text
整数型: x ← 2
整数型: y ← 0
if (x > 1)
  y ← x + 3
endif
```

書き写せたら、次の手順で読んでみましょう。

1. 1行ずつ声に出して読み、行の右に「何をする行か」をメモする
2. 変数の値が変わるたびに、x と y の値を余白に書く
3. 最後の行まで読んだら、x と y の値を答える(x は 2、y は 5)

読めたら、1行目を「整数型: x ← 1」に変えて、もう一度読んでください。条件式が偽になるので、y は 0 のまま変わりません。

## 演習問題

### 問1(基本)

次のプログラムを実行した後の、a と b の値を答えてください。

```text
整数型: a ← 3
整数型: b ← 5
a ← a + b
b ← a - b
```

### 問2(基本)

次のプログラムを実行した後の、y の値を答えてください。

```text
整数型: x ← 7
整数型: y ← 0
if (x > 10)
  y ← 1
elseif (x > 5)
  y ← 2
else
  y ← 3
endif
```

### 問3(応用)

次のプログラムを実行した後の、x の値を答えてください。

```text
○total(整数型: n)
  整数型: sum ← 0
  for (i を 1 から n まで 1 ずつ増やす)
    sum ← sum + i
  endfor
  return sum

x ← total(4)
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

a は 8、b は 3 です。

3行目で、右の a + b(3 + 5)を先に計算し、結果の 8 を a に入れます。4行目の a はすでに 8 なので、b には 8 - 5 の 3 が入ります。「右を計算してから左へ」を1行ずつ守るのがコツです。

</details>

<details>
<summary>問2の解答例</summary>

y は 2 です。

条件式は上から順に判定します。x > 10 は偽なので次へ進み、x > 5 は真です。真になったブロックの y ← 2 だけが実行され、else 側は飛ばされます。

</details>

<details>
<summary>問3の解答例</summary>

x は 10 です。

呼び出し total(4) で、引数 n に 4 が入ります。for文で i が 1、2、3、4 と変わり、sum は 0 → 1 → 3 → 6 → 10 と増えます。return で戻り値 10 が呼び出し元へ返り、x に代入されます。

</details>

## 確認クイズ

### Q1. 科目Bの問題形式の説明として正しいものはどれですか。

- A. 用語の意味を記述式で答える
- B. パソコン上でプログラムを作成して提出する
- C. 擬似言語のプログラムを読み取って答えを選ぶ
- D. 図を作成して提出する

<details>
<summary>答え</summary>

**C** — 科目Bは20問の多肢選択式で、擬似言語のプログラムを読む問題が中心です。書く試験ではありません。

</details>

### Q2. x ← 3 の後に x ← x + 4 を実行したとき、x の値はどれですか。

- A. 3
- B. 4
- C. 7
- D. 34

<details>
<summary>答え</summary>

**C** — ← は代入です。右の x + 4(3 + 4)を先に計算し、結果の 7 を x に入れ直します。

</details>

### Q3. x が 8 のとき、if (x > 10) で y ← 1、else で y ← 2 とすると、y の値はどれですか。

- A. 1
- B. 2
- C. 8
- D. 決まらない

<details>
<summary>答え</summary>

**B** — 条件式 x > 10 は偽なので、else 側のブロックだけが実行されます。真のブロック1つだけが動く、が if文の読み方です。

</details>

### Q4. x ← 0 の後、while (x < 4) の中で x ← x + 2 を繰り返すと、繰返しは何回実行されますか。

- A. 1回
- B. 2回
- C. 4回
- D. 無限に続く

<details>
<summary>答え</summary>

**B** — x が 0 と 2 のとき条件式は真なので2回実行されます。x が 4 になると x < 4 は偽になり、繰返しは終わります。

</details>

### Q5. ○double(整数型: n) の中身が return n + n のとき、x ← double(3) の後の x の値はどれですか。

- A. 3
- B. 6
- C. 9
- D. 33

<details>
<summary>答え</summary>

**B** — 引数 n に 3 が入り、return で戻り値 n + n(3 + 3 = 6)が呼び出し元へ返って x に代入されます。

</details>

# レッスン1-2 配列とトレース

## このレッスンの目標

- [ ] 「配列名[添字]」で要素を参照でき、添字が1始まりであると説明できる
- [ ] 短いプログラムのトレース表を自分で書ける
- [ ] forで配列を走査するプログラムの実行結果を答えられる

## 1-2-1 配列は番号で要素を取り出す

> **配列の要素は「配列名[添字]」で参照し、擬似言語の添字は1から始まる**

30人分の点数を扱うとき、変数を30個宣言するのは現実的ではありません。値を並べてまとめる入れ物が **配列** です。配列の中の1つ1つの値を **要素**、要素の位置を示す番号を **添字** と呼びます。

```text
整数型の配列: data ← {10, 20, 30}
整数型: x
x ← data[2]
```

宣言は変数と同じ形で、型に「の配列」が付きます。中身は波かっこで並べます。`data[2]` は2番目の要素なので、`x` は 20 になります。

注意すべきは添字の始まりです。擬似言語の添字は **1から** 始まります。

- `data[1]` は先頭の 10、`data[3]` は末尾の 30 です
- `data[0]` という要素は存在しません。0始まりと思い込むと読み違えます

## 1-2-2 トレース表で実行を追う

> **変数の値の変化を1行ずつ表に書き出すのがトレースの基本**

繰返しのあるプログラムを頭の中だけで追うと、途中で値を見失います。プログラムを紙の上で1歩ずつ実行することを **トレース**、各ステップでの変数の値を記録した表を **トレース表** と呼びます。

```text
整数型: x ← 1
while (x < 4)
  x ← x + 2
endwhile
```

トレース表は、行が実行ステップ、列が変数です。1行実行するごとに、表へ1行書き足します。

![プログラムの各行を実行するたびに、トレース表へ1行ずつ書き出す対応](t2-trace-table/assets/trace-table.svg)

条件の判定も書いておくと、繰返しの終わりを見失いません。

| ステップ | 実行した行 | x |
| --- | --- | --- |
| 1 | x ← 1 | 1 |
| 2 | x < 4 は真 | 1 |
| 3 | x ← x + 2 | 3 |
| 4 | x < 4 は真 | 3 |
| 5 | x ← x + 2 | 5 |
| 6 | x < 4 は偽 → 終了 | 5 |

最終的に `x` は 5 です。「たぶん4で止まる」と暗算で答えると間違えます。繰返しの回数ずれは定番のひっかけなので、表に書いて毎回確かめてください。

## 1-2-3 繰返しと配列を組み合わせて読む

> **forで添字を動かして配列を順に処理するのが科目Bの最頻出パターン**

試験のプログラムでは、配列と繰返しがほぼ必ずセットで出てきます。配列の要素を先頭から順にたどって処理することを **走査** と呼びます。forの変数がそのまま添字になるのが特徴です。

合計を求める走査が最も基本の形です。

```text
整数型の配列: data ← {10, 20, 30}
整数型: sum ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  sum ← sum + data[i]
endfor
```

トレース表に添字の列を作ると、要素と結果の対応が一目でわかります。

| i | data[i] | sum |
| --- | --- | --- |
| — | — | 0 |
| 1 | 10 | 10 |
| 2 | 20 | 30 |
| 3 | 30 | 60 |

最大値を探すのも同じ走査です。先頭の要素を仮の最大値にして、より大きい要素が見つかったら入れ替えます。

```text
整数型の配列: data ← {4, 9, 6}
整数型: max ← data[1]
for (i を 2 から 3 まで 1 ずつ増やす)
  if (data[i] > max)
    max ← data[i]
  endif
endfor
```

`i = 2` のとき 9 > 4 が真なので `max` は 9 になり、`i = 3` のとき 6 > 9 が偽なのでそのまま。最終的に `max` は 9 です。合計も最大値も「forで添字を動かし、集める変数を更新する」という同じ型で読めます。

## もっと知りたい人へ

- 本試験のプログラムも、このレッスンの「走査 + トレース」の延長で読めるものが大半です
- トレース表の列は「forの変数・参照した要素・集める変数」の3点セットから始めると迷いません
- 次のモジュールで扱う探索や整列も、走査の型の応用です。この型を先に体に入れておきましょう

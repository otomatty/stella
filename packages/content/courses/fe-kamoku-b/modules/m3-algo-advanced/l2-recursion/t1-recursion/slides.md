# 3-2-1
# 再帰は自分自身を呼び出す

基本情報 科目B対策 — Module 3 / レッスン3-2

<!-- ノート: このレッスンでは「再帰」を学びます。科目Bの読解問題で必ず出会う、関数の少し変わった書き方です。 -->

---

## なぜ必要か

- 「n 個の場合の答えは、n − 1 個の場合の答えから作れる」処理があります
- for文で書くと長くなるこの形を、驚くほど短く書く方法があります

<!-- ノート: つかみ。大きい問題を1回り小さい同じ形の問題に任せる、という発想があると伝える。答えはまだ言わない。 -->

---

## 結論

**再帰は関数が自分自身を呼び出す書き方で、必ず止まる条件を持つ**

- 関数の中で、自分自身を引数を小さくして呼び出します
- 止まる条件を **基底条件** と呼びます

<!-- ノート: 再帰とは、関数が自分自身を呼び出す書き方のことです。無限に呼び続けないよう、これ以上呼ばずに値を返す条件が必ず要ります。それが基底条件です。 -->

---

## 最小のコード

```text
○fact(整数型: n)
  if (n が 1 以下)
    return 1
  endif
  return n × fact(n − 1)
```

<!-- ノート: n が 1 以下なら 1 を返す行が基底条件です。それ以外は n × fact(n − 1)、つまり自分自身を n − 1 で呼び出した戻り値を使います。 -->

---

## 基底条件が無いと止まらない

```text
○fact(整数型: n)
  return n × fact(n − 1)
```

- fact(3) → fact(2) → fact(1) → fact(0) → …
- 呼び出しが永遠に続き、プログラムは止まりません

<!-- ノート: 失敗例。if の2行を消しただけで、0 でも −1 でも呼び出しが続いてしまいます。再帰を読むときは、まず基底条件を探す癖をつけましょう。 -->

# 基本情報技術者 科目B対策 カリキュラム

基本情報技術者試験(FE)科目Bの対策講座です。科目Bは擬似言語で書かれたプログラムを読み取る問題が
20問中16問を占めるため、擬似言語の読み方 → トレース → 定番アルゴリズムの順で読める範囲を広げます。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)。クイズは本試験と同じ「読んで選ぶ」形式
- 問題はすべて自作。公式のサンプル問題・公開問題は難易度と出題形式の校正基準としてのみ使う(転載しない)
- 前提講座: **ITのきほん(`it-basics`)**。スキルツリーの入口講座で、コンピュータ・ファイル・Web の基本のことばをそろえてから受講します(`course.json` の `prerequisites` に対応)
- VS Code のコード演習は**本試験と同じ擬似言語**で解く(#133)。TypeScript への翻訳版ではない。
  `@falcon/code-runner` が擬似言語を JS に落として QuickJS で実行し、1 起点の配列と整数除算の切り捨ても
  本試験どおりに評価される。課題は `packages/shared/src/problems/_lang/fe-pseudo/`、
  対応構文は `packages/code-runner/src/fe-pseudo/SYNTAX.md`

## 全体計画

| モジュール | 内容 | 状態 |
| --- | --- | --- |
| **M1. 擬似言語の読み方** | 記法(宣言・代入・分岐・繰返し・関数)、配列、トレース | **実装済み(Phase 1)** + コード演習 4 問 |
| **M2. アルゴリズム基礎** | 探索(線形・二分)、計算量、整列(バブル・選択・挿入) | **実装済み(Phase 1)** + コード演習 3 問 |
| **M3. アルゴリズム応用** | スタック/キュー/リスト、再帰、木構造、文字列処理 | **実装済み(Phase 2 + 追補)** + コード演習 2 問 |
| **M4. 情報セキュリティ** | ケース問題の読み方・アクセス制御・対策の選び方 | **実装済み(Phase 3)** |
| **M5. 総合演習** | 全範囲の総合クイズ(10問)。出題範囲がレッスンに閉じない意図的な例外 | **実装済み(Phase 3)** |

## VS Code のコード演習(擬似言語)

Web のレッスンで記法とトレースを学んだあと、VS Code 拡張で**擬似言語のまま**コードを書いて採点する。

| レッスンキー | 課題 | 学ぶこと |
| --- | --- | --- |
| 1-1 | 大きい方を返す / 1 から n までの合計 | 宣言・代入・if・while |
| 1-2 | 配列の合計 / 最大値の位置 | 1 起点の添字、`〜の要素数`、位置を返す |
| 2-1 | 線形探索 / 二分探索 | 見つからないとき -1、`÷` の切り捨て |
| 2-2 | バブルソート | 配列をその場で書き換える、値の交換 |
| 3-1 | スタックで括弧の対応を調べる | 配列 + 頂上の位置でスタックを表す |
| 3-2 | 階乗を再帰で求める | 再帰と停止条件 |

配線は `course.json` の `exercises`(キーはレッスンキー)。課題本体は `@falcon/shared` が正本で、
模範解答が実際に全テストを通ることは `packages/code-runner/src/fe-pseudo/solutions.test.ts` が CI で検証する。

## M1. 擬似言語の読み方(実装済み: 2 レッスン / 8 トピック)

### レッスン1-1 擬似言語の基本

| ID | トピック | takeaway |
| --- | --- | --- |
| 1-1-1 | 科目Bは擬似言語を読む試験 | 科目Bの問題は、擬似言語で書かれたプログラムを読み取って答えを選ぶ形式 |
| 1-1-2 | 変数の宣言と代入 | 「整数型: x ← 1」のように、変数は型を付けて宣言し、← で代入する |
| 1-1-3 | if文で処理を分岐する | if〜elseif〜else〜endifで、条件式が真のブロックだけが実行される |
| 1-1-4 | 繰返し処理を読む | whileは条件が真の間、forは指定した範囲を順に繰り返す |
| 1-1-5 | 関数の定義と呼び出し | 関数は引数を受け取り、returnで戻り値を呼び出し元へ返す |

### レッスン1-2 配列とトレース

| ID | トピック | takeaway |
| --- | --- | --- |
| 1-2-1 | 配列は番号で要素を取り出す | 配列の要素は「配列名[添字]」で参照し、擬似言語の添字は1から始まる |

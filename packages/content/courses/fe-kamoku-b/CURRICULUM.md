# 基本情報技術者 科目B対策 カリキュラム

基本情報技術者試験(FE)科目Bの対策講座です。科目Bは擬似言語で書かれたプログラムを読み取る問題が
20問中16問を占めるため、擬似言語の読み方 → トレース → 定番アルゴリズムの順で読める範囲を広げます。

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)。クイズは本試験と同じ「読んで選ぶ」形式
- 問題はすべて自作。公式のサンプル問題・公開問題は難易度と出題形式の校正基準としてのみ使う(転載しない)
- VS Code のコード演習(主要アルゴリズムの TypeScript 翻訳版)は未着手。`course.json` の `exercises` への配線は Phase 2

## 全体計画

| モジュール | 内容 | 状態 |
| --- | --- | --- |
| **M1. 擬似言語の読み方** | 記法(宣言・代入・分岐・繰返し・関数)、配列、トレース | **実装済み(Phase 1)** |
| **M2. アルゴリズム基礎** | 探索(線形・二分)、計算量、整列(バブル・選択・挿入) | **実装済み(Phase 1)** |
| **M3. アルゴリズム応用** | スタック/キュー/リスト、再帰、木構造 (文字列処理は追補予定) | **実装済み(Phase 2)** |
| **M4. 情報セキュリティ** | ケース問題の読み方・アクセス制御・対策の選び方 | **実装済み(Phase 3)** |
| **M5. 総合演習** | 全範囲の総合クイズ(10問)。出題範囲がレッスンに閉じない意図的な例外 | **実装済み(Phase 3)** |

## M1. 擬似言語の読み方(実装済み: 2 レッスン / 8 トピック)

### レッスン1-1 擬似言語の基本

| ID | トピック | takeaway |
| --- | --- | --- |
| 1-1-1 | 科目Bは擬似言語を読む試験 | 科目Bの問題は、擬似言語で書かれたプログラムを読み取って答えを選ぶ形式 |
| 1-1-2 | 変数の宣言と代入 | 「整数型: x ← 1」のように、変数は型を付けて宣言し、← で代入する |
| 1-1-3 | if文で処理を分岐する | if〜elseif〜else〜endifで、条件式が真のブロックだけが実行される |
| 1-1-4 | 繰返し処理を読む | whileは条件が真の間、forは指定した範囲を順に繰り返す |
| 1-1-5 | 関数の定義と呼び出し | 関数は引数を受け取り、returnで戻り値を呼び出し元へ返す |

### レッスン1-2 配列とトレース

| ID | トピック | takeaway |
| --- | --- | --- |
| 1-2-1 | 配列は番号で要素を取り出す | 配列の要素は「配列名[添字]」で参照し、擬似言語の添字は1から始まる |
| 1-2-2 | トレース表で実行を追う | 変数の値の変化を1行ずつ表に書き出すのがトレースの基本 |
| 1-2-3 | 繰返しと配列を組み合わせて読む | forで添字を動かして配列を順に処理するのが科目Bの最頻出パターン |

| ID | トピック | takeaway |
| --- | --- | --- |

| ID | トピック | takeaway |
| --- | --- | --- |

## 講座の概要

- **到達目標 (canDo)**: Node.js でファイルやネットワークを扱う小さなプログラムを書き、npm でプロジェクトを組み立てられる
- **前提講座**: `cli-basics`(クリアしていないと開けない)。ターミナル操作・標準入出力・パイプ・環境変数・プロセスの知識を前提にしており、本文でも「コマンドライン入門で学んだ〜」として繰り返し接続します
- **後続 (スキルツリー)**: Git 入門のバックエンドの星が本講座のあとで開く(Git 側の `appearancePrerequisites`)。本線は `typescript-node-basics` → `rest-api-basics`
- **参考にしたロードマップ**: roadmap.sh のバックエンドロードマップ
- **コード演習**: 配線していません。採点基盤(`@falcon/code-runner`)は QuickJS で 1 ファイルを実行する作りで、`node:fs` / `node:http` などの Node.js の組み込みモジュールもファイル分割も扱えないためです。手を動かす部分は各レッスンの `practice.md`「手元で試す」に置き、LMS 上はスライド → まとめ → 確認クイズだけで完走できます

## 設計の方針

- **Node.js は言語ではなく実行環境である、を全体の軸にする。** 0-1-1 でこれを言い切り、以降は「この環境が何を扱えるか」(ファイル・引数・環境変数・通信)という順で広げます。JavaScript の文法そのものは主題にしません
- **JavaScript の前提は明示して、そこで止める。** バックエンドのルート(it-basics → sql-basics → cli-basics → node-basics)は `javascript-basics` を通りません。そのため 0-1-4 を「この講座で書く JavaScript の範囲」に充て、**変数・関数・オブジェクトの3つ**だけを使うと宣言しています。コード例もこの範囲に収めています(配列の高階関数やクラスは使いません)。文法を体系的に学びたい受講者には JavaScript 入門を案内します
- **コマンドライン入門との接続を本文に書く。** 標準出力(1-1-3)、`>` と `>>` に対応する `writeFile` / `appendFile`(4-1-2)、環境変数(4-1-5)、終了ステータスと `&&`(5-1-4)、`ps` と `kill`(6-1-4)は、前講座で学んだ内容の再利用として説明します
- **非同期は仕組みから入る。** 5-1-1 でシングルスレッドとイベントループを先に置き、`await` を呪文にしません。M4 で形として使わせておき、M5 で回収する順にしています
- **フレームワークを使わない。** M6 は `node:http` だけで書きます。Express や Hono は後続の `rest-api-basics` の範囲で、ここでは「フレームワークが何を楽にしているか」が分かる状態を作ります

## M5 非同期処理(1レッスン / 4トピック)

### L5-1 非同期処理
| ID | Takeaway |
|---|---|
| 5-1-1 | Node.jsはコードを1本の流れで実行するので、その流れを止めると他の処理も全部止まる |

## 対象外

次の内容はこの講座では扱いません。

- **TypeScript** — 本講座は素の JavaScript で環境の使い方を扱います。型を書く部分は後続の `typescript-node-basics` の主題です(スキルツリーに出る `canDo` も、実際に扱う内容に合わせて TypeScript に触れない文言にしています)
- **JavaScript の文法の体系的な学習** — 0-1-4 で宣言した3つ(変数・関数・オブジェクト)の範囲で書きます。配列の高階関数・クラス・分割代入などは使いません
- **フレームワーク(Express / Hono / Fastify)** — `rest-api-basics` の範囲です
- **データベース接続** — SQL 入門で学んだ SQL を Node.js から実行する話は `rest-api-basics` 側に置きます
- **ストリーム・Buffer・ワーカースレッド** — 入門の範囲を超えます。4-1-1 で文字エンコーディングに触れる程度に留めます
- **テスト(`node:test`)** — `python-testing-ci-basics` / `test-design-basics` がテストの考え方を扱います
- **デプロイ・PM2 などの運用** — 起動と停止(6-1-4)までを扱います

## 執筆時のメモ

- 前提講座を変える場合は `course.json` と本ファイルの両方を更新する(グラフ検査の対象)
- **JavaScript 未習のまま到達しうる講座である点が、この講座の最大の制約**。0-1-4 の宣言とコード例の範囲は、本文を増やすときも守る。もしカリキュラム側で `javascript-basics` を前提に加える判断をするなら、0-1-4 の位置づけを見直せる
- サムネイル(`thumbnail.webp`)とアイコン(`icon.svg`)は設置済み(`scripts/build_thumbnails.py` の `SPECS` に `node-basics` を登録)。作り直すときも手描きせず `python packages/content/scripts/build_thumbnails.py node-basics` で生成する
- 図解 SVG は未作成(`assets/` を持つトピックが無い)。イベントループ(5-1-1)とリクエスト / レスポンス(6-1-2)は図解の候補

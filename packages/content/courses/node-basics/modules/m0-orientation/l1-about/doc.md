## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「Node.js で TypeScript を実行し、ファイルやネットワークを扱う小さなプログラムを書ける」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- Node.js とは何か (ブラウザとの違い)
- npm スクリプトと TypeScript の実行
- ファイル操作と標準入出力
- HTTP サーバーの最小構成
- イベントループと非同期処理

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

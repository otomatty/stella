## 結論

**この講座では、変数・関数・オブジェクトまでのJavaScriptを使って書く**

- **変数** — 値に名前を付けて置いておく入れ物
- **関数** — 手順に名前を付けて、呼び出せるようにしたもの
- **オブジェクト** — 名前と値の組をまとめたもの

<!-- ノート: 結論を先に言い切ります。3つの言葉はこのあと毎回出てくると予告します。 -->

---

## 使う書き方はこの3つだけ

```js
const port = 3000;              // 変数

function greet(name) {          // 関数
  return "hello " + name;
}

const user = { id: 1, name: "佐藤" };   // オブジェクト
```

- 文法をもっと知りたい人はJavaScript入門の講座で補える

# レッスン0-1 Node.jsとは何か

## このレッスンの目標

- [ ] Node.jsが何であるかを1文で説明できる
- [ ] ブラウザとNode.jsで扱えるものの違いを説明できる
- [ ] `node -v` で自分の環境の版を確かめられる

## 0-1-1 Node.jsはブラウザの外でJavaScriptを動かす

> **Node.jsは、ブラウザの外でJavaScriptを動かすための実行環境**

サーバー側の求人や手順書には「Node.js」が当たり前のように出てきます。まず、これが何なのかをはっきりさせます。

- **JavaScript** — もともとブラウザの中で動いていたプログラミング言語
- **実行環境** — 書いたプログラムを実際に動かす土台

**Node.js は言語ではありません。** JavaScriptという言語を、ブラウザの外でも動かせるようにした実行環境です。

```text
これまで   [ブラウザ]  ← JavaScript が動く唯一の場所

いま       [ブラウザ]  画面の動き
           [Node.js]   サーバー・ツール・自動化
```

言語そのものは同じなので、覚え直す必要はありません。変わるのは動かす場所と、そこで扱えるものです。

## 0-1-2 ブラウザとの違いは扱えるものにある

> **Node.jsには画面が無い代わりに、ファイルやネットワークを直接扱える**

ブラウザ向けのサンプルコードをNode.jsで動かすとエラーになることがあります。同じJavaScriptなのに動かないのは、置かれている場所が違うからです。

- **DOM** — ブラウザが持つ、画面を操作するためのしくみ
- **ファイルシステム** — ディスク上のファイルやディレクトリの世界

```text
             ブラウザ        Node.js
DOM(画面)      あり           なし
ファイル       ほぼ不可        読み書きできる
ネットワーク   制限あり        サーバーを立てられる
```

ブラウザは、利用者を守るために、勝手にファイルを読み書きできないよう強く制限されています。Node.jsにはその制限がない代わりに、画面がありません。`document` や `window` は存在せず、使おうとすると `document is not defined` というエラーになります。

この違いは「どちらが優れているか」ではありません。**画面を操作するのがブラウザ、ファイルとネットワークを扱うのがNode.js** と、役割が分かれていると考えてください。

## 0-1-3 バージョンはLTSをそろえる

> **node -v で自分の環境の版を確かめ、チームはLTSの版にそろえる**

同じコードなのに自分の環境だけ動かない、ということがあります。原因の切り分けで最初に確認するのが、土台の版です。

```bash
node -v
# => v22.14.0

npm -v
# => 10.9.2
```

- **バージョン** — その実行環境の版
- **LTS** — 長期間サポートされる安定版(long term support)

Node.jsは偶数の版(20・22 など)がLTSになります。業務では、最新の機能を追うより、サポート期間が長く安定している版を選ぶのが基本です。チーム全員が同じ版を使っていれば、「自分の環境では動く」というすれ違いが減ります。

`npm` はNode.jsと一緒に入る道具です。詳しくはモジュール2で扱います。

## 0-1-4 この講座で書くJavaScriptの範囲

> **この講座では、変数・関数・オブジェクトまでのJavaScriptを使って書く**

JavaScriptを深く知らないと始められないのか、という不安があると思います。この講座で使う文法の範囲を、先に示しておきます。

```js
const port = 3000;              // 変数

function greet(name) {          // 関数
  return "hello " + name;
}

const user = { id: 1, name: "佐藤" };   // オブジェクト
```

- **変数** — 値に名前を付けて置いておく入れ物
- **関数** — 手順に名前を付けて、呼び出せるようにしたもの
- **オブジェクト** — 名前と値の組をまとめたもの

この3つが読めれば、この講座の内容は追えます。逆に、この講座はJavaScriptの文法そのものを教える講座ではありません。文法をしっかり身につけたい場合は、JavaScript入門の講座で補ってください。

主題はあくまで **Node.jsという環境の使い方** です。ファイルの読み書き、コマンドライン引数、HTTPサーバーといった、環境が提供する機能を扱っていきます。

# 5-1-2
# 時間のかかる処理は待たずに先へ進む

Node.js 入門 — Module 5 / レッスン5-1

<!-- ノート: 実行順が書いた順と違う、という驚きを最初に体験させる回です。 -->

---

## なぜ必要か

- 読み込んだ内容を表示したいのに、空(undefined)が出る
- 書いた順に実行されていないように見える

<!-- ノート: つかみ。初心者が最初に出会う非同期のバグそのものです。 -->

---

## 結論

**ファイル読み込みや通信は結果を待たずに次の行へ進み、終わってから結果が返る**

- **非同期処理** — 結果を待たずに先へ進む処理の進め方
- **Promise** — 「後で結果を渡す」という約束を表すもの

<!-- ノート: 結論を先に言い切ります。Promise は「引換券」だと言うと伝わります。 -->

---

## 結果ではなく引換券が返る

```js
import { readFile } from "node:fs/promises";

const p = readFile("memo.txt", "utf-8");
console.log(p);        // => Promise { <pending> }  ← まだ中身が無い
```

- 中身が欲しいときは、受け取り方を書く必要がある

<!-- ノート: pending は「処理中」です。ここで await を出さずに、問題だけを見せます。 -->

---

# 直したら止めて起動し直す

Node.js 入門 — Module 6 / レッスン6-1

<!-- ノート: 実際に詰まる運用の話です。ポート使用中のエラーはここで必ず出会います。 -->

---

## なぜ必要か

- コードを直したのに、ブラウザの表示が変わらない
- 起動し直そうとしたら `EADDRINUSE` と言われた

<!-- ノート: つかみ。この2つは初日に必ず出会います。 -->

---

## 結論

**起動中のサーバーはコードを直しても変わらないので、Ctrl+Cで止めて起動し直す**

- **EADDRINUSE** — そのポートは既に使われている、というエラー

<!-- ノート: 結論を先に言い切ります。読み込み済みのコードで動き続けている、が理由です。 -->

---

## 止めてから、立て直す

```bash
# Ctrl+C でサーバーを止めてから
node server.js

# 止め忘れて EADDRINUSE が出たら
ps aux | grep node      # PID を調べる
kill <PID>              # 止める
```

- 残ったプロセスがポートを握っている。調べて・止めて・確かめる

## 結論

**createServerでリクエストの受け口を作り、listenでポートを開くとサーバーになる**

- **サーバー** — 要求を待ち受けて、応答を返し続けるプログラム
- **ポート** — 待ち受ける番号。3000番などを使う

<!-- ノート: 結論を先に言い切ります。待ち続けるプログラム、という点が普通のスクリプトとの違いです。 -->

---

## 8行で立つ

```js
import { createServer } from "node:http";

const server = createServer((req, res) => {
  res.end("hello");
});

server.listen(3000);
console.log("http://localhost:3000 で待機中");
```

- 実行してもプログラムが終わらない。待ち続けるのが仕事

<!-- ノート: 終わらないことに戸惑う受講者がいます。仕様だと明言します。 -->

# リクエストを読んでレスポンスを返す

Node.js 入門 — Module 6 / レッスン6-1

## なぜ必要か

- `(req, res)` の2つが何なのか分からないまま写している
- 相手が何を求めているかを読めないと、返す内容を決められない

<!-- ノート: つかみ。写経から抜け出すための回だと位置づけます。 -->

---

## 結論

**受け口の関数は、要求の情報が入ったreqと、応答を書き込むresを受け取る**

- **リクエスト** — 相手からの要求(どのURLへ、どの方法で)
- **レスポンス** — こちらが返す応答

<!-- ノート: 結論を先に言い切ります。req は読む物、res は書く物、と役割で覚えさせます。 -->

---

## 読んで、書いて、終える

```js
createServer((req, res) => {
  console.log(req.method, req.url);      // 読む: GET /about
  res.statusCode = 200;                   // ステータスコード
  res.setHeader("Content-Type", "text/plain; charset=utf-8");
  res.end("こんにちは");                   // 書いて終える
});
```

- **ステータスコード** — 結果の種類。200は成功、404は見つからない

<!-- ノート: res.end を呼ばないと相手はずっと待ちます。必ず終えることを強調します。 -->

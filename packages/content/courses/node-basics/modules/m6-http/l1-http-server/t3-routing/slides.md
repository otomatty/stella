## 分岐で振り分ける

```js
createServer((req, res) => {
  if (req.url === "/") {
    res.end("トップページ");
  } else if (req.url === "/about") {
    res.end("このサイトについて");
  } else {
    res.statusCode = 404;
    res.end("見つかりません");
  }
});
```

- 該当が無いときは404を返す。黙って成功を返さない

<!-- ノート: 404 を返す作法は、後続の REST API 講座にそのままつながります。 -->

# console.logは標準出力に書き出す

Node.js 入門 — Module 1 / レッスン1-1

<!-- ノート: コマンドライン入門で学んだ標準出力と、Node.js のコードがここでつながります。 -->

---

## なぜ必要か

- Node.jsの実行結果を、ファイルに保存したり次の処理に渡したりしたい
- 画面に出すだけの道具だと思っていると、その発想が出てこない

<!-- ノート: つかみ。console.log を「デバッグ用の表示」だけだと思っている状態から広げます。 -->

---

## 結論

**console.logの出力は標準出力に流れるので、パイプやリダイレクトでそのまま扱える**

- **console.log** — 受け取った値を標準出力へ書き出す

<!-- ノート: 結論を先に言い切ります。Node.js のプログラムも、シェルから見れば普通のコマンドの1つです。 -->

---

## 出力先はシェルから差し替えられる

```bash
node app.js > result.txt     # ファイルに書き出す
node app.js | grep error     # 次のコマンドに渡す
```

```js
console.log("処理を開始します");
console.log({ id: 1, name: "佐藤" });   // オブジェクトも表示できる
```

## なぜ必要か

- 「この書き方で合っているか」を確かめたいだけなのに、毎回ファイルを作っている
- 1行の確認に、作って・保存して・実行しての3手順は重い

## 結論

**node とだけ打つとREPLが開き、1行ずつ書いて結果をその場で確かめられる**

- **REPL** — 入力を読んで実行し、結果を返すことを繰り返す対話画面

## 開いて、試して、抜ける

```text
$ node
> 1 + 2
3
> const name = "佐藤"
undefined
> "こんにちは " + name
'こんにちは 佐藤'
> .exit          ← 抜ける(Ctrl+C を2回でも可)
```

- 書いたものは残らない。残したい処理はファイルに書く

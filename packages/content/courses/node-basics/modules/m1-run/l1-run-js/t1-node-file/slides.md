## なぜ必要か

- 書いたコードを動かす方法が分からないと、何も試せない
- ブラウザならHTMLに読み込ませたが、Node.jsではその手が使えない

<!-- ノート: つかみ。動かし方が分からないと学習が始まりません。 -->

## 結論

**node ファイル名 と打つと、そのファイルに書いたJavaScriptが上から順に実行される**

- **スクリプトファイル** — 実行したい処理を書いたファイル。拡張子は `.js`

<!-- ノート: 結論を先に言い切ります。シェルスクリプトと同じ考え方だと添えると、CLI 講座とつながります。 -->

---

## 書いて、実行する

```bash
# app.js に処理を書いてから
node app.js
# => 実行結果が表示される
```

```js
// app.js
const message = "はじめてのNode.js";
console.log(message);
```

<!-- ノート: コマンドラインの「コマンド名 引数」の形そのままです。node がコマンド名、ファイル名が引数です。 -->

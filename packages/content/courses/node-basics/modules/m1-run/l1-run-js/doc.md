# レッスン1-1 JavaScriptを実行する

## このレッスンの目標

- [ ] `node ファイル名` でスクリプトを実行できる
- [ ] REPLで1行ずつ動作を確かめられる
- [ ] エラーが出たときに、種類・メッセージ・行番号を読める

## 1-1-1 nodeコマンドでファイルを実行する

> **node ファイル名 と打つと、そのファイルに書いたJavaScriptが上から順に実行される**

ブラウザ向けのJavaScriptはHTMLに読み込ませて動かしていましたが、Node.jsではその手が使えません。代わりに、コマンドで直接実行します。

```js
// app.js
const message = "はじめてのNode.js";
console.log(message);
```

```bash
node app.js
# => はじめてのNode.js
```

実行したい処理を書いたファイルを **スクリプトファイル** と呼びます。拡張子は `.js` を使います。

形に注目してください。`node app.js` は、コマンドライン入門で学んだ「コマンド名 引数」そのものです。`node` がコマンド名、`app.js` が引数です。シェルスクリプトが「コマンドを並べたファイル」だったように、`.js` ファイルは「JavaScriptを並べたファイル」で、上から順に実行されます。

## 1-1-2 REPLなら1行ずつ試せる

> **node とだけ打つとREPLが開き、1行ずつ書いて結果をその場で確かめられる**

「この書き方で合っているか」を確かめたいだけなのに、毎回ファイルを作って保存して実行するのは手間です。

引数を付けずに `node` と打つと、対話画面が開きます。これを **REPL** と呼びます。read(読む)・eval(評価する)・print(表示する)・loop(繰り返す)の頭文字です。

```text
$ node
> 1 + 2
3
> const name = "佐藤"
undefined
> "こんにちは " + name
'こんにちは 佐藤'
> .exit          ← 抜ける(Ctrl+C を2回でも可)
```

`const name = "佐藤"` の結果が `undefined` と表示されるのは、代入という操作自体に返す値が無いためです。エラーではありません。

REPLで書いたものは残りません。**確認は REPL、残す処理はファイル** と使い分けます。抜け方(`.exit`)は開く前に覚えておいてください。

## 1-1-3 console.logは標準出力に書き出す

> **console.logの出力は標準出力に流れるので、パイプやリダイレクトでそのまま扱える**

`console.log` を「デバッグ用の表示」だと思っていると、その先の使い道に気づけません。実際には、コマンドライン入門で学んだ標準出力に書き出しています。

```js
console.log("処理を開始します");
console.log({ id: 1, name: "佐藤" });   // オブジェクトも表示できる
```

```bash
node app.js > result.txt     # ファイルに書き出す
node app.js | grep error     # 次のコマンドに渡す
```

つまり、**自分で書いたNode.jsのプログラムも、シェルから見れば普通のコマンドの1つ** です。`grep` や `wc` と同じようにパイプでつなげますし、`>` でファイルに残せます。

この性質があるので、Node.jsは「小さな道具を作って、シェルで組み合わせる」という使い方に向いています。

## 1-1-4 エラーは上から3行を読む

> **エラーが出たら、種類・メッセージ・発生したファイルと行番号の3点をまず読む**

赤い文字がたくさん出ると、読む前に諦めてしまいがちです。しかし、必要な情報はそのうちの数行だけです。

```text
/Users/sato/app.js:3
console.log(user.name);            ← 発生した行
              ^
TypeError: Cannot read properties of undefined
 └──┬───┘  └─────────┬──────────┘
  種類            メッセージ
    at Object.<anonymous> (/Users/sato/app.js:3:15)   ← 経路
```

読むのは次の3点です。

1. **種類** — `TypeError` や `ReferenceError` など、何が起きたかの分類
2. **メッセージ** — 具体的な内容(`Cannot read properties of undefined` = 中身の無いものから値を取り出そうとした)
3. **場所** — ファイル名と行番号(`app.js:3`)

`at ...` から始まる行の並びを **スタックトレース** と呼びます。エラーに至るまでの呼び出しの経路ですが、最初のうちは後回しで構いません。

まず3点を読み、その行を開く。これだけで、多くのエラーは自力で直せます。

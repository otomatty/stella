## なぜ必要か

- 処理した結果を、次の人が使えるファイルとして残したい
- 画面に出すだけでは、後の工程に渡せない

## 結論

**writeFileはファイルに書き出す。既にあるファイルの中身は置き換わる**

- **writeFile** — 指定したパスに内容を書き出す

<!-- ノート: 結論を先に言い切ります。シェルの > と同じだと結びつけると腑に落ちます。 -->

## 上書きと追記を書き分ける

```js
import { writeFile, appendFile } from "node:fs/promises";

await writeFile("out.txt", "1行目\n");        // 置き換え(> と同じ)
await appendFile("out.txt", "2行目\n");       // 追記(>> と同じ)
```

- 確認は出ない。書き出し先の名前は実行前に読み返す

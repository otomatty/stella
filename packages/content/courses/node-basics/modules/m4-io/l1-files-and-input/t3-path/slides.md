# 4-1-3
# パスの組み立てはnode:pathに任せる

Node.js 入門 — Module 4 / レッスン4-1

<!-- ノート: 環境差で壊れるコードを書かないための回です。Windows との差を具体例で見せます。 -->

## なぜ必要か

- `"logs" + "/" + name` のような連結が、環境によって壊れる
- 区切り記号が二重になったり、足りなかったりする

<!-- ノート: つかみ。自分の環境では動くのに他人の環境で落ちる、という典型例です。 -->

---

## 結論

**パスを文字列で連結せず、node:pathのjoinで組み立てる**

- **path** — パスを組み立て・分解する組み込みモジュール

<!-- ノート: 結論を先に言い切ります。区切り記号を自分で書かないのが要点です。 -->

---

## 連結ではなく組み立て

```js
import { join } from "node:path";

join("logs", "2026", "app.log");   // => logs/2026/app.log
join("logs/", "/app.log");         // => logs/app.log (重複も直る)
```

- 環境ごとの区切り記号の違いも `join` が吸収する

<!-- ノート: Windows では区切りが \ になります。自分で書かなければ気にしなくてよくなります。 -->

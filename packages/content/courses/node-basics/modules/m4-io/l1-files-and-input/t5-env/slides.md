# process.envで環境変数を読む

Node.js 入門 — Module 4 / レッスン4-1

<!-- ノート: コマンドライン入門 5-1 の環境変数が、コードの側からどう見えるかという回です。 -->

---

## なぜ必要か

- 接続先やパスワードをコードに書くと、そのままGitに残ってしまう
- 開発と本番で値を変えたいのに、コードが同じでは切り替えられない

<!-- ノート: つかみ。秘密の値が履歴に残る怖さは、Git 講座を通っていれば伝わります。 -->

---

## 結論

**環境変数はprocess.envから読み、接続先や鍵はコードに書かず外から渡す**

- **環境変数** — シェルが持ち、起動したプログラムに引き継がれる名前つきの値

<!-- ノート: 結論を先に言い切ります。設定を外に出す、という原則そのものです。 -->

---

## 外から渡して、中で読む

```js
const port = process.env.PORT;
console.log("ポートは " + port);
```

```bash
PORT=3000 node app.js
# => ポートは 3000
```

- 渡し忘れると `undefined` になる。既定値を決めておくと安全

<!-- ノート: 既定値の書き方(|| や ??)は JavaScript 入門の範囲なので、ここでは考え方だけ伝えます。 -->

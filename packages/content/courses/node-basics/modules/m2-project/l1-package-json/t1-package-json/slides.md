## なぜ必要か

- 誰かのプロジェクトを渡されたが、何が必要でどう動かすのか分からない
- 口頭やチャットで手順を伝えると、必ず抜ける

<!-- ノート: つかみ。引き継ぎで困る場面から入ります。 -->

---

## 結論

**package.jsonは、そのプロジェクトの名前・使う道具・実行手順を書いたファイル**

- **npm** — Node.jsに付いてくる、道具を集めて管理する仕組み
- **package.json** — npmが読む、プロジェクトの説明書

<!-- ノート: 結論を先に言い切ります。人間もツールも同じファイルを読む、という点が肝心です。 -->

---

## 最初の1コマンドで作る

```bash
npm init -y
```

```json
{
  "name": "node-practice",
  "version": "1.0.0",
  "scripts": { "start": "node app.js" }
}
```

- 中身はJSONというオブジェクトの書き方。名前と値の組が並ぶ

<!-- ノート: JSON は 0-1-4 のオブジェクトと同じ形だと結びつけます。 -->

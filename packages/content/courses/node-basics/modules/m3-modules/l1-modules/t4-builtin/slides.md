## なぜ必要か

- ファイルを読む機能は、わざわざインストールしないと使えないのか
- 自分で入れた部品と、最初からある機能の区別が付かない

<!-- ノート: つかみ。npm install が必要かどうかを判断できない状態から入ります。 -->

---

## 結論

**Node.jsに最初から入っている機能は、node:で始まる名前で読み込んで使う**

- **組み込みモジュール** — Node.js自体が持つ機能。インストール不要

<!-- ノート: 結論を先に言い切ります。node: を付けると出どころが一目で分かると添えます。 -->

---

## 名前の頭で出どころが分かる

```js
import { readFile } from "node:fs/promises";  // 組み込み
import dayjs from "dayjs";                     // npmで入れたもの
import { withTax } from "./tax.js";            // 自分のファイル
```

- 主な組み込み: `node:fs`(ファイル) `node:path`(パス) `node:http`(通信)

<!-- ノート: 3種類の import が並ぶ画面はこの先ずっと見ます。見分けを今つけさせます。 -->

# 3-1-1
# exportしたものだけが外から見える

Node.js 入門 — Module 3 / レッスン3-1

<!-- ノート: 1ファイルに全部書く段階から抜け出す回です。分ける単位と、公開する範囲を扱います。 -->

---

## なぜ必要か

- 1つのファイルが数百行になり、どこに何があるか分からない
- 名前が衝突して、意図せず別の処理を上書きしてしまう

<!-- ノート: つかみ。ファイルが育ちきった経験は誰にでもあります。 -->

---

## 結論

**1つのファイルが1つのモジュールで、exportを付けたものだけ外から使える**

- **モジュール** — 分割の単位になるファイル
- **export** — そのモジュールの外に公開する印

<!-- ノート: 結論を先に言い切ります。既定は非公開で、公開したいものだけ印を付けると伝えます。 -->

---

## 公開する印を付ける

```js
// tax.js
const RATE = 0.1;                     // 外からは見えない

export function withTax(price) {      // 外から使える
  return Math.round(price * (1 + RATE));
}
```

- 印の無いものは、そのファイルの中だけの持ち物

<!-- ノート: RATE を隠せることが、名前の衝突を防ぐ仕組みそのものです。 -->

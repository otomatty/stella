# importで別のファイルから読み込む

Node.js 入門 — Module 3 / レッスン3-1

<!-- ノート: export と対になる操作です。書き方より「どこから来た関数か」が分かる価値を伝えます。 -->

---

## なぜ必要か

- 分けたのはよいが、別のファイルの関数をどう呼ぶのか分からない
- コードを読む人も、その関数がどこから来たのか知りたい

<!-- ノート: つかみ。分割は呼び出せて初めて意味を持ちます。 -->

---

## 結論

**importは、別のモジュールがexportしたものを名前を指定して読み込む**

- **import** — 読み込む側に書く。ファイルの先頭にまとめる

<!-- ノート: 結論を先に言い切ります。先頭に並ぶ import が、そのファイルの依存の一覧になります。 -->

---

## 名前と場所を指定する

```js
// app.js
import { withTax } from "./tax.js";

console.log(withTax(1000));   // => 1100
```

- 自分のファイルは `./` で始める。`./` が無いとパッケージとして探される

<!-- ノート: ./ の有無で探し先が変わる点は、この先つまずきやすい部分です。 -->

## なぜ必要か

- サーバーのプログラムは、動かしてみるまで間違いに気づけない
- 気づく場所が本番だと、利用者に影響が出てからの発覚になる

<!-- ノート: つかみ。サーバー側は「動かしてみる」の代償が大きい、という文脈を作ります。 -->

---

## 結論

**TypeScriptは、値の種類の取り違えを実行する前に見つけてくれる**

- **型** — その値がどんな種類かを表す情報(数値・文字列など)
- **実行前** — 動かす前。エディタや検査コマンドで分かる

<!-- ノート: 結論を先に言い切ります。テストの代わりではなく、より手前の網だと添えます。 -->

---

## 気づく場所が変わる

```ts
const price: number = 1000;
const label: string = price;   // 実行前にエラーになる
// => Type 'number' is not assignable to type 'string'
```

- JavaScriptなら動いてしまい、後の行で初めて壊れる

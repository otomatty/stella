## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「サーバー側の TypeScript で型を付けて、Node.js から小さなプログラムを書ける」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- ブラウザの TypeScript との違い (DOM が無い、`@types/node`)
- `tsconfig` とモジュール
- 型で API の入出力を表す
- Node.js で TypeScript を実行する
- エラーの型と例外

フロントエンドの TypeScript 入門とは別の講座です。公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

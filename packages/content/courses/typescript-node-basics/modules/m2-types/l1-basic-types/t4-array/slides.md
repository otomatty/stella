## なぜ必要か

- ファイルから読んだ行の一覧を、まとめて扱いたい
- 途中で違う種類の値が混ざると、後の処理が壊れる

## 結論

**string[] は「文字列だけが入る配列」を表し、別の種類の値は入れられない**

- **配列** — 同じ種類の値を順番に並べたもの

<!-- ノート: 結論を先に言い切ります。型の後ろに [] を付けるだけ、という単純さを強調します。 -->

---

## 中身の型に [] を付ける

```ts
const names: string[] = ["佐藤", "田中"];
const prices: number[] = [1200, 800];

names.push("鈴木");     // 問題なし
names.push(100);        // エラー: 数値は入れられない
```

- 型が守ってくれるので、後の処理で種類を確認しなくてよい

<!-- ノート: 混ざらないことが保証されるので、後続の処理が単純になります。 -->

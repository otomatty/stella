# 2-1-2
# 推論できるところは書かない

TypeScript 入門（サーバー） — Module 2 / レッスン2-1

<!-- ノート: 型を書きすぎない、という価値観をここで渡します。冗長な注釈は読みにくさになります。 -->

---

## なぜ必要か

- すべての変数に型を書いたら、コードが読みにくくなった
- 値を見れば分かることを、二重に書いている気がする

<!-- ノート: つかみ。書けば書くほどよい、という誤解を解きます。 -->

---

## 結論

**初期値から型が分かるところは型注釈を書かず、TypeScriptの推論に任せる**

- **型推論** — 値からTypeScriptが型を自動で判断すること

<!-- ノート: 結論を先に言い切ります。推論に任せても検査の強さは変わりません。 -->

---

## 書く場所と、書かない場所

```ts
const name = "佐藤";              // 推論に任せる(string になる)
const price = 1200;               // 推論に任せる(number になる)

let total: number;                // 初期値が無いときは書く
function withTax(price: number) { }  // 引数は必ず書く
```

- 引数と、初期値の無い変数には書く

<!-- ノート: 「引数には必ず書く」は次のレッスンにつながる重要な線引きです。 -->

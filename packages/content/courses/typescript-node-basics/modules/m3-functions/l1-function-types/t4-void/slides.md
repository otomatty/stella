# 3-1-4
# 返さない関数の型はvoid

TypeScript 入門（サーバー） — Module 3 / レッスン3-1

<!-- ノート: 表示やログのような、副作用だけの関数の型です。名前が付くと設計を語れます。 -->

---

## なぜ必要か

- ログを出すだけの関数に、何と書けばよいか分からない
- 何も返さない関数と、返し忘れた関数を区別したい

<!-- ノート: つかみ。書き手の意図を型で表せる、という話につなげます。 -->

---

## 結論

**値を返さない関数の戻り値の型はvoidで、返す値が無いことを明示する**

- **void** — 返す値が無いことを表す型

<!-- ノート: 結論を先に言い切ります。意図的に返さないと宣言することに意味があります。 -->

---

## 返さないと宣言する

```ts
function logOrder(id: number): void {
  console.log("注文 " + id + " を受け付けました");
}

const result = logOrder(1);   // result の型は void(使い道が無い)
```

- 呼び出し側は、戻り値を使わないことが型から分かる

<!-- ノート: 戻り値を使おうとすると型が void で止まります。読み手への合図になります。 -->

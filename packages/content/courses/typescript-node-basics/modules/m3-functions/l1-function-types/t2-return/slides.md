# 戻り値の型は書いて固定する

TypeScript 入門（サーバー） — Module 3 / レッスン3-1

<!-- ノート: 推論に任せられるのにあえて書く、という判断を扱います。理由を言えることが大事です。 -->

---

## なぜ必要か

- 関数の中を直したら、返る値の種類が変わってしまった
- 呼び出している何十か所が、まとめて壊れた

<!-- ノート: つかみ。影響範囲が広がる怖さを具体的に示します。 -->

---

## 結論

**戻り値の型を書くと、実装を変えたときに約束が崩れたことをその場で気づける**

- **戻り値** — 関数が返す値

<!-- ノート: 結論を先に言い切ります。推論できても書く理由がここにあります。 -->

---

## 書いておくと、その関数が赤くなる

```ts
function withTax(price: number): number {
  return "1100";        // エラー: number を返すはずが文字列
}
```

- 書かなければ、呼び出し側が壊れるまで気づけない

<!-- ノート: 書かない場合との差を口頭で補います。壊れる場所が遠くなります。 -->

# 3-1-1
# 引数の型は呼び出し側との約束

TypeScript 入門（サーバー） — Module 3 / レッスン3-1

<!-- ノート: 型の価値がいちばん出る場所です。エラーが出る位置に注目させます。 -->

---

## なぜ必要か

- 関数の中でエラーが出たが、原因は呼び出し側の渡し方だった
- 直すべき場所と、壊れた場所が離れている

<!-- ノート: つかみ。デバッグで時間を溶かす典型的な構図です。 -->

---

## 結論

**引数に型を書くと、間違った値を渡した呼び出し側の行がエラーになる**

- **引数** — 関数が受け取る値

<!-- ノート: 結論を先に言い切ります。エラーが原因の場所で出ることが価値です。 -->

---

## エラーが原因の場所で出る

```ts
function withTax(price: number): number {
  return Math.round(price * 1.1);
}

withTax(1000);      // OK
withTax("1000");    // エラー: ここが赤くなる
```

- 関数の中ではなく、渡した側の行が指摘される

<!-- ノート: 「渡した側が赤くなる」ことを強調します。原因の場所で気づけるのが型の効用です。 -->

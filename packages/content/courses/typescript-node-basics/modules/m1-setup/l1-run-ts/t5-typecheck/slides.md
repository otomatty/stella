# 型検査だけを走らせる

TypeScript 入門（サーバー） — Module 1 / レッスン1-1

<!-- ノート: CI で使う形です。検査と生成を分けて考えられるようにします。 -->

---

## なぜ必要か

- 型が合っているかだけを確かめたいのに、毎回ファイルが生成される
- 検査の結果を、変更を取り込む前の関門にしたい

<!-- ノート: つかみ。CI という言葉はまだ出さず、目的だけを述べます。 -->

---

## 結論

**tsc --noEmitは、ファイルを出さずに型の検査だけを行う**

- **型検査** — 型が矛盾していないかを調べること

<!-- ノート: 結論を先に言い切ります。emit = 出力なので、noEmit は「出さない」です。 -->

---

## 検査と生成を分ける

```bash
npx tsc --noEmit     # 検査だけ。dist は作られない
```

```json
"scripts": {
  "typecheck": "tsc --noEmit",
  "build": "tsc"
}
```

- エラーが1つでもあれば、終了ステータスが1になる

<!-- ノート: 終了ステータスは CLI 講座の && とつながります。自動化の部品になります。 -->

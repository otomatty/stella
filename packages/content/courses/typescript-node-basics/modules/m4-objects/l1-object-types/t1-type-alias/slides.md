# 4-1-1
# typeでオブジェクトの形に名前を付ける

TypeScript 入門（サーバー） — Module 4 / レッスン4-1

<!-- ノート: サーバー側で扱うデータはほぼオブジェクトです。ここが実務の中心になります。 -->

---

## なぜ必要か

- 同じ形のデータを、関数のたびに書き下している
- 項目が1つ増えたとき、直す場所が何か所あるか分からない

<!-- ノート: つかみ。重複した型注釈が保守の負担になる場面です。 -->

---

## 結論

**typeを使うと、オブジェクトの形に名前を付けて何度も使い回せる**

- **型エイリアス** — 型に名前を付ける仕組み(`type 名前 = ...`)
- **プロパティ** — オブジェクトが持つ、名前と値の組

<!-- ノート: 結論を先に言い切ります。名前が付くと会話でも使えるようになります。 -->

---

## 形に名前を付ける

```ts
type User = {
  id: number;
  name: string;
};

function findUser(id: number): User {
  return { id, name: "佐藤" };
}
```

- 項目が増えたときに直すのは、この1か所だけ

<!-- ノート: { id, name: "佐藤" } の短縮記法には触れず、形の話に集中します。 -->

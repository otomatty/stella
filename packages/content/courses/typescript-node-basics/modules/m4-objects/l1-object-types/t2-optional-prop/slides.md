# 4-1-2
# 無いかもしれない項目は?を付ける

TypeScript 入門（サーバー） — Module 4 / レッスン4-1

<!-- ノート: 実データは欠けているのが普通です。欠けを型で表せることを扱います。 -->

---

## なぜ必要か

- 電話番号は登録していない利用者もいる
- 必須にすると、実際のデータが型に合わなくなる

<!-- ノート: つかみ。現実のデータは全項目そろっていない、という前提を共有します。 -->

---

## 結論

**プロパティ名の後ろに?を付けると、その項目は無くてもよくなる**

- **省略可能なプロパティ** — `名前?: 型` と書く

<!-- ノート: 結論を先に言い切ります。引数の ? と同じ考え方だと結びつけます。 -->

---

## 無くてもよい項目を表す

```ts
type User = {
  id: number;
  name: string;
  phone?: string;      // 無くてもよい
};

const a: User = { id: 1, name: "佐藤" };              // OK
const b: User = { id: 2, name: "田中", phone: "03" };  // OK
```

- 使うときは、値が無い場合の確認が要る

<!-- ノート: 使用時に確認が必要になる点は、引数の ? と完全に同じです。 -->

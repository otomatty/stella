# オブジェクトの配列でまとまりを表す

## なぜ必要か

- データベースから取り出した複数件を、そのまま扱いたい
- 1件と複数件で書き方が変わると、混乱のもとになる

<!-- ノート: つかみ。SQL の SELECT 結果を思い出させると、既習知識とつながります。 -->

---

## 結論

**User[] と書くと、同じ形のオブジェクトが並んだデータを型で表せる**

- **レコード** — 1件分のデータ。表の1行に当たるもの

<!-- ノート: 結論を先に言い切ります。SQL の行とオブジェクトが対応することを示します。 -->

---

## 1件と複数件を書き分ける

```ts
type User = { id: number; name: string };

const one: User = { id: 1, name: "佐藤" };

const many: User[] = [
  { id: 1, name: "佐藤" },
  { id: 2, name: "田中" },
];
```

- 中身の形が保証されるので、取り出した後の処理が単純になる

<!-- ノート: 配列の型は「中身の型 + []」でした。ここでも同じ規則です。 -->

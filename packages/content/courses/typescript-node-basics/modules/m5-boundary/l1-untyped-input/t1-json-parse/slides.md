# 5-1-1
# 外から来る値には型が付いていない

TypeScript 入門（サーバー） — Module 5 / レッスン5-1

<!-- ノート: 型の限界を扱う回です。型は書いた通りを信じるだけで、実データは検証しません。 -->

---

## なぜ必要か

- 型を書いたのに、実行時に `undefined` で落ちた
- 型検査は通っていたのに、なぜ防げなかったのか分からない

<!-- ノート: つかみ。型を過信した状態から、限界を知る状態へ移します。 -->

---

## 結論

**JSON.parseの結果は中身が保証されないので、そのまま信用してはいけない**

- **JSON** — 設定や通信でよく使われる、データの書き方
- **any** — どんな値でもよいという型。検査が効かなくなる

<!-- ノート: 結論を先に言い切ります。型検査は実行前、データが来るのは実行時、というずれが原因です。 -->

---

## 型は実行時のデータを見ていない

```ts
type User = { id: number; name: string };

const text = await readFile("user.json", "utf-8");
const user = JSON.parse(text) as User;   // 中身は確かめていない

console.log(user.name.length);   // ファイルが空なら実行時に落ちる
```

- `as` は「そう思って扱う」宣言であって、検査ではない

# 成果物はファイルで残る

Cowork入門 — Module 1 / レッスン1-1

<!-- ノート: M1の締めです。作業場所の中に何が生まれるかの話をします。 -->

---

## なぜ必要か

- チャットでは、もらった結果を自分でコピーしてファイルに移していた
- 会話の中に埋もれた成果を、あとから探し直すことがある

<!-- ノート: つかみ。講座2の受講者なら心当たりのある手間です。ここで結論は言わない。 -->

---

## 結論

**仕上がった成果物は、ワークスペースの中にファイルとして残り、そのまま使えます**

- **成果物** — 作業の結果として受け取るもの。講座2で扱った語です

<!-- ノート: 結論を先に言い切ります。成果物は復習なので1行で流します。画面の中の表示ではなく、手元のファイルになるのが新しい点です。 -->

---

## 受け取りの形

```text
依頼   資料30本を一覧に整理してほしい
結果   ワークスペースに「一覧.xlsx」ができている
       → コピーも貼り直しもせず、そのまま開いて使える
```

<!-- ノート: 最小の例です。受け取る作業自体が消えて、確かめる作業から始められます。 -->

---

## コピーの手間がなくなる

| | チャット | Cowork |
| --- | --- | --- |
| 結果の場所 | 会話の画面の中 | ワークスペースの中 |
| 使うまで | コピーして移す | そのまま開く |
| あとから | 会話をさかのぼる | ファイルを開き直す |

<!-- ノート: 対比枠。ファイルで残るからこそ、中身の確認も普段の道具でできます。確認の話はM3で本格的に扱います。 -->

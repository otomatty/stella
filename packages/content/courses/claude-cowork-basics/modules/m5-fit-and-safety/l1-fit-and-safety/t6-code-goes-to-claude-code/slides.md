# コードはClaude Codeへ送る

Cowork入門 — Module 5 / レッスン5-1

## なぜ必要か

- エンジニアの仕事には、資料と同じ顔をしてコードの作業がまぎれ込む
- 「ファイルを直すのは同じだから」とCoworkに流すと、開発の確かめ方が抜ける

<!-- ノート: つかみ。線を引かないと混ざる、という実務のあるあるです。 -->

---

## 結論

**コードを書き換える作業はCoworkに混ぜず、開発向けのClaude Codeで進めます**

- **コード** — プログラムのソースファイル
- **Claude Code** — 手元の開発環境でコードを対象に使う、開発者向けの製品。講座2で扱った語です

<!-- ノート: 結論を先に言い切ります。Claude Codeは復習なので1行で流します。使い分けの線は「対象がコードか」です。 -->

---

## 線の引き方

```text
資料・文書・調査・画面の作業   → Cowork
リポジトリの中のコードを直す   → Claude Code
迷う例: 手順書の中のコマンド修正 → 手順書は文書。実コードの変更が要るなら送る
```

<!-- ノート: 最小の判定です。対象がどこに置かれているか、講座2の使い分けの言葉がそのまま使えます。 -->

# 3-1-5
# 確認までが自分の仕事

Cowork入門 — Module 3 / レッスン3-1

<!-- ノート: タスクループの締めです。終わりを誰が決めるかの話をします。 -->

---

## なぜ必要か

- 「終わりました」の表示を見ると、仕事が終わった気になる
- 体裁の整った成果物ほど、中身を見ずに信じたくなる

<!-- ノート: つかみ。講座2のArtifactでも扱った「仕上がって見えても仮説」と同じ罠が、より大きな単位で来ます。 -->

---

## 結論

**タスクの完了は、成果物を自分で確認してから決めるもので、確認は自分の仕事です**

- **確認** — 成果物を開き、依頼した完了の形と見比べること
- **完了** — 確認を通ったと自分が判断した状態

<!-- ノート: 結論を先に言い切ります。作業が終わった、と、仕事が完了した、を区別します。後者を決めるのは自分です。 -->

---

## 確認の物差しは書いてある

```text
依頼      「列は 会社名・担当者・最終更新日。更新日が新しい順」
確認      列はそろっているか → 並び順は合っているか
          → 数本を元の資料と突き合わせて中身を見る
```

<!-- ノート: 最小の型です。M2で書いた完了の形が、そのまま確認の物差しになります。全数でなくても、抜き取りで中身まで見ます。 -->

---

## 作業の終わりと仕事の完了

| | 作業が終わった | 仕事が完了した |
| --- | --- | --- |
| 決める人 | Claude側の表示 | 自分 |
| 根拠 | 手順を終えた | 確認を通った |
| 次の行動 | 確認を始める | 提出・共有する |

<!-- ノート: 対比枠。責任を持つの実体がこの1枚です。表示は確認の開始合図であって、提出の許可ではありません。 -->

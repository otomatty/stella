# 3-1-4
# 途中で止めて直せる

Cowork入門 — Module 3 / レッスン3-1

<!-- ノート: 途中経過を見る意味の答え合わせです。見るだけでなく、手を入れられます。 -->

---

## なぜ必要か

- ずれに気づいても「最後まで待ってから直してもらうしかない」と思いがち
- ずれたまま走った分は、そのままやり直しの量になる

<!-- ノート: つかみ。止められると知らないと、見ていても意味がなくなります。ここで結論は言わない。 -->

---

## 結論

**ずれに気づいたら、タスクは途中で中断して、軌道修正してから続けられます**

- **中断** — 進んでいるタスクをいったん止めること
- **軌道修正** — 追いの指示で向きを直し、続きから進めてもらうこと

<!-- ノート: 結論を先に言い切ります。止める・直す・続ける、の3拍子です。最初からやり直しではありません。 -->

---

## 止めて直すの実際

```text
途中経過  一覧の会社名が略称のまま進んでいる
中断      いったん止める
軌道修正  「会社名は正式名称で。ここまでの分も直して」
続行      直した向きで続きが進む
```

<!-- ノート: 最小の例です。M2で学んだ追いの指示が、止めた場面で効きます。 -->

---

## 止めることは失敗ではない

| 思い込み | 実際 |
| --- | --- |
| 止めるのは任せ方の失敗 | ループの想定内の操作 |
| 直しは全部やり直し | ずれた分だけ直して続行 |
| 黙って最後まで待つのが礼儀 | 早い軌道修正ほど安い |

<!-- ノート: 対比枠。相手は人ではないので、途中で口を挟む遠慮は不要です。見極めて直すのは想定内の使い方です。 -->

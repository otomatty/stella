# 使えるのは渡した文脈だけ

Cowork入門 — Module 2 / レッスン2-1

<!-- ノート: ここからM2です。場所は決まりました。次は、そこに何を入れるかの話です。 -->

---

## なぜ必要か

- 社内の事情を知っている前提で頼んで、見当違いの結果を受け取る
- 「これくらい察してくれるだろう」が、まとまった作業では大きなずれになる

<!-- ノート: つかみ。チャットなら一往復で直せたずれが、任せる作業では終盤まで気づけません。ここで結論は言わない。 -->

---

## 結論

**Claudeが作業に使えるのは渡した文脈だけなので、要る材料は自分で選んで渡します**

- **文脈** — 作業の前提になる情報のまとまり。依頼の文章と渡した資料でできる
- **材料** — 文脈として渡す1つずつの情報。講座2で扱った語です

<!-- ノート: 結論を先に言い切ります。材料は復習なので1行で流します。見える範囲の話の続きで、範囲の中に入れた物だけが文脈になります。 -->

---

## 渡しているつもりのずれ

```text
頼んだこと   「いつもの形式で報告書にして」
渡した文脈   資料だけ(「いつもの形式」の見本なし)
結果         知らない形式で仕上がってくる
```

<!-- ノート: 最小の失敗例です。頭の中の「いつもの」は、渡さない限り文脈に入りません。 -->

---

## 作業前チェック

| 問い | やること |
| --- | --- |
| 前提を知らない人に渡して伝わるか | 依頼の文章に前提を書き足す |
| 見本・過去の例はあるか | ワークスペースに入れる |
| 社内だけの言葉を使っていないか | 一言の説明を添える |

<!-- ノート: 図解の代わりの実務チェックです。「新しく来た同僚に引き継ぐつもりで書く」が目安になります。 -->

# 2-1-4
# 足りない情報は途中で足す

Cowork入門 — Module 2 / レッスン2-1

<!-- ノート: M2の締めです。最初に全部を渡しきれなくても作業は壊れない、という話をします。 -->

---

## なぜ必要か

- 完璧な依頼を書こうとして、いつまでも任せ始められない
- 渡し漏れに気づいたとき、最初からやり直すしかないと思ってしまう

<!-- ノート: つかみ。M2をまじめに聞いた人ほど、書き切らないと出せない症状になります。その解毒です。 -->

---

## 結論

**足りない情報は、質問に答えるか追いの指示で、作業の途中からでも渡せます**

- **質問** — 進めるのに足りない情報を、Claudeの側から聞いてくること
- **追いの指示** — 進んでいる作業に、自分から書き足して渡す指示

<!-- ノート: 結論を先に言い切ります。渡す道が2つある、と覚えます。聞かれて答えるか、自分から足すかです。 -->

---

## 途中で渡す2つの道

```text
質問に答える   Claude「並び順の指定はありますか?」
               自分  「更新日が新しい順で」
追いの指示     自分  「会社名は正式名称に直して進めて」
```

<!-- ノート: 最小の例です。どちらも作業を最初からやり直さず、途中から文脈が増えます。 -->

---

## 最初に書くことと後で足すこと

| | 最初の依頼に書く | 途中で足せばよい |
| --- | --- | --- |
| 内容 | 完了の形・できの基準 | 細部の選択・例外の扱い |
| 理由 | 作業全体の向きを決める | 進んでから見えてくる |

<!-- ノート: 対比枠。向きを決める情報だけは最初に書く。細部は途中で足せる。この線引きで「書き切れないから出せない」がなくなります。 -->

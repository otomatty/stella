# プラグインは道具を足す仕組み

Cowork入門 — Module 4 / レッスン4-1

<!-- ノート: ここからM4です。頼める作業の幅を広げる仕組みの話をします。設定手順は扱いません。 -->

---

## なぜ必要か

- 「この形の作業も頼めるのか」を判断する物差しがない
- 頼めないと思い込んで手作業を続けたり、逆に何でも頼めると思って空振りしたりする

<!-- ノート: つかみ。M4の学習対象は設定ではなく「どの作業をどれに頼むか」の判断です。 -->

---

## 結論

**プラグインは、Coworkに作業向けの道具を足して、頼める幅を広げる仕組みです**

- **道具** — 特定の種類の作業をこなすための機能のまとまり
- **プラグイン** — その道具をCoworkに後から足す仕組み

<!-- ノート: 結論を先に言い切ります。スマホにアプリを足す感覚が近いたとえです。本体の頼み方は変わらず、頼める幅が広がります。 -->

---

## 道具で広がる作業の例

```text
調べもの     Webの情報を集めて比べる
文書づくり   決まった体裁のファイルに仕上げる
画面の作業   Webの画面を開いて進める
```

<!-- ノート: この3つの用途を、次のトピックから1つずつ扱います。ここでは「幅が広がる」だけ覚えれば十分です。 -->

## 学ぶのは設定ではなく選び方

| | このモジュールで扱う | 扱わない |
| --- | --- | --- |
| 内容 | どの作業をどの道具に頼むか | 導入手順・設定画面 |

# 任せても判断は自分に残る

Cowork入門 — Module 0 / レッスン0-1

<!-- ノート: M0の締めです。まとめて任せると聞いて「全部おまかせ」と誤解したまま先へ進まないように、ここで釘を刺します。 -->

---

## なぜ必要か

- 「任せられる」と聞くと、渡したら終わりに聞こえる
- 仕上がりをそのまま提出して、間違いごと出してしまう事故が起きる

<!-- ノート: つかみ。便利さの話の直後だからこそ、この誤解が生まれやすいタイミングです。ここで結論は言わない。 -->

---

## 結論

**任せて進める作業でも、4Dの伝える・見極める・責任を持つは自分の仕事のままです**

- **4D** — AIと働くときの4つの判断。講座1で扱った枠組みです
- **任せる** / **伝える** / **見極める** / **責任を持つ** — 何を渡すか決め、望みを書き、結果を確かめ、出したものに責任を持つ

<!-- ノート: 結論を先に言い切ります。4Dは講座1の復習なので一覧1枚に収めます。個々の中身はこの講座のM2以降で実践します。 -->

---

## Coworkで4Dはこう現れる

```text
任せる      → どの作業を渡すか決める(この講座の主役)
伝える      → 依頼に完了の形を書く(M2)
見極める    → 途中と仕上がりを確かめる(M3)
責任を持つ  → 出す前の最終判断は自分(M5)
```

<!-- ノート: この講座の地図を兼ねた例です。Coworkが肩代わりするのは手を動かす部分で、4つの判断はどれも残ります。 -->

---

## 変わるもの・変わらないもの

| | チャットのとき | Coworkのとき |
| --- | --- | --- |
| 手を動かす量 | 自分に多く残る | 大きく減る |
| 4つの判断 | 自分の仕事 | 自分の仕事のまま |

<!-- ノート: 対比枠。減るのは作業で、判断は減りません。むしろ渡す量が増えるぶん、見極めの重みは増します。 -->

# レッスン0-1 チャットの先へ

## このレッスンの目標

- [ ] Coworkが何のための製品かを説明できる
- [ ] チャットとCoworkの「渡す単位」の違いを説明できる
- [ ] 任せても自分に残る判断を挙げられる

## 0-1-1 Coworkはまとめて任せる場

> **Coworkは、まとまった作業をClaudeに任せて仕上がりを受け取るための製品です**

講座2までで、**Claude** に文章で仕事を頼むやり方を扱いました。チャットは相談や短い成果物には十分に働きます。一方で、実務の時間を埋めているのは、別の形の仕事です。フォルダにたまった資料の整理、問い合わせ履歴の分類、報告書のとりまとめ。答えが出ないのではなく、回すのが重い仕事です。

チャットでこれを進めると、貼って、受け取って、また貼るという受け渡しの係が自分に残ります。**Cowork** は、この形を変えるための製品です。作業のまとまりを渡すと、Claudeが複数のステップを進め、自分は仕上がりを受け取って確かめます。

頼める作業のイメージは次のとおりです。

```text
フォルダの資料30本  → 同じ体裁の一覧に整理してもらう
問い合わせの履歴    → 種類ごとに分類してまとめてもらう
報告書の下書き      → 材料から章ごとに起こしてもらう
```

3つに共通するのは、1回の質問では終わらない、複数ステップの**作業**だという点です。

| | チャット | Cowork |
| --- | --- | --- |
| 得意な形 | 相談・短い成果物 | 複数ステップの作業 |
| 自分の役割 | 毎回読んで返す | 任せて仕上がりを見る |
| 終わり方 | 返答をもらって終わる | 作業が終わって終わる |

Coworkはチャットの上位版ではありません。扱う仕事の形が違う、別の入り口です。

## 0-1-2 渡す単位が変わる

> **チャットは一往復ずつ、Coworkは作業のまとまりを依頼として渡して進めてもらいます**

違いを一言にすると、渡す単位です。

チャットの単位は **往復** です。自分が書き、返ってきたものを読む。この1回ぶんのやり取りを重ねて進みます。大きな作業をこの単位で運ぶと、細切れの質問を何十回も繰り返すことになり、自分が席を離れるとそこで作業ごと止まります。

Coworkの単位は作業のまとまりです。**依頼** の書き方そのものは講座2の型と同じで、何をしてほしいかを文章で書きます。変わるのは大きさです。

```text
チャット: 1本目を貼る → 直しを受け取る → 2本目を貼る → …(×30回)
Cowork:  「30本を同じ体裁に整理」とまとめて依頼 → 進んだ結果を受け取る
```

まとめて渡すと、途中の受け渡しをClaudeの側が進めるため、自分の時間の使い方が変わります。

| | 一往復ずつ | まとまりで任せる |
| --- | --- | --- |
| 自分がやること | 毎回の受け渡し | 依頼と受け取り |
| 待ち時間 | 画面に張り付く | 他の仕事に使える |
| 向く仕事 | 短い相談 | 複数ステップの作業 |

逆に言うと、一言で済む相談をわざわざまとまりに仕立てる必要はありません。単位の小さい仕事は、チャットのほうが早く終わります。

## 0-1-3 任せても判断は自分に残る

> **任せて進める作業でも、4Dの伝える・見極める・責任を持つは自分の仕事のままです**

「まとめて任せられる」と聞くと、渡したら終わりのように聞こえます。この誤解のまま使うと、仕上がりをそのまま提出して、間違いごと外に出す事故につながります。

講座1で扱った **4D** を思い出してください。**任せる**(何を渡すか決める)、**伝える**(望みを書く)、**見極める**(結果を確かめる)、**責任を持つ**(出したものに責任を持つ)の4つです。Coworkが肩代わりするのは手を動かす部分で、この4つの判断はどれも自分に残ります。

この講座は、4Dを複数ステップの作業の上で実践する講座だと言えます。

```text
任せる      → どの作業を渡すか決める(この講座の主役)
伝える      → 依頼に完了の形を書く(M2)
見極める    → 途中と仕上がりを確かめる(M3)
責任を持つ  → 出す前の最終判断は自分(M5)
```

| | チャットのとき | Coworkのとき |
| --- | --- | --- |
| 手を動かす量 | 自分に多く残る | 大きく減る |
| 4つの判断 | 自分の仕事 | 自分の仕事のまま |

渡す量が増えるぶん、見極めの重みはむしろ増します。ここから先のモジュールは、この判断を1つずつ道具にしていきます。

## もっと知りたい人へ

- 自分の直近1週間から「回すのが重かった仕事」を1つ思い出してください。それがこの講座でCoworkに任せる候補になります
- 製品の画面や名称は変わっていきます。実際に使うときは、製品のドキュメントで確認してください
- 依頼の書き方の型(成果物・できの基準)は講座2(Claude チャット入門)で扱っています。心もとない場合は先に戻ると、M2がつながりやすくなります

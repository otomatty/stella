## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「npm でパッケージを導入し、ビルドツールで開発サーバーと本番ビルドを動かせる」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- npm と package.json
- 依存パッケージの追加と更新
- セマンティックバージョニング
- Vite で開発サーバーと本番ビルド
- リンター・フォーマッターなどの開発ツール

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

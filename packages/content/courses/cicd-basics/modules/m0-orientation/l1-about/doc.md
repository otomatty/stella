## このレッスンの目標

- [ ] この講座がスキルツリーのどこにあり、何を学ぶ場所なのかを知る

## 0-1-1 この講座で学ぶこと

> **この講座は準備中で、公開されると「ビルド・テスト・デプロイをパイプラインに載せ、失敗を段階で切り分けられる」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- パイプラインの段階 (build / test / deploy)
- GitHub Actions のワークフロー
- 成果物と環境への出し分け
- 失敗したジョブの切り分け
- シークレットをワークフローに書かない

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

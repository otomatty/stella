> **この講座は準備中で、公開されると「fetch で Web API からデータを取得し、非同期処理の流れを自分のことばで説明できる」ようになる**

この講座はまだ準備中です。教材が公開されると、次の内容を学べるようになります。

- Promise と async/await の復習
- fetch で GET / POST を呼ぶ

- ローディングと失敗時の画面づくり
- CORS のきほん

公開までの間は、前提講座の内容を復習しておくと、スムーズに始められます。

## 効く列と効かない列

```text
効きやすい   customer_id … WHERE や JOIN でよく使い、よく絞れる
             created_at  … 期間で絞ることが多い

効きにくい   is_active   … 値が2種類しかなく、半分が該当する
             めったに検索しない列
```

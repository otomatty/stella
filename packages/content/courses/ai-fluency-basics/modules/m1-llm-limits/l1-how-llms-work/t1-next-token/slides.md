## なぜ必要か

- 返ってくる文章が自然なので、中で何が起きているか気にせず使ってしまう
- 外したときに、なぜ外したのかを説明できない

## 結論

**LLM(大規模言語モデル)は、次に来るトークンを確率で選び続けて出力を作ります**

- **LLM** — 大規模言語モデルの略。生成AIの中身にあたる仕組み
- **モデル** — 大量の文章から学んだパターンを持つ本体
- **トークン** — 文章を細かく区切った単位
- **出力** — AIが返してくる文章

<!-- ノート: 結論を先に言い切る。4つの語をここで定義します。以降の講座はすべてこの語で話します。 -->

## 何をしているか

```text
入力: 「今日はいい」
候補: 「天気」…高い / 「一日」…中くらい / 「魚」…低い
選ぶ: 「天気」
→ 選んだぶんを足して、また次の候補を出す
```

<!-- ノート: これを繰り返しているだけです。1回ごとに次の1つを選び、選んだものを含めてまた次を選びます。 -->

## 思いがちな姿 vs 実際

| 思いがちな姿 | 実際 |
| --- | --- |
| 意味を理解して答えている | 次のトークンを確率で選んでいる |
| 正しい答えを探してきている | それらしい続きを作っている |
| 分からなければ黙る | 続きは常に作れてしまう |

# レッスン4-1 Discernment: 出力を見極める

## このレッスンの目標

- [ ] 出力を仮説として読み、確かめる箇所を挙げられる
- [ ] 事実にあたる部分を出典で裏取りできる
- [ ] ずれを言葉にして差し戻し、確かめる深さを影響範囲で決められる

## 4-1-1 出力は答えではなく仮説

> **AIの出力は確定した答えではなく、これから確かめる仮説として読みます**

このレッスンから 4D の3つ目、**Discernment(見極める)** に入ります。返ってきたものをどう読むか、という話です。

迷いのない文章で返ってきたので、そのままレビューに出しました。指摘されて見直したら、存在しないメソッドを呼んでいました。よくある事故です。ここで大事なのは、幻覚は **読み手を疑わせない文体でやってくる** ことです。書きぶりからは判別できません。

そこで、読み方の構えを変えます。出力は **仮説** として読みます。仮説とは、まだ確かめていない、確からしい候補のことです。

読み方が変わると、頭に浮かぶ言葉が変わります。

- 答えとして読む: 「なるほど、これでいこう」
- 仮説として読む: 「これが正しいなら、何を見れば確かめられるか」

後者の利点は、**次にやることが自動的に決まる** ことです。読んだ時点で、確かめる作業が並びます。

| 見えるもの | 答えとして読むと | 仮説として読むと |
| --- | --- | --- |
| 断定的な言い回し | 安心する | 確かめる対象が増える |
| もっともらしい名前 | 見過ごす | 実在するか確かめる |

これは「AI を信じるな」という話ではありません。出力の自信の強さが正しさの手がかりにならない以上、**別の手がかりで確かめる** しかない、というだけの話です。

## 4-1-2 事実は出典で裏を取る

> **数値や固有名詞のような事実は、出典に当たって裏取りしてから使います**

仮説として読む構えができたら、次は優先順位です。全部を同じように確かめる時間はありません。

まず語を2つ置きます。

- **出典** — その事実が書いてある元の資料
- **裏取り** — 出典に当たって、事実かどうかを確かめること

優先して裏取りするのは、次のようなものです。

- 関数名・設定項目名・オプション名
- バージョン番号、日付、金額、割合
- 規格や法令の名称と条番号
- 知識の切れ目より後に変わった可能性のある仕様

共通しているのは、**間違っていても文章として自然に読める** ことです。「そんな設定項目は無い」と気づけるのは、実際に資料や画面を見たときだけです。逆に、考え方や設計の方針といった部分は、読んだ人が自分の頭で妥当性を判断できます。裏取りが最優先なのは前者です。

揺らぎも手がかりに使えます。同じことを2回聞いて答えが変わったら、それは覚えている事実ではなく、その場で作られた候補である合図です。揺らぎは欠点として捉えられがちですが、**裏取りの優先度を決める材料** として使えます。

## 4-1-3 ずれは言葉にして差し戻す

> **出力が期待とずれたら自分で直す前に、ずれた点を伝えて差し戻します**

確かめてずれが見つかったあと、多くの人が無意識に損をしています。惜しい出力が返ってきたので、自分で手直しして提出した。次に同じことを頼んだら、また同じずれ方をした、という進み方です。

ここでやることが **差し戻し** です。差し戻しとは、ずれた点を言葉にして伝え、直したものを出し直してもらうことです。

書き方には強弱があります。

- 弱い: 「違います。書き直して」
- 強い: 「3つ目の見出しが、できの基準の『非エンジニア向け』から外れています。専門用語を平易な言い換えに直してください」

強い差し戻しには、**どこが・どの基準から・どう外れたか** の3点が入っています。この3点が書ければ、たいていの差し戻しは通ります。

差し戻しの本当の効き目は、その場の直しではありません。

| | 自分で直す | 差し戻す |
| --- | --- | --- |
| その場 | 速い | 一往復かかる |
| 次回 | 同じずれが出る | 依頼を直せる |
| 記録 | 頭の中だけ | 文として残る |

ずれた点を言葉にすると、自分の依頼のどこが足りなかったのかも見えます。差し戻しは、相手のための作業ではなく **次の依頼を良くするための作業** です。同じ依頼を何度も出す仕事ほど、効いてきます。

## 4-1-4 確かめる深さは影響範囲で決める

> **確かめる深さは、その出力が間違ったときの影響範囲の大きさで決めます**

ここまでの話をすべての出力に同じ強さで適用すると、疲れて続きません。自分用のメモにまで出典を当たって時間が溶け、その反動で顧客に出す資料を流し読みで通してしまいます。

そこで、**影響範囲** で深さを決めます。影響範囲とは、その間違いが届いてしまう相手の広さのことです。

| 影響範囲 | 例 | 確かめる深さ |
| --- | --- | --- |
| 自分だけ | 調べ物のメモ | ざっと読む |
| チーム | 設計の案、レビュー | 事実だけ裏取り |
| 顧客・本番 | 提出資料、本番の変更 | 全部を1つずつ確かめる |

払う検証コストを、影響範囲に見合う分だけにする、という配分の話です。丁寧さの総量を増やす話ではありません。

判断を誤りやすいのは、途中で段が変わる場面です。

- 自分用に作ったつもりのメモを、そのまま共有してしまう
- 「たたき台だから」と言いながら、内容を確かめずに顧客へ回す

どちらも、作ったときの影響範囲のまま出しています。**出す先が変わったら、確かめ直す** のが原則です。

## もっと知りたい人へ

- 裏取りの手間を減らすには、確かめる先をあらかじめ決めておくのが有効です。よく使う技術の公式資料や社内の規約ページをブックマークしておくと、確認が数十秒で終わります
- 差し戻しの文は、そのまま次回の依頼に足せる材料になります。何度も同じ差し戻しをしているなら、その内容はできの基準として先に渡すべきものです

# アロー関数は=>で短く書く

JavaScript入門 — Module 6 / レッスン6-2

## なぜ必要か

- コールバックのたびに `function` と書くのは長い
- 実務のコードは、ほぼ全部もっと短い記法で書かれている
- 読めないと、世の中のサンプルコードが読めない

<!-- ノート: つかみ。検索して出てくるコードがfunctionで書かれていない、という現実から入ります。 -->

---

## 結論

**アロー関数は、無名関数を=>で短く書ける書き方**

- `(引数) => { 処理 }` の形。**=>** が矢印(アロー)
- 処理が1つの式だけなら `{}` と `return` も省略できる

<!-- ノート: 結論。「functionの代わりに=>」とまず変換規則として覚えます。 -->

---

## 最小のコード

```js
const numbers = [1, 2, 3];
numbers.forEach((n) => {
  console.log(n * 10);
});
// => 10 20 30
```

<!-- ノート: 前トピックのfunction版と全く同じ動きです。差分だけ見せます。 -->

---

## 省略形まで読めるように

```js
const taxIncluded = (price) => price * 1.1;
console.log(taxIncluded(1980));  // => 2178
```

- `{}` が無い形は「その式の値をreturnする」の意味
- 引数が1つのときは `()` を省く書き方もある: `price => ...`

<!-- ノート: 関連枠。書くときは()ありで統一し、()なしは読解対象としておく、が迷わない方針です。 -->

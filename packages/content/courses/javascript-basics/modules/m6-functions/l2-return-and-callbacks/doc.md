# レッスン6-2 戻り値とコールバック

## このレッスンの目標

- [ ] returnで値を返す関数を書け、早期リターンを使える
- [ ] 無名関数・アロー関数を読める・書ける
- [ ] mapとfilterで配列を加工できる

## 6-2-1 returnで結果を返す

> **returnで返した値は、呼び出した場所の値になる**

前レッスンの関数は結果を表示することしかできませんでした。スコープのルールにより中の変数は外から見えないので、結果を外へ持ち出す出口が要ります。それが **return** です。

```js
function taxIncluded(price) {
  return price * 1.1;
}
const total = taxIncluded(1980) + 200;
console.log(total);  // => 2378
```

`return 値;` で関数から値を返します。返ってきた値を **戻り値** といい、`taxIncluded(1980)` と書いた場所そのものが戻り値に置き換わります。だから足し算にも代入にも混ぜられます。

`console.log` する関数は結果をその場で消費してしまいますが、`return` する関数は結果を自由に使い回せます。実務では「**計算はreturnで返し、表示は呼び出し側でやる**」という分担が基本形です。

## 6-2-2 returnは関数をそこで終える

> **returnした時点で関数は終わり、後ろの行は実行されない**

returnには「値を返す」に加えてもう1つの顔があります。**関数をそこで終える**ことです(ループのbreakの関数版と考えると覚えやすいです)。

この性質を使うと、条件外のケースを冒頭で返して終える書き方ができます。これを **早期リターン** といいます。

```js
function buildGreeting(name) {
  if (name === "") {
    return "名前が未入力です";
  }
  return `${name}さん、ようこそ`;
}
console.log(buildGreeting(""));  // => 名前が未入力です
```

空文字のときは最初のreturnで関数が終わり、下の行には到達しません。だから2つ目のreturnを `else` で包む必要がありません。「チェックして早期リターン → 残りは正常なケースだけ」という並びは、ifの入れ子を浅く保つ実務の定番スタイルです。

## 6-2-3 名前のない関数をその場で書ける

> **関数は名前を付けずに書いて、値として引数に渡せる**

ここから大きな一歩です。関数は、数値や文字列と同じ「値」として扱えます。つまり **引数として渡せます**。

- 名前のない関数を **無名関数** といいます
- 引数として渡され、あとで呼ばれる関数を **コールバック** といいます

```js
const numbers = [1, 2, 3];
numbers.forEach(function (n) {
  console.log(n * 10);
});
// => 10 20 30
```

`forEach` は「各要素に対して、渡された関数を呼ぶ」メソッドです(for...ofのメソッド版)。渡しているのは `function (n) {...}` という値そのものです。

注意すべきはカッコの有無です。

```js
function show(n) { console.log(n); }
numbers.forEach(show());  // 間違い: 実行した結果を渡している
numbers.forEach(show);    // 正しい: 関数そのものを渡す
```

`()` を付けると「今すぐ実行」、付けなければ「関数という値」です。この違いは次のモジュールのイベント登録でも定番のつまずきになります。

## 6-2-4 アロー関数は=>で短く書く

> **アロー関数は、無名関数を=>で短く書ける書き方**

コールバックのたびに `function` と書くのは長く、実務のコードやWeb上のサンプルはほぼ **アロー関数** で書かれています。読めないと世の中のコードが読めません。

```js
const numbers = [1, 2, 3];
numbers.forEach((n) => {
  console.log(n * 10);
});
```

`(引数) => { 処理 }` の形で、**=>** が矢印(アロー)です。前トピックのfunction版とまったく同じ動きです。

処理が1つの式だけなら、`{}` と `return` を省略できます。

```js
const taxIncluded = (price) => price * 1.1;
console.log(taxIncluded(1980));  // => 2178
```

`{}` の無い形は「その式の値をreturnする」という意味です。引数が1つのときは `()` を省く書き方(`price => ...`)もあります。自分で書くときは `()` ありに統一し、省略形は読解できれば十分です。

## 6-2-5 mapとfilterで配列を加工する

> **mapは各要素を変換した配列を、filterは条件に合う要素だけの配列を作る**

「全価格を税込にした配列がほしい」「在庫ありだけに絞りたい」 — for...ofと空配列とpushでも書けますが、「変換」と「絞り込み」には専用のメソッドがあります。どちらもコールバックを受け取ります。

```js
const prices = [1000, 2000, 3000];
const withTax = prices.map((p) => p * 1.1);
console.log(withTax);  // => [1100, 2200, 3300]
```

**map** は各要素をコールバックに通し、その戻り値で新しい配列を作ります。

```js
const stocks = [0, 12, 3, 0, 8];
const inStock = stocks.filter((s) => s > 0);
console.log(inStock);  // => [12, 3, 8]
```

**filter** はコールバックがtrueを返した要素だけの新しい配列を作ります。

| メソッド | 個数 | 中身 |
| --- | --- | --- |
| `map` | そのまま | 変換される |
| `filter` | 減りうる | そのまま |

どちらも新しい配列を返し、元の配列は変わりません(push/popとの違いです)。

## もっと知りたい人へ

- mapとfilterはつなげて書けます: `prices.filter((p) => p >= 1000).map((p) => p * 1.1)`
- 集計(合計・最大)には `reduce` というメソッドもあります。読み方が独特なので、必要になったときに調べれば十分です

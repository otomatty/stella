## 結論

**mapは各要素を変換した配列を、filterは条件に合う要素だけの配列を作る**

- **map**(関数) — 各要素を関数に通した結果で新しい配列を作る
- **filter**(関数) — 関数がtrueを返した要素だけの新しい配列を作る

<!-- ノート: 結論。どちらも「新しい配列を返す」(元は変わらない)点も添えます。 -->

---

## 最小のコード

```js
const prices = [1000, 2000, 3000];
const withTax = prices.map((p) => p * 1.1);
console.log(withTax);  // => [1100, 2200, 3300]
```

<!-- ノート: 渡したアロー関数が要素の数だけ呼ばれ、戻り値が新しい配列に並ぶ、という流れを追います。 -->

---

## filterは真偽値で選ぶ

```js
const stocks = [0, 12, 3, 0, 8];
const inStock = stocks.filter((s) => s > 0);
console.log(inStock);  // => [12, 3, 8]
```

- コールバックの戻り値がtrueの要素だけ残る

<!-- ノート: 対比枠。mapは個数そのまま・中身が変わる、filterは中身そのまま・個数が減る、という対比で締めます。 -->

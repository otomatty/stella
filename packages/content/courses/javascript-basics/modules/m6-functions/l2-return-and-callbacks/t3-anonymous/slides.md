# 6-2-3
# 名前のない関数をその場で書ける

JavaScript入門 — Module 6 / レッスン6-2

<!-- ノート: 「関数も値」という抽象度の高い一歩です。イベント(M7)とmap/filterの前提になります。 -->

---

## なぜ必要か

- 「この処理を、あとで実行してほしい」と頼みたい場面がある
- 頼む相手に渡すのは、実行した結果ではなく「処理そのもの」
- 一度しか使わない処理に、いちいち名前を付けたくない

<!-- ノート: つかみ。「クリックされたときにやってほしいこと」を予約するイメージを先に見せます(M7の布石)。 -->

---

## 結論

**関数は名前を付けずに書いて、値として引数に渡せる**

- 名前のない関数を **無名関数** という
- 引数として渡され、あとで呼ばれる関数を **コールバック** という

<!-- ノート: 結論。関数が数値や文字列と同じ「値」の仲間になる瞬間です。 -->

---

## 最小のコード

```js
const numbers = [1, 2, 3];
numbers.forEach(function (n) {
  console.log(n * 10);
});
// => 10 20 30
```

- `forEach` は「各要素に対して、渡された関数を呼ぶ」メソッド

<!-- ノート: forEachはfor...ofのメソッド版として紹介。渡しているのがfunction(n){...}という値そのものだと指差します。 -->

---

## 「実行して渡す」ではない

```js
function show(n) { console.log(n); }
numbers.forEach(show());  // 間違い: 実行した結果を渡している
numbers.forEach(show);    // 正しい: 関数そのものを渡す
```

- `()` を付けると「今すぐ実行」。付けなければ「関数という値」
- 名前のある関数も、名前だけ書けば値として渡せる

<!-- ノート: 失敗例枠。カッコの有無の違いは、この後のaddEventListenerでも定番のつまずきです。 -->

# 6-2-1
# returnで結果を返す

JavaScript入門研修 — Module 6 / レッスン6-2

<!-- ノート: console.logする関数から、値を返す関数への転換点です。 -->

---

## なぜ必要か

- 前レッスンの関数は、結果を表示することしかできない
- 計算結果を「表示」ではなく「次の計算に使いたい」
- 関数の中の結果を、外へ持ち出す出口が要る

<!-- ノート: つかみ。スコープ(6-1-3)で「中の変数は見えない」と学んだ直後なので、出口の必要性が伝わりやすいはずです。 -->

---

## 結論

**returnで返した値は、呼び出した場所の値になる**

- **return** 値; で関数から値を返す
- 返ってきた値を **戻り値** という。呼び出しの式がその値になる

<!-- ノート: 結論。「greet("佐藤")と書いた場所が、値に置き換わる」という言い方が伝わります。 -->

---

## 最小のコード

```js
function taxIncluded(price) {
  return price * 1.1;
}
const total = taxIncluded(1980) + 200;
console.log(total);  // => 2378
```

<!-- ノート: 戻り値だから足し算に混ぜられる。console.logしかしない関数との違いを対比します。 -->

---

## 表示する関数・返す関数

- `console.log` する関数 → 結果はその場で消費される
- `return` する関数 → 結果を代入・計算・表示に自由に使える
- 迷ったら **返す** 関数にしておく方が使い回しやすい

<!-- ノート: 対比枠。実務では「計算はreturn、表示は呼び出し側」という分担が基本形です。 -->

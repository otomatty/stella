# 6-1-1
# 関数は処理に名前を付ける

JavaScript入門 — Module 6 / レッスン6-1

<!-- ノート: 変数は「値に名前」、関数は「処理に名前」。この対で導入します。 -->

---

## なぜ必要か

- 同じ3行の処理を、あちこちに何度も書いている
- 直すとなったら、全部の場所を直して回ることになる
- 「処理のかたまり」を1か所にまとめて、使い回したい

<!-- ノート: つかみ。コピペで増えた同じ処理の修正漏れ、という実務の事故から入ります。 -->

---

## 結論

**functionで処理をまとめて名前を付け、名前()で何度でも呼び出せる**

- 処理に名前を付けたものが **関数**。作ることを **定義** という
- 実行させることを **呼び出し** といい、`名前()` と書く

<!-- ノート: 結論。変数の宣言と対比しながら、定義・呼び出しの2語を入れます。 -->

---

## 最小のコード

```js
function showWelcome() {
  console.log("ようこそ");
  console.log("本日もよろしくお願いします");
}
showWelcome();
showWelcome();
```

<!-- ノート: 定義しただけでは実行されず、呼び出して初めて動く。ここが最初のつまずきポイントです。 -->

---

## 定義しただけでは動かない

- **function** の定義は「手順書の登録」。その場では実行されない
- 呼び出しの `()` があって初めてブロックが実行される
- 手順書は1つ、呼び出しは何度でも

<!-- ノート: 図解の代わりの整理。「登録」と「実行」の2段階を、料理のレシピと調理に例えます。 -->

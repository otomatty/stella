# 6-1-2
# 引数で値を渡す

JavaScript入門 — Module 6 / レッスン6-1

<!-- ノート: 関数を「値を受け取る機械」にするトピックです。 -->

---

## なぜ必要か

- 挨拶の関数は作れたが、毎回「ようこそ」しか言えない
- 「佐藤さんへ」「鈴木さんへ」と、相手を変えて使いたい
- 呼び出すたびに、材料を差し込める口が要る

<!-- ノート: つかみ。定型文の宛名部分だけ変えたい、という2-1-2と同じ欲求が関数にも出てきます。 -->

---

## 結論

**引数を使うと、呼び出すたびに違う値を関数へ渡せる**

- 呼び出し時に渡す値を **引数** という
- 受け取る側の変数を **仮引数** といい、`()` の中に書く

<!-- ノート: 結論。渡す側と受け取る側で呼び名が変わりますが、まず「引数」の一語で通じれば十分です。 -->

---

## 最小のコード

```js
function greet(name) {
  console.log(`${name}さん、ようこそ`);
}
greet("佐藤");  // => 佐藤さん、ようこそ
greet("鈴木");  // => 鈴木さん、ようこそ
```

<!-- ノート: nameが仮引数、"佐藤"が引数。呼び出しごとにnameの中身が変わることを確認します。 -->

---

## 引数は複数持てる

```js
function showTotal(price, quantity) {
  console.log(`合計: ${price * quantity}円`);
}
showTotal(1980, 3);  // => 合計: 5940円
```

- カンマで並べる。渡す順番と受け取る順番が対応する

<!-- ノート: 関連枠。順番の対応(1つ目→price)が全てです。順番を間違えるバグは静かに起きる、と一言。 -->

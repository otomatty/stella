# レッスン6-1 関数を定義する

## このレッスンの目標

- [ ] functionで関数を定義し、呼び出せる
- [ ] 引数で値を渡す関数を書ける
- [ ] スコープ(変数が見える範囲)を説明できる

## 6-1-1 関数は処理に名前を付ける

> **functionで処理をまとめて名前を付け、名前()で何度でも呼び出せる**

同じ3行の処理をあちこちにコピペしていると、直すときに全部の場所を直して回ることになり、修正漏れが事故になります。変数が「値に名前を付ける」仕組みだったのに対し、「処理のかたまりに名前を付ける」仕組みが **関数** です。

```js
function showWelcome() {
  console.log("ようこそ");
  console.log("本日もよろしくお願いします");
}
showWelcome();
showWelcome();
```

- 関数を作ることを **定義** といい、**function 名前() { 処理 }** の形で書きます
- 実行させることを **呼び出し** といい、`名前()` と書きます

大事なのは、**定義しただけでは実行されない**ことです。定義は「手順書の登録」で、呼び出しの `()` があって初めてブロックの中が実行されます。レシピを書いても料理は出てこない、作るのは注文(呼び出し)が入ったとき、というイメージです。手順書は1つ、呼び出しは何度でもできます。

## 6-1-2 引数で値を渡す

> **引数を使うと、呼び出すたびに違う値を関数へ渡せる**

挨拶の関数は作れましたが、毎回同じ文しか言えません。「佐藤さんへ」「鈴木さんへ」と相手を変えて使うには、呼び出すたびに材料を差し込める口が要ります。

```js
function greet(name) {
  console.log(`${name}さん、ようこそ`);
}
greet("佐藤");  // => 佐藤さん、ようこそ
greet("鈴木");  // => 鈴木さん、ようこそ
```

- 呼び出し時に渡す値(`"佐藤"`)を **引数** といいます
- 受け取る側の変数(`name`)を **仮引数** といい、定義の `()` の中に書きます

引数は複数持てます。カンマで並べ、**渡す順番と受け取る順番が対応します**。

```js
function showTotal(price, quantity) {
  console.log(`合計: ${price * quantity}円`);
}
showTotal(1980, 3);  // => 合計: 5940円
```

順番を間違えて渡してもエラーにはならず、静かに間違った結果になります(論理エラー)。引数が増えてきたら、名前と順番をよく確かめてください。

## 6-1-3 関数の中の変数は外から見えない

> **関数の中で宣言した変数は、その関数の中でしか使えない**

関数の中で作った変数を外で使おうとすると、エラーになります。

```js
function calcTotal() {
  const total = 1980 * 3;
  console.log(total);   // ここでは使える
}
calcTotal();
console.log(total);      // エラー: total is not defined
```

変数が見える範囲を **スコープ** といい、関数の中で宣言した変数(**ローカル変数**)のスコープはその関数の中だけです。

これは不便ではなく安全装置です。別の関数で同じ名前 `total` を使っても衝突しませんし、関数の中の作業用変数が外の世界を汚しません。

なお、関数の外で宣言した変数は関数の中からも見えます。ただし、外の変数に頼った関数は単体で読めなくなり再利用もしにくいので、**材料は引数で渡す**のが読みやすい関数の基本形です。

## もっと知りたい人へ

- `if` や `for` の `{}` にもスコープがあります(constやletはブロックの中だけで見える)。「{}の中で宣言したものは、その{}の中だけ」と覚えておけば一貫します
- 仮引数に既定の値を持たせる書き方(`function greet(name = "ゲスト")`)もあります。引数を省略して呼ばれたときの備えに使います

# ifは条件が真のときだけ実行する

JavaScript入門 — Module 4 / レッスン4-1

## なぜ必要か

- 「在庫が少なければ発注する」— 実務の処理は状況で変わる
- ここまでのコードは、毎回すべての行が実行されていた
- 「実行する・しない」を切り替える仕組みが要る

<!-- ノート: つかみ。判定(比較演算子)は学んだので、あとは判定結果で動きを変えるだけです。 -->

---

## 結論

**ifは、()の条件がtrueのときだけ{}の中を実行する**

- 実行するかを決める式を **条件** という
- `{}` で囲んだひとかたまりを **ブロック** という

<!-- ノート: 結論。条件・ブロックという語はループや関数でも使い続けます。 -->

---

## 最小のコード

```js
const stock = 3;
if (stock < 10) {
  console.log("在庫が少なくなっています");
}
```

- stockが10未満のときだけメッセージが出る

<!-- ノート: stockを15に変えると何も出ない、を実演します。「何も起きない」も正しい動作です。 -->

---

## 形を分解する

```text
if (条件) {
  条件がtrueのときだけ実行される行
}
```

- 条件には比較演算子の式がそのまま入る
- ブロックの中は、読みやすさのため字下げする

<!-- ノート: 図解の代わりの形の整理。1-2-3の「比較の結果は真偽値」がここで回収されます。 -->

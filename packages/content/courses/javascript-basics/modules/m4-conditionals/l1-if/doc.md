# レッスン4-1 ifで分ける

## このレッスンの目標

- [ ] if / else if / elseで処理を分岐できる
- [ ] && / || / !で条件を組み合わせられる
- [ ] truthy / falsyの条件を読める

## 4-1-1 ifは条件が真のときだけ実行する

> **ifは、()の条件がtrueのときだけ{}の中を実行する**

「在庫が少なければ発注する」 — 実務の処理は状況によって変わります。ここまでのコードは毎回すべての行が実行されていましたが、**if** を使うと「実行する・しない」を切り替えられます。

```js
const stock = 3;
if (stock < 10) {
  console.log("在庫が少なくなっています");
}
```

- 実行するかを決める式を **条件** といいます。レッスン1-2の比較演算子の式がそのまま入ります
- `{}` で囲んだひとかたまりを **ブロック** といいます。条件がtrueのときだけ、中の行が実行されます

stockが15なら何も出ません。「何も起きない」も正しい動作です。ブロックの中は読みやすさのために字下げ(インデント2スペース)します。

## 4-1-2 elseとelse ifで道を分ける

> **elseは条件が偽のときの道、else ifは条件を足した道を作る**

「在庫があれば表示、なければ入荷待ち」のように道が分かれることを **分岐** といいます。ifだけでは「そうでないとき」が書けないので、**else** と **else if** を組み合わせます。

```js
const stock = 3;
if (stock === 0) {
  console.log("入荷待ち");
} else if (stock < 10) {
  console.log("残りわずか");
} else {
  console.log("在庫あり");
}
```

- **else if** — 追加の条件付きの道。いくつでも足せます
- **else** — 上のどの条件にも当たらなかった「残り全部」の道

大事な性質が1つあります。**条件は上から順に試され、最初にtrueになった道だけが実行されます**。後の条件は見られもしません。この例で `stock < 10` を先に書くと、stockが0のときも「残りわずか」に吸われてしまいます。「厳しい条件を上に」が並べ方のコツです。

## 4-1-3 &&と||で条件を組み合わせる

> **&&は両方が真のとき、||はどちらかが真のときに全体が真になる**

「在庫があり、**かつ** 公開中なら販売する」「管理者、**または** 担当者なら編集できる」 — 条件が1つでは足りない場面はすぐに来ます。条件をつなぐ記号が **論理演算子** です。

| 式 | 読み | 真になるのは |
| --- | --- | --- |
| `a && b` | aかつb | aもbも真 |
| `a \|\| b` | aまたはb | 少なくとも一方が真 |
| `!a` | aでない | aが偽 |

```js
const stock = 5;
const isPublished = true;
if (stock > 0 && isPublished) {
  console.log("販売中");
}
```

注意点は、**&&や||の左右にはそれぞれ完結した条件式を書く**ことです。「10以上かつ20未満」は `stock >= 10 && stock < 20` と、stockを2回書きます(`stock >= 10 && < 20` とは書けません)。

## 4-1-4 値そのものも真偽として扱われる

> **条件に値を書くと、空文字・0・NaNなどは偽、それ以外は真として扱われる**

実務のコードでは `if (userName)` のような、比較していない条件をよく見かけます。条件に真偽値以外の値が入ると、値そのものが真偽として評価されます。

- 真として扱われる値を **truthy**、偽として扱われる値を **falsy** と呼びます
- 文字0個の文字列 `""` を **空文字** といいます。**空文字・0・NaNはfalsy**、それ以外の文字列や数値はtruthyです
- falsyはほかに、`false` 自身と「値が無い」ことを表す値(`null` / `undefined`)を足した数個だけです。falsyの一覧は増えないので、「falsyは決まった数個、それ以外は全部truthy」と覚えられます

```js
const userName = "";
if (userName) {
  console.log(`${userName}さん、こんにちは`);
} else {
  console.log("名前が未入力です");
}
// => 名前が未入力です
```

`if (userName)` は「userNameが空でなければ」と読みます。この読み方を知らないと他人のコードが読めません。一方、自分で書くときは `if (userName !== "")` と明示的な比較で書いて構いません。意図が伝わる方を選び、チームの流儀にも合わせてください。

## もっと知りたい人へ

- `null` や `undefined` は「値が無い」ことを表す値で、「無ければ初期表示にする」のような場面で出会います
- `&&` と `||` は左から評価され、結果が確定した時点で右側を見るのをやめます(短絡評価)。この性質を使った省略記法もありますが、まずは条件として素直に使えれば十分です

# 4-1-3
# &&と||で条件を組み合わせる

JavaScript入門 — Module 4 / レッスン4-1

<!-- ノート: 複合条件です。日本語の「かつ」「または」に対応させて導入します。 -->

---

## なぜ必要か

- 「在庫があり、**かつ** 公開中なら販売する」
- 「管理者、**または** 担当者なら編集できる」
- 条件が1つでは足りない場面がすぐ来る

<!-- ノート: つかみ。権限チェックは実務の複合条件の代表例です。 -->

---

## 結論

**&&は両方が真のとき、||はどちらかが真のときに全体が真になる**

- 条件をつなぐ記号を **論理演算子** という
- **&&**(かつ)/ **||**(または)/ **!**(〜でない)

<!-- ノート: 結論。3つセットで導入しますが、主役は&&と||です。 -->

---

## 最小のコード

```js
const stock = 5;
const isPublished = true;
if (stock > 0 && isPublished) {
  console.log("販売中");
}
```

- `!isPublished` は「公開中でない」でtrue/falseが反転する

<!-- ノート: &&の左右にはそれぞれ完結した条件式を書く点を強調します(stock > 0 && < 10とは書けない)。 -->

---

## 読み方の表

| 式 | 真になるのは |
| --- | --- |
| `a && b` | aもbも真 |
| `a \|\| b` | aかbの少なくとも一方が真 |
| `!a` | aが偽 |

<!-- ノート: 関連枠。「10以上かつ20未満」はstock >= 10 && stock < 20と、条件を2回書くのが正解です。 -->

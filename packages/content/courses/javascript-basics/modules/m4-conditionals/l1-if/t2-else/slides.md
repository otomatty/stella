# 4-1-2
# elseとelse ifで道を分ける

JavaScript入門 — Module 4 / レッスン4-1

<!-- ノート: ifを2択・3択に広げるトピックです。「上から順に、最初に当たった道だけ」が核心です。 -->

---

## なぜ必要か

- 「在庫があれば表示、なければ入荷待ちと表示」— 2択にしたい
- 「10未満なら残りわずか」— 3択目もほしい
- ifだけだと「そうでないとき」が書けない

<!-- ノート: つかみ。ifを2つ並べる書き方の冗長さを見せてから入ると効果的です。 -->

---

## 結論

**elseは条件が偽のときの道、else ifは条件を足した道を作る**

- 道が分かれることを **分岐** という
- **else** = それ以外すべて。**else if** = 追加の条件付きの道

<!-- ノート: 結論。elseは「残り全部」を受け持つ、という言い方が伝わりやすいです。 -->

---

## 最小のコード

```js
const stock = 3;
if (stock === 0) {
  console.log("入荷待ち");
} else if (stock < 10) {
  console.log("残りわずか");
} else {
  console.log("在庫あり");
}
```

<!-- ノート: stockを0、3、20に変えて3つの道を全部通します。 -->

---

## 判定は上から、当たったら終わり

- 条件は上から順に試され、最初にtrueになった道だけ実行される
- 後の条件は見られもしない
- だから「厳しい条件を上に」書く

<!-- ノート: 対比枠。stock<10を先に書くとstock===0がその道に吸われる、という順序バグを口頭で紹介します。 -->

# レッスン4-2 switchと三項演算子

## このレッスンの目標

- [ ] switchでステータス値の分岐を書ける(breakを忘れない)
- [ ] 三項演算子で2択の値を選べる
- [ ] if / switch / 三項演算子を使い分けられる

## 4-2-1 switchは値の一致で分岐する

> **switchは、1つの値をcaseの値と見比べて分岐する**

「ステータスがdraftなら下書き、doneなら完了、…」のように、`else if (status === ...)` が延々と並ぶコードは読みにくくなります。「1つの値との一致比較の連続」には専用の書き方、**switch** があります。

```js
const status = "done";
switch (status) {
  case "draft":
    console.log("下書き");
    break;
  case "done":
    console.log("完了");
    break;
  default:
    console.log("不明");
}
```

- **case** — 一致を調べる値の道。比較は `===` と同じ厳密な一致です
- **default** — どのcaseにも一致しなかったときの道(ifのelseに相当)
- **break** — switchをそこで抜ける印

**breakを忘れると、次のcaseの処理まで続けて実行されます**(下に落ちる)。これはエラーにならないため気づきにくい、switch特有の落とし穴です。この講座では「caseごとにbreakまでで1セット」で統一します。

## 4-2-2 三項演算子は値を選ぶ

> **条件 ? A : B は、条件によってAかBの値になる**

「在庫があれば『あり』、なければ『なし』を変数に入れたい」をif/elseで書くと、代入のために5行かかります。「2択の値を選ぶだけ」なら1行で書けるのが **三項演算子** です。

```js
const stock = 5;
const label = stock > 0 ? "在庫あり" : "在庫なし";
console.log(label);  // => "在庫あり"
```

値になる書き方を **式** といいます。ifは「実行する処理」を分ける文ですが、三項演算子は「値」を選ぶ式です。式なので、結果をそのまま代入したり、テンプレートリテラルの `${}` に埋め込んだりできます。

```js
console.log(`在庫: ${stock > 0 ? "あり" : "なし"}`);
```

使いどころの線引きも大事です。複数行の処理を分けたいときはifを使い、三項演算子の入れ子(? : の中にさらに ? :)は読みにくいので避けてください。

## 4-2-3 分岐の書き方を使い分ける

> **迷ったらifを使い、値の一致が並ぶならswitch、値を選ぶだけなら三項演算子にする**

分岐の書き方が3つ出そろいました。多くの場面ではどれでも書けるので、迷わないための既定を持っておきます。

| 場面 | 書き方 |
| --- | --- |
| 範囲の比較・複合条件・複数行の処理 | `if` / `else if` |
| 1つの値と定数の一致比較が3つ以上並ぶ | `switch` |
| 2択の値を選んで代入・埋め込みする | 三項演算子 |

万能なのはifです。まずifで書ければ困りません。switchと三項演算子は「その方が読みやすくなるときだけ」選びます。

```js
// 2択の値選び: 三項演算子が意図に合う
const label = role === "admin" ? "管理者" : "一般";
```

「3つ以上」は目安です。一致比較が2つならifの方が短いことが多く、逆にcaseが10個並ぶならswitchの独壇場です。読み手が一番速く理解できる書き方を選ぶ、が最終的な基準です。

## もっと知りたい人へ

- switchのフォールスルー(わざとbreakを書かず、複数のcaseで同じ処理を共有する技)は実務のコードで見かけることがあります。読めるようにしつつ、自分で書くのは慣れてからで十分です
- 最近のJavaScriptには、値の形で分岐するより高度な方法も提案されていますが、まずこの3つで実務は書けます

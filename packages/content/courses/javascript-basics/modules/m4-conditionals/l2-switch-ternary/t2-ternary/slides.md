# 4-2-2
# 三項演算子は値を選ぶ

JavaScript入門研修 — Module 4 / レッスン4-2

<!-- ノート: if文との違いは「値になる」こと。文と式の区別に軽く触れる回でもあります。 -->

---

## なぜ必要か

- 「在庫があれば『あり』、なければ『なし』を変数に入れたい」
- if/elseで書くと、代入のために5行かかる
- 「2択の値を選ぶだけ」なら、1行で書きたい

<!-- ノート: つかみ。ラベル文字列の出し分けは画面表示の定番です。 -->

---

## 結論

**条件 ? A : B は、条件によってAかBの値になる**

- 値になる書き方を **式** という。**三項演算子** は分岐する式
- 条件がtrueならA、falseならBの値になる

<!-- ノート: 結論。「ifは実行を分ける、三項演算子は値を選ぶ」という対比で伝えます。 -->

---

## 最小のコード

```js
const stock = 5;
const label = stock > 0 ? "在庫あり" : "在庫なし";
console.log(label);  // => "在庫あり"
```

- 式なので、結果をそのまま代入や埋め込みに使える

<!-- ノート: テンプレートリテラルの${}の中にも書ける、と実用の幅を見せます。 -->

---

## 使いどころの線引き

- 向いている: 2択の **値** を選ぶだけのとき
- 向かない: 処理(複数行)を分けたいとき → if
- 三項演算子の入れ子は読みにくいので避ける

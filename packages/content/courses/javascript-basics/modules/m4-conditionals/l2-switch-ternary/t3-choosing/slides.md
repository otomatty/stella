# 分岐の書き方を使い分ける

JavaScript入門研修 — Module 4 / レッスン4-2

<!-- ノート: モジュール4のまとめ役です。新しい構文は出しません。判断基準だけを扱います。 -->

---

## なぜ必要か

- if / switch / 三項演算子、どれでも書ける場面が多い
- 毎回迷うとコードを書く手が止まる
- 既定の選び方を1つ持っておきたい

<!-- ノート: つかみ。どれが正解か、ではなく、迷わない既定を持つという話です。 -->

---

## 結論

**迷ったらifを使い、値の一致が並ぶならswitch、値を選ぶだけなら三項演算子にする**

- 万能なのは if。まずこれで書けるようになっていれば困らない
- switchと三項演算子は「読みやすくなるときだけ」選ぶ

<!-- ノート: 結論。既定はif。他の2つは読みやすさのための選択肢という位置づけです。 -->

---

## 判断の表

| 場面 | 書き方 |
| --- | --- |
| 範囲の比較・複合条件・複数行の処理 | `if` / `else if` |
| 1つの値と定数の一致比較が3つ以上並ぶ | `switch` |
| 2択の値を選んで代入・埋め込みする | 三項演算子 |

<!-- ノート: 「3つ以上」は目安です。2つならifの方が短いことが多い、と補足します。 -->

---

## 同じ処理を3通りで見る

```js
if (role === "admin") { label = "管理者"; }
else { label = "一般"; }

const label2 = role === "admin" ? "管理者" : "一般";
```

- 2択の値選びなら、三項演算子が一番意図に合う

<!-- ノート: 実例で「値を選ぶだけなら三項演算子が読みやすい」を体感してもらいます。switch版は冗長になるので口頭で言及のみ。 -->

# 文字列の数字はNumberで数値にする

JavaScript入門研修 — Module 1 / レッスン1-2

<!-- ノート: 「入力は文字列で届く」という、後の入力欄(M8)まで効く実務の落とし穴を先に踏んでおきます。 -->

---

## なぜ必要か

- 画面の入力欄から受け取る値は、数字に見えても文字列
- `"100" + 1` を計算すると、期待した101にならない
- 計算の前に、種類をそろえる一手間が要る

<!-- ノート: つかみ。1-1-4の「種類で結果が変わる」の実害バージョンです。 -->

---

## 結論

**文字列の数字は、Number()で数値にしてから計算する**

- 種類を変えることを **変換** という
- **Number**(文字列) が、数値に変換した結果を返す

<!-- ノート: 結論。逆方向のString()もありますが、まず頻出のNumber()に絞ります。 -->

---

## 最小のコード

```js
const input = "100";
console.log(input + 1);          // => "1001"
console.log(Number(input) + 1);  // => 101
```

<!-- ノート: 上の行が静かに間違う論理エラーの典型です。文字列+数値は、数値が文字列側に引きずられます。 -->

---

## 変換できないとき

```js
console.log(Number("abc"));  // => NaN
```

- 数字と読めない文字列は `NaN`(数値ではない)になる
- 計算結果に `NaN` が出たら、どこかで文字列が混ざったサイン

<!-- ノート: 関連枠。NaNは読み方(ナン)と「見かけたら変換ミスを疑う」だけ覚えれば十分です。 -->

# 変数の値を更新する

JavaScript入門 — Module 1 / レッスン1-2

<!-- ノート: count = count + 1 という、初見では奇妙に見える形を腹落ちさせるトピックです。 -->

## なぜ必要か

- 処理した件数を数えたい。合計に金額を足し込みたい
- 「いまの値に1を足した結果」を、また同じ変数に持たせたい
- ループを学ぶときの主役になる書き方

<!-- ノート: つかみ。カウンターを紙で正の字を書くイメージから入ります。 -->

---

## 結論

**今の値を使った計算の結果を、同じ変数に入れ直せる**

- `count = count + 1;` は「今のcount + 1を、countに再代入」
- `=` は「等しい」ではなく代入。右を計算してから左に入れる

<!-- ノート: 結論。数学の=と混同するのが最大のつまずきです。「右が先、左が後」と繰り返します。 -->

---

## 最小のコード

```js
let count = 0;
count = count + 1;
count = count + 1;
console.log(count);  // => 2
```

- この入れ直しを **更新** と呼ぶ。更新する変数はletで宣言する

<!-- ノート: 1行ずつ実行した後のcountの中身を、指で追いながら読みます。 -->

---

## 短く書ける

```js
let total = 0;
total += 500;   // total = total + 500 と同じ
total += 300;
console.log(total);  // => 800
```

- `+=` は「足して更新」。`-=` `*=` などもある

<!-- ノート: 関連枠。+=は実務で頻出です。まず長い形で意味を理解してから省略形、の順で。 -->

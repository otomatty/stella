# レッスン1-2 数値

## このレッスンの目標

- [ ] 算術演算子で計算し、%の使いどころを説明できる
- [ ] 変数の更新(count = count + 1 / +=)を読める・書ける
- [ ] 比較演算子の結果が真偽値であることを説明できる

## 1-2-1 算術演算子で計算する

> **数値は + - * / % の算術演算子で計算できる**

合計金額、税込価格、残り件数 — 実務で扱う値の多くは計算で作ります。計算の記号を **演算子** と呼び、数値の計算に使う5つを **算術演算子** といいます。

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `+` | 足す | `1980 + 20` → `2000` |
| `-` | 引く | `1980 - 80` → `1900` |
| `*` | 掛ける(×) | `1980 * 3` → `5940` |
| `/` | 割る(÷) | `1980 / 2` → `990` |
| `%` | 割った余り | `7 % 3` → `1` |

```js
const price = 1980;
console.log(price * 3);   // => 5940
```

優先順位は算数と同じ(掛け算・割り算が先)で、`()` も同じように使えます。

`%` だけ算数に無い記号です。**剰余**(割り算の余り)を出す演算子で、「3人で配ったときの余り」や「偶数か奇数か」(`n % 2` が `0` なら偶数)の判定に使います。

## 1-2-2 変数の値を更新する

> **今の値を使った計算の結果を、同じ変数に入れ直せる**

処理した件数を数える、合計に金額を足し込む — 「いまの値に足した結果を、また同じ変数に持たせる」書き方です。この入れ直しを **更新** と呼びます。

```js
let count = 0;
count = count + 1;
count = count + 1;
console.log(count);  // => 2
```

`count = count + 1;` は数学の等式ではありません。`=` は代入で、**右側を先に計算してから左に入れます**。「今のcountに1を足した結果を、countに再代入」と読みます。更新する変数は再代入するので `let` で宣言します。

頻出の形には省略記法があります。

```js
let total = 0;
total += 500;   // total = total + 500 と同じ
total += 300;
console.log(total);  // => 800
```

**+=** は「足して更新」です。`-=` `*=` などもあります。まず長い形で意味をつかんでから、省略形を使ってください。

## 1-2-3 比較演算子は真偽値を返す

> **=== や < などの比較演算子は、結果をtrueかfalseで返す**

「在庫が10個未満か?」「入力は空か?」 — 実務のプログラムは判定だらけです。2つの値を比べる記号が **比較演算子** で、結果は必ず真偽値(trueかfalse)になります。

```js
const stock = 8;
console.log(stock < 10);    // => true
console.log(stock === 0);   // => false
console.log(stock !== 0);   // => true
```

| 演算子 | 意味 |
| --- | --- |
| **===** / **!==** | 等しい / 等しくない |
| `<` / `>` | より小さい / より大きい |
| `<=` / `>=` | 以下 / 以上 |

注意点は2つです。

- `=` は代入、`===` は比較。別物です
- 等しさの判定には `==`(イコール2つ)という記号もありますが、種類を勝手に変換して比べるため事故のもとです。この講座では **===に統一** します

比較の結果が「値」であることは、条件分岐のモジュールでそのまま効いてきます。

## 1-2-4 文字列の数字はNumberで数値にする

> **文字列の数字は、Number()で数値にしてから計算する**

画面の入力欄から受け取る値は、数字に見えても文字列です。種類が違うまま計算すると、静かに間違います。

```js
const input = "100";
console.log(input + 1);          // => "1001"
console.log(Number(input) + 1);  // => 101
```

文字列と数値を `+` でつなぐと、数値が文字列側に引きずられて「つなげる」になります。`"1001"` はエラーにならない論理エラーの典型です。

種類を変えることを **変換** といい、**Number**(文字列) が数値に変換した結果を返します。「文字列の数字は、計算の前にNumberで数値にする」と覚えてください。

数字と読めない文字列は変換できません。

```js
console.log(Number("abc"));  // => NaN
```

`NaN`(Not a Number = 数値ではない)が出たら、どこかで文字列が混ざったサインです。

## もっと知りたい人へ

- 小数の計算では `0.1 + 0.2` が `0.30000000000000004` になるなど、わずかな誤差が出ることがあります。コンピューターの数の持ち方によるもので、金額計算では「銭の単位まで整数で持つ」などの工夫をします
- 逆方向の変換は `String(123)` で文字列にできます

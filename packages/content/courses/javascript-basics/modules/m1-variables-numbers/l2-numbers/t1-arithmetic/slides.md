# 算術演算子で計算する

JavaScript入門 — Module 1 / レッスン1-2

<!-- ノート: すでに使ってきた+や*を、演算子という語で正式に導入するトピックです。 -->

---

## なぜ必要か

- 合計金額、税込価格、残り件数 — 実務の値はほぼ計算で作る
- ここまで見よう見まねで使ってきた `+` や `*` を正式に整理する
- 記号は5つだけ。全部この場で覚えられる

<!-- ノート: つかみ。電卓でやっていることをコードに移すだけ、とハードルを下げます。 -->

---

## 結論

**数値は + - * / % の算術演算子で計算できる**

- 計算の記号を **演算子** と呼ぶ
- 数値の計算に使う5つが **算術演算子**

<!-- ノート: 結論。*が×、/が÷である点だけ、算数の記号との違いとして強調します。 -->

---

## 最小のコード

```js
const price = 1980;
console.log(price + 20);  // => 2000
console.log(price * 3);   // => 5940
console.log(price / 2);   // => 990
```

<!-- ノート: 変数と演算子の組み合わせ。優先順位は算数と同じで、()も同じように使えると補足します。 -->

---

## %は「割った余り」

```js
console.log(7 % 3);  // => 1
```

- **剰余**(割り算の余り)を出す演算子
- 「3人で配ったときの余り」「偶数か奇数か」の判定に使う

<!-- ノート: 関連枠。%だけ算数に無い記号なので1枚使います。偶奇判定は条件分岐のモジュールで実際に使います。 -->

## なぜ必要か

- 「在庫が10個未満か?」「入力は空か?」 — 実務は判定だらけ
- 判定の結果を、プログラムの中で値として扱いたい
- その結果の受け皿が、1-1-4で見た真偽値

<!-- ノート: つかみ。判定→結果は2択→真偽値の出番、という流れでつなぎます。 -->

---

## 結論

**=== や < などの比較演算子は、結果をtrueかfalseで返す**

- 2つの値を比べる記号が **比較演算子**
- 等しいかは **===**、等しくないかは **!==** で調べる

<!-- ノート: 結論。=(代入)と===(比較)の区別をここで強調します。 -->

---

## 最小のコード

```js
const stock = 8;
console.log(stock < 10);    // => true
console.log(stock === 0);   // => false
console.log(stock !== 0);   // => true
```

<!-- ノート: 結果がtrueやfalseという「値」でコンソールに出ることを確認します。 -->

---

## 記号の一覧

| 演算子 | 意味 |
| --- | --- |
| `===` / `!==` | 等しい / 等しくない |
| `<` / `>` | より小さい / より大きい |
| `<=` / `>=` | 以下 / 以上 |

- 等しさの判定に `==` という記号もあるが、この講座では使わない(=== に統一)

<!-- ノート: 対比枠。==は種類を勝手に変換して比べるため事故のもとです。「イコール3つ」で統一します。 -->

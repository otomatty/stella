# 1-1-3
# 変数名は中身が分かる名前にする

JavaScript入門研修 — Module 1 / レッスン1-1

<!-- ノート: 名前の付け方は文法ではなく習慣ですが、読みやすさを最初に習慣化します。 -->

---

## なぜ必要か

- `a = 1980` のコードは、1週間後の自分が読めない
- 変数の名前は、コードの中で一番よく読む部分
- チームの誰が読んでも中身が想像できる名前がいい

<!-- ノート: つかみ。実務のコードは書く時間より読む時間の方が長い、という話をします。 -->

---

## 結論

**変数名は、中身が分かる英単語をcamelCaseでつなげて付ける**

- **変数名** は中身を表す英単語で
- 2語以上は **camelCase**(2語目からの先頭を大文字)でつなぐ

<!-- ノート: 結論。JavaScriptの標準的な習慣がcamelCaseです。 -->

---

## 最小のコード

```js
const taxRate = 0.1;       // 税率と分かる
const userName = "佐藤";    // 2語目のNが大文字
const a = 0.1;             // 何の値か分からない
```

<!-- ノート: 良い例2つ、悪い例1つ。aは動きはしますが、読み手に優しくありません。 -->

---

## 名前のルール(文法側)

- 使えるのは英数字と `_` `$`。数字からは始められない
- `let` や `const` などの予約語は変数名にできない(エラーになる)
- 大文字と小文字は区別される(`price` と `Price` は別の変数)

<!-- ノート: 関連枠。習慣の話と文法の話を分けて伝えます。特に大文字小文字の区別は打ち間違いエラーの定番原因です。 -->

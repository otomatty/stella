# レッスン1-1 変数

## このレッスンの目標

- [ ] constとletで変数を宣言し、使い分けを説明できる
- [ ] 中身が分かる変数名をcamelCaseで付けられる
- [ ] 数値・文字列・真偽値を見分けられる

## 1-1-1 変数は値に名前を付ける

> **変数を宣言すると、値に名前を付けて後から使い回せる**

`1980 * 3` の結果をあとの行でも使いたいとき、毎回同じ計算を書き直すのは無駄ですし、書き間違いのもとです。そこで「結果に名前を付けて取っておく」仕組みを使います。

- **値** — 数や文字などのデータそのもの
- **変数** — 値に付けた名前。作ることを **宣言** といいます
- **代入** — 変数に値を入れること

```js
let price = 1980;
console.log(price);      // => 1980
console.log(price * 3);  // => 5940
```

`let 名前 = 値;` で宣言と代入をまとめて行います。以降は名前を書くだけで、その場所が中身の値に置き換わって計算されます。

M0で見たとおりJavaScriptは上から順に実行されるので、宣言より上の行で変数は使えません。「宣言が先、利用が後」です。

## 1-1-2 基本はconstで宣言する

> **変数は基本constで宣言し、後から入れ替えるものだけletにする**

変数の中身を後から入れ替えることを **再代入** といいます。`let` で宣言した変数は再代入できますが、便利な反面、「変わらないはずの値」がどこかで書き換わる事故も起こせてしまいます。

そこでもう1つの宣言、**const** を使います。constで宣言した変数は再代入できません。

```js
const taxRate = 0.1;
taxRate = 0.2;  // エラー: 再代入できない
```

```js
let count = 0;
count = 1;      // letなら再代入できる
```

constへの再代入はエラーで止まります。これは不便ではなく、「変えないつもりの値が変わっていない」ことを言語が保証してくれる安全装置です。

| 値の性質 | 宣言 |
| --- | --- |
| 一度決めたら変わらない(税率・名前) | `const` |
| 進行中に変わる(件数・合計) | `let` |

迷ったら `const` で書き、あとで再代入が必要だと分かったら `let` に変えます。実務のコードもconstが大半です。

## 1-1-3 変数名は中身が分かる名前にする

> **変数名は、中身が分かる英単語をcamelCaseでつなげて付ける**

`const a = 1980;` は動きますが、1週間後の自分やチームの仲間には `a` が何なのか分かりません。**変数名** はコードの中で一番よく読まれる部分です。

- 中身を表す英単語で付ける
- 2語以上は **camelCase**(2語目からの先頭を大文字)でつなぐ

```js
const taxRate = 0.1;       // 税率と分かる
const userName = "佐藤";    // 2語目のNが大文字
const a = 0.1;             // 何の値か分からない
```

文法側のルールも押さえておきます。

- 使えるのは英数字と `_` `$`。数字からは始められない
- `let` や `const` などの予約語は変数名にできない(エラーになる)
- 大文字と小文字は区別される(`price` と `Price` は別の変数)

特に最後の1つは、打ち間違いによる `ReferenceError` の定番原因です。

## 1-1-4 値には種類がある

> **値には数値・文字列・真偽値といった種類があり、種類で扱い方が変わる**

`100` と `"100"` は見た目は似ていますが別物です。値には種類があり、種類が違うとできることが変わります。この講座で使うのは主に3種類です。

| 種類 | 例 | 用途 |
| --- | --- | --- |
| **数値** | `12`、`0.1` | 計算 |
| **文字列** | `"在庫あり"` | 文字の表示・加工 |
| **真偽値** | **true** / **false** | 「あり/なし」などの2択の状態 |

```js
const stock = 12;          // 数値
const label = "在庫あり";   // 文字列
const isOpen = true;       // 真偽値
```

見分け方は引用符です。引用符で囲めば文字列、囲まなければ数値や真偽値として扱われます。

種類の違いは結果に直結します。

```js
console.log(100 + 100);      // => 200
console.log("100" + "100");  // => 100100
```

数値の `+` は足し算ですが、文字列の `+` は「つなげる」です。この違いはレッスン1-2で正面から扱います。

## もっと知りたい人へ

- 値の種類はほかに `null` や `undefined` などもありますが、必要になった場面で紹介します
- 昔のコードには `var` という宣言も出てきます。いまの書き方では使わないので、この講座でも扱いません

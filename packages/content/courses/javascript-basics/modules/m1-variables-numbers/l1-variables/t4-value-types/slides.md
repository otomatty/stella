# 1-1-4
# 値には種類がある

JavaScript入門 — Module 1 / レッスン1-1

<!-- ノート: 型の初歩です。用語は「種類」で通し、深入りせず3種類の見分けだけ扱います。 -->

---

## なぜ必要か

- `100` と `"100"` は、見た目は似ているが別物
- 種類が違うと、できること(計算できる・つなげる)が変わる
- 種類を意識しないと、静かに間違う

<!-- ノート: つかみ。100+100が200にならないことがある、と匂わせておきます(詳細は1-2-4)。 -->

---

## 結論

**値には数値・文字列・真偽値といった種類があり、種類で扱い方が変わる**

- **数値** = 計算に使う数(`100`)
- **文字列** = 文字の並び(`"こんにちは"`)
- **真偽値** = **true**(真)か **false**(偽)の2択

<!-- ノート: 結論。この講座で使う種類はほぼこの3つです。 -->

---

## 最小のコード

```js
const stock = 12;          // 数値
const label = "在庫あり";   // 文字列
const isOpen = true;       // 真偽値
```

- 引用符で囲めば文字列、囲まなければ数値や真偽値

<!-- ノート: 見た目での見分け方は引用符の有無。真偽値は「あり/なし」「済/未」のような2択の状態に使う、と実務の用途を添えます。 -->

---

## 種類で結果が変わる

```js
console.log(100 + 100);      // => 200
console.log("100" + "100");  // => 100100
```

- 数値の `+` は足し算、文字列の `+` はつなげる

<!-- ノート: 対比枠。同じ+でも種類で意味が変わる、という驚きをここで一度体験させます。 -->

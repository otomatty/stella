# 変数は値に名前を付ける

JavaScript入門 — Module 1 / レッスン1-1

<!-- ノート: 言語の本体の最初のトピックです。変数はこの講座の全トピックの土台になります。 -->

---

## なぜ必要か

- `1980 * 3` の結果を、あとの行でも使いたい
- 毎回同じ計算を書き直すのは、無駄だし間違いのもと
- 「結果に名前を付けて取っておく」仕組みが要る

<!-- ノート: つかみ。単価×数量の合計を何度も使う、という業務の場面で話します。 -->

---

## 結論

**変数を宣言すると、値に名前を付けて後から使い回せる**

- **値** = 数や文字などのデータそのもの
- **変数** = 値に付けた名前。作ることを **宣言** という
- 変数に値を入れることを **代入** という

<!-- ノート: 結論。値・変数・宣言・代入の4語をここでまとめて定義します。以降ずっと使う語です。 -->

---

## 最小のコード

```js
let price = 1980;
console.log(price);      // => 1980
console.log(price * 3);  // => 5940
```

- `let 名前 = 値;` で宣言して代入する
- 以降は名前を書くだけで、その値として使える

<!-- ノート: letで宣言→=で代入→名前で参照、の3点をコードで確認します。 -->

---

## 名前は「値の入った箱」

- `price` と書いた場所は、中身の `1980` に置き換わって計算される
- 宣言より上の行では使えない(上から順に実行されるため)

<!-- ノート: 図解の代わりの補足。M0の「上から順に実行」とつながる話として、宣言が先・利用が後を強調します。 -->

# 8-1-3
# オブジェクトの配列が実務のデータ形

JavaScript入門 — Module 8 / レッスン8-1

<!-- ノート: 新しい構文ゼロの統合トピックです。配列×オブジェクト×ループ×filterが一気につながります。 -->

---

## なぜ必要か

- 商品一覧、社員名簿、タスク一覧 — 実務のデータは「同じ形の組」の並び
- 配列とオブジェクトを別々に学んだが、実戦では組み合わせて使う
- この形に慣れれば、実務のデータがそのまま読める

<!-- ノート: つかみ。APIから届くデータもほぼこの形、と実務との接続を語ります。 -->

---

## 結論

**実務のデータは、同じ形のオブジェクトを配列に並べた形で扱うことが多い**

- 一覧 = 配列、1件 = オブジェクト
- ループやfilterと組み合わせて集計・絞り込みする

<!-- ノート: 結論。「一覧は配列、1件はオブジェクト」の分担を言い切ります。 -->

---

## 最小のコード

```js
const products = [
  { name: "ボールペン", stock: 8 },
  { name: "ノート", stock: 0 },
];
for (const product of products) {
  console.log(`${product.name}: 残り${product.stock}`);
}
```

<!-- ノート: for...ofで1件ずつ取り出し、ドット記法で中を読む。既習の合わせ技であることを強調します。 -->

---

## 絞り込みもそのまま効く

```js
const inStock = products.filter((p) => p.stock > 0);
console.log(inStock.length);  // => 1
```

- filterのコールバックの中でもドット記法を使うだけ

<!-- ノート: 関連枠。M6のfilterがオブジェクトの配列でも同じ形で効く、という再利用の気持ちよさで締めます。 -->

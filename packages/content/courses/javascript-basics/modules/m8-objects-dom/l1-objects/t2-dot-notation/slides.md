# 8-1-2
# ドット記法で読み書きする

JavaScript入門 — Module 8 / レッスン8-1

<!-- ノート: メソッド呼び出しで使ってきたドットが、プロパティ全般の読み書きだったという種明かしの回です。 -->

---

## なぜ必要か

- 作ったオブジェクトから、価格だけ取り出したい
- 在庫を1減らす、のような書き換えもしたい
- 実は、その書き方はもう半分知っている

<!-- ノート: つかみ。"abc".lengthやtasks.pushで、ドットはずっと使ってきました。 -->

---

## 結論

**オブジェクトのプロパティは、オブジェクト.名前で読み書きできる**

- この書き方を **ドット記法** という
- 読むのも、代入で書き換えるのも同じ形

<!-- ノート: 結論。lengthもメソッドも「プロパティ」の仲間だった、と過去の書き方を一段抽象化します。 -->

---

## 最小のコード

```js
const product = { name: "ボールペン", price: 120, stock: 8 };
console.log(product.price);   // => 120
product.stock = product.stock - 1;
console.log(product.stock);   // => 7
```

<!-- ノート: constでもプロパティの書き換えはできる(配列の要素と同じ理屈)ことにも触れます。 -->

---

## キーを変数で選ぶなら[]

```js
const key = "price";
console.log(product[key]);      // => 120
console.log(product["price"]);  // 同じ意味
```

- どのキーかが実行時に決まるときは `[]` 記法を使う

<!-- ノート: 関連枠。基本はドット記法、[]は「キーが変数のとき」の道具、という位置づけです。 -->

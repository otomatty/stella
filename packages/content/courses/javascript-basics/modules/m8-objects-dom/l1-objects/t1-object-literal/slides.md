# 8-1-1
# オブジェクトは名前付きの値の集まり

JavaScript入門 — Module 8 / レッスン8-1

<!-- ノート: 最後のモジュールです。オブジェクトを最短で導入し、DOM操作で使う語彙(プロパティ)を支えます。 -->

---

## なぜ必要か

- 「商品」には名前・価格・在庫と、性質の違う値が組で付いてくる
- 配列に `["ペン", 120, 8]` と並べると、どれが何か分からない
- 「名前付きで」まとめる入れ物が要る

<!-- ノート: つかみ。配列は順番の入れ物、今回は名前の入れ物、という対比で入ります。 -->

---

## 結論

**オブジェクトは{}で作り、名前を付けた値をひとまとめに持てる**

- **オブジェクト** の中の「名前と値の組」を **プロパティ** という
- 名前の側を **キー** と呼ぶ

<!-- ノート: 結論。プロパティという語はこのあとのDOM操作(textContentなど)で毎回使います。 -->

---

## 最小のコード

```js
const product = {
  name: "ボールペン",
  price: 120,
  stock: 8,
};
```

- `キー: 値` をカンマで並べる

<!-- ノート: 改行とインデントの整形も込みで「この形で書く」と示します。 -->

---

## 配列との使い分け

| 入れ物 | 向いているデータ |
| --- | --- |
| 配列 | 同じ種類の値の並び(順番が大事) |
| オブジェクト | 1つのものの性質の組(名前が大事) |

<!-- ノート: 対比枠。「タスクの一覧は配列、タスク1件の中身はオブジェクト」という例がわかりやすいです。 -->

# レッスン8-1 オブジェクト

## このレッスンの目標

- [ ] {}でオブジェクトを作り、ドット記法で読み書きできる
- [ ] 配列とオブジェクトの使い分けを説明できる
- [ ] オブジェクトの配列をループやfilterで扱える

## 8-1-1 オブジェクトは名前付きの値の集まり

> **オブジェクトは{}で作り、名前を付けた値をひとまとめに持てる**

「商品」には名前・価格・在庫と、性質の違う値が組で付いてきます。配列に `["ボールペン", 120, 8]` と並べることもできますが、どれが何の値か分かりません。「名前付きで」まとめる入れ物が **オブジェクト** です。

```js
const product = {
  name: "ボールペン",
  price: 120,
  stock: 8,
};
```

`{}` の中に `キー: 値` をカンマで並べます。「名前と値の組」を **プロパティ** といい、名前の側を **キー** と呼びます。

| 入れ物 | 向いているデータ |
| --- | --- |
| 配列 | 同じ種類の値の並び(順番が大事) |
| オブジェクト | 1つのものの性質の組(名前が大事) |

「タスクの一覧は配列、タスク1件の中身はオブジェクト」という分担で考えると迷いません。

## 8-1-2 ドット記法で読み書きする

> **オブジェクトのプロパティは、オブジェクト.名前で読み書きできる**

実はこの書き方の半分は、もう知っています。`"abc".length` も `tasks.push()` も、ドットでプロパティにアクセスする書き方でした(メソッドは「関数が入ったプロパティ」です)。

```js
const product = { name: "ボールペン", price: 120, stock: 8 };
console.log(product.price);   // => 120
product.stock = product.stock - 1;
console.log(product.stock);   // => 7
```

`オブジェクト.キー` で読み書きする形を **ドット記法** といいます。読むのも代入で書き換えるのも同じ形です。constで宣言していてもプロパティの書き換えはできます(配列の要素と同じで、入れ物ごとの再代入だけが禁止されます)。

どのキーかが実行時に決まるときは `[]` 記法を使います。

```js
const key = "price";
console.log(product[key]);      // => 120
console.log(product["price"]);  // 同じ意味
```

基本はドット記法で書き、`[]` は「キーが変数に入っているとき」の道具です。

## 8-1-3 オブジェクトの配列が実務のデータ形

> **実務のデータは、同じ形のオブジェクトを配列に並べた形で扱うことが多い**

商品一覧、社員名簿、タスク一覧 — 実務のデータは「同じ形の組」の並びです。一覧を配列で、1件をオブジェクトで持つ形は、サーバーから届くデータでもそのまま登場します。

```js
const products = [
  { name: "ボールペン", stock: 8 },
  { name: "ノート", stock: 0 },
];
for (const product of products) {
  console.log(`${product.name}: 残り${product.stock}`);
}
```

for...ofで1件ずつ取り出し、ドット記法で中を読む。新しい構文はゼロで、既習の合わせ技です。

絞り込みも同じように書けます。

```js
const inStock = products.filter((p) => p.stock > 0);
console.log(inStock.length);  // => 1
```

filterのコールバックの中でドット記法を使うだけです。この「オブジェクトの配列 + ループ/filter」の形に慣れれば、実務のデータ処理の骨格は読めるようになっています。

## もっと知りたい人へ

- プロパティの値には関数も入れられます(メソッドの自作)。`this` という仕組みが絡むため、この講座では扱いません。必要になったら「JavaScript メソッド定義 this」で調べてください
- オブジェクトの中にオブジェクトや配列を入れる入れ子もよく使われます。`user.address.city` のようにドットをつなげて読めます

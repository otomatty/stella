# 7-1-4
# イベントオブジェクトで詳しく知る

JavaScript入門 — Module 7 / レッスン7-1

<!-- ノート: イベントの詳細情報です。「オブジェクト」という語はM8で正式に導入するため、ここでは固有名詞として扱います。 -->

---

## なぜ必要か

- keydownは「何かのキーが押された」ことしか教えてくれないのか?
- Enterと矢印キーで処理を変えたい
- 「出来事の詳細」を受け取る方法が要る

<!-- ノート: つかみ。検索欄でEnterだけ特別扱いする、という誰もが知るUIを例にします。 -->

---

## 結論

**リスナーの引数には、押されたキーなどの詳細が入ったイベントオブジェクトが渡される**

- ブラウザーはリスナーを呼ぶとき、詳細情報の包みを引数で渡してくる
- この包みを **イベントオブジェクト** と呼ぶ(慣習で `event` や `e` と受ける)

<!-- ノート: 結論。リスナーも関数なので引数を受け取れる、という6-1-2の知識で読めます。 -->

---

## 最小のコード

```js
const input = document.querySelector("input");
input.addEventListener("keydown", (event) => {
  console.log(event.key);
});
```

- **event.key** に、押されたキーの名前が文字列で入っている

<!-- ノート: 実演するとa、Enter、ArrowUpなどが流れて楽しい場面です。HTMLにinput要素がある前提です。 -->

---

## Enterだけ特別扱いする

```js
input.addEventListener("keydown", (event) => {
  if (event.key === "Enter") {
    console.log("送信します");
  }
});
```

<!-- ノート: 関連枠。event.keyの値は"Enter"のように大文字始まりの決まった名前です。条件分岐と組み合わせる型を見せます。 -->

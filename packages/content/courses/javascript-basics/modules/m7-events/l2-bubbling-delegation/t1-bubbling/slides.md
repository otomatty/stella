# 7-2-1
# イベントは親へ伝わる

JavaScript入門 — Module 7 / レッスン7-2

<!-- ノート: バブリングです。最初は驚きの仕様ですが、委譲の土台として前向きに導入します。 -->

---

## なぜ必要か

- ボタンを囲むdivにもclickリスナーを付けたら、両方動いた
- 「押したのはボタンなのに、なぜ親も反応する?」
- この伝わり方を知らないと、リスナーの動きが読めない

<!-- ノート: つかみ。実際に2つのリスナーが両方発火する現象を先に見せてから種明かしします。 -->

---

## 結論

**clickなどのイベントは、起きた要素からその親、さらに親へと順に伝わっていく**

- 要素を囲んでいる外側の要素を **親要素** という
- 内側から外側へ泡のように昇る伝わり方を **バブリング** という

<!-- ノート: 結論。泡(bubble)が水面へ昇るイメージです。「clickなど」と付けているのは、伝わらない種類のイベント(フォーカスの移動など)も一部あるためです。この講座で扱うclick・keydown・submitはすべて伝わります。 -->

---

## 最小のコード

```html
<div>
  <button>申請</button>
</div>
<script>
  const box = document.querySelector("div");
  box.addEventListener("click", () => console.log("divが聞いた"));
</script>
```

- ボタンを押しても「divが聞いた」が出る

<!-- ノート: リスナーはdivにしか無いのに、ボタンのクリックが届く。これがバブリングの効果です。 -->

---

## 伝わる順序

```text
button で発生 → div → body → document
```

- 途中の要素にリスナーがあれば、順に呼ばれる
- 親は「自分の中で起きたclickを全部聞ける」と読み替えられる
- 伝わらない種類のイベントも一部あるが、この講座で扱う分はすべて伝わる

<!-- ノート: 図解の代わりの経路図。この「親は子の分まで聞ける」が次の委譲の伏線です。伝わらない例はフォーカスの移動などですが、名前を暗記させる必要はありません。 -->

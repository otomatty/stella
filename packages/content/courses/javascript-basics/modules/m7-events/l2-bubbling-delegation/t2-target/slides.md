# 7-2-2
# event.targetで起きた場所が分かる

JavaScript入門 — Module 7 / レッスン7-2

<!-- ノート: バブリングとセットの情報です。委譲の直前の部品になります。 -->

---

## なぜ必要か

- 親で聞くと、子のどれで起きたのか分からなくなる?
- 「どのボタンが押されたか」で処理を変えたい
- 発生源の情報がイベントオブジェクトに入っているはず

<!-- ノート: つかみ。7-1-4で「詳細はイベントオブジェクトに入っている」と学んだ流れで自然に導けます。 -->

---

## 結論

**event.targetには、イベントが実際に起きた要素が入っている**

- リスナーを付けた要素ではなく、**発生源** の要素が入る
- バブリングで親に届いても、発生源の情報は失われない

<!-- ノート: 結論。「聞いた場所」と「起きた場所」は別、という区別が核心です。 -->

---

## 最小のコード

```js
const box = document.querySelector("div");
box.addEventListener("click", (event) => {
  console.log(event.target);
});
```

- ボタンを押せば `<button>` が、divの余白なら `<div>` が出る

<!-- ノート: 同じリスナーでも、押す場所でevent.targetが変わることを実演します。 -->

---

## 「聞いた場所」と「起きた場所」

| 情報 | 入っているもの |
| --- | --- |
| リスナーを付けた要素 | 自分(コードに書いた要素) |
| `event.target` | 実際にイベントが起きた要素 |

<!-- ノート: 対比枠。この2つを区別できれば、次のトピックの委譲は「もう分かっている」も同然です。 -->

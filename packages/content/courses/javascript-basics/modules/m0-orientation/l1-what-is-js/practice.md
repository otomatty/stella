# レッスン0-1 演習 — JavaScriptとは

対象トピック: 0-1-1 〜 0-1-4

## 手元で試す

この講座に自動採点の演習はありません。テキストエディタとブラウザーだけで手を動かせます。スマートフォンで受講している場合は、この節は飛ばして「演習問題」から進めてください。

1. テキストエディタで次の内容を書き、`hello.html` という名前で保存する

```html
<body>
  <h1>JavaScriptの練習</h1>
  <script>
    console.log("読み込みました");
    console.log(1 + 2);
  </script>
</body>
```

2. 保存したファイルをブラウザーで開く
3. F12キー(Macは Cmd+Option+I)で開発者ツールを開き、「コンソール」タブに切り替える
4. `読み込みました` と `3` が出ていれば成功

書けたら、次の改造を試してみましょう。

1. `console.log` の行を1行増やして、自分の好きな文字を出す
2. `1 + 2` を別の計算に書き換えて、結果が変わることを確かめる
3. コンソールに直接 `10 * 20` と打ってEnterを押し、ファイルを直さなくても計算できることを確かめる

## 演習問題

### 問1(基本)

次の依頼は、HTML・CSS・JavaScriptのどれを書く仕事ですか。それぞれ答えてください。

1. お知らせの一覧に項目を1つ足したい
2. ボタンを押したら「送信しました」と表示したい
3. 見出しの文字をいつも紺色にしたい

### 問2(基本)

scriptタグをbodyの閉じタグの直前に置くのはなぜですか。1〜2文で説明してください。

### 問3(応用)

次のコードをブラウザーで開いたとき、コンソールに出る順番を答えてください。

```js
console.log("A");
console.log(2 + 3);
console.log("B");
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

1. HTML — ページの中身を変えるから
2. JavaScript — 操作への反応(動き)だから
3. CSS — いつも同じ見た目の指定だから

「中身・見た目・動き」のどれに当たるかで切り分けます。

</details>

<details>
<summary>問2の解答例</summary>

ブラウザーはHTMLを上から読むため、末尾に置けばscriptが動く時点でページの要素が出そろっているからです。あとで要素を取って変えるときに、まだ無い要素を触る失敗を防げます。

</details>

<details>
<summary>問3の解答例</summary>

`A` → `5` → `B` の順です。JavaScriptは書いた順に1行ずつ実行されます。2行目は計算の結果である `5` が出ます。

</details>

## 確認クイズ

### Q1. JavaScriptの担当はどれですか。

- A. ページに何を置くか
- B. ページの見た目
- C. 操作に反応する動き

<details>
<summary>答え</summary>

**C** — 中身はHTML、見た目はCSS、動きがJavaScriptです。

</details>

### Q2. この講座でのscriptタグの置き場所はどこですか。

- A. headの中
- B. bodyの閉じタグの直前
- C. HTMLファイルの先頭

<details>
<summary>答え</summary>

**B** — 末尾に置けば、動く時点でページの要素が出そろっています。

</details>

### Q3. console.log(2 + 3) を実行するとコンソールには何が出ますか。

- A. 2 + 3
- B. 5
- C. 何も出ない

<details>
<summary>答え</summary>

**B** — カッコの中が計算のときは、計算した結果が出ます。

</details>

### Q4. JavaScriptの実行順として正しいものはどれですか。

- A. 書いた順に1行ずつ実行される
- B. 短い行から先に実行される
- C. 全行が同時に実行される

<details>
<summary>答え</summary>

**A** — 上から順に1行ずつです。だから前の行の結果を次の行が使えます。

</details>

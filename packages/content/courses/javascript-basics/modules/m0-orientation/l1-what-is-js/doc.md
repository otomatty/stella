# レッスン0-1 JavaScriptとは

## このレッスンの目標

- [ ] HTML・CSS・JavaScriptの担当の違いを説明できる
- [ ] scriptタグをbodyの末尾に置いてJavaScriptを書ける
- [ ] console.logの結果を開発者ツールのコンソールで確認できる

## 0-1-1 JavaScriptはページに動きを付ける

> **JavaScriptは、HTMLとCSSで作ったページに動きを付けるための言語**

HTML/CSS入門で作ったページは、表示されたら終わりでした。ボタンを置くことはできても、押したときに何かを起こすことはできません。この「操作に反応して何かをする」部分を書く言語が **JavaScript** です。

| 言語 | 担当 |
| --- | --- |
| **HTML** | ページの中身(何を置くか) |
| **CSS** | 見た目(どう見せるか) |
| **JavaScript** | **動き**(操作にどう反応するか) |

```js
alert("こんにちは!");
```

この1行を動かすと、**ブラウザー** に小さなダイアログが出ます。「ページを表示したあとに何かをする」がJavaScriptの担当する動きです(`alert` はここだけの体験用で、以降の本編では使いません)。

線引きの感覚も大事です。「見出しの色をいつも赤にする」のはCSSの仕事で、JavaScriptで書くことではありません。「押したら色が変わる」のように操作への反応が絡んだら、JavaScriptの出番です。

## 0-1-2 scriptタグはbodyの末尾に置く

> **JavaScriptはscriptタグに書き、bodyの閉じタグの直前に置く**

JavaScriptは、HTMLの中の `script` という **タグ** で囲んだ場所に書きます。置き場所はこの講座では1つに固定します。**body** の閉じタグ `</body>` の直前です。

```html
<body>
  <h1>お知らせ</h1>
  <script>
    alert("こんにちは!");
  </script>
</body>
```

ブラウザーはHTMLを上から読むので、`script` が末尾にあれば、動き出す時点でページの **要素** は出そろっています。あとのモジュールで「ページの要素を取って変える」ことをするとき、この置き場所が効いてきます。

CSSと同じように、別ファイルに分けることもできます。

```html
<script src="script.js"></script>
```

実務では別ファイルが基本ですが、この講座の例は、まずファイル1つで完結する「中に書く」形で示します。なお `<script type="module">` という書き方もありますが、保存したファイルをそのままブラウザーで開く学習スタイルでは動かないことがあるため、この講座では使いません。

## 0-1-3 コンソールで動きを確かめる

> **console.logで出した値は、開発者ツールのコンソールで確認できる**

JavaScriptの計算結果は、画面には自動で表示されません。中で何が起きているかを見る窓が、**開発者ツール** の **コンソール** です。開発者ツールはF12キー(Macは Cmd+Option+I)で開き、「コンソール」(Console)タブに切り替えます。

コードからコンソールへ値を出すのが `console.log()` です。

```js
console.log("読み込みました");
console.log(1 + 2);
// => 読み込みました
// => 3
```

カッコの中に「見たいもの」を書きます。文字はそのまま、計算は結果が表示されます。この講座では、動きの確認はすべて `console.log` で行います。

コンソールには直接入力もできます。`1 + 2` と打ってEnterを押せば、ファイルを作らなくてもその場で結果が出ます。ちょっとした試し書きに便利です。

## 0-1-4 上から順に実行される

> **JavaScriptは、書いた順に1行ずつ実行される**

HTMLは全体で一枚の文書でしたが、JavaScriptは「手順書」です。ブラウザーはscriptタグの中を上から読み、1 **行** ずつ **実行**(書いてあることを実際に行うこと)します。

```js
console.log("1番目");
console.log("2番目");
console.log("3番目");
```

コンソールには必ずこの順で出ます。前の行の結果を次の行が使えるのも、この順序があるからです。

順序は結果を変えます。

```js
console.log("合計を出します");
console.log(120 + 80);
```

この2行を入れ替えると、案内より先に数字が出てしまいます。「準備の行が先、それを使う行が後」という並びは、次のモジュールで変数を学ぶときにもそのまま効いてきます。

## もっと知りたい人へ

- 開発者ツールの開き方はブラウザーごとに少し違います。メニューから「その他のツール」→「デベロッパーツール」でも開けます
- `alert` のような「いきなり画面に出る」命令は、実務では確認用にもほぼ使いません。コンソールで確認する習慣をここで付けておくと、後がずっと楽になります

# JavaScriptはページに動きを付ける

JavaScript入門研修 — Module 0 / レッスン0-1

<!-- ノート: HTML/CSS入門を終えた人が対象です。作った静的ページの「次」がこの講座だと伝えます。 -->

---

## なぜ必要か

- HTMLとCSSで作ったページは、表示されたら終わり
- 「ボタンを押したら中身が変わる」は、HTMLとCSSだけでは書けない
- この「押したら変わる」を書く担当が要る

<!-- ノート: つかみ。前講座で作ったページを思い出してもらい、クリックしても何も起きないことを指摘します。ここで結論は言いません。 -->

---

## 結論

**JavaScriptは、HTMLとCSSで作ったページに動きを付けるための言語**

- **HTML** = ページの中身
- **CSS** = 見た目
- **JavaScript** = **動き**(押したら・入力したら、どうするか)

<!-- ノート: 結論を言い切ります。3つの言語の分担は、この講座全体で何度も戻ってくる地図です。 -->

---

## 最小のコード

```js
alert("こんにちは!");
```

- この1行で、ブラウザーに小さなダイアログが出る
- 「ページを表示したあとに何かをする」が動きの正体

<!-- ノート: alertはこの場かぎりの体験用で、以降の本線では使いません。1行で画面が反応する体験だけ持ち帰ってもらいます。 -->

---

## 動きの例

| 画面の動き | 裏で動いている言語 |
| --- | --- |
| ボタンを押すと項目が増える | JavaScript |
| 入力欄の文字数を数えて表示する | JavaScript |
| 見出しの色を変える(常に) | CSS |

- 「いつも同じ見た目」はCSS、「操作に反応する」はJavaScript

<!-- ノート: 対比枠。CSSでできることをJavaScriptで書かない、という線引きも実務では大事だと補足します。 -->

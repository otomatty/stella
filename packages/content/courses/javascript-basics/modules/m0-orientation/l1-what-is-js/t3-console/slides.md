# コンソールで動きを確かめる

JavaScript入門研修 — Module 0 / レッスン0-1

<!-- ノート: HTML/CSS入門で使った開発者ツールに、JavaScript用の画面があることを紹介します。 -->

---

## なぜ必要か

- JavaScriptの計算結果は、画面に自動では表示されない
- 「いま中で何が起きているか」を見る窓が要る
- alertを毎回出すのは、確認のたびに手が止まってつらい

<!-- ノート: つかみ。動きのプログラムは中身が見えないと直せない、という話です。 -->

---

## 結論

**console.logで出した値は、開発者ツールのコンソールで確認できる**

- **開発者ツール** の **コンソール** = JavaScript専用の確認窓
- `console.log(値)` と書くと、その値がコンソールに出る

<!-- ノート: 結論。開発者ツールはF12またはmac: Cmd+Option+I。この講座の確認はすべてconsole.logで行います。 -->

---

## 最小のコード

```html
<script>
  console.log("読み込みました");
  console.log(1 + 2);
</script>
```

- コンソールに `読み込みました` と `3` が出る

<!-- ノート: 文字はそのまま、計算は結果が出る、という2例。カッコの中に「見たいもの」を書く、とだけ押さえます。 -->

---

## コンソールは直接入力もできる

- コンソールに `1 + 2` と打ってEnterでも、その場で結果が出る
- ちょっとした試し書きは、ファイルを作らずここでできる

<!-- ノート: 関連枠。この講座の「手元で試す」では、ファイルに書く方法とコンソールに打つ方法を使い分けます。 -->

# エラーメッセージは場所を教えてくれる

JavaScript入門 — Module 0 / レッスン0-2

## なぜ必要か

- 書き間違えると、動きが止まって赤い文字が出る
- 読まずに閉じると、どこを直せばいいか分からないまま
- 実は、直すための情報がそこに全部書いてある

<!-- ノート: つかみ。赤い文字を見た瞬間に目をそらすのが初心者あるあるです。読めば得しかない、と伝えます。 -->

---

## 結論

**エラーメッセージには、原因の種類と起きた行番号が書かれている**

- **エラー** = 実行できなかった・失敗したという知らせ
- **エラーメッセージ** の読み方: 種類 → **行番号** の順に見る

<!-- ノート: 結論。全部英語ですが、見るのは2か所だけでよい、とハードルを下げます。 -->

---

## 読み方の例

```text
Uncaught ReferenceError: prise is not defined
    at script.js:3
```

- 種類: `ReferenceError`(知らない名前を使った)
- 場所: `script.js` の **3行目**

<!-- ノート: priceのつづり間違いという後のモジュールでも起きがちな例です。「is not defined = そんな名前は知らない」とだけ訳しておきます。 -->

---

## 行番号の使い方

- コンソールのエラーは、クリックするとその行を表示してくれる
- 直すのは「その行」か「その1〜2行上」がほとんど

<!-- ノート: 関連枠。エラーの行そのものではなく直前の行に原因がある(閉じ忘れなど)ケースも先に伝えておきます。 -->

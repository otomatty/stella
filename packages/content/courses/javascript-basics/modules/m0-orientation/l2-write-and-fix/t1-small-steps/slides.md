# 0-2-1
# 少し書いては動かして確かめる

JavaScript入門研修 — Module 0 / レッスン0-2

<!-- ノート: 書き方の前に「進め方」を固めるトピックです。この講座全体の作業リズムになります。 -->

---

## なぜ必要か

- 10行書いてから動かして失敗すると、どの行が悪いのか分からない
- 動きのプログラムは、途中経過が画面に見えない
- 失敗の範囲を狭くする進め方が要る

<!-- ノート: つかみ。全部書いてから確かめる進め方は、未経験者が最初にはまる落とし穴です。 -->

---

## 結論

**一度に書き切らず、少し書くたびに保存して動かして確かめる**

- 1〜2行書く → **保存** → ブラウザーを **再読み込み** → コンソールを見る
- この一周を小さく速く回す

<!-- ノート: 結論。HTML/CSSでも保存と再読み込みはやりましたが、JavaScriptでは「コンソールを見る」まで含めて一周です。 -->

---

## 最小のコード

```js
console.log("ここまで動いた");
```

- 書きかけの途中に、この1行を置いて動かしてよい
- 出れば、そこまでは正しく実行されている

<!-- ノート: 「ここまで動いた」を挟む小技は、この後のすべてのモジュールの手元確認で使います。 -->

---

## 変わらないときの確認順

1. 保存したか
2. 再読み込みしたか
3. 開いているのは、いま直したファイルか

<!-- ノート: HTML/CSS入門と同じ確認順です。JavaScriptでも原因の大半はこの3つで、コードを疑うのはその後です。 -->

# 構文エラーと論理エラー

JavaScript入門研修 — Module 0 / レッスン0-2

<!-- ノート: 「エラーが出ない=正しい」ではない、という大事な区別を入れるトピックです。 -->

---

## なぜ必要か

- 赤い文字が出る失敗と、出ないのに結果がおかしい失敗がある
- 同じ「バグ」でも、直し方の入り口が違う
- どちらのタイプかを先に見分けると、探す場所が絞れる

<!-- ノート: つかみ。「エラーは出てないのに動かないんです」という実務の定番の相談を紹介します。 -->

---

## 結論

**エラーには、動かない構文エラーと、動くが結果が違う論理エラーがある**

- **構文エラー**: 言葉のルール(**構文**)違反。実行が止まり、メッセージが出る
- **論理エラー**: 文法は正しい。実行はされるが、結果が意図と違う

<!-- ノート: 結論。構文=言語の文法、と一言で定義します。 -->

---

## 見比べる

```js
console.log("合計);        // 構文エラー: 閉じる"が無い
console.log(100 - 20);     // 論理エラー: 足すつもりだった
```

- 上はメッセージが出て止まる。下は `80` が出て、静かに間違う

<!-- ノート: 論理エラーはコンピューターにとっては正しい命令なので、誰も教えてくれません。だから0-2-1の「小さく確かめる」が効きます。 -->

# レッスン2-1 文字列を作る

## このレッスンの目標

- [ ] ダブルクォートで文字列を書ける
- [ ] テンプレートリテラルで変数を埋め込んだ文字列を作れる
- [ ] 引用符そのものを含む文字列を書ける

## 2-1-1 文字列は引用符で囲む

> **文字列は、ダブルクォートで囲んで作る**

お知らせの文面、ユーザー名、ボタンのラベル — 実務のプログラムは文字だらけです。文字を `佐藤` とそのまま書くと、JavaScriptには文字なのか変数名なのか区別できません。「ここからここまでが文字」という印が **引用符** です。

```js
const userName = "佐藤";
const message = "承認されました";
console.log(userName);  // => 佐藤
```

引用符にはいくつか種類がありますが、この講座では **ダブルクォート** `"` に統一します。`""` と書けば空の文字列(文字0個の文字列)も作れます。

囲み忘れには特徴的なエラーが出ます。

```js
const userName = 佐藤;  // エラー: 佐藤という変数を探しに行く
```

引用符が無いと変数名として解釈されるため、`佐藤 is not defined` のような `ReferenceError` になります。また、引用符は半角です。全角の `"` を打つと構文エラーになります。

## 2-1-2 テンプレートリテラルで埋め込む

> **バッククォートで囲んだ文字列には、${}で変数の値を埋め込める**

「佐藤さん、こんにちは」の「佐藤」だけ変数にしたい、はよくある場面です。`+` でつなぐと引用符と `+` だらけになって読みにくくなります。

```js
const userName = "佐藤";
console.log("こんにちは、" + userName + "さん");  // 読みにくい
console.log(`こんにちは、${userName}さん`);       // 文面の形のまま読める
```

**バッククォート** `` ` `` で囲む書き方を **テンプレートリテラル** といい、`${変数}` の場所に値が **埋め込み** されます。バッククォートはJISキーボードでは Shift+@ で入力します。

`${}` の中には計算式も書けます。

```js
const price = 1980;
console.log(`合計は${price * 3}円です`);  // => 合計は5940円です
```

改行もそのまま書けます。ダブルクォートの文字列は行をまたぐと構文エラーになりますが、テンプレートリテラルの中の改行はそのまま文字列になります。

```js
const notice = `お知らせ
明日は休業日です`;
```

この講座では、変数を含む文字列の組み立てはテンプレートリテラルを本線にします。

## 2-1-3 引用符そのものを文字列に入れる

> **囲みと別の引用符を使うか、\でエスケープすれば引用符自体を書ける**

`「"承認"ボタンを押してください」` のように、文面に引用符そのものを入れたいことがあります。素直に書くと、囲みの引用符がそこで終わったと解釈されて構文エラーになります。

解決策は2つです。

```js
const guide1 = '「"承認"を押してください」';
const guide2 = "「\"承認\"を押してください」";
console.log(guide1);  // どちらも同じ表示になる
```

1. **囲みと別の引用符を使う** — 引用符には **シングルクォート** `'` もあります。中身にダブルクォートを入れたいなら、外側をシングルクォートにします
2. **エスケープする** — 直前に `\` を付けて `\"` と書くと「引用符という文字そのもの」の意味になります。これを **エスケープ** といいます

読みやすいのは1の方法です。エスケープの仲間には他に `\n`(改行)や `\\`(`\` そのもの)があります。書く機会は多くありませんが、読めるようにしておくと古いコードやエラーメッセージで役立ちます。

## もっと知りたい人へ

- プロジェクトによっては文字列をシングルクォートに統一する流儀もあります。大事なのは「チームでどちらかにそろえる」ことです
- テンプレートリテラルの中でバッククォート自体を書きたいときも、エスケープ(`` \` ``)を使います

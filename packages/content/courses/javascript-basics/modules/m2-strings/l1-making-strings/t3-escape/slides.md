# 引用符そのものを文字列に入れる

JavaScript入門研修 — Module 2 / レッスン2-1

<!-- ノート: 引用符の入れ子問題です。頻度は高くないですが、はまると長い定番のつまずきです。 -->

---

## なぜ必要か

- `「"承認" ボタンを押してください」` のように、文面に引用符を入れたい
- 素直に書くと、囲みの引用符がそこで終わってしまう
- 構文エラーになり、どこが悪いのか分かりにくい

<!-- ノート: つかみ。"Press "OK""を見せて、どこまでが文字列か分からない状態を体感させます。 -->

---

## 結論

**囲みと別の引用符を使うか、\でエスケープすれば引用符自体を書ける**

- 引用符には **シングルクォート** `'` もある。囲みと中身で使い分ける
- `\"` のように直前に `\` を付ける方法を **エスケープ** という

<!-- ノート: 結論。2つの解決策を並べ、まず「別の引用符」の方が読みやすいと伝えます。 -->

---

## 最小のコード

```js
const guide1 = '「"承認"を押してください」';
const guide2 = "「\"承認\"を押してください」";
console.log(guide1);  // どちらも同じ表示になる
```

<!-- ノート: 上が別引用符方式、下がエスケープ方式。表示結果が同じことを確認します。 -->

---

## エスケープの仲間

| 書き方 | 意味 |
| --- | --- |
| `\"` / `\'` | 引用符そのもの |
| `\n` | 改行 |
| `\\` | \そのもの |

<!-- ノート: 関連枠。\nは古いコードやエラーメッセージで見かけます。読めれば十分です。 -->

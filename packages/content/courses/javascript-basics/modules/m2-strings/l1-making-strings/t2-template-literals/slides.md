# テンプレートリテラルで埋め込む

JavaScript入門研修 — Module 2 / レッスン2-1

<!-- ノート: 文字列組み立ての本線をテンプレートリテラルに置くトピックです。 -->

---

## なぜ必要か

- 「佐藤さん、こんにちは」の「佐藤」の部分だけ変数にしたい
- `+` でつなぐと、引用符と `+` だらけで読みにくい
- 文面の形のまま、変数を差し込める書き方がほしい

<!-- ノート: つかみ。"こんにちは、" + userName + "さん"を見せて、読みにくさを体感させます。 -->

---

## 結論

**バッククォートで囲んだ文字列には、${}で変数の値を埋め込める**

- **バッククォート** `` ` `` で囲む書き方を **テンプレートリテラル** という
- `${変数}` の場所に、値が **埋め込み** される

<!-- ノート: 結論。バッククォートはShift+@(JISキーボード)。キーの場所を必ず案内します。 -->

---

## 最小のコード

```js
const userName = "佐藤";
console.log(`${userName}さん、こんにちは`);
// => 佐藤さん、こんにちは
```

- `${}` の中には計算式も書ける: `` `合計は${price * 3}円` ``

<!-- ノート: 文面の形が保たれたまま読める点を、+連結との比較で強調します。 -->

---

## 改行もそのまま書ける

```js
const notice = `お知らせ
明日は休業日です`;
```

- テンプレートリテラルの中の改行は、そのまま文字列になる
- ダブルクォートの文字列は、行をまたぐと構文エラー

<!-- ノート: 関連枠。複数行の文面を作る場面(お知らせ・メールの文面)で便利です。 -->

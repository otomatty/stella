# 文字列は引用符で囲む

JavaScript入門研修 — Module 2 / レッスン2-1

<!-- ノート: ここまで見よう見まねで書いてきた"..."を正式に導入します。 -->

---

## なぜ必要か

- お知らせの文面、ユーザー名、ボタンのラベル — 実務は文字だらけ
- `佐藤` と書いたら、文字なのか変数名なのか区別できない
- 「ここからここまでが文字」という印が要る

<!-- ノート: つかみ。引用符が無いとReferenceErrorになる、と0-2のエラーの話につなげます。 -->

---

## 結論

**文字列は、ダブルクォートで囲んで作る**

- 文字を囲む記号が **引用符**
- この講座では **ダブルクォート** `"` に統一する

<!-- ノート: 結論。書き方が複数あるのは次の話。まず1つに統一します。 -->

---

## 最小のコード

```js
const userName = "佐藤";
const message = "承認されました";
console.log(userName);  // => 佐藤
```

- 空の文字列 `""` も作れる(文字0個の文字列)

<!-- ノート: 引用符は半角です。全角の"を打ってしまうと構文エラーになる、が初回の定番のつまずきです。 -->

---

## 囲み忘れると

```js
const userName = 佐藤;  // エラー: 佐藤という変数を探しに行く
```

- 引用符が無いと、JavaScriptは変数名として解釈する
- `is not defined` が出たら、引用符の付け忘れも疑う

<!-- ノート: 失敗例枠。エラーメッセージの読み(0-2-2)の実践例にもなっています。 -->

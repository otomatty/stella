# レッスン2-1 演習 — 文字列を作る

対象トピック: 2-1-1 〜 2-1-3

## 手元で試す

テキストエディタとブラウザーだけで進められます。スマートフォンで受講している場合は、この節は飛ばして「演習問題」から進めてください。

1. `strings.html` を作り、次を書いて保存する

```html
<body>
  <script>
    const userName = "佐藤";
    const taskCount = 3;
    console.log(`${userName}さんの今日のタスクは${taskCount}件です`);
  </script>
</body>
```

2. コンソールに `佐藤さんの今日のタスクは3件です` と出ることを確かめる

書けたら、次の改造を試してみましょう。

1. `userName` を自分の名前に変えて表示する
2. `${taskCount}` を `${taskCount + 2}` に変えて、埋め込みの中で計算できることを確かめる
3. 文面を複数行のお知らせにして、テンプレートリテラルの中の改行がそのまま出ることを確かめる
4. `console.log('「"完了"を押してください」');` を足して、引用符入りの文字列を表示する

## 演習問題

### 問1(基本)

次のコードの問題点を指摘し、直してください。

```js
const status = 完了;
```

### 問2(基本)

変数 `price`(値は `1980`)を使って、`価格は1980円です` と表示するコードをテンプレートリテラルで書いてください。

### 問3(応用)

次のコードは構文エラーになります。理由を説明し、2通りの方法で直してください。

```js
const guide = "「"OK"を押す」";
```

## 解答例と解説

<details>
<summary>問1の解答例</summary>

`完了` が引用符で囲まれていないため、変数名として解釈されて `ReferenceError` になります。`const status = "完了";` と直します。

</details>

<details>
<summary>問2の解答例</summary>

```js
const price = 1980;
console.log(`価格は${price}円です`);
```

バッククォートで囲み、`${price}` の場所に値が埋め込まれます。

</details>

<details>
<summary>問3の解答例</summary>

`"「"` の2つ目のダブルクォートで文字列が終わったと解釈され、続きが構文エラーになります。

```js
const guide1 = '「"OK"を押す」';      // 囲みをシングルクォートにする
const guide2 = "「\"OK\"を押す」";    // エスケープする
```

</details>

## 確認クイズ

### Q1. この講座で文字列を作るときの基本の囲み方はどれですか。

- A. ダブルクォートで囲む
- B. 何も囲まない
- C. ()で囲む

<details>
<summary>答え</summary>

**A** — 引用符が無いと変数名として解釈されてしまいます。

</details>

### Q2. テンプレートリテラルの説明として正しいものはどれですか。

- A. ダブルクォートで囲み、+で変数をつなぐ
- B. バッククォートで囲み、${}で変数の値を埋め込む
- C. シングルクォートで囲むと自動で変数が埋め込まれる

<details>
<summary>答え</summary>

**B** — 囲みはバッククォート、埋め込みは${}です。${}の中では計算もできます。

</details>

### Q3. `合計${1000 + 500}円` (バッククォート囲み) の表示結果はどれですか。

- A. 合計${1000 + 500}円
- B. 合計1500円
- C. 構文エラーになる

<details>
<summary>答え</summary>

**B** — ${}の中の式は計算され、結果が埋め込まれます。

</details>

### Q4. 文字列の中にダブルクォートそのものを入れる方法として正しいものはどれですか。

- A. 囲みをシングルクォートにするか、\"とエスケープする
- B. ダブルクォートを2回続けて書く
- C. 全角のダブルクォートを使う

<details>
<summary>答え</summary>

**A** — 囲みと別の引用符を使うか、\でエスケープします。全角の引用符は別の文字です。

</details>

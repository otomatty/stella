# 文字列は道具を持っている

JavaScript入門 — Module 2 / レッスン2-2

<!-- ノート: メソッドという語をここで導入します。配列・DOMまでずっと使う、この講座の最重要語の1つです。 -->

## なぜ必要か

- 「文字数を数えたい」「大文字にしたい」を自力で書くのは大変
- 実は、値の側が便利な道具を最初から持っている
- その道具の呼び出し方を1つ覚えれば、全部同じ形で使える

<!-- ノート: つかみ。文字数チェック(入力が長すぎないか)という実務の場面から入ります。 -->

---

## 結論

**文字列にドットを付けると、lengthやメソッドという道具を使える**

- 値に **ドット** `.` を付けて呼び出す道具のうち、`()` を付けて実行するものを **メソッド** という
- **length** は `()` なしで文字数を返す

<!-- ノート: 結論。length(カッコなし)とメソッド(カッコあり)の見た目の違いをここで示します。 -->

---

## 最小のコード

```js
const comment = "対応ありがとうございました";
console.log(comment.length);          // => 13
console.log(comment.toUpperCase);     // 道具そのもの
console.log("abc".toUpperCase());     // => "ABC"
```

<!-- ノート: カッコを付け忘れると道具そのものが表示される、という違いを実演します。 -->

---

## 道具は値の種類ごとに違う

- 文字列には文字列の道具、数値には数値の道具がある
- このレッスンでは、文字列の道具を4つ覚える
- 使い方はすべて `値.道具名()` の形

# sliceで切り出す

JavaScript入門研修 — Module 2 / レッスン2-2

## なぜ必要か

- 「社員番号の先頭3文字だけほしい」「年の部分だけ取り出したい」
- 文字列の一部だけを使う場面は多い
- そのためには「何文字目」の数え方を決める必要がある

<!-- ノート: つかみ。IDやコード値の切り出しは業務システムの定番処理です。 -->

---

## 結論

**sliceは、0から数えたインデックスで指定した範囲を切り出す**

- 文字の位置を **インデックス** といい、**0始まり** で数える
- `slice(開始, 終了)` は開始から「終了の手前」までを切り出す

<!-- ノート: 結論。最初の文字が0番、終了は含まない。この2点がすべてです。 -->

---

## 最小のコード

```js
const employeeId = "EMP-2026-001";
console.log(employeeId.slice(0, 3));  // => "EMP"
console.log(employeeId.slice(4, 8));  // => "2026"
```

<!-- ノート: E=0, M=1, P=2, -=3...と指で数えながら確認します。 -->

---

## 数え方の図

```text
 E  M  P  -  2  0  2  6
 0  1  2  3  4  5  6  7
```

- `slice(4, 8)` = インデックス4から、8の手前(7)まで
- 終了を省くと最後まで: `slice(4)` → `"2026-001"`

<!-- ノート: 「終了は含まない」は最初は不自然に感じますが、終了-開始=文字数になる利点を添えます。 -->

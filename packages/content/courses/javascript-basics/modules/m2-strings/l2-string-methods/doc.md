# レッスン2-2 文字列を操作する

## このレッスンの目標

- [ ] メソッドとlengthを「値.道具名」の形で使える
- [ ] includes / slice / toLowerCase / replaceの使いどころを説明できる
- [ ] インデックスの0始まりの数え方で範囲を切り出せる

## 2-2-1 文字列は道具を持っている

> **文字列にドットを付けると、lengthやメソッドという道具を使える**

「文字数を数えたい」「大文字にしたい」を自力で書く必要はありません。値の側が便利な道具を最初から持っています。

値に **ドット** `.` を付けて呼び出す道具のうち、`()` を付けて実行するものを **メソッド** と呼びます。**length** は例外的に `()` なしで、文字数を返します(ふだんの文字ではそのまま文字数として使えますが、絵文字など一部の文字では見た目の文字数とずれます)。

```js
const comment = "対応ありがとうございました";
console.log(comment.length);       // => 13
console.log("abc".toUpperCase());  // => "ABC"
```

メソッドに `()` を付け忘れると、実行されずに道具そのものが表示されます。「呼び出すならカッコ」と覚えてください。

道具は値の種類ごとに違います(文字列には文字列の道具、数値には数値の道具)。使い方はすべて `値.道具名()` の同じ形です。このレッスンでは文字列の道具を4つ覚えます。

## 2-2-2 includesで含むか調べる

> **includesは、その文字列が含まれているかをtrueかfalseで返す**

「件名に『緊急』が入っていたら目立たせたい」「メールアドレスに@が入っているか確かめたい」 — 含む/含まないの判定は検索・チェックの基本部品です。

```js
const subject = "【緊急】サーバー障害の報告";
console.log(subject.includes("緊急"));  // => true
console.log(subject.includes("完了"));  // => false
```

**includes** の結果は真偽値です。レッスン1-2の比較演算子と同じで、「判定の結果は値」なので、あとで条件分岐にそのまま使えます。なお、大文字小文字や全角半角は区別されます。

先頭だけ調べる **startsWith** もあります。

```js
const fileName = "report_2026.txt";
console.log(fileName.startsWith("report"));  // => true
```

「reportで始まるファイルだけ処理する」のような絞り込みに使います。仲間に `endsWith`(で終わるか)もあります。

## 2-2-3 sliceで切り出す

> **sliceは、0から数えたインデックスで指定した範囲を切り出す**

「社員番号の先頭3文字だけほしい」のように、文字列の一部だけを使う場面は多くあります。そのための数え方がインデックスです。

- 文字の位置を **インデックス** といい、**0始まり** で数える(最初の文字が0番)
- **slice**(開始, 終了) は、開始から「終了の手前」までを切り出す

```js
const employeeId = "EMP-2026-001";
console.log(employeeId.slice(0, 3));  // => "EMP"
console.log(employeeId.slice(4, 8));  // => "2026"
```

数え方を図にするとこうなります。

```text
 E  M  P  -  2  0  2  6
 0  1  2  3  4  5  6  7
```

「終了は含まない」のは最初は不自然に感じますが、終了 − 開始 = 切り出す文字数になるので慣れると数えやすい仕様です。終了を省くと最後までになります(`slice(4)` → `"2026-001"`)。

0始まりの数え方は、この先の配列でもまったく同じように使います。

## 2-2-4 大文字・小文字をそろえてから比べる

> **toLowerCaseなどで表記をそろえてから比べると、揺れに強くなる**

利用者は `OK` とも `ok` とも `Ok` とも入力してきます。`===` は表記の揺れをまったく許さないので、揺れたまま比べると正しい入力を弾いてしまいます。

```js
const answer = "OK";
console.log(answer === "ok");                // => false
console.log(answer.toLowerCase() === "ok");  // => true
```

- **toLowerCase** — すべて小文字に変換した文字列を返す
- **toUpperCase** — すべて大文字に変換した文字列を返す

「比べる直前にそろえる」が型です。元の変数の中身は変わらず、変換後の新しい文字列が返ります。

前後の空白は **trim** で落とせます。

```js
const input = "  ok  ";
console.log(input.trim().toLowerCase());  // => "ok"
```

メソッドはドットでつなげて続けて呼べます。入力値の掃除は「trimで空白を落とす → 表記をそろえる」の順が定番です。

## 2-2-5 replaceで置き換える

> **replaceは、見つけた文字列を新しい文字列に置き換える**

テキストエディタの「置換」をコードでやるのが **replace** です。

```js
const template = "{name}様にお送りします";
console.log(template.replace("{name}", "佐藤"));
// => "佐藤様にお送りします"
```

`文字列.replace(探す, 新しい)` の形で、置き換えた結果の新しい文字列が返ります(元は変わりません)。文面のテンプレートが後から届くような場面では、テンプレートリテラルよりreplaceの出番です。

注意点は「最初の1つだけ」置き換えることです。全部置き換えるなら **replaceAll** を使います。

```js
const date = "2026/08/26";
console.log(date.replace("/", "-"));     // => "2026-08/26"
console.log(date.replaceAll("/", "-"));  // => "2026-08-26"
```

## もっと知りたい人へ

- 文字列のメソッドは他にもたくさんあります。「JavaScript 文字列 メソッド 一覧」で検索すると、リファレンスが見つかります。全部覚える必要はなく、「やりたいこと + JavaScript」で調べて使うのが実務の姿です
- lengthが見た目の文字数とずれるのは、コンピューター内部の数え方(UTF-16という単位)で数えているためです。`"😀".length` は `2` になります

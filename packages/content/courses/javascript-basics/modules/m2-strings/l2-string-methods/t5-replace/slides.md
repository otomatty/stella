# replaceで置き換える

JavaScript入門 — Module 2 / レッスン2-2

<!-- ノート: 文字列メソッドの締めです。「元は変わらず新しい文字列が返る」を改めて確認します。 -->

---

## なぜ必要か

- 文面のテンプレートの一部だけ差し替えたい
- 「様」を「さん」に直したい、記号を取り除きたい
- 手で直すのではなく、コードで置き換えたい

<!-- ノート: つかみ。エディタの「置換」機能をコードでやる、と例えます。 -->

---

## 結論

**replaceは、見つけた文字列を新しい文字列に置き換える**

- `文字列.replace(探す, 新しい)` の形で使う
- 置き換えた結果の新しい文字列が返る(元は変わらない)

<!-- ノート: 結論。「元は変わらない」はtoLowerCaseと同じ性質です。 -->

---

## 最小のコード

```js
const template = "{name}様にお送りします";
console.log(template.replace("{name}", "佐藤"));
// => "佐藤様にお送りします"
```

<!-- ノート: 差し込みテンプレートという実務っぽい例です。テンプレートリテラルとの使い分け(文面が後から来るときはreplace)にも触れます。 -->

---

## 全部置き換えるならreplaceAll

```js
const date = "2026/08/26";
console.log(date.replace("/", "-"));     // => "2026-08/26"
console.log(date.replaceAll("/", "-"));  // => "2026-08-26"
```

- **replace** は最初の1つだけ、**replaceAll** は全部置き換える

<!-- ノート: 対比枠。「最初の1つだけ」は気づきにくい仕様なので、失敗例として見せます。 -->

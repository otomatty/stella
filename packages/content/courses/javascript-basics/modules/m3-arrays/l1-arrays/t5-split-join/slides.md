# 3-1-5
# splitとjoinで文字列と行き来する

JavaScript入門 — Module 3 / レッスン3-1

<!-- ノート: 文字列と配列の変換です。CSV的なデータの分解は実務での登場頻度が高い操作です。 -->

---

## なぜ必要か

- `"佐藤,鈴木,高橋"` のようなカンマ区切りの文字列がよく届く
- 1人ずつ扱うには、配列に分けたい
- 逆に、配列を「、」区切りの文面にしたいこともある

<!-- ノート: つかみ。CSVやタグ一覧など、区切り文字入りの文字列は実務の定番データです。 -->

---

## 結論

**splitは文字列を配列に分け、joinは配列を1つの文字列につなぐ**

- 分ける・つなぐの目印になる文字を **区切り文字** という
- `文字列.split(区切り)` ⇄ `配列.join(区切り)`

<!-- ノート: 結論。双方向で対になっている、と覚えます。 -->

---

## 最小のコード

```js
const csv = "佐藤,鈴木,高橋";
const members = csv.split(",");
console.log(members);           // => ["佐藤", "鈴木", "高橋"]
console.log(members.join("、")); // => "佐藤、鈴木、高橋"
```

<!-- ノート: 分けるときの区切りとつなぐときの区切りは別々に選べる点がミソです。 -->

---

## joinの区切りは自由

```js
const members = ["佐藤", "鈴木", "高橋"];
console.log(members.join(" / "));  // => "佐藤 / 鈴木 / 高橋"
console.log(members.join(""));     // => "佐藤鈴木高橋"
```

- 空文字を渡せば、区切りなしで連結できる

<!-- ノート: 関連枠。表示用の文面作りにjoinが便利、という使い道を見せます。 -->

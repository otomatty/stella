# 番号で読み書きする

JavaScript入門 — Module 3 / レッスン3-1

<!-- ノート: sliceで学んだ0始まりのインデックスが、配列でそのまま使えることを示すトピックです。 -->

---

## なぜ必要か

- 一覧の「最初の1件」だけ表示したい
- 「2番目の項目を書き換えたい」もある
- 配列の中の特定の要素を指す方法が要る

<!-- ノート: つかみ。全部ではなく1つだけ触りたい、という場面です。 -->

---

## 結論

**配列[インデックス]で要素を読み書きでき、番号は0から数える**

- 数え方は文字列のsliceと同じ **0始まり**
- 読むのも書き換えるのも `配列[番号]`

<!-- ノート: 結論。新しい概念はほぼゼロで、sliceの数え方の再利用だと安心させます。 -->

---

## 最小のコード

```js
const tasks = ["見積作成", "レビュー", "報告書"];
console.log(tasks[0]);   // => "見積作成"
tasks[1] = "コードレビュー";
console.log(tasks[1]);   // => "コードレビュー"
```

<!-- ノート: constの配列でも要素の書き換えはできる点は、次のスライドで拾います。 -->

---

## constなのに書き換えられる?

- constが禁止するのは「変数への再代入」(入れ物ごとの交換)
- 中身の要素の入れ替えは再代入ではないのでできる
- 最後の要素は `tasks[tasks.length - 1]` で取れる

<!-- ノート: 関連枠。ここは混乱ポイントなので「入れ物は同じ、中身は変わる」という言い方で通します。 -->

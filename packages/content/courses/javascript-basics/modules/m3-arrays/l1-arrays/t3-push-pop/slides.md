# pushとpopで末尾を出し入れする

JavaScript入門研修 — Module 3 / レッスン3-1

<!-- ノート: 配列を「増減するリスト」として使えるようにするトピックです。M8の買い物リストの布石でもあります。 -->

## なぜ必要か

- タスクは後から増える。終わったら消したい
- 配列を作り直さずに、その場で伸び縮みさせたい
- 一覧に「追加」するのは、この講座の最後の総仕上げでも使う操作

<!-- ノート: つかみ。リストは作って終わりではなく、運用中に増減するものです。 -->

---

## 結論

**pushは配列の末尾に要素を足し、popは末尾の要素を取り出す**

- **push**(値) — 末尾に追加。配列は1つ伸びる
- **pop**() — 末尾を取り除き、その要素を返す

<!-- ノート: 結論。どちらも「末尾」に対する操作、とまとめて覚えます。 -->

---

## 最小のコード

```js
const tasks = ["見積作成", "レビュー"];
tasks.push("報告書");
console.log(tasks);        // => ["見積作成", "レビュー", "報告書"]
console.log(tasks.pop());  // => "報告書"
console.log(tasks.length); // => 2
```

<!-- ノート: pushで伸び、popで縮む様子をlengthでも確認します。 -->

---

## 文字列のメソッドとの違い

- 文字列のメソッドは「新しい文字列を返す」(元は変わらない)
- pushとpopは **配列そのものを変える**
- 変えたくないときの増やし方は、関数を学んだあとに出てくる

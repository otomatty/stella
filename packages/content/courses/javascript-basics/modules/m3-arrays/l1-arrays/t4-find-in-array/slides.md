# 配列からも探せる

JavaScript入門 — Module 3 / レッスン3-1

## なぜ必要か

- 「この担当者は当番表に入っているか?」を調べたい
- 「どの位置にあるか」まで知りたいこともある
- 文字列で学んだ「探す」を、配列でもやりたい

<!-- ノート: つかみ。存在チェックはバリデーションや重複防止の基本部品です。 -->

---

## 結論

**includesは配列でも使え、indexOfは見つかった位置を返す**

- `配列.includes(値)` — 入っていればtrue
- `配列.indexOf(値)` — 見つかったインデックス。無ければ **-1**

<!-- ノート: 結論。同じ名前のメソッドが同じ意味で使える気持ちよさを強調します。 -->

---

## 最小のコード

```js
const members = ["佐藤", "鈴木", "高橋"];
console.log(members.includes("鈴木"));  // => true
console.log(members.indexOf("高橋"));   // => 2
console.log(members.indexOf("田中"));   // => -1
```

<!-- ノート: -1は「見つからなかった」の合図です。0始まりなので0は先頭という正常な位置、と区別します。 -->

---

## どちらを使う?

| 知りたいこと | 使う道具 |
| --- | --- |
| 入っているかどうかだけ | `includes` |
| 位置(何番目か) | `indexOf` |

- 「あるかどうか」に `indexOf(x) !== -1` と書く古い流儀もあるが、includesの方が読みやすい

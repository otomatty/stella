# 3-1-1
# 配列は値を順番に並べる

JavaScript入門研修 — Module 3 / レッスン3-1

<!-- ノート: 配列の導入です。「値が1つずつでは足りない」場面から入ります。 -->

---

## なぜ必要か

- タスクが3件あるとき、`task1` `task2` `task3` と変数を作るのはつらい
- 件数が増えるたびに変数が増え、まとめて扱えない
- 「複数の値を1つの入れ物で持つ」仕組みが要る

<!-- ノート: つかみ。タスク一覧・商品一覧など、実務のデータはほぼ「複数」です。 -->

---

## 結論

**配列は[]で作り、複数の値を順番に持てる**

- **配列** = 値を順番に並べて持つ入れ物
- 中の1つ1つの値を「要素」と呼ぶ

<!-- ノート: 結論。順番を保つ、というのが配列の特徴です。HTMLの要素と同じ言葉ですが、ここでは配列の中身を指します。 -->

---

## 最小のコード

```js
const tasks = ["見積作成", "レビュー", "報告書"];
console.log(tasks);
// => ["見積作成", "レビュー", "報告書"]
```

- `[]` の中に、値をカンマで区切って並べる

<!-- ノート: コンソールでの配列の表示のされ方も確認します。空の配列[]も作れると補足。 -->

---

## 何個入っているかはlength

```js
const tasks = ["見積作成", "レビュー", "報告書"];
console.log(tasks.length);  // => 3
```

- 文字列と同じく、配列もlengthを持っている

<!-- ノート: 関連枠。lengthは文字列で学んだものと同じ書き方で、配列では要素数を返します。 -->

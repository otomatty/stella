# レッスン3-1 値をリストで持つ

## このレッスンの目標

- [ ] 配列を作り、インデックスで要素を読み書きできる
- [ ] pushとpopで配列を伸び縮みさせられる
- [ ] includes / indexOf / split / joinの使いどころを説明できる

## 3-1-1 配列は値を順番に並べる

> **配列は[]で作り、複数の値を順番に持てる**

タスクが3件あるとき、`task1` `task2` `task3` と変数を作っていくのはつらい方法です。件数が増えるたびに変数が増え、まとめて扱うこともできません。複数の値を1つの入れ物で持つのが **配列** です。

```js
const tasks = ["見積作成", "レビュー", "報告書"];
console.log(tasks);
// => ["見積作成", "レビュー", "報告書"]
```

`[]` の中に値をカンマで区切って並べます。中の1つ1つの値を「要素」と呼びます(HTMLの要素と同じ言葉ですが、ここでは配列の中身のことです)。`[]` だけ書けば空の配列も作れます。

配列も文字列と同じく `length` を持っていて、要素の数を返します。

```js
console.log(tasks.length);  // => 3
```

## 3-1-2 番号で読み書きする

> **配列[インデックス]で要素を読み書きでき、番号は0から数える**

一覧の「最初の1件」だけ表示したい、「2番目を書き換えたい」 — 特定の要素を指すには、文字列のsliceで学んだインデックス(0始まり)をそのまま使います。

```js
const tasks = ["見積作成", "レビュー", "報告書"];
console.log(tasks[0]);   // => "見積作成"
tasks[1] = "コードレビュー";
console.log(tasks[1]);   // => "コードレビュー"
```

読むのも書き換えるのも `配列[番号]` です。最後の要素は `tasks[tasks.length - 1]` で取れます(lengthは個数、インデックスは0始まりなので1つずれます)。

「constで宣言したのに書き換えられるの?」と思ったら、こう整理してください。constが禁止するのは **変数への再代入**(入れ物ごとの交換)で、中身の要素の入れ替えは再代入ではありません。入れ物は同じまま、中身が変わっています。

## 3-1-3 pushとpopで末尾を出し入れする

> **pushは配列の末尾に要素を足し、popは末尾の要素を取り出す**

タスクは後から増えますし、終わったら減らしたくなります。配列を作り直さずにその場で伸び縮みさせるのが **push** と **pop** です。

```js
const tasks = ["見積作成", "レビュー"];
tasks.push("報告書");
console.log(tasks);        // => ["見積作成", "レビュー", "報告書"]
console.log(tasks.pop());  // => "報告書"
console.log(tasks.length); // => 2
```

- `push(値)` — 末尾に追加。配列は1つ伸びる
- `pop()` — 末尾を取り除き、その要素を返す

どちらも「末尾」に対する操作です。ここで文字列のメソッドとの性質の違いに注意してください。replaceやtoLowerCaseは新しい文字列を返して元を変えませんが、**pushとpopは配列そのものを変えます**。

## 3-1-4 配列からも探せる

> **includesは配列でも使え、indexOfは見つかった位置を返す**

「この担当者は当番表に入っているか?」のような存在チェックには、文字列で学んだ `includes` が配列でもそのまま使えます。位置まで知りたいときは **indexOf** です。

```js
const members = ["佐藤", "鈴木", "高橋"];
console.log(members.includes("鈴木"));  // => true
console.log(members.indexOf("高橋"));   // => 2
console.log(members.indexOf("田中"));   // => -1
```

indexOfは見つからないと **-1** を返します。0は「先頭にある」という正常な位置なので、見つからなかった合図は0ではなく-1です。

| 知りたいこと | 使う道具 |
| --- | --- |
| 入っているかどうかだけ | `includes` |
| 位置(何番目か) | `indexOf` |

古いコードでは「あるかどうか」を `indexOf(x) !== -1` で書く流儀も見かけます。読めるようにしつつ、自分で書くときはincludesの方が読みやすい書き方です。

## 3-1-5 splitとjoinで文字列と行き来する

> **splitは文字列を配列に分け、joinは配列を1つの文字列につなぐ**

`"佐藤,鈴木,高橋"` のようなカンマ区切りの文字列は、実務でよく届くデータの形です。1人ずつ扱うには配列に分けます。分ける・つなぐの目印になる文字を **区切り文字** といいます。

```js
const csv = "佐藤,鈴木,高橋";
const members = csv.split(",");
console.log(members);           // => ["佐藤", "鈴木", "高橋"]
console.log(members.join("、")); // => "佐藤、鈴木、高橋"
```

- **split**(区切り) — 文字列を区切り文字で分けて、配列にする
- **join**(区切り) — 配列の要素を区切り文字でつないで、1つの文字列にする

分けるときとつなぐときの区切り文字は別々に選べます。joinに空文字 `""` を渡せば区切りなしで連結できますし、`" / "` のような複数文字も使えます。表示用の文面作りに便利です。

## もっと知りたい人へ

- 先頭に対する出し入れは `unshift`(先頭に追加)と `shift`(先頭から取り出し)があります。まずは末尾のpush/popで十分です
- 配列には他にも多くのメソッドがあります。「並べ替えたい」「合計したい」と思ったら「JavaScript 配列 やりたいこと」で検索してみてください。関数を学んだあとのモジュールで、代表的なmapとfilterを扱います

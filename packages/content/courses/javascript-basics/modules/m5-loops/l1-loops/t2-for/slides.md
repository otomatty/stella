# 5-1-2
# forは回数で繰り返す

JavaScript入門 — Module 5 / レッスン5-1

<!-- ノート: 古典的なforです。3つの部品(初期化・条件・更新)の読み解きが山場です。 -->

---

## なぜ必要か

- 「10回繰り返したい」— 配列が無い繰り返しもある
- 「何周目か」の番号を使いたいこともある
- 回数を数えながら回る仕組みが要る

<!-- ノート: つかみ。連番の生成(1〜10のリスト)などを例にします。 -->

---

## 結論

**forは、カウンター変数を使って決めた回数だけ繰り返す**

- 周回を数える変数を **カウンター** と呼ぶ(慣習で `i`)
- **for**(始まり; 続ける条件; 更新) の3点セットで制御する

<!-- ノート: 結論。iはindexのi。3つの部品はすべて既習(let・比較・更新)の組み合わせです。 -->

---

## 最小のコード

```js
for (let i = 1; i <= 3; i += 1) {
  console.log(`${i}回目の処理`);
}
// => 1回目の処理 2回目の処理 3回目の処理
```

<!-- ノート: i=1で開始→条件チェック→本体→更新→条件チェック...の流れを指でなぞります。 -->

---

## インデックスと組み合わせる

```js
const members = ["佐藤", "鈴木", "高橋"];
for (let i = 0; i < members.length; i += 1) {
  console.log(`${i + 1}番: ${members[i]}`);
}
```

- 0始まりで回してインデックスに使う。表示は `i + 1` で1始まりに

<!-- ノート: 関連枠。番号付きで配列を回る形。ただの全件処理ならfor...ofが読みやすい、と使い分けも一言。 -->

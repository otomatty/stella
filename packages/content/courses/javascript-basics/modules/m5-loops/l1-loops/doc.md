# レッスン5-1 繰り返す

## このレッスンの目標

- [ ] for...of / for / whileを場面で使い分けられる
- [ ] 無限ループの原因を指摘して直せる
- [ ] breakとcontinueで繰り返しの流れを制御できる

## 5-1-1 for...ofで配列を順に処理する

> **for...ofは、配列の要素を先頭から1つずつ取り出して繰り返す**

タスクが3件なら `tasks[0]`、`tasks[1]`、`tasks[2]` と書けますが、100件では現実的ではありませんし、件数が変わるたびに書き直すことになります。同じ処理を繰り返す仕組みを **ループ** といい、配列の全要素に対する処理は **for...of** で書きます。

```js
const tasks = ["見積作成", "レビュー", "報告書"];
for (const task of tasks) {
  console.log(`TODO: ${task}`);
}
```

形は `for (const 受け取る変数 of 配列) { 1周ぶんの処理 }` です。1周(**繰り返し**)ごとに、要素が先頭から順に変数へ入ってブロックが実行されます。変数名は自由ですが、配列が `tasks` なら単数形の `task` にすると読みやすくなります。

## 5-1-2 forは回数で繰り返す

> **forは、カウンター変数を使って決めた回数だけ繰り返す**

「10回繰り返したい」のように、配列が無い繰り返しもあります。周回を数える変数を **カウンター** と呼び(慣習で `i` を使います)、**for** はカウンターの3点セットで制御します。

```js
for (let i = 1; i <= 3; i += 1) {
  console.log(`${i}回目の処理`);
}
```

`for (始まり; 続ける条件; 更新)` の3つの部品は、すべて既習の組み合わせです(letの宣言・比較演算子・変数の更新)。流れは「始まり → 条件チェック → 本体 → 更新 → 条件チェック → …」で、条件がfalseになったら抜けます。

インデックスと組み合わせると、番号付きで配列を回れます。

```js
const members = ["佐藤", "鈴木", "高橋"];
for (let i = 0; i < members.length; i += 1) {
  console.log(`${i + 1}番: ${members[i]}`);
}
```

0始まりで回してインデックスに使い、表示だけ `i + 1` で1始まりにするのが定番です。番号が要らないただの全件処理なら、for...ofの方が読みやすい書き方です。

## 5-1-3 whileは条件が続く限り繰り返す

> **whileは、条件が真のあいだ繰り返し続ける**

「残高が300円未満になるまで引き落とす」のように、何回繰り返すか事前に分からない処理もあります。**while** は毎周の頭で条件を調べ、falseになったら抜けます。

```js
let balance = 1000;
while (balance >= 300) {
  balance -= 300;
  console.log(`引き落とし後: ${balance}円`);
}
// => 700円 → 400円 → 100円で終了
```

条件の書き方はifと同じです。3種類の入り口が出そろったので、使い分けを整理します。

| 繰り返しの種類 | 書き方 |
| --- | --- |
| 配列の全要素に | `for...of` |
| 決めた回数だけ | `for` |
| 条件が続く限り | `while` |

## 5-1-4 無限ループは更新忘れで起きる

> **条件を偽にする更新を書き忘れると、ループは止まらなくなる**

ループを書き始めると、誰でも一度はブラウザーを固まらせます。止まらない繰り返しを **無限ループ** といい、原因はほぼ毎回同じです。

```js
let count = 0;
while (count < 3) {
  console.log("処理中");
  // count += 1; を忘れた!
}
```

countがずっと0のままなので、条件が永遠にtrueです(このコードは実行しないでください)。点検ポイントは「**条件の中の変数を、本体の中で動かしているか**」です。

起きてしまったら、タブ(またはブラウザー)を閉じて強制終了すれば大丈夫です。なお、forは更新欄が構文に組み込まれているぶん、whileより更新を忘れにくい形です。

## 5-1-5 breakとcontinueで流れを変える

> **breakはループ全体を抜け、continueはその回だけ飛ばす**

「見つかったら探すのをやめたい」「空の行だけ飛ばしたい」 — 全周を律儀に回るだけでは足りない場面のための制御が2つあります。

- **break** — switchで学んだものと同じ「そこで抜ける」。以降の周回ごと終了します
- **continue** — その周の残りを飛ばして、次の周へ進みます

```js
const inputs = ["佐藤", "", "鈴木"];
for (const name of inputs) {
  if (name === "") {
    continue;  // 空の入力は飛ばす
  }
  console.log(`${name}さん`);
}
```

```js
const members = ["佐藤", "鈴木", "高橋"];
for (const member of members) {
  console.log(`確認: ${member}`);
  if (member === "鈴木") {
    break;  // 見つけたので打ち切り
  }
}
```

上は空文字スキップ、下は検索の打ち切りです。「全部やめる(break)」と「今回だけやめる(continue)」の対比で覚えてください。

## もっと知りたい人へ

- `do...while` という「先に1回実行してから条件を見る」変種もあります。出番は多くないので、読めれば十分です
- 配列の全件処理には、関数を学んだあとに `forEach` や `map` といったメソッドの書き方も出てきます。まずfor...ofで確実に書けることが土台です

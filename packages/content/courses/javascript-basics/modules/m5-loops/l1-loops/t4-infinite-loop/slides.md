# 5-1-4
# 無限ループは更新忘れで起きる

JavaScript入門研修 — Module 5 / レッスン5-1

<!-- ノート: ループ最大の事故を安全に予習するトピックです。実際に踏ませるかは環境次第で判断。 -->

---

## なぜ必要か

- ループを書き始めると、誰でも一度はブラウザーを固まらせる
- 原因はほぼ毎回同じ
- 事故の形を先に知っていれば、慌てず直せる

<!-- ノート: つかみ。「タブが応答しなくなった」は通過儀礼ですが、原因は1種類だと安心させます。 -->

---

## 結論

**条件を偽にする更新を書き忘れると、ループは止まらなくなる**

- 止まらない繰り返しを **無限ループ** という
- whileの本体には「条件に近づく更新」が必ず要る

<!-- ノート: 結論。「条件の中の変数を、本体の中で動かしているか」が点検ポイントです。 -->

---

## 失敗のコード

```js
let count = 0;
while (count < 3) {
  console.log("処理中");
  // count += 1; を忘れた!
}
```

- countがずっと0のままなので、条件が永遠にtrue

<!-- ノート: このコードは実行しないよう注意書きを添えます。読んで原因を指摘できれば十分です。 -->

---

## 起きてしまったら

- タブ(またはブラウザー)を閉じて強制終了する
- 直す: 条件の中の変数が、本体で更新されているか見る
- forは更新欄が構文に組み込まれているぶん、忘れにくい

<!-- ノート: 関連枠。対処法(タブを閉じる)を知っているだけで心理的安全性が違います。 -->

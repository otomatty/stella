# 5-1-1
# for...ofで配列を順に処理する

JavaScript入門 — Module 5 / レッスン5-1

<!-- ノート: ループの主役をfor...ofに置きます。配列と組で使う一番出番の多い形です。 -->

---

## なぜ必要か

- タスクが3件なら3回書けばよいが、100件なら?
- 配列の中身「全部」に同じ処理をしたい
- 件数が変わっても書き直さないコードにしたい

<!-- ノート: つかみ。tasks[0], tasks[1], tasks[2]...と書き並べる無理さを見せます。 -->

---

## 結論

**for...ofは、配列の要素を先頭から1つずつ取り出して繰り返す**

- 同じ処理を繰り返す仕組みを **ループ** という
- **for...of** は配列専用の入り口。1周を **繰り返し** と呼ぶ

<!-- ノート: 結論。「配列の全部に対して」はfor...of、と型で覚えます。 -->

---

## 最小のコード

```js
const tasks = ["見積作成", "レビュー", "報告書"];
for (const task of tasks) {
  console.log(`TODO: ${task}`);
}
```

- 1周ごとに `task` へ要素が順に入り、ブロックが実行される

<!-- ノート: taskは1周ごとに作り直されるのでconstでよい、という点は質問が出たら答える程度で。 -->

---

## 形を分解する

```text
for (const 受け取る変数 of 配列) {
  1周ぶんの処理
}
```

- 変数名は自由。配列が `tasks` なら単数形の `task` が読みやすい

<!-- ノート: 複数形の配列から単数形で1つずつ受け取る、という命名の型も一緒に伝えます。 -->

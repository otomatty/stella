# 5-1-3
# whileは条件が続く限り繰り返す

JavaScript入門研修 — Module 5 / レッスン5-1

<!-- ノート: 回数不定のループです。forとの使い分け(回数が決まっているか)が軸です。 -->

---

## なぜ必要か

- 「残高が0になるまで引き落とす」— 何回かは事前に分からない
- forは回数が決まっている繰り返し向き
- 「条件が満たされている間ずっと」を素直に書きたい

<!-- ノート: つかみ。回数ではなく状態で終わりが決まる処理、という括りで例を挙げます。 -->

---

## 結論

**whileは、条件が真のあいだ繰り返し続ける**

- **while**(条件) { 処理 } の形
- 毎周の頭で条件を調べ、falseになったら抜ける

<!-- ノート: 結論。条件はifと同じ書き方なので、新しい文法はwhileという単語だけです。 -->

---

## 最小のコード

```js
let balance = 1000;
while (balance >= 300) {
  balance -= 300;
  console.log(`引き落とし後: ${balance}円`);
}
// => 700円 → 400円 → 100円で終了
```

<!-- ノート: 300未満になった周の頭で条件がfalseになり抜ける、という終了のタイミングを確認します。 -->

## forとの使い分け

| 繰り返しの種類 | 書き方 |
| --- | --- |
| 配列の全要素に | `for...of` |
| 決めた回数だけ | `for` |
| 条件が続く限り | `while` |

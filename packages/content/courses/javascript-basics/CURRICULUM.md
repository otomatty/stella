# JavaScript 入門研修 カリキュラム

SES 未経験者向けの JavaScript 入門講座です。1 トピック = 覚えることが 1 つ(takeaway 1 文)の粒度で、
HTML/CSS で作った静的ページに動きを付けるところまでを、言語の基礎(変数・文字列・配列・分岐・ループ・関数)から
イベントと DOM 操作まで通します。
構成は [MDN Learn web development の Core Scripting](https://developer.mozilla.org/ja/docs/Learn_web_development/Core/Scripting) の本経路に合わせています(終端は Events + DOM scripting)。

## 終了時の目標

終了時、受講者はテキストエディタとブラウザーだけで、静的ページに動きを付けられます。

- HTML の末尾に `script` を置き、`const` / `let`・文字列・配列・`if` / `else`・`for...of`・関数を書ける
- `querySelector` で要素を取り、`addEventListener` で click / keydown を聞ける
- `textContent` と `classList` で画面を変え、`createElement` + `appendChild` / `remove` と `preventDefault` までできる
- HTML の `onclick` 属性は使わない。TypeScript は書かない

## 前提

- **必須:** `html-css-basics`(HTML と CSS の基本。JavaScript の経験は不要)
- **任意:** `page-composition-basics`(後続の APG 対話 UI 講座の前には推奨。本講座のゲートではない)
- **前提にしない:** `typescript-basics` / `modern-css-basics` / `ui-components-basics`

## 進め方と範囲

- Web(LMS): スライド視聴・まとめ・確認クイズ(合格点 80)
- 手を動かす部分: `practice.md` の「手元で試す」。テキストエディタで書いて、ブラウザーで開いて確かめる
- コード演習(VS Code 拡張の採点)は **この講座にはありません**。採点基盤の JS ランナー(QuickJS)には DOM / `document` が無いため、`course.json` に `exercises` を置きません
- `script` は `body` 末尾の古典形で書きます。`type="module"` は `file://` で CORS が起きるため必須にしません

対象外:

- TypeScript / 型注釈 / Playground
- `fetch` / Promise / async / await(Network requests は DOM のあとの範囲)
- JSON / House data UI
- React その他フレームワーク
- APG ウィジェット実装(タブ・メニュー・ダイアログの JS)。本講座は **解錠** まで
- インライン `onclick` を推奨する書き方
- `getElementById` を本線にする書き方(`querySelector` を本線にする)
- Node.js、Canvas / WebGL、`var`、constructor / `this` の本講義

## この講座の進め方

- 各レッスンは **スライド → まとめ → 確認クイズ** の順で並びます
- `practice.md` の「手元で試す」はテキストエディタとブラウザーだけで完結します。自動採点はありません
- スマートフォンからでも、スライドとまとめと確認クイズだけで最後まで進められます
- MDN の課題記事に相当するハンズオンは、トピックにせず該当レッスンの `practice.md` に置きます
  (文章ジェネレーター = レッスン3-1、買い物リスト = レッスン8-3)。終端の手元は買い物リストです
